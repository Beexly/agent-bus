# Where to watch the agents

Motif stays the lead. A dashboard does not accept work and does not promote memory.

## Use what you already have

Orca, desktop plus the mobile companion. Agent Activity View (v1.4.198 and later) shows waiting, working, monitoring, and done, and opens the agent chat. That is the real-time view of the hands. It cannot freeze the fleet. The kill switch is still `bus/FREEZE` on the Windows box. Repo: https://github.com/stablyai/orca

The bus itself. https://github.com/Beexly/agent-bus is the record. Watch `FLEET-STATUS.md` and `bus/<project>/{inbox,claimed,done,quarantine}`. It is not a live token stream. It is what remains when Motif's VM drops offline.

Hindsight UI, after the pin is running on the Motif VM only: `http://127.0.0.1:9999` on that VM. That is memory, not the org chart. Quarantine still applies. Do not open port 9999 to the internet.

## Do not install as the brain

AI Maestro and Slaw can be read-only later. They are not the lead. Paperclip, Eyrie, CrewAI, Agno, AutoGen, and LangGraph stay out. Orca's experimental dashboard popout is the same product you already run, not a second orchestrator.
