# arxiv-program/research/2026-09-21/arxiv-deep/0240-the-reaction-to-news-in-live.md
## What it is (1-2 sentences)
Ötting, Michels, Langrock & Deutscher (arXiv:2108.00821v2, 2021): the first stake-level (not odds-level) study of live-betting market response to news — a zero-adjusted-gamma state-space model of 1 Hz bookmaker stakes across 306 Bundesliga 2018/19 matches, testing how betting activity reacts to goals by surprise level and to outcome uncertainty. File verdict: ADAPT — overreaction-to-surprising-news finding is directly GSE-relevant market microstructure; adapt the ARX(1)+ZAGA design to odds-derived proxies (line movement as handle proxy) since the stake data is proprietary.

## Key metrics/methods (formulas where given, else "not specified")
- Baseline SSM: observed stakes y_t ~ ZAGA(μ_t, σ, π_t) (zero-adjusted gamma = gamma + point mass at zero). μ_t = exp(α₀ + g_t); latent state g_t = φ g_{t−1} + η_t, η_t ~ i.i.d. N(0, σ_g²), |φ|<1 (stationary), g₁ ~ N(0, σ_g/√(1−φ²)). π_t = π if open_t=1, =1 if market closed (books suspend after goals/red cards).
- Covariates in state-dependent process: μ_t = exp(α₀ + α₁·eloteam + α₂·eloopp + Σ ω_j·kickoff_j + g_t); π_t = logit⁻¹(γ₀ + γ₁·gini_t + γ₂·gini_t² + γ₃·int_t + γ₄·gini_t·int_t + γ₅·gini_t²·int_t) (quadratic + interactions on outcome certainty).
- Final ARX(1) state process: g_t = φ g_{t−1} + β₁·halftime_t + β₂·ginidiff_t + Σ_{j=3..5} β_j·(1/goalteam^{(j)}_t) + σ_g η_t, where j=3/4/5 = surprising/slightly-surprising/unsurprising goals; 1/goalteam encodes rapid decay (effect strongest right after the goal).
- General SSM form: y_t = a(g_t, ε_t), g_t = b(g_{t−1}, η_t) (eq. 1).
- ZAGA: f(y_t) = π_t if y_t=0; (1−π_t)h(y_t) if y_t>0, h = gamma density parameterized by (mean μ_t, SD σ).
- Extended mean: μ_t = exp(α₀ + α₁·eloteam + α₂·eloopp + ω₁·friday + ω₂·saturdayaft + ω₃·saturdayeve + ω₄·sunday + g_t).
- Zero probability: π_t = logit⁻¹(γ₀ + γ₁·gini_t + γ₂·gini_t² + γ₃·int_t + γ₄·gini_t·int_t + γ₅·gini_t²·int_t) if open_t=1; π_t=1 if open_t=0.
- Likelihood integral: ℒ(θ) = ∫…∫ f(g₁)f(y₁|g₁) ∏_{t=2}^T f(g_t|g_{t−1}) f(y_t|g_t) dg_T…dg₁; discretized: ℒ(θ) ≈ h^T Σ…Σ f(b⋆_{i₁})f(y₁|…)∏ f(b⋆_{i_t}|g_{t−1}=b⋆_{i_{t−1}}) f(y_t|g_t=b⋆_{i_t}).
- HMM recursion: ℒ_approx = δP(y₁)ΓP(y₂)ΓP(y₃)…ΓP(y_T)1 with δ_i = h f(b⋆_i), γ_{ij}^{(t)} = h f(b⋆_j | g_{t−1} = b⋆_{i_{t−1}}).
- Estimation: Kitagawa (1987) midpoint-rule discretization of the continuous state into m=150 bins over [−4, 4] → m-state HMM; likelihood via forward algorithm, O(Tm²); numerically maximized in R via nlm() with reparameterization, underflow scaling, many random starts (local maxima); full-data likelihood = product of 612 independent series likelihoods. Approximation validated virtually exact for m≥50 (m=100 conservative).
- News features: halftime_t, ginidiff_t (gini_t − gini_1; negative = more uncertain than at kickoff), 1/goalteam^{(j)}_t for j ∈ {surprising, slightly, unsurprising}.
- Goal-surprise classification by pre-goal odds: surprising (odds >4.00, implied win prob <25%), slightly surprising (odds 2.00–4.00, 25–50%), unsurprising (odds <2.00, >50%).
- Gini of bookmaker implied probabilities as outcome-certainty proxy.

## Data sources named
- Stakes: 1 Hz bookmaker stakes (aggregated to 15-second intervals) on match-outcome bets (home/away win) for all 306 German Bundesliga 2018/19 matches, from a large European bookmaker. 306 matches × 2 teams = 612 time series; 274,778 intervals total; each match ≥420 intervals (90 min + 15 min halftime + injury time). 969 goals observed, avg 3.2/match. Stakes multiplied by undisclosed constant (masked). Proprietary — unreplicable, no public path.
- Static covariates: clubelo.com Elo ratings (mean 1675, SD 104.2, range 1469–1980). Kickoff-time dummies: friday 0.095, saturdayaft 0.513, saturdayeve 0.101, sunday 0.216, weekday 0.075 (reference).
- Descriptives (Table 1): stake mean 3.755, SD 8.347, min 0, max 1027 (scaled units); open 0.908; halftime 0.149; remaining intervals int 210.1±121.7; goalteam 47.85±79.22; gini 0.544±0.297; ginidiff 0.205±0.292 (range −0.794 to 0.916).
- References: Kitagawa (1987); Croxson & Reade (2014, halftime activity); De Bondt & Thaler (1985, overreaction biases); Choi & Hui (2014, in-play soccer overreaction); Durand et al. (2021, "Behavioral biases in the NFL gambling market" — direct NFL citation in the paper).
- No code links, no data links.

## Findings (numbers and facts, not vibes)
- Baseline model (Table 2): φ̂ = 0.985, 95% CI [0.984, 0.986] — very strong serial correlation in latent market activity; σ̂_g = 0.227 [0.223, 0.230]; α̂₀ = 0.642 [0.590, 0.693]; σ̂ = 0.872 [0.870, 0.873]; π̂ = 0.074 [0.072, 0.075] matching empirical zero proportion 0.072.
- State-dependent covariates (Table 3): α̂₁ (eloteam) = 0.439 [0.393, 0.485] — better teams attract more money; α̂₂ (eloopp) = −0.255 [−0.300, −0.211]; ω̂₂ (saturdayaft) = −0.260 [−0.431, −0.088] — stakes higher when no parallel matches (less attention dilution). Zero-probability: γ̂₁ (gini) = −10.054, γ̂₂ (gini²) = 14.605, γ̂₃ (int) = −0.542, γ̂₄ = 3.638, γ̂₅ = −4.291 — bettors prefer uncertain matches; P(zero stake) rises with Gini, especially late in matches.
- Final model (Table 4, news in state process): φ̂ = 0.968 [0.967, 0.970]; σ̂_g = 0.202 [0.198, 0.207]; β̂₁ (halftime) = 0.002 [0.000, 0.005] — slightly elevated halftime activity (agrees with Croxson & Reade 2014); β̂₂ (ginidiff) = −0.094 [−0.099, −0.089] — activity rises when the match becomes MORE uncertain than at kickoff; β̂₃ (surprising goal) = 0.531 [0.494, 0.567]; β̂₄ (slightly surprising) = 0.218 [0.176, 0.261]; β̂₅ (unsurprising) = 0.034 [0.001, 0.067]. Headline: bettors overreact to surprising news — activity on the scoring team jumps even though odds have already shortened; consistent with overconfidence/overreaction biases.
- Key ratio: surprising-goal effect is more than 15× the unsurprising effect (0.531 vs 0.034); unsurprising goals barely move activity.
- Model selection: SSM vs no-state regression ΔAIC = 217,117 in favor of the state-space formulation (enormous — latent activity state is doing nearly all the explanatory work).
- Model checks: 3-minute post-goal stake sums match simulated expectations across goal categories; only notable mismatch: actual stakes slightly BELOW model expectation for slightly surprising goals. Zero-interval check: model predicts no stakes in 7.3% of intervals vs true 7.2%; correctly predicts 96.5% of intervals where stakes were placed. Example match Dortmund vs Schalke: actual vs simulated stake paths visually match.
- Assumptions/limitations flagged: 612 series modeled independently — including the two series of the same match (home bets and away bets independent); authors flag this and propose bivariate/VAR extension but don't fit it. Continuous latent market-activity granularity (no discrete regimes). Gini of implied probabilities as outcome-certainty proxy. 1/goalteam decay form. m=150 binning near-exact (stability validated under increased m/width).
- No out-of-sample test: full-sample ML on all 612 series (274,778 obs); validation is in-sample simulation checks only. AIC only against the no-state variant.
- Endogeneity: stakes contemporaneous with odds-derived covariates (gini, ginidiff, surprise); odds and stakes co-evolve — direction of causation (news → stakes vs stakes → bookmaker odds adjustment) not identified.
- External validity: single book, single league-season (Bundesliga 2018/19, 306 matches). Soccer live betting is 55%+ of European handle with 1 Hz data; NFL in-play structure differs (commercial breaks, fewer/lumpier scoring, US books). Magnitudes (0.531 on scaled stakes) don't transfer.

ZAGA handles zero-inflation (many 1-minute windows with no line move). Effort ~3–4 days (in-play odds capture + ARX-ZAGA harness + surprise classification).
