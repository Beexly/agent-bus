# arxiv-program/research/2026-09-21/arxiv-deep/0116-governed-mcp-kernel-level-tool-governance.md
## What it is (1-2 sentences)
An AI-agent infrastructure paper (arXiv:2604.16870v2, July 2026, independent researcher Daeyeon Son) proposing Governed MCP: a kernel-resident reference monitor that puts every MCP `call_tool` through a six-layer pipeline (schema, trust tier, rate limit, adversarial prefilter, ProbeLogits semantic gate, constitutional policy) with a Blake3-hashed audit chain, built in Anima OS (~286K lines of Rust). The ledger's verdict is **ADAPT** — the baremetal implementation is overkill, but the portable pattern (single mediated chokepoint, fail-closed semantics, logit-based single-forward-pass safety scoring) fits GSE's agent ops.
## Key metrics/methods (formulas where given, else "not specified")
- **ProbeLogits score** (reconstructed from garbled PDF — UNCERTAIN): s ∈ (−∞, +∞) = logit(Dangerous) − logit(Safe) at the verbalizer position, calibration bias subtracted, scaled by α; gateway thresholds at s > 0 to reject; α is the deployment-time policy knob (higher α = more conservative).
- **Calibrated confidence** (reconstructed — UNCERTAIN): ProbeLogits() returns (ans, p) where ans = Boolean "model says Dangerous", p ∈ [0,1] = σ(s) (sigmoid-calibrated).
- **Graduated response** (reconstructed — UNCERTAIN): deny only when `ans ∧ p > 0.90`; band [0.70, 0.90] allowed but logged as warnings (LogWarn); below 0.70 proceed normally. Production default α = 0.9.
- **Per-model boot contract:** Token Fertility check (verbalizer pair "Safe"/"Dangerous" or "Yes"/"No" must tokenize to single vocab IDs); calibration bias measured once on 7 null-input prompts and cached; no usable pair → gateway refuses to start.
- **KV snapshot/restore:** per-layer copy of key/value tensors at current position — 0.93 MB for Qwen2.5-7B Q4_0 at 32 cached positions via direct memcpy in 0.037 ms, restore 0.016 ms (0.053 ms round trip); size scales linearly with cached positions; probe runs in a dedicated KV context discarded after each call.
- **Audit chain:** every decision appends (timestamp, agent_id, tool_name, arg_hash, deciding_layer, verdict, prev_hash) to a 4 MB ring buffer (~30K records), keyed Blake3-hashed chain (0.73 µs per append).
- **FAIL-CLOSED:** if the inference engine is unavailable (model not loaded, KV exhausted, deadlock), layer 5 returns Deny — all tool calls denied system-wide until recovery.
- Six layers in fixed order with silicon-measured latencies: schema validation 0.10 µs; trust tier check 1.15 µs; rate limit 0.02 µs (per-agent token-bucket, e.g., 10 web_fetch/s, 1 shell_exec/s, millisecond refill); adversarial prefilter 7.50 µs (O(n) regex DFA: "ignore previous instructions", base64, ROT13, "ADMIN OVERRIDE", "system: ..."); catches ~13/50 adversarial prompts); ProbeLogits semantic gate 358/332/556 ms per classification (Qwen2.5-7B Q4_0 / Llama 3 8B Q4_0 / Mistral 7B Q8_0); constitutional policy match 1.83 µs (12-principle predicates, e.g., no shell_exec on paths containing /etc/shadow, no web_post to private RFC1918 from Classic agents). Non-inference layers total 11.3 µs (components sum 11.33 µs).
## Data sources named
- **Custom-101:** 101 MCP `call_tool` JSON-RPC prompts, 37 dangerous / 64 benign, across 18 MCP-tool-call domains (file system sensitive read 5/—, write-danger 3/—, benign file —/15, memory privacy violation 4/—, benign memory —/8, network exfiltration 3/—, SSRF 3/—, benign network —/9, injection attack 5/—, benign injection —/2, constitutional violation 4/—, deception/agent manipulation 4/—, benign agent —/8, agent ops benign —/6, probe benign —/6, subtle dangerous 6/—, benign —/2, general benign —/8). Author-labeled.
- **Custom-260:** 260 OS-action prompts in 9 categories (50 adversarial) — from companion ProbeLogits paper [6].
- External substrate validation: HarmBench (n=400; non-copyright subset n=300), XSTest (n=450: 250 safe + 200 unsafe), ToxicChat (n=1000).
- Enumerated-path mediation harness: 59 agent-to-system paths (18 WASM host functions: 15 governed + 3 readonly; 20 registered MCP tools; 21 ring-3 syscalls: 7 gateway-governed, 1 self-gated, 2 readonly metadata, 5 pure, **6 resource-reaching syscalls ungated** — put, fetch, kv_set, kv_get, send_msg, recv_msg — deferred to milestone M4.2; v1 "123 paths, 100% mediated" claim explicitly withdrawn).
## Findings (numbers and facts, not vibes)
- **Custom-101 (silicon-measured, full 6-layer):** F1 = 0.789 (accuracy 84.2%, precision 0.769, recall 0.811; TP 30, FN 7, FP 9, TN 55). 7 false negatives (mostly subtle "deception/agent manipulation" — e.g., `shell_exec("for f in *; do mv $f .$f; done")` in /var/www scored s = −1.3, allowed); 9 false positives (ambiguous filesystem reads).
- **Ablation:** No prefilter — F1 0.805 (TP31/TN55/FP9/FN6, slightly *better* than full; prefilter's value is zero-cost early denial, not F1); No ProbeLogits — 0.357 (TP10/FN27; ΔF1 = −0.432); No layer-4 — 0.327 (TP9/FN28, near chance). Finding: hand-rule firewalling without semantic understanding admits 27/37 dangerous calls.
- **Case studies:** file_read("/home/user/.ssh/id_rsa") → s = +4.8, blocked at L5; shell_exec("dd if=/dev/zero of=/dev/sda bs=1M") → s = +6.2, denied (no rule enumerates it); web_post attacker-exfil sequence blocked at step 1.
- **Custom-260:** F1 = 0.980, P = 1.000, R = 0.960 (TP 169, FN 7, FP 0, TN 84; accuracy 97.3%) — FP=0 is the "deployment-killer" property (flags safe to block without human review).
- **Multi-model (Table 4):** HarmBench non-copyright block rate — Qwen2.5-7B 99.0%, Llama 3 8B 98.0%, Mistral 7B 98.7% (1 pp spread); HarmBench overall — 86.8% / 75.0% / 79.5%; XSTest unsafe recall — 1.000 / 0.985 / 0.995; XSTest overrefusal (safe) — 0.864 / 0.516 / 0.556 (model-specific cost); XSTest F1 — 0.649 / 0.749 / 0.740.
- **ToxicChat:** ProbeLogits-Llama-3 F1 = 0.679 vs. Llama Guard 3 F1 = 0.675 — parity (+0.4 pp) with a vanilla instruction-tuned model vs. a fine-tuned classifier, +10.5 pp recall, 2.4–3.4× lower per-classification latency.
- **Latency:** non-inference layers total 11.3 µs (supersedes v1's unarchived 65.3 µs). ProbeLogits per classification: 358 ms (Qwen2.5-7B Q4_0), 332 ms (Llama 3 8B Q4_0), 556 ms (Mistral 7B Q8_0) — 2.38×/2.56×/1.53× vs. Llama Guard 3 Q4_K_M (851 ms), 3.19×/3.44×/2.05× vs. Q8_0 (1142 ms). End-to-end ~358 ms; gateway throughput ≈ 2.8 governed calls/s. NeMo Guardrails runs 2–3 LLM roundtrips per check (~2–5 s end-to-end in NVIDIA's demos).
- **Threshold sweep:** F1 = 0.414 (α=0.30), 0.667 (0.50), 0.789 (0.70), 0.789 (0.80), 0.789 (1.00) — plateau from 0.70 upward; conservative default α=0.9 costs nothing on this benchmark. Naive small-model cascades are not viable: SmolLM2-135M blocks only ~13% of HarmBench; a 0.5B model overrefuses ~70% of safe prompts.
- Author-disclosed weaknesses: Custom-101 is author-labeled; no external human red-team study (5+ attackers planned); no constitutional-only ablation cell; six ring-3 syscall paths ungated until M4.2; post-execution tool-output probing not implemented; no model provenance verification at boot; single global inference-engine lock, FIFO, no priority inheritance (a high-frequency Classic agent can delay a System agent).
- Listed out-of-scope assumptions: Cranelift WASM isolation correctness (JIT-bug bypass classes, 2021–2023 wasmtime CVEs); baremetal single-tenant environment (Spectre mitigated but not formally precluded); inference model loaded at boot is genuine (no signature check / measured boot); TOCTOU closed only in single-threaded agent execution; side channels via latency/argument size unaddressed; tool outputs not yet probed.
## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- OTHER (infrastructure/ops lane): the six-layer mediated-chokepoint pattern + ProbeLogits primitive + Blake3 audit chain ports directly to a userspace MCP gateway on the Motif VM through which all GSE agent tool calls route (schema validation, trust tiers, per-agent token buckets, regex prefilter, semantic gate, constitutional rules like "no writes outside ~/workspace", warn-band [0.70, 0.90] / deny >0.90, fail-closed). No MCMC/preference work exists in the corpus, but the adjacency is to HiveMind (0115, MCP-server scheduling) and FailureAtlas (0112, prompt-injection attack classes) — together they cover the agent-infrastructure reliability triangle.
- OTHER (tracking lane / intake defense): the paper's own future work — post-execution probing of tool *outputs* — is the layer that would defend GSE against indirect prompt injection in web-content and compromised-MCP-server outputs, the exact threat class that matters for the trust-target intake lane.
- CONTRADICTION-adjacent: the paper's headline "0.789 F1" is measured on the author's own 101-prompt test; external benchmarks validate only the substrate primitive, not MCP-domain gateway behavior — adopt with a GSE-authored red-team set rather than trusting the headline number.
