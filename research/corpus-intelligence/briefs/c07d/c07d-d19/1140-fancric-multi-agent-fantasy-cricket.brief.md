# arxiv-deep/1140-fancric-multi-agent-fantasy-cricket.md
## What it is (1-2 sentences)
Full-read ledger of arXiv:2410.01307 (FanCric: Multi-Agentic Framework for Crafting Fantasy 11 Cricket Teams, Bhatnagar 2024). Verdict: ADAPT — the six-agent pipeline (research → career profile → form assessment → strategy → selection → evaluation) is a usable architecture pattern for GSE's NFL DFS optimizer, but the evidence is a single IPL match (n=1) with no significance testing, so the ledger says adopt the architecture, not the cricket specifics.
## Key metrics/methods (formulas where given, else "not specified")
No equations stated (LLM-prompted system, not a statistical model). Architecture: six LLM agents orchestrated via LangGraph (LangChain): Supervisor, Researcher (venue/home-away, weather both innings: temp, wind, cloud cover, dew, humidity; pitch reports; win odds), Career Profiler (career stats summary + qualitative strengths/weaknesses, relative rating), Form Assessor (recent form rating, home/away, batting first/second splits), Strategizer (team records in conditions, strengths/weaknesses, social-media fantasy tips), Selector (rule compliance via agentic search, generates n teams, iterative refinement loop reviewed by GPT-4o — a stronger model than the GPT-4o-mini used for all other agents — chain-of-thought rationales and team names), Evaluator (post-match fantasy-point scoring backtest). Prompt-engineering baseline: gpt-4o-mini, temperature=1, few-shot (2 examples), 10 teams. Key assumptions: LLMs deprived of player names (ESPN Cricinfo player IDs only) make unbiased ratings; prompt-engineered baseline is a fair comparator; one IPL match suffices for an exploratory signal; percentile rank vs crowd entry distribution measures "winning" quality; top-67% of entries getting entry-fee refund defines "win" (Dream11 payout structure). Evaluation metrics: total points, percentile rank vs crowd distribution, hit rate vs "Dream Team" (optimal ex-post lineup), win rate (entry fee returned).
## Data sources named
- One IPL 2023 match: Lucknow Super Giants vs Mumbai Indians, May 16, 2023 (63rd of 72 games), Bharat Ratna Shri Atal Bihari Vajpayee Ekana Cricket Stadium, Lucknow.
- 13.8M Dream11 contest entries scraped (14 PDF files from Dream11 mobile app via Android emulator), 12.7M unique after dedup; schema: 11 players + captain + vice-captain per team + final fantasy points.
- Player data: IPL career stats through 2022 season + 2023 season-to-date from Kaggle and official IPL site; ESPN Cricinfo player IDs used (not names) to avoid LLM name bias.
- Weather: open-meteo.com API; pitch reports: Tavily agentic search of news; odds: oddsportal.com.
- Frameworks: LangGraph/LangChain, GPT-4o-mini + GPT-4o, Tavily search, open-meteo API, pyspark + pdfplumber. No code/data release stated.
## Findings (numbers and facts, not vibes)
- Crowd (12.7M entries): mean 501.54, std 89.02, median 512, min 0, max 811.5; Dream Team (ex-post optimal) 832.5; distribution left-skewed, KS statistic 0.14, p=0.0 (non-normal).
- Prompt engineering (n=10): mean 512.9 (50.4 percentile), win rate 70%; best team 634 points (95.1 percentile).
- FanCric (n=10): mean 528.55 (58.6 percentile), win rate 80%; best team 644 (96.3 percentile), "Strategic Strikers" with Marcus Stoinis (C), 6/11 Dream Team players.
- Ablation results: n=20 — FanCric avg points 528.5 (prompt 481.6), avg rank 56.9 (42.9), win% 75% (50%), highest rank 99.9 percentile with 722 points (prompt 95.9). n=15 — FanCric 517.9/54.1/66.7%/99.1 vs prompt 498.4/49.1/66.7%/99.3. n=5 — FanCric 507.7/53.0/60%/86.3 vs prompt 501.7/55.1/80%/86.1. n=1 — FanCric 522.5/55.6/100%/55.6 vs prompt 535.5/61.9/100%/61.9 (only n where prompt engineering won).
- FanCric beat crowd mean (501.5) and median (512) at every n except n=5.
- Limitations flagged: n=1 match (no confidence intervals, no multiple-comparison correction across 6 agents × 5 ablation settings); Selector used GPT-4o for refinement vs GPT-4o-mini baseline (model-strength confound, not a pure architecture effect); temperature=1 both methods (high variance, no repeats reported); retrospective with pitch/weather/news availability at generation time not rigorously controlled; Dream Team comparison is ex-post optimal (harsh, uninformative about EV); salary-cap optimization (core of NFL DFS) absent — Dream11's constraint is credit-based quotas, not dollar salary, and GSE's MILP optimizer (ledger 0010) already addresses the harder constrained problem.
## Intelligence connections
- SCHEME: The agent pipeline maps to the weekly DFS process system program — a "DFS context agent" layer (GameContext, FormProfiler, NarrativeStrategist, ConstraintChecker) in front of GSE's existing MILP optimizer, with agents emitting auditable JSON boost/penalty multipliers (e.g., "WR vs bottom-5 shadow corner: −8% projection") fed into the projection vector pre-optimization; Strategist outputs also feed the weekly DFS packet narrative.
- QB-BEHAVIOR / COACHING: The FormProfiler role (last-4-week fantasy points, target share trends, snap counts from nflverse) is the template for QB-behavioral and coaching-tendency form intake — recent-form splits as structured agent inputs rather than vibes.
- TRUST-SIGNAL: The ledger's acceptance gate requires every per-player multiplier to be traceable to a cited data source — no LLM-invented "narratives" — which is the trust-target intake discipline: qualitative context enters only as auditable, source-tagged adjustments.
- OTHER: The model-strength confound (GPT-4o selector vs GPT-4o-mini baseline) is a standing calibration warning for any GSE agent-vs-baseline A/B: match model tiers before claiming an architecture effect.
