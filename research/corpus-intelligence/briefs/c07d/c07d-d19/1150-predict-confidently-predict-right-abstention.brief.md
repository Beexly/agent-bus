# arxiv-deep/1150-predict-confidently-predict-right-abstention.md
## What it is (1-2 sentences)
Full-read ledger of arXiv:2501.08397v1 (Gayen, Pal, Manwani, Sharma 2025): coverage-constrained abstention (reject option) for continuous-time dynamic graphs, grafted onto temporal GNN encoders (TGN, GraphMixer, DyGFormer). Verdict: ADAPT — the coverage-constrained abstention objective (select head + coverage penalty + auxiliary full-data loss) is directly portable to GSE's pick-selection/abstention lane, which the program's existing-research map names as an explicit gap.
## Key metrics/methods (formulas where given, else "not specified")
Objective (eq. 1): max_{f,q} P(f(x)=y | q(x)=0) = max_{f,q} P(f(x)=y | a(x) ≤ θ), θ ∈ (0,1).
Link-prediction loss (eq. 2): L^E_t(f,q) = r̂(f,q|E_t) + λΨ(c − φ̂(q|E_t)), Ψ(b) = max(0,b)².
Empirical selective risk (eq. 3): r̂(f,q|E_t) = Σ_{(u,v,t)∈E_t} ℓ(f(z_u(t),z_v(t)), y_{E_t})(1 − q(z_u(t),z_v(t))) / (|E_t| φ̂(q|E_t)).
Empirical coverage (eq. 4): φ̂(q|E_t) = (1/|E_t|) Σ_{(u,v,t)∈E_t} (1 − q(z_u(t),z_v(t))).
Combined (eq. 5): L^E_t = α L^E_t(f,q) + (1−α) L^E_{h,t} (auxiliary head = plain BCE on ALL samples, no coverage gating, so the model still sees rejected samples).
Node classification: mirror-image L^V_t (eqs. 6–9); imbalance-weighted auxiliary loss (eq. 10): L^V_{h,t} = β L^V_{h,minor,t} + L^V_{h,major,t}, β > 1.
Architecture: prediction head f(x) + abstention head q(x) ∈ {0,1} producing scalar score a(x) ∈ [0,1]; scores sorted on validation, threshold θ chosen to hit target coverage c; abstain iff a(x) > θ. Encoders: TGN (memory + GRU updater + 2 graph-attention heads), GraphMixer (MLP-Mixer link encoder with cos(ωt) time encoding + neighbor mean-pool node encoder), DyGFormer (transformer + neighbor co-occurrence encoding), via DyGLib.
Training hyperparameters (verbatim): Adam (link pred; node classification on Wikipedia) / SGD (Reddit node classification), 75 epochs, early stopping patience 10, batch 200, λ=32, α=0.5, 100-dim time encoding, 172-dim output; 5 seeds (0–4), mean ± std reported. Class imbalance: searched β ∈ [2,100]; best β = 2 or 5, results degrade for β ≥ 10 (Table 5). Coverage sweep: 100%, 90%, 80%, 70%, 60%, 50% (θ re-set per coverage on validation-sorted scores). Metrics: AP and AUC-ROC for link prediction under three negative-sampling strategies (random, historical, inductive NSS); AUC-ROC for node classification. Baselines: TGN and GraphMixer without reject option (= 100% coverage row), DyGFormer in appendix.
Stated/implicit assumptions: binary classification only; θ calibrated post-hoc on validation selection scores (not learned jointly); coverage constraint enforced only via quadratic penalty with fixed λ=32; auxiliary head's full-sample loss prevents collapse onto the easy subset; imbalance fix is a static scalar β, not adaptive; chronological 70/15/15 splits.
## Data sources named
Four public temporal-graph datasets (Appendix A, Table 4; source: Zenodo record 7213796, DyGLib). All are interaction streams (u, v, t), not sports: Wikipedia (1 mo of edits): 9,227 nodes, 157,474 links, 172-dim LIWC features, bipartite, Unix timestamps, 2 labels (217 banned = 0.14%); Reddit (1 mo of posts): 10,984 nodes, 672,447 links, 172-dim LIWC, bipartite, Unix ts, 2 labels (366 banned = 0.05%); Canadian Parliament (2006–2019, MPs' mutual "yes" votes): 734 nodes, 74,478 links, 1-dim features, non-bipartite, yearly; UN Trade (30 yrs, food/agri trade between 181 nations): 255 nodes, 507,497 links, 1-dim normalized trade value, non-bipartite, yearly. Only Wikipedia and Reddit carry node labels (used for node classification). No repo/code stated in paper.
## Findings (numbers and facts, not vibes)
- Transductive link-pred AP (Table 1, random NSS), TGN: Wikipedia 98.56 ± 0.06 (100%) → 99.88 ± 0.02 (60%); Reddit 98.63 ± 0.02 → 99.86 ± 0.04; UN Trade 64.87 ± 1.93 → 81.46 ± 1.81; Can. Parl. 74.14 ± 1.51 → 90.19 ± 3.50 (paper claims ≈16.05-point AP gain on Can. Parl.).
- Inductive link-pred AUC (Table 2, random NSS), TGN Reddit: 97.17 ± 0.04 (100%) → 99.73 ± 0.13 (60%), claimed ≈2.56-point gain.
- Node classification AUC (Table 3, TGN): Wikipedia 86.23 ± 3.30 (100%) → 89.78 ± 2.76 (60%, β=1) → 89.86 ± 2.52 (β>1); Reddit 63.08 ± 1.48 (100%) → 66.03 ± 3.45 (60%, β=1) → 69.58 ± 2.96 (60%, β=5) — the β=5 minority-weighting adds ≈3.55 points on the extreme-imbalance (0.05%) Reddit task.
- Performance peaks then declines as coverage keeps dropping; DyGFormer on UN Trade is erratic (AP 65.37 → 61.02 → 67.45 → 77.76 → 62.40 → 60.21 with std up to ±11.67) — abstention selection unstable there.
- Compute (Table 6, Can. Parl. link pred): TGN 9 s/epoch, 668 MB GPU; DyGFormer 91 s/epoch, 18,326 MB — abstention heads add negligible cost on top of the encoder.
- Leakage/limitations flagged: AP/AUC computed only on non-abstained samples (improvement with lower coverage is mechanically guaranteed — the ledger author's own reading); no comparison to plain softmax-threshold abstention or Monte-Carlo dropout; θ set post-hoc on validation so test-time realized coverage drifts (acknowledged in Appendix B); no abstention calibration (no coverage guarantee, unlike conformal methods); fixed λ=32, α=0.5 with no sensitivity analysis; DyGFormer instability suggests joint (f,q) training is fragile on some encoders/datasets; external validity to NFL is zero (user×page interactions) — the portable part is the selective-loss machinery, not the temporal GNN.
## Intelligence connections
- OTHER (calibration/sizing lane — the strongest connection): This directly fills gap item 4 of the existing-research map, "learning-to-abstain with coverage-risk curves" — abstention is absent from GSE's calibration stack (CQR / grouping loss / temperature scaling / LRD / ECE-by-slice). The mechanism: add a lightweight selection head g(x) alongside GSE's pick classifier, train selective risk + λ·max(0, c−coverage)² + (1−α)·BCE-on-all-samples starting at λ=32, α=0.5, coverage targets {0.9, 0.8, 0.7}; at inference sort selection scores and abstain below the validation-calibrated θ_c. This formalizes the "no play" days in the play-singles lane.
- TRUST-SIGNAL: The minority-weighting result (β ∈ {2,5} optimal, degrades at β ≥ 10) applies to rare high-edge markets (e.g., upset moneylines): reweight the auxiliary loss β·L_minor + L_major when the edge class is tiny, with the paper's β ceiling as the starting grid.
- OTHER (calibration): Ledger's proposed improvement — replace the fixed quadratic penalty with a Lagrangian dual update (learn λ online to pin exact coverage) and per-market coverage budgets (spread vs total vs moneyline get separate θ), since abstention value differs by market edge distribution.
- UNCERTAIN: The reported gains are the paper's mean ± std over 5 seeds; the ledger author notes they are "mechanically guaranteed by the coverage trick" — treat as exploratory, not as expected GSE lift. The honest GSE test is selective ROI vs a softmax-threshold baseline at matched realized coverage.
