# arxiv-program/research/2026-09-21/arxiv-deep/2009-black-box-batch-active-learning-regression.md
## What it is (1-2 sentences)
Deep read (ledger completed 2026-09-22, verdict ADAPT — "the most directly deployable paper in this wave") of Kirsch (2023, OATML Oxford, arXiv:2302.08981, code https://github.com/BlackHC/2302.08981): B³AL, which replaces the gradient kernel in batch active-learning methods (BADGE, BAIT, BatchBALD, Core-Set, LCMD) with an empirical predictive-covariance kernel computed from K sampled predictions, making them work on non-differentiable black-box models (random forests, GBDTs) for regression. Fills the biggest gap in its wave: ledgers 2002/2003/2006 are classification-built, while this paper is regression-native and runs on the gradient-boosted tree stacks that power the yardage/total/spread-margin heads.

## Key metrics/methods (formulas where given, else "not specified")
- Empirical predictive covariance kernel (Eq. 12–13): k_pred(x_i, x_j) = (1/K) Σ_k (μ(x_i;ω_k) − μ̄(x_i))(μ(x_j;ω_k) − μ̄(x_j)), equivalently an inner product of centered K-vectors (valid PSD kernel).
- Plug this kernel into the kernel-based formulations of Holzmüller et al. 2022 to get black-box BADGE, BAIT, BALD, BatchBALD, LCMD, ACS-FW, Core-Set.
- Theory — Prop 3.1: posterior gradient kernel k_grad→post (first-order Taylor around the BMA + GGN approximation) ≈ predictive covariance kernel k_pred, so white-box gradient kernels are just an approximation of the prediction-covariance kernel.
- Prop 3.2: for non-differentiable models, a Bayesian hypothesis-space view with latent hypothesis index Ψ ~ Multinomial(q,1) over the fixed ensemble gives predictive covariance kernel = "posterior" gradient kernel w.r.t. Ψ *exactly*; a Dirichlet/BMC mixture variant gives the same up to a constant factor of 2.
- Gradient kernel (Eq. 6–7): k_grad(x;x′|ω*) = ∇μ(x;ω*)·[∇²(−log p(ω*))]⁻¹·∇μ(x′;ω*)ᵀ; posterior version conditioning on D_train (Eq. 8).
- Entropy bound (Eq. 9): H[Y₁:ₙ|x₁:ₙ] = ½log det(Cov[μ(x₁)…μ(xₙ)] + σ²I) + C_n.
- Non-differentiable latent model: μ̃(x;Ψ) = ⟨μ(x;·),Ψ⟩ (Eq. 24–25), Cov[Ψ] = diag(q) − qqᵀ.
- Acquisition-score log-determinants of the kernel Gram matrix are upper bounds on expected information gain (multivariate normal = max-entropy for a given covariance).
- Regression model assumed: Y|x,ω ~ N(μ(x;ω), σ_N²), homoscedastic. Assumptions: homoscedastic Gaussian noise; K diverse enough to estimate predictive covariance; prediction queries cheap relative to labels; BALD-style MI upper bounds via max-entropy.
- Validation design: Holzmüller et al. 2022 benchmark protocol — log-RMSE averaged over ≥5 trials per dataset/method; per-member evaluation for ensembles (isolates acquisition effect); uniform (random) baseline; ablations on ensemble size K and acquisition batch size B; A100 40GB GPUs.
- Models tested: DNN ensembles (10 members), random forests (100 trees as virtual ensemble / 10 bagged forests), CatBoost virtual ensembles (up to 20 members). Scales in #drawn predictions K, not in #parameters.

## Data sources named
- 15 large tabular regression datasets from UCI ML Repository + OpenML: sgemm, wec_sydney, ct_slices, kegg_undir, online_video, query, poker, road, mlr_knn_rng, fried, diamonds, methane, stock, protein, sarcos. No sports data; generic (x → real y) schema.
- Benchmark protocol from Holzmüller et al. 2022 (App. B.1 best-performing white-box kernel variants used as comparison).
- Cross-referenced corpus items: ledgers 2002 (BADGE), 2003 (BatchBALD), 2006 (Core-Set) — all classification-built and needing regression adaptations, which this paper supplies natively; ledgers 2007/2008's knapsack rules (compose with this paper's acquisition scores for cost-awareness); ledger 2002's white-box BADGE regression adaptation is the explicit baseline to beat in the GSE test.

## Findings (numbers and facts, not vibes)
- DNNs (10-member ensembles): black-box is competitive with white-box for BALD, BatchBALD, BAIT, BADGE, Core-Set; **on average black-box beats white-box for all but ACS-FW and BAIT** (Fig. 3; hypothesis: white-box implicit Fisher-information approximation is poor in the low-data regime where ensembles capture multimodality — the reader notes this rests on one hypothesis without direct evidence).
- Random forests (per-tree virtual ensemble): all black-box methods except BALD (top-k) beat uniform. Bagged RFs and CatBoost virtual ensembles: only LCMD, BADGE, Core-Set beat uniform — attributed to low disagreement among virtual/bagged members (single RF's trees disagree more than bagged forests do).
- Ensemble-size ablation: increasing K improves acquisition for NNs and RFs (except LCMD, which first improves then degrades); for CatBoost virtual ensembles, K ∈ [5,160] gives no boost.
- Batch-size ablation: performance degrades with larger acquisition batches for all methods; at the largest batch (4096) white-box catches up to black-box.
- Black-box also matches/beats the best-performing white-box kernel variants from Holzmüller et al. (App. B.1).
- Failure mode: low inter-member disagreement → AL adds nothing over uniform (the CatBoost/bagged-RF result). Monitor: if inter-member disagreement (mean pairwise |μ_k − μ̄|) on the pool collapses (e.g., late season when models agree), fall back to uniform/geometric sampling.
- Limitations acknowledged in the file: regression only (classification needs Laplace/MC/EP extensions); homoscedastic noise; needs enough diverse empirical predictions; no cost-awareness, no batch-diversity guarantee beyond the inherited method's; black-box methods inherit each white-box method's weaknesses (e.g., top-k BALD still bad); per-member evaluation is fair but real deployments use the full ensemble.

## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- [OTHER — regression-head training pipeline] The paper's method runs unchanged on the heterogeneous model stack (GBMs, linear baselines, any API model) because it needs only predictions — one acquisition pipeline for all heads (spread margin, total, team yardage). Serves the engine's regression-model training/data-efficiency program: for each head, maintain K=10 ensemble (or reuse existing GBM bagged folds as a free virtual ensemble), compute centered prediction vectors per pool game, build the empirical predictive covariance Gram matrix, and run black-box BADGE (k-means++ on prediction-disagreement "embeddings") and black-box Core-Set for weekly charting queues (~2 engineer-days, no gradient plumbing).
- [OTHER — charting-cost optimization] Compose with ledger 2008's knapsack rule: divide the black-box acquisition score by charting cost c(game). The GSE reproducible test targets 2024 held-out margin RMSE per charting dollar (B=16 games/week, 2023–2024 nflverse, K=10 GBM bagged ensemble predicting spread margin). Serves the cost-aware data-acquisition / tracking lane.
- [OTHER — disagreement as a monitoring signal] The mean pairwise |μ_k − μ̄| disagreement metric doubles as a regime indicator: late-season agreement collapses are exactly the failure mode to detect. This interacts with the calibration program — when models agree, uncertainty is low and AL adds nothing. UNCERTAIN: the "low-data-regime multimodality" explanation for black-box beating white-box is the paper's hypothesis without direct evidence.
- [OTHER — classification heads excluded] The paper is regression-only; GSE's classification heads (win-probability) still need the Laplace/MC/EP extensions the paper flags as nontrivial. This bounds the adaptation scope.
