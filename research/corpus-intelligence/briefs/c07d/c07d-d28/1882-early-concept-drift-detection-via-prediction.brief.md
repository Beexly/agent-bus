# arxiv-program/research/2026-09-21/arxiv-deep/1882-early-concept-drift-detection-via-prediction.md
## What it is (1-2 sentences)
Early Concept Drift Detection via Prediction Uncertainty (arXiv:2412.11158): a theoretically-grounded drift detector (PUDD) built on the PU-index — the probability mass a classifier assigns to *not* the true class — which is provably at least as sensitive as error rate and can fire while accuracy is still flat. Validated against 7 classic detectors and 5 SOTA methods, it ranks 1st in 17 of 24 incremental-regime cases.

## Key metrics/methods (formulas where given, else "not specified")
- PU-index: u_i = 1 − f_{y_i}(x_i) (Eq. 7) — for instance x_i with true class y_i, the probability mass the classifier assigns to not the true class.
- Two theorems: (T1) identical PU-index histograms across two windows ⇒ identical error rates and error standard deviations; (T2) equal error rates/stds do *not* imply identical PU-index histograms — so PU-index is at least as sensitive as error rate and can fire while accuracy is flat.
- PUDD detector: (a) sliding window with antiquated-data discard — after a drift at t1, pre-t1 chunks are dropped; (b) all cutting points r ∈ [t1, t+1] explored to form window pairs; (c) Adaptive PU-index Bucketing — Ei-kMeans clustering on the correctly-classified PU values to build histogram bins (k initialized at 5, auto-adjusted by the amplify-shrink algorithm to keep per-bin counts chi-square-valid), with all misclassified instances forced into one extra bin; (d) Pearson's chi-square test on the resulting 2×(K+1) contingency table (rows = windows, columns = bins); drift alarm when p-value < 10^(−X), with PUDD-1/PUDD-3/PUDD-5 tested.
- Expected contingency frequency: E_{ij} = (Σ_j T_{ij} × Σ_i T_{ij}) / Σ_{ij} T_{ij} (Eq. 12).
- Chi-square statistic: χ² = Σ_i Σ_j (T_{ij}² / E_{ij}) − Σ_{ij} T_{ij} (Eqs. 2, 13); p-value from the χ² CDF with w = (cols−1)×(rows−1) dof (Eqs. 3–4).
- Ei-kMeans amplify-shrink distance: M_dist = M_dist ⊙ (1 · e^{θ·(V/(N−1))}); assignment y_i = argmin_j M_dist^{ij}; θ is a shape hyperparameter.
- Drift definition: P_{1,t}(x,y) ≠ P_{t,∞}(x,y) (Eq. 5). Error: e_i = 𝕀(argmax_j f_j(x_i) ≠ y_i) (Eq. 6).
- Assumptions: labeled data available at detection time (PU-index needs true labels); chi-square validity (observed counts > 50, expected > 5 per cell — enforced by bucketing); drift is chunk-level, stream arrives in fixed-size chunks.
- Base classifiers tested: 3-layer DNN (2×64 ReLU + output, 512-256-64 for airline; Adam lr 0.01, 100 epochs), Gaussian Naive Bayes, VFDT (via River); two regimes: incremental test-and-train and train-once-until-alarm.

## Data sources named
- Real-world (public): airline (58k rows, 679 features, binary), elec2 (45k rows, 8 features, binary — electricity pricing, 1996–1998), powersupply (29k rows, 4 features, binary).
- Synthetic: sine (100k, 2 feats), mixed (100k, 4 feats), SEA variants (100k, 3 feats), CIFAR-10-CD (50k images, 32×32, 10 classes — new synthetic drift image set built via a Markov process on user interests).
- Chunk size 1000 for all (100 for CIFAR-10-CD). All experiments repeated 100 times with different random seeds; mean accuracy reported.
- Baselines: 7 classic detectors (ADWIN, DDM, EDDM, HDDM-A, HDDM-W, KSWIN, PH) + 5 SOTA (MCDD, AMF, IWE, NS, ADLTER).
- CIFAR-10-CD: ResNet-18, SGD lr 0.01, 5 epochs, incremental only.
- Code: https://github.com/RocStone/PUDD.

## Findings (numbers and facts, not vibes)
- Incremental regime: PUDD ranks **1st in 17 of 24** dataset×classifier cases, **top-3 in 20 of 24**. Train-once-until-alarm: 1st in 15 cases, top-3 in 19.
- Thresholds: smaller thresholds better — PUDD-1/PUDD-3/PUDD-5 take top-1 in 5/5/8 cases (incremental) and 2/6/8 cases (train-once).
- vs SOTA: top rank in **7 of 8** cases; e.g. PUDD-5 reaches **98.49% accuracy, 2.8% higher than the best SOTA** on one dataset (paper's claim). The exception is **airline**, where NS and ADLTER beat PUDD — attributed to airline's 679 tabular attributes favoring tree ensembles that *adapt* ensembles rather than retrain from scratch.
- Ablation: Adaptive PU-index Bucketing beats Ei-kMeans across all datasets/classifiers/thresholds; improvements statistically significant at 10⁻³ and 10⁻⁵ (critical difference diagrams, appendix).
- CIFAR-10-CD: PUDD outperforms all baselines.
- Example table values (mean accuracy over 100 seeds): airline-I PUDD-5 = 63.35 vs ADWIN 61.65 vs DDM 61.29; elec2-I PUDD-5 = 74.92 vs ADWIN 71.94; powersupply mixed-I PUDD-5 = 82.81 vs ADWIN 78.45.
- Limitations: (a) needs labels at detection time — u_i requires the true class y_i; in live NFL this means drift can only be checked *after* games resolve, no unsupervised/pre-game detection; (b) blunt retrain-on-alarm *loses* to ensemble adaptation (NS/ADLTER) on the one rich tabular dataset (airline, 679 features) — directly relevant since NFL features are tabular and moderately high-dimensional; (c) cutting-point exploration is O(T) per chunk (trivial for 17-week seasons); (d) threshold (10⁻¹/10⁻³/10⁻⁵) is manual — automating it is the paper's own future work; (e) Theorem 1's "early warning while accuracy is flat" depends on calibrated probability output, but the paper's DNNs are not shown to be calibrated (no ECE numbers).
- GSE implementation spec in file: weekly win-probability model (binary); after each week's games resolve, compute per-game PU-index u_i = 1 − P_model(actual outcome) for last N games (chunk = 16 games, weekly slate); sliding window with Adaptive PU-index Bucketing (Ei-kMeans on correctly-predicted PU, k init 5; misclassified = one bin), Pearson chi-square on 2×(K+1) table at α = 10⁻³; on alarm drop pre-drift weeks and refit on post-drift weeks only; offline cron every Tuesday; <100 lines Python (scipy chi2, sklearn k-means), no GPU; ~1 day to wire plus threshold tuning on 2015–2025 nflverse.
- Reproducible test in file: nflverse play-by-play 2015–2025, game-level features, target = home-team win; (a) frozen baseline win-prob model on 2015–2019; (b) from 2020 onward, each week compute PU-index and run PUDD vs error-rate (DDM-style) detector; (c) record alarm weeks. Metric: lead time — weeks between each detector's alarm and the first subsequent 3-week window where the frozen model's Brier degrades ≥0.01 vs its 2015–2019 average (known regime-change seasons: 2020 COVID schedule, 2022 mid-season QB carousels, 2024–25 coaching churn). PUDD must fire ≥1 week earlier on ≥60% of regime-change episodes with ≤2 false alarms per season.
- Acceptance gate in file: ADOPT if (i) PUDD fires ≥1 week earlier than error-rate baseline on ≥60% of known regime-change episodes, (ii) false-alarm rate ≤2/season, (iii) drift-triggered refit (post-alarm weeks only) doesn't degrade Brier by >0.002 vs frozen baseline on non-drift weeks. REJECT if any fails.
- Improvement experiment in file: hybridize — instead of blunt refit-on-alarm (loses on rich tabular data), weight training samples by a PU-index-derived forgetting factor (exponential decay keyed to chi-square drift evidence), keeping old weeks at reduced weight; hypothesis: partial memory helps in NFL where regimes recur (QB returning from injury, seasonal weather) rather than being truly novel.

## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- OTHER (calibration/sizing + online learning): this is genuinely new capability — the existing-research map lists "online learning" and "continuous learning loop" as commissioned topics with results not yet in repo, and the AGENTS.md benchmark inventory has no drift-detection entry. Full sentence: PUDD monitors *whether* the model is still valid week to week while the calibration lane (temperature scaling, grouping-loss paper) fixes how wrong its probabilities are — the two compose into a model-health loop where drift alarms gate recalibration and refits, serving the calibration/sizing program.
- QB-BEHAVIOR: NFL regime changes (OC/QB changes, mid-season injuries) are exactly the "accuracy looks fine for 2 weeks while the distribution already moved" case — a QB injury or backup-QB takeover shifts the outcome distribution before the win-prob model's error rate visibly degrades, so PU-index early warning directly serves QB-behavioral profile validity windows (when a profile is stale).
- COACHING: mid-season coaching changes (OC firings, playcaller swaps — e.g. the 2024–25 coaching churn test episodes) are the canonical drift events; PUDD alarm weeks become labeled coaching-regime boundaries for the coaching-tendencies program.
- TRUST-SIGNAL: the drift alarm is itself a trust signal — weeks flagged as post-drift get down-weighted or excluded from trust-target intake until the refit stabilizes; the weighted-forgetting improvement (exponential decay keyed to chi-square evidence) is a softer, more NFL-appropriate version of the same idea, since regimes recur.
- UNCERTAIN: whether u_i = 1 − P_model(actual outcome) has enough resolution at chunk = 16 games/week for the chi-square test to stay valid (observed counts > 50, expected > 5 per cell required) — weekly chunks may need multi-week windows, which blunts the "early" claim; the file's spec does not resolve this.
- CONTRADICTION: on the one rich tabular dataset (airline, 679 features) the paper's own blunt retrain-on-alarm policy LOSES to ensemble adaptation (NS/ADLTER) — and NFL win-prob features are tabular and moderately high-dimensional, so the paper's exact serving policy may be the wrong one for GSE even if the detection signal is right; the file's improvement experiment (weighted forgetting) is the proposed resolution.
