# arxiv-program/research/2026-09-21/arxiv-deep/0643-bettors-reaction-match-dynamics-evidence.md
## What it is (1-2 sentences)
arXiv:2202.10085v2 (Michels, Ötting & Langrock 2022): a beta-inflated state-space model of in-play betting stakes on all 306 matches of the 2017/18 Bundesliga season, testing whether bettors trade on pre-game strength ("fundamental analysis") or in-game momentum ("technical analysis") — and whether bookmakers' live odds reflect the same dynamics. Verdict in file: ADAPT — the beta-inflated SSM with P-spline time-varying coefficients transfers to NFL in-play handle/line dynamics and bettor-overreaction measurement.
## Key metrics/methods (formulas where given, else "not specified")
- Observation: y_t ~ BEINF(μ_t, σ, p, q) (Rigby et al. 2019 mean/sd parametrisation; beta-inflated to allow y_t exactly 0 or 1). Density: f(y_t) = p if y_t=0; (1−p−q)h(y_t) if 0<y_t<1; q if y_t=1; a = μ_t(1−σ²)/σ², b = (1−μ_t)(1−σ²)/σ².
- Baseline mean (Eq. 1): μ_t = logit⁻¹(α_0 + α·prewindiff + g_t).
- Latent market-sentiment state (Eq. 2): g_t = φ g_{t−1} + β·vaepdiff_{t−1} + ω η_t, η_t iid N(0,1), φ ∈ (−1,1).
- Extended model (Eq. 5): μ_t = logit⁻¹(α_0 + Σ_k ν_k^α B_k(t)·prewindiff + ζ_1·scorediff_t + ζ_2·winprobteam_t + g_t), time-varying α_t, β_t as P-splines (K=10 cubic B-splines, roughness penalty on second differences, λ_α, λ_β chosen by AIC over a 7×7 grid {0.05,0.25,1,5,25,100,500}²).
- Penalized log-likelihood: ℓ_p = log(ℒ_approx) − λ_α/2 Σ_{k=3}^K (Δ²ν_k^α)² − λ_β/2 Σ_{k=3}^K (Δ²ν_k^β)²; AIC = −2ℓ + 2·df̂, df̂ via trace of Fisher-information product (Gray 1992).
- Likelihood via fine state discretization (Kitagawa 1987) → m-state HMM, forward algorithm O(m²T); ℒ_approx = δ P(y_1) Γ⁽¹⁾ P(y_2) … Γ⁽ᵀ⁻¹⁾ P(y_T) 1 (Eqs. 6–8); matches assumed independent.
- VAEP: action value via gradient-boosted trees predicting scoring/conceding probabilities (five seasons + one World Cup + one European Championship of training data).
## Data sources named
Betting: proprietary large European bookmaker in-play stakes, all 306 matches of the 2017/18 German Bundesliga, 1 Hz aggregated to 1-minute intervals; relative stakes on home team per minute; N = 306 series × up to 85 minutes = 26,010 observations; truncated at minute 85; draws excluded; match-outcome bets only. Events: WyScout 1 Hz event data (shots, passes, duels, set pieces with x/y), public via Pappalardo et al. 2019 (Scientific Data). Covariate summaries: relativestake mean 0.493, sd 0.313; prewindiff mean 0.139, sd 0.317, range −0.740–0.851; vaepdiff mean 0.004, sd 0.161, range −1.091–1.167.
## Findings (numbers and facts, not vibes)
- Baseline SSM (Table 2): φ̂ = 0.968 [0.964; 0.971] (market sentiment highly persistent); ω̂ = 0.249 [0.238; 0.261]; σ̂ = 0.300 [0.296; 0.303]; α̂_0 = −0.195 [−0.278; −0.113] — away-team stake bias at equal odds (bettors underestimate home advantage, cf. Levitt 2004); α̂ (prewindiff) = 2.395 [2.151; 2.640]; β̂ (vaepdiff) = 0.600 [0.550; 0.651].
- Model comparison: no-prewindiff ΔAIC = 339.17, no-vaepdiff ΔAIC = 522.04, time-varying coefficients favored by ΔAIC = 270.62.
- Varying-coefficient model: φ̂ = 0.963; ζ̂_1 (scorediff) = 0.234; ζ̂_2 (winprobteam) = 0.336; selected λ_α = 1, λ_β = 5; K = 10. Effect of pre-game strength positive throughout, decreasing approximately linearly over time (strongest at kickoff); effect of VAEP/in-game momentum slightly positive in the first half, then rapidly increasing in the second half — bettors overweight late in-game momentum.
- Simple threshold strategy (1€ bets on home team when tied at halftime and vaepdiff > threshold), mean returns: threshold >0.02: −0.27 (min 45–60), −0.08 (60–75), −0.01 (75–end); >0.03: −0.20, −0.17, +0.04; >0.05: −0.14, −0.28, +0.32. Majority of settings negative, some substantially below ~5% vig → bettors overreact to momentum (UNCERTAIN: authors note positive late-match returns rely on few data points; backtest is in-sample, no out-of-sample split).
- Case study (HSV vs Werder): bookmaker live win probabilities derived from odds barely respond to VAEP swings — "changes in the win probability are almost exclusively resulting from the time remaining" — bookmakers do not price in-play momentum the way bettors bet it, an exploitable gap if it ports to NFL.
- File's implementation spec: Betfair Exchange NFL in-play volume (public API) or Unabated/VSiN ticket%/handle% feeds as handle proxy; NFL VAEP analog = cumulative (EPA_home − EPA_away) per minute or per drive; inputs prewindiff (vig-adjusted pre-game probs via existing Odds API account), score diff, live win probability; serving = one-step-ahead relative-handle forecast for (a) mispricing detection (GSE live prob diverges from market with sustained momentum) and (b) unusual-behavior/steam detection (observed stakes outside 99% forecast quantile).
- File's acceptance gate: ADAPT if on 2024 NFL holdout (a) momentum-SSM beats no-momentum SSM on per-game log-likelihood with β_t second-half shape replicating, AND (b) momentum-divergence rule produces positive CLV, or (c) one-step-ahead relative-volume forecast ≥15% RMSE improvement over naive AR(1).
- File's improvement experiment: build the momentum term on per-drive EPA (not per-minute) with drive-index time-varying coefficients; add weather/pace controls.
## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- OTHER (market/calibration program): first formal method in the corpus for measuring bettor overreaction to momentum vs bookmaker pricing inertia — directly serves the CLV/market-efficiency lane: the second-half rise in β_t gives a testable NFL hypothesis that live-market momentum mispricing concentrates in the second half, which is when CLV-generating divergence flags should fire.
- TRUST-SIGNAL (line-movement/steam lane): the 99%-quantile forecast-violation rule is a principled steam detector for in-play handle — serves the trust-signal intake (unusual handle = information, not noise), with per-minute Betfair volume as the public feed.
- COACHING (in-game decisions): a momentum state g_t estimated from play-level EPA that persists via φ ≈ 0.96+ would quantify "momentum" as the market sees it — coaching tendency analysis could correlate fourth-down/coaching aggressiveness decisions with shifts in market-perceived momentum.
- OTHER (caution): CONTRADICTION note — the paper's finding that bookmaker live odds ignore in-play momentum is in tension with the standing assumption that NFL live markets price EPA efficiently; if the NFL version replicates, live-betting value exists; if not, the soccer result is a market-structure artifact of one German bookmaker's customer base (generalization UNCERTAIN).
