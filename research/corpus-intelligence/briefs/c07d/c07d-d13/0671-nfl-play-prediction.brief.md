# arxiv-program/research/2026-09-21/arxiv-deep/0671-nfl-play-prediction.md
## What it is (1-2 sentences)
arXiv:1601.00574 (Teich, Lutz & Kassarnig 2016): predicts the outcome of individual NFL plays from game situation + parsed play-description strings across classification and regression framings, as a foundation for real-time play-call optimization. Verdict in file: ADAPT — the "progress" measure is a down-aware continuous play-outcome target worth adopting as a complement to EPA; the best-practice ML results are weak baselines, but the feature/target design transfers.
## Key metrics/methods (formulas where given, else "not specified")
- F1 = 2·precision·recall/(precision+recall).
- Progress measure (verbatim): progress(down, togo, gained) = 0 if down∈{3,4} and gained<togo; (gained/togo)^down if down∈{1,2} and gained<togo; 1 if gained≥togo. (Linear on 1st down, quadratic on 2nd down; ad hoc — quadratic penalty asserted, not fitted.)
- Classification: decision trees (balanced class weights), nearest centroid, LDA (SVD / least-squares / eigenvalue with shrinkage), linear + RBF SVM (grid search over C ∈ {2^k}, k∈[−5,17], γ ∈ {2^k}, k∈[−17,4]).
- Regression: regression trees, RBF SVR, linear regression, PyBrain ANNs (up to 10 hidden layers × 100 units, 100 epochs, sigmoid/tanh/linear).
- Categorical features one-hot encoded: 12 → 77 dimensions. Imbalance via balanced class weighting or undersampling. ANOVA F-test for feature ranking; PCA for exploration (authors note PCA questionable on mixed continuous/binary data).
- Assumptions: play outcome depends only on team-level features, not individual players (citing McGarrity & Linnen on QB substitution); penalties invalidate the play string entirely; field-goal-range nuance on 3rd/4th down neglected (all non-conversions = 0); success = first down or touchdown only.
## Data sources named
177,245 plays from all NFL games 2009–2014, via nflgame API (play-by-play JSON; now superseded by nflverse). Penalties, field goals, punts, sacks, fumbles, and non-play strings filtered out. Code: https://www.github.com/romanlutz/NFLPlayPrediction (scikit-learn, PyBrain, nflgame).
## Findings (numbers and facts, not vibes)
- Success classification (70% failure / 30% success imbalance): RBF SVM best — accuracy 66.65%, precision 67.62%, recall 63.75%, F1 65.63% (C=2^1, γ=2^−17); SVD LDA: 66.91% / 67.20% / 65.05% / 66.11%; decision tree (1 rule: togo ≤ 7.5): 69.2% accuracy but precision 47.9%, recall 50.0%; nearest centroid ~50.7% (random); neural nets on imbalanced data collapsed to majority class (~70.5% accuracy, recall ~0).
- Yards regression: RBF SVR best — MAE 5.207 yds, RMSE 8.977 yds; others MAE 5.49–5.78.
- Progress regression: RBF SVR best — MAE 0.1351, RMSE 0.2332; linear regression 0.1412/0.2283; regression trees 0.1424/0.2131; NN 0.1575/0.2449.
- ANOVA F-test: togo 16146.92 (highest), down 6690.42, pass 2927.44; team=NE 48.01 vs team=MIA 0.00005 — million-fold spread, suggesting memorization of team identity rather than generalization (team one-hot features let the model memorize).
- 12 features: team, opponent, half, time (seconds remaining in half), field position (distance to opponent end zone), down, to-go, shotgun, pass, side (left/middle/right), pass length (short/deep), QB run.
- Methodological weakness: no explicit train/test split stated — appears train-on-full or shuffled cross-validation, no time-ordered split; no opponent-strength adjustment beyond identity dummies; sacks/fumbles/punts/FGs (highest-leverage plays) filtered out.
- File's implementation spec: compute progress for every nflverse play 2009–2025; train gradient-boosted regression (XGBoost/LightGBM) with Elo/EPA-based team-strength features (NOT one-hot identities) + tracking-derived features (NGS separation, pass-rush time); time-ordered train ≤2022, validate 2023, test 2024–2025. Effort ~3–5 days.
- File's acceptance gate: adopt progress as a GSE feature if GBM test RMSE < 0.22 on 2024 holdout (beats paper's 0.2332) AND progress adds incremental R² over EPA in a drive-points regression; else keep EPA only.
- File's improvement experiment: replace asserted quadratic down-penalty with fitted parametric family progress = (gained/togo)^f(down), fitting f(1), f(2) by minimizing correlation with next-drive points; test whether learned exponent beats both (1,2) and EPA at predicting drive continuation.
## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- OTHER (play-level modeling lane): the "progress" target is a down-aware continuous play-value measure needing only down/distance (no win-probability model like EPA) — a genuinely new target for the engine-benchmark lane, with a concrete <0.22 RMSE acceptance gate on 2024 holdout.
- SCHEME (play-calling / tendency modeling): 12-feature design (down, to-go, shotgun, pass, side, pass length, QB run, field position) is a ready feature set for situational play-call prediction; the togo F=16146.92 dominance confirms distance-to-go as the primary situational driver of play outcomes.
- QB-BEHAVIOR (caution): the paper's assumption that play outcome depends only on team-level features, not individual players (citing McGarrity & Linnen on QB substitution), is a CONTRADICTION-adjacent claim relative to GSE's QB-behavioral program — modern QB-separation tracking work suggests individual QB effects are real; do not adopt the team-only assumption, adopt the target only.
- COACHING (fourth-down / aggressiveness): progress gives a drive-continuation probability proxy usable in coaching decision models (go-for-it vs punt/FG) without a full WP model — feeds coaching-tendency quantification.
- OL (pass protection features): the tracking-augmentation spec (NGS separation, pass-rush time) is the OL/protection lane's entry point into play-level modeling.
- TRUST-SIGNAL: the cautionary finding is itself the signal — team one-hots produced a million-fold ANOVA spread (NE 48.01 vs MIA 0.00005), a textbook memorization artifact; any GSE play model must use strength features (Elo/EPA), not identity dummies, or it will "learn" team names.
