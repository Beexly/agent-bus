# arxiv-program/research/2026-09-21/arxiv-deep/0592-the-relative-importance-of-ability-luck.md
## What it is (1-2 sentences)
A Bayesian hierarchical model (arXiv:2110.00001v2, Fioravanti, Delbianco & Tohmé 2021) decomposing English Rugby Premiership 2020/21 score differences into latent team ability (random walk anchored on prior season), an "effort" proxy (tries share of scoring attempts, intended as motivation), home advantage, and heavy-tailed luck — finding ability, effort, and luck contribute roughly equal thirds of performance variance. Deep-read verdict: REJECT for direct predictive use — the headline effort result rests on an effort proxy computed from the same game it explains (target-contaminated); ADAPT only the structural components: Student-t margins with estimated ν, dynamic-ability random walk, luck variance decomposition — with strictly lagged pregame aggressiveness proxies.

## Key metrics/methods (formulas where given, else "not specified")
Verbatim equations:
- Likelihood: y_g ~ t_ν(a_diff(g) + eff_diff(g) + ha(g), σ_y), ν ~ Gamma(9, 0.5) (shape 9 chosen as less skewed than Kharratzadeh's Gamma(2,0.5) for soccer, matching rugby's larger mean score differences).
- Ability: a_diff(g) = a_{hw(g),ht(g)} − a_{aw(g),at(g)}; a_{hw(g),ht(g)} = a_{hw(g)−1,ht(g)} + σ·η_{hw(g),ht(g)} for hw ≥ 2; a_{1,ht(g)} = β_prev·prevperf(ht(g)) + η_{1,ht(g)}.
- Effort: eff_diff(g) = β_effort·(effH(g) − effA(g)); effH(g) = (home tries in g)/(home tries in g + attempted home scoring kicks in g), where attempted kicks = conversion opportunities + attempted penalties + attempted drops.
- Home advantage: ha(g) = β_home + β_atten·atten(g) (atten = 0/1 for fan attendance); Model III adds β_day·day(g) (1 if Saturday/Sunday).
- Priors: β_prev, β_effort, β_home, β_atten, β_day ~ N(0.5, 1); σ ~ N(0, 0.1), η ~ N(0, 0.5).
- Luck (Section 6), two definitions: (i) Tango-style variance decomposition Var(Performance) = Var(Luck) + Var(Effort) + Var(Ability), with Var(Luck) = p(1−p)/g, p=0.5, g=22; (ii) luck as large residuals from the regression, classified into four Elias/Gilbert-Wells types — I: physical randomization, II: simultaneous decisions, III: unpredictable human-performance fluctuation, IV: matchmaking.
- Fit in rstan: 4 chains × 2500 iterations, 1500 warm-up; full Stan code in Appendix; Rhat ≈ 1.00, large n_eff; posterior predictive checks via 10,000 replicated score-difference histograms. Four model variants: I (no attendance), II (+attendance), III (+weekend-day dummy), IV (prevperf from points instead of tries).

## Data sources named
English Premiership Rugby 2020/21: 12 teams, 22 rounds, 122 regular-season games analyzed (playoffs excluded — different incentives; 10 games canceled due to COVID-19). Per-game schema: total score, tries, conversions, penalties, drop kicks (scored and attempted), attendance. Source: the corresponding Wikipedia entry. Priors from 2019/20 final standings (attack/defense rankings from tries scored and points received, normalized and averaged). Season ran during COVID-19 (several zero-attendance games). Season won by Harlequins (4th in league phase). No repository link; Stan code printed in the Appendix.

## Findings (numbers and facts, not vibes)
- Model II posteriors (Table 4): β_prev = 1.758 [0.297, 3.185]; β_effort = 3.114 [1.574, 4.639]; β_home = 0.324 [−0.028, 0.657]; β_atten = 0.376 [−0.588, 1.354]; ν = 13.011 [5.445, 25.335]; σ_y = 1.683 [1.380, 2.012]. Model I (Table 3): β_home = 0.366 [0.036, 0.704]; β_prev = 1.760; β_effort = 3.147; ν = 12.375; σ_y = 1.664.
- Model III: β_day = −0.003 [−0.732, 0.715] — no weekend effect. Model IV (points-based prevperf): β_prev drops to 1.1 [−0.3, 2.5]; β_effort stays 3.1 [1.6, 4.6].
- Descriptive: home mean score 26.22 vs. away 22.35; home tries 3.248 vs. 2.796; mean effort home 0.37, away 0.36 (many games at exactly effort = 1/2, the try+conversion structure).
- Luck variance decomposition: Var(Luck) = 0.01136364; Var(Performance) = 0.03798835; Var(Effort) = 0.01563645; Var(Ability) = 0.01098826 — effort, luck, and ability contribute roughly equal thirds to performance variability.
- Bivariate posteriors show no correlation between β_effort and β_prev/β_home — effort captures an effect distinct from ability and home support.
- No predictive-accuracy metrics reported (authors state their goal is explanation, not prediction).
- LEAKAGE (fatal for direct use): the effort proxy is computed from game g's own tries and kick attempts — the same game whose score difference y_g is the target; score difference is mechanically tied to tries, so β_effort is estimated on a regressor containing the outcome. Any NFL port using same-game aggressiveness (that game's 4th-down go-rate, PROE, blitz rate) inherits this leakage verbatim.
- Limitations: entirely in-sample (fit and interpreted on the same 122 games); the rugby ratio is admitted "not uncontroversial" (ignores defense, rewards risk-seeking over winning); single 22-round season, 12 teams; β_effort interval [1.57, 4.64] is wide; luck case studies (Wasps 34–5 Exeter, Worcester 14–62 Northampton, Exeter 74–3 Newcastle) are post-hoc narratives on the three largest residuals — Texas-sharpshooter risk; COVID-19 season (canceled games, empty stadiums) limits external validity; no direct NFL analog for the kick-vs-try tradeoff.

## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- COACHING (the actionable mechanism): the paper's effort concept maps to GSE's existing 4th-down aggressiveness, PROE+, and turnover-luck layers — but the transferable piece is the decomposition structure (ability random-walk + aggressiveness + home + heavy-tailed luck in one hierarchical model) with STRICTLY LAGGED pregame aggressiveness (season-to-date values through week w−1: 4th-down go-rate over expected, PROE, blitz rate) — never same-game ratios. The read specifies a negative control: fit a same-game-aggressiveness variant to demonstrate leakage inflation (expect larger β_effort but worse-or-equal holdout performance); it must never be used predictively. This serves the coaching-tendencies program and late-season situational adjustments.
- OTHER (calibration/sizing): the Student-t margin likelihood with estimated ν (≈13 in rugby, heavier than Gaussian) is a directly adoptable robustness upgrade for GSE's margin-of-victory models — NFL margins are also heavy-tailed (garbage-time TDs). The Tango variance decomposition Var(Performance)=Var(Luck)+Var(Effort)+Var(Ability) is a portable template for decomposing GSE's own pick-record variance.
- TRUST-SIGNAL: the luck-as-large-residuals taxonomy (Elias/Gilbert-Wells types I–IV) gives a structured vocabulary for classifying engine misses in intake — physical randomization vs. simultaneous decisions vs. human fluctuation vs. matchmaking.
- CONTRADICTION-adjacent caution: no existing NFL result in the corpus tests a motivation/aggressiveness term with strictly lagged features — this would be a first empirical test, and the acceptance gate is strict (lagged-β_effort 95% interval must exclude zero AND beat ability-only baseline log-loss by ≥0.5% on 2024–2025 rolling; reject if indistinguishable from zero).
- QB-BEHAVIOR (indirect): team-level aggressiveness decomposes coaching intent from QB execution — lagged 4th-down go-rate reflects coaching, which lets the QB-behavioral lane isolate the QB's marginal execution given the game plan.
