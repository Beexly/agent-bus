# ops/OPERATOR.md
## What it is (1-2 sentences)
The operator runbook of production actions that agents cannot perform: free-settlement recovery, Stripe wiring, CRON_SECRET rotation, no-flip gates, the full environment-variable reference (including ESPN FPI license gating and two line-integrity flags), the canonical-host law, and the launch-readiness command.

## Key metrics/methods (formulas where given, else "not specified")
- State observed 2026-09-02 on `/api/ops/public-surface-truth`: `PUBLIC_PICKS_ENABLED` already ON in production (`gates.canExposePublicPicks: true`, the board serves **55 picks/day**); `PERFORMANCE_STATS`, `LIVE_BOARD`, `PUBLISH_LEDGER` off. Record gates stay closed until calibration eligibility is **GREEN ×3** ("publishing a pick is not a track-record claim").
- Line-integrity flags (C-281..C-284; ledger C-197): `LINE_INTEGRITY_PUBLISH_GUARD_ENABLED` ON suppresses roughly **43% of SPREAD** and **62% of TOTAL** picks on the production counts in ledger C-197 ("a board decision, not an ops toggle"). `LINE_INTEGRITY_VOID_ENABLED` lets the settle-picks remediation lane VOID settled published picks with that defect (rcaCode LINE_NOT_QUOTED, never re-stamping settledAt) and UNPUBLISH unsettled ones; idempotent; writes nothing while unset.
- Flip precondition for the line-integrity flag is `lineIntegrity.sweep.voidSweepComplete === true`, NOT `remainingToVoid === 0` (C-287): the survey samples only the **oldest 300** of a settled population in the **thousands**; `remainingCapReached` is true on every production call, so the old wording could never be satisfied; the `sweep` claim about the whole population reads false until the lane has run two complete passes.
- No formulas otherwise; metrics are counts and gates.

## Findings (numbers and facts, not vibes)
- **Settlement law (since 2026-09-02):** the free grader (ESPN + registered consensus) is the primary pass on EVERY settle-picks cycle regardless of THE_ODDS_API_KEY; a present key only adds a paid `settleSport` supplement for whatever the free pass left PENDING. A dead/deactivated key fails only the supplement (`paidSupplement.failedSports`, `advisories[]` in the response) and no longer blocks the free grader the way it did before. Removing the key is optional hygiene, not a fix for stuck settle.
- If settlement is still stuck: the free grader itself is failing (e.g., free score spine down) — check `/api/health?strict=1` and `docs/ops/FREE_MODE_INGESTION_HEALTH.md`, not the key.
- **No-flip list without founder YES:** LIVE_BOARD · PUBLISH_LEDGER · PERFORMANCE_STATS · Phase C · HEOS #226 · gamma schedule.
- **Env-var reference (agent sessions cannot read `.env*` files; values set in Vercel only):** DATABASE_URL, DIRECT_URL, NEXTAUTH_SECRET, NEXTAUTH_URL (must equal canonical www host), GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET, STRIPE_PRO_MONTHLY_PRICE_ID, STRIPE_PRO_ANNUAL_PRICE_ID, STRIPE_ELITE_MONTHLY_PRICE_ID, STRIPE_ELITE_ANNUAL_PRICE_ID, STRIPE_FANTASY_MONTHLY_PRICE_ID, STRIPE_FANTASY_ANNUAL_PRICE_ID (per-interval IDs with fallback to legacy STRIPE_PRO_PRICE_ID / STRIPE_ELITE_PRICE_ID), STRIPE_TERMS_CONSENT_ENABLED (DEFAULT OFF; set Stripe Dashboard Terms-of-Service URL FIRST, then flip — otherwise Stripe rejects every Checkout Session and new subscriptions 500), THE_ODDS_API_KEY, ESPN_POWERINDEX_LICENSED (see gating above; any value other than exact "true" keeps the source off; agents never set this — AGENTS.md law 3), ANTHROPIC_API_KEY, REDIS_URL, NEXT_PUBLIC_APP_URL.
- **Line-integrity flags (5-LI):** two founder-only flags, default OFF, absent from `.env.example` by design (AGENTS.md law 2 freezes `.env*` for agents). The stored `line` is the arithmetic mean of every book's line, so on a disagreeing market it is a number nobody offers — the rationale for the guard. Reading the counts requires operator auth (C-286): the `lineIntegrity` block on `/api/ops/public-surface-truth` is returned only for an authenticated call; anonymous GET reads `lineIntegrity: null` = NOT SURVEYED (not "nothing to void"). Flip precondition: `lineIntegrity.sweep.voidSweepComplete === true` (C-287), not `remainingToVoid === 0`. Full context: `docs/ops/LINE_INTEGRITY_DECISION_2026-09-08.md`.
- **Canonical host law:** single source of truth `apps/web/lib/seo/site-url.ts` (`SITE_URL`): NEXT_PUBLIC_APP_URL when set, else `https://www.galaxysportsedge.com` (www, never apex). Apex must redirect to www at DNS/platform layer, not app code. Operator steps: set NEXT_PUBLIC_APP_URL and NEXTAUTH_URL identically; add `https://www.galaxysportsedge.com/api/auth/callback/google` to Google Cloud Console OAuth authorized redirect URIs.

Never invents a number; unknowns print as unknown. Run the morning of every slate and after every production deploy; a FAIL is a stop.

## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- [TRUST-SIGNAL] The line-integrity finding serves the **trust-target intake** program directly: on a disagreeing market the stored line is the arithmetic mean of every book's line — a number nobody offers — so 43% of SPREAD and 62% of TOTAL historical picks carry a quoted-line defect (rcaCode LINE_NOT_QUOTED); any backtest or pick record from before the guard must be filtered on this defect before being treated as a trustworthy record.
- [OTHER] ESPN FPI license gating serves **calibration/sizing**: FPI was OFF by default (pipeline never fetched it while `ESPN_POWERINDEX_LICENSED` unset) — so the "independent" probability inputs in the 2026-08-09-era signal slate excluded FPI; when comparing that era's calibration to later states, do not assume FPI was in the ensemble.
- [TRUST-SIGNAL] GREEN ×3 record-gate rule ("publishing a pick is not a track-record claim") serves the **trust-target intake** program: the 55 picks/day on the public board are not a track record until calibration eligibility is GREEN three times running — do not grade them as one.
- [OTHER] Free-grader primary pass (ESPN + registered consensus, hourly) serves the **tracking lane**: settlement provenance for historical picks is the free grader unless the response shows `free+odds-api`; this matters for verifying outcomes in any backtest of that era's picks.
- [COACHING] INFERENCE: the 43%/62% line-defect suppression rates imply SPREAD and TOTAL markets disagreed heavily across books in this era — a market-disagreement signal that could serve **coaching/scheme** analysis of line-movement predictability, but this is inference, not a measured effect.

## Engine-actionable? (yes/no + one-line what)
Yes — any historical pick backtest must void/filter picks with the LINE_NOT_QUOTED defect (43% SPREAD / 62% TOTAL suppression baseline) before grading, and the GREEN ×3 rule blocks treating the public 55-picks/day board as a track record.
