# research/2026-09-28/github-nfl-sweep/repos-wave1-inventory.md
## What it is (1-2 sentences)
Code-grounded inventory of 29 "keeper" NFL repos from a 1,000-repo GitHub sweep (10 pages × 100, `q=NFL&sort=updated&order=desc`, 2026-09-28), each entry grounded in actual source code rather than README claims, with license status and the learned method per repo. License-absent = no license; method-level learning only, no code reuse.

## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- `ryanpmcintire/nfl_py3` feature modules — `qb_identity` feature module (QB-BEHAVIOR): the repo builds explicit QB-identity features into its Bayesian team model, which independently converges with GSE's QB-behavioral-profile program — QB identity is treated as a first-class model feature, not just a roster label, so the mechanism is a QB-level embedding/coefficients that condition the team model.
- `officials`, `weather`, `transaction_wire`, `roster_availability`, `sharp_book_movement` modules (OTHER/TRUST-SIGNAL): official/crew and transaction-wire features feed the same model — these are trust-signal and availability-signal kernels GSE's total-signal doctrine can mirror (referee tendency features, wire-event availability decay).
- Kalshi reconciliation weights fit OOS + joint-draw composites (`JOINT_MODEL_REQUIRED`) (TRUST-SIGNAL): mechanism — market-blend reconciliation weights are fit out-of-sample (not in-sample) so market-signal intake stays honest; legs of any joint bet must share the same Monte Carlo draws or the model refuses to composite, which is the statistically correct way to keep correlation in parlays/same-game props.
- nflalgorithm confidence engine 0-100 = edge size × projection stability × volume certainty × volatility → Premium/Strong/Marginal/Pass (OTHER/calibration-sizing): a multiplicative confidence score that decomposes edge, stability, volume, and volatility — the mechanism maps directly onto GSE's bet-tier sizing (tiered gating on multiplicative confidence rather than raw edge).
- Megatron Transformer d_model=96, 4 heads, 3 layers, 11 stats × 3 quantiles (OTHER): small-data transformer with quantile heads and per-fold calibration per season 2016–2025 — a concrete architecture reference point for the engine's own distributional projection work, though no license means method-learning only.
- `tucknub/nfl-prop-war-room` CI product gates (OTHER): shadow-deploy + canary + QA gates on a 1,310-file prop platform — a process precedent for GSE's own shadow-only props wiring stance (props wire shadow-first with honest model-prob sourcing).
- `sportsdataverse/nfl-ngs-raw` scrape pattern (OTHER/TRUST-SIGNAL): raw library of NGS API JSON, 2009→present logs — this is the same repo family the NGS feed plan studies for its scrape lane; the inventory's code-grounded confirmation is independent evidence the scrape pattern is real and operational.

## Engine-actionable? (yes/no + one-line what)
Yes — adopt the `JOINT_MODEL_REQUIRED` rule (all same-game-parlay/prop legs must evaluate on the same Monte Carlo draws, or refuse to composite) and the multiplicative confidence-score kernel (edge × stability × volume certainty × volatility → tiers) for bet sizing gates.
