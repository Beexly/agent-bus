# arxiv-program/research/2026-09-21/arxiv-deep/0066-mambamot-statespace-model-as-motion-predictor.md
## What it is (1-2 sentences)
A motion-predictor paper (UW Hwang lab, arXiv:2403.10826v2) replacing the Kalman filter in tracking-by-detection multi-object tracking with a learned Mamba (selective state-space) block, plus a MambaMOT+ variant adding an O(N) trajectory-embedding head that merges fragmented tracklets via cosine similarity + hierarchical clustering. Verdict in the file: ADAPT — the weaker sibling in-batch vs. 0063's MambaTrack; take the MambaMOT+ trajectory-embedding tracklet merger and defer to 0063 for the motion model itself.

## Key metrics/methods (formulas where given, else "not specified")
- Task (§III-A): given tracklet boxes over past n frames {B_{t−n},…,B_{t−1}} ∈ R^{n×[x,y,w,h]}, predict box B_T at next timestamp; associate with next-frame detections via Hungarian algorithm (BYTE association from ByteTrack).
- Motion model (§III-B/C): Mamba block preceded by a linear projection lifting [x,y,w,h] to higher dim, then local MLP prediction head: Y_t = MLP_pred(y_t) (Eq. 6). Loss: **L_pred = L_giou + L_mse** (GIoU + MSE vs ground-truth next box).
- MambaMOT+ (§III-D): trajectory representation via second MLP head f_t = MLP_emb(y_t) (Eq. 7) on same Mamba output; cosine embedding loss (Eq. 8): **L_cos(i,j) = 1 − cos(f_i, f_j) if i = j; max(0, cos(f_i,f_j)) if i ≠ j**. Joint loss: **L_total = L_pred + L_cos**.
- Tracklet merging: compare per-tracklet features with cosine similarity, run hierarchical clustering to merge fragments; temporal threshold **50 frames**, spatial threshold **50 pixels** to veto unreasonable merges; per-tracklet forward pass — O(N) vs O(N²) Siamese tracklet-merging networks.
- Continuous SSM (Eqs. 1–2 as printed): y(t) = C·h(t); h(t) = A·h(t−1) + B·x(t). File flags: "Eq. 2 as printed mixes discrete/continuous notation — the paper's own loose notation."
- Selective discretization (Eqs. 3–4, extracted verbatim): Ā_t = exp(ΔA) = 1 − σ(Linear(x_t)); B̄_t = (exp(ΔA) − I)·ΔB = σ(Linear(x_t)). File flags UNCERTAIN: "the paper's own simplification of the selective parameterization (compare the standard Mamba Δ = softplus(Linear(x))); extraction is legible but the algebra as printed is the authors' shorthand, not the canonical Mamba discretization. Do not treat as a citable discretization formula. Reimplementation should follow the mamba-ssm reference, not the printed formulas."
- Eq. 5: y_t = C·h_t and h_t = Ā_t·h_{t−1} + B̄_t·x_t.
- Training (§IV-A): Adam, **lr 0.0001**, **500 epochs, batch 32**; **2 Mamba blocks, hidden dim 64, expansion factor 2**; tracklets sampled with random lengths in (2, n) with padding to n; training data pooled from MOT17, DanceTrack, SportsMOT trajectories; one NVIDIA RTX 4080.
- Inference: **28.8 FPS** on a single GPU — real-time, vs. <10 FPS for transformer trackers like MOTR.
- Assumptions: merge gates of 50 frames / 50 pixels; fixed-size box state [x,y,w,h].

## Data sources named
- **DanceTrack** (dancers, uniform appearance + diverse motion) and **SportsMOT** (multi-sport scenes, similar appearance + diverse motion). No NFL/NGS data. Datasets are public.
- Detectors: DanceTrack uses ByteTrack's YOLOX detections (fair comparison); SportsMOT trains its own YOLOX on the SportsMOT train set with the ByteTrack recipe. SportsMOT results marked * = same YOLOX detections for all methods.
- Baselines: Kalman-based: FairMOT, SORT, DeepSORT, ByteTrack, OC-SORT. Learning-based: CenterTrack, TraDes, QDTrack, TransTrack, MOTR, GTR, MotionTrack.
- Code/checkpoints: not stated in paper — no GitHub link given. Hyperparameters fully stated (§IV-A).
- Related: MambaTrack (0063, ACM MM 2024, same UW Hwang lab lineage; MambaMOT cites it as [33]); 0065 UniTraj (offline generative trajectory modeling/imputation).

## Findings (numbers and facts, not vibes)
- **Table I — DanceTrack test:** MambaMOT **HOTA 55.5**, DetA 80.8, AssA 38.3, IDF1 53.9, MOTA 90.1. MambaMOT+ **56.1 / 80.8 / 39.0 / 54.9 / 90.3**. Same-detections comparisons: ByteTrack 47.3 (**+8.2 HOTA** for MambaMOT); OC-SORT 54.6 (MambaMOT +0.9); MOTR 54.2. MambaMOT+ adds +0.6 HOTA / +1.0 IDF1 over MambaMOT.
- **Table II — SportsMOT test (same * detections):** MambaMOT* **70.4 / 86.7 / 57.2 / 69.5 / 94.7**; MambaMOT+* **71.3 / 86.7 / 58.6 / 71.1 / 94.9**. ByteTrack* 62.0 (**+8.4 HOTA**), OC-SORT* 70.2, TransTrack 68.9. Paper claims: outperforms ByteTrack by 8.2% HOTA and 7.3% AssA under identical association/detector.
- Inference speed (§IV-C): 28.8 FPS single GPU, real-time; vs. MOTR-class < 10 FPS.
- No predictive modeling of game outcomes; no NFL data; no held-out forecasting.
- Reviewer adversarial notes: **superseded within the batch** — MambaTrack (0063) reports SportsMOT test HOTA **72.6** vs MambaMOT+'s 71.3, so MambaTrack's bidirectional MTP is the stronger sports-motion model; MambaMOT's marginal value is the trajectory-embedding merger. No appearance model (motion-only) — in NFL broadcast, jersey numbers are strong appearance cues the paper doesn't exploit. Thin ablations: no ablation of embedding-head merge thresholds, no long-occlusion failure analysis, no FPS/latency-vs-accuracy curve. Domain shift to American football (helmets, pile-ups, broadcast camera motion) untested.
- File's own gates: reproduction gate — on SportsMOT test with the paper's YOLOX detections, reach HOTA ≥ 70.0 (MambaMOT) / ≥ 70.9 (MambaMOT+). GSE gate — on GSE-labeled NFL broadcast tracking, adopt the merging head if tracklet fragmentation drops ≥ 20% at equal or better IDF1 vs Kalman; adopt the motion predictor only if it beats 0063 head-to-head; latency must clear ≥ 25 FPS (paper: 28.8).
