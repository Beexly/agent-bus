# arxiv-program/research/2026-09-21/arxiv-deep/0300-temporal-feature-distillation-for-labelefficient-precise.md
## What it is (1-2 sentences)
Hao Xu, Xinyu Wei, Sam Wells, Sunil Aryal (2026, arXiv:2607.10998) propose a label-efficient precise-event-spotting (PES) video method for tennis/figure skating/diving: a plug-in Temporal Gated Scale (TGS) module (multi-scale dilated temporal convolutions with past/future/static channel split and gated fusion) plus a Temporal Feature Distillation (TFD) teacher-student strategy (two-stage EMA teacher, soft targets on weakly augmented unlabeled clips, MSE feature-alignment loss with cosine-ramped weight) — best in 14 of 16 dataset×label-fraction settings, but with no credible transfer to GSE's NFL outcome/prop engine or current data stack (GSE has no video pipeline).
## Key metrics/methods (formulas where given, else "not specified")
- TGS module (Eqs. 1–7): plug-in after a standard feature extractor (RegNetY, ResNet-18, ViT-Tiny/Small). Input X_in ∈ R^{T×C}; residual MLP projections to F_in ∈ R^{T×C'}; parallel depthwise 1D temporal convolutions at dilations d ∈ {1, 3, 5} (short/mid/long-range); elementwise gated convolution per scale; channels split into thirds — past-context, future-context, static — with past/future thirds cyclically shifted along time, static untouched; softmax-weighted fusion across the three scales; MLP projection + residual → X_out.
  - Equations: F_in = MLP(X_in); F^{(d)} = GateConv_d(F_in), d ∈ {1,3,5}; split thirds [past, future, static]; F̃_fused = Σ softmax(w)_d F^{(d)}; X_out = X_in + MLP(F̃_fused).
- TFD strategy (Eqs. 9–11): student trained supervised; teacher = EMA of student weights with a two-stage EMA schedule — fast decay β₁ = 0.99 while the student is "still learning", base decay β₂ = 0.9995 after convergence (paper's §3.4 is self-contradictory on which decay applies when; reproduction of teacher dynamics uncertain from text alone). Teacher generates soft targets on weakly augmented unlabeled clips; alignment loss = MSE between student and teacher temporal feature maps: L_align = ‖F_s − F_t‖²; total L_TFD = L_sup + λ(t)·L_align, with five-epoch supervised warm-up, λ(t) cosine-ramped 0→1 over ten epochs, then λ = 1. Supervised loss = weighted CE over per-frame multi-label classes plus a binary temporal-detection loss (foreground weighting by inverse class frequency and per-frame event density).
- TMA (Temporal Masked Augmentation): unlabeled views; random 16×16 patch grid, 9 patches masked, p = 0.5; temporal masks of length 3, up to five segments per clip.
- Training: 50 epochs, batch 4, AdamW, lr = 1e-4, weight decay 1e-4; eight NVIDIA A100 GPUs.
- Assumptions: unlabeled video shares the labeled distribution (same sport); temporal feature continuity holds between adjacent frames except at boundaries.
## Data sources named
All public benchmarks: Tennis [39] — 3,345 clips, 28 matches, 33,791 annotations, six classes (serve, forehand, backhand, volley, bounce, fault); source split 19 train/val matches, nine test matches; input 224×224 frames at 30 fps, clip length 100. Figure Skating (FS) [39] — 371 performances from 11 broadcasts, 3,674 events, four classes (jump, spin, footwork, landing); two sub-tasks FS_Comp and FS_Perf (different train/test splits). FineDiving [34] — 3,000 clips, 7,010 events, four classes (takeoff, somersault, twist, entry); train/test by performance videos. Label regimes: 10%, 20%, 40%, 80% of labeled training set; test labels always 100% used. Code: https://anonymous.4open.science/r/TFD-8535/ (anonymous; not verified live). No checkpoint release stated.
## Findings (numbers and facts, not vibes)
- At 10% labels, mAP (Tennis / FS_Comp / FS_Perf / FineDiving): 80.19 / 38.29 / 50.29 / 52.87 — own model best in 14 of 16 dataset×fraction settings. FS_Perf 10%: +4.54 over strongest listed competitor (ASTRM 45.75).
- At 80% labels, theirs matches or exceeds the 100%-labeled fully-supervised baselines on two of four datasets.
- TGS ablations (10% labels, Tennis mAP): ViT-Tiny 10.96 → +TGS 44.77 (+33.81); ViT-Small 46.32 → +TGS 68.39 (+16.83); +TFD → 80.19. FS_Perf: ViT-Small 28.61 → +TGS 41.37 → +TFD 50.29.
- TMA ablation: Tennis 75.32 → 80.19 (+4.87); FS_Perf 48.56 → 50.29 (+1.73).
- Clip-length sensitivity: Tennis L = 50 → 73.50 (−6.69 vs 80.19 at L = 100); FS_Perf L = 125 → 58.97 (+8.68), L = 200 → 58.78 (+8.49) — temporal modeling pays more on slower events.
- Feature-sharpness study: cosine similarity of DINO features at event boundaries ≥0.999 vs TFD 0.003 (Tennis) — TFD features are boundary-sharp while DINO is over-smoothed; non-boundary averages 0.936 (TFD) vs 0.997 (DINO).
- Complexity (ViT-S backbone, 100-frame clip): 23.45M → 28.89M params (+5.44M), 644.30 → 1000.15 GFLOPs (+355.85), 1649 → 867 FPS — still real-time on an A100-class GPU.
- Validation design: metric = average precision / mean AP at tolerance δ = 1 frame; mean over three random seeds; baselines = adapted semi-supervised video methods (FixMatch, Mean Teacher, MixMatch, UDA, FreeMatch, SoftMatch, SimMatch, ASTRM) on same backbones, plus full-supervision baselines and TGS-only ablations.
- Limitations (file's adversarial notes): (a) two-stage EMA description in §3.4 self-contradictory — exact reproduction uncertain; (b) label-fraction sampling is random — no statement that match identity is preserved, so the unlabeled 90% may leak the same matches as the labeled 10%, inflating semi-supervised gains; (c) only three runs, no variance/CIs — gains like +1.73 on FS_Perf may be within noise; (d) the DINO comparison is strawman-adjacent (DINO never trained for boundary sharpness); (e) 1,000 GFLOPs per 100-frame clip is heavy for any production video pipeline; (f) all four datasets are individual/precision sports — no team sport, no occlusion-heavy broadcast scenarios.
## Intelligence connections
- (OTHER) No overlap with any GSE program lane: the existing-research-map's video/ML lanes contain no event-spotting or video-indexing capability, and GSE has no video pipeline — the engine consumes play-by-play/odds, not frames; the method localizes moments in video, not game outcomes. Relevance is limited to a future broadcast-video indexing lane (e.g., auto-labeling highlight clips for content production): the TGS module is the portable piece — a plug-in after any frame feature extractor, trained with the TFD warm-up→ramp→align schedule, on NFL-specific classes (snap, handoff, throw, catch, tackle, kick). That lane would require a labeled NFL clip set (≥10% regime still means thousands of annotations), A100-class training compute, and a re-validation of the EMA schedule ambiguity first. Serves no current program (not QB-behavioral profiles, not coaching tendencies, not trust-target intake, not calibration/sizing, not the tracking lane).
- (TRUST-SIGNAL) Methodological lesson portable to semi-supervised tabular work: the within-match leakage risk (random label-fraction sampling without match-identity preservation) is the same class of leakage GSE must guard against in game-level splits — group structure (match/team/season identity) must be respected in any fractional-label or cross-validation design.
## Engine-actionable? (yes/no + one-line what)
No — video event spotting has no consumer in the current stack; the only gate that would change the verdict is GSE committing to a video-indexing product lane AND the authors' code reproducing within ±2 mAP points on the public benchmarks, neither of which holds.
