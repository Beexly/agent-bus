## Key metrics/methods (formulas where given, else "not specified")
- Task state machine (`CockpitTaskStatus`): NEW → ROUTED → DRAFTED → NEEDS_REVIEW → APPROVED|REJECTED → ARCHIVED (terminal). Any state → BLOCKED → (ROUTED|ARCHIVED). Deliberately NO DRAFTED→APPROVED path (work cannot skip review). Automation owns NEW→ROUTED→DRAFTED→NEEDS_REVIEW and *→BLOCKED ("No transition implies any external action"); human owns NEEDS_REVIEW→APPROVED|REJECTED.
- Risk/compliance enums: `CockpitRiskLevel {LOW, MODERATE, HIGH, COMPLIANCE_HOLD}`; `CockpitComplianceStatus {NOT_APPLICABLE, CLEAR, REVIEW_REQUIRED, HOLD, REJECTED}`.
- 2026 lineup pricing per M in/out (`verified-ext`): Haiku 4.5 $1/$5, Sonnet 4.6 $3/$15, Opus 4.7 $5/$25. Haiku ~3× cheaper input/3× cheaper output vs Sonnet; Opus ~1.67× Sonnet input. Prompt caching: cache reads cost 0.1× input; reported up to 90% cost / 85% latency cuts; routing reports 30–70% cost cuts no quality loss. Default TTL dropped 1h→5min on 2026-03-06 — caching wins only on bursty same-surface traffic; explicit 1h TTL for periodic single-shots (journal/weekly insight).

## Findings (numbers and facts, not vibes)
- Doctrine in one line: "every agent drafts; only a human commits anything externally visible" — enforced via `AGENTS[*].externalActions: "NONE"` and agent-registry header (`verified`).
- Six operator agents verified as enum + static registry: JARVIS (orchestrator/chief of staff), SARAH (support & review, never sends), TAL (engineering, minor impl drafts), SCOUT (sports research: odds movement, injury/news, schedule signals), AVA (content/media drafts, never publishes), BOBBY (funnel/subscription/analytics, observation only). None gain externalActions.
- Jarvis synthesizer is pure/I/O-free; rules forbid auto-bet/auto-publish; emits "unknown" rather than fabricate. `canApplyCalibrationAdjustments` hardcoded `false` (maps to TAL hard stop: no auto calibration changes).
- Media: `CockpitMediaItem.scheduledFor` is "metadata only. There is no worker that reads it" — media never auto-publishes (`verified`). AVA drafts wait in media queue with `qaStatus=DRAFT`, `complianceStatus=REVIEW_REQUIRED`, `approved=false` (schema defaults, schema.prisma:911).
- BOBBY hard stops: no Stripe live mutation (no subscription change/refund/price edit), no pricing change without operator; entitlements server-side only.
- Cost ledger: every Claude call recorded via `recordClaudeApiCall`; per-surface monthly budgets with yellow/orange/red/hard_cap + override. Spend is "measured, not optimized."
- AVA self-audit: banned-phrase + no-fake-percentages + trust-claims suites must pass before NEEDS_REVIEW; banned phrase forces BLOCKED/COMPLIANCE_HOLD. Promos require compliance-gated render + APPROVED_PARTNER registry class.
- SCOUT self-audit: cite source snapshot or emit nothing — no fabricated stats; HARD STOP: never auto-bet, never alter a published pick's line.
- SARAH: drafts pass copy-scan before NEEDS_REVIEW; refund/billing tickets → BOBBY + riskLevel=HIGH.
- Roadmap priorities: P0 settlement reliability (stale unsettled picks alert → JARVIS RED; proof: picks settle within N hours of final); P0 calibration semantics (persist modeled win-probability distinct from confidence UX score; market-aware proposals; bump MODEL_VERSION; operator sign-off); P1 model routing + caching (single `pickModelForSurface(surface)` function consumed via existing `options.model ?? …` slot); P1 agent-eval harness; P1 CLV capture ("the sharp's gold-standard, GSN already stores opening lines"); P2 integration tests vs disposable Postgres, odds failover, vuln triage, repo hygiene.
- Single highest-leverage SAFE improvement (additive, behavior-preserving): `pickModelForSurface()` in `apps/web/lib/claude-api/messages.ts` + optional `cache?: { system?: boolean; ttl?: "5m"|"1h" }` on `ClaudeMessagesRequest`; default map keeps every surface on Sonnet → zero behavior change; cache off by default (exact current body when omitted); verified via existing test (`claude-api-messages.test.ts:32` asserts only URL+headers, no body shape) + one new unit test (all surfaces map to Sonnet; cache.system:true adds cache_control block; no-cache body byte-identical).
- Metrics: tasks NEW→APPROVED median; % aging >24h/>72h; count of active Jarvis safetyWarnings; compliance-block rate; zero hard-stop violations; draft→approved acceptance per agent; $/surface and $/approved-artifact; cache-hit ratio.
- Transition logging: `transitionTask()` writes `CockpitDecision {toStatus, reviewer, note, evidence}` in the same transaction; reviewer free-text (`manual:garrett` | `system` | `agent:tal`).
