# performance/play-classification-layer.md
## What it is (1-2 sentences)
A Sports OS doctrine document governing video/computer-vision-derived play classification intelligence: the legal-rights framework (V3+ only for ML-driven classification), a near-term editorial (human-reviewed play notes) path, source quality tiers, forbidden claims, and approval gates.

## Key metrics/methods (formulas where given, else "not specified")
- **No formulas, no accuracy figures, no sample sizes stated.** Classification types are enumerations, not statistical methods.
- **TTLs:** 7 days for game-specific editorial notes; 30 days for season-trend notes.
- **Retention (ML path):** season active window; no off-season video retention. Storage = labels and scores only — NOT video frames, NOT frame extracts.
- **Source quality tiers:** licensed broadcast footage (T2, league agreement covering analysis); official tracking data NGS/2nd Spectrum (T1/T2, program enrollment + license); operator-entered editorial notes from licensed source (T3, requires verifiable citation); open tracking data/public aggregates (T3, editorial context only — no ML training); unlicensed broadcast footage, community video clips (YouTube/social), re-encoded broadcast clips — FORBIDDEN (copyright violation).
- **Version ladder:** V2 editorial enrichment (Cockpit play note entry, structured templates); V3 tracking-derived (NGS/Second Spectrum route/coverage classification via licensed API); V4 video-derived (licensed broadcast footage analysis with rights clearance).

## Data sources named
- **Open CV tools:** YOLO (YOLOv8 by Ultralytics — MIT model, commercial use allowed, input video must be rights-cleared); OpenPose (CMU — non-commercial academic license; commercial use prohibited without CMU license); MediaPipe (Google — Apache 2.0, commercial outputs generally permitted; video rights issue remains); detectron2 (Meta — Apache 2.0, same video-rights concern).
- **Commercial sports video analytics:** Hudl (commercial license, team accounts, no API for external commercial use of outputs); Catapult Video / formerly SportsTec (team accounts only); InStat (subscription, internal-use only, no redistribution).
- **Broadcast rights holders:** NFL (broadcast: CBS, Fox, NBC, ESPN/ABC; game film: NFL Films; no open access for CV analysis); MLB (similar structure; Baseball Savant provides limited authorized clips); NBA (content guidelines allow limited highlight embeds; raw game video analysis rights-restricted).
- **Editorial note required fields:** game_id (official league id), play_type (from allowed types), context (down, distance, score differential, quarter), source_citation (specific reviewed source), observation_date (ISO 8601), operator_id. Claim governance required; only near-term path is adding a `PlayNote` evidence type (Zone 3 schema addition).

## Findings (numbers and facts, not vibes)
- **Key finding (line audit, Wave 3):** "The computer vision tools themselves are mostly open-source. The blocking factor is the input video — broadcast game footage is copyrighted. Running YOLO or MediaPipe on NFL broadcast footage without a license agreement is a copyright violation, not just a ToS issue."
- License traps: OpenPose commercial use without CMU license (P1) — mitigation is MediaPipe or YOLO instead; OpenPose must not be in any production path.
- ML-derived classifications governed: pass/run classification (from formation, broadcast license), route classification (receiver, tracking license — NGS), coverage classification (man/zone/bracket, tracking), pitch type (radar license Statcast/Trackman), swing type (radar + video).
- Public/private boundary: editorial game-script note — PRO/ELITE with source attribution; play-type tendency aggregate — PRO/ELITE, licensed tracking only, no raw tracking coordinates; ML-derived route efficiency score — NEVER public until V3 licensed; raw tracking data — internal only; video clip in published content — only authorized/licensed clips; OpenPose/MediaPipe analysis of broadcast footage — NEVER.
- Forbidden claims list: "Our AI watched the game and..."; specific-play claims without a licensed source; "Route tree efficiency score" without active tracking license; play-tendency claims from social media/community aggregates; AI-generated play notes without operator review + citation.
- Approval gates: adding `PlayNote` schema type — Owner; any ML video classification — Owner + legal (broadcast license required); OpenPose commercial use — Owner + CMU license review; training any model on game footage — Owner + legal (training data license required separately); publishing picks citing play classification — operator review.
- Risk table: CV on unlicensed footage — P0 (block at ingestion; source must be licensed); community clips ingested — P0 (URL allowlist); frame-level video stored in DB — P1; ML training on copyrighted game footage — P0 (separate training-data license).
- No play classification infrastructure exists at writing time; editorial MVP = schema addition + Cockpit entry + PRO/ELITE surfacing under claim governance; explicitly NOT in editorial MVP: any ML model, any video processing, any automated play detection.

## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- **(QB-BEHAVIOR, COACHING, SCHEME)** The ML classification types (route classification from NGS tracking; coverage classification man/zone/bracket; pass/run tendency; game-script run/pass tendency by down/distance/score) are the licensed-source forms of exactly the signals the QB-behavioral, coaching-tendency, and scheme programs need — but every one requires a tracking or broadcast license before it can feed a model or a pick. CONTRADICTION note: the standing NGS internal-only doctrine (MEMORY.md 2026-09-28 — NGS metrics never shown publicly, reasoning fuel only) is compatible here (V3 route/coverage classification via licensed NGS API, labels internal), but the engine must treat "NGS route efficiency score" as doubly gated: licensed AND internal-only.
- **(OTHER — tracking lane)** The tracking lane's intake path is explicit: V3 tracking-derived classification via licensed NGS/Second Spectrum API, labels + confidence scores only, no frames, season-active retention — the lane's schema must never store tracking coordinates or frames, and raw tracking stays internal per both this doc and the public/private doctrine.
- **(OTHER — media/fair-use boundary)** The open-CV-tools-rights-cleared-only finding reinforces Garrett's standing video rule (real licensed footage only, short transformative clips): YOLO/MediaPipe/OpenPose output is not the legal risk — the input video is. This is load-bearing for any CV pipeline: URL allowlist + license-status on every ingested clip.
- **(OTHER — editorial trust path)** The editorial game-script example ("run-heavy on first-and-10 in the second half of close games, operator-reviewed, Week 1–12") is the only near-term legal route for scheme-tendency intelligence on the public surface (PRO/ELITE with citation) — human-reviewed play notes with verifiable citation and 7/30-day TTLs.
- **(OTHER — data hygiene)** "Open tracking data (public aggregate stats): T3 — editorial context only, no ML training" is a hard constraint for the training pipeline: public aggregates may inform editorial content, never model weights.

## Engine-actionable? (yes/no + one-line what)
**Yes** — route/coverage classification and game-script tendencies are on the licensed path (V3: NGS/Second Spectrum API), so the tracking lane should acquire only the licensed-API signal with labels-only storage, and the editorial path (operator-reviewed play notes with citations, TTL 7/30 days) is the only legal near-term source for public scheme-tendency content.
