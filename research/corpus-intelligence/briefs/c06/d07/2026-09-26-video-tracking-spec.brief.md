# engine/research/2026-09-26/2026-09-26-video-tracking-spec.md
## What it is (1-2 sentences)
A SPEC (not built, written 2026-09-26) for a broadcast-video-to-tracking pipeline that extracts player trajectories (field position, speed, acceleration, cumulative distance) from broadcast video for games without NGS tracking data (college football, historical NFL, all-22 film); stages S4–S6 ARE the V3 math primitive (homography → projection → kinematics), stages S0–S3 are the video front-end feeding it. Detector is a swappable interface with a permissive-license shippable path (`src/video_tracking/`) strictly separated from a restricted-license lab path (`lab/video_tracking/`).
## Key metrics/methods (formulas where given, else "not specified")
- S0 ingest: `t_sec = frame_idx / target_fps` (default 30; 29.97/60 resampled by frame selection, never interpolation); deterministic frame selection `keep_idx = round(i * src_fps / target_fps)`.
- S1 shot segmentation: TransNetV2 (F1 77.9–96.2) primary, PySceneDetect fallback; min shot length 30 frames (1s @30fps), shorter merged + flagged `qc_short_shot`; hard cuts only in v1; tracker/H state resets at every cut.
- S2 detection: RF-DETR Medium (`RFDETRMedium`, COCO AP50:95 54.7, 4.4ms latency), `model.predict(frame_rgb, threshold=0.5)`; only person class kept; NMS IoU default.
- S3 tracking: `trackers` pkg (roboflow, Apache-2.0). Default ByteTrackTracker (73.0 HOTA SportsMOT, 84.0 SoccerNet); moving-camera alternative BoTSORTTracker with CMC (`enable_cmc=true`, `cmc_method="sparseOptFlow"`, `cmc_downscale=6`; 73.8 HOTA SportsMOT, 84.5 SoccerNet); params `track_activation_threshold=0.25`, `minimum_consecutive_frames=1`, `minimum_iou_threshold=0.3`, `lost_track_buffer=30`; test §9.3 picks winner by ID-switch count — "do not assume". V1 scope: no cross-shot re-identification; IDs namespaced per shot.
- S4 homography: normalized DLT + RANSAC (10 px threshold); foot point `u=(x1+x2)/2, v=y2` (bottom-center of bbox; head/center NOT used); QC gate requires ALL: n_inliers ≥ 6, non-collinear spread incl. ≥2 sideline/endzone intersections, inlier ratio ≥ 0.6, held-out mean reprojection error < 5.0 px @720p (linear with resolution); failures emit rows with field coords NULL, never silently project. Per-frame refinement: 9-DoF Kalman on vec(H_t), σ_q=0.001 fixed / 0.02 follow cam; EMA fallback + jump rejection; hard reset at cuts; never extrapolate past last valid fit; failed runs ≤15 frames bridged (`qc_h_bridged`), longer fail loud (`qc_h_unstable`). Virtual yellow 1st-&-10 line and broadcast graphics explicitly excluded from landmarks. Hash-band conditioning trap: ~1.3 px in-band residual can drift off-line — sideline/endzone intersections mandatory. Template: NFL 120×53.33 yd, hashes 18.5 ft; NCAA 120×53.33 yd, hashes 40 ft; wrong template = silent 3.58-yd systematic bias; endzone depth param default 10. Accuracy context: no public football registration benchmark; soccer-derived JaC5 ~69–76, JaC10 ~87–93, MRE ~4.5 px; highest-leverage data investment = 200–500 hand-labeled frames.
- S6 kinematics: sort by t_sec, resample uniform at target_fps (forward-fill gaps ≤5 frames; longer gaps split segment), Savitzky-Golay smooth x(t), y(t) (window=9, polyorder=2) per segment; speed=hypot(dx/dt,dy/dt) central differences; accel=d(speed)/dt; dist_cum cumulative hypot over smoothed positions, reset per segment. QC: flag `qc_implausible_speed` if speed > 12.0 yd/s (~24.6 mph, above verified human max); flag `qc_implausible_accel` if |accel| > 12.0 yd/s². Units: yards, seconds; no mph in storage.
- Coordinate convention: field_x_yd ∈ [0,120] (x=0 back of endzone A), field_y_yd ∈ [0,53.33] (y=0 one sideline); orientation arbitrary per video, recorded as `orientation_note` in manifest.
- Test assertions (§9): determinism (sha256 identical across runs); synthetic homography < 5.0 px @720p, max midfield error < 0.5 yd, inlier ratio ≥ 0.6; hash-band-only landmarks must FAIL gate despite low residual; NCAA-on-NFL template must fail/flag (true bias 3.58 yd); ID switches ≤ 2 per 30s fixture, tracks-per-identity ≤ 1.5; kinematics: 10 yd/s synthetic → mean speed within 2%, |accel| < 0.5 yd/s², dist within 2% of 30.0; exactly 3 shots (±2 frame cut accuracy) on 2-cuts+1-dissolve fixture; tight-zoom segment → 100% rows homography_ok=false + NULL coords; 15 yd/s track → `qc_implausible_speed` flagged; performance target ≥10 fps end-to-end 1080p30 on one consumer GPU with RFDETRMedium.
- License verdicts: RF-DETR ≤L Apache-2.0 shippable; RF-DETR XL/2XL PML 1.0 DO NOT USE; Ultralytics YOLO family all AGPL-3.0 (v9 GPL-3.0) — lab only, no shippable YOLO without enterprise license; LocateAnything-3B NVIDIA non-commercial — lab only; TVCalib MIT shippable; PnLCalib license unverified — lab only until verified; Roboflow Universe `football-field-key-points-mvmjf/2` — terms unverified, lab only (identity correct ~16/20 frames All-22, localization coarse ±3–30 px — name lines, don't measure them); Nie et al. WACV'21 SportsFields — re-implement pattern (no public weights). Shippable path deps restricted to: RF-DETR (≤L), supervision (≥0.31.0 — note built-in sv.ByteTrack removed in 0.31.0), trackers, opencv, scipy, numpy; CI must fail build if `ultralytics`/`locateanything`/AGPL appears in shippable closure. No commercial training on CC BY-NC data (e.g., Big Data Bowl 2026 dataset).

Field templates `templates/nfl.json`, `templates/ncaa.json`. Nie et al. WACV'21 SportsFields dataset (incl. American football) — pattern to re-implement. Big Data Bowl 2026 dataset cited only as CC BY-NC restriction example. Test fixture: license-clean 30s 1080p30 broadcast-style clip with 2+ cuts + 1 dissolve (or synthetic), NOT NFL-copyrighted footage.
## Findings (numbers and facts, not vibes)
- Status is SPEC, not built — it is a build contract "for minis" with file layout given (`src/video_tracking/`, `lab/video_tracking/`, `tests/video_tracking/`).
- Tracker benchmark numbers: BoT-SORT 73.8 vs ByteTrack 73.0 HOTA on SportsMOT; 84.5 vs 84.0 on SoccerNet; fixture test decides, don't assume.
- RF-DETR Medium: COCO AP50:95 54.7, 4.4ms latency. TransNetV2 shot-boundary F1 77.9–96.2.
- NFL vs NCAA template mismatch = silent 3.58-yd systematic bias; `competition` is required/validated caller input.
- Keypoint model identity accuracy ~16/20 frames on All-22; localization ±3–30 px (too coarse for measurement — paired with Hough line geometry).
- Open items: PnLCalib + Roboflow Universe license verification (blocking shippable), 200–500 hand-labeled frames as highest-leverage data investment, license-clean fixture sourcing, competition auto-detection is v2, cross-shot stitching/jersey OCR v2, RF-DETR football fine-tuning as follow-up.
