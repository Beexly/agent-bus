# engine/research/cept/HONEST_CEPT.md
## What it is (1-2 sentences)
"Causal E-Process Theory — the defensible version" (v2.2, August 2026, by Garrett Ryan Baxley): GSE's mathematical framework for sequential, anytime-valid testing of forecast skill that survives performativity (published picks moving the market), with an explicit reflexive-limit impossibility theorem and a randomized-publication instrument; status: implemented, not yet validated.
## Key metrics/methods (formulas where given, else "not specified")
- Intervention-infimum E-factor: E_t = inf_{i∈I_t} p_t(Y_t|do(i)) / m_t(Y_t|do(i)); M_t = Π_{s≤t} E_s, M_0 = 1. Theorem 1: under (R1)–(R2), M is a non-negative supermartingale under every P∈H₀(I); Ville: sup_{P∈H₀} P(∃t: M_t ≥ 1/α) ≤ α; E_P[M_τ] ≤ 1 for every stopping time τ.
- Skill instrument (running in shadow): E_t = p_t/m_t if y_t=1; (1−p_t)/(1−m_t) if y_t=0; under null Bernoulli(m_t), conditional expectation exactly 1.
- Instrumented publication (Theorem 9): IPW score S_t = Z_t R_t/π_t − (1−Z_t)R_t/(1−π_t), π_t∈[ε,1−ε]; E_t = exp(λ_t S_t − λ_t² w_t²/8), w_t = B/(π_t(1−π_t)); load-bearing Hoeffding constant w_t²/8 (variance substitution destroys validity: example mean-zero score +9 w.p. 0.1 / −1 w.p. 0.9 has Var 9 yet E[exp(0.3·S − 0.09·9/2)] ≈ 1.44 > 1). Per-round growth maximized at λ* = 4Δ_t/w_t² with value 2Δ_t²/w_t² = 2Δ_t²π_t²(1−π_t)²/B². Second moment minimized at π* = √μ₁/(√μ₁+√μ₀).
- Hedge regret bound: √(T ln K/2) cumulative; BAEE cumulative log-loss within ln K of best single model (log-loss only, not Brier).
- Selective publication identity (Prop 5): BS_pub = π_δ(1−π_δ) − Var[P|published]; targeting Var[P|published] ≥ 0.03 always suffices for Brier ≤ 0.22; sharp requirement Var[P|published] ≥ π_δ(1−π_δ) − 0.22.
- Murphy decomposition measured: BS = REL − RES + UNC with REL ≈ 0.004, RES ≈ 0.0048 → UNC ≈ 0.2486 (base rate near 0.537/0.463).
