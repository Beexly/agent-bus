# engine/research/2026-09-28/signal-agreement-source-count-defect.md
## What it is (1-2 sentences)
A measured production audit (2026-09-28, read-only, branch motif/orchestration-v4-2026-09-28) proving the signal path's `agreement` field was a source COUNT (`sources.length >= 2 ? "CONFIRMS" : "SOLO"`), not an agreement — two estimators disagreeing in opposite directions were labeled "CONFIRMS" and printed to customers.
## Key metrics/methods (formulas where given, else "not specified")
Old rule: `agreement = sources.length >= 2 ? "CONFIRMS" : "SOLO"`. Fix in `packages/prediction-engine/src/independent-agreement.ts` (`sourceAgreement()`): a source votes only on a finite probability in [0,1] (out-of-domain dropped, not clamped); reads within SOURCE_DIRECTION_EPSILON = 0.005 of 0.5 abstain; votes on both sides → SPLIT; nobody votes → SPLIT; exactly one opinion → SOLO; otherwise CONFIRMS. Verified: tsc --noEmit 0 errors; new suite 14/14; slate+backfill suites 43/43. Fail-closed: "nobody agreed" can never be recorded as "everybody agreed".

## Findings (numbers and facts, not vibes)
- 990 published rows (agreement=CONFIRMS, 2026-06-15..2026-09-27) carry values produced by counting sources; how many are actually false is NOT DETERMINABLE from stored data (rows keep source names, not each source's own homeFairProb).
- Blast radius: only consumer that matters is `pick-explainer/grounding.ts:141` (display string printed to customers, e.g. "agreement CONFIRMS" for poisson+mlb_standings LEAN); no probability, confidence, decision, conviction, or published row affected; signal-staleness treats SPLIT and CONFIRMS identically.
- Adjacent measured finding: NFL signal path is structurally SOLO — last 10 days sources were ["elo"] 124, ["poisson","mlb_standings","elo"] 79 (baseball), ["skellam_cover"] 47, ["poisson","elo"] 5, ["mlb_standings"] 2; zero NFL rows with >1 source. Root cause: `NFL_EPA_MIN_GAMES = 4` (nfl-epa-fair-value.ts:29) vs avg 2.94 games/team in weeks 1–3 — `nflEpaToIndependentFairValue` returns null for every 2026 team, so source 9 can never emit; solo by construction. NFL_NAME_TO_ABBR ruled CORRECT (all 32 codes incl. LA match).
- Founder decision forced: lower NFL_EPA_MIN_GAMES 4→3 or accept solo NFL until week 5 (MODEL_VERSION territory); warning: Elo/EPA correlation is UNMEASURED — fake corroboration is worse than honest SOLO (0.6 discount); a first EPA discrimination query was degenerate (avg_home_margin exactly 0.0000 over 17 of 68 matched games, self-join matched a row against itself) — draft only, number not reported.
- Injuries table cannot validate an injury second source: fetchedAt is the bulk-ingest clock (identical for weeks 1–3 incl. played games), no computedAt <= decisionAt ordering — backtesting an injury coefficient on it is a lookahead artifact (same as the retracted line-movement finding).
