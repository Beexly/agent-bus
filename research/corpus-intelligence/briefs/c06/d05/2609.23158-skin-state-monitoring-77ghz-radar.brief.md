# dfs/research/2026-09-25/arxiv-deep/2609.23158-skin-state-monitoring-77ghz-radar.md
## What it is (1-2 sentences)
A deep-ledger read of arXiv 2609.23158 (KAUST, Sep 19, 2026): can a 77 GHz FMCW radar classify pre- vs post-exercise physiological skin states from single-chirp (102.4 µs) chest snapshots using Wavelet Scattering Transform features and lightweight classifiers, in a leave-one-subject-out setting? The ledger's verdict is REJECT — no transferable GSE input stream, task, or edge exists.

## Key metrics/methods (formulas where given, else "not specified")
Pipeline: (1) FMCW range profiling via FFT across fast time; (2) chest-response selection — Hamming window, range FFT, second-order-section (SOS) Butterworth band-pass retaining dominant chest-reflection interval; (3) Wavelet Scattering Transform with analytic Morlet (Gabor) wavelets, invariance scale 128 samples, quality factors Q = [2,1], [4,1], [8,1]; (4) classifiers: Naive Bayes, SVM, KNN, Kernel-based, feedforward NN.
Equations (copied faithfully):
- Transmit chirp: `s(t) = e^{j2π(fc + Bt/(2T))t}`, 0 < t < T
- Received signal: `r(t) = Σ_{l=1}^{L} α̃_l e^{j2π(fc + Bt/(2T))(t−τ_l)} + n̄(t)` (1), with `τ_l = 2R_l/c`, `n̄(t) ~ N(0, σ²)`
- Demodulated: `x(t) = Σ_{l=1}^{L} α̃_l e^{j2πfcτ_l} e^{j2π(Bτ_l/(2T))t} + n(t)` (2)
- Beat-frequency form: `x(t) = Σ_{l=1}^{L} α_l e^{j2π(2BR_l/(cT))t} + n(t)`, 0 ≤ t ≤ T (3), `α_l = α̃_l e^{j4πfcR_l/c}`; beat freqs `f_bl = 2BR_l/(cT)` estimated by range FFT
- Hamming windowing: `xw(t) = x(t) · w(t)` (4)
- Skin–air reflection: `Γ ≈ (1 − √ε*) / (1 + √ε*)`, ε* = local complex permittivity
Assumptions: normal incidence, L point targets, AWGN, quasi-static target over 102.4 µs, 7.5 cm range resolution isolates chest, single Tx–Rx channel representative.
Validation: primary = leave-one-subject-out (LOSO) cross-validation, mean ± SD across subjects with 95% CI; secondary = random 5-fold CV × 10 runs (higher, as expected; noted as leakage-prone).

## Data sources named
- Hardware: INRAS 77 GHz FMCW MIMO radarbook, 2 GHz bandwidth, 2 Tx / 16 Rx antennas, single Tx–Rx channel, 1 m standoff from chest; chirp T = 102.4 µs, 256 fast-time samples/chirp, ~7.5 cm range resolution
- Subjects: 15 university-level ultimate frisbee athletes, IRB KAUST Protocol 24IBEC032, written informed consent
- Protocol: pre = 15 min rest in hot outdoor environment (1–2 min radar); post = within 10 min after 2 hours intense activity with water intake restriction (1–2 min radar)
- Schema: 125 single-chirp samples selected per subject per condition → 1875 samples/class, 3750 total; WST tensor 25 (paths) × 8 (temporal windows) × 3750 → reshaped 3750 × 200 feature matrix; binary label pre-activity / post-exercise
- No code, no dataset release, no repository link; WST is a standard method (Mallat, 2012) implementable from public libraries

## Findings (numbers and facts, not vibes)
- Abstract headline: mean classification accuracy **91.55%** with 95% CI **[84.27, 98.83]%** on 15 sportsmen, LOSO (feedforward NN).
- Full LOSO table (mean ± SD, 95% CI): NB 76.35 ± 15.98 [68.26, 84.43]; SVM 80.32 ± 15.85 [72.30, 88.34]; KNN 77.87 ± 14.55 [70.50, 85.23]; Kernel 85.07 ± 13.90 [78.03, 92.10]; NN 91.55 ± 14.39 [84.27, 98.83].
- Random 10-run CV accuracies (leakage-prone): NB 89.84 ± 1.52, SVM 92.16 ± 1.12, KNN 90.29 ± 0.87, Kernel 96.51 ± 1.11, NN 99.28 ± 0.56 — the NN CV→LOSO drop (99.28 → 91.55) evidences within-subject leakage in random CV.
- Feature-order contributions (|t|-statistic ranking): zeroth-order S0 ≈ **67.9%**, second-order ≈ **24.4%**, first-order ≈ **7.6%** — low-pass signal energy/amplitude stability dominates; WST beats raw-signal baseline; Q = [4,1] chosen as best tradeoff; WST Q41 reshaping beats WST0 Q41 unfolding.
- Adversarial findings: n = 15 subjects with 250 highly correlated chirps/subject; LOSO CI 14.6 points wide — per-subject accuracies unreported, some held-out subjects plausibly near chance; no ground truth (no corneometry, skin temperature, sweat electrolytes, body-mass loss); 125-chirp "selection procedure" never specified; post-exercise subjects were panting/shifting at 1 m standoff — classifier may detect "exhausted moving person vs calm resting person," not skin permittivity; 2-hour ambient drift unreported; binary pre/post split is the easiest possible task; t-statistic interpretability analysis admits non-independent samples (inflates |t|); single-sport population (ultimate frisbee), demographics unspecified.
- Gate score: 0/3 → REJECT (no transferable data stream, no structurally similar demonstrated application, no evidence of edge over simple features).
- Speculative test defined but not executed: WST vs simple features on pregame line-movement trajectories labeled by CLV outcome, group-out (leave-one-week-out) validation, pass criterion ≥ 0.02 AUC out-of-sample with gain concentrated in non-zeroth-order coefficients.
