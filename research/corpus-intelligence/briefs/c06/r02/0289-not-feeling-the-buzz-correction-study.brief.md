# arxiv-program/research/2026-09-21/arxiv-deep/0289-not-feeling-the-buzz-correction-study.md
## What it is (1-2 sentences)
A full-depth research note on Clegg & Cartlidge (2023, arXiv:2306.01740v4), a replication-and-correction study of Ramirez, Reade & Singleton's "Betting on a buzz" claim that Wikipedia crowd-interest (WikiBuzz) predicts bookmaker mispricing in WTA tennis — the replicators confirmed the mispricing regression but showed most Bet365 profits came from a single erroneous 5.50 quote (true market max 2.10), and the edge died after Feb 2020. The note's verdict is ADOPT: its QA lessons (odds-feed row validation, Kelly x data-error interaction, random-betting significance) are directly actionable for GSE's odds pipeline.
## Key metrics/methods (formulas where given, else "not specified")
- Mincer-Zarnowitz mispricing regression (eq. 1): e_ij = alpha + beta_1 z_ij + beta_2 RankDist_ij + beta_3 WikiBuzz_ij + psi_{S(j)} + phi_{T(j)} + epsilon_ij, SEs clustered by tournament-match.
- z_ij = 1/odds_ij (raw decimal, overround kept); RankDist_ij = -(1/rank_i - 1/rank_j), unranked -> 0; WikiBuzz_ij = ln(w_i/w~_i) - ln(w_j/w~_j) (yesterday's Wikipedia views vs 1-year median).
- Outcome model (eq. 5): p~-ij = alpha-hat + (1+beta-hat_1) z_ij + beta-hat_2 RankDist_ij + beta-hat_3 WikiBuzz_ij; Kelly staking (eq. 7): f*_ij = max(p~-ij - (1-p~-ij)/b_ij, 0), b = decimal odds - 1; bankroll reset to 1 per bet.
- Profit (eq. 8): pi_ij = f*x odds - f* if win, -f* if loss; ROI (eq. 9) = sum pi / sum f*; absolute return = B_T/B_0.
- Significance: Wunderlich & Memmert (2020) random-betting bootstrap — p_bs = probability a random strategy of same bet count matches returns, via 100,000 trials.
## Data sources named
RRS original dataset (github.com/philiprami/betting_on_a_buzz): WTA matches tennis-data.co.uk Jul 2015-Feb 2020, Bet365/market-average/best odds (40-60 books via oddsportal.com), WTA rankings, Wikipedia page-view metrics (Wikimedia Pageview API); in-sample 2016-2018 (15,854 player-matches). Authors' cleaned/extended dataset (github.com/Faxulous/notFeelingTheBuzz): 35,274 rows, 17,751 matches, 584 players, Jul 2015-Aug 2023, after dropping new-player rows, Bet365>best-odds rows, missing-odds rows, 4-SD outlier rows. WTA tennis only.
## Findings (numbers and facts, not vibes)
- Mispricing confirmed: beta-hat_3 (WikiBuzz) = 0.009 (0.004), beta-hat_2 (RankDist) = 0.055 (0.029), significant; RRS Table 4 PM ROI 17.26% is a typo — Stata code shows 17.29%.
- The Hercog bet: 39.3% of bankroll at Bet365 quote 5.50 vs market max 2.10 (Polona Hercog rank 93 vs Misaki Doi rank 112, 22 Mar 2019; 14th-longest winner odds in 2019). Removing it: PM ROI 17.29% -> -7.36%, absolute return 1.24 -> -0.50; PM w/o RD ROI 28.82% -> -6.31%, return 1.44 -> -0.29.
- Surviving strategy: competitive matches PM w/o RD, p in [0.4,0.6] — ROI 29.38% -> 12.44% after removal (263 bets, overround 7.01%), p_bs = 0.002. Broader p in [0.2,0.8]: 20.11% -> -3.36%. Non-competitive: 0.81%, p_bs = 0.22 (not significant). Best-odds strategy ROI 3.05% (2,350 bets, -0.24% overround), unaffected (best odds correctly 2.09).
- Extended data: competitive strategy earns zero further profit after Feb 2020; re-estimated Feb 2020-Aug 2023 (13,913 player-matches): WikiBuzz beta-hat_3 = 0.001 (0.004), p = 0.837; RankDist p = 0.471 — both insignificant. Edge died.
- Cleaning removed 2,020 new-player + 32 Bet365>best-odds + 174 missing-odds + 200 four-sigma outlier rows.
- Limitations: no walk-forward (single train/test split); Bet365-only strategies as good as the feed; p_bs tests returns not the model; Wikipedia bot traffic unverified; edge death not identified (efficiency vs regime shift).
## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, OTHER)
- TRUST-SIGNAL (primary): three operational rules for GSE — (1) odds-sanity filter (drop/flag book quote > cross-book best by >3 SD of best-minus-mean spread, plus z-score consensus outliers) before backtest data is written; (2) Wunderlich-Memmert 100k random-betting bootstrap as mandatory significance screen (never post a strategy with p_bs > 0.05); (3) cap fractional Kelly (<=0.25x full Kelly) to bound single-row data-error damage — full Kelly amplified one bad row into 39.3% bankroll at 5.50.
- OTHER: NFL WikiBuzz analog exists to test — beat-writer/news/X engagement volume per team in 48h pre-kickoff (log-ratio vs season median, mirroring eq. 4) + rank/Elo distance in a Mincer-Zarnowitz regression on NFL moneylines; this fills ML-brief area 13 (text/news as features).
