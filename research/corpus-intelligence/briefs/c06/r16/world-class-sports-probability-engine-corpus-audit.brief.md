## Key metrics/methods (formulas where given, else "not specified")
- CQR non-conformity score: E_i = max(q̂_{α_lo}(X_i) − Y_i, Y_i − q̂_{α_hi}(X_i)); conformal rank index k = ⌈(n + 1)(1 − α)⌉.
- Quantile-clamping result: α=0.10, n=5 → k=⌈6×0.9⌉=6>5, forcing empirical quantile to +∞; clamping to n=5 delivers true coverage n/(n+1) ≈ 83.33% while presented as 90% → 6.67 percentage-point under-coverage defect ("fake tightness").
- Fail-closed rule: when n < ⌈1/α⌉ − 1, emit infinite intervals [−∞, +∞] or abstain via No-Bet block; Jackknife+ gives ≥ 1 − 2α coverage without a calibration holdout.
- Generalized Venn-Abers: dual isotonic regressions → multiprobability bounds [p_0, p_1]; interval width (p_1 − p_0) is the epistemic-uncertainty measure; example No-Bet gate at p_1 − p_0 > 0.20 (policy choice, not derived).
- Loss shift: BCE → Brier loss ("drastically optimizes baseline point-estimate calibration" per NCAA-data evaluations); parameter estimation error ∝ d/n.
- Forecast-Skill E-process: anytime-valid sequential likelihood-ratio martingale under Ville's inequality, testing H0 "model no better than market consensus."
- Hawkes steam detection: per-side exponential-decay Hawkes self-exciting process with online intensity updates separating informed steam from organic volatility.
- Engine modules named: `shadow-evaluation-pass.ts`, TeamStrengthFilter (ETKF), `FilterStateSnapshot`, `ShadowSignal`, VERSA gates, `scheduler-liveness.ts`, `traffic-heartbeat.ts`, `hawkes-steam.ts`, `forecast-skill-eprocess.ts`, `robust-kelly.ts`.
- Table 3 ledger: 278 rows verified (SHEET=258, READ=20; GSE-relevant=Y 155/278; sheet_inflated=Y 123/278).
- State-space: latent strength as stochastic process with sport-specific σ_game; ETKF + sequential Monte Carlo particle filter; AR(1) decay between seasons, random walk within seasons.
