# props/research/2026-09-18/report.md
## What it is (1-2 sentences)
A 2026-09-18 research mission reverse-engineering HOW 9 NFL analytics creators (charts published on X ~Sept 17–18, 2026) produce their numbers, marking claims as confirmed / inferred / unknown-proprietary, so an independent team can replicate, improve, or find the data feeds behind each creator's outputs.
## Key metrics/methods (formulas where given, else "not specified")
- **Common foundation:** nflverse PBP; nflfastR cleans PBP and applies EPA/WPA models. EPA/WPA formal definition: ending-state value minus starting-state value (from nflWAR paper, degruyterbrill.com/doi/10.1515/jqas-2018-0010). nflfastR documents `epa`, `wp`, `wpa`, `vegas_wp`, `vegas_wpa` fields. `calculate_win_probability()` inputs: possession, score differential, clock, spread, down, distance, yard line, timeouts, second-half kickoff indicator.
- **@sfdata9ers (inferred rate formulas, denominators not documented):** `motion_rate` = motion-tagged eligible offensive plays / offensive plays; `screen_rate`, `play_action_rate` = screen/PA plays / relevant pass/dropback plays; `no_huddle_rate` = no-huddle snaps / offensive snaps; `rpo_rate` = RPO-tagged plays / charted offensive plays; `avg_opponent_drive_start_yardline` = mean start yard line of first offensive drive after a team's kickoffs (penalty/onside/return-TD/end-of-half treatment unknown).
- **@ThunderDanDFS Matchup Grade (confirmed inputs, black-box composite):** Week 1 article states it incorporates PFF (grades, O-line data) and FTN DVOA, evaluating blocker quality, offensive scheme, projected role/usage, projected game script — explicitly NOT RB elusiveness/explosiveness/broken tackles. Week 1 used 2025 data with manual personnel/coaching adjustments (analyst override). Inferred: passing matchup grade = f(defense pass DVOA, CB coverage grades, pressure rate, OL pass-block grades); rushing matchup grade = f(defense run DVOA, DL/LB run-defense grades, adjusted line yards, OL run-block grades, RB projected role/share, game script). Implied totals from spread/total via `team_implied_total = total/2 − signed_spread/2`. Related 2026 D/ST method uses DVOA, adjusted sack rate, turnover rate, scaled 0–100 (suggests his 0–100 normalization; does not prove grade weights).
- **@SamHoppen "How the game was won" (confirmed nflfastR feed, inferred categorization):** single-game WPA/EPA decomposed into 10 mutually exclusive facets — Pass Off, Run Off, Pass Def, Run Def, Takeaways, Giveaways, Off Pen, Def Pen, Special Teams, Other. Inferred precedence (needs confirmation): turnovers > penalties > offensive pass/run > defensive pass/run > kicks/punts/returns/FG/PAT > Other. Sanity checks: total EPA additive over plays; WPA should telescope to ≈ final WP − initial WP if every play assigned exactly once (each play's WPA = WP_after − WP_before from team's perspective).
- **@benbbaldwin Team Tiers (confirmed concept: market-implied ratings, inferred blend):** transforms spreads into market-implied ratings with home-field adjustment (2021 market HFA ≈ 0.62 spread points, per PFF explainer). Implied-SRS recipe (footballperspective.com): adjust each spread for HFA, solve team ratings iteratively (transitive spreads). Implementation pattern (gist/boooeee): build team-incidence matrix (home − away), regress spread/margin on it; intercept estimates HFA; team coefficients demeaned to league-average zero. Inferred futures blend: convert American futures odds to raw implied probabilities; de-vig mutually exclusive markets (division/conference/SB) by normalizing within market; for playoff/#1-seed yes/no, normalize paired sides; fit latent team strengths `r_i` and HFA so predicted home margin = `r_h − r_a + HFA` matches near-term spreads while neutral-field win probability (calibrated margin→win logistic/CDF) matches futures-implied probabilities; minimize weighted loss, weighting liquid near-term lines above long-tail futures. Exact Baldwin weights/optimizer unknown/proprietary.
- **@MagicSportsGuy / StatRankings (inferred, formulas standard):** `target_share` = player targets / team targets; `first_read_share` = first-read targets / team first-read targets; `tprr` = targets / routes run; `yprr` = receiving yards / routes; `fp_per_route` = scoring-format points / routes; `alignment_share` = routes at left/right/slot/backfield / routes; assignment/overlap map = projected offensive alignment distribution × defender side/slot assignment rates normalized to 100%; percentiles = empirical percentile rank vs same-position/alignment peer group (minimum-route cutoff unpublished).
- **@tejfbanalytics/SumerSports:** `under_center_rate` = qualifying under-center offensive snaps / qualifying offensive snaps; `under_center_epa_per_play` = Σ EPA on qualifying under-center plays / count. Exclusions (no-plays, spikes, penalties, kneels) unpublished.
- **@Shauncore (PFF QB scatter, inferred denominators):** `pff_positive_grade_rate` = count(grade > 0 on eligible QB pass plays) / eligible graded QB pass plays; `pff_negative_grade_rate` = count(grade < 0) / same denominator; zero-graded plays stay in denominator but neither numerator. PFF grading system (confirmed): every player/play graded −2 to +2 in 0.5 increments (0 = expected), position-specific rubrics, situational adjustment, converted to 0–100 facets.
- **@b_peters12:** no closed-form formula — qualitative manual film charting (concept family, splits, motion, protection, routes, pre/post-snap shell and rotation, QB progression/key defender). Concept names not standardized ("Funnel" vs "Choice/Diagonal" overlap).
- **Top-5 ranked replicable metrics (predictive value × replicability × uniqueness):** 1) market-implied neutral team strength (after Baldwin); 2) coverage/shell-weighted receiver matchup (after MagicSportsGuy + Heath); 3) offense/defense EPA–WPA facet decomposition (after Hoppen); 4) under-center usage × efficiency (after SumerSports); 5) playcalling tendency rates + O-line/run matchup composite (after sfdata9ers + ThunderDan).
## Data sources named
- nflverse PBP (free/public; CSV/Parquet/RDS/QS via https://github.com/nflverse); nflreadr, nflfastR (R), nflreadpy (Python), nflseedR (playoff simulation) — all free.
- FTN Fantasy proprietary in-house charting (routes, motion, coverage, play concept, pressure, stacked box, offense/defense/ST) — paid (FTN Fantasy StatsHub subscription; no public API). FTN DVOA also paid/proprietary.
- PFF proprietary per-play grades −2..+2 — paid (PFF data products; subscriptions). PFF grades + O-line data power ThunderDan's grades.
- SumerSports proprietary play/frame charting ("300+ data points many times per second", real-time pressure/route/coverage charting; formation/coverage/personnel/game-state filters) — subscriber web UI only, no public/documented API; data via authenticated web app; slates update within 2 hours after final game. **Pricing confirmed live 2026-09-18: $10/week, $20/month, $100/year, 7-day free trial for first-time subscribers.** Unverified (from parent's lead, not independently sourced): Sep. 18 launch of LB/defensive-interior/edge tables; preseason/postseason coverage from 2022; `WELCOME15` promo code.
- StatRankings (Kevin Adams, launched per accessnewswire release: 24+ years continuously updated NFL data, projection models, betting trends back to 2000) — no data provider disclosed, no public API; data source unknown/proprietary or paid charting. Do not assert FTN is the source.
- Fantasy Points Data Suite (proprietary coverage/schematic charting: shells, man/zone, alignments, route concepts) — paid; 2026 Advanced Matchups formula paywalled, not accessed.
- The Odds API v4 (verified live endpoint): `https://api.the-odds-api.com/v4/`, sport key `americanfootball_nfl`, markets `h2h,spreads,totals`, bookmakers include draftkings, fanduel, pinnacle; API-key auth; paid/freemium with free tier (capability map: github.com/spablog25/nfl25-agent docs/odds_api_v4_capability_map.md).
- DraftKings game-lines public page (sportsbook.draftkings.com, SPA JSON undocumented; scraping posture unverified — rumored, not confirmed).
- Licensed game film/All-22 (e.g., NFL Game Pass) for manual concept charting (@b_peters12).
- Supporting sources: Aaron Schatz interview on FTN route data (acmepackingcompany.com, 2024-08-14) — route-denominator metrics more stable/predictive; Mock Draft Database probabilities (probability matrix from 79 mock drafts, each team's probabilities summing to 1); RotoViz GPS Matchup Rater; ESPN shadow reports (espn.ph story id 32166443).
