# product/b2b-widgets-and-api-spec.md
## What it is (1-2 sentences)
Phase 5 build spec turning the Intelligence Graph into a B2B product line: four embeddable widgets (Edge Index, Market Pulse, Slate Weather, Model Court) plus a paid REST API under `/api/intelligence/*`, both sharing the same compliance scanner. Code lives at `apps/web/app/embed/`, `apps/web/app/api/intelligence/`, `apps/web/lib/b2b/`; code owner is Codex, buyer personas/sales copy/pricing taxonomy owner is Claude, pricing itself deferred per DEC-OPEN-C.
## Key metrics/methods (formulas where given, else "not specified")
No mathematical formulas specified. Concrete operational parameters specified:
- API key schema: `keyPrefix` (unique, e.g. `gse_live_...`), `keyHash` = SHA-256 of full key; fields: ownerUserId, organizationId (optional), name, tier (BASIC | PRO | ENTERPRISE), rateLimitPerMin default **60**, domainWhitelist (String[]), isActive, expiresAt, timestamps; usage metered per key in `ApiKeyUsage` (endpoint, statusCode, latencyMs, observedAt).
- Edge cache: API responses edge-cached for **60 seconds** (stable response for same game within a 60s window).
- SLA (Enterprise only): **99.9% uptime**, **99th percentile latency < 500ms** for Game / Slate / Ledger endpoints; status page at `status.galaxysportsedge.com`; Pro and Basic = best-effort.
- Pricing sketch (owner-only, subject to revision): Basic **$99/mo**, 10,000 API calls/mo, Edge Index widget free + Market Pulse widget; Pro **$499/mo**, 100,000 API calls/mo, all widgets except Model Court, domain whitelist of 5; Enterprise custom, unlimited with fair-use, Model Court widget, domain whitelist of 25, SLA, account manager.
- Per-call cost note: Model Court is the most expensive widget to operate (Claude API calls per question) — pricing reflects it; creator-pack endpoint pricing reflects Studio generation cost per call.
## Data sources named
Intelligence Graph projections; `GameIntelligenceNode` (full projection for game endpoint); `SlateWeather` for slate date endpoint; `ModelCourtCase` for the explain endpoint; settled-pick ledger records (full historical access vs public `/ledger` which respects bootstrap gating); market data via "consensus across reporting books"; Galaxy Memory slot (post-settlement), Evidence Timeline, lens projections (Enterprise tier only). No external data sources named.
## Findings (numbers and facts, not vibes)
- 4 widgets specced: `/embed/edge-index/[gameId]` (FREE, public, no auth, always branded with Galaxy logo + link — positioned as the SEO/credibility distribution wedge), `/embed/market-pulse/[gameId]` (PAID: consensus across reporting books, line movement since open, volatility flag, sharp money signal when present, last-update timestamp), `/embed/slate-weather` (PAID: daily slate context across all subscribed sports), `/embed/model-court/[gameId]` (PAID, higher tier: conversational Q&A grounded in one game's Intelligence Graph, API key + Galaxy user OAuth embedded).
- 5 API endpoints: `GET /api/intelligence/game/[id]` (tier-graded: Basic = Edge Index + Market Pulse + basic factor breakdown; Pro adds full factor breakdown + pre-mortem; Enterprise adds Memory slot, Evidence Timeline, lens projections), `GET /api/intelligence/slate?date=YYYY-MM-DD`, `GET /api/intelligence/creator-pack?gameId=...` (Studio-style asset pack: pre-generated short-form copy + citations for re-use), `POST /api/intelligence/explain` (body: `{ gameId, question, lens? }`, returns ModelCourtCase), `GET /api/intelligence/ledger?from=...&to=...&filters=...` (paginated settled picks, path-to-researcher-program per DEC-006).
- 7 buyer personas A–G: A = indie newsletter writer (5–50k Substack/Beehiiv subscribers, Basic); B = Discord capper community (500–5k members, Pro, Model Court widget); C = fantasy DFS content shop (50k+ daily readers, Pro/Enterprise, Slate Weather + creator-pack); D = local sports media site (100k+ monthly readers, Basic, free Edge Index wedge); E = sportsbook affiliate content arm (Enterprise, custom contract, compliance + retention as a service); F = academic researcher (free/discounted with co-authorship credit, Researcher Program per DEC-006); G = fintech adjacency/prediction markets (Enterprise).
- Compliance hard-refuse list for ALL widget/API output: banned vocabulary in rendered content; aggregate win-rate claims; "best book" / "sharpest" / competitor comparisons; personal betting advice. Scanner runs on all returned content; JSON response shape prevents most banned-vocabulary leaks at source; Claude-generated content (Model Court answers, Studio packs) scanned before return.
- 10 acceptance criteria for Phase 5 B2B v0: key management at `/b2b/keys`, auth + rate limiting enforced, docs at `/b2b/docs`, all four widgets shippable, domain whitelist enforced, usage metering per key, compliance scanner on all content, status page live, complete documentation site (per-endpoint examples + SDK reference if any), and the commercial gate: at least 3 buyer personas with signed pilot agreements.
- 5 open items: OPEN-B2B-1 SDK vs REST-only (default: JS SDK v0, Python Phase 6+); OPEN-B2B-2 per-org vs per-user keys (default: per-user with optional org grouping); OPEN-B2B-3 Edge Index free forever (default: yes, it's the distribution wedge); OPEN-B2B-4 API white-labeling (default: yes, Phase 6+, Phase 5 ships Galaxy-branded only); OPEN-B2B-5 pricing DEC-OPEN-C unresolved.
