# data/CFB_SOURCE_DECISION_2026-09-04.md
## What it is (1-2 sentences)
A verified 2026-09-04 decision memo on college football data sources: it reads CFBD's terms verbatim (permissive for derived commercial use, fetched 2026-08-12 effective terms), identifies the one open CFBD question (whether the unsuffixed `spread`/`over_under` fields are the closing line), corrects the recurring "nflverse has no closing lines" error with data, and ranks five calibration papers for a frozen deterministic model.
## Key metrics/methods (formulas where given, else "not specified")
- GameLine schema fields (fetched from CFBD/cfbd-python/docs/GameLine.md, no descriptions on any field): `provider · spread · formatted_spread · spread_open · over_under · over_under_open · home_moneyline · away_moneyline`. No closing-line label, no timestamp.
- nflverse evidence: `games.csv` carries `spread_line, total_line, home_moneyline, away_moneyline` on **7,276 rows** with finals; the 27-season replay (`docs/data/NFL_REPLAY_CALIBRATION_2026-09-04.md`) computed **15,939 settled picks** from those columns; spread-sign verification `corr(spread_line, result) = +0.4260` across those rows.
- sportsdataverse `espn_cfb_betting`: self-describes as "closing betting lines and odds", 23 seasons (2004–2026), 48 assets, 286 KB, last asset written 2026-08-27. No moneyline observed (`home_moneyline`/`away_moneyline` NOT OBSERVED); no `home_team`/`away_team` in the betting table (join on `game_id` to schedules).
- Calibration papers (ranked for frozen deterministic models — calibrate outputs, no `MODEL_VERSION` bump to evaluate):
  1. Variable-Based Calibration (Kelly & Smyth; code: markellekelly/variable-wise-calibration): train a decision tree on one chosen variable, fit a per-leaf calibrator — direct fix for the recorded defect "no code path conditions calibration on sport"; split on sport (or favourite strength), freeze, report variable-based calibration error alongside ECE.
  2. Foulley, football forecast verification: reliability, Brier decomposition, discrimination on held-out chronological data — formalizes what the replay doc computes by hand, makes the number literature-comparable.
  3. Conformal prediction beyond exchangeability (Barber, Candès, Ramdas, Tibshirani): recency-weighted quantiles for temporal drift — cited as directly relevant: nfelo's 2009–2024 close-game ATS was **55.06%** but **2024 alone was 45.3%**.
  4. Dirichlet calibration (Kull et al.; has code): multiclass — principled answer to the soccer three-way market that PR #694 suppresses because de-vig is two-way. Not a launch item.
  5. Temporal Probability Calibration (Leathart & Polaczuk): per-horizon calibration maps — relevant only once lines are priced at multiple horizons, requiring an open/close archive not held.
- CLV framing: nflverse gives close only, so every backfilled NFL pick grades `MATCHED_CLOSE` with CLV structurally unmeasurable; if CFBD's unsuffixed fields are the close, CFBD gives open AND close on one row — CLV measurable for NCAAF before NFL.

## Findings (numbers and facts, not vibes)
- CFBD terms VERIFIED by direct fetch: "Commercial use is permitted. Your subscription tier determines your API usage quota, not whether you may use the API commercially." Explicitly permits: privately cache/store/normalize/retain API responses; retain API Data in a private historical corpus after access ends; "historical analysis, backtesting, feature engineering, and model training"; "publish and commercialize independently created analyses, models, model weights, predictions, projections, rankings, visualizations, and other Derived Outputs." Prohibits: selling/sublicensing/publishing API Data as a standalone dataset or bulk download; operating a raw feed, public database mirror, proxy, substitute API, or substantially equivalent data service.
- Registry entry `source-rights-registry.ts:735` stays `vendor_candidate`, all flags false: (1) no free CFBD API key obtained; (2) terms need a *human/legal* read — an agent's fetch is not that. Flipping is the founder's call.
- The registry's standing "terms page is JS-rendered and NOT machine-verifiable" objection is **stale** — it reads fine now.
- CFBD open question = line semantics, not legality: unsuffixed `spread`/`over_under` could be the close (→ both ends of the move on one row) or just "most recent seen" (→ un-defendable CLV). Answerable with a free key + one `/lines` request vs a known closing number. Do NOT compute CLV from these fields until resolved.
- sportsdataverse disqualified on two grounds: no licence (absent licence ≠ permissive; sibling LICENSE path 404s) and no moneyline (engine scores three markets; this feeds two). Pursue only if licence is established.
- The "nflverse has no closing lines" claim is wrong — third time recorded, disproved by the repo's own data (7,276 games.csv rows; 15,939-pick replay; corr +0.4260). Cause each time: reviewer opened the play-by-play release or the nflreadr README instead of the `schedules`/`games.csv` release. Consequence of leaving it uncorrected: it argues for licensing a college source to solve an already-solved NFL problem.
- "Every calibration sample is non-football" defect is on record — variable-based calibration (split on sport) would have caught it automatically.
