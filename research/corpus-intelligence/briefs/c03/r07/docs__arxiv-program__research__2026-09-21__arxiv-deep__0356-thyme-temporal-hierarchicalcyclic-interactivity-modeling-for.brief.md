# docs/arxiv-program/research/2026-09-21/arxiv-deep/0356-thyme-temporal-hierarchicalcyclic-interactivity-modeling-for.brief.md
## What it is (1-2 sentences)
Ledger for Nguyen et al. (2025), arXiv:2507.09200v1 — THYME, a SOTA video scene graph generation model combining hierarchical multi-scale spatial aggregation with cyclic temporal attention, evaluated on ASPIRe (ground-view) and the new AeroEye-v1.0 drone dataset. Verdict: ADAPT — the hierarchical + cyclic-attention recipe and five-type interactivity schema are portable to GSE's real-footage clip tooling as player–player interaction graphs from NGS tracking data.
## Key metrics/methods (formulas where given, else "not specified")
- Pipeline: (1) DETR detector → per-frame object query embeddings q_i^{(t)}; (2) hierarchical aggregation F_t^{(l)}(S_i^{(t)}) = σ(Σ_{S_j∈N(S_i)} a_{ij}^{(t)} (W^{(l)} F_t^{(l−1)}(S_j^{(t)}) + b^{(l)})), attention a_{ij}^{(t)} = softmax over dot-products of level-(l−1) features; (3) cyclic temporal refinement CA_{t′}(S_i) = Σ_{τ=0}^{T′−1} α_{t′,τ}(S_i) V_{(t′+τ) mod T′}(S_i) — modulo links clip tail back to head — then LayerNorm + FFN → refined feature; (4) scene graph from gated fusion of DETR decoder self-attention relation representations across layers: Ĝ = σ(MLP_rel(Σ_k g_a^k ⊙ R_a^k + g_z ⊙ R_z)).
- Loss: focal loss per hierarchy level L(F_t^{(l)}) = −α_t(1−p̃_t)^γ log(p̃_t); L_total = Σ_{l=1}^{L_h} L(F_t^{(l)}).
- Metrics: Recall and mean Recall at top-20/50/100 per interactivity type (standard VidSGG protocol).
- Five interactivity types: appearance (157 predicates), situation (128), position (135), interaction (142), relation (125). Includes sports-relevant predicates (approaching, overtaking, colliding, chasing, catching, dribbling, hitting); qualitative examples use tennis, basketball, and an occlusion case.
## Data sources named
ASPIRe [32]: 1.5K videos, 1.6M frames, 833 object classes, 4.5K relation classes, 7 scenes. AeroEye-v1.0 (introduced here, built on AeroEye [33]): 2,260 videos, 261,503 frames, drone urban/suburban/rural; 56 object categories, >2M bounding boxes; 157 appearance + 128 situation predicates per box; ~752K position, ~318K interaction, ~178K relation annotations; aerial + oblique + ground viewpoints. Baselines: IMP, MOTIFS, VCTree, GPSNet, STTran, TEMPURA, HIG, CYCLO (the authors' own two predecessors — honest self-comparison).
## Findings (numbers and facts, not vibes)
- AeroEye-v1.0 R@20: Position 15.52/mR 1.05 (CYCLO 13.52/0.75; HIG 12.51/0.85); Interaction 13.07/0.16 (CYCLO 12.61/0.14); Relation 16.03/0.95 (CYCLO 14.51/0.83); Appearance 16.52/0.68; Situation 5.53/0.61. R@100: Position 42.03/2.15; Interaction 41.53/2.26; Relation 48.03/2.38.
- ASPIRe R@20: Position 18.52/1.22 (CYCLO 16.32/0.97); Interaction 19.52/0.32 (CYCLO 15.27/0.20); Relation 21.02/1.12 (CYCLO 18.34/0.90); Appearance 18.23/1.07; Situation 6.57/0.26. R@100: Position 50.05/2.53; Interaction 48.04/2.47; Relation 54.05/2.93.
- Ablations (AeroEye-v1.0): hierarchy 1/4 → full: Appearance R@20 14.12→16.52, Position 12.32→15.52, Interaction 10.87→13.07; gains plateau at 3/4 depth. Cyclic vs standard attention: Appearance 15.12→16.52, Position 13.42→15.52, Relation 14.03→16.03 (+1.4–2.0 pp R@20). Temporal window 1/2 → full best, marginal 3/4→full.
- Margins are 2–3% recall/mR over baselines with no confidence intervals or significance tests — could be within run variance. mR@20 <1.1% on AeroEye-v1.0: SOTA means "least bad."
- Limitations: tracking dependence (DETR+tracking errors propagate; partial mitigation only); cyclic tail→head wrap is a heuristic unexamined for non-periodic clips; no sports-domain evaluation (SportsHHI [46] cited, not benchmarked); aerial predicates don't transfer — only architecture + schema are portable.
## Intelligence connections (tag each finding: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- First relational video-understanding method in the corpus (no scene-graph work exists yet) → NGS interaction-graph builder: 22 players as nodes, hierarchical attention (player→unit→formation), play-phase cyclicity, football predicate head {blocking, shedding-block, in-coverage, separating, tackling, pursuing, screening}: SCHEME
- Five-type schema (appearance/situation/position/interaction/relation) as annotation vocabulary for clip metadata (situation = down/distance/score/time; relation = coverage assignments/responsibility): OTHER
- Focal loss per hierarchy level directly reusable for GSE's long-tail event classes (pick-plays, coverage busts): OTHER
- Predicate budget question (which of the 5 types carries retrieval signal) → clip-search ablation experiment: TRUST-SIGNAL
## Engine-actionable? (yes/no + one-line what)
Yes — ADAPT the architecture pattern and schema (not the model) to an NGS interaction-graph builder with football interaction predicates, gated on beating a per-frame baseline by ≥2 pp R@20 on interaction predicates on held-out games; adopt the five-type annotation schema regardless as a zero-cost framework improvement.
