## What it is (1-2 sentences)
Deep read of Pandey & Singh (2026), *FailureAtlas: A Taxonomy of Failure Modes in Multi-Provider LLM Serving Infrastructure* (arXiv:2607.17525v1). Verdict in file: ADAPT — a 5×2 Layer×Detectability taxonomy (Network/Transport, Streaming/Protocol, State/Session, Model Behavior, Governance/Cost × Loud/Silent) plus a catalog of five evidence-verified failure modes, usable as a reliability audit instrument for Garrett's OmniRoute fork and agent stack.
## Key metrics/methods (formulas where given, else "not specified")
Taxonomy grid: 5 layers × 2 detectability classes = 10 cells, five populated. Two-axis inclusion criteria: (1) concrete/specific, (2) independently verifiable provenance (persistent URL), (3) mechanistically explainable. Method: taxonomy design (rejected single-axis-by-symptom and three-axis-with-severity alternatives), manual validation of GitHub issue threads (LiteLLM, Portkey, OpenRouter) plus firsthand stress-testing reproductions. No equations — taxonomy/catalog study. Continuity Preservation Rate (CPR) used as the semantic-continuity metric in firsthand experiments.
## Data sources named
Firsthand: ContinuityBench (CB) Phase 2 evaluation campaigns — hundreds of parallel agent instances against a mock LLM-provider gateway, documented via system logs + semantic-continuity metric drops. Survey: public GitHub issue trackers for LiteLLM (issues #33678, #20256, #21033/#24788 — file notes an internal discrepancy between body and appendix citations), Portkey, OpenRouter. Open catalog repo: https://github.com/Vishalsyscode/failureatlas (YAML records + reproduction scripts).
## Findings (numbers and facts, not vibes)
- Race condition (§6.1, firsthand): at C=5 concurrent agent sessions CPR near-perfect; at C=100, CPR collapsed to ~28% (~72 percentage-point drop). Mechanism: shared global history cache with read-modify-write containing an async yield (the LLM call) and no lock; second writer silently overwrote the first's turn. HTTP 200 on every request — detected only via semantic-continuity metric drops.
- Retry storm (§6.2, firsthand): 100 parallel agents with fixed 1-second retry after transient upstream 502; synchronized retries saturated the provider rate limit every window → 25% of requests failed permanently despite a momentary hiccup; provider billed for partial completions → runaway billable spend for zero successes. Mitigation: exponential backoff with jitter + global circuit breaker.
- Index collision (LiteLLM#33678, Silent): SSE iterator reset internal index counter per chunk, stamping every tool-call chunk index=0; client concatenated independent tool args (e.g., {"path":"a.rs"}{"path":"b.rs"}) into corrupted string saved into history; surfaced next turn as JSONDecodeError misdirecting debugging to the network layer.
- Redis semaphore leak (LiteLLM#20256, Loud): error path bypassed semaphore decrement (missing finally); "active" count stranded in Redis; accumulated upstream errors drove count to max_parallel_requests → permanent HTTP 429 for that key with zero requests in flight; resolved only by manual Redis flush.
- Event-loop block (LiteLLM#21033/#24788): synchronous I/O in asyncio gateway blocks whole event loop; health checks every ~10s → persistent micro-outages. Mitigation: async drivers in critical path or run_in_executor.
- Structural: detectability independent of layer; Silent column sparser (2 of 5 entries) but more dangerous; Model Behavior row entirely empty (no evidence-grade entries found — paper calls this a finding about where observability tooling is weakest).
## Intelligence connections (tag each finding: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- Most operationally severe failures are SILENT (HTTP 200, pass health checks, corrupt semantic payload) — trust-at-the-infrastructure-layer analog of Garrett's trust-no-claims content standard. Tag: TRUST-SIGNAL
- 72-point CPR collapse under concurrency via shared-state race (async yield inside read-modify-write). Tag: OTHER (multi-agent infra)
- Retry storm: 25% permanent failure + billed partial completions from fixed-interval retries; backoff-with-jitter + circuit breaker as fix. Tag: OTHER (data-fetch infra)
- 5×2 Layer×Detectability grid as reusable audit checklist (L1 network, L2 streaming, L3 state/session, L4 model behavior, L5 governance/cost). Tag: OTHER
- Silent-corruption patterns (index collision → JSONDecodeError one turn later; corrupted history writes) require semantic-level observability to detect. Tag: TRUST-SIGNAL
