# docs/arxiv-program/research/2026-09-21/arxiv-deep/0186-early-churn-prediction-user-product-time-series.md
## What it is (1-2 sentences)
Deep read of Bhattacharjee, Thukral & Patil (2023), *Early Churn Prediction from Large Scale User-Product Interaction Time Series* (arXiv:2309.14390v1). Verdict in file: ADAPT — port the 30-day → 4-week multivariate churn formulation with a Transformer encoder to GSE's audience/subscriber retention problem (site, newsletter, X, Kit engagement), enforcing time-ordered splits the paper itself lacks.
## Key metrics/methods (formulas where given, else "not specified")
Formulation: 30 days of user-product interaction → 4 weekly churn probabilities (multivariate time-series classification). Training objective (quoted): min_θ Σ_i Σ_j=1^4 (yij − gj(θ; Xi))² (MSE over users × 4 weeks). Approach 1 — classical ML on 30-day Level-02 aggregates Gi={μi,1,σi,1,…,μi,N,σi,N} (μ,σ per feature) via LR/RF/GBT: P(Ci|Gi)=Model(Gi). Approach 2 — deep on sequences Fi=[f⃗t−30,…,f⃗t−1]: vanilla/VGG-like CNN, CNN with kernel width=n_features, CNN with kernel height=τ=30, custom Inception-ResNet hybrid (9 inception blocks, 3×3/5×5/7×7 kernels, ~2.4M params; InceptionTime tried, deteriorated), scaled-down ConvNeXt (~0.8M), 5-layer LSTM + 2-dense head (~1M), scaled-down Vision-Transformer-style encoder-only Transformer (8 self-attention blocks, ~1.8M params, no decoder). Training: PyTorch, Adam, lr 1e-4, global batch 16K, 100 epochs (plateau ~20, no gain after 50), grid search on validation, BatchNorm + Dropout p 0.1–0.4, Horovod on 4× Nvidia A10, Petastorm from S3. Label: yi,w=1 iff user i has zero activity in week w. Metrics: TPR=TP/(TP+FN); FPR=FP/(FP+TN); AUC per week (ROC + PR curves; PR emphasized under 2–10× label skew).
## Data sources named
Dream11 proprietary (not public, not replicable): user transaction records 2018-01-01 to 2020-12-31; ~10^6 distinct users, ~10^8 raw transactions. Level-01: day-level aggregates (count/sum/mean) per user per day. Eleven features shortlisted via EDA/domain knowledge but NEVER individually named in paper. Sporting events deliberately excluded. No code or dataset released.
## Findings (numbers and facts, not vibes)
- Table 3 AUC per churn week W01–W04 (quoted exactly): LR 0.644/0.749/0.672/0.662; RF 0.640/0.775/0.699/0.687; GBT 0.646/0.773/0.703/0.694; CNN 0.797/0.705/0.686/0.675; ConvNeXt 0.835/0.751/0.729/0.717; Inception-ResNet 0.819/0.729/0.704/0.696; CNN H=τ 0.807/0.742/0.725/0.716; CNN W=N 0.822/0.747/0.728/0.729; LSTM 0.800/0.742/0.727/0.721; Transformer 0.858/0.756/0.732/0.716.
- Headline claim: Transformer best, "~6% improvement on average across all time periods" vs best GBT. Caveat preserved: classical models beat deep models on W02 (RF 0.775, GBT 0.773 vs Transformer 0.756) — the ~6% rests on the other three weeks.
- Training cost: CNN ~6h, Transformer ~13h on 4×A10. Feature-engineering pipelines consume >70% of inference time at ~10^8 scale (production motive for automated features).
- Weaknesses: random user split (0.75/0.05/0.20) NOT time-ordered, over a 2018–2020 window including the COVID regime shift — no temporal generalization test; eleven features unnamed (not reproducible even in principle); grid-search details unreported; label = full week of inactivity (misses partial churn); no calibration analysis under 2–10× skew; sporting-event features excluded by design while the paper argues events drive churn (contradiction).
## Intelligence connections (tag each finding: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- 30-day → 4-week churn formulation with Transformer encoder (0.858 W01 AUC, ~6% avg gain over GBT) — new capability for GSE audience retention (site/newsletter/X/Kit), tied to the autonomous-revenue mandate. Tag: OTHER (retention/revenue)
- Time-ordered splits as a required fix — the paper's random split over COVID-era data inflates temporal trust; TRUST-SIGNAL lesson for any GSE model evaluated with random splits on time-series data. Tag: TRUST-SIGNAL
- Calibration caveat: churn interventions need calibrated probabilities under 2–10× skew; AUC alone insufficient — TRUST-SIGNAL guardrail before acting on scores. Tag: TRUST-SIGNAL
- Exogenous event features (NFL schedule intensity, content calendar, promos) as the improvement lane — the paper names events as the churn cause but doesn't model them; W03/W04 degrade fastest (0.732/0.716). Tag: OTHER
- Acceptance gate in file: Transformer must beat GBT by ≥0.03 AUC on ≥3 of 4 weeks on time-ordered test before any production scoring. Tag: OTHER
