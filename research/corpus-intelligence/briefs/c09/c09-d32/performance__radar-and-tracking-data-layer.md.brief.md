# performance/radar-and-tracking-data-layer.md
## What it is (1-2 sentences)
Doctrine document (not implemented — "doctrine only", Zone 3 owner approval required before any implementation) governing how Sports OS would acquire, store, and use radar-derived ball-flight data and positional tracking data as evidence signals in the prediction/content pipeline. The current prediction engine uses odds data only; there is no `PerformanceSignal` schema model and no radar/tracking ingestion exists today.
## Key metrics/methods (formulas where given, else "not specified")
Named per-player per-week tracking aggregate fields for the NFL (Next Gen Stats path): `player_id, week, position, avg_separation, route_efficiency, target_rate, snap_count_pct`; TTL 7 days for weekly aggregates; storage as derived aggregates only (never raw frame-level tracking data / no raw RFID/GPS coordinates). MLB Statcast radar fields: `pitcher_id, game_date, release_speed, release_spin_rate, pfx_x, pfx_z, plate_x, plate_z, type, events`; TTL 24 hours for current-season aggregates. Signal schema carries `trendDirection` (up/down/flat/volatile/insufficient_data), `sampleSize`, `aggregationWindow` (e.g. `last_5_starts`), TTL/expiry, and `licenseVerified: boolean`.
## Data sources named
Statcast (public endpoint at `savant.baseball` / `baseballsavant.mlb.com`; `pybaseball` wrapper; official commercial program = MLB Data Delivery via MLBAM — license required; public-endpoint scraping is a ToS risk), Trackman (proprietary, no public endpoint), Rapsodo (some Driveline-published data exists in research context; commercial use prohibited without written Driveline agreement), Next Gen Stats NFL (`ngs.nfl.com` public aggregates; raw RFID chip positions not public; commercial license required beyond aggregate display), Second Spectrum NBA (no public raw; NBA data program + commercial license), TRACAB/ChyronHego soccer (no public endpoint), OpenPose/MediaPipe/YOLO (using CV to extract tracking from broadcast video is a copyright/broadcasting-rights issue, not just licensing).
## Findings (numbers and facts, not vibes)
- Wave-3 line audit confirms: no production-quality radar/tracking source has a free commercial path — all require paid enrollment or license.
- Source tiers: official MLBAM radar delivery and NFL NGS official program = T1 (commercial license + program enrollment); Statcast public aggregate = T2 gated on legal review (do not ingest before review); Driveline public datasets and OBP radar = T3 (internal context only, research license, no commercial use); community-scraped tracking = T5, permanently forbidden from the vault; Baseball Savant scrape without license = FORBIDDEN (P0).
- Public/private boundary: aggregate velocity trends / position aggregates / spin-rate-launch-angle aggregates may appear for PRO/ELITE with source attribution; raw pitch-by-pitch coordinates, raw RFID/GPS coordinates, and any Driveline/OBP-derived radar signals are NEVER public; users never see raw values or coordinates.
- MVP path: no radar/tracking at MVP (MVP limited to Health/Participation modality); Phase 2 = Statcast public aggregates after legal review; Phase 3 = NFL NGS + NBA Second Spectrum (significant cost commitments, owner decision).
- Licensing risks table: license revoked mid-season → 48-hour data removal protocol; OBP radar in commercial product = P0 permanent block.
- Forbidden claims include using "Statcast data" before MLBAM commercial enrollment and "sharp bettors are following velocity trends" (forbidden regardless of source).
- Relevant to Garrett's standing doctrines: this file's posture ("no commercial use without license; learn internally") is compatible with his NGS internal-only doctrine and his INGEST-AND-LEARN rule — NGS data as internal reasoning fuel.
