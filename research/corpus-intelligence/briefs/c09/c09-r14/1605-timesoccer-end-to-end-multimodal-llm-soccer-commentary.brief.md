# arxiv-program/research/2026-09-21/arxiv-deep/1605-timesoccer-end-to-end-multimodal-llm-soccer-commentary.md
## What it is (1-2 sentences)
Deep read of TimeSoccer (arXiv:2504.17365), an end-to-end multimodal LLM that jointly predicts timestamps and generates soccer commentary over full 45-minute matches in a single forward pass, built on TimeChat with a training-free motion-aware frame compressor (MoFA-Select) and progressive long-video training.
## Key metrics/methods (formulas where given, else "not specified")
MoFA-Select: (a) time-constrained K-Means of N_o frame features into U=6 segments minimizing Σ_k Σ_{t∈k}(1−sim(f_t,c_k)); (b) motion-aware budget per cluster R_k = max(1, min(⌊N_p·|B_k|/N_o⌋ + s_k·⌊N_p·|B_k|/N_o⌋, |B_k|)), where s_k = Var(f_t|t∈B_k)/max_j Var; (c) iterative fine-grained merging of max-similarity adjacent pairs, skipping merge when Δ_motion(i)=Var({f_i,f_{i+1}}) > δ=0.3. Architecture: EVA-CLIP ViT-G/14 → Image Q-Former with time-aware conditioning → MoFA-Select → sliding Video Q-Former → LLaMA-2 7B with LoRA rank 32 (ViT and base LLM frozen; Q-Formers fine-tuned). Training: progressive schedule (3→15→45-min videos) + position-embedding extrapolation by periodic replication (beats interpolation). Loss: standard NLL L = −Σ_i log P(Q_a^{(i)} | Q_a^{(<i)}, Q_v, Q_t). Metrics: temporal Precision@0.3/0.5/0.7/0.9, F1 (±5s, IoU); caption CIDEr/METEOR/SODA_c; LLM-judge M-S and C-S (Qwen2.5-VL-72B-Instruct, 1–10).
## Data sources named
SoccerNet-Caption with MatchTime refined timestamps; 422 train / 49 test videos, MatchTime split. Baselines: SN-Caption, SN-Caption+MatchTime, SN-Caption+UniSoccer, Video-LLaMA, MovieChat, LLaVA-Video-72B, LLaVA-OneVision-72B, TimeChat (fine-tuned).
## Findings (numbers and facts, not vibes)
TimeSoccer 45-min end-to-end: P@0.3 17.0, P@0.5 11.0, P@0.7 6.0, P@0.9 3.4 (vs SN-Caption 12.5/7.2/3.0/1.1); CIDEr 8.3, METEOR 6.2, SODA_c 2.7; M-S 5.03, C-S 5.14 (vs SN-Caption 3.41/4.30). 3-min×15 chunked variant scores higher (P@0.3 22.5, F1 12.0, CIDEr 13.8, C-S 6.18) but needs 15 forward passes, not end-to-end. MoFA-Select beats G-Prune; removing motion-awareness hurts captions most in ablations. Progressive training + replicated (not interpolated) position embeddings is the best recipe. No public code release. Absolute temporal precision remains modest (P@0.9 = 3.4%).
