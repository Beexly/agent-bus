# arxiv-program/research/2026-09-21/arxiv-deep/1676-global-forecast-combination.md
## What it is (1-2 sentences)
Deep read of Eckert, Hyndman & Panagiotelis (2023, arXiv:2207.07318): a general framework for GLOBAL forecast combination — per-task combination weights shrunk toward a shared weight vector via a task-coupling penalty, interpolating between local (per-task) and hard-global (one vector) weighting, with γ tuned per task by LOO-CV.
## Key metrics/methods (formulas where given, else "not specified")
Soft global objective (eq. 4): min_{w^{(1)}…w^{(m)}∈𝓦, w̄} Σₖ₌₁ᵐ (w^{(k)⊤}Σ^{(k)}w^{(k)} + λ‖w^{(k)}‖_q^q + γ‖w̄−w^{(k)}‖_q^q), q∈{1,2}. γ→0 ⟹ local combination; γ→∞ ⟹ hard global; finite γ ⟹ soft global. Closed form for q=2: Ω_{γ,2} = (γ/m)Σ_{k,l}‖w^{(l)}−w^{(k)}‖₂² — explicitly penalizes mutual distances between task weight vectors. Proposition 2: explicit (nonlinear) solution form for optimal weights with A^{(k)}=[Σ^{(k)}+(λ+γ)I]⁻¹; γ=0 ⟹ Bates–Granger weights shrunk toward equal by λ. Extensions: task grouping (penalty per group; m groups ⟹ local), task scaling (normalize losses by per-task difficulty τ_q^{(k)}), tandem shrinkage λ‖w‖_q^q (λ→∞ ⟹ equal weights). Globalises Bates–Granger optimal weights, Conflitti optimal convex weights, Matsypura optimal equal-subset weights. γ tuned over 10 log-spaced values (0.001–1000) per task by LOO-CV (valid when combination errors uncorrelated, Bergmeir et al. 2018). Pairwise-complete covariance + nearest-PD projection handle missing forecaster data.
## Data sources named
Synthetic (p=T=50 forecasters/samples, ρ=0.75 correlation, relatedness α∈{0,1/3,2/3,1}, m∈{2,5,10}); ECB Survey of Professional Forecasters (m=6 tasks: growth/inflation/unemployment × 1-/2-year horizons; p=34 forecasters, 1999–2021); M4 appendix (up to 70 series, quarterly/monthly/weekly).
## Findings (numbers and facts, not vibes)
Synthetic: hard global improves roughly linearly with task relatedness but HURTS when tasks are unrelated (worse with more tasks); soft global with CV'd γ nearly matches hard global when tasks identical and ameliorates the unrelated case — "best of both worlds". More tasks ⇒ more upside. Optimal weights (unbounded) benefit most from globalisation. Robust for T∈{25,100,150}; q=1 vs q=2 makes no material difference. ECB SPF pre-COVID (2017–2019): soft global MSFE/EW ≈ 0.921 average, beating local, hard global, AND equal weights. Post-COVID (2019Q4+): mixed (~half cases beat EW) — structural break (F-tests: forecast-error variance differs post-COVID at 1% level for growth/inflation) with too little post-break data; authors recommend EW "until more data is available". Forecast-combination puzzle implication: soft global + shrinkage beats EW empirically — an operational answer to the puzzle GSE currently "solves" by defaulting to EW.
