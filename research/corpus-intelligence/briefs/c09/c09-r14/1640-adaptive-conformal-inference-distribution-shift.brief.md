# arxiv-program/research/2026-09-21/arxiv-deep/1640-adaptive-conformal-inference-distribution-shift.md
## What it is (1-2 sentences)
Deep read of Gibbs & Candès (2021, arXiv:2106.00170, NeurIPS 2021) introducing Adaptive Conformal Inference (ACI): an online α_t feedback controller that expands/shrinks conformal intervals after each miss/cover so long-run empirical coverage converges to the nominal level under arbitrary distribution shift, with a distribution-free guarantee.
## Key metrics/methods (formulas where given, else "not specified")
Update: α_{t+1} = α_t + γ(α − err_t), err_t = 1{Y_t ∉ C_{α_t}(X_t)} — missing pushes α_t down (wider intervals); covering pushes it up (narrower). Online gradient descent on the pinball/quantile loss. Long-run guarantee (Theorem 2, NO distributional assumptions, holds for ANY sequence): |(1/T) Σ err_t − α| ≤ (max(α_1, 1−α_1) + γ)/(Tγ) — converges at O(1/(Tγ)). Experiments use γ = 0.005 as empirical sweet spot (larger γ adapts faster but intervals oscillate; smaller γ is sluggish). Requirements: Y_t revealed after each prediction (full feedback). Applications: (1) stock volatility — 12 S&P-500 stocks, GARCH(1,1) on rolling 1,250-trading-day window, target = next-day absolute return; (2) 2020 US election — ~3,000 counties, demographic features, two-party vote share, counties ordered by timezone to simulate reporting-order shift.
## Data sources named
12 S&P-500 daily returns (GARCH(1,1) fitted); 2020 US presidential county-level returns with demographics (ethnicity, age, sex, median income, education). No dedicated code repo; ~5 lines on top of any conformal interval routine.
## Findings (numbers and facts, not vibes)
Volatility app (nominal 90%): fixed-α conformal's local coverage oscillates and sags well below 90% during volatility regimes; ACI tracks ~90% throughout, widening intervals exactly when volatility spikes. Election app (nominal 90%): fixed conformal coverage troughs at timezone transitions; ACI maintains ≈90% across the whole sequence. Limitations: guarantee is LONG-RUN average only — any finite window can undercover; with γ=0.005 adaptation takes hundreds of steps (an NFL season is ~272 games, so per-team/slate adaptation is slow); local coverage (what matters week-to-week) has NO guarantee; requires Y_t revealed each step — mid-week props/futures have delayed/no feedback (paper flags lagged feedback as unresolved); no comparison to rolling-window recalibration.
