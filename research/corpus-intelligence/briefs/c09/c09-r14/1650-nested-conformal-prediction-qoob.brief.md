# arxiv-program/research/2026-09-21/arxiv-deep/1650-nested-conformal-prediction-qoob.md
## What it is (1-2 sentences)
Deep read of Gupta, Kuchibhotla & Ramdas (2022, arXiv:1910.10562): a nested-set framework that unifies split, cross-conformal, jackknife+, and OOB conformal methods into one formalism, plus QOOB (quantile-regression forests + out-of-bag calibration + cross-conformal aggregation) — a new method that uses ALL data for both training and calibration, winning at small sample sizes.
## Key metrics/methods (formulas where given, else "not specified")
Nested sets: F_t(x) = {y : s(x,y) ≤ t}, nested in t; calibrating t on held-out scores ≡ standard conformal. Any nonconformity score induces nested sets; framework extends to K-fold cross-conformal, CV+, jackknife+ as nested-set operations. QOOB = quantile-regression-forest nested quantile sets + OOB predictions as calibration scores (no split) + cross-conformal aggregation; includes an EFFICIENT cross-conformal algorithm (naive is O(n²)-ish per test point). Width = Lebesgue measure of prediction set. Theoretical results: score-based ⟺ nested equivalence proofs; finite-sample coverage for C^LOO; Conv(C^LOO) can be strictly SMALLER than the jackknife+ interval. Evaluation: 100 independent versions per dataset × 768 train/232 test per UCI dataset, α=0.1, metrics Ave-Mean-Width + Ave-Mean-Coverage with SDs; base regressor random forests (bootstrap ≈63.2%). MATLAB code at github.com/AIgen/QOOB.
## Data sources named
6 UCI regression datasets (blog feedback, concrete strength, superconductivity, news popularity, kernel performance, protein structure; +5 more in appendix); simulated contaminated data (Y ~ Pois(sin²(X)+0.1) + 0.03Xε₁ + 25·1{u<0.01}ε₂) for conditional-coverage experiments.
## Findings (numbers and facts, not vibes)
QOOB significantly outperforms split-CQR at small sample sizes on ALL 6 datasets (narrower intervals at valid coverage). Nominal quantile selection has a significant effect on QOOB width (needs tuning). QOOB intervals get SHORTER as T (trees) increases — no plateau in tested range. Cross-conformal outperforms jackknife+ (tighter, still valid). QOOB shows empirical conditional coverage on the contaminated simulation at n ≤ 300, matching split-CQR's behavior at n=2000. Costs: QOOB ≈ n× the prediction compute of split-CQR (n individual OOB predictions); exchangeability assumed throughout, no drift handling; MATLAB reference needs porting to the TS stack.
