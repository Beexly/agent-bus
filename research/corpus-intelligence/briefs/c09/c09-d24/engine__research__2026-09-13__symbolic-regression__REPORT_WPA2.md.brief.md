# engine/research/2026-09-13/symbolic-regression/REPORT_WPA2.md
## What it is (1-2 sentences)
Execution report for the WPA² win-leverage protocol (DeepSeek Phase 2 follow-up): hypothesis was that symbolic regression on EPA² drops the time term because EPA is time-independent, while a WPA² target should retain `quarter_seconds_remaining`. Verdict: NULL under the spec'd protocol — GP collapsed to degenerate constants in every configuration, so the time-term hypothesis is untestable with this method, not disproven.
## Key metrics/methods (formulas where given, else "not specified")
Data: nflverse play-by-play 2021–2024 (parquet, `pbp` release tag), scrimmage plays only, 141,288 rows. Target y = wpa² clipped at 99th percentile (clip99 = 0.0258). Features: W1 (9 pre-snap: down, ydstogo, yardline_100, score_differential, quarter_seconds_remaining, shotgun, no_huddle, posteam_timeouts_remaining, defteam_timeouts_remaining) and W2 (W1 + pre-snap wp). GP: gplearn SymbolicRegressor, population 2000 × 30 generations × 3 seeds (42, 123, 7), functions {add, sub, mul, div, sqrt, log, exp(protected)}. Splits: train 2021+2022 (n=70,912) → test 2023 (n=35,474); replication train 2022+2023 (n=70,778) → test 2024 (n=34,902). Metrics: test R² with 95% bootstrap CIs; affine recalibration y = a·f(x)+b via least squares on replication-train. Key numbers: GP W1 best seed 42 `log(log(-2.719))` = constant 0.0003, test R² = −0.0787 (95% CI [−0.0817, −0.0759]); GP W2 best seed 42 `sub(X4,X4)` = constant 0, R² = −0.1541; train-mean baseline B1 ≈ −0.0000. Baselines B2/B3: −317,751.73 / −30,826.24 / −1,329,398.11 (raw, scale-mismatch dominated). Supplementary: gradient boosting test R² = 0.2129 (W1) / 0.2188 (W2); `down` correlates +0.21 with wpa², `quarter_seconds_remaining` −0.044; linear on down alone R² = 0.0404, all 9 features linear 0.0487. Calibrated GLI-0.1: R² = 0.0037 (vs claimed 0.112/0.079 — measured for the first time, those claims were never executed). Adequate-budget run (3000 pop × 150 gen, W1, seed 42): still constant `sub(X2,X2)` = 0.0, R² = −0.1541. Leading diagnosis: heavy-tail overfitting attractor — standardized tail points reach y≈6.6; generation-0 best fitness already implies R²≈0.63 on the 25k training subsample (impossible vs HGB cap 0.21), so selection climbs noise. Recommended fix: robustified fitness (Huberized MSE), rank/log-transformed target, or tail trimming.
## Data sources named
nflverse play-by-play 2021–2024 (parquet `pbp` tag); gplearn SymbolicRegressor; GLI-0.1 (DeepSeek's proposed formula); generation-zero fitness diagnostics.
## Findings (numbers and facts, not vibes)
- All six GP configurations (3 seeds × W1/W2) plus the 3000×150 supplementary run converged to constants — the time-term hypothesis is untestable with plain-MSE gplearn symbolic regression on this target, NOT disproven.
- The signal itself is real and large: HGB reaches R² 0.2129; `down` is the best single correlate (+0.21; 4th downs carry huge leverage); `quarter_seconds_remaining` correlates −0.044 (late-game plays carry more leverage — exactly the expected time signal).
- GLI-0.1's first measured execution: R² = 0.0037 (affine-calibrated), nowhere near DeepSeek's predicted 0.112/0.079 (never executed; DeepSeek has no code environment).
- Ruled out as sole causes: target scaling (standardized y still collapses), constant magnitude (const_range (−0.01, 0.01) still collapses), the exp operator alone (dropping it still collapses at both 30 and 150 generations), budget alone (3000×150 also fails).
- Even a one-multiply program (`down × 0.00077`, beating every constant) is never found — pathology is the lucky-overfit attractor at generation 0 on the heavy-tailed target.
- Code artifacts: `wpa2.py`, `wpa2.log`, `wpa2_results.csv`, `wpa2_verdict.json`, `wpa2_big.py` / `wpa2_big.log` / `wpa2_big_result.txt`.
