# arxiv-program/research/2026-09-21/arxiv-deep/0242-uefa-euro-2020-forecast-via-nested.md
## What it is (1-2 sentences)
A full-text read of Gilch (2021, arXiv:2106.05174v1, Passau technical report), which forecasts UEFA EURO 2020 with a nested zero-inflated generalized Poisson regression: simulate the stronger team's goals first, then model the weaker team's goals CONDITIONAL on the realized favorite score, with team Elo + location covariates, 100k Monte Carlo tournament replications with in-replication Elo updating. The corpus reader's verdict is ADAPT: the nested conditional dependence mechanism is a deployable, sport-agnostic dependency primitive the corpus's symmetric bivariate inventory (Dixon-Coles, copulas) lacks.
## Key metrics/methods (formulas where given, else "not specified")
ZIGP pmf: P(X=0) = ω + (1−ω)e^{−μ/φ}; P(X=k) = (1−ω)μ(μ+(φ−1)k)^{k−1}/k!·φ^{−k}e^{−(μ+(φ−1)k)/φ}, k ≥ 1; moments E(X) = (1−ω)μ, Var(X) = (1−ω)μ(φ² + ωμ). Steps: (1) log μ_A(Elo_B) = α₀⁽¹⁾ + α₁⁽¹⁾Elo_B + α₂⁽¹⁾loc (stronger's scoring vs weaker's Elo); (2) log ν_B(Elo_A) = α₀⁽²⁾ + α₁⁽²⁾Elo_A + α₂⁽²⁾loc (goals conceded model); (3) ad hoc reconciliation by averaging: μ_A|B = (μ_A+ν_B)/2, φ_A|B = (φ_A+ψ_B)/2, ω_A|B = (ω_A+δ_B)/2; (4) nested dependence: log μ_B|A = α₀⁽³⁾ + α₁⁽³⁾Elo_A + α₂⁽³⁾loc + α₃⁽³⁾·G_A — the weaker team's scoring mean depends on the realized stronger-team goals (e.g., G_A = 5 → concentration-breaking late goals more likely; G_A = 1 → B scores 0–1 as A protects the lead). Elo update: Elo_after = Elo_before + K·G·(W − W_e); K = 60 (WC), 50 (continental); W_e = 1/(10^{−D/400}+1). Match weighting: w(m) = (1/2)^{D(m)/H}·w_importance(m), H = 3 years, importance 4/3/2.5/1 (WC/continental/qualifier/other). Validation: in-sample χ² GOF per team; EURO 2016 retrospective vs Nested Poisson (Gilch 2019) scored with MDL, Brier, RPS.
## Data sources named
eloratings.net (World Football Elo Ratings variant) — all participating-team matches 1 Jan 2014 – 7 Jun 2021, with Elo_before/after, opponent Elo, location, goals. No code release; computations in R 3.6.2.
## Findings (numbers and facts, not vibes)
EURO 2016 retrospective (ZIGP vs Nested Poisson): MDL 22 vs 26; Brier 17.52441 vs 18.68; RPS 5.280199 vs 5.36 — ZIGP better on all three. EURO 2020 forecast (100k sims), champion probabilities: Belgium 18.4%, France 15.4%, Spain 13%, England 7.8%, Portugal 7.7%, Netherlands 7.1%, Germany 6.1%, Italy 4.8% (Italy actually won). Stage probabilities given for final/semifinal/quarterfinal/last-16 (e.g., Belgium: final 29.1%, semi 47.7%, QF 68.7%, last-16 98.5%). In-sample attack GOF p-values: Belgium 0.98, France 0.15, Portugal 0.34, Spain 0.33, Italy 0.93, Germany 0.05; defense regression "very poor" for Italy/Portugal (low-impact by construction). Worked example France vs Germany (Munich): expected France goals (1−ω)·μ = 1.32516; combined mean 1.627268; Germany's μ_Germany|France = 1.54118 when G_A = 1. No bookmaker/market benchmark anywhere in the paper. Note: (2.3) as typeset duplicates the α₀⁽³⁾ coefficient (typographical slip). Model was fit on data through 7 Jun 2021, forecast pre-tournament — no temporal leakage, but only in-sample GOF on the regressions.
## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- OTHER: new dependency primitive for score simulation — nested conditional (favorite's realized output drives underdog's distribution) vs symmetric Dixon-Coles λ₃ / copulas. The garbage-time/prevent-defense analogue is a genuine NFL mechanism: underdog scoring rate depends on the realized favorite score.
- SCHEME: in-game score dynamics — a leading team's "protect the lead" mode vs trailing team's garbage-time inflation is exactly the nested mechanism; one extra covariate log μ_B|A in an existing count regression plus a two-stage sampler.
- COACHING: within-replication rating updating captures in-tournament/playoff momentum form — adaptable to playoff bracket simulation with form updating across rounds.
