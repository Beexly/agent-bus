# arxiv-program/research/2026-09-21/arxiv-deep/0574-a-spectral-approach-for-the-dynamic.md
## What it is (1-2 sentences)
Deep-read note on Tian, Shi, Shen & Song (arXiv:2307.16642v2): proposes Kernel Rank Centrality (KRC), a spectral estimator that kernel-smooths binary pairwise outcomes over time into a Markov transition matrix and reads item strengths from its stationary distribution — the first distribution theory (entrywise asymptotic normality) for a spectral ranker in the dynamic Bradley-Terry setting. File verdict is ADAPT — use KRC as a cheap, online-updatable NFL weekly power-rating engine plus the Sherman–Morrison rank-one online update for in-week refresh, but do not rely on the win-only Bradley-Terry likelihood for spread/total markets.
## Key metrics/methods (formulas where given, else "not specified")
- Dynamic Bradley-Terry (Eq. 2.1): P(y_ij(t)=1) = π_j(t)/(π_i(t)+π_j(t)), Σ_i π_i(t)=1.
- Kernel-smoothed transition matrix (Eq. 3.1): P̂_ij(t) = (1/n)·(Σ_{t_k∈T_ij} y_ij(t_k)K_h(t,t_k))/(Σ K_h(t,t_k)) for i≠j; P̂_ii(t)=1−Σ_{s≠i} P̂_is(t). Rows sum to 1 → Markov chain; π(t) is the stationary distribution (detailed balance).
- KRC estimator (Eq. 3.3): π̂(t)^⊤=π̂(t)^⊤P̂(t), Σ π̂_i=1. Irreducibility guaranteed with prob ≥ 1−O((nM)^−10) (Lemma 2); optional teleportation regularization [(1−σ_n)P̂_ij+σ_n/n], σ_n/n=1/n².
- Online updating (Lemma 1 + Algorithm 2): a new game changes only rows i and j of P̂; two Sherman–Morrison rank-one updates via the ROU operator — π_new=π_old−φ with φ^⊤=[π_i,old/(1+δ^⊤A^#_{.i,old})]δ^⊤A^#_old, plus group-inverse update (Eq. 3.5). No re-optimization.
- Theorem 1 rates: relative ℓ2 error ≤ C1√(1/(nMh))+C2h²; relative ℓ∞ error ≤ C3√(log(nM)/(nMh))+C4h²; optimal bandwidth h≍(nM)^(−1/5). Theorem 2: finite-dimensional asymptotic normality of any fixed subvector, covariance diagonal (asymptotic independence as n→∞) under nMh⁷→0. Theorem 3: group-inverse diagonal approximation max_i‖Ã_.i−A^#_.i‖=O(1/√n).
## Data sources named
Simulations: n=10…100 items, M=50–200 comparisons per pair, capabilities α_i ~ U(1,3), true strengths π_i(t)=α_i+sin(5α_i t), outcomes Bernoulli(π_j(t)/(π_i(t)+π_j(t))), 100 replications. Real data: NBA regular seasons 2009-10 through 2018-19 (10 seasons × 1230 games), from nba.com; forecasting design: first 7 seasons base, capability curves estimated on last 3 seasons using only data before time t, predict each game's winner as higher-skill team. Baselines: static Rank Centrality, MLE, WMLE (h=0.1/0.5/1/1.5), FiveThirtyEight NBA Elo (Silver & Fischer-Baum 2015). No code link stated.
## Findings (numbers and facts, not vibes)
- Table 1 forecasting accuracy (seasons 2016-17 / 2017-18 / 2018-19 / Total): RC 0.6114/0.5732/0.5935/0.5927; KRC(h=0.1) 0.6228/0.6333/0.6341/0.6301; KRC(h=0.5) 0.6301/0.6317/0.6407/0.6341; KRC(h=1) 0.6455/0.6325/0.6366/0.6382; KRC(h=1.5) 0.6301/0.6081/0.6138/0.6173; MLE 0.6179/0.5740/0.5919/0.5946; WMLE(h=0.1) 0.6089/0.6260/0.6358/0.6236; WMLE(h=0.5) 0.6276/0.6260/0.6463/0.6333; WMLE(h=1) 0.6447/0.6236/0.6382/0.6355; WMLE(h=1.5) 0.6341/0.6065/0.6171/0.6192; Elo 0.6309/0.6325/0.6431/0.6355.
- "our method achieved comparable results to Elo and outperformed Elo when h=1 in the average accuracy" (0.6382 vs 0.6355 total) — paper notes "season-length data is more informative"; feature-rich Elo beat featureless KRC in 2 of 3 seasons. The +0.27pp edge is one bandwidth's margin with no CI on accuracy differences; h=1.5 collapses to 0.6173.
- "the KRC method outperforms WMLE for most bandwidths"; static RC "had the worst results in all seasons"; KRC's compute cost "significantly lower than that of the WMLE" with the gap widening in n.
- Table 2 CIs: e.g., column Warriors over row Rockets 0.51 (0.46, 0.57) — contains 0.5 ("the Rockets were a strong opponent"); Celtics over Raptors 0.57 (0.51, 0.63).
- Simulations: estimation error decreases as M or n increases; KRC "nearly indistinguishable" from WMLE in error; empirical densities match theory, pairwise correlations ≈ 0.
