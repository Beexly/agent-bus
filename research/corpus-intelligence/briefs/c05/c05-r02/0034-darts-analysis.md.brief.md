# arxiv-program/research/2026-09-21/arxiv-deep/0034-darts-analysis.md
## What it is (1-2 sentences)
Amateur darts win-probability study (Makhamra, Satynska, Weselcouch, arXiv:2511.14537, 2025) comparing five models on 1,131 games of "Darts 271" from the spring 2025 Minton Invitational (Roanoke College), evaluated under both Brier score and a head-to-head betting game. The reader's verdict was ADAPT — the darts model doesn't transfer, but the betting-game evaluation protocol (one model sets odds, the other bets, profit decides) is a portable model-comparison tool GSE lacks.
## Key metrics/methods (formulas where given, else "not specified")
- Null: π_NULL = ½·(1 + (s1−s2)/100), truncated [0,1] (0.5 pp per score point).
- Logistic: π_REG = 1/(1 + e^{-(c0 + c_{p1} − c_{p2} + c1·s1 + c2·s2)}).
- Basic simulation: Monte Carlo, 1000 games from current score, π_SIM = W/1000.
- Time-adjusted sim: distance vector (accuracy proportions, extrapolated via linear regressions on date/time to Apr 1, 2025) + multiplier vector m = ⟨m0, m1, m2, m3⟩.
- Score-dependent Massey (SDMM, new): perceived strength at score s_i: (271−s_i)/271·r_i^(1) + s_i/271·r_i^(2); π_SDMM = ½·(1 + Δperceived), truncated [0,1].
- Betting-game payout: expected payout for betting on event = |α_t−β_t|·(p_t − α_t) — positive iff true probability exceeds model α's estimate.
- Recalibrated null: π'_NULL = ½·(1 + (s1−s2)/85); marginal effect 100·Δr/542 = 0.59 pp/point.
## Data sources named
Custom data collection (Roanoke College, Feb 6–May 2, 2025): 1,131 games, 15,306 rounds, 45,918 throws, 45 players. Train = before Apr 1, 2025; test = on/after (362 games at Round 1; 2,465 round-predictions). No code/data link; non-public.
## Findings (numbers and facts, not vibes)
- Brier (2,465 round-predictions): Null 0.1902, Logistic 0.1980 (worst — overfit on low-sample players), Basic Sim 0.1849, Adjusted Sim 0.1857, SDMM 0.1807 (best). Round-1: SDMM 0.2372 vs Null 0.2500.
- Recalibrated null Brier 0.1889 (slight improvement over null).
- Betting game (per-round and game-start): SDMM outperforms all models head-to-head; null model shows a betting edge over every model except SDMM — indicating other models systematically overestimated the favorite.
- Paper's conclusion (exact): "we conclude that the probabilities generated by the score-dependent Massey model most accurately reflect reality, although the model may systematically err on the conservative side."
