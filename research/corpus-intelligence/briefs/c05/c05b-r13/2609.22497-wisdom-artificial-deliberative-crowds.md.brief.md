# docs/dfs/research/2026-09-25/arxiv-deep/2609.22497-wisdom-artificial-deliberative-crowds.md
## What it is (1-2 sentences)
Full-paper ledger (VERDICT: ADAPT) on Barrera-Lemarchand, Sigman, Navajas's "The Wisdom of Artificial Deliberative Crowds" (cs.AI, 2026-09-25 read): a three-stage independent-estimate → deliberative-consensus → post-deliberation-revision aggregation protocol over diverse LLM groups, tested in four domains including 2026 FIFA World Cup forecasting against a Polymarket benchmark, with a full GSE implementation spec, reproducible test, and acceptance gate.

## Key metrics/methods (formulas where given, else "not specified")
Formulas: none stated in the paper — statistical machinery described narratively. Methods: Stage i1 (independent estimates, several repetitions, justification ≤200 tokens inside parse tags); Stage c (deliberation: groups of 3, one model per family — Claude Haiku 4.5, GPT-5-nano, Gemini 3.1 Flash Lite — short messages target ~10 tokens, hard cap 66/80 tokens, ≤10 rounds, one message per model per round in random order, convergence = all three declare same value in same round, fallback = same parsed value in all three final-round messages; agents see only their own i1 answer + discussion, never others' i1); Stage i2 (private post-deliberation revision); controls: social-influence-only and homogeneous "clone" deliberation. Stats: Bayes factors with JZS prior (Cauchy on δ, scale r = √2⁄2; sensitivity r = 1, √2); two-sided Mann–Whitney U (crowd-level, 2,000 bootstraps); Wilcoxon signed-rank (paired, with Cohen's d); market overround normalization: Polymarket raw prices summed ~1.0075 avg (median 1.0100, range 0.9850–1.0295), each event's price divided by the event's listed-price sum. Metrics: Study 1 squared error in log space (base 10); Studies 2–4 Brier score. Deterministic adaptation spec for GSE: revision rule `p_s ← p_s + α·w_s·(median_others − p_s)` (α default 0.3, w_s = earned reliability weight), consensus = median of final round, convergence when max pairwise spread ≤ 0.01 within ≤5 rounds; expert-dominance detector: one source's Brier < consensus Brier with paired Wilcoxon p < 0.05 over ≥50 events → bypass ensemble for that market type.

## Findings (numbers and facts, not vibes)
- Study 1 (jar counts, 14 photos, true 38–589 disks; 504 observations; 167/168 groups converged): aggregating 12 consensus estimates vs averaging 36 individuals: z = 19.4, p = 4×10⁻⁸³, d = 4.75. Within-group consensus (0.164 ± 0.019) vs i1 mean (0.195 ± 0.019): z = 5.33, p = 9.8×10⁻⁸, d = 0.40. i1→i2: 0.230 → 0.159 (z = 7.36, p = 1.9×10⁻¹³, d = 0.40); i2 equal-or-lower than consensus in all 14 pictures (z = 3.18, p = 0.0015, d = 1.33). Deliberation beats social-influence-only (z = 18.85, p = 3.0×10⁻⁷⁹, d = 3.25).
- Study 2 (100 NeurIPS papers, 50 oral/50 rejected; 600/600 converged): crowd z = 19.35, p = 2×10⁻⁸³, d = 6.71; within-group d = 0.25; i2 reproduced consensus exactly in 82/100.
- Study 3 (50 trajectories; 299/300 converged; 25 sabotage analyzed): within-group d = 0.30; i2→consensus: 417/447 exact matches; gain in 19/25 sabotage cases (d = 0.90).
- Study 4 (44 World Cup events, favorites won 35/44; 175/176 converged): deliberative crowd beats i1 pooling event-by-event in 31/44 (z = 3.16, p = 0.0016, d = 0.49); deliberative crowd vs Polymarket: z = 1.12, p = 0.26, BF₀₁ = 3.63 (moderate evidence for null — statistically indistinguishable from the real-money benchmark). Independent crowd vs market: market better in 30/44.
- Paired within-group effect sizes across all four domains: d = 0.25–0.49.
- Diversity boundary: clone deliberation adds nothing — d = 0.087/0.144/0.062 (n.s., BF for null 5.60/3.99/6.19) in Study 1; d = 0.10/0.06/0.01 in Study 2 vs heterogeneous d = 0.26–0.48.
- Expert dominance: best single model beats heterogeneous consensus in 3/4 domains (d = 0.31–1.31); dominant identity switched across domains (Gemini: Studies 1, 4; Anthropic: Study 2) — not knowable ex ante. Gemini alone vs Polymarket: z = 0.48, p = 0.63, BF₀₁ = 6.03 (moderate evidence for null).

- Acceptance gate for ADOPT: out-of-sample ≥200 NFL games with ≥3 distinct source families: deliberative consensus reduces mean Brier ≥1.5% vs existing mean ensemble (paired Wilcoxon p < 0.05) AND clone control <0.5% improvement; module must run <50 ms/event with zero network calls on hot path.
