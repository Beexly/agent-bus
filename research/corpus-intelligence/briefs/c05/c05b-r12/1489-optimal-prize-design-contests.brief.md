## What it is (1-2 sentences)
Deep read (full text + complete appendix proofs) of Deng, Li, Li & Qi (arXiv:2505.08342v1), a pure game-theory paper on parallel rank-order contests (the DK/FD lobby): designers set prize structures under fixed budgets, contestants choose which contest to enter and how much costly effort to exert. Verdict in file: ADAPT — GSE is an entrant, not a designer, so adapt the contestant-equilibrium sorting result (Theorem 1 / Corollary 1) into a field-strength model for the DFS optimizer's contest-selection layer.
## Key metrics/methods (formulas where given, else "not specified")
- Two-stage game: m rank-order contests, n contestants; designer j announces w⃗ⱼ=(wⱼ,₁,…,wⱼ,ₙ), wⱼ,₁≥…≥wⱼ,ₙ≥0, Σₖwⱼ,ₖ≤Tⱼ (budget). Contestant i has private skill vᵢ i.i.d. from continuous F (quantile qᵢ∼U[0,1], v(q)=F⁻¹(1−q), lower q = higher skill); chooses contest Jᵢ and effort eᵢ at linear cost eᵢ/vᵢ; prizes rank-by-effort (ties by skill); utility uᵢ=vᵢ·Wᵢ−eᵢ.
- Interim allocation function: x_{w⃗ⱼ}(φ) = Σₖ₌₁ⁿ wⱼ,ₖ·C(n−1,k−1)·φᵏ⁻¹(1−φ)ⁿ⁻ᵏ (expected prize when the mass of stronger competitors is φ). Strictly decreasing in φ iff wⱼ,₁>wⱼ,ₙ; constant iff all prizes equal.
- Lemma 1: in sBNE, effort is deterministic given (contest, quantile): eᵢ=βⱼ(qᵢ) with β̂ⱼ strictly decreasing.
- Theorem 1 (choice equilibrium): {j : Φⱼ′(qᵢ)>0} ⊆ argmaxⱼ xⱼ(Φⱼ(qᵢ)) — equilibrium contest choice reduces to picking argmax of expected *prize* (effort choice separates out).
- Corollary 1: Φⱼ(q) = xⱼ⁻¹(Q⁻¹(q)), Q(x)=Σⱼxⱼ⁻¹(x) (unique when all xⱼ strictly decreasing).
- Lemma 3: disclosing competitor counts before effort choice leaves expected utilities and the choice equilibrium unchanged: Eₖ[xⱼ⁽ᵏ⁾(Φⱼ(qᵢ)/Φⱼ(1))]=xⱼ(Φⱼ(qᵢ)).
- Theorem 3: with weight-monotone α⃗ⱼ, winner-takes-all w⃗ⱼ*=(Tⱼ,0,…,0) is a *dominant strategy* for the designer (Corollary 2: SPE where all designers go winner-takes-all).
- Theorem 4: under participation objective θⱼ, optimal structure is always a *simple contest* w⃗ⱼ=(Tⱼ/k*,…,Tⱼ/k*,0,…,0) with k*=argmaxₖ ξₖ(φ*), φ*=Φⱼ*(θⱼ;·). Theorem 5: with common θ across designers, designer SPE is efficiently computable.
- Assumptions: continuous i.i.d. private skills; linear effort cost e/v; rank-by-effort allocation (no luck); one contest per contestant (no multi-entry); symmetric strategies; fixed budgets; effort one-dimensional and perfectly rankable.

## Findings (numbers and facts, not vibes)
- No numerical results reported; quantitative claims are the closed forms above.
- Designer results are for operators (DK/FD), not for GSE — GSE cannot set prize structures.
- Limitations named in file: no-luck assumption — DFS lineup score = skill + large variance, so the rank-by-effort mapping overstates how deterministically skill converts to prizes (weaker players win GPPs regularly); one-entry-per-contestant contradicts DFS reality (multi-entry up to 150 lineups; "effort" margin in DFS is number of entries, not modeled); no entry fees/rake modeled (DK/FD take ~10–15%); no empirical test against any real contest data.
- GSE implementation spec in file: (1) `contest-selection` module — input = DK/FD lobby snapshot (contest list with entry fee, field size, payout structure — all scrapable from public lobby); (2) Theorem-1 sorting heuristic — compute each contest's interim-allocation curve x(φ) from the published payout table, simulate Corollary-1 quantile sorting (assumed skill distribution, e.g., lognormal fit to historical GPP vs cash-game ROI) to estimate skilled-player share per contest; (3) routing rule (inversion of Theorem 4) — prefer flat-payout multipliers/small-field contests where high-skill concentration is predicted lowest, deprioritize large-field top-heavy GPPs absent overlay or ownership-leverage edge; (4) use disclosed entrant counts as live input (Lemma 3 says they don't distort equilibrium); effort ~3–4 days (lobby scraper + sorting simulation + routing rules).
- Reproducible test in file: DK/FD public lobby snapshots for 4 NFL weeks + GSE lineup pool scores; metric = realized ROI of routed entries vs same lineups entered uniformly across the slate's GPPs; accept if routed portfolio ROI is ≥5 pp better over the 4-week window (time-ordered, no lookahead).
- Acceptance/rejection gate: ADAPT if offline replay shows routed contest selection beating uniform GPP entry by ≥5 pp ROI over 4 weeks AND the x(φ) sorting simulation reproduces the qualitative pattern (top-heavy large-field GPPs concentrate the highest estimated skill share); reject as a router if results flip under plausible alternative skill priors — then keep as descriptive dashboard.
