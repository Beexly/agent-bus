# arxiv-program/research/2026-09-21/arxiv-deep/1499-dynamic-quantification-of-player-value.md
## What it is (1-2 sentences)
Deep read of Rosenof (arXiv:2409.09884v1), which introduces H-scoring: a dynamic fantasy draft-value framework that optimizes per-pick category weights and positional allocations by gradient descent on format-specific win probability — implicitly learning to punt categories — and beats static G-score rankings in 20 seasons of simulated 12-team drafts. Verdict in file: ADAPT — ports to GSE as adaptive DFS/fantasy draft strategy that optimizes pick value against the evolving roster rather than a static board.
## Key metrics/methods (formulas where given, else "not specified")
- H-scoring framework: for each candidate player, (1) estimate optimal strategy parameters j maximizing format objective V(j); (2) draft the player with highest V(j). Three functions: X(j) = distribution of category-total differentials vs opponents; W(X(j)) = category win probabilities = CDF of differential at zero; V(W) = format objective.
- H0 implementation: j = (j_C category weights summing to 1; j_U, j_G, j_F flex-share vectors). X(j) modeled as normal: X(j) = N·X_s + X_p + X_δ(j) − X_Om, variance 2N + (N−K−1)X²_σ.
- X_δ(j) approximates future-pick value under the planned strategy: available players' stats assumed multivariate normal with category covariance Σ; chosen player is ωσ above generic in the j_C basis and γσ below in the generic v basis (ω = 0.7, γ = 0.25, empirically calibrated via regression with R² ≈ 47%/46%).
- X-scores: X_p = (m_p − m_μ)/m_τ (counting); X_p = (a_q/(a_μ))·(r_q − r_μ)/r_τ (percentage). v converts X-score → G-score basis: v = m_τ/√(m²_τ + m²_σ).
- Category win prob: w_c = ½[1 + erf(μ/(√2·σ))].
- Objectives: Each Category: V = Σ_c w_c, gradient ∇V = Σ_c PDF_c(X(j))·∇X(j). Most Categories: V = P(win majority) over the 256 winning scenarios in 9-cat (computed via tipping-point probabilities T(j, c₁)). Gradient descent with Adam; j initialized as v perturbed 1/500 toward the candidate's stats (exactly v gives undefined gradient); V non-convex (normal CDF) so only local optima.
- Positional model: assignment problem (Jonker-Volgenant via scikit-learn) placing drafted players in least-desirable eligible slots, freeing good slots for future picks; flex shares control expected position mix.
## Data sources named
Simulated NBA fantasy seasons 2004–05 through 2023–24: 12-team, 13-player head-to-head leagues; each player's season simulated by sampling 20 weeks from actual weekly performances (injured weeks excluded; players with <10 weeks excluded). Yahoo positional eligibility. 1,000 simulated seasons per draft seat (seats 0–11) per format → standard errors ≈ 1.6%.
## Findings (numbers and facts, not vibes)
- Win rates: 21.8% (Each Category) and 37.7% (Most Categories) vs 8.3% random-chance baseline — beats static G-score drafting decisively.
- Better from higher draft seats (top picks make the job easier); worst case 3.2% (2013–14, 11th pick, Each Category).
- Implicit punting: category win-rate histograms show mass slightly above 50% plus a lower mode at 0% — H0 learns to punt without being told. "Soft punting": optimal weights mostly slightly above default, long tail below (~20% of weights < 0.95, i.e., 1–2 punted categories); weights rarely go to 0%.
- Gradient intuition: gradients ∝ category PDF at zero — average categories get boosted, weak ones snowball downward (punt), strong ones held slightly above 50% rather than maxed. Most-Categories punting is more extreme (no marginal value beyond the majority).
- Predicted vs actual category win rates match above ~10%; distortions below (assists/3s/blocks over-predicted; turnovers/FT% under-predicted).
- Turnovers: not down-weighted by default, contrary to analyst folk wisdom; correlated-multivariate-normal gradient analysis (Table 4) shows turnovers ≈ as important as other counting stats.
- ω/γ calibration: best-fit slopes 0.37 (R² 47%) and 0.87 (R² 46%) vs assumed 0.7/0.25 — roughly consistent.
- Limitations named in file: opponents modeled as naive G-score drafters (edge shrinks vs smart fields); static performance distributions — no in-season drift, injuries, trades/waivers (paper's biggest flagged gap); equal-variance and multivariate-normal assumptions "roundly unfounded" (blocks have heavy right tails); week-to-week category correlations ignored; local optima only; rotisserie infeasible (12! orderings per category); no real-draft validation — simulation only.
- GSE adaptation spec in file: (a) adapt H-scoring to points leagues — X(j) = projected-points differential distribution vs opponents; V(j) = P(finish position) via Monte Carlo over remaining picks; (b) positional scarcity via assignment-problem trick (flex shares → RB/WR/TE); (c) per-pick gradient weight optimization with the "soft-punt" insight — let the optimizer de-weight replaceable positions rather than hard-coding positional runs; (d) snake-draft seat adjustment. Effort ~2 weeks (X_δ future-pick approximation is the subtle piece; prototype in Python with scipy).
- Acceptance gate: ADOPT if, across 1,000 simulated seasons per seat, it beats static-rank drafting by ≥5 percentage points of playoff rate with SE ≤ 1.6%; reject if the gain concentrates only in top seats.
