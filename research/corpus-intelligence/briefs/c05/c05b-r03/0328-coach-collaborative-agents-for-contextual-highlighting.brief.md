# arxiv-program/research/2026-09-21/arxiv-deep/0328-coach-collaborative-agents-for-contextual-highlighting.md
## What it is (1-2 sentences)
Research note on arXiv:2512.01853v2 (Wong et al., AAAI 2026): COACH, a multi-agent sports-video framework — shared backbone (Flan-T5-XL + TC-CLIP-B/16 + Q-Former) with role-specialized agents (Orchestrator/Grounder/Critic) via Structured CoT Tuning, coordinated by intent-routed pre-defined SOPs — validated on badminton rally QA and summarization. Verdict in-file: ADAPT the architecture pattern (not the sport/taxonomy) to GSE's NFL broadcast-video content pipeline: automated play localization, fact-checked recap generation, video QA.
## Key metrics/methods (formulas where given, else "not specified")
- Shared backbone: Flan-T5-XL LLM + TC-CLIP-B/16 video encoder + Q-Former vision-language alignment; captioning alignment; supervised 2 epochs, lr 2e-5, batch 16. One model serves all agents via multi-GPU parallelism.
- Structured CoT Tuning (no weight separation): role instruction prefixes + distinct CoT templates — Orchestrator (conditional routing: text query→single answer; video query→multi-step visual reasoning; summarization→decompose into Grounder sub-queries); Grounder ("Observe → Report" temporal localizer, must return empty set when no evidence — hallucination guard); Critic ("Analyze Assertion → Compare Evidence → Adjudicate Verdict" backward-reasoning fact-checker).
- Intent-driven orchestration: pre-defined SOPs, not online planners — Analytical Rally QA (Orchestrator→Retriever→Critic→synthesis); Generative Video Summarization (Orchestrator plans→Grounder batch-localizes→Critic verifies→Orchestrator writes narrative→Media Composition assembles video).
- Eval metrics: EM (factual), stroke-level F1/precision/recall (localization), NQA (negative-query accuracy, hallucination robustness), ROUGE-L (generative). Training data COACH-Data: 22 badminton matches, ~19,000 human strokes (ShuttleSet) → teacher-LLM (gpt-oss-120b) generated (Q, CoT, A) constrained by human few-shot exemplars; Knowledge QA from crawled badminton corpus (BWF statutes, BadmintonBible, Wikipedia).
## Data sources named
ShuttleSet (badminton stroke annotations); BWF statutes, BadmintonBible, Wikipedia (knowledge QA); teacher LLM gpt-oss-120b for synthetic (Q,CoT,A). No code/dataset URL in text; project page https://aiden1020.github.io/COACH-project-page/.
## Findings (numbers and facts, not vibes)
- Rally QA (Table 1), COACH w/ Critic vs Gemini 2.5 Pro: Action Classification EM 85.60% vs 24.20% (+61.4); Action Count 79.20% vs 37.60%; Summarisation ROUGE-L 33.56 vs 23.55; Temporal Localization Hit@1 76.66% vs 18.12%, EM 63.97% vs 7.04%, F1 76.21% vs 13.73% (+62.5); Knowledge QA ROUGE-L 27.40 vs 29.76 — Gemini wins (larger textual priors; isolates gains to architecture).
- Ablation w/o Critic: classification 85.60%→82.20% (−3.4); F1 76.21%→73.63%.
- Temporal grounding (Table 2): F1 84.77% vs 24.82%; NQA 91.80% vs 21.23%; precision 86.95% vs 27.49%.
- Role-pattern ablation (Table 3, same weights): Grounder pattern F1 84.77% vs Orchestrator pattern 75.95% (+8.82); NQA 91.80% vs 85.50% (+6.3) — validates Structured CoT Tuning as the specialization mechanism.
- Limitations flagged in-file: badminton-only; fixed SOPs can't handle novel task structures; summarization evaluated on localization metrics only (narrative quality never human-evaluated); GSE's standing video rule constrains Media Composition to real broadcast clips only.
- In-file spec: GSE-COACH with Grounder (play localizer over broadcast footage), Critic (fact-checks script claims vs nflverse/NGS box score), Orchestrator (intent router: recap vs film-breakdown vs prop-receipt); nflverse play-by-play as the ShuttleSet analog; teacher-LLM synthesized (Q,CoT,A). NFL-specific addition: replay-aware Grounder (deduplicate 3–4 broadcast replays to live-play instance). Gates: Grounder play-level F1 ≥ 0.75 on 3-game test; Critic catches ≥90% of injected false stat claims.
