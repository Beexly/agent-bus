# arxiv-program/research/2026-09-21/arxiv-deep/0238-towards-optimized-actions-in-critical-situations.md
## What it is (1-2 sentences)
Rahimian, Oroojlooy & Toka (2021) apply batch off-policy deep RL to soccer critical situations (high ball-loss/goal probability, no pass/dribble option), learning an optimal action policy maximizing expected goals and evaluating it via importance sampling + doubly-robust OPE without live deployment. Verdict in file: ADAPT — port the off-policy PG + doubly-robust OPE framework to NFL critical decisions (4th downs, 2-pt conversions, clock management) and as GSE's harness for evaluating new pick/staking policies on historical data.
## Key metrics/methods (formulas where given, else "not specified")
Possession value PV(s) = P(shot|X)·P(goal|shot,X) (Eq. 1). Reward: r = PV(s) if shot; PV(s')−PV(s) if kept; −0.1 if lost (Eq. 2). Return R(τ) = Σγᵗr / Σγᵗ, γ=0.99 (Eq. 3). Off-policy PG: ∇_θE[f] = E[(p(x)/q(x))·f(x)·∇_θ log p(x)] (Eq. 4). Doubly robust: V_DR^{H+1−t} = V̂(s_t) + ρ_t(r_t + γV_DR^{H−t} − Q̂(s_t,a_t)), ρ_t = π₁/π₀ (Eq. 5, Jiang & Li 2016). Defensive pressure via spectral clustering (kNN k=5 → Laplacian → K-means, ball holder as initial centroid, 3 zones; elbow method). Behavior policy: CNN-LSTM (100-unit LSTM + softmax) over possession endings. xG: logistic regression.
## Data sources named
InStat event + tracking data (1 frame/sec, 22 players), 104 European soccer matches, 2017–2018 season (proprietary; authors state reproducible on public Wyscout event data — though pressure features need tracking Wyscout lacks). Code: github.com/Peggy4444/soccer_RL. 28,054 possessions (max 10 actions); 15,225 shots for xG model.
## Findings (numbers and facts, not vibes)
Behavioral-policy classifier state III (hand-crafted + pressure features): 81% accuracy, 0.56 loss, 56,036 params — pressure features beat exact locations (state II: 75%/0.65, fails to converge; state I: 68%/0.71). Trained policy mean reward ≈ +0.45 vs behavioral ≈ −0.1 expected goals/episode; all 104 games improved (in-sample OPE). Scenario analyses: fouled player (−0.16) should have shot (0.4 expected); error-conceded-goal situation should have fouled; bad control should have sent ball out. xG logistic regression: AUC 0.798, Brier 0.012 (5-fold CV, beat XGBoost/RF/SVM). Limitations noted in file: OPE evaluated on the same 104 training games (in-sample); −0.1 loss penalty hand-tuned; no IS weight diagnostics/clipping; no held-out matches for policy eval.
## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- COACHING: quantifies "coach/player mistakes" in critical situations via learned-policy vs behavioral-policy comparison — directly portable to NFL 4th-down go/punt/FG, 2-pt go/kick, timeout/onside decisions using historical coach decisions (nflverse) as the behavior policy and Δ win probability as reward.
- OTHER: doubly-robust off-policy evaluation as a standard harness for scoring any new GSE pick-selection or staking policy on historical picks before live deployment — no A/B test needed.
- TRUST-SIGNAL: paper's honest failure modes (in-sample OPE, unaddressed importance-weight variance) define the pre-registered gates (held-out seasons, effective sample size >50%).
