# arxiv-program/research/2026-09-21/arxiv-deep/0278-parlaymarket-automated-market-making-for-parlaystyle.md
## What it is (1-2 sentences)
Rana, Nadkarni, Moshrefi & Viswanath (Princeton/Kaleidoscope Blockchain, 2026) design ParlayMarket, an automated market maker supporting parlay-style joint contracts over M binary events with coherent pricing via a pairwise exponential-family (Ising) model, O(M²) state, and online dependence learning from trade flow. Verdict in file: ADAPT the statistical machinery (coherent joint probabilities over correlated events) — not the AMM itself, since GSE is not a market maker.
## Key metrics/methods (formulas where given, else "not specified")
Belief state (Eq. 11): P_φ(x) ∝ exp(Σ_i θ_i x_i + Σ_{i<j} W_ij x_i x_j) — max-entropy distribution matching first/second moments; prices via belief propagation. Update (Eq. 13): φ_{t+1} = φ_t − η∇_φ CE(p_m*, p_m^{φ_t}) — each trade treated as cross-entropy error on composite pseudo-likelihood (Eq. 12); "shadow trades" propagate info across markets. Contracts f_S(x) = ∏_{i∈S} x_i (Eq. 1); prices p_S(φ) = E_{P_φ}[f_S(x)] (Eq. 2). Trader model: correlated arithmetic Brownian scores (Eq. 3). Theorems: parameter contraction 0.9/round (Thm 1); mean per-market loss ℓ̄_M = O(bη/2^M) halves per added market (Prop 2); higher-order parlays raise μ_eff, accelerate convergence (Prop 3). Loss quadratic in parameter error (Lemma 1).
## Data sources named
Synthetic: M ∈ {4..9} correlated binary assets (Gaussian score model, ρ=0.3), 100 runs, η=0.2. Kalshi RFQ audit: 220,746 native trades (sample 2026-02-03, 16 days); spreads on 999 base markets (5.12¢) vs 549 combo markets (11.89¢); 33 near-independent two-leg combos (NBA × ATP). Kalshi NBA replay (2026-03-07): 732 base markets, 5,918 combo tickers (2–10 legs), 3,710 candle updates + 5,436 executed parlay trades; LMSR liquidity b=10,000. No public code/data release stated.
## Findings (numbers and facts, not vibes)
Loss scaling: per-market loss halves per added market (ℓ_{M+1}/ℓ_M ≈ 0.49–0.50); ℓ_M·2^M ≈ 0.15 constant for M=4..9 — aggregate loss flat, polynomial not exponential; only non-oracle model whose loss decays with M. Ablation: without parlay flow the ranking reverses — ParlayMarket has the HIGHEST non-oracle loss; parlays are the primary information channel for dependence learning. RFQ audit: 13/33 = 39% of near-independent combo quotes violate the Fréchet upper bound P(A∩B) ≤ min(P(A),P(B)), some by 5.7×; aggregating 4.5 quotes/maker tightens spreads by only 0.19¢. Kalshi replay: standalone MM (θ_corr) 3,973 accepted trades, 86.8% win, $113,984.58 PnL, Sharpe 1.0049 — best risk-adjusted non-native strategy (vs Kalshi execution $244,190.77, Sharpe 0.7151). LP backtest: native execution $591,485.31 PnL, 52.35% ROI, Sharpe 0.2177. Limitations noted: Ising cannot represent higher-order dependence (unquantified floor); mutually exclusive outcomes need a structural preprocessing layer; replay scope is one NBA slate.
