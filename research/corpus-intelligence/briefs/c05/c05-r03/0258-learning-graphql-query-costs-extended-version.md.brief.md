# arxiv-program/research/2026-09-21/arxiv-deep/0258-learning-graphql-query-costs-extended-version.md
## What it is (1-2 sentences)
An ML-for-systems paper (Mavroudeas et al., 2021) that learns to estimate GraphQL query execution cost (type complexity) before running the query, replacing worst-case static-analysis upper bounds for fairer provider-side rate limiting. Verdict in file: REJECT — GSE is an API consumer, not a GraphQL API provider; there is no query-cost problem in GSE's stack for this to solve.
## Key metrics/methods (formulas where given, else "not specified")
estimate(s,c,q) = m(h(s,c,q)) ≈ tcx(r, Query, c). Feature extractors: h_f (bag-of-words field counts), h_g (graph2vec AST embeddings), h_s (six summary features: static-analysis upper bound, query size, width, nesting, list count, sum of list limits). Three Lale AutoML pipelines (StandardScaler → {No-Op, polynomial, Nystroem} → {linear, tree, Ridge, RF, kNN k=3, GBR}), 43 hyperparameters, 5-fold CV with Hyperopt (60h / 1,500 combos per dataset), then Wolpert stacked ensemble over the three estimates. Metrics: MAE = 1/n Σ|c_i − ĉ_i|; Error% = (ĉ−c)/c. Validation: 5-fold CV pipeline selection, per-feature-group ablation, mutual-information ranking, rate-limit simulator (1,000 sims × 1,000 queries), adversarial robustness sim.
## Data sources named
100,000 query-response pairs from the GitHub GraphQL API; 30,000 from the Yelp GraphQL API (synthetically generated queries, real commercial API responses). GitHub query size mean 109 (max 1,425), response cost mean 79 (max 2,548); Yelp query size mean 66 (max 229), response cost mean 1,301 (max 7,363). Artifact: github.com/Alan-Cha/graphql-complexity-paper-artifact.
## Findings (numbers and facts, not vibes)
MAE vs static bound: GitHub static 31.5 ± 263.8 vs ML 8.2 ± 35.5; Yelp static 14,180.5 ± 30,827.9 vs ML 60.7 ± 180.4. Ablation: summary features alone nearly match the stack (GitHub MAE 8.7 vs final 8.2); graph2vec embeddings worst alone (GitHub 31.58, Yelp 880.9). Hyperopt preferred gradient boosting in most pipelines. Rate-limit sim: threshold violations ≤6% of accepted queries on GitHub (≤80% over) and ≤15% on Yelp. Robustness: ML estimate rises rapidly as the static-bound feature enters the malicious regime; GBR plateaus outside training range (no extrapolation). Retraining required as API/data evolves.
