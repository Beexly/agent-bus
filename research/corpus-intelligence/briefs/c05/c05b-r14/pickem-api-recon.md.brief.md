# dfs/research/2026-09-25/pickem-api-recon.md
## What it is (1-2 sentences)
A live-verified recon of 10 pick'em/DFS/sportsbook platform APIs (curl-tested 2026-09-25 from the VM), verdicting each as WIRE (no-auth usable), KEY (needs user's own session token), or SKIP, with six intake modules already written default-OFF and env-gated.
## Key metrics/methods (formulas where given, else "not specified")
- DraftKings Pick6 (WIRE): 7 no-auth GET routes on `https://api.draftkings.com`; plain `/pick6/...` routes answer, `/public/pick6/...` variants 404. `GET /pick6/v1/pickgroups/{id}/category/pickcards?format=json` returns full board (e.g., NFL group 153812: 150,682 bytes, 28 cards, e.g. Jonathan Taylor Rushing Yards 39.5). `GET /pick6/v1/entrydetails/{pickGroupId}?format=json` returns payout multipliers: 2-pick 3x, 3-pick 6x, 4-pick 10x (pick sets 2–8). JS bundle inventory at `https://pick6.draftkings.com/assets/endpoints-C5u8nxYj.js` (hash rotates per deploy; re-fetch to re-discover). No rate limits documented; no 429s in low-volume sequential testing.
- Underdog Fantasy pick'em (WIRE): `GET https://api.underdogfantasy.com/v2/over_under_lines?product=fantasy&sport_id=NFL` returns 4,290 lines / 539 players (~11.94 MB), each line with `stat_value`, `options[]` (higher/lower, american + decimal prices), `status`, `updated_at`; player join via `appearances[]`. Sample: Chase Brown rushing_yds 63.5, -112 both sides. `/beta/v[4,5,6]/over_under_lines` now returns **426 upgrade_required** (killed Aug–Sep 2026); `product=` accepts ONLY `fantasy` (other values 400); `?product=fantasy` requires `sport_id`. Stats host `https://stats.underdogfantasy.com`: `/v2/sports`, `/v1/scoring_types`, `/v1/sports/NFL/slates` (Week 3 "Sun Main Slate" 2026-09-27T17:00Z), `/v1/sports/NFL/matches?date=2026-09-27` (`?date=` required, bare path 400s).
- PrizePicks (WIRE): `GET https://partner-api.prizepicks.com/projections?league_id=9` → 200, ~8.72 MB, 7,554 NFL projections, updated 2026-09-25T13:26-04:00; fields: `line_score`, `stat_type`, `stat_display_name`, `start_time`, `status`, `board_time`, `updated_at`, `allowed_wager_types`, `is_promo`, `flash_sale_line_score`; players via `relationships.new_player` → `included[]`. League ids: 9=NFL, 7=NBA, 15=CFB, 2=MLB, 12=UFC, 8=NHL, 3=WNBA, 1=PGA, 5=TENNIS, 82=SOCCER, 125=F1, 42=BOXING, 241=WORLD CUP. Classic `api.prizepicks.com` is DataDome bot-walled (403 JS challenge); partner-api works. `/projections` no params = all leagues ~47 MB. 10 rapid sequential requests → all 200; community guidance ~2s between requests.
- Sleeper (WIRE): documented public API `https://api.sleeper.app`, <1,000 calls/min (20 rapid GETs all 200). `GET /v1/state/nfl` (week 3, season 2026, 211 bytes); `GET /v1/players/nfl` (~10k players, ~14.66 MB — cache daily); `GET /v1/players/nfl/trending/{add|drop}?lookback_hours=24&limit=25`; `GET /v1/stats/nfl/regular/2026/3` (box-score stats incl. snap counts `off_snp`, `tm_off_snp`, pos ranks ppr/half/std; 36,310 bytes); `GET /v1/projections/nfl/regular/2026/4` (9,422 players, 628,382 bytes, fields `adp_dd_ppr`, `pts_ppr/pts_half_ppr/pts_std`, projected stat lines). Dead: `/v1/schedule/nfl`, `/v1/schedules/nfl/2026` (404); legacy host `api.sleeper.com` (404).
- Action Network scoreboard (WIRE): `GET https://api.actionnetwork.com/web/v1/scoreboard/{league}?date=YYYYMMDD&bookIds=15,30` → per-book moneyline/spread/total rows; bookIds DraftKings=15, FanDuel=30, Caesars=68, BetMGM=69. Sample: `/nfl?date=20260927&bookIds=15,30` → 200, 908,305 bytes, 16 NFL Week 3 games.
- Drafters (KEY): no no-auth API; ~60 endpoint paths reverse-engineered from own shipped Angular bundle (`https://drafters.com/drafts/main.js`, 6.3 MB). `GET https://node.drafters.com/props-game/get-props-games/{league_id}?stats=` 403s unauthenticated ("A token is required for authentication"); needs user's OWN Bearer token from own browser devtools. League ids: NFL=2, CFB=10, NHL=1, CBB=7, NBA=4, MLB=3. Module gated on BOTH `DRAFTERS_INTAKE_ENABLED=true` AND `DRAFTERS_BEARER_TOKEN`.
- FanDuel fantasy DFS (SKIP): all data routes 401 unauthenticated (`/fixture-lists`, `/sports`); hardened with 2FA since Oct 2023.
- FanDuel Picks (SKIP): product shut down permanently March 2026 (final contests Apr 23; withdrawals through May 29).
- FanDuel sportsbook sbapi (SKIP): static `_ak=FhMFpcPWXMeyZxOx` token verified live 200 (1.3 MB odds JSON) but fragile/rotation-prone with ToS exposure; Action Network is the better route.

## Findings (numbers and facts, not vibes)
- 6 WIRE verdicts (DK Pick6, Underdog pick'em, Underdog stats, PrizePicks, Sleeper, Action Network), 1 KEY (Drafters), 3 SKIP (FanDuel fantasy, FanDuel Picks, FanDuel sbapi).
- 6 new intake modules written: `prizepicks-intake.ts`, `underdog-pickem-intake.ts`, `dk-pick6-intake.ts`, `sleeper-projections-intake.ts`, `drafters-intake.ts`, `action-network-scoreboard-intake.ts` (each with `.test.ts`), all default-OFF env-gated.
- Biggest raw boards: Underdog pick'em ~11.94 MB (4,290 lines / 539 players); PrizePicks 7,554 NFL projections (~8.72 MB, updated 2026-09-25T13:26-04:00); Sleeper projections 9,422 players (628,382 bytes); Sleeper player DB ~14.66 MB.
- ToS caveat stated in file: PrizePicks and Underdog APIs are undocumented/reverse-engineered; their ToS almost certainly prohibit automated collection — internal research use, gentle rates, do not republish raw feeds. Health checks should alert on 426/403/404.
