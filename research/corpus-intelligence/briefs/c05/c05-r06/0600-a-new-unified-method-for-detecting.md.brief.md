# arxiv-program/research/2026-09-21/arxiv-deep/0600-a-new-unified-method-for-detecting.md
## What it is (1-2 sentences)
Deep read of Nag et al. (2020, arXiv:2005.12524) proposing a three-stage hybrid pipeline (gradient-magnitude/directional-coherence temporal candidate detection, Bayesian skin detection with Viola-Jones face-to-torso geometry, adaptive pixel-linking deep text detector) to detect bib numbers on marathon runners and sports players in video. Ledger verdict REJECT: bib-number OCR on marathon runners has no viable transfer path to GSE's numerical/odds NFL engine.
## Key metrics/methods (formulas where given, else "not specified")
Stage 1 (candidate detection): GM(i) = log(1 + (sum Sx^2 + sum Sy^2)/2) (eq. 1); covariance matrix E(i) from Sx, Sy -> eigenvalues lambda_1, lambda_2; DC(i) = ((lambda_1 - lambda_2)/(lambda_1 + lambda_2))^2 (eq. 3); GMdiff/DCdiff via 5x5 max-min; Fuse = GMdiff + DCdiff; frame differencing + K-means k=3 (Max/Min/Average clusters); key frames from cluster statistics (eqs. 7-9). Stage 2 (Bayesian skin): P(skin) = MODE(Avg)/(MODE(Avg)+MODE(Max)) (eq. 10); P(skin|window) posterior via eq. 11, threshold >= 0.50; torso geometry Height_Torso = 7 * Height_Head (eq. 12), Width_Torso = 2 * Height_Head (eq. 13), multipliers fit on 500 samples. Stage 3 (adaptive pixel-linking): VGG16 backbone, PixelLink base; L = 2 alpha(t) L_pixel + (1 - alpha(t)) L_link (eq. 14); training SGD momentum 0.8, weight decay 6e-6, lr 0.0001 for 20K iterations then 0.001 for 40K. F-measure with alpha = 0.5 (eq. 17).
## Data sources named
Six datasets, 9,115 videos/images total: own dataset (44 ~10s clips, soccer/tennis/cricket/marathon, 150x150 to 1280x720, not released); MMM (50 marathon videos); RBNR (50 marathon bib videos); R-ID (8,706 re-identification videos with bib text); CTW1500 (15 curved-text images); MS-COCO Text (~250 images). Training: 10,206 images (7,206 train / 2,000 val / 1,000 test) from ICDAR 2015 fine-tuning + RBNR + R-ID + MMM samples. No code link stated; own-dataset videos not released.
## Findings (numbers and facts, not vibes)
Key steps on own dataset (P/R/F): key-frame detection 0.86/0.91/0.88; skin detection 0.80/0.78/0.79; face detection 0.86/0.83/0.84. Torso detection F-measures: RBNR 0.92, MMM 0.79, CTW1500 0.79, MS-COCO 0.76, R-ID 0.87, own 0.78 — beats prior RBNR/MMM methods on nearly every dataset. Text/bib detection F (proposed best on all six): RBNR 0.75, MMM 0.79, Re-ID 0.90, CTW1500 0.71, MS-COCO 0.37, own 0.82. The "-Torso" variants of EAST/RRD/TextSnake/Re-ID/CRAFT all improve over "-Full" (e.g., CRAFT-Torso 0.81 vs 0.80 on own data), confirming torso pre-segmentation helps every detector. Recognition: torso-region input beats full-image for every method on every dataset (e.g., SEE-Torso 0.83 vs SEE-Full 0.80). All methods fail on MS-COCO (F <= 0.37). Reader flags: 2020-era hybrid is obsolete vs PaddleOCR/EasyOCR/TrOCR; handcrafted constants (K=3, multipliers 7/2) are fit-and-forget; no code/data release; skin pipeline breaks on covered bodies/backs/helmets; zero NFL external validity.
