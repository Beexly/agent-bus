# arxiv-program/research/2026-09-21/arxiv-deep/0529-dasharena-benchmarking-llms-on-interactive-analytic.md
## What it is (1-2 sentences)
Deep read of Wang & Deng (2026, arXiv:2608.10567) introducing DashArena, a benchmark for LLM-generated interactive analytic dashboards evaluated via replayable interaction trajectories and a distilled VLM judge with Bradley-Terry aggregation. Ledger verdict REJECT: an LLM code-generation benchmark with no math, model, or dataset transferring to NFL team-rating prediction.
## Key metrics/methods (formulas where given, else "not specified")
Protocol: (1) task briefs derived from Tableau Public dashboards (Claude Opus 4.6 writes task intent); (2) candidate generates one HTML dashboard + JSON interaction trajectory; (3) Playwright executor replays trajectory, reports renderable/replayable deterministic validity; (4) VLM pairwise judge outputs A/B/tie preference with rationale; (5) Bradley-Terry aggregation, leaderboard scaled 1000 + 400*theta, task-bootstrap 95% CIs. DashJudge-8B distilled from Claude Opus 4.6 teacher: Qwen3-VL-8B-Instruct, LoRA rank 16, scale 32, dropout 0.05, lr 1e-4, batch 8, cosine schedule, 2 epochs, ~50 min on one 80GB A100. Only equation: P(i > j) = sigma(theta_i - theta_j) (Bradley-Terry logistic link).
## Data sources named
234 tasks derived from Tableau Public crawled dashboards (14 topic clusters, deduped by data similarity); 120 held-out leaderboard tasks; 100 stratified candidate pairs (6 annotators, Fleiss kappa = 0.384) for human calibration; 300 teacher-labeled pairs (255 train / 45 judge-test, A/B-swapped to 510 SFT examples). No sports or NFL data whatsoever.
## Findings (numbers and facts, not vibes)
Judge agreement with humans (99 pairs): base Qwen3-VL-8B-Instruct 70.7% (kappa=0.419); teacher Claude Opus 4.6 78.8% (kappa=0.590); DashJudge-8B 79.8% (kappa=0.600). Adding interaction evidence to screenshots: 71.7% -> 79.8% (+8.1 pts). Deterministic validity: no model exceeds 86% render rate or 74% replay rate (GPT-5.5: 85.8%/73.3%; Grok 4.3 last). Leaderboard: GPT-5.5 first (CI overlaps human baseline); human baseline and GLM-5.2 next; Claude Opus 4.6, DeepSeek V4 Pro, Gemini 3.5 Flash, Kimi K2.7 Code mid-tier. Failure audit (100 candidates): of 70 signal-enriched, 95.7% contained a confirmed model-attributed defect; 21 of 30 execution-clean candidates still had defects deterministic checks cannot detect. Task-subsampling stability: mean Kendall tau = 0.810 at 25 tasks, 0.867 at 50, 0.945 at 100.
