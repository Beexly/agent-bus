# arxiv-program/research/2026-09-21/arxiv-deep/0509-analysing-long-short-term-memory-models.md
## What it is (1-2 sentences)
Deep read of Chakwate & Madhan (2020, arXiv:2011.02122) on LSTM models for cricket match-outcome prediction, evaluated at ball-by-ball timestamps across ODIs. Ledger verdict ADAPT: the per-timestep all-inputs/all-outputs LSTM architecture transfers to NFL live spread/total probability surfaces, but cricket-specific features do not.
## Key metrics/methods (formulas where given, else "not specified")
No equations stated in the paper (LSTM gating, softmax, BCE described only in prose). Three-block network: shared Input Transformation block per ball + LSTM block + Output Transformation block mapping to a 2-dim win/lose vector, softmax → win probability, mean Binary Cross Entropy over all balls as training objective. Four architecture variants tested: A (all-input/single output), B (all-input/multi-output — one output head per timestamp, selected best, converges in 100 epochs), C (randomly sampled prefixes/single output), D (cumulative-sum features/single output). Best model appends three ablations to inputs: pre-match LGBM classification result, first-innings target score, wickets fallen.
## Data sources named
Open-source ODI cricket dataset (unnamed, "open source ODIs dataset"), 1,597 international matches from 1971 onward, 300 balls/innings nominally, ball-level attributes (innings, over.ball, team, batsman, bowler, runs, extras, wicket flag) + match-level stats (venue, toss, weather, etc.). Code stated at github.com/ruc98/American_Express_Ignite_2019_Challenge (not verified by reader). Baselines: AdaBoost and LGBM pre-match classifiers; Jhawar et al. 2017 per-over Random Forests (75.68% avg accuracy).
## Findings (numbers and facts, not vibes)
Architecture comparison (test accuracy % at J=300/250/200 balls): Model A 93.7/63.5/57.2; Model B 95.7/75.1/66.4; Model C 79.6/66.7/59.2; Model D 60.8/52.6/52.6. Pre-match classification test accuracy: AdaBoost 47.2%, LGBM 61.3% (train 76.3%). Ablation gains on Model B (test, J=300/250/200): baseline 95.7/75.1/66.4 → +pre-match result 96.3/77.6/68.2 (~+2% avg) → +target score 98.0/90.1/87.1 (~+13% avg) → +wickets fallen 98.4/92.5/88.2 (~+2% further). Best model accuracy curve (train/test %): 300 balls 98.3/98.4; 240 91.0/92.1; 180 88.7/88.0; 120 85.2/87.3; 90 80.4/85.6; 60 78.1/82.7; 30 70.2/72.4; 6 62.3/62.7. Reader flags: test accuracy exceeding train at several checkpoints signals a small/odd test split; late-match accuracy is near-deterministic arithmetic (score vs target), so only early-ball accuracy (62-82%) is real signal; no calibration metrics reported (no Brier, log loss, AUC); hyperparameters unstated; train/test split methodology unstated.
## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- [OTHER] Per-timestep recurrent output architecture is a template for live in-play NFL probability modeling (live spread/total surfaces — the exact gap item 7 in GSE's existing research map).
- [TRUST-SIGNAL] The +13% accuracy ablation from appending the target score to every timestep argues score-differential conditioning is the dominant feature class for in-play models — supports wiring de-vigged pre-game spread/total into every play-level input.
- [SCHEME] Ablations show pre-match priors appended as features add only ~+2%, while in-game state (target score) adds ~+13%: information decay structure useful for weighting pre-game vs live signals.
