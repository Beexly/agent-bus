# frontier/MODEL_PROMOTION_GATE_CONTRACT.md
## What it is (1-2 sentences)
A frozen implementation contract for a three-leg model promotion gate (paired Brier calibration superiority, CLV non-inferiority, procedural integrity) that inverts the DEC-062 failure — a structurally fake champion/challenger promoter whose `computeClvMean()` returned 0.5 for every input and whose Brier comparison read the same field for both sides — into six required safety tests.
## Key metrics/methods (formulas where given, else "not specified")
- Promotion rule: challenger K replaces champion C iff K's out-of-sample predictive quality exceeds C's with sufficient evidence, same events, leak-free walk-forward, pre-registered parameters. Gate outputs ELIGIBLE / NOT_ELIGIBLE + evidence; MODEL_VERSION switch stays founder-applied.
- Leg 1 — paired Brier differential: d_i = (p_C,i − y_i)² − (p_K,i − y_i)² (positive = K better); range width (b−a) = 2, not 1.
- Leg 1 test formula (empirical-Bernstein LCB, NOT a t-test — deliberately non-asymptotic, valid at every n): LCB(δ) = d̄ − s_d·√(2·ln(2/δ)/n) − (b−a)·7·ln(2/δ)/(3(n−1)), with (b−a) = 2. Note: hard-coding (b−a)=1 understates uncertainty by 7·ln(2/δ)/(3(n−1)) — about 0.017 at n=500, δ=0.05, >8x δ_prac — toward false eligibility.
- Leg 1 pass: LCB(0.05) > δ_prac AND coverage ≥ coverageFloor (default 0.95 of pre-registered event universe, window-hashed), δ_prac = 0.002 Brier points, n ≥ N_min = 500 paired settled events (power note: detecting μ_d = 0.005 at s_d ≈ 0.08 needs n ≈ 700).
- Leg 2 — CLV non-inferiority: `welchOneSidedNonInferiority` / `welchCompare` (prediction-engine), H0: μ_CLV,K ≤ μ_CLV,C − ε rejected at 0.05, ε = 5 bps; both sides ≥ 100 graded shadow/production CLV picks in-window. Zero-variance samples: decide directly by sign of mean(K) − mean(C) + ε (deterministic evidence, not absence of evidence). Caveat: shadow-evaluation lane ("Workstream E router") has no implementation on trunk — no ShadowPick/shadow-lane storage exists; architecture question must be resolved before any trial window collects Leg 2 evidence.
- Promotion rule: Leg 1 AND Leg 2. CLV-superior-but-calibration-flat challengers are a founder-judgment case, never auto-promoted.
- Leg 3 — procedural integrity: pre-registered window/market family/N_min/δ_prac/ε/universe/coverageFloor before window opens; one evaluation per challenger per window; m concurrent challengers ⇒ Bonferroni δ/m on both legs; walk-forward only (PickSignalSnapshot discipline; rejects windows containing post-lock predictions); all timestamps must carry explicit timezone designator (Z or ±HH:MM); row-level corruption rejected not filtered (duplicate ids, out-of-range/non-finite probabilities, non-binary outcomes, non-finite CLV, unknown model labels throw typed integrity errors); post-promotion hysteresis — new champion immune until 200 further settled picks (anti-flapping burn-in).
- Six anti-DEC-062 required tests: (1) identity fixed point — K ≡ C ⇒ all d_i = 0, LCB < δ_prac, NOT_ELIGIBLE; (2) oracle promotes Leg 1 — K = outcome oracle ⇒ Leg 1 passes in isolation (does not assert full-gate ELIGIBLE); (3) placebo rejects — K = C + seeded noise ⇒ eligibility rate ≤ δ across seeded runs (property test); (4) no self-reports structurally — harness input type accepts only row-level persisted records, computes every aggregate itself; (5) replayable decision — PromotionDecision records (window hash, stats, code revision, verdict) appended to hash-chain ledger, recompute.ts re-derives verdict byte-for-byte; (6) founder gate.
- Implementation map: packages/prediction-engine/src/promotion/ — pairedBrierLcb, clvNonInferiority over welchCompare, evaluatePromotion; evaluator + ledger record only, dark until a founder registers the first trial window.
## Data sources named

- DEC-062 record: the declined `laughing-wozniak-gyryjx` promoter (task #75).
## Findings (numbers and facts, not vibes)
- The declined promoter could never promote anything (computeClvMean() = 0.5 constant; brierImprovement identically 0) and its tests asserted the tautology — the deep failure was trusting model-adjacent self-reports instead of recomputing from persisted ground truth.
- Canonical EB formula corrected after external review caught the (b−a)=1 hard-code; ~0.017 LCB bias at n=500/δ=0.05.
- Thresholds: δ_prac = 0.002 Brier points; N_min = 500 paired events; coverageFloor = 0.95; ε = 5 bps CLV margin; min 100 graded CLV picks per side; 200-pick anti-flap burn-in.
- Contract status: FROZEN, ready for Sonnet implementation; supersedes the DEC-062-declined promoter; no ShadowPick/shadow-lane storage exists on trunk as of writing.
