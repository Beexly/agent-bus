# arxiv-program/research/2026-09-21/arxiv-deep/2193-os2fsu-online-sparse-streaming-feature-selection-uncertainty.md
## What it is (1-2 sentences)
Research ledger for OS2FSU — Online Sparse Streaming Feature Selection with Uncertainty (arXiv:2208.01562v2), the only online streaming feature selection method treating missingness as a first-class problem: latent-factor-analysis imputation of sparse streaming features, then fuzzy-logic-regulated significance thresholds plus neighborhood-rough-set dependency scoring to absorb imputation uncertainty. Best on 6/6 datasets at every missing rate, Wilcoxon-significant. Ledger verdict: ADAPT the LFA-impute + fuzzy-select loop for GSE's new metrics and market features that arrive with short/gappy histories (NGS-derived, props, injury designations) — a principled third way between dropping gappy features and crude fills.
## Key metrics/methods (formulas where given, else "not specified")
- Phase I — LFA imputation: buffer Bs=15 streaming features into matrix B (M×Bs); factorize R̂ = PQᵀ minimizing L(P,Q) = ½‖W⊙(R−PQᵀ)‖²_F + (λ/2)(‖P‖²_F + ‖Q‖²_F) (Eq. 1) via SGD; W masks observed entries; completed matrix B̂ = PQᵀ.
- Phase II — selection per feature F̂_j in B̂: (a) online relevance via Fisher's-z test (continuous) / G² test (discrete) → re-Dep(C, F̂_j|∅) vs re-Ind; (b) online redundancy I/II: Markov-blanket-style — discard F̂_j if ∃S ⊆ SF with P(C|F̂_j,S) = P(C|S); re-check incumbents after adding; (c) fuzzy correlation analysis: trapezoidal membership function lets significance threshold μ float in [0.01, 0.1] instead of fixed 0.01/0.05; features with μ < p ≤ 0.1 are "fuzzy relevance features," scored by neighborhood-rough-set dependency γ_{F̂_j}(C) = |R̲_G D|/|U| (Eq. 7), top |SF|/2 added to SF.
- Neighborhood δ_h^G(x) = {y : Δ(x,y) ≤ h} (Eq. 5); lower/upper approximations (Eq. 6); per-entry SGD objective (Eq. 8).
- Complexity: O(M·T·(1−θ)·d + |RF−RF₁|^ω·|SF| + |RF₁|·|SF|^ω·|SF|). Hyperparameters: Bs=15, λ=0.01, η=0.00001.
- Assumptions: (i) missingness recoverable by low-rank structure (LFA); (ii) imputation error is the dominant uncertainty source, addressable by softening α; (iii) buffer Bs=15 gives enough co-occurrence for factorization; (iv) test data complete (train-only missingness). GSE transfer: buffer each week's new/sparse features (Bs=8 weeks), LFA via SGD (rank d=8, λ=0.01); feed selected sparse features into the 2191 NFS gate with an "imputed" flag so downstream can down-weight.
## Data sources named
- Six real datasets (Table II): mfeat-factors (217 feats × 2000), SMK-CAN-187 (19993 × 187), lung (3312 × 203), USPS (256 × 9298), COIL (241 × 1500), Isolet (617 × 1560) — all public (ASU, OpenML, UCI). Training data sparsified at missing rates θ = 0.1–0.9; test data complete. Evaluation: average accuracy of KNN + SVM + Random Forest, 5-fold CV. Baselines: LOSSA, fast-OSFS, SAOLA, OSFASW, SFS_FI (last four on zero-filled (_Z) or mean-filled (_M) data — 9 competitors total).
## Findings (numbers and facts, not vibes)
- θ = 0.1: OS2FSU best on 6/6 datasets (Table IV). D1 90.05 ± 0.56 (vs LOSSA 83.95); D2 72.78 ± 1.57 (vs 69.84); D3 89.64 ± 1.22 (vs 86.48); D4 86.26 ± 2.48 (vs 77.44); D5 82.8 ± 8.01 (vs 71.97); D6 73.25 ± 3.19 (vs 50.66 — a 22.6-point gap). Average 82.46 vs LOSSA 73.39 vs SAOLA_M 62.65 (paper: +10.29 pp over runner-up, +19.81 pp over last).
- D1 across θ (Table V): OS2FSU best at every θ from 0.1 (90.05) to 0.9 (61.05); average 85.26 vs LOSSA 77.53. Accuracy flat-to-improving for θ ≤ 0.6 (90.05 → 87.95), then drops rapidly (77.47 at 0.8, 61.05 at 0.9) — imputation error dominates past 60% missingness.
- Wilcoxon (Table VI, α = 0.1, reject if R_m ≤ 2 with N=6): R⁻ = 0 (OS2FSU never loses a dataset) at nearly all θ ≤ 0.7 vs every competitor → statistically significant.
- Selection size (Table III, θ=0.1): OS2FSU selects a moderate 16.73 features on average (vs LOSSA 8.97, SAOLA_Z 15.77) — the fuzzy band admits useful marginal features rather than over-pruning.
- Adversarial notes from file: test-complete/train-sparse flatters imputation methods; low-rank missingness assumption untested (not-at-random missingness bakes in bias); accuracy collapses past θ=0.6 for ALL methods (bounded operating envelope); fuzzy band [0.01, 0.1] and top-|SF|/2 are heuristics without ablation; redundancy analysis exponential in |SF| subsets — fine at |SF|~17, untested at larger pools; classification-only, no regression/log-loss validation.

## Engine-actionable? (yes/no + one-line what)
Yes — reimplement the two-phase loop (weekly LFA-SGD imputation of sparse newcomer features + Fisher's-z relevance with fuzzy μ ∈ [0.01, 0.1] band and rough-set dependency γ for fuzzy-band features), feeding selected features into the 2191 NFS gate with "imputed" flags; accept iff on the 2015–2024 gse-lab masked-feature test (30% of entries masked in 10 metrics, test 2024 cover log-loss) arm C (OS2FSU) beats both arm A (drop) and arm B (mean-fill) by ≥ 0.002 AND retains ≥ 5 of the 10 masked features; reject if imputation unstable across seeds on real sparse features or any real feature has θ > 0.6 (outside the operating envelope — drop instead); improvement experiment: make the fuzzy band missingness-adaptive — scale μ by each feature's LFA reconstruction error on held-out observed entries, doubling the confidence scores as data-quality monitoring for the weekly pipeline.
