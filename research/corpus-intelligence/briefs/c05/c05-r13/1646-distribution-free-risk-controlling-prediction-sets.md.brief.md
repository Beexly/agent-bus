# arxiv-program/research/2026-09-21/arxiv-deep/1646-distribution-free-risk-controlling-prediction-sets.md
## What it is (1-2 sentences)
Ledger verdict: ADAPT. Full read of Bates et al. (2021), "Distribution-Free, Risk-Controlling Prediction Sets" (arXiv:2101.02703, JACM 2023): generalizes conformal prediction from controlling miscoverage to controlling ANY monotone risk with high probability 1−δ — the formal risk-control layer for GSE's abstention-gated public pick publishing (complements ledger [0743] Conformal Risk Control, which controls risk only in expectation).
## Key metrics/methods (formulas where given, else "not specified")
UCB calibration for Risk-Controlling Prediction Sets (RCPS): fix a NESTED family of set predictors {T_λ} (larger λ ⇒ larger sets ⇒ loss nonincreasing in λ); on calibration data compute empirical risks R̂(λ); form high-probability upper confidence bounds R̂⁺(λ); choose λ̂ = inf{λ : R̂⁺(λ′) ≤ α ∀λ′ ≥ λ}. Formulas: R(T) = E[L(Y,T(X))]; Theorem: P(R(T_λ̂) ≤ α) ≥ 1−δ; example Hoeffding UCB: R̂⁺(λ) = R̂(λ) + sqrt(log(1/δ)/(2n)). Supported UCBs: Hoeffding, Hoeffding–Bentkus, Waudby–Smith–Ramdas, Pinelis–Utev, CLT/asymptotic. GSE transfer: T_λ = {games with |edge| ≥ λ} is nested in λ; loss L = fraction of posted picks that lose.
## Data sources named
Five vision problems: (1) ImageNet classification with class-varying loss, 30,000 calibration / 20,000 evaluation points, 100 random splits; (2) MS COCO multi-label (80 categories, TResNet); (3) ImageNet hierarchical (WordNet tree); (4) polyp image segmentation (per-polyp pixel recall); (5) protein structure (AlphaFold-style). Code in the angelopoulos-lab RCPS GitHub repo.
## Findings (numbers and facts, not vibes)
ImageNet class-varying loss: risk controlled at nominal level across all 100 splits with "reasonable" set sizes; realized-risk histogram concentrates just below α (near-tightness). COCO multi-label: risk controlled at reasonable set sizes. Hierarchical ImageNet: risk controlled with "relatively precise (low depth)" predictions — safety not bought with trivially huge sets. Polyp segmentation: captures 90% of true polyp pixels per polyp per image with the CLT bound. No competing-method horse race; the empirical claim is tightness (risk ≈ α from below). Caveat: with a 100-pick calibration window and δ=0.1, the Hoeffding penalty sqrt(log(1/δ)/2n) ≈ 0.12 — enormous against α=0.45; the paper's own remedy is the tighter Waudby–Smith–Ramdas (empirical-Bernstein) UCB.
