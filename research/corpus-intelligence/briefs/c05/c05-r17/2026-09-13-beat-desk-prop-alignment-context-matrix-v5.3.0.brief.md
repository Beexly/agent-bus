## What it is (1-2 sentences)
A 2026-09-13 calibration proposal (status: PROPOSED; supersedes v5.2.7) for five interlocking engine moves — calibrated confidence, stronger thresholds, beat desk, prop alignment, context matrix — with a 2026-10-01 audit note stating all five moves are NOT implemented and NOT part of shipped v5.3.0 (consumed by the 2026-09-27 narrative_contract promotion, PR #954, merged 2026-09-29).
## Key metrics/methods (formulas where given, else "not specified")
- Calibrated confidence: `confidence = round(calibrated_p × 100)` from regularized logistic regression (glass-box; GBM challenger) on the full factor vector + new layers; features per pick: consensus, depth, edge, movement, rest, form, quality, H2H, venue, uncertainty, cross-market, schedule stress. `rankingP` and `calibrated_p` converge to one object.
- Stronger thresholds: Premium becomes a conjunction (calibrated confidence ≥ cutoff AND shrunk edge ≥ min_edge AND beat-vector agreement AND prop alignment ≥ neutral AND dataQualityScore ≥ bar); cutoffs refit from backtested CLV/ROI where marginal CLV/ROI turn durably positive.
- Beat desk: ingest → classify (injury/lineup/scheme/motivation/weather/off-field) → entity-resolve → polarity × magnitude → freshness decay (half-life ~24–48h; injury decays slower) → source trust weight. Trust tiers T1 (official) → T4 (Reddit, volume-gated); weights update on rolling correlation with realized outcomes ("tipster leaderboard"). High-magnitude unresolved negative items act as hold flags blocking Premium.
- Prop alignment: derive prop-implied game script (pace, pass-heaviness, scoring level); alignment score = similarity with the pick-implied script; aligned → small boost, conflicted → penalty + human-review flag. Anti-circularity guard: use independent prop sources, down-weight when props echo the same steam as sides.
- Context matrix: travel (miles, time zones, altitude, road-trip game number), rest differential (non-linear, 1 day noise / 3+ signal), O-vs-D unit matchups, coaching/scheme (coaching ATS H2H, scheme clashes, 4th-down aggressiveness, coordinator-change priors) — all learned weights, interactions (rest × altitude, injuries × spread size).
