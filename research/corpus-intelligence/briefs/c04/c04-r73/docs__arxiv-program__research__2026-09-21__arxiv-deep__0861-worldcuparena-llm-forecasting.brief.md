# docs/arxiv-program/research/2026-09-21/arxiv-deep/0861-worldcuparena-llm-forecasting.md
## What it is (1-2 sentences)
An evaluation-benchmark paper (SJTU/UCL/McGill team, July 2026, arXiv:2607.18084) — WorldCupArena — grading 13 LLMs/research agents on all 104 matches of the 2026 World Cup across five layers (result+score, players, events, tactics/stats, competition) with a novel Scoreline partial-credit metric, availability-aware aggregation, and a lock-predictions-24h-before-deadline verification protocol. The deep-read ledger rates it ADAPT for its evaluation machinery, not its leaderboard (2026 models/events unverifiable from here).
## Key metrics/methods (formulas where given, else "not specified")
- Scoreline partial-credit (eq. 1): S_score = 45·I_r + 25[1 − e_d/5]_+ + 20[1 − e_t/6]_+ + 10[1 − e_team/8]_+, where I_r = correct result class, e_d = goal-difference error, e_t = total-goals error, e_team = team-wise goals error. Exact = 100; result class worth 45/100.
- Five layers (Table 1): T1 result+score (0.40), T2 players/lineups (0.20), T3 events (0.15), T4 tactics/statistics (0.15), T5 competition (0.10); T1 weights: 1X2 0.35, exact 0.20, scoreline 0.30, goal diff 0.10, qualification 0.05.
- Availability-aware aggregation (eq. 2): S_A = Σ_{j∈A} w_j S_j / Σ_{j∈A} w_j over available components only — missing truth excluded, never zero-filled.
- Display contrast calibration (eq. 3): C(R) = 100·(σ((R−50)/5) − σ(−10))/(σ(10) − σ(−10)) — monotonic; ledger warns not to adopt for external reporting (stretches mid-range).
- T5 competition score (eq. 4): T5_complete = (0.25G + 0.35(0.7A + 0.3M) + 0.20H)/0.80; G = Kendall τ group order; A/M = round-weighted (1,2,4,8,16) advancement/exact-pairing; H = 100 if champion correct.
- Also: 3-way Brier for calibration; Jaccard/F1/nDCG for players; Hungarian-matched MAE/event-F1; sMAPE for counts. Minimum-coverage rule: ≥52 valid predictions (≥50% of most-complete).
## Data sources named
All 104 matches of the 2026 FIFA World Cup (72 group, 16 R32, 8 R16, 4 QF, 2 SF, 3rd-place, final; champion Spain; final Spain–Argentina). Baselines: Polymarket (last price in [T−24h,T), 104 fixtures), BetVictor via Sportmonks pre-match odds (104), human fans (152-user internal group, 94 matches). In-play track: 2,957 checkpoints over 100 matches, median gap 6.8 min (IQR 6.2–12.4). Code/data/prompts: https://github.com/wzk1015/WorldCupArena.
## Findings (numbers and facts, not vibes)
- Table 2 (104 matches): Claude Opus 4.7 (Thinking, S1, N=95) composite 33.76, result acc 68.4%, exact 15.8%, Scoreline 63.16; Claude Thinking+Search (S2, N=58) 31.26 / 70.7% / 17.2% / 68.49; GPT-5.4 (N=102) 29.91 / 65.7% / 11.8% / 56.05; Polymarket 65.4% / 8.7%; BetVictor 68.3% / 16.3% / Scoreline 53.35; human fans 69.7% / 15.6% / 53.40.
- Best LLM beats fans by only +1.0pp result accuracy (70.7 vs 69.7), BetVictor +2.4pp, Polymarket +5.3pp; exact-score +0.9pp over BetVictor (17.2 vs 16.3) — but Scoreline +15.14 display points over BetVictor (68.49 vs 53.35): the edge is near-miss calibration, not hit rate.
- Search effect on shared matches: −0.26 (Claude), −4.26 (GPT-5.4), −1.03 (Gemini) — no reliable gain (commercial products, not architectures).
- Consensus failures: all 13 systems missed Spain–Cape Verde 0–0, Netherlands–Japan 2–2, France–England 4–6 (3rd-place).
- Stratification: heavy-favorite matches (p_max ≥ 0.65) 75.5% result acc vs balanced (≤0.50) 55.4%; low-scoring (≤1 goal) 57.7%.
- In-play: result acc 61–90 min 74.4–75.8%; after an observed goal, accuracy jumps +11.9 to +22.0pp (adaptation to observed state, not anticipation).
- Ledger caveat: model names and completed-tournament framing postdate verifiable records — treat leaderboard as reported-by-authors; value is metric/protocol design.
