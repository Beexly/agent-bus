# docs/data/CARDS_SCANNERS.md
## What it is (1-2 sentences)
An INTERNAL/CROWN-class build deck of 10 scanner cards (SC1-SC10) for market-structure scanners over the GSE line archive — ladder coherence (C3.1), boost EV (C3.5), line-archive reader, prop-quote assembly, prop dispersion, ladder divergence, softness map (E-G1) — plus three research cards resolving data gaps (alt-ladder capture, boost source clearance, latency measurement E-G2), with routing, dependency order, invariants, and per-card attack lists.
## Key metrics/methods (formulas where given, else "not specified")
- Devig entry (Shin, NOT proportional — proportional split banned for props due to favourite-longshot bias): noVigFromAmericanPrices(american) -> { fairProbabilities, insiderShareZ } | null; sub-vig/crossed markets return null.
- SC1 ladder-coherence: after devig, P(X > line) must be non-increasing in the line; flags: non_monotone (gap >= tau, default tau = 0.01), duplicate_contradiction (maxQ - minQ > dupTolerance, default 0.005). Median convention: copy, sort asc; odd n -> middle, even n -> mean of the two middles. Symmetric-price identity: over = under = -110 gives qOver = 0.5 exactly.
- SC2 boost-ev: americanToDecimal(a): a>0 -> 1 + a/100; a<0 -> 1 + 100/(-a); null unless finite and |a| >= 100. evModel = pWin*(boostedDecimal - 1) - (1 - pWin); evMarket = boostedDecimal*qReference - 1; breakEvenP = 1/boostedDecimal. All EVs per 1 unit staked.
- SC5 prop-dispersion (Kaunitz outlier generalized to props): consensus = MEDIAN of qOver (never the mean); outlier scan requires >= MIN_PROP_BOOKS = 3 clean books at modal line (captured prop width is exactly 3 books: DK/FD/MGM); tau default 0.03; modalLine = line with most books' two-way quotes, tie -> lowest; under-side consensus = 1 - medianQOver.
- SC7 softness-map: p90 by nearest rank, index ceil(0.9*m) - 1 (m=5 -> index 4); families ranked descending by medianQDispersion (nulls last), then medianLineDispersion, then outlierRate; softnessRank 1 = softest; n < minProps (default 5) -> thin list. Null dispersions are missing data, never 0.
- SC6 ladder-divergence: ranks rungs by |pOver - qOver| desc, tie -> lower line; caller's P(X > line) must be a valid survival function (tripwire: any increase > 1e-9 in line order -> refuse "bad_predictive"); invalid predictive values are skipped, never clamped.
- OddsLineSnapshot schema: phase OPEN/INTERIM/CLOSE (OPEN stamped per (gameId, market); CLOSE re-tagged at settle onto the last pre-kickoff row); capturedAt is OUR poll time at refresh-cycle granularity, NOT the book's update time; prop market encoding "<oddsApiKey>|<playerSlug>" (e.g. "player_receptions|justin_jefferson"); one-sided books stored as ONE row — never invent the missing side; prop prices are American; captured prop books are exactly draftkings/fanduel/betmgm.
- SC3 as-of discipline: reads take explicit `asOf` and exclude capturedAt > asOf (lookahead guard); tie-breaking by id; CLOSE fallback to latest pre-kickoff rows when no CLOSE rows and kickoffAt provided.
## Data sources named
The GSE's own OddsLineSnapshot archive (indexed [gameId, market, capturedAt] and [phase, capturedAt]); The Odds API (getEventOdds open market list; getEventMarkets 1-credit per event-book discovery; free tier 500 credits/month; prop ingest capped at 8 calls/sport/cycle). Gated prop ingest market lists: NFL [player_pass_tds, player_receptions], NBA [player_points].
