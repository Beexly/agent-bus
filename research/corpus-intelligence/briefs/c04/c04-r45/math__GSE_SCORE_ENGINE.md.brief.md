# docs/math/GSE_SCORE_ENGINE.md
## What it is (1-2 sentences)
The 2026-07-04 specification of the GSE Score Engine: a shadow-only decision-quality layer that outputs a 0-100 GSE Action Score (a decision-quality index, not a win probability), separating modeled probability, confidence score, feature contract, calibration contract, and no-bet strength; it is explicitly not wired into live pick generation.
## Key metrics/methods (formulas where given, else "not specified")
The final GSE Action Score is a 0-100 decision-quality index composed of five separated concepts: modeled probability (model parliament's estimate), confidence score (from model agreement, vote quality, evidence health), feature contract (required inputs/source policy/freshness survival), calibration contract (whether probability language is earned), and no-bet strength (how strongly the system should refuse action). No explicit formulas or weights are given in this file ("Outputs expose drivers, not internal protected weights"). Decision ladder: `PLAY` (shadow score clears local quality gates), `LEAN` (positive but not strong enough for a hard action recommendation), `WATCH` (needs monitoring; evidence incomplete or not yet strong), `PASS` (no-bet pressure or low score suppresses action), `HARD_PASS` (missing data, source rights, responsible-gaming, or other hard block). Guardrails: missing required data forces `HARD_PASS`; stale required data forces `HARD_PASS` (stale optional data is a warning); source-rights blocks force `HARD_PASS`; high expected value cannot override hard-pass data gaps; model disagreement reduces confidence and increases no-bet pressure; stale data increases no-bet pressure; calibration claims blocked unless calibration contract validated.
