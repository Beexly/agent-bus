## Key metrics/methods (formulas where given, else "not specified")
- **Lane state (GSE's own):** YOLOv8n detector, precision 1.00 / recall 0.74 on 57 hand-labeled people; IoU tracklet association fragments at broadcast pace (52–65 tracklets from ~6 players, median life 0.6–0.8s); DLT homography fails on yard-lines-only input (v1 fallback = ~30s hand-seed per game window).
- **Sloan 2018 (#5571):** All-22 pipeline — Hough Lines → rotation correction (arccos; paper underspecified, reconstruction marked [RECONSTRUCTED]) → LOS detection via O-line proximity → formation ID from pre-snap coords relative to QB: CART 86.5% QB position (Shotgun/Under Center/Pistol), 72.3% formation across 29 classes. Tracking at 5 fps; per-screenshot yard calibration from 5-yard line spacing; frame-1 reference-point anchoring to cancel camera-follow drift; speed = euclidean distance / frame-rate → yards → mph (26.2 mph worked example). Route case studies: Jackson 22.4 vs Harris 19.3 mph in first 0.6s; Garçon 1.3 fewer yards than Jackson on mirrored comebacks.
- **MDPI Electronics 2023, 12(3), 726:** YOLOv3 single-class detector (0.35 operating point from 0.05–0.95 sweep); ResNet-152 per-player labeling; 12→8 label grouping (exact mapping extracted); QB/OL/RB occlusion rules (**QB rule +4pp measured**: exactly one QB pre-snap); 90.3%/98.8%/99.2% module-wise, 84.8% end-to-end.
- **Chung Brown thesis (2024):** YOLOv8 visual features + yard-line detection via Hough + hash-mark detection (LoG blobs + Hough) + XGBoost on play-by-play → run/pass 74.13% test / 73.78% validation. Zero numeric parameters in thesis (no rho/theta, thresholds, sigma, HSV bounds — all deep-dive values marked [DERIVED]).
- **the-playmakers (Brown YOLOv8):** 503 claimed images (443 on Roboflow v3), 8 classes (WR/CB/Safety/LB/RB/QB/TE/FB); mAP@0.5 0.759, F1 0.62 @ conf 0.229, WR 94.2% precision.
- **Kaggle NFL impact detection (2020):** $75K, 2,849 entrants; metric F1@IoU0.35 ±4 frames; winner's recipe: 2-stage detector + oversampling (positives 0.18%) + temporal-window rescoring.
- **Harsh Raj (2026, LinkedIn):** ~30 semi-supervised Roboflow frames → RF-DETR segmentation per-frame seer → SAM 2 with adapted memory bank for pile-ups → OpenCV classical geometry camera-motion cancellation → small OCR pass on sharp crops for long-gap re-ID (jersey digits). Insight: appearance ReID dead end in identical uniforms; identity from motion continuity. Coast through occlusions: 15 frames vs GSE's current 5.
- **Roboflow home-mxzv1/nfl-competition:** 9,947 images, 193,736 helmet boxes; 33% hard labels (Blurred/Difficult/Partial/Sideline); TRAP: Helmet-Sideline (7.76%) = non-player sideline personnel — must be excluded.
- **Geeklocker Hawk-Eye accuracy ladder:** GNSS ±12", LPS/UWB ±4", CV ±0.1" @300+fps, Zebra RFID ±6"; NFL uses Sony Hawk-Eye for first-down measurement (line-to-gain only, not ball spotting); 2,700/7,680 = 0.35"/pixel.
- **Amazon Science NGS retrospective:** pose estimation 29 body parts, x/y/z at 60fps from 16 angles; hybrid RFID + optical skeleton; 75+ ML models. NFL-internal — ceiling reference.
- **AWS Digital Athlete:** 38 synchronized 5k cameras at 60fps per stadium; 6.8M frames/week.
- **AWS SageMaker blog:** YOLOv3 vs Faster-RCNN vs SSD; honest accounting — no per-architecture numbers in text, "Faster-RCNN best on small objects (the football); SSD underperforms on small objects" is qualitative. HPO: 100 jobs, Bayesian, lr 0.001–0.1, resnet50_v1b/resnet101_v1d, mAP objective.
- **Mendez homography tutorial:** NFL pitch template 120×53.3 (1px = 1 yard); OpenCV findHomography; 4-point minimum; homography.empty() colinearity guard.
- **Zacyauney Madden classifier:** Inception v3 → 4 shotgun-variant formation classes; ResNet18 per-frame + voting → play classes (Inside Zone, Y-Sail, Mesh Spot, scramble); vote formula unspecified.
- **ResearchGate tracking-data review:** Schilling et al. safe-target-area: safe passes 89% vs 59% completions; 2 of 410 INTs on safe passes; +2.02 YPA / +0.25 EPA.
