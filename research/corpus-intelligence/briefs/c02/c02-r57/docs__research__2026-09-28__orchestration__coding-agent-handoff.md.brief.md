## Key metrics/methods (formulas where given, else "not specified")
- **DFS salary import:** `GET https://api.draftkings.com/draftgroups/v1/draftgroups/{draftGroupId}/draftables?format=json` → HTTP 200, no auth, verified live 2026-09-28. Per-player fields: salary, position, rosterSlotId (66=QB, 67=RB, 68=WR, 69=TE, 70=FLEX, 71=DST; FLEX rows duplicate playerId — dedup on playerId), teamAbbreviation, names, status/newsStatus (injury flags), isDisabled, competition (game + kickoff), competitions[] (home/away), draftStatAttributes (id 90 = DK avg-points/game), playerAttributes (ByeWeek). Not from DK: projections, floor/ceiling, ownership. Repo contract `apps/web/lib/fantasy/dfs-slate.ts`: `DfsPlayer { id, name, pos, team, opp, salary, proj, floor, ceiling, own, ... }`, SALARY_CAP = 50000. Plain HTTP clients get Akamai 403; curl_cffi `chrome131` + `Origin/Referer: https://www.draftkings.com` verified working. Slate discovery: `GET https://api.draftkings.com/draftgroups/v1/` (~867KB, 126 draft groups; filter NFL / SalaryCap / Upcoming) or `GET https://www.draftkings.com/lobby/getcontests?sport=NFL` (contest `dg` field = draftGroupId).
- **CLV harness:** honesty rule in `clv-decomposition.ts` — never label residual "sharp/public money"; `sharpSplitSourced` gate. `markClosingSnapshots` = last pre-kickoff per market/book/side = CLOSE.
- **Movement spec:** reference RMSE band 0.518–0.540 yd (BDB 2026 winner takeaways); 23 entities/frame at 10 Hz; raw frames as per-play Parquet in the lake, Postgres gets derived features only; loader/physics/calibration gates (ECE < 0.15 yd, coverage ± 5 pp).
- **Rankings program:** immutable weekly snapshots `{season, week, product, generated_at, input_hashes, model_version}`; corrections as new snapshots with changelogs; confidence tiers on the 9.2 Hold floor.
- **License facts:** MIT/Apache-2.0 usable with notice; CC-BY-4.0 with attribution; LGPL unmodified-dependency only; no-license = method only; GPL-3.0/AGPL-3.0 = study only, zero code ported, clean-room (design doc first, provenance headers). No formulas beyond these gates.
