# docs/arxiv-program/research/2026-09-21/arxiv-deep/0041-a-finegrained-attention-and-geometric-correspondence.md

## What it is (1-2 sentences)
A 2025 arXiv paper (arXiv:2509.05913, Rahman et al.) proposing ViSK-GAT, a multimodal deep model fusing athlete image pixels with MediaPipe 2D skeletal keypoints to classify musculoskeletal risk into 8 REBA posture categories on a custom 8,989-sample dataset. The corpus reader's verdict is REJECT: the labels are a deterministic rule-based function of the same skeletal inputs the model receives, so the 93.89% test accuracy is inflated by label circularity and transfers nothing to real injury prediction.

## Key metrics/methods (formulas where given, else "not specified")
- Pipeline: image branch 224×224 → ResNet-inspired residual blocks → 256×128 image tokens; 33 MediaPipe keypoints → pose token embedding `E_pose = P W_e + b_e` (d=128) → Transformer block → F_pose ∈ R^{33×128}.
- FGAM: 8-head self-attention on image tokens → 2 stacked lightweight Transformer blocks → `F̂_img = LayerNorm(F3 + FFN(F3))`.
- MGCM: both modalities projected to d=256; cross-attention `F_attn = MultiHeadAttn(Q=F'_img, K=F'_pose, V=F'_pose)`; concat [F'_img ∥ F_attn] → 2 Transformer layers (4-head) → F_corr ∈ R^{512} classifier.
- Joint-angle equations: θ_ABC = cos⁻¹((BA⃗·BC⃗)/(‖BA⃗‖·‖BC⃗‖)) (cosine law); θ_trunk = tan⁻¹(|x_shoulder−x_hip|/(|y_shoulder−y_hip|+ε)).
- REBA labeling (Algorithm 2): joint angles → trunk/neck/leg (Group A), arm/wrist (Group B) region scores → REBA matrix lookup → 8 classes; load/activity modifiers fixed to zero.
- Training: 100 epochs, batch 16, AdamW (wd 1e−5), OneCycleLR (peak 3e−4, 10% warmup, div 1000), cross-entropy w/ label smoothing 0.1, grad clip 1.0; RTX 3060 12GB, CUDA 12.6, PyTorch 2.6.0, Python 3.12.9. Final-epoch train loss 0.0007, train accuracy 99.97%.

## Data sources named
- MusDis-Sports (custom, 8,989 samples): images compiled from Sports1M, "Sports Classification," "Sports Image Classification," and Cricket Shot datasets (full-body visible filtered); 33 MediaPipe 2D keypoints per subject (visibility < 0.5 discarded); labels = rule-based REBA scores from the same coordinates. Class distribution: C1 1,083; C2 1,213; C3 1,181; C4 1,332; C5 1,144; C6 1,117; C7 888; C8 1,031 (total 8,989). Access via GitHub https://github.com/mak-raiaan/MusDis-Sports_Dataset "upon valid request for research purposes only" (repo not independently verified).

- Reported metrics: validation accuracy 93.55% (abstract) but 93.66% in Table 7 (0.11pp discrepancy); test accuracy 93.89% both; test precision 93.86%, F1 93.85%, Cohen's κ 0.93, MCC 93%, RMSE of predicted probability distribution 0.1205, MAE 0.0156; val loss 0.4376, test loss 0.4808. — TRUST-SIGNAL
- Class-wise F1 (Table 2): C1 96.97%, C2 89.32%, C3 91.44%, C4 88.58%, C5 96.63%, C6 95.44%, C7 98.78%, C8 99.23%; multiclass ROC AUC ≈ 1.0 most classes (C2/C3 0.99, C4 0.98). — TRUST-SIGNAL
- Module ablation (Table 5), F1 / Δ from baseline: baseline simple-concat 0.8712; +ResBlocks 0.9028 (+0.0316); +FGAM 0.9213 (+0.0501); +MGCM 0.9385 (+0.0673); Cohen's κ 0.867→0.891→0.911→0.930. — OTHER
- Baselines (Table 7): ResNet101 test 88.39%; DenseNet121 88.06%; EfficientNet-B0 87.42%; prior REBA-based CNN (Doong et al.) 76.10%. — OTHER
- Label circularity: REBA scores are generated by a deterministic rule-based algorithm applied to the input coordinates — the model largely re-learns a known deterministic mapping from its own inputs (stated by the authors). Train accuracy 99.97% vs test 93.89% suggests heavy memorization. — TRUST-SIGNAL
- Single-frame images, no temporal dynamics; load/activity REBA modifiers zero; random 70/10/20 split, not athlete-disjoint; REBA is an occupational-ergonomics tool, its mapping to athletic injury probability asserted, not validated against injury outcomes. — TRUST-SIGNAL
- Reader observed flags: abstract/Table 7 val-accuracy discrepancy; v1 PDF read while assignment listed v3 (numbers identical in abstracts — cosmetic); "surpassing" OWAS/RULA studies (76.10–93.00%) conflates different scoring systems, tasks, datasets. — TRUST-SIGNAL
