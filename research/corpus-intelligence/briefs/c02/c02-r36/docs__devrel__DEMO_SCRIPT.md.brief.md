# docs/devrel/DEMO_SCRIPT.md

## What it is (1-2 sentences)
A ~90-second narrated demo script showing a governed agent decision flow: a real REFUSE decision on an SRQC violation producing an ed25519-signed, publicly verifiable receipt, with setup, troubleshooting, and pointer to public surfaces (`/integrity`, `docs/formal/SRQC_STATUS.md`).

## Key metrics/methods (formulas where given, else "not specified")
- not specified (no sports/calibration math). Method notes: REFUSE is generated by a gate wired to `admitUnderSRQC` fed a synthetic window containing a genuine GE2 violation (two concurrently-pending attempts on one invocation); receipts carry `argsDigest` (no raw args), ed25519 signature with `kid`; canonical signed payload is order-independent per `docs/formal/OPEN_GOVERNED_RECEIPT.md` §3; production default posture is SHADOW; ENFORCE demo requires `SRQC_ENFORCE=1`.

## Data sources named
