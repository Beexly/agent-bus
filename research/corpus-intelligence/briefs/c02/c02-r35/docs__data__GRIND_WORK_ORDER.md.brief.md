# docs/data/GRIND_WORK_ORDER.md
## What it is (1-2 sentences)
A 7-day sprint work order for "OX-BETA" (a second Hermes agent) that sequences GSE's edge-building program into four tiers: Tier 0 token substrate (cost-reduction infra), Tier 1 validation bench, Tier 2 NFL battle-order edges, Tier 3 fleet factory — all under the standing `priced:false`, fail-closed, no-scraping rules.
## Key metrics/methods (formulas where given, else "not specified")
- T1.1 `npm run edge:validate <covariate>`: walk-forward expanding-window CV by season/week — random K-fold explicitly BANNED. Scorers: log-loss + Brier for binaries, CRPS for counts/yardage, PIT histograms, calibration slope, all per prop family. Exit-code non-zero on regression.
- T1.2: simulated flat-stake CLV vs consensus close at decision time from the repo's own line archive; a covariate improving log-loss but not CLV is "describing the market, not beating it."
- T1.3 `npm run edge:mine <grid.yaml>`: pre-registered grid config (checked in; adding cells requires a new version), hierarchical partial pooling, BH-FDR across the whole grid, season sign-stability, minimum-effective-sample with design effects; emits ranked HYPOTHESIS rows.
- T0.5: provenance registry of every p-side covariate with `provenance: L0|L1|L2|L3|MARKET_GAME|MARKET_PROP` + `known_at`; guard fails the build if any `MARKET_PROP` feature reaches `p` or any feature's `known_at` is later than decision time.
- No explicit math formulas for the named Tier-2 edges in this file (formulas would live in EDGE_SUPREMACY_DOCTRINE.md §H0).
