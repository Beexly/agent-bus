# docs/data/CARDS_LAUNCH_QA.md
## What it is (1-2 sentences)
The Launch QA work-order deck (Deck LQ): 18 severity-ordered implementation cards (LQ1–LQ18) covering paywall/entitlement holes, unsupported-claims copy fixes, LLM numeric-grounding gaps, and preflight/launch-night checks — a trust gate over the site, each card a self-contained spec with a deterministic verify command and an ATTACK list for cross-verification.
## Key metrics/methods (formulas where given, else "not specified")
- Rate limits: 120 req/60s per user on premium analytics gates; 60 req/min per IP on public board routes (`board/passes`).
- Numeric-guard contract: `extractNumericClaims` pulls percent (68%), decimal (3.5), and record (12-4) shapes; `validateNumericClaims(text, {allowed, tolerance?})` with default tolerance 0.1; bare integers ignored.
- Clause-scoping constants for the numeric guard: `SAFE_WINDOW_BEFORE = 60`, `SAFE_WINDOW_AFTER = 24`, `CLAUSE_BOUNDARY = /[.!?;—]/`.
- PROVEN milestones named: verified CLV ≥ 52.4%; ≥100 canonical settled picks; ≥30 settled picks in the defined window to make any win-rate claim.
- Tier entitlements: FREE | FANTASY | PRO | ELITE; ELITE-only alerting; FANTASY/PRO/ELITE share `canUseFantasyFull`; daily free pick limit 2.
- No scoring/EV formulas specified; the deck is infra/gates/copy, not modeling.
