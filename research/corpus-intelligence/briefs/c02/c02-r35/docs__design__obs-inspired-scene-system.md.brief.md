# docs/design/obs-inspired-scene-system.md
## What it is (1-2 sentences)
Doctrine-only reference architecture (Status: Doctrine only — no implementation) translating OBS Studio's scene/source/filter/transition model into the rules for Sports OS's future Media Studio: five named production scenes, source rules, three mandatory logical filters, transition rules, and approval gates for all intelligence-brief and social media output.
## Key metrics/methods (formulas where given, else "not specified")
- Scene transitions: duration 300–600ms (matches the DESIGN.md motion standard); style = fade or horizontal slide only; no transition may be misread as a pick-result celebration.
- Win-rate claim rule: win-rate claims forbidden unless ≥30 settled picks in the defined window are available; investor demos must also name the defined model version and defined window; no fabricated performance statistics.
- Freshness filter: stale data must be labeled or removed; any live/near-live data (odds, injury status, pick status) must show a last-updated timestamp.
- No formulas specified.
## Data sources named
The Odds API (live odds context for the market-gravity scene; must be attributed in scene metadata and in any published clip using it); Pick card panel (top 3 active picks, tier-gated); the Signal Ledger (WITHHELD/UNRESOLVED statuses); the cockpit evidence drawer (INTERNAL — not for public distribution); the Source Acquisition Mesh (only T1/T2/T3 data may appear in media output; T5/T6 never).
## Findings (numbers and facts, not vibes)
- Five canonical scenes: (1) Daily Intelligence Brief — pick card panel, market gravity meter, source freshness indicator, brand monogram lower right, "Entertainment purposes only" disclosure lower left always visible; (2) Pick Provenance Walkthrough — screen-recording of evidence-chain construction with source tier badges, requires blur/redact of API keys, internal source reliability scores, and user account data; (3) Market Gravity Explainer — may describe what line movement is but may NOT claim line movement alone constitutes a "sharp money" signal; (4) Galaxy Studio Social Clip — 30–90 seconds, pick card graphic + ambient motion background (design token colors only, no casino imagery), text overlay with pick direction + sport + "For entertainment only", no auto-upload; (5) Investor Demo.
