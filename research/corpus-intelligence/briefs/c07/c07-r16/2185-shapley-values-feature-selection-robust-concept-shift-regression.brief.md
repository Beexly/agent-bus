# arxiv-program/research/2026-09-21/arxiv-deep/2185-shapley-values-feature-selection-robust-concept-shift-regression.md

## What it is (1-2 sentences)
Full-paper read (ar5iv HTML) of "A Feature Selection Method Based on Shapley Values Robust to Concept Shift in Regression" (arXiv:2304.14774v3, Sebastián & González-Guillén, 2023): "SHAPEffects," a backward feature-selection method that relates *local* SHAP values to *validation-set* prediction errors, eliminating variables whose learned effect pushes predictions in the wrong direction under concept shift — where a historically influential variable can actively hurt current predictions. Ledger verdict ADAPT — as GSE's feature-pruning layer for regime changes (new OC, QB turnover, rule changes), where standard importance-based selection keeps stale-but-influential features.

## Key metrics/methods (formulas where given, else "not specified")
- Shapley value: φ_i = Σ_{S⊆N\{i}} |S|!(|N|−|S|−1)!/|N|! · (v(S∪{i}) − v(S)); permutation form φ_i = 1/|Π(N)| Σ_{π∈Π(N)} (v(P_i^π ∪ {i}) − v(P_i^π)).
- Per-observation effect: Effect_{var,x} = sgn(SHAP_var) · SHAP_var² (squaring amplifies the most influential); group effect Ef_{var,group} = Σ_{x∈group} Effect_{var,x}.
- Error grouping (Definition 1): classify validation observations by err(x,y) = y − ŷ(x) into Correctly Predicted / Over-Predicted / Under-Predicted using error quantiles Q_low = Quantile(err, q_low), Q_high = Quantile(err, q_high), with bias-translation (Q*_low, Q*_high) when 0 ∉ [Q_low, Q_high] so model bias lands in the wrongly-predicted space.
- Negative influence (Definition 2, 5 cases): infinite if the variable has zero effect anywhere (pure noise/overfit candidate — all such dropped at once); otherwise computed from how group effects align with the model's current bias direction (median error q₂(err)) — e.g., if the model over-predicts (q₂(err)<0) and the variable increases over-predictions while reducing under-predictions, negative influence = |Ef_O.P| − |Ef_U.P| (undesirable minus desirable); a variable worsening both tails gets |Ef_U.P|+|Ef_O.P|. Drop the variable with the largest non-zero negative influence; iterate until none remain; return the feature set with the best validation metric. Optional preprocessing: Boruta-style noise prefilter (add permuted copy of most influential variable, drop variables with mean influence ≤ random's over n_iter_prev seed repeats).
- Assumptions: TreeSHAP faithfully attributes per-observation effects; validation-set error stratification reflects the current regime; a feature whose effect consistently opposes the correction direction is shifted, not merely noisy; the method does NOT detect shift explicitly — it only eliminates variables with negative local influence; regression only (classification extension is future work); O(2^|N|) exact Shapley infeasible — approximations used.

## Data sources named
Synthetic (sudden + incremental shift): f(x_t) = 2x_{1,t} + λ₁x²_{2,t} + 3sin(2πx_{3,t}) − 0.4x_{4,t} + λ₂x²_{5,t} + (same 5 terms at t−1) + ε_t, ε~N(0,0.01); x_i ~ U(0,1), i=1..10 (only first 5 informative) + lag of target; λ₁: {−10,−1,−0.1}→{−4,−0.4,−0.04}, λ₂: {10,1,0.1}→{−25,−2.5,−0.25}; all 81 combinations; sudden shift at sample 20001, incremental linearly over 20001–25000; train 1–20000 / validation 20001–25000 / test 25001–30000. Real case 1 — Spanish day-ahead electricity price (335 explanatory variables, ESIOS portal + MIBGAS gas price; shift = 2022-06-15 Iberian gas-price cap decree). Real case 2 — Sberbank Russian Housing market. Static benchmarks: CAT Scan Localization (UCI, 384 features), Appliances Energy Prediction (UCI, 28 variables + 2 random), Max Planck Weather (12 atmospheric vars, lags 1 day–1 week → 80 variables, wind-speed target). Baselines: Powershap, Boruta-Shap, Shapicant, Boruta, PIMP, best-Lasso. Code: https://github.com/CCaribe9/SHAPEffects.

## Findings (numbers and facts, not vibes)
- 81 synthetic scenarios: MAE-difference histograms (SHAPEffects minus competitor) predominantly negative (SHAPEffects better); positive differences "practically negligible", only when shifted variables' coefficients were near-insignificant. Sudden vs incremental shift results nearly identical.
- Real shift case 1 (test set): SHAPEffects(0.1–0.9) MAE **12.61**, RMSE 15.60, R² −0.99 vs Boruta 13.41/17.14/−1.40, PIMP 13.39/17.11/−1.39, Best Lasso(0.001) 13.41/17.14/−1.40, Shapicant 19.27/22.30/−3.07 — ~6% MAE improvement over the best SOTA selector.
- Real shift case 2 (test set): SHAPEffects(0.2–0.8) MAE 12.97, RMSE 15.98, R² −1.09 vs Boruta-Shap 13.71/17.52/−1.51, PIMP 13.65/17.44/−1.49.
- Static scenarios: SHAPEffects comparable to SOTA (CAT Scan, Appliances, Max Planck tables) — also eliminates overfitting variables creating "forced relationships" in training.
- Quantile parameters matter: (0.25–0.75) vs (0.1–0.9) give different elimination paths; (0.1–0.9) best in real case 1 (authors' stated future work: automatic quantile selection).
- Note: R² negative in real cases — all methods struggle post-shift in absolute terms; the claim is relative superiority.
- Limitations from the ledger: shift begins *inside the validation set* — needs post-shift validation data (validating on a stale season detects nothing); backward elimination with TreeSHAP refits per iteration is expensive at GSE feature counts; TreeSHAP can assign non-zero values to irrelevant-but-correlated features (Sundararajan & Najmi / Janzing critique — may kill correlated-but-useful features); regression-only — cover/no-cover classification needs the unbuilt extension; synthetic shifts change only coefficients, while real NFL shift changes feature *semantics* (new scheme), a harder case.

## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- COACHING: NFL is a shift-rich domain — OC/DC turnover (~25%/yr), QB changes, rule changes (kickoff 2024) — and global-importance selection keeps features whose learned effects have inverted under a new regime; the ledger's concrete failure mode: "pressure rate" strongly predictive 2019–2022 may invert after a scheme change, and SHAPEffects' local error analysis drops it exactly when its effect starts pushing predictions the wrong way.
- TRUST-SIGNAL: eliminated features are flagged with their negative-influence magnitude as a "regime-casualty report" — an interpretable story for the DFS packet / edge notes ("YPRR dropped after scheme change").
- OTHER (feature pruning): complements any selector; the improvement experiment extends it to classification via the same local logic on log-loss residuals, unlocking the cover/no-cover target the authors left as future work.
