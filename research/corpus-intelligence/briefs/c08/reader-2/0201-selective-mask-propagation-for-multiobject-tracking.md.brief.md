# docs/arxiv-program/research/2026-09-21/arxiv-deep/0201-selective-mask-propagation-for-multiobject-tracking.md
## What it is (1-2 sentences)
Ledger read of arXiv:2606.13033v3 (Alexander Holmberg, 2026): a training-free multi-object tracking method (SAM-Deep-EIoU) that runs a lightweight base tracker on every frame and dispatches an expensive video-object-segmentation model (SAM 3) only to temporal windows where the Hungarian assignment margin signals ambiguity, with an asymmetric gated-correction rule plus jersey-OCR global track association. **Verdict in file: ADAPT** — the dispatch + identity logic is the right architecture pattern for a GSE video→tracks lane; adopt the design, not the weights/thresholds.
## Key metrics/methods (formulas where given, else "not specified")
- Assignment margin (dispatch): m_j* = min_{i≠i*} C_{i,j*} − C_{i*,j*} (second-best minus best assignment cost; window opens when m_j* < τ_entry). τ_entry = 0.05 used throughout (ablated at 0.01/0.025). Other thresholds (τ_seed, τ_IoMA, τ_exit, N_seed, N_exit, G) named but not valued — "Not stated in paper."
- Mask containment: IoMA(M,B) = |M ∩ B| / |M| (Eq. 2). Exit requires IoMA ≥ τ_IoMA, margin recovered > τ_exit, spatial isolation, for N_exit consecutive frames.
- Asymmetric decision rule: SWAP (mask settled into different track → rename IDs from swap frame) vs CLEAN/STALE/DEGRADED/EDGE/END (base output untouched). Paper's guarantee: the only way to harm the base tracker is a false-positive SWAP.
- Global track association (GTA): jersey-number OCR on pose-guided torso crops (Koshkina & Elder 2024) + team classification + appearance embeddings; hierarchical merge (same number+team first, then appearance with vetoes: temporal overlap, opposite-edge transitions, conflicting identities); gaps via linear box interpolation.
## Data sources named
SportsMOT (Cui et al., ICCV 2023; basketball, football/soccer, volleyball scenes — test set); DanceTrack (Sun et al., 2022; 25-sequence validation set) with fixed YOLOX detections across three base trackers. Public benchmarks; exact counts/splits not recoverable.
## Findings (numbers and facts, else not vibes)
- DanceTrack val, no per-tracker tuning: SORT HOTA 39.8→46.1 (+6.2), AssA 23.8→31.1 (+7.3); ByteTrack 54.6→61.2 (+6.6), AssA 39.0→48.2 (+9.2); Deep-EIoU 51.7→59.7 (+8.0), AssA 36.7→47.7 (+11.0). Gains largest on association metrics. SAM 3 beats SAM 2 on every base tracker (modular swap claim).
- τ_entry ablation (RTX 5090): 0.01 → ΔHOTA +6.0 (1,009 windows, 119 SWAPs, 0.154 SAM s/frame); 0.025 → +8.0 (1,203 windows, 138 SWAPs, 0.165); 0.05 → +8.2 (1,375 windows, 142 SWAPs, 0.171).
- SportsMOT test, SAM 3-Deep-EIoU: HOTA 87.2 / AssA 84.2 / IDF1 93.6 / MOTA 98.1 — claimed SOTA on all four (v1 claimed 86.8; NOOUGAT 85.6/83.0/92.3/95.9).
- Per-sport (SportsMOT val, deltas over Deep-EIoU+GTA): basketball HOTA +5.5, football +2.0, volleyball +3.7 — basketball benefits most; football (soccer) improves least.
- ~93% of windows on SportsMOT and ~75% on DanceTrack leave base output unchanged (CLEAN/STALE/EDGE/END/DEGRADED).
- Limitations noted: SportsMOT "football" is soccer, not American football; six hyperparameters, only τ_entry ablated; SAM seconds/frame ~0.15–0.17 (batch, not real-time); false-positive SWAP rate unquantified; SAM 3 training corpus undisclosed (possible pretraining leakage on sports footage).
