# docs/arxiv-program/research/2026-09-21/arxiv-deep/0351-from-sharp-to-blur-unsupervised-domain.md
## What it is (1-2 sentences)
Corpus deep read of arXiv:2507.22438v1 (Kim et al. 2025): unsupervised domain adaptation of a 2D multi-human pose estimator from sharp to motion-blurred images, bridged by event cameras (motion-aware blur augmentation + multi-modal student–teacher with mutual uncertainty masking). Ledger verdict: REJECT — the entire method requires event-camera hardware co-located with RGB cameras; GSE has no such data source and no pose-estimation program.
## Key metrics/methods (formulas where given, else "not specified")
Backbone: DEKR (center heatmap H_C, offset maps O, keypoint heatmaps H_k); supervised loss L_g = L_H + λ_g·L_O, λ_g=0.03. Motion-aware blur synthesis: events sliced into 2N_E (N_E=5) segments, self-supervised event optical flow, forward-warp sharp image to 2N_E+1 warped images, hole-aware averaging B̃^src(x,y)=Σ_t W_tδ_t/(Σδ_t+ε); blur-translation loss closes discrete-vs-continuous gap. Four stages: (1) multi-modal teacher trained on synthetic blur only; (2) student on source labels + confidence-thresholded teacher pseudo-labels (th=0.1); (3–4) mutual uncertainty masking — networks cross-score poses C(P_i)=H_c^T(p_c^i)·Σ_kH_k^T(p_k^i)/K, regions kept only if min(C,C′)≥th′ (=0.1) for both networks, alternating adaptation. Training: 512×512 inputs, LR 1e-3, 100 epochs, batch 5, 2× TITAN RTX, 8/12/12/12 h per stage. Metrics: COCO-style mAP@0.5:0.95 / mAR@0.5:0.95 on sharp and blur domains.
## Data sources named
EHPT-XC (Cho et al. 2025): 158 sequences from a triplet camera system (pixel-aligned synchronized event streams + sharp + blurry images); 38K 2D keypoints, 14 per person, plus bboxes and track IDs; train-source 47 sequences×100 sharp image–event pairs, train-target blurry unlabeled, test 26 sequences. Not released by this paper. Code: https://github.com/kmax2001/EvSharp2Blur.
## Findings (numbers and facts, not vibes)
Test mAP/mAR (sharp/blur/avg): Ours student 64.2/68.1 sharp, 51.6/57.5 blur, 57.9/62.8 avg; Ours-Teacher blur 52.9/58.2; Oracle Base(I+E) (target labels) 74.5/77.9 sharp, 58.8/65.1 blur ("comparable to oracle" overstated — 7.2 mAP gap on blur, ~12% relative); Base(I+E) source-only blur 37.5/40.5 → ours gains +14.1 mAP; UDA-HE(I+E) blur 36.4/40.6; DualTeacher(I+E) blur 34.6/37.5. Ablations (blur): Base 37.5 → +MBA augmentation 40.4 → +Stage 2 49.1 (+8.7 mAP, the biggest jump — pseudo-labeling, not augmentation) → +Stages 3&4 50.4 → full 51.6. Motion augmentation alone adds only +0.2 mAP (+0.4 with blur-translation). Image-only distilled student (no events at test): blur 46.0 vs Base(I) 28.6 — but still requires events at training. Single-dataset evaluation; pseudo-label thresholds ablated on the test distribution; no cross-dataset validation.
