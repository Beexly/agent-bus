# docs/arxiv-program/research/2026-09-21/arxiv-deep/0361-egocentric-eventbased-vision-for-ping-pong.md
## What it is (1-2 sentences)
Corpus deep read of arXiv:2506.07860 (Alberico et al. 2025): real-time ping-pong ball trajectory prediction from an egocentric (player-worn) event camera via gaze-foveated ROI processing, IMU motion-compensated moving-object detection, circle-fit depth, and a physics-drag + EKF trajectory estimator. Ledger verdict: ADAPT — the gaze-foveated ROI + physics-model trajectory pipeline is portable to NFL ball-flight tracking if the event camera and circle fitting are replaced with RGB ellipse fitting for a football.
## Key metrics/methods (formulas where given, else "not specified")
(1) Detection: events restricted to w×w window (w=80) around eye-gaze reprojection, Δt=5 ms; IMU-gyro motion compensation x_i^mc=K[I−[ω̄]_×(t_i−t_0)]K^−1 x_i; normalized-timestamp binary map B(x)=1 iff ρ(x)>θ_0+θ_1‖ω̄‖; DBSCAN on (t,x,y); circularity γ_j=P(conv(S_j))²/(4π·A(conv(S_j))). (2) Depth: 3-point max-distance convex-hull circle fit per temporal batch; Ẑ_m,ball=f·W_metric/r̂_m,ball, W_metric=0.02 m. (3) Trajectory: monotonically-constrained polynomial regression (Ż(t)≤0); physics DEs p(t_i)=p(t_{i−1})+vΔt, v(t_i)=v(t_{i−1})−k_d|v|vΔt+gΔt; EKF bootstrap x^ekf=[p,v,a]^T, constant-acceleration model. Supplement: full aerodynamics derivation ΣF=mg−½C_dρA|v|v (C_d=0.4, ρ=1.225, r=0.02 m, m=0.0027 kg), Magnus extension F_m=C_mρAr(ω×v) with k_m=C_mρAr/m, inelastic bounce v_z^+=e·v_z^−, sensing-latency model τ_E=(1/v̂)·(Δu·d²)/(f·r_o+Δu·d), audio impact-trigger via high-pass Butterworth + scipy find_peaks at >¼ signal magnitude. Metrics: detection success (2D error <5 px vs OptiTrack @200 Hz), impact-point RMSE (m), pipeline latency.
## Data sources named
Self-collected: 30 table-tennis sequences, 5 participants; Meta Project Aria glasses (RGB 1408×1408@30 FPS, eye tracking @60 FPS, 7-mic audio @48 kHz, SLAM @30 FPS, IMUs @1 kHz/800 Hz) + iniVation DVXplorer event camera (640×480, 6 mm lens) + OptiTrack motion capture (ball 3D @200 Hz, glasses 6D pose) as ground truth. Dataset release not stated; code: https://github.com/uzh-rpg/event_based_ping_pong_ball_trajectory_prediction.
## Findings (numbers and facts, not vibes)
Latency (Intel i7-13700H, w=80): mean pipeline 2.35 ms (ego-motion 1.390 ms/59.1%, threshold+morphology 0.083 ms/3.5%, DBSCAN+filtering 0.879 ms/37.4%); worst case 4.5 ms vs 66 ms perception-only for 30 FPS camera. Gaze-ROI cropping: 1.5 ms, 735 events vs 16.18 ms, 7,157 events without — 10.81× event reduction. Detection: θ_1=0.8 → 92.59% (best); with ROI 92.59% vs 81.48% without (cropping removes false circular distractors). Trajectory, 0.2 s horizon, impact-point RMSE: DCGN 0.1072±0.1085 m (best); Diff Eq @200 Hz 0.1472±0.0938; Diff Eq EKF 0.1432±0.0991; Diff Eq @30 Hz 0.1915±0.1705; oracle 0.0121±0.0075. 200 Hz event updates cut error by 4.8 cm (physics) / 8.4 cm (DCGN) vs frame-based. Single-batch 33 ms window: Diff Eq @200 Hz 0.242±0.096 m vs @30 Hz 0.409±0.504 m; 10–20 ms windows weak (0.784 m RMSE at 10 ms). DCGN horizon analysis: longer horizons lower RMSE (0.30 s: 0.1177 vs 0.01 s: 0.2616) — short lookaheads underperform. Circle fitting beats ellipse/PCA and Taubin on event clusters (1-px radius error at 3 m = cm-scale depth error). θ_1 sweep and all numbers from the same 30 sequences (small-sample parameter-overfit risk); sequences manually cut at opponent impact (no auto trigger deployed).

- OTHER: foveated ROI lesson (10.81× compute reduction) ports as saliency-ROI processing in any future GSE video pipeline (full-res only inside tracked region — ball carrier, QB).
- SCHEME: spin-aware flight modeling (ellipse rotation across frames → spin axis) tested on punts vs kickoffs; the paper's drag-only model ignores spin.
- TRUST-SIGNAL: horizon caution from the DCGN analysis — short lookaheads underperform; any GSE flight-model horizon choice must be validated, not assumed.
- OTHER: paper's ellipse-fitting finding is inverted for football — their convex-hull 3-point circle fit is the reliable one for spheres, but a football demands ellipse fitting; don't copy the circle fit verbatim.
