# docs/arxiv-program/research/2026-09-21/arxiv-deep/0341-3dpcnet-pose-canonicalization-for-robust-viewpointinvariant.md
## What it is (1-2 sentences)
Corpus deep read of arXiv:2509.23455v1 (Ekanayake et al. 2026): 3DPCNet, an estimator-agnostic, pose-only canonicalization network that predicts a per-frame global rotation mapping any monocular 17-joint 3D pose into a canonical reference frame. Ledger verdict: ADAPT — adopt the canonicalization layer as preprocessing for multi-camera NFL pose work, but drop/constrain the non-rigid residual Δ so downstream measurements stay honest.
## Key metrics/methods (formulas where given, else "not specified")
Hybrid adaptive-GCN (3-layer, hidden 256, A=σ(α)A_0+(1−σ(α))A_learned) + 2-layer Transformer (8 heads, dim 384) with cross-attention and learned gating. Predicts continuous 6D rotation → SO(3) via Gram–Schmidt, plus optional 17×3 residual Δ: X̂_c = R̂ᵀX + Δ. Training: 80 epochs, AdamW, lr 5e-4, batch 1024; loss = pose MSE (wp=1) + geodesic rotation error arccos((tr(R̂R_GTᵀ)−1)/2) (wr=1) + cycle consistency (wc=0.25) + bone/joint perceptual terms (wperc=0.15) + regularization. Per-frame, no temporal modeling. Assumptions: viewpoint variation = rigid global rotation (+ small residual); ground-truth canonical frames available at training via synthetic-rotation protocol; upstream pose estimator "good enough."
## Data sources named
MM-Fi (train/eval): 40 subjects, 27 activities, 4 environments, synthetic yaw/pitch/roll rotations, official S1/S2/S3 splits. TotalCapture (qualitative only): ~1.9M frames, 5 subjects, 8 RGB views, Vicon GT + 13 IMUs. Both public. Code: https://github.com/tharindu326/3DPCNet.
## Findings (numbers and facts, not vibes)
MM-Fi S2 split — geometric baseline: 62.85 MPJPE / 0 PA-MPJPE / 20.64° rotation error; 3DPCNet (S2-trained): 47.57 / 37.49 / 3.58°; 3DPCNet (S3-trained): 46.24 / 36.94 / 3.43°. S3 split — geometric: 64.58 / 0 / 21.56°; 3DPCNet (S2): 48.83 / 38.22 / 4.29°; (S3): 47.71 / 37.61 / 4.24°. So ~24–28% MPJPE reduction vs geometric baseline, rotation error ~21° → ~3.5–4.3°, cross-environment transfer holds. No quantitative TotalCapture numbers. The residual Δ breaks strict rigidity — the network can silently "edit" joint positions, corrupting limb lengths/joint angles. No scale recovery, no temporal consistency (per-frame), no evaluation on noisy estimator outputs; viewpoint variation is synthetic, not real multi-camera geometry.
