## What it is (1-2 sentences)
CDSeer (Pham et al., arXiv 2410.09190): a model- and distribution-agnostic concept-drift detector — a lightweight "inspector model" (random forest) runs beside the deployed model emitting pseudo-labels; a standard supervised CDD (Page–Hinkley/DDM) monitors the disagreement-rate stream — achieving supervised-grade drift detection with 0.6–0.8% labels. GSE verdict: ADAPT (adopt the inspector protocol; reject the labeling machinery — NFL labels are free).
## Key metrics/methods (formulas where given, else "not specified")
error_i = 0 if ŷ = ŷ_{insp,i} else 1 (Eq. 1). Clustering: DBSCAN(W, ε, w/100) with ε from knee detection, falling back to KMeans(W, w/100) (Eqs. 2–3); ≤1% stratified labeling into fixed-size queue memory M (default 15, FIFO); sklearn LabelSpreading propagates labels across window W; inspector retrained on labeled window. Defaults: window 1,000, memory 15 (20 in RQ3). Metrics: MAcc, Precision = TP/detected, Recall = TP/GT drifts, Lbl = % labeled. Evaluated on ROUTER (46,694×32 telecom, 2 drifts), Sine/SEA (16,000×2, 2 drifts), ELEC (45,312×9, 22 drifts), NOAA (18,159×8, 3 drifts), GCT (263,509×19, 28 drifts), FM fashion-MNIST, LMR sentiment; 5 seeds; GT-free drifts labeled by supervised PHT on the non-retrained model.
## Data sources named
Public: ELEC, NOAA, GCT (Google cluster job failure), FM (Fashion-MNIST), LMR (text sentiment), Sine/SEA synthetic; proprietary ROUTER telecom. Baseline: ECHO (official Java impl, github.com/ahhaque/ECHO).
## Findings (numbers and facts, not vibes)
CDSeer (MAcc/Precision/Recall/Lbl%): ROUTER 96.76/71.4/100.0/0.6 vs PHT 97.88/100/50/100 vs ECHO 94.60/14.3/100/48.1; SEA 95.55/61.5/80.0/0.6; Sine 75.97/48.1/80.0/0.6; ELEC 77.30/30.4/72.7/0.6; NOAA 77.51/15.0/80.0/0.6; GCT 97.33/17.6/35.7/0.8. Improves online-model accuracy on 5/6 datasets vs no-CDD; beats ECHO on precision AND recall; beats supervised PHT on recall, trails on precision; 0.6–0.8% labels vs ECHO's 48–100%. Labeling requests on ROUTER: ECHO 22,459 vs CDSeer 80. Industrial deployment: 57.1% precision improvement with 99% fewer labels vs SOTA. RQ3 model-agnostic: FM net 62.5% precision/100% recall/0.99% labels; LMR net 80%/80%/0.98%. Weak spots: precision 15–48% on ELEC/NOAA/GCT (alarms are review flags, not auto-retrain triggers); GCT recall only 35.7%; circular reference standard where GT drifts unavailable; label frugality nearly irrelevant for NFL (game outcomes are free).
