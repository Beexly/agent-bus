# arxiv-program/research/2026-09-21/arxiv-deep/2109-attention-driven-multimodal-alignment-for-long-term-action-quality-assessment.md
## What it is (1-2 sentences)
A ledger (read 2026-09-22) on Wang, Li, Shen 2025 "Attention-Driven Multimodal Alignment for Long-term Action Quality Assessment" (arXiv:2507.21945, Applied Soft Computing): LMAC-Net — learnable temporal queries per modality (RGB/flow/audio) + an attention-center consistency loss forcing modalities to agree on which temporal segments matter + two-level scoring (segment scores → softmax-weighted overall). Ledger verdict: ADAPT — the transferable machinery is cross-modal temporal alignment over long sequences and interpretable segment-level scoring ("which plays decided it").
## Key metrics/methods (formulas where given, else "not specified")
Per layer: q̂_k^{(m,i)} = p_k^{(m,i−1)} + q_k^{(m,i)} (Eq. 4); cross-attention α_{k,t} = exp(q̃_kᵀv_t/τ)/Σ_j exp(q̃_kᵀv_j/τ), τ init 0.07 (Eq. 6); p_k^{(m,i)} = Σ_j a_{k,j} v_j + p_k^{(m,i−1)} (Eq. 7); final Ŝ = Σ_k w̃_k ŝ_k, w̃ = softmax(w) (Eqs. 9–10); loss L = λ_1 L_score + λ_2 L_feature, L_feature = L_rank + L_sparsity + L_consistency; attention center ᾱ_k^m = Σ_t t·α_{k,t}^m (Eq. 14); L_sparsity = Σ|t − ᾱ_k^m|·α_{k,t}^m (Eq. 16); L_consistency = Σ_t Σ_{i<j} ‖ᾱ_t^{m_i} − ᾱ_t^{m_j}‖² (Eq. 17); Spearman ρ Fisher-z averaged (Eq. 18). Config: K=5 queries, 2 stacked decoders, 8 heads, 2 layers, dim 512, dropout 0.1/0.2, AdamW lr 9e-4/9e-5, cosine decay, batch 32.
## Data sources named
RG (rhythmic gymnastics): 1,000 videos (250 each ball/clubs/hoop/ribbon), ~1m35s @ 25 fps, 200 train / 50 test per type, labels = difficulty/execution/final scores. Fis-V (figure skating): 500 short-program videos ~2m50s @ 25 fps, 400 train / 100 test, labels = TES and PCS from nine international judges. Features from prior multimodal AQA work; labels normalized to [0,1]. No repo URL found in extracted text.
## Findings (numbers and facts, not vibes)
- RG avg Spearman: LMAC-Net 0.840 vs PAMFN 0.819 vs GDLT 0.765; Fis-V avg 0.850 (TES 0.811, PCS 0.881) vs PAMFN 0.822 vs GDLT 0.820.
- Efficiency: 0.419G FLOPs, 8.95M params, 4 ms inference — vs PAMFN 18.06M params / 33 ms.
- Ablation (RG/Fis-V avg): concat baseline 0.676/0.731 → +MLQE 0.730/0.765 → +L_rank 0.731/0.779 → +L_sparsity 0.735/0.779 → +L_consistency 0.797/0.808 — consistency loss the single biggest contributor (note: ablation-run numbers differ from headline 0.840/0.850, config unexplained).
## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- SCHEME: drive-level assessment — treat a DRIVE as the long sequence (segments = plays; modalities = tracking, broadcast video, crowd audio, pbp text), learnable queries attend over the play sequence, two-level scoring yields publishable "the 3 plays that decided the drive" readouts (film-room content).
- COACHING: per-play attention weights w̃_k give an interpretable coaching/game-script readout of which plays decided each drive.
- TRUST-SIGNAL: paper's weak point — exact consistency forces modalities to attend to identical segments, which destroys genuine cross-modal lead-lag (crowd roar anticipates the play; cadence precedes the snap). Must use an asymmetric or lag-tolerant consistency loss (learned per-pair offset δ_ij with L1 penalty), not the paper's exact-center matching.
