# arxiv-program/research/2026-09-21/arxiv-deep/2171-discover-physics-informed-gpu-accelerated-symbolic-regression-framework.md
## What it is (1-2 sentences)
A ledger (read 2026-09-22) on DISCOVER (Gajera et al., arXiv:2602.06986): a Python-native GPU-accelerated symbolic regression framework whose differentiators are hard dimensional-consistency enforcement via the `pint` unit library during feature generation (invalid expressions pruned before evaluation) and interchangeable exact/heuristic sparse solvers (OMP, MIQP, simulated annealing) for the L₀ descriptor problem. Ledger verdict: ADAPT the unit-tracking idea as a hard-constraint complement to the soft LLM-judge guard in ledger 2168.
## Key metrics/methods (formulas where given, else "not specified")
Core objective: min_β ‖y − Φβ‖²₂ subject to ‖β‖₀ ≤ D (Eq. 1, NP-hard L₀-regularized least squares). Candidate features generated from user features + operator library, then sparse selection via OMP / MIQP / simulated annealing / heuristics. Physics constraints via config file: operator restrictions, complexity caps, variable-combination rules; dimensional consistency enforced with `pint` — units tracked through every symbolic operation, invalid candidates excluded during generation. GPU: CUDA (NVIDIA) and MPS (Apple Silicon), CPU fallback.
## Data sources named
Software paper; no new datasets. Motivating use cases cited: crystal structure stability descriptors, ion mobility in battery materials, magnetic-structure discrimination (materials-science tabular data from the authors' prior papers). SISSO (Ouyang et al. 2018) as deterministic baseline; SISSO++ as large-scale alternative. No benchmark experiments in the paper (benchmarking listed as ongoing development).
## Findings (numbers and facts, not vibes)
No numerical results — software announcement; all performance claims aspirational (ledger's adversarial note). SISSO-style linear-in-features assumption is narrower than full SR (no nested compositions like sin(x²+e^x) unless pre-generated). GSE currently has no GPU SR bottleneck, so the acceleration angle is irrelevant to current needs.
## Intelligence connections (tag each: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- TRUST-SIGNAL: a unit registry is the cheapest hard guard for SR feature generation — annotate each sports feature with a unit class ({probability [0,1], points, epa, rate, count, yards, time, dimensionless}) and forbid unit-violating operations at generation time (e.g., points × probability forbidden; probabilities only via sigmoid/logit composition; epa/play × plays → epa ok). Prevents nonsense like "win_probability + temperature²" ever entering the search. Warning from the paper itself: over-restrictive constraints exclude valid expressions — the gate must include a recall check that no historically successful feature is pruned.
- OTHER: model discovery — add MIQP as an exact sparse selector for the linear-in-features discovery path (team descriptors, ≤ 20 features) alongside the evolutionary search; complements ledgers 2166–2170 (MDL, LLM judge, NED, Taylor priors) with the first hard constraint.
