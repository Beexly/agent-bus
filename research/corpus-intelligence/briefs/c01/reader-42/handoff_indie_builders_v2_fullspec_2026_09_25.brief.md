## Key metrics/methods (formulas where given, else "not specified")
- BUILD 1 (TreMatt03, MIT — code liftable with attribution): per-QB rolling EPA/dropback keyed by passer_player_id (follows trades), 16-game rolling window crossing seasons; availability weight = prior-games snap share with anti-leakage rule (weeks strictly before current; repo test `test_snap_share_excludes_the_current_week` to replicate). Findings: team efficiency stats add nothing over Elo (0.632 vs 0.632); individual QB rating = single largest gain: log loss 0.633→0.625, AUC 0.690→0.700; walk-forward 3,816 games 2012-2025: 65.2% acc, Brier 0.216. Repo: github.com/TreMatt03/nfl-game-predictor.
- BUILD 2 (howlscastle97, learn-only): joint Kalman filter over 32 team strengths + home field, hyperparameters by one-step predictive log-likelihood on seasons ≤2023; leakage-safe chronological features (EWMA point differential, EPA aggregates, QB familiarity = share of last 16 starts by listed starter, rest, division, indoor); 5 heteroscedastic MLP deep ensemble on beta-NLL (beta=0.5), variance recalibration scale 1.039 (fit GSE's own constant); weekly-refit walk-forward from 2021; "square-3 rule": big model-market disagreements flagged `missingNewsSuspected: true`, not edges.
- BUILD 3 (seidcubro/PriorLine, learn-only): per-market bakeoff {ridge, elastic-net, HGB, Poisson, RF} — ridge wins rush attempts, elastic net rush yards/receptions, HGB passing, Poisson pass TDs, RF TD classifiers; quantile models q10-q90, P(over) from quantile curve not point estimate; 20,000 sims/matchup with Dirichlet touch-shares, all markets read off same simulated outcomes; over-shade correction (books shade toward overs; quantile medians beat means); blind 2025 backtest −4.3% ROI → top tier +4.1% over 3,952 graded picks; "every bucket was 14 to 29 points overconfident" before recalibration.
- BUILD 4 (Sujar Henry, methodology only): ensemble voter (LogReg + trees + XGBoost + RF voting); 20+ features; nflverse back to 2003, 6,234 games, holdout 2021-2025; self-reported 88%/68% weeks, "55-65% typical"; confidence tiers by ensemble agreement AND |p−0.5| distance (mirrors R2's 9-1 on 60%+ picks).
- BUILD 5 (Damepivot, learn-only): team ratings = EPA/play split pass/rush × off/def + success + explosive rate, schedule-adjusted via ridge regression over one-hot team indicators (penalty shrinks thinly-sampled teams to league avg); prior-season blend w(week) = n/(n+6), n = games played; QB inputs: rolling EPA/dropback + CPOE, 16-game window; situation features (rest, division, indoor/outdoor, surface, timezone, kickoff hour, week); held-out 2023-2025 (816 games): margin MAE 10.077 vs Elo 10.253, Brier 0.2182, calibration slope 0.998; "~10-point MAE is close to the practical floor".
- BUILD 6 (bweezy615/Soothbet, open source): Elo + damped MOV + opponent-aware EPA + rest → ISOTONIC REGRESSION refit each season on prior seasons only; sealed pre-kickoff ledger with tamper-evident hash, graded Brier vs de-vigged closing market; published LOSING record 49.5% ATS vs 52.4% breakeven ("It lost to the market… So we published the losing record"); 2,608-game walk-forward.
