## What it is (1-2 sentences)
Full-text read of arXiv:2108.05053v1 (Orr, Sanyal, Ling, Goel, Leszczynski — Stanford/Uber AI/Apple, 2021): a VLDB tutorial paper from the Uber Michelangelo feature-store team on managing the industrial ML pipeline (training-data curation, training/deployment, monitoring/maintenance) plus the coming challenges of pretrained embeddings as first-class model inputs. Ledger verdict: ADAPT the monitoring doctrine (freshness/null-count/mutual-information metrics, training-deployment skew, near-real-time drift detection) to GSE's NFL feature layer; the embedding half applies only if GSE adopts learned player/team embeddings.
## Key metrics/methods (formulas where given, else "not specified")
- Feature-store lifecycle (Uber Michelangelo, 2017): (1) training data — feature authoring/publishing with definitional metadata (update cadence + definition SQL), streaming features via aggregation functions persisted to online store + logged to offline store; (2) training/deployment — date-partitioned features with time-based join APIs, dual datastore (SQL warehouse offline, in-memory DBMS online); (3) monitoring/maintenance — feature quality metrics (freshness, null counts, mutual information across features) and model quality metrics (training-deployment skew, near-real-time outlier/input drift detection); offending features isolated and replaced.
- Model storage: parameters/artifacts stored for provenance and reproducibility (integrated model store).
- Embedding challenges: nearest-neighbor stability (Wendlandt et al. 2018); downstream instability = number of predictions that change with different embeddings (Leszczynski et al. 2020); eigenspace overlap score (May et al. 2019); structured-data augmentation +40 F1 on rare entities (Orr et al. 2021); fine-grained monitoring via user-defined subpopulation functions (Robustness Gym); error correction via augmentation/weak supervision/slice-based learning.
- No equations stated. No validation, splits, baselines, or metrics — tutorial paper, not an evaluated system.
