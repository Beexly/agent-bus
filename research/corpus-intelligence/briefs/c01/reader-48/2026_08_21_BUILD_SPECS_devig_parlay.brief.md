## Key metrics/methods (formulas where given, else "not specified")
Common prelude (all 7 methods): `invOdds[i] = 1/decimalOdds[i]`; `margin = sum(invOdds) - 1` (identical for all methods; only redistribution differs). All methods must sum to 1.0 within 1e-9.
1. **multiplicative:** `probs[i] = invOdds[i] / sum(invOdds)`
2. **additive:** `probs[i] = invOdds[i] - margin/n`
3. **power:** find k>0 solving `sum(invOdds[i]^k) == 1`; `probs[i] = invOdds[i]^k`; f(k) monotone on [0,100] — bisection-safe
4. **shin** (Shin 1992/1993 closed form, insider-trading param z): `shinProb(z)[i] = (sqrt(z^2 + 4*(1-z)*invOdds[i]^2/sum(invOdds)) - z) / (2-2z)`; solve z on [0,100] so `sum(shinProb(z))==1`; fall back to multiplicative if no sign change (do not port scipy.ridder's unguarded behavior)
5. **differential_margin_weighting** (Buchdahl, closed form): `fairOdds[i] = (n*odds[i])/(n - margin*odds[i])`; `probs[i] = 1/fairOdds[i]`
6. **odds_ratio** (Cheung): find c>0 solving `sum(invOdds[i]/(c+invOdds[i]-c*invOdds[i])) == 1`; bracket [0,100]
7. **logarithmic:** `logOdds[i]=ln(p/(1-p))` with p=clip(invOdds[i],1e-15,1-1e-15); solve c so `sum(sigmoid(logOdds[i]-c))==1`; bracket [0,20], fallback [-20,20]
Root finder: bisection to 1e-12, maxIter 200.
