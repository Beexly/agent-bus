# arxiv-program/research/2026-09-21/arxiv-deep/1982-autogluon-tabular-robust-and-accurate-automl.md
## What it is (1-2 sentences)
Deep read of AutoGluon-Tabular (arXiv:2003.06505): a battle-tested open-source tabular AutoML system that replaces the CASH (algorithm-selection + hyperparameter search) paradigm with a fixed strong model zoo, multi-layer stacking, and repeated k-fold bagging. Verdict in file: ADOPT — the stacking+repeated-bagging recipe applies directly to GSE's game/team tabular modeling with minimal adaptation.
## Key metrics/methods (formulas where given, else "not specified")
Method: robust preprocessing (auto type inference, imputation, zero-mean/unit-variance scaling, text handling, rare-category bucketing); fixed model zoo (LightGBM, CatBoost, XGBoost, Random Forest, ExtraTrees, kNN, PyTorch tabular NN with entity embeddings + skip connections) ordered cheap→expensive; repeated k-fold bagging (OOF predictions become stacker-layer features); multi-layer stacking (layer-2+ stackers reuse the same base model types, skip connections concatenate raw features each layer); ensemble selection (Caruana) or weighted average on top. Cross-dataset aggregation metric: per-dataset loss rescaled to [0,1] with champion=0, worst=1, linear interpolation. No other formulas stated.
## Data sources named
OpenML AutoML Benchmark (39 datasets, classification + regression, m5.2xlarge EC2, 4h budget each); 11 Kaggle competitions (secret test labels scored by Kaggle, 4h limit on raw data). Competitor frameworks benchmarked: TPOT, H2O AutoML, Auto-WEKA, auto-sklearn, GCP-Tables. Code: github.com/awslabs/autogluon; benchmark repro: github.com/Innixma/autogluon-benchmarking.
## Findings (numbers and facts, not vibes)
- OpenML Benchmark (4h): AutoGluon champion on 23/39 datasets; avg rank 1.8438; avg rescaled loss 0.1385; avg time 201 min; 1 failure. H2O AutoML: champion 2, avg rank 3.1250, rescaled loss 0.2447, 8 failures.
- Kaggle suite (4h, 7 competitions where all ran): AutoGluon avg rank 1.7143, avg percentile 0.7041 (~70% of human teams beaten), 0 failures, 7 champions. GCP-Tables 0.6281; H2O 0.5129; auto-sklearn 0.4819; TPOT 0.4711; Auto-WEKA 0.2056.
- Ablation (avg rescaled loss): full 0.1660 → NoRepeat 0.2199 → NoMultiStack 0.5237 → NoBag 0.7199 → NoNetwork 0.8171; multi-layer stacking is the single biggest contributor. "Even after 4h, the NoMultiStack variant could usually not outperform the full version trained for only 1h."
- Headline claim "beat 99% of data scientists" is 2 cherry-picked Kaggle competitions; honest number is avg percentile 0.7041.
## Intelligence connections (tag each finding: QB-BEHAVIOR, COACHING, OL, TRUST-SIGNAL, SCHEME, OTHER)
- Multi-layer stacking being the dominant contributor (bigger than bagging or the NN) → OTHER (modeling architecture finding: stackers-output-of-base-models is the highest-ROI ensemble pattern for tabular game/team models; complements GSE's calibration work — stacker probabilities feed isotonic/temperature scaling)
- Fixed strong zoo beats exhaustive CASH search under a fixed time budget → OTHER (search-cadence strategy: full 4h-style search once per offseason, lightweight 30-min refit weekly in-season; no per-week HPO)
- No temporal validation in the benchmark (cross-sectional) → TRUST-SIGNAL (must wrap with rolling-origin/purged folds for sequential NFL data; rescaled-loss metric is benchmark-relative, inflates small absolute gaps)
