# data/CARDS_EDGE_VALIDATE.md
## What it is (1-2 sentences)
The 17-card "Wave EV" builder deck (EV1–EV17) for `npm run edge:validate`: a GRIND Tier-1 validation bench for the GSE prediction engine — walk-forward CV, injected kernel-slot scorers (Brier/Murphy, calibration, CRPS, PIT-by-family), an EV-vs-close economic referee, a §6 promotion-gate report, plus 10 hardening cards fixing fail-open leak walls in the evaluation stack.
## Key metrics/methods (formulas where given, else "not specified")
- `evVsClose(p, qClose, y)`: fires side sign(p − qClose); return (ySide − qSide) / qSide; throws RangeError unless fired side's q ∈ (0,1). Independent-derivation pin: p=0.60, q=0.55, y=1 → return 0.818181….
- Brier cross-check pin: rows (p=.8/y=1, p=.2/y=0, p=.5/y=1, p=.9/y=0) ⇒ mean (p−y)² = (0.04+0.04+0.25+0.81)/4 = 0.285 exactly.
- Count-side fire rule: p = 1 − dist.cdf(floor(line)) (P(over) for half-point lines); integer lines refused (no push approximation).
- Referee verdicts: `too_few_plays` when fired < minPlays (default 50); else `positive` iff meanReturn > 0 AND (bootstrap CI present ⇒ ci.lower > 0); `negative` symmetric; bootstrap default blockLength = min(8, max(1, floor(fired/10))), resamples 2000, level 0.95, block form over decisionAt-ordered returns.
- Promotion ladder: gates as_of → temporal_cv → improvement (n-weighted pooled delta > 0) → seasons ≥ 2 → sign_stability (delta > 0 every season) → fdr (BH grid required; absent ⇒ not_run, caps at CANDIDATE) → economic_referee (every season positive ⇒ pass; `no_market_feed` ⇒ not_run, caps at CANDIDATE; zero/negative/too_few_plays with improvement ⇒ DESCRIBES_MARKET). Ceiling is `VALIDATED_PENDING_HOLDOUT`; literal string "VALIDATED" forbidden in the module. Live→RETIRED (rolling 8-week demotion) out of scope.
- Synthetic fixture (EV7): 3 pseudo-seasons × 20 weeks × 10 rows; trueP = sigmoid(0.8·f1 − 0.5·f2); y ~ Bernoulli(trueP); qClose = clamp(trueP + 0.05·(rng()−0.5), 0.02, 0.98); count leg Poisson(exp(0.5 + 0.3·f1)).
- PIT-by-family default bins 10, minPitN 50; `logLoss` clamp [1e-12, 1−1e-12]; hitRate reported but NEVER decisive.

## Findings (numbers and facts, not vibes)
- Test-gap audit verdict: the leak wall is fail-open — `latestPriorRow` admits FUTURE data when `kickoffWeek` or `row.week` is NaN (NaN === 0 false, NaN comparisons false), `knownAtWeek` stamped at emission but enforced nowhere at consumption, one poisoned CSV row kills a validation run (props-hb-validation.ts top-level .catch → exit(3)). (QB-BEHAVIOR)
- `expectedSnapsNext(null, teamSnaps, false)` THROWS RangeError on the week-1/rookie path; EV12 replaces with a refuse union (`no_pooled_share`/`bad_share`/`bad_team_snaps`), injuryOut=true ⇒ expected 0 even when share null. (OTHER)
- `estRoutesTprr` accepts negative targets (negative tprr emitted) and playerOffenseSnaps > teamOffenseSnaps (est_routes > team_dropbacks, e.g. 80·40/70 ≈ 45.7 > 40); EV16 refuses both. (OL)
- Kneel/garbage: `posteamType: "unknown"` while trailing-large in short clock returns regime `garbage_hurry` with positive pass-attempt inflation; EV17 decision: refuse `bad_input` (fallback: `normal` with zero adjustments, pinned). - Cross-family verification mandatory everywhere: verifier ≠ author model family; a test recomputing the implementation's own formula is vacuous — known values from independent derivations only. (OTHER)
- Data classes: all EV cards INTERNAL (Grok/Hermes on no-training endpoints, never stealth/Ox Alpha); REAL-candidate reports are CROWN (never committed, untracked `reports/`; survivor lists never pasted into worker prompts or public surfaces); every record `priced: false`; no `Math.random` anywhere (injected rng via `makeRng`/`boxMuller` only); no `openHoldout(` (build fails); random K-fold banned — expanding-window temporal CV only.
