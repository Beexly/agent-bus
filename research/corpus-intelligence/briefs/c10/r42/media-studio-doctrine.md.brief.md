# design/media-studio-doctrine.md
## What it is (1-2 sentences)
Governance for all Galaxy Sports Edge visual/multimedia assets: approved formats, tools, claim-governance rules for pick data in graphics, approval gates, and forbidden content — explicitly counter-positioned against tout-adjacent social-graphic practices.
## Key metrics/methods (formulas where given, else "not specified")
Quantified specs: social graphics PNG/WebP 1200×630 OG, 1080×1080 IG square, 1080×1920 Story; GIFs ≤8s, loopable, 12–24fps, max 8MB; thumbnails 1280×720 PNG/JPG. Win-rate claims require ≥30 settled picks, defined window, model version. OG images auto-generated by `/api/og`.
## Data sources named
None (media governance). Cross-references `docs/brain/claim-governance.md`, `docs/audit/prompt-leak-and-sensitive-source-policy.md`, `docs/audit/piracy-malware-do-not-use-register.md`, `docs/design/stitch-agent-workflow.md`.
## Findings (numbers and facts, not vibes)
- Public/private boundary: public = brand graphics, social pick cards, thumbnails, brand GIFs; PRIVATE (never published) = cockpit screenshots with pick data/evidence chains/source names, images with user personal data, images derived from Tier 5 source content, anything with internal tool output/agent prompts. (TRUST-SIGNAL)
- Required on pick graphics: GSE monogram/wordmark, source freshness disclosure, "For entertainment purposes only." Forbidden: sportsbook green, casino imagery, lock/fire emojis, fake confidence visuals (glowing "99" without evidence chain), win/loss celebration without settlement confirmation. (TRUST-SIGNAL)
- Claim governance in media: pick direction ⇒ freshness disclosure; confidence score ⇒ "not a guarantee" context; win rate ⇒ ≥30 settled picks + defined window + model version; injury status ⇒ Tier 1 or "Unconfirmed"; sharp money claim ⇒ Tier 1/2 backing, never line movement alone; lock imagery forbidden. (TRUST-SIGNAL)
- AI image generation: never real athletes/coaches/public figures, never pick result visualizations, never anything mistaken for factual sports photography; operator reviews each use case. (TRUST-SIGNAL)
- No auto-publish: "all media requires operator post action"; auto-upload workflow = P0 violation. Codex audit: `/api/og` brand compliance, no real-person AI images in `public/`, no casino/sportsbook imagery. (TRUST-SIGNAL)

no — Media/publishing governance, not engine intelligence; the claim-governance rules (freshness, ≥30 settled picks for win-rate claims, Tier 1/2 backing for sharp-money) are directly reusable as output-layer constraints for any public-facing GSE surface.
