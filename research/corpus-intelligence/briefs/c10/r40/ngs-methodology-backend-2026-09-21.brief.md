# arxiv-program/research/2026-09-21/nextgenstats-profile/ngs-methodology-backend-2026-09-21.md
## What it is (1-2 sentences)
A comprehensive read-only research report on how NFL Next Gen Stats metrics are actually calculated, covering 11 metrics (2026 run-scheme/route models, completion probability, xRY/RYOE, xYAC, pressure probability, tackle probability, QB passing score, defensive alerts, defender ghosting), the RFID/optical data pipeline, public datasets, code repos, API dead ends, and 11 documented methodology gaps. All findings from public sources only; verbatim quotes marked as such.
## Key metrics/methods (formulas where given, else "not specified")
- **Completion Probability** (2018; XGBoost on SageMaker): inputs = 10+ in-play tracking factors; only ~6 named publicly — Air Distance, Target Separation, Sideline Separation, Pass Rush Separation (QB-to-nearest-rusher), Passer Speed, Time to Throw. Trained on 36,000+ pass attempts back to 2016, validated on random 10% holdout; Actual Completion % vs Completion Probability r-squared = 0.98. CPOE = actual completion % − expected completion %; expected_completion_percentage computed from per-play completion probability. (Full feature set, XGBoost hyperparameters, calibration — not published.)
- **Expected Rushing Yards (xRY)** (2020; 2D CNN by Philipp Singer & Dmitry Gordeev, "The Zoo", winners of 2020 Big Data Bowl, >2,000 entrants, $75K prizes): inputs only 5 vector features for all 22 players — X, Y, S (speed), A (acceleration), Dir (direction) — evaluated at handoff; output = probability distribution over rushing outcomes (not a point estimate), scored with CRPS; xRY = Σ (outcome × probability). Example: Nick Chubb 88-yd TD — xRY 7 (7.3), RYOE +81, TD probability <0.1%. RYOE = actual − expected yards; RYOE/Att per attempt; ROE = % of runs gaining more than expected; also First Down Probability and Touchdown Probability at handoff.
- **Pressure Probability** (2023; GNN + random forest + blocking-matchup model): Pressure defined as pressure probability > 75%. Definitions: pressure rate = total pressures / total pass-rush snaps (avg rusher 10.3%); time to pressure avg 2.9s; quick pressures within 2.5s; pressure probability at snap based on alignment/locations of rushers vs blockers; pressure rate over expected = avg pressure probability − probability at snap; positive rush rate avg 54%. Old logic replaced: within 2 yards of QB at pass-forward or 1.5 yards at any point. Whitepaper: "Feeling the Pressure" (Abdoo co-author), MIT Sloan conference.
- **Tackle Probability** (2024; built on >2M data points, AWS ProServe + Keegan Abdoo/Mike Band): 20 features/frame for all 11 defenders, computed every 10th of a second; trained 2018–2022, tested on 2023; 15 ML models tested on >1M data points in 4 months; winning model type undisclosed. Derived: missed tackles, tackle efficiency, tackle yards saved (tackle prob + expected-yards fusion), missed tackle yards lost, downhill/upfield/chase-down attempts.
- **NGS QB Passing Score** (Jan 13, 2022; Amazon Science methodology article Aug 26, 2022, Aubet & Ehrlich; AWS-released PyTorch code + demo notebook): temporal convolutional network over per-timestep features (x/y position, x/y speed, x/y accel, direction, body orientation per player → 176 columns = 22 players × 8 features, variable rows snap-to-release, ~40 rows for 4s throw), + static features (down, score, games remaining); MLP outputs spliced binned-Pareto distribution (discrete binned base, tails below 5th/above 95th quantiles replaced by weighted generalized Pareto); play score = rank (0–1) of actual yards gained in predictive CDF, standardized; aggregated game/season (Kyler Murray 87 for 2021 season, 9th of playoff QBs; 99 under pressure on 2.5–4s throws). Training: ~50,000 passing plays 2018–2020 (34,000 completions, 15,000 incompletes, 1,200 INTs); 8h on 1-GPU p3.8xlarge; inference 0.001 s/play. Correlates better with win/playoff % than prior QB metrics.
- **Defensive Alerts** (broadcast): acceleration patterns + presnap shifts + situational context (down, distance, game state) → generative AI predicts likely rushers. No equations published.
- **Defender ghosting** (CNN-LSTM, AWS ML Solutions Lab, Lin Lee Cheong): tracking accurate within 6 inches in 99.9% of cases; speed cap 12.5 yd/s (top measured ~11 yd/s); composite metric of DB trajectory quality: actual avg −0.1036 vs predicted −0.0825. Not a public stat — component of stats under development (QB decision-making on hypothetical throws).
- **Run Scheme Classification** (2026; transformer over 10Hz spatial-temporal player data): 16 intended-design labels (man/zone/gap); secondary tags (read option, split zone, pitch); intended gap vs actual gap hit; companion models for play-action concepts and defender gap responsibility. Built with AWS ProServe. Labels/accuracy not published.
- **Run Blocking Matchups** (2026): blocking assignment + block type (pull, down, crack) + engagement begin/end per player; derived: double-team frequency, time-to-shed, blocks springing runners open. Architecture not published.
- **Route Classification 2.0** (2026): separates shallow vs deep crossing routes, fade vs go, screens via blocker movement + receiver path, inside/outside release. Architecture not published.
- **Expected YAC** (2018; superseded by Singer/Gordeev structure): inputs qualitative — receiver openness, speed, defenders/blockers in space. No equations.
- **Data pipeline**: RFID in shoulder pads + ball; 20+ UWB receivers/stadium; players 10x/s, ball 25x/s; accuracy ~few inches (2026); ~300M data points/season (2021); 75+ ML models processing in <1s, 500–1,000 stats/play. Optical pose: 4K × 16 angles → x,y,z of 29 body parts at 60 Hz, processed ~700ms on-site + <100ms cloud inference, <1s capture-to-analysis; 2026 first season with full league-wide installation; data stays internal while validated. NGS tools: SageMaker, QuickSight, AWS ProServe, Amazon Q Business.

## Findings (numbers and facts, not vibes)
- The 2D-CNN Zoo architecture (5 features × 22 players at handoff, CRPS-scored distributional output) is the winning template reused for xRY, xYAC, and kickoff-return-yards community solutions; third-party transformer (SumerSports) improves tackle-location ADE to 4.61 vs Zoo's 5.78.
- 2026 Big Data Bowl (8th annual): predict all 22 players' positions 4 frames after a pass is thrown (200–500 ms), restricted to passes with targeted receiver ≥5 yds from nearest defender; eval = average Euclidean distance.
- 2026 is the first season with full optical pose capture league-wide; capture-to-analysis <1s; data internal while validated.
- Documented methodology gaps (11): 16 run-scheme labels not enumerated; blocking matchup architecture; Route Classification taxonomy; play-action/gap-responsibility companion models; completion probability full feature set + hyperparameters + calibration; xYAC equations; tackle probability 20 feature names + winning model type + missed-tackle thresholds; defensive alerts generative-AI component; broadcast pipeline internals; no public Keegan Abdoo personal methodology writeups; 2018 original xYAC model.
