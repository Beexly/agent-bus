## Key metrics/methods (formulas where given, else "not specified")
- Blended cost (3:1 input:output), effective dollars: Sonnet 5.5 — Vercel $4.00 vs OpenRouter $4.22 vs direct $4.00. Grok 4.7 — Vercel $3.00 vs OpenRouter $3.17 vs direct $3.00. GPT-4o-mini — Vercel $0.2625 vs OpenRouter $0.2769 vs direct $0.2625. Llama 3.1 8B — OpenRouter $0.0607 vs Neon $0.225 (OpenRouter wins).
- OpenRouter fee math: 5.5% Stripe deposit fee (5% crypto, $0.80 minimum), no volume discounts -> x1.055 effective at every spend level ($50/mo -> $52.75; $200/mo -> $211). Credits expire after 1 yr; fee non-refundable.
- Vercel AI Gateway: zero markup, zero platform fee on tokens. $5/mo free credit (requires payment method; permanently forfeited on first top-up). Per-request ZDR and `disallowPromptTraining` filter free. Team-wide ZDR $0.10/1K requests.
- Vercel Workflows: $0.02/1K events; one step = 3 events; 4-step chain at 15-min cadence (2,880 runs/mo) ≈ 40,300 events/mo ≈ $0.81/mo. Functions invoked by workflows bill at same Fluid rates as crons.
- Vercel Sandbox (Pro, iad1): Active CPU $0.128/hr; memory $0.0212/GB-hr; creations $0.60/1M; 10,000 concurrent; 24h max sessions; 8 vCPU / 16 GB / 64 GB ephemeral NVMe / 15 open ports; Node 22/24, Python 3.13. Math: 100 backtests/mo x $0.11 (30-min, 4 vCPU) ≈ $11/mo — inside the $20 credit.
- Observability posture: free tier + Plus on prod only ($1.20/1M events, no base fee; auto-enabled for teams created/upgraded on/after 2026-04-03) + spend alerts = $0–3/mo. Log drains $0.50/GB — skip.
- Firewall: AI Bots managed ruleset (free on Pro; workflow: Log 7 days -> review -> Deny); Bot Protection Challenge; rate limit `/api/*` 100 req/60s/IP -> 429 (per-region counters); blocked scraper request saves bandwidth ($0.15/GB), invocations, compute.
- Preview deploys: every push = full build billed in build minutes even if it fails; 50+ failed deploys ≈ 200 wasted build minutes; measured build-heavy setup burned $269/30d on builds alone. Fixes: `ignoreCommand` docs-only pattern; disable previews on agent branches (`motif/*`, `hermes/*`) or `previewDeploymentsDisabled: true`; `github.autoJobCancelation: true`.
- Fluid sizing: for 60s I/O-bound cron, memory ~70% of cost; per-60s run ≈ $0.00016 at 512 MB vs $0.00025 at 1 GB. Hottest cron (15-min): $0.72 -> $0.46/mo. All 23 crons single-digit $/mo.
- Edge middleware: 1M invocations/mo included on Pro, then $0.65/1M. Narrow matcher to fenced surface only.
- Pro included allowances sweep: Web Analytics 100K/mo ($3.00 value), Speed Insights 10K (~$6.50), middleware 1M ($0.65), image transforms 5,000 ($0.25), ISR reads/writes 1M/200K (~$1.20), Fast Data Transfer 1 TB ($150 value), 100 cron jobs/project (using 23/100), 1 GB Blob.
- ISR cost gotchas: one uncached fetch/cookies()/headers()/awaited searchParams poisons whole route dynamic; cache hits never count as invocations; ISR writes ~10x pricier than reads (8 KB units); v15+ fetch() not cached by default.

## Findings (numbers and facts, not vibes)
- [OTHER] Vercel AI Gateway wins or ties on every basket model — zero markup everywhere vs OpenRouter's structural 5.5% deposit fee. OpenRouter's only basket win is Llama 3.1 8B raw list price, fee narrows it.
- [OTHER] Per-model prices per 1M input/output: Sonnet 5.5 $2.00/$10.00 (Vercel and direct); Grok 4.7 $2.00/$6.00 (Vercel, direct; OpenRouter ≥200k prompt $4/$12); GPT-4o-mini $0.15/$0.60; Llama 3.1 8B OpenRouter $0.05/$0.08 vs Neon $0.15/$0.45; Qwen3 235B A22B OpenRouter $0.455/$1.82 — SKU expires 2026-10-09; gpt-oss-120b $0.15/$0.60 (models.dev flags Neon entries at $0.072/$0.28: inconsistency, queued).
- [OTHER] Training-data defaults: every basket family has a no-prompt-training agreement on the gateway EXCEPT DeepSeek (assumed-trains unless the filter is set — which then blocks DeepSeek routes entirely).
- [OTHER] Next.js 16 has two mutually exclusive caching models (previous model vs Cache Components `cacheComponents: true`); mixing them is a build error. Recommendation: implement previous model now; Cache Components a later deliberate migration.
- [OTHER] Concrete ISR patterns given: public projections `revalidate = false` + CRON_SECRET-protected revalidate route with warm-up fetch; rankings `revalidate = 86400` safety net; authenticated/fenced APIs `export const dynamic = 'force-dynamic'`.
- [OTHER] Next 16 corrections: `updateTag(tag)` is Server Actions only (won't work in cron route.ts); from cron/publish routes use `revalidateTag(tag, 'max')` (profile arg required in Next 16); `'use cache'` runtime output does not durably persist on Vercel serverless.
- [OTHER] PPR: stable in Next 16, but a route with PPR holes still invokes the function on a shell hit — for uniform pages hole-free ISR is cheaper.
- [OTHER] Vercel Sandbox "5 CPU-hrs / 420 GB-hrs / 5K creations / 10 concurrent" figures are Hobby quotas, not Pro; Pro has no included allowance — all Sandbox bills on-demand against the $20 credit.
- [OTHER] Founder hard blocks: AI Gateway pilot decision ($5 free tier first), DeepSeek data posture decision, Vercel spend budget (default $200 too high), re-verify Grok 4.7 "40% off" promo before budgeting.
