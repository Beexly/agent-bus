# ops/LAUNCH_CALIBRATION_COHORT_2026-09-12.md
## What it is (1-2 sentences)
Evidence-only calibration cohort log (branch hermes/c298-inplay-parity-2026-09-12): five cohorts (A–E) documenting launch calibration eligibility floors, publish-time market_p recompute, closing-line value, an identical-row bake-off, and a 2006-2025 NFL market baseline. No inclusion rule changed, no production write, no threshold touched.
## Key metrics/methods (formulas where given, else "not specified")
- Market_p resolution order (live-calibration-p.ts): odds-table resolver first (2+ books; exactly one book resolves as `resolver_single_book`), then proof-receipt marketFairProb, then factor-breakdown market fair; synthetic 0.5 rejected; Confidence/100 never scored for floors. Receipt was demoted after production showed it sitting 0.169 above the odds table at generatedAt on v5.2.7 pre-game rows.
- Cohort B (WP-28/WP-28b) recompute: engine americanToImpliedProbability per book, mean per side, proportional two-way de-vig; method tag `mean_implied_proportional_devig`; snapshot rule = latest H2H row with fetchedAt at or before generatedAt (rows after generatedAt never read); >= MIN_BOOKMAKERS (engine constant, never literal) distinct bookmaker keys quoting BOTH sides tags `market_p_from_odds_table`, one real book → `market_p_single_book` (C-110); boundary-aware selectionIsHomeSide evaluated both directions, null on ambiguous selection.
- Cohort D bake-off metrics: engine brierDecomposition, 10-bin ECE (4dp); bootstrap seeded/paired (same resample indices per score), deterministic.
- Exclusion buckets (counted, never silently dropped): non_moneyline_market, three_way_market, in_play (generatedAt at/after commenceTime; when commenceTime absent the row is KEPT), no_market_probability, unverifiable_market_p (C-300).
## Data sources named
Odds table (books), proof receipts, factor breakdowns, ESPN finals, ESPN public / DraftKings routed lines (`espn_public`), rundown lines (`rundown_default` excluded; unknown `rundown_<id>` affiliates kept as distinct books), nflverse games.csv (CC BY 4.0).
## Findings (numbers and facts, not vibes)
- Cohort A (market_anchored_v3, C-298 2026-09-09), settled WIN/LOSS two-way MONEYLINE: endpoint-reported (quoted, NOT independently recomputed) eligibility GREEN n=407, Brier 0.2103, raw ECE 0.0549, debiased 0.038688; gates statsPublic, canExposePublicPicks, canExposePerformanceStats, calibrationPublished all true. Version note: endpoint reports probability basis market_anchored_v4 vs local v3 — deployed-vs-local drift consistent with known SHA mismatch; v4 semantics NOT attributed to this code.
- Cohort A CLV (quoted, same source): graded 1443, beat 328, matched 611, lost 504, rate 0.2273, clearsBreakEven=false, canExposeClv=true — honestly labeled result, not proof of edge.
- Cohort C CLV method: close = LAST odds batch at/before commenceTime (`capturedAt`; null when no batch precedes kickoff), averaged across books as the scorer forms consensus; moneyline CLV in implied probability (close minus pick); spread/total CLV in points, side flips sign so POSITIVE always means beat the close; verdicts epsilon-banded BEAT_CLOSE / LOST_TO_CLOSE / MATCHED_CLOSE. `bookmakerCount` is a documented misnomer: counts ROWS in the closing batch, not distinct books (ClosingOddsRow carries no bookmaker id). Spread/total and moneyline samples must stay separate downstream (points vs probability units).
- Cohort D identical-row bake-off (C-265, 2026-09-08): truth surface read confidence n=745, independent_trueProb n=712, marketFairProb n=135 — the n=135 vs n=475 gap explained: the by-market row builder reads factor breakdown BEFORE receipt and never calls the resolver.
- Cohort E (baseline, do not cross-quote): 5,281 settled NFL games 2006-2025, walk-forward folds (train <= N, eval N+1, never one pooled number); pooled held-out 2016-2025 n=2,750: base rate 55.02%, Brier 0.2106 [0.2050, 0.2172], reliability 0.0324, resolution 0.0361, ECE equal-width 0.0180 / adaptive 0.0126 (adaptive is the honest binner; equal-width inflated by sparse tails); ties excluded. NOT the 15,939-pick spreads/totals 1999-2025 replay corpus — the two populations must never be cross-quoted.
- Governed suites green at write time: publish-time-market-p.test.ts (20), report-sample-completeness.test.ts (9), clv-capture.test.ts (10).
- UNREPRODUCED per policy (unavailable rows, not estimates): current eligibility counts beyond the endpoint quote; fresh odds-table market_p recompute on current production rows; ESPN-contradicted-finals sensitivity cell; anything not named with a command or quoted source = absent.
