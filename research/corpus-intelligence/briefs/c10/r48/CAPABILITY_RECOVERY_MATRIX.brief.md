# research/intelligence/CAPABILITY_RECOVERY_MATRIX.md
## What it is (1-2 sentences)
2026-08-12 audit by 4 parallel research agents of a 30-component DeepSeek "blueprint": every claim verified against live npm, PyPI, Hugging Face, OpenRouter, and the repo; verdicts corrected from "90% fiction" (the packaging was fake, most architecture pointed at something real).
## Key metrics/methods (formulas where given, else "not specified")
Verdict counts across 30 components: Already have it = 16; Engineer in repo = 5; Use a real package = 2; Not worth it = 7; No recoverable capability = 2 ("AHA", "T3MP3ST" — acronyms with no stated function). Method: `npm audit --omit=dev` on production deps run 2026-08-12.
## Data sources named
npm registry (`npm view`), PyPI JSON API, Hugging Face Hub, OpenRouter `/api/v1/models` (live), llm-stats.com RSC payload (350 models), `npm audit --omit=dev` on the repo, direct reads of `apps/web/lib/**`, `scripts/guardrails/**`, `packages/db/prisma/schema.prisma`, `docs/brain/**`.
## Findings (numbers and facts, not vibes)
- URGENT (verified, not from the blueprint): `npm audit --omit=dev` on prod deps found **critical: 2, high: 6, low: 1**. Both criticals in `next-auth`/`@auth/core` — the library enforcing the paywall: (a) config errors can cause existence-based auth checks to **fail open** (auth object populated with an error); (b) `getToken()` throws uncaught on malformed Bearer headers; (c) email normalizer validates before Unicode normalization (homoglyph @ bypass). Highs: `next` (Image Optimizer DoS, RSC deserialization DoS), `postcss` (XSS + arbitrary file read via sourceMappingURL), `fast-uri` (host confusion), `nanoid`, `brace-expansion`. CI has `--no-audit` 7 times in `.github/workflows/ci.yml`; `.github/dependabot.yml` does not exist.
- Prescription, ranked #1 of 5 actions: patch `next-auth`/`@auth/core`, add `audit-ci` 7.1.0 + `dependabot.yml`, drop the 7 `--no-audit` flags (effort S).
- Correction: `tencent/hy3:free` no longer free — the `:free` route was retired; live OpenRouter pricing is $0.132/$0.528 per 1M with 262K context (295B MoE / 21B active, Apache-2.0, released 2026-07-06).
- Actually-free routes verified live (19 at $0/$0): `nvidia/nemotron-3.5-lightning:free` (1M ctx), `nvidia/nemotron-3-ultra-550b-a55b:free` (1M ctx), `nvidia/nemotron-3-super-120b-a12b:free` (262K), `google/gemma-4-31b-it:free` (262K), `cohere/north-mini-code:free` (256K), `poolside/laguna-s-2.1:free` (262K), `openai/gpt-oss-20b:free` (131K). Limits: 20 req/min; 50 req/day with no credits, 1,000/day after $10 lifetime spend.
- Local model benchmarks (llm-stats, Aug 2026, GPQA / SWE-bench Verified): Qwen3.6-27B — 17GB, GPQA 0.878, SWE-V 0.772, `qwen3.6:27b` (file states it "beats every proprietary model priced under $1/1M"); Qwen3.5-9B — 6.6GB, GPQA 0.817; Qwen3.6-35B-A3B — GPQA 0.860, SWE 0.734; Gemma 4 31B — GPQA 0.843. All Apache-2.0. Cheapest competitive API: DeepSeek-V4-Flash-0423 at $0.10/$0.20 per 1M (GPQA 0.874, SWE 0.786, 1M ctx); caveat: of 350 models on llm-stats, only 93 carry a price.
- Two "inventions" that are real research: LLMRouterBench (arXiv 2601.07206); PAST-Bench (arXiv 2608.04003, github.com/Gen-Verse/PAST-Bench) — its core finding: agents with the same headline gain differ in whether evidence supports the intended pathway; recommendation: copy its experience-on/experience-off A/B design into `npm run agent:eval`, add no dependency.
- Package-name traps: npm `transformers` is a string/templating library (installs clean, fails at runtime; the real one is `@huggingface/transformers` 4.2.0); npm `semgrep` is a 0.0.1 stub (real is PyPI `semgrep` 1.172.0); `@openpolicyagent/opa-wasm` is 404 (real: `@open-policy-agent/opa-wasm` 1.10.0); PyPI `memgpt` is a squatter (real: `letta` 0.16.8).
- Accepted in-repo equivalents (already-built, more governed): `claude-api/model-router.ts`, `claude-api/jynx.ts` (Bedrock -> Azure -> Vertex -> Anthropic + `cerebras_free` lane), `claude-api/provider-dispatch.ts`, `ai-control-plane/budget.ts` (1,164-line reserve/settle ledger, integer micros), `lib/performance/proof-hash.ts` (Merkle across 16 files, Pedersen ledger in `packages/crypto`), `promptfoo` 0.122.0 at `eval/promptfoo`, `ai-control-plane/policy-registry.ts` + `enforce-gate.ts`, `.claude/skills/` (8 SKILL.md + `npm run agent:eval`), `lib/autonomy/operating-kernel.ts` (pure deterministic planner stamping `requiresOwner`), `cti-miner.ts` + `accept-proposal.ts` (acceptance is human-only by design).
- The one genuine gap: LLM response cache — ~80 lines of exact-key caching on `ioredis ^5.10.1` (deliberately NOT embedding-based semantic caching, which could silently serve stale answers).
- Secondary gap: `.claude/settings.json` does not exist — nothing constrains agent Bash calls in a repo holding live Stripe and production DB env; prescription: `permissions.deny` + PreToolUse hook (zero dependencies).
