# arxiv-program/research/2026-09-21/arxiv-deep/1474-beep-balancing-effectiveness-and-efficiency-when.md
## What it is (1-2 sentences)
Deep-read ledger for arXiv:2307.11780v2 (KDD 2023) by Jiang Wu, Dongyu Liu, Ziyang Guo, Yingcai Wu: Beep, an MDL-based multivariate sequential pattern miner with noise-tolerant encoding and LSH acceleration. Verdict: ADAPT — adapt from table-tennis rally mining to unsupervised NFL opponent-tendency/tactic discovery on play-by-play sequences.
## Key metrics/methods (formulas where given, else "not specified")
- Objective (Eq. 1): minimize_P L(S|P) = L(P) + Σ_{s∈S} L(s|P), where L(P) = pattern-set description length, L(s|P) = sequence s encoded with the pattern set (code table CT / code stream CS).
- Pattern code: L(code_p(p)) = −log2(usage(p)/Σ usage(p_i)); gap/fill/miss codes as relative shares of gaps+fills+misses; miss codes add L_N(|A|) extra bits for the missing-attribute index. Code table length L(P) = L(ST) + L(CT*) with universal-integer coding L_N(k).
- Encoding features: empty values match any value; missing values (single-value noise tolerance, ≤ ||p||/10, at most 1 per event); gap events (≤ |p|−1); interleaving/overlapping patterns allowed.
- Search: initialize with all singletons; iterate pair-combination candidates at every alignment (conflicts → missing value); add candidates reducing L(S|P); prune patterns whose removal reduces L(S|P); stop at stabilization.
- Acceleration: weighted LSH (Ioffe weighted minhash) on sequence-position sets (segments ≤ l=20 events); combine pairs only if weighted Jaccard similarity ≥ threshold th.
- Covering (Appendix A): greedy Krimp-style, cover order ↓||p||, ↓support(p|S), ↑lexicographic, KMP search per pattern; time O(|P|·||s|| + ||P|| + ||s||) per sequence; total O(|P|·||S|| + ||P||·|S| + ||S||).
## Data sources named
Table-tennis case-study dataset: 716 rallies from 10 matches (2019, Mima Ito vs Chinese players; avg 5.91 events/rally); each hit = 4 categorical attributes (Tech 16 values, Ball 12 table-area values, Spin 7 values, Player 6 position values); proprietary analyst-annotated, not publicly hosted. 5 synthetic datasets generated by authors (not public): |S|∈{50,70}, |s_i|∈{20,30}, |A|∈{5,7}, |V_k|∈{100,200}; each with 5 planted patterns + 10 planted missing values.
## Findings (numbers and facts, not vibes)
- Table-tennis case study (Table 1): Ditto |P|=161, avg.freq=4.36, t=1747 s vs Beep |P|=62, avg.freq=12.94, miss=280, t=425 s (~4.1× faster, 2.6× fewer patterns, ~3× higher per-pattern frequency).
- Synthetic (Table 2): Beep consistently higher ΔL% than Ditto at lower runtime (e.g., row 1: Ditto ΔL%=24.5, t=399 s vs Beep ΔL%=27.2, t=79 s ~5.1×; row 5: Ditto t=175 s vs Beep t=18 s ~9.7×). LSH alone cuts runtime ~10× (1276→120 s row 3) at small ΔL% cost.
- All algorithms recovered all 5 planted patterns per synthetic dataset (manual check); Beep-miss/Beep recovered all planted missing values.
- Analyst anecdote: a Beep pattern spanning single-value deviations surfaced an actual data-recording error (confirmed by analysts) — miss codes caught a labeling error.
- Limitations: analyst validation n=2, subjective, no blinded A/B; synthetic eval favorable-by-construction; sequences short (avg 5.91 events); MDL minimization can merge distinct co-occurring tactics (avg freq 12.94 vs Ditto 4.36 may hide sub-tactics); no predictive validation; categorical-only assumption requires discretizing continuous NFL features.
