## Findings (numbers and facts, not vibes)
- **cuOpt family** — NVIDIA GPU-accelerated decision-optimization engine (vehicle routing TSP/VRP/PDP, LP/QP, MILP beta) with Python, C, gRPC, REST server APIs; six catalog skills incl. `cuopt-multi-objective-exploration`. GSE fit: DFS lineup construction is exactly a MILP (maximize projected points subject to salary cap, position slots, exposure caps, stack constraints) — cuOpt MILP replaces OR-Tools CP-SAT as GPU-backed deterministic auditable solver; multi-objective skill fits ceiling-vs-floor-vs-ownership tradeoff surface. Brev GPU price tier UNVERIFIED.
- **Clinical ASR flywheel → Parakeet TDT v2 sports-commentary transcription**: full ASR flywheel (term curation → synthetic benchmark → keyword-error-rate scoring → fine-tune). Models CC-BY-4.0 (commercial-safe); nvidia/Nemotron-3-Diarization + multitalker Parakeet for speaker-attributed transcripts; transcription at ~3400x real-time batched. GSE fit: real-footage content research — transcribe broadcasts/podcasts to searchable text, mine analyst quotes, locate moments for the clip pipeline; audio→text only, inside the HARD VIDEO RULE.
- **Nemotron Parse / nv-ingest** — end-to-end VLM extracting formatted text (Markdown/LaTeX), bounding boxes, semantic block classes with reading order; token-compressed variant for batch/edge. Missing document-ingestion half of the already-shortlisted RAG Blueprint. GSE fit: ingest the 750-paper arXiv corpus + stat PDFs; stat-sheet tables come out as Markdown tables.
- **Cosmos Dataset Search blueprint** — semantic search over video archives: Cosmos-embed NIM embeddings, Milvus (cuVS-accelerated), React UI + REST + CLI; text-to-video and video-to-video search. GSE fit: the missing retrieval layer for the real-footage operation — query "4th-quarter pick six" in plain English, get exact timestamps for seconds-long telestrated commentary-led clips. Zero synthetic video.
- **DeepStream import-vision-model + RTVI CV customize** — import custom vision model (e.g., YOLO-style) into DeepStream GPU streaming pipeline. GSE fit: run play/ball/tracking detection on real video to auto-flag highlight moments and tracking-research datasets. Real footage in, detections out, never synthetic. Streaming wants always-on GPU — heaviest cost of the five (batch-on-demand cuts it). Brev tiers UNVERIFIED.
- No clean mapping (honest): lead-gen/outreach/prospecting, social content scheduling/drafting/analytics, website building, SEO, marketplace/ecommerce, sports analytics/prediction/odds — NOTHING in the NVIDIA/Brev catalog. Nearest: RAG + AI-Q deep-research stack for prospect research; x-poster skill stays for drafting.
- cudaq-guide assessed and rejected as premature: quantum route for DFS — QUBO/TSP encodings blow up (n² qubits for TSP), hardware access expensive/experimental; cuOpt classical MILP dominates on every practical axis.
- Dismissed: skill-card-generator, physical-ai video-data-augmentation (HARD VIDEO RULE flag — training-data only, never content), dali-dynamic-mode, DGX Spark playbooks, omniverse-*/physicsnemo.
