# docs/ops/PLATT_HIERARCHICAL_FULL_POSTURE.md
## What it is (1-2 sentences)
The GSE calibration posture document: Platt MAP IRLS (two-parameter logistic recalibration on logit scores with Gaussian prior, fit by Newton offline) plus a hierarchy of extensions (group intercepts, partial pooling, nested sport+market, full Bayes, DP clustering), with code paths, runtime placement, and product-honesty rules.
## Key metrics/methods (formulas where given, else "not specified")
Base model: `p_cal = σ(A·s + B)`, `s = logit(clip(p_raw, ε, 1-ε))`; A = slope (A<1 compresses overconfidence, A>1 sharpens), B = bias/shift. MAP objective: NLL + Gaussian prior, defaults μ_A=1, σ_A²=1, μ_B=0, σ_B²=1; MLE = same without prior (overfits small holdouts). IRLS/Newton: g = Xᵀ(p−y) + Σ₀⁻¹(θ−θ₀), H = XᵀWX + Σ₀⁻¹, θ ← θ − H⁻¹g; θ=(B,A)ᵀ, X rows (1,sᵢ); 2×2 inverse only; stop ΔA²+ΔB² < 1e-12 or maxIter≈25. Numerics: stable sigmoid, wᵢ ≥ 1e-12, clip preds to [ε,1−ε], binary only (exclude PUSH). Data protocol: canonical settled only (!bootstrap, not seed), time-ordered train/holdout, fit train → score holdout Brier, ECE, Murphy REL/RES/UNC, log loss; never train ECE as publish proof; version artifact {method, A, B, prior, nTrain, dateRange, modelVersion, scoreSpace:"logit"}. Bake-off order: Raw → Temperature → Platt → Isotonic PAVA/CIR → hierarchical EB-τ. Hierarchical extensions: (1) group intercepts logit pᵢ = B + A·sᵢ + u_{g(i)}, u_g ~ N(0,τ²), g = sport|market, τ EB moment or Laplace marginal clamped [0.05,2], unseen g → u=0; fit global MAP → τ̂ → joint MAP/ridge; (2) partial pooling on slope A_g=A+a_g, B_g=B+b_g (prefer intercept-only unless holdout proves); (3) nested sport+market u_g = v_sport + w_{sport,market} (offline research); (4) full Bayes on τ ~ HalfNormal/LogNormal, NUTS, non-centered u_g = τ·z_g (offline only; non-centered irrelevant for MAP+EB τ); (5) hierarchical Beta-Binomial bins as companion to Platt. Fit recipe: s=logit(clip(p_raw)) → global (A,B) MAP IRLS → û_g from group residuals with (A,B) fixed → τ² = clip(mean(û²)−mean(noise), τ_min², τ_max²) → joint MAP design [1,s,1_g…] ridge 1/τ² on u → freeze {A,B,û_g,τ,group keys,version} → predict with û_g if known else 0 → holdout Brier/ECE/Murphy vs global Platt. Explicitly NOT PROVEN unlocks: hierarchy ≠ resolution (live Murphy RES≈0.002); "Platt improves REL… better-calibrated weak ranker, not PROVEN. Enable apply only after selective publish / sport models move RES." Runtime: fit on Node cron/offline, predict cheap σ(As+B); gate with applyAllowed/adjustments flag (CALIBRATION_ADJUSTMENTS default false); never IRLS per request or on Edge.
