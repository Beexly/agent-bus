# arxiv-program/research/2026-09-21/arxiv-deep/0243-markov-cricket-using-forward-and-inverse.md
## What it is (1-2 sentences)
Vohra & Gordon (2021; full-text read) model ODI cricket as a Markov process so that reinforcement learning yields three tools: (1) a neural value-function alternative to Duckworth-Lewis-Stern for interrupted games, (2) an inferred true reward function and optimal batting policy via inverse RL, and (3) a full game simulator producing posterior final-score distributions from any state. The ledger's verdict is ADAPT — the inverse-RL primitive is genuinely new to the corpus (fills gap #4 on RL/bandits) and complements Sandholtz's 4th-down MDP, which assumes a reward rather than inferring one; the cricket simulator and DLS work do not transfer.
## Key metrics/methods (formulas where given, else "not specified")
- Markov Reward Process + Monte Carlo value learning; reward = fraction of total runs scored in the state; neural-network value-function approximator (5 input neurons first innings / 6 in second innings, hidden layers, 1 output = value = % scoring resources remaining). State spaces: first innings [51, 11, 50, 6, 2]; second innings [51, 11, 50, 50, 6, 2] (over, wickets lost, score band in 10-run intervals, ball-in-over, extra indicator; second innings adds target band).
- PredictedScore = ⌈CurrentScore / (1 − r)⌉, where r = resources remaining (Eq. 1). %Error = (Predicted − Actual)/Actual × 100, averaged per fold (Eq. 2).
- IRL (first innings only): MDP with actions = {dot ball (0), 1, 2, 3, 4, 6 runs}; linear reward r(s,a) = x₁s₁+…+x₅s₅ (a=0, dot ball) and x₁s₁+…+x₅s₅ + y_a·1000·a otherwise (Eq. 3); objective maximize Σᵢ p(V^π*(s₀) − V^πᵢ(s₀)), p = squared Euclidean distance (Eq. 4; Ng & Russell 2000 form, guided-cost-learning framing per Finn et al. 2016). Expert strategies = action sequences of WINNING teams; non-expert = losing teams'.
- Game simulator: transition probabilities estimated from history — P(runs ∈ 0–6 | state, not wicket ball), P(wicket | state), P(non-optimal action | state); simulate from initial state (wicket check → optimal-action check → action sampled → next state); 100 simulations → posterior final-score distribution.
## Data sources named
Cricsheet (https://cricsheet.org) — freely available structured ball-by-ball data for international and T20 league matches (accessed June 2020); ODI matches used. No code or repository links. Networks trained with unspecified framework.
## Findings (numbers and facts, not vibes)
- Value model vs DLS (10-fold CV, random interruption after over 20): first innings best net mean % error range −2.11% to −0.11% vs DLS 2.77% to 5.41% (model underestimates slightly; DLS overestimates with larger magnitude); second innings best −0.96% to 1.82% vs DLS 2.06% to 4.54%. Conclusion headline: "up to 10 times improved accuracy" (first innings −1.11% vs 4.27% ≈ 3.8×; second innings 0.43% vs 4.35% ≈ 10×) — in-file caveat: ratio of small percentages; absolute improvement ~3 points.
- IRL coefficients (Fig. 6): state features 1 (over), 3 (score band), 4, 5 hit the upper bound 1.0 (constraint-bound → weights unidentified, per the ledger's critique); wickets lost is the ONLY negative coefficient. Action coefficients: 2 runs = 1.0 (highest — keeps the successful batter on strike, low run-out risk); 4 runs second-highest; 6 runs just above 0.5 (high reward, high caught-risk); 1 run low; 3 runs LOWEST (run-out risk vs time taken).
- Optimal policy: win by losing fewer wickets and batting the full 50 overs; dot balls valuable early and after wicket clusters; singles valuable early; fours the highest-value action (declines as wickets fall); sixes valuable late with >half wickets in hand. Linearity forces action rankings to be state-independent (flagged limitation).
- Simulator: first innings with optimal actions wins 82% of 100 simulations vs 50% using transition probabilities only. Interruption posterior: first-innings optimal-action model 9.87% ± 16.09%; without optimal actions 2.83% ± 15.10%; second innings 2.09% ± 11.10%. In-file limitation: simulator evaluated in-sample (full dataset for both transition probabilities and interruption test) — optimistic.
- In-file limitations: expert = winners is noisy (teams can win sub-optimally); linear reward can't express state-dependent action values (e.g., six should dominate four on the last ball); no held-out validation of the IRL reward function.
