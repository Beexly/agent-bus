A.3     Splitting Criterion
Following [5], we split the tree at the point (x i , c i ) that gives the
greatest reduction in y-variance, so the splitting criterion is:
                        Nst                   Ns f
      Variance(s) − [       · Variance(st ) +      · Variance(s f )]
                        Ns                    Ns
where s is the whole set of data records (x i ) on a node, st is the
set of data records on a child node for which the split condition is
true (x i ≤ c i ), s f is the set of data records on another child node
for which the split condition is false (x i > c i ), and Ns represents
the number of data records in set s.

ear regression with a complexity penalty on the weight parameters.
