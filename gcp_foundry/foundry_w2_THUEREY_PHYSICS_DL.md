<THINK_TRACE>

The causal chain that produces Thuerey's research program is unusually legible, and it runs backwards from a single structural frustration: **the forward simulator is a scientific instrument, and the learning system wants to treat it as a black box.** Almost every primitive in this dossier is a different way of resolving that tension.

Hop one. Physically-based fluid animation is historically a *real-time* discipline. Real-time means the temporal discretization is chosen by a frame budget, not by accuracy. The canonical remedy is to make the timestep cheap rather than small — operator splitting, larger $\Delta t$, and sub-grid models that stand in for unresolved motion. Thuerey's early work sits exactly here: lattice-Boltzmann methods for interactive liquids, smoothed-particle and mesh-based liquid animation, and procedural "wavelet turbulence" style detail synthesis (Erlangen, then the ETH Zurich / Disney Research Zurich orbit). The intellectual residue of that period is a durable instinct: **if you cannot afford to resolve a scale, you must model it, and a model that is merely plausible is not the same as a model that is dynamically consistent.** That instinct is the entire reason his later machine-learning work is not generic surrogate modeling.

Hop two. The lattice-Boltzmann detour matters more than it looks. LBM is a *kinetic* method: you evolve a distribution function $f_i(\mathbf{x},t)$ over discrete velocities $\mathbf{c}_i$ and recover macroscopic moments,
$$\rho = \sum_i f_i, \qquad \rho \mathbf{u} = \sum_i f_i \mathbf{c}_i,$$
with the Navier–Stokes equations recovered only in the Chapman–Enskog limit, i.e. to $O(\mathrm{Ma}^2)$ in the Mach number $\mathrm{Ma} = u/c_s$ (dimensionless). Anyone who has debugged an LBM code has internalized a specific lesson: **the discrete scheme has its own physics, and that physics is not the continuum physics.** This is precisely the lesson that resurfaces, a decade later, as the argument for training turbulence closures *inside* the solver rather than against a continuum ground truth.

Hop three. Graphics and scientific computing converge on the same object from opposite ends. Graphics wants a fast approximate $\mathcal{A}_\theta$ such that $\mathcal{A}_\theta \approx \mathcal{S}_{\Delta t}$ where $\mathcal{S}$ is a numerical solver. Science wants $\mathcal{S}$ itself to be right. The differentiable-physics program fuses them: write $\mathcal{S}$ in an autodiff framework (PhiFlow, built by Philipp Holl with Thuerey, is the concrete artifact), and then $\theta$ can be optimized by *any* objective that touches the solver's output — including objectives that no dataset contains.

Hop four, and this is the actual frontier primitive. Once $\mathcal{S}$ is differentiable, the training signal is no longer "match this reference field." It becomes "produce a trajectory whose *statistics* are correct," or "produce a trajectory that conserves momentum," or "choose a control $\mathbf{f}(\mathbf{x},t)$ that minimizes a downstream cost." The loss function acquires physical units and the gradient acquires an adjoint interpretation. This is the move from curve-fitting to **inverse-problem solving with a verified forward operator.**

Hop five, the turbulence application, which is where the program becomes sharp rather than merely elegant. Classical turbulence closure (Smagorinsky, dynamic Smagorinsky, WALE) is calibrated *a priori*: you fit the model coefficient against filtered DNS fields, correlation by correlation. The known pathology is the a priori/a posteriori gap — a closure can correlate beautifully with the true sub-grid stress and still blow up or mispredict spectra when actually run inside the solver, because the errors compound dynamically. The differentiable-solver line attacks this directly: put the neural closure inside the loop, backpropagate through $k$ solver steps, and let the loss be a *posteriori* quantity (the JFM paper on learned turbulence modelling with differentiable fluid solvers, List, Chen and Thuerey, is the reference point; I recall it as JFM 2024, verify). The companion finding is that the useful **optimization horizon** is finite and set by the flow's own decorrelation time, not by "as long as possible."

Hop six, the probabilistic turn. If the horizon is finite and the system is chaotic, then a deterministic long rollout is the wrong object. The later work couples generative models (diffusion-style samplers, including a wavelet-domain variant for 3D turbulence) with differentiable-physics consistency terms, so that samples are both diverse and dynamically admissible. This is the honest response to a positive Lyapunov exponent: stop predicting the state, start predicting the measure.

The synthesis: Thuerey's primitives are not "add a physics loss." They are **(i) a unit-bearing differentiable forward operator, (ii) a residual or conservation functional defined on that operator's output, and (iii) an adjoint-derived gradient whose validity horizon is a physical quantity you can compute in advance.** Everything else in this dossier is a corollary.

## SOVEREIGN FRONTIER PRIMITIVES

**P1 — Solver-as-loss (differentiable physics).** Write the discrete update as $\mathbf{u}^{n+1} = \mathcal{S}_{\Delta t}(\mathbf{u}^n; \theta)$ and embed it in an autodiff graph. Objective $J$ may be a control cost, a statistical mismatch, or a terminal observation. Units of $\nabla_\theta J$ follow from $J$; if $J$ is a mean-squared velocity error, $[\nabla_\theta J] = \mathrm{m^2\,s^{-2}}$ per unit of $\theta$. *Assumption:* every operator in $\mathcal{S}$ is differentiable a.e. *Breakdown:* memory grows as $O(N_{\text{steps}} \times N_{\text{DOF}})$ unless checkpointed; see S2.

**P2 — Physical residual constraint (soft).** For incompressible Navier–Stokes,
$$\mathbf{R}(\mathbf{u},p) \;=\; \partial_t \mathbf{u} + (\mathbf{u}\cdot\nabla)\mathbf{u} + \tfrac{1}{\rho}\nabla p - \nu \nabla^2 \mathbf{u} - \mathbf{f}, \qquad \nabla\cdot\mathbf{u}=0,$$
with $[\mathbf{R}] = \mathrm{m\,s^{-2}}$, $[\nu] = \mathrm{m^2\,s^{-1}}$, $[p/\rho] = \mathrm{m^2\,s^{-2}}$. Loss $\mathcal{L}_{\text{res}} = \frac{1}{|\Omega|}\int_\Omega \|\mathbf{R}\|_2^2 \, \mathrm{d}V$ has units $\mathrm{m^2\,s^{-4}}$. *Assumption:* strong form holds pointwise (continuum, Newtonian, isothermal). *Breakdown:* spectral bias of MLPs against high-wavenumber content; residual weighting is a non-dimensionalized conditioning problem, and $\mathcal{L}_{\text{res}}$ and $\mathcal{L}_{\text{data}}$ generally have incommensurate units, so any weighted sum is unit-dependent unless explicitly nondimensionalized by $u_{\text{rms}}$ and $L$.

**P3 — Conservation by construction (hard).** Rather than penalize, architect the invariant. For particle discretizations, enforce $\sum_i m_i \Delta \mathbf{v}_i = \mathbf{0}$ for internal interactions, units $\mathrm{kg\,m\,s^{-1}}$; the "Guaranteed Conservation of Momentum for Learning Particle-based Fluid Dynamics" line (Prantl, Um, Xu, Thuerey, NeurIPS 2022, verify) does this by antisymmetric/equivariant layer construction, and the EnergyGuided line does the analogue for an energy functional $[\mathrm{J}]$. *Breakdown:* if the *reference solver* is itself dissipative (S6), a hard conservation constraint fights the data and you have simply moved the error.

**P4 — Adjoint sensitivity.** The continuous adjoint of $J$ with respect to the incompressible NS operator, for terminal-cost $J = \int_\Omega j(\mathbf{u}(T))\,\mathrm{d}V$, is
$$-\partial_t \boldsymbol{\lambda} - (\nabla \mathbf{u})^{\mathsf{T}}\boldsymbol{\lambda} + (\mathbf{u}\cdot\nabla)\boldsymbol{\lambda} - \nu\nabla^2\boldsymbol{\lambda} + \nabla \mu = \mathbf{0}, \qquad \nabla\cdot\boldsymbol{\lambda}=0, \qquad \boldsymbol{\lambda}(T) = \partial j/\partial \mathbf{u}\big|_T,$$
with $[\boldsymbol{\lambda}] = [\partial J/\partial \mathbf{u}] = \mathrm{J\,s\,m^{-1}} = \mathrm{kg\,m\,s^{-1}}$. The discrete adjoint is the exact transpose of the Jacobian, $\bar{\mathbf{u}} = \left(\partial \mathcal{S}/\partial \mathbf{u}\right)^{\mathsf{T}} \boldsymbol{\lambda}$ — which is what reverse-mode autodiff through the solver computes, to floating-point accuracy, *for the discrete scheme*. *Assumption:* the discrete adjoint is the transpose of the discrete tangent, not a discretization of the continuous adjoint; these differ by $O(\Delta t^p, \Delta x^q)$ and the difference is not cosmetic at long horizons.

**P5 — A posteriori / in-the-loop training.** Optimize $\theta$ against $\mathcal{L} = d\big(\mathcal{M}(\mathcal{S}^k_{\theta}), \mathcal{M}(\text{DNS})\big)$ where $\mathcal{M}$ extracts statistics (spectrum $E(k)$ in $\mathrm{m^3\,s^{-2}}$, structure functions $S_p(r)$ in $\mathrm{m^p\,s^{-p}}$, dissipation $\varepsilon$ in $\mathrm{m^2\,s^{-3}}$) and $k$ is the unroll length. *Breakdown:* $k$ beyond the decorrelation time injects gradient noise faster than it injects signal (S2).

**P6 — Probabilistic closure.** Learn $p_\theta(\mathbf{u})$ and use differentiable physics as a consistency/regularization term rather than a point predictor. Information units: KL in nats, $\mathrm{D}_{\mathrm{KL}}(p\|q) = \int p \log(p/q)\,\mathrm{d}\mathbf{u}$.

**P7 — Neural flow maps / operator surrogates.** Learn $\tilde{\mathcal{S}}_{\Delta t}$ directly (including on meshes and via neural flow maps, Prantl/Xu/Thuerey and Wandel/Weinmann/Thuerey lines). Cheapest per step, weakest dynamic guarantee; the correct use is inside a differentiable loop, not as a replacement for one.

<RETROCAUSAL_GENEALOGY>

**Coaching-tree DNA (academic lineage).** Graphics-first, not optimization-first. The Erlangen/ETH/Disney Research fluid-animation lineage contributes: (a) comfort with aggressive operator splitting and large $\Delta t$; (b) comfort with sub-grid *procedural* detail models; (c) a validation culture built on visual plausibility plus energy spectra, not on held-out MSE. The TUM phase converts that culture into a scientific one by adding the adjoint. The single most predictive fact about this program is that its author spent years building simulators whose *discretization error was the product* before he ever trained a network.

**Historical situational scars.** Three are load-bearing.
1. *The surrogate hangover (roughly 2017–2020).* Feed-forward learned accelerations of Eulerian solvers looked excellent at short horizons and degraded silently at long ones. The scar is a permanent suspicion of one-step MSE as a validation metric.
2. *The PINN correction.* Physics-informed neural networks were oversold for high-Reynolds-number turbulence; the spectral-bias and conditioning problems are real, and the field's retreat toward solver-in-the-loop training is a direct consequence. Thuerey's group published explicit PINN-for-fluids diagnostics (Wandel/Weinmann/Thuerey, "Teaching Fluid Flows to Physics-Informed Neural Networks," and related) that read as scar tissue.
3. *The a priori/a posteriori gap.* Decades of classical closure calibration established that correlation-with-truth does not imply stability-in-the-loop. Differentiable solvers are the first tool that makes the a posteriori objective cheap enough to optimize directly.

**Multi-week tape traps.** The field's benchmark tapes are systematically too kind: low $Re$, short horizons, periodic boxes, and — critically — reference data generated by the *same* discretization the model will run in. A model can therefore look vindicated while having learned the truncation error of a specific scheme. This is the scientific form of "he only looks good against that coverage."

**Scientific proof barriers.** Two, and they are hard.
- *Global regularity of 3D incompressible Navier–Stokes is open* (a Clay Millennium Problem). Leray–Hopf weak solutions exist; uniqueness and smoothness are not established. Consequence: any claim that a learned model "satisfies the physics exactly" is conditional on a solution existing and being smooth on the interval considered. Residual-based losses are therefore *consistency* statements, not *correctness* proofs.
- *Discrete conservation is scheme-relative.* Continuum invariants (energy, helicity, momentum) are not automatically invariants of a finite-volume or SPH discretization. Enforcing them by construction is only meaningful relative to a stated discrete conservation law.

</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>

Model the training episode as a three-agent recursion under existential pressure (i.e., the loss is about to plateau or diverge).

**Agent A — the optimizer's 100-rep comfort call.** Under pressure, gradient descent retreats to the highest-curvature-negative, lowest-variance direction available: fit the mean, suppress the tails. In turbulence terms, the model reproduces $E(k)$ at low $k$ (where the energy is, and where the gradient is large) and quietly abandons the dissipative range. *Tell:* validation loss improves while $\varepsilon$ and $S_3(r)$ (units $\mathrm{m^3\,s^{-3}}$) drift. The comfort call is not laziness; it is the mathematically cheapest descent direction given the loss's unit weighting.

**Agent B — the discretization's tendency bait.** The solver's truncation error is a *free* correlation the model can exploit. If the reference and the rollout share a scheme, the network can reduce training loss by learning the scheme's error rather than the flow's dynamics. This is genuine co-adaptation, and it is invisible to any in-distribution validation. *Tell:* performance collapses on a change of $\Delta x$ or of advection scheme (e.g., switching from a low-order upwind flux to a higher-order one), with no change in $Re$.

**Agent C — the internal clock.** Every explicit scheme has a stability ceiling, and every flow has a decorrelation time. The CFL condition (S1) is the solver's hard clock; the Lyapunov time $\Lambda^{-1}$ is the information's soft clock. A model's usable optimization horizon is $H \approx \min(\text{CFL-limited stable window},\ c\,\Lambda^{-1})$. Asking for gradients beyond $H$ is asking the QB to hold the ball past the pocket's collapse: the mechanics do not degrade gracefully, they invert.

**Crisis regression.** Under distribution shift (higher $Re$, different geometry), all three agents regress simultaneously: the optimizer reverts to the mean, the model reverts to exploiting whatever discretization it was trained on, and the effective horizon shrinks because $\Lambda$ grows. The failure is therefore *not* a smooth degradation in MSE; it is a change of regime. This is why single-number validation is structurally inadequate here and why the veto layer below is not optional.

</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>

Each condition below vetoes a naive statistical expected-value argument ("this architecture has lower held-out error, therefore deploy it").

**S1 — CFL / diffusive stability ceiling.** For explicit advection–diffusion,
$$\Delta t \;\le\; C_{\text{cfl}} \min_k \frac{\Delta x_k}{\max |\mathbf{u}\cdot \mathbf{e}_k|}, \qquad \Delta t \;\le\; \frac{\Delta x^2}{2 d \nu},$$
with $C_{\text{cfl}} \in (0,1]$ dimensionless, $d$ the number of spatial dimensions, $[\Delta t] = \mathrm{s}$. *Veto:* a learned surrogate with lower MSE but an inference-time $\Delta t$ above this bound is not a faster solver, it is a different (unstable) dynamical system. *Breakdown of the bound itself:* it is sufficient, not necessary; implicit and semi-Lagrangian schemes evade it and reintroduce numerical dissipation instead (S6).

**S2 — Adjoint chaos / Lyapunov horizon.** For a perturbation $\delta \mathbf{u}$,
$$\|\delta \mathbf{u}(t)\| \;\approx\; \|\delta \mathbf{u}(0)\| \, e^{\Lambda t}, \qquad [\Lambda] = \mathrm{s^{-1}},$$
and the usable gradient horizon satisfies $\Lambda H \lesssim \ln(\mathrm{SNR}_{\text{grad}})$. In 3D turbulence $\Lambda = \Theta(1/\tau_\eta)$ with the Kolmogorov time $\tau_\eta = (\nu/\varepsilon)^{1/2}$ in seconds. *Veto:* any claim that "longer unrolls give better gradients" is false past $H$; gradient norm grows like $e^{\Lambda t}$ while its cosine with the true descent direction decays. This is the single most important veto in the dossier, and it is the one that the differentiable-physics literature had to discover empirically.

**S3 — Resolution / degrees-of-freedom wall.** With $\eta = (\nu^3/\varepsilon)^{1/4}$ in metres and $Re_L = u'L/\nu$ dimensionless,
$$N_{\text{DOF}} \sim Re_L^{9/4}, \qquad N_{\text{steps}} \sim Re_L^{3/4}, \qquad W \sim Re_L^{3}.$$
*Veto:* an adjoint-based method's memory cost is $O(N_{\text{steps}} N_{\text{DOF}})$ without checkpointing, so the wall arrives as an $Re^{9/4}$ memory event, not a compute event. Any EV calculation that budgets FLOPs but not activation memory is wrong by orders of magnitude.

**S4 — Non-differentiability / measure-zero traps.** Limiters, clamps, $\mathrm{max}(\cdot,\cdot)$, sign functions, level-set reinitialization, and topology changes (splash generation, interface breakup) have undefined or zero a.e. derivatives. Autodiff returns *some* subgradient, and the chain rule across a measure-zero switching set is not valid. *Veto:* a model trained through a topology-changing operator has a gradient that is silently wrong precisely at the events that dominate the loss.

**S5 — Ill-posedness of the inverse problem.** Hadamard well-posedness requires existence, uniqueness, and continuous dependence. Recovering $\mathbf{u}(0)$ from $\mathbf{u}(T)$ has singular values decaying like $\sigma_{\min}(J) \sim e^{-\Lambda T}$. *Veto:* in the information layer, the required channel capacity scales as $\log_2 \mathrm{DOF} \approx \tfrac{9}{4}\log_2 Re_L$ bits per field, so any architecture whose effective precision is fixed will fail at a predictable $Re$, independent of training quality.

**S6 — Numerical dissipation masquerading as physics.** For a first-order upwind advection discretization the implicit viscosity is
$$\nu_{\text{num}} \;\approx\; \tfrac{1}{2}\,|\mathbf{u}|\,\Delta x\,(1 - C_{\text{cfl}}), \qquad [\nu_{\text{num}}] = \mathrm{m^2\,s^{-1}},$$
so $\nu_{\text{num}}/\nu \sim \tfrac{1}{2} Re_{\Delta x}(1-C_{\text{cfl}})$ with $Re_{\Delta x} = |\mathbf{u}|\Delta x/\nu$. *Veto:* at $Re_{\Delta x} \gtrsim 2$, the scheme's dissipation dominates the physical dissipation, and a model trained a posteriori inside that scheme has learned a different viscosity. Conservation-by-construction (P3) then conflicts with the data rather than rescuing it.

**S7 — Spectral bias.** For ReLU MLPs the neural tangent kernel's eigenvalue spectrum decays with target frequency, so fitting content at wavenumber $k$ requires capacity growing polynomially-to-exponentially in $k$. *Veto:* a residual loss dominated by high-$k$ content will underfit regardless of data volume; Fourier-feature or multi-resolution encodings are a precondition, not a hyperparameter.

**S8 — Reynolds extrapolation.** A closure trained at $Re_1$ and deployed at $Re_2 > Re_1$ faces a distribution shift whose magnitude scales with the inertial-range mismatch $\int |E_{12}(k) - E_{22}(k)|\,\mathrm{d}k$ in $\mathrm{m^3\,s^{-2}}$. *Veto:* in-distribution validation at $Re_1$ carries essentially zero information about $Re_2$.

**Adjudication rule.** Deploy only if the candidate passes S1 (stable $\Delta t$), S2 ($H < \Lambda^{-1}\ln \mathrm{SNR}$), S4 (no gradient path through a switching set that carries loss mass), and S6 ($\nu_{\text{num}} \ll \nu$). Failing any one vetoes the MSE argument outright, irrespective of how good the MSE is.

*Setup.* 2D or 3D decaying turbulence, $Re_\lambda$ moderate; agent chooses a body force $\mathbf{f}(\mathbf{x},t)$; reward is verifiable: (a) target dissipation $\varepsilon$ within tolerance, (b) energy spectrum slope in the inertial range, (c) no NaNs.
*Surface model.* Reward the one-step field match. It climbs fast, then plateaus.
*Veto reasoning.* The gradient of a $k$-step objective has norm $\sim e^{\Lambda k}$; past $k \approx \Lambda^{-1}\ln \mathrm{SNR}$ the reward signal is dominated by noise. The fix is not more data — it is a shorter horizon plus a statistical (not pointwise) objective, i.e., P5 with $k$ chosen from $\tau_\eta$.
*Falsifiable prediction.* In a controlled comparison at matched compute, the one-step-reward agent's validation $\varepsilon$-error plateaus within a few percent of its 200-update value, while the $\tau_\eta$-horizon agent continues improving monotonically through 2,000 updates. If the one-step agent matches the horizon agent at 2,000 updates, this veto is wrong.

**Veto 2 — The conservation reward (S6 + P3).**
*Setup.* Particle-based fluid; verifiable reward is exact momentum conservation, checked as $\|\sum_i m_i \mathbf{v}_i(t) - \sum_i m_i \mathbf{v}_i(0)\| < 10^{-10}\,\mathrm{kg\,m\,s^{-1}}$.
*Surface model.* Add a soft penalty $\lambda \|\Delta \mathbf{P}\|^2$. It reduces drift but never reaches machine precision, and $\lambda$ trades directly against data fidelity — with incommensurate units, so the trade is arbitrary.
*Veto reasoning.* A penalty cannot deliver a hard invariant; only an architectural constraint can (antisymmetric interaction layers). And if the reference solver is dissipative at the chosen $\Delta x$ (S6, $Re_{\Delta x} \gtrsim 2$), the hard constraint will fight the data — so the correct experiment changes $\Delta x$ *first*.
*Falsifiable prediction.* The soft-penalty model exhibits momentum drift growing approximately linearly in time with slope $\propto 1/\lambda$; the constrained model holds at round-off. If the soft penalty reaches round-off at any finite $\lambda$, this veto is wrong.

**Veto 3 — The spectrum reward (S7 + S8).**
*Setup.* Super-resolution or closure task; verifiable reward is the compensated energy spectrum $k^{5/3}E(k)$ flat across the inertial range (dimensionless), plus $S_3(r) = -\tfrac{4}{5}\varepsilon r$ (units $\mathrm{m^3\,s^{-3}}$) — an exact Kolmogorov relation, hence verifiable.
*Surface model.* Train a priori against filtered DNS fields; excellent correlation with the true sub-grid stress.
*Veto reasoning.* Two independent vetoes. S7: an MLP without Fourier features cannot represent the high-$k$ content, so the residual loss underfits regardless of data. S8: the a priori correlation does not transfer to a different $Re$ or a different advection scheme, because the model has partially learned the reference scheme's $\nu_{\text{num}}$.
*Falsifiable prediction.* The a priori model shows high stress correlation but a $k^{5/3}E(k)$ that rolls off early and an $S_3$ magnitude off by tens of percent; the a posteriori model with Fourier features matches both. Crucially, re-running the a priori model under a *different* $\Delta x$ at fixed $Re$ should degrade it sharply, while the a posteriori model degrades gracefully. If the a priori model is $\Delta x$-invariant, S6 is not binding in that configuration and the veto is wrong.

**Cross-cutting falsifiable claim.** For all three: the failure mode is a *regime change*, not a slope change. Plot error against training compute on log-log axes; the vetoed models should show a knee, the veto-respecting models a straight line. A knee is the empirical signature of a cross-layer singularity, and its absence would falsify the entire adjudication framework above.
