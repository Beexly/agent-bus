The core technical problem in US 8,938,463 B1 is that implicit user feedback—clicks, dwell, and selection records—does not measure document relevance in isolation; it measures relevance entangled with presentation bias. The patent explicitly states that a first implicit user feedback model obtains "a measure of relevance for the document result independent of a context of the search query," while a second obtains "a measure of presentation bias for the document result independent of a context of the search query" [PAGE 4]. A third model then produces "an additional signal ... correspond[ing] to an aspect of document relevance independent of the context of the search query" [PAGE 4]. This is a multi-hop causal separation problem: the system must infer an unobserved relevance variable from an observed selection variable that is a function of both relevance and exposure.

The derivation proceeds as follows. The computer-implemented method receives "multiple features, including a first feature indicative of presentation bias that affects document result selection ... and a second feature indicative of relevance for a second document result returned along with a first document result within a context of a search query" [PAGE 5]. It obtains "information regarding document result selections ... including selection of the first document result" [PAGE 5], then generates "a prior model ... representing a probability of document result selection given values of the multiple features" [PAGE 5]. This prior is output to a ranking engine "to reduce influence of the presentation bias" [PAGE 5]. The receiving step can involve "a first set of features including the first feature and a second set of features including the second feature," with "the second set of features being a proper subset of the first set of features" [PAGE 5]. This subset relation is a gray-zone hazard: if relevance features are nested inside bias features, the linear or log-linear component assigned to relevance may be partially absorbed by the bias component, making the two effects statistically non-identifiable without strong structural assumptions.

Another gray zone is the log-reduction step: "identifying, based on frequency of document result selection, a reduced set of document result selection records from one or more logs ... and collecting the information ... from the reduced set" [PAGE 5]. Frequency-based truncation conditions the estimation sample on observed popularity, which induces truncation bias: documents with few selections are systematically excluded, so the prior model learns from a selected subset of the population rather than the full document space. The patent anticipates this by saying the prior model "can be used to estimate what the implicit feedback should be for results that are too infrequent, or too recent to have sufficient historical records" [PAGE 5], but such estimation is extrapolation under high posterior variance. The breakdown regime is therefore threefold: (1) perfect confounding between position and relevance destroys identifiability; (2) zero-frequency documents collapse to the prior mean with vanishing information gain; (3) frequency-thresholded logs bias the prior toward head items and away from the tail. Any ranking engine consuming this prior must detect these regimes and veto updates rather than silently propagating a mis-specified separation of relevance and bias.

The prior model is a conditional probability:
\[
\pi(d; \theta) \;=\; \Pr(C_{d,q,p}=1 \mid X_d; \theta), \qquad \pi \in [0,1] \text{ (dimensionless probability).}
\]
The patent describes this as "a prior model representing a probability of document result selection given values of the multiple features" [PAGE 5].

A formal separability assumption, implied by the independent relevance and independent bias models [PAGE 4], is a log-odds decomposition:
\[
\operatorname{logit}\!\bigl(\Pr(C_{d,q,p}=1 \mid d,q,p)\bigr)
\;=\; \lambda \cdot \operatorname{rel}(d,q) \;+\; \beta \cdot \operatorname{bias}(d,p) \;+\; \varepsilon_{d,q,p},
\]
where \(\operatorname{rel}(d,q) \in \mathbb{R}\) is the relevance measure independent of query-context selection noise, \(\operatorname{bias}(d,p) \in \mathbb{R}\) is the presentation-bias measure independent of query context, \(\lambda, \beta \in \mathbb{R}\) are coefficients, and \(\varepsilon\) is zero-mean noise. The units of the left-hand side and of \(\lambda \cdot \operatorname{rel}\) and \(\beta \cdot \operatorname{bias}\) are log-odds (dimensionless). Information-theoretic quantities such as log-likelihood are measured in nats; mutual information between features and selections in bits.

Normalization of a separate implicit feedback model \(M_{\text{implicit}}\) uses the prior:
\[
\widetilde{F}(d) \;=\; F_{\text{implicit}}(d) \;-\; \log \pi(d; \theta)
\quad\text{or}\quad
\widetilde{F}(d) \;=\; \frac{F_{\text{implicit}}(d)}{\pi(d; \theta)},
\]
producing a dimensionless residual or normalized feedback signal, consistent with the patent's statement that the prior model "can be used to normalize the output of a separate implicit user feedback model in view of the effects of presentation bias" [PAGE 5].

Singularity and breakdown regimes:
1. **Identifiability singularity**: if \(\operatorname{bias}(d,p) = g(\operatorname{rel}(d,q))\) almost surely (e.g., relevant documents are always placed at top positions), the design matrix for \([\lambda, \beta]\) is rank-deficient and \(\lambda,\beta\) are not separately identifiable.
2. **Cold-start / zero-frequency**: if selection count \(N_d = 0\) over the observation window, the Fisher information for document-specific parameters vanishes and the posterior collapses to the prior mean; estimate variance diverges.
3. **Truncation bias from log reduction**: conditioning on \(N_d > \tau\) yields \(\mathbb{E}[C \mid N_d > \tau] \neq \mathbb{E}[C]\), biasing \(\pi\) toward frequently selected head documents [PAGE 5].

Multi-week traps arise from temporal dynamics not fully bounded in the excerpt. User selection distributions exhibit weekly seasonality (e.g., weekday vs. weekend intent) and query-distribution drift. A prior model built on historical logs therefore becomes stale over a multi-week horizon unless refreshed. More perniciously, the ranking engine creates a feedback loop: changing the rank alters presentation position \(p\), which alters exposure and hence observed selections \(C\), which then updates the prior \(\pi\). Over weeks, this self-referential loop can entrench initial bias: documents that were ranked highly because of bias receive more clicks, reinforcing the bias signal in the next prior. The patent's use of relevance and bias measures "independent of the context of the search query" [PAGE 4] is an attempt to break this loop, but if the clock of prior-refresh is slower than the drift rate of user behavior, the model regresses toward a historical distribution that no longer represents current intent. A multi-week trap is thus defined as the interval between prior-model updates exceeding the characteristic time scale of user-behavior drift, causing the rank modifier to optimize against a stale counterfactual.

<RECURSIVE_THEORY_OF_MIND>
The ranking engine implements a recursive theory of mind: it maintains a probabilistic model of how a user will select results given a ranking, and it updates that model based on observed selections. Under normal operation, the engine assumes users select documents according to the decomposed relevance-plus-bias generative process [PAGE 4]. Under crisis conditions—sparse logs, new documents, or abrupt shifts in query intent—the engine's confidence in its user model collapses. The patent's remedy is regression to the prior: "a prior model can be used to estimate what the implicit feedback should be for results that are too infrequent, or too recent to have sufficient historical records" [PAGE 5]. This crisis habit regression means the system stops trusting document-specific implicit feedback and falls back to the background probability of selection derived from presentation-bias features.

The counter-trap is the risk that the engine mistakes systematic bias for stable user preference. If users habitually click the top result regardless of content, an uncorrected implicit-feedback model would regress to selecting that document forever, treating position bias as intrinsic relevance. The patent counters this by maintaining a second implicit user feedback model that explicitly measures "presentation bias ... independent of the context of the search query" [PAGE 4], and by normalizing the primary feedback model against the prior [PAGE 5]. The recursive theory of mind must therefore distinguish (i) the user's true relevance preference, (ii) the user's position-dependent clicking habit, and (iii) the engine's own belief about both. The clock governing this recursion is the log-collection and prior-update interval; if the clock is too slow, the engine's belief lags reality, and if too fast, noise is mistaken for signal. Crisis habit regression, counter-trap avoidance, and clock synchronization form a closed control loop around the prior model.
</RECURSIVE_THEORY_OF_MIND>
