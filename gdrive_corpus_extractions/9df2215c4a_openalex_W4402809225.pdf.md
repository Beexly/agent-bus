The source defines a task hierarchy that is not merely a taxonomy but a sequence of increasing latent-variable commitments. First, action classification asks for a single label from a video clip. The source states: “Action classification is a task that takes a video clip as input and generates the best class that describes the actions in the video” [PAGE 3]. Formally, this commits the system to estimating a posterior distribution over a discrete action space, without explicitly estimating when the action occurs or where it occurs. Second, action temporal localisation adds onset and offset estimation. The source says: “This task requires a higher level of understanding of actions, as it needs to be capable of determining the beginning and end point of actions” [PAGE 3]. This adds temporal latent variables measured in seconds. Third, action spatio-temporal localisation adds spatial attribution, because the source says it “uses a bounding box to highlight the area where an action may be happening in a given video frame” [PAGE 3]. This adds spatial latent variables measured in pixels or normalized image coordinates. The resulting derivation chain is therefore: from label-only inference, to interval inference, to interval-plus-actor inference. In information terms, each stage adds conditional uncertainty that must be reduced by the visual signal.

The source also establishes that team sports make this hierarchy harder because the visual environment is not a single stable camera view. It says team sports “are typically performed in fast-moving visual environments involving many moving people, objects and changing cameras” [PAGE 2]. This is a gray-zone audit point: a formal model must distinguish between a single-clip classification assumption and the realities of broadcast video. Broadcast football, basketball, and Australian rules football contain cuts, zoom changes, occlusions, and changing viewpoints. The source explicitly says: “broadcast video is shot using several cameras around the court” [PAGE 30]. It also says: “any HAR system should be able to track continuous action in non-continuous frame sequences” [PAGE 30]. This creates a formal discontinuity problem: the observation stream is piecewise continuous, while the action may be semantically continuous across shot boundaries.

A second gray zone is relationality. Team-sport actions often cannot be verified from a single actor. The source gives the example that a pass is completed “only if another player on the same team has received/caught the ball” [PAGE 30]. Therefore, a purely actor-centric model is under-specified for relational actions. A formal system must represent at least three entities: passer, receiver, and ball. If any one is unobservable because of occlusion, camera distance, or poor visibility, the posterior for the relational action becomes broad. This is why the source emphasizes “longer-term temporal tracking capability, strong video understanding ability, and multiple object tracking and position capability” [PAGE 30].

A third gray zone is temporal resolution. The source notes that some sports actions are extremely brief: “the action of having interaction between the foot and the ball, which is typically very short” [PAGE 39]. If the frame rate is too low relative to the action duration, the action can be undersampled. This is not a modeling preference; it is an observability constraint. If an action lasts shorter than the inter-frame interval, the system cannot reliably observe the action’s onset, duration, or offset. The source also notes that “when the camera is shooting from afar, the ball is hard to see and detect in a given frame, as it might become only a few pixels in a given frame” [PAGE 39]. This is another physical observability constraint: small object size reduces signal energy and increases detection variance.

A fourth gray zone is label ambiguity. The source says manual annotation is “laborious and inefficient” [PAGE 38], and that “in some cases, it is hard to define the start and ending points for actions” [PAGE 29]. This means temporal localisation labels themselves are uncertain. If the ground-truth boundary is fuzzy, a model can be penalized not because it failed to recognize the action but because the action’s semantic boundary is not sharply defined. The same applies to overlapping actions. In team sports, multiple actions can occur simultaneously: dribbling while scanning, passing while moving, shooting while contested. A single-label clip classifier cannot represent this without collapsing distinct events into one dominant class.

A fifth gray zone is distribution shift caused by camera motion and viewpoint changes. The source says: “The changes in lighting/illumination conditions, occlusion, viewpoint changes, and camera movement bring additional challenges to this task” [PAGE 6]. It also says: “The changes in viewpoints result in disjointed tracking of players and the ball” [PAGE 40]. This breaks the assumption that appearance features are stationary across time. A model trained on close-up views may fail on far-away views, and a model trained on one broadcast style may fail on another. The source notes that pre-trained models are attractive because of “great generalisation potential” [PAGE 7], but that does not guarantee domain-specific robustness. Team-sport actions remain vulnerable to camera-induced distribution shift.

The audit therefore yields a conservative architecture: the system should not assume a single stable camera, a single actor, or sharply defined temporal boundaries. It must represent uncertainty over time, space, actor identity, and modality availability. The source supports this conclusion because it repeatedly identifies these failure modes as core challenges rather than minor implementation details.

<SOURCE_OPERATORS_AND_EQUATIONS>
Below are formal operators extracted from the source’s described methods, with SI/information/probability units, assumptions, and breakdown regimes.

1. Video observation operator  
Let a video be  
\[
X = \{I_t\}_{t=1}^{T}, \quad I_t \in \mathbb{R}^{H \times W \times 3},
\]  
where \(H\) is height in pixels, \(W\) is width in pixels, \(T\) is the number of frames, and the sampling rate is \(f_s\) in Hz. If the clip duration is \(D\) seconds, then  
\[
T \approx \lceil f_s D \rceil.
\]  
Units: pixels, frames, seconds.  
Source basis: the source treats video as a sequence of frames containing spatial and temporal information [PAGE 3], and notes that RGB and optical flow are primary modalities [PAGE 3].  
Breakdown regime: if \(f_s\) is too low relative to the action duration, the action is undersampled.

2. Action classification operator  
For action class space \(\mathcal{Y} = \{1,\dots,C\}\), a classifier computes  
\[
p_\theta(y \mid X) = \operatorname{softmax}(f_\theta(X))_y,
\]  
with \(p_\theta(y \mid X) \in [0,1]\) and \(\sum_y p_\theta(y \mid X)=1\).  
The standard cross-entropy objective is  
\[
\mathcal{L}_{\mathrm{CE}}(\theta)
=
-\frac{1}{N}\sum_{i=1}^{N}\log p_\theta(y_i \mid X_i),
\]  
where \(\mathcal{L}_{\mathrm{CE}}\) is measured in nats per sample if the logarithm is natural.  
Source basis: “Action classification is a task that takes a video clip as input and generates the best class that describes the actions in the video” [PAGE 3].  
Assumptions: one dominant action label per clip; label space is exhaustive and mutually exclusive enough for training.  
Breakdown regime: when multiple actions co-occur, when labels are ambiguous, or when tail classes have very few examples, the posterior becomes poorly calibrated. The source notes that “Many datasets have an imbalanced data distribution” [PAGE 38].

3. Temporal localisation operator  
For an untrimmed video, the system predicts action intervals  
\[
\hat{Y} = \{(\hat{y}_k, [\hat{s}_k, \hat{e}_k])\}_{k=1}^{K},
\]  
where \(\hat{s}_k\) and \(\hat{e}_k\) are start and end times in seconds. For a predicted interval \(I=[\hat{s},\hat{e}]\) and ground truth \(I^*=[s^*,e^*]\),  
\[
\mathrm{IoU}(I,I^*) =
\frac{|I \cap I^*|}{|I \cup I^*|},
\]  
which is dimensionless and lies in \([0,1]\). A common localisation surrogate is  
\[
\mathcal{L}_{\mathrm{IoU}} = 1 - \mathrm{IoU}(I,I^*).
\]  
Boundary errors are  
\[
\delta_s = |\hat{s}-s^*|, \qquad \delta_e = |\hat{e}-e^*|,
\]  
with units of seconds.  
Source basis: “This task requires a higher level of understanding of actions, as it needs to be capable of determining the beginning and end point of actions” [PAGE 3].  
Assumptions: temporal boundaries are annotatable; the broadcast timeline is either continuous or shot-aware.  
Breakdown regime: when broadcast cuts interrupt continuity, or when action onset/offset is semantically fuzzy, interval supervision becomes unstable. The source notes that “many sports games are broadcast as a whole (contiguous) video” [PAGE 4], but also that broadcast contains changing cameras [PAGE 2].

4. Spatio-temporal localisation operator  
For each time step \(t\), a normalized bounding box is  
\[
b_t = (x_t, y_t, w_t, h_t),
\]  
where \(x_t/W\), \(y_t/H\), \(w_t/W\), and \(h_t/H\) are dimensionless normalized coordinates. For multi-person scenes, the model must infer an assignment  
\[
a_t: \{1,\dots,M_t\} \to \{1,\dots,M_t\},
\]  
mapping tracked actors to boxes.  
Source basis: the task “uses a bounding box to highlight the area where an action may be happening in a given video frame” [PAGE 3]. The source also notes that MultiSports contains “more than 37k actions have been annotated with 902k bounding boxes” [PAGE 25].  
Assumptions: players and objects are detectable enough to be localized; identity assignment is observable.  
Breakdown regime: occlusion, low resolution, and viewpoint changes make actor assignment ill-posed. The source states that in indoor small-court games “many people and objects overlap, making it hard to distinguish the actions of single or multiple persons” [PAGE 30].

5. Optical-flow constraint operator  
The brightness constancy constraint is  
\[
I_x u + I_y v + I_t = 0,
\]  
where \(I_x\) and \(I_y\) are spatial intensity derivatives, \(I_t\) is the temporal derivative, and \((u,v)\) are optical-flow components. If \(u\) and \(v\) are measured in pixels per frame, then converting to pixels per second requires  
\[
(u_{\mathrm{px/s}},v_{\mathrm{px/s}}) = f_s (u,v).
\]  
Units: intensity derivatives are intensity per pixel, \(I_t\) is intensity per frame, and flow is pixels per frame or pixels per second after conversion.  
Source basis: “optical flows are used to capture the motion of each pixel in a 2D vector field” [PAGE 9].  
Assumptions: brightness constancy, small motion, sufficient texture.  
Breakdown regime: aperture ambiguity, large displacement, motion blur, and occlusion violate the constraint.

6. Histogram of Oriented Gradients operator  
For image intensity \(I(x,y)\), the gradient is  
\[
\nabla I = (I_x, I_y).
\]  
Gradient magnitude and orientation are  
\[
m(x,y) = \|\nabla I(x,y)\|_2,
\qquad
\theta(x,y) = \operatorname{atan2}(I_y, I_x),
\]  
where \(m\) is in intensity units per pixel and \(\theta\) is in radians. A cell histogram is  
\[
h_b = \sum_{(x,y)\in \text{cell}} 
\mathbf{1}\left[\operatorname{bin}(\theta(x,y)) = b\right] m(x,y).
\]  
Local contrast normalization is commonly  
\[
\tilde{h} = \frac{h-\mu}{\sqrt{\sigma^2+\epsilon}},
\]  
where \(\mu\) and \(\sigma^2\) are the mean and variance over a block, and \(\epsilon\) is a small positive constant. The normalized descriptor is dimensionless.  
Source basis: HOG is described as designed for human detection and as “invariant to scale, rotation and translation” [PAGE 9]. The source table also lists HoG as illumination invariant [PAGE 8].  
Assumptions: local gradients carry discriminative appearance information.  
Breakdown regime: subtle actions, severe illumination changes, or very low resolution reduce gradient reliability.

7. Homography and camera-motion estimation operator  
For corresponding image points \(\tilde{x} \leftrightarrow \tilde{x}'\) in homogeneous coordinates, a homography satisfies  
\[
\tilde{x}' \simeq H\tilde{x},
\qquad
H \in \mathbb{R}^{3\times 3},
\]  
with \(H\) defined up to scale. RANSAC estimates \(H\) by maximizing the inlier set  
\[
\mathcal{I}(H) = 
\left\{
i : d\left(x_i', Hx_i\right) < \epsilon
\right\},
\]  
where \(d(\cdot,\cdot)\) is a reprojection distance measured in pixels and \(\epsilon\) is a pixel threshold.  
Source basis: improved dense trajectories estimate camera motion using “corresponding matching points and estimating the homography” and apply RANSAC [PAGE 12]. The source also says that “if too many people are in the frame, this method does not give good performance” [PAGE 12].  
Assumptions: background dominates the motion field; matching points are approximately coplanar or satisfy homography assumptions.  
Breakdown regime: moving foreground dominance, insufficient correspondences, or degenerate point configurations cause RANSAC to fail.

8. Improved dense trajectory operator  
A trajectory is a sequence of tracked points  
\[
\tau_i = \{(x_t^{(i)}, y_t^{(i)})\}_{t=t_0}^{t_0+L},
\]  
where positions are in pixels and \(L\) is the trajectory length in frames. Descriptors such as HOG, HOF, and MBH are computed along \(\tau_i\), encoded into a fixed-length vector, and classified.  
Source basis: improved dense trajectories combine “HoG, HoF, MBH; camera motion estimation to better track human actions and minimise the effect of background variation” [PAGE 8].  
Assumptions: local motion trajectories are informative; camera motion can be compensated.  
Breakdown regime: background clutter, fast motion, and crowded scenes reduce trajectory quality. The source notes that handcrafted methods are “low-level feature extraction method[s]” [PAGE 8].

9. Fisher-vector encoding operator  
For a generative model \(p(X \mid \lambda)\) with parameters \(\lambda\), the Fisher vector is  
\[
G_\lambda(X) = \nabla_\lambda \log p(X \mid \lambda).
\]  
For a Gaussian mixture with means \(\mu_k\), covariances \(\Sigma_k\), and weights \(w_k\), common components are  
\[
G_{\mu_k} =
\frac{1}{\sqrt{w_k}}
\sum_{t=1}^{T}
\gamma_t(k)
\Sigma_k^{-1/2}
(x_t-\mu_k),
\]  
where \(\gamma_t(k)\) is the posterior responsibility of component \(k\) for sample \(x_t\). The final vector is often power-normalized and L2-normalized. Units follow the underlying descriptor; after normalization the vector is dimensionless.  
Source basis: Fisher vector is “obtained from the gradient of the probability density function of the signal’s parameters log-likelihood” [PAGE 13]. It converts variable-length samples into fixed-length vectors [PAGE 13].  
Assumptions: local descriptors are generated from a mixture model; gradients are informative.  
Breakdown regime: the source notes that Fisher vector is “Not good for non-linear separable problem” [PAGE 8].

10. Two-stream convolutional operator  
Let \(f_{\mathrm{spatial}}(I_t)\) process RGB appearance and \(f_{\mathrm{temporal}}(F)\) process optical-flow stacks \(F\). A late-fusion posterior can be written as  
\[
p(y \mid X) =
(1-\lambda) p_{\mathrm{spatial}}(y \mid I_t)
+
\lambda p_{\mathrm{temporal}}(y \mid F),
\]  
with \(\lambda \in [0,1]\) dimensionless.  
Source basis: “The two-stream architecture ... was able to capture both spatial and temporal information with two streams processed separately” [PAGE 14].  
Assumptions: spatial appearance and motion are complementary; optical flow is reliable.  
Breakdown regime: noisy optical flow, camera motion, or occlusion degrade the temporal stream.

11. Recurrent temporal operator  
A generic LSTM cell uses gates to update hidden state:  
\[
c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t,
\]  
\[
h_t = o_t \odot \tanh(c_t),
\]  
where \(f_t, i_t, o_t \in [0,1]\) are forget, input, and output gates. The source notes that RNN architectures suffer because of the “vanishing gradient problem” [PAGE 16]. In a simplified linearized recurrence,  
\[
\frac{\partial h_T}{\partial h_1}
=
\prod_{t=2}^{T} D_t,
\]  
where \(D_t\) is a diagonal Jacobian. If spectral values of \(D_t\) are consistently less than one, the product approaches zero as \(T\) grows. Units: dimensionless gradients; breakdown when long-range dependency information decays exponentially.

12. Self-attention operator  
For query, key, and value matrices \(Q,K,V \in \mathbb{R}^{N \times d_k}\),  
\[
\operatorname{Attention}(Q,K,V)
=
\operatorname{softmax}
\left(
\frac{QK^{T}}{\sqrt{d_k}}
\right)V.
\]  
Here \(N\) is the number of tokens, \(d_k\) is the feature dimension, and the softmax is dimensionless. If tokens are video patches, then  
\[
N = T_p H_p W_p,
\]  
where \(T_p\), \(H_p\), and \(W_p\) are temporal and spatial patch counts. Computational and memory cost scales as \(O(N^2 d_k)\).  
Source basis: the source says the “Transformer” has “Long-range dependencies” but “Computational cost is high” [PAGE 8], and that “The transformer approach would consume a tremendous amount of calculation resources during the training process” [PAGE 18].  
Breakdown regime: when \(N\) becomes large because of long videos or high resolution, memory becomes prohibitive.

13. Masked autoencoding operator  
For masked token indices \(M\) and mask ratio  
\[
\rho = \frac{|M|}{N},
\]  
with \(\rho \in [0,1]\), a masked autoencoder minimizes  
\[
\mathcal{L}_{\mathrm{MAE}}
=
\frac{1}{|M|}
\sum_{i \in M}
\left\|
x_i - \hat{x}_i
\right\|_2^2.
\]  
The loss has units of squared intensity if pixels are unnormalized; after normalization it is dimensionless.  
Source basis: VideoMAE “utilised plain ViT backbones and a high mask ratio to lower the dimensions of inputs” [PAGE 18].  
Assumptions: video has sufficient redundancy for masked reconstruction.  
Breakdown regime: if masking removes too much motion evidence, temporal action features may be lost.

14. Multi-modal fusion operator  
Let modalities be \(X^{(1)}, \dots, X^{(M)}\), for example RGB, optical flow, audio, skeleton, or depth. A fused posterior can be written as  
\[
p\left(y \mid X^{(1)},\dots,X^{(M)}\right).
\]  
Under a conditional-independence assumption,  
\[
p\left(y \mid X^{(1)},\dots,X^{(M)}\right)
\propto
p(y)
\prod_{m=1}^{M}
p\left(X^{(m)} \mid y\right).
\]  
A late-fusion approximation is  
\[
p_{\mathrm{fusion}}(y)
=
\sum_{m=1}^{M}
\alpha_m p_m(y),
\qquad
\alpha_m \ge 0,
\qquad
\sum_m \alpha_m = 1.
\]  
The weights \(\alpha_m\) are dimensionless.  
Source basis: “Multi-modal approaches use two or more modalities of information to model actions” [PAGE 19]. The source also discusses early, intermediate, and late fusion [PAGE 19, PAGE 39].  
Assumptions: modalities are temporally aligned and complementary.  
Breakdown regime: missing modalities, temporal misalignment, or modality conflict degrade fusion. If one modality is absent, the posterior must be renormalized or the fusion collapses.

15. Class-imbalance and information operator  
Let \(N_c\) be the number of training instances for class \(c\), and \(N\) the total number of instances. The empirical class prior is  
\[
\hat{p}_c = \frac{N_c}{N}.
\]  
The class distribution entropy is  
\[
H(\hat{p}) =
-\sum_{c=1}^{C}
\hat{p}_c \log_2 \hat{p}_c,
\]  
measured in bits. If natural logarithms are used, units are nats.  
Source basis: “Many datasets have an imbalanced data distribution” [PAGE 38], and rare events such as a “red card may only have a small number of examples” [PAGE 38].  
Assumptions: class frequencies are estimated reliably.  
Breakdown regime: when \(N_c\) is very small, variance in tail-class risk estimates increases, and decision boundaries become unstable.

16. Temporal sampling constraint  
Let \(\tau_a\) be the duration of a short action, in seconds. A necessary condition for observing at least one frame inside the action is  
\[
f_s \tau_a > 1,
\]  
where \(f_s\) is frame rate in Hz. More generally, to resolve onset and offset with temporal precision \(\delta t\),  
\[
f_s \ge \frac{1}{\delta t}.
\]  
Units: Hz and seconds.  
Source basis: the source says some actions, such as foot-ball interaction, are “typically very short” [PAGE 39].  
Breakdown regime: if \(f_s \tau_a \le 1\), the action may be missed or merged with adjacent frames.

17. Information-bottleneck veto condition  
Let \(Y\) be the action variable and \(X\) the observed video signal. The mutual information is  
\[
I(Y;X) = H(Y) - H(Y \mid X),
\]  
with units bits if logarithms are base 2. If a physical process \(X \mapsto Z\) destroys information, the data-processing inequality gives  
\[
I(Y;Z) \le I(Y;X).
\]  
If occlusion, low resolution, or poor visibility makes \(I(Y;X) \approx 0\), no downstream classifier can reliably infer \(Y\).  
Source basis: the source notes that “when the camera is shooting from afar, the ball ... might become only a few pixels in a given frame” [PAGE 39], and that in poor weather “less information may be recorded due to low visibility” [PAGE 39].  
Assumptions: the action remains semantically defined even when observation is poor.  
Breakdown regime: when observation removes the discriminative signal, the posterior remains close to the prior.

<RETROCAUSAL_GENEALOGY>
The source describes a scientific lineage from handcrafted video features to deep spatiotemporal models. This lineage is not merely chronological; it is a sequence of responses to failure modes. The earliest handcrafted methods derive from image-level descriptors such as HOG, where the source says HOG is “designed to be invariant to scale, rotation and translation” [PAGE 9]. These methods were extended to motion by combining appearance with optical flow, as in HOF and MBH. The source says HOF combines “HoG method with motion-based features” [PAGE 9], while MBH “removes local constant camera motion effects” [PAGE 9]. This lineage assumes that local appearance and local motion are sufficient primitives for action recognition.

The next historical operator is the spatio-temporal interest point. The source explains that the method extends interest points from the spatial domain to the spatio-temporal domain [PAGE 9]. It is useful because it does not require tracking the human body [PAGE 11]. However, the source also notes that interest points are limited when subtle actions produce sparse points [PAGE 10]. This creates a historical trap: systems that rely only on sparse local events fail when the action is small, occluded, or distributed across many actors.

Dense trajectories represent the next corrective step. The source says dense trajectories “densely sample some feature points equally covering all positions and scales in each frame” and track points over a fixed frame length [PAGE 12]. Improved dense trajectories add camera-motion estimation to reduce background variation [PAGE 12]. This is a key genealogical correction: the field learned that camera motion must be explicitly modeled or compensated. The source notes that iDT achieved strong results on UCF50 and HMDB51 [PAGE 12]. But the correction is incomplete in crowded scenes, because the source says “if too many people are in the frame, this method does not give good performance” [PAGE 12].

The deep-learning lineage begins with CNNs. The source says CNNs “Capture spatial information” but need extra design for temporal information [PAGE 8]. The two-stream network is the historical bridge: it processes RGB and optical flow separately and then fuses them. The source states that the two-stream architecture “was able to capture both spatial and temporal information with two streams processed separately” [PAGE 14]. This introduced a durable principle: temporal action recognition requires explicit temporal representation. Later 3D CNNs extend this by using spatiotemporal kernels. The source notes that 3D convolution “Could capture the spatial and temporal information at the same time” but requires optimization because of computational burden [PAGE 8].

Recurrent networks add a second temporal lineage. The source says RNNs “Could capture context information” but suffer from the “vanishing gradient problem” [PAGE 8]. LSTMs and GRUs are historical corrections. The source says LSTM “Could capture long-term temporal information” but is more complex than RNN [PAGE 8]. This lineage is important because it shows that long videos expose memory decay. In team sports, actions can require tracking over multiple seconds and across camera changes. If the temporal model forgets earlier context, relational actions such as passes or sustained offensive sequences become hard to recognize.

The transformer lineage is the next correction. The source says transformers provide “Long-range dependencies” but have high computational cost [PAGE 8]. TimeSformer, MViT, Swin, and VideoMAE are historical responses to the cost and scalability problem. The source says VideoMAE “proposed a highly efficient masked autoencoder” to reduce dependence on additional pre-training data [PAGE 18]. This lineage matters because team-sport video is abundant but labeled action data is scarce. Self-supervised pretraining is a genealogical response to annotation scarcity.

Multi-modal methods form the most recent lineage. The source says multi-modal approaches use “two or more modalities of information to model actions” [PAGE 19]. This includes RGB, depth, skeleton, audio, and sensor signals. The historical motivation is that single-modality video can be noisy. For example, audio can help identify events that are visually occluded, and optical flow can help when RGB appearance is blurred. However, the source also says that “Lack of Suitable Multi-modal Datasets” is a challenge [PAGE 38]. Thus, the lineage is not simply additive; it depends on synchronized data and reliable fusion.

Multi-week research traps follow from this genealogy. First, researchers may overfit to a benchmark dataset and assume that the learned action grammar transfers to another sport. The source says “a specially designed dataset is required when it comes to HAR in sports” [PAGE 29]. Second, researchers may underestimate annotation cost. The source says “Manual annotation work is laborious and inefficient” [PAGE 38]. Third, researchers may assume that broadcast video is stationary, forgetting that “broadcast video is shot using several cameras around the court” [PAGE 30]. Fourth, researchers may ignore tail-class failure. The source gives the example of a red card being rare [PAGE 38]. Fifth, researchers may assume that pre-trained models are domain-ready, although team-sport camera motion and occlusion remain challenging. These traps are multi-week because they appear only after a model is trained, evaluated, and deployed across heterogeneous clips.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
A recursive theory-of-mind analysis treats the research system as a set of agents with beliefs, incentives, and failure habits. The primary agents are: the dataset curator, the model developer, the sports analyst, and the evaluation harness. In a crisis case, such as a new camera angle, adverse weather, or a rare event class, each agent’s beliefs can regress to a habitual shortcut.

Crisis habit regression occurs when the team defaults to the easiest observable signal. For action classification, the habitual shortcut is RGB-only clip classification. This works when actions are visually obvious and the clip is trimmed. The source defines classification as predicting “the best class that describes the actions in the video” [PAGE 3], which implicitly encourages clip-level shortcuts. Under crisis, the developer may assume that a strong RGB classifier is sufficient, even though team sports require tracking and interaction. This regression ignores the source’s warning that team sports involve “many moving people, objects and changing cameras” [PAGE 2].

The counter-trap is the deliberate introduction of formal uncertainty and structural constraints. Instead of assuming a single label, the system models intervals, actors, and relations. Instead of assuming continuous video, the system models shot boundaries and camera motion. Instead of assuming all classes are equally sampled, the system models tail risk. Formally, the developer moves from  
\[
p_\theta(y \mid X)
\]  
to a richer posterior such as  
\[
p_\theta(y, s, e, b_{1:T}, r \mid X),
\]  
where \(s,e\) are temporal boundaries in seconds, \(b_{1:T}\) are boxes in normalized image coordinates, and \(r\) is a relational variable such as passer-receiver-ball relation. The counter-trap is costly because it requires annotation and computation, but it reduces false confidence.

The clock introduces a second recursive pressure. There are three clocks: inference clock, annotation clock, and game semantics clock. The inference clock measures latency in milliseconds or seconds. If a system is intended for real-time analysis, the model must process frames fast enough to be useful. The annotation clock measures how long expert labeling takes. The source says manual annotation is “laborious and inefficient” [PAGE 38]. The game semantics clock measures the true duration and dependency structure of the action. A pass may require waiting for a receiver; a sustained attack may require tracking over several seconds. If the model’s temporal receptive field is shorter than the action’s semantic duration, the model fails even if its per-frame features are good.

A recursive belief update can be expressed as  
\[
P_{t+1}(\theta)
\propto
P_t(\theta)
\exp\left(-\eta \mathcal{L}_t(\theta)\right),
\]  
where \(P_t(\theta)\) is the developer’s belief over model configuration at cycle \(t\), \(\mathcal{L}_t\) is observed validation loss, and \(\eta\) is a learning-rate-like trust parameter. This equation is formal, not metaphorical: it captures how evidence should update beliefs. If evaluation only measures trimmed clip classification, the belief update rewards shortcut features. If evaluation measures temporal boundary error, occlusion robustness, and tail-class recall, the belief update rewards structural competence.

The recursive failure mode is that evaluation metrics shape beliefs. If the evaluation harness only reports average accuracy on easy clips, the model developer will optimize for easy clips. The source’s dataset discussion warns that many datasets are constructed for specific problems and have narrow annotation coverage [PAGE 38]. A counter-trap is to evaluate with counterfactual stressors: camera cuts, occlusion, rare classes, and missing modalities. The clock-based countermeasure is to separate offline accuracy from online reliability. A model can be accurate in an offline benchmark but unusable if it cannot update fast enough during a broadcast or if it requires annotations that cannot be produced within the operational week.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The cross-layer veto framework asks whether physical, biomechanical, weather-related, or sensing constraints make a proposed recognition claim invalid before any model-level tuning can succeed. The core proof uses information theory. Let \(Y\) be the true action and \(X\) the raw observation. If the observation process reduces mutual information to zero, then  
\[
I(Y;X) = 0
\]  
implies that no measurable function of \(X\) can reduce uncertainty about \(Y\). This is a hard veto: model architecture cannot recover information that was never captured.

Physical veto 1: ball invisibility. The source says that when the camera is far away, “the ball is hard to see and detect in a given frame, as it might become only a few pixels in a given frame” [PAGE 39]. If the ball is the essential object for an action such as a kick, pass, or shot, and its projected size falls below the detector’s reliable resolution, then the observation lacks the necessary signal. Formal condition: if the ball’s projected area \(A_{\mathrm{px}}\) is below a threshold \(A_{\mathrm{min}}\), detection probability approaches zero. The units are pixels squared. If \(A_{\mathrm{px}} < A_{\mathrm{min}}\), the action cannot be reliably localized or classified from that view. This is a physical veto, not a model defect.

Physical veto 2: temporal undersampling. The source says some actions, such as foot-ball interaction, are “typically very short” [PAGE 39]. If the action duration is \(\tau_a\) seconds and the frame rate is \(f_s\) Hz, then the expected number of frames observing the action is approximately \(f_s \tau_a\). If  
\[
f_s \tau_a < 1,
\]  
the action may be absent from sampled frames or appear only as an ambiguous transitional blur. This is a hard sensing veto. Units: \(f_s\) in Hz, \(\tau_a\) in seconds, product dimensionless.

Biomechanical veto 3: pose occlusion. Many actions are recognizable only through a kinematic chain: foot-ball contact, arm-shooting posture, torso orientation, or multi-player spacing. If occlusion hides the relevant joints, the posterior over the action remains broad. The source says that in team sports “many people and objects overlap” and that the system must “deal with partially overlapping problems” [PAGE 30]. If the visible evidence is compatible with multiple biomechanical classes, the model cannot uniquely identify the action. This is not merely a classification error; it is an identifiability failure.

Weather veto 4: low visibility. The source says that in poor weather, “rain or snow, the light condition is different and less information may be recorded due to low visibility” [PAGE 39]. Formally, adverse weather reduces contrast and increases noise. Let signal contrast be \(\mu_s\) and noise standard deviation be \(\sigma_n\). A dimensionless contrast-to-noise ratio is  
\[
\mathrm{CNR} = \frac{\mu_s}{\sigma_n}.
\]  
If \(\mathrm{CNR}\) falls below a detector threshold, the probability of reliable detection decreases sharply. If the weather layer reduces \(I(Y;X)\) to near zero, then no temporal model, transformer, or multimodal fusion can restore the missing action evidence. This is a cross-layer veto because the failure occurs before representation learning.

Camera-motion veto 5: homography breakdown. The source says improved dense trajectories use camera-motion estimation, but “if too many people are in the frame, this method does not give good performance” [PAGE 12]. Let \(N_{\mathrm{bg}}\) be background correspondences and \(N_{\mathrm{fg}}\) be moving-foreground correspondences. If  
\[
\frac{N_{\mathrm{fg}}}{N_{\mathrm{bg}} + N_{\mathrm{fg}}}
\]  
is too large, RANSAC homography estimation becomes unstable. Units: dimensionless ratio. If the moving foreground dominates, the estimated homography may model player motion instead of camera motion. The result is invalid camera compensation, causing background stabilization errors and false motion features.

Viewpoint-change veto 6: disjoint tracking. The source says that viewpoint changes “result in disjointed tracking of players and the ball” [PAGE 40]. If the system assumes a single coordinate frame, a cut or zoom creates a discontinuity. Formal condition: if the coordinate transform between shots is unknown, then tracking state \(z_t\) cannot be propagated across the boundary without error. The state transition becomes  
\[
p(z_{t+1} \mid z_t, X_{t+1})
\]  
undefined across an unmodeled shot boundary. This is a physical/broadcast veto because the visual continuity assumption is false.

The adjudication rule is therefore: if a proposed system claims robust team-sport action recognition under broadcast conditions, but the data violate observability constraints such as frame rate, visibility, occlusion, camera-motion estimation validity, or shot continuity, the claim is vetoed. The source supports these vetoes by identifying them as central challenges: “occlusion, viewpoint changes, and camera movement” [PAGE 6], ball visibility [PAGE 39], poor weather [PAGE 39], fast actions [PAGE 39], and multi-person overlap [PAGE 30].
</CROSS_LAYER_VETO_ADJUDICATION>
