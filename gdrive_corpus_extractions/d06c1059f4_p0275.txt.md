Scenario 1: Non-unimodular group intervention.
Counterfactual: Replace the compact abelian group assumption with the ax + b group G = {(a, b) : a > 0, b ∈ ℝ}, left Haar measure dμ(a, b) = da db / a². Let A = [1, 2] × [0, 1] so that μ(A) > 0. Let y = (2, 0) and apply right translation Ay.
Veto condition: The reasoner predicts μ(Ay) = μ(A) using left-invariance alone.
Verifiable prediction: Modular function Δ(a, b) = 1/a. For right translation by y = (2, 0), μ(Ay) = Δ(y) μ(A) = (1/2) μ(A) ≠ μ(A). The reward signal is the discrepancy |μ(Ay) − μ(A)|; if the model outputs equality, it fails the veto. Observation: direct integration of the right-translated set yields a factor of 1/2, falsifying the invariant prediction.

Scenario 2: Null-set measurability intervention.
Counterfactual: Work on ℝ with Lebesgue measure but use a non-complete σ-algebra (e.g., Borel sets only). Let N be a Cantor-like null set containing a non-Borel subset A (exists since |N| = continuum and Borel σ-algebra has cardinality continuum, but subsets of N have cardinality 2^continuum). Let μ(A) be undefined (non-measurable), though A ⊂ N and μ(N) = 0.
Veto condition: The reasoner extends equation (4) to conclude A⁻¹ is measurable because μ(A) = 0, without first verifying that A itself is measurable.
Verifiable prediction: A⁻¹ = −A is also non-Borel (inversion is a homeomorphism, preserving non-Borel status). The model that claims "A⁻¹ measurable since μ(A) = 0" produces a false positive. The reward signal: a set-membership oracle querying whether A⁻¹ ∈ ℬ(ℝ) returns false. Prediction confirmed by cardinality argument: there are 2^continuum subsets of N but only continuum Borel sets.

Scenario 3: Product-measure σ-finiteness intervention.
Counterfactual: Equip G with a non-σ-finite measure ν (constructed, e.g., as an uncountable sum of point masses, though not a Haar measure on a locally compact group; alternatively take a locally compact group with a non-Radon measure). Let A, B have positive ν-measure. The reasoner applies (ν × ν)(A × B⁻¹) = ν(A)ν(B⁻¹) and invokes Theorem C to find x with ν(x⁻¹A ∩ B) > 0.
Veto condition: The product measure is not σ-finite, so Fubini/Tonelli and the factorization (5) may fail or the product σ-algebra may not capture all sections.
Verifiable prediction: There exist A, B with ν(A) > 0, ν(B) > 0 such that (ν × ν)(A × B⁻¹) ≠ ν(A)ν(B⁻¹), or the section x ↦ ν(x⁻¹A ∩ B) is not measurable, so "positive for at least one x" cannot be established. The reward signal: a computational oracle computing sections returns non-measurable or undefined values on a positive-measure set of x. Prediction: Theorem E's conclusion is not derivable; any model asserting the existence of C₁, C₂ under these conditions fails the veto.

All three vetoes are verifiable without reference to betting lines, spreads, totals, moneylines, or odds; they rely on measure computation, set-theoretic cardinality, and σ-finiteness checks.
