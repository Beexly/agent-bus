**1. State Representation & Memory Order:**
Let $A = \{L, R\}$ be the set of possible actions. A sequence is $S = a_1, a_2, \ldots$.
*   **Single Alternation (SA)**: Requires recognizing the pattern $L,R,L,R,\ldots$. This is a Deterministic Finite Automaton (DFA) with 2 states ($q_L, q_R$). Transition function: $\delta(q_L, L) = q_R$, $\delta(q_R, R) = q_L$. Success probability approaches 1 as trials $n \to \infty$.
*   **Double Alternation (DA)**: Requires recognizing $L,L,R,R,L,L,\ldots$. This needs a DFA with 4 states representing position in the cycle: $q_{L1}, q_{L2}, q_{R1}, q_{R2}$. Transitions: $\delta(q_{L1}, L)=q_{L2}$, $\delta(q_{L2}, L)=q_{R1}$, etc. The key is that the same action $L$ leads to different next states depending on the current state.

**2. Temporal Differentiation Operator $\mathcal{D}$:**
Following Tolman's concept of "sign-objects distinguished solely by virtue of their position in a temporally spaced order" [PAGE 1], we define:
$$\mathcal{D}: W_k \rightarrow \Sigma$$
where $W_k = (a_{t-k+1}, \dots, a_t)$ is a window of $k$ past actions, and $\Sigma$ is a set of distinct temporal contexts. For DA, $k=2$ and $\Sigma = \{ \text{"First L"}, \text{"Second L"}, \text{"First R"}, \text{"Second R"} \}$. The output of $\mathcal{D}$ determines the next action.
*   **Unit**: Dimensionless classification label.
*   **Assumption**: The cognitive system can accurately compute and maintain $W_k$.
*   **Breakdown Regime**: When $k$ exceeds working memory capacity (typically $k \approx 4$ for primates, $k \le 2$ for rodents under similar constraints) or when the inter-trial interval exceeds the memory decay time constant $\tau_m$.

**3. Information-Theoretic Measure of Temporal Structure:**
The minimum description length (MDL) principle quantifies complexity. The Kolmogorov complexity of the infinite SA sequence is lower than that of DA. More formally, the entropy rate $H$ of the optimal policy:
For SA, the policy is deterministic given last action, $H_{SA} = 0$ bits/action.
For DA, the policy is deterministic given the last two actions, but an agent remembering only one action faces uncertainty. The mutual information $I(S_{next}; S_{prev})$ is zero for a memory-1 agent facing DA, indicating no usable cue exists at that timescale.

$$\tau \frac{dV}{dt} = -V + \sum_i w_i \delta(t-t_i)$$
