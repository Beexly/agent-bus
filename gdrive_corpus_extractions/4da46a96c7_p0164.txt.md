Tolman’s prose lacks formal notation, but his concepts can be rigorously mapped to information theory and probability spaces. Let us define the operators.

**1. Sign-Gestalt Expectation Operator ($\mathcal{E}$):**
Let $S$ be the sensory input at a bifurcation (e.g., an alley opening). Let $\Omega$ be the set of possible future states: $\Omega = \{F, B, W\}$, where $F=$ Food/Explorable object, $B=$ Blind end, $W=$ Wall/Non-explorable feature. 
In classical conditioning, the response would be $R(S)$. For Tolman, the internal state is a **sign-gestalt**, which we model as a probability measure over $\Omega$.
Initially (naive state), before experience, the expectation is vague. We can model it as a Dirichlet prior or a uniform distribution perturbed by species-specific predispositions.
\[
\mathcal{E}_{0}(S) = \left( p_F^{(0)}, p_B^{(0)}, p_W^{(0)} \right) \quad \text{where} \quad \sum_{i \in \{F,B,W\}} p_i^{(0)} = 1.
\]
Tolman’s key claim is that $\mathcal{E}_{0}(S)$ is *not* degenerate (i.e., not $(1,0,0)$ pointing only to $F$). Instead, it maintains significant weight on $\neg F = \{B, W\}$.

**2. Complementary Expectation Principle:**
Tolman: “To expect one thing is, pari passu, to expect the ‘possibility’ of the opposite.” Formally:
\[
p_F^{(0)} > 0 \implies 1 - p_F^{(0)} = p_B^{(0)} + p_W^{(0)} > 0.
\]
This is tautological in probability theory, but psychologically profound. It means the cognitive map encodes uncertainty. The "double action affair" is the joint activation of the $F$-attractor basin and the $\neg F$-attractor basin in the neural manifold.

**3. Refinement via Experience (Bayesian Update):**
Experience consists of traversing an alley and observing outcome $O_t \in \{F, B, W\}$. The sign-gestalt updates. Using a simple Bayesian update with a Dirichlet conjugate prior:
\[
\mathcal{E}_{t+1} | O_t \sim \text{Dirichlet}\left( \alpha_F + \mathbb{I}(O_t=F), \alpha_B + \mathbb{I}(O_t=B), \alpha_W + \mathbb{I}(O_t=W) \right)
\]
where $\alpha = (p_F^{(0)}K, p_B^{(0)}K, p_W^{(0)}K)$ for some concentration parameter $K$ representing initial confidence. As trials accumulate, if the correct path leads to $F$, $p_F^{(t)} \rightarrow 1$ and $p_B^{(t)}, p_W^{(t)} \rightarrow 0$. The "vague" expectation sharpens into a precise predictive map.

**Units & Dimensions:**
*   **Sign-Gestalt ($\mathcal{E}$):** Dimensionless probability vector in $\mathbb{R}^3$.
*   **Vagueness/Entropy ($H$):** Measured in bits. Initial state has high entropy:
    \[
    H(\mathcal{E}_0) = -\sum_{i} p_i^{(0)} \log_2 p_i^{(0)}.
    \]
    Learning minimizes this entropy, maximizing predictability.
*   **Force (Legacy Behaviorism):** Tolman was moving away from Thorndike’s "law of effect" where strength $w$ grew by trial-and-error. We can map Tolman’s expectation to a generalized force field $\vec{F}$ in configuration space, but this force is now conditional on belief: $\vec{F}(x) = \nabla_x V(x)$ where $V(x)$ is the expected value derived from $\mathcal{E}$.

**Exact Breakdown Regimes:**
The formalization breaks down under conditions of **radical novelty**. If a rat encounters a stimulus type never seen before (e.g., a laser grid blocking an alley), the prior $\mathcal{E}_0$ may have no support for this outcome category. The model assumes a fixed $\Omega$. Tolman acknowledges new objects are "further-to-be-explored," so the agent must possess a meta-cognitive mechanism to expand $\Omega$ dynamically, adding new categories. This requires a non-stationary prior, pushing the model toward hierarchical Bayesian inference or world-model learning, areas where Tolman’s mid-20th-century framework lacks explicit computational machinery.
