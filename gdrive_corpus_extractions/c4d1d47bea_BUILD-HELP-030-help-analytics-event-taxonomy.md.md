<RECURSIVE_THEORY_OF_MIND>
Model the new user's recursive state upon encountering a major GSE help item. The product team holds a first-order belief: "The user will read the explanation, trust the media, and take the next action." The user holds a second-order belief: "This proprietary interface should be self-explanatory; if it is not, I will leave." The mismatch is a recursive theory-of-mind gap: the team models the user as patient and manual-reading; the user models the interface as immediately legible.

Introduce the crisis clock:
\[
\tau_{\mathrm{crisis}} = 10\ \mathrm{s}.
\]
If \(\mathcal{T}_{\mathrm{comp}}(u,i) > \tau_{\mathrm{crisis}}\), the user enters crisis habit regression: the habitual coping behavior for confusion in a complex proprietary product—close the tab, switch to a competing tool, or file a support ticket. Once regression begins, the conditional probability of successful onboarding decays rapidly because the user has already exited the help context.

The counter-trap is the four-part help pattern mandated by [PAGE 1]: a short summary (reduces uncertainty immediately), a next action (provides an exit from uncertainty into action), a trust note (addresses the trust-safe media requirement), and a media/visual slot (offers a non-textual comprehension channel). For the counter-trap to work, all four elements must be perceptible before \(\tau_{\mathrm{crisis}}\). If any element is missing, delayed, or buried in generic help text, the user regresses to habit and the build fails its acceptance criterion.

Recursive depth: the team must also model that the user models the team as having designed for them. When the help text sounds human and carries a trust note [PAGE 1], the user's model of the system shifts from adversarial/complex to cooperative, lowering the regression trigger. When copy sounds synthetic or leaks proprietary methodology [PAGE 1], the user's model reverts to "this is not for me," and crisis habit regression fires earlier. The build therefore succeeds only if the help item updates the user's mental model within ten seconds.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Adjudicate vetoes across three physical/environmental layers. The source requires mobile behavior and reduced-motion behavior [PAGE 1], which maps directly onto these layers.

Physical layer (device and ambient conditions): mobile screens, variable pixel density, and outdoor glare. Veto condition: body text smaller than 16 px at mobile breakpoint, or contrast \(C < 4.5:1\), renders the summary unreadable in sunlight. Screenshot QA and mobile readability checks [PAGE 1] are the detection instruments. Veto class: hard if contrast fails WCAG AA; soft if readability is marginal but correctable with font scaling.

Biomechanical layer (touch and motor): touch-target size and vestibular tolerance. Veto condition: help affordance smaller than \(44 \times 44\ \text{CSS px}\), or located outside the thumb zone on large phones, prevents reliable activation. Veto condition: motion in the media slot without a reduced-motion fallback triggers vestibular discomfort for motion-sensitive users. The reduced-motion check [PAGE 1] is the veto instrument; a positive \(\mu\) without static fallback is a hard accessibility veto under WCAG 2.3.3.

Weather/environment layer (context of use): rain on screen, one-handed use, glare, low bandwidth. Veto condition: a video-only media path fails under low bandwidth or when the user cannot attend to audio/visuals; the trust note must survive as plain text. The media/visual slot acceptance criterion [PAGE 1] permits table, visual, or example path, which provides the redundancy required for environmental veto resistance.

Veto hierarchy: accessibility/biomechanical veto outranks physical veto, which outranks cosmetic veto. If reduced-motion behavior is absent, the build is vetoed regardless of how good the copy is. If mobile readability fails screenshot QA, the component is hidden behind \(\phi\) and rolled back per the rollback plan [PAGE 1], because no data or billing changes are involved. The adjudication rule: ship only if \(\phi = 1\), \(P(A_i = 1) \ge \theta_A\), \(\mathcal{T}_{\mathrm{comp}} \le 10\ \mathrm{s}\) under representative mobile conditions, and \(\mu\)-mapped static fallback exists.
</CROSS_LAYER_VETO_ADJUDICATION>
