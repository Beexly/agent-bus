**Conformity score (Eq. 1, [PAGE 3]), dimensionless ratio in $[0,\infty)$:**
$$A_k(B,x,y)=\frac{\min\!\Big\{\tfrac1k\sum_{i=1}^{k}\mathrm{CosDist}\big(f(x),f(x_i)\big)\,\big|\,y_i=y\Big\}}{\min\!\Big\{\tfrac1k\sum_{i=1}^{k}\mathrm{CosDist}\big(f(x),f(x_i)\big)\,\big|\,y_i\neq y\Big\}}$$
Small $A_k$ ⇒ $x$ resembles class $y$ (conforming). $\mathrm{CosDist}(a,b)=1-\frac{a\cdot b}{\lVert a\rVert\lVert b\rVert}\in[0,2]$ (dimensionless, scale-invariant).

**Exchangeability (Eq. 2, [PAGE 5]):** $(X_i,Y_i)_{i=1}^n$ exchangeable iff $\big(f(X_1,Y_1),\dots\big)\stackrel{d}{=}\big(X_{\pi(1)},Y_{\pi(1)},\dots\big)$ for all permutations $\pi$. This is the sole enabling assumption; no units.

**Conformal p-value and set (Eq. 3, [PAGE 5]):**
$$p(y_j)=\frac{\#\{i\in C_{y_j}:\alpha_i(y_j)\ge\alpha_{l+1}\}+1}{|C_{y_j}|+1},\qquad \Gamma_\epsilon(x)=\{y_j:p(y_j)>\epsilon\}.$$
$\epsilon\in(0,1)$ is the (dimensionless) significance level. **Discreteness/breakdown regime:** the minimum attainable nonzero p-value is $p_{\min}=1/(n_{\mathrm{cal}}+1)$. To certify any label as a singleton at level $\epsilon$ you need $\epsilon<1$, but to *exclude* all labels you need $\epsilon<1/(n_{\mathrm{cal}}+1)$; for $\epsilon<1/(n_{\mathrm{cal}}+1)$ no set can be smaller than the full space, so efficiency collapses to $|Y|$ while coverage trivially $=1$. This is a genuine finite-sample singularity: small calibration sets (e.g., CB with $\sim 250$ train examples, [PAGE 22]) force a coarse probability "quantum" $1/(n_{\mathrm{cal}}+1)$.

**Guarantees (Eq. 4–5, [PAGE 5–6]):** marginal $\Pr[Y\in\Gamma_\epsilon(X)]\ge 1-\epsilon$; classwise $\Pr[Y\in\Gamma_\epsilon(X)\mid Y=y]\ge 1-\epsilon\ \forall y$. Both are probabilities in $[0,1]$; both are voided the instant exchangeability fails.

**Credibility / confidence (Eq. 6, [PAGE 6]):** $\text{Cred}=\max_{y}p(y)$, $\text{Conf}=1-\max_{y\neq y^\ast}p(y)$, $y^\ast=\arg\max_y p(y)$. Dimensionless. **Efficiency / correct efficiency (Eq. 7, [PAGE 6]):** $\mathbb{E}[|\Gamma_\epsilon(x)|]$ (set size, lower-better) and $cEff = 1-\mathbb{E}\big[\tfrac{|\Gamma_\epsilon(x)|}{|Y|}\,\big|\,Y\in\Gamma_\epsilon(x)\big]\in[0,1]$. **Derived ceiling:** $cEff\le 1-1/|Y|$ (see THINK_TRACE #2); reported table values exceed this, so those columns are a distinct operational metric.

**Distances (Eq., [PAGE 8]):** $\mathrm{Dist}_{\cos}(u,v)=1-\frac{u^\top v}{\lVert u\rVert\lVert v\rVert}$ (dimensionless); $\mathrm{Dist}_{\mathrm{Mah}}(x,\mu)=\sqrt{(x-\mu)^\top\Sigma^{-1}(x-\mu)}$ (units of standard deviations when $\Sigma$ is a covariance). **Mahalanobis singularity:** $\Sigma^{-1}$ exists iff $\Sigma\succ 0$; as features collinearize, $\lambda_{\min}(\Sigma)\to 0$, condition number $\kappa(\Sigma)=\lambda_{\max}/\lambda_{\min}\to\infty$, and $\lVert\Sigma^{-1}\rVert\to\infty$, so the metric amplifies null-space noise. <RECURSIVE_THEORY_OF_MIND>

Model the calibration loop as a scoring game between the nonconformity ranker and a possibly-adversarial data-generating environment parameterized by class prior $\pi$ and drift.

**Crisis.** Exchangeability breakdown: class imbalance, label noise, covariate/label drift, or representational collapse. This is the regime where Eq. 4/5 guarantees silently void.

**Habit regression (default behavior under crisis).** To keep the *marginal* average $\Pr[Y\in\Gamma_\epsilon]\ge 1-\epsilon$, the ranker rationally spends its coverage budget on the dominant class. BoolQ is the archetype: "true" is predicted for $906$ of $1{,}237$ "false" inputs [PAGE 12], i.e., the predictor regresses to the majority label; marginal curves "almost diagonal" while the false class collapses to $26.8\%$ accuracy. The environment "wins" by making the two classes non-separable in $f_\ell$.

**Counter-trap (deliberate counter-measure).** Mondrian/classwise calibration (Eq. 5) re-normalizes per class, directly countering the majority-regression. It is *partially* effective — Fig. 4 shows false-class coverage pulled back toward the diagonal [PAGE 14] — but "some under-coverage remains, especially … for low $\epsilon$" [PAGE 14]. The secondary trap: aggressively tuning $\ell,k,T$ to the calibration set to chase per-class curves re-introduces overfitting and instability ("performance is sensitive to the choice of intermediate layer" [PAGE 16]).

**Clock.** The finite calibration count $n_{\mathrm{cal}}$ sets the resolution of achievable coverage: the p-value quantum is $1/(n_{\mathrm{cal}}+1)$, and the exchangeable split injects sampling randomness. Low-data tasks (CB $\sim250$, RTE $\sim2500$, WNLI $635$ [PAGE 22]) run a coarse clock, so per-class coverage can only move in large steps — one cause of the residual asymmetry that neither scale (RoBERTa-large) nor Mondrian correction removes (CB "neutral … below 0.5 across all $\epsilon$" [PAGE 14]). Counter-trap reasoning must therefore budget for a *coarse clock*: increasing $n_{\mathrm{cal}}$ (finer clock) dominates layer/temperature micro-tuning when the crisis is data scarcity rather than representation quality.
