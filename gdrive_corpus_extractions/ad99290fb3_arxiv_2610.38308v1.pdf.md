Trap 2: the public package TD target computes bootstrapped targets over padded length t = 0,…,T_max−2, discarding the final reward of the longest sequence in a batch and allowing shorter sequences to bootstrap from padded steps; with λ_AS = 0.01 this setting failed to learn in all 18 runs [PAGE 5–6]. Trap 3: the ST-GCN input lacks a missingness mask. Absent joints are placed at the mid-hip (zero after normalisation), missing frames and padded steps are all zeros, and batch-normalisation statistics aggregate across these zeros, so the same posture can yield different embeddings depending on batch composition [PAGE 12, Appendix A–B]. Trap 4: seed variance. Without requiring the same sign across all three seeds, match-bootstrap intervals alone produce spurious significant off-ball differences in both directions [PAGE 7]. These are not one-off bugs; they are protocol fossils that persist across weeks of training and can invert the apparent ranking of pose representations. The authors correctly treat results as valid only for “this training protocol” [PAGE 11].
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
Crisis habit regression: when an action-valuation model produces weak or noisy values, the instinctive practitioner response is to enrich the state space—here, adding raw 3D joints, ST-GCN embeddings, or torso/head orientation—on the assumption that more information about posture must improve value estimates. The paper directly counters this trap: the learning setting dominates the state representation. Under terminal TD with λ_AS = 0.01 (the prior model’s configuration), the position-only baseline has on-ball skill 0.003 and ρ(Q,xG) = 0.23, barely better than a constant predictor; removing the action-prediction loss lifts skill to 0.040 and correlation to 0.60, a change roughly five times larger than the best pose-induced improvement (−2.71×10⁻⁴ vs −12.2×10⁻⁴ MSE reduction) [PAGE 7]. Thus the “crisis” of low value validity is not solved by adding pose; it is solved, at least partially, by changing the auxiliary loss and stopping criterion.

The counter-trap is equally important: pose is not uninformative. It robustly improves prediction of the on-ball action 0.2 s ahead (macro AUC 0.914 → 0.934 with raw joints) and pass success from the passer’s pose at execution (AUC 0.844 → 0.856) [PAGE 7–8]. The failure is not in the signal but in the credit-assignment horizon. Body orientation and readiness affect the next action within 0.2 s, yet the reward is delivered only at the end of the attack—several actions and several seconds later—and depends on later decisions by both teams [PAGE 9–10]. With γ = 1 and a terminal-only reward, the pose signal is diluted by a sparse, high-variance return; this is a temporal credit-assignment bottleneck, not a representational insufficiency.

Clock: the training-clock pathology interacts with the value clock. Because early stopping watches total loss including L_AS, models with λ_AS = 0.01 train for 47–134 epochs even though the TD loss deteriorates after epoch one, while models with λ_AS = 0 are forcibly stopped at six epochs before values can stabilise [PAGE 5, 9]. At matched six epochs, every pose condition scores below the position-only baseline in the action-information probe (Table 3), showing that the apparent pose advantage after long training partly reflects baseline decline rather than genuine pose information [PAGE 9].

Recursive theory of mind in the model itself is limited. The network has no player identifier; the target player is defined solely by input-slot construction—the last four dimensions of x_t—and all players share one set of weights [PAGE 4]. Off-ball values are never validated against an observed counterfactual return, because only the taken action’s return is known [PAGE 3]. Consequently the model cannot validate rankings of alternative actions, causal player contributions, or an explicit model of teammates’ intentions; values of unobserved off-ball actions can fall far outside the [−1,1] return range [PAGE 3, 11, Figure 3]. The “theory of mind” is implicit in relative coordinates, not recursive, and the evaluation deliberately restricts itself to observed-action values [PAGE 3]. Any claim that pose improves off-ball decision value therefore oversteps the validated scope.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical layer. The pose pipeline imposes hard geometric constraints that can veto downstream value claims. Every joint coordinate is expressed relative to the mid-hip and divided by 2.44 m [PAGE 12, Appendix A]. Missing joints default to the mid-hip position (zero after normalisation); missing frames, steps without pose, and padded batch steps are all zeros [PAGE 12, Appendix A]. The ST-GCN encoder receives this unmasked 5×29×3 tensor, and batch-normalisation statistics are computed over the entire batch including zero-filled steps, whose share depends on sequence lengths in the batch [PAGE 12, Appendix A–B]. Because evaluation uses running statistics from training, the embedding of an identical posture can shift with batch composition [PAGE 12]. This is a physical veto: any robust improvement claimed for ST-GCN embeddings is suspect unless the encoder is re-run with explicit missingness masks and per-sample normalisation. Nine of twelve robust deteriorations in Table 1 are ST-GCN conditions [PAGE 7], consistent with this contamination.

Biomechanical layer. Only the target player’s pose is used; surrounding players’ posture is absent [PAGE 11, Limitations]. The pose window is five 25 Hz frames within one 5 Hz step (0.2 s), so for the imminent-action task the preceding step’s pose may already capture a kick’s backswing, making it short-range anticipation rather than pure pre-action preparation [PAGE 11]. For pass success, the passer’s pose at the pass step can include the kick itself [PAGE 8]. A qualitative failure case shows a fallen or misestimated pose (head below hips in all frames) collapsing the off-ball movement value from 0.04 to −0.80 [PAGE 8], demonstrating that pose noise directly corrupts value estimates. There is no correction for multiple comparisons across representations, settings, and step types [PAGE 11].

Weather layer. The data source is Hawk-Eye tracking and 3D pose rather than broadcast video, which reduces but does not eliminate environmental dependency; the paper does not report weather, lighting, or occlusion statistics, so no weather veto can be calibrated from the text. However, missing joints and frames—precisely the conditions under which broadcast pose estimation degrades—are handled by zero-filling without masking, which is a proxy for weather/occlusion fragility [PAGE 12].

Veto adjudication. The authors’ own robustness rule is a veto: a difference counts only if the bootstrap CI excludes zero and the sign agrees across all three seeds [PAGE 6]. Applying this, only 3 of 50 pose comparisons pass, all torso+head [PAGE 7]. ST-GCN is vetoed by nine robust deteriorations and by off-ball values escaping the [−1,1] return range at 82 and 124 test steps under λ_AS = 0.01, whereas no baseline value does so [PAGE 7, 9]. Package TD with λ_AS = 0.01 is vetoed by non-learning (value drift to −36) [PAGE 6]. Raw joints are vetoed by null results across all settings [PAGE 7]. The only surviving claim is that torso+head orientation improves values in two specific TD settings, an improvement amounting to roughly one-fifth of the effect of removing the action-prediction loss [PAGE 9]. Consequently, any deployment of pose-aware action valuation must condition on learning protocol, not merely on pose availability.

<RLVR_COUNTERFACTUAL_VETOES>
Scenario 1 — Matched-duration veto. Counterfactual: re-train terminal TD with λ_AS = 0.01 for exactly six epochs instead of early stopping after 47–134 epochs, then compare torso+head against none on the same test steps. Verifiable from Table 3 and Section VII-A [PAGE 9]: at six epochs, the position-only baseline reaches on-ball macro AUC 0.853 in the action probe, whereas after full early stopping it drops to 0.735; every pose condition is below the baseline at matched length, robustly so for raw, ST-GCN, and ST-GCN+torso. Prediction: the three robust torso+head improvements in Table 1 (on-ball terminal TD λ_AS = 0.01; on- and off-ball package TD λ_AS = 0) will vanish or become non-robust, because they are confounded with longer training rather than pose information. The main effect will be confirmed as the removal of L_AS, which raises on-ball skill from 0.003 to 0.040 and ρ(Q,xG) from 0.23 to 0.60 [PAGE 7].

Scenario 2 — Encoder masking veto. Counterfactual: modify the ST-GCN input pipeline so missing joints carry an explicit missingness mask (not mid-hip zero), missing frames and padded steps are excluded from batch-normalisation statistics, and normalisation is per-sample rather than across the batch [PAGE 12, Appendix A–B]. Verifiable because the current encoder has 79,360 parameters and raises total trainable parameters from ~32k to ~120k [PAGE 12, Table 4], with no masking and batch-norm over all batch steps including zeros. Prediction: the nine robust ST-GCN deteriorations in Table 1 [PAGE 7] will shrink or reverse; raw joints may exit the “within noise” band and show a small positive Δ; torso+head will likely remain the sole robustly positive representation. Failure to observe this shift would imply the ST-GCN harm is intrinsic to sparse value-signal training rather than an input artefact.

Scenario 3 — Dense intermediate reward veto. Counterfactual: replace the terminal-only EPV/goal/concede reward (γ = 1, r_t = 0 for t < T) with a dense intermediate reward such as pass success, ball retention, or one-step ΔEPV after the next action, while retaining the same pose representations and SARSA learner. Verifiable because the current terminal reward is sparse by design [PAGE 3] and the same pose features already improve the 0.2 s-ahead action prediction (macro AUC 0.914 → 0.934) and pass-success classification (AUC 0.844 → 0.856) [PAGE 7–8]. Prediction: robust pose-induced value improvements will rise above 3/50, concentrated in on-ball steps and in torso+head/raw representations, because the credit-assignment horizon collapses from several seconds to the next action. If robust improvements do not increase, the bottleneck is architectural (e.g. shared network without player ID, absent surrounding-player pose) rather than purely temporal [PAGE 4, 11].
