<THINK_TRACE>
The source document defines a source operator, Offline-Poly, that transforms coarse tracklet collections into refined tracklets under the Tracking-by-Tracking paradigm. The central derivation chain is: (1) upstream trackers emit finalized tracklets, not raw detections; (2) those tracklets are filtered using full-sequence statistics; (3) temporally disjoint fragments are re-linked by motion-predicted nodes and a global assignment solve; (4) overlapping but entangled tracklets are split and re-organized; (5) multiple upstream hypotheses are consolidated through scene-level adjacency clustering; and (6) fused trajectories are corrected by global rigidity constraints and local temporal optimization. The source states this architecture explicitly: “Offline-Poly consists of four components: pre-processing, matching, fusion, and refinement.” [PAGE 4] The offline advantage is formulated as two properties: “resource unconstrainedness” and “future observability.” [PAGE 1]

A formal derivation begins with the input set. For tracker \(i\), the source defines \(T^i_{in}=\{T^i_{in}\mid i=1,\dots,N^i_{in}\}\) and each state \(B_j\in\mathbb{R}^{N_s}\) as \((x,y,z,w,l,h,v_x,v_y,\theta,\mathrm{Conf},t,\mathrm{CLS},ID)\) [PAGE 3]. The output mapping is written as \(T_{out}\leftarrow \mathrm{Tracking\text{-}by\text{-}Tracking}(T_{in})\) [PAGE 3]. The operator is therefore a set-to-set map on tracklet sequences, not a detector. This matters because every downstream equation inherits the error modes of upstream tracking: fragmented tracklets, false positives, missed detections, identity switches, and timestamp gaps. The source acknowledges this by saying TBT “operates exclusively on arbitrary off-the-shelf tracking outputs” [PAGE 1].

Pre-processing is the first veto layer. The source removes tracklets only when both age and mean confidence are below thresholds: “we remove any tracklet … whose age and mean confidence are both below predefined thresholds \(\theta_{age}\) and \(\theta_{score}\).” [PAGE 4] Formally, if \(A_i\) is age in frames and \(\overline{\mathrm{Conf}}_i\in[0,1]\), the retention predicate is
\[
\mathrm{keep}(T_i)=\neg(A_i<\theta_{age}\ \wedge\ \overline{\mathrm{Conf}}_i<\theta_{score}).
\]
This is not a probabilistic classifier; it is a deterministic lifetime-and-confidence veto. Its breakdown regime is immediate: if \(\theta_{age}\) is too high, short but true objects are deleted; if too low, ghost tracklets survive and increase downstream graph density. The source confirms the empirical direction: “applying a single filtering criterion … proves overly restrictive” while “incorporating both lifecycle and confidence constraints … achieves a +0.3% AMOTA improvement” [PAGE 10].

The STWO module reconnects non-overlapping fragments. The source performs forward-backward motion extrapolation, then builds an IoU-based cost matrix, solves with blossom matching, and merges pairs below a cost threshold. The key physical assumption is short-horizon motion continuity. The source states: “Predictions exceeding 1 second are discarded to prevent drift.” [PAGE 5] This is an exact temporal breakdown boundary. If an occlusion or detection gap exceeds one second, the module refuses to extrapolate, preventing uncontrolled drift but potentially leaving a fragmentation unresolved unless multi-tracker fusion later supplies evidence. The assignment operator is globally optimal under the stated one-to-one assumption: “We adopt the blossom algorithm … to solve the assignment problem” [PAGE 5]. Its singularity regime is the degenerate cost matrix: invalid predicted states and self-assignments are set to infinity, so no feasible matching exists if every candidate pair is invalid.

The STW module handles overlapping lifecycles and false-positive merges. It builds a frame-level adjacency matrix using generalized IoU and then extracts connected components to identify entangled nodes. The source explains: “Tracklets that are directly or indirectly connected within a frame are marked as entangled.” [PAGE 6] The formal object is a graph \(G_t=(\mathcal{V}_t,\mathcal{E}_t)\) whose connected components are split. If the graph is over-connected, many distinct objects are merged into one component; if under-connected, an entangled tracklet remains corrupt. This is a gray-zone audit point: the module depends on the threshold used in the underlying gIoU/IoU affinity and on the temporal aggregation rule later used in multi-tracker matching.

Multi-tracker matching generalizes the operator from single-input to multiple-input. The source states: “we adopt a one-to-many formulation, allowing multiple trajectory hypotheses from distinct trackers to correspond to the same object.” [PAGE 6] The frame-level adjacency is binarized:
\[
A^{multi,t}_{i,j}=\mathbf{1}\left(C^{multi,t}_{i,j}<\theta_{multi}\right),
\]
with \(C^{multi,t}_{i,j}\) an IoU-type spatial dissimilarity [PAGE 7]. Temporal aggregation uses concatenation followed by max pooling:
\[
\tilde A^{multi}_{i,j}=\max_{t=1,\dots,L_s}\hat A^{multi}[t,i,j].
\]
The source explicitly flags the failure mode: “max pooling is employed to achieve high recall with minimal computational overhead, despite its susceptibility to spurious edge responses.” [PAGE 7] This is the principal information-theoretic trade-off: max pooling converts a temporal sequence of Bernoulli-like adjacency observations into a single binary edge, maximizing recall but increasing false-edge probability when trackers produce isolated accidental overlaps.

Refinement then operates on fused trajectories. Global refinement assumes rigid-object size invariance: “A fundamental property of rigid objects is the temporal invariance of physical size.” [PAGE 8] The source selects the top-\(K\) reliable observations, weights them by softmax-normalized tracking scores, and applies corner alignment. Its breakdown regime is sample-size dependent: “too few (<4) lead to overfitting, whereas too many (>14) introduce outliers.” [PAGE 12] Local refinement uses a sliding-window MSE objective:
\[
\min_{B_t}\sum_{\Delta t=-M/2}^{M/2}\left(f_{t\to t+\Delta t}(B_t)-B_{t+\Delta t}\right)^2,
\]
solved with Levenberg-Marquardt [PAGE 8]. The source’s exact horizon warning is: “Extending the prediction range beyond 4 seconds reduces accuracy due to motion-model drift.” [PAGE 12] Thus the operator is locally valid only when motion-model error growth over the chosen window remains below the tolerance required by the state units: meters for position, meters per second for velocity, radians for heading.

The gray-zone audit therefore centers on three coupled risks: (a) threshold-induced graph distortion, where \(\theta_{blo}\), \(\theta_{multi}\), and filtering thresholds trade recall against false edges; (b) motion-model extrapolation failure beyond the source-defined one-second prediction ban and four-second refinement horizon; and (c) upstream dependence, because TBT cannot recover objects that were never emitted as tracklets by any upstream tracker. The source’s claimed advantage is not magical recovery of detections; it is structural reorganization of existing tracklet evidence under global observability.

   \[
   \mathrm{reject}(T_i)=\mathbf{1}\left(A_i<\theta_{age}\ \wedge\ \overline{\mathrm{Conf}}_i<\theta_{score}\right).

4. **Forward-backward motion prediction for STWO nodes**

   \[

   \end{cases}
   \]
   Units: \(f_{t_0\to t}\) maps a state at frame/time \(t_0\) to frame/time \(t\). For constant velocity, the center position propagates as
   \[
   p(t+\Delta t)=p(t)+v(t)\frac{\Delta t}{f_s},
   \]
   where \(\Delta t\) is frame displacement and \(f_s\) is sensor/annotation frequency in hertz \([\mathrm{s^{-1}}]\).  
   Assumptions: motion model class is explicit, e.g. Constant Velocity, Constant Turn Rate and Acceleration [PAGE 4]; observed or predicted nodes are aggregated into \(B_{pred}\in\mathbb{R}^{N_{ReID}\times N_s}\).  
   Exact source boundary: “Predictions exceeding 1 second are discarded to prevent drift.” [PAGE 5]  
   Breakdown: if motion model mismatch is large, predicted boxes are geometrically implausible and either discarded or incorrectly matched.

5. **IoU cost and blossom assignment**  
   Source equation (3) [PAGE 5]:
   \[
   C^{ReID,t}_{i,j}=1-\frac{\Lambda(\tilde B_{i,t}\cap \tilde B_{j,t})}{\Lambda(\tilde B_{i,t}\cup \tilde B_{j,t})}.
   \]
   Units: \(\Lambda(\cdot)\) is BEV area in \([\mathrm{m^2}]\) or 3D volume in \([\mathrm{m^3}]\); the ratio is dimensionless; cost is dimensionless in \([0,1]\).  
   Boundary conditions: diagonal entries and invalid-state costs are set to infinity [PAGE 5]. If \(\Lambda(\tilde B_{i,t}\cup \tilde B_{j,t})=0\), the ratio is undefined; the operator must treat this as invalid or infinite cost.  
   Matching rule: matched pairs satisfy \(C^{ReID,t}_{i,j}<\theta_{blo}\). The source uses the blossom algorithm, stating that it “efficiently computes globally optimal pairings among tracklet nodes under a unified cost objective.” [PAGE 5]  
   Breakdown: if \(\theta_{blo}=1\) is excessively loose, the source reports: “An excessively loose threshold (=1) leads to FP matching, degrading the system performance.” [PAGE 12]

6. **Overlapping-lifecycle adjacency and clustering**  
   For STW, a frame-level adjacency matrix \(\hat A_{stw}\in\mathbb{R}^{L_s\times N_{ReID}\times N_{ReID}}\) is constructed using generalized IoU and the multi-tracker adjacency rule [PAGE 5–6]. The operator identifies connected components at each frame; entangled nodes are split into pre-event and post-event segments [PAGE 6].  
   Information unit: each adjacency entry is a binary symbol, \(0\) or \(1\), carrying one bit in a discrete graph representation.  
   Assumption: false-positive associations are local around the mismatching event, so long-term segments remain reliable. The source states: “FP associations typically corrupt trajectories locally around the mismatching event, while long-term segments before and after remain reliable.” [PAGE 6]  
   Breakdown: if the corruption persists across many frames, a tracklet is segmented multiple times; if the adjacency graph is over-connected, distinct objects are placed in one entangled component.

7. **Multi-tracker node concatenation and scene-level adjacency**  
   Source equation (5) [PAGE 6]:
   \[
   T_{pad}=\left\{T^j_{pad}\mid j=1,\dots,N_{all}\right\},\qquad
   N_{all}=\sum_{i=1}^{N}N^i_{sin}.
   \]
   Tracklets are padded to full scene length \(L_s\) with NaN placeholders and a validity mask. Units: \(L_s\) is a frame count; if converted to duration, \(T_{scene}=L_s/f_s\) in seconds.  
   Frame-level binarized adjacency [PAGE 7]:
   \[
   A^{multi,t}_{i,j}=\mathbf{1}\left(C^{multi,t}_{i,j}<\theta_{multi}\right)\in\{0,1\}.
   \]
   Temporal aggregation:
   \[
   \hat A^{multi}=\mathrm{Concat}(A^{multi,1},\dots,A^{multi,L_s}),\qquad
   \tilde A^{multi}_{i,j}=\max_{t=1}^{L_s}\hat A^{multi}[t,i,j].
   \]
   Units: \(\tilde A^{multi}\in\{0,1\}^{N_{all}\times N_{all}}\) is a binary graph adjacency matrix.  
   Clustering operator:
   \[
   T_{multi}\leftarrow \mathrm{DFS}(\tilde A^{multi}).
   \]
   The source uses depth-first search to identify trajectories with direct or indirect adjacency relationships [PAGE 7].  
   Assumptions: same-object tracklets exhibit spatio-temporal coherence; one-to-many correspondence is allowed. The source states: “Tracklets belonging to the same object are expected to exhibit strong geometric or appearance consistency across frames, i.e., spatio-temporal coherence.” [PAGE 6]  
   Breakdown: max pooling is vulnerable to spurious edges. The source states: “max pooling is employed to achieve high recall with minimal computational overhead, despite its susceptibility to spurious edge responses.” [PAGE 7] Computationally, constructing all frame-level pairwise costs is \(O(L_s N_{all}^2)\) time and memory before aggregation. If \(N_{all}\) grows large, memory becomes the singularity regime.

8. **Fusion of attribute observations**  
   The source says fusion is “attribute-agnostic: per-frame attributes are computed as weighted averages of all valid observations.” [PAGE 7] A formal version for a continuous attribute \(s_{t,c}\) at frame \(t\) and tracker/source \(c\) is
   \[
   \bar s_t=\frac{\sum_{c\in\mathcal{V}_t}w_{c,t}s_{c,t}}{\sum_{c\in\mathcal{V}_t}w_{c,t}},
   \]
   where \(\mathcal{V}_t\) is the set of valid observations at frame \(t\), and \(w_{c,t}>0\) are weights, for example confidence-derived weights. If \(\sum_c w_{c,t}=0\), the estimator is undefined and the frame must remain missing or be interpolated by later refinement.  
   Category consistency is enforced to maintain semantic consistency [PAGE 7].  
   Breakdown: if clusters contain different categories, weighted fusion mixes incompatible semantics; if all valid observations are noisy, the weighted average inherits their bias.

9. **Global size and center refinement**  
   The source assumes rigid-object temporal size invariance: “A fundamental property of rigid objects is the temporal invariance of physical size.” [PAGE 8] For top-\(K\) selected observations with scores \(q_k\), a softmax weighting is used:
   \[
   w_k=\frac{\exp(q_k)}{\sum_{\ell=1}^{K}\exp(q_\ell)},\qquad
   \widehat{\mathrm{size}}=\sum_{k=1}^{K}w_k\,\mathrm{size}_k.
   \]
   Units: size in meters \([\mathrm{m}]\); scores dimensionless.  
   Center correction uses corner alignment because the L-shaped inflection point is a more reliable geometric reference than the inferred box center [PAGE 8].  
   Exact breakdown from source sensitivity analysis: “too few (<4) lead to overfitting, whereas too many (>14) introduce outliers.” [PAGE 12]

10. **Local sliding-window optimization**  
   Source equation (10) [PAGE 8]:
   \[
   \min_{B_t}\sum_{\Delta t=-M/2}^{M/2}\left(f_{t\to t+\Delta t}(B_t)-B_{t+\Delta t}\right)^2.
   \]
   The optimization is solved by Levenberg-Marquardt [PAGE 8]. Only motion-related attributes are optimized: 3D center, velocity, and heading angle [PAGE 8].  
   Dimensional audit: as written, the residual mixes position \([\mathrm{m}]\), velocity \([\mathrm{m\,s^{-1}}]\), and angle \([\mathrm{rad}]\). A dimensionally explicit implementation requires weighted or normalized residuals:
   \[
   J(B_t)=\sum_{\Delta t}\left[
   w_p\lVert p_{pred}-p_{obs}\rVert_2^2+
   w_v\lVert v_{pred}-v_{obs}\rVert_2^2+
   w_\theta d_{\mathrm{ang}}^2(\theta_{pred},\theta_{obs})
   \right],
   \]
   with \(w_p,w_v,w_\theta\) chosen to normalize units.  
   Assumptions: \(M\) is even or the summation limits are adjusted; the motion model is valid over the window; enough observations exist to make the linearized system full rank.  
   Exact breakdown from source: “Extending the prediction range beyond 4 seconds reduces accuracy due to motion-model drift.” [PAGE 12]  
   Numerical singularity: if the Jacobian of the motion residuals is rank deficient, the normal equations are singular; Levenberg-Marquardt damping is required, and without regularization the step may diverge.

11. **Evaluation metrics and units**  
   nuScenes uses AMOTA, MOTA, AMOTP, IDS, FP, FN, and ASE [PAGE 8]. KITTI uses HOTA, with 3D evaluation via sAMOTA [PAGE 8–9]. AMOTA, MOTA, HOTA, and sAMOTA are dimensionless performance scores, reported as percentages in the source. IDS, FP, and FN are counts. AMOTP is a distance-like error metric, typically reported in meters for 3D tracking or image-plane units for 2D evaluation; the source reports numerical values without unit suffix.  
   Probabilistic interpretation: detection/association metrics estimate empirical probabilities or expected accuracies over benchmark samples; they are not instantaneous physical units.

</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
The paper’s lineage begins with online Tracking-by-Detection. The source states that most offline 3D MOT implementations “remain adaptations of online Tracking-By-Detection (TBD) trackers” and that common strategies such as weighted box fusion, extending tracklet age, and bidirectional tracking are “heuristically incorporated into online pipelines to approximate offline behavior.” [PAGE 1] This historical dependency creates the main multi-week research trap: treating offline tracking as merely a post-processing patch on top of an online detector-tracker pair. That trap leads to architectures tied to a detector, a specific tracker, or intermediate association metadata.

A second lineage is the polyhedral family. The source cites Poly-MOT as a reformulation of multi-category tracking and Fast-Poly as a runtime-optimized polyhedral algorithm [PAGE 2]. Offline-Poly inherits the geometry-based, category-aware style but changes the problem class: it does not optimize detections frame-by-frame; it optimizes tracklet graphs across an entire sequence. The source says: “TBT treats upstream tracking results as atomic inputs and produces globally refined trajectories optimized for the offline setting.” [PAGE 2] This is a conceptual inversion: the primitive is no longer a detection box but a tracklet.

A third lineage is dedicated offline tracking. The source identifies PC3T, RethinkMOT, OTOP, and BiTrack as methods that treat offline 3D MOT more explicitly [PAGE 3]. It criticizes them for input dependence: “BiTrack relies on observation-tracklet matching pairs inherited from online tracking, OTOP requires static maps for tracklet completion, and the bidirectional tracking in DetZero is bound to the BYTETrack framework.” [PAGE 3] This criticism defines Offline-Poly’s retro-causal motivation: remove the dependency on specialized inputs and make the offline operator input-agnostic.

The historical scientific lineage also includes motion estimation. Online trackers use Markov filters such as Kalman filters due to real-time constraints [PAGE 8]. Offline trackers can use bidirectional context, global rigidity, and future-aware refinement. Offline-Poly replaces simple forward filtering with a sliding-window optimization that uses past and future observations. The source contrasts this with learning-based refinement that encodes temporal cues from raw sensor data, arguing for an “unsupervised and interpretable sliding-window optimization that operates solely on structured bounding box representations.” [PAGE 8]

A major multi-week trap is overfitting to a single upstream tracker. The source repeatedly evaluates across CenterPoint, Fast-Poly, MCTrack, MV2DFusion, ADA-Track, VirConv, and other detectors/trackers [PAGE 9–10]. This genealogy suggests that the field’s previous offline gains were often not general offline reasoning but accidental exploitation of one tracker’s error distribution. Offline-Poly’s genealogical claim is that the same operator can improve heterogeneous trackers because it operates on tracklet-level structure rather than detector-specific features.

Another multi-week trap is threshold fixation. The source provides sensitivity analyses for \(\theta_{age}\), \(\theta_{score}\), \(\theta_{blo}\), \(\theta_{multi}\), \(K\), and \(M\) [PAGE 11–12]. Historically, MOT systems often tune thresholds until validation improves, then fail under distribution shift. Offline-Poly’s genealogy attempts to avoid this by using coarse physical constraints: one-second prediction discard, rigid size assumption, and bounded sliding-window horizons. These are not learned parameters; they are structural assumptions about object permanence and motion continuity.

Finally, the paper situates offline tracking inside 4D auto-labeling. The source states that offline 3D MOT “aggregates frame-level detections into instance-level tracklets, bridging the gap between per-frame detection outputs and temporally consistent 4D annotations.” [PAGE 1] The retro-causal pressure from 4DAL explains why Offline-Poly values recall, completeness, and multi-source fusion more than low-latency inference. In this lineage, false negatives caused by occlusion are treated as recoverable evidence gaps, not permanent failures, provided the gap is shorter than the allowed prediction horizon or another tracker observed the object.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
The recursive theory-of-mind layer asks: what do the upstream tracker designer, the offline auto-labeling engineer, and the benchmark evaluator implicitly believe, and how does Offline-Poly exploit or correct those beliefs?

The upstream tracker designer usually assumes a causal online clock: detections arrive sequentially, association must be completed before the next frame, and identity state must be maintained with limited future information. That designer’s habit is to treat a missed detection or occlusion as a temporary loss and to terminate or coast a tracklet under a local age policy. Offline-Poly’s theory of mind is different: it knows the entire sequence has already been observed. The source states: “offline 3D MOT operates without real-time constraints and has access to the entire temporal sequence, enabling global reasoning over full-scene trajectories.” [PAGE 3] Therefore, a fragment that the online tracker would abandon can be retained as evidence if its full lifecycle and confidence statistics pass the offline pre-filter.

The offline auto-labeling engineer, however, may fall into a crisis-habit regression: under label-quality pressure, they often add more detections, more upstream trackers, or more learned modules, assuming that more input automatically yields more complete labels. This is not necessarily true. Offline-Poly’s counter-trap is structural: it first removes ghost tracklets, then re-identifies fragments, then disentangles overlapping errors, and only then fuses multiple sources. The source explicitly warns that frame-wise heuristics “often retain high-confidence FP, which subsequently evolve into ghost tracklets.” [PAGE 4] If the engineer skips pre-processing, the downstream graph becomes denser and more error-prone. The recursive belief correction is: more evidence is beneficial only after false-positive tracklets are vetoed.

A second recursive loop concerns tracker complementarity. One tracker may be good at rigid vehicles under clear geometry but weak on pedestrians; another may use appearance cues and recover objects after long occlusion. Offline-Poly assumes that different trackers expose different observation subsets. The source says: “Different trackers can capture complementary aspects of the same object. Aggregating these heterogeneous hypotheses produces more complete and accurate trajectories.” [PAGE 6] The theory-of-mind operation is to treat each upstream tracker not as a competitor to be replaced but as a partial observation process over the same latent object trajectory. The adjacency graph then estimates the latent object cluster by unioning temporal evidence across trackers.

A third loop involves the benchmark evaluator’s clock. nuScenes and KITTI evaluate tracking under different frequencies and categories. The source notes nuScenes annotations at 2 Hz and KITTI at 10 Hz [PAGE 8]. A method tuned on one temporal scale may fail on another because motion prediction error grows with frame displacement. Offline-Poly’s counter-clock is the explicit horizon: predictions beyond one second are discarded [PAGE 5], and sliding-window refinement beyond four seconds becomes unreliable [PAGE 12]. This prevents the evaluator’s long-horizon expectation from forcing the model to extrapolate beyond physical model validity.

The crisis-habit regression is especially visible when trackers produce entangled overlapping tracklets. An online habit is to trust the geometry-based merge because the boxes overlap in BEV. Offline-Poly instead asks: did the overlap persist over many frames, and does the connected-component structure indicate an entangled cluster? The source says: “FP associations typically corrupt trajectories locally around the mismatching event, while long-term segments before and after remain reliable.” [PAGE 6] The recursive counter-trap is to split at ambiguous frames, preserve reliable pre- and post-event segments, and re-link them using motion prediction. This avoids both the crisis of over-merging and the opposite crisis of over-splitting.

Finally, the method’s own self-model must avoid overconfidence in multi-source fusion. The source admits that max pooling “is susceptible to spurious edge responses” [PAGE 7]. A naive theory of mind would assume that any cross-tracker overlap proves same-object identity. Offline-Poly’s more cautious model is that max pooling is a recall-first graph builder, and later refinement must correct spatial and kinematic inconsistencies. Thus the recursive architecture is: upstream trackers provide hypotheses; offline graph clustering proposes identity sets; refinement checks physical plausibility; and evaluation metrics penalize residual identity and localization errors.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Cross-layer veto adjudication asks whether physical, biomechanical, or environmental constraints can override the algorithmic output of Offline-Poly. The answer is yes, but the vetoes are expressed as admissibility constraints rather than learned predictions.

First, the temporal extrapolation veto is exact. The source states: “Predictions exceeding 1 second are discarded to prevent drift.” [PAGE 5] This is a hard physical-motion constraint. If an object disappears for longer than the allowed horizon under the selected motion model, the STWO module will not create a confident bridge unless another tracker supplies evidence. Formally, if the gap duration \(\Delta t_{gap}>1\ \mathrm{s}\), the extrapolation operator is invalid. The veto is not weather-specific, but weather can cause the gap by reducing detections.

Second, the rigid-size veto is physical. The source says: “A fundamental property of rigid objects is the temporal invariance of physical size.” [PAGE 8] For cars, trucks, buses, and rigid-bodied objects, large fluctuations in estimated size across frames indicate either observation noise, pose error, or category confusion. Global refinement uses top-\(K\) reliable observations to enforce temporal invariance. If \(K<4\), the estimate is underconstrained; if \(K>14\), outliers dominate. The source’s sensitivity analysis states this exactly [PAGE 12]. Therefore, a physical veto is: if the variance of size observations after corner alignment remains high, the tracklet should not be treated as a stable rigid object for downstream label generation.

Third, the motion-model veto is kinematic. The local sliding-window optimizer assumes that a chosen motion model, such as constant velocity, is locally valid. The source states: “Extending the prediction range beyond 4 seconds reduces accuracy due to motion-model drift.” [PAGE 12] If an object undergoes abrupt acceleration, sharp turning, or non-constant velocity beyond the model’s validity, the optimizer may smooth the trajectory into a physically implausible path. The veto condition is that the residual motion error over the window must remain below a threshold tied to the state units: meters for center position, meters per second for velocity, and radians for heading. If residuals exceed this, the local refinement should be rejected or the window shortened.

Fourth, the category-consistency veto is semantic-physical. The source says: “Category-consistent association is enforced to maintain semantic consistency.” [PAGE 7] A car cluster should not fuse with a pedestrian cluster merely because boxes overlap in BEV. This is especially important in dense scenes where a pedestrian stands near a vehicle. The veto is: if \(\mathrm{CLS}_i\neq \mathrm{CLS}_j\) and the trackers disagree on class with high confidence, the multi-tracker adjacency edge should be suppressed.

Fifth, the weather/environment layer enters indirectly through upstream observation quality. Offline-Poly does not ingest raw LiDAR or camera data; it ingests tracklets. Therefore, weather cannot directly veto a tracklet except by changing the statistics of the upstream outputs. In rain, fog, snow, or low illumination, LiDAR returns may be sparse or noisy, and camera features may degrade. Upstream trackers may produce low confidence, short age, fragmented tracklets, or delayed detections. Offline-Poly’s pre-processing filter vetoes low-age and low-confidence tracklets only when both are below thresholds [PAGE 4]. If a true object survives only as a low-confidence, short-age tracklet in adverse weather, it may be removed. Conversely, if multiple trackers independently observe it, multi-tracker fusion can rescue it. The formal condition is: weather-induced degradation is vetoed if \(\overline{\mathrm{Conf}}_i<\theta_{score}\) and \(A_i<\theta_{age}\) for all relevant upstream tracklets, and no cross-tracker cluster provides sufficient evidence.

Sixth, the graph-topology veto is computational-physical. The multi-tracker adjacency matrix uses max pooling over frames [PAGE 7]. This is recall-biased. In dense traffic, accidental overlaps across many frame pairs can create a giant connected component containing multiple objects. The DFS clustering then over-merges. The veto condition is: if a cluster contains multiple plausible motion modes or inconsistent sizes after global refinement, the cluster should be split or rejected. The source’s one-to-many assumption allows multiple hypotheses per object, but it does not eliminate the need for physical consistency checks.

Finally, the benchmark-metric veto is epistemic. HOTA jointly penalizes localization error, false positives, false negatives, and identity switches [PAGE 8]. Therefore, an operation that increases recall by max pooling but creates identity switches may not be admissible under HOTA, even if AMOTA or MOTA appears improved in another setting. The source reports Offline-Poly achieves 83.00% HOTA on KITTI test and 77.6% AMOTA on nuScenes test [PAGE 1, PAGE 9–10]. These results show that the admissible operating point is not merely maximal graph connectivity but balanced precision-recall under the chosen evaluation geometry.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
The following are three verifiable RLVR-style counterfactual veto scenarios. Each scenario identifies a condition under which Offline-Poly should be rejected, modified, or expected to degrade, and each includes a prediction grounded in the source’s reported numbers.

1. **Single-source-only veto: multi-tracker evidence is removed**  
   Counterfactual: remove all additional upstream trackers and retain only one upstream tracking result.  
   Formal condition: \(N=1\), so \(N_{all}=N^1_{sin}\), and the multi-tracker adjacency matrix collapses to intra-tracker adjacency only. The source’s MTM module is then inactive.  
   Source evidence: Table I shows that with CenterPoint and Fast-Poly, Offline-Poly improves AMOTA from 73.7 without Offline-Poly to 74.8 with Offline-Poly under forward tracking, 75.5 under backward tracking, and 76.2 under bidirectional tracking [PAGE 8]. When multi-modal MV2DFusion is combined with Fast-Poly forward and backward, AMOTA reaches 81.3, and adding ADA-Track raises it to 81.4 [PAGE 8]. The source states: “By combining appearance-based and geometry-based trackers, complementary spatio-temporal cues are leveraged, resulting in improved trajectory completeness (81.4% AMOTA).” [PAGE 9]  
   Prediction: if a system relies on only one upstream tracker, Offline-Poly can still improve fragmentation and filtering, but it loses the recall benefit from complementary hypotheses. In high-occlusion scenes, fragmented pedestrian or vehicle trajectories that would have been recovered by a second tracker will remain incomplete. Expected outcome: lower AMOTA and possibly higher FN relative to multi-tracker fusion, especially for long occlusions.

2. **Weak pre-processing veto: only one of age or score filtering is used**  
   Counterfactual: disable either the age filter or the score filter, leaving only one criterion.  
   Formal condition: retention becomes \(\mathrm{keep}(T_i)=\neg(A_i<\theta_{age})\) or \(\mathrm{keep}(T_i)=\neg(\overline{\mathrm{Conf}}_i<\theta_{score})\), rather than the conjunction-based rejection used in the full method.  
   Source evidence: Table III reports that using score only yields 69.9 AMOTA, age only yields 72.0 AMOTA, and both together yield 74.0 AMOTA, compared with baseline 73.7 AMOTA [PAGE 9]. The source states: “applying a single filtering criterion … proves overly restrictive, resulting in lower recall and degraded overall performance.” [PAGE 10]  
   Prediction: score-only filtering will delete short but real objects because their average confidence is low; age-only filtering will retain long-lived false positives. The downstream matching graph becomes either too sparse or too noisy. Expected outcome: AMOTA drops relative to dual filtering; false negatives increase under score-only, while false positives and ghost tracklets increase under age-only. IDS may also change unpredictably because graph connectivity changes.

3. **Motion-based STWO veto: replace geometric IoU matching with a less reliable affinity**  
   Counterfactual: replace the proposed motion-based IoU/gIoU tracklet re-identification with a learned or weaker affinity, or set the re-identification threshold too loose.  
   Formal condition: the cost \(C^{ReID,t}_{i,j}\) is no longer a strict geometric dissimilarity, or \(\theta_{blo}\) approaches 1.  
   Source evidence: Table VIII compares matchers on the STWO module: OTOP with NN achieves 64.1 MOTA and 367 IDS; Motion with gIoU3d achieves 64.7 MOTA and 380 IDS; Motion with A-gIoU3d achieves 64.8 MOTA and 380 IDS; Motion with IoU achieves 65.0 MOTA and 251 IDS [PAGE 10]. The source also states: “An excessively loose threshold (=1) leads to FP matching, degrading the system performance.” [PAGE 12]  
   Prediction: if the affinity is not sufficiently discriminative, fragmented tracklets are incorrectly merged, increasing identity switches or creating false trajectories. If the threshold is too loose, geometrically accidental overlaps cause FP matching. Expected outcome: MOTA and AMOTA decline, while IDS or FP-related metrics worsen depending on whether the error is over-merging or over-connecting. The strongest admissible configuration uses strict geometric cost and a moderately relaxed threshold, with the source noting optimal performance “around 0.9” for STWO [PAGE 12].

Additional verifiable veto pattern: **sliding-window horizon veto**. If the local refinement window exceeds the source’s stated stable horizon, the prediction should be rejected. The source states: “Extending the prediction range beyond 4 seconds reduces accuracy due to motion-model drift.” [PAGE 12] Counterfactual prediction: if \(M/2\) corresponds to more than four seconds at the dataset frame rate, the refined trajectory will show increased position and heading error, especially during turning or acceleration. This veto is especially important for pedestrians and cyclists, whose motion can deviate from constant velocity more abruptly than rigid vehicles.
</RLVR_COUNTERFACTUAL_VETOES>
