Today’s $S_{\mathrm{rec}}$ influences tomorrow’s behavior; tomorrow’s behavior alters strain, sleep, and HRV; the altered physiology changes the next score. This is a closed-loop controller with the human in the loop, but the patent discloses no anti-windup or deadband, so the user can enter limit-cycle behavior: low score → rest → artificially inflated next-day score → hard training → crash → low score.
