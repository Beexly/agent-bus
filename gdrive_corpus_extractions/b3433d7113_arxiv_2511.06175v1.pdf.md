<THINK_TRACE>
The source is not a black-box classifier; it is a constraint-satisfaction-to-posterior pipeline. The multi-hop derivation is: (1) raw logs become a constraint set \(C_t\) with four classes, evidence \(E\), phenomenon \(P\), assertions \(A\), and hypotheses \(H\); (2) hard constraints define the feasible assignment space \(AS_t\); (3) every feasible world-state assignment \(a:P\to R\) receives a soft score; (4) scores are normalized into \(Pr(a\mid C_t)\); (5) player-role marginals and a MAP world are read out; (6) marginal accuracy and MAP accuracy are averaged over rounds and games. The paper states the key compression: “Hard constraints prune impossible role assignments, while weighted soft constraints score the remainder; information-gain weighting links each hypothesis to its expected value under entropy reduction, and a simple closed-form scoring rule guarantees that truthful assertions converge to classical hard logic with minimum error” [PAGE 1]. That sentence is the whole architecture in miniature: symbolic pruning, probabilistic scoring, information-theoretic weighting, and a limiting theorem.

The central gray-zone is the word “truthful.” The error bound is not unconditional. Page 3 says: “When all assertions are truthful, using high–weight soft constraints is (almost) equivalent to treating them as hard constraints: the posterior probability error is bounded by \(|Prs(a) - Prh(a)| \le 1/w_A\)” [PAGE 3]. Page 9 repeats the premise: “Suppose all assertion constraints in A are truthful” and concludes “A straightforward bounding of the residual term shows \(|Prs(a) - Prh(a)| \le 1/w_A\)” [PAGE 9]. Therefore the theorem is a truth-conditioned limit, not a deception-robust guarantee. If a false assertion enters \(A\), the high weight \(w_A \gg 1\) can deterministically favor the liar’s world. The paper’s own lie split is tiny: “Because the Lying-Good split contains only a handful of games (n = 4)” [PAGE 5]. So the empirical audit for deception is preliminary, not a rebuttal of the poisoning regime.

A second gray-zone is empty feasibility. The printed feasible set is \(AS_t=\{a\mid a\models E,\ a\models P\}\) [PAGE 3]. If a false hard evidence item or incompatible phenomenon is injected, then \(AS_t=\varnothing\), the denominator \(\sum_{a'\in AS_t} S(a')\) is zero, and the posterior is undefined. The paper says “Each new evidence or phenomenon constraint reduces the feasible assignment space” [PAGE 3], but monotone reduction can reduce to nothing. Operationally this requires inconsistency detection or constraint relaxation; the equations alone do not supply it. A third gray-zone is role cardinality. The equations as printed do not show an explicit cardinality operator, yet the LLM prompt asks for a “MAP assignment that respects the known role counts” [PAGE 4]. Thus the printed CSP formalism is incomplete unless the implementation adds global role-count constraints. A fourth gray-zone is extraction fidelity: the paper claims “As all extractions reached 100% fidelity, we do not report extraction accuracy separately in the experiments” [PAGE 11], but the human audit is described for Datasets 1 and 2, while AvalonLogs is programmatic and dialogue-free. A false hard constraint in a live pipeline would be more damaging than a false soft hypothesis because it prunes before scoring.

The empirical audit also has non-uniform discriminative power. The Random row reports Mafia MAF at \(1.00/1.00\) [PAGE 5], so that column is near-ceiling and cannot separate methods. The stronger evidence is Avalon, where the paper reports “CSP methods dominate consistently” [PAGE 5] and “LLM struggles with complex reasoning” [PAGE 5]. The hybrid is not uniformly additive: on Avalon objective and Loyal Servant views, CSP-assisted LLM gains are minimal or negative, while on simpler Mafia the hybrid can surpass pure CSP [PAGE 6]. The LLM capacity ablation further undercuts a scale-only interpretation: “increasing model scale yields only modest and sometimes negative returns on role-inference accuracy” [PAGE 7], and “the performance bottleneck is not a matter of model capacity but a conceptual limitation” [PAGE 7]. The deeper inference is that CSP4SDG is best read as a structured belief-state engine with an LLM as a constraint extractor, not as an LLM reasoner with a decorative solver.

The formal model is an SDG-CSP tuple \(M_t=(P,R,C_t)\), where \(P=\{p_1,\dots,p_n\}\) is the player set, \(R=\{r_1,\dots,r_m\}\) is the role set partitioned into good and evil, and \(C_t=E\cup P\cup A\cup H\) is the accumulated constraint set [PAGE 2, PAGE 3]. A world-state assignment is a function \(a:P\to R\). The feasible set is
\[
AS_t=\{a\mid a\models E,\ a\models P\},
\]
and hard updates are
\[
AS_{t+1}=\{a\in AS_t\mid a\models c\},\qquad AS_{t+1}\subseteq AS_t,
\]
for \(c\in E\cup P\) [PAGE 3]. The paper states: “Each new evidence or phenomenon constraint reduces the feasible assignment space” [PAGE 3].

For soft constraints, the score is
\[
S(a)=\left(\prod_{c\in A,\ a\models c}w_A\right)\left(1+\sum_{h\in H,\ a\models h}w_H(h)\right),
\]
where \(w_A\gg 1\) and the hypothesis weights are either manual or information-gain based [PAGE 3]. The posterior is
\[
Pr(a\mid C_t)=\frac{S(a)}{\sum_{a'\in AS_t}S(a')}.
\]
Information gain is
\[
IG(h)=H(\text{prior})-H(\text{posterior}\mid h),
\]
with entropy
\[
H(X)=-\sum_x Pr(x)\log Pr(x),
\]
and \(w_H(h)=IG(h)\) [PAGE 3]. Page 1 summarizes this as “information-gain weighting links each hypothesis to its expected value under entropy reduction” [PAGE 1].

The accuracy metrics are
\[
MA_q=\frac{1}{P}\sum_{p=1}^{P}a_{p,r_p^\star},\qquad
MAP_q=\frac{1}{P}\sum_{p=1}^{P}\mathbf{1}[\hat r_p=r_p^\star],
\]
then averaged over rounds \(Q\) and games \(G\) [PAGE 5]. These are dimensionless proportions; percentage-point changes are \(100\Delta\) in those proportions. The weights \(w_A,w_H\) are dimensionless. Entropy is in bits if \(\log_2\) is used and nats if \(\ln\) is used; the paper writes \(\log\) without specifying the base, so the numerical IG scale is base-dependent even though relative ordering is preserved. The model contains no physical SI dimensions; it is a discrete probability and information model.

Assumptions and breakdown regimes are exact. First, the theorem assumes truthful assertions. Page 9: “Suppose all assertion constraints in A are truthful” and the bound is \(|Prs(a)-Prh(a)|\le 1/w_A\) [PAGE 9]. If \(w_A=1\), the bound is vacuous and assertions no longer act as near-hard constraints. If \(w_A\to\infty\), truthful assertions collapse to hard logic; false assertions collapse to the liar’s logic. Second, if \(AS_t=\varnothing\), the posterior denominator is zero and \(Pr(a\mid C_t)\) is undefined. Third, if \(H(\text{prior})=0\) or the hypothesis has zero entropy reduction, \(IG(h)=0\) and the hypothesis contributes no weight. Fourth, exhaustive enumeration becomes infeasible for large \(n\); the paper’s MCMC fallback is \(O(Mn)\) and is not deployed because current datasets are \(n\le 10\) [PAGE 3]. Fifth, false hard constraints from the LLM extractor cause irreversible pruning; the paper’s “100% fidelity” claim is scoped to the audited dialogue datasets: “As all extractions reached 100% fidelity, we do not report extraction accuracy separately in the experiments” [PAGE 11]. Sixth, the printed feasible set lacks an explicit global role-count operator, while the prompt requires a “MAP assignment that respects the known role counts” [PAGE 4]; implementations must add cardinality constraints or risk invalid worlds. Seventh, weight scaling is empirically flat within the reported range: “Scaling all weights by factor \(\lambda \in \{0.25, 0.5, 1, 2, 4\}\) set altered MAP accuracy by \(\le 1.5\) pp (percentage points)” [PAGE 5], so the method is not highly sensitive to that scaling, but this is an empirical stability claim, not a theorem.
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
The scientific lineage is a merge of three older programmatic traditions. The first is classical constraint satisfaction: variables, finite domains, and hard relations that must all hold, with propagation and backtracking providing exact, interpretable search [PAGE 9]. The second is soft and valued CSP: violations receive costs so near-consistent worlds can be ranked [PAGE 9]. The third is probabilistic or mixed CSP: some variables are stochastic and the objective is likelihood of constraint satisfaction [PAGE 9]. CSP4SDG inherits all three but changes the weighting source: instead of hand-tuned costs, it uses information gain and expected entropy reduction, connecting to MacKay-style information-based objective functions and value-of-information reasoning [PAGE 9]. The paper explicitly frames its contribution as a bridge: “We merge these ideas: conversational evidence becomes soft CSP constraints whose weights are proportional to their VOI” [PAGE 9].

The SDG lineage runs from lexical and pragmatic deception cues, through the Mafiascum corpus and supervised classifiers, to transformer role classifiers, DeepRole-style reinforcement learning, psychologically inspired mental-state agents, and planning-LLM hybrids such as Cicero [PAGE 1, PAGE 9]. The retrocausal inversion is important: CSP4SDG does not try to make the LLM a better deductive reasoner; it makes the LLM an information converter that emits structured constraints, then lets a solver enforce logical consistency and entropy-weighted scoring [PAGE 9]. That inversion explains why the paper reports “LLMs excel at information extraction but not at the structured reasoning as CSP does” [PAGE 6].

The multi-week traps are predictable from that lineage. Trap one: treating dialogue as opaque text and hoping model scale solves combinatorial inference. The ablation reports “increasing model scale yields only modest and sometimes negative returns on role-inference accuracy” [PAGE 7]. Trap two: extracting hard constraints from noisy language without a dual-author audit. The paper’s audit is strong on Datasets 1 and 2, but the live failure mode is a false “role is” or “evil at least” constraint that empties or distorts \(AS_t\). Trap three: ignoring the truth-conditioned theorem. The bound \(1/w_A\) is not a deception defense; false assertions are precisely the counter-trap. Trap four: over-reading the small lie sample. The Lying-Good split has \(n=4\) [PAGE 5], so claims about robust deception handling are preliminary. Trap five: assuming hybrid gains are monotone. On Avalon objective and Loyal Servant views, CSP-assisted LLM gains are minimal or negative, while on simpler Mafia the hybrid can surpass pure CSP [PAGE 6]. Trap six: confusing marginal and MAP calibration. The paper observes that “pure CSP consistently shows slightly higher marginal accuracy compared to MAP accuracy” while LLM methods show the reverse [PAGE 6]; a system tuned only for MAP can hide a poorly calibrated posterior.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
Recursive theory-of-mind in this paper is not a separate module; it is encoded through perspective evidence and soft constraints. Page 5 defines views \(V=\{\text{objective}\}\cup\{\text{each role}\}\): Merlin gets hard constraints that all evils are known, Percival constrains Merlin/Morgana candidates, evil roles reveal fellow evils, and otherwise none [PAGE 5]. This is a compact recursive model: the agent’s private role changes its belief state, which changes which worlds are feasible. The empirical result is that “Good-role perspectives (blue) achieve higher accuracy, evil-role perspectives (red) exhibit broader variance, and objective views (gray) record lower accuracy levels” [PAGE 7]. That is exactly what a recursive ToM account predicts: private information narrows the hypothesis space, while the objective observer must infer from public evidence alone.

The crisis-habit regression mode is the LLM’s fallback to surface heuristics under sparse or adversarial dialogue. The paper reports that pure LLM methods “have minimal improvements or even degrade over time, especially in the LLM-turn mode” [PAGE 6], and that “Even with 100% correct CSP priors, the LLM struggles to disregard misleading or irrelevant dialogue elements” [PAGE 6]. This is a habit regression: when the combinatorial burden rises, the model reverts to frequency and salience rather than maintaining a coherent belief state. The larger-model ablation reinforces the diagnosis: scale produces “modest and sometimes negative returns” [PAGE 7]. In recursive ToM terms, the model fails to hold nested beliefs about what other players know and intend; it treats each utterance as a local cue rather than as an action in a belief game.

The counter-trap mode is deception. Assertions are weighted \(w_A\gg 1\), so a false role claim is not a minor perturbation; it is a near-hard constraint on the scoring side. The theorem’s truth premise is therefore a vulnerability. The paper’s Lie split is small, and it says “A larger, dedicated study of deception effects is left for future work” [PAGE 6]. A counter-trap-aware system needs a truth model or credibility variable on assertions, not just a high constant weight. Otherwise a good-aligned liar or an evil manipulator can force the posterior toward a false world.

The clock mode is temporal belief update. Hard constraints prune monotonically across quests or day/night cycles; soft hypotheses accumulate; +TurnIG uses current-turn hypotheses with IG weights; +HypIG uses global hypotheses [PAGE 4, PAGE 5]. The quest-by-quest plots show CSP methods improving from Quest 3 onward and rising sharply at the assassination round, while LLM-turn mode can degrade [PAGE 6]. That is a clock effect: evidence arrives in ordered blocks, and the posterior must be updated rather than recomputed from a bag of text. The paper’s real-time claim, “The resulting posterior over roles is fully interpretable and updates in real time” [PAGE 1], is plausible for \(n\le 10\) enumeration but not for large lobbies without the \(O(Mn)\) MCMC approximation. The recursive ToM conclusion is therefore conditional: CSP provides the clock and the feasible belief space; the LLM provides noisy observations; without a deception model, the counter-trap remains the weak layer.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
There is no physical, biomechanical, or weather layer in the source model. The tuple is \(M_t=(P,R,C_t)\), with \(C_t=E\cup P\cup A\cup H\) [PAGE 3]. The only state variables are players, roles, assignments, and extracted constraints. There is no sensor stream, no body-state variable, no biomechanical torque or fatigue variable, and no meteorological variable. Therefore a claim that weather or biomechanics “vetoes” a role inference is not admissible under the paper’s operators unless that information is first mapped into a constraint \(c\in E\cup P\cup A\cup H\).

A formal veto proof is straightforward. Let \(X\) be any external physical, biomechanical, or weather state. If \(X\) is not mapped into \(C_t\), then
\[
Pr(a\mid C_t,X)=Pr(a\mid C_t),
\]
because the posterior depends on \(X\) only through \(C_t\). The feasible set \(AS_t\) and score \(S(a)\) are functions of \(C_t\), not of \(X\) directly. Thus \(X\) cannot change the posterior, cannot prune a world, and cannot veto an assignment. If \(X\) is mapped, the mapping must specify whether it is evidence, phenomenon, assertion, or hypothesis. A physical sensor reading would need to be encoded as hard evidence to prune \(AS_t\); a soft biomechanical cue would need a weight \(w_H\). The paper provides no such mapping, no calibration, and no validation for physical or weather variables. The correct adjudication is therefore: cross-layer physical veto is out of scope and unproven in this source. The only admissible cross-layer statement is that any external layer must be translated into the same four constraint classes and must obey the same empty-set and truth-conditioned breakdown regimes.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Scenario 1: assertion-poisoning veto. Take a Truth game from Avalon-NLU and flip one high-weight role assertion from true to false while keeping all hard constraints and role counts fixed. The CSP+Assert posterior should shift sharply toward the false assertion because \(w_A=10{,}000\) and the theorem’s premise is violated. Verifiable prediction: on the flipped item, marginal accuracy for the affected player drops substantially relative to Strict, and the MAP world satisfies the false assertion if it remains feasible. Veto condition: if the posterior remains unchanged or improves, then either the assertion is not actually entering \(A\), or the solver is not applying the multiplicative \(w_A\) term of Eq. (1). This directly tests the boundary between the truthful limit and the deceptive counter-trap.

Scenario 2: false-hard-evidence veto. Inject one false hard evidence constraint, for example “role is(player-3, merlin)” when the ground truth is servant, while retaining role counts. The printed feasible set \(AS_t=\{a\mid a\models E,\ a\models P\}\) [PAGE 3] should either become empty or exclude the true world. Verifiable prediction: the solver either returns \(AS_t=\varnothing\) and an undefined posterior, or returns a posterior with zero mass on the true assignment; accuracy on that game collapses. Veto condition: if the system returns a calibrated posterior with unchanged accuracy and no inconsistency flag, then the implementation is not enforcing hard constraints as specified. This scenario is especially relevant to LLM extraction errors because a false hard constraint prunes before soft scoring can correct it.

Scenario 3: weight-scaling and model-scale invariance veto. The paper reports that scaling all weights by \(\lambda\in\{0.25,0.5,1,2,4\}\) altered MAP accuracy by \(\le 1.5\) pp [PAGE 5], and that increasing LLM scale yields “only modest and sometimes negative returns” [PAGE 7]. Verifiable prediction: re-run the same Avalon-NLU evaluation across those \(\lambda\) values and across GPT-4o-mini, GPT-4o, GPT-4.1, DeepSeek-v3, and Gemini-2.0-flash; MAP changes should stay within the reported band, and the LLM-only ranking should not show a large monotone scale advantage. Veto condition: if a \(\lambda\) change produces a large MAP swing, or if a larger backbone produces a large uniform gain over smaller backbones, then the claimed weight stability and the “conceptual limitation” diagnosis are falsified. A fourth, optional check is hybrid monotonicity: on Avalon objective and Loyal Servant views, CSP assistance should not be assumed uniformly positive [PAGE 6]; a uniform large gain there would veto the paper’s own non-monotone hybrid interpretation. These scenarios are verifiable because they use the paper’s own metrics, its own weights, and its own reported thresholds rather than an invented reward.
</RLVR_COUNTERFACTUAL_VETOES>
