The source is a mathematical monograph, not an empirical dataset, so the first multi-hop step is to translate every stabilization statement into a topological statement about a continuous map or vector field. The core formal object is a continuous control system \(\mathcal{S}=(M,U,F)\), with \(F:U\to TM\) fiber-preserving over \(M\), and a feedback \(\mu:M\to U\) whose closed loop is \(F\circ\mu:M\to TM\) [PAGE 67]. Because continuity is preserved under composition, a topological obstruction to a continuous closed-loop vector field \(X=F\circ\mu\) satisfying property \(P\) immediately obstructs every continuous feedback in that class. This is exactly the “composition” reduction stated in Remark 5.1: if no continuous vector field on \(M\) has \(P\), then no continuous feedback can force \(F\circ\mu\) to have \(P\) [PAGE 72]. The second hop is to identify which properties \(P\) are topologically forced. For an isolated locally asymptotically stable equilibrium \(p^\star\), the vector-field index is not free: \(\operatorname{ind}_{p^\star}(X)=(-1)^n\) [PAGE 44]. On a smooth compact oriented boundaryless \(n\)-manifold, Poincaré–Hopf forces \(\chi(M)=\sum_{i\in I}\operatorname{ind}_{p_i^\star}(X)\) for isolated zeros [PAGE 42]. Therefore, if one proposes to globally asymptotically stabilize a single isolated equilibrium by continuous static feedback on a compact manifold, the Euler characteristic must agree with \((-1)^n\), and on many manifolds it cannot. The third hop is the stronger retraction/domain-of-attraction theorem: for a locally asymptotically stable equilibrium \(p^\star\), the domain of attraction \(D(\phi_X,p^\star)\) is open and contractible to \(p^\star\) [PAGE 84]. If the stabilization is global, then \(D=M\), so a noncontractible \(M\) is an immediate veto: “when \(M\) is not contractible, there is no \(p^\star\in M\) that happens to be globally asymptotically stable under the flow of some complete vector field \(X\in\mathfrak{X}^r(M)\)” [PAGE 85]. The fourth hop specializes to vector bundles: if \(\pi:M\to B\) is a vector bundle over a compact boundaryless base \(B\), then an isolated globally asymptotically stable equilibrium cannot exist on \(M\) [PAGE 86]. The proof uses the zero section as a deformation retract and the noncontractibility of compact boundaryless bases. The fifth hop extends from points to submanifolds and sets: if \(A\) is a compact attractor with domain \(D\), then \(A\) is a weak deformation retract of \(D\) [PAGE 99]. Hence a global attractor must be a deformation retract of the ambient manifold. For a compact submanifold \(A\) inside the zero section of a vector bundle, the only possible global attractor is the whole zero section \(Z_\pi(B)\) [PAGE 96]. For arbitrary compact sets, Kvalheim–Koditschek give a Brockett-type necessary condition when \(\chi(A)\neq 0\) [PAGE 98]. The sixth hop is the local multistability and odd-number layer: for hyperbolic equilibria, the unstable manifold dimensions must be even if all zeros are to be locally asymptotically stabilized without introducing new equilibria [PAGE 91]. This is compatible with the Poincaré–Hopf count and explains why odd-dimensional unstable manifolds can create an index obstruction.

The gray-zone audit is essential. The source repeatedly assumes smooth compact oriented boundaryless manifolds for Poincaré–Hopf; for vector fields only continuous, Corollary 3.1 extends the result when zeros are isolated [PAGE 42]. The theorem breaks if \(M\) is noncompact without a properness hypothesis, if zeros are nonisolated, if the vector field is not defined on all of \(M\), or if the boundary is present without the inward/outward-pointing boundary modification [PAGE 120]. Brockett’s condition is necessary, not sufficient; it can hold while no smooth feedback exists [PAGE 84]. Zabczyk’s index condition strengthens Brockett but is not necessary for dynamic feedback [PAGE 81]. Time-varying feedback can evade some local obstructions, but not all global ones; the augmented clock \(\dot s=1\) diverges as \(t\to+\infty\), so Example 6.4 uses partial stability and uniform-in-\(s\) stabilization to recover an obstruction [PAGE 86–87]. Discontinuous feedback does not automatically remove obstructions: “Brockett’s condition even prevails when certain forms of discontinuous feedback are allowed” [PAGE 82], and the solution notion itself affects the obstruction [PAGE 82]. Almost global stabilization is not a robust substitute: although the excluded set may have measure zero in the idealized model, under arbitrarily small perturbations “this set to avoid remains by no means of measure zero” [PAGE 114]. Units are similarly constrained: \(n,m,z,\chi,\operatorname{ind},b_k\) are dimensionless integers; time \(t\) has units of seconds in physical models; feedback inputs \(u\) carry the physical units of the actuator; probability measure is dimensionless; the source uses no entropy or information-rate units, and topological invariants are dimensionless. Thus the audit must reject pseudo-quantities and require dimensionally consistent state, input, and time variables.

<SOURCE_OPERATORS_AND_EQUATIONS>
The source’s main operators are continuous control systems, continuous feedback sections, vector-field indices, Euler characteristics, retractions, deformation retracts, and homological degree conditions. The base control object is
\[
\mathcal{S}=(M,U,F),\qquad \pi_u:U\to M,\quad \pi_x:TM\to M,\quad \pi_x\circ F=\pi_u,
\]
with \(F\) continuous and fiber-preserving [PAGE 67]. A continuous static feedback is a continuous section \(\mu\in\Gamma^0(U)\), so the closed-loop vector field is \(F\circ\mu:M\to TM\) [PAGE 67]. Assumption 5.1 adds completeness and unique integrability of vector fields when flows are used [PAGE 59]. The dimensional bookkeeping is: \(M\) has dimension \(n\in\mathbb{N}\), \(U\) has input dimension \(m\in\mathbb{N}\), time \(t\) is in seconds for physical systems, and \(F\circ\mu\) has units of state per second.

The central invariant is the index of an isolated zero:
\[
\operatorname{ind}_{p^\star}(X)=\deg\!\left(v:\partial U\to S^{n-1},\ v(p)=\frac{X(p)}{\|X(p)\|_2}\right),
\]
with \(\operatorname{ind}_{p^\star}(X)\in\mathbb{Z}\) dimensionless [PAGE 40]. For a locally asymptotically stable isolated equilibrium,
\[
\operatorname{ind}_{p^\star}(X)=(-1)^n,
\]
also dimensionless [PAGE 44]. On a smooth compact oriented boundaryless manifold \(M\),
\[
\chi(M)=\sum_{i\in I}\operatorname{ind}_{p_i^\star}(X),
\]
where \(\chi(M)\in\mathbb{Z}\) is the Euler characteristic and the sum is finite for isolated zeros [PAGE 42]. The continuous-vector-field version is Corollary 3.1 [PAGE 42]. The exact breakdown regimes are: noncompact \(M\) without properness; boundary present without the inward/outward correction; nonisolated zeros; failure of orientability or of the compactness hypothesis; and vector fields that are not continuous. The boundary variant is stated on [PAGE 120]: if \(X\) points inward along \(\partial M\), the indices sum to \((-1)^m\chi(M)\); for outward pointing fields, Poincaré–Hopf is unchanged.

Brockett’s necessary condition is:
\[
\exists\,\mu\in C^0(M,\mathbb{R}^m),\ \mu(0)=0,\ \text{with }0\text{ locally asymptotically stable}
\ \Longrightarrow\
f:\mathcal{O}(0,0)\to\mathcal{O}(0)\text{ is surjective}.
\]
This is stated as “only if \((x,u)\mapsto f(x,u)\) is a surjective map from a neighbourhood of \((0,0)\) onto a neighbourhood of \(0\)” [PAGE 79]. It is necessary but not sufficient; it can hold while no smooth stabilizing feedback exists [PAGE 84]. Zabczyk’s index condition strengthens it:
\[
\mu(0)=0,\ 0\text{ locally asymptotically stable}
\ \Longrightarrow\
\operatorname{ind}_0\!\big(f(\cdot,\mu(\cdot))\big)=(-1)^n,
\]
dimensionless [PAGE 80]. It is not necessary for dynamic feedback in the non-lifted system [PAGE 81]. Coron’s homological condition is the induced-homomorphism form
\[
f_\star\!\left(H_{n-1}(\mathcal{E}_\varepsilon;\mathbb{Z})\right)
=
H_{n-1}(\mathbb{R}^n\setminus\{0\};\mathbb{Z})
\simeq\mathbb{Z},
\]
for \(n\ge2\), \(m\ge1\), under continuity of \(f\) and the existence of a continuous stabilizing feedback [PAGE 81]. The singular case \(n=1\) and the non-surjective map case are breakdown regimes.

Sontag’s global domain obstruction is:
\[
p^\star\text{ locally asymptotically stable}
\ \Longrightarrow\
D(\phi_X,p^\star)\text{ is open and contractible to }p^\star.
\]
The verbatim statement is: “the set \(D(\phi_X,p^\star)\) as given by (5.3) is open and contractible to \(p^\star\)” [PAGE 84]. If \(D=M\), then \(M\) must be contractible; therefore “when \(M\) is not contractible, there is no \(p^\star\in M\) that happens to be globally asymptotically stable” [PAGE 85]. Bhat–Bernstein specializes this to bundles: “there is no continuous vector field on \(M\) with an isolated globally asymptotically stable equilibrium point” when \(M\) is a vector bundle over a compact boundaryless base of dimension at least one [PAGE 86]. The proof uses the zero section as a deformation retract and the noncontractibility of compact boundaryless manifolds [PAGE 86]. The global multistability count is:
\[
M^n\text{ admits a continuous }X\text{ with }z\text{ isolated locally asymptotically stable zeros}
\iff
\chi(M^n)=z,
\]
with \(z\in\mathbb{N}_{\ge0}\) and \(\chi\) dimensionless [PAGE 87]. For compact Lie groups \(G^n\) with \(n\ge1\), \(\chi(G^n)=0\) [PAGE 45], so global continuous stabilization of a point is obstructed [PAGE 85]. The odd-number local obstruction is:
\[
\dim W^u(\phi_X,p_i^\star)\text{ even for all }i\in I
\]
if the set \(\{p_i^\star\}_{i\in I}\) is to be locally asymptotically stabilized by continuous feedback without introducing new equilibria [PAGE 91]. The theorem assumes hyperbolic isolated equilibria; non-hyperbolic equilibria and non-isolated zeros are outside its exact scope.

For submanifolds, the retraction condition is: if \(A\) is a compact attractor with domain \(D(\phi,A)\), then “\(A\) is a weak deformation retract of \(D(\phi,A)\)” [PAGE 99]. If \(A\) is a compact embedded submanifold, it is a strong neighbourhood deformation retract of \(M\) [PAGE 95]. For a vector bundle \(\pi:M\to B\) and a compact embedded submanifold \(A\subseteq Z_\pi(B)\), if \(A\) is a global attractor under a continuous flow, then “\(A=Z_\pi(B)\)” [PAGE 96]. Therefore a proper compact submanifold of the zero section cannot be a global attractor. For arbitrary compact attractors with \(\chi(A)\neq0\), Kvalheim–Koditschek require the local surjectivity condition
\[
F(\pi_u^{-1}(W))\cap X(W)\neq\varnothing
\]
for every neighbourhood \(W\subseteq M\) of \(A\) and some neighbourhood \(V\subseteq TM\) of the zero section, with \(X:W\to V\) continuous [PAGE 98]. The breakdown regime is \(\chi(A)=0\), where this specific condition may be silent; retraction and homotopy methods must then be used instead [PAGE 100].

The source also records active evasion mechanisms. Hybrid control uses a family of Lyapunov functions and switching: “if one switches appropriately between controllers induced by these potential functions, one cannot get trapped at the wrong critical point and hence \(p^\star\) will be stabilized” [PAGE 113]. But hybrid switching is discontinuous and requires a jump-set/flow-set solution theory [PAGE 112]. Time-varying feedback works locally under controllability, but global uniform partial stabilization remains obstructed on noncontractible compact bases [PAGE 86–87]. Almost global stabilization “cannot be categorized as robust” because the excluded set is not measure zero under perturbations [PAGE 114]. Finally, Lusternik–Schnirelmann category gives a covering lower bound: if \(M\) is covered by local controllers each stabilizing a contractible attractor, one needs at least \(\operatorname{cat}(M)+1\) controllers [PAGE 121], and on \(S^1\) “one needs at least two of those controllers” [PAGE 114].

<RETROCAUSAL_GENEALOGY>
The lineage in the source runs from Poincaré’s qualitative dynamics and analysis situs through Brouwer’s degree and homotopy formalization, Borsuk’s retraction theory, and the Krasnosel’skii–Zabreiko index school, into modern nonlinear control. The preface states the core contrast: for linear systems, controllability implies a continuous globally asymptotically stabilizing feedback, but for controllable nonlinear systems “there might not exist a feedback that is both continuous, globally well-defined and stabilizing in the asymptotic sense” [PAGE 6]. The historical section credits Poincaré with the qualitative viewpoint, vector-field index, and transversality ideas [PAGE 6–7]; Brouwer with formalizing homotopy and degree around 1910 [PAGE 5]; Borsuk with retractions in the late 1920s [PAGE 5]; and Krasnosel’skii and Zabreiko with a large body of index-theoretic nonlinear analysis that predates Brockett’s Western formulation [PAGE 9]. The modern control lineage includes Jurdjevic–Quinn’s 1978 controllable planar system that cannot be stabilized by differentiable feedback, Sussmann’s 1979 demonstration that controllability does not imply continuous stabilizability, and Brockett’s 1983 necessary condition [PAGE 9]. Bhat–Bernstein’s 2000 bundle obstruction and the later retraction/domain theorems are descendants of the same program [PAGE 86, PAGE 99]. 

The multi-week traps are historical and conceptual. Trap one: assuming controllability implies stabilizability. The source explicitly says controllability “does not seem to play a key role when it comes to sufficiency” and that controllable systems may fail continuous feedback stabilization [PAGE 79]. Trap two: trusting local linearization. The nonholonomic integrator is controllable but its linearization is not informative, and Brockett’s condition fails [PAGE 80]. Trap three: treating continuous function approximators as rich enough. The source warns that “the space of continuous functions is sufficiently rich” is tempting but false when stability is desired [PAGE 13–14]. Trap four: treating almost global stabilization as robust. The source rejects this because perturbations can hit the excluded set [PAGE 114]. Trap five: assuming \(\chi(M)=0\) means no obstruction. The source’s retraction results show that Euler characteristic is only a coarse necessary condition; homotopy type and deformation retracts matter [PAGE 100]. Trap six: assuming time-varying or discontinuous feedback is an automatic escape. Time-varying feedback can evade local Brockett obstructions but not uniform global bundle obstructions [PAGE 86–87], and discontinuous feedback can still satisfy Brockett-type obstructions [PAGE 82]. These traps recur across multi-week research programs because each one replaces a global topological condition with a local or numerical proxy.

<RECURSIVE_THEORY_OF_MIND>
Under crisis pressure, the default habit regression is to treat stabilization as a controller-tuning problem: linearize, simulate, fit a continuous policy, and declare success if trajectories visually converge. The source shows why this habit fails: local linearization can miss topological impossibility [PAGE 80], continuous feedback can be obstructed by index and contractibility [PAGE 84–85], and numerical simulation can produce a vector field whose hyperbolic equilibria are generic and whose index is locally \(\pm1\) while the global count is impossible [PAGE 82–83]. The counter-trap is the opposite overcorrection: “if continuous static feedback fails, use time-varying or discontinuous or hybrid control.” That is sometimes correct locally, but not universally. Time-varying feedback is obstructed for uniform partial global stabilization over compact noncontractible bases [PAGE 86–87], and discontinuous feedback does not automatically remove Brockett-type obstructions [PAGE 82]. The clock trap is the time-augmentation habit \(\dot s=1\): it turns a time-varying system into an autonomous flow on \(S\times M\), but the augmented state diverges in \(s\), so ordinary global asymptotic stability is the wrong notion; one needs partial stability uniform in \(s\) [PAGE 86]. In recursive theory-of-mind terms, the agent must model not only the plant but also the verifier’s assumptions: compactness, boundaryless, orientability, isolated zeros, continuity class, feedback class, and whether “global” means \(D=M\) or only almost global. The source’s own language enforces this: the problem is posed on three levels—attractor topology, domain-of-attraction topology, and dynamics outside the domain [PAGE 77]. A disciplined agent should first ask “which invariant is forced?” and only then choose a controller class. If the invariant is \(\chi(M)\), index, contractibility, or deformation retract, the correct response is to state the necessary condition and downgrade the claim—not to invent a different controller and hope the obstruction disappears. This is the counter-trap against both naive continuous feedback and naive hybrid/time-varying escapism.

<CROSS_LAYER_VETO_ADJUDICATION>
A cross-layer veto is warranted when a lower layer supplies a state manifold, target set, feedback class, and stability notion that violate a necessary topological condition from this source. For a continuous static feedback claim of global asymptotic stabilization of a point on \(M\), veto if \(M\) is not contractible; Theorem 6.4 and its corollary make the domain of attraction contractible, so \(D=M\) is impossible on a noncontractible manifold [PAGE 84–85]. For a vector bundle \(\pi:M\to B\) over a compact boundaryless base \(B\), veto an isolated globally asymptotically stable point by Bhat–Bernstein [PAGE 86]. For a compact embedded submanifold \(A\subseteq Z_\pi(B)\), veto a global attractor unless \(A=Z_\pi(B)\) [PAGE 96]. For a compact attractor with \(\chi(A)\neq0\), veto if the Kvalheim–Koditschek surjectivity condition fails [PAGE 98]. For a set with \(\chi(A)=0\), do not veto solely on Euler characteristic; instead use the weak deformation retract condition \(A\) of \(D(\phi,A)\) [PAGE 99] and the strong neighbourhood deformation retract condition for submanifolds [PAGE 95]. For local multistability of hyperbolic equilibria, veto if any unstable manifold has odd dimension [PAGE 91]. For compact Lie groups, veto global continuous point stabilization because \(\chi(G)=0\) [PAGE 45].

The physical/biomechanical layer is directly represented by the pendulum on \(S^1\times\mathbb{R}\), the planar circle \(S^1\), the two-link robotic arm on \(T(S^2\times S^2)\), the satellite on \(T\mathrm{SO}(3)\), and the DNA rod on \(SE(3)\) [PAGE 2, PAGE 63, PAGE 96–97]. These are not decorative examples: the pendulum’s upright stabilization is a stabilization problem on a noncontractible state space, the robot arm cannot globally continuously stabilize a curve homeomorphic to \(S^1\) in the zero section of \(TS^2\), and the satellite cannot globally stabilize the pointing submanifold \(A\) by continuous feedback [PAGE 96–97]. A biomechanical gait or heartbeat model represented as a periodic orbit inherits the same submanifold and periodic-orbit constraints; the preface explicitly names “the stationary pumping of the heart and the gait of a walking robot” as periodic-orbit stabilization examples [PAGE 6]. The weather layer is not modeled in this source, so a meteorological veto cannot be directly proved from these pages. The only defensible cross-layer weather statement is a robustness veto: if a controller is certified only on an almost-global or measure-zero-excluded set, then weather-like perturbations invalidate the certificate because the excluded set need not remain measure zero [PAGE 114]; small perturbations can also invalidate a necessary condition used numerically [PAGE 100]. Thus weather uncertainty must downgrade a claim to a scenario-dependent one, not certify global asymptotic stability. The adjudication rule is therefore: topological vetoes are hard vetoes; physical examples are hard vetoes when their state space matches the theorem; weather claims are soft unless mapped to a perturbation model, in which case robustness failure is a hard veto against certification.

<RLVR_COUNTERFACTUAL_VETOES>
Scenario 1: An RL policy proposes a continuous static feedback law to globally asymptotically stabilize the upright pendulum on \(S^1\times\mathbb{R}\). Verifiable check: \(S^1\times\mathbb{R}\) deformation retracts to \(S^1\), which is not contractible; Sontag’s theorem requires the global domain \(D=M\) to be contractible [PAGE 84–85]. Prediction: no continuous static feedback can make the upright equilibrium globally asymptotically stable; the closed loop must retain an extra equilibrium, a periodic orbit, or an unwinding-type nonconvergent set. The verifier should inspect the closed-loop vector field on a cross-section \(S^1\) and check the index sum against \(\chi(S^1)=0\) [PAGE 42, PAGE 45]. A claimed certificate that reports a single stable equilibrium and no other limit set is vetoed.

Scenario 2: An RL policy claims continuous static feedback globally asymptotically stabilizes a rigid-body attitude on \(\mathrm{SO}(3)\). Verifiable check: \(\mathrm{SO}(3)\) is a compact Lie group, so \(\chi(\mathrm{SO}(3))=0\) [PAGE 45]; Bhat–Bernstein and Sontag then obstruct an isolated globally asymptotically stable equilibrium under continuous feedback [PAGE 85–86]. Prediction: any continuous static controller must leave additional equilibria or nontrivial limit sets; the index sum over zeros must equal \(0\), so a single stable zero of index \((-1)^3=-1\) would require another zero of index \(+1\), or a non-isolated zero, contradicting the certificate. The verifier should also check whether the policy secretly uses a discontinuity, a hybrid jump, or a time-varying clock; if so, the claim is outside the continuous-static class and must be re-verified under the appropriate solution notion [PAGE 82, PAGE 86–87].

Scenario 3: An RL policy uses time-varying feedback \(\dot s=1,\ \dot x=f(x,\mu(s,x))\) and claims uniform global asymptotic stabilization of a point on a compact vector bundle over a noncontractible base. Verifiable check: the source’s Example 6.4 constructs a homotopy contradiction for partial global asymptotic stability uniform in \(s\) when the base is a compact boundaryless manifold and the bundle is nontrivial enough to obstruct contraction [PAGE 86–87]. Prediction: if the certificate requires uniform-in-\(s\) convergence for all initial \(s\) and all \(x\), no continuous time-varying feedback exists; any simulation that appears to converge will either depend nonuniformly on \(s\), diverge in the clock coordinate, or rely on a non-robust almost-global exclusion. The verifier should test multiple initial clock values and check for uniformity of the settling-time bound; if the bound degrades with \(s\) or if the trajectory escapes to \(s\to+\infty\) without partial convergence, the claim is vetoed. A fourth, counterfactual success case is a hybrid controller on \(S^1\) using two potential functions; that can succeed, but it requires a jump map and at least two controllers by the category bound [PAGE 113–114, PAGE 121]. The verifier should predict success only for the hybrid class, not for continuous static feedback.
