Notes aligned to the same score note are ordered by onset; notes falling within a temporal window of $\tau = 35\text{ ms}$ are bundled into one vector, and subsequent notes form the next vector [PAGE 2]. Let $\mathcal{S} = \{s_1,\dots,s_N\}$ be the ordered score notes of a continuo line, and let $\mathcal{P} = \{p_1,\dots,p_M\}$ be the set of MIDI performance notes with onset times $t_m \in \mathbb{R}_{\ge 0}$ (units: ms) and MIDI pitch numbers $n_m \in \{0,\dots,127\}$ (unitless semitone integers). The alignment operator $\mathcal{A}: \mathcal{P} \to \mathcal{S}$ is implemented by dynamic time warping [PAGE 2]; the authors state that bass-note alignment is "nearly perfect" while the full alignment is "not perfect" [PAGE 2].

A griff window has fixed duration $\tau = 35\text{ ms}$ [PAGE 2]. For score note $s_i$, the aligned performance notes are partitioned into ordered vectors
\[
v_{i,j} = \left\{ p_m \in \mathcal{P} : \mathcal{A}(p_m)=s_i,\; t_m \in [t_{i,j}^{\text{start}},\, t_{i,j}^{\text{start}}+\tau) \right\},
\]
where successive windows advance by $\tau$ [PAGE 2-3]. A griff is the sequence $G_i = (v_{i,1},\dots,v_{i,K_i})$. Pitches are converted to intervals from the aligned bass note $b_i$:
\[
\iota(p_m) = n_m - b_i \in \mathbb{Z},
\]
yielding transposition-invariant interval content [PAGE 2-3]. String encoding joins interval values within a vector by "\_" and vectors by "\|" [PAGE 3]. A griff $k$-gram concatenates $k$ encoded griff strings with "\#" [PAGE 3].

For player classification, each performance $p$ is mapped to a bag-of-words feature vector over the vocabulary $\mathcal{T} = \{\tau_1,\dots,\tau_V\}$ of all griff types observed in the relevant data split [PAGE 3]:
\[
\phi(p)_j = \sum_{g \in G(p)} \mathbb{1}[g = \tau_j], \qquad j=1,\dots,V.
\]
Vocabulary sizes from Table 1 [PAGE 4]: whole dataset intervals $V=54$, griffs $V=7{,}061$, griff bigrams $V=14{,}107$, griff trigrams $V=15{,}989$. Total griff tokens after filtering empty griffs: 17,152 [PAGE 4].

The classifier is the scikit-learn SVC [PAGE 3, citing Pedregosa et al. 2011]. For a linear kernel, the primal optimization is
\[
\min_{w,b,\xi} \frac{1}{2}\|w\|^2 + C\sum_{i=1}^{N}\xi_i
\quad \text{subject to}\quad
y_i\bigl(\langle w,\phi(x_i)\rangle + b\bigr) \ge 1 - \xi_i,\;\; \xi_i \ge 0,
\]
where $y_i \in \{1,\dots,7\}$ indexes the harpsichordist [PAGE 3-4]. Evaluation uses stratified 5-fold cross-validation [PAGE 4], so each fold trains on $\approx 140$ performances and tests on $\approx 35$.

Accuracy results from Table 2 [PAGE 4], whole dataset: intervals 0.60, griffs 0.87, bigrams 0.73, trigrams 0.49. Per-score griff accuracies: Score 001 0.91, Score 002 0.97, Score 003 0.94, Score 004 0.97, Score 005 0.89 [PAGE 4, Table 2]. Player-focused experiments: all players except 8780 achieve 0.8–1.0; player 8780 averages 0.68 [PAGE 4].

Breakdown regimes. (1) High-dimensional singularity: for whole-dataset trigrams, $V=15{,}989 \gg N_{\text{train}}\approx 140$, so the linear SVM operates in an under-specified regime; the observed 0.49 accuracy is near the noise floor for this representation. (2) Griff monopoly: at score note n113, one griff type occurs in 20 of 25 performances and is shared by all but one player, driving note-level accuracy to 0.17 [PAGE 5, Table 3]. (3) Alignment jitter: if onset error $\delta t$ exceeds $\tau/2 = 17.5\text{ ms}$, notes cross griff boundaries and $G_i$ is recomputed with incorrect membership, invalidating the count statistics.

These style-null regions are where crisis habit regression dominates; the high-accuracy regions are where the counter-trap finds stable deviations. The clock’s resolution determines whether a given deviation is captured as a separate griff vector or absorbed into a neighbor, thereby modulating the recursion’s gain.

<CROSS_LAYER_VETO_ADJUDICATION>
Four layers can veto the inference that griff BOW features isolate personal style:

Layer 1 — Acoustic/weather layer: The data are symbolic MIDI, not audio. Temperature, humidity, and hall acoustics are abstracted away; this layer is vetoed by design. However, this also means the study cannot detect style elements that are expressed through touch, articulation, or timbral variation rather than pitch-content choice.

Layer 2 — Biomechanical/physical layer: Griffs are explicitly described as "tactile properties of basso continuo playing – actually pressing several keys at a keyboard using learned patterns" [PAGE 2]. Hand span, finger substitution, and harpsichord action weight constrain which griff shapes are physically executable. A player with small hands may be biomechanically vetoed from certain chord positions, artificially reducing their griff vocabulary and inflating apparent inter-player distance for reasons unrelated to aesthetic style.

Layer 3 — Alignment layer: DTW alignment is "not perfect" [PAGE 2], and Chiruthapudi et al. (2025) document challenges in performance-to-score alignment [PAGE 2]. If alignment error shifts a performance note across the 35 ms window boundary or misassigns it to the wrong score note, the interval encoding $\iota = n - b_i$ is computed relative to the wrong bass note, corrupting the griff string. Veto condition: onset error $|\delta t| > \tau/2 = 17.5\text{ ms}$ or bass-note misalignment.

Layer 4 — Representation layer: Empty griffs (deletions, bass-only events) are excluded because they contain "no pitch content information" [PAGE 3, footnote]. This vetoes any stylistic signal carried by omission, rhythm, or texture reduction. Transposition invariance removes absolute register information, vetoing style elements tied to specific keyboard ranges.

Adjudication: the veto chain is strongest at Layer 3, because alignment error propagates into every downstream feature. The claim of personal-style identification is valid only for performances where alignment error remains below the window half-width and where griff differences are not reducible to hand-size or register constraints. The paper’s exclusion of empty griffs and its reliance on interval (transposition-invariant) encoding are reasonable for pitch-content analysis but constitute an explicit narrowing of the style construct to harmonic-voicing choices only.
