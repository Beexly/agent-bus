with \(\mathbf{z}_p^{(1)} \in \mathbb{R}^{50}\), because the paper states: “we initially boost from the original two-dimensions up to 50 at the first hidden layer” [PAGE 5]. where \(T\) is the number of teams. The unit is probability per set; if multiplied by 100, it may be read as percentage points per set. <CROSS_LAYER_VETO_ADJUDICATION>
A physical, biomechanical, and weather veto layer is required because probabilistic estimates can be statistically plausible while being physically impossible or contextually invalid.

First, spatial constraints impose hard vetoes. The field is described as similar in size to American Football, with a 100 m by 70 m pitch [PAGE 2]. Therefore, any predicted meter gain that would place the ball outside \([0,100]\times[0,70]\) is invalid. Let \(m_{\mathrm{gain}}\) be predicted meters gained from position \(x\). A necessary condition is
\[
x + m_{\mathrm{gain}} \le 100\,\mathrm{m}
\]
for an attacking team moving toward the opponent goal-line, ignoring lateral boundary effects. If the model predicts expected meters that would cross the goal-line beyond the maximum possible scoring opportunity, the prediction must be clipped or vetoed. Similarly, if a contextual expected-meters surface assigns high value to positions outside the pitch, the surface is invalid.

Second, scoring constraints impose discrete-event vetoes. Rugby League scoring values are fixed: four points for a try, two points for a successful conversion, two points for a penalty kick, and one point for a field goal [PAGE 2]. Let \(\Delta S\) be a realized score change. Then
\[
\Delta S \in \{1,2,4\}
\]
for a single scoring event, with combinations producing larger changes. A continuous scoreline distribution is acceptable as an approximation, but any exact claim about final score must be reachable by an integer combination of these scoring units. If a predicted final differential cannot be expressed as a feasible sequence of tries, conversions, penalty kicks, and field goals within the remaining clock, the prediction is vetoed. Likewise, if the 90-10 interval includes a margin that cannot be attained given remaining time and possession structure, the interval must be rejected or widened with a physical constraint layer.

Third, temporal constraints bound maximum scoring. If \(T_{\mathrm{rem}}\) is time remaining and \(\lambda_{\mathrm{set}}\) is the maximum feasible number of completed sets, then the maximum possible score change is bounded by the maximum points per set. The paper does not provide a formal maximum, but the principle is clear: no late-game interval should imply more scoring than can physically occur before the clock expires. The example where the interval excludes zero by H2 33:32 is consistent with this because only a limited scoring fluctuation remains [PAGE 8].

Fourth, weather and surface conditions are omitted covariates. The described tackle-level data include position, play-by-play events, players, teams, possession, and game context such as tackle number, score, and time remaining [PAGE 4]. Weather is not listed. In rain, wind, or extreme heat, expected meters, kicking accuracy, handling errors, and fatigue can shift materially. If weather covariates are unavailable, the model should either inflate predictive variance or veto fine-grained spatial recommendations. A formal test is to compare residual variance in wet versus dry matches; if residual variance increases beyond a pre-registered threshold, the dry-trained conditional distributions are invalid.

Fifth, biomechanical constraints veto implausible individual-play valuations. A 22-meter run can be top-five-percent under context [PAGE 8], but if the runner is injured, fatigued, or replaced by a lower-speed player, the conditional distribution shifts. Since the source does not explicitly model player-level fatigue or injury state, any claim that a specific player will replicate a top-five-percent run must be treated as provisional. The veto rule is: if a physical state variable outside the model’s feature set changes materially, the model’s conditional expectation is not admissible without adjustment.
