Multi-hop derivation and gray-zone audit.

Hop 1 — the bipartite attention core. The paper treats data association as a query-to-query cross-attention with detections as queries (targets) and tracks as keys/values (sources). Per [PAGE 4], the pre-softmax logit for detection $j$ attending track $i$ is the scaled dot product plus an edge term: $(Q_D W_Q)(Q_T W_K)^\top/\sqrt{d_k} + E\,W_{E1}\mathbf{1}$. The critical structural fact is that the edge features $E^{(l)}\in\mathbb{R}^{N_D\times N_T\times d_k}$ are added *inside* the softmax argument, so geometry (a relative box encoding) competes additively with appearance (dot product) before normalization. This is not a cosmetic fusion; it changes the invariance class of the score. Because $E^{(1)}_{pos}=\mathrm{MLP}(|b_{T,i}-b_{D,j}|)$ ([PAGE 4]) uses the absolute difference of 9-D box parameters, the affinity is translation-sensitive in box space and, at layer 1 with $E^{(0)}=0$, purely a function of pairwise geometry.

Hop 2 — why softmax is the load-bearing weakness. [PAGE 2] and [PAGE 6] state the failure precisely: "even if all pre-softmax attention scores are low for certain detection queries, the highest score will be amplified after softmax." The mathematical singularity is the degenerate normalization regime: when a detection has no true correspondent (new object, false positive, occlusion), the *correct* target distribution is uniform (≈$1/N_T$ everywhere), yet softmax over $N_T$ keys forces $\sum_i A_{ji}=1$ and re-amplifies the argmax. That spurious mass then (a) contaminates the feature aggregation $\hat A^{(l)}(Q_T W_V)$ in Eq. (2) and (b) is read out directly as affinity. This is the crack ADA-Track++ widens.

Hop 3 — the counter-mechanism. Adding an auxiliary token $q_\varnothing\in\mathbb{R}^{d_k}$ enlarges the key set to $N_T+1$ ([PAGE 6]), giving $A\in\mathbb{R}^{N_D\times(N_T+1)}$. Softmax can now dump the "no-match" probability mass onto a null sink, so irrelevant tracks are down-weighted rather than spuriously up-weighted. Supervision closes the loop: assigning $\varnothing$ as target for unmatched detections back-propagates through $S$ into $A$, forcing the network to *learn to abstain*.

Hop 4 — the subtle gray zone. The paper's own Table 16 ([PAGE 12]) exposes an internal tension: the cross-entropy loss $L_{CE}$ (Eq. 4) implies a softmax over $N_T+1$, but inference uses a *sigmoid* on $S$ as Hungarian cost. Swapping to softmax activation drops AMOTA by 1.5%P and inflates IDS to 1180. The stated reason ([PAGE 12]) is that softmax "normalizes the affinity across one direction," which is a sub-optimal cost for a *bidirectional* bipartite solver. So the training objective is directionally normalized while the matching cost must remain per-pair independent — a deliberate train/inference mismatch. That is the paper's deepest gray zone and it is only defensible empirically, not derived.
