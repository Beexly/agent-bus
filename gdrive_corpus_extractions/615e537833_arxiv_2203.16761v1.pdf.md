The source drives a single architectural claim: multi-object tracking should not be decomposed into an isolated detector plus an external matcher, but should instead preserve a long spatio-temporal state and let an attention-based decoder solve detection and association together. The paper states this as: “MeMOT preserves a large spatio-temporal memory and actively encodes the past observations via an attention-based aggregator.” [PAGE 8] The gray-zone issue is therefore not merely “can it detect people?” but “can it keep identity when the visual evidence is missing, ambiguous, or re-enters the scene after a long gap?”

The multi-hop derivation begins with the causal frame stream. For frame \(I_t\), a CNN backbone produces a feature map, a Transformer encoder refines it, and a decoder emits proposal embeddings. The source says the hypothesis generator “produces object proposals in the current video frame” [PAGE 1] and that the proposal embeddings are “each representing one hypothetical object instance” [PAGE 2]. At the same time, the system does not treat each track as a single last box. It stores a memory tensor over recent frames and encodes that memory into a track embedding. The key gray-zone operator is the memory encoder: it “first divides the spatial temporal memory on each object into short- and long-term memories and aggregates them each into one embedding vector through cross attention modules” [PAGE 2]. This matters because occlusion is not a simple missing box; it is a non-Gaussian, non-linear interruption of observation. The paper explicitly says: “occlusion in visual multiple object tracking is clearly non-linear and non-Gaussian.” [PAGE 2]

The next hop is decoding. The decoder receives both proposal embeddings and track embeddings. For each entry it predicts a box, an objectness score, and a uniqueness score. The paper defines the operational confidence as \(s_k^t = o_k^t \cdot u_k^t\) [PAGE 4]. This is the gray-zone gate: objectness asks “is there a visible object?” while uniqueness asks “is this a new object or already tracked?” The source emphasizes that “a proposal is only considered novel when it is not related to any object being tracked” [PAGE 4]. Without this separation, a tracker can either hallucinate new identities or suppress genuine newborns. The ablation on single versus dual confidence confirms the operational value: the dual-score model obtains 73.15 IDF1, 68.08 MOTA, and 59.75 HOTA, whereas the single-score variant falls to 69.09 IDF1, 63.51 MOTA, and 52.86 HOTA [PAGE 8].

The temporal gray-zone is the memory horizon. The buffer is finite. The paper says: “The memory is implemented with a first-in-first-out (FIFO) data structure.” [PAGE 4] It also says: “Nmax is set to be significantly large (e.g., 300 or 600) to cover the typical number of objects in a video, and a choice of Tmax is 24.” [PAGE 4] In implementation, the temporal length is reduced by hardware constraints: “Its maximum temporal length is 22 for MOT16/17 and 20 for MOT20, which is mainly limited by the GPU memory.” [PAGE 5] This creates an exact breakdown regime: if an identity disappears for longer than the effective memory window, the oldest states graduate from memory and the model can no longer rely on those states. The paper’s qualitative example shows the intended regime: object 55 is occluded from frame 125 to 128 and is re-linked at frame 129 using an embedding from frame 124 and a full-body feature from frame 121 [PAGE 7]. The counterfactual is clear: if the occlusion exceeds the retained temporal support, re-identification becomes unsupported by stored evidence.

The paper supplies the assignment semantics: tracked objects have objectness 1, uniqueness 1, confidence 1; new objects also have objectness 1, uniqueness 1, confidence 1; backgrounds have objectness 0, uniqueness 1, confidence 0; suppressed objects have objectness 1, uniqueness 0, confidence 0 [PAGE 5]. This is not a toy rule because it is learned through a bipartite matching process and supervised end-to-end. The paper’s formal operators can be written as three interacting maps: hypothesis generation \(\Theta_H\), memory encoding \(\Theta_E\), and memory decoding \(\Theta_D\) [PAGE 3].

1. Input and hypothesis generation. Given video frames \(I = \{I_0, I_1, \dots, I_T\}\), the hypothesis module takes frame \(I_t\), encodes it to \(z_1^t \in \mathbb{R}^{d \times HW}\), and decodes proposal embeddings
\[
Q_{pro}^t \in \mathbb{R}^{N_{pro}^t \times d}.
\]
The source says the hypothesis generator “produces object proposals in the current video frame” and that each proposal embedding represents “one hypothetical object instance” [PAGE 1][PAGE 2]. Units: \(N_{pro}^t\) is an integer count of proposals; \(d\) is the learned embedding width; \(H \times W\) is spatial resolution of encoded features. The source implementation resizes frames so that the shorter side is 800 pixels [PAGE 5].

2. Spatio-temporal memory. The memory buffer is
\[
X \in \mathbb{R}^{N \times T \times d},
\]
with maximum object capacity \(N_{max}\) and maximum temporal length \(T_{max}\). The source says the buffer “reserves at most Nmax objects and a maximum of Tmax time steps for each object” and that it is FIFO: “When T is larger than Tmax, the ‘oldest’ state of each tracklet graduates from the memory.” [PAGE 4] Units: \(N\) is object count, \(T\) is frame count, \(d\) is feature dimension. Default conceptual choice: \(T_{max}=24\) [PAGE 4]. Implemented limits: temporal length 22 for MOT16/17 and 20 for MOT20 due to GPU memory [PAGE 5].

A formal FIFO update can be written as
\[
X^t = \operatorname{FIFO}\left(X^{t-1}, \hat{q}_t; N_{max}, T_{max}\right),
\]
where \(\hat{q}_t\) is the current identity embedding for an active or newborn track, and entries older than \(t-T_{max}\) are removed.

3. Memory encoding. The encoder uses short-term and long-term cross-attention branches:
\[
Q_{AST}^t = f_{short}\left(X^{t-1}, X^{t-1-T_s:t-1}\right),
\]
\[
Q_{ALT}^t = f_{long}\left(Q_{dmat}^{t-1}, X^{t-1-T_l:t-1}\right),
\]
\[
\left[Q_{tck}^t, Q_{dmat}^t\right] = f_{fusion}\left(\left[Q_{AST}^t, Q_{ALT}^t\right]\right).
\]
The source says the short-term module “smoothes out noises in recent frames,” the long-term module “extracts supportive features from long-range context,” and the fusion block aggregates both branches [PAGE 4]. The long-term query is the Dynamic Memory Aggregation Token, DMAT. When a tracklet is initiated, it receives the same DMAT as other tracks; afterward DMAT is updated iteratively [PAGE 4]. Units: \(T_s\) and \(T_l\) are frame counts, with \(T_s \ll T_l\) [PAGE 4]. The ablation selects \(T_s=3\) as an accuracy-efficiency trade-off, while \(T_l=24\) is the tested long-term length [PAGE 7][PAGE 9].

The underlying attention operator is the standard scaled dot-product attention:
\[
\operatorname{Attn}(Q,K,V) = \operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.
\]
Assumption: \(Q \in \mathbb{R}^{n_q \times d_k}\), \(K \in \mathbb{R}^{n_k \times d_k}\), \(V \in \mathbb{R}^{n_k \times d_v}\). The logits \(QK^\top / \sqrt{d_k}\) are dimensionless; the softmax output is a probability vector over key positions; the final output lies in the value embedding space. The source uses cross-attention and self-attention modules in the encoder and decoder [PAGE 2][PAGE 4].

4. Memory decoding. The decoder takes proposal and track embeddings as queries and image features as keys and values:
\[
\left[\widehat{Q}_{pro}^t, \widehat{Q}_{tck}^t\right]
=
\Theta_D\left(\left[Q_{pro}^t, Q_{tck}^t\right], z_1^t\right).
\]
For each query entry \(q_i^t\), the model predicts a bounding box \(b_i^t \in \mathbb{R}^{4 \times 1}\), an objectness score \(o_i^t\), and a uniqueness score \(u_i^t\) [PAGE 4]. The box contains center coordinates, width, and height. Units: coordinates and sizes are in the tracking coordinate convention; with the implemented 800-pixel shorter-side input, they are ultimately tied to pixel-scaled image coordinates or learned reference-point offsets [PAGE 4][PAGE 5]. Scores \(o_i^t, u_i^t \in [0,1]\) are dimensionless probabilities or pseudo-probabilities.

5. Confidence gate. The paper’s equation (1) is
\[
s_k^t = o_k^t \cdot u_k^t.
\]
The source says: “We define a unified confidence score for both proposal and track entries as the multiplication of objectiveness and uniqueness scores.” [PAGE 4] At inference, entries are retained if
\[
s_i^t \ge \epsilon.
\]
The selected thresholds are \(\epsilon_{pro}=0.7\) and \(\epsilon_{tck}=0.6\) [PAGE 9]. Units: \(s_i^t\) and \(\epsilon\) are dimensionless.

+
\lambda_{L1}L'_{bbox}
+
\lambda_{iou}L'_{iou}.
\]
This is equation (2) [PAGE 5]. Here \(L'_{obj}\) and \(L'_{uni}\) are focal classification losses, \(L'_{bbox}\) is an \(L_1\) box regression loss, and \(L'_{iou}\) is generalized IoU loss. The auxiliary detection loss is

=
\lambda_{cls}L_{obj}
+
\lambda_{L1}L_{bbox}
+
\lambda_{iou}L_{iou}.
\]
This is equation (3) [PAGE 5]. The clip loss combines them as
\[
L_{clip}
=
\lambda_{tck}L_{clip\text{-}tck}
+
\lambda_{det}L_{clip\text{-}det}.
\]
A formal reconstruction from the prose and OCR is

\]
\[

<RETROCAUSAL_GENEALOGY>
The intellectual lineage of this paper is not a single straight line; it is a convergence of classical state estimation, deep detection, Transformer querying, and external memory architectures.

The classical root is recursive Bayesian filtering. The paper cites Kalman filters and particle filters as widely adopted tools for tracking [PAGE 2]. In the linear-Gaussian case, an optimal state can be estimated; in non-linear, non-Gaussian settings, finite-dimensional state representations become insufficient. The source says: “In a linear-Gaussian case, the optimal state can indeed be estimated, while for more general non-linear, non-Gaussian cases, it is difficult to estimate the optimal state with a finite-dimensional state representation.” [PAGE 2] Occlusion is exactly such a regime. This motivates storing richer histories rather than relying only on a compact motion state.

The second lineage is tracking-by-detection. Classical MOT methods used ready-made detectors and then associated detections [PAGE 2]. Tracktor++ propagated tracked boxes as proposals; CenterTrack used point heatmaps; JDE used homogeneous branches for detection and re-identification. The paper notes that joint detection and tracking improves runtime but “sacrifice[s] the tracking recovery after occlusion and cannot reconnect long-term missing objects.” [PAGE 2] This is the historical failure mode that MeMOT tries to repair: short memory or single-frame association cannot support delayed re-identification.

The third lineage is Transformer-based object querying. TrackFormer and MOTR concatenate object and track queries as inputs to the decoder in the next time step [PAGE 2]. The source says this family “explores the mechanism of representing object states as dynamic embeddings,” but “the modeling of long-term spatio-temporal observations and adaptive feature aggregation methods are underdeveloped.” [PAGE 2] MeMOT’s contribution is therefore not merely adding memory, but adding an adaptive encoder that separates recent noise smoothing from long-range identity support.

The fourth lineage is memory networks. The paper traces memory networks in NLP, action recognition, and video object segmentation, and then notes memory use in single-object tracking such as MemTrack and STMTrack [PAGE 2]. The novelty is moving memory from single-target template updating to multi-object association under a common detection-association decoder.

Multi-week traps in reproducing or extending this lineage are concrete. First, training-data scale is a trap: Table 1 marks training-data multipliers, and MeMOT compares with methods using much larger detection corpora [PAGE 5][PAGE 6]. Second, solver-type is a trap: in-network association solvers and post-network association solvers are not directly comparable because post-processing can change identity behavior [PAGE 5]. Third, metric choice is a trap: MOTA can reward detection quality while IDF1, HOTA, and AssA expose identity persistence [PAGE 5][PAGE 6]. Fourth, clip-centric training is a trap: the source starts clips at length 2 and increases with stride 4 every 20 epochs, with sampled frame intervals from 1 to 10 [PAGE 5]; changing this curriculum can alter memory learning. Fifth, hardware memory is a trap: the paper explicitly says the temporal memory length is limited by GPU memory [PAGE 5][PAGE 8].
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
The system can be interpreted as an agent that must infer identity under crisis. The crisis is occlusion, crowding, detection failure, or low visual quality. The recursive question is: what habit does the model fall back to, what counter-trap is designed, and what clock enforces causality?

Crisis habit regression. A default tracking habit is recency bias: trust the latest visible box or the latest embedding. In MeMOT, the short-term branch explicitly encodes this habit. It uses the most recent state as the query for short-term cross-attention and is intended to “smooth out noises in recent frames” [PAGE 4]. If the model only used recency, then during occlusion it would regress to whatever last visible cue exists, and during reappearance it might either fail to recognize the object or create a new identity. The paper’s earlier failure modes support this: joint detection-tracking methods “sacrifice the tracking recovery after occlusion” [PAGE 2].

Counter-trap. The long-term branch is the counter-trap. It uses DMAT, a dynamically updated query, to retrieve supportive context from a longer window. The source says the long-term module “extracts supportive features from long-range context” [PAGE 4]. The visualization shows the mechanism: for object 55, occluded by object 60 from frame 125 to 128, the model attends to the embedding just before occlusion and a full-body feature from earlier, enabling re-linking at frame 129 [PAGE 7]. This is a counter-trap because it does not rely only on the crisis-time observation; it retrieves pre-crisis identity evidence.

Clock. The clock is the FIFO memory horizon. The paper says memory is first-in-first-out and that the oldest state graduates when \(T\) exceeds \(T_{max}\) [PAGE 4]. The implemented temporal lengths are 22 for MOT16/17 and 20 for MOT20 [PAGE 5]. This clock enforces online causality: the tracker cannot wait for future frames, and it cannot retain unlimited history. It also defines a boundary: if reappearance occurs after the clock expires, the model has no stored state to support the identity. The threshold gate is another clock-like mechanism: at inference, only entries with \(s_i^t \ge \epsilon\) are retained, with \(\epsilon_{pro}=0.7\) and \(\epsilon_{tck}=0.6\) [PAGE 9].

Recursive evaluation habit. A further recursive habit is metric chasing. If a tracker is trained or tuned only for MOTA, it may generate boxes but not stable identities. MeMOT’s dual confidence score and uniqueness branch counter this ambiguity. The paper says the single-head design is ambiguous: low confidence can mean “not an object” or “not a new object.” The dual design “removes the ambiguity and avoids under-training of the classification layers.” [PAGE 8] In recursive terms, the model must anticipate that a naive confidence habit will conflate detection with novelty, and it inserts a separate uniqueness operator to veto that collapse.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The cross-layer veto test asks whether a claimed capability survives physical, biomechanical, and weather or illumination constraints. For MeMOT, the adjudication is conditional: the architecture is valid within memory-bounded occlusion, but it is vetoed when evidence is absent, capacity is exceeded, or visual support is too weak.

Physical layer. The memory buffer is a finite tensor \(X \in \mathbb{R}^{N \times T \times d}\). Its approximate memory footprint is
\[
C_{mem} \approx B \cdot N_{max} \cdot T_{max} \cdot d \cdot p,
\]
where \(B\) is batch size, \(N_{max}\) is maximum object count, \(T_{max}\) is temporal length, \(d\) is embedding width, and \(p\) is bytes per scalar. The source explicitly says the maximum temporal length is limited by GPU memory: “which is mainly limited by the GPU memory.” [PAGE 5] The limitations section repeats that the spatio-temporal memory “increases the GPU memory cost in training” and “limits the temporal length of the memory.” [PAGE 8] Therefore, any claim that MeMOT can track through arbitrarily long disappearance is physically vetoed unless hardware or memory compression expands \(T_{max}\).

Biomechanical layer. Crowd tracking is not merely detection; it involves human motion, crossing trajectories, partial occlusion, and full occlusion. The paper states that occlusion is “clearly non-linear and non-Gaussian” [PAGE 2]. In a Bayesian view, if the observation likelihood collapses during occlusion, the posterior cannot be updated by current visual evidence. MeMOT’s memory can act as a prior, but it cannot create a detection where the decoder has no visual support. The source’s example shows the intended boundary: object 55 is re-linked after occlusion because frames 124 and 121 provide supportive appearance evidence [PAGE 7]. If no distinctive pre-occlusion state exists, or if the occlusion exceeds the retained temporal window, the identity link is vetoed.

The memory padding rule reinforces this boundary. The source says a state is “padded with 0 if this object does not appear in the frame” [PAGE 4]. Padding preserves the tensor shape, but it does not create positive evidence. If the track’s recent states are mostly padding and the long-term branch has no discriminative token, the decoder cannot reliably infer a visible object. The confidence gate then suppresses entries below threshold. Formally, if
\[
s_i^t = o_i^t u_i^t < \epsilon,
\]
the entry is not retained [PAGE 4][PAGE 9]. This is the operational veto: no score, no track update, no new track.

Weather and illumination layer. The paper does not provide a formal weather model, but it gives an empirical weather-like veto condition: small object size and poor lighting degrade feature-similarity association. It says: “Due to the small object size and poor lighting, feature similarity-based association methods [54,70] are precarious, causing higher IDsw.” [PAGE 7] MeMOT improves detection and association in crowded scenarios, but it does not remove the physical reduction in visual evidence. If poor illumination or adverse weather reduces the objectness or discriminative embedding quality, the confidence product can fall below threshold. The veto is therefore not a separate module; it is expressed through low objectness, low uniqueness, or low confidence.

Adjudication proof. Let \(E_t\) be the visual evidence available at time \(t\). The decoder can output a retained identity only if three conditions hold: first, there is a hypothesis or track query; second, the image feature provides non-degenerate key-value support; third, the predicted confidence satisfies \(s_i^t \ge \epsilon\). If any layer vetoes, the condition fails. Physical veto: \(T_{required} > T_{max}\). Biomechanical veto: occlusion interval exceeds stored identity support or no distinctive pre-occlusion embedding exists. Weather or illumination veto: visual evidence is too weak to produce objectness or embedding support above threshold. Under these conditions, the source’s claim of robust long-span tracking is bounded, not absolute.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
The following three counterfactual vetoes are verifiable from the paper’s ablations. Each one rejects a claimed design improvement if the supporting operator is removed or replaced.

Veto 1: Remove dynamic DMAT update. The long-term query is not static. The source says DMAT is “iteratively updated from the previous step” and that dynamic updating “contributes to better detection and tracking performance.” [PAGE 4][PAGE 8] Table 7 reports the no-update variant: IDF1 61.03, MOTA 43.42, HOTA 49.24, IDsw 161, DetA 42.40, AssA 57.96. The updated model reports IDF1 73.15, MOTA 68.08, HOTA 59.75, IDsw 93, DetA 57.92, AssA 63.10 [PAGE 8]. Prediction: if a variant freezes DMAT, it loses the recent-firsthand information needed for current association and should exhibit lower IDF1, lower MOTA, higher ID switches, and weaker detection-association agreement. Verifiable veto: any claim that DMAT updating is unnecessary is rejected by the large drop from 73.15 to 61.03 IDF1 and from 68.08 to 43.42 MOTA.

Veto 2: Remove uniqueness score separation. The dual-score design separates objectness and uniqueness. The source explains that a single head is ambiguous: for tracked queries it means existence confidence, while for proposals it means new-object confidence. The ablation in Table 8 shows single-head performance: IDF1 69.09, MOTA 63.51, HOTA 52.86, IDs 104, DetA 55.76, AssA 61.77. The dual-score model reports IDF1 73.15, MOTA 68.08, HOTA 59.75, IDs 93, DetA 57.92, AssA 63.10 [PAGE 8]. Prediction: collapsing objectness and uniqueness increases false positives and identity switches because the model cannot separately express “not visible” and “already tracked.” Verifiable veto: any claim that a single confidence head is sufficient is rejected by the drop in IDF1, MOTA, HOTA, and the increase in IDs from 93 to 104.

Veto 3: Replace attention aggregation with heuristic pooling. The paper tests average and maximum pooling over memory states. Table 5 reports: average pooling with \(T=3\) gives IDF1 25.04, MOTA 30.72, HOTA 21.89, IDs 267; max pooling with \(T=3\) gives IDF1 46.83, MOTA 41.28, HOTA 35.44, IDs 235; average pooling with \(T=24\) collapses to MOTA \(-7.29\); max pooling with \(T=24\) gives IDF1 25.78, MOTA 10.20, HOTA 6.54, IDs 332. The learned attention model reports IDF1 73.15, MOTA 68.08, HOTA 59.75, IDs 93 [PAGE 8]. Prediction: heuristic pooling cannot preserve identity-relevant features and will produce unstable or degenerate tracking, especially as the memory window grows. Verifiable veto: any claim that simple pooling can replace adaptive memory aggregation is rejected by the collapse from 73.15 IDF1 and 68.08 MOTA to the pooling variants.

A further related veto is the joint use of learnable tokens for both short-term and long-term branches. Table 4 reports IDF1 41.09, MOTA 59.80, HOTA 43.28, IDsw 207, DetA 45.36, AssA 38.52 when both branches use learnable tokens [PAGE 8]. This supports the source’s claim that the branches are complementary: short-term aggregation benefits from querying with the latest observation, while long-term aggregation benefits from a learnable, dynamically updated token [PAGE 8]. The verifiable prediction is that conflating the two branches destroys the separation between noise smoothing and long-range identity retrieval.
