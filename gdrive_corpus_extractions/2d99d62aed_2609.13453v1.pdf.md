Net: claim (i) is supported by construction; claim (ii) is supported at the statistical-equivalence bar, not bitwise reproducibility, and the authors say so.

<SOURCE_OPERATORS_AND_EQUATIONS>

NDVI (dimensionless reflectance ratio; [PAGE 11, PAGE 14]):
$$\mathrm{NDVI}=\frac{\rho_{\mathrm{NIR}}-\rho_{\mathrm{Red}}}{\rho_{\mathrm{NIR}}+\rho_{\mathrm{Red}}},\qquad \rho\in[0,1]\ \text{(dimensionless)},\quad \mathrm{NDVI}\in[-1,1].$$
Singularity: undefined when $\rho_{\mathrm{NIR}}+\rho_{\mathrm{Red}}=0$ (deep water, saturated shadow, SCL classes 1/2/6). Red/NIR map to bands B04/B08 [PAGE 14].

Overall accuracy ($N$ samples, dimensionless, [PAGE 11–12]):
$$\mathrm{OA}=\frac{1}{N}\sum_{i=1}^{N}\mathbb{1}[\hat y_i=y_i]=0.82.$$

Per-class P/R/F1 ($TP_c,FP_c,FN_c$ counts, dimensionless):
$$P_c=\frac{TP_c}{TP_c+FP_c},\quad R_c=\frac{TP_c}{TP_c+FN_c},\quad F1_c=\frac{2P_cR_c}{P_c+R_c}.$$
Breakdown: $P_c$ undefined if class $c$ never predicted; $R_c$ undefined if $c$ absent from truth [PAGE 12, Table 5].

Cohen's $\kappa$ (two raters = two backends; dimensionless, $\kappa\in[-1,1]$):
$$\kappa=\frac{p_o-p_e}{1-p_e},\qquad p_e=\sum_{k=1}^{K}p_k^{(A)}p_k^{(B)},\qquad \kappa=0.76,\ N=258{,}168.$$
Breakdown regimes: undefined as $p_e\to 1$ (both raters degenerate on one class); severely biased under skewed marginals (prevalence paradox); and the variance $\mathrm{Var}(\kappa)\approx \frac{p_o(1-p_o)}{N(1-p_e)^2}$ is invalid here because effective sample size $N_{\mathrm{eff}}\ll N$ under spatial autocorrelation — hence no CI is reported [PAGE 12, citing [40]].

Softmax labeling (`ml_label_class`, probability simplex, dimensionless, [PAGE 7]):
$$\sigma(\mathbf z)_i=\frac{e^{z_i}}{\sum_{j=1}^{C}e^{z_j}},\qquad \sum_i\sigma(\mathbf z)_i=1.$$
Numerical breakdown: overflow for large $|z_i|$; cured by shift-invariance $\sigma(\mathbf z)=\sigma(\mathbf z-\max_j z_j)$.

Uncertainty operators (dimensionless, [PAGE 7]): least-confidence $u=1-\max_i p_i\in[0,1-\tfrac1C]$; margin $u=p_{(1)}-p_{(2)}$; ratio $u=p_{(2)}/p_{(1)}\in[\tfrac1C,1]$.

Tensor input layouts [PAGE 4]: features $X\in\mathbb R^{N\times F}$; time-series $(B\times T\times C)$; patch $(B\times C\times H\times W)$; spatio-temporal $(B\times T\times C\times H\times W)$ or $(B\times T\times C\times Z\times Y\times X)$; bi-temporal $(B\times 2\times C\times H\times W)$.

Random Forest split candidates: $\mathrm{mtry}=\lfloor\sqrt F\rfloor$ (Breizh uses `max_variables="sqrt"` [PAGE 11]). Derived $F$: 12 reflectance bands $\times$ 5 monthly medians (May–Sep 2017) $+$ 5 monthly NDVI $= 65 \Rightarrow \mathrm{mtry}=8$ (assumption: 5 calendar-month bins; stated because the paper does not report $F$).

TerraMind FM reshape (spatial unit = pixels at 10 m; [PAGE 16, PAGE 22]):
$$\text{In}=(\text{batch}:-1,\ \text{band}:12,\ y:224,\ x:224),\quad \text{Out}=(\text{batch}:-1,\ \text{level}:24,\ \text{patch}:196,\ \text{emb}:1024).$$
Here $196=14^2$ ⇒ ViT token grid $224/14=16$ px/token; $\text{emb}=1024$ = hidden width; $\text{level}=24$ = encoder depth. Output tiling: $y_{\text{out}}=\lfloor 2242/224\rfloor=10,\ x_{\text{out}}=\lfloor 2213/224\rfloor=9$; dropped residues $\Delta y=2242-10\cdot224=2$ px $=20$ m, $\Delta x=2213-9\cdot224=197$ px $=1970$ m. Breakdown: if a cube axis $<224$ px, that axis yields zero output patches.

Time-series sample (Rondônia): $T=23$ (16-day composites over 2022, $\lfloor365/16\rfloor\approx23$), $C=11$ (10 S2 bands $+$ NDVI), batch $B=64$ [PAGE 13–14].

<CROSS_LAYER_VETO_ADJUDICATION>
Physical/atmospheric/geometric veto proof (the "weather/biomechanical veto" layer is literally present here as a radiometric-quality veto). (1) Cloud veto: pixels with SCL $\in\{3,8,9\}$ = cloud shadow, cloud-medium-probability, cloud-high-probability are masked before compositing [PAGE 11], and scenes with cloud cover $\ge 50\%$ are excluded at load (`max_cloud_cover=50`) [PAGE 10]. A prediction over such a pixel is physically inadmissible because top-of-canopy radiance is contaminated; the veto is not a modeling choice but a radiative-transfer constraint. (2) Compositional veto: monthly median aggregation [PAGE 10] is the operator that rejects residual undetected cloud/noise, valid only if $\ge\lceil n/2\rceil$ clear observations exist per bin; with sparse months the median degenerates to a single observation and loses its noise-rejection guarantee. (3) Radiometric domain veto: reflectance $\rho\in[0,1]$; NDVI singular where $\rho_{\mathrm{NIR}}+\rho_{\mathrm{Red}}=0$ (water/shadow). (4) Geometric veto: patch tiling admits only complete $224\times224$ windows, discarding $\Delta y=2$ px and $\Delta x=197$ px at the margins [PAGE 16]; any inference over those strips is undefined by construction. These four layers can each independently veto a prediction irrespective of model quality — the adjudication is that data-validity physics dominates downstream accuracy in operational EO.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Three verifiable counterfactual vetoes with predictions.
1. Naive-independence κ veto. If κ's significance were computed as if $N=258{,}168$ iid pixels (ignoring spatial autocorrelation), the standard error would be $\approx\sqrt{p_o(1-p_o)}/(1-p_e)/\sqrt N \approx 0.002$–$0.004$, yielding a spuriously tight CI excluding any "fair" agreement. Prediction/verification: recomputing with an autocorrelation-adjusted $N_{\mathrm{eff}}$ (per Foody 2004, [40]) widens the CI by roughly $\sqrt{N/N_{\mathrm{eff}}}$; the authors' refusal to report a CI [PAGE 12] is vindicated.
2. ONNX-exchange veto (removes re-training divergence). Section 7.1.2 states ONNX exchange would "reduce remaining differences to preprocessing divergences alone" [PAGE 17]. Counterfactual: export the openEOcubes RF to ONNX, run it on dask-ml against the identical cube. Prediction: modal field agreement rises above the current 85% [PAGE 13] and κ above 0.76, because RNG/tree-building differences vanish. Verifiable by re-running Use Case 5 with `load_stac_ml` instead of independent `ml_fit`.
3. Patch-remainder inclusion veto. If the 197-px x-remainder were mirror-padded to a full 224 window rather than dropped [PAGE 16], output would gain one patch column ($x_{\text{out}}:9\to10$, covering 2240 px vs 2016 px, +2240 m). Prediction: the embedding cube's spatial x-extent increases by one token-grid column ($14$ tokens) with edge artifacts; verifiable by toggling the padding flag in dask-ml's reshaping and diffing output dimensions.
