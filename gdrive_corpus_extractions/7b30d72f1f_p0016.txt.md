<SOURCE_OPERATORS_AND_EQUATIONS>
Let the target player be indexed by t and the set of similar players be i ∈ {1,…,N}. Each player carries an attribute vector x ∈ 𝒜 over a mixed-type attribute space (age, position, season load, prior injury history, etc.). The patent grounds similarity in Kolmogorov Complexity [PAGE 16]: define the algorithmic distance D_K(x_i,x_t) ≈ K(x_i|x_t*) + K(x_t|x_i*), where * denotes the shortest program; because K is uncomputable, an implementation must use a computable proxy such as normalized compression distance, introducing an approximation error δ_K that is not quantified in the source.

Similarity factor: M(i) = 𝒮(D_K(x_i,x_t)) ∈ [0,1], dimensionless percentage rescaled to a unit interval [PAGE 16].

Peer injury frequency: P(S(i)) = n_inj(i,[t_start,t]) / n_games(i,[t_start,t]) ∈ [0,1], dimensionless probability over calendar interval [t_start,t] [PAGE 16].

Equation 3 (similar player-based probability) [PAGE 16]:
P(I/S | t) = \frac{\displaystyle\sum_{i=1}^{N} P(S(i)) \, M(i)}{\displaystyle\sum_{i=1}^{N} M(i)}
Units: dimensionless [0,1]. Valid only if Σ_{i=1}^{N} M(i) > 0. This is a convex-weighted average of peer injury frequencies when weights are normalized by the denominator.

Equation for target self-history [PAGE 16]:
P(I/T | t) = \frac{n_{\text{inj}}(t,[t_{\text{start}},t])}{n_{\text{games}}(t,[t_{\text{start}},t])}
Units: dimensionless [0,1]; undefined (0/0 singularity) if n_games(t,[t_start,t]) = 0.

Fusion at block 816 [PAGE 16]:
Linear: P(I | t) = \frac{1}{2} P(I/S | t) + \frac{1}{2} P(I/T | t), cited verbatim as “Linear Combination=(P(I/S)+P(I/T))/2” [PAGE 16].
Nonlinear: P(I | t) = \sqrt{P(I/S | t)} + P(I/T | t), cited verbatim as a square-root (or any root) of P(I/S) added to P(I/T) [PAGE 16]. This nonlinear form is not guaranteed to remain within [0,1] unless a clipping or calibration layer is added, which the patent does not disclose.

Block 818 output: P(I) → report generator 108 → prediction report 112 [PAGE 16].

Exact singularity/breakdown regimes: (a) N = 0 or Σ M(i) = 0 ⇒ Equation 3 denominator vanishes; (b) n_games(t) = 0 ⇒ P(I/T) undefined; (c) max_i M(i) < ε for ε → 0 ⇒ numerically ill-conditioned weighted average dominated by floating-point noise; (d) Kolmogorov distance uncomputable ⇒ exact Equation 3 cannot be evaluated as written, only approximated [PAGE 16].

<RETROCAUSAL_GENEALOGY>
The methodological lineage in [PAGE 16] traces to three historical strands. First, Kolmogorov Complexity (Kolmogorov, 1965; Chaitin, 1966) supplies the information-theoretic root for attribute distance, but the patent invokes it only as an unnamed “analysis” without specifying the computable compression surrogate, breaking the formal link between theory and implementation [PAGE 16]. Second, the similarity-weighted average is a case-based reasoning / kernel regression estimator (Nadaraya, 1964; Watson, 1964; Aha, 1991 k-NN), in which the target is predicted by a locally weighted peer mean. Third, P(I/T) is a plain empirical risk frequency, the simplest maximum-likelihood estimator of a Bernoulli injury rate over games.

The fusion step resembles linear opinion pooling or Bayesian model averaging, but unlike principled ensemble methods it offers no calibrated weight λ derived from validation loss; the text arbitrarily fixes λ = 0.5 [PAGE 16]. Multi-week traps are structural: (a) early-season cold start—N and n_games are both small, so both P(I/S) and P(I/T) have high variance; (b) mid-season attrition—the similar-player pool changes as peers are traded, injured, or rested, invalidating the fixed peer set assumed at block 812 [PAGE 16]; (c) late-season non-stationarity—player attributes drift under fatigue and load management, so a similarity computed at t_start misrepresents risk at t_end [PAGE 16]; (d) retroactive leakage—if similar-player injury outcomes include dates after the target date, future information contaminates P(I/S), producing an upward-biased retro-causal estimate [PAGE 16].

<RECURSIVE_THEORY_OF_MIND>
Crisis habit regression: when a team faces an active injury crisis, decision-makers overweight P(I/T) because the target’s own recent unavailability is cognitively salient, even when P(I/S) better captures positional or role-based exposure [PAGE 16]. Counter-trap: over-reliance on P(I/S) treats the target as exchangeable with the peer collective—the “virtual player” mean-field assumption [PAGE 16]—and ignores unique biomechanical fragility (e.g., a prior Achilles rupture or asymmetric loading pattern not represented in aggregate performance attributes). Clock: P(I/T) is path-dependent over [t_start,t] [PAGE 16]; an injury in game 2 persists in the numerator for the remainder of the season, creating hysteresis that decouples the statistic from current physiological readiness. The model assumes stationarity of player attributes across the season [PAGE 16], but load management, coaching changes, tactical shifts, and circadian disruption from travel break this assumption, rendering early-season and late-season probability estimates incomparable without explicit time-decay or drift correction, neither of which is disclosed [PAGE 16].

<CROSS_LAYER_VETO_ADJUDICATION>
The source text [PAGE 16] describes a purely algorithmic, data-driven pipeline operating on historical performance and injury data. It contains no biomechanical layer (joint contact loads, ground-reaction forces, muscle-tendon activation), no meteorological layer (ambient temperature, humidity, precipitation, turf hardness or friction coefficient), and no scheduling layer (consecutive-game intervals shorter than 72 hours, trans-meridian travel, time-zone displacement). Therefore P(I) must be adjudicated as a statistical prior subject to hard physical vetoes.

Veto proof: if the physical layer indicates acute mechanical risk—e.g., frozen natural turf elevating traction injury probability, or fixture congestion imposing <72 hours between matches—the algorithmic output is overridden regardless of P(I/S) or P(I/T) [PAGE 16]. The model cannot represent sudden, low-base-rate events (traumatic contact injury, non-contact mechanical failure) absent from similar-player histories; its probability mass is concentrated on chronic/overuse patterns visible in peer data and is blind to exogenous mechanical shocks. Any deployment must gate the report generator 108 output [PAGE 16] behind a cross-layer veto that suppresses P(I) when biomechanical or environmental risk exceeds a physical threshold independent of the statistical estimate.
