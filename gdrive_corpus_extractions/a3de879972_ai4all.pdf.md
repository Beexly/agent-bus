A gray-zone audit is necessary because several source statements are pedagogical accelerations rather than bounded theorems. The most visible is [PAGE 6]: “Deep learning has fully solved the curse of dimensionality. It vanished like an RNN gradient!” This is not a formal theorem. Universal approximation, described on [PAGE 5] as the statement that “a feed-forward network with a single hidden layer containing a ﬁnite number of neurons can solve any given problem to arbitrarily close accuracy as long as you add enough parameters,” is an existence result. It says that some parameter configuration can approximate a target function. It does not say that finite samples, finite compute, stable optimization, or tractable generalization are available. The curse of dimensionality concerns the relationship between input dimension, sample size, and error. For a smooth target class on a d-dimensional domain, minimax approximation and estimation error generally retain dimension dependence unless strong compositional or low-dimensional structure is assumed. Thus the source’s joke is rhetorically correct about neural networks’ flexibility, but technically incomplete about statistical and computational scaling.

Another gray zone is the relationship between self-play and external validity. [PAGE 22] states: “AlphaGo Zero showed that algorithms matter much more than big data and massive amounts of computation.” This is correct inside a formal game with verifiable rules. It does not automatically transfer to open environments where reward is ambiguous, where other agents are non-stationary, or where physical constraints intervene. The source itself acknowledges environment dependence through [PAGE 27], quoting Endsley: “Situation awareness is the perception of the elements in the environment within a volume of time and space, and the comprehension of their meaning, and the projection of their status in the near future.” That sentence introduces a temporal-physical layer that is absent from pure board-game self-play.

The source also contains a recursive planning operator. On [PAGE 19], SuperDyna includes: “Plan: (while there is time remaining in this time step) imagine hypothetical states and actions you might take.” This is the clearest place where an internal clock enters the derivation. Planning is not free; it consumes wall-clock time, energy, and compute. Therefore, any agent architecture derived from the source must include a meta-reasoning allocation problem: how much simulation, inference, and deliberation should be performed before action. The gray-zone trap is to treat planning as unlimited. In physical deployment, the clock is a hard constraint.

Finally, the source’s meta-learning and multi-agent sections create a second recursion. [PAGE 23] states: “We design a Theory of Mind neural network – a ToMnet – which uses meta-learning to build models of the agents it encounters, from observations of their behaviour alone.” This is important because it shifts the object of learning from the environment to other agents’ inferred models. If an agent models other agents, and those agents model the original agent, then recursive belief dynamics can stabilize or destabilize behavior. The source does not provide a full stability theorem for that recursion. Therefore, a rigorous foundry reading must add breakdown conditions: finite time, partial observability, noisy inference, reward misspecification, and physical latency.

<SOURCE_OPERATORS_AND_EQUATIONS>
1. Learning operator from Mitchell’s definition  
Source marker: [PAGE 3]. Verbatim quote: “A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E.”  
Formal operator:  
\[
\Delta P_t = P(\mathcal{M}_t, T) - P(\mathcal{M}_{t-1}, T)
\]  
Units: \(P\) has task-specific units, such as accuracy, reward, loss, or utility; \(\Delta P_t\) has the same units.  
Assumptions: tasks \(T\) are measurable, performance is evaluated on a fixed or controlled distribution, and experience \(E\) produces a parameterized model update.  
Breakdown regime: if \(P\) is non-identifiable, adversarially gamed, or evaluated on a distribution different from deployment, \(\Delta P_t > 0\) may not imply real capability gain.

2. Universal intelligence operator  
Source marker: [PAGE 14]. Verbatim quote: “Intelligence measures an agent’s ability to achieve goals in a wide range of environments.” The source gives:  
\[
\Upsilon(\pi) := \sum_{\mu \in E} 2^{-K(\mu)} V^\pi_\mu
\]  
Units: \(K(\mu)\) is Kolmogorov complexity in bits; \(2^{-K(\mu)}\) is dimensionless; \(V^\pi_\mu\) is environment-specific utility or expected reward.  
Assumptions: \(E\) is the space of computable reward-summable environments; the reference machine \(U\) is fixed; rewards are bounded or summable.  
Breakdown regime: \(K(\mu)\) is uncomputable; the sum over all computable environments is not exactly evaluable; if rewards are unbounded or environments are non-summable, the operator diverges. Practical systems replace \(K\) with model priors, compression proxies, or curated environment distributions.

3. Gradient-based parameter fitting operator  
Source marker: [PAGE 5]. Verbatim quote: “The backpropagation procedure is nothing more than a practical application of the chain rule for derivatives.”  
Formal chain rule for loss \(L\) and parameters \(\theta\):  
\[
\frac{\partial L}{\partial \theta} = \frac{\partial L}{\partial h} \frac{\partial h}{\partial \theta}
\]  
Units: \(\partial L/\partial \theta\) has units of loss per parameter unit.  
Assumptions: differentiable computational graph, finite precision arithmetic, stable activation Jacobians.  
Breakdown regime: vanishing gradients, exploding gradients, non-differentiable operations, saturated nonlinearities, ill-conditioned Jacobians, or rank-deficient feature maps.

4. Self-attention operator  
Source marker: [PAGE 9]. Verbatim quote: “The self attention operation takes a weighted average over all the input vectors.” Source equations:  
\[
y_i = \sum_j w_{ij} x_j
\]  
\[
w_{ij} = \frac{\exp(x_i^T x_j)}{\sum_j \exp(x_i^T x_j)}
\]  
Units: if embeddings are normalized, logits and weights are dimensionless; \(y_i\) has the same units as \(x_j\).  
Assumptions: token embeddings lie in a bounded latent space; attention logits are numerically stable; softmax normalization is over a finite token set.  
Breakdown regime: quadratic sequence length cost in time and memory; softmax saturation when logits have large variance; attention collapse when one weight approaches one and the rest approach zero; finite-precision overflow in exponentials.

5. Generative adversarial minimax operator  
Source marker: [PAGE 12]. Verbatim quote: “Simultaneously train two models: a generative model G that captures the data distribution, and a discriminative model D that estimates the probability that a sample came from the training data rather than G.” Source equation:  
\[
\min_{\theta_g} \max_{\theta_d} \left[ \mathbb{E}_{x \sim p_{data}(x)}[\log D_{\theta_d}(x)] + \mathbb{E}_{z \sim p_z(z)}[\log(1 - D_{\theta_d}(G_{\theta_g}(z)))] \right]
\]  
Units: probabilities are dimensionless; logarithms are in nats if natural log is used, or bits if base-2 log is used.  
Assumptions: densities exist or can be implicitly compared; discriminator and generator are differentiable; mini-batch estimates approximate expectations.  
Breakdown regime: non-convex minimax optimization, mode collapse, vanishing gradients when discriminator is too strong, memorization when generator lacks diversity, instability from finite sample estimates. At optimal discriminator, the objective reduces to a Jensen-Shannon divergence between data and generated distributions, which can be zero only when distributions match.

6. Reinforcement learning return and value operators  
Source marker: [PAGE 16]. Verbatim quote: “The goal in RL is to train the agent to maximize the discounted sum of all future rewards Rt, called the return.” Source equations:  
\[
R_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \ldots
\]  
\[
Q(s,a) = \mathbb{E}[R_t]
\]  
Units: \(r_t\) has reward units; \(\gamma\) is dimensionless; \(R_t\) and \(Q(s,a)\) have reward units.  
Assumptions: Markovian or sufficiently informative state, stationary or controlled nonstationary dynamics, bounded rewards for convergence.  
Breakdown regime: if \(\gamma = 1\) and rewards are unbounded, return diverges; if the environment is nonstationary, learned value estimates become stale; if states are partially observed, \(Q(s,a)\) may be insufficient without belief state.

7. Policy-gradient operator  
Source marker: [PAGE 18]. Verbatim quote: “Increase probability of actions that lead to high rewards and decrease probability of actions that lead to low rewards.” Source equation:  
\[
\nabla_\theta \mathbb{E}_\tau[R(\tau)] = \mathbb{E}_\tau \left[ \sum_{t=0}^{T-1} \nabla_\theta \log \pi(a_t \mid s_t, \theta) R(\tau) \right]
\]  
Units: \(\log \pi\) is dimensionless; \(\nabla_\theta \log \pi\) has units of inverse parameter units; the full expression has units of return gradient.  
Assumptions: trajectory sampling is on-policy or corrected; return estimator has finite variance; policy is differentiable.  
Breakdown regime: high variance, sparse reward, long horizon credit assignment failure, deterministic policy gradients with insufficient exploration, or reward hacking.

8. Meta-learning update operator  
Source marker: [PAGE 24]. Verbatim quote: “The goal of model-agnostic meta-learning for fast adaptation of deep networks is to train a model on a variety of learning tasks, such that it can solve new learning tasks using only a small number of training samples.” Source equation:  
\[
\theta \leftarrow \theta - \beta \nabla_\theta \sum_{T_i \sim p(T)} L_{T_i}(f_{\theta_i'})
\]  
Units: \(\beta\) has units chosen to make parameter updates dimensionally consistent; losses \(L_{T_i}\) have task-specific loss units.  
Assumptions: task distribution \(p(T)\) is representative, inner-loop adaptation is stable, and validation tasks are not leaked.  
Breakdown regime: task distribution too narrow, meta-overfitting, unstable inner-loop gradients, or adaptation requires more samples than the meta-learner expects.

9. Meta-reasoning clock operator, derived from SuperDyna  
Source marker: [PAGE 19]. Verbatim quote: “Plan: (while there is time remaining in this time step) imagine hypothetical states and actions you might take.”  
Formal allocation rule:  
\[
m^* = \arg\max_m \frac{\mathbb{E}[\Delta U_m]}{\Delta t_m}
\]  
where \(m\) is a meta-action such as simulate, query, explore, or act; \(\Delta U_m\) is expected utility gain; \(\Delta t_m\) is expected wall-clock cost.  
Units: if \(\Delta U_m\) is utility, the ratio has units of utility per second; if information gain is used, units are bits per second.  
Assumptions: the agent can estimate marginal utility and marginal time cost.  
Breakdown regime: if minimum planning time exceeds remaining decision time, the agent must act with a prior policy; if utility estimates are uncalibrated, the agent may over-plan or under-plan.

<RETROCAUSAL_GENEALOGY>
The source’s genealogy is not merely historical decoration; it explains why certain operators are emphasized and why certain traps recur. The lineage begins with learning as performance improvement, formalized on [PAGE 3] through Mitchell. This creates the ancestor of supervised learning, reinforcement learning, and evaluation-driven engineering. The next ancestor is representation learning, visible in the multilayer perceptron and deep learning discussion on [PAGE 4] and [PAGE 5]. The source states that deep learning allows “computational models that are composed of multiple processing layers to learn REPRESENTATIONS of (raw) data with multiple levels of abstraction” [PAGE 3]. This is the bridge from shallow pattern recognition to hierarchical feature learning.

A second lineage runs through convolutional networks. The source says on [PAGE 6] that the deep convolutional network was “inspired by Hubel and Wiesel’s seminal work on early visual cortex” and “uses hierarchical layers of tiled convolutional ﬁlters to mimic the effects of receptive ﬁelds.” This lineage explains parameter sharing in space and local spatial correlation. The multi-week trap here is to treat convolution as a universal prior. Convolution is powerful when local translation and spatial hierarchy are valid, but it is not automatically optimal for long-range symbolic relations, which is one reason attention later appears.

A third lineage runs through recurrent networks. [PAGE 7] describes recurrent neural networks as “networks with loops in them, allowing information to persist.” This leads to LSTMs, sequence modeling, and eventually attention. The trap is to assume that recurrence is required for time. The source later presents transformers as a more generic architecture where “the only interaction between units is through self-attention” [PAGE 8]. The historical shift is from hand-designed temporal recurrence to learned pairwise interaction. However, the transformer lineage also imports a new trap: quadratic attention cost and hardware dependence.

A fourth lineage runs through self-play and search. The source says on [PAGE 22]: “AlphaGo Zero showed that algorithms matter much more than big data and massive amounts of computation.” This is a reaction against data-heavy supervised learning in domains where rules are known and outcomes are verifiable. The trap is to export this result to domains where verification is weak. Self-play can produce extraordinary performance inside a closed formal system, but it can also produce brittle niche strategies if the evaluation distribution does not include external adversaries or physical perturbations.

A fifth lineage runs through model-based RL and world models. [PAGE 18] presents model-based RL as the agent generating “predictions about the next state and reward before choosing each action.” [PAGE 19] extends this with World Models and SuperDyna. The genealogy is important because planning agents inherit two failure modes: model bias and model compounding error. If the world model is learned from limited data, policy optimization may exploit model errors rather than improve real-world performance.

A sixth lineage runs through meta-learning. [PAGE 23] introduces learning to learn, and [PAGE 24] introduces MAML and AI-GAs. The source quotes Jeff Clune on generating learning algorithms, architectures, and environments [PAGE 24]. The multi-week trap is recursive overconfidence: if a meta-learning system can modify its own learning algorithm, it may also amplify its own evaluation blind spots. Without external validation, meta-learning can optimize for measurable proxies rather than robust capability.

The retro-causal reading is that the present AI stack is caused by past constraints: limited data, limited compute, local spatial correlations, temporal dependencies, game structure, and human supervision. Each successful operator leaves behind a trap. Convolution traps locality assumptions. Recurrence traps long-horizon memory assumptions. Transformers trap hardware capacity assumptions. Self-play traps rule-based verifiability. Model-based RL traps learned dynamics. Meta-learning traps evaluation validity.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
The source contains the materials for a recursive theory of mind because it combines reinforcement learning, multi-agent systems, self-play, and meta-learning. On [PAGE 23], the source states: “We design a Theory of Mind neural network – a ToMnet – which uses meta-learning to build models of the agents it encounters, from observations of their behaviour alone.” This creates an agent that does not only model the world; it models other models. In crisis conditions, this recursion becomes dangerous if the agent regresses to habit while believing it is reasoning about others.

Define an agent’s belief state as a probability distribution over world states and other agents’ policies:  
\[
b_t(o) = p(o \mid h_t)
\]  
where \(h_t\) is the observation-action history. A theory-of-mind extension introduces second-order beliefs:  
\[
b_t^{(2)} = p(\text{other agent model} \mid h_t)
\]  
Units: probabilities are dimensionless. The crisis problem is that under time pressure or stress, the agent may replace explicit model-based inference with a cached habitual policy. This is crisis habit regression.

Crisis habit regression can be formalized as a switch from meta-controlled policy to default policy:  
\[
\pi_{\text{crisis}}(a \mid o) = \pi_{\text{habit}}(a)
\]  
when the estimated value of further deliberation falls below the cost of delay. The source’s SuperDyna planning line is relevant: “Plan: (while there is time remaining in this time step) imagine hypothetical states and actions you might take” [PAGE 19]. If remaining time \(T_{\text{rem}}\) is small, the feasible planning depth satisfies:  
\[
C(d) \le T_{\text{rem}} R_{\text{compute}}
\]  
where \(C(d)\) is compute cost for depth \(d\) and \(R_{\text{compute}}\) is available compute rate. Units: \(C(d)\) may be measured in operations, seconds, or joules; \(T_{\text{rem}}\) is seconds; \(R_{\text{compute}}\) is operations per second, seconds of compute per second, or watts depending on the bottleneck.

The counter-trap is not simply more deliberation. It is calibrated meta-reasoning. The agent should choose among: act now, simulate, query another agent, request information, or defer. A formal meta-control rule is:  
\[
m^* = \arg\max_m \mathbb{E}[U(a_m) - \lambda C(m)]
\]  
where \(U\) is expected utility, \(C(m)\) is time or energy cost, and \(\lambda\) converts cost into utility units. If information gain is the relevant quantity, the rule becomes:  
\[
m^* = \arg\max_m \frac{I(A; O_{\text{next}} \mid h_t, m)}{\Delta t_m}
\]  
with units bits per second. This prevents the agent from confusing activity with progress.

Recursive theory of mind adds another trap: projection. An agent under crisis may assume that other agents share its own regression. The ToMnet quote warns against this only implicitly; it models others from behavior, not from the agent’s own internal panic. Therefore, a robust counter-trap must separate first-order world estimation, second-order agent estimation, and third-order recursive belief stability. If the agent believes that another agent believes that the agent will panic, the agent may create a self-fulfilling coordination failure.

The clock is the adjudicator. In crisis, the clock determines whether recursion is useful or harmful. If \(T_{\text{rem}}\) is too short for stable inference, the correct policy is a safe fallback, not deeper simulation. If \(T_{\text{rem}}\) is sufficient, the agent should allocate time to the highest marginal information gain per second. The source’s SuperDyna loop supplies the architectural clue: interact, learn, plan, discover. In crisis, discovery should be suppressed unless it reduces uncertainty enough to improve immediate action.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
A cross-layer veto proof is needed because the source treats AI as computation, but deployed intelligence must satisfy physical, biomechanical, and environmental constraints. The source acknowledges autonomous agents as devices that perceive and act: “An autonomous agent is any device that perceives its environment and takes actions that maximize its chance of success at some goal” [PAGE 14]. It also lists robotics environments, gym environments, AI Habitat, and hardware [PAGE 27], [PAGE 28], [PAGE 29]. Those pages establish the bridge from software agents to physical systems. The veto proof is as follows.

Suppose a system claims sufficient competence for deployment. Let \(S\) be success, \(A\) be safety, \(E\) be energy feasibility, \(L\) be latency feasibility, and \(W\) be weather or environmental feasibility. A necessary condition for deployment is:  
\[
p(S = 1) \ge p_{\text{target}}
\]  
with constraints:  
\[
p(A = 1) \ge 1 - \epsilon
\]  
\[
E_{\text{used}} \le E_{\text{budget}}
\]  
\[
L_{\text{total}} \le L_{\text{max}}
\]  
\[
W \in W_{\text{operational}}
\]  
All probabilities are dimensionless; \(E\) is joules or watt-hours; \(L\) is seconds; \(W\) is an environmental state category. If any constraint fails, the deployment claim is vetoed regardless of model sophistication.

Physical veto: inference and control latency. For a real-time controller, total loop time is:  
\[
L_{\text{total}} = L_{\text{sense}} + L_{\text{compute}} + L_{\text{actuate}}
\]  
Units: seconds. If the physical plant has stability margin \(L_{\text{max}}\), then:  
\[
L_{\text{compute}} > L_{\text{max}} - L_{\text{sense}} - L_{\text{actuate}}
\]  
implies veto. This is a hard breakdown. A transformer may be theoretically powerful [PAGE 8], but if its inference cannot complete within the control interval, it is unusable for that loop.

Biomechanical veto: embodied agents have actuator limits. For a joint \(j\), torque \(\tau_j\) and velocity \(v_j\) must satisfy:  
\[
\tau_j \le \tau_{j,\max}
\]  
\[
v_j \le v_{j,\max}
\]  
Units: newton-meters for torque, meters per second or radians per second for velocity. If a learned policy commands torques or velocities beyond these limits, the policy is physically inadmissible. The source’s discussion of robotics and environments [PAGE 27], [PAGE 28] supports the need for embodied validation. A model that performs well in simulation may still veto in reality if contact dynamics, friction, or payload constraints are violated.

Energy and thermal veto: compute has power cost. Let \(P_{\text{model}}\) be average power during inference, and \(T_{\text{mission}}\) be required mission duration. Then:  
\[
E_{\text{model}} = P_{\text{model}} T_{\text{mission}}
\]  
Units: watts times seconds equals joules. If \(E_{\text{model}} > E_{\text{budget}}\), veto. Thermal constraints add:  
\[
P_{\text{dissipated}} \le P_{\text{cooling}}
\]  
where \(P_{\text{cooling}}\) is heat removal capacity. If the chip throttles, \(L_{\text{compute}}\) increases, possibly triggering the latency veto. The source’s hardware section [PAGE 29] reminds the reader that model capability is bounded by hardware. This is especially important for edge devices.

Weather and environmental veto: weather changes both observation and dynamics. Let \(W\) be weather state. The observation model becomes:  
\[
p(o \mid s, W)
\]  
and the transition model becomes:  
\[
p(s' \mid s, a, W)
\]  
If weather reduces sensor signal quality, the mutual information between state and observation falls:  
\[
I(S; O \mid W)
\]  
measured in bits. If this information falls below the information required for control, the policy cannot distinguish critical states. For example, rain, fog, snow, dust, glare, or wind can alter perception and actuation. The source’s quote “Run a physics sim long enough and you’ll get intelligence” [PAGE 26] is not sufficient for weather because real weather is stochastic, partially observable, and not fully specified by the simulator.

The final veto proof is therefore a conjunction. Even if the AI has excellent benchmark performance, deployment is valid only if:  
\[
L_{\text{total}} \le L_{\text{max}}
\]  
\[
E_{\text{used}} \le E_{\text{budget}}
\]  
\[
\tau_j \le \tau_{j,\max}
\]  
\[
v_j \le v_{j,\max}
\]  
\[
p(A = 1) \ge 1 - \epsilon
\]  
\[
W \in W_{\text{operational}}
\]  
If any condition fails, the cross-layer veto is active. This is not a minor engineering caveat. It is a formal boundary condition derived from physics, biomechanics, and information theory.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
RLVR means reinforcement learning with verifiable rewards. The source provides RL operators: maximize return [PAGE 16], learn Q-values [PAGE 16], optimize policies [PAGE 18], and use self-play [PAGE 22]. It also lists environments such as OpenAI Gym [PAGE 27], robotics environments [PAGE 27], and trading environments [PAGE 27]. The following three counterfactual veto scenarios are verifiable because each specifies observable metrics, units, and falsification conditions.

Scenario 1: Verifiable simulator reward veto in a trading environment.  
The source lists “OpenAI Gym Environment for Trading” [PAGE 27]. Suppose an RL agent receives verifiable simulated profit-and-loss reward. The reward is verifiable in the simulator because transactions, holdings, and cash are explicit. However, the real objective includes transaction costs, slippage, latency, risk limits, and regulatory constraints. Define simulated return \(J_{\text{sim}}\) and live utility \(J_{\text{live}}\), both in currency units per episode. The veto condition is:  
\[
J_{\text{sim}} - J_{\text{live}} > \Delta_{\text{veto}}
\]  
where \(\Delta_{\text{veto}}\) is a pre-registered currency threshold. Prediction: as training continues, \(J_{\text{sim}}\) rises while \(J_{\text{live}}\) stagnates or falls because the policy exploits simulator omissions. Verification: compare held-out live utility, transaction-cost-adjusted return, and maximum drawdown. If the gap exceeds threshold for three consecutive evaluation windows, the RLVR claim is vetoed. Counterfactual repair: include costs, constraints, and robust risk objectives in the reward. If the gap closes after repair, the original veto was due to misspecified verification.

Scenario 2: Self-play win-rate veto under opponent diversity collapse.  
The source states that AlphaGo Zero learned “without human data, guidance or domain knowledge” [PAGE 22] and achieved superhuman performance in its domain. In a multi-agent setting, self-play can produce a verifiable win probability against itself. Define win probability:  
\[
p_{\text{win}} = \frac{N_{\text{wins}}}{N_{\text{matches}}}
\]  
Units: dimensionless probability. The veto condition is:  
\[
p_{\text{win,self}} \ge p_{\text{high}}
\]  
but  
\[
p_{\text{win,external}} < p_{\text{external,min}}
\]  
with confidence intervals excluding the threshold. Prediction: the agent will appear strong in self-play metrics while failing against held-out opponents that use strategies absent from the self-play niche. Verification: evaluate against a fixed external suite, measure win probability, variance, and exploitability. If external win probability is below the minimum acceptable probability, the RLVR claim is vetoed. Counterfactual repair: add diverse opponents, population-based training, or human prior data. If external win probability rises above threshold, the veto was due to insufficient opponent diversity.

Scenario 3: Model-based RL world-model verification veto under rollout divergence.  
The source presents model-based RL as predicting “the next state and reward before choosing each action” [PAGE 18] and cites World Models and latent planning [PAGE 18], [PAGE 19]. Suppose a learned model has low one-step reconstruction error:  
\[
e_1 = \mathbb{E}[\|s_{t+1} - \hat{s}_{t+1}\|]
\]  
with units of state norm, such as meters, radians, or normalized feature distance. Verification seems successful if \(e_1\) is small. However, policy optimization over long horizons can amplify small model errors. Define multi-step error:  
\[
e_H = \mathbb{E}[\|s_{t+H} - \hat{s}_{t+H}\|]
\]  
If the environment has positive Lyapunov exponent \(\lambda\), measured in inverse seconds, small errors can grow approximately as:  
\[
e_H \approx e_1 \exp(\lambda H \Delta t)
\]  
where \(\Delta t\) is the time step in seconds. The veto condition is:  
\[
e_H > e_{\max}
\]  
before the policy horizon \(H\) is completed. Prediction: simulated return improves while real return fails because the policy exploits model error. Verification: compare planned return \(J_{\text{model}}\) and executed return \(J_{\text{real}}\). If the absolute gap exceeds a pre-registered threshold, veto. Counterfactual repair: shorten planning horizon, use real-world rollouts, add model uncertainty penalties, or learn robust latent dynamics. If the gap closes after repair, the veto was caused by compounding model error rather than policy failure.
</RLVR_COUNTERFACTUAL_VETOES>
