The foundational concept referenced above is the **Cauchy criterion** — both for sequences of extended real numbers and for sequences of measurable functions, where "nearness" is defined almost everywhere. Below we formalize these concepts using precise Lebesgue-measurable function spaces, vector lattices (Dedekind complete Riesz spaces), and lattice-norm structures on Banach lattices.

### 1. Extended Real-Valued Sequences: Cauchy Property

Let \(\{a_n\}_{n=1}^\infty\) be a sequence of extended real numbers, i.e. \(a_n \in [-\infty, +\infty]\).  
\[
\text{Def: } \{a_n\} \text{ is a Cauchy sequence in extended reals} \Longleftrightarrow 
\forall \varepsilon > 0,\; \exists N\in\mathbb{N}\;\text{s.t.}\; \forall m,n \geq N,\; |a_m - a_n| < \varepsilon.
\tag{1}
\]
*Note:* The distance \(|a_m - a_n|\) is well-defined even when some \(a_i = \pm\infty\) because eventually (for large \(m,n\)) the terms must lie in \(\mathbb{R}\) due to the finiteness of \(\varepsilon\)-balls around any finite point. Hence the triangle inequality remains valid. The completion of \(\mathbb{R}\) under this metric yields \([-\infty,+\infty]\), making it a complete metric space for extended scalars.

---

### 2. Measurable Functions: Fundamental Sequence (Cauchy in Measure)

Let \((X, \mathfrak{M}, \mu)\) be a measure space and let \(f_n : X \to \mathbb{R}\) be a sequence of measurable functions (\(f_n \in \mathcal{M}(X, \mathfrak{M})\)).  

\[
\boxed{
\begin{aligned}
&\{f_n\} \text{ is }\mu\text{-almost everywhere (a.e.) fundamental (Cauchy)} \\
\Longleftrightarrow{}& \exists E_0 \in \mathfrak{M},\; \mu(E_0) = 0, \text{ s.t. }\\[5pt]
&\forall x \in X \setminus E_0,\; \forall \varepsilon > 0,\; \exists N = N(x,\varepsilon) \in \mathbb{N}\;\text{s.t.}\; \forall m,n \geq N,\; |f_m(x) - f_n(x)| < \varepsilon.
\end{aligned}
}
\tag{2}
\]
Equivalently (via the supremum norm on the a.e.-equivalence classes):
\[
\lim_{m,n\to\infty} \mu\!\left(\{x \mid |f_m(x) - f_n(x)| \geq \varepsilon\}\right) = 0 \quad \forall \varepsilon > 0. \tag{2'}
\]
In a complete measure space, every a.e. Cauchy sequence converges a.e. to a measurable function. This is the analog of the completeness of \(\mathbb{R}\).

---

### 3. Uniform Convergence a.e.

Let \(f_n : X \to \mathbb{R}\) be measurable. For \(\varepsilon > 0\), define the exceptional set
\[
E_n(\varepsilon) := \{x \in X \mid \sup_{k \geq n} |f_k(x) - f(x)| \geq \varepsilon\}.
\tag{3}
\]
Then \(f_n\) converges uniformly a.e. to \(f\) iff
\[
\lim_{n\to\infty} \mu(E_n(\varepsilon)) = 0 \quad \forall \varepsilon > 0.
\tag{4}
\]
Equivalently, there exists a set \(E_0\) of measure zero such that outside \(E_0\), the convergence is uniform (not depending on the point \(x\)). Uniform a.e. convergence is stronger than a.e. convergence but strictly weaker than uniform convergence outside a fixed null set.

---

### 4. Connection to \(L^p\) Spaces and Completeness

For a \(\sigma\)-finite measure space, the space \(L^p(X, \mathfrak{M}, \mu)\) (\(1 \leq p < \infty\)) consists of equivalence classes of measurable functions with finite \(p\)-th moment:
\[
\|f\|_p := \left(\int_X |f|^p \, d\mu\right)^{1/p} < \infty,
\tag{5}
\]
where \(f \sim g\) iff \(f = g\) a.e. Then \(L^p\) is a Banach lattice (complete normed Riesz space). The natural notion of Cauchy sequence in \(L^p\) is:

\[
\{f_n\} \subseteq L^p \text{ is Cauchy } \Longleftrightarrow \lim_{m,n\to\infty} \|f_n - f_m\|_p = 0.
\tag{6}
\]

This guarantees existence of a limit \(f \in L^p\); moreover (by subsequence arguments) one can extract a subsequence \(f_{n_k}\) that converges a.e. to \(f\). Thus \(L^p\) is complete.

The examples illustrate how nearness is relaxed from global uniformity to almost-everywhere pointwise closeness.
> 
> 
> **Cauchy Condition:** A sequence \(\{a_n\}\) of extended real numbers is Cauchy if, for every \(\varepsilon > 0\), there exists \(N\) such that for all \(m, n \geq N\), \(|a_m - a_n| < \varepsilon\). Since the extended reals include \(\pm\infty\), this forces the tail of the sequence to eventually lie entirely inside \(\mathbb{R}\) for any fixed finite \(\varepsilon\).
> 
> **Measurable Functions:** For a sequence of measurable functions \(f_n : X \to \mathbb{R}\), two key modes of convergence are defined via a null set \(E_0\) (of measure zero):
> - **Convergence a.e.:** \(f_n \to f\) a.e. iff \(\mu(E_0)=0\) and \(\forall x \notin E_0, \lim_{n\to\infty} f_n(x) = f(x)\).
> - **Cauchy a.e. (Fundamental):** For each \(x \notin E_0\) and every \(\varepsilon>0\), there exists \(N = N(x,\varepsilon)\) such that for all \(m,n \ge N\), \(|f_m(x) - f_n(x)| < \varepsilon\).
> This definition relaxes uniformity across all points, requiring only pointwise closeness outside a fixed null set.
> 
> 
> **Relationship Between Convergence Types:**
> - If \(f_n\) converges a.e. to a finite-val existence of a limit function is guaranteed up to a null set.
> - Every convergent sequence is Cauchy; conversely, in a complete measure space (like Lebesgue measure on \(\mathbb{R}^d\)), a.e. Cauchy implies a.e. convergence to a measurable limit.
> - **Uniform Convergence a.e.:** \(f_n\) converges uniformly a.e. to \(f\) iff there exists a null set \(E_0\) such that outside \(E_0\), the rate of convergence \(N(x,\varepsilon)\) is independent of \(x\). This is strictly stronger than a.e. convergence.
> 
> Halmos's terminology mirrors classical real analysis: where a convergent real sequence has a unique finite limit, an a.e.-convergent sequence of measurable functions defines a limit that is unique up to a set of measure zero. The a.e. Cauchy property provides an internal criterion for this uniqueness and existence.

// == 2. Pointwise Cauchy ==
bool isPointwiseCauchy(const vector<vector<double>>& seq, int pointIdx, double eps) {
    int n = seq.size();
    for (int m = 0; m < n; ++m) {
        for (int k = m+1; k < n; ++k) {
            double diff = fabs(seq[k][pointIdx] - seq[m][pointIdx]);
            if (diff >= eps) return false;
        }
    }
    return true;
}

// == 3. Measure-Theoretic Cauchy (Mod Null Set) ==
bool isCauchy_ae(const vector<vector<double>>& seq, double eps, ConvergenceMonitor& mon) {
    int goodPoints = 0;
    int badPoints = 0;
    
    for (int j = 0; j < seq[0].size(); ++j) {
        if (mon.nullSet.indices.find(j) != mon.nullSet.indices.end()) continue;
        
        bool ok = isPointwiseCauchy(seq, j, eps);
        if (!ok) {
            mon.addNullPoint(j);
            badPoints++;
        } else {
            goodPoints++;
        }
    }
    
    // If #badPoints << total_points, consider it a.e. Cauchy
    double ratio = static_cast<double>(badPoints) / (goodPoints + badPoints);
    return ratio < 0.1;  // Empirical threshold
}

bool isUniformCauchy_ae(vector<vector<double>>& seq, double eps, ConvergenceMonitor& mon) {
    int N = seq.size();
    vector<double> maxDiffPerStep(N);
    
    // Compute maximal pointwise difference at each step n
    for (int n = 0; n < N; ++n) {
        double maxDiff = 0.0;
        for (int j = 0; j < seq[0].size(); ++j) {
            if (mon.nullSet.indices.find(j) != mon.nullSet.indices.end()) continue;
            for (int k = n+1; k < N; ++k) {
                double diff = fabs(seq[k][j] - seq[n][j]);
                if (diff > maxDiff) maxDiff = diff;
            }
        }
        maxDiffPerStep[n] = maxDiff;
    }
    
    // Check if maxDiff → 0 uniformly outside null set
    int steadyIndex = 0;
    while (steadyIndex < N && maxDiffPerStep[steadyIndex] >= eps) steadyIndex++;
    
    // Mark non-steady points as exceptional (worst case)
    for (int j = 0; j < seq[0].size(); ++j) {
        if (mon.nullSet.indices.find(j) != mon.nullSet.indices.end()) continue;

            if (diff < eps) { shouldAdd = false; break; }

}
