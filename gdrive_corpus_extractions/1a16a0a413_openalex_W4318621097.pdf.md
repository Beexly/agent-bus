   \[
   \mathbb E_{Y\sim p}[S(p,Y)]\le \mathbb E_{Y\sim p}[S(q,Y)]
   \]
   for all \(p,q\), with strict inequality for strict propriety when \(p\ne q\) [PAGE 4].
2. A top-\(k\) list \(t=(\hat Y,\hat t)\) is padded by assigning the residual mass
   \[
   \pi(t)=\frac{1-\sum_{y\in\hat Y}\hat t_y}{m-k}
   \]
   to every class not in \(\hat Y\), with \(\pi(t)\equiv0\) when \(k=m\). The padded vector is \(\tilde t\) [PAGE 6].
3. Validity is not calibration. A list may be calibrated relative to \(p\) but invalid, or valid relative to some \(q\) but uncalibrated. The paper’s Example 3.1 gives both cases: \(s=(\{1,4\},(0.5,0.1))\) is calibrated but invalid; \(r=(\{1,4\},(0.5,0.2))\) is valid but not calibrated [PAGE 6]. This distinction is the main gray-zone audit point: a scorer that ignores validity can reward a list whose padded distribution equals \(p\) but which is not an admissible top-\(k\) functional value.
4. Symmetric proper scoring rules have symmetric concave entropy functions \(G\). By Lemma 4.3, such \(G\) are Schur-concave, and strictly Schur-concave when the rule is strictly proper [PAGE 9]. A true top-\(k\) list’s padded vector majorizes any calibrated top-\(k\) list’s padded vector [PAGE 10]. Therefore, the expected padded score of a true list is no worse than that of any calibrated list, and strict propriety gives strict consistency on valid lists [PAGE 12].
5. Invalid lists require a separate extension. If one simply applies the padded score to an invalid list, consistency can fail: Example 5.1 shows an invalid top-2 list attaining a lower expected score than a true top-2 list because its padded vector equals \(p\) [PAGE 11]. The repair is to score the largest valid sublist \(t'\) and add a penalty \(c_{\text{invalid}}>0\): \(S(t,y)=S(t',y)+c_{\text{invalid}}\) [PAGE 13]. Strict consistency is recovered exactly when the underlying rule is strictly proper and the penalty is nonzero [PAGE 13–14].
6. Comparability is the cross-\(k\) bridge: extending a true top list cannot worsen the expected score, \(\mathbb E[S(t_{k+1},Y)]\le \mathbb E[S(t_k,Y)]\) [PAGE 11–12]. The lineage runs from weather verification to modern classification evaluation. <RECURSIVE_THEORY_OF_MIND>
The “crisis habit regression” is the reversion to mode-only accuracy when uncertainty is uncomfortable. The paper names the habit directly: classifier evaluation “often focuses on the most likely class (i.e., the mode of the predictive distribution) through the use of classification accuracy and related metrics derived from the confusion matrix” [PAGE 1]. Under crisis—large label sets, missing total order, or costly non-uniform misclassification—the familiar habit is to emit a hard class and score it with accuracy. The paper’s alternative is a top list with confidence scores, because probabilistic classification “separates the prediction task from decision making” and supports diverse cost-loss structures [PAGE 1–2].

The “counter-trap” is the evaluator’s inverse problem: if the predictor knows the evaluator uses an improper or validity-blind metric, it can optimize the metric rather than truth. Example 2.1 is a concrete trap: the most likely label set \(\{1,2\}\) has expected instance F1 \(0.64\), but predicting only \(\{1\}\) attains \(2/3\), so the F1 score rewards a non-mode singleton over the mode [PAGE 5]. Similarly, an invalid top list can be padded into a distribution that matches \(p\) and thereby attain a better padded score than a true list if validity is ignored [PAGE 11]. The zero-penalty case is another counter-trap: Example 5.5 shows the invalid list’s largest valid sublist can match \(p\), making the expected score minimal when \(c_{\text{invalid}}=0\) [PAGE 13]. The recursive fix is to make the evaluator’s rule strictly proper and validity-aware, so the predictor’s best response is truthful reporting.

The “clock” is the evaluation protocol that keeps this recursion stable across instances and across list lengths. The clock ticks at: fixed \(k\); validity check \(\min_{y\in\hat Y}\hat t_y\ge\pi(t)\); penalty \(c_{\text{invalid}}>0\) for invalid lists; empirical mean score over instances; and comparability across \(k\), \(\mathbb E[S(t_{k+1},Y)]\le\mathbb E[S(t_k,Y)]\) [PAGE 11–12]. The paper’s consistency theorem makes the true top-\(k\) list the minimizer, and strict propriety makes it the unique minimizer among valid lists [PAGE 12]. The Brier-based padded score is the preferred clock because it is finite, bounded in the paper’s examples, and gives little incentive to inflate list length [PAGE 3, PAGE 15–16]. The recursive theory of mind is therefore: predictor models evaluator; evaluator models predictor; if the evaluator’s metric is improper, the predictor regresses to the trap; if the evaluator’s metric is strictly proper, valid, and penalized, the predictor’s stable strategy is calibrated top-list reporting.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The source supplies no biomechanical, physical, or weather measurements, so no empirical cross-layer veto can be adjudicated from its pages. The weather layer appears only as historical motivation for proper scoring [PAGE 1]; biomechanics is absent; physical variables are absent. The formal veto proof is therefore conditional and mathematical: let \(\mathcal E\) be an external signal not represented in \((\mathcal Y,p,t,S)\). The consistency statement is a quantified inequality over \(p,t,s\):
\[
\mathbb E_{Y\sim p}[S(t,Y)]\le \mathbb E_{Y\sim p}[S(s,Y)]
\]
for true \(t\) and any admissible \(s\) [PAGE 4, PAGE 12]. If \(\mathcal E\) does not enter \(\mathcal Y\), \(p\), \(t\), or \(S\), it cannot change the inequality; it is not an admissible veto. If \(\mathcal E\) changes \(p\)—for example, a physical constraint sets some class probabilities to zero, or a weather event shifts the conditional distribution—then it is not an external veto but an input to the probabilistic model. If \(\mathcal E\) violates the assumptions—non-symmetric scoring, improper scoring, invalid top list without penalty, zero-probability log event—then the mathematical guarantee is already broken, and the veto is the assumption violation, not the external signal.

Concrete veto conditions from the source are: (i) invalid list with \(\pi(t)>\min_{y\in\hat Y}\hat t_y\) cannot be scored as valid without consistency failure [PAGE 6, PAGE 11]; (ii) \(c_{\text{invalid}}=0\) fails strict consistency for invalid lists [PAGE 13]; (iii) logarithmic score can be infinite on zero-probability outcomes [PAGE 15]; (iv) \(k=m\) makes \(m-k=0\), so the proxy must be defined separately [PAGE 6]; (v) top-\(\beta\) lists are not covered by the consistency theorem [PAGE 16]. A physical “impossibility” constraint is admissible only as \(p_y=0\) for an impossible class; it does not create a new scoring rule. A weather covariate is admissible only if it is part of the feature vector or conditional distribution \(p(X)\). A biomechanical constraint is admissible only if it changes the class set or probability model. Otherwise, the cross-layer claim has no formal standing in this source.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
For an RLVR-style verifier, the source supports three concrete counterfactual vetoes.

1. **Invalid-list padding veto.** Let \(m=4\), \(p=(0.4,0.2,0.2,0.2)\), and let the model output \(t=(\{1,2\},(0.4,0.1))\). Here
   \[
   \pi(t)=\frac{1-0.5}{4-2}=0.25>0.1,
   \]
   so \(t\) is invalid [PAGE 6]. Counterfactual: if the verifier scores the padded vector \(\tilde t=(0.4,0.1,0.25,0.25)\) without validity checking or penalty, it may reward a non-admissible list. The paper’s Example 5.5 shows the largest valid sublist \(t'=(\{1\},(0.4))\) matches \(p\), so the expected score is minimal at \(c_{\text{invalid}}=0\) [PAGE 13]. Veto: require validity and \(c_{\text{invalid}}>0\). Prediction: with a positive penalty, the invalid list’s expected score is strictly worse than the true top-2 list; the verifier will flag it. This is verifiable by direct computation of \(\pi(t)\), the validity inequality, and the penalty term.

2. **Improper-F1 reward veto.** Use Example 2.1: \(p_{\{1,2\}}=0.28\), \(p_{\{1,3\}}=p_{\{1,4\}}=p_{\{1,5\}}=0.24\). The most likely label set is \(\{1,2\}\), but the expected instance F1 of \(\{1,2\}\) is \(0.64\), while predicting \(\{1\}\) gives \(2/3\) [PAGE 5]. Counterfactual: an RLVR reward based on F1 will reinforce the singleton \(\{1\}\) even though the mode is \(\{1,2\}\). Veto: do not use instance F1 as the verifier for a top-list/mode functional; use a strictly proper padded score such as the padded Brier score. Prediction: under F1 reward, the policy’s preferred set will be \(\{1\}\); under a strictly consistent top-list score, the true top-\(k\) list will be optimal [PAGE 12]. This is verifiable by enumerating the expected F1 values and comparing them to the functional truth.

3. **Log-score zero-probability veto.** Suppose a model outputs a hard mode or a top list with zero assigned probability to a realized class. The paper states: “the log score assigns an infinite score in case of the true outcome being predicted as having zero probability” [PAGE 15]. Counterfactual: if RLVR uses the logarithmic score as a reward, a single rare outcome can produce an infinite penalty, driving the policy toward overlong or overconfident coverage rather than calibrated top lists. Veto: use the padded Brier score, which remains finite in the paper’s examples, or enforce a strictly positive proxy probability and a valid penalized extension. Prediction: under \(p^{(h)}=(0.99,0.01,0,0,0)\), the hard mode has expected Brier score \(0.02\) but infinite log score with probability \(0.01\) [PAGE 15]. The verifier will detect the zero-probability event and veto the log-based reward whenever the realized class lies outside the predicted support. This is verifiable by checking whether the realized class has assigned probability zero and whether the scoring rule is finite.
</RLVR_COUNTERFACTUAL_VETOES>
