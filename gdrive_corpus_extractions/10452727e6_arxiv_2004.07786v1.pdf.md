## The paper: Siamese Track-RCNN (Shuai et al., AWS Rekognition, arXiv 2004.07786v1, 16 Apr 2020)

Core idea: Unified MOT system with three branches sharing a backbone:
1. Detection branch (Faster-RCNN style) — localizes all people at time t+δ.
2. Track branch (Siamese, GOTURN-inspired) — tracks existing tracks from t to t+δ.
3. Re-id branch — discriminative embeddings to reinstate terminated tracks after occlusion/reappearance.

### Key equations

**Eq 1 (Track branch prediction)** [PAGE 5]:
$$(\hat{v}, \hat{m}) = \phi(f_{target_t}, f_{search_{t+\delta}})$$

where $\hat{m}$ is estimated motion parameterized as:
$$\hat{m} = \left[\frac{x_{t+\delta}-x_t}{w_t}, \frac{y_{t+\delta}-y_t}{h_t}, \log\frac{w_{t+\delta}}{w_t}, \log\frac{h_{t+\delta}}{h_t}\right]$$

$\hat{v}$ = visibility (binary). $\phi$ = fully connected network inspired by GOTURN.

Search region: $search_{t+\delta} = [x_t, y_t, w_t \cdot r, h_t \cdot r]$ with $r = 2$.

Features flattened and concatenated before $\phi$.

**Eq 2 (Track loss)** [PAGE 6]:
$$\ell_{track} = \begin{cases} \ell_{cls}(\hat{v}, v_{gt}) + \mathbb{1}[v_{gt}]\,\ell_{motion}(\hat{m}, m_{gt}) & \text{if } target_t \in \mathcal{P}^+ \\ \ell_{cls}(\hat{v}, 0) & \text{if } target_t \in \mathcal{N}^- \end{cases}$$

$\ell_{cls}$ = binary cross entropy. $\ell_{motion}$ = smooth L1. $\mathcal{P}^+$ positive samples, $\mathcal{N}^-$ negatives.

**Eq 3 (Re-id triplet loss)** [PAGE 6]:
$$\ell_{reid} = \max\left(0, \max_{q \in \mathcal{P}_p} d(p,q) - \min_{n \in \mathcal{N}_p} d(p,n) + \alpha\right)$$

$\alpha$ = margin = 0.2. $d$ = distance (L2). This is the standard "batch-all" triplet formulation from Hermans et al. (In Defense of the Triplet Loss).

**Total loss** [PAGE 7]:
$$\ell = \ell_{detect} + \ell_{track} + \ell_{reid}$$

### Solver [PAGE 7-8]

<THINK_TRACE>
The paper's thesis is a single multi‑hop claim: detection, short‑term tracking, and re‑identification can share one backbone and be trained end‑to‑end, and this unification is simultaneously cheaper and more accurate than the modular pipeline [PAGE 2]. The derivation chain runs as follows. (1) Tracking‑by‑detection decomposes into localize + associate; association via graph optimization is accurate but expensive because each cue is its own network [PAGE 1]. (2) Tracktor collapses this to detection + regression, gaining speed but losing appearance, so it fails under occlusion and among same‑type neighbors [PAGE 2]. (3) Tracktor++ restores appearance via a bolt‑on re‑id net, recovering accuracy but forfeiting efficiency [PAGE 2]. (4) Siamese Track‑RCNN's move is to internalize all three cues behind a shared ResNet‑101‑DCN/FPN backbone so the low‑level convolution is paid once [PAGE 7, FIG. 1 PAGE 4].

The second multi‑hop thread is *complementarity*, which the ablations quantify. Re‑id alone is unstable under partial occlusion: embeddings computed on truncated appearances split tracklets [FIG. 2 PAGE 19]. Track alone cannot survive full disappearance because it only propagates while the target is visible [PAGE 6]. Combining them yields AP50 39.7 versus 27.8 (track only) and 26.4 (re‑id only) on JTA [TABLE 4 PAGE 13]. Crucially, the interaction is not merely additive: merely *training* with the re‑id branch while inferring with the track branch lifts track‑only AP50 from 27.8 to 29.3 [TABLE 4 PAGE 13], evidence that a shared representation regularizes the motion head.

The third thread is metric epistemics — the sharpest gray zone. MOTA weights identity switches and false negatives equally [PAGE 11], but FN vastly outnumber IDsw (MOT17: 228813 FN vs 556 IDsw [TABLE 1 PAGE 8]). Hence MOTA is dominated by detection recall, not identity fidelity. The authors demonstrate the failure directly: an IoU tracker on strong detections reaches MOTA 85.5 yet AP50 8.07 [TABLE 3 PAGE 12]. This motivates TrackAP, whose identity‑aware IoU exposes temporal coherence MOTA hides [PAGE 11, FIG. 4 PAGE 11].

Gray‑zone audit. (a) The TrackAP operator as transcribed is written as a *sum* $\sum_{t=1}^{T}$ yet described as "the average IoU" [PAGE 11]; the correct operator (following Yang et al. [56]) must divide by $T$, so the transcription almost certainly drops the $1/T$. (b) The runtime is called "sublinear" in track count [PAGE 9]; the plausible mechanism is that the shared backbone dominates cost, so marginal Siamese comparisons are cheap relative to fixed detection cost — not that per‑track cost literally decreases. (c) The solver's constants (IoU>0.3 merge, $\hat v<0.3$ termination, embedding‑L2<0.5 reinstatement, 30 s buffer, 5‑box settling) are hand‑tuned [PAGE 8]; TABLE 6 [PAGE 14] shows a *learned* solver beats them by +8.9 AP50, implicitly conceding the thresholds are suboptimal. (d) MOT16 59.8 vs MOT17 59.6 [PAGE 2] are internally consistent with TABLES 1–2.

<SOURCE_OPERATORS_AND_EQUATIONS>
Detection branch (Faster‑RCNN): classification by multi‑class cross entropy, regression by smooth‑$\ell_1$ [PAGE 5]; loss averaged over the frame pair, $\ell_{\text{detect}} = \tfrac12(\ell_{\text{detect}}^{(t)} + \ell_{\text{detect}}^{(t+\delta)})$ [PAGE 5].

Search construction and motion parameterization [PAGE 5]:
$$
\text{search}_{t+\delta} = [\,x_t,\, y_t,\, w_t r,\, h_t r\,],\qquad r=2 .
$$
$$
(\hat v,\hat m) = \phi\!\left(f_{\text{target}_t},\, f_{\text{search}_{t+\delta}}\right),\qquad
\hat m = \left[\frac{x_{t+\delta}-x_t}{w_t},\ \frac{y_{t+\delta}-y_t}{h_t},\ \log\frac{w_{t+\delta}}{w_t},\ \log\frac{h_{t+\delta}}{h_t}\right].
$$
Units: the two translation terms are dimensionless (pixels/pixels); the two scale terms are dimensionless log‑ratios; $\hat v\in[0,1]$ (dimensionless, BCE‑trained). Singularities: $\hat m$ diverges as $w_t\to 0$ or $h_t\to 0$ (degenerate boxes), and $\log(w_{t+\delta}/w_t)$ is undefined for $w_{t+\delta}\le 0$ or $w_t=0$ — i.e., the parameterization is only valid on strictly positive‑extent boxes, which is why tiny boxes ($<25\times50$ px) are discarded [PAGE 10].

Track loss [PAGE 6]:
$$
\ell_{\text{track}} =
\begin{cases}
\ell_{\text{cls}}(\hat v, v_{gt}) + \mathbb{1}[v_{gt}]\,\ell_{\text{motion}}(\hat m, m_{gt}), & \text{target}_t \in \mathcal{P}^{+},\\[4pt]
\ell_{\text{cls}}(\hat v, 0), & \text{target}_t \in \mathcal{N}^{-},
\end{cases}
$$
with $\ell_{\text{cls}}$ = binary cross entropy and $\ell_{\text{motion}}$ = smooth‑$\ell_1$. Breakdown: for $\text{target}_t\in\mathcal{N}^-$, $m_{gt}$ is undefined, so the indicator $\mathbb{1}[v_{gt}]$ correctly suppresses the motion term; if a negative were mislabeled positive the loss would regress toward an undefined target.

Re‑id triplet loss [PAGE 6]:
$$
\ell_{\text{reid}} = \max\!\Big(0,\ \max_{q\in\mathcal{P}_p} d(p,q) - \min_{n\in\mathcal{N}_p} d(p,n) + \alpha\Big),\qquad \alpha=0.2 .
$$
This is the batch‑hard formulation [ref 28, PAGE 6]; $d(\cdot,\cdot)$ is Euclidean distance in the 128‑D embedding (dimensionless learned metric). Breakdown/singularity: $\min_{n\in\mathcal{N}_p}$ and $\max_{q\in\mathcal{P}_p}$ are undefined if $\mathcal{N}_p$ or $\mathcal{P}_p$ is empty — the batch (40 frame pairs [PAGE 7]) must contain at least one positive and one hard negative per anchor or the term collapses; if $\alpha$ is too large every triplet is active and gradients saturate toward zero.

Joint objective [PAGE 7]: $\ell = \ell_{\text{detect}} + \ell_{\text{track}} + \ell_{\text{reid}}$ — an unweighted sum, so loss scales are assumed comparable (a gray zone, since no per‑term normalization is stated).

TrackAP [PAGE 11], corrected for the missing normalizer:
$$
\text{IoU}_{\text{track}}(\hat T, T^{gt}) = \frac{1}{T}\sum_{t=1}^{T}\text{IoU}_{\text{det}}\!\left(\hat{bb}_t,\, bb^{gt}_t\right),\quad \text{IoU}_{\text{det}}\in[0,1],
$$
with $\text{IoU}_{\text{det}}=0$ where no box is predicted, then thresholded at 0.50/0.75 to give AP50/AP75 [PAGE 11]. Singularity: $T\to 0$ (empty GT track) is undefined.
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
Intellectual lineage is explicit and shallow‑depth. The detector is Faster R‑CNN [ref 41] enriched à la Mask R‑CNN [ref 24]; the backbone is ResNet‑101 [ref 25] with FPN [ref 36] and deformable convolutions [ref 12] [PAGE 7]. The nearest ancestor is Tracktor [ref 5], whose "regress the box from the previous frame" idea the authors adopt and then extend; the paper positions itself as the answer to Tracktor's two stated failures — no appearance model, no long‑term reinstatement [PAGE 2]. The motion head $\phi$ descends from GOTURN [ref 26]; the authors state they are "the first… to propose to use Siamese‑based trackers in an end‑to‑end trainable framework for MOT" [PAGE 3], citing the SOT lineage SiamFC [6], SiameseRPN [34], SiamRPN++ [33], SiamMask [51]. The re‑id head inherits the triplet loss of Hermans et al. [28]. The unified‑network idea is bracketed against MOTS (Voigtlaender [49]) and Yang et al. [56], who unified detection + re‑id for *mask* tracking; the delta here is bbox tracking plus an explicit motion branch, and TrackAP itself is imported from Yang et al.'s video instance segmentation [PAGE 11].

The "multi‑week traps" — reinterpreted as the debts this lineage leaves outstanding — are concrete and author‑acknowledged. First, scope: the framework is demonstrated only on *people*; generalization to arbitrary categories is future work [PAGE 14]. Second, evaluation‑data scarcity: there is "no publicly available, large scale, real‑world multi‑person tracking dataset," forcing the ablation onto synthetic JTA rendered by the GTA engine [PAGE 10], which builds in a domain gap to real optics. Third, the hand‑tuned solver is superseded by a learned one only *after* publication‑grade results, leaving the shipped thresholds as a lineage debt [PAGE 14]. Fourth, MOTChallenge's seven training videos are "too few to further split," so the benchmark cannot support its own ablation [PAGE 10].

<RECURSIVE_THEORY_OF_MIND>
Mapped honestly to a tracker, "theory of mind" is the network's implicit model of a target's *visibility dynamics* — the branch decisions encode beliefs about whether the person is still present. Crisis‑habit regression corresponds to the failure mode of pure regression (Tracktor): when a target enters occlusion (a crisis), a position‑extrapolating tracker continues to "habitually" predict forward motion and drifts onto a crossing neighbor, producing the ID switches seen in FIG. 1 [PAGE 19]. The Siamese track branch counter‑traps this by conditioning on the target's *appearance template* $f_{\text{target}_t}$ against the search region [PAGE 5], so a sudden appearance change no longer derails it (FIG. 5 right, PAGE 13). The re‑id branch is the long‑horizon counter‑trap: after full occlusion it reinstates via embedding similarity, and richer cues (velocity, size, confidence) matter "especially when their appearance has largely changed" (FIG. 4, PAGE 20).

The "clock" is the set of temporal horizons the solver commits to: training pairs sampled within a 1 s window ($\delta=30$ at 30 fps) [PAGE 7]; inference at $\delta=1$ frame as a sliding window [PAGE 7]; a reinstatement decision deferred until the new track has been observed "for a few frames" and then averaged over the "5 most similar bounding boxes" [PAGE 8]; and a 30 s embedding buffer trading memory against recall of terminated identities [PAGE 8]. These constants define the model's temporal "belief horizon": anything disappearing beyond 30 s is information‑theoretically unrecoverable because no cached embedding remains.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
For this paper the veto layers are computational, input‑quality, and physical‑optical rather than biomechanical or meteorological; I prove each as a breakdown condition.

Veto 1 — detection‑quality veto (dominant). Because the benchmark uses *provided public detections* [PAGE 8], MOTA is bounded by detector recall: with FN dominating MOTA's numerator (228813 vs 556 IDsw, MOT17 [TABLE 1 PAGE 8]), $\text{MOTA}\approx 1-\frac{FN+FP+IDsw}{\text{GT}}$ is FN‑dominated. Proof of veto: any regime that inflates FN (small, distant, densely occluded people) collapses MOTA regardless of association quality. The paper's own appendix confirms detection sensitivity: sequence MOT17‑03 with SDP reaches 78.4 MOTA vs 72.0 with FRCNN [PAGE 20].

Veto 2 — scale/optical‑resolution veto. Angular size sets a hard floor: boxes are discarded below $25\times50$ px, beyond 25 m, or under 50% joint visibility, and 1080p is downsampled to short side 900 [PAGE 10]. Physical proof: once a person subtends fewer resolvable pixels than the appearance model needs, $f_{\text{target}}$ carries no discriminative signal and both track and re‑id heads are information‑starved.

Veto 3 — real‑time compute veto. Throughput is 6 fps at ~20 people, 5 fps at ~40, 4 fps at ~60 on one Tesla V100 at 1080×1920 [PAGE 9–10]. For a live 30 fps feed with tens of targets, the pipeline is sub‑real‑time — a hard compute veto for deployment despite the efficiency claim relative to Tracktor++.

Veto 4 — occlusion‑horizon veto. Reinstatement requires an embedding within the 30 s buffer [PAGE 8]; occlusions longer than the buffer, or appearance drift exceeding the triplet margin $\alpha=0.2$'s learned separation, make reinstatement fail — verified by the Re‑ID branch only partially cutting IDsw (10700 → 6380 on JTA, TABLE 3 PAGE 12).

Veto 5 — synthetic‑to‑real domain veto. GTA‑rendered JTA [PAGE 10] omits real sensor noise, motion blur, and lighting/weather statistics; conclusions drawn on JTA AP50 need not transfer to real optics — an external‑validity veto, not a numerical one.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Three falsifiable scenarios with predictions checkable against the paper's own data.

Veto A — MOTA is detection‑confounded, not tracker‑driven. Counterfactual: hold the tracker fixed and degrade input detections; predict MOTA falls roughly with recall while the Siamese‑vs‑Tracktor MOTA gap shrinks, because both consume identical detections. Verifiable against appendix TABLE 2 [PAGE 20]: per‑sequence MOTA already swings with detection source (MOT17‑03: SDP 78.4 / FRCNN 72.0 / DPM 72.3). Prediction: the tracker's true marginal value shows up in IDF1/IDsw/TrackAP, not MOTA; if someone reports a large MOTA gain from the track branch under poor detections, that claim is vetoed.

Veto B — TrackAP must be an average, not a sum. Counterfactual: reimplement the transcribed operator $\sum_t \text{IoU}_{\text{det}}$ without the $1/T$ [PAGE 11]; predict scores scale with track length, so long‑track‑heavy methods (e.g., an aggressive IoU linker) would be spuriously inflated and the method ranking would invert relative to TABLE 3 [PAGE 12]. Verifiable: only the $1/T$‑normalized operator reproduces the published, length‑fair AP50 ordering (Deepsort 8.07 < Tracktor 18.3 < Siamese 29.3 < Siamese+ReID 39.7). If a sum‑based reimplementation fails to reproduce those numbers, the transcription‑as‑sum reading is refuted.

Veto C — the optimal $\delta$ is motion/resolution‑relative, not universal. Counterfactual: the peak at $\delta=30$ (AP50 39.7, TABLE 5 PAGE 14) should hold only when $\delta$ × per‑frame displacement stays inside the $r=2$ search window and within the appearance‑change tolerance set by $\alpha$. Prediction: retraining JTA at higher fps or scaled velocity shifts the AP50 maximum to smaller frame‑$\delta$ (same physical time), and the U‑shape's minimum moves accordingly. Verifiable by re‑sampling pairs at altered motion statistics; if the AP50 peak stays pinned at 30 frames across fps/motion changes, the "displacement‑relative" hypothesis is refuted and $\delta=30$ would be an unexplained dataset constant.

Each veto is decidable from data already latent in the paper (per‑sequence detection tables, the four‑row TrackAP ablation, and the $\delta$ sweep), so all three are verifiable rather than rhetorical.
</RLVR_COUNTERFACTUAL_VETOES>
