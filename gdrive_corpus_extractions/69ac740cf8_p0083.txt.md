**Theorem A (Local Density):**  
Let $E \subseteq \mathbb{R}$ be Lebesgue measurable with $0 < \mu(E) < \infty$. For any $0 \leq \alpha < 1$, there exists an open interval $U$ such that  
\[
\mu(E \cap U) \geq \alpha \mu(U). \tag{1}
\]
*Proof sketch from [PAGE 83]:* Let $\mathcal{U}$ be the class of open sets. By outer regularity (cited as 15.C in Halmos), $\mu(E) = \inf \{ \mu(V) : E \subset V, V \in \mathcal{U} \}$. Choose open $V_0 \supset E$ with $\alpha \mu(V_0) \leq \mu(E)$. Decompose $V_0$ into disjoint open intervals $\{U_n\}_{n=1}^\infty$. Then  
\[
\mu(E) = \sum_{n=1}^\infty \mu(E \cap U_n), \quad \mu(V_0) = \sum_{n=1}^\infty \mu(U_n).
\]
Thus,  
\[
\alpha \sum_{n=1}^\infty \mu(U_n) \leq \sum_{n=1}^\infty \mu(E \cap U_n).
\]
It follows that for some $n$, $\alpha \mu(U_n) \leq \mu(E \cap U_n)$. Take $U = U_n$.

**Theorem B (Steinhaus Theorem):**  
If $E \subseteq \mathbb{R}$ is Lebesgue measurable and $\mu(E) > 0$, then there exists $\delta > 0$ such that  
\[
(-\delta, \delta) \subseteq D(E). \tag{2}
\]
*Proof from [PAGE 83]:* Assume $E$ does not contain an interval (otherwise trivial). Apply Theorem A with $\alpha > 1/2$ (specifically, choose $\alpha$ so that $2\alpha > 1$). Obtain a bounded open interval $U$ satisfying  
\[
\mu(E \cap U) > \frac{1}{2} \mu(U). \tag{3}
\]
Let $A = E \cap U$. For $x \in \mathbb{R}$ with $|x| < \mu(U)$, consider the sets $A$ and $A_x := A + x$. Both are measurable with $\mu(A) = \mu(A_x)$. Note that  
\[
A \subseteq U, \quad A_x \subseteq U + x.
\]
The union $W_x := U \cup (U + x)$ is an interval whose length is $\mu(W_x) < 2\mu(U)$ because the shift $x$ is smaller than the length of $U$. More precisely, if $U = (a,b)$, then $W_x = (\min(a, a+x), \max(b, b+x))$, and its length is $(b-a) + |x| = \mu(U) + |x| < 2\mu(U)$ when $|x| < \mu(U)$.

Now suppose $A$ and $A_x$ are disjoint. Then  
\[
\mu(A \cup A_x) = \mu(A) + \mu(A_x) = 2\mu(A).
\]
Since $A \cup A_x \subseteq W_x$, we have  
\[
2\mu(A) \leq \mu(W_x) < 2\mu(U). \tag{4}
\]
However, from (3), $2\mu(A) > \mu(U)$. This alone does not contradict (4). To obtain a contradiction, we need a stronger inequality. The text hints at using a sharper bound from Theorem A: by choosing $\alpha$ close enough to 1, we can ensure $\mu(A) > \frac{1}{2}\mu(U) + \epsilon$ for some $\epsilon > 0$. Then for $|x|$ sufficiently small, $\mu(W_x) = \mu(U) + |x| < \mu(U) + \delta$ for any $\delta > 0$. Taking $|x| < 2(\mu(A) - \frac{1}{2}\mu(U))$ yields  
\[
2\mu(A) > \mu(U) + |x| = \mu(W_x),
\]
which contradicts $2\mu(A) \leq \mu(W_x)$. Hence $A \cap A_x \neq \emptyset$. There exist $y \in A$ and $z \in A$ such that $y = z + x$, i.e., $x = y - z \in D(E)$. Thus $(-\delta, \delta) \subseteq D(E)$ for $\delta = 2(\mu(A) - \frac{1}{2}\mu(U)) > 0$.

Theorem B is a cornerstone of measure theory with roots in early 20th-century developments. Its historical lineage traces back to work by W. Sierpiński and later popularized by H. Steinhaus (1920), hence the name "Steinhaus theorem." Steinhaus proved it for sets of positive Lebesgue measure on the real line, demonstrating that such sets cannot be too sparse: their difference set must contain an interval around zero. This was a precursor to more general results in harmonic analysis, particularly concerning Bohr compactifications and almost periodic functions.

The proof technique employed by Halmos—using outer regularity and a density argument—is characteristic of the measure-theoretic approach solidified in the 1930s-1950s. Prior to this, results about difference sets were often established using Baire category or direct construction. The Steinhaus theorem itself influenced the development of additive number theory (e.g., Freiman's theorem) and ergodic theory (via the Poincaré recurrence theorem, which can be viewed as a dynamical version of Steinhaus).

From a multi-week trap perspective, students often misapply Theorem B by assuming it holds for arbitrary sets of positive outer measure or for non-Lebesgue-complete measures. A common error is to think that if $E$ is measurable and $\mu(E)>0$, then $E$ must contain an interval—which is false (fat Cantor sets). The theorem correctly asserts something weaker but still powerful: the difference set contains an interval. Another trap is confusing this with the Lebesgue density theorem, which gives pointwise density conditions almost everywhere. Theorem B is a global consequence of local density, but it does not follow directly from density points without additional work (though alternative proofs exist using convolution).

Historically, the theorem was used to prove that the set of differences of a set of positive measure is large, which in turn helped characterize when a function is approximately continuous or when a set is a uniqueness set for trigonometric series. In modern contexts, it appears in the study of sumsets in additive combinatorics (e.g., $A+A$ contains an interval if $A$ has positive measure) and in the analysis of random walks on groups. The genealogy shows a shift from concrete examples (like intervals) to abstract measure spaces, emphasizing structural properties over explicit construction.
