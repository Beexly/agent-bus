(5) Sparse co-user neighborhoods (|U_i^tr ∩ U_j^tr| = 0) yield B_ij = 0, blurring BEN in low-density regions such as Electronics tails [PAGE 9, Section 7.1].
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
Historical and scientific lineage, plus multi-week operational traps.

Lineage. BRIDGE descends from pairwise implicit-feedback ranking (BPR [21], Rendle et al. 2009) and graph collaborative filtering (LightGCN [4], He et al. 2020), extended into multimodal settings through VBPR [3], MMGCN [28], GRCN [27], DualGNN [26], and LATTICE [36] [PAGE 2]. The cross-view alignment family includes AlignRec [10], while frequency-aware methods include SMORE [16], FITMM [33], SSR [34], MSCF-Net [6], DuGRec [13], and D-DPDG [29] [PAGE 2]. Behavior-guided precursors use interaction structure to validate content relations (BPR, LightGCN, DRAGON [38], FGCM [15], JBM-Diff [18], causal-inspired multimodal recommendation [31]) [PAGE 2]. Item-neighborhood and linear item–item methods (Sarwar et al. [23], EASE [24]) are the closest behavioral ancestors, but BRIDGE differs by treating raw co-occurrence and EASE as candidate-side residual controls rather than standalone catalog-wide rankers [PAGE 2]. The dual-frequency intuition traces to spectral views that organize multimodal or collaborative evidence, though BRIDGE keeps band decomposition as a representation core rather than a standalone predictor [PAGE 2].

Multi-week traps. In a production retrieval-and-rank system with weekly retraining, BRIDGE exhibits several temporal failure modes. Trap 1: behavior graph staleness. B_ij and e_b^ui are computed strictly from D_tr; validation and test interactions are never used to construct the behavior graph, user histories, item popularity, or user-degree features [PAGE 6]. If the user-item interaction distribution shifts week-over-week, the signed evidence b_ui encodes stale co-user overlap and may demote newly relevant items or promote obsolete lookalikes. Trap 2: cold-item and cold-user breakdown. New items have U_i^tr = empty, so B_ij is undefined or zero; new users have H_u^tr = empty, so e_b^ui is empty and b_ui cannot be normalized. The paper removes cold-start users from validation/test after filtering [PAGE 7], but live traffic introduces them continuously, creating a coverage gap the residual cannot fill. Trap 3: candidate-scope drift. C_tr_u is recomputed for each mini-batch from detached base embeddings rather than cached across epochs [PAGE 6], so the scope tracks the evolving base scorer within an epoch, but between weekly retraining cycles the base manifold can shift enough that previously plausible candidates exit the shortlist; because the top-K membership itself is detached, gradients do not directly optimize scope membership, producing a recursive lag between representation learning and calibration scope. Trap 4: popularity skew intensifies over time. Head items accumulate more interactions, making co-user overlap denser for head pairs while tail and cold items rely on cross-modal structure [PAGE 8, Table 4]. Without recalibration of lambda_b on a rolling validation window, the residual strength selected on historical data may over-correct head items and under-correct long-tail items as the catalog grows.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
Crisis habit regression, counter-trap, and clock dynamics.

Crisis habit regression. When behavior evidence is removed, the model regresses to the base multimodal backbone as its default habit under stress. On Amazon Baby, the full BRIDGE achieves R@20 = 0.1128, but w/o behavior evidence drops to R@20 = 0.1016 and N@20 = 0.0453 [PAGE 8, Table 2]. This regression is not graceful degradation to a stronger multimodal baseline; it is a collapse toward the base encoder behavior, confirming that the residual branch is load-bearing rather than ornamental. The same pattern holds on Sports (w/o behavior evidence R@20 = 0.1162 vs. BRIDGE 0.1262) and Electronics (0.0656 vs. 0.0778) [PAGE 8, Table 3], so the crisis response is domain-general: without signed co-user authorization, the system defaults to pure content geometry.

Counter-trap. The global-correction variant is the counter-trap: applying the same behavior evidence outside the candidate scope recovers part of the loss but remains inferior to candidate-restricted calibration (Baby R@20 = 0.1092 vs. 0.1128; N@20 = 0.0507 vs. 0.0525) [PAGE 8, Table 2]. The trap is the assumption that more signal uniformly improves ranking. When the residual reaches items outside C_tr_u, it competes with the multimodal backbone and perturbs scores for implausible candidates, diluting the local ordering signal. BRIDGE avoids this by gating the correction with I[i in C_u], so behavior evidence only reorders items the backbone has already admitted as plausible [PAGE 6].

Clock. The operational clock is the candidate-refresh cadence. During training, C_tr_u is recomputed for each mini-batch from detached base embeddings rather than cached across epochs, so the scope tracks the evolving scorer [PAGE 6]. At inference, C_u = TopK(s_base(u, ·), K_c) with K_c = 200 is fixed [PAGE 6]. The clock period is therefore the mini-batch refresh interval versus epoch caching. If base embeddings drift between recomputations faster than the candidate set updates, boundary items near rank 200 flicker in and out of scope, inducing high variance in the residual gradient. This recursive misalignment means the base scorer must remain responsible for moving new positives into C_tr_u through L_base whenever the residual is inactive [PAGE 7], establishing a two-timescale system: fast base-encoder updates and slow behavior-residual calibration bounded by the candidate clock.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical, biomechanical, and weather veto proofs.

Physical veto (computational layers). Table 2 [PAGE 8] provides direct layer vetoes. Removing behavior evidence vetoes BRIDGE: Baby R@20 falls from 0.1128 to 0.1016. Relaxing the top-K scope (w/o top-K calibration) vetoes candidate restriction: R@20 = 0.1025. Global correction vetoes unbounded residuals: R@20 = 0.1092, N@20 = 0.0507, both below full BRIDGE. Removing the item graph vetoes the second smoothing stage: Baby R@20 collapses to 0.0824, the largest single-module drop in Table 2(a), showing the cached item-item graph carries the largest share of multimodal gain. Removing image or text alone causes smaller losses (0.1089 R@20 each), confirming modalities are complementary rather than interchangeable [PAGE 8].

Biomechanical veto (architecture and regularization). Disabling the information-bottleneck surrogate vetoes gate control: Baby R@20 = 0.1031 vs. 0.1128 [PAGE 8]. Disabling the frequency structural regularizer vetoes band geometry: R@20 = 0.1107, N@20 = 0.0517 [PAGE 8]. Disabling both frequency objectives gives R@20 = 0.1023 [PAGE 8]. Removing frequency decomposition entirely under equal capacity yields R@20 = 0.1110, close but below BRIDGE’s 0.1128 [PAGE 9, Section 7.2]; Gram, DCT, and random orthogonal bases remain within 0.0002 of each other, vetoing the claim that any particular spectral basis is sacred—the important factor is the band split itself, not the basis [PAGE 9].

Weather veto (environmental and distributional stress). Table 4 [PAGE 8] vetoes the hypothesis that gains come from head-item favoritism: BRIDGE raises Recall@20 in every stratum (Baby Head 0.1739, Mid 0.0261, Tail 0.0189, Cold 0.0109; Sports Head 0.1986, Mid 0.0497, Tail 0.0438, Cold 0.0283; Electronics Head 0.1115, Mid 0.0099, Tail 0.0045, Cold 0.0024) while reducing head exposure (Baby 0.9426, Sports 0.8429, Electronics 0.9726) versus base [PAGE 8]. The weather stress is strongest on Electronics, where base head exposure is 0.9939 and the catalog is largest (192,403 users, 63,001 items) [PAGE 7, Table 4]; sparse overlap and local interaction bursts blur BEN there, and the conservative coefficient variant trails the fixed residual (Electronics R@20 0.0738 vs. 0.0778) [PAGE 8, Table 2(b)], vetoing adaptive gating as a substitute for the fixed candidate-weighted rule under sparsity.

Adjudication outcome. All three veto layers concur: behavior evidence must exist, must be normalized, and must be masked by the detached top-K candidate scope; the frequency split must remain as a structural core with both IB and frequency regularizers; and the system must not attempt global score rewriting. Breakdown occurs when sigma_u → 0, when co-user neighborhoods are empty or sparse, or when the candidate clock drifts faster than base-encoder updates.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Three verifiable RLVR counterfactual veto scenarios with formal predictions.

Scenario 1: Global-scope veto. Counterfactual intervention: remove the indicator I[i in C_u] from Eq. 20 so Delta_bridge(u,i) = lambda_b b_ui applies to every catalog item, while retaining BEN normalization and the same lambda_b grid. Verification protocol: retrain BRIDGE on Amazon Baby with the unmasked residual and evaluate under the identical full-sort protocol and processed splits [PAGE 7, Section 6.1]. Observable metric: Recall@20 and NDCG@20 on the held-out test set. Pass/fail threshold: if test R@20 <= 0.1095 and N@20 <= 0.0510, the veto is confirmed, because the paper’s global-correction control already reports Baby R@20 = 0.1092 and N@20 = 0.0507 [PAGE 8, Table 2]. Prediction: global application competes with the base backbone on implausible items, shrinking the margin; NDCG degrades more than Recall because top-ordering near the cutoff is corrupted by out-of-scope corrections.

Scenario 2: Spectral-null veto. Counterfactual intervention: disable dual-frequency decomposition by setting M = 1 with H_{c,1} = Z_c (complete representation only), or equivalently zero out all bands m > 1 so no high-frequency private variation reaches the base embedding. Verification protocol: replace DFGE band routing with the equal-capacity no-decomposition control H_{c,m} = (1/M) Z_c [PAGE 5, Eq. 10] but remove band gates, then evaluate Baby Recall@20 and NDCG@20. Observable metric: delta relative to BRIDGE R@20 = 0.1128 and N@20 = 0.0525 [PAGE 8]. Pass/fail threshold: if test R@20 <= 0.1115 and N@20 <= 0.0515, the veto is confirmed, consistent with the equal-capacity control of 0.1110 R@20 reported in Section 7.2 [PAGE 9]. Prediction: the loss of higher-frequency bands removes local ranking signal, so NDCG@20 drops disproportionately relative to Recall@20 because top-list ordering depends on private variation not shared across views.

Scenario 3: Temporal-leakage veto. Counterfactual intervention: construct the BEN behavior graph B_ij using validation and test interactions in addition to D_tr, violating the training-only constraint [PAGE 6]. Verification protocol: build B_ij from the full interaction matrix including future test edges, keep all other hyperparameters fixed (K_b = 1000, z-score normalization, K_c = 200), and evaluate on the same test split. Observable metric: validation Recall@20 during training versus final test Recall@20. Pass/fail threshold: if validation R@20 exceeds the main BRIDGE validation value by > 0.005 while test R@20 falls below 0.1100, the veto is confirmed, demonstrating non-causal optimistic bias. Prediction: leakage inflates behavior evidence with future co-user overlap, producing a validation-test gap; the candidate scope admits items that appear behaviorally supported only because of test contamination, so calibration loses its authorization function and test ranking collapses relative to the training-only oracle.
</RLVR_COUNTERFACTUAL_VETOES>
