Co-contraction raises $b$ and $k$ but consumes metabolic energy and reduces bandwidth. Tendon yield strength and Golgi tendon organ reflex thresholds impose $\tau_{tendon} < \tau_{yield}$. A voluntary command is biomechanically vetoable if predicted joint torque $\tau_j(t) > \tau_{yield}$ or if the required co-contraction stiffness would push the closed-loop poles into the right-half plane because increased $K$ shifts $\omega_{pc}$ and erodes phase margin.

Layer 3 — Weather / environment: External disturbances enter as additive input $d(t)$ to the plant. Temperature changes nerve conduction velocity $v$ [m/s], altering sensorimotor delay $\tau = L/v$; humidity and wind alter sensor noise covariance $R$ and effective $S/N$ in the information channel. A command is weather-vetoable if the worst-case disturbance bound $\|d\|_\infty > d_{crit}$ or if sensor degradation raises $\sigma_{\max}(S(j\omega)) > \gamma$ (robustness margin violated).

Adjudication hierarchy and veto predicate:
$$\mathcal{V}(u_c, x, d) = \mathbb{I}\Bigl[ \|u_c\|_\infty > u_{sat} \;\lor\; \rho(A_{cl}) > 1 \;\lor\; \sigma_{\max}(S(j\omega)) > \gamma \;\lor\; \tau_j(x, u_c) > \tau_{yield} \Bigr]$$

Priority rules: biomechanical veto (tendon yield, joint torque) overrides physical command execution because tissue damage is irreversible; weather veto (delay growth, noise covariance explosion) overrides both physical and biomechanical layers because it invalidates the model used to compute $A_{cl}$ and $S(j\omega)$. Formal proof of veto sufficiency: if $\mathcal{V}=1$ and the command is suppressed, the closed-loop system remains within the robust control invariant set $\mathcal{C} = \{x : \exists u \in \mathcal{U}, \forall d \in \mathcal{D}, \; x^+ \in \mathcal{C}\}$; if $\mathcal{V}=0$, execution is safe by construction. This is a veto proof because no admissible disturbance or plant drift within the stated bounds can drive the state outside $\mathcal{C}$ when the veto predicate is enforced at every clock tick.
