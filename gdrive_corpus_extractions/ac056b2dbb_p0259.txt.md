Units: λ carries dimensionless measure-theoretic units. If Λ is normalized so that Λ(1_X) = 1 (when 1_X ∈ L⁺), then λ takes probability units, i.e. λ(C) ∈ [0, 1] and is dimensionless.

Positivity [PAGE 244]:
\[
\Lambda \text{ positive} \implies \Lambda(f) \geq 0 \ \forall f \in L^{+} \implies \lambda(C) \geq 0.
\]

Finiteness [PAGE 244]: For compact C and bounded open U with C ⊂ U, choose f ∈ L⁺ such that f|_C = 1 and f|_{X\setminus U} = 0. Then
\[
\lambda(C) \leq \Lambda(f) < \infty.
\]

Monotonicity [PAGE 244]:
\[
D \subseteq C \implies \{f : f \geq \chi_C\} \subseteq \{f : f \geq \chi_D\} \implies \lambda(D) \leq \lambda(C).
\]

Subadditivity [PAGE 244]: Since f + g ≥ χ_{C∪D},
\[
\lambda(C \cup D) \leq \Lambda(f + g) = \Lambda(f) + \Lambda(g)
\]
and, after taking infima,
\[
\lambda(C \cup D) \leq \lambda(C) + \lambda(D).
\]

Disjoint additivity [PAGE 244]: If C ∩ D = ∅, local compactness and Hausdorffness yield disjoint bounded open U, V with C ⊂ U, D ⊂ V. The proof concludes
\[
\lambda(C \cup D) = \lambda(C) + \lambda(D),
\]
so λ is a content on 𝒦(X).

\]

<RLVR_COUNTERFACTUAL_VETOES>
Three verifiable counterfactual veto scenarios with checkable predictions:

Scenario 1 (non-locally-compact base space). Replace X by ℚ ∩ [0, 1] with the subspace topology. Let C = {0}, which is compact. There is no bounded open U ⊂ ℚ containing 0 whose closure in ℚ is compact, because compact subsets of ℚ are nowhere dense and bounded open sets in ℚ have non-compact closures. Consequently no f ∈ C_c(ℚ) satisfies f = 1 on {0} and f = 0 outside a bounded U. Prediction: the admissible set {f : f ≥ χ_C} is empty or the infimum is +∞, so λ({0}) is not finite and the finiteness step fails. Scenario 2 (signed functional). Let X = ℝ and let Λ be the signed linear functional Λ(f) = f(0) − f(1) on C_c(ℝ). This Λ is not positive. Take C = [0, 1]. Admissible functions satisfy f ≥ 1 on [0, 1], hence f(0) ≥ 1 and f(1) ≥ 1. Then Λ(f) = f(0) − f(1) can be made arbitrarily negative by choosing f(1) arbitrarily large while keeping f(0) = 1. Prediction: λ([0, 1]) = −∞, so λ(C) ≥ 0 fails catastrophically and λ is not a content. Verifiable: direct computation shows the infimum is unbounded below.

Moreover, continuous real-valued functions on X are constant, so L⁺ contains only constant functions; no f can equal 1 on {a} and 0 on {b}. Verifiable: check that any continuous f: X → ℝ is constant, hence the admissible classes for {a} and {b} are identical, forcing λ({a}) = λ({b}) while λ({a, b}) equals the same value, violating additivity unless the common value is 0 (which is incompatible with f ≥ χ_C giving positive Λ).
