<Formulation based on cited page [PAGE 1] and explicit definitions}

The metric governing mean convergence is

\[
\rho(f,g) = \int_X |f - g|\ d\mu,
\]

which satisfies the triangle inequality:

\[
\rho(f_1, f_n) \leq \sum_{k=1}^{n-1} \rho(f_k, f_{k+1}) \quad (\forall n \ge 2).
\]

If \(\{f_n\}\) is mean-Cauchy, then for any \(\varepsilon > 0\) there exists \(N\) such that \(m,n \ge N\) implies \(\rho(f_m, f_n) < \varepsilon\).

Theorem A. Given a mean-Cauchy sequence of simple integrable functions, denoted \(s_n\). For any fixed \(m\) the sequence \(\{|s_n - s_m|\}\) is mean-Cauchy and converges in measure to \(s - s_m\) where \(s\) is the limit of the original sequence. Hence

\[
\int_X |s - s_m|\ d\mu = \lim_{n \to \infty} \int_X |s_n - s_m|\ d\mu.
\]

Since \(\{s_n\}\) is mean-Cauchy, \(\int_X |s_n - s_m|\ d\mu \to 0\) as \(m \to \infty\). Therefore \(s - s_m \in L^1(\mu)\) and \(\rho(s,s_m) \to 0\). Choosing \(s_m = g\) yields the first claim.

Theorem B. Given a mean-Cauchy sequence of arbitrary integrable functions \(\{f_n\}\). By definition 8B for each \(n\) there exists a simple integrable function \(g_n\) such that \(\rho(f_n, g_n) < \frac{1}{2^n}\). Using the triangle inequality,

\[
\rho(g_n, g_m) \leq \rho(g_n, f_n) + \rho(f_n, f_m) + \rho(f_m, g_m) < \frac{1}{2^n} + \frac{1}{2^m} + \varepsilon.
\]

Hence \(\{g_n\}\) is mean-Cauchy. By Theorem A, \(g_n \to h\) in mean for some integrable simple \(h\). Finally,

\[
\rho(f_n, h) \leq \rho(f_n, g_n) + \rho(g_n, h) \to 0 \text{ as } n \to \infty,
\]

so \(f_n \stackrel{L^1}{\to} h \in L^1(\mu)\).

Assumptions: \(\sigma\)-finiteness ensures that exhaustion-by-finite-measure sets permits diagonal extraction arguments; the integrability of simple functions guarantees that all intermediate expressions are finite real numbers. Breakdown occurs when \(\mu(X) = \infty\) and no dominating integrable function exists, e.g., the classical example \(f_n = \chi_{[n,n+1]}\) on \(\mathbb{R}\) with Lebesgue measure.
