**Strict propriety definition** [PAGE 4]: A scoring rule S(F_X, Y) is proper if S(F_Y, Y) ≤ S(F_X, Y) for all X, and strictly proper if equality holds iff F_X = F_Y. Negative orientation: smaller is better.

**CRPS** [PAGE 4, eq. (1)]:
CRPS(F_X, y) = ∫_{-∞}^{∞} (F_X(z) - 1{y < z})² dz = E|X - y| - (1/2) E|X - e_X|,
where e_X is an iid copy. Units: same units as Y (e.g., kWh, passengers). Strictly proper w.r.t. distribution of Y. Breakdown: requires numerical integration or ensemble estimator; no closed form for complex models.

**Energy score** [PAGE 5, eq. (2)]:
ES_β(F_X, y) = E(‖X - y‖_2^β) - (1/2) E(‖X - f_X‖_2^β),

**Variogram score** [PAGE 5, eq. (3)]:

**Strict propriety definition** [PAGE 4]: S(F_Y, Y) ≤ S(F_X, Y) for all X; equality iff F_X = F_Y. Negative orientation: smaller is better. Units: score units match the underlying variable for marginal scores; dimensionless for copula scores.

**Continuous ranked probability score (CRPS)** [PAGE 4, eq. (1)]:
CRPS(F_X, y) = ∫_{−∞}^{∞} (F_X(z) − 1{y < z})² dz = E|X − y| − (1/2) E|X − e_X|,
where e_X is an iid copy of X. Units: same unit as Y (e.g., passengers, kWh). Strictly proper w.r.t. the distribution of Y. Breakdown: no closed form for complex forecast densities; requires numerical integration or ensemble estimator.

**Energy score** [PAGE 5, eq. (2)]:
ES_β(F_X, y) = E(‖X − y‖_2^β) − (1/2) E(‖X − f_X‖_2^β),
with f_X an iid copy, β ∈ (0, 2), β = 1 standard. Units: (unit of Y)^β. Strictly proper for all β [PAGE 5]. Breakdown: β must be small enough for moments to exist under heavy tails [PAGE 5]; score scales with H, motivating H^{−1/2} scaling in copula applications.

**Variogram score** [PAGE 5, eq. (3)]:
VS_{W,p}(F_X, y) = Σ_{i=1}^H Σ_{j=1}^H w_{i,j} (|y_i − y_j|^p − E|X_i − X_j|^p)².
Units: (unit of Y)^{2p}. Only proper, not strictly proper [PAGE 5]; cannot identify the true underlying model. Breakdown: insensitive to mean shifts [PAGE 26–27].

**Dawid–Sebastiani score (DSS)** [PAGE 6, eq. (4)]:
DSS(F_X, y) = log(det(Σ_X)) + (y − μ_X)' Σ_X^{−1} (y − μ_X).
Units: dimensionless (log-determinant plus Mahalanobis distance). Proper but not strictly proper; matches only first two moments [PAGE 6]. Breakdown: sample covariance singular when M ≤ H [PAGE 17]; copula version unbounded below as det(R_{U_X}) → 0 [PAGE 12].
