<THINK_TRACE>
The source treats correlation-filter tracking as a layered inference pipeline rather than a single detector. The pipeline begins with candidate generation, then feature extraction, then correlation response, then template update, then final state selection. The paper states this directly: “In single object tracking, there are two non-depth methods: generative method and discriminative method. At present, the five steps of the discriminative method commonly used are motion model, feature extraction, observation model, model update and integration method” [PAGE 5]. This is important because the failure modes are not only “wrong feature” failures; they are failures of the whole chain. A perfect filter can still fail if the motion model never proposes the true target location, and a perfect motion model can fail if the observation model is corrupted by occlusion, illumination, or boundary artifacts.

My multi-hop derivation starts from MOSSE. MOSSE uses Fourier-domain correlation to replace spatial convolution with elementwise multiplication: “In the MOSSE algorithm, to create a fast tracker, the fast Fourier transform (FFT) is used to calculate the correlation in the Fourier domain” [PAGE 6]. The mathematical consequence is that the filter can be learned in closed form from many training images, but the solution is a ratio of accumulated cross-power to accumulated input power. That ratio becomes unstable when the denominator is small at some Fourier frequency. In practical terms, low-energy frequencies, saturated regions, or nearly uniform patches can create ill-conditioned updates. The paper later introduces regularization in CSK: “the formula used by CSK is just to add a regular term 휆‖w‖2 behind MOSSE to prevent overfitting” [PAGE 7]. This is not cosmetic. It changes the singularity structure: without regularization, exact division by near-zero spectral energy can explode; with regularization, the solution remains bounded but may become biased toward smooth filters.

A second derivation path is the shift from sparse sampling to cyclic shifts. KCF uses the circulant structure to generate many shifted training samples, but that same structure creates artificial wrap-around. The source is explicit: “Due to the use of cyclic shift, the KCF algorithm has a boundary effect problem” [PAGE 7]. The gray-zone issue is subtle: the cyclic shift improves speed and sample count, but it violates the physical assumption that the search window is a local crop of a larger scene. When the object is near the boundary, the filter may learn periodic replicas of background content. That is not merely a numerical nuisance; it changes the observation model. The tracker may respond strongly to a wrapped duplicate, producing a confident but wrong peak.

A third path is failure detection. MOSSE introduces PSR, and the source says: “In the experiment, the PSR value between 20 and 60 is considered to be a good tracking effect” [PAGE 6], while the next page continues that when the PSR value “is lower than 7, it is judged as tracking failure and the template is not updated” [PAGE 7]. This is a formal veto mechanism. The assumption is that the response map has a sharp dominant peak and that the surrounding response distribution is approximately Gaussian. In gray-zone cases, such as repeated textures or multiple similar objects, PSR may remain high even when the peak is on the wrong object. Thus PSR is necessary but not sufficient.

A fourth path is scale. DSST adds a scale pyramid, but the scale grid is discrete. The source states: “The DSST algorithm has a scale factor a of 1.02 and a scale number S of 33” [PAGE 8]. That means the scale hypothesis set is finite and geometric. If the true scale ratio falls between grid points, the tracker can only approximate it. If the target changes scale too rapidly, the temporal lag of the update equations becomes visible. The source also notes computational pressure: “DSST uses 33 scale estimates increasing the computational burden” [PAGE 9]. This creates a control-theoretic tradeoff: more scales improve coverage but reduce frame budget, and reduced frame rate increases inter-frame motion, which in turn increases the chance that the target leaves the search window.

A fifth path is reliability. The paper’s proposed reliability network treats the response matrix itself as evidence about whether the peak should be trusted. It extracts nine features from the response map and trains a small network: “The reliability network model is a single-layer network structure consisting of nine feature inputs, two predictive outputs and three neurons” [PAGE 20]. The important conceptual move is that the tracker no longer treats argmax as truth. It treats argmax as a hypothesis whose reliability must be estimated. This is especially relevant for fast motion, where the paper reports improved performance: “The results show that this method achieves better results than the basic algorithm” [PAGE 21].

Overall, the gray-zone audit yields three persistent traps. First, confidence metrics can be locally valid but globally wrong. Second, template update is a double-edged operator: it adapts to appearance change but also admits contamination. The source warns: “The continuous update of each frame may introduce unwanted noise, thereby affecting the tracking effect” [PAGE 5]. Third, real-time constraints force discretization in scale, search region, and update frequency, and each discretization creates a breakdown regime. The paper’s own framing supports this: “Although the correlation filter object tracking methods have a good real-time tracking effect, it still faces many challenges such as scale variation, occlusion, and boundary effects” [PAGE 1].

Assumptions and units. Let frame index be \(t\in\mathbb{N}\), image domain be \(\Omega\subset\mathbb{Z}^2\), pixel coordinates be \((x,y)\), and bounding-box width/height be \(W_t,H_t\) in pixels. Frame rate is \(\mathrm{FPS}\) in \(\mathrm{frames/s}\), with inter-frame interval \(\Delta t=1/\mathrm{FPS}\) in seconds. Response maps and correlation scores are dimensionless after normalization. Learned filters may be real-valued in spatial domain and complex-valued in Fourier domain. For Fourier-domain quantities, if the input image intensity is normalized to dimensionless units, then the discrete Fourier coefficients inherit dimensionless amplitude units under the same normalization; if raw intensity units are retained, correlation products scale as intensity squared. Probability-like outputs, such as Gaussian regression targets \(y_i\), are dimensionless in \([0,1]\).

1. MOSSE correlation operator. The spatial correlation is
\[
g = f \otimes h,
\]
where \(f\) is the input image, \(h\) is the filter template, and \(g\) is the response output. By the convolution theorem,
\[
F(g)=F(f)\cdot F(h)^*,
\]
where \(F(\cdot)\) is the Fourier transform, \(\cdot\) denotes elementwise multiplication, and \(*\) denotes complex conjugation. In shorthand,
\[
G = F \cdot H^*.
\]
The source states this reduction explicitly: “The symbol ⊙ represents element-by-element multiplication, * indicates complex conjugate” [PAGE 6]. The formal multi-image MOSSE objective is
\[
\min_{H^*} \sum_{i=1}^{m} \left\| H^* F_i - G_i \right\|_2^2,
\]
with closed solution
\[
H^* = \frac{\sum_i G_i \cdot F_i^*}{\sum_i F_i \cdot F_i^*}.
\]
The online update form is
\[
H_i^* = \frac{A_i}{B_i},
\]
\[
A_i = \eta G_i \odot F_i^* + (1-\eta)A_{i-1},
\]
\[
B_i = \eta F_i \odot F_i^* + B_{i-1}.
\]
Here \(\eta\) is the learning-rate parameter, dimensionless if \(A_i\) and \(B_i\) are scaled consistently. Failure detection uses
\[
\mathrm{PSR} = \frac{\mathrm{peak}-\mu}{\sigma},
\]
where \(\mu\) and \(\sigma\) are the mean and standard deviation of the response map. PSR is a dimensionless \(z\)-score. The source gives an empirical operating interval: “In the experiment, the PSR value between 20 and 60 is considered to be a good tracking effect” [PAGE 6], and failure when PSR “is lower than 7, it is judged as tracking failure and the template is not updated” [PAGE 7].  
Breakdown regimes: (i) denominator \(\sum_i F_i \cdot F_i^*\) becomes zero or numerically tiny at a frequency, causing division blow-up; (ii) \(\sigma=0\) makes PSR undefined; (iii) non-Gaussian or multimodal response maps make PSR thresholds invalid; (iv) grayscale-only features have limited discriminative power, as the source notes for MOSSE: “the MOSSE algorithm uses grayscale features that are not powerful enough and expressive in general” [PAGE 7].

2. CSK kernelized ridge-regression operator. CSK solves
\[
\min_{w,b} \sum_i L\left(y_i, f(x_i)\right) + \lambda \|w\|_2^2,
\]
with squared loss
\[
L\left(y_i, f(x_i)\right)=\left(y_i-f(x_i)\right)^2,
\]
and linear predictor
\[
f(x_i)=\langle w,x_i\rangle+b.
\]
The targets \(y_i\) are Gaussian-shaped labels, dimensionless in \([0,1]\). In kernel form, with kernel matrix \(K\), the solution is
\[
\alpha = (K-\lambda I)^{-1}y.
\]
Here \(\lambda\) is a dimensionless regularization parameter if \(K\) and \(y\) are normalized.  
Breakdown regimes: (i) \(K-\lambda I\) is singular if \(\lambda\) coincides with an eigenvalue of \(K\); (ii) if \(\lambda=0\) and \(K\) is rank-deficient, the inverse is undefined; (iii) dense sampling increases computational burden, which the source acknowledges by noting that CSK “uses a dense sampling method. The use of dense sampling leads to computational burden problems” [PAGE 7].

3. KCF circulant operator. Let \(x\in\mathbb{R}^n\) and let \(P\) be the cyclic-shift operator. The circulant matrix is
\[
X=C(x)=
\begin{bmatrix}
x_1 & x_2 & \cdots & x_n\\
x_n & x_1 & \cdots & x_{n-1}\\
\vdots & \vdots & \ddots & \vdots\\
x_2 & x_3 & \cdots & x_1
\end{bmatrix}.
\]
The KCF objective is
\[
w = \arg\min_w \sum_i \left(\langle w,\phi(x_i)\rangle-y_i\right)^2+\lambda\|w\|_2^2.
\]
In the Fourier domain, for a single-channel kernelized case, the source gives
\[
\hat{\alpha}=\frac{\hat{y}}{\hat{k}_{xx}+\lambda}.
\]
Detection is
\[
f(z)=\mathcal{F}^{-1}\left(\hat{k}_{xz}\odot\hat{\alpha}\right).
\]
Units: \(x\) may be grayscale intensity, HOG features, or other feature maps; \(y\) is dimensionless Gaussian label; \(\lambda\) regularizes the feature scale.  
Breakdown regimes: (i) \(\hat{k}_{xx}+\lambda=0\) causes division failure; (ii) cyclic shift creates boundary artifacts: “Due to the use of cyclic shift, the KCF algorithm has a boundary effect problem” [PAGE 7]; (iii) fixed search area fails under fast motion: “In addition, the search area is fixed in KCF, so it is easy to exceed the search range in fast motion” [PAGE 7].

4. DSST scale-space operator. The DSST loss over \(d\) channels is
\[
\varepsilon = \sum_{l=1}^{d}\left\|h_l*f_j-g\right\|_2^2+\lambda\sum_{l=1}^{d}\|h_l\|_2^2.
\]
The per-channel frequency-domain solution is written as
\[
H_l = \frac{\bar{G}F_l}{\sum_{k=1}^{d}F_kF_k+\lambda}, \quad l=1,\ldots,d.
\]
The scale search is geometric:
\[
a^n P \times a^n R, \quad n\in\left\{-\frac{S-1}{2},\ldots,\frac{S-1}{2}\right\}.
\]
The source states: “The DSST algorithm has a scale factor a of 1.02 and a scale number S of 33” [PAGE 8]. Thus \(P,R\) have pixel units, \(a\) is dimensionless, and \(S\) is a count. The response score is
\[
y = \mathcal{F}^{-1}\left(\sum_{l=1}^{d}\frac{A_lZ_l}{B+\lambda}\right).
\]
Breakdown regimes: (i) denominator \(\sum_k F_kF_k+\lambda\) becomes small; (ii) scale grid misses the true scale if inter-frame scale change exceeds the grid resolution; (iii) computational load grows with \(S\): “DSST uses 33 scale estimates increasing the computational burden” [PAGE 9].

5. SRDCF spatial-regularization operator. The baseline DCF loss is
\[
\varepsilon_t(f)=\sum_{k=1}^{t}\alpha_k\left\|Sf\odot x_k-y_k\right\|_2^2+\lambda\sum_{l=1}^{d}\|f^l\|_2^2.
\]
SRDCF adds a penalty matrix \(w\):
\[
\varepsilon(f)=\sum_{k=1}^{t}\alpha_k\left\|Sf\odot x_k-y_k\right\|_2^2+\sum_{l=1}^{d}\|w\cdot f^l\|_2^2.
\]
The source states: “The SRDCF algorithm [23] added a regular penalty term” [PAGE 9]. In linear-system form,
\[
\tilde{A}_t f = \tilde{b}_t,
\]
with recursive updates
\[
A_t=(1-\gamma)A_{t-1}+\gamma(D_t^TD_t+W^TW),
\]
\[
\tilde{b}_t=(1-\gamma)\tilde{b}_{t-1}+\gamma D_t^T\tilde{y}_t.
\]
Here \(\gamma\) is a dimensionless learning rate.  
Breakdown regimes: (i) \(A_t\) becomes ill-conditioned if spatial regularization is too weak; (ii) \(\gamma=0\) freezes adaptation; (iii) if \(w\) is poorly chosen, the filter suppresses useful target evidence. The source notes the intended benefit: “After adding the regular coefficient matrix, the response value at the background is obviously suppressed” [PAGE 10].

6. STAPLE complementary-learner operator. STAPLE fuses a template score and a histogram score:
\[
f(x)=\gamma_{\mathrm{temp}1}f_{\mathrm{temp}1}(x)+\gamma_{\mathrm{hist}}f_{\mathrm{hist}}(x).
\]
The template score is
\[
f_{\mathrm{temp}1}(x;h)=\sum_{u\subset\tau}h[u]^T\phi_x[u],
\]
and the histogram score is
\[
f_{\mathrm{hist}}(x;\beta)=g(\psi_x;\beta).
\]
The weights \(\gamma\) are dimensionless mixing coefficients. The source motivates the design: “When the light changes, the color features are not well expressed. The HOG features can track the object under the illumination variation” [PAGE 10].  
Breakdown regimes: (i) color histogram becomes invalid under strong illumination change; (ii) HOG becomes less reliable under severe deformation if local gradient structure changes drastically; (iii) fixed fusion weights can underperform if the reliability of each cue changes rapidly.

7. LMCF APCE peak-oscillation operator. The source defines
\[
\mathrm{APCE}=
\frac{|F_{\max}-F_{\min}|^2}
{\mathrm{mean}\sum_{w,h}\left(F_{w,h}-F_{\min}\right)^2}.
\]
This is dimensionless. It measures response-map oscillation. The source says: “If the APCE suddenly decreases, the target is likely to be occluded or lost” [PAGE 11], and “In this case, the model is not updated to avoid model drift” [PAGE 11].  
Breakdown regimes: (i) denominator zero if all response values equal \(F_{\min}\); (ii) multiple equal maxima can produce ambiguous APCE; (iii) thresholds for “sudden decrease” are empirical and dataset-dependent.

8. BACF background-aware operator. BACF enlarges the search area and inserts a cropping matrix \(P\) into the training objective. The source states: “The BACF algorithm [27] first enlarges the object search area, and then improves the quality of the generated samples” [PAGE 11]. A representative objective is
\[
E(h)=\frac{1}{2}\sum_j\left\|y^{(j)}-\sum_k h_k^T P X_k^{(j)}\right\|_2^2+\sum_l\|w\cdot f^l\|_2^2+\frac{\lambda}{2}\sum_k\|h_k\|_2^2.
\]
Using augmented Lagrange and ADMM, the auxiliary variable subproblem is split over \(T\) dimensions, reducing complexity from \(O(K^3T^3)\) to \(O(K^3T)\), and then to \(O(KT)\) after Sherman–Morrison simplification. The source states: “This makes the complexity of ̂g* from O(K3T3) down to O(K3T)” [PAGE 12].  
Breakdown regimes: (i) augmented-Lagrange matrices become singular if penalty parameters are invalid; (ii) cropping matrix \(P\) may discard true target evidence if misaligned; (iii) larger search area increases background clutter.

9. DRT reliability-decomposition operator. DRT decomposes a filter into base filter and reliability mask:
\[
W_d = h_d \odot V_d,
\]
with
\[
V_d=\sum_{m=1}^{M}\beta_m P_d^m.
\]
The source explains the motivation: “This may cause the trained filter to be dominated by unexpectedly highlighted areas on the feature map, resulting in model degradation” [PAGE 12]. The optimization is constrained by
\[
\theta_{\min}\leq\beta_m\leq\theta_{\max}.
\]
Breakdown regimes: (i) bounds too narrow prevent adaptation; (ii) bounds too wide permit unreliable regions to dominate; (iii) local-response consistency terms can over-smooth genuine target detail.

10. ASRCF adaptive spatial-regularization operator. The source states: “Dai et al. [29] proposed a new adaptive spatial regularization correlation filter (ASRCF) model, which can effectively estimate the object’s perceived spatial regularization and obtain more reliable filter coefficients in the tracking process” [PAGE 13]. The objective is
\[
E(H,w)=\frac{1}{2}\left\|y-\sum_{k=1}^{K}x_k*(P^T h_k)\right\|_2^2+
\frac{\lambda_1}{2}\sum_{k=1}^{K}\|w\odot h_k\|_2^2+
\frac{\lambda_2}{2}\|w-w_r\|_2^2.
\]
The spatial weight solution has the form
\[
w^* = \frac{\lambda_2 w_r}{\lambda_2\sum_{k=1}^{K}h_k\odot h_k+\lambda_2 I},
\]
as written in the source. Here \(w_r\) is a reference weight, and \(\lambda_1,\lambda_2\) are dimensionless regularization parameters.  
Breakdown regimes: (i) denominator zero if all \(h_k\) vanish and \(\lambda_2=0\); (ii) poor reference \(w_r\) biases the filter; (iii) adaptive weights can oscillate if online updates are too aggressive.

11. Proposed motion-feature update operator. The scale-change ratios are
\[
S_w=\frac{W_o}{W_p}, \qquad S_h=\frac{H_o}{H_p}.
\]
These are dimensionless ratios of target width/height to frame width/height. Velocity is
\[
V_x=\frac{P_x^{(i)}-P_x^{(i-1)}}{S_w}, \qquad
V_y=\frac{P_y^{(i)}-P_y^{(i-1)}}{S_h}.
\]
The source says the units are “pixels per frame” [PAGE 16]. Speed magnitude and direction are
\[
\|\vec{v}\|=\sqrt{V_x^2+V_y^2}, \qquad \tan\theta=\frac{V_y}{V_x}.
\]
Acceleration is
\[
a_x=V_x^{(i)}-V_x^{(i-1)}, \qquad a_y=V_y^{(i)}-V_y^{(i-1)},
\]
\[
\|\vec{a}\|=\sqrt{a_x^2+a_y^2}, \qquad \tan\alpha=\frac{a_y}{a_x}.
\]
Acceleration units are pixels per frame squared.  
Breakdown regimes: (i) \(S_w=0\) or \(S_h=0\) makes velocity undefined; (ii) noisy bounding boxes amplify acceleration noise; (iii) if candidate confidence falls below threshold \(T_C\), the source says the target “may belost due to occlusion, illumination changes and the like” [PAGE 17].

12. Reliability-feature operators. Negative samples are defined by Euclidean-distance conditions:
\[
\sqrt{(x_n-gt(x_n))^2+(y_n-gt(y_n))^2}>
\sqrt{(t_s(w)/\varepsilon)^2+(t_s(h)/\varepsilon)^2},
\]
\[
\sqrt{(x_n-x_{n-1})^2+(y_n-y_{n-1})^2}>
\sqrt{(t_s(w)/\gamma)^2+(t_s(h)/\gamma)^2}.
\]
Distances are in pixels; target width/height are in pixels; \(\varepsilon,\gamma\) are dimensionless tolerance constants. The response matrix \(R\) is centralized into \(r_c\), then binarized:
\[
B=f(r_c)=
\begin{cases}
1, & r_c(i,j)>\text{adjacent eight response values},\\
0, & \text{otherwise}.
\end{cases}
\]
Then
\[
R_1=r_c.*B.
\]
Feature counts and ratios include peak number \(n_f\), large-response ratio
\[
P_b=\frac{\text{number }a_{i,j}>\mu_2}{n\cdot m},
\]
negative-value ratio
\[
z=\frac{\text{number }a_{i,j}<0}{n\cdot m},
\]
difference value
\[
v=\sum_{i=1}^{n_f}(R.\max-R(i))^2,
\]
and directional gradients
\[
\frac{\partial \text{response}}{\partial x}=
\begin{cases}
\frac{a_{x,y}-a_{x-1,y}}{\Delta x}, & x=n,\\
\frac{a_{x,y}-a_{x+1,y}}{\Delta x}, & x\neq n,
\end{cases}
\]
with analogous \(y\)-direction definition. The gradients have units of response per pixel. The reliability network is described as “a single-layer network structure consisting of nine feature inputs, two predictive outputs and three neurons” [PAGE 20].  
Breakdown regimes: (i) flat response maps make gradients zero and APCE unstable; (ii) thresholds \(\mu_1,\mu_2,\mu_3\) are empirical; (iii) if no peak passes threshold, the reliability features collapse to null counts, which may force overly conservative behavior.

<RETROCAUSAL_GENEALOGY>
The scientific lineage in the source moves from fast correlation filtering to structured regularization and reliability. MOSSE is the origin point because it introduced correlation filtering into visual tracking: “The MOSSE algorithm [16] introduced the correlation filter technology into the visual tracking field” [PAGE 6]. Its historical importance is speed, but its structural weakness is weak feature representation and sparse sampling. The source says MOSSE “can adapt to small-scale variation, but it cannot adapt to large-scale variation” [PAGE 7]. This creates the first multi-week trap: teams may optimize MOSSE-like speed while ignoring that grayscale correlation is insufficient for appearance changes.

CSK and KCF form the second lineage. CSK introduces kernelization and dense sampling, while KCF exploits circulant matrices for fast training. The source says CSK “used a dense sampling method” and that KCF “sample generation method uses the cyclic shift method” [PAGE 7]. This lineage creates a major evaluation trap: cyclic-shift augmentation can inflate apparent sample diversity while introducing periodic boundary artifacts. A tracker may look strong on datasets where targets remain near the center, but fail near frame boundaries or when the search window is small.

The third lineage is scale and boundary correction. DSST, fDSST, SRDCF, STRCF, BACF, DRT, and ASRCF all respond to weaknesses in KCF. DSST adds scale estimation; the source notes that “Most existing methods are unable to handle scale variation in complex image sequences” [PAGE 8]. SRDCF adds spatial regularization to reduce boundary effects: “The SRDCF algorithm [23] added a regular penalty term” [PAGE 9]. BACF enlarges the search region and improves sample quality: “The BACF algorithm [27] first enlarges the object search area, and then improves the quality of the generated samples” [PAGE 11]. ASRCF makes the spatial regularization adaptive: “Dai et al. [29] proposed a new adaptive spatial regularization correlation filter (ASRCF) model” [PAGE 13]. This lineage creates a multi-week trap of incremental regularization: each new penalty improves one benchmark attribute but may overfit to benchmark-specific occlusion or illumination patterns.

The fourth lineage is reliability-aware tracking. DRT introduces reliability terms because “the trained filter to be dominated by unexpectedly highlighted areas on the feature map, resulting in model degradation” [PAGE 12]. The paper’s own reliability network extends this idea by treating response-map geometry as a confidence signal. The trap here is threshold drift: thresholds calibrated on one dataset may not transfer. The source itself uses empirical intervals such as PSR between 20 and 60 and failure below 7, which are dataset- and implementation-sensitive.

The fifth lineage is evaluation infrastructure. The source introduces OTB, VOT, TColor-128, UAV123, and LASOT. These datasets create multi-week traps because each has different attribute definitions. OTB uses average pixel error and overlap rate, with thresholds “typically set to 20 pixels” and “generally set to 0.5” [PAGE 3]. VOT uses success rate and robustness. TColor-128 emphasizes color. UAV123 emphasizes aerial sequences. LASOT emphasizes long-term tracking. A method that wins on short sequences may fail on long sequences because template drift accumulates. The source notes LASOT “consists of 1400 sequences of more than 3.5 million frames” [PAGE 5], which changes the evaluation regime from short-term localization to long-term model stability.

The final lineage is the tradeoff between traditional correlation filters and deep learning. The source says: “Currently, deep learning algorithms achieve the highest tracking accuracy. However, calculations of deep learning algorithms take much time and run slowly” [PAGE 21]. This is a multi-week trap for system design: a team may chase accuracy and lose real-time feasibility, or chase speed and lose robustness. The source’s proposed answer is hybrid: keep traditional filters fast, add reliability or memory-based update control, and selectively use deep features.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
A recursive theory of mind for this tracker must model three agents: the target, the tracker, and the evaluation environment. The target has motion state, scale state, appearance state, and visibility state. The tracker has a response map, a filter template, an update policy, and failure detectors. The environment has frame rate, illumination, occlusion, clutter, and boundary conditions. The crisis is the moment when the target’s state changes faster than the tracker’s update policy can verify.

Crisis habit regression occurs when the tracker habitually updates after every frame. The source warns: “The continuous update of each frame may introduce unwanted noise, thereby affecting the tracking effect” [PAGE 5]. In a recursive model, the tracker’s habit is to trust the current maximum response. If the target is partially occluded, the maximum response may shift to a distractor. If the template updates, the tracker internalizes the distractor. On the next frame, the distractor becomes the model’s prototype of the target. This is habit regression: the system learns the wrong habit and then reinforces it.

The counter-trap is to introduce a verification layer before update. MOSSE PSR provides one such layer: failure is declared when PSR is too low, and the template is not updated [PAGE 6][PAGE 7]. LMCF APCE provides another: if APCE suddenly decreases, the target is likely occluded or lost, and the model is not updated [PAGE 11]. The proposed reliability network provides a third: response-map geometry is used to decide whether the best matching position is reliable [PAGE 20]. These are counter-traps because they block the tracker’s habitual response to a local maximum.

However, the counter-trap can become its own trap. If the failure detector is too conservative, the tracker stops updating during legitimate appearance change. Then the template becomes stale. The source’s visual-memory mechanism addresses this by saving an alternate template when confidence is low: “When the confidence value of the selected target is lower than the threshold Ta, the template (context regression model) which has been trained from the previous frame is saved as an alternate template Ra” [PAGE 17]. This creates a second-order policy: do not update the main template during crisis, but preserve a clean prior model for later reacquisition.

The clock agent is frame rate and latency. MOSSE is historically fast, with the source citing “an amazing tracking speed of 669 fps” [PAGE 6]. STAPLE runs at “a very good speed 80fps” [PAGE 10]. DSST with 33 scales increases computational burden [PAGE 9]. The clock determines how much crisis evidence can be processed before the target moves again. If the frame interval is too long, inter-frame displacement may exceed the search window. The source notes for KCF: “the search area is fixed in KCF, so it is easy to exceed the search range in fast motion” [PAGE 7]. Thus the clock is not merely performance; it is a constraint on the reachable state space.

The recursive equilibrium is therefore a three-way negotiation. The tracker must update enough to follow true appearance change, but not so much that it follows occlusion or clutter. It must use motion prediction to expand the reachable region, but not so aggressively that prediction locks onto a false velocity. It must use failure detection to freeze the model, but not so long that the model becomes obsolete. The source’s proposed strategies instantiate this equilibrium: motion features predict candidate regions, confidence thresholds trigger alternate-template preservation, and reliability features decide whether the response peak is trustworthy [PAGE 16][PAGE 17][PAGE 20].
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Cross-layer veto adjudication separates physical visibility, kinematic reachability, sensor/feature validity, and algorithmic confidence. A tracker may be mathematically stable yet still be vetoed because the target is not physically observable inside the candidate region.

Layer 1: Kinematic reachability veto. Let the predicted search window at frame \(t\) have width \(W_t\) and height \(H_t\) in pixels. Let the true target center move from \(p_{t-1}\) to \(p_t\). Define inter-frame displacement
\[
d_t=\|p_t-p_{t-1}\|_2,
\]
in pixels/frame. If the search window is centered at \(p_{t-1}\) and has half-width \(W_t/2\) and half-height \(H_t/2\), a necessary condition for the true target to lie inside the search window is approximately
\[
|x_t-x_{t-1}|\leq \frac{W_t}{2}, \qquad
|y_t-y_{t-1}|\leq \frac{H_t}{2}.
\]
If this condition fails, the target is outside the candidate set. Then the correlation filter cannot observe the target, regardless of filter quality. This is a formal veto. The source confirms the architectural weakness for fixed-window KCF: “the search area is fixed in KCF, so it is easy to exceed the search range in fast motion” [PAGE 7].  
Proof sketch: The filter response is computed only over candidate patches inside the search window. If the true target patch is absent from that set, the response maximum must be attained on some non-target patch or on background. Under a monotone similarity assumption, the maximum response cannot correspond to an absent target. Therefore localization fails. This veto is independent of PSR, APCE, or reliability-network output because those metrics evaluate the response map, not the absent target.

Layer 2: Scale-reachability veto. DSST uses a discrete scale grid
\[
a^n, \quad n\in\left\{-\frac{S-1}{2},\ldots,\frac{S-1}{2}\right\}.
\]
With \(a=1.02\) and \(S=33\), the maximum upward scale factor is \(1.02^{16}\) and the maximum downward scale factor is \(1.02^{-16}\). If the true scale ratio \(s_t/s_{t-1}\) lies outside this interval, the tracker cannot exactly represent the target scale. It may still approximate, but if the target changes scale rapidly, the approximation error can push the bounding box below the success threshold. The source gives the scale parameters: “The DSST algorithm has a scale factor a of 1.02 and a scale number S of 33” [PAGE 8]. This creates a scale veto: if the required scale ratio is outside the grid and the approximation error exceeds the overlap tolerance, tracking is adjudicated as failed.

Layer 3: Visibility and occlusion veto. Let visible target area be \(A_{\text{vis}}\). If full occlusion or out-of-view occurs, \(A_{\text{vis}}\to 0\). Then the observation model has no target evidence. The source lists occlusion and out-of-view among tracking challenges [PAGE 3]. If \(A_{\text{vis}}=0\), any response peak is necessarily based on non-target evidence. A reliability layer may detect this, but it cannot localize the absent target. The veto is physical: no algorithm can extract target information from zero target pixels.

Layer 4: Illumination and feature-validity veto. Color histograms assume that color distributions remain discriminative. The source says: “When the light changes, the color features are not well expressed” [PAGE 10]. HOG is more robust under illumination variation: “The HOG features can track the object under the illumination variation” [PAGE 10]. If illumination changes so severely that both color and gradient cues lose discriminative power, the observation model is vetoed. Formally, if the feature-space distance between target and background collapses below the classifier margin, the filter’s discriminant becomes non-identifiable. This is not a threshold tuning problem; it is a feature-validity veto.

Layer 5: Boundary-effect veto. Cyclic-shift-based correlation filters assume periodic repetition. The source states: “Due to the use of cyclic shift, the KCF algorithm has a boundary effect problem” [PAGE 7]. If the target or distractor is near a boundary, the learned filter may respond to wrapped replicas. In such cases, even if the target is inside the search window, the response maximum may be contaminated by artificial periodicity. The veto is architectural: the training distribution violates the physical non-periodicity of the scene.

Adjudication rule. A tracker candidate should be accepted only if all layers pass: kinematic reachability, scale reachability, nonzero target visibility, feature validity, and response-map reliability. If any layer fails, the correct action is not to force an update. The source supports conservative behavior in failure cases: MOSSE does not update when PSR is too low [PAGE 7], and LMCF does not update when APCE suddenly decreases [PAGE 11].
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
RLVR-style counterfactual vetoes are verifiable checks that reject a tracking hypothesis or model-update action when a formal condition is violated. The source provides three verifiable veto structures: PSR-based failure detection, APCE-based peak-instability detection, and reliability-assisted response-map validation.

Veto Scenario 1: PSR collapse under occlusion.  
Formal condition: compute the response map \(R_t\), its peak \(F_{\max}\), mean \(\mu_t\), and standard deviation \(\sigma_t\). Define
\[
\mathrm{PSR}_t=\frac{F_{\max}-\mu_t}{\sigma_t}.
\]
If \(\mathrm{PSR}_t<7\), the source’s failure rule says tracking failure is declared and the template is not updated [PAGE 7]. Counterfactual: if the tracker updates anyway, the template absorbs occluder or background response. Prediction: after occlusion ends, a tracker that froze the template will reacquire the target more reliably if the target remains within the motion-predicted region; a tracker that updated during occlusion will show increased drift and lower overlap. Verifiable metric: OTB success threshold uses overlap ratio, with threshold “generally set to 0.5” [PAGE 3]. Prediction: the freeze policy will have higher average overlap rate after occlusion than the always-update policy, especially in sequences where the target is occluded by a similar object.
