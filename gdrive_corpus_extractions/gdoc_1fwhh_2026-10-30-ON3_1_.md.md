<SOURCE_OPERATORS_AND_EQUATIONS>
Formal operators, LaTeX, units, and page citations.

Operator 1 — Pressure attribution split [PAGE #5][PAGE #7][PAGE #8][PAGE B7].
Let D_q be QB q dropbacks, F_q pressures faced, S_q sacks. Pressure faced rate π_q = F_q / D_q ∈ [0,1] (pressures per dropback, dimensionless). Conversion rate γ_q = S_q / F_q ∈ [0,1] (sacks per pressure, dimensionless). Observed sack rate σ_q = S_q / D_q = γ_q · π_q. Pressure Over Expectation Δ_q = π_q − E[π_q | L_q, S_q], where L_q is offensive-line context and S_q is scheme context; Δ_q unit is pressures per dropback (ppd), range approximately [−0.15, +0.10] per chart [PAGE #5]. League reference σ ≈ 0.23 conversion at Δ ≈ −0.02 [PAGE #5]. Breakdown: when F_q < ~80 pressures, one sack moves γ_q by ~1.7 percentage points [PAGE #5 risks], so QB-level conversion is statistically noisy, not a biomechanical truth. Veto: any pressure citation lacking the (creator, converter) attribution split or an explicit “unsplit” label is excluded from 360° cards.

Operator 2 — Nash equilibrium indifference condition [PAGE #9].
Offense chooses pass mix π ∈ [0,1]; defense chooses box call b ∈ {light, heavy}. Light-box EPA values stated: run R_L = −0.07 EPA/play, pass P_L = +0.02 EPA/play [PAGE #9]. Heavy-box values R_H, P_H are not stated in the post. Defense indifference requires offense mix π* such that expected EPA is equal across box calls:
(1 − π*)R_L + π*P_L = (1 − π*)R_H + π*P_H.
Solving: π* = (R_H − R_L) / [(R_H − R_L) + (P_L − P_H)]. Reported crossing ≈ 0.55 pass [PAGE #9]. Singularity: denominator zero when R_H = R_L and P_L = P_H (box call irrelevant) or when lines are parallel so no finite crossing exists. Breakdown: binary box split erases the 7-man box; since-2022 pooling hides trend; league-average equilibrium is a prior, not a team tendency, violated by team-specific personnel (e.g., bad run-blocking OL).

Operator 3 — Turnover and luck variance accounts [PAGE #11][PAGE A1][PAGE gap audit references ON2 #2].
Net points off turnovers: N_t = T_scored,t − T_allowed,t, unit points. Observed extremes: GB +35 (45 scored, 10 allowed implied), NYJ +22 (22 scored, 0 allowed), NO −15 (37 scored, 52 allowed), SEA +4 (51 scored, 47 allowed) [PAGE #11]. Net lucky wins: L_t = W_t − Σ_{g=1}^{7} p_g^(2.1), unit wins; MIN +2.7, NYJ −2.3 [PAGE A1]. Combine with ON1 deserve-to-win for three independent variance accounts.

Operator 4 — Vectorless RAG retrieval operator [PAGE #17].
Document corpus parsed into tree T = (V, E); node v ∈ V carries section title, page range [a_v, b_v], and summary s_v. Query q induces selection path π(q) over nodes via LLM reasoning over titles/summaries; full sections retrieved; loop back if evidence insufficient. Cost: C_tree(q) = O(d) LLM calls where d is tree depth; vector search cost C_vec(q) = O(log N) approximate nearest neighbor. Breakdown: |T| must fit in context window; large collections require document-level narrowing first [PAGE #17]. No benchmark numbers given; superiority claim argued, not measured.

Operator 5 — RLVR ExpDis exploration-distillation boundary [PAGE #20].
Explorer policy trained with novelty bonus λ · RND(h) on hidden states h, applied only to verifier-correct completions. Trajectories filtered for correctness, ≤ 32,768 tokens, no repetition loop, shortest per problem, capped at 500 per round. Verified-correct solutions distilled into student; standard RL run on student without novelty bonus; repeated for rounds. Unit: pass@k (dimensionless probability); wall-clock budget in seconds. Models: Qwen3-1.7B, Qwen3-4B, Ministral-3-3B; stack JAX/Flax for TPU. Breakdown: math-reasoning domain only; TPU/JAX stack not Garrett’s; results are paper’s own claims, unverified by Motif.

Units inventory: EPA/play (expected points added per play, points), pressures per dropback (dimensionless probability), sacks per pressure (dimensionless ratio), points (points), wins (dimensionless count), pass@k (dimensionless probability), tokens (count), wall-clock (seconds).
