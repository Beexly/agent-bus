The paper’s core derivation chain is a multi-hop pipeline from raw demoﬁles to contextual player valuation. First, unstructured server-client event logs are organized into a hierarchical data model: matches contain maps, maps contain rounds, and rounds contain timestamped events [PAGE 1], [PAGE 3]. The analytic atom is not a kill or death alone, but a game state \(G_{i,t}\), defined as “all of the current game information in round i at tick t” [PAGE 3]. This state includes map identity, tick time, equipment value, players remaining, HP remaining, bomb planted status, bomb plant site, and team bombsite distances [PAGE 3]. The paper then estimates the conditional round-win probability \(P(Y_i=1\mid G_{i,t})\), where \(Y_i=1\) denotes a CT round win [PAGE 5]. An action \(a_{i,t}\) is valued as the change in estimated win probability caused by the transition \(G_{i,t}\rightarrow G_{i,t+1}\) [PAGE 5]. Summing normalized action values yields Win Probability Added, then standardizes by rounds played [PAGE 5].

The gray-zone audit begins with calibration. Because WPA is a difference of predicted probabilities, any miscalibration directly contaminates player valuation. If the model says 0.80 but the empirical frequency is 0.60, the action value is not a true probability change; it is a biased estimator of outcome shift. The authors therefore evaluate calibration explicitly, using 100 equal-width bins and plotting mean predicted probability against mean true probability [PAGE 6]. XGBoost is selected because it “produced the most well calibrated win probabilities” [PAGE 6]. Its test performance is better than logistic regression and CatBoost across log loss, Brier score, and AUC [PAGE 6]. However, AUC near 0.79 still leaves substantial uncertainty, especially early in rounds. The paper itself shows that predictive power improves as round time advances [PAGE 6], [PAGE 7]. Thus, WPA for early-round actions has a wider confidence interval than WPA for late-round actions, even if point estimates look similar.

A second gray zone is event coverage. The framework observes game states on footsteps, damages, and bomb events, but WPA calculations only consider damage events [PAGE 6]. The authors acknowledge that “our framework does not consider the level of the match being played” and that a “strong assumption” is similar skill categories [PAGE 10]. More importantly, they state that one limitation is that WPA “only considers damage events” [PAGE 9]. This creates a conservation problem. If all actions were included and the state space were exhaustive, sequential adjacent action values should telescope: the sum of changes from round start to round end should approximate the final outcome. With only damage events, the sum is partial. A player who plants the bomb, creates space, blinds an opponent, or forces a rotation may change the true win probability without receiving full WPA credit. The paper even illustrates a high-impact sequence including a bomb plant and a kill [PAGE 9], while the formal WPA metric is damage-only [PAGE 6]. This is not fatal, but it means WPA is a context-aware damage valuation, not a complete action valuation.

A third gray zone is spatial modeling. The paper rejects Euclidean distance because CSGO maps have obstructions and vertical asymmetry [PAGE 4]. It builds a directed navigation-mesh graph and uses A* shortest paths [PAGE 4]. The non-symmetry is crucial: “one might be able to jump down to a position, but not back up” [PAGE 4]. Therefore, any spatial feature must use directed graph distance, not symmetric planar distance. The authors later note that navigation-mesh tile size is not uniform and suggest geodesic distance as future work [PAGE 10]. This means current graph-distance features are approximate, especially where tile granularity is coarse.

A fourth gray zone is metric validity. The paper compares WPA to KDR, ADR, KAST%, and HLTV Rating 2.0 using stability and independence [PAGE 7]. WPA has the highest month-to-month correlation among reported metrics, and it is less correlated with KDR than HLTV Rating 2.0 [PAGE 8]. However, independence is not absolute: WPA’s KDR correlation is 0.73, while ADR’s is 0.67; the paper reports that WPA is not more independent from KDR than ADR [PAGE 8]. Thus, WPA is useful but not radically orthogonal to kill-centric statistics, because damage events often accompany kills. The uniqueness claim is therefore probabilistic, not categorical.

A fifth gray zone is causal interpretation. Feature importance from XGBoost shows equipment value, HP remaining, players remaining, and map as important [PAGE 7]. But gain-based importance is predictive, not causal. Equipment value may proxy team economy, round phase, and strategic intent. HP remaining may proxy near-completed fights. Map may proxy tactical meta. The model can be useful for valuation without identifying the true causal mechanism of winning. Finally, the training set contains many correlated adjacent states [PAGE 7], which can inflate apparent performance if not temporally separated. The authors mitigate this with a strict temporal test split [PAGE 6], but residual dependence remains because rounds, maps, patches, and player pools evolve over time.

Let a match \(m\) contain map demoﬁles, and let each demoﬁle be decomposed into rounds \(i\in\{1,\dots,R_m\}\). The paper’s state variable is

\[
G_{i,t} = \big(\text{Map}, \text{TicksSinceStart}, \text{EquipmentValue}, \text{PlayersRemaining}, \text{HPRemaining}, \text{BombPlanted}, \text{BombPlantSite}, \text{TeamBombsiteDistance}\big),
\]

where \(t\) is a tick. The server tick rate is usually 128 ticks per second, so one tick is approximately \(7.8125\times10^{-3}\,\text{s}\) [PAGE 2]. The round outcome variable is

\[
Y_i =
\begin{cases}
1, & \text{if CT wins round } i,\\
0, & \text{otherwise.}
\end{cases}
\]

The target is the conditional probability

\[
\hat{\pi}_{i,t}
=
\hat{P}(Y_i=1\mid G_{i,t}),
\]

with \(\hat{\pi}_{i,t}\in[0,1]\), dimensionless as a probability [PAGE 5]. The paper says: “We are interested in estimating \(P(Y_i = 1 | G_{i,t})\)” [PAGE 5]. For an action \(a_{i,t}\), the action value is

\[
V(a_{i,t})
=
\hat{\pi}_{i,t+1}-\hat{\pi}_{i,t}.
\]

The unit is a change in win probability. One unit equals probability mass 1; in practical reporting, a change of \(0.01\) is one percentage point of win probability. The paper states: “We can value the player’s action as the difference in win probability between the two states” [PAGE 5], and notes that \(V(a_{i,t})\in[-1,1]\) [PAGE 5]. Because \(Y_i\) is coded as a CT win, T-side beneficial actions must be sign-normalized. If \(s_i\in\{+1,-1\}\) denotes the actor’s team relative to the CT-coded outcome, then the credited value is

\[
\tilde{V}(a_{i,t}) = s_i\left(\hat{\pi}_{i,t+1}-\hat{\pi}_{i,t}\right).
\]

For player \(p\), total WPA over games is

\[
\text{WPA}_p
=
\sum_{r\in\mathcal{R}_p}
\sum_{a\in\mathcal{A}_{r,p}}
\tilde{V}(a),
\]

where \(\mathcal{R}_p\) is the set of rounds played by \(p\), and \(\mathcal{A}_{r,p}\) is the set of credited actions by \(p\) in round \(r\). To standardize across variable round counts, the paper reports

\[
\text{WPA per round}_p
=
\frac{\text{WPA}_p}{|\mathcal{R}_p|}.
\]

The unit is win-probability change per round. If action values are expressed as probabilities, WPA per round is an average probability-point contribution per round [PAGE 5].

The paper contrasts WPA with older metrics. Kill-death ratio is

\[
\text{KDR}
=
\frac{\text{Kills}}{\text{Deaths}},
\]

with breakdown when \(\text{Deaths}=0\) [PAGE 4]. Average damage per round is

\[
\text{ADR}
=
\frac{\text{Total Damage}}{\text{Rounds}},
\]

with breakdown when \(\text{Rounds}=0\) [PAGE 4]. KAST% is

\[
\text{KAST\%}
=
\frac{\text{Kills}+\text{Assists}+\text{Survivals}+\text{Trades}}{\text{Rounds}},
\]

also requiring nonzero rounds and assuming a stable definition of trade [PAGE 4]. HLTV Rating 1.0 is given as

\[
\text{Rating}_{1.0}
=
\frac{\text{Rating}_K+0.7\times\text{Rating}_S+\text{Rating}_{MK}}{2.7},
\]

where the component ratings are functions of kills and deaths [PAGE 4], [PAGE 5]. Rating 2.0 is not fully reproducible because its methodology is not public [PAGE 5].

For spatial features, the map is represented as a directed graph

\[
\mathcal{G}_{\text{map}}=(V,E),
\]

where each node \(v\in V\) is a navigation-mesh surface, and a directed edge \((u,v)\in E\) means movement from \(u\) to \(v\) is allowed [PAGE 4]. The graph distance is

\[
d_{\mathcal{G}}(u,v)
=
\min_{\rho\in\mathcal{P}(u,v)}
\sum_{e\in\rho} c(e),
\]

where \(\mathcal{P}(u,v)\) is the set of directed paths from \(u\) to \(v\), and \(c(e)\) is traversal cost. The paper uses A* to compute shortest paths [PAGE 4]. In general,

\[
d_{\mathcal{G}}(u,v)\neq d_{\mathcal{G}}(v,u),
\]

because vertical movement, jumps, and walls create directed asymmetry [PAGE 4]. Units are graph traversal units, often approximated by node counts or navmesh tile costs; they are not Euclidean meters unless tile costs are calibrated to physical distance. A team bombsite distance feature can be written as

\[
D_{\text{site}}(T,s)
=
\min_{p\in T} d_{\mathcal{G}}(v_p,s),
\]

where \(T\) is a team, \(v_p\) is the node occupied by player \(p\), and \(s\in\{A,B\}\) is a bombsite.

The win-probability model is evaluated with probabilistic losses. Log loss is

\[
\mathcal{L}_{\text{log}}
=
-\frac{1}{N}
\sum_{n=1}^{N}
\left[
y_n\log \hat{\pi}_n
+
(1-y_n)\log(1-\hat{\pi}_n)
\right].
\]

If natural logarithms are used, the unit is nats; if base-2 logarithms are used, the unit is bits. The singularity regime is exact: if \(y_n=1\) and \(\hat{\pi}_n=0\), or \(y_n=0\) and \(\hat{\pi}_n=1\), the loss diverges to \(+\infty\). Brier loss is

\[
\mathcal{L}_{\text{Brier}}
=
\frac{1}{N}
\sum_{n=1}^{N}
(y_n-\hat{\pi}_n)^2,
\]

which is bounded and has units of squared probability. Calibration is assessed by bins. For bin \(B_k\), let

\[
\bar{\pi}_k
=
\frac{1}{|B_k|}
\sum_{n\in B_k}\hat{\pi}_n,
\qquad
\bar{y}_k
=
\frac{1}{|B_k|}
\sum_{n\in B_k}y_n.
\]

Perfect calibration requires \(\bar{y}_k=\bar{\pi}_k\) for all bins. The paper uses 100 equal-width bins and states that XGBoost “most closely follows the perfect calibration line” [PAGE 6]. A scalar calibration error can be defined as

\[
\text{ECE}
=
\sum_{k=1}^{K}
\frac{|B_k|}{N}
\left|
\bar{\pi}_k-\bar{y}_k
\right|,
\]

with units of probability. The reported test metrics are: XGBoost log loss \(0.5353\), Brier score \(0.1842\), AUC \(0.7913\); CatBoost \(0.5443\), \(0.1875\), \(0.7851\); logistic regression \(0.5539\), \(0.1912\), \(0.7743\); map-average baseline \(0.6917\), \(0.2493\), \(0.5303\) [PAGE 6].

Feature importance is reported as normalized gain:

\[
\phi_j
=
\frac{G_j}{\sum_k G_k},
\]

where \(G_j\) is total gain from feature \(j\), and \(\sum_j \phi_j=1\) or 100% after normalization [PAGE 7]. The paper finds equipment value, HP remaining, players remaining, and map to be important [PAGE 7]. Stability is measured by month-to-month correlation:

\[
r_{m,m+1}(X)
=
\operatorname{corr}(X_{i,m},X_{i,m+1}),
\]

across players \(i\). The Fisher \(r\)-to-\(z\) transform is

\[
z
=
\operatorname{artanh}(r)
=
\frac{1}{2}\ln\left(\frac{1+r}{1-r}\right),
\]

with approximate standard error \(1/\sqrt{n-3}\) for sample size \(n\). The paper reports WPA month-to-month correlation \(0.40\), KDR \(0.38\), ADR \(0.24\), KAST% \(0.30\), Rating 2.0 \(0.29\) [PAGE 8]. It also reports WPA-KDR correlation \(0.73\), lower than Rating 2.0’s \(0.93\), but higher than ADR’s \(0.67\) [PAGE 8].
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
The intellectual lineage of this paper comes from three streams: sports action valuation, probabilistic state modeling, and esports data engineering. The action-valuation stream descends from Decroos et al.’s soccer framework, where player actions are valued by how they change scoring or conceding chances [PAGE 2]. Yurko et al. extended this idea to American football with win probability and expected points, using regression on play-by-play data [PAGE 2]. Cervone et al. introduced Markov-chain possession valuation in basketball [PAGE 2]. Later neural and spatiotemporal models moved toward tracking data, expected possession value, and micro-action valuation in soccer, basketball, and ice hockey [PAGE 2]. The CSGO paper inherits this lineage but adapts it to a round-based, discrete-tick, first-person shooter environment.

The esports lineage is shorter. Yang et al. used logistic regression for DOTA2 match prediction [PAGE 2]. Hodge et al. explored ensembles for multiplayer esports win prediction [PAGE 2]. Makarov et al. used TrueSkill, decision trees, and logistic regression for CSGO round winners [PAGE 2]. Bednarek et al. used spatial death clustering for player ratings [PAGE 2]. The present paper departs from these by insisting on a reproducible, context-aware valuation framework, not merely a predictor [PAGE 1], [PAGE 2].

The data-engineering lineage is equally important. Demoﬁles are described as “a serialization of the data transferred between the host (game server) and its clients” [PAGE 2]. Because raw demoﬁles are unstructured, the paper creates Round objects, event lists, and game states [PAGE 3]. This reflects a broader shift in sports analytics from ad hoc event logs to structured event streams that can enter modern data-science pipelines [PAGE 1], [PAGE 3]. The graph-distance component draws from AI bot navigation. Bots use navigation meshes containing traversable surfaces and neighboring surfaces [PAGE 4]. The authors convert this into a directed graph and use A* to define shortest paths [PAGE 4]. This is a retro-causal technical genealogy: game-AI infrastructure becomes an analytic measurement instrument.

A multi-week trap appears in metric genealogy. Early CSGO valuation relied on kills, deaths, assists, ADR, KAST%, and HLTV ratings. These metrics are easy to compute but context-blind. The paper criticizes KDR for rewarding kills but not damage or assists [PAGE 4]. It criticizes ADR for being sensitive to context such as players remaining and equipment [PAGE 4]. It criticizes KAST% for treating kills, assists, survivals, and trades equally and for unstable definitions of trade [PAGE 4]. HLTV Rating 1.0 is public and decomposable, but Rating 2.0 is opaque [PAGE 5]. The trap is that intuitive metrics can persist because they are legible, not because they are valid. WPA attempts to replace outcome counting with state-transition valuation, but it inherits a new trap: if the win-probability model is poorly calibrated or missing action types, the metric may be sophisticated yet biased.

Another retro-causal trap is temporal. The model is trained on matches from October 2016 to May 2019 and tested on matches from June to December 2019 [PAGE 6]. This temporal split is stronger than random splitting, but it does not eliminate regime change. Patches, map-pool changes, player transfers, and tactical meta shifts can alter the relationship between game state and round outcome. A metric that is stable over one month may drift over several months if the underlying game changes. The authors’ stability analysis uses month-to-month correlations [PAGE 7], [PAGE 8], but long-horizon validity remains an open issue. The final limitation section explicitly notes that the framework does not consider match skill level and assumes similar skill categories [PAGE 10]. This is a crucial boundary condition: WPA is most defensible within homogeneous competitive strata, not across arbitrary skill levels.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
The recursive theory-of-mind problem is that players, coaches, and analysts can learn the metric and then behave differently because of it. If WPA becomes a scouting or tactical target, rational agents will infer what increases WPA and what decreases it. This creates a three-level loop: first, the model estimates win probability from game state; second, players act to increase credited value; third, opponents adapt to those actions, changing the game state distribution. The model then becomes stale unless updated.

Crisis habit regression is one observable behavioral trap. Under economic disadvantage, teams often revert to default habits: stacking a bombsite, playing for picks, saving equipment, or forcing simplified executes. If WPA is damage-centric, these crisis behaviors may be under-rewarded because they involve positioning, baiting, trading, utility use, and map control rather than direct damage. A player who creates space without dealing damage may be essential to the round but receive little WPA. Conversely, a player who finds a late damage event in a collapsing round may receive a large point value because the model sees a low-probability state becoming more favorable. This is not necessarily wrong, but it can mislead if the action did not cause the probability shift; it may have merely coincided with an opponent error.

The counter-trap is to treat WPA as one observable among several, not as a universal objective. A robust analytic system should combine WPA with uncertainty estimates, role-adjusted expectations, and non-damage event attribution. The paper’s uncertainty estimation is relevant here. It resamples rounds with replacement to generate distributions of mean WPA per round [PAGE 9]. For example, gla1ve has lower variance than device or dupreeh in the Astralis sample [PAGE 9]. A counter-trap strategy is to value not only mean WPA but also stability under pressure, role constraints, and opponent-specific matchups. If a player has high WPA only against weak opposition or in favorable map pools, the metric may overstate transferable skill. The paper’s own limitation about match level [PAGE 10] supports this caution.

The clock layer is also part of recursive reasoning. The model’s predictive power increases as round time advances [PAGE 6], [PAGE 7]. Early-round actions are evaluated under high uncertainty; late-round actions are evaluated under low uncertainty. Therefore, the same nominal WPA value should not be interpreted identically at 10 seconds and at 90 seconds into a round. At 10 seconds, the state estimate is noisy and many future transitions remain possible. At 90 seconds, the player count, HP, equipment, bomb status, and spatial constraints are more resolved. A player who accumulates WPA in late-round clutch situations may look more impactful partly because the model is more confident then. A player who accumulates early-round WPA may be creating value under more epistemic uncertainty.

A further recursive trap is side asymmetry. The outcome variable is CT-coded [PAGE 5]. If T and CT strategic structures differ, a single global model may obscure side-specific value. HLTV Rating 2.0 already uses separate calculations for T and CT performances [PAGE 5]. WPA can filter by side, map, pistol rounds, or player count [PAGE 8], but the core model does not explicitly encode side-specific priors beyond the map and state features. Recursive opponents can exploit this by changing side-specific tempo. For example, a CT team may slow the round to force late information states; a T team may rush to collapse the decision horizon. If the model has not learned these tempo effects, WPA may misattribute causation.

The final recursive danger is metric gaming. Suppose teams learn that bomb plants are not fully credited by WPA. They may still plant because it wins rounds, but analysts may under-rate plant-heavy players. Over time, this could distort scouting if WPA is used alone. The paper acknowledges that future work should include bomb plants, defuses, grenades, and movement [PAGE 9]. Until then, the counter-trap is explicit: use WPA for damage-based context, not for total tactical contribution. The clock and crisis layers should be included in interpretation: early, high-uncertainty damage may be less actionable than late, high-confidence state changes, while crisis habits may create hidden value that damage-only WPA cannot see.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Cross-layer veto means rejecting any valuation or prediction that violates the physical, informational, or temporal constraints of the game layer. In CSGO, the physical layer includes map geometry, directed traversability, health, equipment, bomb state, and round timing. The informational layer includes tick resolution, event observability, and model calibration. The temporal layer includes causality: an action at tick \(t\) cannot alter states before \(t\), and future effect is bounded by remaining round time.

The first veto proof is spatial. Euclidean distance is invalid where obstacles or vertical asymmetry exist. The paper explicitly states that “distance symmetry doesn’t always hold” and illustrates a case where jumping down is possible but returning is not [PAGE 4]. Therefore, any feature using symmetric planar distance in a map with walls, height differences, or one-way drops must be vetoed unless corrected by directed graph distance. Formally, if a proposed feature uses \(d_E(u,v)=\|u-v\|_2\) but the map graph has \(d_{\mathcal{G}}(u,v)\neq d_{\mathcal{G}}(v,u)\), the feature is not admissible as a general CSGO spatial measure. The paper’s graph-distance example shows A-to-C as 13 nodes, A-to-B as 15 nodes, and B-to-A as 19 nodes despite Euclidean ambiguity [PAGE 4]. This is a direct physical veto against symmetric distance features.

The second veto proof is temporal and causal. The game state is defined at tick \(t\), and actions advance the state to \(t+1\) [PAGE 3]. With a 128-tick server rate, one tick is about \(7.8\,\text{ms}\) [PAGE 2]. Any model that assigns action value using future information unavailable at \(t\) is leaking. For example, if an action value uses the eventual round winner directly rather than the model estimate conditioned on \(G_{i,t}\), it is not an ex ante valuation. The valid operator is \(\hat{P}(Y_i=1\mid G_{i,t})\), not \(Y_i\) itself. This veto also applies to non-causal feature engineering: post-round statistics, future kills, or end-of-round economy cannot enter the state at decision time.

The third veto proof is event completeness. The formal WPA framework currently credits damage events only [PAGE 6]. If a proposed player rating claims to measure total contribution while using damage-only WPA, it must be vetoed unless the claim is narrowed to damage-based contribution. The paper itself notes that bomb plants and defuses can have unclear attribution [PAGE 9]. If the T side plants and three CT players remain, assigning the full probability loss to the planter may be unfair. Therefore, any all-action valuation must include an attribution model. A simple conservation check is:

\[
\sum_{a\in\mathcal{A}_{r}} \tilde{V}(a)
\approx
Y_i^{\text{team}} - \pi_{i,0},
\]

where \(\pi_{i,0}\) is the estimated pre-round or round-start probability and \(Y_i^{\text{team}}\) is the team-coded outcome. If only damage events are included, this identity generally fails, and the metric cannot be interpreted as full round contribution.

The fourth veto proof is skill-level homogeneity. The paper assumes that “analyzed teams are of similar skill categories” [PAGE 10]. A model trained on LAN professional matches may not transfer to lower-skill matches because state-outcome relationships differ. If a game state in a low-skill setting has a different empirical win probability than the same state in a high-skill setting, applying the professional model produces miscalibrated values. The veto condition is simple: if calibration fails across skill strata, cross-stratum WPA is invalid. The metric can be used within a stratum after recalibration, but not across arbitrary levels without adjustment.

The fifth veto layer is biomechanical and network observability. The model observes client inputs resolved by the server at ticks [PAGE 2]. Human reaction, aim, and decision latency are not directly modeled. Therefore, any claim that WPA measures “mechanical skill” independent of context is too strong. WPA measures the model’s estimated probability effect of observed damage events, conditioned on encoded state features. It does not isolate aim, reaction time, or neural latency. If a biomechanical claim is made, it must be treated as an unmodeled latent variable, not as an observed quantity. Weather is not applicable: CSGO is a virtual engine with no meteorological layer. Any weather feature would be vetoed as nonexistent in the source domain.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
The following three RLVR-style veto scenarios are verifiable because they can be tested with logged CSGO data, round outcomes, calibration metrics, and spatial path audits.

Scenario 1: Damage-only valuation undercredits non-damage round-winning actions.  
Veto condition: A player or team receives low WPA despite causing a large probability shift through a bomb plant, defuse, trade setup, or space creation. Counterfactual test: reconstruct rounds with a broader action set, including bomb plants, defuses, grenade effects, and movement-defined control events. Compare damage-only WPA to an expanded action valuation. Prediction: the expanded model will reduce the residual gap between summed action values and round outcomes. It will also reduce the apparent dominance of pure fragging and increase the measured value of support roles. If damage-only WPA remains unchanged after adding non-damage events with meaningful state effects, then the original WPA framework was already sufficient for the tested contexts. If WPA changes materially, damage-only WPA is vetoed as a complete valuation metric.

Scenario 2: Cross-skill transfer without recalibration.  
Veto condition: A professional-trained win-probability model is applied to a lower-skill match pool without recalibrating state-outcome relationships. Counterfactual test: split data by skill proxy, such as LAN professional matches versus lower-tier online matches, then evaluate calibration using Brier score, log loss, and expected calibration error. Prediction: the professional model will show higher Brier score and higher calibration error in the lower-skill stratum. A specific verifiable prediction is that predicted probabilities above 0.80 in low-skill states will have empirical frequencies below 0.80 by a statistically significant margin. If calibration holds across strata, the skill-level veto is rejected. If calibration fails, cross-skill WPA must be vetoed until stratum-specific models or hierarchical priors are introduced.

Scenario 3: Euclidean spatial features on asymmetric maps.  
Veto condition: A spatial feature uses symmetric Euclidean distance in maps where directed graph distance materially differs. Counterfactual test: for each player position, compute both Euclidean distance to bombsites and directed navmesh graph distance. Identify states where Euclidean distance ranks a rotation or plant position as favorable but graph distance ranks it unfavorable. Then compare model performance with Euclidean features versus graph-distance features. Prediction: graph-distance features will improve log loss or Brier score on maps with vertical asymmetry, and they will alter feature importance for spatial variables. If Euclidean features perform equally well even in high-asymmetry states, the graph-distance veto is weakened. If graph-distance features improve calibration or predictive performance, Euclidean spatial valuation is vetoed for those maps.

A fourth cross-cutting veto, useful as a meta-test, is the calibration singularity veto. If the model assigns \(\hat{\pi}=0\) to an event that later wins, or \(\hat{\pi}=1\) to an event that later loses, log loss diverges. In practical data, this appears as extreme confidence errors. The verifiable prediction is that bins near 0 and 1 must contain empirical frequencies close to 0 and 1. If the calibration curve departs sharply near the boundaries, WPA values derived from those states are unstable and should be shrunk toward calibrated priors before being used for player ranking.
</RLVR_COUNTERFACTUAL_VETOES>
