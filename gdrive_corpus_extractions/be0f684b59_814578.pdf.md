The key multi-hop move is from discrete execution traces to measure transformers. Operationally, a program state includes a machine state plus stacks of random bits, as shown by the reduction rules and term semantics in [PAGE 33]. Denotationally, the same program is reinterpreted as an operator mapping probability distributions to subprobability distributions [PAGE 41]. This shift is not cosmetic: it changes the object of verification from “which single execution occurs?” to “what measure over executions is induced?”. The source makes this explicit when it says that denotationally “a program is interpreted as an operator mapping probability distributions to (sub)probability distributions” [PAGE 41].

A second hop is from assignments and tests to kernels. Terms denote Markov kernels, assignments become pushforwards, conditionals become subprobability restrictions, and sequencing becomes kernel composition [PAGE 27], [PAGE 43]. The formal composition law is integration against a kernel: for kernels P : S → T and Q : T → U, (P ; Q)(s,A) = ∫ P(s,dt) Q(t,A) [PAGE 27]. This equation is the semantic glue of the book. It explains why probabilistic program equivalence is not mere trace equality but equality of induced measures, and why coupling proofs can be seen as constructing joint measures with prescribed marginals [PAGE 149].

A third hop is from finite approximation to limiting semantics. While loops are interpreted by fixed-point constructions. For expected runtime, the least fixed point is obtained as the supremum of finite Kleene approximants: lfp F_t = sup_n F_t^n(0) [PAGE 199]. For denotational semantics of possibly nonterminating programs, the source also introduces a mean-ergodic limit for nonterminating while-true programs: P[[e]](μ) = lim_{n→∞} (1/n) Σ_{j=0}^{n-1} [[e]]^j(μ) [PAGE 45]. This creates a gray zone: a program may have zero least-fixed-point denotation because it never halts, yet still possess a meaningful invariant or ergodic semantics. The Cantor program illustrates this: “since the program never halts. Formally … [[cantor]](μ) = 0” [PAGE 55], but the mean ergodic theorem recovers the Cantor measure [PAGE 57]. Thus, “nontermination” is not a single failure mode; it can mean zero subprobability mass, divergence of expectation, or existence of a nontrivial invariant measure.

A fourth gray zone is normalization. In Bayesian probabilistic programming, a program with score or observe computes an unnormalized measure. The source defines normalization only when the evidence is finite and positive: evidence ∈ (0,∞); if evidence = 0 it returns a distinguished failure token; if evidence = ∞ it returns another distinguished failure token [PAGE 85]. The astronomy example shows the singularity concretely: prior density e^{-t}, likelihood e^t, posterior proportional to 1, so the normalizing integral diverges [PAGE 69]. This is a hard breakdown regime: the mathematical object exists as an unnormalized measure, but no probability distribution exists without further regularization.

A fifth gray zone is computability. Type-2 computable distributions allow continuous semantics, but equality testing is not computable [PAGE 95], and conditioning can be noncomputable. The source states that a computable joint distribution can have a noncomputable conditional: “nonComp encodes a computable distribution P(N,X) whose conditional P(N | X) is not computable” [PAGE 129]. Therefore, a verifier must distinguish three claims: existence of a measure, computability of the measure, and computability of the conditional posterior. Conflating them produces false confidence.

A sixth gray zone is runtime. Almost-sure termination is weaker than positive almost-sure termination. The source explicitly says “Almost-sure termination is too weak” for finite expected runtime [PAGE 207], and gives a program whose expected runtime is infinite despite termination with probability one: “the expected runtime of program ccex is infinite even though it terminates with probability one” [PAGE 223]. Hence, any operational claim about “the program finishes” must be refined into termination probability, expected runtime, and tail bounds.

A seventh gray zone is quantitative reasoning under dependence. Chernoff–Hoeffding requires independence and bounded support [PAGE 269]. Bernstein improves bounds using variance but still requires bounded deviations or suitable moment control [PAGE 271]. Azuma–Hoeffding extends to martingales with bounded differences [PAGE 289]. If disturbances are unbounded, such as an untruncated Gaussian, the source notes that “the concentration of measure inequalities are no longer applicable” without truncation or another argument [PAGE 273]. Thus, physical or weather-like uncertainty must be checked for boundedness, independence, or martingale structure before any concentration bound is admitted.

Finally, the logical layer clarifies states versus predicates. A state is a normalized distribution; a predicate is a fuzzy evidence function. Conditioning is state update by a predicate: ω|p is defined only if ω |= p is nonzero [PAGE 323]. This prevents category errors such as treating evidence likelihoods as states or treating unnormalized scores as probabilities. The overall audit rule is therefore: construct the measure, check normalization, check computability, check runtime, check dependence structure, and only then assert a quantitative property.

1. Markov-kernel composition.  
Source: “Composition is given by integration” [PAGE 27].  
Formal operator:
\[
(P;Q)(s,A)=\int_{t\in T}P(s,dt)\,Q(t,A).
\]
Assumptions: \(P:S\times\Sigma_T\to[0,1]\) and \(Q:T\times\Sigma_U\to[0,1]\) are Markov kernels; \(A\in\Sigma_U\) is measurable.  
Units: \(P(s,dt)\) is a probability measure; \(Q(t,A)\) is dimensionless probability in \([0,1]\); the integral is dimensionless probability. If the kernel models a physical transition rate rather than a probability kernel, then units would be transition probability per step, but the source’s kernel is probabilistic, not rate-based.  
Breakdown regime: if \(Q(\cdot,A)\) is not measurable or \(P(s,\cdot)\) is not a probability measure, composition is undefined. Associativity relies on Fubini-type integrability [PAGE 27].

2. Pushforward of a measure along a kernel.  
Source: “Given a measure μ on BS, its pushforward under the Markov kernel P … is the measure P∗(μ) on BT defined by” [PAGE 27].  
Formal operator:
\[
P_*(\mu)(B)=\int_{s\in S}P(s,B)\,\mu(ds).
\]
Units: \(\mu(ds)\) carries probability mass; \(P(s,B)\in[0,1]\); output \(P_*(\mu)(B)\) is probability mass.  
Breakdown regime: if \(B\) is not measurable or \(\mu\) is not a finite/probability measure, the pushforward need not be a probability measure. For subprobability semantics, total mass may be less than one.

3. Denotational state transformer.  
Source: “a program is interpreted as an operator mapping probability distributions to (sub)probability distributions” [PAGE 41].  
Formal schema:
\[
\llbracket e\rrbracket : \mathcal{M}_{\mathbb{R}^n}\to\mathcal{M}_{\mathbb{R}^n}.
\]
Assumption: states are measures over memory stores; programs may lose mass through conditioning or nontermination.  
Breakdown regime: if the program contains conditioning with zero evidence, the output submeasure may have mass strictly below one or be undefined after normalization.

4. Assignment as pushforward.  
Source: “Given such a term t and an index i, we define the Markov kernel \(F_t^i\) … and define \(\llbracket x_i := t\rrbracket\) as the operator” [PAGE 43].  
Formal equation:
\[
\llbracket x_i := t\rrbracket(\mu)=(F_t^i)_*(\mu).
\]
Units: input measure mass is preserved by deterministic assignment; if \(t\) samples, mass is redistributed according to the sampling kernel.  
Breakdown regime: if \(t\) is partial or diverges, the denotation may fail to be total unless divergence is modeled by a bottom element or subprobability loss.

5. While-loop fixed point.  
Source: “The runtime of a loop, however, is defined as the least fixed point of its characteristic functional” [PAGE 197]; and “lfp Ft = sup n∈N Fn t (0)” [PAGE 199].  
Formal operator:
\[
\mathrm{lfp}(F_t)=\sup_{n\in\mathbb{N}}F_t^n(0).
\]
Units: in expected-runtime semantics, units are abstract computation steps; the source says “every random assignment consumes one unit of time” [PAGE 189]. If mapped to SI, multiply by seconds per abstract step.  
Breakdown regime: if the supremum is infinite, expected runtime is infinite. If the fixed point is zero but the program has nonterminating runs, the zero denotation may hide an invariant or ergodic semantics [PAGE 55], [PAGE 45].

6. Mean-ergodic semantics for nonterminating loops.  
Source: “it can be shown … that \(\llbracket e\rrbracket\) is mean ergodic” [PAGE 45].  
Formal operator:
\[
P_{\llbracket e\rrbracket}(\mu)=\lim_{n\to\infty}\frac{1}{n}\sum_{j=0}^{n-1}\llbracket e\rrbracket^j(\mu).
\]
Units: output is an invariant measure or mean measure; probability mass is preserved under suitable normalization.  
Breakdown regime: the limit may fail to exist if the operator is not mean ergodic; for terminating programs the least-fixed-point semantics is usually the primary semantics, while the mean-ergodic semantics is an alternative for nontermination [PAGE 45].

7. s-finite kernels.  
Source: “A kernel k : X ⇝ Y is s-finite if there is a sequence k1 . . . kn . . . of finite kernels and Σ ki = k” [PAGE 83].  
Formal definition:
\[
k=\sum_{i=1}^{\infty}k_i,
\]
where each \(k_i:X\times\Sigma_Y\to[0,\infty)\) is finite, meaning there exists finite \(r_i\) such that \(k_i(x,Y)<r_i\) for all \(x\).  
Units: \(k(x,U)\) is a possibly unbounded measure value in \([0,\infty]\); finite kernels have uniformly bounded total mass.  
Breakdown regime: arbitrary kernels are not well-behaved; the source notes that with a counting measure, program order can matter and some programs are not well-defined because projections of Borel sets may fail to be Borel [PAGE 77]. s-finiteness is a semantic regularity condition, not a cosmetic restriction.

8. Normalization.  
Source: “We give a semantics to normalization by finding the normalizing constant and dividing by it” [PAGE 85].  
Formal operator:
\[
\mathrm{evidence}_{\gamma,t}=\llbracket t\rrbracket_{\gamma;\llbracket A\rrbracket},
\]
\[
\llbracket\mathrm{normalize}(t)\rrbracket_\gamma=
\begin{cases}
\left(0,\left(\mathrm{evidence}_{\gamma,t},\frac{\llbracket t\rrbracket_{\gamma;(-)}}{\mathrm{evidence}_{\gamma,t}}\right)\right), & \mathrm{evidence}_{\gamma,t}\in(0,\infty),\\
(1,()), & \mathrm{evidence}_{\gamma,t}=0,\\
(2,()), & \mathrm{evidence}_{\gamma,t}=\infty.
\end{cases}
\]
Units: evidence is a nonnegative mass; normalized output is a probability measure only in the first case.  
Breakdown regimes: evidence zero or infinity. The source’s example gives prior \(e^{-t}\), likelihood \(e^t\), so posterior density is proportional to \(1\), and \(\int_U 1\,dt\) diverges [PAGE 69]. This is a singular normalization regime.

9. Computable real and computable distribution.  
Source: fast Cauchy sequences encode reals [PAGE 95]; computable distributions are limits in the Prokhorov metric [PAGE 97].  
Formal metric:
\[
d_\rho(\mu,\nu)=\inf\{\epsilon>0\mid \mu(A)\le\nu(A_\epsilon)+\epsilon\text{ for every Borel }A\},
\]
where \(A_\epsilon=\{x\in X\mid d(x,y)<\epsilon\text{ for some }y\in A\}\).  
Units: \(\epsilon\) has the metric units of \(X\); \(\mu(A)\) and \(\nu(A_\epsilon)\) are dimensionless probabilities.  
Breakdown regime: equality testing \(=0:\mathbb{R}\to\{0,1\}\) is not computable because it requires inspecting an entire Cauchy sequence [PAGE 95]. Conditioning can also be noncomputable: “nonComp encodes a computable distribution \(P(N,X)\) whose conditional \(P(N\mid X)\) is not computable” [PAGE 129].

10. Probabilistic lambda-calculus operational distribution.  
Source: step-indexed approximations yield a distribution \(\langle M\rangle\) [PAGE 147].  
Formal definition of expected reduction length:
\[
\mathrm{ExLen}(M)=\sum_{m=0}^{\infty}\left(1-\sum_{n=0}^{m}\|\langle M\rangle_n\|\right).
\]
Units: number of reduction steps.  
Positive almost-sure termination:
\[
\mathrm{ExLen}(M)<\infty.
\]
Breakdown regime: almost-sure termination alone does not imply \(\mathrm{ExLen}(M)<\infty\); the source distinguishes these notions [PAGE 151].

11. Coupling.  
Source: “a sub-distribution μ over pairs \(A_1\times A_2\) is a coupling for \((\mu_1,\mu_2)\) if \(\pi_1(\mu)=\mu_1\) and \(\pi_2(\mu)=\mu_2\)” [PAGE 149].  
Formal condition:
\[
\pi_1(\mu)=\mu_1,\qquad \pi_2(\mu)=\mu_2.
\]
Units: all quantities are probabilities or subprobabilities; coupling mass equals marginal mass.  
Consequence: if a coupling satisfies \(\Pr_{(a_1,a_2)\sim\mu}[a_1\ne a_2]\le\epsilon\), then total variation distance is bounded by \(\epsilon\) [PAGE 155].  
Breakdown regime: for relational Hoare logic loops, “Losslessness is needed for soundness” because liftings can only relate sub-distributions of equal weight [PAGE 167].

12. Expected-runtime transformer.  
Source: “The number ert[c](t)(σ) is the expected runtime of executing program c on initial state σ assuming that t captures the runtime of the computation following c” [PAGE 193].  
Formal equations:
\[
\mathrm{ert}[c_1;c_2](t)=\mathrm{ert}[c_1](\mathrm{ert}[c_2](t)),
\]
\[
\mathrm{ert}[\mathrm{if}(\phi)\{c_1\}\ \mathrm{else}\ \{c_2\}](t)
=1+[\phi]\cdot\mathrm{ert}[c_1](t)+[\neg\phi]\cdot\mathrm{ert}[c_2](t).
\]
Units: abstract time units; one unit per guard evaluation or random assignment [PAGE 189].  
Loop upper-bound rule: if \(F_t(I)\le I\), then \(\mathrm{ert}[\mathrm{while}(\phi)\{c\}](t)\le I\) [PAGE 199].  
Breakdown regimes: lower-bound metering functions are unsound in general for probabilistic programs because fixed points may require a supremum not attained at finite depth [PAGE 201]. Infinite expected runtime can coexist with almost-sure termination [PAGE 223].

13. Ranking supermartingale.  
Source: “it holds a.s. that \(E[X_{n+1}\mid F_n]\le X_n-\epsilon\cdot 1_{X_n\ge0}\)” [PAGE 247].  
Formal condition:
\[
\mathbb{E}[X_{n+1}\mid\mathcal{F}_n]\le X_n-\epsilon\mathbf{1}_{X_n\ge0}.
\]
Units: \(X_n\) is a potential or distance-to-termination quantity; \(\epsilon\) has the same units per step.  
Breakdown regime: symmetric random walk has zero expected drift, so no ranking supermartingale of the strict decrease form exists: “the expected one-step change of the symmetric random walk is zero” [PAGE 257].

14. Concentration inequalities.  
Chernoff–Hoeffding:
\[
\Pr(S_n\ge\mathbb{E}[S_n]+t)\le
\exp\left(-\frac{2t^2}{\sum_{j=1}^n(b_j-a_j)^2}\right),
\]
for independent \(X_j\in[a_j,b_j]\) almost surely [PAGE 269].  
Bernstein:
\[
\Pr(X-\mathbb{E}[X]\ge t)\le
\exp\left(-\frac{t^2}{2(3Mt+2\sum_{i=1}^n\sigma_i^2)}\right),
\]
under bounded deviation and variance information [PAGE 271].  
Azuma–Hoeffding for supermartingale with bounded differences:
\[
\Pr(X_j-X_0\ge t)\le
\exp\left(-\frac{t^2}{2\sum_{i=0}^{j-1}c_i^2}\right),
\]
when \(|X_{i+1}-X_i|\le c_i\) [PAGE 289].  
Units: \(t\), \(c_i\), \(a_i\), \(b_i\), and \(\sigma_i\) have the units of the underlying random variable; probabilities are dimensionless.  
Breakdown regime: independence or bounded differences may fail. For unbounded Gaussian disturbances, the source says the inequalities are no longer applicable without truncation [PAGE 273].

15. Bayesian validity and conditioning.  
Source: “For an arbitrary state ω on a set A and a predicate p : A → [0,1] … the validity ω |= p … is” [PAGE 315].  
Formal equations:
\[
\omega\models p=\sum_{a\in A}\omega_a p_a,
\]
\[
\omega\mid p=\sum_{a\in A}\frac{\omega_a p_a}{\omega\models p}|a\rangle.
\]
Bayes rule in this notation:
\[
\omega\mid p\models q=
\frac{(\omega\mid q\models p)(\omega\models q)}{\omega\models p}.
\]
Units: \(\omega_a\) is probability mass; \(p_a\in[0,1]\) is fuzzy evidence; validity is dimensionless.  
Breakdown regime: conditioning is undefined when \(\omega\models p=0\); the source conditions the definition on “the validity ω |= p is non-zero” [PAGE 323].

16. Quantitative equational reasoning.  
Source: “We can now define a metric on TX over the quantitative theory U by” [PAGE 365].  
Formal operator:
\[
d_U(s,t)=\inf\{\epsilon\mid \emptyset\vdash s=_\epsilon t\in U\}.
\]
Units: \(\epsilon\) is a nonnegative rational distance bound in the quantitative theory.  
Breakdown regime: this is generally a pseudometric and may take infinite values: “we only have a pseudometric and second, the metric can take on infinite values” [PAGE 365]. Quotienting by zero distance is required to obtain a genuine metric.

17. Kantorovich/Wasserstein metric.  
Source: Kantorovich metric is defined by integration against nonexpansive functions and equivalently by optimal transport [PAGE 361].  
Formal equations:
\[
K(p,q)=\sup_f\left|\int f\,dp-\int f\,dq\right|,
\]
\[
K(p,q)=\inf_{\pi\in C(p,q)}\int d(x,y)\,d\pi(x,y).
\]
Units: if \(d(x,y)\) has units of the underlying metric space, then \(K(p,q)\) has those same units. Probabilities are dimensionless.  
Breakdown regime: if the base metric is unbounded and moments are not finite, the transport integral may diverge. If the space is not Polish or the coupling set is empty due to incompatible marginals, the metric construction fails.

<RETROCAUSAL_GENEALOGY>
The scientific lineage in the corpus is not a single thread but a convergence of several traditions. The oldest relevant root is the measure-theoretic foundation of probability, especially the treatment of σ-algebras, measures, Lebesgue integration, and the impossibility of assigning translation-invariant length to all subsets of \(\mathbb{R}\) [PAGE 23]. This root explains why probabilistic programming must use measurable spaces rather than arbitrary sets: programs denote measures, and measures require domains closed under countable operations.

A second root is the categorical probability tradition. The source explicitly connects Markov kernels to the Kleisli category of the Giry monad and cites Lawvere, Giry, Panangaden, and Doberkat [PAGE 27]. This lineage matters because it gives probabilistic programs a compositional semantics: sequencing is kernel composition, assignment is pushforward, and conditioning is a predicate-transforming or state-updating operation. The historical trap is to treat composition as ordinary function composition without checking measurability and integrability. The source’s associativity of kernel composition relies on Fubini’s theorem [PAGE 27], which is a classical analytical constraint, not a programming convenience.

A third root is Kozen’s program semantics. The source cites Kozen 1981 and 1985 as foundational for probabilistic PDL and semantics of probabilistic programs [PAGE 27], [PAGE 41]. Kozen’s contribution is to make probabilistic programs into operators on measures. The multi-week trap here is to confuse operational traces with denotational measures. An operational semantics enumerates one reduction path at a time; a denotational semantics keeps all paths simultaneously as a measure. The source demonstrates this with the simple coin program: operationally there are two transitions, denotationally there is one operator producing \(\frac12\delta_0+\frac12\delta_1\) [PAGE 41].

A fourth root is program logic and verification. The source traces program logics to Hoare and Floyd, then to relational Hoare logics and pRHL for probabilistic relational properties [PAGE 173]. The coupling interpretation of pRHL is historically important because it connects probability theory’s coupling method with formal verification. The trap is to assume that relational postconditions are ordinary predicates. In pRHL, postconditions are lifted relations between distributions, and loop rules require losslessness to preserve equal mass [PAGE 167].

A fifth root is expected-runtime analysis. The source situates randomized algorithms in the lineage of Rabin, Solovay–Strassen, and later primality results [PAGE 185]. The weakest-precondition-style ert calculus then imports Dijkstra-style reasoning into probabilistic runtime analysis [PAGE 193]. The historical trap is to reuse deterministic termination intuitions. In deterministic programs, termination means all runs are finite. In probabilistic programs, almost-sure termination allows a measure-zero nonterminating run, and positive almost-sure termination requires finite expected time. The source’s ccex example shows that two positively almost-surely terminating programs can compose into a program with infinite expected runtime [PAGE 205], [PAGE 223].

A sixth root is martingale theory. Ranking functions from deterministic termination analysis become ranking supermartingales in the probabilistic setting [PAGE 223], [PAGE 247]. The source surveys McIver–Morgan, Chakarov–Sankaranarayanan, Chatterjee–Fu–Novotný, and related work. The trap is to demand strict expected decrease in every step. Symmetric random walks terminate almost surely but have zero drift, so no ordinary ranking supermartingale exists; one must use PRSMs, lexicographic ranking supermartingales, or other refinements [PAGE 257], [PAGE 261].

A seventh root is concentration of measure. The source connects Chernoff–Hoeffding, Bernstein, Janson, and Azuma–Hoeffding to quantitative program analysis [PAGE 269], [PAGE 271], [PAGE 289]. The historical trap is to apply independence-based inequalities to programs with loop-carried dependence. The source’s affine-form and martingale approaches are responses to that trap: affine forms track dependency graphs, while martingales replace independence with conditional expectation constraints.

An eighth root is computable analysis. The corpus introduces Type-2 computable distributions, fast Cauchy sequences, qcb0 spaces, valuations, and realizability [PAGE 95], [PAGE 107], [PAGE 115]. The trap is to assume that every mathematically definable posterior is algorithmically obtainable. The source’s nonComp example proves that a computable joint distribution can have a noncomputable conditional [PAGE 129]. This lineage forces a distinction between semantic existence and effective samplability.

A ninth root is quantitative equational logic. Instead of equality, one reasons with indexed approximate equalities \(s=_\epsilon t\) [PAGE 363]. The Kantorovich and total variation metrics arise as free constructions from quantitative theories [PAGE 361], [PAGE 367]. The trap is to treat \(\epsilon\)-equality as transitive in the ordinary sense. The source replaces transitivity with a triangle-inequality rule and an infinitary continuity rule [PAGE 363].

Multi-week traps are therefore predictable: first, conflating operational nontermination with denotational zero; second, forgetting normalization singularities; third, assuming all conditionals are computable; fourth, applying concentration bounds without checking dependence and boundedness; fifth, confusing states and predicates; sixth, using deterministic ranking functions where martingale drift is zero; seventh, ignoring losslessness in relational loop proofs.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
A crisis in probabilistic program reasoning usually appears as pressure to produce an answer quickly: a model must be accepted, a loop must be declared terminating, or an observation must be conditioned upon. Under that pressure, the common habit regression is to collapse probabilistic questions into deterministic yes/no questions. For example, “Does the program halt?” replaces “What is the halting probability?”; “Is the expected runtime finite?” replaces “What is the distribution of runtime?”; “Is the posterior computable?” replaces “Does the posterior measure exist mathematically?” This regression is tempting because deterministic questions feel simpler, but the corpus shows that the simpler questions are often ill-posed or strictly weaker. The source explicitly says that even the elementary question “does a program halt with probability one?” is “more undecidable” than the halting problem [PAGE 13]. Thus, crisis reasoning must resist replacing quantitative semantics with Boolean shortcuts.

The counter-trap is to return to the formal objects: measures, kernels, normalizing constants, computability representations, and runtime transformers. If a model is under pressure, the correct recursive move is not to invent a heuristic score but to ask: what measure is being computed? Is it s-finite? Is the evidence finite and positive? Is the conditional computable? Is the loop’s expected runtime finite? These questions are slower, but they are the only ones that the source supports. For example, normalization has three distinct outcomes, not one: finite positive evidence yields a normalized posterior; zero evidence yields a failure token; infinite evidence yields another failure token [PAGE 85]. A crisis habit that treats “posterior exists” as binary will miss the singular cases where the unnormalized measure exists but no probability distribution exists.

The “clock” dimension is the temporal/resource layer. In this corpus, the clock is not a wall-clock metaphor but a formal expected-runtime object. The ert calculus defines expected runtime as a continuation-passing transformer: \(\mathrm{ert}[c](t)(\sigma)\) is the expected runtime of \(c\) from state \(\sigma\) assuming continuation runtime \(t\) [PAGE 193]. Loops are solved by least fixed points, and upper invariants provide proof rules [PAGE 199]. The clock therefore has three regimes: finite expected runtime, infinite expected runtime, and almost-sure termination without finite expected runtime. The source’s ccex program demonstrates the third regime: it terminates with probability one but has infinite expected runtime [PAGE 223]. A crisis agent that only checks “does it terminate?” will incorrectly believe the clock is finite.

A recursive theory of mind must model three internal agents: the Habit Agent, the Counter-Trap Agent, and the Clock Agent. The Habit Agent seeks closure and prefers deterministic simplifications. The Counter-Trap Agent audits the Habit Agent by checking source-defined invariants: measurability, normalization, computability, and losslessness. The Clock Agent audits temporal claims by checking fixed points, supermartingale drift, and expected runtime. A healthy verification protocol runs them in sequence: Habit proposes a claim; Counter-Trap asks for the semantic object; Clock asks for the resource bound.

This structure also explains common failure modes in Bayesian inference. A Habit Agent sees evidence and immediately normalizes. A Counter-Trap Agent asks whether the evidence has finite positive mass. A Clock Agent asks whether inference is computable in finite expected time. If the model is the astronomy example with prior \(e^{-t}\) and likelihood \(e^t\), the Counter-Trap Agent detects infinite evidence [PAGE 69]. If the model is nonComp, the Counter-Trap Agent detects noncomputable conditional distributions [PAGE 129]. If the model is ccex, the Clock Agent detects infinite expected runtime [PAGE 223].

The correct crisis policy is therefore: do not let the Habit Agent erase probabilistic distinctions. Instead, require every claim to be represented as a tuple: \((\text{measure}, \text{normalization}, \text{computability}, \text{runtime}, \text{dependence structure})\). A claim is accepted only if all components survive their respective audits. This is not a bureaucratic ritual; it is the minimal structure imposed by the mathematics in the source.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Theorem (Cross-layer veto). Let a proposed probabilistic-program claim be represented by a tuple \((\mu, Z, C, R, D)\), where \(\mu\) is the induced measure or kernel, \(Z\) is the normalizing evidence, \(C\) is a computability certificate, \(R\) is a runtime bound, and \(D\) is a dependence/boundedness certificate for quantitative bounds. The claim is vetoed if any layer fails.

Proof sketch and adjudication:

1. Physical finite-time veto.  
The physical layer requires finite expected computation time for any executable inference claim. The source defines expected runtime by the ert transformer and loop fixed points [PAGE 193], [PAGE 199]. If \(\mathrm{ert}[c](0)(\sigma)=\infty\), then no finite-time physical execution can guarantee completion in expectation. The source’s ccex program is a concrete counterexample: it terminates almost surely, but “the expected runtime of program ccex is infinite even though it terminates with probability one” [PAGE 223]. Therefore, any claim that ccex-like inference can be executed within a finite expected physical clock is vetoed.

2. Biomechanical/safety-layer veto.  
The corpus contains physical-inference examples such as an anesthesia infusion model and a robotic end effector. In the anesthesia example, the state variable \(x_4\) has safety thresholds: too much anesthesia may cause loss of breathing, too little may cause consciousness during surgery [PAGE 263]. In the robotic example, the final position is checked against a failure assertion [PAGE 261]. A biomechanical veto applies when the induced measure assigns non-negligible probability to unsafe states and the analysis cannot bound that probability. If concentration bounds are unavailable because disturbances are unbounded or dependent, the safety claim is vetoed. The source warns that for an unbounded Gaussian disturbance, “the concentration of measure inequalities are no longer applicable” without truncation [PAGE 273]. Thus, a biomechanical safety claim based on an unbounded disturbance model is not admissible without additional regularization.

3. Weather/environmental stochastic-layer veto.  
Weather is modeled in the source as disturbance \(w(t)\) in a linear state-space model, with truncated Gaussian range \([-0.4,0.4]\) in the anesthesia example [PAGE 263], and as wind disturbances in a fixed-wing UAV forecast model [PAGE 279]. If the actual environmental layer violates the source assumptions—e.g., disturbances are unbounded, nonmeasurable, or strongly dependent—then the probabilistic bound is invalid. Chernoff–Hoeffding requires independence and bounded ranges [PAGE 269]; Azuma requires bounded martingale differences [PAGE 289]. A weather-related claim that uses these inequalities without verifying boundedness or martingale structure is vetoed.

4. Normalization veto.  
Even if the measure exists as an unnormalized object, a probabilistic claim requires finite positive evidence. The source’s normalize operator returns a posterior only when \(\mathrm{evidence}_{\gamma,t}\in(0,\infty)\); if evidence is zero or infinite, it returns failure tokens [PAGE 85]. The astronomy example has prior \(e^{-t}\) and likelihood \(e^t\), yielding posterior proportional to \(1\), whose normalizing integral diverges [PAGE 69]. Any claim that this model yields a proper posterior without regularization is vetoed.

5. Computability veto.  
A posterior may exist mathematically but fail to be computable. The source proves that a computable joint distribution can encode a noncomputable conditional because computing the conditional would solve the halting problem [PAGE 129]. Therefore, any claim that an exact posterior can be sampled by a finite algorithm is vetoed unless the model satisfies a computability condition such as a bounded computable conditional density [PAGE 131].

6. Coupling/losslessness veto.  
For relational claims, a coupling proof must preserve mass. The source states that “Losslessness is needed for soundness” because liftings can only relate sub-distributions with equal weights [PAGE 167]. If a loop in a relational proof is not lossless, the coupling conclusion is vetoed.

Conclusion: A claim passes all layers only if it has (i) a well-defined measurable semantics, (ii) finite positive normalization, (iii) a computability certificate, (iv) finite expected runtime or an explicitly nonfinite runtime classification, (v) valid dependence/boundedness for concentration, and (vi) losslessness for relational coupling. Failure in any layer produces a veto.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Scenario 1: Infinite normalizing constant veto.  
Model: astronomer example with prior \(t\sim\mathrm{Exponential}(1)\), likelihood \(d\sim\mathrm{Normal}(1,(2\pi e^{2t})^{-1/2})\), observed \(d=1\). Source: “So the prior density is \(e^{-t}\), but the likelihood is \(e^t\)” [PAGE 69].  
Veto: The posterior density is proportional to \(1\), and the normalizing integral over \(t\) diverges. The normalize operator must return the infinite-evidence failure token: \(\mathrm{evidence}=\infty\) [PAGE 85].  
Prediction: Any verifier that attempts to return a normalized posterior for this program without changing the model will fail. A correct system should output a distinguished non-normalizable flag, not a probability distribution. If the likelihood is bounded or the prior decays faster than the likelihood grows, normalization may be restored; but under the source’s exact numbers, normalization is vetoed.

Scenario 2: Noncomputable conditional veto.  
Model: nonComp program encoding a joint distribution whose conditional requires deciding whether the \(n\)-th Turing machine halts. Source: “nonComp encodes a computable distribution \(P(N,X)\) whose conditional \(P(N\mid X)\) is not computable” [PAGE 129].  
Veto: Exact posterior inference is not computable. Any claim that a generic finite algorithm can compute \(P(N\mid X)\) for all inputs is false.  
Prediction: A system restricted to bounded computable conditional densities can succeed only after smoothing the observation, as in obsDens [PAGE 131]. A system claiming exact posterior sampling for the unsmoothed nonComp model will either diverge, hang, or require an oracle for the halting problem. Verifiable test: encode a Turing-machine halting predicate into the observation and check whether the posterior changes at the halting boundary; a finite algorithm cannot decide all such boundaries.

Scenario 3: Almost-sure termination without finite expected runtime veto.  
Model: ccex program: first loop flips a fair coin until heads and doubles \(x\); second loop decrements \(x\) to zero. Source: both subprograms have finite expected runtime, but the composition has infinite expected runtime; “the expected runtime of program ccex is infinite even though it terminates with probability one” [PAGE 223].  
Veto: Any runtime proof that uses only almost-sure termination is insufficient. A claim that ccex terminates within finite expected time is false.  
Prediction: A correct ert analysis returns \(\infty\) for the whole program. A termination-only analyzer may incorrectly certify it as terminating; a positive-a.s.-termination analyzer must reject it. If the first loop is replaced by a bounded number of iterations, or if the doubling is removed, the expected runtime becomes finite; otherwise the infinite-runtime veto remains.

These three vetoes are verifiable because each corresponds to an explicit source theorem or example: normalization cases [PAGE 85], noncomputable conditional distributions [PAGE 129], and infinite expected runtime despite almost-sure termination [PAGE 223].
