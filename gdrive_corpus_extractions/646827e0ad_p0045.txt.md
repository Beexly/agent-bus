<SOURCE_OPERATORS_AND_EQUATIONS>
Formal operators and equations are derived directly from Halmos's foundational
framework. Let R be a ring of subsets of a non-empty set X. An extended real
valued set function μ : R → [−∞, ∞] is finitely additive if for any finite
disjoint collection {E_1, … , E_n} ⊆ R with ∪_{i=1}^{n} E_i ∈ R, we have

\[
\mu\left(\bigcup_{i=1}^{n} E_i\right) = \sum_{i=1}^{n} \mu(E_i).
\tag{1}
\]

Countable additivity extends this requirement to countably infinite disjoint
collections {E_n}_{n∈ℕ} ⊆ R with ∪_{n∈ℕ} E_n ∈ R:

\[
\mu\left(\bigcup_{n∈ℕ} E_n\right) = \sum_{n∈ℕ} \mu(E_n),
\tag{2}
\]

where the series on the right is required to converge absolutely because μ takes
values in [−∞, ∞]. A measure μ on a ring R satisfies μ(∅)=0, μ(E)≥0 for all
E∈R, and (2).
