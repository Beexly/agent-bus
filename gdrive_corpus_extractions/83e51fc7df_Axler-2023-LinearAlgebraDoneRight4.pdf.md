In pure mathematics the scalar field \(\mathbb F\) is dimensionless; in applied instantiations, if vector components carry SI units, then \(\langle u,v\rangle\) carries the product of the units of \(u\) and \(v\), while \(\|v\|\) carries the unit of \(v\).

1. Scalar field and vector space.  
Source assumption: \(\mathbb F\) denotes \(\mathbb R\) or \(\mathbb C\) [PAGE 18].  
Formal object: \(V\) is a vector space over \(\mathbb F\).  
Breakdown regime: if the scalar set is not a field, or if addition/scalar multiplication fail the axioms, the source framework does not apply.

2. Inner product.  
Source quote: “An inner product on V is a function that takes each ordered pair (u, v) of elements of V to a number ⟨u, v⟩∈F” with positivity, definiteness, additivity in the first slot, homogeneity in the first slot, and conjugate symmetry [PAGE 197].  
Formal equation:
\[
\langle u+v,w\rangle=\langle u,w\rangle+\langle v,w\rangle,
\qquad
\langle \lambda u,v\rangle=\lambda\langle u,v\rangle,
\qquad
\langle u,v\rangle=\overline{\langle v,u\rangle}.
\]
Units: if \(u\) has unit \([u]\) and \(v\) has unit \([v]\), then \(\langle u,v\rangle\) has unit \([u][v]\).  
Breakdown: positivity fails for indefinite bilinear forms; definiteness fails for degenerate forms.

3. Norm induced by an inner product.  
Source quote: “For v∈V, the norm of v, denoted by ∥v∥, is defined by ∥v∥ = √⟨v,v⟩” [PAGE 200].  
Formal equation:
\[
\|v\|=\sqrt{\langle v,v\rangle}.
\]
Units: \(\|[v]\|=[v]\).  
Breakdown: if \(\langle v,v\rangle\) is not nonnegative real, the norm is not defined in the source sense.

4. Cauchy–Schwarz inequality.  
Source quote: “Suppose u, v∈V. Then |⟨u, v⟩| ≤ ∥u∥ ∥v∥” and “This inequality is an equality if and only if one of u, v is a scalar multiple of the other” [PAGE 203].  
Formal equation:
\[
|\langle u,v\rangle|\le \|u\|\,\|v\|.
\]
Equality regime:
\[
|\langle u,v\rangle|=\|u\|\,\|v\|
\iff
u=\lambda v \text{ or } v=\lambda u
\]
for some scalar \(\lambda\).  
Breakdown: if the inner product axioms fail, Cauchy–Schwarz need not hold.

5. Orthonormal basis expansion.  
Source quote: if \(e_1,\dots,e_n\) is an orthonormal basis, then
\[
v=\langle v,e_1\rangle e_1+\cdots+\langle v,e_n\rangle e_n
\]
[PAGE 214].  
Also:
\[
\|v\|^2=|\langle v,e_1\rangle|^2+\cdots+|\langle v,e_n\rangle|^2.
\]
Units: coefficients \(\langle v,e_k\rangle\) carry the unit of \(v\) if \(e_k\) is unit-normalized in the same unit system.  
Breakdown: if the list is not orthonormal, the formula fails; if it is orthonormal but not complete, one obtains Bessel-type inequality rather than equality [PAGE 198].

6. Riesz representation theorem.  
Source quote: “Suppose V is finite-dimensional and φ is a linear functional on V. Then there is a unique vector v∈V such that φ(u) = ⟨u, v⟩ for every u∈V” [PAGE 219].  
Formal equation:
\[
\forall u\in V,\quad \varphi(u)=\langle u,v_\varphi\rangle.
\]
Units: if \(\varphi\) outputs units \([\varphi]\), then \(v_\varphi\) must have units such that \(\langle u,v_\varphi\rangle\) has units \([\varphi]\).  
Breakdown: finite-dimensionality is essential. On \(C[-1,1]\), point evaluation \(\varphi(f)=f(0)\) has no representing continuous \(g\) [PAGE 210].

7. Adjoint of a linear map.  
Source quote: “Suppose T∈L(V, W). The adjoint of T is the function T* : W → V such that ⟨Tv, w⟩ = ⟨v, T*w⟩ for every v∈V and every w∈W” [PAGE 242].  
Formal equation:
\[
\langle Tv,w\rangle_W=\langle v,T^*w\rangle_V.
\]
Units: if \(T\) maps \([v]\mapsto[w]\), then \(T^*\) maps \([w]\mapsto[v]\) so that both inner products have the same unit.  
Breakdown: existence is guaranteed in the finite-dimensional inner-product setting via Riesz [PAGE 242]; in infinite-dimensional settings additional completeness/topological hypotheses are needed.

8. Matrix of the adjoint.  
Source quote: with orthonormal bases,
\[
\mathcal M(T^*)=(\mathcal M(T))^*
\]
[PAGE 246].  
Formal entrywise equation:
\[
(\mathcal M(T^*))_{j,k}=\overline{(\mathcal M(T))_{k,j}}.
\]
Breakdown: source warns that this fails for nonorthonormal bases: “With respect to nonorthonormal bases, the matrix of T* does not necessarily equal the conjugate transpose of the matrix of T” [PAGE 246].

9. Self-adjoint operator.  
Source quote: “An operator T∈L(V) is called self-adjoint if T = T*” [PAGE 247].  
Formal equation:
\[
T=T^*.
\]
Consequence:
\[
\langle Tv,w\rangle=\langle v,Tw\rangle.
\]
Spectral consequence given in source: “Every eigenvalue of a self-adjoint operator is real” [PAGE 247].  
Breakdown: over \(\mathbb R\), the definition still makes sense, but real normal operators may fail to have real eigenvalues.

10. Normal operator.

TT^*=T^*T.

\|Tv\|=\|T^*v\|\quad\text{for every }v\in V

[PAGE 250].  
Orthogonality consequence:

Tv=\lambda v,\ Tw=\mu w,\ \lambda\ne\mu
\implies

for normal \(T\) [PAGE 252].
