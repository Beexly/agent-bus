Physical, biomechanical, and weather veto layers with proof-style adjudication.

The means-end field model assumes that path length L(π) fully determines choice. Three independent layers can veto this assumption.

Physical layer (maze topology): Walls and barriers impose w(u,v) = ∞ for impermissible transitions. Proof: If the geometrically shortest chain π* requires crossing a solid wall, then π* ∉ Feasible(G). The veto is absolute; no motivational scaling of β can resurrect a physically severed edge. Adjudication: overlay the observed path on the maze blueprint; any observed traversal through a wall indicates measurement error, not model failure; any failure to traverse an open shortest path indicates a higher-layer veto.

Biomechanical layer (locomotor constraints): The rat has finite maximum speed v_max, minimum turning radius r_min, and limb-cycle constraints. An edge of geometric length ℓ has traversal time τ ≥ ℓ / v_max + κ(θ), where κ(θ) is the turning penalty for angle θ. Two chains with equal Σℓ can have different Στ if one requires tight turns. The “length” in Tolman’s principle must therefore be interpreted as effective effort/time, not bare Euclidean distance. Veto condition: if the rat consistently avoids a geometrically short path with acute-angle turns in favor of a longer, wider-radius path, the pure distance model is falsified; the cost function w must include angular and dynamic terms.

Weather/environmental layer (ambient conditions): Standard lab mazes are indoors, so precipitation and wind are null. However, ambient temperature T and humidity modulate metabolic cost: w(T) = w_0 [1 + α(T − T_opt)] for T outside the thermoneutral zone. Veto: if T deviates such that the incremental cost of running exceeds the demand value U_GO (i.e., U_GO − λ L(π) < 0 for all π), the rat will not initiate the chain at all, regardless of relative path lengths. This is a global veto on the entire field, not a rerouting within it.

Adjudication protocol: A path choice is explained by the means-end field only if (a) the path is physically feasible, (b) its effective cost respects biomechanical time/turning penalties, and (c) ambient conditions do not globally suppress initiation. Failure at any layer invalidates the field-only explanation for that trial.
