The 2017 Soccer Prediction Challenge explicitly restricts participants to “commonly available match data” [PAGE 2], which per the schema means only home/away team, goals, date, league, and season [PAGE 2]. Therefore the physical/biomechanical/weather layer is entirely absent from the challenge’s information set. This yields a formal veto rule: any prediction model that assumes constant player availability, constant fitness, or weather-invariant pitch behavior across the 206-match target window is invalidated by missing data.

Physical veto: match reports do not encode player suspensions, injuries, or fatigue. A key defender’s absence, unrepresented in the schema, alters defensive transition probabilities but leaves the pre-match feature vector unchanged. Biomechanical veto: accumulated external and internal load (GPS distance, accelerometer load, heart-rate response, RPE) [PAGE 4–5] affects injury susceptibility and match-day performance, yet none of these variables appear in the training matrix. Weather veto: precipitation, temperature, and wind alter ball-surface interaction and player thermoregulation, but weather fields are not part of the match report schema [PAGE 2].

Adjudication: because the challenge data cannot observe the physical/biomechanical/weather state, any model claiming to predict the 206 matches using only the provided schema must treat those layers as exogenous noise. If a deployed system imports post-match injury announcements or weather records after the prediction lock, it violates the temporal integrity of the challenge. The veto is therefore absolute: models restricted to [PAGE 2] schema inputs cannot condition on player health, biomechanical load, or meteorological conditions, and their error bounds must account for this omitted-variable uncertainty.

RLVR counterfactual vetoes are verifiable rejection rules applied to proposed model updates before deployment. Three scenarios follow, each with a verifiable constraint, a veto trigger, and a counterfactual prediction.

Scenario 1 — Post-match event-stream leakage. Constraint: every feature timestamp must be \(\le\) submission deadline [PAGE 2]. Proposed update: incorporate Opta event-stream counts (shots, passes, cards) [PAGE 4] for the target matches as predictors. Veto trigger: event-stream data exist only after match completion; including them violates temporal integrity. Prediction: an in-sample fit using these post-match features would yield \(\overline{\mathrm{RPS}} \approx 0.0000\) and \(\mathrm{ACC} \approx 1.0000\), but on the held-out 206 matches the model collapses to the league-prior baseline \(\overline{\mathrm{RPS}} = 0.2255\), \(\mathrm{ACC} = 0.4515\) [PAGE 3], because the leakage features are unavailable at prediction time.

Scenario 2 — Temporal cross-validation violation. Constraint: training must respect chronological ordering; no match after the deadline may inform predictions for earlier target matches [PAGE 2]. Proposed update: random \(k\)-fold cross-validation across all 216,743 matches [PAGE 2], mixing pre- and post-deadline fixtures. Veto trigger: future leakage into training folds. Prediction: cross-validated accuracy would appear inflated above 0.70, but true out-of-sample accuracy on the 206 future matches would fall to \(\le 0.50\), likely near the global-prior range of 0.4515 [PAGE 3], due to distribution shift across the 2000–2017 span.

Scenario 3 — League-homogeneity violation. Constraint: league-specific base rates must be modeled separately because scoring and home advantage vary across the 52 leagues [PAGE 2]. Proposed update: a single global model with no league intercepts or priors. Veto trigger: heterogeneity breach; the global prior itself achieves only \(\overline{\mathrm{RPS}} = 0.2261\), \(\mathrm{ACC} = 0.4515\) [PAGE 3], worse than league-aware submissions. Prediction: relative to the best league-aware submission (Team DBL*, \(\overline{\mathrm{RPS}} = 0.2054\) [PAGE 3]), the global model forfeits at least \(0.2261 - 0.2054 = 0.0207\) RPS units and would perform no better than the global-prior baseline \(\mathrm{ACC} = 0.4515\) [PAGE 3].
