R := MerkleRoot( {C_i}_{i=1..n} )

An inclusion proof π_i consists of the set of sibling hashes along the path from leaf i to the root. Verification is the predicate:

Verify(π_i, C_i, R) = 1  ⇔  RecomputePath(C_i, π_i) = R

Pr[ A finds x ≠ y : SHA-256(x) = SHA-256(y) ] ≤ negl(λ),   birthday bound ≈ 2^(λ/2) = 2^128 operations
Pr[ A finds x : SHA-256(x) = h ] ≤ negl(λ),               preimage bound ≈ 2^256 operations
