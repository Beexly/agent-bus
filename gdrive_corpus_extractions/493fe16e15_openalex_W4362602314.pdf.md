<SOURCE_OPERATORS_AND_EQUATIONS>
The source’s target is a conditional probability, not a deterministic goal count. For shot \(i\) with feature vector \(\mathbf{x}_i\) and parameter vector \(\theta\),
\[
p_i=\Pr(Y_i=1\mid \mathbf{x}_i;\theta),\qquad Y_i\in\{0,1\},\qquad p_i\in[0,1],
\]
where \(p_i\) is dimensionless and \(1-p_i\) is the no-goal probability. The paper frames xG as “a classification problem” [PAGE 2] and evaluates probability outputs rather than hard labels [PAGE 11]. Assumption: shots are conditionally exchangeable given \(\mathbf{x}_i\). Breakdown regime: if match-level random effects \(u_m\) are omitted, then \(p_i\) is a marginal probability, not a match-conditional probability, and calibration can fail even when average log loss is low.

The primary evaluation operator is log loss:
\[
\mathcal{L}(\theta)=-\frac{1}{n}\sum_{i=1}^{n}\left[y_i\ln p_i+(1-y_i)\ln(1-p_i)\right].
\]
If the logarithm is natural, units are nats per shot; if base 2, bits per shot. The paper uses log loss because “the lower this score, the better the classification algorithm is at accurately estimating goal probability” [PAGE 11]. Breakdown regime: as \(p_i\to 1-y_i\), the loss diverges to \(+\infty\); if \(p_i=0\) or \(p_i=1\) with the wrong label, the logarithm is undefined. This is why probability clipping or regularization is required in implementation.

Feature scaling uses min-max normalization:
\[
x'=\frac{x-\min(x)}{\max(x)-\min(x)},
\]
which is dimensionless. The paper states this was done “to avoid larger weights being assigned to variables with larger values” [PAGE 10]. Breakdown regime: if \(\max(x)=\min(x)\), the denominator is zero and the transform is undefined; constant features must be dropped or handled separately.

Elo rating is modeled as
\[
P_i=\frac{1}{1+10^{(\beta_j-\beta_i)/400}},\qquad \Delta_i=k(r-P_i),
\]
where \(\beta_i,\beta_j\) are pre-match Elo ratings in Elo points, \(r\in\{0,0.5,1\}\) is the result, \(k=20\) is the update scale in Elo points, and \(P_i\) is dimensionless [PAGE 9]. There is no finite singularity, but the logistic saturation regime is exact: as \(\beta_j-\beta_i\to+\infty\), \(P_i\to 0\); as \(\beta_j-\beta_i\to-\infty\), \(P_i\to 1\). In both tails the gradient \(P_i(1-P_i)\to 0\), so updates become vanishingly small.

PlayeRank is
\[
r(u,m)=\frac{1}{R}\sum_{i=1}^{76}w_i x_i,
\]
where \(r(u,m)\) is normalized between 0 and 1, \(R\) is a normalization constant, \(w_i\) are feature weights, and \(x_i\) are the 76 feature values [PAGE 7]. Units are dimensionless after normalization. Breakdown regime: \(R=0\) is undefined; the paper does not state a guard. More importantly, the cumulative version \(C(u,m)=\sum_{m'\prec m}r(u,m')\) accumulates over prior matches, so early-season values are near zero regardless of ability. The paper later admits “a frequent drawback to calculating PlayeRank scores cumulatively was the large proportion of lower values within the variable” [PAGE 26].

Weighted team form is
\[
\omega_j=\frac{\sum_{p=j-k}^{j-1}2\left(p-(j-k-1)\right)r_p}{3k(k+1)/2},
\]
where \(r_p\in\{0,1,3\}\) is points from the \(p\)-th match, \(k=6\) is the window, and \(\omega_j\) is a weighted points quantity [PAGE 9]. Breakdown regime: \(k=0\) gives a zero denominator; the paper uses \(k=6\) following prior work [PAGE 23]. The window choice is a multi-week modeling decision: it defines how much recent form is allowed to matter.

Match importance uses
\[
RP_i(g)=\max\left(TP_{1st}(g)\frac{M}{g}-TP_i(g),0\right),
\]
where \(RP_i\) is required points, \(TP_i\) is current points, \(g\) is gameweeks played, and \(M\) is total matches [PAGE 8]. Units are points. Breakdown regime: \(g=0\) gives division by zero at the season start; the max clamps negative required points to zero. The importance score is then a difference of binomial cumulative probabilities, dimensionless, with trials equal to remaining maximum points and success probability 0.5 [PAGE 8].

The Gini impurity used for tree splits is
\[
G=\sum_{k=1}^{m}p_k(1-p_k),
\]
dimensionless, where \(p_k\) is the proportion of class \(k\) in a node [PAGE 11]. Breakdown regime: a pure node has \(G=0\); maximum impurity occurs at \(p_k=0.5\) for binary outcomes.

Other reported operators include Brier score \(B=\frac{1}{n}\sum_i(p_i-y_i)^2\), dimensionless squared probability; AUC ROC, dimensionless and undefined if only one class is present; and future-goal-ratio mean squared error \(\mathrm{MSE}=\frac{1}{N}\sum_t(\hat{g}_t-g_t)^2\), with units \((\text{goals/match})^2\) [PAGE 18, 23–24]. The paper’s best all-leagues tuned XGBoost is reported as log loss \(0.28184\), Brier \(0.0799\), AUC \(0.8\) in Table 3 [PAGE 18], while the prose reports Brier \(0.07908\) [PAGE 18]. This numerical discrepancy is a reproducibility flag.

For omitted-layer analysis, write the true logit as
\[
g^*(\mathbf{x},W)=\beta_0+\mathbf{x}^{\top}\beta+\gamma W,
\]
but estimate \(g(\mathbf{x})=\beta_0+\mathbf{x}^{\top}\beta\) without \(W\). If \(\gamma\neq 0\) and \(\mathrm{Cov}(\mathbf{x},W)\neq 0\), then \(\hat{\beta}\) is biased and \(\hat{p}\) is not the causal probability under intervention. There is no singularity in the equation, but there is an identification breakdown. The source supplies the missing-layer evidence: “there is no positional data (so some influential features examined in other works [2] cannot be included in the models)” [PAGE 5], and other models used “positional data, in addition to event data” [PAGE 19]. Units for omitted physical variables would be metres for player/ball position, metres per second for speed, radians for body orientation, degrees Celsius for temperature, metres per second for wind, and millimetres for precipitation; none are present in the source’s event-only Wyscout data.

<RETROCAUSAL_GENEALOGY>
The paper’s historical lineage is explicitly retrocausal. It says it is “not clear when the expected goals statistic was first developed and who conceived it,” with most sources crediting Macdonald’s ice-hockey shot-outcome study, while others attribute it to Green’s article [PAGE 2]. Football xG is therefore a later relabeling of an earlier shot-quality probability tradition: ice hockey shot models, then association-football event models, then public-data xG models, then commercial xG systems such as StatsBomb. The paper positions itself in that lineage by citing Rathke’s distance-and-angle zones, Spearman’s off-ball scoring opportunities, Brechot and Flepp’s shot-type and situation effects, Lucey et al.’s spatiotemporal context, Kharrat et al.’s “big chance” and “goal value,” Eggels et al.’s FIFA-rating proxies, Madrero et al.’s player-ability work, and Anzer and Bauer’s synchronized positional-plus-event model [PAGE 2–4, 18–19]. The retrocausal move is to treat Macdonald’s hockey model as the ancestor of a football metric that now includes player value, team Elo, match importance, and possession length.

The multi-week traps are built into the feature engineering. Cumulative PlayeRank is the clearest: it sums prior-match ratings, so a strong player early in the season has a low cumulative value simply because fewer matches have accumulated. The paper admits the playing-time problem and suggests dividing by gameweek or otherwise contextualizing the score [PAGE 26]. Form uses a \(k=6\) match window [PAGE 9, 23], so “form” is not a static trait; it is a rolling weighted memory. Elo ratings are also path-dependent: the paper notes that Elo “may be inflated by beating the same opponent on several occasions” and that the authors “restrict the dataset to a limited number of seasons to avoid much of these issues” [PAGE 9]. Previous-season ranking has a promotion/relegation trap: “Teams that had been promoted were assigned the previous season ranking of the teams that had been relegated the season before” [PAGE 6]. That is a defensible imputation, but it injects a synthetic continuity across seasons. Match importance has an early-season instability because \(RP_i(g)\) contains \(M/g\); at \(g=0\) it is undefined, and at small \(g\) it is highly sensitive to the current table. Finally, the evaluation window itself is multi-week: next-match result and future goal ratio are averaged over the subsequent six matches [PAGE 23]. Any claim that xG “predicts the future” is therefore a claim about a six-match horizon, not a one-match causal effect.

The historical lesson is that xG has moved from shot geometry to a broader latent-quality model. That broadening improves prediction but also increases the risk of retrofitting narratives: a feature added for “psychology” may actually be a team-quality proxy, and a feature added for “ability” may be a market-value proxy. The paper itself warns that goal differential “could have aspects within it which more strongly point it out to be a proxy for team quality” [PAGE 26–27]. The genealogy therefore supports a cautious reading: xG is a strong predictive summary, not a complete causal decomposition of football.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
The recursive theory-of-mind layer has three competing mechanisms: crisis habit regression, counter-trap, and clock. Crisis habit regression predicts that under high pressure players and teams revert to habitual, lower-probability actions: rushed headers, weak-foot stabs, long-distance shots, or set-piece dependence. The paper’s psychological proxies are consistent with a pressure effect: “goal probability increased both when there were fewer fans present at matches and when the consequences of match outcome were less crucial to the fortunes of a team” [PAGE 22–23]. That is the signature of pressure reducing conversion. But the paper also rates match importance as only “medium-to-low” in impact and attendance as relatively unimportant [PAGE 22], so the effect is not strong enough to support a grand psychological theory.

The counter-trap is that goal differential is not clean psychology. It is one of the most influential variables, with the result that “the less a team is losing by and the more a team is winning by, the more likely they are to score” [PAGE 23]. But winning teams are usually better teams, and better teams have better players and better shot locations. The paper concedes the proxy ambiguity [PAGE 26–27]. A recursive model must therefore separate the shot-taker’s belief (“we are ahead, I can be relaxed”) from the analyst’s belief (“this coefficient is pressure”) from the opponent’s belief (“we are behind, we must press and leave space”). Without within-match randomization or fine-grained tracking, these beliefs are observationally entangled.

The clock mechanism is the cleanest. The paper reports that “shots which occur later on in matches have a slightly higher chance of being successful” [PAGE 13], that early shots are less successful, that there is a dip before half-time around 2700 seconds, and that after half-time “the likelihood of a shot resulting in a goal increases significantly” [PAGE 14]. This is a recursive state update: players observe the clock, update risk tolerance, and change behavior. Late-game urgency can produce more open space and more attacking risk, raising conversion. The clock also changes the coach’s belief and the goalkeeper’s belief. The correct interpretation is not “time causes goals” but “time proxies for strategic risk, fatigue, scoreline, and information updating.” The paper’s time feature is therefore a reduced-form state variable, not a structural causal variable.

In recursive terms: the shot-taker models the goalkeeper’s position and the coach’s expectations; the goalkeeper models the shot-taker’s likely placement; the analyst models both, but only through event labels. The source cannot observe the first two layers directly. That is why the psychological findings should be treated as hypothesis-generating. The strongest defensible claim is that pressure-sensitive proxies and clock state are associated with conversion changes, while the causal mechanism remains underidentified.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The cross-layer veto is formal. Let \(Y\) be goal, \(X\) the event features used by the paper, \(W\) the omitted physical and weather layer, and \(B\) the omitted biomechanical layer. The paper estimates \(p=\Pr(Y=1\mid X)\). A causal claim about “true” goal probability or player ability requires \(\Pr(Y=1\mid do(X))\). If \(W\) or \(B\) affects \(Y\) and is correlated with \(X\), then the event-only conditional is not the interventional quantity. This is not a philosophical objection; it is an identification veto.

Physical-layer veto: the source has no positional tracking. It states “there is no positional data (so some influential features examined in other works [2] cannot be included in the models)” [PAGE 5]. Positional data would include player coordinates, ball coordinates, goalkeeper position, defender distance, closing speed, and pressure angle, often at up to 25 Hz [PAGE 2]. Without those, a shot from 12 m with no defender is treated similarly to a shot from 12 m with two defenders closing, except insofar as the event labels capture match situation. That is a physical-layer veto on any claim that the model measures chance quality independent of defensive structure.

Biomechanical-layer veto: the paper includes body part as “head/body, strong foot and weak foot” [PAGE 5]. That is a categorical label, not biomechanics. It does not measure foot orientation, contact point, hip rotation, jump height, sprint speed before contact, or goalkeeper limb reach. A header from a standing jump and a header from a sprinting jump can share the same label. Therefore the model cannot adjudicate execution quality. Any claim that player value “causes” better shooting must be vetoed unless the biomechanical and positional channels are measured or randomized.

Weather-layer veto: the source includes match attendance but not wind, rain, temperature, altitude, pitch condition, or ball inflation. Attendance is not weather. A match played in strong wind or heavy rain can change shot speed, flight path, grip, and goalkeeper handling. Without \(W_{\text{weather}}\), the model cannot estimate weather effects. The veto condition is exact: if \(\gamma_{\text{weather}}\neq 0\) and \(\mathrm{Cov}(X,W_{\text{weather}})\neq 0\), then the reported coefficients are biased. If weather is randomized or measured and included, the veto is lifted; otherwise it stands.

The source itself supplies the comparative proof of missing layers: the paper notes that Eggels and Anzer and Bauer “used positional data, in addition to event data, in their models” [PAGE 19], while this study could not. That does not invalidate the paper’s predictive comparison; it limits causal interpretation. The correct adjudication is: the event-only model is a valid predictive approximation within its data layer, but it is vetoed as a complete physical, biomechanical, or weather model.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Scenario 1: match-grouped versus shot-level test partition. The source reports a 70/30 train/test split [PAGE 10] but does not explicitly state that shots are grouped by match. A verifiable counterfactual is to rerun the all-leagues tuned XGBoost with a match-grouped partition and a fixed random seed. Prediction: if same-match leakage is material, test log loss will rise from the reported 0.28184 [PAGE 18] to at least 0.290 nats per shot. Veto rule: if the grouped-split log loss changes by less than 0.005 nats per shot, the leakage veto is rejected; if it rises by 0.010 or more, the original split overstated generalization. Reward is binary and verifiable from saved predictions and match IDs.

Scenario 2: distance-only AdaBoost ablation. The paper reports that after tuning, “the only feature the AdaBoost took into account when making predictions was distance” [PAGE 18]. A verifiable test is to train a distance-only AdaBoost with the same folds, scaling, and hyperparameter grid. Prediction: distance-only log loss will be within 0.005 nats per shot of the tuned full-feature AdaBoost for every league. Veto rule: if distance-only is worse by 0.010 or more in any league, the claimed collapse is incomplete and non-distance features remain identifiable in that learner. Reward is binary and computed from the same test-set log-loss function.

Scenario 3: goal-differential replacement by pre-match team quality. The paper finds goal differential highly influential [PAGE 23] but admits it may proxy team quality [PAGE 26–27]. A verifiable counterfactual is to ablate goal differential and replace it with pre-match Elo and current rank, then stratify test matches by pre-match match importance. Prediction: if the psychological interpretation is real, the calibration gain from goal differential should remain larger in high-importance matches than in low-importance matches after team-quality adjustment. If the gain disappears, goal differential is primarily a team-quality proxy. Veto rule: if the high-importance versus low-importance difference in log-loss gain is less than 0.005 nats per shot, the psychological interpretation is vetoed. Reward is binary and verifiable from stratified test log loss and saved feature attributions.
