**Operator 1 — Traffic-tag footprint.** For a seed image \(I\) and retrieval epoch \(t\), let \(\mathcal{R}_\theta(I,t)\) be the URL set returned by the Web-detection module at match threshold \(\theta\). Define
\[
\mathcal{F}(I,t)=\{\,(u,\,d(u),\,\tau(u))\;:\;u\in\mathcal{R}_\theta(I,t)\,\},
\]
with \(d(u)\) the registrable domain and \(\tau(u)\) the top-level domain, both extracted via `tldextract` [PAGE 9, footnote 12]. Units: \(\mathcal{F}\) is a set of URL records; \(|\mathcal{R}_\theta(I,t)|\) is a dimensionless count of pages. Assumption: domain identity is a stable proxy for platform identity (Table 1, [PAGE 10]).

**Operator 2 — Horizon of retrievability as a fuzzy subset.** Let \(W(t)\) be the publicly addressable Web at epoch \(t\) and \(\mu_t: W(t)\to[0,1]\) the retrievability membership. Then
\[
H_\theta(t)=\{x\in W(t): \mu_t(x)\ge\theta\},\qquad
N_{\mathrm{obs}}(I,t)=\bigl|\{x\in M(I)\cap W(t):\mu_t(x)\ge\theta\}\bigr|,
\]
where \(M(I)\) is the true match set. Because \(\mu_t\le 1\), \(N_{\mathrm{obs}}\le |M(I)\cap W(t)|\) always; equality holds only if the engine retrieves everything retrievable. The paper's own gloss is verbatim: "Google's results are not the Web" [PAGE 5].

**Operator 3 — Architectural veto as a Boolean product.** Indexability at time \(t\) is
\[
\iota(u,t)=a(u)\cdot r(u)\cdot s(u)\cdot \ell(u),\qquad \iota\in\{0,1\},
\]
where \(a\) = HTTP availability, \(r\) = robots.txt allowance, \(s\) = source-code visibility of the image URL, \(\ell\) = absence of a login wall. Empirical assignments from the source: Twitter \(r=1\) because its robots.txt "allows access to all public tweet and profile URLs" [PAGE 16, footnote 16]; Facebook individual photos \(r=0\) (paths "/photo.php," "/photos.php," "/album.php" blocked) and profiles \(\ell=0\) [PAGE 17, footnote 18]; Instagram \(s=0\) because "the page's source code masks image URLs by dynamically generating the HTML code displaying it" [PAGE 17]. Hence "no Instagram URLs have been found in our experiment" [PAGE 17] is a *structural zero*, not a low rate.

**Operator 4 — Verbal/nonverbal overlap.** For Google-returned Twitter URLs \(G\) (\(|G|=1303\)) and the query-derived tweet set \(V\),
\[
\frac{|G\cap V|}{|G|}=\frac{52}{1303}=0.0399,\qquad
J(G,V)=\frac{52}{1303+5978-52}=\frac{52}{7229}\approx 7.20\times10^{-3}.
\]
Units: dimensionless. Assumption flagged in the source: \(V\) membership is under-determined, so \(J\) is a lower bound.

**Operator 5 — TLD diversity.** With \(p_i(t)\) the share of open-Web occurrences under TLD \(i\),
\[
H_{\mathrm{TLD}}(t)=-\sum_i p_i(t)\log_2 p_i(t)\ \text{[bits]},\qquad N_{\mathrm{eff}}(t)=2^{H_{\mathrm{TLD}}(t)}.
\]
Prediction from the source's TLD inventory [PAGE 15–16]: \(H_{\mathrm{TLD}}(\text{A})>H_{\mathrm{TLD}}(\text{B})\gg H_{\mathrm{TLD}}(\text{D})\), since Picture D is "exceptionally devoid of national TLDs" [PAGE 14].

**Operator 6 — Non-monotonicity.** Differentiating the observation equation,
\[
\frac{dN_{\mathrm{obs}}}{dt}=\int_{M(I)\cap W(t)}\frac{\partial \mu_t}{\partial t}\,dx \;+\; \bigl|\partial_t(M\cap W)\bigr|,
\]
the first term may be negative — dynamic pages (hashtag pages, profile pages; 87% of retrieved Twitter URLs were profile pages [PAGE 17, footnote 17]) re-render and evict the image — so \(\partial N_{\mathrm{obs}}/\partial t<0\) is admissible while the underlying circulation is non-decreasing. This is exactly the reported behaviour: "the number of occurrences does not grow continuously," with a peak on 14 December and a decrease on 22 December [PAGE 11].

**Operator 7 — Saturation.** \(N_{\mathrm{obs}}=\min\{|M\cap W|,\,K\}\) with \(K=951\) [PAGE 7, footnote 10]. Where the true match set exceeds \(K\), \(\partial N_{\mathrm{obs}}/\partial |M|=0\) and the estimator is blind.

(B2) *Non-injectivity*: page-count \(\to\) posting-count is many-to-one (thumbnail repetition), so popularity inference is invalid on open-Web domains. (B3) *Saturation*: \(|M\cap W|>K\). (B4) *Architectural non-identification*: \(\iota=0\) produces missingness-not-at-random; the posterior over the true rate equals the prior. The tool chain is datable in the same way: TinEye (2008) and Google "search by image" (2011) precede the 2015 Cloud Vision API [PAGE 5, footnotes 4–5], which in turn is scripted through Memespector (Rieder, Den Tex, & Mintz, 2018) [PAGE 7, footnote 9].

Multi-week traps lurk in the 21-day observation arc — 1, 2, 13 and 21 December at 12:00, plus the 18:00 launch — because that window is long enough for a Google re-crawl and short enough to look like a content life-cycle. Three specific traps follow. First, the *decay trap*: reading the 22 December decline as waning public interest, when Operator 6 shows the sign of \(\partial\mu_t/\partial t\) is unconstrained. Second, the *late-arrival trap*: Twitter, the very platform from which seeds were drawn, "appear[s] significantly late in the listed occurrences... they only show up in results on December 14, skipping the first three Vision API retrieval iterations" [PAGE 11]; an analyst sampling only the first three epochs would conclude Twitter was absent. Third, the *retrocausal trap* properly so called: Picture C's montage overlays new text on a photograph from a 2015 preliminary draw, so the image's indexical pre-history (355 hits at \(t_0\)) *precedes and partially constitutes* the 2017 event's visibility; likewise Picture A was posted at 14:30, "30 minutes before the ceremony" [PAGE 8]. The event is thus not the origin of its own image traffic — it is a re-activation point in an existing retrieval field, which is precisely why a 21-day window cannot arbitrate between "new circulation" and "re-surfaced old circulation."
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>

Three nested models are in play, and each has a characteristic failure mode.

*Model of the platform.* The naive researcher holds \(\Pr(\text{index})=\Pr(\text{exists})\) — the totalizing fallacy the authors explicitly reject: it is "crucial not to take Google's centrality within the culture of Internet users as if totalizing" [PAGE 5]. The counter-trap is to substitute the veto operator \(\iota(u,t)\) for the identity, converting an ontological claim about circulation into a bounded claim about retrievability.

*Model of the user.* The verbal-query habit assumes sharers label content in the researcher's vocabulary. The evidence against it is direct: "at least half of them did not feature the terms and hashtags used to collect data from Twitter" [PAGE 17]. The nonverbal seed is the counter-trap; the residual risk is over-correction, i.e., assuming images are *language-free* when Pictures C and D are explicitly language-bearing ("Chile no va"; the Arabic kabsa pun) [PAGE 9].

*Model of the other researcher.* The default peer practice is the "single-platform study" and the "API-led study" [PAGE 3]; the recursive risk is that this paper's own instrument reproduces platform-centrism by over-reporting Twitter, which is partly circular because "the pictures were selected because of an already known large occurrence on this platform" [PAGE 16].

*Crisis habit regression.* When the counts move counterintuitively, the analyst regresses to the habits the paper names: (i) treating page counts as popularity, invalidated by the elpais.com.uy thumbnail case [PAGE 11]; (ii) interpolating between five points, invalidated by the authors' own disclaimer [PAGE 12]; (iii) reading absence as low incidence, invalidated by the Instagram zero [PAGE 17]. The disciplined response is to hold the regression at bay by re-deriving each claim through Operator 3 before admitting it.

*The clock problem.* Two clocks are superimposed and are not synchronized: the liveness clock \(\varphi_{\text{event}}\), whose support is roughly the ceremony plus the "two hours after it ended" capture window (15:00–18:00 UTC, 1 December 2017) [PAGE 6], and the index clock \(\varphi_{\text{index}}\), whose granularity is days. The observed series is \(N_{\mathrm{obs}}(t)=f(\varphi_{\text{index}}(t))\), not \(f(\varphi_{\text{event}}(t))\); the near-vertical early slope for Picture A versus the "funnel-shaped" curve for Picture B [PAGE 13] is a joint product of both clocks plus a genuine 1,890-versus-1,062 difference in retweet volume [PAGE 9]. Collapsing the two clocks into one is the single most consequential theory-of-mind error available here.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>

A claim is admissible only if it survives every layer of the stack; any layer may veto.

**L0 — Physical / infrastructural.** The verifiable physical facts are: a ceremony in the State Kremlin Palace, Moscow, on 1 December 2017; a broadcast reaching 203 countries; a capture window defined in UTC [PAGE 6]. These constrain timestamp alignment and the plausible breadth of the sharer population. They do not constrain image semantics. *Veto consequence:* any inference from TLD geography to physical location of a device is blocked, because "websites may use a TLD not related to their location" [PAGE 14]; the authors apply this veto themselves and fall back on content inspection — Picture D's pages "contain texts in Arabic" despite the absence of ".eg" or ".sa" [PAGE 14].

**L1 — Network / protocol.** HTTP availability, robots.txt, DNS, and IANA TLD delegation. *Veto:* a null result on a domain with \(r=0\) carries zero evidential weight.

**L2 — Platform architecture.** Login walls and dynamic HTML generation. *Veto proof:* for Instagram, \(\iota=0\) identically, so \(\Pr(\text{observe}\mid\text{Instagram})=\Pr(\text{observe}\mid\neg\text{Instagram})=0\); the observation is non-identifying and the posterior equals the prior. The same argument applies, more weakly, to Facebook, where only landing pages and "/photos" sections are crawlable [PAGE 17]. The correct reading of "Instagram is notably absent in the collected data" [PAGE 13] is therefore *architectural*, and the authors say so: content "has migrated from openly available Web pages to the fenced grounds of social media platforms" [PAGE 17].

**L3 — Algorithmic / ML.** Match threshold \(\theta\), the undocumented fully/partially criterion, and the \(K=951\) ceiling. *Veto:* comparisons of absolute volume across images are admissible only up to \(K\); beyond \(K\) the estimator is saturated.

**L4 — Semiotic / linguistic.** Meme text and regional publics. *Veto:* a claim of "global appeal" for Picture D is barred because its legibility is language-bound, and the TLD evidence is explicitly regional despite non-regional suffixes.

**Explicitly vacuous layers.** No biomechanical layer exists in this corpus: there is no motion capture, no physiological telemetry, no player-load data, no injury record. No meteorological layer exists: Moscow's December climate appears nowhere as a variable, and the draw is an indoor ceremony. I therefore enter a formal veto against any inference of the kind "weather affected circulation" or "physical fatigue shaped sharing": both would be fabricated layers with zero source support, and their introduction would violate the requirement that every operator be traceable to a page. The only admissible cross-layer chain is L2 \(\to\) L3 \(\to\) L1, and it terminates in the retrievability bound rather than in any physical causation.
</CROSS_LAYER_VETO_ADJUDICATION>

**Scenario 1 — Lift the source-code veto on Instagram.** Counterfactual: set \(s(u)=1\) for Instagram by serving statically addressable image URLs. Prediction: the Instagram domain count moves from exactly 0 to a strictly positive value within one index cycle, and total \(N_{\mathrm{obs}}\) for Pictures C and D rises disproportionately, since those are the user-generated, meme-like items the authors associate with social platforms rather than editorial ones [PAGE 13]. Verification: re-run the same 219-URL seed set through a CBIR endpoint that ignores dynamic rendering; a null Instagram count under the lifted condition would falsify the architectural explanation and force a genuine low-incidence explanation. Current observation to be overturned: "no Instagram URLs have been found in our experiment" [PAGE 17].

**Scenario 2 — Restrict retrieval to verbal queries only.** Counterfactual: replace CBIR with the 47-term/17-language Twitter query and match Google's URL output against it. Prediction: overlap rises toward 1.0 by construction while total reach collapses — specifically, the recovered set loses the majority of Google-returned tweets, because "at least half of them did not feature the terms and hashtags used to collect data from Twitter" [PAGE 17]. Verification: the observed 52/1303 = 3.99% is the falsifiable signature; if a purely verbal pipeline also achieved high recall against the *unknown* universe of sharers, the nonverbal-advantage thesis fails.

**Scenario 3 — Remove the pre-existing index mass for Picture C.** Counterfactual: treat the montage as created at event time rather than overlaid on a 2015 photograph. Prediction: the first retrieval epoch would return near-zero rather than 355 occurrences [PAGE 14], and the 3 December dip would attenuate or vanish, since the dip is attributed to "a drastic reconfiguration of Google's indexation" following new uploads [PAGE 14]. Verification: compare \(N_{\mathrm{obs}}(t_0)\) across images known to be event-native (Picture D, which "was created and shared only during the ceremony's broadcast" [PAGE 14]) versus images known to be recycled; the contrast is the test.

**Scenario 4 (binding constraint check) — Raise the retrieval ceiling.** Counterfactual: set \(K=10^{4}\) as originally requested. Prediction: any image whose true match set exceeds 951 shows an observed plateau exactly at 951 with zero variance across epochs, independent of true volume. Verification: the reported maximum of 951 against a requested 10,000 [PAGE 7, footnote 10] is itself the observable; a per-image distribution with a hard mode at 951 confirms internal truncation rather than organic saturation, and would invalidate any cross-image volume comparison at the top of the range.
