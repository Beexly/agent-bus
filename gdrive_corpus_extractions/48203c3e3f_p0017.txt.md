RLVR = verifiable counterfactual veto scenarios. Each specifies a manipulation (veto condition), the falsifiable prediction, and the breakdown regime under which the prediction fails.

Scenario 1 — Goal-path occlusion (cognitive map vs. habit).
Veto condition: Block the previously rewarded direct path from start to goal with a physical barrier W such that \gamma_{\text{habit}} \cap W \neq \emptyset, but leave an indirect path open. Source layer: Ch. VIII spatial hierarchies (p. 117 [PAGE 1]) and Ch. VII means-distances (p. 101 [PAGE 1]).
Prediction: If Tolmanian sign-gestalt expectancy operates, the rat takes the indirect path to the same goal location rather than running to the old food cup or repeating the blocked motor sequence. Path efficiency (ratio of actual path length to Euclidean goal distance) remains < \eta_{\text{crit}}.
Verification: Video-tracked path traces; compare to pure-motor-habit null model which predicts perseveration at the barrier or reversion to reinforced food-cup location.
Breakdown: If the barrier is introduced after extensive overtraining (>N_{\text{overtrain}} sessions), habit regression (per <RECURSIVE_THEORY_OF_MIND>) may dominate, causing the rat to persist at the blocked path despite the open alternative.

Scenario 2 — Delayed reaction with interpolated distractor.
Veto condition: In Ch. X delayed-reaction trials (p. 113 ordinal anomaly [PAGE 1]), insert a distractor period of duration \tau_{\text{distractor}} during the delay, with no goal cues present.
Prediction: Choice accuracy decays exponentially:
\[
\text{Accuracy}(\tau) = \frac{1}{|\mathcal{G}|} + \left(1 - \frac{1}{|\mathcal{G}|}\right) e^{-\tau/\tau_{WM}},
\]
where \tau is total delay in seconds. Verifiable veto: if accuracy remains at asymptotic chance (1/|\mathcal{G}|) for \tau > 2\tau_{WM}, the expectancy trace is nulled.
Breakdown: If \tau_{WM} is not individually calibrated, the threshold 2\tau_{WM} is mis-specified; the veto may falsely appear to fail.

Scenario 3 — Start-location transfer with constant goal.
Veto condition: Start the rat from a novel maze arm never used in training, while keeping the goal object and its distal sign-configuration \sigma constant.
Prediction: If a cognitive map and sign-gestalt expectation exist (Ch. IV p. 71 and Ch. IX p. 131 [PAGE 1]), initial heading error \theta_{\text{error}} relative to the goal vector is less than \theta_{\text{crit}} (e.g., 30°) on the first transfer trial. Pure motor habit predicts systematic veering toward the compensated direction from the old start arm.
Verification: First-trial heading angle measured within 1 second of release.
Breakdown: If the novel start arm places the rat outside the previously explored \mathcal{X} (configuration space), the spatial hierarchy \mathcal{H} has no defined map region, and the prediction is invalid by domain restriction.
