**Set definitions and identities**
\[
S = \{ E \triangle N : E \in \mathcal{S},\ N \subseteq A,\ A \in \mathcal{S},\ \mu(A)=0 \}.

Alternatively,
\[
S = \{ E \cup N : E \in \mathcal{S},\ N \subseteq A,\ A \in \mathcal{S},\ \mu(A)=0 \}.
\]
The second form follows because for any \(N \subseteq A\), we have \(E \cup N = E \triangle (A \setminus N)\) and \(A \setminus N\) is still a null set if \(N \subseteq A\).

**Completion operation**
The extended measure \(\overline{\mu}: S \to [0,\infty]\) is defined by
\[
\overline{\mu}(E \triangle N) = \mu(E).
\]
Well-definedness: If \(E_1 \triangle N_1 = E_2 \triangle N_2\), then \(\mu(E_1 \triangle E_2)=0\). Consequently, \(\overline{\mu}\) is additive on finite disjoint unions, and by monotone convergence, it is a complete measure.

**Key formal properties (verified from first principles)**

*σ-Ring property*:  
Closed under difference:  
Let \(X = E_1 \triangle N_1\), \(Y = E_2 \triangle N_2\) with \(E_i \in \mathcal{S}\) and \(N_i \subseteq A_i\), \(\mu(A_i)=0\).  
Then
\[
X \setminus Y = (E_1 \triangle N_1) \cap (E_2^c \triangle N_2^c) = (E_1 \cap E_2^c) \triangle (N_1 \cup N_2'),
\]
where \(N_2' = (N_2 \cap E_2^c) \cup (A_2 \cap E_1 \cap N_1)\) has \(\mu(N_2')=0\). Hence \(X \setminus Y \in S\).

Closed under countable union:  
Given \((X_n)_{n=1}^\infty\) in \(S\), write each \(X_n = E_n \triangle N_n\). Then
\[
\bigcup_{n=1}^\infty X_n = \left( \bigcup_{n=1}^\infty E_n \right) \triangle \left( \bigcup_{n=1}^\infty N_n \right).
\]
Since \(\bigcup_{n=1}^\infty E_n \in \mathcal{S}\) and \(\bigcup_{n=1}^\infty N_n\) is contained in \(\bigcup_{n=1}^\infty A_n\) (a null set), the union belongs to \(S\).

*Complete measure*:  
If \(X \in S\) and \(Y \subseteq X\) with \(\overline{\mu}(X)=0\), then \(Y \in S\). Indeed, write \(X = E \triangle N\) with \(\mu(E)=0\). Because \(\overline{\mu}(X)=\mu(E)=0\), we have \(Y \subseteq N \cup Z\) where \(Z\) is a null subset of \(E\). As \(N \cup Z\) is a null set in \(\mathcal{S}\), \(Y \in S\).

**Direct verification of cited lemmas**  

Lemma 1 (Well-definedness):  
If \(E_1 \triangle N_1 = E_2 \triangle N_2\) with \(N_i \subseteq A_i\) and \(\mu(A_i)=0\), then \(\mu(E_1 \triangle E_2)=0\). Hence \(\mu(E_1)=\mu(E_2)\), so \(\overline{\mu}\) is independent of the representation.

Lemma 2 (\(\sigma\)-additivity):  
Let \((X_k)\) be disjoint in \(S\); write \(X_k = E_k \triangle N_k\). Define
\[
B = \bigcup_{k=1}^\infty N_k \quad\text{(contained in } \bigcup_{k=1}^\infty A_k, \text{ a null set)},
\qquad
E = \bigcup_{k=1}^\infty E_k.
\]
Then \(\bigcup X_k = E \triangle B\). Moreover,
\[
\sum_{k=1}^\infty \overline{\mu}(X_k) = \sum_{k=1}^\infty \mu(E_k) = \mu(E),
\]
using the σ-additivity of \(\mu\) on \(\mathcal{S}\). Also, \(\mu(B)=0\), giving \(\overline{\mu}(E \triangle B)=\mu(E)\). Thus
\[
\overline{\mu}\left( \bigcup_{k=1}^\infty X_k \right) = \sum_{k=1}^\infty \overline{\mu}(X_k).
\]
