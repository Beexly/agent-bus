The method descends from a well-defined lineage. CLIP [1] and ALIGN [2] established zero-shot transfer via aligned image-text spaces [PAGE 1]. CoOp [8] replaced handcrafted prompts with learnable continuous embeddings, improving base accuracy but introducing two overfitting modes: base accuracy peaks then declines, and novel accuracy monotonically decays below zero-shot CLIP [PAGE 1, Fig. 1]. CoCoOp [9] attempted dynamic, image-specific prompts with a Meta-Net but still failed to prevent the late base drop and remained below zero-shot CLIP on novel classes (60.42% vs 69.05%) [PAGE 1, PAGE 7]. ProGrad [10] and VPT [11] added gradient-surgery and variational components without diagnosing the root cause, increasing computational burden [PAGE 3].

The theoretical substrate includes the No Free Lunch theorem [12, 13], which implies that without assumptions no learner generalizes across arbitrary distribution shifts; gradient flow theory [41–44] as a continuous limit of SGD; NTK linearization of wide networks [46]; and the low-dimensional trajectory hypothesis [45], which justifies PCA on checkpoint trajectories. The paper also cites gradient starvation [13] as a related learning proclivity.

Several multi-week traps are documented. Early stopping is unrealistic because few-shot settings lack a held-out validation set [PAGE 2]. Data augmentation is not robust across datasets [PAGE 2]. Training loss always decreases, so overfitting cannot be detected from training metrics alone [PAGE 2]. CoCoOp adds a Meta-Net but does not eliminate the spurious late gradient direction [PAGE 1]. SubPT breaks this sequence by explicitly measuring gradient-flow orthogonality and projecting updates onto the early eigensubspace, thereby removing spurious components without extra network parameters or validation data [PAGE 5–6].</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
Crisis habit regression refers to the model's recursive drift, in later epochs, toward spurious feature directions that are orthogonal to the early generalizable direction. The "crisis" is the overfitting collapse: base accuracy improves early, then worsens as the prompt optimizer repeatedly reinforces features that fit the few-shot base labels but do not transfer. This is a habit regression because each gradient step compounds the previous one in the wrong eigendirection.

The counter-trap is SubTP's projection operator U^\top U, applied at every back-propagation step. By constraining updates to the early-stage subspace, it recursively vetoes any component orthogonal to the trusted generalizable directions. The habit is not merely suppressed; the optimization dynamics are rerouted so that the later-stage spurious attractor becomes inaccessible.

The clock is t_{early}, the epoch boundary that defines which checkpoints enter the PCA subspace. If the clock is set too late (t_{early} equal to total training), the subspace absorbs the spurious trajectory and the counter-trap fails, reverting to CoOp behavior [PAGE 10, Table VII]. If set correctly (e.g., epoch 10 for 1-shot Caltech101), the clock preserves the generalizable manifold and blocks the late regression.

NFL introduces a second-order recursive loop: zero-shot CLIP acts as a teacher whose fixed text features supervise the learnable prompt features on novel categories through cosine similarity [PAGE 6, Eq. (7)]. This is a teacher-student recursion. When the teacher's prior is correct, novel generalization improves (novel accuracy rising from 58.75% to 66.91% averaged across datasets) [PAGE 7, Table II]. When the teacher is wrong—e.g., the Spyker C8 confusion [PAGE 12, Fig. 9]—the recursion injects error, and CoOp+SubPT+NFL inherits the teacher's mistake. Thus the system has two nested clocks: the training-epoch clock for SubPT and the teacher-reliability clock for NFL.</RECURSIVE_THEORY_OF_MIND>
