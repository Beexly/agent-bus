The source defines in-game win probability as “a statistical metric that provides a sports team’s likelihood of winning at any given point in a game, based on the performance of historical teams in the same situation” [PAGE 1]. The modeling target is therefore a conditional distribution over win, tie, and loss for the home team, given a game state \(x_t\). The paper immediately identifies the central difficulty: association football is low-scoring and tie-heavy, so “the construction of a good in-game win probability model [is] significantly harder” than in baseball, basketball, or American football [PAGE 2]. This is not a cosmetic difference. In a sport where “At each moment in time, a win or loss could be converted to a tie, and a tie could be converted to a win or a loss for one of both teams” [PAGE 3], a model that only classifies the eventual W/D/L label is fragile because the label space is highly sensitive to a single rare event.

The first multi-hop inference is that porting direct W/D/L classifiers from other sports is structurally mismatched. The paper tests a logistic regression model, multiple logistic regression classifiers, and a random forest model, then reports that “Only the Bayesian classifier has well calibrated win, draw and loss probabilities” [PAGE 7]. The random forest is not useless, but “the predictions for the probability of ties break down in late game situations. It never predicts a high tie probability” [PAGE 8]. The logistic and multiple-logistic models also struggle with tie probabilities [PAGE 8]. Thus the failure mode is not merely accuracy; it is calibration, especially in the draw class, which is exactly the class that football’s low-scoring structure makes dominant in close games.

The second multi-hop step is the paper’s decomposition. Instead of directly estimating \(P(\text{win}),P(\text{tie}),P(\text{loss})\), the Bayesian model estimates the future goals each team will score after time \(t\): \(y_{>t,\text{home}}\sim \mathcal{B}(T-t,\theta_{t,\text{home}})\) and \(y_{>t,\text{away}}\sim \mathcal{B}(T-t,\theta_{t,\text{away}})\) [PAGE 5]. The stated advantage is that “By estimating the likelihood of each possible path to a win-draw-loss outcome, our model can capture the uncertainty of the win-draw-loss outcome in close games” [PAGE 5]. A second advantage is momentum: “by modelling the number of future goals instead of the total score at the end of the game, our model can better cope with these changes in momentum that often happen after scoring a goal” [PAGE 5]. This is a genuine structural claim: the future-goal representation preserves goal-difference uncertainty instead of collapsing it into a three-way label.

The third step is the temporal process. The scoring intensities are not constant; the paper notes that “the importance of these game state features varies over time” and that “this variation is not linear, for example, because of a game’s final sprint” [PAGE 5]. Therefore \(\alpha_t\) is modeled as a random walk: \(\alpha_t\sim N(\alpha_{t-1},2)\), with intercept \(\beta\sim N(0,10)\) and home advantage \(H_a\sim N(0,10)\) [PAGE 6]. The stochastic-process view “allows sharing information and performing coherent inference between time frames” [PAGE 5], which matters for rare events such as a red card early in the match. The evaluation uses Ranked Probability Score and calibration curves on an external 2017/18 season [PAGE 6-8], and the paper reports that accuracy and RPS improve as the game progresses, while early frames are similar to an Elo-only pre-game model [PAGE 8].

The gray-zone audit must flag several assumptions. First, the two future-goal distributions are modeled as independent Binomials [PAGE 5]. Real football can induce correlated scoring via game state, red cards, tactical shifts, or open-game transitions; independence is a simplifying assumption, not a proven invariance. Second, the clock is normalized to \(T=100\) frames with halftime at 50 to handle stoppage time [PAGE 3], but stoppage time remains uncertain and is estimated with a random forest using game time, substitutions, cards, goals, injury time, and tension [PAGE 3]. Third, the feature set is deliberately small because “The addition of each variable increases the size of the state space exponentially and makes learning a well-calibrated model significantly harder” [PAGE 4]. Fourth, the feature interpretation contains a counterintuitive result: “winning more duels has a negative effect on the win probability, which is not what one would intuitively expect” [PAGE 9]. Fifth, the Elo prior’s effect becomes less certain over time: “For the pre-game Elo rating differential, mainly the uncertainty about the effect on the scoring rate increases during the game” [PAGE 9]. These are not fatal errors, but they are audit points: the model is a calibrated event-stream abstraction, not a full causal simulator of football.
</THINK_TRACE>

<SOURCE_OPERATORS_AND_EQUATIONS>
The source’s operators are probabilistic and temporal. Let \(T=100\) be the normalized game clock in time-frame units, with halftime at \(T=50\): “we split each game into T = 100 time frames, each corresponding to a percentage of the game. Halftime always corresponds to T = 50” [PAGE 3]. Let \(x_{t,i}\) be the feature vector for team \(i\in\{\text{home},\text{away}\}\) at frame \(t\). The outcome variable is \(Y\in\{\text{win},\text{tie},\text{loss}\}\) for the home team. Probabilities are dimensionless; goal counts are goals; \(T-t\) is a count of remaining time frames; \(\theta_{t,i}\) is a per-frame scoring probability and is dimensionless; \(\alpha_t\) is in logit units per feature unit; \(\beta\) and \(H_a\) are logit-scale intercepts.

The paper first presents a logistic-regression baseline as printed:
\[
P(Y=o\mid x_t)=\frac{e^{w^{T}x_t}}{1+e^{w^{T}x_t}},
\]
where \(Y\) is the dependent random variable representing win, tie, or loss for the home team, \(x_t\) is the game-state feature vector, and \(w\) is estimated from historic match data [PAGE 4]. The excerpt prints this in binary-logistic form rather than as a normalized three-class softmax; that is a source-level ambiguity worth noting.

The core generative operator is the future-goal model:
\[
y_{>t,\text{home}}\sim \mathcal{B}(T-t,\theta_{t,\text{home}}),\qquad
y_{>t,\text{away}}\sim \mathcal{B}(T-t,\theta_{t,\text{away}}),
\]
where \(y_{>t,i}\) is the number of goals team \(i\) scores after time \(t\), \(T-t\) is the number of remaining frames, and \(\theta_{t,i}\) is the team’s estimated scoring intensity in frame \(t\) [PAGE 5]. The paper states these are modeled “as independent Binomial distributions” [PAGE 5]. A derived W/D/L mapping, not printed as a separate equation in the excerpt, follows by conditioning on current scores \(S_h,S_a\):
\[
G_h\sim \operatorname{Bin}(T-t,\theta_{t,h}),\qquad
G_a\sim \operatorname{Bin}(T-t,\theta_{t,a}),
\]
\[
\Delta=(S_h-S_a)+(G_h-G_a),
\]
\[
P(\text{win}\mid x_t)=\sum_{g_h,g_a}\mathbf{1}\{S_h+g_h>S_a+g_a\}
\binom{T-t}{g_h}\theta_{t,h}^{g_h}(1-\theta_{t,h})^{T-t-g_h}
\binom{T-t}{g_a}\theta_{t,a}^{g_a}(1-\theta_{t,a})^{T-t-g_a},
\]
with analogous sums for \(\Delta=0\) and \(\Delta<0\). This derivation uses the independence assumption from Eq. (2) [PAGE 5]; it is a formal consequence, not an additional source equation.

The scoring intensities are:
\[
\theta_{t,\text{home}}=\operatorname{invlogit}(\alpha_t x_{t,\text{home}}+\beta+H_a),
\]
\[
\theta_{t,\text{away}}=\operatorname{invlogit}(\alpha_t x_{t,\text{away}}+\beta),
\]
\[
\alpha_t\sim N(\alpha_{t-1},2),\qquad
\beta\sim N(0,10),\qquad
H_a\sim N(0,10),
\]
where \(\alpha_t\) are regression coefficients, \(\beta\) is the intercept, and \(H_a\) models home advantage [PAGE 6]. The excerpt does not specify whether the second normal parameter is variance or standard deviation; this is a source ambiguity. The model was trained with “PYMC3’s Auto-Differentiation Variational Inference (ADVI) algorithm” and mini-batching [PAGE 6].

Evaluation uses Ranked Probability Score:
\[
\mathrm{RPS}_t=\frac{1}{2}\sum_{i=1}^{2}\left(\sum_{j=1}^{i}p_{t,j}-\sum_{j=1}^{i}e_j\right)^2,
\]
where \(p_t=[P(Y=\text{win}\mid x_t),P(Y=\text{tie}\mid x_t),P(Y=\text{loss}\mid x_t)]\), and \(e\) encodes the final outcome as win \(e=[1,1,1]\), tie \(e=[0,1,1]\), or loss \(e=[0,0,1]\) [PAGE 6-7]. RPS is dimensionless and lower is better.

The Added Goal Value operator is:
\[
\mathrm{AGV}_{p90_i}=
\frac{\sum_{k=1}^{K_i}\left(3\cdot\Delta P(\text{win}\mid x_{t_k})+\Delta P(\text{tie}\mid x_{t_k})\right)}{M_i}\cdot 90,
\]
where \(K_i\) is goals scored by player \(i\), \(M_i\) is minutes played, and \(t_k\) is the time of goal \(k\) [PAGE 11]. The unit is expected league points per 90 minutes: \(3\cdot\Delta P(\text{win})+\Delta P(\text{tie})\) is in points, and the division by minutes plus multiplication by 90 converts to points per 90.

Exact singularity/breakdown regimes:
1. \(\theta_{t,i}\to 0\) or \(1\): the logit \(\eta_{t,i}=\alpha_t x_{t,i}+\beta+H_a\) diverges, \(\operatorname{invlogit}(\eta)\) saturates, Binomial variance \((T-t)\theta(1-\theta)\to 0\), and calibrated probabilities collapse toward deterministic 0/1. Logistic gradients vanish in saturation.
2. \(T-t=0\) at the end of the match: the future-goal Binomial has \(n=0\), so \(G_h=G_a=0\) with probability one; the W/D/L map becomes deterministic given the current score. RPS and accuracy can look perfect for structural rather than inferential reasons.
3. \(\alpha_t\) random-walk divergence or drift: if the random walk accumulates large scale, \(\eta_{t,i}\) can become extreme, causing saturation and unstable late-game calibration. The source writes \(\alpha_t\sim N(\alpha_{t-1},2)\) but does not resolve variance-vs-scale in the excerpt [PAGE 6].
4. Independence violation: if \(G_h\) and \(G_a\) are positively or negatively correlated through game-state adaptation, the derived \(\Delta\) distribution has wrong variance and tie probability. The source explicitly assumes independent Binomials [PAGE 5], so this is a model-boundary, not a mathematical error.
5. Stoppage-time misestimation: \(T=100\) normalizes the clock, but the actual added time is estimated from features such as substitutions, cards, goals, injury time, and tension [PAGE 3]. If added-time behavior shifts, late-frame probabilities are miscalibrated.
6. Tie-class breakdown in competing models: the paper reports that the RF model “never predicts a high tie probability” in late-game situations [PAGE 8], a direct calibration singularity for the draw class.
7. State-space explosion: adding contextual features “increases the size of the state space exponentially” [PAGE 4], so over-featurization is a breakdown regime for calibration.
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
The scientific lineage runs from early score-progress modeling in baseball [PAGE 13, ref. 12] through WPA-style in-game probability in baseball, basketball, and American football [PAGE 1], to the 2018 World Cup emergence of public football win-probability predictions from FiveThirtyEight and Google [PAGE 2]. The paper’s Bayesian model is a retrocausal synthesis: it inherits Elo-based pre-game strength [PAGE 3, PAGE 6], RPS calibration from probabilistic football forecasting [PAGE 6], ADVI variational inference [PAGE 6], and Pettigrew-style added goal value from ice hockey [PAGE 11]. The future use cases also reach backward into model design: because the model estimates future goals, it can compute goal-by-goal changes in win probability for AGV [PAGE 11]; because it uses a temporal stochastic process, it can share information across frames and handle rare events [PAGE 5]; because it outputs calibrated W/D/L probabilities, it can support “story stat” fan engagement [PAGE 10] and “clutch” performance analysis [PAGE 11].

The multi-week traps are clear. Trap one: treating football as if it were basketball or American football and directly porting a W/D/L classifier. The paper shows this yields poor calibration, especially for ties [PAGE 8]. Trap two: treating the match as a fixed 90-minute clock. “Football games rarely last precisely 90 minutes” [PAGE 3], so a fixed-clock model mis-specifies late-game information. Trap three: optimizing only accuracy. A model can be accurate late because the score is already decisive while still being badly calibrated in the tie class; the paper’s calibration curves and RPS address this [PAGE 7-8]. Trap four: adding every available contextual feature. The paper warns that each variable expands the state space exponentially and makes calibration harder [PAGE 4]. Trap five: overinterpreting single-game probabilities. The paper explains that an 8% win probability means that across many games from that state, about eight of a hundred would be won; it cannot be validated on one game [PAGE 7-8]. Trap six: assuming feature effects are stable across the match. The paper finds that goals, yellows, and attacking passes increase in effect over time, while red cards and duel strength have larger first-half effects [PAGE 9]. These traps are not merely historical; they are recurring failure modes for any later model that tries to compress football into a generic in-game probability template.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
The paper does not explicitly formalize recursive opponent modeling, but its own limitations imply it. The model treats home and away future goals as independent Binomials [PAGE 5]. In real football, a team’s belief about the opponent’s response changes its own behavior: after scoring, a team may sit deeper, press higher, or bait the opponent into overcommitting. The source acknowledges that goals “often change the subsequent ebb and flow of the game in terms of how space opens up and who dominates the ball – and where they do it” [PAGE 3]. That is a theory-of-mind loop: my action depends on my belief about your reaction, which depends on your belief about my action.

Crisis habit regression appears when pressure causes teams to revert to pre-game strength and habitual defensive or direct-play patterns. The model captures part of this through the Elo rating differential, which is “the prior estimated difference in strength with the opponent” [PAGE 3], and through time-varying feature importance: early in the game, prior strength is most informative; near the end, in-game performance matters more [PAGE 5]. But if crisis causes a nonlinear reset—e.g., a team abandons its shape after conceding—the \(\alpha_t\) random walk may lag the behavioral shift, because it shares information across frames rather than instantaneously re-identifying a new tactical regime.

The counter-trap is the strategic inversion: a team that appears to be attacking may be leaving space intentionally; a team that appears to be defending may be inviting pressure to counter. The model’s “Attacking Passes” and “Duel Strength” features are rolling averages over the previous 10 time frames [PAGE 4], so they are performance proxies, not mental-state inferences. They can capture “how effective teams are at regaining possession” [PAGE 4], but not whether the opponent is deliberately conceding possession as a trap. This is a recursive-theory-of-mind gap, not a bug in the probability math.

The clock is the third layer. Time pressure changes risk tolerance: trailing teams accept more defensive risk, leading teams protect space. The model normalizes the clock to \(T=100\) and sets halftime at 50 [PAGE 3], and it notes that feature effects vary nonlinearly, “for example, because of a game’s final sprint” [PAGE 5]. But stoppage time is uncertain [PAGE 3], so the clock itself is a belief variable. A recursive model would need to represent each team’s belief about remaining time and about the opponent’s belief about remaining time. The source’s random-forest stoppage-time estimator [PAGE 3] is a statistical correction, not a strategic game-theoretic clock. Thus the paper’s model is best interpreted as a calibrated reduced-form approximation: it captures crisis-habit regression through Elo and rolling performance, and it captures clock effects through normalized time and temporal weights, but it does not close the recursive counter-trap loop.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The physical/biomechanical/weather veto is provable by feature enumeration. The paper states the model “uses eight features for each team” [PAGE 12]. The listed variables are: Game Time, Score Differential, Rating Differential, Team Goals, Yellows, Reds, Attacking Passes, and Duel Strength [PAGE 3-4]. There is no weather variable, no temperature, no precipitation, no wind, no pitch-condition variable, no player-tracking load, no sprint-distance variable, no acceleration/deceleration load, no heart-rate or metabolic proxy, and no biomechanical joint-load variable. The two performance proxies are explicitly event-stream constructs: “Attacking Passes: A rolling average of the number of successfully completed attacking passes (a forward pass ending in the final third of the field) during the previous 10 time frames” and “Duel Strength: A rolling average of the percentage of duels won in the previous 10 time frames” [PAGE 4]. Those are not physical-load measurements.

The stoppage-time estimator also does not rescue a physical layer. It uses “the current game time, the number of substitutes, the number of yellow and red cards, the number of goals scored, the time lost due to injuries and whether the game is tense” [PAGE 3]. “Time lost due to injuries” is a clock-adjustment feature, not a biomechanical diagnosis. Home advantage is modeled as a scalar \(H_a\sim N(0,10)\) [PAGE 6], not as a physiological or environmental mechanism.

Therefore the cross-layer veto is: any claim that this model proves a weather effect, a biomechanical fatigue effect, or a physical-load causal mechanism is vetoed by the source’s own feature set. The model can support claims about event-stream performance, score state, cards, Elo prior, and rolling pass/duel proxies. It cannot adjudicate whether rain reduced passing accuracy, whether accumulated sprint load changed duel success, or whether temperature altered late-game intensity. Those are outside the identifiable layer. If a later analyst adds weather or biomechanical variables, that is a new model, not a proof from this paper. The correct adjudication is layer separation: the source’s probabilities are conditional on \(x_t\) as defined [PAGE 3-4], and no physical/weather variable is in that conditioning set.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Scenario 1 — Direct W/D/L classifier replacement. Intervention: replace the Bayesian future-goal model with the paper’s direct logistic-regression or multiple-logistic W/D/L classifier [PAGE 4]. Prediction: tie-class calibration degrades, especially late; the calibration curve for ties deviates from the diagonal, and RPS increases relative to the Bayesian model. This is verifiable on the 2017/18 test set using the paper’s calibration curves and RPS [PAGE 7-8]. Veto condition: if the direct classifier matches the Bayesian model’s tie calibration and RPS, the claim that future-goal decomposition is necessary is vetoed.

Scenario 2 — Fixed 90-minute clock. Intervention: remove the \(T=100\) normalized clock and the stoppage-time random forest [PAGE 3], forcing every match into a fixed 90-minute frame. Prediction: late-frame calibration and RPS degrade disproportionately for matches with large actual added time, because the model misallocates remaining time. Verification: stratify the 2017/18 test set by actual added time; compare late-frame calibration and RPS between the fixed-clock and \(T=100\) models. Veto condition: if fixed-clock late-frame calibration is statistically indistinguishable from the normalized-clock model across added-time strata, the stoppage-time operator is not earning its complexity.

Scenario 3 — Constant scoring intensity. Intervention: set \(\theta_{t,i}=\operatorname{invlogit}(\alpha x_{t,i}+\beta+H_a)\) with a single time-invariant \(\alpha\), removing the random walk \(\alpha_t\sim N(\alpha_{t-1},2)\) [PAGE 6]. Prediction: the model cannot capture the source’s claim that “the importance of these game state features varies over time” and that “this variation is not linear, for example, because of a game’s final sprint” [PAGE 5]; late-game RPS worsens, and the estimated feature-weight traces become flat rather than time-varying. Verification: compare RPS by time frame and inspect the \(\alpha_t\) traces against Figure 3’s time-varying weights [PAGE 9]. Veto condition: if the constant-intensity model produces the same late-frame RPS and the same time-varying weight pattern, the temporal stochastic process is not supported by the evidence.

A fourth optional veto, if space allows, is Elo ablation: remove Rating Differential and predict early-frame performance drops toward a non-informative baseline, because the paper reports that early frames are similar to an Elo-based pre-game model [PAGE 8] and that Elo has a positive impact on scoring rate [PAGE 9]. Verification is early-frame RPS/accuracy. Veto if early-frame performance is unchanged. These counterfactuals are verifiable because each maps to a reported metric—calibration, RPS, or feature-weight trace—rather than to a subjective narrative.
