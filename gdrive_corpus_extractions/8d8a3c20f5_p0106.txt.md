**Definitions:**
Let $(X, \mathcal{M}, \mu)$ be a measure space, $E \in \mathcal{M}$ with $\mu(E) < \infty$. Let $f, f_n: E \to \mathbb{R}$ be measurable functions.
For $\epsilon > 0$, define:

E_n(\epsilon) := \{ x \in E : |f_n(x) - f(x)| \ge \epsilon \}.
\]
Units: If $f_n$ represent quantities with dimension $[Q]$, then $|f_n-f|$ has dimension $[Q]$, and $\epsilon$ must have same dimension. $\mu$ typically has dimension of length, area, or probability (dimensionless). The condition $|f_n-f| \ge \epsilon$ is dimensionally consistent.

**Theorem A (Halmos):**
\[
f_n \xrightarrow{a.e.} f \quad \Longleftrightarrow \quad \forall \epsilon > 0, \; \mu\left( E \cap \limsup_{n\to\infty} E_n(\epsilon) \right) = 0,
\]
where 
\[
\limsup_{n\to\infty} E_n(\epsilon) = \bigcap_{N=1}^\infty \bigcup_{n=N}^\infty E_n(\epsilon) = \{ x : x \in E_n(\epsilon) \text{ for infinitely many } n \}.
\]

**Proof Decomposition:**
1. **Pointwise Divergence Criterion:**  
   $x \notin \{ f_n \to f \} \iff \exists \epsilon > 0 \text{ s.t. } \forall N, \exists n \ge N \text{ with } |f_n(x)-f(x)| \ge \epsilon \iff \exists \epsilon > 0 \text{ s.t. } x \in \limsup_{n\to\infty} E_n(\epsilon)$.  
   Let $D = \{ x : f_n(x) \not\to f(x) \}$. Then $D = \bigcup_{k=1}^\infty \limsup_{n\to\infty} E_n(1/k)$.

2. **Measure Zero Condition:**  
   $f_n \to f$ a.e. on $E$ $\iff \mu(E \cap D) = 0$.  
   Since $D$ is a countable union, $\mu(E \cap D) = 0 \iff \forall k, \mu(E \cap \limsup_{n\to\infty} E_n(1/k)) = 0$.  
   As $\epsilon \mapsto \limsup E_n(\epsilon)$ is monotone decreasing, it suffices to have $\forall \epsilon > 0$, $\mu(E \cap \limsup_{n\to\infty} E_n(\epsilon)) = 0$.

3. **Continuity from Above (Key Step):**  
   Define $A_N(\epsilon) = \bigcup_{n=N}^\infty E_n(\epsilon)$. Then $A_N(\epsilon) \downarrow \limsup_{n\to\infty} E_n(\epsilon)$ as $N \uparrow \infty$.  
   Since $\mu(E) < \infty$, we have $\mu(E \cap A_1(\epsilon)) \le \mu(E) < \infty$, so by continuity of measure from above:
   \[
   \mu\left( E \cap \limsup_{n\to\infty} E_n(\epsilon) \right) = \lim_{N\to\infty} \mu\left( E \cap \bigcup_{n=N}^\infty E_n(\epsilon) \right).
   \]
   Thus, the theorem is equivalent to:
   \[
   f_n \xrightarrow{a.e.} f \iff \forall \epsilon > 0, \; \lim_{N\to\infty} \mu\left( \left\{ x \in E : \sup_{n \ge N} |f_n(x)-f(x)| \ge \epsilon \right\} \right) = 0.
   \]

**Convergence in Measure:**
\[
f_n \xrightarrow{\mu} f \iff \forall \epsilon > 0, \; \lim_{n\to\infty} \mu(E_n(\epsilon)) = 0.
\]
Note that $E_n(\epsilon) \subseteq \bigcup_{k=N}^\infty E_k(\epsilon)$ for $n \ge N$, so convergence a.e. implies convergence in measure when $\mu(E)<\infty$.

**Fundamental in Measure:**
A sequence $\{f_n\}$ is fundamental in measure if:
\[
\forall \epsilon > 0, \; \lim_{m,n\to\infty} \mu\left( \{ x : |f_n(x)-f_m(x)| \ge \epsilon \} \right) = 0.
\]
This is equivalent to the Cauchy criterion in the metric $d(f,g) = \int \frac{|f-g|}{1+|f-g|} d\mu$, which metrizes convergence in measure on finite measure spaces.
