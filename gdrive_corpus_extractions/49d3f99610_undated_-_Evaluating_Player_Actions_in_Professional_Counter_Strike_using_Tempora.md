<THINK_TRACE>
The source’s inference chain is: replay parsing → virtual-state graph → temporal graph classification → per-snapshot defender win probability → post-hoc Shapley decomposition of probability changes into player-action contributions. The first hop is data construction: professional CS2 demos from S-tier events from October 2023 to September 2024 are parsed at four snapshots per second on the map Inferno, yielding 114 matches [PAGE 2]. The second hop is spatial representation: the map is manually discretized into smoke-sized nodes, with undirected edges only where player movement is possible in both directions [PAGE 3]. The third hop is heterogeneous graph snapshots: map nodes and player nodes receive different feature sets, player nodes are attached to the nearest map node, and graph-level variables include remaining time, bomb state, alive counts, team health, equipment value, and the defender-win label [PAGE 4]. The fourth hop is temporalization: 20 consecutive snapshots are concatenated into a 5-second dynamic graph, with a 2.5-second offset augmentation, producing “approximately 90.000 DTDGs” [PAGE 4]. The fifth hop is THGNN classification: spatial convolutions are followed by GraphGRU temporal layers and dense outputs, with the best model using “single-headed Graph Attention (GAT) convolution for each subconvolution” and “two heterogeneous convolution layers, followed by three map-to-map convolution layers” [PAGE 7]. The sixth hop is explanation: the paper defines \(\Delta W(t-1,t)\), decomposes it into action-level \(\delta W\), then uses Shapley values and a local ridge explainer to distribute attributed probability change back to state-describing features [PAGE 9-10].

The gray-zone audit begins at causality. The paper says “Player actions are the primary drivers in the win probability changes” [PAGE 9], but the implemented object is a predictive model plus a local attribution model, not an identified structural causal model. The Shapley values explain the local explainer’s output over observed feature changes, not an intervention in the game. Thus “impact” is associative-retrocausal unless counterfactual ablations validate it. A second gray zone is equation 4.3: the normalization by \(\sum_f |S_f|\) has an exact singularity when all Shapley magnitudes are zero; then the action impact is undefined, and a zero convention is a convention, not identification. A third gray zone is the 2-second post-death window: the paper correctly states “A player eliminated during the round cannot impact the win probability after their death” [PAGE 10], yet allows a 2-second attribution window, which is defensible for delayed effects but not a physical impossibility proof. A fourth gray zone is the intentionally overfit ridge explainer: “Ridge regression models with \(\alpha\) values of 0.1 were employed, intentionally overfitting the datasets” [PAGE 10]. That improves local fidelity to the GNN but can also fit noise. A fifth gray zone is evaluation leakage: the source reports strong metrics and calibration but does not, in the supplied text, specify a match-level or temporal holdout; overlapping 5-second windows with 2.5-second offsets create dependent samples, so random window splits can inflate accuracy, AUC, and ECE. A sixth gray zone is scope: one map, Inferno; near-balanced classes at “approximately 50.5%” CT and “49.5%” T [PAGE 5]; no cross-map, cross-patch, or cross-meta validation is shown. A seventh gray zone is layer mismatch: the feature set contains virtual state, weapons, health, positions, velocities, and grenade trajectories [PAGE 2], but not reaction time, biomechanics, weather, or external environment. Any claim crossing those layers is out-of-model, not merely uncertain. Finally, the paper’s use-case examples are existence proofs of plausible explanations, not population estimates: siuhy’s opening kill at “15%” [PAGE 11], frozen’s defuse at “+25%” [PAGE 12], a held incendiary at “nearly 5%” [PAGE 14], and Stewie2K’s opening kill at “nearly +30%” [PAGE 15] show context sensitivity, but they also show that identical event types can carry very different attributed values. That is the central audit finding: the framework is a high-resolution retrospective attribution instrument, not a causal simulator or a cross-layer physical model.

<SOURCE_OPERATORS_AND_EQUATIONS>
Formal graph operators. The map graph is \(G_{\mathrm{map}}=(V,E)\), with node feature vector \(\mathbf{x}_{v_i}=(X,Y,Z,\mathbf{1}_{\mathrm{fire}},\mathbf{1}_{\mathrm{smoke}})^{\top}\). The source’s design principle is that “each node \(v_i \in V\) should represent an area approximately the size of a smoke grenade’s coverage” [PAGE 3], and “An undirected edge \(e_{ij} \in E\) connects nodes \(v_i\) and \(v_j\) if player movement is possible between them in both directions” [PAGE 3]. Assumption: smoke-area quantization is a sufficient spatial resolution. Breakdown regime: sub-smoke geometry, vertical stacking, or one-way drops are unresolved; if a claimed action depends on a path not in \(E\), the physical map operator vetoes it. Positions, velocities, and map coordinates are in engine/game units, not SI; the source gives no SI conversion, so no fabricated metre or m/s conversion is valid.

Static heterogeneous snapshot operator. A snapshot is \(G_t=(V_{\mathrm{map}}\cup V_{\mathrm{player}},E_{\mathrm{map-map}}\cup E_{\mathrm{player-map}}\cup E_{\mathrm{player-player}})\), with player features including “X, Y, Z coordinates, velocity, view direction, weapons carried and equipped, health points,” match statistics, and prior-year performance metrics; the player feature count “exceeds 160” [PAGE 4]. Graph-level variables include remaining time \(\tau_t\) in seconds, bomb-planted indicator and coordinates, alive counts, total team health, team equipment value, and the label \(y_t\in\{0,1\}\) for defender round win [PAGE 4]. Assumption: the nearest map node is a sufficient attachment operator. Breakdown regime: players between smoke-sized nodes, or in vertical spaces not represented by the nearest-node projection, are mislocalized; equipment value is in game currency with no SI conversion stated.

Temporal operator. The dynamic graph is \(D_t=(G_{t-19},\ldots,G_t)\). With four snapshots per second, \(\Delta t=0.25\,\mathrm{s}\), and the window span is \(20\Delta t=5.0\,\mathrm{s}\). The source says “concatenating 20 consecutive snapshots along the temporal axis to form 5-second time windows” and uses a “2.5-second temporal offset” [PAGE 4]. Assumption: a 5-second history is sufficient for round-level win-probability state. Breakdown regime: delayed utility, fake executes, or rotates longer than 5 seconds are truncated; overlapping windows with 2.5-second offset create dependent samples, so i.i.d. calibration and test assumptions are not automatic.

THGNN operator. The model outputs defender win probability per snapshot: \(f_{\theta}(D_t)=(\hat y_{t-19},\ldots,\hat y_t)\), where \(\hat y_i=\Pr(y_i=1\mid D_t)\). The paper frames this as “a binary graph classification problem” with defender-win probability outputs at each snapshot [PAGE 5-6]. A standard binary cross-entropy loss is \(\mathcal{L}(\theta)=-\frac{1}{N}\sum_{n=1}^{N}\left[y_n\log \hat y_n+(1-y_n)\log(1-\hat y_n)\right]\), reported as “Log-Loss” [PAGE 7]; if natural logarithms are used the unit is nats, if base-2 then bits, but the source does not specify the base. AUC, F1, and accuracy are dimensionless. The best reported model has log-loss \(0.4587\), F1 \(0.7463\), and AUC \(0.8549\) [PAGE 7], with “accuracy exceeding 76%” [PAGE 1]. Calibration is asserted: the model “probabilities are well-calibrated” and have “low Expected Calibration Error” [PAGE 8]. A standard ECE is \(\mathrm{ECE}=\sum_{m=1}^{M}\frac{|B_m|}{n}\left|\mathrm{acc}(B_m)-\mathrm{conf}(B_m)\right|\), dimensionless; it breaks down when bins \(B_m\) are empty or sparse.

Spatial convolution operator. A heterogeneous layer applies an ordered sequence: player self-loop embedding, player-to-map propagation, then map-to-map propagation. Schematically, \(\mathbf{h}'_{p}=\phi_{\mathrm{self}}(\mathbf{h}_{p},\sum_{q\in N_{\mathrm{self}}(p)}\mathbf{W}_{\mathrm{self}}\mathbf{h}_{q})\), \(\mathbf{m}'_{v}=\phi_{\mathrm{p2m}}(\mathbf{m}_{v},\sum_{p\in N_{\mathrm{p2m}}(v)}\mathbf{W}_{\mathrm{p2m}}\mathbf{h}'_{p})\), and \(\mathbf{m}''_{u}=\phi_{\mathrm{m2m}}(\mathbf{m}'_{u},\sum_{v\in N_{\mathrm{m2m}}(u)}\mathbf{W}_{\mathrm{m2m}}\mathbf{m}'_{v})\). The best model uses single-headed GAT, so the propagation weights are attention-normalized. The paper describes the intuition as “players are the primary sources of all changes in win probability” [PAGE 6]. Breakdown regime: if player-to-map attachment is wrong or map edges are degree-preserving but physically invalid, the convolution can propagate over impossible geometry.

Explanation operators. Let \(W(t)\in[0,1]\) be the estimated defender win probability at timestamp \(t\). The source’s Eq. 4.1 is \(\Delta W(t-1,t)=W(t)-W(t-1)\), in probability units per \(\Delta t\) [PAGE 9]. Eq. 4.2 is, in standard notation, \(\Delta W(t-1,t)=\sum_{p=1}^{n_p}\sum_{a=1}^{n_{p,[t-1,t]}}\delta W_{a,p}^{[t-1,t]}\), where \(p\) indexes players and \(a\) indexes actions between timestamps \(t-1\) and \(t\) [PAGE 9]. Assumption: additive separability of action effects. Breakdown regime: simultaneous actions, interactions, strategic complementarities, and unobserved actions violate additivity. Eq. 4.3 is, in standard notation, \(\delta W_{a,p}^{[t_1,t_2]}=\frac{S_{f_a}}{\sum_{f}|S_f|}\Delta W(t_1,t_2)\), where \(S_{f_a}\) is the Shapley value of the feature representing action \(a\), and \(\sum_f|S_f|\) is the sum of absolute Shapley values over features [PAGE 10]. Exact singularity: if \(\sum_f|S_f|=0\), Eq. 4.3 is undefined; setting the contribution to zero is a convention. The Shapley operator is \(\phi_i(v)=\sum_{S\subseteq F\setminus\{i\}}\frac{|S|!(|F|-|S|-1)!}{|F|!}\left[v(S\cup\{i\})-v(S)\right]\), in probability units if \(v\) is the local probability function; it is exponential in feature count and is applied here to a ridge local explainer, not to the original game’s causal mechanism. Filtering conditions: “A player eliminated during the round cannot impact the win probability after their death” with a 2-second allowance [PAGE 10], and “If a state-describing feature does not change during the analyzed interval, its contribution to the win probability is zero” [PAGE 10]. Breakdown regimes: post-death deliberate sacrifice, feature quantization to zero change, and local explainer misspecification all make the attribution non-identified.

<RETROCAUSAL_GENEALOGY>
The genealogy runs from tabular win-probability models to graph-temporal attribution. The paper explicitly builds on Xenopoulos et al., whose XGBoost model used “tabular data representing game state” and proposed “Win Probability Added (WPA)” [PAGE 16]. The source says: “Our solution improves upon the previous approach by using THGNNs to capture both the spatial structure of the map and temporal patterns in player actions” [PAGE 16]. The scientific lineage is thereby: sports win-probability models → esports WPA → dynamic graph learning → GraphGRU/GAT → Shapley-based post-hoc attribution. The retrocausal move is that the action’s “value” is assigned after the round outcome and after the model’s probability path are observed: \(\delta W_{a,p}\) is computed from \(\Delta W\) and local Shapley values, so the explanation is a retrospective accounting of probability movement, not a pre-registered causal effect. That is useful for film review, but it is not equivalent to an intervention such as “if player \(p\) had not thrown the smoke, the round-win probability would have been \(q\).”

Multi-week traps appear when this framework is used repeatedly across a season. First, single-map overfitting: the dataset is 114 matches on Inferno [PAGE 2], so a team that generalizes weekly conclusions to all maps is overreaching. Second, meta drift: the data window is October 2023 to September 2024 [PAGE 2], and CS2 patches, map pools, utility lineups, and opponent tendencies change; a Shapley value learned in one meta week is not stationary. Third, dependence leakage: 5-second windows with 2.5-second offset [PAGE 4] overlap heavily; if train/test splits are by window rather than by match or round, repeated near-duplicates inflate metrics. Fourth, explainer overfitting: the ridge explainer is deliberately overfit with \(\alpha=0.1\) “to replicate the GNN’s predictions as closely as possible for the selected round” [PAGE 10]; across weeks, that can turn one-off noise into a scouting narrative. Fifth, post-hoc rationalization: the paper’s examples are selected to align with broadcast intuition, which is a useful sanity check but not an unbiased sample of all events. Sixth, calibration drift: the reported low ECE [PAGE 8] is a static evaluation; weekly deployment requires recalibration as team styles and map pools shift. The correct genealogical reading is therefore not “the model discovered the causal value of an action,” but “the model produced a temporally conditioned probability path and a local attribution that is credible only when validated against held-out matches, causal ablations, and domain review.”
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
The paper’s features encode observable state, not explicit beliefs. Yet its best examples are belief-and-counterbelief stories. In a crisis, “crisis habit regression” means a team under clock and health pressure reverts to rehearsed defaults: default site execute, default retake, default utility. The THGNN can detect the probability signature of that regression because it sees remaining time, alive counts, positions, utility, health, and bomb state [PAGE 4]. The recursive theory-of-mind layer is that players are modeling opponents’ models: attacker believes defender will rotate; defender believes attacker believes the rotate is late; both act on nested expectations. The model only sees the resulting state trajectory, so its Shapley values can identify which observable feature change coincided with the probability shift, but not which nested belief caused it.

Counter-trap logic is visible in the source’s smoke example. An attacker smoke lands at A-long; the defender immediately throws a smoke at middle; the framework recognizes the threat and the counter, and “the win probability does not change” because the defender balances the probabilities [PAGE 14]. That is a recursive counter-trap: the defender models the attacker’s map-control plan and negates it. The clock is equally explicit: remaining time is a graph-level variable [PAGE 4], and the frozen 1v2 clutch example shows a “5 second long defuse” boosting defender chances by “+25%” before the defuse is interrupted [PAGE 12]. The clock changes the value of the same action: holding an incendiary is worth “nearly 5%” when four attackers are nearby and a push is plausible [PAGE 13-14], because the utility is a threat that buys time; the same utility in a different clock and belief state may be worth less. Crisis habit regression versus counter-trap is therefore not a binary label the model outputs. It is an interpretive overlay: regression is the default policy under pressure; counter-trap is the opponent’s higher-order response to that default; clock is the pressure variable that changes both. The paper’s context-dependent opening kills support this: siuhy’s opening kill is “+15%” [PAGE 11], Stewie2K’s is “nearly +30%” [PAGE 15], Boombl4’s is “+17%” [PAGE 15], and nexa’s is “+22%” [PAGE 15]. Same event class, different recursive game state. A valid use of the framework must therefore report the clock, utility, equipment, and positional context alongside the attributed percentage; otherwise it mistakes a state-conditioned belief effect for a universal action value.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The source’s admissible feature set is virtual-state, not multi-layer physical. It includes “positions, velocities, weapons, inventories and health points” and “grenade trajectories” [PAGE 2]; graph-level variables include remaining time, bomb state, alive counts, team health, and equipment value [PAGE 4]. It does not include reaction time, mouse kinematics, fatigue, heart rate, posture, ground reaction force, weather, temperature, altitude, or network jitter. Therefore, a cross-layer claim is admissible only if it can be expressed as a function of the source features and the map graph.

Physical veto proof. Let \(C_{\mathrm{phys}}\) be a claim that a player moved or affected play through a path \(v_i\to v_j\). The map graph admits only undirected edges where “player movement is possible between them in both directions” [PAGE 3]. If the claimed path is not in \(E\), or if it requires sub-smoke resolution below the node size “approximately the size of a smoke grenade’s coverage” [PAGE 3], then \(C_{\mathrm{phys}}\) is vetoed: the graph operator cannot represent it. Grenade trajectories are present [PAGE 2], so ballistic claims must be checked against those trajectories; a Shapley attribution to an unobserved grenade path is not evidence.

Biomechanical veto proof. Let \(C_{\mathrm{bio}}\) be a claim about reaction time, aim biomechanics, fatigue, or motor learning. The source uses “Only state-describing features” for event explanations, “as these are directly or indirectly influenced by player decisions” [PAGE 10]. There is no biomechanical channel in the feature vector. Formally, if \(x_{\mathrm{bio}}\notin F_t\), then the Shapley value \(\phi_{x_{\mathrm{bio}}}\) is undefined; any nonzero biomechanical attribution is model misspecification. The correct inference is limited to observable virtual actions, not their neuromuscular causes.

Weather and external-environment veto proof. CS2 is a virtual indoor environment; the source contains no meteorological covariate and no indoor/outdoor weather variable. A claim that weather, temperature, or altitude changed the round probability is therefore outside the model’s support. The only external-environment variables that could be defended are explicit match metadata such as LAN/online status or network conditions, and the supplied text does not list them. Thus weather claims are vetoed by feature-set exclusion, not by a negative empirical result. The adjudication rule is: if a proposed explanation requires a variable absent from \(F_t\), the correct output is “not adjudicable by this framework,” not a zero or a guessed attribution.
