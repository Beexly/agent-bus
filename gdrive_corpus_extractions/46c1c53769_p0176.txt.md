If W_{t+1} is not 𝓕_t-measurable, then any decision D_t depending on W_{t+1} has D_t⁻¹(B) ∉ 𝓕_t for some Borel B. Veto proof: assume D_t is 𝓕_t-measurable and D_t = φ(X_t, W_{t+1}); since W_{t+1} is independent of (or at least not determined by) 𝓕_t, there exist ω, ω' with same 𝓕_t but different W_{t+1} and different φ values, violating measurability. Unit mismatch across layers (e.g., comparing Pa to mⁿ without a dimensioned coupling) is itself a veto if no measurable, unit-consistent transformation exists.

Adjudication rule: a cross-layer action is permitted only if every intermediate transformation is measurable on its domain σ-algebra, injective where a functional inverse is assumed, and composition-compatible (range of upstream layer ⊆ domain of downstream layer). Any violation in any layer triggers a hard veto before any output is emitted.
