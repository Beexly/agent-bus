The formal test is whether F(W) differences survive adjustment for biomechanical load; if they do not, the physical layer dominates.

Weather veto. Rain, wind, and surface conditions alter P_ij and therefore W_ij. If P_ij falls, shortest-path costs l_ij = 1/W_ij rise, λ₁ falls, clustering can change, and λ̃₂ can collapse toward zero if the graph fragments. Singularity: if P_ij = 0 for enough edges, the network becomes disconnected, p_ij = ∞, d is undefined, and λ̃₂ = 0. A weather-stratified replication should test whether the FCB signature persists within rain/wind strata; if it disappears or reverses, the network signature is not a stable topological claim. The source cannot perform this adjudication because weather is absent. The honest conclusion is therefore a veto obligation, not a proof: the paper establishes a completed-pass network description, while physical, biomechanical, and weather explanations remain live alternative hypotheses.

RLVR-style verifiable-reward counterfactuals are useful because each can be scored against pre-registered predictions using the same Opta event data. Reward = 1 if the prediction is confirmed, 0 otherwise; no subjective tactical labels are required.

1. Pass-count-matched downsampling veto. Counterfactual: randomly subsample FCB’s completed passes to the opponent’s pass count per match, or use fixed 50-pass windows [PAGE 6], then recompute C, d, λ₁, and λ̃₂. Prediction: if FCB’s average-network advantages are mostly a quantity effect, the C and λ₁ advantages should attenuate and the d advantage should shrink when pass counts are matched; if the advantages persist, the topology interpretation survives. Verifiable criterion: bootstrap confidence intervals for the matched contrast; veto the “topology” claim if the matched effect is indistinguishable from zero.

2. Goal-label placebo veto. Counterfactual: relabel non-goal moments matched on minute and score state as placebo “goals,” then compute the same pre-event network metrics. Prediction: true pre-goal FCB signatures—such as dispersion increase before receiving a goal [PAGE 7, PAGE 10], λ₁ increase before receiving a goal, and λ̃₂ decrease before receiving a goal [PAGE 10]—should differ from placebo windows. Verifiable criterion: permutation test comparing true event windows to matched placebo windows. If the distributions overlap, the event-specific causal interpretation is vetoed; the shifts are clock or score-state artifacts.

3. Environmental/physical stratification veto. Counterfactual: join match-level weather (rain, wind, temperature), pitch dimensions, rest days, travel, and player-tracking load; stratify or inverse-probability-weight by completion conditions. Prediction: if FCB’s network signature is robust, the higher C and λ₁, lower d, and higher advance ratio should persist within weather and load strata; if the signature disappears, the physical/weather veto is confirmed. Verifiable criterion: pre-registered stratified effect estimates with FDR control, following the source’s multiple-comparison caution [PAGE 14]. A further prediction is that advance ratio and centroid x-position will be more sensitive to pitch normalization than C or d, because the former are geometric while the latter are topological; if that ordering fails, the geometric interpretation is vetoed.
