Let $T_i$ be the duration random variable for sponsorship $i$, measured in quadrennials $q$ where $1q = 4$ years. Let $d_j$ be the number of sponsorships ending in interval $j$, and $n_j$ the number at risk at the start of interval $j$.

Survivor function (Kaplan–Meier product-limit):
\[
\hat{S}(t) = \prod_{t_j \le t} \left(1 - \frac{d_j}{n_j}\right), \quad S(t) = \Pr(T_i > t).
\]
Units: dimensionless probability in $[0,1]$. Source: Singer & Willett (2003) as quoted on [PAGE 1].

Discrete-time hazard:
\[
h_j = \Pr(T_i = j \mid T_i \ge j) = \frac{d_j}{n_j}.
\]
Units: events per quadrennial, dimensionless conditional probability.

Cumulative hazard:
\[
\hat{H}(t) = \sum_{t_j \le t} h_j, \quad \text{reported } \hat{H}(1) = 0.1977.
\]
Exact per-interval termination probability: $p_j = 1 - e^{-h_j}$. For $h=0.1977$, $p \approx 0.1795$. The paper’s interpretation of 0.1977 as 19.77% is a linear approximation valid only when $h \ll 1$. Breakdown/singularity: if $h_j \ge 1$ or $\hat{H}(t) \gtrsim 1$, $1 - e^{-H}$ saturates and the linear reading fails.

Median lifetime:
\[
t_{\text{med}} = \inf \{t : \hat{S}(t) \le 0.5\}.
\]
Reported $t_{\text{med}} = 2.43$ periods $= 9.72$ years. [PAGE 2].
