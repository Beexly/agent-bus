Under crisis conditions—occlusion, rapid line changes, scoreboard occlusion, broadcast cuts, or poor visibility—the model’s habitual regression is to fall back to the strongest learned prior. Because the null class constitutes 50.4% of tracklet examples [PAGE 3], one likely habit is to output “null” whenever jersey evidence is weak. Another habit is to trust the unmasked probability vector \(p_{jn}\) when OCR or shift synchronization fails, which can produce confident but incorrect identities.

The counter-trap is not to disable the prior, but to make failure explicit. If OCR cannot read game time, the system should fall back to roster-only masking, because roster-only obtains 86.32% accuracy, compared with 82.02% when neither shifts nor roster data are used [PAGE 7]. If the shift database is suspected unreliable, the system should widen the mask, lower confidence, or abstain rather than multiply by an overconfident zero mask. If team affiliation is uncertain, the system should compare home-mask and away-mask hypotheses and select the one with better temporal consistency, rather than committing early to one team assignment.

The clock is the hidden state variable. OCR produces start time \(t_s\) and end time \(t_e\), and these must be synchronized with the shift database \(S\) [PAGE 5]. If clock error exceeds the duration of a player shift, the selected players can change while the mask remains stale. The source says player shifts help the algorithm focus on “a smaller subset of possible players present at a particular time” [PAGE 6]. The recursive prediction is therefore: when clock error is small and database coverage is high, shift masking raises accuracy toward the reported 87.97%; when clock error is large, the same operator becomes a veto and can reduce accuracy below the no-mask baseline. The safe policy is hierarchical: use shift mask only when OCR confidence and database validation pass; otherwise use roster mask; otherwise output unmasked probability with calibrated uncertainty.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical veto: jersey recognition requires visible pixels of the jersey number. The weak-label pipeline assumes that the sampled sequence contains at least one frame with a visible jersey number, as stated: “at least one image with a visible jersey number is present in the sampled tracklet” [PAGE 5]. If the player is turned away, occluded by opponents, officials, boards, or camera framing removes the torso, then no temporal transformer can create evidence that was not present in the image formation process. The exact breakdown regime is when all sampled frames have the jersey hidden or when the weak-label set contains no positive frame; then the model’s valid output is null or abstention, not a confident non-null identity.

Biomechanical veto: skating posture, shoulder tilt, arm position, and body rotation change the visible region. The source’s hard example shows a tilted jersey number 2 with heavy occlusion by an opposition player wearing jersey number 12 [PAGE 7]. This is not primarily a weather issue but a biomechanical and occlusion issue: the optical appearance of the digit is deformed, partially hidden, or confused with another player’s jersey. If the digit strokes are outside the visible contour, the visual likelihood collapses even if the tracklet-level label is correct.

Shift-database veto: the mask equations are multiplicative. If the OCR interval selects a shift set that excludes the true jersey number, the true class probability becomes zero under element-wise multiplication [PAGE 5][PAGE 6]. The source acknowledges that “The lower accuracy of the first test video is due to inaccuracies in the shifts database” [PAGE 7]. Therefore the database layer can veto even a perfect visual prediction. The exact failure condition is: true jersey index \(j^*\) is not in the selected home or away set, so \((p_{jn} \odot v)[j^*] = 0\), making exact argmax recovery impossible.

Weather veto: indoor NHL arenas largely remove weather as a first-order variable, but if the method is transferred to outdoor rinks, rain, snow, fog, low sun angle, or glare can reduce contrast, obscure jersey digits, and corrupt OCR of time or scoreboard. The proof is conditional: if weather reduces the effective visible jersey evidence below the weak-label threshold, or prevents OCR time extraction, both the visual and shift layers fail. In the indoor setting, weather is a low-probability veto; in outdoor or low-quality broadcast settings, it becomes a valid cross-layer veto.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
1. Visibility veto: construct a tracklet where the jersey number is never visible, or set the weak-label threshold so that all frame labels become zero. Verification: the frame-label algorithm requires positive indices where \(b_k = 1\) [PAGE 4][PAGE 5]. If no such index exists, the sampling algorithm cannot guarantee a visible jersey number. Prediction: the model should output null or a shift-allowed number, but exact identification of a non-null true player is impossible. Observable signature: accuracy on this subset collapses toward the null-class baseline.

2. Clock/OCR veto: inject an OCR time offset large enough that the queried interval no longer overlaps the true player shift. Verification: the source extracts start time \(t_s\) and end time \(t_e\) using OCR, then extracts the shift subset \(S'\) present between those times [PAGE 5]. If \(t_s\) and \(t_e\) are wrong, the selected home and away sets \(H\) and \(A\) are wrong. Because
\[
Id = \arg\max(p_{jn} \odot v_h)
\]
or
\[
Id = \arg\max(p_{jn} \odot v_a),
\]
the true class is zeroed if it is excluded from the selected mask [PAGE 5][PAGE 6]. Prediction: affected tracklets cannot be correctly identified by the shift-masked system; mean accuracy falls toward the no-shift baseline and can drop below it if the wrong mask actively excludes the true class. The paper’s video 1 example, where shift-database inaccuracies reduce accuracy, is consistent with this failure mode [PAGE 7].

3. Team-affiliation veto: flip the home/away assignment for a tracklet. Verification: the system applies \(v_h\) if the tracklet is assigned to the home team and \(v_a\) if assigned to the away team [PAGE 5]. If the true jersey number appears only in the opposite team’s set, the selected mask removes the true class. Prediction: the system will choose an allowed but wrong number or null; accuracy drops relative to correct team assignment. Observable signature: a symmetric drop when home and away labels are swapped, with recovery when the correct mask is restored.

These are verifiable counterfactual vetoes because each one follows directly from the paper’s own operators and produces a discrete prediction: correct identity is impossible whenever the visibility condition, OCR clock, or team-affiliation condition removes the true jersey index from the active hypothesis set.
