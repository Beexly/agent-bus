**Derivation 2: The Dinkelbach fractional program (Chapter 4).**

We maximize $C = a(x)/b(x)$ where $a(x) = \sum m(\cdot)o$, $b(x) = \sum n(\cdot)o > 0$. Claim: $C^* = \max_x a/b = \max\{\alpha : \exists x, a(x) - \alpha b(x) \ge 0\}$.

Proof sketch: If $\alpha \le a(x)/b(x)$ for some x (with b>0), then $a(x) - \alpha b(x) \ge 0$. Conversely if $a(x) - \alpha b(x) \ge 0$ then $a(x)/b(x) \ge \alpha$. So the largest α for which the feasible set $\{x: a(x)-\alpha b(x)\ge 0\}$ is nonempty equals $\sup_x a(x)/b(x)$. Since the objective $a - \alpha b$ is linear in the binary flow variables $o_{ij}^p$ and constraints (4.6) are linear, each feasibility check is an ILP. Binary search on α ∈ [0,1] converges; 10 iterations → $2^{-10}\approx 10^{-3}$ precision on a metric that lives in [0,1].

This is exactly Dinkelbach's algorithm for linear-fractional programming, and matches [30] Charnes-Cooper cited in bibliography (PAGE 116: "A. Charnes and W. Cooper. Programming with Linear Fractional Functionals."). The thesis cites [30] for the LP transformation. Good — I can note the lineage.

**Derivation 3: The IDF1 proxy decomposition (Chapter 5).**

IDF1 (Eq 5.2): numerator counts matched frames (IoU>0.5 between predicted and GT box), denominator = predicted-length + GT-length. The problem: at inference, G unknown, so can't compute the indicator $\mathbb{1}(IoU(d_n,g_n)>0.5)$ or the GT support $\{n:g_n\ne 0\}$.

The fix: decompose into per-frame learnable quantities.
- $iou_n \approx IoU(d_n, g_n)$ — regress the per-frame overlap.
- $lab_n \approx \mathbb{1}(g_n \ne 0)$ — predict whether GT exists at frame n (i.e., the tracklet is "real" here).
- Then $\mathbb{1}(IoU>0.5) \approx \mathbb{1}(iou_n > 0.5)$, approximated softly, and the count $\sum \mathbb{1}(IoU>0.5) \approx \sum_{d_n\ne0, lab_n>0.5} iou_n$ (soft count weighted by predicted IoU). Denominator GT-length $\sum \mathbb{1}(g_n\ne0) \approx \sum \mathbb{1}(lab_n>0.5)$.

Proof: the physics veto fires when lateral Magnus deflection over the fit window exceeds $D_l$; tripling $D_l$ (25→75 cm) triples the admissible deflection, empirically moving the veto boundary outside the observed regime.

Veto C — rolling friction.
