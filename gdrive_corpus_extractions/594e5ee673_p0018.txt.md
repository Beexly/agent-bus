Halmos (*Measure Theory*, 1950, p. 3):
"A topological space is a set \(X\) and a class of subsets of \(X\), called the open sets of \(X\), such that the class contains \(\emptyset\) and \(X\) and is closed under the formation of finite intersections and arbitrary unions."
Formally, let \((X,\tau)\) be a topological space. Here, \(\tau\) denotes the collection of open sets satisfying:
- \(\emptyset \in \tau\)
- \(X \in \tau\)
- For any finite collection \(\{U_i\}_{i=1}^n \subset \tau\), \(\bigcap_{i=1}^n U_i \in \tau\).
- For any arbitrary collection \(\{U_\alpha\}_{\alpha \in A} \subset \tau\), \(\bigcup_{\alpha \in A} U_\alpha \in \tau\).

Define the interior operator \(\circ : \mathcal{P}(X) \to \mathcal{P}(X)\) by:
\[
E^\circ = \bigcup \{U \mid U \subseteq E,\, U \in \tau\},
\]
the largest open set contained in \(E\). The closure operator \(\overline{\cdot} : \mathcal{P}(X) \to \mathcal{P}(X)\) is:
\[
\overline{E} = \bigcap \{F \mid E \subseteq F,\, F^c \in \tau\},
\]
the smallest closed set containing \(E\). Closed sets satisfy dual identities:
- \(\emptyset^c = X\) is closed,
- \(X^c = \emptyset\) is closed,
- Finite unions of closed sets are closed,
- Arbitrary intersections of closed sets are closed.

A set \(E\) is dense in \(X\) if \(\overline{E} = X\). For a subspace \(Y \subseteq X\), the relative (subspace) topology \(\tau_Y\) is:
\[
\tau_Y = \{Y \cap U \mid U \in \tau\}.
\]
Then \((Y,\tau_Y)\) is a topological space. A base \(\mathcal{B}\) for \(\tau\) is a collection of open sets such that every open set can be written as a union of members of \(\mathcal{B}\). Equivalently, for each \(x \in X\) and each neighborhood \(U\) of \(x\), there exists \(B \in \mathcal{B}\) with \(x \in B \subseteq U\). A subbase \(\mathcal{S}\) is a collection whose finite intersections form a base. The topology generated by \(\mathcal{S}\) is the smallest topology containing \(\mathcal{S}\). The standard topology on \(\mathbb{R}\) has the collection of all open intervals as a base. A space is separable if it possesses a countable base.

Theorem (Alexandroff-Zorn Lemma): Every partially ordered set in which every chain has an upper bound contains a maximal element.
Proof sketch: Given a partially ordered set \((P,\leq)\) with the specified property, consider the collection of all chains in \(P\), ordered by inclusion. This collection is inductive, so by Zorn's lemma it has a maximal element \(C^*\). If \(C^*\) does not have an upper bound, adjoining an element larger than all elements of \(C^*\) produces a strictly larger chain, contradicting maximality. Thus \(C^*\) has an upper bound \(u\); if \(u\) were not maximal, an element greater than \(u\) could be adjoined, again contradicting maximality. Hence \(u\) is a maximal element of \(P\).

Theorem (Basis Criterion): A collection \(\mathcal{B}\) of subsets of \(X\) is a base for some topology on \(X\) iff
1. \(\bigcup_{B \in \mathcal{B}} B = X\),
2. For any \(B_1,B_2 \in \mathcal{B}\) and \(x \in B_1 \cap B_2\), there exists \(B_3 \in \mathcal{B}\) with \(x \in B_3 \subseteq B_1 \cap B_2\).

Proof: If \(\mathcal{B}\) is a base, condition 1 holds because every point lies in some open set (hence in some basic open set), and condition 2 follows from the definition of a base. Conversely, assume 1 and 2. Define a topology \(\tau\) on \(X\) by declaring a set \(U\) open iff for each \(x \in U\) there exists \(B \in \mathcal{B}\) such that \(x \in B \subseteq U\). Verify that \(\tau\) satisfies the axioms of a topology; then \(\mathcal{B}\) is clearly a base for \(\tau\).

Lemma (Subspace Base): If \((X,\tau)\) has base \(\mathcal{B}\) and \(Y \subseteq X\), then \(\mathcal{B}_Y = \{B \cap Y \mid B \in \mathcal{B}\}\) is a base for the subspace topology on \(Y\).

Proof: Since \(\mathcal{B}\) covers \(X\), \(\mathcal{B}_Y\) covers \(Y\). For any \(y \in U \cap Y\) with \(U\) open in \(Y\), write \(U = V \cap Y\) with \(V\) open in \(X\). For each \(b \in \mathcal{B}\) with \(y \in b \subseteq V\), \(b \cap Y\) belongs to \(\mathcal{B}_Y\) and \(y \in b \cap Y \subseteq U\). Thus \(\mathcal{B}_Y\) satisfies the basis criterion.

Theorem (Separability and Second-Countability): Every second-countable space is separable. The converse fails.

Proof: Suppose \(\tau\) has a countable base \(\{B_n\}_{n=1}^\infty\). Choose \(x_n \in B_n\) for each \(n\). Then \(D = \{x_n\}_{n=1}^\infty\) is dense: for any non-empty open set \(U\), pick a basic open set \(B_k \subseteq U\); since \(x_k \in B_k \subseteq U\), \(U \cap D \neq \emptyset\). Thus \(X\) is separable. For the failure, the discrete topology on an uncountable set is separable (any point is dense) but not second-countable, because any base must contain all singletons, which is uncountable.
