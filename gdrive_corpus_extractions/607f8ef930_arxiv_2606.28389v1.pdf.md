<THINK_TRACE>
The source is a two-page system report, not a full derivation paper, so the audit must separate explicit claims from implicit assumptions. The first multi-hop step is pipeline decomposition: the organizers provide a two-stage pipeline, where “a Track-Aware Action Detector (TAAD) processes video to produce per-player action logits” and “a Denoising Sequence Transduction (DST) autoregressive transformer converts game-state features and TAAD logits into structured event sequences” [PAGE 1]. Therefore any claimed improvement must be attributed either to Stage 1 TAAD changes, Stage 2 DST changes, or the ensemble. The report states a final “58.94 Macro-F1 on the challenge set” [PAGE 1], while Table 1 rounds this to 58.9 [PAGE 2]. That small inconsistency is benign, but it signals that the paper’s numbers are reported at different precision levels; a rigorous audit should treat 58.94 as the headline and 58.9 as tabular rounding.

The second hop is architectural. TAAD is extended from an X3D backbone with a temporal transformer: ROI-aligned per-player per-frame features are projected to d=256, then L=4 transformer encoder layers with 8 heads, feedforward dimension 1024, GELU, pre-norm, and learnable positional embeddings up to 50 frames are applied [PAGE 1]. This is a temporal-context operator, not a relational player-graph operator. The DST stage then adds per-player attention: Stage 1 is spatial cross-player attention across 26 players at each frame; Stage 2 is per-player temporal self-attention across frames [PAGE 1]. The crucial ablation is that the authors “found that using only game-state features (positions, velocities, visibility) for the per-player attention, excluding TAAD logits, outperforms using all channels” [PAGE 1]. This means the DST attention is not simply a richer feature mixer; it is a selective prior that trusts geometric game-state structure over noisy action logits for the attention pathway. That is a gray-zone: the TAAD logits are still concatenated later, but excluding them from the attention mechanism changes the information bottleneck.

The third hop is temporal order. The authors report that “processing spatial attention first, then temporal, yields a significant improvement (+1.87% Macro-F1 on validation, from 0.549 to 0.567)” [PAGE 1]. The stated intuition is that spatial configuration at each frame provides richer context for later temporal reasoning. Formally, this is an inductive-bias claim: factorizing the joint player-time attention as spatial-then-temporal reduces the hypothesis space and matches the causal structure of a team sport, where simultaneous player geometry constrains which temporal transitions are plausible. The alternative parallel-attention Model D sums independent temporal and spatial branches and scores 0.569 validation F1 [PAGE 2], slightly above Model A but below Model C’s 0.572. This is not a monotone proof that spatial-first is universally best; it is evidence within this specific data and hyperparameter envelope.

The fourth hop is ensemble mechanics. The ensemble groups predictions by “(team, shirt number, action class)”, clusters within ±12 frames by greedy assignment to the nearest cluster center sorted by score descending, computes average score times “(n/N)0.5 as an agreement boost”, and applies “min models=2: discard events predicted by fewer than 2 models” [PAGE 2]. The reported result is that “fusion with min models=2 consistently outperforms all alternatives” [PAGE 2]. The rare-class exception is critical: “Tackle events are extremely rare (26 occurrences across 96 training games)” and “tackle predictions bypass the agreement filter and are kept even with single-model support” [PAGE 2]. This is a hand-designed counter-prior against the agreement filter’s majority bias. The gray-zone is that this exception preserves recall but may admit single-model hallucinations; the table shows ensemble tackle F1 0.123, below Model B’s 0.154 [PAGE 2], so the exception does not make tackle strong—it merely prevents the filter from erasing it entirely.

The fifth hop is calibration and validation leakage. The authors state that per-class optimized Macro-F1 thresholds “overfit to the 6 validation games (48.0 vs. 48.6 on challenge)” and that “Using τ=0 with default thresholds consistently performs best” [PAGE 2]. This is a direct warning about small-validation tuning. The term “logit adjustment temperature τ” is ambiguous: if τ were a literal softmax temperature, τ=0 would be a mathematical singularity; the reported use of τ=0 therefore most plausibly means disabling class-wise logit adjustment, not dividing logits by zero. A rigorous audit must flag this. The validation-to-challenge gap is reported to narrow “from ∼6 points (single model) to ∼2 points (ensemble)” [PAGE 2], which supports the claim that agreement filtering improves generalization, but six validation games are a small sample and cannot certify robustness across weather, camera, league, and officiating distributions.

The sixth hop is physical plausibility. The report is entirely data-driven; it does not encode ball physics, player reachability, or weather vetoes. Yet soccer action spotting is constrained by kinematics: a header requires ball-head proximity, a tackle requires foot-body proximity and opponent possession context, and a pass requires a plausible ball departure. An ensemble of neural models can agree on a physically impossible event if all models share the same broadcast view and frozen TAAD logits. Therefore the correct adjudication layer is not another learned score but a veto predicate that checks physical feasibility, biomechanical reach, and weather/visibility reliability before accepting an event. This is the cross-layer veto.

The seventh hop is counterfactual verification. The source gives several explicit comparisons that can be converted into RLVR-style checks: spatial-first versus temporal-first, min models=2 versus no filter, per-class τ tuning versus τ=0, and solo tackle exception versus no exception. Each has a measurable prediction. The deepest trap is not a single hyperparameter but a multi-week experimental trap: the warmup scheduler bug where “the learning rate stopped updating prematurely and remained at its warmup value for the remainder of training” [PAGE 1] can waste long training cycles; small-validation threshold tuning can produce deceptive gains; and frozen TAAD logits cap DST improvements while making ensemble diversity narrower than it appears. The final 58.94 must be read as a system-level number under those constraints, not as proof that each component is independently optimal.

<SOURCE_OPERATORS_AND_EQUATIONS>
The source defines a two-stage system. Stage 1 is TAAD: per-player ROI-aligned features are extracted per frame, projected to d=256, and processed by L=4 transformer encoder layers with 8 attention heads, feedforward dimension 1024, GELU, pre-norm, and learnable positional embeddings up to 50 frames; the output is projected to 512 dimensions before a “9-class classification head” [PAGE 1]. The standard scaled dot-product attention operator is
\[
\operatorname{Attn}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d_k}}\right)V,
\]
where Q, K, and V are dimensionless embedding matrices and d_k is a dimensionless head width. The softmax is
\[
\operatorname{softmax}(z)_k=\frac{e^{z_k/T}}{\sum_{j=1}^{K}e^{z_j/T}},\qquad T>0,
\]
with logits z_k in dimensionless units and temperature T in dimensionless units. If T approaches zero, the softmax approaches a one-hot limit; at T=0 the expression is undefined. The report’s “logit adjustment temperature τ” [PAGE 2] should therefore not be interpreted as a literal softmax temperature at τ=0. The safe interpretation is that τ=0 disables class-wise logit adjustment. If a system literally divides logits by τ=0, the breakdown regime is numerical singularity: infinite or NaN logits, saturated softmax, and invalid Macro-F1.

Stage 2 DST adds per-player attention. Let x_{t,r} be the feature vector for player r at frame t, with r in 1..26 and t in 1..T. The spatial stage is
\[
H^{S}_{t,1:26}=\operatorname{Enc}_{S}\!\left(\{x_{t,r}\}_{r=1}^{26}\right),
\]
and the temporal stage is
\[
H^{T}_{r,1:T}=\operatorname{Enc}_{T}\!\left(\{H^{S}_{t,r}\}_{t=1}^{T}+\operatorname{PE}(t)\right),
\]
where PE(t) is sinusoidal positional encoding, t is a frame index, and T is the number of frames. The report specifies Stage 1 as “Cross-player spatial attention at each frame” with dp=64 and 4 heads, and Stage 2 as “Per-player temporal self-attention across frames” [PAGE 1]. The attended features are mean-pooled across players and concatenated with game-state logits per frame:
\[
u_t=\frac{1}{26}\sum_{r=1}^{26}H^{T}_{r,t},\qquad
z_t=W_u u_t+W_g g_t+b,
\]
where g_t denotes game-state logits and z_t is the frame-level representation passed to the main encoder. The decoder is autoregressive:
\[
p_\theta(y_{1:M}\mid z_{1:T})=\prod_{m=1}^{M}p_\theta(y_m\mid y_{<m},z_{1:T}),
\]
where y_m is a tuple of frame, action, and role, and the probability is dimensionless. The source states that the decoder “autoregressively generates (frame, action, role) tuples” [PAGE 1].

The ensemble operators are explicit. Predictions are grouped by team, shirt number, and action class. Clustering within ±12 frames uses greedy assignment to the nearest cluster center sorted by score descending [PAGE 2]. For cluster j with n_j contributing models out of N, the fused score is
\[
s_j=\left(\frac{1}{n_j}\sum_{i\in\mathcal{C}_j}s_i\right)\left(\frac{n_j}{N}\right)^{1/2},
\]
where s_i is a model score in dimensionless probability-like units if normalized to [0,1]. The agreement boost is dimensionless. The keep predicate is
\[
\mathbb{1}_{\text{keep}}(j)=\mathbb{1}(n_j\ge 2)\lor\mathbb{1}(\text{action}_j=\text{tackle}),
\]
which encodes “min models=2” and the solo tackle exception [PAGE 2]. The breakdown regimes are: if N=0 the boost is undefined; if scores are unnormalized logits, the average is not a probability and the square-root boost has no probabilistic meaning; if the ±12-frame tolerance is too large, adjacent events merge; if too small, one true event splits into multiple clusters; if the greedy order changes, cluster assignment can change because the algorithm is order-dependent.

The Macro-F1 metric is
\[
F1_k=\frac{2TP_k}{2TP_k+FP_k+FN_k},\qquad
\operatorname{MacroF1}=\frac{1}{K}\sum_{k=1}^{K}F1_k,
\]
with TP, FP, and FN as dimensionless counts and K the number of evaluated classes. The source reports a “9-class classification head” [PAGE 1] but Table 2 lists eight action columns: dri, pas, crs, thr, sho, hea, tac, blk [PAGE 2]. The exact K used for the challenge Macro-F1 is therefore a reporting ambiguity; if background is excluded, K=8 for the table, while the classifier head remains 9-way. The breakdown regime for F1 is a zero denominator: if a class has no true positives and no predicted positives, F1 is undefined unless a convention sets it to zero. This matters most for tackle, where the source reports “26 occurrences across 96 training games” and per-model F1 “∼0.05–0.15” [PAGE 2].

The attention and ensemble equations have information-theoretic units only if scores are calibrated probabilities. For a calibrated classifier, entropy is
\[
H(Y)=-\sum_{k=1}^{K}p_k\log_2 p_k\ \text{bits},
\]
and mutual information between the event label Y and agreement count A is
\[
I(Y;A)=\sum_{y,a}p(y,a)\log_2\frac{p(y,a)}{p(y)p(a)}\ \text{bits}.
\]
The source does not report calibration curves, so these quantities are diagnostic rather than measured. The agreement filter’s benefit depends on conditional independence of model errors given the true label; if all DST models share frozen TAAD logits, their errors are positively correlated, and agreement is weaker evidence than the (n/N)^{1/2} boost suggests. This is a formal breakdown regime: correlated errors inflate consensus without increasing information.

The source’s ablation values are: DST with improved TAAD 0.541 validation and 48.6 challenge; plus per-player attention 0.549 validation; plus spatial-first order 0.567 validation and 55.1 challenge; 4-model ensemble 0.609 validation and 58.9 challenge [PAGE 2]. The spatial-first gain is stated as “+1.87% Macro-F1 on validation, from 0.549 to 0.567” [PAGE 1]. The per-class table shows ensemble gains on common-to-medium classes, with ensemble dri .839, pas .840, crs .764, thr .828, sho .677, hea .450, tac .123, blk .354, while Model B has the strongest tackle at .154 [PAGE 2]. The report concludes that “The ensemble outperforms all individual models on every class except tackle” [PAGE 2]. That exception is the key gray-zone: agreement filtering is a precision mechanism that trades away rare-class recall unless an explicit exception is added.

Finally, the physical veto equations are not in the source but are necessary for cross-layer adjudication. For player i and ball b, a minimal feasibility predicate is
\[
\mathcal{V}_{\text{phys}}(e)=\mathbb{1}\!\left[\exists\,\mathbf{p}_i(t):\ \|\dot{\mathbf{p}}_i\|\le v_{\max},\ \|\ddot{\mathbf{p}}_i\|\le a_{\max},\ \operatorname{dist}(\mathbf{p}_i(t_e),\mathbf{b}(t_e))\le R_i(\text{action})\right],
\]
with positions in meters, velocities in m/s, accelerations in m/s², and R_i in meters. A weather/visibility gate is
\[
\mathcal{V}_{\text{weather}}=\mathbb{1}(\operatorname{vis}\ge \operatorname{vis}_{\min}\ \land\ \operatorname{conf}_{\text{ball}}\ge c_{\min}),
\]
where vis is in meters or a calibrated visibility score and conf is dimensionless. The exact thresholds require calibration; the source provides none. The breakdown regime is decisive: when V_phys=0, no amount of ensemble agreement can make the event physically real; when V_weather=0, high model scores may reflect occlusion-driven hallucination rather than observable evidence.

<RETROCAUSAL_GENEALOGY>
The scientific lineage runs from X3D video recognition [PAGE 2, ref. 4] to spatio-temporal action detection under large motion [PAGE 2, ref. 2], then to the FootPass multi-modal tactical dataset [PAGE 2, ref. 1] and the “language of soccer” DST formulation [PAGE 2, ref. 3]. The report’s architecture is retrocausally legible: X3D supplies efficient clip features, TAAD supplies per-player action logits, and DST supplies a sequence prior over frame-action-role tuples. The authors’ contribution is not a new backbone but a re-factorization of the DST input: a flat 26-role vector becomes per-player spatial attention followed by per-player temporal attention [PAGE 1]. The final ensemble then retroactively justifies the architectural diversity: Models A-D vary hidden dimension, player-attention depth, and parallel versus sequential attention, and the ensemble reaches 58.9 challenge F1 [PAGE 2]. In a retrospective genealogy, it is tempting to say the spatial-first design “caused” the gain, but the source only reports a validation comparison from 0.549 to 0.567 [PAGE 1] and a challenge jump from 48.6 to 55.1 after spatial-first plus per-player attention [PAGE 2]. The causal chain is therefore conditional on the TAAD checkpoint, the six validation games, and the training schedule.

The multi-week traps are long-horizon experimental failure modes. First, the warmup scheduler bug: “the learning rate stopped updating prematurely and remained at its warmup value for the remainder of training” [PAGE 1]. A team can spend weeks comparing architectures while the optimizer is effectively frozen at a warmup rate. Second, small-validation threshold tuning: per-class optimized Macro-F1 on six validation games produced “48.0 vs. 48.6 on challenge” [PAGE 2], meaning validation-tuned thresholds looked better locally but generalized worse. Third, frozen TAAD logits: the report says “The resulting TAAD logits are used as frozen input to all DST experiments” [PAGE 1]. This is efficient, but it caps DST gains and makes ensemble errors correlated. Fourth, rare-class agreement filtering: tackle occurs only 26 times across 96 training games [PAGE 2], so min models=2 will erase correct single-model detections; the solo tackle exception is a patch, not a solution. Fifth, checkpoint sweep: “A checkpoint sweep selects the best-performing epoch per model” [PAGE 2] on validation, which can overfit the six-game sample. Sixth, tracklet count increases from 4 to 6 at epoch 16 [PAGE 1] while DST models are trained for 10 epochs [PAGE 2]; the two stages have different clocks, and a multi-week experiment that confuses them can attribute gains to the wrong stage.

The retrocausal lesson is that the final ensemble’s success selects which earlier branches appear necessary. The report’s own Table 2 undercuts a simple “ensemble is always better” story: the ensemble is best on every class except tackle, where Model B is strongest [PAGE 2]. A rigorous genealogy must preserve that exception. The 58.94 headline is a system-level outcome produced by TAAD improvements, per-player attention, spatial-first ordering, four-model fusion, min models=2, and the solo tackle exception. Remove any one and the lineage changes. The “multi-week trap” is to search for a single winning component when the evidence supports a pipeline of conditional fixes.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
Treat the pipeline as a set of agents with beliefs. TAAD forms per-player action beliefs; each DST model forms a sequence belief over frame-action-role tuples; the ensemble forms a meta-belief about which model beliefs are reliable via agreement count n and boost (n/N)^{1/2} [PAGE 2]. This is recursive theory of mind in a narrow engineering sense: the ensemble models the other models’ consensus, and the solo tackle exception models the failure mode of that consensus. The crisis habit regression appears under class imbalance. When tackle is rare, the models regress to background and common actions; the agreement filter then acts as a social prior toward consensus, which suppresses the rare true event. The source confirms the crisis: tackle has “the lowest per-model F1 (∼0.05–0.15)” and only 26 occurrences across 96 training games [PAGE 2]. The ensemble’s tackle F1 of 0.123 is below Model B’s 0.154 [PAGE 2], showing that the meta-belief does not solve the rare-class habit; it only avoids complete erasure.

The counter-trap is the hand-coded exception: “tackle predictions bypass the agreement filter and are kept even with single-model support” [PAGE 2]. This is a counter-prior against consensus. It preserves recall but creates a new failure mode: a single model’s hallucinated tackle is accepted. A second counter-trap is τ=0 with default thresholds. The authors tried per-class optimized thresholds and found they “overfit to the 6 validation games (48.0 vs. 48.6 on challenge)” [PAGE 2]. The counter-trap is to trust the validation-tuned thresholds because they look better locally; the correct counter-counter-trap is to use default thresholds and accept lower validation elegance for better challenge transfer. A third counter-trap is spatial-first attention: the intuitive order is temporal-first because events unfold in time, but the source reports spatial-first improves validation from 0.549 to 0.567 [PAGE 1]. The recursive lesson is that the model’s own intuition about what should help can be wrong; the ablation is the theory-of-mind check.

The clock is the temporal adjudication layer. The ensemble clusters within ±12 frames [PAGE 2], the DST decoder generates frame-action-role tuples autoregressively [PAGE 1], and the TAAD positional embeddings cover up to 50 frames [PAGE 1]. These are three different clocks: event tolerance, sequence generation order, and attention context. A crisis habit regression can occur when the clock is misaligned: if the ±12-frame window is too wide, a pass and a subsequent tackle can merge; if too narrow, one event splits. The decoder’s autoregressive clock means early tuple errors condition later tuples, so a single false frame can cascade. The checkpoint clock matters too: DST models train for 10 epochs with decay at epochs 3, 6, and 8 [PAGE 2], while TAAD changes tracklet count at epoch 16 [PAGE 1]. A recursive theory of mind must track which clock each agent is on. The ensemble’s agreement count is not clock-free; it assumes predictions from different models refer to the same event within the same tolerance. If model clocks drift, agreement becomes accidental.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The physical veto is a proof obligation, not a post-hoc score adjustment. Let E be an event tuple. Under the event definition, E entails physical feasibility and observable evidence. Define V_phys as the existence of a player trajectory satisfying speed, acceleration, and action-specific reach constraints, and V_weather as the existence of sufficient visibility and ball-detection confidence. If V_phys=0, then no trajectory exists that realizes E, so P(E|V_phys=0)=0 under the kinematic event definition. If V_weather=0, the video evidence is unidentifiable: high model scores may reflect occlusion, rain, glare, camera motion, or broadcast cutaways rather than the event. Therefore the acceptance predicate must be
\[
A_{\text{final}}(e)=\mathbb{1}(s_e\ge \theta)\land\mathbb{1}(n_e\ge 2)\land\mathcal{V}_{\text{phys}}(e)\land\mathcal{V}_{\text{weather}}(e),
\]
with the tackle exception replacing the n_e≥2 term only when the action is tackle. The proof sketch is: the ensemble score is a function of model beliefs; model beliefs are functions of video features; features can be corrupted; physical feasibility is an independent constraint on the event. If the constraint is false, the event is impossible regardless of belief. If the constraint is true but weather is bad, belief is unreliable. Thus the veto dominates the ensemble.

Biomechanically, the veto must check action-specific reach envelopes. A header requires ball-head proximity and a plausible jump or lean; a tackle requires foot-body proximity and opponent possession context; a pass requires a plausible ball departure from the passer’s foot. The source does not provide these thresholds, so they must be calibrated and documented. The formal breakdown regime is clear: if v_max or a_max is set too low, true elite actions are vetoed; if set too high, impossible actions pass. Weather adds a second breakdown: if vis_min is too low, rain and occlusion produce false positives; if too high, legitimate night matches are vetoed. The ensemble cannot repair missing information. Because the DST models share frozen TAAD logits [PAGE 1], their agreement can be correlated; a physical veto is therefore especially valuable as an independent layer. The final adjudication should report veto counts by class, because a high veto rate on headers or tackles may indicate either model hallucination or an over-tight physical prior.
</CROSS_LAYER_VETO_ADJUDICATION>
