All equations below are quoted from the source with page markers; units and breakdown regimes are my analysis.

Cross-correlation response map [Eq. 1, PAGE 3]:
$$v = \tau(x,z) = \varphi(x) * \varphi(z) + b$$
φ(·) is the 5-layer AlexNet embedding. Units: dimensionless response scores. Feature shapes are $f_{z_i}=\varphi(z_i)\in\mathbb{R}^{6\times6\times256}$, $f_{x_i},f_{x_j}\in\mathbb{R}^{20\times20\times256}$ [PAGE 3]. Breakdown: valid convolution of a 6×6 kernel over a 20×20 map yields a 15×15 response; at test time the instance feature is $\mathbb{R}^{22\times22\times256}$ [PAGE 6], which is why ROI-Align is mandatory to re-center the target before GAP.

SOT logistic loss [Eq. 2, PAGE 3]:
$$\mathcal{L}_{SOT}=\sum_{p\in P}\frac{1}{|P|}\log\!\left(1+e^{-v_p y_p}\right),\quad y_p\in\{+1,-1\}$$
Dimensionless (nats, natural-log cross-entropy). Smooth everywhere; no singularity.

Triplet loss [Eq. 3, PAGE 4]:
$$\mathcal{L}_{Tri}=\frac{1}{N}\sum_{i,j}\max\!\big(0,\ \|w_{z_i}-w_{x_i}\|_2^2-\|w_{z_i}-w_{x_j}\|_2^2+m\big)$$
Breakdown regime: zero gradient whenever the margin constraint is already satisfied (the hinge saturates), and the paper explicitly reports the positive/negative imbalance makes hard mining unreliable [PAGE 4], motivating replacement.

N-pair loss [Eq. 4, PAGE 4]:
$$\mathcal{L}_{N\text{-pair}}=\frac{1}{N}\sum_{i=1}^{N}\log\!\Big(1+\sum_{i\neq j}\exp\!\big(w_{z_i}^{\top}w_{x_j}-w_{z_i}^{\top}w_{x_i}\big)\Big)$$
Singularity/breakdown: the argument of exp is an unbounded real (no L2 normalization is specified before the dot product in the text), so large positive hard-negative gaps cause $\exp(\cdot)\to\infty$ overflow; numerical evaluation requires log-sum-exp stabilization. This is a genuine, verifiable numerical hazard, not a toy concern.

Identification loss [Eq. 5, PAGE 4] and total objective [Eq. 6, PAGE 4]:
$$\mathcal{L}_{Iden}=-\Big(\tfrac{1}{N}\sum_i\log\hat p_{z_i}+\tfrac{1}{N}\sum_i\log\hat p_{x_i}\Big),\qquad \mathcal{L}=\mathcal{L}_{SOT}+\big(\lambda_1\mathcal{L}_{N\text{-pair}}+\lambda_2\mathcal{L}_{Iden}\big)$$
Softmax over 439 identity classes via FC layers of dim 512 then 439 [PAGE 4]; $\lambda_1=\lambda_2=0.1$ [PAGE 7].

Affinity operators [Eq. 7 and Eq. 11]:
$$c=w_I^{\top}w_{I'},\qquad c'=\frac{1}{K}\sum_{k=1}^{K}w_d^{\top}w_{t_k}$$
Both are raw inner products (units: squared feature-norm scale, dimensionless). Threshold α = 0.6 [PAGE 7] is only meaningful if $\|w\|$ is bounded; the text does not state explicit L2 normalization, so the threshold's calibration is an assumption.

TSA squeeze/excite [Eq. 8-9, PAGE 5]:
$$s_l=\mathrm{GAP}_l(f)\in\mathbb{R},\qquad a=\sigma\!\big(W_2\,\delta(W_1 s)\big)\in[0,1]^{256}$$
with $W_1\in\mathbb{R}^{64\times256}$, $W_2\in\mathbb{R}^{256\times64}$ [PAGE 5] — a 4:1 bottleneck. Output is a bounded gate vector, so re-weighting $f^{SOT},f^{AFF}$ [Eq. 10] is numerically safe.

Assignment complexity: the Hungarian algorithm over $C\in\mathbb{R}^{|D|\times|T|}$ [PAGE 6] is $O(n^3)$ in $n=\max(|D|,|T|)$.

<RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
Framed against the paper's actual content, "recursive theory of mind" maps to how the pipeline models an adversarial environment (occlusions and distractors) and reasons about latent target state. Each target carries a two-state belief — tracked or occluded — decided by occlusion detection [PAGE 5-6]. The model effectively maintains a first-order belief over each target's visibility and a second-order contingency (if occluded, hold identity up to 30 frames, then terminate) [PAGE 7].

Crisis-habit regression: under crowd density spikes, the SOT branch (f^SOT) can drift because context features that help tracking (auxiliary objects near the target [PAGE 5]) become distractors during dense interaction. The regression is that a tracker tuned to exploit context will over-attach to a neighbor.

Counter-trap: the affinity branch (f^AFF) is deliberately tuned to suppress cluster background and focus on "local semantic features around the key points" [PAGE 5], which is the counter-measure — it re-anchors identity when the SOT drifts, via the c′ tracklet-vs-detection affinity over K uniformly sampled tracklet frames [Eq. 11, PAGE 6].

Clock: the temporal budget is explicit — occlusion is tolerated for 30 frames before termination [PAGE 7], and historic-average IOU with the nearest detection gates the tracked/occluded decision [PAGE 6]. The "clock" and the "belief" are coupled: a target surviving on affinity alone (c ≥ α) but with IOU < β is flagged occluded, so the identity persists in T while its geometry is not trusted — a deliberate separation of identity memory from motion evidence.
</RECURSIVE_THEORY_OF_MIND>
