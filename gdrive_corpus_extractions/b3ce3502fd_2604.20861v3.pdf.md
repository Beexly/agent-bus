All symbols, units, and regimes below are drawn verbatim from the source; the "⊮" glyph in [PAGE 5] is the indicator $\mathbf{1}[\cdot]$.

Residual quantization (Eq. 3, [PAGE 3]):
$$s^{(h)}_i = \arg\min_k \lVert R^{(h)}_i - c^{(h)}_k \rVert_2,\quad R^{(1)}_i = e_i,\quad R^{(h+1)}_i = R^{(h)}_i - c^{(h)}_{s^{(h)}_i}.$$
Units: $e_i \in \mathbb{R}^d$ (dimensionless embedding), residuals in the same $\ell_2$ metric. Assumption: "MiniOneRec-compatible setting, we use $H=3$" [PAGE 3]. Breakdown: if $e_i$ lies outside the codebook convex hull, residual norm does not monotonically vanish and coarse-to-fine structure degrades.

DCIM extraction / fusion (Eqs. 1–2, 6–7, [PAGE 3–4]):
$$z_i = M(\text{Prompt}_{\text{DCIM}}(t_i,d_i,v^{\text{text}}_i)),\quad x^{\text{text}}_i=\text{Concat}(t_i,d_i,v^{\text{text}}_i,z_i),$$
$$e^{\text{text}}_i=f_{\text{emb}}(x^{\text{text}}_i),\quad e^{mm}_i = W_f[\,e^{\text{text}}_i;\,e^{\text{vis}}_i\,],\quad e^{\text{vis}}_i = W_v f_{\text{vis}}(v_i).$$
$f_{\text{emb}}$ is "Qwen3-Embedding-4B" [PAGE 4]. Fusion is pure concatenation + linear projection $W_f$ — no cross-attention. Units dimensionless; $W_f$ absorbs dimension change to RQ-VAE input.

SFT objective (Eq. 8, [PAGE 5]):
$$\mathcal{L}_{\text{SFT}} = -\!\!\sum_{(X,Y)\in\mathcal D}\sum_{h=1}^{H}\log p_\theta(y_h\mid X,y_1,\dots,y_{h-1}).$$
Units: nats per token; $\mathcal D$ = training set.

Quality labeling (Eqs. 9–10, [PAGE 5]):
$$l^{(j)}_i = \text{LLM}_{\text{cls}}(z^{(j)}_i)\in\{0,1\},\qquad q_i = \frac{\sum_{j=1}^{J_i} w^{(j)}_i\, l^{(j)}_i}{\sum_{j=1}^{J_i} w^{(j)}_i}.$$
$q_i\in[0,1]$ dimensionless — a confidence-weighted fraction of positive descriptors (an empirical probability, not an information measure, unless one further takes $-\log$). If confidence missing, $w^{(j)}_i=1$.

Reward (Eqs. 11–14, [PAGE 5]):
$$r_{\text{exact}}(y)=\mathbf 1[\text{SID}(y)=\text{SID}(i^\*)],\quad r_{\text{format}}(y)=\lambda_{\text{valid}}\mathbf 1[y\in\mathcal S]+\lambda_{\text{pref}}\frac{\text{LCP}(y,\text{SID}(i^\*))}{H},$$
$$r_{\text{quality}}(y)=\mathbf 1[\hat i(y)=i^\*]\cdot q_{\hat i(y)},\qquad r(y)=r_{\text{exact}}+r_{\text{format}}+\alpha\, r_{\text{quality}},\ \ \alpha=0.5.$$
$r\in[0,\,1+\lambda_{\text{valid}}+\lambda_{\text{pref}}+0.5]$. The gate $\mathbf 1[\hat i(y)=i^\*]$ is the veto.

GRPO (Eqs. 15–16, [PAGE 5]):
$$\hat A_j = \frac{r_j - \text{mean}(\{r_j\}_{j=1}^G)}{\text{std}(\{r_j\}_{j=1}^G)+\epsilon},\quad \epsilon=10^{-6};\qquad J(\theta)=\mathbb E_{y\sim\pi_\theta}\!\big[r(y)-\beta\, D_{\mathrm{KL}}(\pi_\theta\Vert\pi_{\text{ref}})\big].$$
$\hat A_j$ dimensionless (z-score); $D_{\mathrm{KL}}$ in nats; $\beta=0.001$, $G=8$ [PAGE 6]. **Singularity regime:** when all $r_j$ equal, numerator $=0$ ⇒ $\hat A_j=0$ (no gradient) — the sparse-reward degeneracy. $\epsilon$ guards the $0/0$ but does not create signal.

<CROSS_LAYER_VETO_ADJUDICATION>
Two hard vetoes govern the architecture. **Veto 1 — DPI (information veto).** Since $s_i=Q(e^{mm}_i)$ and RL acts only on $s_i$, $I(\text{intent};s_i)\le I(\text{intent};e^{mm}_i)$; post-hoc stages cannot recover erased intent. This adjudicates in favor of CMSA/DCIM *pre-quantization* and against any "let RL fix it later" design. **Veto 2 — relevance gate (cross-layer consistency).** The semantic-quality layer is subordinate to the correctness layer: $r_{\text{quality}}$ fires only when $\hat i(y)=i^\*$. A third, subtler veto is *modality consistency* inside CMSA: the caption path $v^{\text{text}}_i=V(v_i,\text{Prompt}_{\text{align}})$ (Eq. 3) and the embedding path $e^{\text{vis}}_i=W_v f_{\text{vis}}(v_i)$ (Eq. 5) must agree before fusion; a hallucinated caption that contradicts the image embedding is a latent veto failure the paper does not test. **"Physical" (bandwidth) constraint:** codebook capacity is not the binding limit — for $\sim18\text{K}$ items, $H=3$ needs only $\lceil 18000^{1/3}\rceil=27$ codes/level, while MiniOneRec-style codebooks ($\sim256$/level, $256^3\approx1.68\times10^7$ slots) are orders of magnitude larger. So the true constraint is *semantic resolution within the used codebook region*, not raw bits. Evidence of complementarity: Table V [PAGE 9] shows super-additivity — caption-only $+0.0011$ and image-only $+0.0007$ over Text-Only sum to $+0.0018$ (predicted $0.0659$), but the full model reaches $0.0678$ ($+0.0037$), exceeding the additive prediction by $0.0019$, consistent with (though, absent error bars, not proof of) complementary visual evidence.
