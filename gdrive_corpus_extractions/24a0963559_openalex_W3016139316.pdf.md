The derivation therefore branches into two incommensurable regimes: (i) N_targets ≤ 4, where human parallel/covert strategies dominate accuracy; and (ii) N_targets > 4, where humans must serialize via overt fixations while algorithms can assign separate processor cores per target ([PAGE 8]). The gray zone is the transition at N ≈ 4, where neither biological serial refreshing nor algorithmic parallel assignment is clearly optimal, and where the paper notes no practical computer-vision algorithm unifies attention, memory, and motion-prediction modules ([PAGE 20]).

The second hop concerns the mechanism of identity-location binding. Oksama & Hyönä ([12], reviewed on [PAGE 6-7]) postulate two systems: an ambient system tracking positions and a focal system recognizing items. In MOT (indistinguishable targets), only the ambient system is used, yielding parallel processing with fixation frequency invariant to set size. In MIT (distinguishable targets), both systems engage, making tracking serial and fixation frequency increase with set size ([PAGE 6-7]). Li et al. ([22], [PAGE 8]) refine this: high-resolution identity demands force foveal serial sampling; low-resolution discrimination permits covert parallel sampling from blank inter-target regions. This resolution-dependent serial/parallel switch is a gray-zone controller: when feature discriminability falls below a critical threshold, the system regresses to serial foveal sampling, increasing temporal cost and vulnerability to occlusion.

The third hop is memory architecture. The Atkinson–Shiffrin memory model (ASMM) with sensory, short-term, and long-term stages is explicitly imported into computer vision on [PAGE 17] to handle illumination changes and occlusion. The breakdown regime is temporal: if a target remains occluded beyond the short-term memory retention window, the appearance template decays and re-identification fails upon reappearance ([PAGE 13-14, 17]). This couples with the "what–where trade-off" ([PAGE 11, reference 37]): identity processing consumes the same attentional resources as location processing, so high-load identity tasks degrade tracking accuracy ([PAGE 11]).

The fourth hop is spatial and depth geometry. Humans build a polygon with targets as vertices and track its center of mass overtly while monitoring vertices covertly ([PAGE 12]). This configuration cue improves occlusion handling for vehicles on highways ([PAGE 14]). Binocular stereopsis yields a bilateral hemifield advantage stronger in MOT than MIT ([PAGE 12]), and overall accuracy is higher in 3D than 2D ([PAGE 12-13, references 62-63, 68]). Historical and scientific lineage.

The intellectual genealogy begins with Pylyshyn & Storm (1988), cited on [PAGE 8], who introduced the multiple independent targets paradigm and argued for a parallel tracking mechanism. This is the root node from which the MIT/MOT distinction grows: Oksama & Hyönä (2016, [PAGE 6-7]) split tracking into ambient position tracking and focal identity tracking, while Cavanagh & Alvarez (2005, [PAGE 22]) proposed multifocal attention with a capacity of roughly four targets. The Atkinson–Shiffrin memory model (ASMM), referenced on [PAGE 17], supplies the temporal substrate (sensory → short-term → long-term) that computer-vision memory trackers explicitly emulate. Goodale & Milner’s two-stream hypothesis ([PAGE 16-17, reference 100]) underwrites the spatiotemporal continuity algorithms that separate "what" (identity/appearance) from "where" (location/motion) pathways.

Multi-week traps appear in the experimental-temporal domain. Familiarity effects are block-structured: target and distractor identities remain constant within a block of trials in the familiarity condition and change every trial in the unfamiliarity condition ([PAGE 8-9]). Over repeated exposures within a block, cognitive load for identity encoding drops, producing a within-session learning curve that can masquerade as a stable capacity limit if the block duration is not controlled. Emotional content introduces another trap: angry faces are tracked more successfully than neutral faces, an effect persisting even when angry faces appear among distractors ([PAGE 9-10]). This affective prioritization can bias longitudinal studies if emotional valence is not counterbalanced across weeks of testing. The serial versus parallel controversy itself is a multi-week theoretical trap: Wu & Wolfe (2018, [PAGE 7]) found no fixation-frequency difference with set size for either task, challenging the serial-MIT/parallel-MOT dichotomy, while Li et al. (2019, [PAGE 8]) showed the pattern reverses depending on whether high-resolution identity information is required. These lineage traps imply that any capacity estimate extracted from a single experimental block or a single stimulus family is non-robust across the full task ontology.

<RECURSIVE_THEORY_OF_MIND>
Crisis habit regression versus counter-trap versus clock.

Crisis habit regression: under attentional crisis (high set size, low discriminability, or crowding), human observers regress from parallel covert tracking to serial overt fixations. The paper reports that slowing target motion induces serial tracking even in MOT-like conditions, with fixation frequency and target visits increasing with set size ([PAGE 6-7]). Identity processing becomes mandatory and consumes shared resources, lowering location accuracy ([PAGE 11]). This regression is the biological fallback when the ambient system is overwhelmed.

Counter-trap: computer-vision algorithms can escape the regression by assigning separate processing branches or cores to each target, exploiting parallel hardware ([PAGE 8]). The dynamic CNN framework with separate branches per tracker ([PAGE 16]) and LSTM-based data association ([PAGE 18-19]) are algorithmic counter-traps designed to avoid serial bottlenecks. However, the counter-trap contains its own trap: assigning network sub-units to targets has no evidence in brain organization ([PAGE 21]), and identity switching remains a failure mode when targets share features ([PAGE 10-11]).

Clock: the temporal layer is governed by motion extrapolation and refresh cycles. Position representations lag behind actual target positions ([PAGE 21, reference 122]); the brain may not predict future positions during tracking of more than two targets ([PAGE 21]). Temporal attention weights previously detected samples against new ones according to occlusion amount ([PAGE 16]). The clock variable is the update interval \(\Delta t\): if \(\Delta t\) exceeds the motion-coherence time, tracking drifts; if \(\Delta t\) is too short, computational cost rises without accuracy gain. The recursive loop is thus: crisis triggers serial regression → serial regression increases temporal sampling cost → increased cost forces larger \(\Delta t\) → larger \(\Delta t\) worsens lag → lag triggers identity loss → identity loss triggers further regression. The veto point is reached when \(\Delta t\) cannot be reduced because hardware or attentional capacity saturates.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical, biomechanical, and environmental veto proof.

Physical layer: human foveal vision captures high-resolution information from only a small part of the visual field at any time ([PAGE 22]); binocular depth information improves MTT performance ([PAGE 5, 12-13]). Monocular algorithms lack this physical cue and therefore fail under depth-ambiguous occlusion or scale variation. Veto condition: \(V_{\mathrm{phys}} = 1\) if the sensor is monocular and the scene contains depth-dependent occlusion or clutter ([PAGE 22]).

Biomechanical layer: saccades, fixation frequency, pupil dilation, and rescue saccades are bounded by oculomotor physiology ([PAGE 6-7, 13]). The fovea projects crowded targets onto high spatial resolution, enabling rescue saccades toward critically proximate targets ([PAGE 13, references 78-80]). Veto condition: \(V_{\mathrm{bio}} = 1\) if inter-target spacing falls below the minimum saccadic landing precision or if required rescue-saccade rate exceeds oculomotor bandwidth.

Environmental/weather layer: occlusion, crowding, illumination changes, and variable target appearance are environmental stressors ([PAGE 13-14, 17]). Complete occlusion removes the visual input channel; if occlusion duration \(T_{\mathrm{occ}}\) exceeds working-memory decay \(\tau_{\mathrm{WM}}\), the target is lost ([PAGE 13-14, 17]). Veto condition: \(V_{\mathrm{env}} = 1\) if \(T_{\mathrm{occ}} \ge \tau_{\mathrm{WM}}\) OR if crowding reduces \(d_{\mathrm{target-distractor}}\) below \(d_{\mathrm{crit}}\) OR if illumination changes invalidate the appearance model without a memory module ([PAGE 17]).

Composite veto: tracking success is vetoed if \(V = V_{\mathrm{phys}} \lor V_{\mathrm{bio}} \lor V_{\mathrm{env}} = 1\). The paper notes that almost no existing algorithm unifies attention, memory, and motion prediction into one building-block set ([PAGE 20]), so the composite veto remains active in current state-of-the-art systems.
