It then links to subjectivist probability, where beliefs are expressed through willingness to stake, and to Shannon information, where “The agent seeks to maximise the expected logarithmic growth rate:” [PAGE 4]. Kelly made this dynamic, and the source says “Informational advantage is thus converted directly into long-run capital growth.” [PAGE 4]. Thorp operationalized edge detection and risk control; Benter added a key statistical correction: “fractional Kelly to reduce sensitivity to estimation error” [PAGE 4]. Football modeling inherits a parallel ancestry: Dixon-Coles, state-space models, dynamic Poisson intensity, expected-goals models, and physical-context features such as weather, travel, and altitude [PAGE 5].

Multi-week traps are encoded in non-stationarity. First, league-level regimes shift: home advantage changed under pandemic crowd restrictions [PAGE 2], and the 2023/24 season was “unusually high scoring” [PAGE 9]. A model calibrated to prior seasons can therefore inherit a biased prior. Second, promoted teams create cold-start distribution shift: the source says “No general handling of newly promoted teams” [PAGE 13]. Third, parameter drift within a season makes static fits stale; the market updates continuously while many agents do not. The recursive lesson is that backtests must be walk-forward, fold boundaries must respect time, and any feature must be tested for stability before deployment.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
Model each agent as a policy \(\pi_t(a\mid \mathcal{F}_t)\) over actions \(a\), including modeling, staking, and tool invocation. In a crisis, defined by a drawdown
\[
D_t = \max_{s\le t}\ln W_s - \ln W_t
\]
exceeding a tolerance, a competent agent should update beliefs and possibly reduce exposure. The observed models often show habit regression: entropy of the action distribution collapses to a fallback behavior. Examples include Kimi’s “Kelly code written but never invoked” [PAGE 12], GLM’s fixed draw probability that was diagnosed but not changed [PAGE 13], and Opus deferring to a flawed model after diagnosing it [PAGE 13]. This is not merely lack of knowledge; it is a failure of recursive self-correction. The agent knows at the meta-level that its model is broken, but the execution loop does not feed that knowledge into code or staking.

A counter-trap policy would maintain an explicit monitor: verify that the code invoked matches the intended staking rule, compare predicted probabilities to realized frequencies, and trigger a pivot when calibration drifts. The paper’s best seeds approximate this: walk-forward retraining, fractional Kelly, and penny-stake preservation when edge disappears [PAGE 11, 14]. The clock adds another pressure: episodes require “500-1000 tool calls” [PAGE 8] and context management. When context degrades, tool formatting fails and the agent enters loops, as with Kimi’s repeated malformed shell commands [PAGE 18]. Thus crisis behavior is the interaction of three clocks: financial drawdown, model staleness, and context/tool-call decay.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical, biomechanical, and weather variables can veto a claimed edge if they are not in the agent’s information set at decision time or if their predictive content is already reflected in the public price. Let \(\mathcal{F}_t\) be all timestamped data available before matchday \(t\), and let \(Z_t\) denote physical context such as weather, travel, altitude, fatigue, or availability. A claimed edge from \(Z_t\) is admissible only if the agent can form a distribution \(P(Z_t\mid \mathcal{F}_t)\) and the conditional mutual information
\[
I(X_t; Z_t \mid \mathcal{F}_t)
\]
is positive after conditioning on the public measure \(q_t\). If \(I=0\), then \(Z_t\) adds no decision-relevant information and the claimed edge is a phantom. If \(Z_t\) is realized only after the decision boundary, no staking rule can exploit it.

The source supports this veto. It lists weather, travel, and altitude as potential fundamental features [PAGE 5], but also admits important data are missing: “we do not give models any tracking data” [PAGE 20], and it does not provide set-piece or in-play information. The closing price may contain availability news, but that news is not supplied to the agent [PAGE 20]. The source also says, “The English Premier League is widely regarded as one of the most informationally efficient prediction markets in the world” [PAGE 20]. Therefore, any model claiming a physical edge must prove that its feature is timestamped before the decision, measured without leakage, and not already encoded in \(q_t\). The formal proof is by contradiction: if the feature is not in \(\mathcal{F}_t\), then
\[
\mathbb{E}[r_t\mid \mathcal{F}_t, \text{feature}]
\]
cannot be conditioned on it; if it is in \(\mathcal{F}_t\) but already priced, then \(D_{\mathrm{KL}}(p^*\Vert q)\) has no residual component from that feature. In either case, the edge is vetoed unless a causal, pre-decision, unpriced signal is demonstrated.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Use verifiable reward \(r_t = \ln(W_{t+1}/W_t)\) as the RLVR anchor. Each counterfactual below predicts a sign and magnitude in reward or calibration error.

1. Information sufficiency veto. Counterfactual: give agents true pre-decision availability and physical context \(Z_t\), with a timestamp audit proving \(Z_t\in\mathcal{F}_t\). If the negative returns persist and \(\Delta\mathrm{LL}\) does not improve by at least \(0.02\) nats per event, then market efficiency plus model quality, not missing data, dominates. Prediction: if missing data were the primary veto, Claude Opus 4.6’s best seed should improve from \(+21.5\%\) to above \(30\%\), or its five-seed average should become positive. If not, the data-sufficiency hypothesis is vetoed.

2. Execution integrity veto. Counterfactual: enforce that any written staking routine is invoked, tool calls are syntactically validated, and the bankroll update is reconciled after each matchday. If the knowledge-action gap is the main failure, ROI should improve materially. Prediction: Kimi’s invoked-Kelly rate moves from near zero to \(1.0\), and its average return improves from \(-89.6\%\) to above \(-20\%\). If no improvement occurs, execution failure is not the dominant veto.

3. Contamination or aggregate-season leakage veto. Counterfactual: disclose only the high-scoring nature of the test season and require explicit calibration of draw probability. If agents silently exploit season-level memory, then draw log-loss should improve by at least \(0.02\) nats and ROI should rise when the agent removes an empirical draw-inflation factor. Prediction: models that previously hardcoded a \(25\%\) draw rate should reduce it toward the realized frequency and show lower log-loss. If no change occurs, reward hacking from season memory is not detectable in this setup.

These vetoes are RLVR-compatible because each predicts a measurable change in the verifiable reward or calibration error. They prevent post hoc storytelling: a hypothesis survives only if the counterfactual changes the log-wealth path in the stated direction.
</RLVR_COUNTERFACTUAL_VETOES>
