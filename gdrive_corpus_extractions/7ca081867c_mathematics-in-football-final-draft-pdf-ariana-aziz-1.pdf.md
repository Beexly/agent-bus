<CROSS_LAYER_VETO_ADJUDICATION>
The tactical model is subordinate to physical, biomechanical, and weather feasibility. The source’s xG factor list includes goalkeeper position, distance, angle, and body part [PAGE 1], but it does not include wind, rain, pitch friction, ball aerodynamics, or the shooter’s torque limits. The source’s penalty discussion mentions only “better foot or strength” [PAGE 4], so the \(2\times2\) matrix cannot be treated as a complete physical model. Adjudication rule: let \(F(s)\) be the set of actions physically feasible for body state \(s\). If a tactical action \(a\notin F(s)\), then any model probability \(P(Y=1\mid s,a)\) must be set to zero or redefined; a positive probability on an infeasible action is a misspecification. Biomechanical veto: if the required joint torque \(\tau_{\mathrm{req}}\) exceeds the maximum voluntary torque \(\tau_{\max}\), or if the required angular acceleration \(\alpha_{\mathrm{req}}=\tau_{\mathrm{req}}/I\) exceeds the joint’s capacity, the action is infeasible. Flight-time veto: for shot distance \(L\) and ball speed \(v\), \(t_f=L/v\); if the available keeper time \(t_f\) is below reaction plus dive time, the keeper cannot reach a target region, so a model that assigns keeper interception probability as if he could is vetoed. Weather veto: with lateral wind acceleration \(a_w\), lateral deviation is approximately \(\Delta x_w=\tfrac12 a_w t_f^2\); if \(|\Delta x_w|\) exceeds the goal half-width or the intended placement tolerance, the shot cannot be treated as on-target without a wind feature. The source’s “Cosine Rule” angle [PAGE 1] is a static geometry; it is vetoed as a sufficient statistic whenever wind or ball spin changes the trajectory. The correct adjudication is not to discard the tactical model but to condition it: \(p_{\mathrm{final}}=p_{\mathrm{tactical}}\cdot \mathbf{1}[a\in F(s)]\) for hard infeasibility, and a calibrated downward adjustment when soft constraints such as wind increase trajectory variance. This is the cross-layer proof: probability mass cannot be assigned to impossible physical events in a well-calibrated model.
