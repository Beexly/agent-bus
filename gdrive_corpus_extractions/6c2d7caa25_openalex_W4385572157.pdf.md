The source is an ACL 2023 paper, GRACE, whose central claim is that attribute-controlled text generation can be improved by combining a frozen PLM with (i) a trained attribute discriminator, (ii) a non-parametric retrieval repository built from unlabeled corpora, (iii) anti-target debiasing, and (iv) a gradient-guided revision loop. The multi-hop derivation runs from Bayes’ rule to a kNN retrieval heuristic, then to a convex fusion score, then to a discriminator-gradient update that changes the query representation used for subsequent retrieval/generation. The paper states the architecture plainly: “Our framework consists of three parts (see Fig. 2): (1) Attribute Discriminator ... (2) Retrieval Repository ... (3) Generator” [PAGE 3]. The important audit point is that GRACE is not a single equation; it is an operator stack. Eq. 1 is a proportionality derived from Bayes’ rule, Eq. 2 is an additive score, ΔP is a debiasing difference, λ(i) is a step clock, and DΘ−∆Θ is a parameter update. Each has a different failure mode.

The gray-zone issues are substantial. First, Eq. 1 is exact only up to the denominator P(c|Xi); the paper says “Given the current subsequence Xi and the target attribute c, P(c|Xi) is determined by the discriminator” [PAGE 11]. If that denominator approaches zero, the conditional is ill-conditioned even though the softmax is finite in practice. Second, the retrieval sets N+ and N− can be empty or nearly empty; the paper’s averaging over each set then has no defined value. Third, S_fuse is not guaranteed to be nonnegative because ΔP is a difference of probabilities, yet the paper says only that “After the integration, we normalize the score and use the existing decoding strategy” [PAGE 5]. The normalization operator is not fully specified, which matters if λ is large and ΔP is negative. Fourth, the gradient-guided update changes D to DΘ−∆Θ, producing a new r′c; the repository items, however, were built with the original D [PAGE 3], so there is a potential representation-drift/re-indexing ambiguity. Fifth, debiasing assumes domain-specific words have high mass under both P+ and P−; if the target attribute and the domain are perfectly confounded, the subtraction can remove the attribute signal too. The paper itself notes that attribute datasets “imply attributes in specific text domains” [PAGE 13]. Sixth, the human evidence is moderate-agreement, not high-agreement: Fleiss κ = 0.59 [PAGE 7] and κ = 0.54 [PAGE 8]. The source defines the retrieval heuristic as
\[
P_{\mathrm{kNN}}(x_{i+1}\mid c,X_i)\;\propto\;P_{\mathrm{kNN}}(x_{i+1}\mid X_i)\,P(c\mid X_i,x_{i+1}),
\]
which is Eq. 1 in the paper [PAGE 3]. The derivation in Appendix A is
\[
P(c,x_{i+1},X_i)=P(c\mid x_{i+1},X_i)P(x_{i+1}\mid X_i)P(X_i)
\]
and
\[
P(c,x_{i+1},X_i)=P(x_{i+1}\mid c,X_i)P(c\mid X_i)P(X_i),
\]
so that
\[
P(x_{i+1}\mid c,X_i)
=
\frac{P(x_{i+1}\mid X_i)P(c\mid X_i,x_{i+1})}{P(c\mid X_i)}.
\]
The paper then says: “Given the current subsequence Xi and the target attribute c, P(c|Xi) is determined by the discriminator. Therefore, we obtain” the proportionality [PAGE 11]. Units: all \(P(\cdot)\) terms are dimensionless probabilities in \([0,1]\); if log-probabilities were used they would be information quantities in nats or bits, but the paper reports probabilities and PPL, not log-loss units. Assumption: the proportionality is safe only when \(P(c\mid X_i)>0\) and when the discriminator’s conditional is calibrated enough that ranking by the product is meaningful. Breakdown/singularity: \(P(c\mid X_i)\to 0\) makes Eq. 5 ill-conditioned; \(K=0\) or no repository item makes the kNN distribution undefined; and a threshold \(p\) that empties \(N^+\) or \(N^-\) makes the later set averages undefined.

The repository item is formalized as \((r_s,r_c,v_c)\): \(r_s\) is the frozen generator’s context representation, \(r_c\) is the discriminator’s attribute-augmented context representation, and \(v_c\) is the discriminator’s attribute vector for \(X_{i+1}\) [PAGE 3]. Retrieval uses “K nearest items” by similarity between stored \(r_s\) and the query \(r_s\) [PAGE 4]. Attribute retrieval selects items whose \(v_c\) is close to the one-hot target \(c\), using cosine similarity and a threshold \(p\): the paper says “similarities between the items’ attribute vectors vc and the target attribute c excel a threshold p” [PAGE 4]. Units: cosine similarity is dimensionless in \([-1,1]\); \(p=0.9\) is dimensionless. The anti-target set \(N^-\) is built analogously for \(\neg c\), and the footnote defines \(\neg c\) as “all the undesirable attributes” [PAGE 4].

The debiasing operator is
\[
\Delta P(x_{i+1}\mid c,X_i)
=
P^+_{\mathrm{kNN}}(x_{i+1}\mid c,X_i)
-
P^-_{\mathrm{kNN}}(x_{i+1}\mid \neg c,X_i),
\]
as stated on [PAGE 5]. Units: difference of probabilities; if both terms lie in \([0,1]\), then \(\Delta P\in[-1,1]\), and it is not itself a normalized probability. The paper’s intuition is: “if a word has a high probability on both P + kNN(xi+1|c, Xi) and P − kNN(xi+1|¬c, Xi) by retrieving with both c and ¬c, the word is likely critical to the domain instead of the target attribute c” [PAGE 5]. The complementary case is that high \(P^+\) and low \(P^-\) indicates a word “insignificant to the domain but essential to the target attribute” [PAGE 5]. Breakdown: if \(N^-=\varnothing\), then \(\Delta P=P^+\) and debiasing is disabled; if the target and domain are confounded, both terms rise and cancel; if \(N^+=\varnothing\), the attribute signal vanishes.

The fusion operator is
\[
S_{\mathrm{fuse}}(x_{i+1},c,X_i)
=
\lambda\Delta P(x_{i+1}\mid c,X_i)
+
(1-\lambda)P_{\mathrm{LM}}(x_{i+1}\mid X_i),
\]
which is Eq. 2 [PAGE 5]. Units: \(\lambda\) is dimensionless; \(P_{\mathrm{LM}}\) is a probability; \(S_{\mathrm{fuse}}\) is a score that is not guaranteed to be a probability unless normalization is specified. The paper says “a token is desirable if it is consistent with the given context and closely related to the target attribute” [PAGE 5]. The step clock is
\[
\lambda(i)=
\begin{cases}
\dfrac{\lambda_{\min}-\lambda_0}{I}\,i+\lambda_0, & i\le I,\\[4pt]
\lambda_{\min}, & i>I,
\end{cases}
\]
where “\(\lambda_0\) is the initial rate at the 0-th step, \(\lambda_{\min}\) is the minimum rate, and I is a pre-defined step number” [PAGE 5]. Units: \(i\) and \(I\) are token-step counts; \(\lambda\) is dimensionless. Singularity: \(I=0\) makes the slope undefined; the paper uses \(I\in\{20,40,80\}\) [PAGE 6]. The paper sets “λ0 and λmin ... as 0.8 and 0.4” [PAGE 13], so \(\lambda\) decays from 0.8 to 0.4 over the control window. Breakdown: \(\lambda=0\) removes attribute control; \(\lambda=1\) removes the PLM prior; large \(\lambda\) can amplify negative \(\Delta P\) and destabilize normalization.

The gradient-guided operator is: evaluate \(X_{i+1}\) with D; if it does not satisfy the target, “we save the gradient of D’s encoder and classification layer ∆Θ to help update Xi+1” and “we optimize D’s encoder and classification layer according to ∆Θ to obtain DΘ−∆Θ” [PAGE 5]. The paper then says the updated discriminator “produces context representations containing richer attribute-related information, which is helpful for retrieving texts with the target attribute” [PAGE 6]. The paper limits “the maximum iteration number in Sec. 3.4 to 1” [PAGE 13], and notes “The gradient update in Sec. 3.4 only affects the current generation output and does not influence other generated sentences” [PAGE 6].

<RETROCAUSAL_GENEALOGY>
GRACE’s lineage is retrocausal: it recombines earlier operators and then reinterprets them as one pipeline. The retrieval heuristic is explicitly borrowed: “The idea of retrieval follows the heuristic in Eq. 1 inspired by Krause et al. (2021)” [PAGE 4]. That points to GeDi’s Bayes-rule style control. The inference-control lineage includes PPLM, which “updates the hidden states toward the target tokens” [PAGE 2], and FUDGE, which “adjusts word probabilities with the discriminator’s prediction of whether the future generation satisfies the attribute” [PAGE 2]. The debiasing lineage includes DExperts: “DEXPERTS (Liu et al., 2021) combines the output distributions from attribute-specific expert and anti-expert models” [PAGE 2]. The retrieval lineage includes kNN language modeling and retrieval-augmented generation; the paper cites Khandelwal et al. for nearest-neighbor language models and uses FAISS for fast retrieval [PAGE 6/10]. In that sense, GRACE is a retrocausal assembly: kNN memorization supplies fluency and natural-language patterns, GeDi supplies the attribute likelihood heuristic, DExperts supplies the expert/anti-expert subtraction, and PPLM/FUDGE supply the inference-time control posture.

The historical trap is that each ancestor solved a different problem. Fine-tuning-based control, represented by GPT2-F, “excels GRACE in attribute accuracy” but “is the worst in domain resemblance” [PAGE 7]; the paper’s appendix shows GPT2-F generating movie-review-like text even for arbitrary prefixes [PAGE 20]. A multi-week research program that responds by fine-tuning longer will therefore buy controllability at the cost of domain lock-in. The second trap is keyword stuffing: FUDGE “may repeat specific keywords because it increases the possibilities of a limited number of keywords” [PAGE 7], and the examples show repetition pathologies [PAGE 15-18]. A multi-week program that adds more attribute keywords can improve a classifier score while degrading fluency. The third trap is removing debiasing to improve surface fluency: the ablation says “−Debias is the highest in domain resemblance and underperforms GRACE-40 in attribute accuracy” [PAGE 8]. The fourth trap is skipping revision: “−Revision generates without the gradient-guided generation scheme ... and achieves low attribute accuracy” [PAGE 8]. The fifth trap is over-retrieving: GRACE-80 reaches high attribute accuracy but lower human Qual than GRACE-20 in Table 1 [PAGE 7]. The sixth trap is measurement circularity: automatic attribute relevance uses an SST-2 sentiment classifier and a BERT topic classifier trained on Agnews [PAGE 6], so a system can learn domain-correlated cues that the evaluator rewards. These are multi-week traps because they look like incremental wins early and only surface when cross-domain or human evaluation is added.

<RECURSIVE_THEORY_OF_MIND>
The recursive loop is explicit: the generator produces \(x_{i+1}\), the discriminator evaluates \(X_{i+1}\), and if the suffix fails the target the system saves \(\Delta\Theta\), updates D, re-encodes, re-retrieves, and regenerates [PAGE 5]. This is a theory-of-mind-like self-model: the generator is not only predicting the next token; it is predicting how its own future suffix will be judged by D, then revising the judge to make the suffix more retrievable toward \(c\). The paper describes the effect as “When DΘ−∆Θ is optimized toward the target attribute, its encoder produces context representations containing richer attribute-related information” [PAGE 6]. The risk is that the judge and the generator co-adapt to the same bias.

Crisis habit regression appears when control pressure rises and the model falls back to high-frequency domain habits. The paper’s examples are diagnostic: PPLM “may degenerate toward repeating the same word when the PLM’s latent representations are not properly updated” [PAGE 7], and FUDGE “may repeat specific keywords” [PAGE 7]. GPT2-F regresses to movie-review style because fine-tuning entangles attribute with domain [PAGE 7/20]. In GRACE terms, crisis regression is what happens when retrieval is sparse or \(\Delta P\) is dominated by domain mass: the model’s “habit” is the repository’s most frequent domain pattern, not the target attribute.

The counter-trap is anti-target retrieval. \(N^-\) is a counterfactual set: “what would the repository produce under \(\neg c\)?” Subtracting \(P^-\) is meant to remove words that are “critical to the domain instead of the target attribute c” [PAGE 5]. But the counter-trap is confounded counterfactual: if \(\neg c\) is also the domain marker, the subtraction can remove the target’s own lexical signal. The paper’s own dataset discussion warns that attributes are embedded in specific domains [PAGE 13], so the counter-trap is real, not hypothetical.

The clock is the \(\lambda(i)\) schedule plus the stopping rule. The paper says “the early generation sets the tone for the entire generation and is the key to achieving a controlled generation,” and gives the example that “if the generation starts with ‘The pizza is awful’, the generated result tends to imply a negative sentiment” [PAGE 9]. Hence the strongest control is early: \(\lambda\) starts at 0.8 and decays to 0.4, and retrieval stops after \(I\) steps [PAGE 5/13]. The clock has two failure modes: too short a window and the suffix drifts back to PLM habits; too long a window and the model over-controls, reducing fluency, as the GRACE-80 vs GRACE-20 trade-off shows [PAGE 7]. The revision clock is also short: maximum iteration \(=1\) [PAGE 13], which avoids runaway self-correction but also means a single discriminator false positive can terminate the loop.
</RECURSIVE_THEORY_OF_MIND>
