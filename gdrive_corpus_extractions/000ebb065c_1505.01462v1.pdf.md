This is not probabilistic — it is structural. Footnote [PAGE 19] shows experiment (b) used a disconnected topology and had to be excluded from aggregation. Adjudication: **absolute veto**; check connectivity before any rate claim.

**Veto 2 — Boundedness $\ell_\infty$.** Proposition 17 [PAGE 36] is an unconditional proof: with unbounded $\mathcal W_\infty$, $\sup_{w^\*}\mathbb E\|\hat w-w^\*\|_2^2=\infty$. *Proof sketch (verbatim):* "for every comparison, the item with the higher quality score … wins," an event of probability $\ge 2^{-n}$, under which $w^\*$ is indistinguishable from $cw^\*$ for all $c\ge0$ [PAGE 36]. Since this event has probability bounded away from 0, expected error is unbounded. Adjudication: **absolute veto as $B\to\infty$**; the physical analog is the flattening of $F$ (probabilities saturating near 0/1) that destroys curvature information.

**Veto 3 — Model misspecification (F wrong / misspecified link).** All constants $\gamma,\zeta$ are computed from the assumed $F$. The MTurk evidence [PAGE 16] explicitly warns "model misspecification can in some cases cause the outcomes to differ from our theoretical predictions," and Table 2 [PAGE 20] shows the ranking of ordinal vs cardinal flipping across tasks (spelling: cardinal wins; distance/audio: ordinal wins) — exactly what unmodeled heteroscedastic human noise would produce. Adjudication: **soft but decisive veto** — the *rate* $d/n$ or $d^2/n$ is robust (it depends only on $L$ and the strong-log-concavity class), but the *constant* $b_u,b_\ell$ and hence the paradigm decision are fragile. The "biomechanical" analog here is the human cognitive limit on comparing $>m$ items [PAGE 10, Miller 1956; Saaty–Ozdemir 2003], which caps $m=O(1)$ and prevents the naive escape of "just present more items to get more information per sample."

Cross-layer verdict: physical vetoes 1–2 are binary (satisfied or the theorem is void); veto 3 only perturbs constants, so topology-selection conclusions (which graphs are optimal) survive misspecification, while the cardinal/ordinal *crossover* does not.

Three falsifiable scenarios, each with a checkable prediction derived strictly from the paper.

**Counterfactual A — "Topology doesn't matter."** *Veto setup:* Run synthetic Thurstone estimation at fixed $d$ on a star vs a path graph. *Prediction:* theory [PAGE 12] mandates $\lambda_2^{\text{star}}=\Theta(1/d)$ vs $\lambda_2^{\text{path}}=\Theta(1/d^3)$, so the rescaled error $\|\hat w-w^\*\|_2^2\, n/d^2$ stays $O(1)$ for the star but *grows* for the path; equivalently the path needs $\sim d$ times more samples for equal error. *Verifiable:* Figure 3 [PAGE 15] and MTurk Figure 4 [PAGE 16] confirm complete/star best, path worst. Falsifier: if path and star overlapped at equal $n,d$, the $\lambda_2$ theory is wrong.

**Counterfactual B — "Cardinal always wins (more bits = more info)."** *Veto setup:* Compare minimax $\ell_2$ error when $\sigma_c>\sigma$ (ordinal less noisy). *Prediction:* (12a)/(12b) [PAGE 19] give cardinal $\sigma_c^2 d/n$ vs ordinal $\le \sigma^2 b_u d/n$; whenever $\sigma^2 b_u(\sigma,B)<\sigma_c^2$ the ordinal error is strictly smaller *despite one-bit labels*. *Verifiable:* Table 1 [PAGE 18] shows ordinal per-sample error < cardinal-converted for 5 of 7 tasks (e.g., circle 6% vs 17%, audio 20% vs 29%). Falsifier: uniform ordinal $\ge$ cardinal error across all tasks would rescue the DPI intuition.

**Counterfactual C — "Unbounded quality is estimable."** *Veto setup:* Drop $\|w^\*\|_\infty\le B$ and attempt estimation over $\mathcal W_\infty$. *Prediction:* Proposition 17 [PAGE 36] forces minimax risk $=\infty$ in both $\|\cdot\|_2$ and $\|\cdot\|_L$, because the all-orderings-correct event (prob $\ge 2^{-n}$) leaves scale $c$ unidentifiable. *Verifiable/derivable:* any estimator's worst-case risk is unbounded; a simulation with $w^\*$ scaled by $c\to\infty$ shows error growing without limit as $F$ saturates. Falsifier: a bounded-risk estimator over all of $\mathcal W_\infty$ would contradict the two-point argument.

Each veto is an operational rejection test: run the comparison, check the predicted ordering/scaling, and the corresponding theoretical claim either survives or is empirically falsified.
