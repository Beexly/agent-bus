Deep multi-hop derivation & gray-zone audit:

The paper’s reasoning chain can be reconstructed as a sequence of weakly supervised operators. First, a video is represented by a global frame feature and a set of person-centric features. Second, each person track is encoded temporally by a bidirectional recurrent network. Third, an attention distribution over the currently detected persons produces an attended player representation at each time step. Fourth, an event-state recurrent network consumes the global frame context and the attended player representation to classify or detect an event. The key gray zone is that the attention mechanism is not directly supervised as “shooter” or “key actor”; it is only indirectly shaped by event classification loss. Therefore, any claim that attention identifies the key actor must be evaluated through auxiliary probes, such as the paper’s ball-distance shooter evaluation.

A second gray zone is the difference between tracking-based and tracking-free attention. The tracking-based model can aggregate information over a player’s trajectory, which should improve representation when identity is stable. However, the same temporal aggregation can create a prior for players who remain visible for the entire event. The paper explicitly acknowledges this failure mode: the tracking model can become attached to a persistent defender rather than the momentary shooter. This is important because the event label may depend on a transient interaction, while the recurrent track representation is biased toward continuity. The no-tracking model avoids identity persistence but loses temporal denoising and is more exposed to per-frame detection noise, occlusion, and identity ambiguity.

A third gray zone is the evaluation proxy for “key actor.” The authors label the shooter as the player closest in image space to the annotated ball on a subset of test clips. This is a reasonable physical proxy for shot events, but it is not a universal definition of key actor for all event phases. For a steal, two players may jointly define the event. For defensive formations, a defender may be informative even if not closest to the ball. Thus, the shooter AP table should be interpreted as evidence for transient attentional localization, not as proof that attention always recovers the causal actor of every event.

A fourth gray zone is detection versus classification. The classification benchmark uses isolated 4-second clips. The detection benchmark slides a 4-second window over untrimmed videos and includes a large set of negatives. The introduction of negatives changes the decision problem: many negatives are ordinary basketball actions, especially passes, that resemble steals. The paper notes that steal detection is especially hard because passes and steals are similar except for team possession. This means that a model can perform well on isolated clip classification yet still produce false positives in continuous detection due to hard negatives.

A fifth gray zone is the role of the softmax temperature. The attention weights depend on a temperature parameter. Low temperature sharpens attention and approximates hard selection; high temperature flattens attention and approaches uniform pooling. The chosen temperature affects both performance and interpretability. If attention becomes too sharp, gradient flow to non-selected players may weaken. If attention becomes too flat, the model loses discriminative person selection. The paper selects temperature by validation, but does not provide a full sensitivity analysis across event classes, occlusions, or detection recall.

Overall, the safest derivation is: the model learns a temporally conditioned mixture over person representations, and the mixture can localize event-relevant players when the visual evidence is temporally local and the event class has a strong spatial signature. The risk is that recurrence, tracking, and class imbalance can cause the mixture to lock onto persistent, visually stable actors that are not the true event initiators.

Assumptions and units:

1. Time is discretized into video frames. The dataset uses 4-second clips subsampled to 6 frames per second, so the frame interval is Δt = 1/6 s ≈ 0.1667 s [PAGE 5].  
   Quote: “All the event videos clips were four seconds long and subsampled to 6fps.” [PAGE 5]

2. Frame features are activations, not physical SI quantities. A frame feature vector f_t has dimension 1024 and is treated as a dimensionless real vector, f_t ∈ ℝ^{1024} [PAGE 4].  
   Quote: “Each video-frame is represented by a 1024 dimensional feature vector ft” [PAGE 4].

3. Player features combine appearance and spatial localization. For player i in frame t, p_t^i ∈ ℝ^{2805}, composed of a 1365-dimensional appearance vector and a 1440-dimensional spatial vector [PAGE 4].  
   Quote: “we compute a 2805 dimensional feature vector pti which contains both appearance (1365 dimensional) and spatial information (1440 dimensional)” [PAGE 4].

4. Recurrent hidden states have dimension 256.  
   Quote: “We used a hidden state dimension of 256 for all the LSTM and BLSTM RNNs” [PAGE 5].  
   Units: dimensionless real vector space ℝ^{256}.

5. Attention weights form a probability distribution over detected persons at time t. If N_t is the number of detections, then γ_t ∈ Δ^{N_t−1}, where Δ^{N_t−1} is the probability simplex. Units: dimensionless probabilities summing to 1.

6. The loss is a squared-hinge multi-class loss and is dimensionless.  
   Quote: “We measure the squared-hinge loss as follows” [PAGE 4].

7. Mean average precision, mAP, is reported as a scalar in [0,1] and is dimensionless. Tables 2–4 report mAP values [PAGE 6][PAGE 7].

Formal equations from the paper:

Frame-level bidirectional context:

\[
h_t^f = \mathrm{BLSTM}_{\mathrm{frame}}(h_{t-1}^f, h_{t+1}^f, f_t)
\]

Source citation and quote: “This is a concatenation of the hidden states from the forward and reverse LSTM components of a BLSTM” [PAGE 4].  
Units: h_t^f ∈ ℝ^{256}; f_t ∈ ℝ^{1024}.  
Breakdown regimes: at sequence boundaries, h_{t-1}^f or h_{t+1}^f may be undefined unless boundary padding or zero initialization is specified. If the clip has only one frame, bidirectional context collapses.

Event-state recurrence:

\[
h_t^e = \mathrm{LSTM}(h_{t-1}^e, h_t^f, a_t)
\]

Source citation and quote: “Next we use a unidirectional LSTM to represent the state of the event at time t” [PAGE 4].  
Units: h_t^e ∈ ℝ^{256}; a_t is the attended player representation.  
Breakdown regimes: if a_t is undefined because N_t = 0, the event state cannot be updated from player evidence.

Squared-hinge loss:

\[
L = \frac{1}{2}\sum_{t=1}^{T}\sum_{k=1}^{K}
\max\left(0, 1 - y_k w_k^\top h_t^e\right)^2
\]

Source citation and quote: “We measure the squared-hinge loss as follows” [PAGE 4].  
Units: L is dimensionless. y_k ∈ {−1,+1}; w_k ∈ ℝ^{256}; h_t^e ∈ ℝ^{256}; K = 11 event classes [PAGE 1][PAGE 3].  
Breakdown regimes: if margins are very large, loss becomes zero and provides no gradient; if features or weights are unbounded, numerical overflow can occur.

Player-track BLSTM:

\[
h_{t,i}^p = \mathrm{BLSTM}_{\mathrm{track}}(h_{t-1,i}^p, h_{t+1,i}^p, p_t^i)
\]

Source citation and quote: “The latent representation of player i in frame t is given by the hidden state hp ti of the BLSTM across the player-track” [PAGE 5].  
Units: h_{t,i}^p ∈ ℝ^{256}; p_t^i ∈ ℝ^{2805}.  
Breakdown regimes: track birth/death, occlusion, identity switch, or missing detections make h_{t,i}^p undefined or unreliable. The paper acknowledges that tracking can be difficult in crowded scenes: “Often, tracking people in a crowded scene can be very difficult due to occlusions and fast movements.” [PAGE 5].

Tracking-based attention:

\[
a_t^{\mathrm{track}} = \sum_{i=1}^{N_t} \gamma_{t,i}^{\mathrm{track}} h_{t,i}^p
\]

\[
\gamma_{t,i}^{\mathrm{track}} =
\mathrm{softmax}\left(
\phi(h_t^f, h_{t,i}^p, h_{t-1}^e); \tau
\right)
\]

Source citation and quote: “we compute at as a convex combination of the player representations at that time-step” [PAGE 5].  
Units: γ_{t,i}^{track} ∈ [0,1], ∑_i γ_{t,i}^{track} = 1. τ is the softmax temperature parameter and is treated as a dimensionless scalar [PAGE 5].  
Breakdown regimes: N_t = 0 makes the convex combination undefined; τ → 0^+ approaches hard argmax attention; τ → ∞ approaches uniform attention. If φ outputs unbounded logits, numerical softmax overflow can occur.

Tracking-free attention:

\[
a_t^{\mathrm{notrack}} = \sum_{i=1}^{N_t} \gamma_{t,i}^{\mathrm{notrack}} p_t^i
\]

\[
\gamma_{t,i}^{\mathrm{notrack}} =
\mathrm{softmax}\left(
\phi(h_t^f, p_t^i, h_{t-1}^e); \tau
\right)
\]

Source citation and quote: “this is similar to the tracking based attention equations except for the direct use of the player detection feature pti in place of the BLSTM representation hp ti” [PAGE 5].  
Units: same as above.  
Breakdown regimes: detection noise directly enters the attention distribution; identity switches matter less, but per-frame bounding-box jitter and occlusion can corrupt p_t^i.

Information-theoretic audit constructs:

The attention distribution at time t is a categorical distribution over N_t persons. Its entropy is:

\[
H(\gamma_t) = -\sum_{i=1}^{N_t} \gamma_{t,i} \ln \gamma_{t,i}
\]

Units: nats. If log base 2 is used, units are bits.  
Interpretation: H(γ_t) = 0 means all attention is on one person; H(γ_t) = ln N_t means uniform attention over N_t persons.  
Breakdown: undefined if N_t = 0.

\[
\ell_{\mathrm{attn}}(t) = -\ln \gamma_{t,s_t}
\]

Units: nats.  
Assumption: the shooter is defined as the player closest in image space to the ball. Source: “we labeled the player who was closest (in image space) to the ball as the ‘shooter’.” [PAGE 7]  
Breakdown: ball annotations exist only for 850 test clips [PAGE 3][PAGE 7], so this proxy is not available for all events.

Breakdown: if ball is occluded or annotation is missing, D_i(t) cannot be computed.

<RETROCAUSAL_GENEALOGY>
Historical and scientific lineage:

The paper sits at the intersection of four lineages: recurrent video modeling, attention alignment, weakly supervised localization, and multi-person activity recognition. The attention lineage is explicitly connected to machine translation, image captioning, and video captioning. The authors state that prior work uses attention to align input elements to output tokens: “[3] translate sentences in one language to another language, attending to different words in the input; [68] generate an image-caption, attending to different regions in the image; and [70] generate a video-caption, attending to different frames within the video.” [PAGE 2]. The novelty is not merely applying attention to video, but applying attention to a variable-size set of person tracks or detections within each frame.

The recurrent lineage comes from LSTM/BLSTM models for sequence modeling. The paper cites Graves et al. for bidirectional LSTM and uses BLSTM both for frame context and for player-track representations [PAGE 4][PAGE 5]. This lineage brings a temporal assumption: hidden states summarize history and, in bidirectional form, future context. That assumption is useful for event phase modeling but also creates a historical bias: if a player is present for a long time, the recurrent representation may become more stable and therefore more attractive to attention.

The weakly supervised localization lineage comes from the desire to avoid expensive key-actor annotations. The paper frames this as “weakly supervised key person identification” [PAGE 1]. This is retro-causally important: because the model is not told who the key actor is, any apparent localization must be evaluated post hoc. The paper does this with ball-proximity shooter labels, but only on a subset of test clips [PAGE 3][PAGE 7]. This creates a multi-week evaluation trap: researchers may overinterpret attention heatmaps as causal explanations when they are only correlational responses to training loss.

Multi-week traps:

Trap 1: Train/test leakage through game identity. The split is by video, which is correct, but if future experiments use overlapping games, venues, teams, or broadcast styles, apparent gains may come from domain familiarity rather than event reasoning.

Trap 2: Confusing clip classification with event detection. Isolated clip classification can be easier because the event is centered in the clip. Detection introduces negatives, especially passes and transitional play, making the task harder. The paper shows this gap for steal: classification mAP is high but detection mAP drops, and the authors explain that negatives “often correspond to players passing the ball to each other” [PAGE 6].

Trap 3: Treating tracking as always beneficial. The tracking model slightly improves classification mAP overall, but the paper also finds that tracking can make attention less selective for the shooter: “the tracking model is often reluctant to switch attention between frames and focuses on a single player throughout the event.” [PAGE 7]. A multi-week experiment that only reports classification accuracy may incorrectly conclude that tracking universally improves key-actor localization.

Trap 4: Ignoring class imbalance. The dataset includes rare classes such as slam dunk failure. The paper notes poor performance for classes with little data: “performance is much poorer (for all methods) for classes such as ‘slam dunk fail’ for which we have very little data.” [PAGE 6]. Any model comparison that averages over classes can hide failure on rare but semantically important events.

Trap 5: Treating attention entropy as interpretability. Attention weights can be sharp because the model is confident, but confidence may reflect scene persistence rather than event causality. The free-throw example is the canonical trap: the tracking model attends to a defender who is visible throughout the event, even though the shooter is the transient actor of interest [PAGE 7].
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
Crisis habit regression vs counter-trap vs clock:

The paper can be interpreted as a recursive theory-of-mind problem involving three agents: the model, the annotator/evaluator, and the physical event. The model tries to infer which person matters. The evaluator defines key actor through a proxy, usually ball proximity. The physical event defines the true interaction, such as a shot, pass, steal, or rebound. Crisis occurs when these agents disagree because visual persistence, occlusion, or annotation sparsity makes the proxy ambiguous.

Crisis habit regression:

Under crisis, the model regresses to habits learned from visual stability. In tracking-based attention, the habit is to remain with a player track because the track representation is temporally smoothed. The paper observes exactly this: “the tracking model is often reluctant to switch attention between frames and focuses on a single player throughout the event. This biases the model towards players who are present throughout the video.” [PAGE 7]. In free-throw events, the model may attend to a defender with a stable court position rather than the shooter, because the defender is continuously visible. This is a recursive habit: the model assumes that the most reliably tracked person is the most relevant person.

Counter-trap:

The counter-trap is to break temporal persistence. The no-tracking model does this by attending directly to per-frame detections. The paper motivates it by saying: “Often, tracking people in a crowded scene can be very difficult due to occlusions and fast movements. In such settings, it is beneficial to have a tracking-free model.” [PAGE 5]. The no-tracking model allows attention to switch more freely. Empirically, this improves shooter localization on several classes. The attention evaluation table shows mean shooter AP of 0.618 for no-track attention versus 0.438 for track attention [PAGE 7]. For free-throw success, no-track AP is 0.772 versus 0.416 for track attention; for free-throw failure, no-track AP is 0.685 versus 0.387 [PAGE 7]. This is strong evidence that the counter-trap succeeds for transient shooter identification.

However, the counter-trap has its own failure mode. Without tracks, per-frame detection noise, bounding-box jitter, and identity switches can corrupt the player representation. The model may attend to a nearby but non-key player because the detection is momentarily salient. Thus, the counter-trap is not a universal solution; it is a targeted correction for cases where temporal persistence is harmful.

Clock:

The clock is the event-phase operator. The event-state LSTM h_t^e acts as a temporal clock because it conditions attention on the current state of the event. The paper gives a clear example: “during the start of a ‘free-throw’ it is important to attend to the player making the shot. However, towards the end of the event the success or failure of the shot can be judged by observing the person in possession of the ball.” [PAGE 5]. This means the desired attention target is not fixed across the event. The clock must change the attention target from shooter to ball possessor or outcome observer.

The recursive tension is therefore:

1. The model wants temporal stability to reduce noise.  
2. The event wants temporal switching to follow the causal actor.  
3. The evaluator wants a proxy, such as ball proximity, that may only be valid at certain event phases.  
4. The physical event may involve multiple key actors at different phases.

A robust system must therefore model phase explicitly. If the clock is wrong, attention may be stable but semantically misaligned. If the clock is right, attention can shift from shooter to defender to ball handler as the event unfolds.

Recursive implications:

If the model is trained only on event labels, it may learn that persistent players are useful because they provide stable evidence. If evaluated only on shooter labels, it may appear that tracking is bad for key-actor localization. If evaluated only on classification mAP, it may appear that tracking is good because temporal smoothing helps overall event recognition. The correct evaluation must separate classification performance, detection robustness, and attention localization across event phases.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical/biomechanical/weather veto proof:

A cross-layer veto adjudication asks whether a candidate attention or event decision should be rejected because it violates physical, biomechanical, or environmental constraints. The paper’s basketball domain is useful because many events have strong spatial regularities. The authors note that attention concentrates in plausible court regions: “the model consistently focuses under the basket for a layup, at the free-throw line for free-throws and outside the 3-point ring for 3-pointers.” [PAGE 7]. This supports a spatial veto layer.

Layer definitions:

Layer 0: Raw visual evidence.  
Frame features f_t and player features p_t^i. Units: dimensionless network activations.  
Source: frame and player features are described in Section 4.1 [PAGE 4].

Layer 1: Detection and tracking.  
Detections produce N_t players per frame. Tracks associate detections across frames.  
Source: “we retain all detections above a confidence of 0.5 per frame; this resulted in 6–8 person detections per clip” [PAGE 3].  
Physical assumption: each detection corresponds to a visible player; tracking assumes identity continuity under motion.

Layer 2: Attention distribution.  
γ_{t,i} is a probability over players. Units: dimensionless.  
Physical interpretation: attention mass should be assignable to a physically plausible player.

Layer 3: Event-state decision.  
The event LSTM outputs class scores for 11 event types. Units: dimensionless scores passed to loss or mAP evaluation.

Layer 4: Physical/biomechanical plausibility.  
This layer checks whether the attended person or event class is compatible with ball location, court geometry, and motion constraints.

Ball-proximity veto for shooter identification:

Define b(t) as the image-space ball coordinate and c_i(t) as the image-space center of player i. Define:

\[
D_i(t) = \|c_i(t) - b(t)\|_2
\]

Units: pixels.  
Define the shooter set:

\[
S_t = \arg\min_i D_i(t)
\]

If several players tie, S_t is a set. The paper’s shooter annotation uses this principle: “we labeled the player who was closest (in image space) to the ball as the ‘shooter’.” [PAGE 7].

A physical veto for shooter attention is:

\[
\text{Veto}_{\text{shooter}}(t) =
\begin{cases}
1, & \text{if } \sum_{i \in S_t} \gamma_{t,i} = 0 \\
0, & \text{otherwise}
\end{cases}
\]

Interpretation: if the model assigns zero attention mass to every ball-closest player at a shot-initiation frame, the attention is physically implausible as shooter localization. This veto does not require a magic threshold; it uses exact zero mass as a categorical failure. If a softer threshold is desired, it must be calibrated on validation data, not invented post hoc.

Court-zone veto:

Let z_t be the canonical court coordinate of an attended player, obtained after transforming to a canonical court view. The paper aligns attended boxes to a canonical image: “we annotated 5 points on the court and aligned all the attended boxes for an event to one canonical image.” [PAGE 7]. For each event class c, define a plausible court region R_c. Then:

\[
\text{Veto}_{\text{zone}}(t,c) =
\begin{cases}
1, & \text{if } z_t \notin R_c \\
0, & \text{otherwise}
\end{cases}
\]

Examples from the paper: layup attention should be near the basket, free-throw attention near the free-throw line, and 3-point attention outside the 3-point ring [PAGE 7].  
Breakdown: court transformation can fail if camera viewpoint changes, if calibration points are occluded, or if broadcast switching changes the court projection.

Track-continuity veto:

For tracking-based models, a track should not undergo physically impossible identity jumps. Let x_{i,t} be the image position of track i at time t. If a track assignment requires a displacement much larger than plausible player motion between frames, the track is suspect. Because the paper does not provide player velocity priors or camera calibration, this veto should be expressed qualitatively or learned from optical flow rather than assigned an arbitrary pixel threshold.  
Relevant source: tracking uses KLT and bipartite matching: “We use a KLT tracker combined with bipartite graph matching [34] to perform the data association.” [PAGE 5].  
Breakdown: fast motion, occlusion, and crowded scenes can cause identity switches, as acknowledged in the no-tracking motivation [PAGE 5].

Biomechanical veto:

A shot event has a biomechanical ordering: player gathers or holds ball, ball leaves hand, ball travels toward basket. If attention locks onto a stationary defender during the ball-release phase, the model may be contextually useful but not identifying the shooter. The paper’s free-throw observation is exactly this: “Free-throws have a distinctive defense formation, and observing the defenders can be helpful” [PAGE 7]. Therefore, a biomechanical veto should be phase-dependent. During ball release, ball-proximal shooter attention is required for shooter localization; during defensive formation or outcome confirmation, defender attention may be valid.

Weather veto:

The NCAA basketball setting is not primarily weather-driven. The paper’s broader motivation mentions sports arenas and outdoor areas: “Videos captured in sports arenas, market places or other outdoor areas typically contain multiple people interacting with each other.” [PAGE 1]. For indoor basketball, weather is not a direct physical veto unless broadcast lighting, glare, or camera exposure changes. For outdoor basketball, weather can alter ball trajectory, player clothing appearance, and lighting. In that case, a weather veto would require environmental variables such as precipitation, wind, or illumination. Since the provided dataset is NCAA basketball and does not supply weather annotations, weather veto is assumed inactive or weak unless external environmental data are added.

Final adjudication rule:

A candidate attention decision passes physical adjudication only if:

1. N_t > 0.  
2. If shooter localization is claimed, attention mass is not zero on the ball-closest set S_t.  
3. If court-zone evidence is available, attended canonical location is compatible with event class.  
4. If tracking is used, track continuity is not contradicted by strong optical-flow evidence.  
5. If event phase indicates ball release, shooter evidence must dominate; if event phase indicates defensive formation or outcome, defender evidence may be admissible.

This adjudication does not replace learned evaluation, but it supplies physically grounded vetoes that can detect implausible attention patterns.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Three verifiable RLVR veto scenarios and predictions:

Scenario 1: Track-identity corruption veto for tracking-based attention.

Counterfactual: introduce synthetic identity swaps or track fragmentation during occlusions and fast motion. Then compare tracking-based attention with tracking-free attention on classification, detection, and shooter localization.

Why this is a veto: if the tracking model’s advantage depends on clean identity continuity, then corrupting tracks should disproportionately harm it. If it still outperforms or matches the no-track model under corrupted tracks, the tracking advantage is robust. If it collapses, the claimed benefit of track-based attention is contingent on ideal tracking.

Prediction: the tracking model will degrade more than the no-track model for classes with rapid movement or frequent occlusion, such as layup, slam dunk, and steal. The no-track model should be more robust for shooter localization because it does not rely on identity persistence.

Source support: the paper reports that tracking helps overall classification slightly, with mean classification mAP 0.516 for track attention versus 0.505 for no-track attention [PAGE 6]. However, for shooter localization, the no-track model is much stronger: mean AP 0.618 versus 0.438 [PAGE 7]. The paper also warns that tracking can be difficult due to occlusions and fast movements [PAGE 5].

Verifiable metric: change in mAP ΔmAP = mAP_corrupted − mAP_clean. The veto is triggered if ΔmAP_track < ΔmAP_notrack by a meaningful validation-calibrated margin. No arbitrary margin should be invented; the margin should be selected from validation variance.

Scenario 2: Persistent-defender free-throw veto.

Counterfactual: evaluate attention at free-throw initiation where the shooter is ball-proximal but a defender is spatially stable. Compare the tracking model’s attention distribution to the no-track model’s distribution.

Why this is a veto: if the tracking model attends to the defender rather than the shooter, then the claim that tracking improves key-actor localization is vetoed for free-throw initiation. The defender may be useful for event context, but not for identifying the shooter.

Prediction: the no-track model will assign higher attention to the ball-closest shooter during free-throw initiation, while the tracking model will assign more attention to a persistent defender. This will produce higher shooter AP for no-track attention in free-throw classes.

Source support: the paper states that the tracking model “is often reluctant to switch attention between frames and focuses on a single player throughout the event” and that in free-throws it “always attends to the defender at a specific position, who is visible throughout the entire event unlike the shooter.” [PAGE 7]. The shooter AP table confirms large free-throw gaps: free-throw success track 0.416 versus no-track 0.772; free-throw failure track 0.387 versus no-track 0.685 [PAGE 7].

Verifiable metric: per-class shooter AP for free-throw success and failure, plus attention entropy or attention mass on ball-closest set S_t at event start. The veto is triggered if γ(S_t) is systematically lower for the tracking model while defender attention mass is higher.

Scenario 3: Pass-steal hard-negative detection veto.

Counterfactual: construct a detection evaluation that isolates negative windows containing passes between teammates, especially passes that visually resemble steals. Then test whether adding team-possession features or hard-negative mining improves steal detection.

Why this is a veto: the paper explains that steal detection is hard because many negatives are passes: “These negatives often correspond to players passing the ball to each other. The ‘steal’ event is quite similar to a ‘pass’ except that the ball is passed to a player of the opposing team.” [PAGE 6]. If a model cannot distinguish steal from pass in detection, then its high isolated-clip steal classification may be misleading.

Prediction: the baseline detection model will produce elevated false positives on pass negatives. Adding explicit team identity, jersey-color features, or possession-change features should increase steal detection mAP without substantially reducing other class mAP. If no such improvement occurs, then the model’s steal detection failure is not merely a possession-representation issue but a deeper temporal localization issue.

Source support: steal classification mAP is high in Table 2, 0.893 for track attention and 0.886 for no-track attention [PAGE 6]. But steal detection mAP in Table 3 is much lower, 0.339 for track attention and 0.340 for no-track attention [PAGE 6]. This gap supports the hard-negative explanation.

Verifiable metric: steal detection mAP with and without team-aware features, plus false-positive rate on pass-only negative windows. The veto is triggered if baseline false positives on pass negatives are high and team-aware features significantly reduce them.

Summary of veto predictions:

1. Track corruption will hurt tracking-based attention more than no-track attention, especially for fast-motion classes.  
2. In free-throw initiation, no-track attention will beat tracking-based attention on shooter localization because tracking locks onto persistent defenders.  
3. Steal detection will improve when explicit team possession or hard pass negatives are introduced, because the main confusable class is pass.

These scenarios are verifiable because they use observable interventions: corrupted tracks, phase-specific shooter labels, and controlled pass-steal negatives. They also respect the paper’s own evidence rather than relying on speculative ratios or invented metrics.
</RLVR_COUNTERFACTUAL_VETOES>
