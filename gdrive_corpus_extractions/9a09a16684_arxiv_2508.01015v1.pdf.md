<SOURCE_OPERATORS_AND_EQUATIONS>
The source defines sampling, windowing, fixation, gaze-distance, classifier, and rank-evaluation operators. Units are stated where the source states them; where the source does not state a unit, I mark the assumption explicitly.

Sampling operator. Let \(f_s\) be the eye-tracker sampling frequency. The source says PupilCore samples at 200 Hz by default [PAGE 4]. Therefore
\[
\Delta t_s=\frac{1}{f_s},\qquad f_s=200\,\mathrm{Hz},\qquad \Delta t_s=5\,\mathrm{ms}.
\]
This is a timing operator, not a model score. It sets the temporal resolution of the raw gaze sequence.

Window-length operator. Let \(W\) be the evaluation window in seconds, \(W\in\{5,10,15,20,30\}\,\mathrm{s}\) [PAGE 7]. The nominal number of samples in a window is
\[
N_W=f_s W.
\]
Thus \(N_5=1000\) samples, \(N_{30}=6000\) samples, assuming one channel. The source states that the 1D CNN accepts “a 2-channel sequence of normalized (x, y) gaze coordinates with a fixed input size of the eye tracker’s sampling rate multiplied by each tested window size” [PAGE 7]. If both eyes are retained, the effective input has two coordinate channels per eye or one coordinate pair per sample, but the source’s wording should be followed exactly: the fixed input length is \(f_s W\).

Sliding-window operator. Let \(T\) be the usable recording duration for a participant and let \(t_0\) be the first valid sample. For window index \(k=0,1,\ldots,M-1\), define
\[
t_k=t_0+k\frac{W}{2},
\]
with the number of complete windows
\[
M=\left\lfloor \frac{T-W}{W/2}\right\rfloor+1
\quad \text{for } T\geq W.
\]
If \(T\) is smaller than \(W\), \(M=0\) and no complete window exists. This is an exact breakdown regime: the operator has no support when the observation period is shorter than the window. The source describes the half-window advance: a 10-second window “would start at the beginning of the experiment and segment relevant gaze and fixation data for this single sequence, then the window would advance 5 seconds so the next sequence would include 5 seconds of previous data and 5 seconds of new data” [PAGE 7].

Average Fixation Duration. Let \(\tau_i\) be the duration of fixation \(i\), with source-reported range 80 to 4000 ms [PAGE 6]. For a window with \(FC\) fixations,
\[
\mathrm{AFD}=\frac{1}{FC}\sum_{i=1}^{FC}\tau_i.
\]
Units are seconds or milliseconds depending on the stored representation; the source table lists milliseconds. AFD is defined for \(FC\geq 1\). The source reports that “experts showing significantly lower AFD, a tendency to log more fixations than non-experts, and lower overall AED” [PAGE 7].

Fixation Count. \(FC\) is the number of fixations recorded in a sequence. It is a count with no physical unit, range \(1\) to \(N\) counts per the dataset table [PAGE 6]. It is not a ratio and should not be converted into an invented score.

Average Euclidean Distance between fixations. Let \(p_i=(x_i,y_i)\) be the coordinate of fixation \(i\) in the eye-tracker coordinate frame. The source defines AED as the “average Euclidean distance (AED) between fixations” [PAGE 7]. A standard estimator consistent with that wording is
\[
\mathrm{AED}=\frac{1}{FC-1}\sum_{i=1}^{FC-1}\left\|p_{i+1}-p_i\right\|_2.
\]
Units are screen-coordinate units: normalized screen fractions if the pipeline stores normalized coordinates, or pixels if the pipeline stores pixel coordinates. The source states normalized \((x,y)\) positions are recorded [PAGE 4], so normalized screen units are the defensible assumption. Exact singularity: if \(FC=1\), the denominator is zero and AED is undefined. Any implementation must either exclude such windows or declare a separate convention; the source does not specify one.

Gaze Relational Index. The source also lists a “Gaze Relational Index (GRI) score, which is the ratio of mean fixation time to total fixation count” [PAGE 6]. Because the source simultaneously describes the table range as “0 - 1 normalized” [PAGE 6], the normalization and exact units are underspecified. I therefore do not use GRI as a primary equation here; it is a source-reported feature, not a validated operator in the main classifier description.

Classifier operator. The architecture is multi-stream. Let \(X_{gaze}\) be the normalized gaze sequence, and let \(AFD\), \(FC\), and \(AED\) be the three scalar sequence features. The source states: “The outputs of the three MLPs and the 1D CNN were concatenated into a final embedding vector, followed by an additional MLP making the final categorization into expert or non-expert classes based on the softmax score (1.0 denoting high expertise, while 0.0 denoting no expertise in a given domain)” [PAGE 7]. Formally, if each branch emits a 64-element embedding,
\[
h_g=\mathrm{CNN}_{\theta_g}(X_{gaze})\in\mathbb{R}^{64},\quad
h_a=\mathrm{MLP}_{\theta_a}(\mathrm{AFD})\in\mathbb{R}^{64},
\]
\[
h_f=\mathrm{MLP}_{\theta_f}(FC)\in\mathbb{R}^{64},\quad
h_d=\mathrm{MLP}_{\theta_d}(\mathrm{AED})\in\mathbb{R}^{64},
\]
\[
h=[h_g;h_a;h_f;h_d]\in\mathbb{R}^{256},\qquad
z=\mathrm{MLP}_{\phi}(h)\in\mathbb{R}^{2}.
\]
The expert-class probability is
\[
p(y=\mathrm{expert}\mid h)=\frac{\exp(z_e)}{\exp(z_e)+\exp(z_n)}.
\]
This is a probability in \([0,1]\), dimensionless. It is a softmax score, not a calibrated posterior unless calibration is separately demonstrated; the source does not report calibration analysis.

AUROC operator. Let \(S_e\) be the expert-class softmax score for an expert-labelled window and \(S_n\) the score for a non-expert-labelled window. The rank-probability definition is
\[
\mathrm{AUROC}=\Pr(S_e>S_n)+\frac{1}{2}\Pr(S_e=S_n).
\]
AUROC is dimensionless and lies in \([0,1]\). It is a probability of correct ranking, not an information quantity in bits. The source reports mean AUROC values of \(0.694\pm0.237\), \(0.757\pm0.212\), \(0.734\pm0.226\), \(0.798\pm0.219\), and \(0.831\pm0.180\) for 5, 10, 15, 20, and 30 seconds respectively in the initial-plus-verbal-phase table [PAGE 8]. After restricting to initial-phase sequences, the 5-second model reaches \(0.751\pm0.237\) and the 10-second model reaches \(0.780\pm0.194\) [PAGE 8].

Mann-Whitney U operator. For the feature-distribution comparison, the source says: “We conducted a non-parametric Mann-Whitney U test (assuming the significance level α = 0.05)” [PAGE 7]. A standard two-sample U statistic is
\[
U=\sum_{i=1}^{n_e}\sum_{j=1}^{n_n}
\left[
\mathbf{1}(X_i>Y_j)+\frac{1}{2}\mathbf{1}(X_i=Y_j)
\right],
\]
where \(X_i\) are expert-window feature values and \(Y_j\) are non-expert-window feature values. \(U\) is a dimensionless count. The source states that distributions “followed the typical left-sloped long-tailed distribution probability densities for AFD, FC, and the AED” [PAGE 7], which is why a non-parametric test is appropriate.

Assumptions and exact breakdown regimes. First, the subject-disjoint split has four experts and four non-experts in training, one expert and one non-expert in validation, and one expert and one non-expert in testing [PAGE 7]. An AUROC is undefined if a test batch contains only one class. Second, overlapping windows are not independent; the effective sample size is smaller than the number of windows, and standard deviations across 12 trained models per window size [PAGE 8] do not by themselves quantify subject-level uncertainty. Third, for \(W\) larger than the initial-decision time, initial-phase-only windows disappear for average participants: the source says 9.5 seconds was the average initial-decision time and that larger windows “far exceeded” it, so initial-phase-only retraining was not performed [PAGE 8]. Fourth, AED is singular at \(FC=1\). Fifth, physical calibration failure is an exclusion regime: recordings that made proper calibration impossible were discarded [PAGE 6]. Sixth, the source does not report weather variables, so no weather-conditioned equation is identifiable from this source.

<RETROCAUSAL_GENEALOGY>
The scientific genealogy runs from perception research to expertise assessment to human-saliency-guided machine learning. The source places itself in the eye-tracking tradition: “Eye tracking has been employed in human perception research to better identify gaze and eye movement during visual tasks” [PAGE 3], and it cites expert-novice studies in medical domains where expertise is backed by medical degrees or years of practice [PAGE 3]. The historical consensus it invokes is that “domain experts tend to log more fixations and more fixations of shorter duration than their novice counterparts” [PAGE 3]. AutoSIGHT’s result—experts show lower AFD, more fixations, and lower AED [PAGE 7]—is therefore a continuation of that lineage, not a free-standing discovery. The second branch is trustworthy AI and explainability. The paper motivates itself through trust, black-box models, Grad-CAM, and human saliency [PAGE 2]. It argues that human saliency can improve model feature maps or guide learning, but that non-expert annotators can inject erroneous features [PAGE 3]. AutoSIGHT is positioned as a way to grade the human before using that human’s saliency. The third branch is iris presentation-attack detection. The source reviews printouts, textured contact lenses, post-mortem samples, artificial eyes, and GAN-generated irises [PAGE 3], and it uses those categories in a balanced 16-deck design of 54 images per deck [PAGE 5]. The retrocausal point is that the final AUROC is not merely a model score; it is the end of a chain that begins with historical claims about expert gaze, passes through a specific biometric task, and terminates in a subject-disjoint classifier.

The multi-week traps are where this genealogy becomes dangerous. First, expertise is nonstationary. The abstract explicitly targets settings that “need to react dynamically to nonstationary expertise distribution between the human and AI players (e.g., when the experts need to be replaced, or the task at hand changes rapidly)” [PAGE 1]. If expertise changes across weeks, a classifier trained on one session cannot be assumed to remain valid across weeks. Second, fatigue and habituation are plausible multi-week drift mechanisms, but the source does not measure them longitudinally. It mentions educational tools that can “continuously monitor a participant’s performance and identify fatigue” as an application [PAGE 1], but that is a future-use claim, not an experimental result. Third, task change is a trap: the same expert in iris PAD may not be an expert in fingerprint PAD or code review, and the authors recommend future studies in “domains with less ambiguous expertise designations” [PAGE 10]. Fourth, label leakage across weeks is a trap: if a participant is labelled expert once and that label is propagated to future sessions, the classifier may learn identity or session artifacts rather than current expertise. The source avoids within-session subject leakage through subject-disjoint splits [PAGE 7], but it does not test time-disjoint or multi-week generalization. Fifth, the easy-sample trap is a multi-week issue because a non-expert who repeatedly sees easy categories may look expert for long stretches. The source states that “a non-expert participant may not be able to tell about the significant security vulnerabilities that irises wearing textured contacts create for iris recognition systems, but they can easily and expertly recognize the abnormal features of these samples” [PAGE 10]. Over weeks, such easy-sample exposure could produce apparent expertise drift that is really stimulus familiarity. The correct retrocausal reading is therefore conservative: AutoSIGHT demonstrates short-window, single-session, subject-disjoint separation on one iris task; it does not establish multi-week expertise tracking, and any genealogy that treats the 0.751 or 0.831 AUROC as a stable longitudinal property is overreading the source.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
The recursive problem is that the classifier’s estimate of human expertise can change the human’s behavior, and the human’s changed behavior can change the classifier’s next estimate. The source motivates this loop through human-AI pairing: expertise weighting should “react dynamically to nonstationary expertise distribution between the human and AI players” [PAGE 1]. But the experiment does not close the loop; participants are not shown the classifier’s score, and there is no adaptive AI weighting during the task. The three relevant regimes are crisis habit regression, the counter-trap, and the clock.

Crisis habit regression is the hypothesis that under stress, fatigue, or time pressure, an expert may regress toward a less expert-like gaze pattern. The source does not test crisis induction. The nearest evidence is indirect: it proposes continuous monitoring to “identify fatigue” [PAGE 1] and it treats expertise as potentially changing during a task [PAGE 1]. If crisis regression occurs, the classifier should see AFD rise, FC fall, or AED rise relative to the expert baseline, because the measured expert pattern is lower AFD, more fixations, and lower AED [PAGE 7]. That prediction is not verified in the source; it is a testable extension. The important audit point is that a single low score during a crisis should not automatically relabel a known expert as a non-expert, because the classifier was trained on ordinary single-session behavior, not crisis behavior.

The counter-trap is the opposite failure: a non-expert can temporarily produce expert-like sequences on easy samples. The source is explicit: “on occasion, the non-expert participant will show expert-level performance in brief sequences or series of sequences” [PAGE 9]. It also notes that non-experts can “easily and expertly recognize the abnormal features” of some attack types [PAGE 10]. This is a counter-trap because the classifier may be correct about the sequence and wrong about the person. A 5-second window can capture a genuine expert-like inspection episode from a non-expert. The source’s own results show that the 5-second initial-phase model has mean AUROC 0.751 with standard deviation 0.237 [PAGE 8], so some windows and some splits are far from the mean. The recursive consequence is that if the AI down-weights the human after a low score, it may overreact to a single non-expert window; if it up-weights after a high score, it may over-trust a non-expert who happened to see an easy sample.

The clock is the observation-latency constraint. The source’s average initial decision time is 9.5 seconds [PAGE 8]. A 5-second window can be scored every 2.5 seconds if the half-window stride is used, but it may be contaminated by verbal-description behavior if phase is not controlled. A 30-second window can be scored every 15 seconds and gives the best overall AUROC, but it necessarily crosses beyond the average initial decision and therefore mixes decision and post-decision behavior unless the task is redesigned. The authors recommend 30 seconds when latency can be afforded and state that shorter windows do not show a significant decrease for 5, 10, 15, and 20 seconds [PAGE 8], but the standard deviations are large. In recursive terms, the clock determines whether the AI’s expertise estimate is fast enough to matter and stable enough to avoid oscillation. A fast 5-second clock is responsive but noisy and phase-sensitive; a slow 30-second clock is more stable but delayed. The source does not measure the feedback loop, so the correct conclusion is that AutoSIGHT provides an open-loop expertise score, not a validated closed-loop theory-of-mind controller.

<CROSS_LAYER_VETO_ADJUDICATION>
Physical-layer veto. The source provides explicit hardware and calibration conditions. The tracker is a PupilLabs PupilCore headset sampling at 200 Hz by default, with some sessions limited to one eye “to ensure the capture of reliable and high quality data only” [PAGE 4]. Participants sat “approximately 1.5 meters away from a 55-inch TV monitor” and the room was positioned “to minimize environment lighting affects” [PAGE 4]. Calibration was performed before each experiment using the built-in Pupil Capture calibration [PAGE 4]. The source then discarded low-quality recordings: “Low-quality recordings (e.g., from participants wearing glasses, which in certain circumstances made it impossible to properly calibrate the pupil core headset, or issues related to head shape, which caused the eye camera placement not supporting the participant’s full range of visual scanning) were discarded, ending up with good-quality data collected from 53 non-expert and 6 expert participants” [PAGE 6]. This is a physical veto proof by exclusion: if glasses or head shape prevented calibration or full visual scanning, the recording is not admissible. The source does not report a numeric calibration residual threshold, so the veto is procedural and qualitative, not a fabricated numerical cutoff.

Biomechanical-layer veto. The source imposes a strict postural constraint: “participants were given strict instruction not to move their heads once they became comfortably situated in the chair for the duration of the experiment” [PAGE 4]. This matters because AFD, FC, and AED are computed from fixation coordinates and fixation durations. If the head moves, the eye-tracker coordinate frame shifts, and Euclidean distances between fixations no longer represent the same visual search geometry. The fixation-duration range in the dataset is 80 to 4000 ms [PAGE 6], so the features span three orders of magnitude; a coordinate-frame shift can therefore distort AED without producing an obvious failure in AFD or FC. The biomechanical veto condition is: a session with unapproved head movement, incomplete calibration over the participant’s full scanning range, or unstable eye-camera placement is not admissible for AED-based expertise inference. This is supported by the source’s exclusion of head-shape cases that did not support “the participant’s full range of visual scanning” [PAGE 6]. Again, the source does not give a numeric motion threshold, so the adjudication must remain at the level of procedural validity.

Weather-layer veto. The source contains no meteorological measurement, no outdoor exposure variable, and no weather-conditioned analysis. The only environmental control mentioned is lighting: participants were positioned “to minimize environment lighting affects” [PAGE 4], and the authors excluded pupillometry because “Pupil size may also be affected by ambient lighting conditions” [PAGE 6-7]. Therefore a weather-specific veto cannot be proven from this source in the positive sense; it can only be adjudicated as non-identifiable. Any claim that weather changes AutoSIGHT’s AUROC, or that weather can be used to adjust expertise weights, is outside the measured layer. The correct cross-layer proof is a negative proof: because the source did not collect weather, temperature, humidity, barometric pressure, or outdoor illumination, no weather-conditioned conclusion is verifiable. The only defensible environmental statement is that ambient lighting was controlled and that pupillometry was excluded partly because of lighting sensitivity [PAGE 6-7]. If a future deployment adds weather variables, the physical and biomechanical vetoes above still apply first: calibration and head stability must be valid before any weather covariate is interpretable.

Cross-layer interaction. The physical and biomechanical layers are not independent. Glasses can prevent calibration [PAGE 6], and head shape can prevent full scanning [PAGE 6]; both can masquerade as low expertise because the classifier sees abnormal AFD, FC, or AED. The source’s subject-disjoint evaluation reduces identity leakage but does not eliminate hardware-induced feature distortion. The cross-layer adjudication rule is therefore: a window is admissible only if calibration succeeded, the participant’s full scanning range was supported, head movement was absent, and the recording was not limited by a one-eye capture that compromised the feature set. The source’s one-eye limitation [PAGE 4] is a partial veto, not an absolute one, because the source says it was used “to ensure the capture of reliable and high quality data only.” The weather layer remains unadjudicable; it should not be inserted into the model as if it were measured.
</CROSS_LAYER_VETO_ADJUDICATION>
