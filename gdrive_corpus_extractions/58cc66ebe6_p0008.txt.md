Measurable space and measure. Let X be a set and Σ a σ-algebra on X:
X ∈ Σ, E ∈ Σ ⇒ X \ E ∈ Σ, E₁,E₂,… ∈ Σ ⇒ ⋃_{i=1}^∞ E_i ∈ Σ .
A measure is a set function μ : Σ → [0,∞] such that μ(∅)=0 and, for every pairwise disjoint sequence (E_i)_{i∈ℕ} ⊂ Σ,
μ(⊔_{i=1}^∞ E_i) = Σ_{i=1}^∞ μ(E_i), with extended-addition conventions in [0,∞].
Units: μ itself is dimensionless as a set function. If X = ℝⁿ and μ = m is Lebesgue measure, then m(E) carries SI unit mⁿ. A probability measure ℙ satisfies ℙ : Σ → [0,1] and ℙ(X)=1; it is dimensionless.

Integration and expectation. For measurable f : X → ℝ,
∫_E f dμ has units [f]·[μ]. Under ℙ, 𝔼[Y] = ∫_Ω Y dℙ has the units of Y.

Absolute continuity, singularity, and Lebesgue decomposition. ν ≪ μ means μ(A)=0 ⇒ ν(A)=0. Two measures are singular, μ ⟂ ν, if ∃N ∈ Σ with μ(N)=0 and ν(X\N)=0. The Lebesgue decomposition writes ν = ν_ac + ν_s with ν_ac ≪ μ and ν_s ⟂ μ. The Radon–Nikodym derivative dν_ac/dμ exists when μ and ν are σ-finite; without σ-finiteness the theorem’s conclusion is not guaranteed.
