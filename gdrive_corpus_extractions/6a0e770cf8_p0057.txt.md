Physical veto: strap-to-appendage coupling coefficient \kappa(t) < \kappa_{crit} disables m_{opt} and m_{hyb} because optical path length becomes undefined. Adjudication proof: hard vetoes are partially ordered; if \mathcal{V}(\mathbf{s}) = \emptyset the system asserts \bot (invalid data) rather than interpolating HR, because no mode satisfies physical law. If \mathcal{V}(\mathbf{s}) \neq \emptyset, \pi^* selects from \mathcal{M} \setminus \mathcal{V}. The fallback m_{safe} uses the last valid HR sample plus accelerometer-only motion context. Breakdown regime: simultaneous strap detachment, V_{bat} < V_{cutoff}, and E_v > E_{sat} yields \mathcal{V} = \mathcal{M}; at that singularity the only correct output is a silence flag. Any synthesized HR in this regime violates the sensor-physics assumptions stated on [PAGE 42] and is not recoverable by post-processing.
