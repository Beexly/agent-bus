The TREC-2002 Video Track evaluation pipeline is a composition of staged operators: raw archival video is first segmented into shots via manually created reference boundaries; those shots are then annotated for binary semantic features; finally, ranked shot lists are produced against 25 multimedia topics and judged for relevance. Each stage injects error that propagates downstream, so the metric reported at search time—mean average precision (MAP)—is a function of shot-boundary fidelity, feature-detector correlation, and topic construction bias, not of retrieval quality alone.

A multi-hop trace begins with the shot boundary determination (SBD) layer. According to the report, the test collection comprised 18 MPEG-1 videos, 2.88 GB, 545,068 total frames, and 2,090 shot transitions according to manually created reference data [PAGE 3]. Crucially, that reference data was created by a single student at NIST [PAGE 3], which establishes a single-point failure mode: if the student's categorization of cut/dissolve/fade/other is systematically skewed, every precision/recall figure in Figures 1–3 inherits that bias. The detection rule itself tolerates decoder frame-numbering skew by expanding each abrupt reference transition by 5 frames in each direction [PAGE 4], and abrupt transitions are assigned an effective length of two frames (last pre-transition plus first post-transition) rather than zero [PAGE 4]. Very short gradual transitions (<= 5 frames) are collapsed into cuts [PAGE 4]. This means the SBD layer is not a boundary-localization measurement but a frame-overlap detection measurement; any conclusion about "accuracy" of boundary placement is vetoed by the ±5 frame matching tolerance.

The feature extraction layer compounds this. Feature detections were exchanged among groups in MPEG-7 format [PAGE 2], so search systems did not always operate on independent feature estimates. Figure 4 shows that the number of true shots contributed uniquely by any given system, summed over all features, is relatively small [PAGE 6], indicating heavy overlap and common-mode failure across participants. The test set contained only 1,848 shots while result sets could contain up to 1,000 shots [PAGE 5–6], forcing large overlap by construction and compressing the dynamic range of average precision.

The search layer introduces topic-construction retrocausality. NIST developed the 25 topics rather than participants, releasing them 4 weeks before results were due [PAGE 2], and constructed them by working backward from the test collection rather than from real user queries [PAGE 8–9]. The report concedes this leaves open the possibility that some topics were biased toward automatic speech recognition because words from the audio were incorporated into topic wording [PAGE 9]. Relevance judgments used top-50 pooling per result set [PAGE 8], and the bottom half was judged but yielded few additional relevant shots except for topics already rich in relevant material [PAGE 10]. Let \(R\) denote the reference set of relevant shots or reference transitions, and \(S\) the submitted set, with cardinality measured in shots or frames. Detection precision and recall are dimensionless quantities in \([0,1]\):

\[
P = \frac{|R \cap S|}{|S|}, \qquad R_{\text{cll}} = \frac{|R \cap S|}{|R|}.
\]

For shot boundary detection, a submitted transition matches a reference transition iff there is at least one frame of overlap [PAGE 4]. A submitted abrupt transition is modeled as the set containing the last pre-transition frame and first post-transition frame, so its effective length is \(\ell_{\text{abrupt}} = 2\) frames rather than zero [PAGE 4]. Each abrupt reference transition is expanded by \(\pm 5\) frames in each direction before matching to absorb inter-decoder frame-numbering differences [PAGE 4]. Gradual transitions \(\tau_g\) match only gradual transitions, and cuts \(\tau_c\) match only cuts, except that any gradual transition of duration \(d \le 5\) frames is treated as a cut [PAGE 4]. Frame-level accuracy for gradual transitions uses frame-based precision and recall, measured in frames.

Average precision for a topic or feature \(t\) with reference relevant set \(R_t\) and ranked submission \(S_t = (s_1,\dots,s_n)\) is:

\[
\text{AP}(t) = \frac{1}{|R_t|} \sum_{k=1}^{n} P(k) \cdot \text{rel}(k),
\]

where \(\text{rel}(k) \in \{0,1\}\) and \(P(k)\) is precision at rank \(k\). Mean average precision over \(T\) topics is \(\text{MAP} = \frac{1}{|T|}\sum_{t\in T}\text{AP}(t)\). All are dimensionless \([0,1]\).

Artificial ceiling derivation (verifiable from the text): when the number of hits \(|R_t|\) exceeds the result-set cap \(C\), perfect ranking can retrieve at most \(C\) relevant items, so

\[
\text{AP}_{\text{ceiling}}(t) = \frac{C}{|R_t|}, \qquad \text{for } C < |R_t|.
\]

This yields exact agreement with the reported bounds: feature 8 (speech), \(|R|=1382\), \(C=1000 \Rightarrow 1000/1382 = 0.7236 \approx 0.724\) [PAGE 6]; feature 9 (instrumental sound), \(|R|=1221\), \(C=1000 \Rightarrow 1000/1221 = 0.819\) [PAGE 6]; topic 82, \(|R|=170\), \(C=100 \Rightarrow 100/170 = 0.588\) [PAGE 9]; topic 86, \(|R|=105\), \(C=100 \Rightarrow 100/105 = 0.952\) [PAGE 9]; topic 93, \(|R|=161\), \(C=100 \Rightarrow 100/161 = 0.621\) [PAGE 9]; topic 94, \(|R|=303\), \(C=100 \Rightarrow 100/303 = 0.330\) [PAGE 9].

Breakdown/singularity conditions: if \(|R_t| \le C\), the ceiling is inactive (\(\text{AP}_{\text{ceiling}} = 1\)); if \(|R_t| \gg C\), \(\text{AP}_{\text{ceiling}} \to 0\), and MAP loses resolution. Shot boundary matching breaks down when inter-decoder frame offsets exceed \(\pm 5\) frames [PAGE 4]. Third, groups could develop with knowledge of the search test collection (training pattern A) or without it (pattern B) [PAGE 6], creating a knowledge-leakage variable that confound cross-group comparison.

Most retrocausally, the 2003 plan—making the track an independent evaluation (TRECVID 2003), using 120 hours of 1998 news video, creating roughly 50 topics "unbiased by detailed knowledge of the test collection," and significantly increasing collection sizes [PAGE 16]—diagnoses the 2002 design flaws by implication. The demand for unbiased topics in 2003 retrocausally establishes that 2002 topics were collection-biased; the demand for larger collections establishes that the 2002 test sets were too small to support generalizable claims; and the move to independence establishes that embedding the track within TREC created institutional confounds.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
The search task is explicitly human-in-the-loop; all systems "included a human in the loop" [PAGE 6], which creates a recursive theory-of-mind problem: the system must model the searcher's model of the topic, and the searcher must model the system's retrieval behavior. Under crisis conditions, habits regress. DCU limited all topic searches to 4 minutes of total elapsed time [PAGE 14], and across interactive runs, time spent varied "from an average of just over 1 minute to just under 30 minutes per topic," with "no simple relationship between elapsed search time and effectiveness as measured by mean average precision" [PAGE 9]. When clock pressure mounts, searchers revert to crisis habits: CMU's expert Informedia user "did not have knowledge of the current TREC video collection" and attempted "high recall rather than speedy results" [PAGE 11], while topic text itself sometimes incorporated audio words, biasing users toward ASR-based strategies [PAGE 9].

Teams likewise regressed to prior-year architectures under the compressed timeline: Fudan "used most parts of their TREC-2001 shot segmentation system" [PAGE 12], CLIPS used "almost the same system for shot boundary detection as the one used for the TREC-2001 evaluation" [PAGE 13], and Microsoft's submission was "based on the last year's work" [PAGE 14]. This is crisis habit regression at the organizational level: rather than redesigning for the 2002 feature and topic distributions, groups tuned parameters on TREC-2001 corpora and submitted.

The counter-trap is feature donation. Several groups volunteered feature detections in MPEG-7 format so other groups could leverage them in the search task [PAGE 2]. CLIPS submitted a search run "based only on a combination of donated features" [PAGE 13], Fudan's Sys3 used "reference feature extraction results provided by IBM and MediaMill" [PAGE 13], and DCU's interactive system used seven donated features alongside its own three [PAGE 14]. This counter-trap mitigates individual detector brittleness but introduces common-mode failure: because many systems consumed the same donated outputs, their errors correlate, and Figure 4 shows that the number of true shots contributed uniquely by any given system is small [PAGE 6]. The clock and the counter-trap thus interact: elapsed search time was added as an effort measure [PAGE 2], yet no time-effectiveness relationship emerged [PAGE 9], suggesting that the human-in-the-loop recursion is dominated by feature quality and topic bias rather than search duration.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Three layers must be vetoed independently before any search-result claim can be admitted.

Physical layer. The video signal layer uses MPEG-1/VCD at 25 or 30 frames per second [PAGE 2]. DCU's speech and music detectors operated directly on the encoded MPEG-1 bitstream [PAGE 14], and Eurecom classified DCR macro-blocks without complete stream decoding [PAGE 14]. Decoder-dependent frame numbering forced the \(\pm 5\) frame reference expansion in SBD matching [PAGE 4]. Veto: if a claim depends on sub-frame boundary localization, it is invalidated by the two-frame effective transition model and the \(\pm 5\) frame tolerance [PAGE 4].

Biomechanical layer. Human assessment is the terminal operator. SBD reference data was created by one NIST student [PAGE 3], with software sanity checking and corrections [PAGE 3]. Search relevance judgments used top-50 pooling per result set by a NIST assessor [PAGE 8]; double judging in TREC-2001 showed high assessor agreement, so TREC-2002 did not double-judge [PAGE 8]. Manual mode conflates searcher and system effects, although within-group comparison remains possible if one searcher is used [PAGE 7]. DCU ran twelve test users through all 25 topics [PAGE 14]. Veto: any conclusion about system superiority across groups is invalid if searcher expertise differs, because manual mode conflates searcher and system effects [PAGE 7].

Weather/environmental layer (collection conditions). The source corpus consists of advertising, educational, industrial, and amateur films from the 1930s–1970s, varied in age, production style, and quality [PAGE 2–3]. The report states that publicly available video collections of significant size are "extremely hard to find" and that collection characteristics "will affect the scope of any conclusions drawn here" [PAGE 6]. Veto: external validity to modern broadcast, surveillance, or user-generated video is void; conclusions apply only to this archival, MPEG-1, pre-1970s corpus.

Cross-layer veto synthesis: a MAP ranking is admissible only if (a) the SBD reference is stable under decoder re-numbering, (b) the relevance cap \(C\) does not bind unequally across compared topics, and (c) the topic set is not biased by ASR wording or backward construction from the collection. Where (a)–(c) fail, the metric is a property of the evaluation apparatus, not of the retrieval system.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Three verifiable counterfactual veto scenarios, each tied to a reported parameter and a falsifiable prediction:

Veto Scenario 1 — Exact boundary localization replaces frame-overlap detection. If the SBD criterion were changed from "at least one frame of overlap" [PAGE 4] to exact frame coincidence (zero tolerance), and if decoder frame offsets persist at the \(\pm 5\) frame scale [PAGE 4], then reported cut precision and recall would collapse. Prediction: detection curves in Figure 1 would shift downward substantially for all groups, because the effective two-frame abrupt-transition model [PAGE 4] and decoder skew make exact matching systematically impossible; the current "solved" status for abrupt transitions [PAGE 4] would no longer hold.

Veto Scenario 2 — Result cap removed for capped topics. If the search result limit were raised from \(C=100\) shots to \(C \ge |R_t|\) for topics 82, 86, 93, and 94, the artificial AP ceilings (0.588, 0.952, 0.621, 0.330) [PAGE 9] would vanish. Prediction: MAP rankings among systems for these topics would reorder, because systems could retrieve additional relevant shots beyond the current cap; the ceiling-constrained comparisons in Figures 6–7 and 11–12 are not invariant to the cap, so current topic-level rankings are vetoed as measures of intrinsic retrieval quality.

Veto Scenario 3 — Donated feature outputs excluded from search. If the MPEG-7-donated feature detections [PAGE 2] were removed and systems could use only self-extracted features, then runs that relied on donated features—CLIPS's donated-features-only search run [PAGE 13], Fudan's Sys3 using IBM/MediaMill reference features [PAGE 13], and DCU's mixed donated/self feature system [PAGE 14]—would degrade. Prediction: per-feature median average precision would fall, especially for speech and instrumental sound where detector quality varies widely; the observed overlap in Figure 4 [PAGE 6] would decrease, but unique true-shot contribution per system would not rise enough to offset the loss in detector recall, lowering overall MAP for feature-dependent topics.
</RLVR_COUNTERFACTUAL_VETOES>
