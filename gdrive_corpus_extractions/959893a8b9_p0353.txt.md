In crisis conditions, agents regress to habit: they substitute a familiar heuristic (availability, affect, or past frequency) for the missing Knightian probability distribution. This habit regression is itself observable to other agents, creating a recursive theory-of-mind problem. Agent i believes agent j believes that discovery d is probable; j, however, may be using a stale frequency from a pre-discovery reference class. If i acts on the belief that j is rational, i over-invests in imitation; if i suspects j is regressing to habit, i under-invests and cedes first-mover profit.

The counter-trap is the false precision trap: converting Knight’s “we do make such judgments” [PAGE 840] into a numeric \(p\) and then optimizing expected utility as if \(F_X\) were known. This is recursive because each agent’s attempt to model others’ probability judgments changes the very distribution being estimated. The equilibrium is a fixed point in beliefs about unobservable probabilities, and it is fragile: any public signal that \(E_{\mathrm{prev}}\) has risen (e.g., a patent suit) causes a cascade of belief revision, collapsing imitation demand not because \(C_{\mathrm{mat}}\) changed, but because the second-order belief “others will not imitate” becomes self-fulfilling.
