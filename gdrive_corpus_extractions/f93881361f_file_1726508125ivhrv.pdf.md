<CROSS_LAYER_VETO_ADJUDICATION>
Honest reframing: "physical/biomechanical/weather vetoes" do not exist here, but statistical practice has real vetoes — assumption violations that invalidate an inference. These are provable, not fabricated.

1. Normality veto (partial): the t-test/CI survives moderate non-normality (p.357 calls it "relatively robust"), but the χ² test on a variance does not — p.342 states even "moderate departures from normality" corrupt it. Verdict: any variance-test conclusion on non-normal data is vetoed unless normality is checked (probability plot / goodness-of-fit, pp.231, 351).

2. Independence veto: the binomial, Poisson-process, and pooled-t results all assume independence. Sampling without replacement from a small batch (hypergeometric regime, p.115) vetoes the binomial; the book quantifies when it is safe: sample size small relative to batch (p.96, n/N ≲ 0.1 makes trials "approximately independent").

3. Variance-homogeneity veto: the pooled two-sample t (Eq. 10-14, p.384) is "very sensitive to the assumption of equal variances"; when σ₁²≠σ₂² the Welch–Satterthwaite test (Eq. 10-16, p.387) must be used instead. The arsenic example (p.387, s₁=7.63 vs s₂=15.3) is the worked veto trigger.

4. Small-expected-count veto: goodness-of-fit χ² requires expected frequencies ≳ 3–5 (p.351); cells below that must be pooled or the test statistic is invalid.

Each veto has a proof obligation the book discharges (normal probability plot, slope comparison, variance ratio, expected-count check). There is no weather or biomechanical layer to adjudicate.
</CROSS_LAYER_VETO_ADJUDICATION>

Three verifiable counterfactual checks, each computed directly from source data, each with a checkable prediction (I decline to invent betting/physical scenarios; these are the genuine "verifiable" cases the book supplies):

Prediction (verifiable): despite a "positive" test, posterior risk stays below 1%; raising the prior to a symptomatic-population value flips the conclusion. Recompute via Bayes to confirm.
