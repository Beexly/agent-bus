**O1 — Finite-mixture PLS likelihood (segment identification).** For respondent *i* with endogenous indicator block **y**ᵢ and exogenous block **x**ᵢ, latent class *k* ∈ {1,…,K} carrying weight vector **w**ₖ and path vector **β**ₖ:

$$\mathcal{L}(\Theta)=\sum_{i=1}^{N}\ln\!\Big[\sum_{k=1}^{K}\pi_k\, f_k(\mathbf y_i\mid\mathbf x_i;\boldsymbol\beta_k,\mathbf w_k,\boldsymbol\Sigma_k)\Big],\qquad \sum_{k=1}^{K}\pi_k=1,\ \pi_k\ge 0$$

Units: **nats** (natural-log information units), dimensionless in the physical sense. Assumption: local independence within class and conditional normality of the inner residuals. Singularity regime: **label switching** whenever βₖ ≡ βₖ′ and πₖ ≡ πₖ′ for k ≠ k′ — the likelihood is then invariant under permutation of class labels and the segmentation is non-identified; also **segment collapse** as any πₖ → 0, at which point the Hessian is rank-deficient in the corresponding β direction and standard errors diverge. **O2 — Normalized entropy (segment separation).** Following Ramaswamy, DeSarbo, Reibstein & Robinson (1993):

$$E_N \;=\; 1+\frac{1}{N\ln K}\sum_{i=1}^{N}\sum_{k=1}^{K}\hat p_{ik}\ln \hat p_{ik}\;\in\;[0,1]$$

Units: dimensionless. Limit behaviour: E_N → 1 as posteriors become degenerate (perfect separation); E_N → 0 under uniform posteriors p̂ᵢₖ = 1/K. Breakdown: E_N is **monotonically non-decreasing in K** for fixed data, so it cannot be used as a K-selection criterion — it is a separation diagnostic only. The source states "The value of Normalized Entropy coefficient (NE) ... is higher for two segments, thus confirming the results of the cluster method" [PAGE 6] but prints no numeric E_N for any K, so the monotonicity trap cannot be excluded from the page set.

**O3 — Measurement-model operators (reliability and convergent validity).**

$$\mathrm{CR}_m=\frac{\big(\sum_{j\in J_m}\lambda_{mj}\big)^2}{\big(\sum_{j\in J_m}\lambda_{mj}\big)^2+\sum_{j\in J_m}\mathrm{Var}(e_{mj})},\qquad \mathrm{AVE}_m=\frac{\sum_{j\in J_m}\lambda_{mj}^2}{\sum_{j\in J_m}\lambda_{mj}^2+\sum_{j\in J_m}\mathrm{Var}(e_{mj})}$$

Units: dimensionless proportions. Thresholds applied: CR > 0.7, AVE > 0.5, |λ| > 0.6 — "the standardized load or outer loadings, which exceeded the minimum value of 0.6" [PAGE 5]. Reported values: CR = 0.933 / 0.933 / 0.937 / 0.900 and AVE = 0.874 / 0.823 / 0.834 / 0.751 for event attitude, sponsor attitude, congruence and purchase intent respectively [PAGE 5, Table 1]. Breakdown: CR and AVE both degenerate when Σλ → 0 (indicator-block extinction) and are inflated under correlated errors, since both assume Var(e) diagonal.

**O4 — Fornell–Larcker discriminant condition.**

$$\sqrt{\mathrm{AVE}_m}\;>\;\max_{n\ne m}\big|r_{mn}\big|\quad\forall m$$

Units: dimensionless. Breakdown: the condition is necessary but not sufficient for discriminant validity; it fails structurally whenever constructs are near-isomorphic (r → 1), in which case the two latent variables are empirically one and all downstream path coefficients are unstable.

**O5 — Bootstrap significance operator.** With B resamples, $\;t=\hat\beta/\widehat{\mathrm{SE}}^{*}(\hat\beta)\;$, dimensionless ratio, referred to a t-distribution with df ≈ B − 1 (asymptotically standard normal). "PLS's bootstrap procedure assigns t values to the estimated regression parameters, allowing identification of significant relationships between variables" [PAGE 5]. Breakdown: the operator is invalid when the resampling unit is not independent — here the unit is the respondent, but respondents are self-selected through a single web banner, so the bootstrap distribution is conditional on a non-random selection event and systematically understates variance.

**O6 — Permutation multi-group test (the actual H4 test).** For a test statistic θ (here θ = β₁^(2) − β₁^(1)):

$$p=\frac{1+\#\{\,|\theta^{*}_{b}|\ \ge\ |\theta_{\text{obs}}|\,\}_{b=1}^{B}}{B+1}$$

Units: dimensionless probability. "A multi-group analysis is performed using the procedure of random assignment or permutation (Chin & Dibbern, 2010)" [PAGE 6]. Breakdown: permutation assumes exchangeability of group labels under H₀; with n₁ = 45 vs n₂ = 214 the exchangeability is intact but the *power* is asymmetric, and the minimum attainable p is 1/(B+1), so very small p values are quantised.

**O7 — Image-transfer operator and its singularity.** Let $A_E$ be attitude toward the event, $A_S$ attitude toward the sponsor, $C$ perceived congruence, $\theta_i$ the dimensionless involvement factor score, and $\theta^{*}$ the latent class boundary:

$$A_S=\beta_1(\theta)\,A_E+\beta_3(\theta)\,C+\zeta_1,\qquad \mathrm{PI}=\beta_2(\theta)\,A_S+\zeta_2$$

$$\beta_1(\theta)=\begin{cases}0, & \theta<\theta^{*}\ (\text{class 1})\\[2pt] \beta_1^{H}>0, & \theta\ge\theta^{*}\ (\text{class 2})\end{cases}$$

Units: all coefficients standardized, dimensionless. Empirical calibration: $\beta_1^{(1)}: t=1.236$, $\beta_1^{(2)}: t=2.279$; $\beta_3^{(1)}: t=5.890$, $\beta_3^{(2)}: t=8.609$; $\beta_2^{(1)}: t=7.346$, $\beta_2^{(2)}: t=7.859$; permutation difference in standardized β₁ = 0.21, p = 0.029 [PAGE 6, Table 2]. **Breakdown regime:** on the low-θ stratum the Jacobian ∂A_S/∂A_E collapses in spectral radius from |β₁^H| to zero, and the transfer map becomes **rank-1** — only the congruence direction survives. Crucially, this is a *modelled discontinuity*, not an observed physical one: the FIMIX posterior is bimodal at θ*, but β₁ is a continuous function of θ in any correct specification, so the "zero" is a between-class test artifact whose magnitude is bounded above by the n₁ = 45 standard error.

**O8 — Effect size, predictive relevance, and fit.**

$$f^2=\frac{R^2_{\text{incl}}-R^2_{\text{excl}}}{1-R^2_{\text{incl}}},\qquad Q^2=1-\frac{\sum_i \hat e_i^2}{\sum_i o_i^2},\qquad \mathrm{GoF}=\sqrt{\overline{\text{communality}}\times\overline{R^2}}$$

Units: dimensionless. Reported: R²(sponsor attitude) = 0.647, f² = 0.547; R²(purchase intent) = 0.610, f² = 0.369 [PAGE 5, Table 1]; "The value of the statistic is 0.281, thus the model has predictive relevance" [PAGE 5, Q²]; "The value is 0.646 ... A GoF greater than 0.61 is considered large" [PAGE 5–6]. Breakdown: Q² < 0 ⇒ predictive irrelevance (the blindfolding reconstruction is worse than the mean); GoF → 0 when either mean communality or mean R² → 0, and GoF is **not** a model-selection statistic — it cannot arbitrate between K = 2 and K = 3, which is precisely the decision left open in O2.

<RETROCAUSAL_GENEALOGY>

The operator stack in this paper is a four-decade compression of separate research programmes, and the compression is where the traps live. **Lineage, forward:** Heider's balance theory (1958) and Osgood & Tannenbaum's congruity principle (1955) supply the idea that inconsistent attitude triads resolve toward equilibrium — cited at [PAGE 2] as the congruence ancestry. McCracken's meaning-transfer model (1989) supplies the cultural-symbol channel, and Gwinner (1997) collapses both into a measurable image-transfer model that "allows us to measure sponsorship effectiveness levels to increase sponsor product purchase intentions" [PAGE 2]. Speed & Thompson (2000) supply the psychometric instrument, and Grohs & Reisinger (2014) supply the unresolved moderator question that this paper claims to close. **Lineage, methodological:** Hahn et al. (2002) → Sarstedt & Ringle (2010) → Sarstedt, Becker, Ringle & Schwaiger (2011) is the FIMIX-PLS line, imported wholesale into a domain that had never used it, per the paper's own priority claim [PAGE 2].

**Trap 1 — the settled-moderator trap (multi-week).** The paper is written as a closure ("This paper is the first to include segmentation by Finite Mix in sponsorship research" [PAGE 1]) while simultaneously conceding the field is open: "Grohs (2015) affirms that the fit between sponsor and sponsored directly influences the sponsor's image. Regarding the implication, Grohs confirms that the literature has yet to determine its exact influence and depth" [PAGE 3]. The retrocausal risk is that subsequent work cites the closure sentence and stops reading the concession. Any multi-week literature audit that only samples abstracts of citing papers will inherit the closure and lose the caveat.

**Trap 2 — the segmentation-as-causation trap (multi-week).** Because FIMIX segments rather than randomizes, a decade of citation can convert a cross-sectional class difference into a developmental claim ("involvement grows transfer"). The paper's own future-research section is the antidote and is routinely dropped: "Perform a longitudinal analysis on the same sample in order to study the effects of possible sponsor changes" [PAGE 7]. Until that is run, θ is confounded between trait involvement and state involvement on tournament day.

**Trap 3 — the medium-event generalisation trap.** The stimulus is one ATP 500 tournament, "In 2013 it received more than 900 hours of television broadcasting. It had over 65 million TV viewers worldwide" [PAGE 5], and the authors themselves flag "one should be cautious in extrapolating the results to sports organizations in general, even to different types of sports" [PAGE 7]. Multi-week citation drift reliably converts a single-tournament Spanish convenience sample into a general law of sponsorship.

**Trap 4 — the borrowed-criterion trap.** Each imported operator arrives with a home-domain validity condition that is silently dropped: entropy arrives from mixture modelling without its monotonicity caveat; GoF arrives from Tenenhaus et al. (2005) without its non-comparability caveat; Q² arrives from Stone–Geisser blindfolding without the requirement that the omitted-block procedure match the outer weighting scheme. Imported criteria are not free.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>

**The crisis habit.** Under ROI pressure the sponsor's reflex is reach maximization — buy exposure, count impressions, assume affect bleeds through. The page set gives that reflex a precise name and a precise failure mode: the transfer kernel it depends on is exactly the one that reads t = 1.236 in the low-involvement stratum [PAGE 6]. Crisis habit regression therefore looks like *doubling the banner*, which the model predicts will increase exposure to the segment where transfer is already strong (2.279) and add nothing where it is absent (1.236). The behaviour is a regression to the pre-theoretic playbook precisely when the evidence against it is strongest.

**The counter-trap.** The tempting over-correction is to abandon the 17 % low-involvement stratum and concentrate spend on high-involvement fans. The model vetoes this: for that same stratum, congruence → sponsor attitude reads 5.890 and sponsor attitude → purchase intent reads 7.346, both strongly alive [PAGE 6]. The low-involvement spectator is reachable — but only through fit and prior brand attitude, not through borrowed event affect. The counter-trap is mistaking *one dead channel* for *a dead consumer*.

**The mentalizing layer.** The paper's own theory of the consumer's mind is the Elaboration Likelihood Model, and it is stated in both directions: "when involvement is high, the consumer makes a greater cognitive effort to process information (central route). When involvement is low, the consumer depends more on affective signals when evaluating the message" [PAGE 4]. Recursively, the sponsor must model *the spectator modelling the sponsor*: high-involvement fans are running a deliberate fit-check on the sponsor-event pairing, so incongruent pairings are detected and penalized; low-involvement spectators are running a peripheral affect check with almost no brand-elaboration capacity, so what reaches them is the ambient feeling of the event, not the sponsor's attributes. "It is not congruent that a fast food company or an alcoholic beverage sponsor sporting events, but repetitive exposure ... means that the consumer will develop a better fit" [PAGE 7] — the paper's own account of how repeated exposure *manufactures* the perception of fit that then carries the low-involvement channel.

**The clock.** The model has an explicit temporal structure that a static analysis hides: "it is recommended to provide opportunities of interaction with consumers before, during, and after the event (Beaton et al., 2011)" [PAGE 7], with the tactical clock named concretely as "regular fan meetings, autograph sessions, and weekly chat sessions on their website" [PAGE 7]. The weekly cadence is the resolution limit of the theory: it is the shortest interval at which the congruence-building exposure process can be re-sampled. A campaign that fires only during the tournament's nine days operates below the model's own clock resolution and should be predicted to fail on the congruence channel even while succeeding on raw impressions.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>

**Layer audit, stated before any adjudication.** The 12-page corpus contains **zero** biomechanical measurements (no ground-reaction force, no joint kinematics, no load-rate), **zero** physiological measures (no heart rate, no cortisol), and **zero** meteorological variables (no temperature, wind, humidity, precipitation). Any claim in this domain that invokes a biomechanical or weather veto would be fabricated and is inadmissible a priori. The cross-layer veto must therefore be re-instantiated onto the three layers the page set *does* document, and each is adjudicated as a hard gate rather than a covariate.

**Layer L1 — the media-delivery layer (physical broadcast envelope).** Parameters: "more than 900 hours of television broadcasting ... over 65 million TV viewers worldwide" [PAGE 5]. This is the physical transport of the sponsorship stimulus. **Veto condition V1:** if the stimulus is delivered predominantly through broadcast rather than through the on-site/online channel used for recruitment, then the measured attitudes are conditioned on a broadcast-mediated exposure whose intensity per respondent is unmeasured. The paper reports no exposure-frequency covariate, so V1 cannot be discharged. Consequence: the model's β₁ estimates are conditional on an unquantified exposure field and are not transportable to events with different broadcast envelopes.

**Layer L2 — the measurement-channel layer (device and self-selection physics).** Recruitment is "a banner ... on the website of a tennis event, Valencia Open 500, which redirected the user to an online self-administered survey with a Likert type scale" [PAGE 4]. **Veto condition V2:** because involvement is simultaneously the moderator and the most plausible determinant of banner exposure, the measurement channel *selects on the moderator*. The authors register the mechanism without propagating it: "The method used to administer the survey may have influenced the characteristic of the sample; the respondents may have specific characteristics attributable to online users" [PAGE 7]. Under V2 the class separation is not identifiable as a consumer property rather than a channel property.

**Layer L3 — the sampling-frame layer (population base).** "A convenience sampling method was used, given the absence of an adequate sampling frame. In sporting events that are marketed to spectators ... there is no known population base of spectators or followers that would permit carrying out probabilistic sampling techniques" [PAGE 5]. **Veto condition V3:** with no frame, no design weights exist, and the 82 %/17 % split [PAGE 6] has no known relation to the population split. All aggregate claims — including the abstract's categorical "the least involved individuals do not process the image transfer effect" [PAGE 1] — inherit this veto.

**Layer L4 — measurement invariance (the statistical veto on the whole H4 construct).** A multi-group path comparison is licensed only if configural, compositional and scalar invariance hold across groups. The page set reports per-group *t*-values only; no per-group loadings, no per-group AVE, no MICOM-type invariance test. **Veto condition V4:** if scalar invariance fails, the reported difference of 0.21 in standardized β₁ is partly a rescaling artifact, and H4 is not identified. V4 is undischarged in the corpus.

**Adjudication.** V1 and V2 are *fatal to transportability*, not to internal description: the within-sample ordering (2.279 > 1.236) survives. V3 and V4 are *fatal to the categorical negation*: the correct surviving statement is the weaker, channel-specific one — on this convenience sample, at this broadcast-heavy single event, the event-attitude → sponsor-attitude path failed to reach significance in the smaller class while the congruence and intention paths remained strong. No physical, biomechanical or meteorological claim is admitted, because none exists in the source.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>

**RLVR-1 — Threshold-collision veto (verifiable by arithmetic on Table 2).**
*Setup:* Page 5 asserts "All hypotheses are supported with a p-value below 0.05." Table 2 [PAGE 6] prints p = 0.099 for `CONGRU → ATTSPO` with `Significant: Yes`, and p = 0.040 for `ATTSPO → PURINT` with `Significant: No`.
*Veto:* Under a strict α = 0.05 gate applied to the printed column, the congruence row fails and the intention row passes — the exact inverse of both the printed flags and the prose ("The relationship between congruence and attitude towards the sponsor is significantly different between groups"; "The relationship between the attitude towards the sponsor and purchase intention is not significantly different between groups").
*Prediction (falsifiable):* the printed p column and the printed significance column were generated by two different statistics (difference test vs. within-group path test), and at least one row is a transcription inversion. A request for the raw SmartPLS permutation output will show the verdict-generating statistic is not the printed p. If instead the p column is correct, then the paper's own α = 0.05 statement is false for H3 and H3's support collapses to a directional finding.

**RLVR-2 — Underpowered-null veto (verifiable by recomputation at n₁ = 45).**
*Setup:* The H4 verdict rests on Group 1, "45 individuals, 17 % of the sample" [PAGE 6], with a reported significance coefficient of 1.236.
*Veto:* Failure to reject at n₁ = 45 with a twelve-indicator, three-path model is not evidence of absence. Back-solving from t = 1.236 gives a standardized β₁ on the order of 0.18, far below the minimum detectable effect at conventional power.
*Prediction (falsifiable):* an equivalence test (TOST) with any reasonable margin δ ≥ 0.10 applied to the Group-1 estimate will **fail to establish equivalence to zero** — i.e. the data cannot distinguish "no transfer" from "small positive transfer." Further, a pre-registered replication with n₁ ≥ 150 will recover a *small positive* β₁ in the low-involvement class rather than a null. If the replication returns β₁ indistinguishable from zero at n₁ ≥ 150, RLVR-2 is falsified and the categorical negation stands.

**RLVR-3 — Moderator–selection collinearity veto (verifiable by channel instrumentation).**
*Setup:* Recruitment is an official-site banner [PAGE 4–5] with no sampling frame [PAGE 5]; involvement is the segmentation variable [PAGE 6]; the authors concede online-user bias as a limitation [PAGE 7].
*Veto:* If banner exposure is increasing in involvement, the latent classes are partly a channel artifact. **Prediction (falsifiable):** instrumenting recruitment source (banner click-through vs. direct navigation vs. off-site social referral) will show the involvement distribution differs by source; a replication recruiting off the official site will (i) reduce the entropy separation at K = 2 and (ii) shrink the permutation difference in standardized β₁ below the reported 0.21. If the off-site replication reproduces both the 0.21 difference and the group split, RLVR-3 is falsified and the segmentation is a consumer property rather than a channel property.

**RLVR-4 (corollary) — Invariance veto.** *Setup:* no per-group loadings or invariance test reported. *Prediction:* a MICOM-type test on the same data will pass compositional invariance but fail equal-weights/scalar invariance for at least one construct (most likely purchase intent, whose AVE of 0.751 is the lowest in Table 1 [PAGE 5]). If scalar invariance holds for all four constructs, the 0.21 difference is a pure structural effect and this veto is discharged.
</RLVR_COUNTERFACTUAL_VETOES>
