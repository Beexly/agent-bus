The paper’s formal evaluation operators are stated on [PAGE 3]. Accuracy is a dimensionless proportion:
\[
\mathrm{Accuracy}=\frac{N_{\mathrm{correct}}}{N_{\mathrm{total}}},
\]
where \(N_{\mathrm{correct}}\) and \(N_{\mathrm{total}}\) are counts of matches, so the result is dimensionless in \([0,1]\). The paper defines it verbally as “the total number of correct predictions divided by the total number of input samples” [PAGE 3].

Precision is:
\[
\mathrm{Precision}=\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FP}},
\]
with \(\mathrm{TP}\) and \(\mathrm{FP}\) being counts, so the result is dimensionless. The source states: “Precision is the number of True Positives divided by the number of True Positives and False Positives” [PAGE 3].

Recall is:
\[
\mathrm{Recall}=\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FN}},
\]
also dimensionless. The source states: “The recall is the number of True Positives divided by the number of True Positives and the number of False Negatives” [PAGE 3].

For \(K\)-fold cross-validation, the average metric is:
\[
\bar{M}=\frac{1}{K}\sum_{k=1}^{K}M_k,\qquad K=10,
\]
where \(M_k\) is a dimensionless metric on fold \(k\). The overall metric is:
\[
M_{\mathrm{overall}}=\frac{\sum_{k=1}^{K}N_{\mathrm{correct},k}}{\sum_{k=1}^{K}N_{\mathrm{total},k}}.
\]
The paper reports both “Overall accuracy” and “Avg. accuracy” [PAGE 4]. For DF: overall accuracy \(0.889474\), average accuracy \(0.926316\); ANN: \(0.715789\) and \(0.810526\); SVM: \(0.701111\) and \(0.783172\) [PAGE 4]. The headline uses the lower DF overall value, not the higher average value.

For single-label multiclass classification with \(C\) classes, \(N\) samples, true labels \(y_i\), and predictions \(\hat y_i\):
\[
\mathrm{MicroPrecision}
=\frac{\sum_{c=1}^{C}\mathrm{TP}_c}{\sum_{c=1}^{C}(\mathrm{TP}_c+\mathrm{FP}_c)}
=\frac{\sum_{i=1}^{N}\mathbf{1}[\hat y_i=y_i]}{N}
=\mathrm{Accuracy},
\]
and
\[
\mathrm{MicroRecall}
=\frac{\sum_{c=1}^{C}\mathrm{TP}_c}{\sum_{c=1}^{C}(\mathrm{TP}_c+\mathrm{FN}_c)}
=\frac{\sum_{i=1}^{N}\mathbf{1}[\hat y_i=y_i]}{N}
=\mathrm{Accuracy}.
\]
Thus the exact equality of “Overall precision”, “Overall recall”, and “Overall accuracy” in Table 2 [PAGE 4] is consistent with micro averaging and is not independent class-level evidence. A macro average would instead be:
\[
\mathrm{MacroPrecision}=\frac{1}{C}\sum_{c=1}^{C}\frac{\mathrm{TP}_c}{\mathrm{TP}_c+\mathrm{FP}_c},
\qquad
\mathrm{MacroRecall}=\frac{1}{C}\sum_{c=1}^{C}\frac{\mathrm{TP}_c}{\mathrm{TP}_c+\mathrm{FN}_c},
\]
and it need not equal accuracy.

The Decision Forest operator is a vote over \(T\) trees:
\[
\hat y(x)=\mathrm{mode}\{h_t(x)\}_{t=1}^{T},
\qquad
\hat p(y\mid x)=\frac{1}{T}\sum_{t=1}^{T}\mathbf{1}[h_t(x)=y],
\]
which matches the source’s description that “Decision Forest [18] works by creating multiple decision trees and then voting on the most popular output categories” [PAGE 3]. The probability estimate is dimensionless in \([0,1]\). The SVM operator is a hyperplane decision:
\[
f(x)=w^{\top}\phi(x)+b,
\qquad
\hat y(x)=\mathrm{sign}(f(x)),
\]
consistent with “SVM is based on the idea of creating a hyperplane that divides the data set into two classes in the best way” [PAGE 3]. The ANN is described only as “a supervised learning algorithm, which requires a labelled dataset” [PAGE 3]; no architecture, activation, loss, or training schedule is specified, so no further equation is justified from the source.

A proper probabilistic scoring rule, if the authors had released class probabilities, would be log-loss:
\[
\mathcal{L}=-\frac{1}{N}\sum_{i=1}^{N}\sum_{c=1}^{C}y_{ic}\log \hat p_{ic},
\]
with units of nats per match when using natural logarithms. The paper does not report this or a Brier score.

\]

\[
P(Y\mid X,C).
\]
By the law of total probability:
\[
P(Y\mid X)=\sum_{c}P(Y\mid X,c)P(c\mid X).
\]
This equality is valid as a marginal only if the training distribution of \(C\) matches the deployment distribution and the model is allowed to average over \(C\). It does not identify the conditional \(P(Y\mid X,c^{*})\) for a specific physical context \(c^{*}\). The omitted-variable gap is:
\[
\Delta(c^{*})=P(Y\mid X,c^{*})-P(Y\mid X),
\]
and without assumptions on \(P(Y\mid X,c)\) and \(P(c\mid X)\), \(\Delta(c^{*})\) has no sign bound and no magnitude bound. Therefore the paper cannot veto a physical claim by citing its 89% overall accuracy, and it cannot endorse one either.

\[
X\cap C=\varnothing.
\]
A model \(g:X\rightarrow\Delta(Y)\) is constant in \(C\). If a proposed physical veto requires the model to react to \(c^{*}\), then \(g\) must abstain. The exact breakdown regimes are: unseen team pairing with \(P(X)=0\); unseen physical context with \(P(c^{*}\mid X)=0\); zero class prior for a result class; and a deployment distribution shifted from the historical season.
