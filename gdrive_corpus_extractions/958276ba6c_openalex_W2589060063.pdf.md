The audit begins with the source’s data-producing pipeline rather than with its conclusions. On [PAGE 17] the author states: “The match date and the result will help to evaluate the eﬀects of fatigue in match result.” That sentence licenses a multi-hop derivation: match date to rest interval, rest interval to a binary “fatigue” field, binary fatigue to an ANOVA against binary match result, and then a causal-managerial interpretation. Each hop needs separate scrutiny.

Hop one: rest interval. Let match dates be \(t_i\) in days, so \(r_i=t_i-t_{i-1}\) has units of days. This is a legitimate schedule feature. Hop two: binarization. On [PAGE 18] the source says: “values less than 7 as ’0’ and more than 7 as ’1’. The value 7 is the average diﬀerence between two matches.” If fatigue means “overused through the season without proper rest” as stated on [PAGE 12], then short rest should map to high fatigue, not long rest. The source’s coding appears inverted relative to its own fatigue concept. The threshold also has a gray zone at exactly 7 days: the source gives no tie rule. Hop three: result coding. The source makes win equal to 1 and draw or loss equal to 0, which is a legitimate binary outcome but discards the ordinal difference between a draw and a loss. Hop four: ANOVA. On [PAGE 20] the source lists: “Dependent Variable : binomial fatigue ( data type : binomial ) Independent Variable: binomial result ( data type: binomial )”. This reverses the stated causal direction in the later prose, and more importantly applies a normal-errors ANOVA to two binary variables. The F-test can be computed, but its usual normal homoscedastic assumptions are not satisfied by Bernoulli outcomes. Hop five: the p-value. On [PAGE 21] the source says: “P value is less than 0.5, that means our hypothesis is true.” This is a serious threshold error: \(0.5\) is not a conventional alpha, and “hypothesis is true” is not what a rejection means. Hop six: the decision tree. On [PAGE 18] the source says: “It has got 25 independent variables and 1 dependent variable.” A single league season gives roughly 38 matches. With 25 tactical predictors and a small sample, a tree can memorize idiosyncratic match configurations. On [PAGE 20] the source says: “The Real Madrid Points attribute is termed as polynomial.” This creates a modeling ambiguity: if points are categorical, the tree is a classifier over three ordinal labels; if points are numeric, it should be a regression tree. <SOURCE_OPERATORS_AND_EQUATIONS>
The source contains five recoverable operators: rest-difference construction, binary thresholding, binary result construction, one-way ANOVA, and decision-tree partitioning. Their formal versions are as follows.

Let \(i=1,\dots,n\) index matches, with \(t_i\) the match date in days. The rest interval is
\[
r_i=t_i-t_{i-1},\qquad [r_i]=\mathrm{d}.
\]
The source’s fatigue indicator is, from [PAGE 18], “values less than 7 as ’0’ and more than 7 as ’1’”. In indicator form,
\[
F_i^{\mathrm{src}}=\mathbf{1}\{r_i>7\},
\]
with the gray zone \(r_i=7\) undefined. If fatigue is intended as short recovery, the risk indicator should instead be
\[
F_i^{\mathrm{risk}}=\mathbf{1}\{r_i \leq 7\}.
\]
The outcome is
\[
Y_i=\mathbf{1}\{\text{match }i\text{ is a win}\}\in\{0,1\}.
\]
The one-way ANOVA model is
\[
Y_{ij}=\mu+\tau_j+\epsilon_{ij},\qquad \epsilon_{ij}\sim\mathcal{N}(0,\sigma^2)\ \text{i.i.d.},
\]
where \(j\) indexes the two fatigue groups. The test statistic is
\[
F=\frac{SS_B/(k-1)}{SS_W/(N-k)}
=\frac{\sum_{j=1}^{k} n_j(\bar Y_j-\bar Y)^2/(k-1)}
{\sum_{j=1}^{k}\sum_{i=1}^{n_j}(Y_{ij}-\bar Y_j)^2/(N-k)}.
\]
For \(k=2\), under the null \(F\sim F_{1,N-2}\). Units: \(F\) is dimensionless; \(SS_B\) and \(SS_W\) are sums of squared binary outcomes, hence dimensionless. The breakdown regimes are important: if all \(Y_i\) are identical, \(SS_T=0\) and the F statistic is undefined; if all \(r_i\) fall on one side of 7, the fatigue factor has zero variance and the between-group sum of squares is zero; if \(r_i=7\) for any match, the source’s rule does not assign a group. The normal homoscedastic ANOVA assumption is also violated because a Bernoulli outcome has variance \(P(Y=1)(1-P(Y=1))\), which depends on the group mean. A more defensible model is logistic:
\[
\mathrm{logit}\,P(Y_i=1\mid F_i)=\beta_0+\beta_1 F_i,
\]
where \(\beta_1\) is dimensionless on the logit scale. This still estimates association, not causation.

The decision-tree operator is recursive impurity reduction. For a node \(S\), let
\[
p_k(S)=\frac{1}{|S|}\sum_{i\in S}\mathbf{1}\{y_i=k\}.
\]
The Gini impurity is
\[
G(S)=1-\sum_{k=1}^{K}p_k(S)^2\in[0,1-1/K],
\]
which is dimensionless. The entropy is
\[
H(S)=-\sum_{k=1}^{K}p_k(S)\log_2 p_k(S),
\]
with units of bits. The information gain for split \(A\) is
\[
IG(S,A)=H(S)-\sum_{a\in A}\frac{|S_a|}{|S|}H(S_a),
\]
also in bits. If the label is treated numerically as “Real Madrid Points,” the regression-tree criterion is
\[
SSE(S)=\sum_{i\in S}(y_i-\bar y_S)^2,
\]
with units of points squared, and the split reduction is
\[
\Delta SSE(S,A)=SSE(S)-\sum_{a\in A}\frac{|S_a|}{|S|}SSE(S_a).
\]
The source’s wording on [PAGE 20] — “The Real Madrid Points attribute is termed as polynomial” — leaves unclear whether the tree is classification over labels or regression over points. That ambiguity matters because a three-level ordinal target is not the same as a continuous target.

The causal estimand that the prose implicitly wants is
\[
\tau(x)=\mathbb{E}[Y_i(x)-Y_i(x')],
\]
where \(Y_i(x)\) is the potential match result under tactical configuration \(x\). Identification requires consistency, conditional exchangeability, and positivity. If unmeasured confounders \(C\) affect both tactics and results, the backdoor adjustment is
\[
P(Y=y\mid do(X=x))=\sum_c P(Y=y\mid X=x,C=c)P(C=c).
\]
Because the source does not measure injury availability, travel, weather, opponent strength, game state, or non-league fixtures, the sum over \(c\) is incomplete. On [PAGE 24] the source concedes: “The dataset has failed to include the other matches that occurs in between the league games”. That omission is a direct positivity and confounding failure for the fatigue claim. The source’s own literature review on [PAGE 15] warns: “Bayesian nets has been combined with the decision tree ([12]) which had a better output, but it was a complicated model that can make serious mistakes with the lesser number of input samples.” The same small-sample warning applies to the source’s tree. On [PAGE 16] the source also says: “Anova is very handy when the independent variable is continuous and the dependent is binary ([16]).” In this study both variables are binary, so the cited justification does not match the design. The exact singularity regimes are: zero within-group variance, zero between-group variance, a leaf with one class only, a split with no contrast, and a p-value threshold of 0.5 that admits far too many nulls. These are not cosmetic issues; they determine whether the reported operators can support the managerial conclusions.

<RECURSIVE_THEORY_OF_MIND>
The source’s tactical claims are best interpreted through a recursive theory-of-mind model in which the manager and opponent reason about each other’s beliefs. Let \(b_t\) be the manager’s belief over opponent type and match state, and let \(b_t^{O}\) be the opponent’s belief over the manager’s policy. A standard belief update is
\[
b_{t+1}(s')=\frac{O(o_{t+1}\mid s',a_t)\sum_{s}T(s'\mid s,a_t)b_t(s)}
{P(o_{t+1}\mid b_t,a_t)},
\]
where \(O\) is the observation model, \(T\) is the transition model, and all quantities are probabilities. The manager’s policy is \(\pi_M(a_t\mid b_t,h_t)\), and the opponent’s policy is \(\pi_O(a_t\mid b_t^{O},h_t)\). Recursive theory of mind means that the manager’s action depends on the manager’s belief about the opponent’s belief about the manager’s habit. The source lacks this layer entirely. It records tactical actions and points, but not the opponent’s defensive adjustment, the score-time state, or the manager’s pre-match intent.

Crisis habit regression is the first failure mode. Under perceived crisis, a manager may revert to a salient habit rather than to the adaptive best response. The source’s tree may be picking up exactly that: on [PAGE 22] it says “Their maximum loses came when they favored long shots when in possession.” Long shots are often a symptom of chasing a game, not a cause of losing. A recursive model would condition on score differential and minute; without those, the tree cannot separate “long shots produced losses” from “losses produced long shots.” The counter-trap is the second failure mode. If the manager’s habit is to attack the right side, the opponent can overload that side and concede central progression. The source notices a related concern on [PAGE 22]: “There were also areas of concern when it comes to attacking through the middle.” A recursive opponent would exploit the predictable right-side bias by forcing play central, where the source says Real Madrid were weaker. The observed “right side, no loss” rule may therefore be a selection effect: right-side attacks may occur against opponents who are already stretched, while central attacks occur against compact blocks. The third failure mode is the clock. On [PAGE 12] the source says: “The manager also has to choose whether he wants to protect his lead or to score one more and kill the match.” That is a score-time decision. A tree with no minute variable and no score-differential variable cannot represent it. The same tactical action can mean “protect a lead” in one state and “chase a goal” in another. The source’s decision tree collapses those states. A recursive theory-of-mind audit would require a state vector containing score difference, minute, opponent defensive shape, player availability, and rest interval. The source has only a subset of tactical event counts and points. The correct prediction is not that the tree is worthless, but that its splits are policy traces rather than causal levers. If an opponent anticipates the right-side habit, the manager’s counter-trap is to randomize between right, central, and long-shot actions according to the opponent’s belief. The source’s own narrative about Bale supports this: the right-side rule is entangled with the availability of a specific right-sided player, so the opponent’s problem is not “stop the right side” in the abstract but “exploit the fact that the right-side threat is conditional on Bale’s fitness.”
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Cross-layer veto adjudication asks whether a physical, biomechanical, or weather layer can invalidate the source’s tactical inference before it reaches a managerial recommendation. The source’s design lacks all three layers. On [PAGE 24] it admits: “The dataset has failed to include the other matches that occurs in between the league games”. That means the rest-day variable is not a true recovery variable. A physical veto is therefore active whenever a player’s true load differs materially from the league-only rest interval. Let \(L_i\) be a load vector with components such as distance covered in km, high-speed running in m, acceleration count, and collision load in arbitrary units. The source has no \(L_i\). If \(L_i\) affects both tactical execution \(X_i\) and result \(Y_i\), then the observed association \(P(Y\mid X)\) is not the causal effect \(P(Y\mid do(X))\). The backdoor path \(X\leftarrow L_i\rightarrow Y\) remains open. A physical veto predicate can be written as
\[
V_{\mathrm{phys},i}=\mathbf{1}\{\text{player unavailable or load above pre-registered threshold}\}.
\]
The exact threshold must be pre-registered; the source provides none. The proof of veto is by counterexample: suppose right-side attacks are more frequent when the squad is rested and Bale is fit. If forcing right-side attacks in a fatigued squad without Bale does not improve results, then the right-side split is not a causal tactic. The source cannot rule this out because it does not measure the physical layer.

The biomechanical layer is also absent. Asymmetry, pain, previous injury, and movement compensation change the execution of tactical actions. The source’s only biomechanical discussion is the Bale injury narrative on [PAGE 22]: “He had injuries regularly to an aggregate of 80 days in total, which made him to miss 17 of the 37 league games.” That is a post hoc explanation, not a covariate. A biomechanical veto predicate is
\[
V_{\mathrm{bio},i}=\mathbf{1}\{\text{asymmetry, pain, or injury status above pre-registered threshold}\}.
\]
If \(V_{\mathrm{bio},i}=1\), the observed tactical action is not the intended intervention: a player may be on the right side but unable to sprint, cut, or cross. The decision-tree split “attack through the right side” then mixes tactical intent with biomechanical capacity. The source’s conclusion that right-side attacks avoid losses is not transportable to a squad with different injury states.

The weather layer is entirely missing. Weather affects both tactics and physiology. Heat, wind, and rain change passing accuracy, sprint intensity, and the value of possession versus direct play. A weather veto predicate is
\[
V_{\mathrm{weather},i}=\mathbf{1}\{\mathrm{WBGT}>\theta_{\mathrm{WBGT}}\ \text{or wind}>\theta_{\mathrm{wind}}\ \text{or rain}>\theta_{\mathrm{rain}}\},
\]
with units of degrees Celsius, metres per second, and millimetres per hour. The thresholds must be pre-registered; the source provides none. If a match is played in heavy rain, a “long shots” split may reflect slippery conditions and lost possession rather than a stable tactical law. If \(V_{\mathrm{weather},i}=1\) for a large fraction of matches, the effective sample for clean tactical inference shrinks, and positivity can fail if a tactic occurs only under one weather regime.

The adjudication rule is conservative: if any veto layer is active and unmeasured, the tree output is downgraded from causal claim to exploratory association. The source itself gives the strongest proof of this downgrade on [PAGE 24]: “anova was still was able to prove that fatigue aﬀects the results of the game.” The verb “prove” is not licensed when the schedule proxy ignores cup and continental matches, when injury is narratively handled, and when weather is absent. The breakdown regimes are explicit: if \(V=1\) for all matches in a tactic’s support, there is no clean contrast; if \(V=1\) only for wins, the leaf is pure by selection; if the source’s fatigue threshold has no tie rule at exactly 7 days, the binary factor is partially undefined. Under those regimes, the correct output is abstention, not a managerial recommendation.
</CROSS_LAYER_VETO_ADJUDICATION>
