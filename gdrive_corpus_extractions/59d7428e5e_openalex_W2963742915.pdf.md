<THINK_TRACE>
The source paper defines a supervised camera-selection problem for soccer broadcast: given multiple candidate camera views, predict which view should be “on air.” The authors formalize the task as instantaneous single-frame classification, writing “yt = f(xt)” and stating “We do instantaneous single frame prediction and xt is a feature representation from all camera views” [PAGE 3]. The hard part is not the classifier itself; it is the data-generating process. The ideal training set would contain all candidate views plus the human director’s selection, but the authors note that such data are “generally not available to researchers” because they are owned by broadcasters [PAGE 1]. Their workaround is to use many Internet broadcast videos that contain only the selected view, plus one complete main game. This creates a missing-data problem: the auxiliary videos provide many positive examples but omit the unselected candidate views. The paper’s own missing-data classification is crucial: “The missing data in our problem is MNAR because the missing data is related to the value itself (all missing data is unselected by human operators)” [PAGE 2]. In other words, the fact that a view is missing is not accidental; it is caused by the human operator’s choice.

A multi-hop derivation starts by writing the complete candidate feature vector at time t as X_t = [x_{t,L}, x_{t,M}, x_{t,R}], with K = 3 candidate PTZ cameras in the main experiment [PAGE 2]. For the main game, all components are observed. For an auxiliary game, only the broadcast-selected component is observed; the other two are missing. Let M_{t,k} ∈ {0,1} be the observation indicator for camera k at time t. In the complete main game, M_{t,L}=M_{t,M}=M_{t,R}=1. In auxiliary broadcast video, exactly one M_{t,k}=1 and that camera is the one labeled by Y_t. This makes the missingness mechanism label-dependent: M_{t,k}=0 whenever k ≠ Y_t. The paper recognizes this circularity and responds by imputing missing values only during training, using the label Y because “this process is in training phase so that Y is available” [PAGE 4]. The imputation model is a random survival forest, which approximates draws from p(X_mis | X_obs, Y). The authors write: “Xmis ∼ p(Xmis|Xobs, Y)” and then give the integral form “p(Xmis|Xobs, Y) = ∫ p(Xmis|Xobs, θ)p(θ|Xobs, Y)dθ” [PAGE 4]. The derivation chain is therefore: complete data estimate tree parameters θ; auxiliary data draw missing features from the posterior given observed broadcast view and label; imputed features are then fused with complete-game features to train a final classifier.

The second major hop is feature representation. The authors use two 16-dimensional feature streams: a whole-image feature from a binary classification CNN that asks whether an image is selected by human operators, and a foreground feature built from a spatial-appearance heatmap [PAGE 5]. The foreground heatmap is motivated by the observation that “camera operators are trained to capture interesting players and keep the ball visible” [PAGE 2]. The authors argue that auxiliary games introduce background nuisance variation: “Auxiliary games are very different in lighting, fan celebration and stadium decoration” [PAGE 2]. The spatial-appearance heatmap is intended to suppress this nuisance by encoding player locations and appearances on a 16 × 9 grid, with each player represented by five bounding-box points contributing weighted appearance features to nearby cells [PAGE 5]. The final feature dimension is 96, because there are 16 whole-image dimensions plus 16 foreground dimensions for each of three candidate cameras: “The dimension of the feature is 96 (16 × 3 × 2 for two types of features from three candidate cameras)” [PAGE 5].

The evaluation chain is also important for gray-zone auditing. The authors test on the main game using “3-fold” cross-validation [PAGE 5] and use human operator selections as ground truth. The main result is that auxiliary data improve accuracy: “auxiliary data provides significant performance improvement (about 9.4%)” [PAGE 6]. They further decompose the gain: “the main improvement is from the feature extraction stage (about 6.6%). Data imputation provides an extra 2.8% improvement” [PAGE 6]. Table 2 shows the “both” feature model moving from 66.5% with main-game-only training to 75.9% with main plus auxiliary training [PAGE 7]. Table 3 places the full model against baselines: constant selection 40.9%, closest-to-ball 37.6%, team occupancy map 49.8%, ADA 54.1%, C3D 64.3%, and the proposed model 75.9% [PAGE 7]. These numbers support the paper’s claim, but they also expose the fragile dependencies: the gain depends on auxiliary label quality, imputation quality, detector quality, and the assumption that main and auxiliary games share a sufficiently similar broadcast policy.

The gray-zone audit identifies several nontrivial risks. First, the MNAR mechanism is handled by using Y during imputation. This can be legitimate in training, but it can also create a shortcut: the model may learn to infer the missing view from the observed broadcast view because both were generated by the same operator behavior. The paper explicitly assumes that “images from different viewpoints are correlated at a particular time instance” and that “Camera operators (from different viewpoints) cooperate to tell the story of the game” [PAGE 3]. This is a strong recursive assumption about operator coordination. If auxiliary games have different camera crews, different tactical styles, or different audience-management conventions, the posterior p(X_mis | X_obs, Y) may be biased. Second, the auxiliary labels are not perfectly reliable. The authors use a camera-ID CNN whose “prediction accuracy is about 85%” after five games, then manually check and refine labels [PAGE 5]. That means roughly one in six boundary-frame labels could be wrong before correction, and residual noise can propagate into the imputed feature distribution. Third, the foreground feature depends on player and ball detection. The authors use detected bounding boxes and a siamese appearance network, but detector failure or motion blur can collapse the heatmap into an invalid representation. Fourth, the temporal dimension is deliberately simplified. The paper admits that “our method models the viewpoint prediction problem as single frame prediction problem without using temporal information” [PAGE 3]. Later, it observes that human operators have “better temporal consistency while ours tends to provide more information in single frames” [PAGE 7]. This is the central tension: single-frame informativeness can conflict with broadcast continuity.

Overall, the paper is best read as an empirical demonstration that Internet broadcast video can be turned into auxiliary supervision if one carefully models missingness, imputes missing candidate views, and suppresses background nuisance. The strongest evidence is the accuracy jump from 66.5% to 75.9% when auxiliary data and imputation are added [PAGE 7]. The weakest points are the assumptions that auxiliary games are distributionally close enough to the main game, that RSF imputation is accurate enough under MNAR missingness, and that foreground appearance features remain stable under weather, lighting, and crowd variation. The next sections formalize these dependencies and identify breakdown regimes.

<SOURCE_OPERATORS_AND_EQUATIONS>
Let time be indexed by t, sampled at 1 frame per second for the main-game annotation and final model training. The source states ball annotations are at “1fps” on selected cameras [PAGE 3] and that “about 6,000 examples are uniformly downsampled (1fps) from the main game” [PAGE 5]. Thus the temporal unit is seconds, and the sampling frequency is 1 s⁻¹. The candidate camera set in the main experiment has cardinality K = 3: left, middle, and right PTZ cameras [PAGE 2, PAGE 7].

1. Classification operator.
The paper’s basic predictor is

\[
y_t = f(x_t),
\]

where \(y_t \in \{1,2,3\}\) is the selected camera label and \(x_t\) is the concatenated feature vector from all candidate views [PAGE 3]. In probabilistic form, the learned operator can be written as a posterior estimate

\[
\hat{p}_k(t) = \Pr(Y_t = k \mid x_t), \qquad k \in \{L,M,R\},
\]

with \(\hat{p}_k(t) \in [0,1]\) and \(\sum_k \hat{p}_k(t)=1\). Accuracy is dimensionless and reported as a percentage:

\[
\mathrm{Acc} = \frac{1}{N}\sum_{t=1}^{N} \mathbf{1}[\hat{y}_t = y_t],
\]

where \(\hat{y}_t = \arg\max_k \hat{p}_k(t)\). The source reports accuracy in tables and figures [PAGE 6, PAGE 7].

2. Missingness operator.
Define \(M_{t,k} \in \{0,1\}\) as the observation indicator for candidate camera k at time t. For complete main-game frames,

\[
M_{t,L}=M_{t,M}=M_{t,R}=1.
\]

For auxiliary Internet broadcast frames, only the selected broadcast camera is observed:

\[
\sum_{k \in \{L,M,R\}} M_{t,k} = 1,
\]

and, because the missing views are the unselected views,

\[
M_{t,k}=0 \iff k \neq Y_t.
\]

This is the formal meaning of the paper’s statement: “The missing data in our problem is MNAR because the missing data is related to the value itself (all missing data is unselected by human operators)” [PAGE 2]. The missingness mechanism is therefore not ignorable in the Rubin sense, because the probability of missingness depends on the very label being predicted.

3. Random survival forest imputation.
The target conditional distribution is

\[
X_{\text{mis}} \sim p(X_{\text{mis}} \mid X_{\text{obs}}, Y),
\]

with the marginalization

\[
p(X_{\text{mis}} \mid X_{\text{obs}}, Y)
=
\int p(X_{\text{mis}} \mid X_{\text{obs}}, \theta)
\, p(\theta \mid X_{\text{obs}}, Y)
\, d\theta,
\]

where \(\theta\) denotes tree parameters [PAGE 4]. The source explicitly notes that this is done during training: “Please note this process is in training phase so that Y is available” [PAGE 4]. In a survival tree, internal-node splits are optimized using observed data by minimizing cross entropy,

\[
H(p,q) = -\sum_{y} p(y)\log q(y),
\]

where \(p(y)\) is the empirical label distribution in the node and \(q(y)\) is the predicted distribution. For a missing feature dimension inside a node, the paper imputes by drawing from a uniform distribution

\[
X_{\text{mis},d} \sim U(a_d,b_d),
\]

where \(a_d\) and \(b_d\) are lower and upper bounds of observed values for dimension d in the target node [PAGE 4]. At terminal nodes, missing values are replaced by majority vote for categorical variables or mean values for continuous variables [PAGE 4].

Breakdown regimes for the RSF operator are exact and important. First, if a node has no observed values for a dimension d, then \(a_d\) and \(b_d\) are undefined and the uniform imputation operator has no valid support. Second, if the complete-data posterior \(p(\theta \mid X_{\text{obs}},Y)\) is sharply overfitted due to small sample size, the integral collapses toward unstable tree partitions. The final model uses only about 6,000 main-game examples and a 96-dimensional feature vector, with random-forest parameters “tree number 20, maximum depth 20 and minimum leaf node number 5” [PAGE 5]. This is not enormous relative to the feature dimension and the heterogeneity of soccer events. Third, if the label-dependent missingness mechanism changes across games, for example because an auxiliary broadcast crew uses a different storytelling policy, then the learned posterior is biased even if imputation is numerically plausible.

4. Contrastive appearance operator.
The foreground appearance feature is learned with a siamese network using the contrastive loss

\[
L_c(x_i,x_j,y_{i,j})
=
y_{i,j}D(x_i,x_j)^2
+
(1-y_{i,j})\max(\delta - D(x_i,x_j),0)^2,
\]

where \(x_i\) and \(x_j\) are sub-images, \(y_{i,j} \in \{0,1\}\) indicates similar or dissimilar player patches, \(D(\cdot)\) is the L2 distance, and \(\delta\) is the margin, set to 1 in the paper [PAGE 5]. Positive pairs come from tracked players in consecutive frames: “the tracked players in consecutive frames have similar appearance, pose and team membership” [PAGE 5]. The unit of \(D\) depends on the feature normalization; if features are normalized, \(D\) is dimensionless, and \(\delta=1\) is a dimensionless margin. If tracking is wrong, the positive-pair assumption becomes false and the loss pulls together dissimilar players. This is a direct failure mode for foreground features.

5. Spatial-appearance heatmap operator.
The image plane is quantized into a 16 × 9 grid [PAGE 5]. For each detected object p, five points are used: four bounding-box corners and one center point. Let \(a_{p,q}\) be the appearance feature contributed by point q of object p, and let \(w_{p,q}(u,v)\) be the barycentric weight of point q with respect to cell centers around grid cell \((u,v)\). A formal representation is

\[
H(u,v)
=
\sum_{p}
\sum_{q \in \mathcal{Q}_p}
w_{p,q}(u,v)\, a_{p,q},
\]

where \(\mathcal{Q}_p\) is the set of five points for object p. The source describes this as follows: “Each point contributes ‘heat’ to its located and neighboring cells” and “The weights are the barycentric coordinates of the corner with respect to four cell centers” [PAGE 5]. The heatmap is then input to a binary classification CNN, and the second-last fully connected layer is used as the foreground feature [PAGE 5].

Breakdown regimes for the heatmap operator are geometric. If a bounding box lies partially or wholly outside the 16 × 9 quantized image support, the barycentric weights are incomplete or invalid. If many players overlap, the heatmap sums multiple appearance vectors into the same cells, potentially causing destructive or constructive interference. If the detector misses the ball or a player, the corresponding heat is absent. The paper’s own result that baselines using ball location perform poorly suggests that sparse geometric cues alone are insufficient: “Baselines 1-3 do not work well on this dataset mainly because they omit the image content from the PTZ cameras” [PAGE 6].

6. Feature dimension and model size.
The source specifies two feature types, each 16-dimensional, and three candidate cameras:

\[
\dim(x_t) = 16 \times 3 \times 2 = 96.
\]

This exact expression is quoted in the implementation section: “The dimension of the feature is 96 (16 × 3 × 2 for two types of features from three candidate cameras)” [PAGE 5]. The final classifier is a random forest with 20 trees, maximum depth 20, and minimum leaf node number 5 [PAGE 5].

7. Imputation error metric.
For auditing imputation on the main game, the authors mask features of unselected cameras and measure absolute errors normalized by the range of each feature dimension. The normalized error for dimension d is formally

\[
e_{t,d}
=
\frac{|\hat{x}_{t,d}^{\text{mis}} - x_{t,d}^{\text{true}}|}
{\mathrm{range}_d},
\]

with \(e_{t,d} \in [0,1]\) under bounded features. The paper reports: “When the error threshold is 0.2, about 80% of the data are correctly predicted” [PAGE 7]. This gives an explicit breakdown threshold: if the normalized imputation error exceeds 0.2 for more than about 20% of masked entries, the imputation regime is worse than the paper’s reported operating point.

8. Temporal regularization.
The paper does not make temporal regularization the core model, but it discusses the CDF method from prior work: “The CDF method prevents too short (brief glimpse) and too long (monotonous selection) camera selections” [PAGE 6]. In constrained form, if \(\tau_i\) is the duration of camera shot i, then temporal regularization imposes

\[
T_{\min} \le \tau_i \le T_{\max},
\]

where \(T_{\min}\) and \(T_{\max}\) are minimum and maximum acceptable shot durations in seconds. The source does not provide exact numerical values for \(T_{\min}\) and \(T_{\max}\), but the qualitative constraint is explicit. The combined temporal experiment reports “our method is more accurate than [8] (70% vs. 66%)” on the external dataset [PAGE 6].

<RETROCAUSAL_GENEALOGY>
The paper’s lineage begins with the economic and production problem: soccer broadcasts require a director to choose among cameras, and automated selection could reduce production cost. The authors state that “Automatic camera selection is one of the key techniques in computational broadcasting” [PAGE 1]. This places the work in a tradition of computational sports broadcasting, where the goal is not merely tracking or event detection but the editorial decision of which view to show. The paper cites earlier automatic and semi-automatic viewpoint selection methods, including PTZ camera control and multi-camera selection [PAGE 2]. It also distinguishes its problem from single-camera viewpoint prediction by saying “Our problem belongs to multiple dynamic camera systems” [PAGE 2].

The most immediate methodological ancestor is prior camera-selection work by Chen et al. The paper cites ADA, the automated director assistance system, which used hand-crafted features such as player distribution and game flow [PAGE 2]. It also cites a later regression-based method constrained by temporal smoothness, which used a cumulative distribution function regularization to prevent too short or too long camera durations [PAGE 2]. The current paper positions itself against that method by noting that the prior method “requires a real-valued label (visual importance) for each candidate frame,” whereas the present work uses classification labels from human camera selections [PAGE 2]. This genealogical shift is important: the earlier line needed dense importance labels, while the present line tries to learn from sparse selection labels plus auxiliary broadcast videos.

The statistical-learning lineage comes from decision forests and random survival forests. The paper cites decision forests as a unified framework [PAGE 9, reference 10] and random survival forests as the imputation method [PAGE 9, reference 24]. It explicitly says: “we introduce the random survival forest method (RSF) [24] from statistical learning to impute the missing data” [PAGE 1]. The survival-tree imputation procedure is adapted from missing-data algorithms for random forests [PAGE 9, reference 34]. The genealogy is therefore: classical decision trees, random forests, survival trees, missing-data imputation, and finally multi-camera sports selection. The authors emphasize novelty: “To the best of our knowledge, we are the first to use Internet videos and RSF to solve camera selection problems” [PAGE 2].

The feature lineage is also traceable. The foreground appearance feature uses a siamese network and contrastive loss, citing Chopra et al. and Hadsell et al. [PAGE 5, PAGE 9]. Player tracking supervision comes from tracking literature, where consecutive-frame tracks provide positive examples [PAGE 5]. Object detection uses a method similar to R-FCN [PAGE 3, PAGE 9]. The spatial-appearance heatmap is related to earlier heatmap representations but modifies them by replacing fixed heat values with learned appearance features: “In the conventional heatmap, the ‘heat’ is pre-defined values such as the number of players. In our heatmap, the ‘heat’ is the object appearance feature that is learned from the data” [PAGE 5].

There are several multi-week data traps embedded in this genealogy. The first is label drift in auxiliary videos. The authors detect shot boundaries, train a CNN to classify camera IDs, and then manually refine labels. They report that “After five games, the prediction accuracy is about 85%” [PAGE 5]. This implies that over a multi-week collection process, the labeler’s behavior, the CNN’s confidence, and the manual correction standard can drift. If a systematic boundary-frame error is introduced early, it can propagate into the auxiliary training set. The second trap is stadium-specific adaptation. The authors constrain main and auxiliary games to the same stadium to reduce camera-location mismatch [PAGE 2]. This helps with geometric alignment but does not eliminate differences in lighting, crowd behavior, team tactics, or broadcast style. The paper acknowledges that “Auxiliary games are very different in lighting, fan celebration and stadium decoration” [PAGE 2]. The third trap is temporal aliasing. The main-game annotation is at 1 fps [PAGE 3], and imputation samples around shot boundaries within 2 seconds [PAGE 5]. Fast events such as a one-touch shot or a quick foul may occur between sampled frames, producing incomplete evidence for the classifier.

The paper’s dataset genealogy also matters. The authors compare their USL dataset with prior datasets and state that their dataset has “94 + 108” minutes, “1+12” games, and professional ground truth [PAGE 3]. They note that the 108 auxiliary minutes are “sparsely sampled from total 1,080 minutes data” [PAGE 3]. This is a large auxiliary corpus by academic standards, but it is still limited in diversity: one main game and twelve auxiliary games from the same stadium. The genealogy therefore leads to a method that is data-hungry but also highly dependent on local consistency. The historical lesson is that the method’s strength, namely leveraging Internet broadcast videos, is inseparable from its vulnerability: Internet videos are editorial artifacts, not neutral observations of all candidate views.

<RECURSIVE_THEORY_OF_MIND>
The paper implicitly models the human camera operator as an intentional agent. It states: “Camera operators (from different viewpoints) cooperate to tell the story of the game. For example, often the focus of attention of the cameras is the same (i.e. joint attention)” [PAGE 3]. This is a recursive theory-of-mind assumption: the director and camera operators are not merely recording pixels; they are coordinating attention to produce a coherent narrative. The model must infer not only where the ball is, but which story the production crew is telling. This is why the observed broadcast view can be informative about the missing views: if the cameras share joint attention, the observed view carries evidence about what the other cameras likely saw.

A first failure mode is crisis habit regression. During high-arousal events such as goals, fouls, cards, or celebrations, human operators may follow habitual editorial patterns: hold on the scorer, cut to the bench, show the crowd, or return to a wide safety shot. The paper groups evaluation by events such as “Goal/attempt,” “Kicks,” “Throw in,” “Foul/card,” and “General play” [PAGE 6]. If the model is trained mostly on frequent general-play transitions, it may regress toward the majority policy and underpredict rare crisis switches. The paper’s decomposition shows that data imputation helps especially in “throw in” and “general play,” but the figure-level detail for goal and card events requires careful auditing [PAGE 6]. A model that minimizes average cross-entropy can be accurate overall yet fail precisely when the director deviates from routine.

A second failure mode is the counter-trap of single-frame salience. The paper admits that its single-frame predictions “tend to provide more information in single frames,” while human operators have better temporal consistency [PAGE 7]. This means the model can be locally informative but editorially unstable. A counter-trap arises when the model learns that switching to the camera with the most foreground activity is better than maintaining a stable shot. In broadcast, however, too much switching can be visually exhausting. The CDF-based temporal model is introduced precisely to counter this: it “prevents too short (brief glimpse) and too long (monotonous selection) camera selections” [PAGE 6]. The recursive issue is that the director’s choices depend on expected viewer experience over time, not just instantaneous information content.

A third failure mode is the clock mismatch. The paper’s base model is instantaneous, but human camera work is temporally structured. The imputation procedure samples “within 2 seconds” of shot boundaries [PAGE 5], and the external temporal experiment uses a 5-minute sequence for testing [PAGE 6]. If the event dynamics occur on a faster clock than the model’s sampling or smoothing clock, the model will miss rapid transitions. If the smoothing clock is too slow, the model will suppress legitimate quick cuts. The recursive theory-of-mind requirement is therefore to estimate the operator’s temporal policy: how long they dwell on a player, how quickly they cut after a ball movement, and how they balance action versus reaction.

The auxiliary-game assumption also depends on a recursive model of broadcast consistency. The authors assume that the broadcast crew will behave similarly across games: “we expect the broadcast crew to have consistent behaviors across games to some extent” [PAGE 3]. This is plausible within one league and one stadium, but it is not guaranteed. If a different director prefers more crowd shots, more tactical wide shots, or more player close-ups, then the auxiliary labels encode a different objective. The classifier may then learn the auxiliary director’s habit rather than the main-game director’s habit. This is a theory-of-mind trap: the model infers intentions from behavior, but the behavior it observes belongs to a different intentional agent.

The strongest countermeasure in the paper is the foreground spatial-appearance heatmap. By focusing on players and ball, it attempts to infer the operational attention target rather than background style. The paper says the foreground feature “excludes the negative impact of backgrounds (e.g. different fan groups, weather and light conditions) of auxiliary games” [PAGE 6]. This is a reasonable counter-trap against stadium-specific background confounding. However, it introduces a new dependency: the model now trusts detected foreground objects. If the detector fails during a crisis event, the theory-of-mind inference collapses because the model no longer knows which players or ball the operator was attending to.

A recursive audit therefore recommends three layers. First, model the operator as an agent with event-dependent habits, not as a stationary classifier. Second, model time explicitly: shot duration, switch cost, and minimum dwell time should be part of the decision process. Third, verify that auxiliary games come from the same intentional regime, not merely the same stadium. The paper’s own evidence supports this concern: the full model improves to 75.9% with auxiliary data [PAGE 7], but the improvement is not uniform across events and depends on imputation and foreground features [PAGE 6]. The temporal experiment improves to 70% versus 66% on the external dataset when combined with CDF regularization [PAGE 6], showing that temporal policy matters. The unresolved question is whether the model has learned the main director’s crisis habits or merely the average habit of twelve auxiliary broadcasts.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
A cross-layer veto is required when a recommendation is physically, biomechanically, or environmentally invalid even if the learned classifier assigns it high posterior probability. The paper’s method operates under physical camera constraints. The main game uses three PTZ candidate cameras: one mid-field overview and two behind the left and right goals [PAGE 2]. The authors state: “Our system only uses information from the three PTZ cameras to select the broadcast camera” [PAGE 2]. Later they observe that “most of the shots are from the three cameras that cover the left goal area, the middle field and the right goal area” [PAGE 7]. This is an explicit spatial coverage assumption.

Physical veto proof. Let \(S_t\) be the true soccer event location at time t, and let \(C_k\) be the coverage region of camera k. Define a visibility indicator

\[
V_{t,k} =
\begin{cases}
1, & S_t \in C_k \text{ and camera } k \text{ can physically acquire } S_t,\\
0, & \text{otherwise}.
\end{cases}
\]

If \(V_{t,k}=0\) for all candidate cameras, then no valid broadcast selection exists from the candidate set. If \(V_{t,k}=0\) for the human-selected camera but \(V_{t,j}=1\) for another camera j, the observed label may reflect an editorial choice, a technical workaround, or a labeling error. A classifier trained without visibility constraints may recommend an invalid camera if the feature distribution resembles a valid event. Therefore, any predicted camera with \(V_{t,k}=0\) should be vetoed. This veto follows directly from the paper’s limited camera coverage: left goal, middle field, right goal [PAGE 7]. Actions in uncovered regions, such as extreme corners, behind-goal areas not visible to the PTZ heads, or off-field events, can break the assumption.

Biomechanical veto. Players and ball move continuously, but the model samples at 1 fps for annotation and final training [PAGE 3, PAGE 5]. Let player position be \(p(t)\) and ball position be \(b(t)\), with velocities \(v_p(t)\) and \(v_b(t)\) in m s⁻¹. If the frame interval is \(\Delta t = 1\) s, then the displacement between samples is approximately \(v\Delta t\). For fast ball movement or rapid player transitions, the sampled bounding box may not represent the true event position at the cut time. The spatial-appearance heatmap uses five bounding-box points to distribute heat to a 16 × 9 grid [PAGE 5]. If the bounding box is displaced by more than one grid cell, the foreground feature can encode the wrong spatial attention. The veto condition is:

\[
\| \hat{b}(t) - b(t) \|_2 > \gamma_{\text{cell}},
\]

where \(\gamma_{\text{cell}}\) is the physical scale of one grid cell. If this occurs for the event-critical object, the foreground feature is invalid for that frame.

The ball-visibility assumption is also biomechanically fragile. The paper states that camera operators are trained to “keep the ball visible” [PAGE 2]. But in soccer, the ball can be occluded by players, officials, goalposts, or advertising boards. If the ball is occluded, the operator may choose a camera based on player formation, tactical context, or prior knowledge, not direct ball visibility. A model that relies heavily on foreground appearance may misinterpret the operator’s intention. The veto proof is that the observation model \(x_{t,k}\) is not a faithful measurement of the true attention state when occlusion or motion blur destroys the relevant visual evidence.

Weather and lighting veto. The paper explicitly notes that auxiliary games differ in “lighting, fan celebration and stadium decoration” [PAGE 2]. Weather is not directly measured in the paper, but outdoor soccer is exposed to sun, rain, fog, wind, and artificial-light changes. Let \(E\) be illuminance in lux and \(L\) be scene luminance in cd m⁻². Detection and appearance features depend on contrast and exposure. If rain reduces lens transmittance, if fog scatters light, or if glare saturates the image, then the detected bounding boxes and appearance vectors can become unreliable. A formal corruption model can be written as

\[
\tilde{x}_{t,k} = g(x_{t,k}; \eta_t) + \epsilon_t,
\]

where \(\eta_t\) encodes environmental state and \(\epsilon_t\) is sensor noise. If \(g\) is non-invertible or strongly label-dependent with respect to environment, then a classifier trained on clear-weather auxiliary games may fail under adverse weather. The veto condition is that environmental corruption exceeds the training envelope:

\[
D_{\text{env}}(P_{\text{test}}(x \mid \eta_{\text{test}}) \,\|\, P_{\text{train}}(x \mid \eta_{\text{train}})) > \tau_{\text{env}}.
\]

If this holds, predictions from the auxiliary-trained foreground model should be suspended unless validated on main-game weather-matched data. The paper’s foreground feature is designed to reduce background nuisance, but it does not remove weather-induced appearance distortion from the players and ball themselves.

A concrete cross-layer veto proof can be stated as follows. Suppose at time t the true event is a goal-mouth scramble. The human director selects the right-goal camera because it shows the ball crossing the line. A classifier trained on auxiliary games may predict the middle camera because in many auxiliary examples the middle camera is the safe default. If the middle camera does not have visibility of the goal line at that instant, then \(V_{t,M}=0\) for the event. Even if \(\hat{p}_M(t)\) is high, the prediction is physically invalid. The veto is not a statistical correction; it is a hard constraint. Therefore, deployment requires a visibility layer, a detector-confidence layer, and a temporal-safety layer before accepting the classifier’s recommendation.

The final adjudication is that the paper’s method is valid only inside a bounded physical regime: three PTZ cameras with established coverage, sufficiently reliable detection, stable lighting, and event dynamics compatible with 1 fps sampling. Outside that regime, the learned posterior should be vetoed or downgraded. This is especially important for small-budget broadcasting, which the paper mentions as an application [PAGE 7]. Small-budget systems may lack robust detection and stable lighting, making the physical veto layer essential.

The following are three verifiable reinforcement-learning-style veto scenarios with counterfactual predictions. The reward signal is the human operator’s camera selection, verified against the predicted camera. A veto is triggered when the reward-generating process or the observation channel is no longer trustworthy.

1. Auxiliary label-noise veto.
Verification scenario. The auxiliary labels are generated by detecting shot boundaries and classifying camera IDs. The paper reports: “After five games, the prediction accuracy is about 85%” [PAGE 5]. The authors then manually check and refine labels, collecting “1,634 pairs of boundary frames from twelve videos” [PAGE 5]. The veto condition is:

\[
\mathrm{LabelNoise}_{\text{aux}} > 0.15
\]

after manual correction, measured on a held-out manually verified boundary-frame set. If the residual label error exceeds the reported 85% CNN accuracy baseline, the auxiliary reward signal is too noisy.

Counterfactual prediction. If this veto is ignored and auxiliary labels remain noisy, the model will learn incorrect mappings from observed broadcast views to missing candidate features. The paper’s reported auxiliary gain is about 9.4% overall, decomposed into about 6.6% from feature extraction and 2.8% from imputation [PAGE 6]. Under high label noise, the 2.8% imputation gain should shrink toward zero, and the 6.6% feature-extraction gain should degrade because the whole-image and foreground CNNs will be trained with incorrect positive/negative labels. The expected outcome is that main-plus-auxiliary accuracy falls toward the main-only baseline of 66.5% [PAGE 7], or possibly below it if noisy auxiliary examples actively distort the decision boundary.

2. Imputation-error veto.
Verification scenario. The paper validates imputation on the main game by masking features from unselected cameras and measuring normalized absolute error. It reports: “When the error threshold is 0.2, about 80% of the data are correctly predicted” [PAGE 7]. The veto condition is:

\[
\Pr(e_{t,d} > 0.2) > 0.20
\]

on a masked main-game validation set, where \(e_{t,d}\) is the normalized imputation error for feature dimension d. This condition says that more than one fifth of imputed feature entries exceed the paper’s reported operating tolerance.

Counterfactual prediction. If the veto triggers, the imputed auxiliary features are not close enough to the complete-data manifold. The final random-forest classifier may still train, but it will rely on distorted features. The paper compares RSF with nearest neighbor, OptSpace, and an autoencoder: RSF achieves 75.9%, nearest neighbor 72.2%, OptSpace 68.6%, and autoencoder 73.9% [PAGE 8]. If RSF imputation error exceeds the stated regime, the expected performance should fall below the RSF result and approach the weaker imputation alternatives. In the extreme, the main-plus-auxiliary model should converge toward the main-only model at 66.5% [PAGE 7].
