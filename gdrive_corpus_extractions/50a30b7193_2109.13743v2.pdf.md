The source explicitly states: “At each t′ ∈T , for each pair of compared items {i, j} ∈Et′, we perform L independent comparisons. Their outcomes are independent Bernoulli variables” [PAGE 4]. The dynamic problem is not identifiable from one sparse graph, because a single \(G_{t'}\) may be disconnected. The central smoothing move is therefore to pool data over a temporal neighborhood \(N_\delta(t)=\{t'\in T: |t-t'|\le \delta/T\}\) [PAGE 5], then form the union graph \(E_\delta(t)=\cup_{t'\in N_\delta(t)}E_{t'}\), average edge outcomes, and run a Rank Centrality spectral estimator on the pooled transition matrix. The abstract says the authors “adapt the Rank Centrality method – a popular spectral approach for ranking in the static case – by locally averaging the available data on a suitable neighborhood of t” [PAGE 1].

The multi-hop derivation is: BTL likelihood at each time gives edge probabilities; Assumption 1 imposes Lipschitz smoothness, “There exists M ≥0 such that |y∗ ij(t) −y∗ ij(t′)| ≤M|t −t′|” [PAGE 4]; neighborhood averaging creates a bias of order \(M\delta/T\), since the paper states “|¯y∗ ij(t) −y∗ ij(t)| ≤Mδ/T” and “if δ = o(T)” then the averaged population edge probability converges to the pointwise one [PAGE 5]. The primary source operators are as follows.

1. Dynamic BTL probability operator. For positive strengths \(w^*_{t,i}\) and \(i\ne j\),
\[
\mathcal B_t(w^*_t)_{ij}
=
\frac{w^*_{t,j}}{w^*_{t,i}+w^*_{t,j}}.
\]
The source states the probability that item \(j\) beats item \(i\) is given by this ratio and describes the model as the dynamic BTL model [PAGE 4]. The output is a probability in \([0,1]\), hence dimensionless.

2. Temporal smoothness operator. Assumption 1 states
\[
|y^*_{ij}(t)-y^*_{ij}(t')|\le M|t-t'|,
\qquad t,t'\in[0,1],\ i\ne j\in[n].
\]
This is quoted on [PAGE 4]. If \(t\) is measured in seconds, \(M\) has units of \(\mathrm{s}^{-1}\); because the paper normalizes \(t\in[0,1]\), \(M\) is dimensionless in normalized time. \(y^*_{ij}\) is a probability, so the left side is dimensionless.

3. Neighborhood and union-graph operators. The neighborhood is
\[
N_\delta(t)=\{t'\in T: |t-t'|\le \delta/T\},
\]
quoted on [PAGE 5]. The union graph is \(G_\delta(t)=([n],E_\delta(t))\) with
\[
E_\delta(t)=\bigcup_{t'\in N_\delta(t)}E_{t'}.
\]
Here \(T\) is a grid size, \(\delta\) is a grid-count half-width, and \(|T|=T+1\). Both are dimensionless counts. The paper notes \(\delta\in[1/2,T]\) is required to avoid empty neighborhoods for some \(t\) [PAGE 5].

4. Nearest-neighbor edge-average operator. For \(\{i,j\}\in E_\delta(t)\),
\[
\bar y_{ij}(t)
=
\frac{1}{|N_{ij,\delta}(t)|}
\sum_{t'\in N_{ij,\delta}(t)} y_{ij}(t'),
\]
where \(N_{ij,\delta}(t)=\{t'\in N_\delta(t): \{i,j\}\in E_{t'}\}\). The paper calls these “nearest neighbor estimators” because they average over a suitable neighborhood of \(t\) [PAGE 5]. This operator reduces variance as \(\delta\) grows but introduces bias bounded by \(M\delta/T\).

5. Empirical transition operator. The source defines \(\widehat P(t)\) on the union graph using the averaged outcomes, with
\[
\widehat P_{ij}(t)
=
\frac{\bar y_{ij}(t)}{d_\delta(t)}
\quad \text{for } \{i,j\}\in E_\delta(t),
\]
and diagonal entries chosen so that the row sums equal one, using \(d_\delta(t)\ge d_{\max,\delta}(t)\) [PAGE 6]. The population transition matrix \(\bar P(t)\) replaces \(\bar y_{ij}(t)\) by the corresponding BTL population ratios and is reversible with respect to \(\pi^*(t)=w_t^*/\|w_t^*\|_1\) [PAGE 6]. The spectral estimator is the leading left eigenvector:
\[
\widehat\pi(t)^\top=\widehat\pi(t)^\top\widehat P(t).
\]

6. Error metrics. The relative \(\ell_2\) error is
\[
\frac{\|\widehat\pi(t)-\pi^*(t)\|_2}{\|\pi^*(t)\|_2},
\]
and the relative \(\ell_\infty\) error is
\[
\frac{\|\widehat\pi(t)-\pi^*(t)\|_\infty}{\|\pi^*(t)\|_\infty}.
\]
Both are dimensionless because \(\pi^*\) is a normalized probability vector. The non-normalized \(\ell_2\) error has probability-mass units. The paper’s main \(\ell_2\) theorem is Theorem 1 on [PAGE 8]; its bias term scales like
\[
\frac{M\delta |E_\delta(t)|b^{7/2}(t)d_\delta(t)}
{T\xi_\delta(t)d_{\min,\delta}(t)d_{\max,\delta}(t)},
\]
and its variance term scales like
\[
\frac{b^{9/2}(t)}{\xi_\delta(t)d_{\min,\delta}(t)}
\sqrt{\frac{N_{\max,\delta}(t)d_{\max,\delta}(t)}{L N_{\min,\delta}^2(t)}}.
\]
The source calls the first term the bias and the second the variance [PAGE 8]. In the Erdős–Rényi specialization, Theorem 2 gives the relative \(\ell_2\) bound
\[
\frac{\|\widehat\pi(t)-\pi^*(t)\|_2}{\|\pi^*(t)\|_2}
\lesssim
\frac{M\delta n b^{7/2}(t)}{T}
+
b^{9/2}(t)
\sqrt{\frac{1}{Lnp_\delta(t)p_{\delta,\mathrm{sum}}(t)}},
\]
with \(p_\delta(t)=1-\prod_{t'\in N_\delta(t)}(1-p(t'))\) and \(p_{\delta,\mathrm{sum}}(t)=\sum_{t'\in N_\delta(t)}p(t')\) [PAGE 9]. Here \(p_\delta(t)\) and \(p_{\delta,\mathrm{sum}}(t)\) are dimensionless probabilities and expected edge-coverage counts respectively; \(L\) is a count of Bernoulli trials.

7. Information and logarithm units. The high-probability statements use \(\log n\), \(O(n^{-10})\), and \(O(n^{-9})\) [PAGE 8, PAGE 11]. If the logarithm is natural, \(\log n\) is measured in nats; if base two, in bits; absolute constants absorb the base. The spectral gap \(\xi_\delta(t)\) is dimensionless. The log terms are not physical energy units; they are information-theoretic concentration units.

Assumptions and breakdown regimes. The model requires positive strengths \(w^*_{t,i}>0\), finite \(b(t)=\max_{i,j}w^*_{t,i}/w^*_{t,j}\), and \(d_\delta(t)\ge d_{\max,\delta}(t)\) [PAGE 7]. Theorem 1 additionally requires \(n\ge c_1\log n\), \(\xi_\delta(t)>0\), and the inequality (3.1) [PAGE 8]. If \(\xi_\delta(t)\le0\) or the union graph is disconnected, the stationary distribution is not unique; the source says connectivity and strict positivity ensure irreducibility [PAGE 7]. If \(d_\delta(t)<d_{\max,\delta}(t)\), the transition matrix normalization is invalid. If \(b(t)\) diverges, the relative error bound degenerates because a tiny true probability is being estimated. If \(p_{\delta,\mathrm{sum}}(t)\ll\log n\), Lemma 12’s concentration of \(N_{\min,\delta}(t)\) and \(N_{\max,\delta}(t)\) fails; the paper warns this condition implicitly imposes completeness of \(G_\delta(t)\) [PAGE 12] and introduces \(\widetilde G_\delta(t)\) to handle sparser regimes [PAGE 12]. <RETROCAUSAL_GENEALOGY>
The scientific genealogy runs from the classical static BTL model of Bradley and Terry and Luce [PAGE 2] to Rank Centrality as a spectral ranking method [PAGE 2], then to static optimality analyses such as Chen et al. [PAGE 2], and then to dynamic extensions. The paper positions its contribution against two nearby dynamic lines: Bong et al. use kernel smoothing followed by maximum likelihood, with a logit version of BTL and Gaussian-process-like smoothness [PAGE 28]; Li and Wakin study time-varying pairwise comparison matrices with latent factors and noisy linear measurements [PAGE 29]. The source says Bong et al. derive \(\ell_\infty\) bounds for \(\widehat\beta\) and recover the \(T^{-1/3}\) rate for pointwise estimation of Lipschitz functions [PAGE 29]. The present paper differs by using nearest-neighbor averaging plus Rank Centrality, giving \(\ell_2\) and \(\ell_\infty\) guarantees under Erdős–Rényi comparison graphs.

The retrocausal reading is that the static theory is not discarded; it is the base case. When \(M=0\), the dynamic problem reduces to pooling a constant edge-probability graph, and the paper notes \(\delta=T\) is optimal [PAGE 10]. When \(M>0\), the temporal smoothing bandwidth \(\delta\) becomes a bias–variance clock. The paper’s Example 1 gives an explicit sparse illustration: for \(L=1\), \(b(t)\asymp1\), \(M\asymp1\), and \(p_{\min},p_{\max}\asymp1/n\), Theorem 5 yields, for \(\delta=T^{2/3}(\log n)^{1/3}/n^{2/3}\) and a stated range of \(T\), the relative \(\ell_2\) rate \((n\log n/T)^{1/3}\) [PAGE 14]. Theorem 4 in the dense regime yields \((n/T)^{1/3}\) for \(\delta=(T/n)^{2/3}\) [PAGE 14]. This shows the genealogy from nonparametric Lipschitz estimation to graph-based ranking: the rate is inherited, but graph sparsity inserts \(n\), \(\log n\), and degree factors.

Multi-week traps are temporal-data traps. First, the single-week trap: using only \(G_t\) can fail because “Gt is not necessarily going to be connected” and all comparison graphs can be disconnected [PAGE 3]. Second, the whole-season smoothing trap: setting \(\delta=T\) forces a large union graph but creates bias of order \(M\delta/T\), which is \(O(M)\) and does not vanish with \(T\) when \(M>0\). Third, the sparse-week trap: each weekly graph may be very sparse, so the paper deliberately works with the union over a neighborhood and states that consistency can hold even when each \(G_{t'}\) is potentially disconnected [PAGE 3]. Fourth, the regime-shift trap: an abrupt roster, injury, weather, or strategy change makes \(y^*_{ij}(t)\) non-Lipschitz or increases \(M\), breaking the smoothness premise [PAGE 4]. Fifth, the correlation trap: the model assumes independence across time, but the authors themselves flag this as questionable in future work: “the independence across different time points” is one of the main assumptions [PAGE 30]. Sixth, the edge-coverage trap: if \(p_{\delta,\mathrm{sum}}(t)\) is too small, \(N_{\min,\delta}(t)\) and \(N_{\max,\delta}(t)\) do not concentrate, which is why the modified graph construction appears [PAGE 12]. These traps are multi-week because they emerge only when one compares several successive graphs, not from a single adjacency matrix.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
A recursive analyst modeling this paper must model three failure modes in their own reasoning. Crisis habit regression is the fallback to static Rank Centrality on one weekly graph when the union graph looks sparse or noisy. That habit feels “local” and interpretable, but it contradicts the paper’s identifiability condition: connectivity of the union graph is required, and a single \(G_t\) may be disconnected [PAGE 3, PAGE 7]. The static fallback also discards the temporal averaging that reduces variance. The source’s whole design is a counter to this habit: pool over \(N_\delta(t)\), form \(G_\delta(t)\), then run the spectral estimator.

The counter-trap is overcorrection: choosing \(\delta\) very large, up to \(T\), to force connectivity and reduce variance. This is not free. The source says the bias “will scale as O(δ/T)” due to Assumption 1 [PAGE 7]. If \(M>0\), taking \(\delta=T\) makes the bias non-vanishing. The paper’s optimal choice in Corollary 1 is \(\delta=\Theta(T^{2/3})\), not \(\delta=T\), precisely to balance the \(M\delta n/T\) bias against the variance \(\propto 1/\sqrt{Ln\delta p_{\min}}\) [PAGE 10]. Thus the counter-trap is mistaking “more smoothing” for “more truth.”

The clock is the bandwidth ratio \(\delta/T\). It is the model’s temporal resolution. A fast clock, meaning small \(\delta\), has high variance and possible disconnection. A slow clock, meaning large \(\delta\), has high bias and washes out genuine temporal changes. The paper’s \(\ell_2\) and \(\ell_\infty\) corollaries both choose a \(T^{2/3}\) clock in the Lipschitz regime [PAGE 10, PAGE 12]. The recursive theory of mind is that an analyst must also model how the ranking will be used: if users or teams respond to rankings, future comparison data may become endogenous, violating the paper’s independence assumptions. The source explicitly flags this in future work, saying one main assumption is “the independence of the outcomes for all comparisons at a given time t, and the independence across different time points” [PAGE 30]. It also flags a home effect as a model limitation [PAGE 30]. Therefore the correct mental model is not “estimate ranks once,” but “estimate ranks under a stated bandwidth, connectivity condition, and independence assumption, then monitor whether the data-generating process has broken the assumption.” The crisis habit is static; the counter-trap is global; the clock is the disciplined neighborhood.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The cross-layer veto question is whether a physical, biomechanical, or weather variable can override the BTL rank inference. The adjudication rule is that such a variable has admissible force only if it changes the pairwise outcome probability \(y^*_{ij}(t)\) or changes the edge support \(E_t\). The rank functional depends on \(\pi^*(t)\), which is the normalized positive-strength vector, and on the connectivity of the union graph \(G_\delta(t)\). If a weather variable \(Z\) is constant across all compared pairs and does not alter \(y^*_{ij}(t)\) or \(E_t\), then it has no path to \(\pi^*(t)\), so it cannot veto the ranking. This is a path-intervention criterion: no measured effect on pairwise probability and no effect on graph support implies zero adjudicative effect.

If \(Z\) does alter \(y^*_{ij}(t)\), it must enter through the dynamic BTL probability or through the smoothness constant \(M\). It is then not an external veto; it is part of the data-generating process. The paper’s assumption is
\[
|y^*_{ij}(t)-y^*_{ij}(t')|\le M|t-t'|,
\]
so a weather or biomechanical shock is admissible only if the induced change is compatible with this Lipschitz bound [PAGE 4]. If an injury or weather event causes an abrupt jump that violates the bound, then the bias term \(M\delta/T\) dominates and the \(T^{-1/3}\) guarantee is vetoed by the model’s own assumptions, not by an external layer. If the event disconnects the union graph or makes \(b(t)\) unbounded, then the stationary distribution is not unique or is ill-conditioned [PAGE 7]. If the event leaves connectivity intact and the Lipschitz constant finite, then the spectral estimator remains admissible; the event is absorbed into \(w_t^*\) and \(M\).

A concrete proof sketch is therefore: assume a candidate cross-layer variable \(Z\). Either \(\Delta y^*_{ij}(t;Z)=0\) for all compared edges and \(E_t\) is unchanged, in which case \(Z\) is causally irrelevant to the rank functional; or \(\Delta y^*_{ij}(t;Z)\ne0\), in which case \(Z\) is a component of \(y^*\), and the only question is whether it respects the smoothness, positivity, and connectivity conditions. If it does, the BTL/rank-centrality result applies with the modified \(w_t^*\) and \(M\). If it does not, the theorem’s hypotheses fail: either \(\xi_\delta(t)\le0\), or \(b(t)\) is infinite, or the noise-control condition (3.1) is violated. Thus physical, biomechanical, or weather layers can veto only by breaking these explicit mathematical conditions; they cannot veto by unsupported narrative.
</CROSS_LAYER_VETO_ADJUDICATION>
