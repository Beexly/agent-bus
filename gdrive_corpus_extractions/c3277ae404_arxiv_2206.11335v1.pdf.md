**Operator 1: Sampling operator.** Let \(x(t)\) be a continuous signal, e.g. player position or heart-rate-related waveform. The sampled sequence is
\[
x_k=x(t_k),\qquad t_k=t_0+k\Delta t,\qquad f_s=\frac{1}{\Delta t}.
\]
Units: \(t_k\) in s, \(\Delta t\) in s, \(f_s\) in Hz. The source supplies the approximate rate: “a sample rate of around 20 times per second” [PAGE 2]. Under the assumption of ideal uniform sampling, the Nyquist representable bandwidth is \(B_{\max}=f_s/2\), so \(B_{\max}\approx 10\,{\rm Hz}\). Breakdown regimes: \(\Delta t\le 0\) is undefined; if the signal has significant spectral power above \(B_{\max}\), aliasing occurs; if the actual ZXY rate differs from 20 Hz, the bandwidth bound changes. The source does not provide a spectrum, so the 10 Hz figure is a bound, not a measurement.

**Operator 2: Finite-difference velocity and acceleration.** For position \(p_k\in\mathbb{R}^3\) in m,
\[
v_k=\frac{p_{k+1}-p_{k-1}}{2\Delta t},\qquad
a_k=\frac{p_{k+1}-2p_k+p_{k-1}}{\Delta t^2}.
\]
Units: \(v_k\) in m s\(^{-1}\), \(a_k\) in m s\(^{-2}\). The source supports the existence of derived values: “These positioned data are processed to separate standard values like as distance covered, speed and acceleration, and so on” [PAGE 2]. Assumption: position samples are time-aligned and position noise is independent. If position error variance is \(\sigma_p^2\), the second-difference acceleration error variance scales as
\[
\sigma_a^2\approx \frac{6\sigma_p^2}{\Delta t^4}.
\]
Breakdown regimes: \(\Delta t\to 0\) makes the denominator singular and amplifies position noise; therefore raw 20 Hz second differences can be numerically unstable for small \(\sigma_p\). Smoothing, filtering, or model-based estimation is required before biomechanical interpretation.

**Operator 3: End-to-end latency.** A formal latency decomposition is
\[
T_{\rm e2e}=T_{\rm sense}+T_{\rm proc}+T_{\rm net}+T_{\rm dec}+T_{\rm act},
\]
\[
T_{\rm net}=T_{\rm prop}+T_{\rm ser}+T_{\rm queue}+T_{\rm retx},
\qquad
T_{\rm prop}=\frac{d}{c},\qquad
T_{\rm ser}=\frac{S}{B_{\rm net}}.
\]
Units: all \(T\) terms in s; \(d\) in m; \(c\) in m s\(^{-1}\); \(S\) in bit; \(B_{\rm net}\) in bit s\(^{-1}\). The source motivates the fog term: “Applications that use fog computing can circumvent network performance limitations in cloud computing by processing data close to edge devices” [PAGE 4], and fog nodes “can reduce both propagation delay and bandwidth utilization” [PAGE 4]. Assumption: the network path is known and stable. Breakdown regimes: \(B_{\rm net}\to 0\) makes \(T_{\rm ser}\to\infty\); a lost link makes cloud-only \(T_{\rm e2e}\) undefined for the decision deadline; queueing can diverge near capacity; retransmission can violate soft real-time constraints. The source gives no numeric \(T_{\rm e2e}\) budget, so “real-time” [PAGE 4] remains an architectural aim, not a measured guarantee.

**Operator 4: Video rate and bandwidth pressure.** For raw video,
\[
R_{\rm raw}=N_{\rm pix}\,b\,f_{\rm frame},\qquad
R_{\rm comp}=\frac{R_{\rm raw}}{C_c}.
\]
Units: \(N_{\rm pix}\) dimensionless pixels per frame; \(b\) in bit per pixel; \(f_{\rm frame}\) in Hz; \(R_{\rm raw},R_{\rm comp}\) in bit s\(^{-1}\); \(C_c\) dimensionless compression factor. The source states: “A substantial amount of data is also generated through the video streams supplied by the stadium’s cameras. As high-deﬁnition cameras become more affordable, the bandwidth necessary to drive data from the edge to the cloud can expand in volume, but network capacity remains constant [35]” [PAGE 4]. Assumption: compression factor and frame parameters are constant. Breakdown regimes: \(C_c\to 0\) is undefined; if \(B_{\rm net}\) is below \(R_{\rm comp}\), cloud-only video transport cannot meet a fixed deadline; if camera count or resolution grows while \(B_{\rm net}\) is constant, the inequality worsens. This is the formal reason the source recommends edge/fog processing.

**Operator 5: RF coverage and occlusion.** Let \(A\) be the playing-field area and \(\mathcal S_i\) the set of positions covered by receiver \(i\) within its angular field of view and without occlusion:
\[
\mathcal S_i=\left\{x\in A:\theta_i(x)\le \frac{\Theta_i}{2},\ \text{no occluder on path}\right\},
\qquad
C=\frac{\left|\bigcup_i \mathcal S_i\right|}{|A|}.
\]
Units: \(C\) dimensionless; angles in rad or degree; area in m\(^2\). The source supplies: “The system contains eleven stationary radio receivers mounted around the ﬁeld. Each of the receivers has a nearly 90-degree ﬁeld of view. This forms an overlapping zone in the soccer ﬁeld, which provides high immunity to indicating signal blocking and occlusion” [PAGE 2]. <RECURSIVE_THEORY_OF_MIND>
The recursive model is not a claim about any named coach or analyst; it is an operational model of how a human decision-maker under time pressure reasons about the system. Let the agent choose an action \(a\) from a set containing manual annotation, automated/fog-assisted annotation, and hybrid annotation. A compact expected-utility rule is
\[
U(a)=\sum_s P(s\mid z,a)U(s,a)-\lambda\,E[T_a]-\kappa\,R(a),
\]
where \(s\) is the latent game state, \(z\) is the observed data stream, \(T_a\) is action latency in s, \(R(a)\) is a dimensionless risk penalty, \(\lambda\) is utility per s, and \(\kappa\) converts risk into utility. Under crisis, the agent’s effective \(\lambda\) rises: fast action becomes more attractive. That is where “crisis habit regression” appears. The source says the coach annotation system “replaces the conventional pen-and-paper annotations” [PAGE 3], but under a network failure, clock failure, or dashboard dispute, the human may regress to paper, verbal recall, or post-hoc clip review. The regression is not irrational; it is a fallback that minimizes immediate latency while increasing recall and sync error. The counter-trap is automation bias: because “fog computing can be used to move decision-making closer to the edge in order to reduce latency and analyze data in real-time” [PAGE 4], the agent may overestimate \(P(s\mid z,a)\) and underestimate the risk term \(R(a)\). The source itself blocks that overconfidence by listing fog security and privacy failures [PAGE 4]. The clock is the third pole. The annotation path relies on NTP synchronization, yet only at “second-granularity” [PAGE 3]. At 20 Hz [PAGE 2], a one-second sync tolerance spans about 20 samples, so the observation \(z\) can be misaligned with the event \(s\). The recursive theory-of-mind prediction is therefore conditional: in low-latency, low-threat conditions, hybrid human-plus-fog annotation is preferred; in link-loss or security-crisis conditions, manual fallback dominates until time sync and video alignment are re-established; and in sub-second event disputes, neither pure manual nor pure automated annotation should be trusted without explicit sync evidence. The source’s own emphasis on expert annotation, video synchronization, and fog limitations supports this tri-part model.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
A formal acceptance predicate for any cross-layer claim \(c\) can be written as
\[
\mathcal A_{\rm accept}(c)=\prod_{\ell\in\{\rm RF,\ video,\ biomech,\ weather,\ sync,\ security\}}\mathbf 1_{\ell\ \text{satisfied}},
\]
where each indicator is dimensionless and equals 1 only when the layer is measured or explicitly supported by the source. If any indicator is 0, the claim is vetoed. The RF/physical layer is partially supported but not absolute. The source gives “eleven stationary radio receivers”, “nearly 90-degree ﬁeld of view”, and an “overlapping zone” that “provides high immunity to indicating signal blocking and occlusion” [PAGE 2]. That supports a geometry-based veto test: if the union of receiver coverage does not equal the playing area, or if occlusion defeats the overlap, continuous tracking is not proven. The 2.45 GHz ISM band [PAGE 2] also means interference and physical blockage must be treated as real failure modes; the paper does not quantify them. The video layer is supported as a subsystem but not as an unlimited pipeline: “bandwidth necessary to drive data from the edge to the cloud can expand in volume, but network capacity remains constant [35]” [PAGE 4]. Therefore a claim that cloud-only high-definition video analytics is always feasible is vetoed by the source’s own bandwidth argument. The biomechanical layer is the most important gray zone. The source supports motion analysis variables such as “distance covered, speed and acceleration” [PAGE 2] and the use of activity profiles to compare players with similar attributes [PAGE 2]. But it does not establish that ZXY-derived workload predicts injury. It explicitly says research on mental fatigue and post-match retrieval is “crucial” [PAGE 4] and that fatigue and injury monitoring “warrants” more research [PAGE 4]. Thus any claim of injury prevention or causal fatigue diagnosis from the described system is vetoed as an overclaim. The weather layer is absent from [PAGE 1]–[PAGE 4]: no rain, snow, temperature, wind, or surface-condition variable is reported. Therefore any weather-conditioned performance claim is vetoed for lack of source support unless external weather and calibration evidence are added. The synchronization layer is also bounded: NTP sync is “second-granularity” [PAGE 3], so fine-grained event claims must prove that \(e_{\rm sync}\) is below the event duration. The security layer is explicitly non-zero-risk: fog is “prone to security attacks such as forgery [41], tampering [42], and Jamming [43]” and has privacy concerns over user, data, identity, usage, location, and network privacy [PAGE 4]. The cross-layer veto proof is therefore a conjunction: the source supports an integrated architecture, but it does not support unconditional claims across RF occlusion, video bandwidth, biomechanical causality, weather, sub-second sync, or fog security.
</CROSS_LAYER_VETO_ADJUDICATION>
