<RETROCAUSAL_GENEALOGY>
The foundational "Foundations of Probability" text of Andrey Kolmogorov appeared in 1933, but the rigorous measure-theoretic integration framework underpinning statistical mechanics — initially developed for ergodic theory by John von Neumann and George David Birkhoff between 1931-1937 — laid down the groundwork for Lebesgue integration techniques. This led directly to Paul Halmos' "Measure Theory," published in 1950, where Theorems D, E, and F establish the essential properties of measurable functions and sets of measure zero for non-negative and integrable functions. The key insight was to decompose a function into its positive and negative parts, enabling the construction of a complete vector lattice of integrable functions. The Radon-Nikodym theorem (1936) further generalized the concept of density, which is crucial for understanding singular measures and their interaction with Lebesgue measure. By the 1950s, this measure theory had become the standard mathematical language for defining expectation and variance in probability spaces, forming the bedrock upon which modern machine learning and deep learning metrics would later be built.

Theorems D, E, and F are stated explicitly.  
\textbf{Theorem D}: Let \(f\) be a non-negative measurable function on a measure space \((X,\mathcal{M},\mu)\). If the integral \(\int_X f\,d\mu\) is finite, then for every \(\varepsilon > 0\) the set \(\{x : f(x) \geq \varepsilon\}\) has finite measure.  
\[
\text{If } \int_X f\,d\mu < \infty,\ \text{then } \mu(\{x : f(x) \geq \varepsilon\}) < \infty\ \text{for every } \varepsilon > 0.
\]
\textbf{Theorem E}: If \(f\) is an integrable function and \(\int_F f\,d\mu = 0\) for every measurable set \(F\), then \(f = 0\) almost everywhere (a.e.) with respect to \(\mu\).
\textbf{Theorem F}: If \(f\) is an integrable function, then the set \(N(f) = \{x : f(x) \neq 0\}\) has \(\sigma\)-finite measure, i.e., \(N(f) = \bigcup_{n=1}^\infty A_n\) with \(\mu(A_n) < \infty\).
\end{pagex}

[LEVEL 1: EXPANDED STATEMENT]
The three theorems form the backbone of Lebesgue integration theory, establishing conditions under which a function must vanish almost everywhere and characterizing the domain of definition of integrable functions. Theorem D demonstrates that finiteness of the Lebesgue integral controls the size of level sets; Theorem E provides a pointwise identification principle for integrals, proving that vanishing integrals over all measurable sets force the function to be zero a.e.; Theorem F shows that the exceptional set where an integrable function differs from zero is "small" in a specific sense, enabling approximation by simple functions.
[HOP 1: PROOF ANALYSIS OF THEOREM D]
The proof begins by writing \(F_0 = \{x : f(x) \geq 0\}\) and \(F_n = \{x : f(x) \geq \varepsilon/n\}\) for \(n=1,2,\dots\). Since \(f\) is non-negative, the assumption of integrability gives \(\int_{F_0} f\,d\mu < \infty\), and hence \(F_0\) itself has finite measure. Using the identity
\[
F_0 = \bigcup_{n=1}^\infty F_n,
\]
the countable additivity of \(\mu\) yields
\[
\mu(F_0) \leq \sum_{n=1}^\infty \mu(F_n).
\]
Moreover, for each fixed \(n\) we have
\[
\varepsilon \cdot \mu(F_n) \leq \int_{F_n} f\,d\mu \leq \int_X f\,d\mu < \infty.
\]
Thus \(\mu(F_n) \leq \frac{1}{\varepsilon}\int_X f\,d\mu < \infty\) for all \(n\), implying that each \(F_n\) has finite measure. Consequently, \(F_0\) is a countable union of finite-measure sets, so it too has \(\sigma\)-finite measure.
GRAY ZONES: The step using \(\varepsilon \cdot \mu(F_n) \leq \int_{F_n} f\,d\mu\) assumes that \(\varepsilon > 0\); at \(\varepsilon = 0\) the statement becomes trivial, but the theorem's content lies precisely for \(\varepsilon > 0\). Also, the argument implicitly uses the fact that \(\int_X f\,d\mu < \infty\) implies \(\int_E f\,d\mu < \infty\) for any measurable subset \(E\); this follows from the monotonicity of the integral, which holds for non-negative integrands.
[HOP 2: PROOF OF THEOREM E]
Assume \(f\) is integrable and \(\int_F f\,d\mu = 0\) for every measurable set \(F\). Define \(N = \{x : f(x) \neq 0\}\). Decompose \(N\) into the union of two sets:
\[
N_+ = \{x : f(x) > 0\},\quad N_- = \{x : f(x) < 0\}.
\]
Apply Theorem D to both \(f_+ = \max(f,0)\) and \((-f)_+ = \max(-f,0)\). Since \(f_+\) and \((-f)_+\) are both non-negative and integrable, Theorem D implies that for any \(\varepsilon > 0\) the sets
\[
A_\varepsilon = \{x : f_+(x) \geq \varepsilon\},\quad B_\varepsilon = \{x : (-f)_+(x) \geq \varepsilon\}
\]
have finite measure. Now observe that
\[
N_+ \subseteq \bigcup_{k=1}^\infty A_{1/k},\qquad N_- \subseteq \bigcup_{k=1}^\infty B_{1/k},
\]
so both \(N_+\) and \(N_-\) are \(\sigma\)-finite. It remains to show that they have measure zero. Suppose, for contradiction, that \(\mu(N_+) > 0\). Then there exists some \(k\) such that \(\mu(A_{1/k}) > 0\). But for the measurable set \(A = A_{1/k}\) we have
\[
\int_A f_+\,d\mu \geq \frac{1}{k} \mu(A_{1/k}) > 0,
\]
contradicting the hypothesis \(\int_F f\,d\mu = 0\) for all measurable \(F\) (take \(F = A\)). Hence \(\mu(N_+) = 0\). Similarly, \(\mu(N_-) = 0\). Therefore, \(\mu(N) = \mu(N_+ \cup N_-) = 0\), meaning \(f = 0\) a.e.
CRITICAL OBSERVATION: The proof relies heavily on the Hahn decomposition and the Jordan decomposition of the signed measure associated with \(f\). Without these tools, one cannot separate the positive and negative variations of an arbitrary integrable function. Moreover, the use of exhaustion arguments via unions of level sets presupposes the axiom of dependent choice, which is strictly weaker than the full axiom of choice.
[HOP 3: PROOF OF THEOREM F]
Let \(f\) be integrable. By definition, there exists a sequence of simple functions \(\{f_n\}\) that converges in mean to \(f\); i.e.,
\[
\lim_{n \to \infty} \int_X |f - f_n|\,d\mu = 0.
\]
Each simple function \(f_n\) takes only finitely many values and is supported on a set of finite measure. Write \(N(f_n) = \{x : f_n(x) \neq 0\}\). Since \(f_n\) is simple, \(\mu(N(f_n)) < \infty\) for all \(n\). Now define
\[
E = N(f) \setminus \bigcup_{n=1}^\infty N(f_n),
\]
and let \(F\) be any measurable subset of \(E\). Because \(E\) contains points where \(f(x) \neq 0\) but all approximating simple functions eventually vanish, we have \(f = 0\) a.e. on \(E\). Applying Theorem E to the restriction \(f|_E\) yields \(\mu(E) = 0\). Consequently,
\[
N(f) = \left(\bigcup_{n=1}^\infty N(f_n)\right) \cup E,
\]
which is a countable union of finite-measure sets plus a null set, hence \(\sigma\)-finite.
[HOP 4: INTERRELATION WITH RADON-NIKODYM]
The Radon-Nikodym theorem states that if \(\nu\) is a \(\sigma\)-finite measure absolutely continuous with respect to \(\mu\) (written \(\nu \ll \mu\)), then there exists a measurable function \(g\) such that
\[
\nu(A) = \int_A g\,d\mu\quad\text{for all measurable } A.
\]
This density function \(g\) plays a central role in defining conditional expectations and likelihood ratios in statistics. Theorems D, E, and F together guarantee that when considering a random variable \(X\) with density \(p(x)\) (w.r.t. Lebesgue measure), the event \(\{X \in N(p)\}\) has probability zero, allowing us to work with modified versions of \(X\) that agree almost everywhere without changing expectations. This fact underlies the validity of empirical risk minimization: replacing a true density by an estimated histogram still yields consistent estimators because only the behavior on a set of measure zero affects the integral.
[HOP 5: EXTENSIONS AND GENERALIZATIONS]
**Lebesgue Decomposition Theorem**: Any two \(\sigma\)-finite measures \(\lambda\) and \(\mu\) can be uniquely decomposed as \(\lambda = \lambda_a + \lambda_s\), where \(\lambda_a \ll \mu\) and \(\lambda_s \perp \mu\) (singular). Applying this to \(\lambda(A) = \int_A |f|\,d\mu\) shows that an integrable function can be written as \(|f| = g + h\), where \(g\) is absolutely continuous and \(h\) is singular. **Fubini-Tonelli Theorem**: For product measures, iterated integration can be swapped under integrability conditions. Theorems D–F ensure that almost-everywhere equal functions have the same iterated integrals, justifying the manipulation of joint densities in high-dimensional learning problems.
[HOP 6: CRUCIAL APPLICATIONS IN MACHINE LEARNING]
In stochastic gradient descent (SGD), the loss function \(L(\theta; x)\) is viewed as a function of parameters \(\theta\) (which lie in an Euclidean space) and data \(x\) (drawn from an unknown distribution \(P\)). The empirical risk
\[
\hat{R}_n(\theta) = \frac{1}{n} \sum_{i=1}^n L(\theta; X_i)
\]
converges uniformly to the population risk \(R(\theta) = \mathbb{E}[L(\theta; X)]\) thanks to VC-dimension bounds or PAC-Bayes inequalities. The population risk can be expressed as
\[
R(\theta) = \int_\Theta L(\theta; x)\, dP_X(x),
\]
where \(P_X\) is the marginal distribution of the data. Theorems D–F guarantee that if \(\int |L(\theta; x)|\,dP_X(x) < \infty\) for all \(\theta\), then the set of \(\theta\) for which the integrability fails is a null set, allowing SGD to optimize \(\hat{R}_n\) while controlling the generalization gap. Furthermore, in reinforcement learning, the value function \(V^\pi(s)\) satisfies Bellman's equation
\[
V^\pi(s) = \mathbb{E}_{a,r}[r + \gamma V^\pi(s') \mid s, \pi],
\]
where the expectation is taken over the next state \(s'\) and reward \(r\). Ergodic theorems ensure that time averages converge to expected values under stationarity, and theorems D–F ensure that these expectations are well-defined whenever the rewards are integrable.
