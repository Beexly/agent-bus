\text{If } f \in \mathcal{L}^+, \text{ then } \int_X f \, d\mu = 0 \iff f(x) = 0 \quad \forall x \in X.
\]
*Proof Logic:* Necessity (\(\Leftarrow\)): Trivial. Sufficiency (\(\Rightarrow\)): Suppose \(\int_X f \, d\mu = 0\). Choose a bounded open Baire set \(U\) containing \(\{x: f(x) \neq 0\}\). Let \(E = \{x: f(x) = 0\}\). Then \(\int_U f \, d\mu = 0\). Since \(f \ge 0\), we have \(\int_{U \setminus E} f \, d\mu = 0\). But on \(U \setminus E\), \(f > 0\), so necessarily \(\mu(U \setminus E) = 0\). As \(U \setminus E\) is open Baire, by hypothesis \(\mu(U \setminus E) > 0\) unless \(U \setminus E = \emptyset\). Thus \(U \setminus E = \emptyset \implies U \subseteq E\), meaning \(f(x)=0\) for all \(x \in U\), hence everywhere.

**Formal Statement of Theorem C:**
\[
\text{Let } \mu_o \text{ be a Baire measure, } \varepsilon > 0. \\
\text{For every integrable simple Baire function } f, \exists \text{ an integrable simple function } g = \sum_{i=1}^n \alpha_i \chi_{C_i},
\]
where each \(C_i\) is a compact Baire set, such that
\[
\int_X |f - g| \, d\mu < \varepsilon.
\]
*Proof Sketch:* Write \(f = \sum_{i=1}^n \alpha_i \chi_{E_i}\) with \(E_i\) disjoint Baire sets. Since \(f\) is integrable, \(\mu(E_i) < \infty\) for \(\alpha_i \neq 0\). By the inner regularity of Baire measures (a consequence of local compactness and Riesz representation-type arguments), for each \(E_i\) and \(\delta_i > 0\), there exists a compact Baire set \(C_i \subseteq E_i\) such that \(\mu(E_i \setminus C_i) < \delta_i\). Choose \(\delta_i\) sufficiently small so that \(\sum |\alpha_i| \mu(E_i \setminus C_i) < \varepsilon\). Define \(g = \sum \alpha_i \chi_{C_i}\). Then
\[
\int_X |f - g| \, d\mu = \sum_{i=1}^n |\alpha_i| \mu(E_i \Delta C_i) = \sum_{i=1}^n |\alpha_i| \mu(E_i \setminus C_i) < \varepsilon.
\]
