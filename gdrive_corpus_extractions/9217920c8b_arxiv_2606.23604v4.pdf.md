The source should be read as an attempt to import the recursive estimation logic of the Kalman filter into the appearance domain of multi-object tracking. The core multi-hop derivation is: detection crops are embedded by MobileNetV3-small into a high-dimensional feature matrix \(X_t\); this matrix is projected into a lower-dimensional appearance-state space; the state is recursively updated by a transition operator, a frequency-domain relational term, and a learned gate; the updated state is used to predict the next appearance embedding; the predicted embedding is then fused with trajectory costs for data association. This is stated on [PAGE 1] when the manuscript says that Polycepta “reformulates appearance modeling as a recursive estimation problem” and on [PAGE 3] when it says that features are “projected from the high-dimensional feature space df = 576 into a state space of dimension ds = 24.” The hypothesis that the recursive state becomes more informative over time is explicit on [PAGE 8]: “appearance estimation quality should improve as appearance states accumulate information over time.”

A formal gray-zone audit requires separating three claims. First, the claim that appearance-state recursion can reduce identity switches is supported by benchmark tables on [PAGE 10] and [PAGE 11], but the support is conditional on detector quality, threshold selection, and modality availability. Second, the claim that appearance estimation improves during inference is supported by the long-horizon experiment on [PAGE 8] and [PAGE 9], but only under the assumption that observations remain informative. If an object is fully occluded, or if weather collapses visual contrast, recursion can preserve memory but cannot create new identity information. Third, the claim that state-erasure learning improves generalization is supported by [PAGE 12], but the evidence is limited to pedestrian/vehicle cross-category transfer; it does not prove category-agnostic identity semantics for arbitrary classes.

The key gray zone is that the method replaces a static embedding with a learned latent dynamical system, but the latent state has no explicit probabilistic calibration. The paper’s margin \(M=D_1-D_2\) on [PAGE 9] is a ranking discriminant, not a posterior probability. If we convert similarity scores to probabilities through a softmax, \(p_{ij}=\exp(M_{ij}/\tau)/\sum_k \exp(M_{ik}/\tau)\), then the associated uncertainty is entropy in nats or bits. The manuscript does not report calibrated entropy, so the improvement claim should be treated as an association-quality improvement, not as a calibrated identity-belief improvement. Another gray zone is the learned discretization \(\bar A_t=I+\Delta_t A_t\), \(\bar B_t=\Delta_t B_t\) on [PAGE 4]. This is an explicit first-order approximation. If \(\Delta_t\) is learned without timestamp grounding, the state may behave as if time is normalized by frame index rather than physical seconds, which changes stability and memory decay. If \(\rho(\bar A_t)\geq 1\), the recursion can drift; if \(\rho(\bar A_t)\) is too small, memory decays too quickly and the system reduces to short-term smoothing.

A third gray zone is the orthogonality loss on [PAGE 7]. It prevents state collapse, as shown by the collapse without \(\mathcal L_{\mathrm{orth}}\) on [PAGE 12], but it does not guarantee that separated states correspond to true identities. It can push different objects apart even when the underlying visual evidence is weak. The full configuration on [PAGE 9] shows the best combined behavior: Polycepta with VRR and U-Gate obtains P50 start/end values of 0.958/0.975 and the lowest reported IDSw value of 184 among the ablated rows. However, the VRR module alone slightly degrades early appearance quality because history is sparse, while the U-Gate alone improves later quality but compresses the margin. This is a genuine interaction effect: history helps only when there is enough history, and gating helps only when the state can still be protected from noisy observations.

The throughput audit also needs care. The manuscript states “Polycepta operates at 90.57 Hz” on [PAGE 1]. The component rates reported on [PAGE 13] imply an aggregate frame cadence if stages are sequential: \(1/f_{\mathrm{sys}} \approx 1/124.78 + 1/377.16 + 1/2713.25\), which gives approximately 90.5 Hz. The final adjudication is that the paper’s strongest valid claim is recursive appearance smoothing and association assistance under sufficient visual information, not universal improvement under arbitrary sensing degradation.

The source defines the feature matrix \(X_t\in\mathbb R^{n_t\times d_f}\) with \(d_f=576\), and the appearance-state matrix \(H_t\in\mathbb R^{n_t\times d_s}\) with \(d_s=24\) [PAGE 3]. The latent relational dimension is \(d_\ell=6\) [PAGE 4]. Unless otherwise stated, embeddings are treated as dimensionless vectors after LayerNorm. If timestamps exist, \(\Delta_t=t_t-t_{t-1}\) has units of seconds; if only frame indices exist, \(\Delta_t\) is in frame units. Continuous-time operators would have units \(\mathrm{s}^{-1}\), while discrete-time operators are dimensionless.

Projection and discretization are given on [PAGE 3]:
\[
z_t=\mathrm{LayerNorm}(X_t),
\]
\[
\Delta_t=\mathrm{softplus}(W_\delta z_t+b_\delta),
\]
\[
B_t=\mathrm{LayerNorm}(W_B z_t+b_B),
\]
\[
C_t=W_C z_t+b_C.
\]
Here \(\Delta_t\) controls memory horizon, \(B_t\) injects the current observation, and \(C_t\) selects state components for output estimation. The state transition is built from a fixed HiPPO matrix and a learnable diagonal term [PAGE 4]:
\[
A_{\mathrm{diag}}=\exp(\theta),
\]
\[
A_t=A_{\mathrm{hippo}}-\mathrm{diag}(A_{\mathrm{diag}}).
\]
The manuscript then uses explicit discretization:
\[
\bar A_t=I+\Delta_t A_t,
\]
\[
\bar B_t=\Delta_t B_t.
\]
This is a first-order Euler-like discretization. A breakdown regime occurs when the spectral radius satisfies \(\rho(\bar A_t)\geq 1\), causing recursive state growth. For a stable continuous eigenvalue \(\lambda\) with \(\mathrm{Re}(\lambda)<0\), a necessary discrete stability condition is approximately \(|1+\Delta_t\lambda|<1\). If \(\Delta_t\) is too large, the recursion can oscillate or explode; if too small, memory accumulation becomes negligible.

The Visual Relational Reasoning module correlates recent observations with prior states in the Fourier domain [PAGE 4]:
\[
F(\bar B_t)=\mathrm{FFT}(\bar B_t),
\]
\[
F(H_{t-1})=\mathrm{FFT}(H_{t-1}),
\]
\[
F(I_t)=F(H_{t-1})\odot F(\bar B_t)\odot \Phi_t,
\]
\[
I_t=\mathrm{LayerNorm}\left(\mathrm{FFT}^{-1}(F(I_t))\right).
\]
The complex filter has dimensions \(\theta_{\mathrm{re}},\theta_{\mathrm{im}}\in\mathbb R^{\lfloor d_s/2\rfloor+1}\) [PAGE 4]. The claimed computational advantage is reduction from \(O(d_s^2)\) to \(O(d_s\log d_s)\) per object [PAGE 4]. The breakdown regime includes zero history \(H_{t-1}=0\), zero observation \(\bar B_t=0\), or a degenerate filter \(\Phi_t=0\), in which case \(I_t\) carries no relational information. Circular correlation also assumes periodic boundary behavior; if the latent appearance manifold is non-periodic, wrap-around artifacts can create spurious correlations.

The cross-appearance fusion gate is given on [PAGE 4] and [PAGE 5]:
\[
G_{\mathrm{fused}}=\mathrm{FFT}^{-1}\left(F(\bar B_t)+F(I_t)+F(H_{t-1})\right),
\]
\[
G=\sigma\left(\mathrm{LayerNorm}(W_g G_{\mathrm{fused}})\right).
\]
The compressed relational features are

S_{\mathrm{latent}}=\tanh\left(\mathrm{LayerNorm}(W_{\mathrm{in}}I_t+b_{\mathrm{in}})\right),
\]
\[
S_t=G\odot(W_{\mathrm{out}}S_{\mathrm{latent}}+b_{\mathrm{out}}).
\]
The gate \(G\in[0,1]^{n_t\times d_s}\) is dimensionless. If \(G\approx 0\), synthetic features are suppressed; if \(G\approx 1\), the model trusts relational reconstruction. Failure occurs if \(I_t\) is noisy but \(G\) is high, causing state updates to inherit Fourier artifacts.

The object-centric state update is given on [PAGE 5]:
\[
\tilde H_t=\bar A_t H_{t-1},
\]
\[
\psi_t=\tanh\left(\mathrm{LayerNorm}(W_K(\bar B_t+S_t))\right),
\]
\[
U_t=\sigma\left(\mathrm{LayerNorm}(W_U[H_{t-1};\psi_t])\right),
\]
\[
H_t=\mathrm{LayerNorm}\left(U_t\odot\psi_t+(1-U_t)\odot\tilde H_t\right).
\]
The gate \(U_t\in[0,1]^{n_t\times d_s}\) balances new evidence against prior state. The manuscript states that this mechanism “improves robustness to observation noise while preserving appearance information accumulated over time” [PAGE 5]. A breakdown regime is \(U_t\to 0\) for all entries, which freezes the state, or \(U_t\to 1\), which discards history. Another breakdown occurs if LayerNorm normalization causes high-magnitude relational features to dominate, even when their visual support is weak.

\]

\hat X_{t+1}=(D_t\odot X_t)+(W_{\mathrm{proj}}Y_t).
\]
Here \(D_t\) is a learned residual mask. If \(D_t\approx 1\) and \(W_{\mathrm{proj}}Y_t\approx 0\), the estimator reduces to a pass-through of current features. If \(C_t\) selects poor state coordinates, the estimated appearance inherits that error. The output \(\hat X_{t+1}\) is used as the appearance cue for the next association step [PAGE 5].

\log\left(

\right).

The matrix \(M\) is dimensionless; \(\tau_f\) is a dimensionless temperature. If \(\tau_f\to 0\), logits become sharp and training can become unstable; if \(\tau_f\) is too large, gradients become weak.

<RETROCAUSAL_GENEALOGY>
The scientific lineage is explicitly recursive. Polycepta borrows the temporal state-update logic of the Kalman filter, which the manuscript contrasts with static ReID descriptors on [PAGE 1]: “the enduring success of the KF lies precisely in its ability to recursively refine an object’s kinematic state over time.” The Kalman reference appears in the reference list on [PAGE 13]. The learned state-space component also inherits from HiPPO and Mamba-style selective state spaces, cited as [19] and [21] on [PAGE 4]. The frequency-domain correlation step inherits from FFT convolution/correlation theory, cited as [22] and [23] on [PAGE 4]. The lightweight embedding backbone is MobileNetV3-small [PAGE 3]. Thus the causal chain is: detection embedding, compact latent state, transition dynamics, relational Fourier correlation, gated update, and future-appearance prediction.

A retro-causal reading asks which earlier failures force the later design. The first failure is static appearance matching. The manuscript says conventional ReID descriptors are “frame-independent” and “brittle under partial occlusions, perspective changes, or environmental noise” [PAGE 1]. This causes the later introduction of recursive appearance state. The second failure is memorization of training identities. The source states that “all appearance states are reset at the end of each training epoch” [PAGE 2], forcing reconstruction from observations rather than persistence of object-specific memory. The third failure is state collapse. The orthogonality loss is introduced because otherwise distinct objects can collapse to identical state representations [PAGE 12]. The fourth failure is modality mismatch. The gated fusion on [PAGE 7] exists because LiDAR trajectory availability and camera appearance availability may be asymmetric.

Multi-week traps are the methodological hazards that emerge if this genealogy is ignored. Trap one is category memorization: a model may perform well on seen pedestrians but fail on unseen classes. The source addresses this with state erasure and reports that unseen-class IDSw improves from 144 to 118 [PAGE 12]. Trap two is state leakage across epochs: if states persist, validation can appear artificially strong because the model has effectively seen object histories. The erasure rule \(H_0=0_{n\times d_s}\) on [PAGE 6] prevents that leakage. Trap three is detector confounding: Polycepta’s benefit can be mixed with the benefit of adding a 2D detector. On [PAGE 10], the authors note that an IDSw increase on KITTI can arise because “the fusion of an additional detector (YOLOv8)” creates detections absent from ground truth. Trap four is threshold overfitting: the clamps \(\beta_p\) and \(\beta_k\) can improve one benchmark while harming another if tuned to local cost statistics. Trap five is modality overconfidence: appearance may be strong in camera-visible regions but weak in LiDAR-only regions, so availability gating is essential. Trap six is metric mismatch: margin and cosine similarity improve, but the downstream metric may be dominated by detector false negatives or false positives. The paper reports false negatives and identity switches on [PAGE 10], which helps, but does not eliminate this trap. Trap seven is evaluation-domain drift: KITTI cars, MOT17 pedestrians, and WOD vehicles have different appearance statistics, so cross-category generalization must be tested rather than assumed. The cross-category table on [PAGE 11] provides evidence, but only for two coarse classes.

<RECURSIVE_THEORY_OF_MIND>
Polycepta can be modeled as an agent that maintains a latent belief about each object’s visual identity. The belief is not an explicit probability distribution in the source, but it behaves like one: the state \(H_t\) accumulates evidence, the gate \(U_t\) decides how much new evidence to admit, and the estimate \(\hat X_{t+1}\) predicts the next observation. In a recursive theory-of-mind frame, the tracker is not merely matching current pixels; it is inferring what the object will look like next under the assumption that appearance evolves smoothly. This is the conceptual bridge between motion filtering and appearance filtering. The manuscript states that Polycepta “extends the state-estimation principle that has long underpinned motion modeling in MOT to the appearance domain” [PAGE 2].

The crisis-habit regression mode occurs when observation quality deteriorates. Under heavy occlusion, false detections, or low contrast, a conventional tracker often regresses to motion-only association because appearance becomes unreliable. The source describes this practical abandonment of appearance cues in real-time systems on [PAGE 1]: “real-time online trackers often omit appearance cues entirely, relying solely on trajectory data association.” That is a habit regression: under crisis, the system falls back to the older motion-only habit because appearance has historically been brittle. Polycepta’s counter-trap is to make appearance robust through recursion and gating. The U-Gate can emphasize accumulated state when the current observation is noisy, as stated on [PAGE 5]: “the gate places greater emphasis on the accumulated appearance state.” This prevents immediate abandonment of appearance when a single frame is bad.

The counter-trap also includes state erasure during training. If the model learned to rely on persistent training memories, it would regress during deployment when object histories are short. The source says state erasure “forces the model to repeatedly reconstruct appearance states from observations rather than relying on persistent training-time memories” [PAGE 2]. This is a countermeasure against the habit of memorizing identities. The orthogonality loss is another countermeasure: it prevents different objects from collapsing into the same latent state, which would make the tracker indifferent between identities. The reported collapse without \(\mathcal L_{\mathrm{orth}}\) is a direct demonstration of the crisis mode: without regularization, states become identical and the model relies mostly on the feature extractor [PAGE 12].

The clock dimension is decisive. A recursive estimator is only useful if its update rate exceeds the rate at which appearance changes or the rate at which association decisions must be made. The manuscript reports “Polycepta operates at 90.57 Hz” [PAGE 1]. If the sensing stream is 30 Hz, the estimator has ample time per frame. If the system must operate at 10 Hz because of heavy detection load, the recursion may still be fast enough, but the observation cadence itself becomes the limiting clock. The hidden trap is not computational speed alone; it is clock alignment. If \(\Delta_t\) is learned but not aligned to physical frame intervals, the model may treat skipped frames as consecutive frames, causing overconfident memory decay or excessive persistence. In theory-of-mind terms, the tracker may believe it has continuous evidence when it has only sparse evidence. The correct counter-trap is to treat \(\Delta_t\) as a temporal uncertainty parameter: larger gaps should increase uncertainty and reduce trust in accumulated appearance unless the gate or a probabilistic variance term compensates. The source does not provide an explicit uncertainty estimate, so this remains a gray zone.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
A cross-layer veto means that a higher-level claim is rejected if a lower physical or biomechanical layer invalidates the assumptions required by that claim. For Polycepta, the highest-level claim is that recursive appearance estimation improves association. This claim requires four lower-layer conditions: photons must carry object appearance information, the object’s image evidence must be sufficiently stable across frames, inter-frame motion must be within association gates, and environmental conditions must not destroy feature discriminability. If any lower layer fails, the higher-level claim is vetoed.

The first veto is the information-veto theorem. Let \(O_t\) be the visual observation of object \(i\), and let \(Z_i\) be its identity label. The appearance recursion can improve expected discrimination only if \(I(O_t;Z_i)>0\) bits per frame over the relevant horizon. If full occlusion, total blur, or sensor failure makes \(I(O_t;Z_i)=0\), then the posterior over appearance identity does not change:
\[
p(Z_i\mid O_{1:t})=p(Z_i\mid O_{1:t-1}).
\]
Therefore the expected similarity to the true next appearance cannot increase due to new visual evidence. The U-Gate can preserve old state, but preservation is not improvement. The source acknowledges that the gate helps when the current observation is “noisy, partially occluded, or unreliable” [PAGE 5], but this statement applies to partial degradation, not to zero-information conditions. Thus, if an object is fully occluded for the entire evaluation window, Polycepta cannot be expected to improve appearance similarity.

The second veto is biomechanical. Let object center position be \(p_t\in\mathbb R^3\), velocity \(v_t\), and acceleration \(a_t\). Over frame interval \(\Delta t\), displacement is approximately
\[
d=\|p_t-p_{t-1}\|\approx \|v_t\Delta t+\tfrac12 a_t\Delta t^2\|.
\]
If the trajectory association radius is \(r_{\mathrm{assoc}}\), and \(d>r_{\mathrm{assoc}}\), then motion association fails before appearance can help. For pedestrians, typical walking speeds may be around \(1\) to \(3\ \mathrm{m\,s^{-1}}\); at 30 frames per second, displacement is roughly \(0.033\) to \(0.1\ \mathrm m\) per frame. For fast motion or low frame rate, displacement can exceed small association gates. If detection boxes are noisy, the apparent center jump can be larger than true motion. In that regime, Polycepta’s appearance cue cannot veto a bad motion association unless the fusion weights allow appearance to dominate. The source’s gated fusion on [PAGE 7] can help, but it cannot overcome a complete motion gate failure if trajectory availability is the only valid modality.

The third veto is weather and contrast. Define image contrast as
\[
C=\frac{\mu_{\mathrm{fg}}-\mu_{\mathrm{bg}}}{\sigma_{\mathrm{bg}}},
\]
where \(\mu_{\mathrm{fg}}\) and \(\mu_{\mathrm{bg}}\) are foreground and background intensity means, and \(\sigma_{\mathrm{bg}}\) is background standard deviation. In fog, rain, night, or sensor saturation, \(C\) can fall below a usable threshold \(C_{\min}\). If feature embeddings become dominated by noise, the appearance-state recursion may actually propagate corrupted evidence. The source claims robustness to “environmental noise” in motivation [PAGE 1], but the reported benchmarks do not isolate severe weather. Therefore, under low-contrast conditions, the claim that appearance estimation improves over time should be vetoed unless the observation quality remains above the feature extractor’s operating regime.

The fourth veto is state-space stability. If \(\bar A_t\) is unstable or \(\Delta_t\) is mis-specified, the recursive state can drift away from the true appearance manifold. The explicit discretization on [PAGE 4] has no built-in covariance inflation. If the state becomes overconfident while observations are poor, the gate may retain a bad memory. This is a algorithmic-layer veto triggered by a physical-layer trigger: bad observations plus unstable memory. The proper adjudication is that Polycepta is valid as a recursive appearance prior under partial occlusion, moderate noise, and sufficient temporal cadence, but it is not a universal identity-recovery mechanism when the sensor layer provides no information.
</CROSS_LAYER_VETO_ADJUDICATION>

Veto 1: State-collapse veto without orthogonality regularization.  
Test protocol: Train two variants, one with \(\mathcal L_{\mathrm{orth}}\) and one without it, then measure the mean cosine similarity between appearance states of distinct objects over a fixed horizon. The source already reports this experiment: without orthogonality, the appearance-state similarity is constant at 1.0000, while with orthogonality it spans \([-0.9962,0.9720]\) [PAGE 12].  
Formal metric:
\[
S_{\mathrm{state}}=\frac{1}{N(N-1)}\sum_{i\neq j}\frac{h_i^\top h_j}{\|h_i\|\|h_j\|}.
\]
Prediction: If \(S_{\mathrm{state}}>0.99\) for distinct objects, the state representation has collapsed. In that regime, the discrimination margin \(M=D_1-D_2\) should fall below the non-collapsed regime, and IDSw should increase. The source supports this by stating that orthogonality “prevents appearance-state collapse” [PAGE 12]. Veto condition: If removing \(\mathcal L_{\mathrm{orth}}\) leaves margin and IDSw unchanged, then the orthogonality claim is not supported. Conversely, if collapse occurs and downstream metrics worsen, the veto is confirmed.

Veto 2: Clock-latency veto for recursive benefit.  
Test protocol: Measure end-to-end throughput and per-frame latency for feature extraction, Polycepta state update, and association. The source reports 90.57 Hz for the full system [PAGE 1] and component rates on [PAGE 13].  
Formal condition:
\[
f_{\mathrm{system}}\geq f_{\mathrm{sensor}}
\]
is required for the recursive estimate to be fresh at the sensor cadence. If \(f_{\mathrm{system}}<f_{\mathrm{sensor}}\), the tracker must skip updates or delay association. Define staleness \(\tau_{\mathrm{stale}}=1/f_{\mathrm{system}}-1/f_{\mathrm{sensor}}\) when positive.  
Prediction: If the full system is run on a constrained embedded platform and throughput falls below the camera or LiDAR frame rate, the expected benefit of accumulated appearance state should shrink. In that case, the recursive claim is vetoed for that deployment even if the source’s mobile-workstation result is valid. The source’s efficiency claim is conditional on the reported hardware and implementation [PAGE 13]. Veto condition: A deployment-specific measurement showing \(f_{\mathrm{system}}<f_{\mathrm{sensor}}\) and no identity-switch reduction vetoes the real-time recursive advantage.

Veto 3: Low-information visual veto under occlusion or weather.  
Test protocol: Evaluate Polycepta on a held-out set with controlled degradation: synthetic fog, motion blur, night contrast reduction, or occlusion masks. Measure start and end similarity percentiles and margin. The source’s clean-condition full Polycepta result shows P50 improving from 0.958 to 0.975 [PAGE 9].  
Formal metric:
\[
\Delta P_{50}=P_{50,\mathrm{end}}-P_{50,\mathrm{start}},
\]
\[
\Delta M=M_{\mathrm{end}}-M_{\mathrm{start}}.
\]
Prediction: Under severe degradation, if the observation mutual information \(I(O_t;Z_i)\) is near zero, then \(\Delta P_{50}\leq 0\) and \(\Delta M\leq 0\) are expected. The gate may preserve old state, but it cannot create new identity information. Source support: the gate helps when observations are noisy or partially occluded [PAGE 5], but the method is not claimed to solve full visual loss. Veto condition: If Polycepta improves similarity under full occlusion or severe weather without additional sensors, that would contradict the information-veto theorem; if it fails to improve under those conditions, the universal-improvement interpretation is vetoed, while the conditional improvement claim remains valid.

Additional verifiable veto: threshold-fusion veto.  
If \(\beta_p\) is set too high, the normalized appearance cost \(\tilde C_p=C_p'/(1-\beta_p)\) becomes unstable or overly compressed; if availability vectors \(\gamma_i\) are wrong, the gating logic on [PAGE 7] assigns weight to a missing modality. Test by sweeping \(\beta_p,\beta_k\) and checking whether IDSw reduction persists. Prediction: If appearance gains disappear when appearance availability is artificially removed, the benefit is not from Polycepta’s state recursion alone but from the added modality. This is a necessary control experiment for any claim that Polycepta itself reduces identity switches.
