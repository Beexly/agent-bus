The thesis's central logical chain is: continuous video → tracks (mid-level features) → qualitative spatial relations per frame → smoothed relations via HMM → episodes → interaction graphs → generative model over event classes → MAP interpretation via MCMC → functional object classes via an event-class lattice. Each arrow introduces an information bottleneck and a distinct failure surface. Let me trace the load-bearing steps.

First, the reduction from RCC-5 to three relations. On [PAGE 62] the author writes: "the three original relations PP, PPi and EQ (Equals) in RCC-5 are combined into one state P." This collapses five jointly-exhaustive-pairwise-disjoint (jepd) relations to three: ℜ = {P, PO, DR}. The gray zone here is subtle: RCC-5's value is precisely that it is jepd, enabling sound composition-table reasoning. Collapsing PP/PPi/EQ into one undirected "P" is only valid because the thesis also builds a duality convention into the graph edges (the upward/downward arrows on [PAGE 60], [PAGE 69]). So the relation set is not truly jepd in the scalar label; disjointness is recovered only by edge direction. Any consumer of ℜ that ignores edge orientation loses information. This is a representational invariant that is easy to violate downstream.

Second, the temporal calculus. The thesis adopts Allen's seven relations minus inverses ([PAGE 62]): ℵ = {<, m, o, s, d, f, =}. But Appendix D ([PAGE 151]) contains two apparent transcription errors that matter for any reimplementation: "Before ⇐⇒ End(i1) < Start(i2) −1" and "Meets ⇐⇒ End(i1) < Start(i2) −1" are printed identically, and "Starts" and "Finishes" are also printed identically as "Start(i1) < Start(i2) ∧ End(i1) < End(i2)." These cannot be correct; Before and Meets must be distinguished (typically End(i1) < Start(i2) vs End(i1) = Start(i2)), and Starts vs Finishes differ in which endpoint is shared. A multi-hop consequence: if the Temporal functor in Eq (3.4) is populated from these definitions, the "germane temporal relationship" set A becomes ill-defined, which in turn breaks the isomorphism guarantee for interaction graphs (the whole point of excluding non-germane relations on [PAGE 57]-[PAGE 58]).

Third, the generative model's factorization. On [PAGE 93]-[PAGE 94] the posterior is factorized as Î = arg max P(Θ)P(Λ|Θ,Ω,Υ)P(T|Λ) under the conditional-independence assumption "T is conditionally independent of Θ, Ω, Υ given Λ." This is the key modeling bet: all evidence from tracks flows through the discrete activity graph Λ. The gray zone is that Λ is itself latent and combinatorially enormous, and P(T|Λ) factorizes further into per-track-pair HMM likelihoods (Eq 3.12/3.13), each of which is a product over frames. So the "likelihood" is a product of products, and its logarithm (used in Eq 4.4's exponential form) is a double sum. Any single frame with a degenerate bounding box poisons an entire pair's likelihood, hence an entire event's likelihood.

Fourth, the search. MAP is approximated by Metropolis-Hastings with simulated annealing ([PAGE 98]-[PAGE 99], Algorithm 1). At each iteration the algorithm re-solves for the optimal event model Θ_{t+1} by, per [PAGE 91]-[PAGE 92], "enumerate all possible class labellings for this set of graphs." That inner enumeration is the true complexity trap: it is exponential in the bag size, and it is nested inside an MCMC whose outer state space is the space of activity-graph partitions. The convergence claim is standard-MCMC asymptotic and, with κ = .9999 geometric cooling ([PAGE 121]), practically unverifiable in finite time.

Finally, the functional-object stage. The event-class lattice ([PAGE 101]-[PAGE 103]) induces functional roles R as instantiations of a predicate F. The key hypothesis is explicitly stated on [PAGE 100]: "the mapping between the layer 1 nodes of an event graph and the corresponding object occurrences induces an alignment." This alignment is the load-bearing assumption for the entire object-learning contribution, and it is unproven — it holds only if tracking is correct and if occurrences of a class are genuinely spatiotemporally alignable.

The thesis sits on four independent lineages, each with its own "multi-week trap" — a place where a reimplementer burns weeks rediscovering a known subtlety.

Lineage 1 — Qualitative spatial reasoning. RCC-5 traces to Randell, Cui & Cohn (1992) and Cohn et al. (1997) ([PAGE 142]-[PAGE 153]); Allen's interval algebra to Allen (1983). The trap: RCC-5's power is its composition table over jepd relations. By merging PP/PPi/EQ the thesis leaves the calculus's core benefit (sound path-consistency reasoning) and re-enters it only through graph-edge orientation. Anyone porting this to a reasoning engine that consumes scalar labels alone will silently lose disjunctiveness — a classic multi-week debugging hole.

Lineage 2 — Behaviour modelling from video. Galata et al. (1999, 2002) and Fernyhough, Cohn & Hogg (2000a,b) are the direct qualitative-spatio-temporal predecessors ([PAGE 154]); the author explicitly credits them for the "sparse research" this work extends ([PAGE 140]). Lineage 3 — Graph mining. SUBDUE (Holder et al., 1994), AGM (Inokuchi et al., 2000), FSG (Kuramochi & Karypis, 2001), gSpan (Yan & Han, 2002) ([PAGE 144]-[PAGE 161]). <RECURSIVE_THEORY_OF_MIND>

Interpreted here as the interaction between (a) the model's implicit "beliefs" about what an event is, (b) adversarial/degenerate inputs that regress those beliefs, and (c) the annealing clock that governs escape from bad basins.

The generative model encodes three "beliefs" as priors: events are large (γ₂, size), events are interactive (γ₁, interactivity), and events recur (γ₃, frequency), plus anti-beliefs: minimal overlap (γ₄) and minimal coincidence (γ₅). Experiment 2's trace analysis ([PAGE 115]-[PAGE 117]) is essentially a theory-of-mind readout of the search's own trajectory: "In the first phase ... expected size and interactivity increases steeply, while there is hardly any increase in frequency ... In the second phase ... expected frequency evidences a substantial rise ... In the third phase ... it is increases in expected frequency that cause an increase in the posterior" ([PAGE 115]-[PAGE 117]). The model first hallucinates large interactive structures at ~50% error, then lets recurrence correct them.

Crisis-habit regression. The dangerous regime is a coincidence that is large AND interactive AND recurrent. The priors were designed on the assumption (stated [PAGE 79]) that "coincidences do not tend to have the property implied by the combination of these three event-like properties." The thesis itself documents the regression on real data: "The first class has also erroneously captured coincidental interactions" and "A total of 4 coincidental occurrences ... were erroneously captured by class 1" ([PAGE 123]). So the model's habit — trust the size/interactivity/frequency conjunction — regresses precisely when a domain violates the anti-coincidence assumption (e.g., a recurring, spatially-engaged loading maneuver that is not one of the target IATA events).

Counter-trap. The Change-Spatial-Relationships move (Fig 4.4, [PAGE 91]) and the noise-modelling argument ([PAGE 86]-[PAGE 87]) are the designed counter-trap: they let the sampler propose Λ′ that is more prototypical for a noisy embedding while P(Λ|Θ) still favors the true Λ. This works only if the frequency prior (γ₃) outweighs the likelihood drop from noise — a balance the LP-estimated parameters happen to strike for this domain but that is not guaranteed to transfer.

Clock. The annealing schedule (T = κ^t, κ = .9999, cooling initiated after 3000 iterations; [PAGE 121]) is the clock that arbitrates exploration vs exploitation. With κ this close to 1 the chain stays hot for a very long time; the thesis notes that outside the good parameter range "some times the Markov chain does not converge after several thousand iterations" ([PAGE 117]). So the clock is the fragile third party: too cold ⇒ premature lock onto coincidence-driven event classes; too hot ⇒ non-convergence within compute budget. There is no convergence diagnostic reported — only visual inspection of traces on one of twenty simulations ([PAGE 115] footnote 5).

<CROSS_LAYER_VETO_ADJUDICATION>

Framed as a physical-layer admissibility check: which of the model's constructs survive contact with the pixel/geometry/occlusion layer.

Veto 1 — Geometric (the δ measure). Eq (3.8) requires a well-defined inscribed circle in the region intersection. For DR (disconnected) states this is empty by construction. The thesis papers over this by defining d(c₁) via the enclosing circle for the disconnected case ([PAGE 77]), but the transition point δ = 0 (exact tangency) is a measure-zero set where the two circle definitions must agree; numerically, near-tangent jitter flips the sign of δ, which is exactly the instability the HMM is introduced to fix. Proof of physical admissibility: the HMM's Viterbi smoothing ([PAGE 80]) restores temporal consistency only if the per-frame emission (Eqs 3.9-3.11) is monotone in δ within each state's regime — true for DR and P (monotone sigmoids) but the PO model uses |δ − β₂₃|, which is V-shaped and thus non-monotone across δ = β₂₃, weakening the guarantee exactly in the overlap regime that aircraft-apron scenes populate most.

Veto 2 — Occlusion/merged-blob (the track layer). The pipeline detects five classes (plane, trolley, loader, bridge, plane-puller) and explicitly drops pedestrians because "their size reduces substantially, making detections complex" ([PAGE 110]). Physically, when two objects merge into one detection blob, δ is computed on the union region, corrupting every pairwise relation involving the merged pair. The model has no merged-blob veto at the geometric layer; it relies entirely on the tracker (Yu & Medioni MCMC) to split them upstream. If the tracker fails to split, the corruption propagates deterministically into Λ. This is an unmitigated physical-layer failure mode the thesis acknowledges only indirectly via "observation noise."

Veto 3 — Biomechanical/temporal (the interval layer). Appendix D as printed makes Before and Meets share the predicate "End(i1) < Start(i2) − 1," and makes Starts and Finishes identical ([PAGE 151]). Physically, Meets should encode End(i1) = Start(i2) (zero-gap adjacency), and Starts/Finishes differ by which endpoint coincides. With the printed definitions, the germane-temporal-relationship filter (Eq 3.4, [PAGE 68]) cannot distinguish "meets" from "before," so two physically distinct aircraft-apron interactions (loader arrives exactly as plane stops vs. loader arrives well after) collapse to the same graph node label a. Cross-layer veto proof: because layer-3 nodes are the only carriers of temporal ordering (Fig 3.5, [PAGE 59]), a defect here is not correctable at any other layer — it directly falsifies the isomorphism claim of Section 3.4.

Net adjudication: the representation survives the geometric layer with caveats (PO non-monotonicity), does not itself survive the occlusion layer (delegated to an upstream tracker), and is compromised at the temporal layer by an apparent transcription defect that must be corrected before any faithful reimplementation.

Three falsifiable scenarios in which the method's own reported behavior predicts failure, each with a concrete, checkable prediction. These are analytical predictions from the thesis's stated mechanics, not new experiments.

Veto A — Recurrent coincidental interaction.
Setup: a domain with a maneuver that is simultaneously large, interactive, and frequent but semantically not a target event.
Prediction: the model will absorb it as a false-positive event class. This is not hypothetical — it is exactly what Table 6.2 records: class 1 "erroneously captured 4 coincidental occurrences" and class 2 captured 7 coincidental occurrences ([PAGE 123], [PAGE 135]). Falsifiable prediction: increasing the true recurrence rate of such a coincidence monotonically increases the model's false-positive rate, because the γ₃ frequency term rewards recurrence without a semantic gate.
Falsification test: construct synthetic data (Appendix B generator, [PAGE 147]-[PAGE 148]) with a controlled recurrent coincidence proportion and verify the accuracy curve degrades; the thesis's own Fig 6.5 shows accuracy falling as coincidence proportion rises for both baseline and generalized models ([PAGE 130]).

Veto B — Degenerate/near-tangent detection.
Setup: two objects whose separation hovers at the DR/PO tangency (δ ≈ 0) across many frames.
Prediction: the emission model's V-shaped PO term (Eq 3.10, non-monotone at β₂₃) plus the HMM's limited k-best disambiguation (thesis uses only top-2, [PAGE 70]-[PAGE 71]) will produce a bistable spatial-relation sequence, degrading event recovery for any class whose prototype depends on that pair's DR→PO→P ordering.
Falsification test: the reported HMM result — "the sequence of episodes for 85.7% of the test segments ... exactly corresponded to the ground truth" with "variance of 8.3%" ([PAGE 122]) — should drop measurably if the test set is stratified to near-tangency segments only. If it does not drop, Veto B is falsified.

Veto C — Non-alignable occurrences (functional-role hypothesis failure).
Setup: an event class whose occurrences are spatiotemporally valid but not alignable at layer-1 nodes (e.g., variable object ordering, or a class with prototypes that differ in region-history count).
Prediction: the event-class lattice (Section 5.2, [PAGE 101]-[PAGE 104]) will induce spurious functional roles, because its core hypothesis — "the mapping between the layer 1 nodes ... induces an alignment ... that results in intuitive functional roles" ([PAGE 100]) — fails when occurrences are not node-aligned. The thesis concedes the current functional-similarity notion is "overly restrictive" ([PAGE 143]-[PAGE 144]: objects deemed similar only if "taken away from the same plate").
Falsification test: functional-object accuracy (Table 6.3, [PAGE 127]: trolley 82.7%, loader 73.6%, bridge 78.2%, plane-puller 70.0%, plane 93.75%) should degrade most for the class whose occurrences have the highest region-history-count variance. Plane (most geometrically stable, least variable) scores highest at 93.75%, and plane-puller (small, distant, more variable detection) scores lowest at 70.0% — consistent with, but not proof of, Veto C. A stratified re-evaluation by per-class occurrence-alignability would confirm or falsify it.

Collectively these three vetoes mark the honest boundary of the thesis's claims: robust to observation noise under its stated priors (demonstrated, [PAGE 133]-[PAGE 126]), but structurally exposed to recurrent coincidences, geometric near-degeneracies, and non-alignable class occurrences — each of which the author flags in the Future Work of Chapter 7.
