<THINK_TRACE>

The multi-hop chain worth auditing here is the paper's central mathematical object, the PR-MOTA score, because it is where the formalism is both most interesting and most fragile.

Hop 1 — the atom. The paper defines an MOT system as detection + tracking ([PAGE 1], footnote 1: "MOT system = detection + tracking"). Performance is scored by MOTA, which counts three error types against ground truth. MOTA is a normalized count ratio and is therefore unbounded below: nothing in its definition prevents the false-positive count from exceeding the ground-truth count, which drives it negative. This is the first breakdown regime and the paper's own data confirms it (DPM+CMOT at −3.4%, [PAGE 14]).

Hop 2 — the lift. Because a single MOTA number depends on where you sit on the detector's precision-recall curve, the authors lift MOTA into a functional Ψ(p,r) over the PR curve C and integrate: Ω* = ½∫_C Ψ ds ([PAGE 12]). The one-half is pure normalization; the substance is a line integral of an unbounded-below integrand along a curve in the unit square.

Hop 3 — the bound. The appendix ([PAGE 27]) argues Ω* ≤ 100%. The argument discretizes arc length as Δs_i = √(Δp_i² + Δr_i²), uses Ψ ≤ 100, then bounds √(Δp_i² + Δr_i²) ≤ |Δp_i| + |Δr_i| (L2 ≤ L1), and finally asserts Σ|Δp_i| ≤ 1 and Σ|Δr_i| ≤ 1 "since p and r are in [0,1]."

Hop 4 — the gray-zone audit (the important one). The step Σ|Δr_i| ≤ 1 is fine: recall is monotone non-decreasing as the detection threshold drops (more boxes ⇒ weakly more true positives ⇒ weakly higher recall), so its total variation equals its range ≤ 1. But Σ|Δp_i| ≤ 1 is not justified by "p ∈ [0,1]." Precision is non-monotone in the threshold — every added box is a TP or an FP, so precision oscillates. The quantity Σ|Δp_i| is the *total variation* of precision, which for a non-monotone sequence exceeds its range and grows with the number of oscillations; it is not bounded by 1. The correct object being bounded is the arc length ∫_C ds = TV(p) + TV(r) (after the L1 relaxation), and only TV(r) ≤ 1 is guaranteed. Hence the theoretical claim Ω* ≤ 100% is not established by the argument as written; it holds only for a PR curve that is monotone in both coordinates (an "L-shaped" traversal), which is exactly the degenerate equality case the authors themselves describe on [PAGE 27].

Hop 5 — does it matter? Practically, no. The integral is computed from only 10 threshold samples (footnote 10, [PAGE 11]: "we vary the threshold 10 times with equal interval"), so Σ Δs_i is a small finite polygonal length and the empirical best score is 21.1% ([PAGE 14], EB+KIOU). The bound is never approached, so the gap is a rigor defect, not a numerical one. That distinction — real theoretical hole, zero practical consequence — is the honest verdict, and it is the kind of finding that only surfaces if you actually differentiate monotone (r) from non-monotone (p) coordinates instead of waving at "p ∈ [0,1]."

A secondary audit: the equality conditions on [PAGE 27] ("precision p → 0, recall r = 0, and recall r → 0, precision p = 0") describe a degenerate L-shaped path along the axes with Ψ ≡ 100. This is a non-realized idealization (a "perfect detector everywhere"), consistent with my Hop-4 point: tightness requires single-pass monotone traversal of each coordinate.

</THINK_TRACE>

<SOURCE_OPERATORS_AND_EQUATIONS>

**MOTA (CLEAR MOT), [PAGE 11], Eq. (1).** Verbatim: "MOTA = 100 · (1 − Σ_v Σ_t (FN_{v,t} + FP_{v,t} + IDS_{v,t}) / Σ_v Σ_t GT_{v,t})[%]", with "the hit/miss threshold of the bounding box overlap between an output trajectory and the ground truth set to be 0.7."

$$\mathrm{MOTA} = 100\left(1 - \frac{\sum_v\sum_t \big(FN_{v,t}+FP_{v,t}+IDS_{v,t}\big)}{\sum_v\sum_t GT_{v,t}}\right)[\%]$$

- Units: dimensionless (counts/counts) × 100 ⇒ percent.
- Domain/range: $\mathrm{MOTA}\in(-\infty,\,100]$.
- **Breakdown regime:** as $\sum(FN+FP+IDS)\to\infty$ with $\sum GT$ fixed, $\mathrm{MOTA}\to-\infty$. Realized empirically by DPM+CMOT at $-3.4\%$ PR-MOTA ([PAGE 14]) and by twelve systems scoring $<0\%$ on the hard subset ([PAGE 18], verbatim: "The PR-MOTA scores of twelve MOT systems ... are all less than 0%").

**Detection overlap (IoU), threshold 0.7.** $\mathrm{IoU}=\dfrac{|B_d\cap B_{gt}|}{|B_d\cup B_{gt}|}\in[0,1]$, dimensionless; a detection is a hit iff $\mathrm{IoU}\ge 0.7$ ([PAGE 11]).

**Average Precision (11-point VOC), [PAGE 11].** Verbatim: "calculate the average precisions at the fixed 11 recall values from 0 to 1: {0, 0.1, 0.2, · · · , 0.9, 1.0}."

$$AP = \frac{1}{11}\sum_{k=0}^{10} p_{\text{interp}}\!\left(\tfrac{k}{10}\right),\qquad p_{\text{interp}}(r)=\sup_{r'\ge r} p(r')$$

- Units: dimensionless ⇒ percent. Range $[0,100]$.
- **Breakdown regime:** if recall never reaches a sampled $r_k$ (detector misses too much), $p_{\text{interp}}(r_k)$ is undefined/zero and AP collapses; this is why DPM (25.74% AP) and ACF (46.44%) trail RD2 (85.35%) on [PAGE 13].

**PR-MOTA score, [PAGE 12] and Eq. (2)–(3) [PAGE 27].**

$$\Omega^{*} = \frac{1}{2}\int_{C}\Psi(p,r)\,ds,\qquad \Psi(p,r)=\text{MOTA at }(p,r)$$

with discretization ($\lambda=\max_i \Delta s_i$, [PAGE 27]):

$$\Delta s_i=\sqrt{\Delta p_i^{2}+\Delta r_i^{2}},\qquad \Omega^{*}=\frac12\lim_{\lambda\to0}\sum_{i=1}^{n}\Psi(p_i,r_i)\,\Delta s_i$$

- Units: $\Psi$ in percent, $ds$ dimensionless (p, r ∈ [0,1]) ⇒ Ω* in percent; the ½ normalizes $(-∞,200\%]\to(-∞,100\%]$ (footnote 11, [PAGE 11], verbatim: "we have ∫_C Ψ(p, r)ds ∈ (−∞, 200%]").
- **Sampling:** $n=10$ thresholds, equal interval (footnote 10, [PAGE 11]); the integral "is difficult to compute ... we approximate it with additions over sampled locations" (footnote 11).

**Upper-bound proof and its gap, [PAGE 27].** Claimed chain:

$$\Omega^{*}\le \tfrac12\cdot100\cdot\lim_{\lambda\to0}\sum_i\Delta s_i = 50\lim\sum_i\sqrt{\Delta p_i^2+\Delta r_i^2}\le 50\lim\sum_i\big(|\Delta p_i|+|\Delta r_i|\big)\le 50(1+1)=100.$$

- The inequality $\sqrt{\Delta p_i^2+\Delta r_i^2}\le|\Delta p_i|+|\Delta r_i|$ is correct (ℓ₂ ≤ ℓ₁).
- **Singularity in the argument:** the final step assumes $\sum|\Delta p_i|\le1$. This holds for $\sum|\Delta r_i|$ (recall monotone in threshold ⇒ total variation = range ≤ 1) but **fails** for $\sum|\Delta p_i|$, since precision is non-monotone in the threshold and its total variation is not bounded by its range. The rigorous statement is $\int_C ds = \mathrm{TV}(p)+\mathrm{TV}(r)$ with only $\mathrm{TV}(r)\le1$ guaranteed. Consequently $\Omega^{*}\le100\%$ is proven only for a both-monotone ("L-shaped") curve — the equality case on [PAGE 27] — and is otherwise a loose, non-rigorous bound. Numerically irrelevant here (empirical max $\Omega^{*}=21.1\%$, [PAGE 14]), but a genuine derivation defect.

**Attribute operators (all dimensionless).** Scale $s=\sqrt{\text{area}}$ in pixels; small 0–50, medium 50–150, large >150 ([PAGE 5]). Occlusion ratio = occluded-area / box-area; partial ∈ [1%,50%], heavy >50% ([PAGE 5]). Truncation ratio > 50% ⇒ box discarded ([PAGE 5]). Difficulty via EdgeBox recall at 5,000 proposals: easy 97.0%, medium 85.0%, hard 64.0% ([PAGE 5]).

<RETROCAUSAL_GENEALOGY>

"Retrocaual" (backward-in-time causation) is not a mechanism present in this paper, so I read the section as intended — the forward scientific lineage that produced these operators — and trace it from the source's own review sections.

**Tracking lineage ([PAGE 9]–[PAGE 10]).** The genealogy runs: state-estimation filters — Kalman ([PAGE 9], "Leven and Lanterman, 2009; Pellegrini et al., 2009") and particle filters — which the paper flags as short-horizon only ("predict the target states in short duration effectively but do not perform well in complex scenarios," [PAGE 9]); then JPDAF (Fortmann et al., 1983) and MHT (Reid, 1979) for frame-to-frame linking, with the paper naming JPDAF's scaling failure verbatim ("with an increasing number of targets in the sequence, the computational complexity of the method becomes intractable," [PAGE 10]); then the optimization era — K-shortest paths, max-weight independent sets, network flows (Zhang et al., 2008; Pirsiavash et al., 2011 = GOG), Hungarian/CMOT, generalized linear assignment (Dicle et al., 2013 = IHTLS), and energy minimization (Andriyenko & Schindler, 2011 = CEM; Andriyenko et al., 2012 = DCT) ([PAGE 10]). The evaluated trackers are the leaves of this tree.

**Detection lineage ([PAGE 7]–[PAGE 9]).** Viola–Jones (Haar) → HOG (Dalal & Triggs, 2005) → multi-channel features (Dollár et al., 2014 = ACF) → DPM (Felzenszwalb et al., 2010) → R-CNN (Girshick et al., 2014) → Fast/Faster R-CNN (RoIPool, then RPN; Ren et al., 2017) → one-shot regression (YOLO; Redmon et al., 2016) → complexity-aware cascades (CompACT; Cai et al., 2015) → the challenge winners GP-FRCNN (2017) and RD2 (2018) ([PAGE 8]–[PAGE 9]).

<RECURSIVE_THEORY_OF_MIND>

There is no "clock," "crisis habit," or adversarial mind-model in this paper; I won't invent one. The genuine analog of a *recursive* dependency is the bidirectional coupling between the detection layer and the tracking layer — the paper's core thesis — plus its documented failure to be monotone.

The thesis (verbatim, [PAGE 2]): "the performance ... of MOT systems vary significantly using different settings for object detection." Concretely, CEM beats DCT at PR point (0.433, 0.341) but loses at (0.674, 0.183) ([PAGE 3]) — a ranking reversal, i.e., no single detector setting induces a consistent "theory of mind" over trackers.

The counter-monotonicity evidence is what plays the role of "counter-trap." Average PR-MOTA does rise with detector quality — DPM 0.41%, ACF 7.84%, R-CNN 9.49%, CompACT 11.40%, Faster R-CNN 11.98% ([PAGE 15]) — yet the map is not order-preserving: CompACT+GOG (14.2%) > Faster R-CNN+GOG (13.7%), ACF+CEM (4.5%) > R-CNN+CEM (2.7%), R-CNN+DCT (11.7%) > CompACT+DCT (10.8%) ([PAGE 16]). The paper's own reasoning: CEM "uses a global energy minimization strategy to reduce false positives" and "does not exploit target appearance information," so it is stable but non-responsive to better detectors; GOG uses "a greedy algorithm ... which may generate more false trajectories," inflating PR-IDS/PR-FM ([PAGE 18]–[PAGE 19]). That is the real "each layer models the other" story — a coupling, not a mind.
