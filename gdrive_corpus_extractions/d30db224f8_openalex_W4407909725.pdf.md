The paper states: “a log transformation to the current value is applied to reduce skewness” [PAGE 4]. Let \(y_i\) be the transformed target used in training, \(x_i \in \mathbb{R}^p\) the standardized feature vector, and \(v_i\) the raw current value. A generic log transform is
\[
y_i = \log(v_i), \quad v_i > 0.
\]
This transform has a singularity at \(v_i \le 0\). The source removes zero-valued targets: “some players’ current values are marked as 0, which is impossible in real life, therefore, these data are removed” [PAGE 3]. That removal avoids the log singularity and the MAPE denominator singularity, but it changes the population and can induce selection bias if zero-coded rows are not missing completely at random.

Ridge regression is reported with a fixed penalty: “ridge regression with a parameter (alpha equal to 10)” [PAGE 4]. With standardized features, the ridge operator is
\[
\hat{\beta}_{\lambda}
=
\arg\min_{\beta_0,\beta}
\left[
\sum_{i=1}^{n}
\left(y_i-\beta_0-x_i^{\top}\beta\right)^2
+
\lambda\|\beta\|_2^2
\right],
\quad \lambda=10.
\]
If \(y_i\) is log-monetary, the squared residual is in squared log-monetary units; if \(y_i\) is standardized log-monetary, the residual is dimensionless. The penalty term is in the same squared target units because the features are standardized. The ridge solution can be written as
\[
\hat{\beta}_{\lambda}
=
\left(X^{\top}X+\lambda I\right)^{-1}X^{\top}y
\]
for centered data, where \(\lambda=10>0\) guarantees invertibility even if \(X^{\top}X\) is singular. The breakdown regime is not numerical singularity when \(\lambda>0\); it is bias dominance when \(\lambda\) is too large, and variance dominance when \(\lambda\) is too small. The paper itself notes that the fixed and “relatively high” regularization “will probably lead to the rigidness of the prediction” [PAGE 9].

Random forest is an ensemble of trees:
\[
\hat{f}_{\mathrm{RF}}(x)
=
\frac{1}{B}
\sum_{b=1}^{B}
T_b(x;\Theta_b),
\]
where \(B\) is the number of trees and \(\Theta_b\) indexes the randomized bootstrap and split structure. The output units are the target units used in training, either log-monetary or standardized log-monetary. The breakdown regimes are extrapolation failure outside the training feature support, leaf averaging that compresses extreme targets, and impurity-based importance bias toward high-cardinality or continuous features. The source reports random forest performance as RMSE 0.463, R2 0.924, and MAPE 2.222 percent [PAGE 4].

Gradient boosting is sequential:
\[
F_m(x)=F_{m-1}(x)+\nu h_m(x),
\]
where \(h_m\) is fit to pseudo-residuals such as
\[
r_{im}
=
-\left[
\frac{\partial L(y_i,F)}{\partial F}
\right]_{F=F_{m-1}(x_i)}
\]
for a differentiable loss \(L\), and \(\nu\) is the learning-rate shrinkage. With squared loss and log-monetary target, the pseudo-residual is in log-monetary units and the additive correction is also in log-monetary units. The source reports gradient boosting as RMSE 0.450, R2 0.928, and MAPE 2.294 percent [PAGE 4]. Its breakdown regimes are overfitting under too many boosting rounds, sensitivity to noisy residuals, target leakage through dominant features, and poor tail calibration when high-value cases are sparse.

The 3-fold cross-validation operator is
\[
\widehat{\mathrm{Err}}_{\mathrm{CV}}
=
\frac{1}{K}
\sum_{k=1}^{K}
\frac{1}{|D_k|}
\sum_{i\in D_k}
L\left(y_i,\hat{f}^{(-k)}(x_i)\right),
\quad K=3.
\]
The source states “3-fold Cross-validation” [PAGE 4]. The breakdown regime is fold dependence and leakage: if \(D_k\) is not grouped by player, team, or season, the CV error measures within-pool interpolation rather than future-season generalization. The dataset covers “2 seasons 2021-2022 and 2022-2023” [PAGE 1], so a grouped or temporal holdout is the natural stress test.

The reported metrics are:
\[
\mathrm{RMSE}
=
\sqrt{
\frac{1}{n}
\sum_{i=1}^{n}
\left(y_i-\hat{y}_i\right)^2
},
\]
with units of the target space. If \(y_i\) is log-monetary, RMSE is in log-monetary units; if \(y_i\) is standardized, RMSE is dimensionless; if \(y_i\) is raw monetary value, RMSE is monetary. The paper does not state which space Table 2 uses. The coefficient of determination is
\[
R^2
=
1-
\frac{
\sum_{i=1}^{n}
\left(y_i-\hat{y}_i\right)^2
}{
\sum_{i=1}^{n}
\left(y_i-\bar{y}\right)^2
},
\]
which is dimensionless and is undefined when the denominator sum of squares is zero. The paper says “The range of R2 is from 0 to 1, the closer to 1, the more precise the prediction delivers” [PAGE 4]. That statement is imprecise for out-of-sample evaluation: test-set \(R^2\) can be negative when the model is worse than the test-set mean predictor. The mean absolute percentage error is
\[
\mathrm{MAPE}
=
\frac{100}{n}
\sum_{i=1}^{n}
\left|
\frac{
y_i-\hat{y}_i
}{
y_i
}
\right|,
\]
with percent units. It is undefined when any \(y_i=0\), which is why the source's zero removal [PAGE 3] is also a MAPE pre-condition. MAPE is also unstable for small positive \(y_i\) and is not symmetric in overprediction and underprediction. The source reports Table 2 values as RMSE, R2, and MAPE in percent [PAGE 4].

Tree feature importance is typically an impurity decrease:
\[
\Delta I
=
I(\text{parent})
-
\frac{N_L}{N}I(\text{left})
-
\frac{N_R}{N}I(\text{right}),
\]
where \(I\) is an impurity such as variance in squared target units. The source reports that “the highest value is the most important factor in predicting the current value of a player, because it stands for the global achievement of a player, followed by the age and the health condition of a player” [PAGE 8]. This is a model-internal importance statement, not a causal effect. If “Highest value” contains future or contemporaneous target information, the importance is leakage importance. If it is historical maximum only, it is a prior-value signal. The source does not define the time window, so the interpretation is underdetermined.

<RECURSIVE_THEORY_OF_MIND>
The crisis habit regression here is the analyst's default under deadline: read Table 2, select the model with the lowest RMSE and highest R2, and treat the ranking as settled. The source encourages that habit because gradient boosting has the lowest RMSE 0.450 and highest R2 0.928 [PAGE 4]. But the same table shows random forest has the lower MAPE, 2.222 percent versus 2.294 percent [PAGE 4]. A single aggregate metric cannot adjudicate a multi-objective decision. The crisis habit is to collapse a vector of losses into one leaderboard rank and then narrate causality from feature importance.

The counter-trap is to make the decision context explicit. If the user is a team manager estimating current value for negotiation support, the loss should be asymmetric: underestimating an elite player may be more costly than overestimating a low-value player. Then the relevant test is not global R2 but high-value tail bias, calibration, and uncertainty intervals. The paper itself reports that random forest and gradient boosting “always tend to underestimate” high-value players [PAGE 6, PAGE 7]. A counter-trap model would use quantile regression, stratified evaluation, or a two-stage model with a tail classifier. If the user is a player trying to understand which factors matter, the counter-trap is to distinguish model importance from causal leverage. The paper says “the highest value is the most important factor” [PAGE 8], but a player cannot directly improve a historical market maximum. The actionable features are age, minutes, appearances, goals, assists, and injury days, yet those are also confounded by team quality, league, position, and contract.

The clock is the two-season window and the career-time mismatch. The dataset covers 2021-2022 and 2022-2023 [PAGE 1], but “Days injured” ranges to 1570 [PAGE 3], roughly 4.3 years. If that variable is career-cumulative rather than season-specific, then the model mixes different time horizons. A player's current value at the end of 2022-2023 is being predicted with an injury count that may include earlier career history. That is not automatically wrong, but it changes the estimand from “this season's performance” to “career health plus recent performance.” The clock also matters for market regime: transfer inflation, club liquidity, and league broadcasting revenue shift across seasons. A random 3-fold CV [PAGE 4] does not simulate a future market regime.

Recursive theory of mind adds three perspectives. The model-builder assumes the manager wants a point prediction, so the builder optimizes RMSE. The manager assumes the builder has removed leakage and validated temporally, so the manager treats the output as a negotiation anchor. The player assumes feature importance is causal, so the player over-invests in a proxy such as awards or highest past value. Each perspective is locally rational and globally incomplete. The counter-trap is to force each assumption into a test: grouped CV for the builder, contract-aware baselines for the manager, and causal-invariance checks for the player. The clock forces those tests to be time-indexed. A model that wins a random fold but fails a season holdout is not a robust valuation model; it is a within-sample interpolator.
