Second, construct features in two families: win-ratio features and game-statistics features [PAGE 2]. Third, train logistic regression with Newton-Raphson and SVMs with linear, polynomial, and tangent kernels [PAGE 1]. Fourth, perform backward/forward feature selection, mostly with logistic regression because it was fastest and usually best [PAGE 2]. Fifth, introduce three-week “momentum” features [PAGE 3]. Sixth, compare two averaging cutoffs: averages up to the game week and averages up to the test week [PAGE 3-4]. Seventh, report season-level accuracy and compare loosely with expert picks from 2006 through week 14 [PAGE 5].

The gray-zone audit centers on temporal validity. The “up to test week” method is described as: “It is completely fair because we want to classify week 16's games and by then we have all the outcomes of week 1-15” [PAGE 3]. If the cutoff is strictly through week 15 for a week-16 test game, the test features are point-in-time valid. But the same cutoff is applied retrospectively to training samples from weeks 1-15, so a week-2 training sample can contain information from week 15. That is not leakage relative to the week-16 test set, but it is a temporal mismatch between training and the natural deployment of the model. The paper says, “This technique increased the accuracy for all models” [PAGE 3] and “in every case the set whose average was calculated up to the test week had better results” [PAGE 4]. A strict replay should verify that the cutoff never includes the test week itself; if it does, accuracy is inflated by target leakage. The wording “up to test week 16” in the example is ambiguous enough to require an audit.

<SOURCE_OPERATORS_AND_EQUATIONS>
Target and accuracy. Let \(y_g \in \{0,1\}\) be the game outcome for game \(g\), with \(y_g=1\) if the visitor wins, following the paper’s example “where 1 means visitor won” [PAGE 3]. Let \(x_g \in \mathbb{R}^d\) be the feature vector. A probabilistic classifier outputs \(p_g = P(y_g=1 \mid x_g)\), dimensionless and constrained to \([0,1]\). A hard prediction is \(\hat y_g = \mathbf{1}[p_g \ge \tau]\), with \(\tau=1/2\) unless a confidence threshold is chosen. Accuracy is \(A = \frac{1}{N}\sum_{g=1}^{N}\mathbf{1}[\hat y_g = y_g]\), dimensionless, reported as a percentage. The paper reports season accuracy, for example “2005: 65.83% - 2004: 61.37% - 2003: 67.08%” [PAGE 4]. Assumption: games are exchangeable within the evaluation window. Breakdown: accuracy is not a proper scoring rule; it ignores calibration and can reward overconfident but lucky classifiers.

Logistic regression. The paper used “my own implementation of logistic regression in matlab, which used Newton-Raphson method” [PAGE 1]. The model is \(p_g = \sigma(\beta_0 + \beta^\top x_g)\), where \(\sigma(z)=1/(1+e^{-z})\). The log-loss is \(L(\beta)=-\frac{1}{N}\sum_{g=1}^{N}[y_g\log p_g + (1-y_g)\log(1-p_g)]\), in nats per game. Newton-Raphson uses \(\beta^{(k+1)}=\beta^{(k)} - H^{-1}\nabla L(\beta^{(k)})\), with Hessian \(H = X^\top W X\) and \(W_{gg}=p_g(1-p_g)\). Assumptions: independent games, linearity in the log-odds, and a nonsingular Hessian. Breakdown regimes: complete or quasi-complete separation makes coefficients diverge; collinear features make \(H\) ill-conditioned; small samples and rare outcomes make the inverse unstable. The paper’s feature selection can also create selection bias if the same data are reused for selection and evaluation.

SVM operators. The paper used “svm-light with linear, polynomial and tangent kernels” [PAGE 1]. A kernel SVM has \(f(x)=\sum_i \alpha_i y_i K(x_i,x)+b\), with decision \(\hat y=\operatorname{sign}(f(x))\). The paper’s table gives linear \(K(a,b)=a\cdot b\), polynomial \(K(a,b)=(s a\cdot b+c)^d\), and tangent \(K(a,b)=\tanh(s a\cdot b+c)\), with parameters such as “C:1” and “s:0.1, c:1, C:1” [PAGE 1-2]. Units: kernel arguments are dimensionless only if features are standardized; if raw yards and counts are used, the dot product mixes yards with counts and the kernel scale is not physically interpretable. Breakdown: unnormalized features, kernel parameter sensitivity, and class imbalance can dominate the margin. The paper notes that “the sigmoid kernel for one or two experiments” was “not very good” [PAGE 1].

Win-ratio and three-week momentum. For team \(i\), define \(r_i(w)=\frac{W_i(w)}{W_i(w)+L_i(w)+T_i(w)}\), dimensionless. The denominator is zero before the first game, so \(r_i\) is undefined at season start; the paper avoids classifying “the first two weeks of each season” [PAGE 1]. The three-week feature is \(r_i^{(3)}(w)=\frac{\sum_{k=w-3}^{w-1}\mathbf{1}[i\text{ wins game }k]}{\sum_{k=w-3}^{w-1}\mathbf{1}[i\text{ plays game }k]}\), also dimensionless, with the same zero-denominator breakdown. The paper’s momentum rationale is that “a team is more likely to have a closer performance to its recent performance” [PAGE 3]. But after eliminating week number, “the best feature set didn't have any 3-week averages” [PAGE 3], so the momentum operator is not robust in this study.

Averaging cutoff. Let \(\mathcal{H}_w(i)\) be team \(i\)’s history through week \(w\). A game-week feature is \(x_g^{g}=\phi(\mathcal{H}_{w_g-1}(i),\mathcal{H}_{w_g-1}(j),w_g)\). A test-week feature is \(x_g^{t}=\phi(\mathcal{H}_{W-1}(i),\mathcal{H}_{W-1}(j),w_g)\) for a test cutoff \(W\). The paper argues for the latter: “It is completely fair because we want to classify week 16's games and by then we have all the outcomes of week 1-15” [PAGE 3]. The validity condition is strict: the cutoff must exclude the test week, \(W-1 \lt w_{\text{test}}\). If \(\mathcal{H}_W\) includes test-week outcomes, the operator is leaky. Breakdown regimes: inclusive test-week cutoff, season-boundary resets, and training samples whose features are computed with future information relative to their own game week.

Feature selection. The paper’s wrapper objective can be written \(\hat S = \arg\max_{S\subseteq F}\hat A_{\text{validation}}(S)\). Assumption: the validation slice is representative and independent of the evaluation. Breakdown: if selection is performed on the same season or on a small sample, \(\hat S\) overfits; the paper reports that cross-season feature sets were “not consistently better” [PAGE 2]. The week-number result is a clear operator: removing week number improved the best logistic-regression case [PAGE 2, PAGE 5].

Expert accuracy. The expert metric is \(A_E=R/(R+W)\), dimensionless, where \(R\) is right and \(W\) is wrong. The paper reports values from 0.5284 to 0.6193 for 2006 through week 14 [PAGE 5]. The comparison is confounded because experts can abstain: “they have the luxury of not picking a winner for some games” [PAGE 5]. Assumption for fair comparison: same season, same games, same abstention rule. Breakdown: selective prediction changes the denominator and can inflate accuracy.

<RETROCAUSAL_GENEALOGY>
The paper sits at the intersection of three lineages. The first is generalized linear modeling: logistic regression with Newton-Raphson is a classical maximum-likelihood procedure, and the paper explicitly used a custom MATLAB implementation [PAGE 1]. The second is statistical learning with kernels: the paper uses svm-light and a kernel table with linear, polynomial, and tangent kernels [PAGE 1-2]. The third is sports forecasting: win ratios, recent-form “momentum,” and strength-of-schedule corrections. The paper gestures at the third lineage when it says “BCS like formulas can be used to account for unbalanced schedules” [PAGE 5].

A retrocausal reading asks which later methodological norms would have diagnosed the earlier design. Point-in-time data discipline would require every feature to be computed from the information set available at prediction time, with a strict cutoff \(\mathcal{H}_{W-1}\). Walk-forward validation would separate feature selection from evaluation and would report confidence intervals. Calibration analysis would replace bare accuracy with log loss and Brier-type proper scores. Causal graph analysis would separate team quality from schedule difficulty, injuries, weather, and game state. None of these are present in the paper’s reported tables.

The multi-week traps are specific. First, week number is a season-clock proxy: it can correlate with data availability, schedule strength, and team improvement. The paper found that “Week Number was a bad feature” [PAGE 3], and that removing it improved results [PAGE 2]. But the reason may be confounding rather than irrelevance. Second, three-week momentum is collinear with week number and with recent opponent quality; after week number was removed, the best set had no three-week averages [PAGE 3]. Third, the “up to test week” averaging method changes the information set for training samples, so it is a transductive preprocessing choice, not a purely point-in-time feature. The paper defends it as fair for the test week [PAGE 3], but a rigorous genealogy would demand a strict cutoff audit. Fourth, cross-season feature selection assumes “the game doesn't change much” [PAGE 2], yet the paper calls that “a not a fool-proof assumption” [PAGE 2] and reports inconsistent transfer. Fifth, unbalanced schedules create a latent strength-of-schedule variable; without it, win ratios are noisy estimates of team quality. The paper’s own conclusion points toward schedule correction and confidence scoring [PAGE 5].

<RECURSIVE_THEORY_OF_MIND>
The paper’s model is a statistical profile model, not a strategic-interaction model. It admits “psychological factors” as a source of unpredictability [PAGE 1], but the features are win ratios and game statistics, not beliefs, intentions, or counterfactuals. In recursive theory-of-mind terms, each team’s coaching staff models the opponent’s tendencies, then chooses a game plan that exploits those tendencies. A simple representation is \(B_i^{(k+1)}=\mathcal{F}_i(B_j^{(k)},H_i,C_t)\), where \(B_i\) is team \(i\)’s belief about opponent \(j\), \(H_i\) is team \(i\)’s habit/base-rate history, and \(C_t\) is the game-clock and score state. The paper’s classifier uses only \(H_i\) and \(H_j\), not \(B_i\), \(B_j\), or \(C_t\). That omission creates three distinct failure regimes.

Crisis habit regression: under stress, play-callers and players often revert to high-frequency habits. A historical average may capture the habit, but it does not capture the deviation from the habit when the team is trailing late, has lost a key player, or faces an unfamiliar defensive look. The model’s three-week win ratio is a recent-form proxy, not a crisis-state operator. Counter-trap: the opponent anticipates the habit and designs a counter. If team A’s historical tendency is to run on third-and-short, team B can bait that tendency and then defend it. The observed outcome is anti-correlated with the historical base rate. The model has no variable for “opponent has both the incentive and capability to counter.” Clock: time remaining, score differential, timeouts, and possession change risk preferences. The paper removed week number and did not include game-clock state; its own recommendation to avoid “close games” [PAGE 5] is an implicit clock/uncertainty veto. The recursive theory-of-mind conclusion is that the classifier can rank average team strength, but it cannot resolve strategic deception, crisis regression, or late-game clock pressure without additional state variables.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The cross-layer veto is a sufficiency argument. Let \(x\) be the paper’s feature vector and let \(z\) be an unmodeled physical, biomechanical, or weather state. The model estimates \(P(Y\mid x)=\int P(Y\mid x,z)\,dP(z\mid x)\). If the test distribution of \(z\) lies outside the training support, the integral is an extrapolation, not an interpolation. A sufficient veto condition is \(\max_z\left|\operatorname{logit}P(Y=1\mid x,z)-\operatorname{logit}P(Y=1\mid x)\right|>\tau_v\), where \(\tau_v\) is the decision margin implied by the probability threshold. Equivalently, if an unmodeled covariate can move the log-odds across the decision boundary, the classifier’s hard prediction is not physically justified. Units for \(z\) are concrete: wind speed in m s\(^{-1}\), precipitation in mm h\(^{-1}\), temperature in degrees Celsius, rest in days, travel distance in metres, and player availability as a categorical injury/status state. The paper’s features include “AVG_YARDS_BY PASSING” [PAGE 2], which is weather-sensitive, but the model does not condition on wind, precipitation, or temperature. It also acknowledges “injuries to players” [PAGE 1], yet it does not encode injury reports or personnel changes.

The biomechanical layer is equally important. Offensive-line continuity, quarterback pressure, ankle and knee status, and accumulated hits affect performance and are not in the win-ratio features. A team with a strong win ratio but a depleted offensive line can have a materially different conditional distribution than the historical average. The weather layer affects passing efficiency, kicking, and ball security; a model trained on a mixture of weather states can be miscalibrated when the test game is in an extreme wind or precipitation regime. The adjudication rule is therefore: a physical or weather veto overrides a statistical prediction when the test state is out-of-support or when the unmodeled covariate’s plausible effect exceeds the model margin. The paper’s own call for a “confidence score” and for “not predicting close games” [PAGE 5] is consistent with this veto logic. The proof is conditional, not empirical: if \(P(z\mid x_{\text{test}})\) differs from the training distribution and \(z\) is predictive of \(Y\), then \(P(Y\mid x)\) is not a calibrated conditional probability for that test game. No amount of win-ratio accuracy can establish physical invariance.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
RLVR here means a verifiable-reward audit: each veto is a programmatic check with an observable outcome, so the prediction can be rewarded or penalized without human judgment. The verifier should log accuracy, log loss, and calibration error under strict point-in-time replay.

Scenario 1: test-week cutoff leakage veto. Veto condition: the feature cutoff for a test game in week \(W\) includes any outcome from week \(W\). The verifier reruns the paper’s “up to test week” method with \(\mathcal{H}_{W-1}\) only and compares it with an inclusive \(\mathcal{H}_W\) variant. Prediction: the inclusive variant will report higher accuracy than the strict variant on the same games; if the gap exceeds roughly three percentage points, the paper’s reported “up to test week” advantage is materially contaminated by look-ahead. If the gap is near zero, the paper’s temporal conclusion survives the audit. The paper’s own justification is “by then we have all the outcomes of week 1-15” [PAGE 3], so the strict cutoff is the correct verifier target.

Scenario 2: injury and availability veto. Veto condition: a quarterback, offensive lineman, or other high-impact player is ruled out or materially limited after the feature cutoff. The verifier joins public injury/status reports to the game log and stratifies error by status change. Prediction: the classifier’s accuracy will be lower and its log loss higher on games with a late high-impact status change than on matched games without one. A veto that abstains on those games will improve calibration even if raw accuracy changes little. This is directly supported by the paper’s admission that “injuries to players” matter [PAGE 1] and by the absence of injury features in the reported feature sets.

Scenario 3: weather out-of-support veto. Veto condition: wind speed, precipitation, or temperature at the venue lies outside the training interquartile range or exceeds a physically motivated threshold for passing efficiency. The verifier joins venue weather data and evaluates error as a function of wind speed and precipitation. Prediction: error and miscalibration will increase monotonically with wind speed for models that rely on “AVG_YARDS_BY PASSING” [PAGE 2]. A veto that suppresses predictions in extreme wind or heavy precipitation will reduce log loss and calibration error relative to the unvetoed classifier, even if it reduces coverage. The paper’s recommendation to “not predict close games” [PAGE 5] is a weaker version of the same selective-prediction logic.

A fourth optional audit, if needed, is schedule-strength veto: when a team’s win ratio is built against an unusually weak or strong schedule, the verifier should compare raw win ratio with a schedule-adjusted rating. The paper notes that “BCS like formulas can be used to account for unbalanced schedules” [PAGE 5]. Prediction: schedule-adjusted features will reduce variance in accuracy across seasons and will shrink the apparent week-number effect. All three core vetoes are verifiable because they require only game logs, cutoff timestamps, injury reports, and venue weather; none require an unverifiable psychological latent.
</RLVR_COUNTERFACTUAL_VETOES>
