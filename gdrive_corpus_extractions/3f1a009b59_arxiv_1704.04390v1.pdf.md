### RECURSIVE_THEORY_OF_MIND

Crisis habit regression vs counter-trap vs clock.

- Recursive theory of mind: Radar i models what radar j will choose. In BRD, radar i computes best response to s−i, which itself is a best response to others. This is level-k reasoning. In scenario 1, since utilities are identical, higher-order reasoning collapses: all radars want the same balanced allocation, so first-order best response suffices. In scenario 2, heterogeneous weights mean radar i must anticipate radar j's preferences (Battle of the Sexes analogy [PAGE 8]).
- Crisis habit regression: Algorithm 1 step s4 explicitly implements regression to previous strategy s(k−1) if current utility drops. This is a "crisis habit"—when coordination failure occurs (Fig 4: multiple radars switch to same target causing cyclic behavior), the system reverts to last known good state. Memory requirement: store previous action and utility.
- Counter-trap: The counter-trap to coordination failure is the probability α < 1 of not updating (or ε exploration). By randomizing, the system avoids deterministic cycles (simultaneous BRD can cycle). In regret matching, probabilities proportional to regret mean radars switch away from strategies that caused past losses—counter-trap to lock-in on suboptimal anti-coordination.
- Clock: Discrete time k, update time tu = 0.25 s (or 0.025 s). Algorithms run at each time instant or every K instants. The "clock" is the scan period. If target dynamics (F, Q) evolve faster than the clock, the EKF prediction step grows uncertainty between updates; if the game-theoretic reallocation clock (every K scans) is slower than target maneuver, the equilibrium becomes stale.

Correlated equilibrium requires a probability vector π on S (nonnegative coordinates summing to 1) such that Σ_{s_{−i}∈S_{−i}} π(s_i, s_{−i})[u_i(s_i, s_{−i}) − u_i(s′_i, s_{−i})] ≥ 0 for all i and all s_i, s′_i ∈ S_i [PAGE 2–3].

Target kinematics use x_j,k = F · x_j,k−1 + w_j,k−1 and z^{(i)}_{j,k} = h^{(i)}_j(x_j,k) + ν^{(i)}_{j,k} [PAGE 3]. The state transition is F = [1 t_u; 0 1] ⊗ I₂ [PAGE 3], and process noise covariance is Q = σ²_w · [t³_u/3, t²_u/2; t²_u/2, t_u] ⊗ I₂ [PAGE 4], with σ²_w in km²/s³. Measurement noise covariance is R_{j,i} = diag{[σ^{(i)}_{rj}]², [σ^{(i)}_{aj}]²} [PAGE 3], with σ_r in meters and σ_a in milliradians [PAGE 10].

Utility is u_i(s_i, s_{−i}) = Σ^T_{j=1} gain_j(mt_j) [PAGE 4], where gain_j(mt_j) = Tr{P_{j,k|k−1} − P^{(mt_j)}_{j,k|k}} [PAGE 4], yielding units of km² (trace of position-error covariance). The incremental gain is ∆g^{(j)}_p = Tr{P^{(p−1)}_{j,k|k} − P^{(p)}_{j,k|k}} [PAGE 5], and gain_j(mt_j) = Σ^{mt_j}_{p=1} ∆g^{(j)}_p [PAGE 5]. Assumptions: ∆g^{(j)}_p > 0 and ∆g^{(j)}_p > ∆g^{(j)}_{p+1} [PAGE 4–5]. Case (a) sets ∆g^{(j)}_p = ∆g_p ∀j; case (b) requires min_j ∆g^{(j)}_p > max_j ∆g^{(j)}_{p+1} for j ≠ ℓ [PAGE 5].

Proposition 1: case (a) has PoA = 1; any track assignment is NE if Σ_j s_i,j = m, with mt_j ≤ 1 when N·m ≤ T, or |mt_j − mt_ℓ| ≤ 1 when N·m > T [PAGE 5]. Proposition 2: case (b) has PoA > 1, with level-filling by ⌈N·m/T⌉ [PAGE 5]. Best response is BR_i(s_{−i}) = arg max_{s_i} u_i(s_i, s_{−i}) [PAGE 5]. Algorithm 1 (LC-BRD) updates simultaneously with probability α and reverts to s(k−1) via step s4 if u_i(s(k), s_{−i}(k)) < u_i(s(k−1), s_{−i}(k−1)) [PAGE 5–6]. Theorem 1: Algorithm 1 converges to a pure NE [PAGE 6–7], using exact potential function Φ = u_i because all radars share identical payoffs in Scenario 1.

Scenario 2 relaxes homogeneity: s_i,j = a if j ∈ T_i else 0 [PAGE 7], and u_i = Σ^T_{j=1} w_i,j · gain_j(mt_j(i)) with weights w_i,j [PAGE 8]. Because the game is generally not potential, correlated equilibrium is used [PAGE 8]. Regret is R_{i,k}(s_i, s′_i) = max{D_{i,k}(s_i, s′_i), 0} [PAGE 7], where D_{i,k} = (1/k) Σ_{kp≤k} [u_i(s′_i(kp), s_{−i}(kp)) − u_i(s_i(kp), s_{−i}(kp))] [PAGE 7–8]. Strategy probabilities update as π^{k+1}_i(s′_i) = (1/μ)R_{i,k}(s_i, s′_i) for s′_i ≠ s_i, with π^{k+1}_i(s_i) absorbing the remainder [PAGE 8], and μ > 0 is fixed large enough to keep probabilities positive. Empirical distribution is η_k(s) = (1/k) #{kp ≤ k : s(kp) = s} [PAGE 8]. Theorem 2: η_k converges almost surely to the set of correlated equilibria as k → ∞ [PAGE 8]. For time-varying gains, discounted recursion is D_{i,k} = D_{i,k−1} + θ_k [u_i(s′_i(k), s_{−i}(k)) − u_i(s_i(k), s_{−i}(k)) − D_{i,k−1}] [PAGE 9]; θ_k = 1/k recovers static convergence, while fixed θ_k = θ enables adaptation via stochastic averaging [PAGE 9].

Computational complexity: regret-matching O(N · |T_i|^m), centralized exhaustive search O(|T_i|^{N·m}), LC-BRD O(N · m · |T_i|) [PAGE 9–10]. Simulations used N = 3 radars, m = 2, T = 5 targets, t_u = 0.25 s, σ²_w = 2.5·10⁻⁵ km²/s³, σ_a = 2 mrad, σ_r = 15 m, and P_{0|0} = diag{(0.1 km)², (0.1 km)², (0.1 km/s)², (0.1 km/s)²} [PAGE 10].

<RETROCAUSAL_GENEALOGY>
The intellectual genealogy traces correlated equilibrium to Aumann (1974), “Subjectivity and correlation in randomized strategies” [PAGE 13, ref. 43], and the regret-matching dynamic to Hart and Mas-Colell (2000), “A simple adaptive procedure leading to correlated equilibrium” [PAGE 13, ref. 51]. Potential-game foundations come from Monderer and Shapley (1996) [PAGE 13, ref. 50], and the normal-form game framework follows Shoham and Leyton-Brown (2008) [PAGE 2, ref. 24]. Within radar-specific game theory, the paper builds on waveform-design zero-sum games [33–35], power-control non-cooperative games [37], Shapley-value coalitional games [38], and correlated-equilibrium data association at a single radar [39], extending prior conference work [42] into a full journal treatment [PAGE 1–2, 13].

The multi-week trap is temporal: the paper formulates a one-shot normal-form game at each discrete time k, yet tracking is inherently multi-step over weeks of operation. Trap 1: a Nash equilibrium at time k is myopic; it optimizes instantaneous covariance trace but ignores future observability. If a target maneuvers between scans, the EKF covariance P grows through F P Fᵀ + Q [PAGE 3–4], so yesterday’s equilibrium allocation can leave a target under-observed tomorrow. Trap 2: Algorithm 1’s reinitialization every K instants [PAGE 6] produces a sawtooth performance profile. Between reinitializations, target drift erodes the learned equilibrium; if K is too large relative to maneuver time constants, the system operates far from equilibrium most of the time. Trap 3: in Scenario 2, correlated equilibrium existence is asymptotic (k → ∞) [PAGE 8]. Over a finite multi-week window, the empirical distribution η_k may remain far from the CE set if radar interests, observability sets T_i, or connectivity neighborhoods N_i change faster than the regret-matching convergence rate. Trap 4: the weights w_i,j and partial observability constraints are assumed fixed within a learning epoch [PAGE 7–9]; a new priority target appearing after weeks of operation invalidates the accumulated regret history D_{i,k}, forcing a cold restart that sacrifices tracking performance during re-learning.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
Radar i’s decision embeds recursive theory of mind: to compute its best response BR_i(s_{−i}) [PAGE 5], radar i must anticipate the strategies of all other radars. In Scenario 1, because utilities are identical (common-payoff game), first-order reasoning suffices: every radar prefers the same balanced allocation, so higher-order beliefs collapse into a single coordination focal point. In Scenario 2, heterogeneous weights w_i,j create a Battle of the Sexes structure [PAGE 8]; radar i must model radar j’s target preferences, because j’s best response depends on j’s own weight vector, not merely on i’s action. This second-order reasoning is precisely what makes the game non-potential and necessitates correlated equilibrium rather than Nash.

Crisis habit regression is instantiated in Algorithm 1 step s4 [PAGE 5–6]: if a simultaneous update causes utility to drop below the previous time step, the radar reverts to s(k−1). This is a habit regression to the last known-good coordination state, triggered by a coordination failure such as multiple radars simultaneously illuminating the same target (Fig. 4, [PAGE 6]). The regression requires memory of the prior action and utility, a small but non-trivial state that distinguishes the algorithm from stateless simultaneous BRD.

The counter-trap is the randomization pressure α < 1 [PAGE 5–6] and the regret-proportional switching probabilities in Equation (19) [PAGE 8]. Deterministic simultaneous best response can cycle endlessly through suboptimal profiles; by updating with probability less than one, or by switching in proportion to accumulated regret, the system escapes deterministic limit cycles. Regret matching further counter-traps lock-in: radars migrate away from strategies that caused historical losses, regardless of whether those strategies were locally myopic best responses.

The clock is the discrete scan index k with update time t_u = 0.25 s (or 0.025 s in high-rate trials) [PAGE 10]. Algorithms either run every scan (K = 1) or are reinitialized every K = 10 scans [PAGE 10]. If target dynamics governed by F and Q [PAGE 3–4] evolve on a timescale shorter than the game-theoretic reallocation clock, the equilibrium computed at scan k is stale by scan k+1, and recursive reasoning operates on an outdated model of other radars’ constraints.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical-layer veto: the EKF measurement matrix H = ∂h/∂x is linearized about the current estimate [PAGE 3–4]. If targets are not well-separated or appear at similar range-azimuth from a radar, data association is no longer trivial (the paper assumes trivial association) [PAGE 3], and the trace-based utility gain_j(mt_j) = Tr{P_{k|k−1} − P^{(mt_j)}_{k|k}} [PAGE 4] ceases to represent actual tracking performance. A second physical veto is the zero-measurement singularity: when N·m < T, some target receives mt_j = 0 [PAGE 5]. With no measurement update, covariance propagates as P_k = F P_{k−1} Fᵀ + Q [PAGE 3–4]; since Q ≻ 0 with σ²_w = 2.5·10⁻⁵ km²/s³ [PAGE 10], position variance grows without bound, making the target effectively untrackable until reacquisition. The Kalman gain inversion [H P Hᵀ + R]⁻¹ in Equation (8) [PAGE 3] requires R ≻ 0; if σ_r or σ_a approach infinity (sensor failure), gain vanishes and utility becomes flat, destroying the diminishing-returns Assumption 2 [PAGE 4–5].

Biomechanical/kinematic veto: targets are modeled as constant-velocity with bounded maneuverability via σ²_w [PAGE 3–4]. If a target executes a maneuver beyond the process-noise envelope, the EKF linearization error invalidates P, and covariance trace no longer bounds true error. Track selection based on ∆g increments then optimizes a meaningless objective. Weather veto: the paper assumes fixed Gaussian measurement noise with σ_r = 15 m and σ_a = 2 mrad [PAGE 10], and does not model atmospheric attenuation, clutter, or weather-induced variance inflation. Rain or turbulence would increase σ_r and σ_a asymmetrically across radars, altering gain_j(mt_j) mid-epoch; because the algorithms assume static noise within a K-interval [PAGE 6, 9], weather changes are an unmodeled veto that can render learned NE or CE allocations obsolete.

Breakdown regimes: (i) N·m ≤ T with mt_j = 0 targets causes covariance divergence; (ii) violation of Assumption 2 (non-diminishing gains) invalidates Propositions 1–2 and the NE structure; (iii) decreasing θ_k = 1/k converges to static CE but cannot track time-varying interests, while fixed θ_k adapts only to sufficiently small changes [PAGE 9]; (iv) simultaneous BRD without step s4 or α < 1 can cycle under strategic uncertainty [PAGE 6].
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Veto Scenario 1 — Zero-measurement covariance explosion. Set N = 3, m = 1, T = 5 so that N·m = 3 < T and two targets receive mt_j = 0 [PAGE 5]. Verification: run LC-BRD and log Tr(P_{j,k|k}) for unmeasured targets over k = 1…50 scans. Prediction: with Q ≻ 0 and no updates, P grows via P_k = F P_{k−1} Fᵀ + Q [PAGE 3–4]; after 50 scans at t_u = 0.25 s (12.5 s elapsed), position standard deviation exceeds the initial 0.1 km by orders of magnitude. The marginal gain of the first post-gap measurement becomes arbitrarily large, violating uniform concavity across time and voiding the static NE conditions of Proposition 1. The veto triggers forced reacquisition: any rational allocator must assign a beam to the divergent target regardless of the current NE.

Veto Scenario 2 — Simultaneous BRD limit cycle without memory. Set N·m > T under case (b) heterogeneous gains, run pure simultaneous BRD with α = 1 and no step s4 reversion. Verification: log Φ(k) = u_i(s(k)) each scan and detect Φ(k) < Φ(k−1) recurring. Prediction: as illustrated by the coordination failure in Fig. 4 [PAGE 6], multiple radars can switch to the same target in lockstep, producing a limit cycle where the sum of traces Σ_i Σ_j w_i,j Tr{P^{(mt_j(i))}_{j,k|k}} [PAGE 10, Eq. 23] oscillates rather than converges. Theorem 1’s convergence guarantee explicitly requires step s4 or α < 1 [PAGE 6–7]; removing either vetoes convergence. The system must inject memory or probabilistic skipping to escape.

Veto Scenario 3 — Non-stationary interest matrix outpacing regret adaptation. In Scenario 2, let the weight matrix W change every K_w scans (e.g., a new target jumps from w_i,j = 0 to w_i,j = 1) while regret uses fixed θ_k = θ. Verification: compare the empirical distribution η_k against the time-varying correlated equilibrium and measure the tracking error in sum of traces. Prediction: Theorem 2 guarantees convergence only for static games [PAGE 8]; with fixed step size, the algorithm tracks changes only if they are sufficiently small [PAGE 9]. A sudden weight jump leaves accumulated regret D_{i,k} [PAGE 7–8] biased by old history; reallocation to the new priority target requires O(1/θ) scans. During that window, the high-priority target is under-illuminated, and its covariance trace grows via the prediction step [PAGE 3–4]. Veto triggers if |Δw|/θ exceeds the adaptation bandwidth; the system must reset π or temporarily increase θ to avoid persistent priority-target loss.
