<RECURSIVE_THEORY_OF_MIND>
The recursive structure is architectural. Each agent is a JAM agent with a world model, plan library, interpreter, intention structure, and observer [PAGE 5–6]. The anticipator holds *copies* of these agents: "The anticipator copies information from the agent, such as facts from its world model or the current goal of the agent, and stores it in a copy of the agent" [PAGE 8]. The recursion is therefore second-order: the anticipator reasons about what the agent will do, and the agent reasons about what the other characters will do, but the anticipator does not attempt third-order nesting (player models player models player). This bounded recursion is a deliberate design choice and is the key to tractability.

**Crisis habit regression.** When the real player's input diverges from prediction, the system does not escalate recursion depth; it executes a habit-level fallback: "If the actual state does not evolve according to predictions the anticipator can discard the current predictions, gather new information, and start the cycle anew" [PAGE 8]. This is regression to the synchronization primitive — a low-cost, well-rehearsed loop rather than a deeper inference. The analogy to crisis habit regression in human cognition is exact: under prediction error, the system reverts to the most over-learned routine (snapshot, resimulate, re-veto).

**Counter-trap.** The opposite failure is over-intervention. The paper names the stakes: "A player, in a few mouse clicks, may ruin an experience that has painstakingly been designed by an author" [PAGE 4]. The counter-trap is that a sufficiently aggressive anticipator will veto so many player actions that agency collapses. The mitigation is the effector cost ordering — prefer parameter updates over beats, beats over scenes — and the requirement that interventions be transparent: "It is important that transitions from one state of affairs to another are made accessible and understandable to the player" [PAGE 14].

**Clock.** The third pole is the real-time constraint. "The time complexity must be low enough to allow for faster than real-time execution" [PAGE 11]. Because the simulation omits I/O — "The simulation has no side effects, such as output to the front-end" [PAGE 7] — the anticipator can run faster than the wall clock. But the observer plan only grants access "between each planning step," not uninterrupted insight [PAGE 6–7]. The clock therefore bounds recursion depth, veto frequency, and effector granularity simultaneously. The three-way tension (habit regression vs. counter-trap vs. clock) is resolved by the synchronization barrier: the anticipator waits for all affected agents to call the synchronization method before applying any effector [PAGE 8], which serializes intervention and prevents mid-step inconsistency.

The paper's architecture implies a strict four-layer veto hierarchy. I formalize it as a partial order and prove non-deadlock.

**Layer P (physical domain).** Parameter values must lie in their declared domains: love for Niklas is an interval $(0\dots9)$ [PAGE 12], and life/death may be Boolean or interval-valued [PAGE 14]. A write outside the domain is physically inadmissible. Veto rule: $e$ is rejected if $\exists p:\ \pi_{t+1}(p)\notin \mathrm{dom}(p)$.

**Layer B (biomechanical / agent-architectural).** The agent's world model, plan library, and intention structure must remain internally consistent. The paper's own example shows the constraint: to initiate a fight, two agents "will need opposing views of the matter at hand, different knowledge, different arguments" [PAGE 10]. Veto rule: $e$ is rejected if it would leave an agent with a plan whose preconditions are unsatisfiable given its beliefs.

**Layer W (weather / environmental).** Environmental updates include introducing or removing characters, altering the flow of time, and creating disruptive events such as "throwing a temper tantrum or starting a row with another character" [PAGE 13]. These are legitimate effectors but are constrained by narrative coherence. Veto rule: $e$ is rejected if it produces "unexplained or unexplainable twists or turns" [PAGE 14].

**Layer N (narrative admissibility).** The automaton itself vetoes: any transition not depicted leads to the dead state $\bot$ [PAGE 17]. Veto rule: $e$ is rejected if the resulting $M$-state is $\bot$ and the system is not in designated resilience mode.

**Proof of non-deadlock.** The admissible effector set is finite ($E$ is a finite union of parameter writes, beats, scenes, sequences, and acts). Each candidate passes layers in descending priority P → B → W → N; the first failure rejects it. If all candidates fail, the anticipator does not loop: it enters resilience mode, permitting a temporary excursion into $U$ with a pre-specified return edge to $D$ [PAGE 15]. Termination follows because each cycle is triggered by a finite observer synchronization event [PAGE 7–8]. The absorbing dead state is the unique fixed point, and by construction it is "naturally an undesired state" [PAGE 17], so the system never rests there.
