Complexity lineage: time/space complexity from Hartmanis & Stearns [1965] and Hartmanis, Lewis & Stearns [1965]; Savitch's theorem from Savitch [1970]; abstract measures from Blum [1967] (Blum's two axioms, [PAGE 329]); the gap/speed-up/union theorems from Borodin, Trakhtenbrot, Blum, McCreight & Meyer ([PAGE 319]). NP-completeness: Cook [1971b] "The complexity of theorem proving procedures," with the SAT reduction of Theorem 13.1 ([PAGE 341]), and the catalogue of Karp [1972] ([PAGE 375]). PSPACE-completeness: Stockmeyer [1974] for QBF, Meyer & Stockmeyer [1973] for the first provably exponential-space problem ([PAGE 375]).

**Multi-week traps (pedagogical and research dead-ends the text flags):** (i) The naive pumping lemma "is of no help" for languages like $L_3$ ([PAGE 145]) — a trap that costs weeks before one discovers Ogden's lemma. (ii) The "single instance" trap: problems with one instance are "trivially decidable" (Fermat's-conjecture example, [PAGE 179]) — undecidability requires infinitely many instances. (iii) The linear-speed-up theorem "does not apply if $T(n)$ is a constant multiple of $n$" ([PAGE 307]) — a boundary condition routinely forgotten. (iv) The equivalence problem for DCFLs "is an important unresolved problem" ([PAGE 247]), later resolved (Sénizergues) but open in 1979 — a genuine multi-decade trap.

<RECURSIVE_THEORY_OF_MIND>
Model the "adversary" as an agent playing the pumping-lemma quantifier game ([PAGE 73]); the "clock" as the resource bound; the "counter-trap" as a diagonal construction that defeats a whole class of strategies.

**Crisis/habit regression.** A one-tape TM that "accepts … to the right of the cells on which its input was originally written" and repeats a crossing sequence between two cells is forced into a fixed behavioral loop (Exercise 12.1, [PAGE 331]) — the machine "regresses" to a periodic habit detectable by finite crossing-sequence analysis ([PAGE 209], Example 8.5: scanning a cell $\ge 4$ times is decidable precisely because a repeated crossing sequence traps the machine).

**Counter-trap (diagonal defeat).** Given any proposed decider, the diagonalizer constructs an input on which it must fail: "$w_i\in L_d$ iff $M_i$ does not accept $w_i$" ([PAGE 199]). Rice's theorem generalizes the trap to *every* nontrivial property of $L(M)$ ([PAGE 205]). The oracle construction of Theorem 13.18 is the sharpest counter-trap: "we can construct $B$ so that the string of each length … is so cleverly hidden that a DTM with oracle $B$ cannot find it in polynomial time," giving an oracle with $\mathrm{P}^B\neq\mathrm{NP}^B$ ([PAGE 381]).

**Clock.** The halting clock (Lemma 12.1): "$M$ sets up a counter of length $\log n$, and counts in base $4st$ … if $M$ loops having used only $i$ tape cells, then the counter will detect this" ([PAGE 297]). In Theorem 13.18 the adversary's clock is explicit: "the simulation of $M_i'$ on $0^i$ continues for $i^{\log i}$ steps," and the counting bound $\sum_{j=1}^{i} j\log j < i^{1+\log i} < 2^i$ for $i>32$ guarantees an unhidden word survives ([PAGE 381]). The recursion theorem (Sm$n$ + fixed point, [PAGE 223–225]) is the meta-move that lets a machine "know its own code" — the deepest counter-trap, used to show a formal system $F$ cannot prove its own TM's halting behavior ([PAGE 225], Example 8.10).
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Since there is no physical/biomechanical/weather layer, "cross-layer veto" = equivalence and collapse theorems that **forbid** over-claiming computational power or decidability.

**V1 (power veto).** Nondeterminism does *not* raise FA power: NFA $=$ DFA ([PAGE 39–43]); $\varepsilon$-moves add nothing ([PAGE 43]); two-way FA $=$ FA (Theorem 2.5, crossing sequences, [PAGE 55]). Proof: any claimed 2NFA-only language is vetoed by the crossing-sequence equivalence to an NFA. For PDAs the veto *fails* — nondeterministic PDA $\supsetneq$ DPDA (e.g., $\{ww^R\}$ and $\{0^n\}\cup\{0^n1^{2n}\}$ are CFLs accepted by no DPDA, [PAGE 113, PAGE 265]).

**V2 (decidability veto).** Rice's theorem vetoes deciding any nontrivial semantic property of r.e. sets — "emptiness, finiteness, regularity, context-freedom" are all undecidable ([PAGE 205]). Post's Correspondence Problem is undecidable ([PAGE 209]), and it vetoes deciding CFG ambiguity, $L(G_1)=L(G_2)$, $L(G)=\Sigma^*$ (Theorem 8.11–8.12, [PAGE 219]).

**V3 (lower-bound veto).** The linear speed-up theorem bounds how much a constant factor can be "recovered": for $\inf T(n)/n=\infty$, $\mathrm{DTIME}(T(n))=\mathrm{DTIME}(cT(n))$ ([PAGE 307]); but at $T(n)=\Theta(n)$ this veto weakens to only $(1+\varepsilon)$ factors (Theorem 12.4, [PAGE 307]). Physical analog: you cannot compress space below the constant-factor floor (Theorem 12.1, tape compression, [PAGE 289]).

These vetoes compose: closure non-results are themselves vetoes — CFLs are *not* closed under intersection or complement (Theorem 6.4 and corollary, [PAGE 151]), which is precisely the property used to prove a language is *not* a DCFL (Example 10.1, [PAGE 239]).
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Three verifiable (checkable-against-text) counterfactual vetoes, each with a falsifiable prediction. "Reward" = a proof certificate exists in the cited pages.

**CV-1: "Suppose $L_d$ were recursively enumerable."** Then $\overline{L_d}$ would be r.e. too, and by the reduction $L_d \le_m L_u$ (Fig. 8.5, [PAGE 201]) $L_u$ would be recursive — contradicting Theorem 8.5. *Veto:* Lemma 8.1, "$L_d$ is not r.e." ([PAGE 199]). *Prediction (verifiable):* any TM $M_j$ proposed to accept $L_d$ must fail on the diagonal input $w_j$ — running $M_j$ on $w_j$ and checking acceptance against $w_j$'s membership flips the answer, exhibiting the contradiction concretely.

**CV-2: "Suppose the CFLs were closed under intersection."** Then $L_1\cap L_2$ with $L_1=\{a^ib^jc^k d^i\}$, $L_2=\{a^ib^jc^j d^k\}$ (both CFLs, [PAGE 151]) would be a CFL; but the intersection is $\{a^nb^nc^nd^n\}$, killed by the CFL pumping lemma applied to $a^nb^nc^nd^n$ (the pumped $vx$ cannot span both the $a$-block and $c$-block since $|vwx|\le n$, [PAGE 143]). *Veto:* Theorem 6.4, CFLs "are not closed under intersection" ([PAGE 151]). *Prediction:* the complement of a CFL is not always a CFL (DeMorgan corollary), so any claimed CFG for $\overline{\{a^nb^nc^nd^n\}\text{-style}}$ intersection must fail the pumping test.

**CV-3: "Suppose there is a relativizing proof that $\mathrm{P}=\mathrm{NP}$."** A relativizing argument would hold for all oracles $A$. But Baker–Gill–Solovay-style separation is present: there exists oracle $B$ with $\mathrm{P}^B\neq\mathrm{NP}^B$ via $L=\{0^i\mid B\text{ has a word of length }i\}\in\mathrm{NP}^B\setminus\mathrm{P}^B$ (Theorem 13.18, [PAGE 381]). *Veto:* any proof technique that is invariant under adding oracles cannot resolve $\mathrm{P}\overset{?}{=}\mathrm{NP}$. *Prediction (verifiable):* simulate the diagonal against oracle $B$; the polynomial clock $i^{\log i}$ is beaten because $B$ hides its length-$i$ witness among $2^i$ candidates while the DTM can query only $\mathrm{poly}(i)$ of them — the counting bound $2^i > i^{1+\log i}$ for $i>32$ ([PAGE 381]) is the checkable certificate.

**Bonus falsifier (information units).** Predict $\log_2 N_{\text{conf}}(n)=\Theta(S(n))$ bits per configuration ([PAGE 297/379]); verify by plugging $S(n)=\log_2 n$ to get $N_{\text{conf}}=\mathrm{poly}(n)$, i.e., $\mathrm{NSPACE}(\log n)\subseteq\mathrm{DTIME}(n^{O(1)})$ — matching Theorem 12.10's configuration-graph reachability argument. Any claim that $\mathrm{NSPACE}(\log n)$ requires super-polynomial time contradicts this bit-count and is vetoed.
</RLVR_COUNTERFACTUAL_VETOES>
