All equations below are stated with the source’s definitions. Units are explicit where the source permits them; where the source does not state coordinate units, I mark the unit as coordinate-dependent rather than inventing SI values.

1. Total-body bounding-box volume. The source defines an axis-aligned rectangular prism from minimum and maximum joint coordinates and gives “Volume = w × h × d” [PAGE 6]. Formally, for joint coordinates \(\{(x_i,y_i,z_i)\}_{i=1}^{n}\) at frame \(t\),
\[
V_{\mathrm{bb}}(t)=\left(\max_i x_i-\min_i x_i\right)\left(\max_i y_i-\min_i y_i\right)\left(\max_i z_i-\min_i z_i\right).
\]
Units: \([L^3]\) if coordinates are in length units; otherwise coordinate-units cubed. The paper normalizes this by player height \(H\): “normalised by dividing by the cube of each player’s height” [PAGE 9], giving
\[
\tilde V_{\mathrm{bb}}(t)=\frac{V_{\mathrm{bb}}(t)}{H^3},
\]
which is dimensionless. Assumptions: all tracked joints belong to one player; the bounding box is axis-aligned; min/max are computed per frame. Singularity/breakdown: \(H=0\) or missing height makes \(\tilde V\) undefined; degenerate joints (all points collinear or coincident) make one or more extents zero, so \(V_{\mathrm{bb}}=0\); tracking-ID swaps or occlusion can inflate or collapse the box; the box is sensitive to a single outlier joint because it uses extrema, not robust quantiles.

2. Upper-body convex-hull volume. The source uses “the ConvexHull class from the scipy.spatial module” and defines the hull as “the smallest convex shape that can enclose a set of points in three-dimensional space” [PAGE 6]. For selected upper-body points \(P_t=\{p_1,\dots,p_m\}\),
\[
V_{\mathrm{hull}}(t)=\mathrm{Vol}\!\left(\mathrm{conv}(P_t)\right).
\]
Units: \([L^3]\) or coordinate-units cubed; normalized analogously by \(H^3\) if used. Assumptions: \(m\ge 4\); points are not all coplanar; joint identities are correct. Singularity/breakdown: fewer than four non-coplanar points gives zero or undefined 3D hull volume; coplanar points give zero volume; missing wrists/thumbs/fingers under occlusion distort the hull; the convex hull is convex by construction, so it cannot represent concave postural shape and is sensitive to extreme joints.

3. Body-bend and face-tilt angles. The source states that body-bend angle is “the angle between the vector from the mid-hip to the neck and the vertical Z-axis,” while face-tilt angle is “the angle between the vector from the neck to the nose and the vector from the hip to the neck” [PAGE 6]. The vector angle is computed by the dot-product formula:
\[
\theta=\cos^{-1}\!\left(\frac{\vec v_1\cdot \vec v_2}{\|\vec v_1\|\,\|\vec v_2\|}\right)
=\cos^{-1}\!\left(\frac{x_1x_2+y_1y_2+z_1z_2}{\sqrt{x_1^2+y_1^2+z_1^2}\sqrt{x_2^2+y_2^2+z_2^2}}\right),
\]
with radians converted by “θ° = θ · 180/π” [PAGE 7]. Units: radians, then degrees. Assumptions: both vectors are nonzero and normalized; the arccos argument lies in \([-1,1]\). Singularity/breakdown: \(\|\vec v_1\|=0\) or \(\|\vec v_2\|=0\) makes the angle undefined; floating-point roundoff can push the ratio slightly outside \([-1,1]\), requiring clamping; pose jitter near collinearity makes the angle unstable; body-bend uses a global vertical axis, so camera/world-coordinate calibration errors propagate directly.

4. Instantaneous speed. The source computes distance between successive frames and divides by the temporal interval: “The distance traversed between successive frames was utilised, with the resultant figure subsequently being divided by the temporal interval between said frames” [PAGE 7]. Formally,
\[
v_t=\frac{d_t}{\Delta t},
\]
where \(d_t=\|\mathbf r_{t+\Delta t}-\mathbf r_t\|\) in the horizontal plane if 2D positional data are used. Units: \([L\,T^{-1}]\); with 50 Hz sampling, \(\Delta t=0.02\ \mathrm{s}\) [PAGE 3], so if positions are in metres, \(v_t\) is in m/s. Assumptions: frame timestamps are uniform and correctly ordered; player identity is stable across frames. Singularity/breakdown: \(\Delta t=0\) or duplicate timestamps makes \(v_t\) undefined; tracking swaps create false jumps; occlusion gaps create missing or interpolated positions; pitch-coordinate calibration errors scale speed linearly.

5. Linear mixed-effects model. The source uses “linear mixed-effects models (LMMs)” with “play context as a fixed effect and player ID as a random intercept,” and Type III F-tests with Satterthwaite approximation [PAGE 9]. A minimal formal model is
\[
y_{ij}=\beta_0+\beta_{\mathrm{context}(j)}+\mu_i+\varepsilon_{ij},\qquad
\mu_i\sim\mathcal N(0,\sigma_\mu^2),\quad
\varepsilon_{ij}\sim\mathcal N(0,\sigma^2),
\]
where \(i\) indexes player and \(j\) indexes event/context observation. Effect sizes are reported as omega-squared, \(\omega^2\), dimensionless variance proportions. Reported examples: total-body volume \(F(2,117)=104.2,\ p<0.001,\ \omega^2=0.63\) [PAGE 10]; upper-body hull \(F(2,114)=38.6,\ p<0.001,\ \omega^2=0.39\) [PAGE 10]; body-bend angle \(F(2,120)=62.2,\ p<0.001,\ \omega^2=0.5\) [PAGE 12]; face-tilt angle \(F(2,107)=49.1,\ p<0.001,\ \omega^2=0.47\) [PAGE 12]; speed \(F(2,117)=90.5,\ p<0.001,\ \omega^2=0.6\) [PAGE 13]; subjective NVB score \(F(2,115)=231.9,\ p<0.001,\ \omega^2=0.8\) [PAGE 13]. Assumptions: conditional residuals are normal and homoscedastic; random intercepts are Gaussian; fixed-effect structure is correctly specified. Singularity/breakdown: \(\sigma_\mu^2\to 0\) gives a singular fit and collapses toward pooled regression; missing random slopes can bias context contrasts; log or square-root transformations require positive or nonnegative supports respectively; influential outliers can dominate small event sets.

6. Repeated-measures correlation and PCA. The source uses repeated-measures correlation because “the same player appeared in different scenes, resulting in non-independence of observations within each player” [PAGE 10]. Correlation coefficients \(r_{\mathrm{rm}}\) are dimensionless; the paper interprets \(r_{\mathrm{rm}}=0.1,0.3,0.5\) as small, medium, large [PAGE 10]. PCA is run after “z-score normalisation (mean = 0, standard deviation = 1)” [PAGE 10]; the first component explains “approximately 92% of the total variance” [PAGE 13]. Assumptions: linear association; sufficient within-player variation; PCA linearity. Singularity/breakdown: zero within-player variance makes \(r_{\mathrm{rm}}\) undefined; a zero-standard-deviation rating makes z-scoring undefined; PCA is unstable with tiny samples or near-perfect collinearity, and the first component is not a validated psychological scale.
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
The scientific lineage is explicit and partly retrocausal. The paper begins with Watzlawick’s axiom that “one cannot not communicate” [PAGE 2], then moves through the face-first tradition of FACS and automated facial analysis, the body-coding tradition of BAP and the Nonverbal Behaviour Coding System for Soccer Penalties (NBCSP), and the newer computer-vision tradition of 3D pose estimation. The stated historical problem is methodological lag: facial coding matured faster because whole-body movement has more degrees of freedom; motion capture is laboratory-bound; manual body-coding systems are training-intensive [PAGE 2]. The paper positions 3D pose as the next step in that genealogy.

The Brunswik lens model is the key retrocausal operator. The paper says the design “draws inspiration from Brunswik’s lens model” and distinguishes “cue validity” from “cue utilisation” [PAGE 3]. Historically, this is a mid-20th-century perceptual-ecology framework later imported into social perception and sport NVB. The retrocausal risk is that a modern computational pipeline can make the lens model look more mechanistic than it is: a geometric feature becomes a “cue,” a rating becomes “utilisation,” and a correlation becomes “validity.” The source does not establish the full lens-model chain because the criterion — the player’s actual psychological state — is unobserved. Observers’ ratings are not an external criterion; they are another lens.

A second lineage is the power-pose and dominance-posture literature. The paper cites Carney et al. (2005, 2010) for expansive postures and dominance/confidence, and Keltner and Tracy–Matsumoto for shame/embarrassment postures [PAGE 4–5]. A multi-week genealogy trap is to treat this lineage as settled. The power-posing literature has had replication and mechanism debates outside the source; the present paper uses it as theoretical motivation, not as a tested mechanism. The retrospective danger is to read the scoring-team expansiveness result as confirming a causal posture-to-power pathway, when the design cannot separate posture from scoreline, celebration, tactical role, or fatigue.

A third lineage is the “thin slices” tradition. The paper justifies 10 s windows by research showing “brief ‘thin slices’ of several seconds are sufficient for reliable evaluations of athletes’ NVB” [PAGE 4]. This is a strong inheritance: it licenses short clips, but it also imports the assumption that short windows contain diagnostic signal. The multi-week trap is to keep shortening or re-slicing windows until the desired effect appears, then present the final window as theoretically motivated. The source’s windows are fixed at 10 s post-goal and 20 s around kick-off/end, which is better than post hoc slicing, but the event set remains hand-selected.

A fourth lineage is the “first study” claim. The abstract calls the work an “inaugural investigation” [PAGE 1], and the introduction says “to the best of our knowledge, this is the first study” linking human judgments to 3D-pose features from actual football matches [PAGE 3]. “First” claims are genealogically fragile: they depend on database coverage and on how “3D pose,” “actual match,” and “human judgment” are defined. A multi-week trap is to defend the novelty claim by narrowing the comparison set after the fact. The safer reading is that the paper is an early demonstration within a specific pipeline, not a priority claim over all prior NVB or sports-vision work.

A fifth lineage is the statistical one: LMMs, Satterthwaite degrees of freedom, omega-squared, repeated-measures correlation, and PCA. These are mature tools, but their combination creates a multi-week “garden of forking paths”: transform choice, outlier handling via Cook’s distance, model simplification, PCA retention, and aggregation level can all change the apparent result. The source reports that assumptions were checked with Q-Q plots and residual plots and that transformations were applied “where necessary” [PAGE 9]. That is appropriate, but it also means the analysis space is not fully pre-specified in the article body. The genealogy of the result therefore includes analyst degrees of freedom, not only the historical theories.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
The recursive theory-of-mind structure has three levels. Level 0 is the player’s internal state: confidence, shame, dominance, or valence after scoring or conceding. Level 1 is the observer’s inference: participants watch a short clip and rate the player on four scales. Level 2 is the researcher’s inference about observers: the PCA-derived “subjective NVB score” is treated as a summary of what observers perceived. Level 3 is the model’s inference about the researcher’s inference: the objective features are claimed to capture expressive behaviour “meaningful to human observers” [PAGE 16]. The paper is careful enough to call this cue utilisation, but the prose sometimes slides toward treating observer ratings as ground truth.

Crisis habit regression is the most plausible mechanism story. A goal is a high-stakes, goal-conducive or goal-obstructive event; the paper invokes appraisal and self-regulation theory and says a scored goal is “likely to be appraised by the team as goal-conducive” while a conceded goal is “goal-obstructive” [PAGE 4]. Under that crisis, players may regress to habitual nonverbal routines: expansive, upward, faster behaviour after scoring; contracted, withdrawn, slower behaviour after conceding. The data are consistent with that pattern: scoring-team players show larger normalized volumes, larger upper-body hulls, faster instantaneous speed, and higher subjective NVB scores; conceding-team players show smaller volumes, smaller hulls, slower speed, larger face tilt, and lower subjective scores [PAGE 10–14]. But the body-bend result breaks the simple habit-regression story: conceding players were more upright, not more forward-leaning, and the authors call it “unanticipated” [PAGE 16]. A recursive account must therefore allow context-specific habits — e.g., upright scanning or reactive braking after conceding — rather than a single shame posture.

The counter-trap is circular validation. If observers use the same visible geometry that the algorithm computes, then a high objective–subjective correlation is expected even if neither tracks the player’s actual psychological state. The observer is not an independent thermometer; the observer is another decoder of the same 3D skeleton or tactical crop. The paper’s strongest counter-trap evidence would be a dissociation: a feature that predicts observer ratings but not actual performance, or a feature that predicts actual performance but not ratings. The source does not provide an external performance or self-report criterion, so the counter-trap remains open.

The clock is the temporal frame. Goals are clipped to “only the 10 s immediately following the goal” [PAGE 4], while kick-off/end windows are 20 s. Participants see 50 clips in random order [PAGE 9], so the observer’s judgment is a thin-slice snapshot, not a trajectory. This matters for recursive ToM because nonverbal emotion unfolds: celebration, realization, restart, and tactical reorientation can occur within the same 10 s. A single mean over frames erases the clock. The paper’s use of mean values per player and event is defensible for stability, but it cannot distinguish an immediate reaction from a strategic display. The recursive inference “observer sees player’s state” is therefore really “observer sees a 10 s average of a multi-phase social event.”
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
A cross-layer veto is a condition under which a higher-layer claim — e.g., “scoring causes expansive NVB” or “3D pose metrics are ecologically valid” — must be rejected or downgraded because a lower-layer physical, biomechanical, or environmental constraint is not satisfied. The source supplies enough information to define several veto proofs.

Physical-layer veto. The 3D keypoints are reconstructed from video, and the paper admits “3D pose estimation from video can be affected by inaccuracies, particularly in cases of player occlusion, which may introduce noise” [PAGE 16]. If a player’s joints are occluded by other players or the camera angle, then \(V_{\mathrm{bb}}\), \(V_{\mathrm{hull}}\), \(\theta_{\mathrm{bend}}\), \(\theta_{\mathrm{tilt}}\), and \(v_t\) are not measurements of that player’s body; they are measurements of the reconstruction error. A valid veto condition is: if a non-trivial fraction of frames in a scoring/conceding contrast has low keypoint confidence or track discontinuity, the contrast cannot be interpreted as NVB until the pipeline is re-run with occlusion-aware filtering. The source does not report per-frame confidence thresholds or occlusion rates in the main text, so this veto is not discharged by the article alone.

Biomechanical-layer veto. Body-bend angle is constrained by joint limits and by the definition of the mid-hip–neck vector relative to vertical; face-tilt angle is constrained by neck–nose geometry. The volume measures are normalized by \(H^3\), but height normalization does not remove limb-length, posture, or anthropometric differences. If two players differ in height or build, \(\tilde V_{\mathrm{bb}}\) and \(\tilde V_{\mathrm{hull}}\) can differ for reasons unrelated to emotion. The source uses FBref height data [PAGE 9], but it does not report measurement error or whether height was available for all 28 players. A biomechanical veto applies when the scoring/conceding contrast is not robust to player-specific anthropometric scaling or when the contrast disappears within-player. The body-bend anomaly is a partial biomechanical warning: the expected shame posture did not appear, so the mapping from angle to state is not mechanically stable.

Weather/environment-layer veto. The source contains no weather variables, no temperature, no wind, no precipitation, no pitch-surface measurement, and no stadium-environment covariate. Therefore any claim that weather explains or does not explain the NVB pattern is untestable from the supplied article. The correct adjudication is a missing-variable veto: weather cannot be ruled out as a confound for speed or posture, but it also cannot be invoked as a proven mechanism. If the match were outdoors, wind and heat could affect movement speed and posture; if the stadium were climate-controlled, the weather channel would be attenuated. The article does not specify enough to decide. A rigorous cross-layer audit must mark weather as “not identified” rather than “controlled.”

The combined veto logic is:
\[
\text{Accept causal NVB claim }C \iff
\begin{cases}
\text{pose confidence and occlusion are below audit threshold},\\
\text{anthropometric normalization is valid and within-player robust},\\
\text{event/score/time confounds are modeled or matched},\\
\text{weather/environment is either measured or explicitly bounded}.
\end{cases}
\]
The source satisfies none of these fully in the main text. It satisfies the descriptive association claim, not the causal cross-layer claim. The strongest defensible statement is conditional: within this single match, this event set, this pose pipeline, and this observer sample, the computed features and observer ratings move together in the reported directions.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
I define three verifiable RLVR-style counterfactual vetoes. Each has a manipulation, a measurable prediction, and a pass/fail rule. These are audit scenarios, not claims that the authors ran them.

Veto 1 — Pose-confidence and occlusion ablation. Manipulation: recompute all features after excluding frames whose keypoint confidence falls below a pre-specified threshold or whose player track shows an identity switch, then rerun the same LMMs. Prediction: if the scoring/conceding volume and speed effects are driven by reconstruction noise, the reported large effects will attenuate; specifically, the 95% CI for the scoring-versus-conceding contrast should include zero, or \(\omega^2\) should fall below the large-effect band. Pass condition for the paper’s claim: the direction and significance survive with occlusion-filtered data. Fail condition: the effect disappears or reverses. This is verifiable because the pipeline can output per-frame confidence and track IDs; the source already warns that occlusion “may introduce noise” [PAGE 16].

Veto 2 — Height-normalization and team-bias counterfactual. Manipulation: replace FBref height normalization with a player-specific skeletal scale estimated from the pose data itself, or with measured anthropometry, and rerun the volume models. Prediction: if the scoring-team expansiveness is an artifact of systematic height or build differences between the teams, the normalized-volume contrast will shrink or lose significance. Pass condition: the scoring-versus-conceding contrast remains in the same direction with a 95% CI excluding zero. Fail condition: the contrast’s CI includes zero after renormalization. This is verifiable because the source states volumes were “normalised by dividing by the cube of each player’s height” [PAGE 9]; changing the denominator is a direct, reproducible perturbation. A secondary prediction: if the effect is robust, the rank order of players by normalized volume should be stable across the two normalization schemes.

Veto 3 — Clock-matched within-player event counterfactual. Manipulation: restrict analysis to players who appear in both a scoring and a conceding event, match windows by match minute and phase (e.g., first 10 s after goal versus post-restart), and add random slopes for event and time. Prediction: if the context effect is a stable player-level response, the within-player scoring-versus-conceding difference should remain in the same direction. If the effect is between-team or between-role confounding, the within-player contrast should attenuate. Pass condition: the within-player contrast’s 95% CI excludes zero and agrees in sign with the pooled model. Fail condition: the within-player CI includes zero or reverses. This is verifiable because the match has four goals and the source identifies the goal times: “Netherlands 1–0 (10′), Netherlands 2–0 (45 + 1′), USA 1–2 (76′), and Netherlands 3–1 (81′)” [PAGE 4]. The same player set can be filtered to those with both scoring and conceding exposure. A further prediction: the subjective NVB score should show the same attenuation pattern if observer ratings are driven by the same context confound; if subjective ratings survive while objective features do not, that is evidence for cue utilization independent of the computed geometry.
</RLVR_COUNTERFACTUAL_VETOES>
