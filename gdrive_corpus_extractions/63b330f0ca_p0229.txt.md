Let the observation operator be \(\mathcal{O}\) and the measurement variance \(\sigma^2_{\text{obs}}\). Veto condition: \(\mathcal{V}_{\text{phys}} = \bot\) if \(\mathcal{O} = \emptyset\) or if \(\sigma^2_{\text{obs}}\) exceeds the signal variance of the factor–consequence association, rendering the first-order estimate unreliable.

2. Biomechanical / cognitive layer. Integrating the second-order confidence distribution \(\int \pi(p)\,u(a|p)\,dp\) imposes a computational and working-memory load. Let \(C_{\max}\) be the agent’s cognitive bound. Veto condition: \(\mathcal{V}_{\text{bio}} = \bot\) if the required integration exceeds \(C_{\max}\), forcing the agent toward a heuristic rather than a full Bayesian update.

3. Weather / contextual layer. Here “weather” denotes the non-stationary environmental context in which the association must hold. Let the training and deployment distributions be \(\mathcal{D}_{\text{train}}\) and \(\mathcal{D}_{\text{deploy}}\). Veto condition: \(\mathcal{V}_{\text{ctx}} = \bot\) if the distributional divergence \(D(\mathcal{D}_{\text{train}} \| \mathcal{D}_{\text{deploy}}) > \delta\), indicating that the empirical proportion from one context does not transfer to another [PAGE 214].

Veto proof: A decision \(a\) is admissible only if
\[
\mathcal{V}_{\text{phys}} \land \mathcal{V}_{\text{bio}} \land \mathcal{V}_{\text{ctx}} = \top.
\]
If any layer returns \(\bot\), the action is vetoed and a robust fallback (minimax regret or satisficing) is triggered. This mirrors Knight’s point that in everyday problems rigorous scientific procedure is excluded, so the decision-maker must explicitly estimate dependability rather than assume a stable probabilistic connection [PAGE 214].

Three verifiable counterfactual veto scenarios with falsifiable predictions:

Scenario 1 — Non-stationarity veto. Estimate \(\hat{p}\) from weeks 1–3 and deploy in week 4. The veto triggers if a two-sample Kolmogorov–Smirnov test between the weekly outcome distributions rejects \(H_0\) at \(\alpha=0.05\). Prediction: decisions executed despite the veto exhibit an out-of-sample log-loss increase \(\Delta L > 0\) relative to the vetoed robust policy, verifiable on a holdout week.

Scenario 2 — Hidden-heterogeneity veto. The a priori rule assumes symmetry \(p=1/k\) across \(k\) categories. The veto triggers if a Pearson chi-square goodness-of-fit test rejects uniformity at \(p<0.01\). Prediction: expected-frequency decisions taken under the veto show calibrated out-of-sample error \(\left| \hat{p}_{\text{out}} - 1/k \right| > \epsilon\), verifiable via a contingency-table holdout.

Scenario 3 — Knightian diffuse-belief veto. The posterior confidence \(\pi(p)\) has differential entropy \(H[\pi] > H_{\text{crit}}\), or the admissible set \(\mathcal{P}\) contains measures that induce rank reversal among candidate actions. The veto triggers expected-utility maximization and forces a minimax-regret action. Prediction: the minimax agent incurs lower maximum regret than an agent that forces a point estimate \(\hat{p}\), verifiable via simulated decision trees with known payoff matrices and misspecified likelihoods. All three scenarios are falsifiable because each specifies a test statistic, a threshold, and a directional out-of-sample prediction.
