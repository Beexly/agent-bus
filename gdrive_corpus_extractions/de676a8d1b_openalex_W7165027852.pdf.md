This audit treats the manuscript as an edge-perception control law rather than as a conventional detector/tracker report. The central claim is not merely that a network detects players, but that detection, association, scheduling, and compression co-adapt so that a sports multi-object tracking (MOT) system can remain inside an edge power/thermal envelope while preserving identity continuity. The derivation therefore proceeds through five coupled layers: (i) detector arithmetic cost, (ii) tracker state propagation and association, (iii) keyframe scheduling, (iv) asynchronous latency accounting, and (v) quantization/pruning memory and power. The paper’s strongest evidence is the integration of these layers; its weakest evidence is the absence of a fully closed accounting that reconciles all reported numbers, especially across Tables 4–6.

Start with the latency layer. The paper defines end-to-end synchronous latency as  
\[
T_{\text{total}} = T_{\text{pre}} + T_{\text{det}} + T_{\text{assoc}} + T_{\text{post}}
\]
and asynchronous keyframe latency as  
\[
T_{\text{async}} = T_{\text{pre}} + \max(T_{\text{det}},T_{\text{assoc}}) + T_{\text{post}},
\]
with mixed-sequence average  
\[
\overline{T} = rT_{\text{async}} + (1-r)(T_{\text{pre}}+T_{\text{assoc}}+T_{\text{post}}).
\]
These appear on [PAGE 27]. For the Orin Nano INT8 row, the paper reports \(T_{\text{det}}=8.3\) ms, \(\overline{T}=14.7\) ms, FPS \(=68.0\), and model size 5.8 MB [PAGE 28]. It also states that association “never exceeds 2.1 ms even with 20+ active tracks” [PAGE 29]. The adaptive keyframe table gives an average trigger ratio of 34.6% [PAGE 29]. If we set \(r=0.346\), \(T_{\text{det}}=8.3\) ms, and conservatively \(T_{\text{assoc}}=2.1\) ms, then solving the mixed-latency equation gives an implied residual \(T_{\text{pre}}+T_{\text{post}}\approx 10.45\) ms. This residual is not directly reported, but it is necessary to reconcile the 14.7 ms average. The arithmetic is consistent with 68.0 FPS because \(1000/14.7\approx 68.0\). This is a meaningful gray zone: the paper’s headline FPS is credible under the mixed keyframe regime, but it depends on a non-keyframe fraction that collapses under sustained high motion.

The same latency equations expose a second gray zone in the synchronous baseline. If the implied residual \(T_{\text{pre}}+T_{\text{post}}\approx 10.45\) ms is correct and the detector/association costs remain 8.3 ms and 2.1 ms, then a fully synchronous keyframe would cost about \(10.45+8.3+2.1=20.85\) ms, or about 48 FPS. 1. Depthwise separable convolution cost ratio.  
[PAGE 7] states: “MobileNet v1 introduced depthwise separable convolutions” and gives  
\[
R = \frac{C_{\text{in}}K^2HW C_{\text{out}}}{C_{\text{in}}K^2HW + C_{\text{in}}C_{\text{out}}HW}.
\]
Units: numerator and denominator are multiply-accumulate counts; \(R\) is dimensionless. After cancellation,  
\[
R = \frac{K^2 C_{\text{out}}}{K^2 + C_{\text{out}}}.
\]
Breakdown/singularity: if \(C_{\text{out}}=0\), the ratio is undefined; if \(K=1\), \(R=1\), so no saving; as \(C_{\text{out}}\to\infty\), \(R\to K^2\), explaining the approximate \(K^2\) reduction for large output channel counts. The expression assumes dense convolution, no grouped convolution, and no activation memory.

2. Inverted residual block cost.  
[PAGE 7] gives  
\[
\mathrm{MACs}_{\text{inv}} = HW C_{\text{in}}(2t C_{\text{in}} + tK^2).
\]
Units: MACs per block. \(t\) is dimensionless expansion factor; \(K\) is kernel side length. Breakdown: if \(t<1\), the block is no longer expanding; if \(C_{\text{in}}=0\), cost vanishes; if hardware lacks efficient pointwise or depthwise kernels, theoretical MAC savings may not translate to latency.

3. Kalman prediction/update.  
[PAGE 9] states: “the standard discrete-time prediction and update steps are given by the well-known formulations” and provides  
\[
\hat{x}_{k|k-1}=Fx_{k-1}+Bu_k,\quad P_{k|k-1}=FP_{k-1}F^T+Q,
\]
\[
K_k = P_{k|k-1}H^T(HP_{k|k-1}H^T+R)^{-1},\quad
x_k = \hat{x}_{k|k-1}+K_k(z_k-H\hat{x}_{k|k-1}).
\]
Units: \(x_k\) may contain position in meters or pixels, velocity in m/s or px/frame, and scale; \(P,Q,R\) are covariances in squared state units; \(z_k\) is measurement in observation units. Breakdown: \(Q\) and \(R\) must be positive definite/semidefinite for stable covariance propagation; \(HPH^T+R\) must be invertible. If \(P\) becomes ill-conditioned, Mahalanobis distances become unstable. The paper itself notes that “abrupt nonlinear accelerations common in competitive play violate the constant-velocity assumption embedded in standard Kalman motion models” [PAGE 10].

4. Hungarian association.  
[PAGE 9] gives  
\[
\sigma^* = \arg\min_{\sigma}\sum_{i=1}^{\min(M,N)} C_{i,\sigma(i)}.
\]
Units: cost \(C\) is dimensionless if built from IoU/Mahalanobis terms after normalization. Breakdown: if \(M\neq N\), dummy nodes or padding are required; if multiple assignments tie, the optimum is non-unique; if the cost is non-metric or discontinuous, assignment may oscillate frame-to-frame.

\[
x_q = \operatorname{clamp}\left(\left\lfloor \frac{x}{s}\right\rfloor + z, 0, 2^b-1\right),
\]
\[
\epsilon = |x-s(x_q-z)| \le \frac{s}{2}.
\]
Units: \(x\) has signal units; \(s\) has signal units per quantization step; \(z\) is integer; \(x_q\) is integer; \(\epsilon\) has signal units. Breakdown: if \(s=0\), the mapping is singular; if values lie outside calibration range, clamp saturation can make error exceed \(s/2\); if \(b\) is too small, representational capacity collapses.

Units: nats if natural logarithm is used; bits if log base 2 is used. Breakdown: if \(P_{\text{int8}}(a_i)=0\) where \(P_{\text{fp32}}(a_i)>0\), divergence is infinite; if calibration samples miss activation modes, scale estimates become unstable.

I_{l,j} = \sum_{c=1}^{C_{\text{in}}}\sum_{k_h}\sum_{k_w}|W_{l,j,c,k_h,k_w}|.
\]
Units: weight units. [PAGE 19] gives

\(p\) is dimensionless pruning ratio. Breakdown: if \(p\to 1\), the network loses representational capacity; if pruning crosses residual connections or detection heads, accuracy may collapse nonlinearly. Units: dimensionless loss; feature maps \(\phi\) must have matching spatial dimensions or require resampling. Breakdown: if \(\gamma\) is too large, the student overfits teacher feature space and may underperform on domain shift; if class/reg branches are imbalanced, localization may degrade.

The paper correctly identifies the sports failure mode: teammates share appearance, and nonlinear motion violates constant-velocity assumptions [PAGE 10]. Its counter-lineage is motion-consistency association, buffering unmatched tracks for up to three frames, and removal of a dedicated Re-ID network [PAGE 16].

The third lineage is edge inference optimization: TensorRT, ONNX Runtime, OpenVINO, INT8 quantization, structured pruning, and knowledge distillation [PAGE 10]–[PAGE 11], [PAGE 17]–[PAGE 18]. The paper’s historical contribution is not a new quantization algorithm but a deployment pipeline tailored to sports MOT: hardware-aware NAS, latency-aware loss, pruning, INT8 calibration, distillation, and asynchronous scheduling [PAGE 17]–[PAGE 18].

<RECURSIVE_THEORY_OF_MIND>
The relevant recursive agents are: (1) the live-match practitioner, (2) the edge-deployment engineer, (3) the sports-analytics researcher, and (4) the manuscript author anticipating reviewer objections. Each has a crisis habit and a clock.

The practitioner’s crisis is live latency. The paper says cloud inference delay “can swing between 40 and 200 ms depending on stadium connectivity” [PAGE 5]. Under match pressure, the habitual regression is to add a larger detector, send frames to the cloud, or attach a heavier Re-ID model. This habit feels safer because it targets identity confidence directly, but it violates the stated deployment envelope: “a power envelope often below 15 W on stadium-mounted accelerators” [PAGE 5]. The paper’s counter-trap is co-design: reduce detection frequency, replace appearance association with motion-consistency, and overlap detection with tracking [PAGE 15]–[PAGE 16].

The engineer’s crisis is thermal and memory boundedness. The habit is to assume that any TensorRT INT8 engine will fit and run. The counter-trap is to measure \(T_{\text{det}}\), \(\overline{T}\), model size, and power on the actual device [PAGE 28]. The clock is explicit: at 30 fps, the frame period is 33.3 ms; at 60 fps, it is 16.7 ms. The reported \(\overline{T}=14.7\) ms supports 68 FPS under mixed keyframe operation, but only if the asynchronous max assumption holds and the keyframe ratio remains near 34.6% [PAGE 28]–[PAGE 29].

The researcher’s crisis is benchmark transfer. The paper notes that trackers tuned on MOT17 can lose “12 to 18 points” of IDF1 on SportsMOT without retraining [PAGE 4]. The habit is to trust pedestrian Re-ID datasets. The counter-trap is to model sports-specific constraints: uniform appearance, nonlinear acceleration, and dense clusters [PAGE 5]–[PAGE 6], [PAGE 10].

The author’s recursive move is to anticipate the reviewer’s objection that edge latency gains are benchmark artifacts. The counter-move is the asynchronous pipeline and ablation table [PAGE 26], [PAGE 28]. However, the clock still exposes a residual risk: if optical flow exceeds the threshold continuously, the keyframe ratio approaches 1. The paper itself admits that during “sustained fast action—a basketball fast break, for instance—the keyframe interval contracts toward nearly every frame, and the latency savings diminish accordingly” [PAGE 30]. Thus the counter-trap is not universal; it is regime-dependent.

<CROSS_LAYER_VETO_ADJUDICATION>
The physical layer does not veto the paper’s central single-stream claim, but it does impose conditional limits.

Compute and power proof. The claimed detector cost is 3.2 GFLOPs per forward pass [PAGE 14]. At 68.0 FPS, required detector throughput is  
\[
Q_{\text{det}} = 3.2\times 10^9 \times 68.0 = 2.176\times 10^{11}\ \text{operation/s}.
\]
At 9.4 W, the effective energy per operation is  
\[
e = \frac{9.4}{2.176\times 10^{11}} \approx 43.2\ \text{pJ/op}.
\]
This is physically plausible for an INT8 accelerator, though the manuscript does not specify whether “GFLOPs” counts FLOPs, MACs, or TensorRT operations. If the true count is 2× larger because each MAC is counted as two FLOPs, the energy per MAC is still plausible. Therefore no hard physical veto arises for the reported single-stream 1080p30 case, assuming the power measurement is sustained and not a short benchmark sample.

Memory proof. The reported peak activation memory is about 18 MB, and weight storage is about 3.8–5.8 MB depending on accounting [PAGE 19], [PAGE 28]. The Orin NX/Orin Nano class platform is described with 8 GB LPDDR5 [PAGE 19]. The inequality  
\[
M_{\text{weights}} + M_{\text{activations}} \ll M_{\text{device}}
\]
holds by orders of magnitude. Memory is not the veto layer; bandwidth and concurrency are.

Biomechanical layer. The paper states that players can have heterogeneous motion: “a goalkeeper may stay nearly stationary while a winger accelerates past 8 m/s” [PAGE 8]. At 30 fps, 8 m/s corresponds to 0.267 m/frame. Over 15 frames, that is 4.0 m of displacement. If the Kalman model is constant-velocity and detection corrections are absent during occlusion, identity drift becomes likely. The paper explicitly admits failure when “more than 80% of a player's body occluded for over 15 consecutive frames” because “the Kalman prediction accumulates drift without detection corrections” [PAGE 31]. This is a biomechanical veto for prolonged severe occlusion. The three-frame unmatched-track buffer [PAGE 16] is insufficient for 15-frame occlusion.

Weather/environmental layer. The manuscript does not provide rain, fog, snow, or low-light benchmarks. It does acknowledge “abrupt lighting transitions” such as moving “from outdoor sunlight into a shadowed tunnel entrance” and says these cause “transient detection recall drops that the tracker cannot compensate for within a single keyframe interval” [PAGE 31]. Therefore, weather is a conditional veto: clear indoor/outdoor conditions are supportable by the reported experiments; adverse weather or rapid illumination transitions require illumination normalization or emergency keyframes, which are not yet implemented.

Cross-layer adjudication. A veto occurs if any layer forces the closed-loop inequality  
\[
\overline{T} \le T_{\text{frame}}
\]
to fail while identity metrics remain unacceptable. For 30 fps, \(T_{\text{frame}}=33.3\) ms; the reported 14.7 ms average satisfies it. For 60 fps, \(T_{\text{frame}}=16.7\) ms; the reported 14.7 ms still satisfies it only under the mixed keyframe regime. If keyframe ratio rises to 1, the inferred latency becomes \(T_{\text{pre}}+T_{\text{det}}+T_{\text{post}}\approx 18.8\) ms, which fails a strict 60 fps clock. If association no longer overlaps and becomes additive, latency can approach 20.9 ms or more, again failing 60 fps. Thus the physical veto is not the reported nominal case; the veto is the fast-action or contention regime.
</CROSS_LAYER_VETO_ADJUDICATION>
