This forces a first-principles model of a visitor with zero context, limited time, and no founder privileges.

The clock is the 10-second clarity window. In information-theoretic terms, T_comprehend = I_page / R_hum must be ≤ 10 s [PAGE 1]. If the visual design increases I_page (cinematic animations, dense copy, ambiguous hierarchy) without increasing R_hum (familiar sports-native signal language, calm reading states), the user exits before activation. P0 priority compresses the calendar clock, while the 10-second rule compresses the cognitive clock; the two pressures compound. The recursive counter-trap is to treat the Test Plan as an adversarial user model: route probe, mobile viewport screenshot, keyboard/focus check, reduced-motion check, and copy scan are explicit simulations of the public user's constraints [PAGE 1]. Each test asks, "If I were a new user on a mobile device with reduced motion enabled, would I understand this in ten seconds?" If any answer is negative, the change is vetoed before merge.

Betting-line invariant: this theory-of-mind analysis never invokes spreads, totals, moneylines, or odds. The only gambling-adjacent references are the card's own prohibitions on guaranteed-betting language and casino/tout feel [PAGE 1], used strictly as boundary constraints.

<CROSS_LAYER_VETO_ADJUDICATION>
Physical, biomechanical, and environmental veto layers with adjudication protocol.

1. Physical layer (device and network). The homepage must function on mobile viewports [PAGE 1]. Physical state variables include screen width W \in [320, 480] CSS px typical for mobile, device pixel ratio dpr, and available bandwidth B [bits/s]. Veto condition V_phys:
\[ V_{\text{phys}} = 1 \iff \text{layout overflows mobile viewport} \lor T_{\text{load}} > T_{\text{budget}} \text{ on low-end device}. \]
Breakdown regime: if the shipping clone's mobile CSS is not inspected before implementation, V_phys cannot be evaluated and the change is assumed unsafe.

2. Biomechanical layer (human-device interaction). Variables: contrast ratio \rho [dimensionless], touch-target area A [CSS px^2], focus-visible state f \in \{0,1\}, reduced-motion preference m \in \{0,1\}. Veto condition V_bio:
\[ V_{\text{bio}} = 1 \iff (\rho_{\text{normal}} < 4.5:1) \lor (\rho_{\text{large}} < 3:1) \lor (A_{\text{touch}} < 44 \times 44) \lor (f = 0 \text{ for interactive elements}) \lor (\text{motion not respected when } m=1). \]
Source: Test Plan requires mobile viewport screenshot, keyboard/focus check, and reduced-motion check [PAGE 1]. Accessibility basics must pass per Acceptance Criteria [PAGE 1].

3. Environmental/weather-analog layer (ambient conditions). Variables: ambient illuminance E [lx], glare G \in [0,1], network stability S \in [0,1]. Though weather does not directly change code, high glare reduces effective contrast and unstable networks increase effective T_load. Veto condition V_env:
\[ V_{\text{env}} = 1 \iff \text{content unreadable at high glare} \lor \text{offline/flaky-network state causes hard failure}. \]
Calm reading states and high contrast [PAGE 1] are the mitigations; if they fail under glare or latency, the layer vetoes.

Adjudication hierarchy. Vetoes are not tradable. The priority order is:
\[ \text{Legal} \succ \text{Accessibility} \succ \text{Performance} \succ \text{Visual polish}. \]
A legal veto (\mathcal{L} = 1 from Section 2) overrides all other layers: even a high-converting, fast, accessible homepage is removed if it contains guaranteed-betting language or affiliate links [PAGE 1]. An accessibility veto overrides performance: a fast homepage that fails contrast or focus management does not ship. A performance veto overrides visual polish: a cinematic homepage that worsens T_load is reverted. Visual polish has no veto power; it may only proceed if all lower-priority layers pass. This hierarchy is consistent with the card's Legal / Compliance Boundary being categorical [PAGE 1] and its Acceptance Criteria listing accessibility and performance as hard gates [PAGE 1].

No betting lines are invoked in this adjudication; the legal layer references the document's own compliance prohibitions only [PAGE 1].
