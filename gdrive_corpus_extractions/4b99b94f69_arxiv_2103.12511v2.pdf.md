<THINK_TRACE>
The source is a nine-page arXiv paper on GCNet, the Global Correlation Network, which claims an end-to-end joint multi-object detection and tracking pipeline for vehicles on UA-DETRAC. The central derivation is not a tracking heuristic; it is a representational substitution. Local convolutional features cannot regress an absolute bounding box when the receptive field is too small, so the paper replaces offset prediction with a global-correlation vector computed between each local query \(Q_{ij}\) and the whole key map \(K\). The paper states: “we want to regression absolute coordinate and size of bounding box rather than relative coordinate or offset” [PAGE 1]. The first hop is Eq. (1): \(Q_{ij}=W_qF_{ij}\) and \(K_{ij}=W_kF_{ij}\) from \(F\in\mathbb{R}^{h\times w\times c}\) [PAGE 1]. The second hop is Eq. (2): for each \(Q_{ij}\), the network forms cosine-normalized interactions with all \(K_{mn}\), flattens them, and applies \(W\) to produce \(C_{ij}\in\mathbb{R}^{c'}\) [PAGE 1-2]. The paper then says these vectors “have been encoded the correlation between local feature vectors \(Q_{ij}\) with global feature map \(K\)” and can regress absolute boxes [PAGE 2]. The third hop is the detection/tracking duality: detection uses same-frame \(Q\) and \(K\), while tracking uses previous-frame \(Q\) and current-frame \(K\) [PAGE 2]. That is the paper’s key conceptual move: one operator serves both localization and identity propagation.

The fourth hop is classification and peak selection. GCNet uses a CenterNet-like confidence map \(Y_d\), and Eq. (3) uses \(3\times3\), stride-1 max-pooling to select peaks “without box non-maximum suppression (NMS)” [PAGE 2]. The fifth hop is the regression branch in Eq. (4): \(K\) is gated by the detection confidence map \(Y_d\), \(Q\) and \(V\) are generated from \(F\), and Eq. (6) combines the correlation vector \(C_{ij}\) with \(V_{ij}\) through batch normalization and a linear map to produce absolute \([x,y,h,w]\) boxes [PAGE 4]. The tracking module is “almost the same” as detection and shares most parameters except a fully connected layer for tracking confidence [PAGE 4]. The sixth hop is lifecycle management: Algorithm 1 updates confidences with \(Y_i=\min(2Y_iY_{t,i},1.5)\), deletes tracks below \(p_2\), promotes detections above \(p_1\), and ignores detections with IoU above \(p_3\) [PAGE 5-6]. The paper sets \(p_1=0.5\), \(p_2=0.3\), \(p_3=0.5\) [PAGE 6].

The gray-zone audit is substantial. First, the phrase “cosine distance” in the prose [PAGE 2] conflicts with Eq. (2), which is a cosine similarity: larger normalized dot products mean greater alignment. Second, Eq. (2) has no stated epsilon, so \(\|Q_{ij}\|\|K_{mn}\|=0\) is a singular regime. Third, Eq. (5) splits the channel index at \(c/2\); if \(c\) is odd, the printed piecewise definition is ill-typed [PAGE 4]. Fourth, “without NMS” is not the same as “without peak suppression”: Eq. (3) still performs max-pooling, so two object centers inside the same \(3\times3\) neighborhood collapse to one peak [PAGE 2]. Fifth, “end-to-end” is qualified by two-stage training: “First, train the detection module, and then fine-tune the entire network” [PAGE 5]. Sixth, “no data association” is qualified by candidate sets, confidence thresholds, deletion rules, and IoU gating in Algorithm 1 [PAGE 5-6]. Seventh, the tracking module is trained with \(I_{t-i}\) and \(I_t\) where “\(i\) is between 1 and 5” [PAGE 5], so the temporal horizon is short and explicit. Eighth, the ablation is “only conducted on the detection benchmark” [PAGE 7], so tracking-component attribution is inferential. Ninth, results are vehicle-specific: UA-DETRAC, 60 training and 40 test sequences [PAGE 6], with no pedestrian or biomechanical validation. Tenth, the reported PR-MOTA of 19.1 is lower than EB+KIOU’s 21.1, even though PR-MOTP is much higher, 57.3 versus 28.6 [PAGE 9]. The claim is therefore strong for precision-like tracking quality but not uniformly dominant across all tracking metrics.

<SOURCE_OPERATORS_AND_EQUATIONS>
The paper’s operators are defined over image tensors and confidence fields; no SI mechanical units are used. Coordinates are image-plane coordinates, box sizes are in the same image-plane units as the input raster, confidence values are dimensionless probability-like scores, AP and MOT metrics are percentages, and FPS is frames per second. The input size is “512 × 896” [PAGE 6], and the finest feature map is \(h'\times w'\times c\) with \(h'=h/8\), \(w'=w/8\) [PAGE 4].

Global correlation operator. For \(F\in\mathbb{R}^{h\times w\times c}\):

\[
Q_{ij}=W_qF_{ij},\qquad K_{ij}=W_kF_{ij}
\]

where \(F_{ij}\in\mathbb{R}^{c}\) is the feature vector at row \(i\), column \(j\) [PAGE 1]. The correlation vector is:

\[
C_{ij}
=
W\cdot
\mathrm{flatten}
\left(
\left[
\frac{Q_{ij}K_{11}}{\|Q_{ij}\|\|K_{11}\|},
\ldots,
\frac{Q_{ij}K_{1w}}{\|Q_{ij}\|\|K_{1w}\|},
\ldots,
\frac{Q_{ij}K_{h1}}{\|Q_{ij}\|\|K_{h1}\|},
\ldots,
\frac{Q_{ij}K_{hw}}{\|Q_{ij}\|\|K_{hw}\|}
\right]
\right)
\]

with \(C_{ij}\in\mathbb{R}^{c'}\) [PAGE 1-2]. Units: the normalized dot products are dimensionless cosine similarities; \(C_{ij}\) is a dimensionless embedding. Assumption: \(Q_{ij}\) and every \(K_{mn}\) are nonzero. Breakdown: if any denominator is zero, Eq. (2) is undefined; the paper gives no epsilon or normalization safeguard. Terminology gray zone: the prose calls this “cosine distance” [PAGE 2], but the equation is cosine similarity.

Peak-selection operator. The paper writes:

\[
B_{ij}\in Result
\quad
\forall i,j
\to
\mathrm{maxpool}(Y,3,1)_{ij}=Y_{ij}
\]

[PAGE 2]. Here \(Y\) is a confidence heatmap, the kernel is 3 cells, stride is 1 cell, and output values are dimensionless confidences. Breakdown: two true centers within the same 3×3 max-pool window produce one surviving peak; the operator therefore depends on object-center separation relative to feature-map resolution.

Regression-branch operators. Eq. (4) is:

\[
Q=\mathrm{BN}_Q(\mathrm{Conv}_Q(F,1,1,c)+P)
\]
\[
K=\mathrm{Gate}[\mathrm{BN}_K(\mathrm{Conv}_K(F,1,1,c)+P),Y_d]
\]
\[
V=\mathrm{Conv}_V(F,1,1,c)
\]

[PAGE 4]. \(\mathrm{Conv}(F,a,b)\) denotes kernel size \(a\), stride \(b\), and \(c\) kernels; \(\mathrm{Gate}\) is a spatial-attention step “similar with sSE block” [PAGE 4]. The position embedding is printed as:

\[
P_{ijk}=
\begin{cases}
\cos\left(\frac{4\pi k}{c}+\frac{\pi i}{h}\right), & 0\le k\lt c/2\\
\cos\left(\frac{4\pi k}{c}+\frac{\pi j}{w}\right), & c/2\le k\lt c
\end{cases}
\]

for \(0\le i\lt h'\), \(0\le j\lt w'\) [PAGE 4]. Units: cosine arguments are dimensionless; \(i,j,k\) are indices. Breakdown: if \(c\) is odd, the \(c/2\) partition is not an integer partition; the paper does not state a parity assumption.

The box output is:

\[
B_{d,ij}=W\cdot \mathrm{BN}\left(\left[C_{ij};V_{ij}\right]\right)
\]

where the printed form concatenates \(C_{ij}\) and \(V_{ij}\), and \(B_{d,ij}=[x_{ij},y_{ij},h_{ij},w_{ij}]\) [PAGE 4]. Units: \(x,y\) are image-plane coordinates; \(h,w\) are image-plane box dimensions. Gray zone: the paper overloads \(h,w\) for image height/width and box height/width. The “absolute” claim is image-absolute, not world-absolute: no camera calibration, ego-motion transform, or metric depth is defined.

Training operators. The Gaussian heatmap target is:

\[
Y_{gt,ijk}=\max_{1\le n\le N_k}(G_{ijn})
\]
\[
G_{ijn}
=
\exp\left[
-\frac{(i-x_n)^2}{2\sigma_{x,n}^2}
-\frac{(i-y_n)^2}{2\sigma_{y,n}^2}
\right]
\]

[PAGE 4]. As printed, the second squared term also uses \(i\); conventional heatmap construction normally uses the column index \(j\), so this is an implementation/typographical gray zone. The variances are:

\[
\sigma_x=\frac{h(1-\mathrm{IoU}_{threshold})}{3(1+\mathrm{IoU}_{threshold})},
\qquad
\sigma_y=\frac{w(1-\mathrm{IoU}_{threshold})}{3(1+\mathrm{IoU}_{threshold})}
\]

with IoU threshold 0.3 [PAGE 5]. Units: \(\sigma_x,\sigma_y\) inherit box-size units; IoU is dimensionless. Breakdown: \(\mathrm{IoU}_{threshold}=-1\) makes the denominator zero; \(\mathrm{IoU}_{threshold}=1\) makes \(\sigma=0\); the fixed 0.3 avoids these singularities. The classification loss is focal loss:

\[
L_{d,cla}
=
-\frac{1}{h'w'n}
\sum_{ijk}
\begin{cases}
(1-Y_{d,ijk})^2\log(Y_{d,ijk}), & Y_{gt,ijk}=1\\
(1-Y_{gt,ijk})^2Y_{d,ijk}^2\log(1-Y_{d,ijk}), & Y_{gt,ijk}\ne 1
\end{cases}
\]

[PAGE 5]. Units: dimensionless. The regression loss is:

\[
L_{d,reg}
=
\sum_{[ij]=1}
\beta_{ij}\cdot L_{CIoU}(B_{gt,ij},B_{d,ij})
\]

[PAGE 5], with assignment:

\[
[ij]=
\begin{cases}
1, & \exists n: G_{ijn}\gt 0.3\ \mathrm{and}\ \sum_n G_{ijn}-\max_n G_{ijn}\lt 0.3\\
0, & \mathrm{otherwise}
\end{cases}
\]

[PAGE 5]. Total loss:

\[
Loss=L_{d,cla}+L_{t,cla}+0.1\times(L_{d,reg}+L_{t,reg})
\]

[PAGE 5]. Units: dimensionless weighted sum. The 0.1 weight is a fixed scalar assumption, not an uncertainty-calibrated coefficient.

Inference confidence operator. The lifecycle update is:

\[
Y_i=\min(2Y_iY_{t,i},1.5)
\]

[PAGE 5]. Units: confidence is dimensionless, but the ceiling 1.5 means the internal score is not a probability after this update; the paper says such tracks “may be greater than 1” [PAGE 5]. Breakdown: if \(Y_i\) or \(Y_{t,i}\) is miscalibrated, repeated multiplication can dominate lifecycle decisions. The thresholds are \(p_1=0.5\), \(p_2=0.3\), \(p_3=0.5\) [PAGE 6]. Algorithm 1 deletes tracks below \(p_2\), deletes candidates below \(p_1\), ignores detections with IoU above \(p_3\), and creates new tracks for remaining detections above \(p_1\) [PAGE 6]. This is not association-free in an absolute sense; it is association-by-shared-operator plus thresholded lifecycle rules.

Performance units. Detection is “74.04% AP and 36 FPS,” tracking is “19.10% PR-MOTA and 34 FPS” [PAGE 1]. Table 2 gives GCNet Full AP 74.04, Easy 91.57, Medium 81.45, Hard 59.43, Sunny 83.53, Night 78.50, Rainy 65.38 [PAGE 8]. Table 3 gives GCNet PR-MOTA 19.1, PR-MOTP 57.3, PR-MT 20.9, PR-ML 9.6, PR-IDS 755.8, PR-FM 994.5, PR-FP 17660.9, PR-FN 148517.5 [PAGE 9]. EB+KIOU has PR-MOTA 21.1 and PR-MOTP 28.6 [PAGE 9], so GCNet is not uniformly superior on every tracking metric.

<RETROCAUSAL_GENEALOGY>
The paper’s lineage is the tracking-by-detection tradition and its partial dissolution. The abstract states: “Most MOT algorithms follow tracking-by-detection framework, which separates detection and tracking into two independent parts” [PAGE 1]. Related work divides detection into anchor-based and anchor-free families, then notes that anchor-based methods “regress offsets between anchor boxes and ground truth by local features,” while anchor-free methods estimate key points and then boxes [PAGE 2]. The transformer line is explicitly present: “DETR [4] adopt an encoder-decoder architecture based on transformers to achieve object detection,” but its self-attention “requires a lot of computation and GPU memory, which is difficult to apply to high-resolution feature maps” [PAGE 2]. GCNet’s global correlation layer is historically positioned between convolutional local regression and transformer global attention: it seeks global information without full self-attention cost. The joint-detection lineage includes FairMOT, RetinaTrack, Chained-Tracker, and CenterTrack-like tracking-as-points, cited in the related-work section [PAGE 3]. GCNet’s own novelty claim is that detection and tracking are “done in the same way” [PAGE 3].

Retrocausally, the paper anticipates later attention-style MOT design while retaining a CenterNet classification head. It says the classification branch uses “the same network structure and training strategy as CenterNet” [PAGE 2] and the backbone uses “the same skip connection structure as FPN, but only output the finest level feature map F” [PAGE 4]. This mixed genealogy matters: the method is not a pure transformer; it is a convolutional detector with a global correlation regression head and a shared-parameter tracking head. The tracking module is “almost the same” as detection, with most parameters shared except the tracking-confidence fully connected layer [PAGE 4]. That sharing is the scientific continuity: identity propagation is not a separate ReID network but a re-use of the same \(Q,K,V\) machinery with previous-frame \(Q\) and current-frame \(K\) [PAGE 2].

The multi-week traps are several. First, benchmark specificity: UA-DETRAC is a vehicle dataset with 100 sequences, 60 training and the rest testing, and the training/test data “come from different traffic scenarios” [PAGE 6]. That is a strength for generalization within traffic, but it is not evidence for pedestrians, sports, or biomechanical motion. Second, the ablation trap: “The ablation study is only conducted on the detection benchmark” [PAGE 7], justified by shared parameters and correlation between detection and tracking. That justification is plausible but not a direct tracking ablation. Third, the metric trap: GCNet’s PR-MOTA is 19.1 versus EB+KIOU’s 21.1, while its PR-MOTP is 57.3 versus 28.6 [PAGE 9]. A careless summary that says “best tracker” without naming the metric is therefore not verifiable from Table 3. Fourth, the end-to-end trap: the paper claims end-to-end joint detection and tracking, but training is two-stage: “First, train the detection module, and then fine-tune the entire network” [PAGE 5]. Fifth, the post-processing trap: “does not need non-maximum suppression, data association, and other complicated tracking strategies” [PAGE 1] coexists with max-pooling peak selection [PAGE 2] and Algorithm 1’s thresholds and candidate lifecycle [PAGE 6]. Sixth, the temporal-horizon trap: tracking training uses \(I_{t-i}\) and \(I_t\) with “\(i\) is between 1 and 5” [PAGE 5], so long-occlusion identity claims exceed the stated training window. Seventh, the weather trap: rainy AP is 65.38 versus full 74.04 [PAGE 8], so “all-weather” is not supported without qualification. These are multi-week traps because each can survive a quick read of the abstract but fails under table-level or equation-level audit.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
This paper contains no recursive theory of mind in the psychological sense: it does not model other agents’ beliefs, intentions, or counterfactual strategies. The audit metaphor must therefore be applied carefully. “Crisis habit regression” here means the model’s habitual fallback under difficult conditions: center-heatmap peak selection, gated \(K\), confidence decay, and thresholded lifecycle rules. “Counter-trap” means the paper’s designed alternative: global correlation for absolute box regression, concatenation of \(V\) for texture/local information, and a cosine position embedding intended to reduce “the negative impact of similar objects when tracking” [PAGE 4]. “Clock” means the discrete frame index and the finite temporal window: detection at frame \(t\), tracking between \(t-i\) and \(t\), and confidence update at each step.

The crisis habit is visible in the architecture. The classification branch produces \(Y_d\), whose peaks correspond to object centers [PAGE 2]. The Gate step uses \(Y_d\) as spatial attention on \(K\) [PAGE 4], which means a classification false negative can suppress the regression branch’s key map. Under occlusion, rain, night, or dense traffic, the model’s first habit is to trust the confidence peak; the second habit is to delete or demote tracks whose updated confidence falls below \(p_2=0.3\) [PAGE 6]. The paper gives a “trust margin” rationale: \(Y_i=\min(2Y_iY_{t,i},1.5)\) gives high-tracking-confidence tracks a margin and allows confidence above 1 [PAGE 5]. That is a clocked habit: each frame multiplies evidence, with a hard ceiling and hard thresholds.

The counter-trap is the global correlation design. The paper explicitly rejects local offset regression for its purpose: “we want to regression absolute coordinate and size of bounding box rather than relative coordinate or offset” [PAGE 1]. It also rejects transformer self-attention on high-resolution maps because of computation and memory [PAGE 2]. The counter-trap is therefore: encode global context through correlation, regress absolute boxes, and reuse the same operator for tracking by changing \(Q\)’s frame. The tracking module “works in an object-wise way, so it can naturally pass the ID of each object to the next frame, which is similar to the parallel single-object tracking (SOT)” [PAGE 4]. That is the strongest identity claim: ID propagation is architectural, not a separate Hungarian-style assignment step.

The clock is the weak point in the recursive audit. Training uses two images \(I_{t-i}\) and \(I_t\), with \(i\in[1,5]\) [PAGE 5]. There is no stated memory bank, no learned long-term re-identification, and no explicit occlusion-reasoning module. The inference loop tracks existing trajectories and candidates, updates \(Q_i=K_{mn}\), \(V_i=V_{mn}\) at the center of the tracked box, and deletes low-confidence entries [PAGE 6]. Thus the model’s “theory” of a disappeared object is not a belief state; it is a candidate set plus a confidence score. If an object is absent longer than the training window or its confidence falls below threshold, the counter-trap can fail and the crisis habit—new-track creation from the next high-confidence detection—takes over. The paper’s own claim that it “does not need ... data association” [PAGE 1] should therefore be read as “does not use a separate assignment solver,” not as “has no identity lifecycle logic.” The recursive audit conclusion is: GCNet is strong at short-horizon, object-wise identity propagation; it is not evidence for long-horizon belief modeling or opponent-aware reasoning.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical-layer veto. The paper’s physical layer is image-plane geometry, not world physics. Bounding boxes are \([x,y,h,w]\) with “absolute coordinates and size” [PAGE 4], but these are absolute in the image frame; no camera intrinsics, extrinsics, ego-motion, or metric depth are defined. The input is \(512\times896\) [PAGE 6], and the finest feature map is \(h/8\times w/8\) [PAGE 4]. Therefore, any claim about metric vehicle speed, physical acceleration, or world-space trajectory is vetoed unless an external calibration layer is added. The paper’s “physical” evidence is limited to image raster geometry and UA-DETRAC boxes. Occlusion and ignore regions are represented in Figure 1, where “black areas indicate areas that are ignored defined in UA-DETRAC” [PAGE 2]. Those regions are a dataset-level veto on crediting detections inside them; they are not a physical occlusion model.

Biomechanical-layer veto. There is no biomechanical layer in this paper. No human pose, gait, joint torque, fatigue, injury, or driver-state variable is defined. The application motivation is “autonomous driving, motion attitude analysis and traffic monitoring” [PAGE 1], and the experiments are vehicle detection and tracking on UA-DETRAC [PAGE 6]. Therefore, any inference about human biomechanics, athlete fatigue, or occupant state is categorically vetoed. The paper cannot support such a claim even indirectly, because its objects are vehicles and its features are convolutional appearance/correlation features. The only “motion” information is implicit in box trajectories and shared \(Q,K,V\) features, not in a biomechanical model.

Weather-layer veto. Weather is tested, but not modeled explicitly. The ablation says GCNet “gets high AP on full, medium difficulty, night, and rainy parts of the test set” [PAGE 7]. Table 2 quantifies: Full 74.04, Medium 81.45, Hard 59.43, Sunny 83.53, Night 78.50, Rainy 65.38 [PAGE 8]. Thus rainy conditions reduce AP by 8.66 points relative to Full, and Hard is the weakest listed condition at 59.43. The paper’s training augmentation includes “random horizontal flip, random brightness adjustment and scale adjustment” [PAGE 6], not a rain-specific physical renderer or weather-adaptive module. The weather veto is therefore conditional: the paper supports “competitive on rainy/night UA-DETRAC,” not “weather-invariant.” Any claim of all-weather robustness beyond this benchmark is vetoed by the rainy AP drop and by the absence of cross-weather training analysis.

Cross-layer adjudication. The valid evidentiary chain is: UA-DETRAC image boxes → shared \(Q,K,V\) features → detection heatmap and tracking heatmap → thresholded lifecycle → reported AP and PR metrics. The invalid chain is: image boxes → metric world state → biomechanical state → weather-invariant guarantee. The paper’s own numbers veto the last two links. The physical layer also vetoes “no post-processing” absolutism because Eq. (3) still performs max-pooling [PAGE 2] and Algorithm 1 still performs IoU and confidence gating [PAGE 6]. The weather layer vetoes “all-weather” absolutism because Rainy AP is 65.38 versus Full 74.04 [PAGE 8]. The biomechanical layer vetoes any human-factor claim because no such variable exists in the source. The strongest defensible cross-layer statement is narrower: GCNet demonstrates image-plane vehicle detection and short-horizon tracking with competitive UA-DETRAC metrics, including non-trivial rainy and night performance, but it does not establish metric physical validity, biomechanical validity, or universal weather invariance.

<RLVR_COUNTERFACTUAL_VETOES>
The following are three verifiable counterfactual veto scenarios constructed for this audit. RLVR here means reinforcement-learning-with-verifiable-rewards-style audit logic: a claim is accepted only if a deterministic verifier can be evaluated on a concrete counterexample. These scenarios are not claims made by the paper; they are falsification tests for overbroad interpretations of the paper.

Scenario 1: zero-norm cosine singularity. Setup: synthesize or search for an input where \(Q_{ij}=0\) or some \(K_{mn}=0\), so \(\|Q_{ij}\|\|K_{mn}\|=0\). Verifier: compute the denominator in Eq. (2) and check for zero. Prediction: Eq. (2) is undefined or numerically unstable unless an epsilon is inserted; the paper gives no epsilon [PAGE 1-2]. Veto: any claim that the global correlation operator is universally well-defined for all feature maps is vetoed. The paper’s own text says the correlation vectors encode global information, but it does not specify zero-norm handling [PAGE 2]. This is a high-value veto because it attacks the core operator, not a peripheral hyperparameter.

Scenario 2: 3×3 peak-collision veto. Setup: place two object centers within the same 3×3 max-pool neighborhood on the confidence map. Verifier: evaluate Eq. (3), \(\mathrm{maxpool}(Y,3,1)_{ij}=Y_{ij}\), and count surviving peaks [PAGE 2]. Prediction: at most one peak survives in that neighborhood, so one object center is suppressed before box regression. Veto: any claim that GCNet removes the need for NMS under arbitrary object density is vetoed. The paper correctly says it gets boxes “without box non-maximum suppression (NMS)” [PAGE 2], but that is a different claim from “no peak suppression at all.” The feature map is \(h/8\times w/8\) [PAGE 4], so the collision condition is resolution-dependent. This scenario is verifiable by replaying a synthetic heatmap and checking peak counts.

Scenario 3: temporal-horizon and confidence-deletion veto. Setup: an object disappears for more than five frames or its tracking confidence falls below \(p_2=0.3\). Verifier: check the training window “\(i\) is between 1 and 5” [PAGE 5], then check Algorithm 1’s rule that tracks with confidence lower than \(p_2\) are deleted [PAGE 5-6]. Prediction: the model has no stated long-term memory to bridge the gap; the track is deleted, and a later detection either becomes a candidate or a new track. Veto: any claim of robust long-occlusion identity preservation is vetoed. The paper’s evidence is short-horizon object-wise propagation, not long-term re-identification. This scenario is verifiable in a replay harness that masks an object for six or more frames and measures ID continuity.

A fourth optional weather veto is also verifiable: compare Table 2’s Rainy AP 65.38 with Full AP 74.04 [PAGE 8] and reject “weather-invariant” language. Together, these vetoes constrain the paper’s legitimate claim: global correlation is a strong image-plane, short-horizon vehicle-tracking mechanism on UA-DETRAC, with competitive detection and tracking numbers, but it is not a universal singularity-free, density-free, long-occlusion-proof, biomechanical, or all-weather system.
</RLVR_COUNTERFACTUAL_VETOES>
