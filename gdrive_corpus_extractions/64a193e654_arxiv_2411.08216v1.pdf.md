<SOURCE_OPERATORS_AND_EQUATIONS>

**Embedding operator.** For each tracklet $T_i=\{t_0,\dots,t_{n}\}$, a CNN ReID model (OSNet [32], trained on SportsMOT) produces box-grained embeddings $F^i_m\in\mathbb{R}^d$, typically L2-normalized, so $\lVert F^i_m\rVert=1$. The embedding dimension is not stated in the provided pages.

**Tracklet-level pseudo-distance (Eq. 1, [PAGE 7]).**

$$D_{i,j}=\begin{cases}1, & i\neq j \ \wedge\ \Pi_i\cap\Pi_j\neq\emptyset\\[4pt] \dfrac{1}{N_iN_j}\displaystyle\sum_{m\in\Pi_i}\sum_{n\in\Pi_j}\left(1-\frac{F^i_m\cdot F^j_n}{\lVert F^i_m\rVert\,\lVert F^j_n\rVert}\right), & \text{otherwise}\end{cases}$$

Units: dimensionless, nominal range $[0,2]$; realized range $[0,1]$ for non-negative embeddings. $\Pi_i\subset\mathbb{Z}_{\ge0}$ is a frame-index set of cardinality $N_i$. Note this operator is exactly the UPGMA / average-linkage inter-cluster distance between two *bags* of frame embeddings, so the connector is average-linkage hierarchical clustering lifted from frames to tracklets. It is symmetric and zero on the diagonal by construction, but it is **not** a metric: for $A,B,C$ with $\|a-b\|$ near 2 and $A,C$ tight, $D(A,C)\ll D(A,B)+D(B,C)$ can fail in either direction depending on cardinalities, because $D$ is a cardinality-weighted mean, not an infimum. Lance–Williams update for merging $A,B$ into $A\cup B$ against $C$: $D_{A\cup B,C}=\frac{N_A D_{A,C}+N_B D_{B,C}}{N_A+N_B}$, which is well-defined only if the implementation stores cardinalities; otherwise the merge criterion silently degrades to single or complete linkage.

**Splitter operator (DBSCAN, [PAGE 5–6]).** With metric $d(x,y)=1-\cos(x,y)$ on the unit sphere:

- Core condition: $p$ is core iff $\lvert N_\epsilon(p)\rvert\ge s$, where $N_\epsilon(p)=\{q: d(p,q)\le\epsilon\}$. With $s=5$, this requires 4 neighbors plus self.
- Density-reachability: transitive closure of "$q\in N_\epsilon(p)$ and $p$ core"; clusters are maximal density-connected sets.
- Border assignment: order-dependent in general DBSCAN; unspecified here.
- Modified outlier rule [PAGE 6]: *"unlike traditional DBSCAN implementations, our adapted version assigns outliers to the nearest clusters at the end of the clustering process."*
- Cap: *"If the total number of final clusters exceeds $k$, clusters are progressively merged until only $k$ clusters remain"* [PAGE 6], with $k=3$ [PAGE 8].

**Spatial gate (Eqs. 3–4, [PAGE 7]).**

$$\theta_{\mathrm{hor}}=\beta\,\Delta_{\max,\mathrm{hor}},\qquad \theta_{\mathrm{ver}}=\beta\,\Delta_{\max,\mathrm{ver}},\qquad \beta\in(0,1]$$
$$D_{i,j}\leftarrow 1 \ \text{ if } \ \Delta_{i,j,\mathrm{hor}}>\theta_{\mathrm{hor}} \ \vee\ \Delta_{i,j,\mathrm{ver}}>\theta_{\mathrm{ver}}$$

$\Delta_{\max}$ are measured in pixels over all bounding-box centers in the video; $\Delta_{i,j}$ are center displacements between exit and entry endpoints. Units: pixels (image-plane), not meters.

**Operating points [PAGE 8].** $s=5$, $\epsilon=0.6$ (i.e. cosine similarity $\ge0.4$ for neighborhood membership), $k=3$, $\alpha=0.4$, $\beta=1$ (SportsMOT), $\beta=0.7$ (SoccerNet).

**Formal breakdown / singularity regimes.**

1. $\Delta_{\max,\mathrm{hor}}\to0$ (static scene, degenerate): $\theta\to0$, so every pair with any nonzero displacement is forced to $D=1$. All merging is destroyed. Not scale-invariant — the normalizer is content-dependent, so the *same* physical displacement is penalized differently depending on the widest box excursion anywhere in the video.
2. $\beta=1$: the gate is identically satisfied (proof: $\Delta_{i,j}\le\Delta_{\max}$ by definition of the maximum). Zero contribution on SportsMOT.
3. $N_i=0$ or $N_j=0$: Eq. 1's second branch divides by zero; excluded only by the implicit assumption of non-empty tracklets.
4. $\lvert T\rvert<s=5$: no core points exist, DBSCAN returns a single all-noise partition, and "nearest cluster" has no referent. The splitter's output on short tracklets is mathematically undefined by the text.
5. True identity count in a tracklet exceeding $k=3$: irreducible under-split. Figure 3 [PAGE 3] itself depicts three identities; four would exceed capacity.
6. Non-L2-normalized or signed embeddings: $d\in[0,2]$, so $\epsilon=0.6$ no longer corresponds to a fixed angular cone and the hyperparameter becomes embedding-dependent.
7. Complexity: the distance matrix costs $\Theta\!\left(\sum_{i\ne j} N_iN_j\right)=\Theta(M^2)$ frame-pair inner products for $M$ total boxes, plus $\Theta(N^2)$ memory in tracklets. For a full 90-minute, 25 fps soccer broadcast ($M\sim1.35\times10^5$), this is $\sim1.8\times10^{10}$ inner products per sequence — infeasible without blocking or landmark pruning. The paper evaluates on 240 SportsMOT sequences and the SoccerNet 2023 test clips, which are short; the method's stated ambition of "entire matches" [PAGE 2] is not demonstrated at that scale.
8. Temporal-overlap veto is a hard, non-relaxable constraint: any correct merge of two fragments whose spans intersect is impossible by construction. Since splitter output fragments are frame-index subsets of one tracklet, they are pairwise disjoint and therefore mergeable — the pipeline is consistent here — but *cross-tracklet* pairs with genuine overlap (a mixed-up pair) can never be merged, only split. The architecture is thus asymmetric: splitting fixes mix-ups, merging fixes cut-offs, and neither substitutes for the other. This matches the ablation [PAGE 10], where Connector alone captures most of the gain (SORT +9.15 HOTA on SportsMOT) and the Splitter adds only +1.09 more.

**Derived headroom accounting.** With DetA fixed, $\mathrm{HOTA}\le\mathrm{DetA}$ since $\mathrm{AssA}\le\mathrm{DetA}$. Capture fraction $=\frac{\mathrm{HOTA}_{\mathrm{GTA}}-\mathrm{HOTA}_{0}}{\mathrm{DetA}-\mathrm{HOTA}_{0}}$: SORT 56.9%, ByteTrack 49.8%, Deep-EIoU 34.8% on SportsMOT; 69.4%, 45.2%, 38.6% on SoccerNet. The method closes roughly a third to a half of the association-only gap, with diminishing returns as the baseline strengthens — a monotone signature of a refinement layer, not a new tracker.
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>

The lineage is unusually legible because the author list is shared across the ancestors. Bewley et al.'s SORT [3] (ICIP 2016) established the Kalman-plus-Hungarian template; Wojke et al. [26] (ICIP 2017) added appearance embeddings; Zhang et al.'s ByteTrack [31] (ECCV 2022) recovered low-score boxes; the same UW group's Deep-EIoU [19] (WACV 2024) added iterative scale-up expansion and deep features for sports, and is the strongest baseline here at 77.21 HOTA on SportsMOT and 79.41 on the SoccerNet 2023 test set.

The direct ancestor is Wang et al., "Split and Connect: A Universal Tracklet Booster for Multi-Object Tracking" [25] (IEEE TMM 2022), which already established the split-then-connect template using CNN and temporal attention. GTA's contribution is a substitution, not a new principle: replace learned attention with unsupervised DBSCAN plus a hierarchical average-linkage merge, and add an image-plane geometric gate. The paper's own framing concedes this — *"Drawing inspiration from global link models presented in recent works [18] [29]"* [PAGE 5]. Sibling branches in the same lineage include Translink [30] (CNN plus temporal attention, binary classification on tracklet pairs), AFLink [9] (spatio-temporal only, no appearance), MambaTrack [15] (learned motion model as a global linker), and the multi-camera clustering family [5, 17, 28]. The hierarchical-merge step is explicitly attributed: *"we further conduct hierarchical clustering following [14]"* — Hsu et al., CVPRW 2019, vehicle re-ID across cameras. The clustering primitive itself descends from Ester, Kriegel, Sander and Xu, KDD-96 [11].

**Multi-week traps in this genealogy.**

- *Trap A (benchmark year mismatch).* [PAGE 8] states Deep-EIoU scores "85.4% on the SoccerNet test set published in 2022," while all SoccerNet experiments here use *"the test set from the SoccerNet tracking dataset published in 2023"* [PAGE 8], where the same tracker scores 79.41. Anyone assembling a comparison table across papers will conflate a 6-point benchmark revision with an algorithmic regression.
- *Trap B (reference mis-slots).* Table 1 [PAGE 9] cites SORT as [26] (Wojke) while Table 3 [PAGE 10] cites [3] (Bewley); and "[9]" on [PAGE 4] is described as AFLink while reference 9 in the bibliography [PAGE 12] is StrongSORT. Automated citation-graph extraction will propagate both errors.
- *Trap C (the vacuous-beta trap).* A replicator who inherits $\beta=1$ from the SportsMOT configuration and then ablates the spatial constraint will measure exactly zero effect and may conclude the constraint is worthless. It is not worthless; it is disabled on that dataset.
- *Trap D (oracle-detection transfer).* SoccerNet results use *"oracle detection following others' implementations [19] for fair comparison"* [PAGE 8]. The 83.11 figure is therefore not a deployable number; it is an association-ceiling measurement conditioned on perfect boxes.
- *Trap E (over-claimed module).* The abstract attributes the headline number to the whole method, but the ablation shows the Splitter is worth +1.09 HOTA (SORT, SportsMOT), +0.23 (ByteTrack), +0.56 (Deep-EIoU), +0.99 (SORT, SoccerNet), +0.92 (ByteTrack), +1.10 (Deep-EIoU). The Connector is the load-bearing component in every cell.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>

Three agent models matter for predicting what this artifact will be used for.

**The crisis-regression agent.** A practitioner whose pipeline fails an ID-consistency audit late in a delivery cycle reaches for a post-hoc refiner precisely because it requires no retraining and no detector change — the properties the abstract advertises ("plug-and-play refinement tool for any multi-object tracker," [PAGE 1]). Under time pressure this agent copies the published hyperparameters wholesale: $s=5$, $\epsilon=0.6$, $k=3$, $\alpha=0.4$, $\beta\in\{1,0.7\}$. Prediction: this agent will report gains on indoor basketball-like footage and near-zero or negative gains on anything with camera motion, and will not notice that $\beta=1$ silently disabled half of their configuration. The regression is specifically *toward appearance-only operation with an inert geometric prior*, because that is the only regime in which the published constants are calibrated.

**The counter-trap agent.** This agent reads Eq. 4 and asks what $\Delta_{\max}$ is normalized by. On recognizing it is a per-video image-plane extremum, this agent predicts the failure mode before running anything: on a zoomed-out tactical camera, $\Delta_{\max}$ is large, so $\theta$ is loose and the gate never fires; on a tight broadcast follow-cam, $\Delta_{\max}$ is small, so $\theta$ is tight and legitimate re-entries across the frame are vetoed. This agent also refuses to accept the outlier-reassignment rule without a tie-break specification, and refuses to accept the hierarchical stopping rule as written, since *"until no tracklet pair's distance is larger than the merging threshold $\alpha$"* [PAGE 7] describes a complete-linkage halt applied to a matrix built with an average-linkage operator. This agent will reimplement linkage choice explicitly and report both variants.

**The metric-defender agent.** This agent's only question is whether 81.04 is comparable to the number in a rival paper. The answer from Table 1's structure is no, not directly: DetA is fixed at 88.21, so 81.04 is conditional on YOLOX detections of a particular quality, and the AssA ceiling is 88.21 regardless of how good the linker becomes. Any tracker with DetA below 88.21 cannot exceed that ceiling under GTA. This agent will therefore always quote HOTA in the pair (DetA, AssA), never alone.

**Clock pressures.** Three clocks interact. The conference clock (WACV 2024 for the ancestor [19], arXiv posting 12 Nov 2024 for this paper) compresses the ablation: there is no per-dataset hyperparameter sensitivity study, no runtime table, and no Frag column despite the conclusion's claim. The dataset clock is visible in the SoccerNet 2022→2023 revision, which silently re-based a comparison. The deployment clock in a live analytics pipeline is unforgiving of the $\Theta(M^2)$ matrix: a full-match product cannot wait for a quadratic pass, so any real adoption forces blocking by time window, which reintroduces exactly the long-absence cut-off errors the connector exists to fix. That tension — the fix's cost scaling as the square of the very sequences it targets — is the deepest strategic risk in the artifact, and neither the paper nor a hurried adopter will surface it.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>

**Layer 1 — image-plane geometry.** The only hard geometric prior is Eq. 4, and its stated justification is *"In a common sports game video where the camera position remains fixed, player movement is constrained by the field boundaries, and players do not exit and re-enter from opposite sides of the field"* [PAGE 7]. Proof of vacuity at $\beta=1$: $\Delta_{\max,\mathrm{hor}}=\max_{\text{boxes}}\lvert x-x'\rvert \ge \Delta_{i,j,\mathrm{hor}}$ for all $i,j$, hence $\Delta_{i,j,\mathrm{hor}}>\theta_{\mathrm{hor}}=\Delta_{\max,\mathrm{hor}}$ is unsatisfiable. The gate is a no-op on SportsMOT. ∎ At $\beta=0.7$ on SoccerNet the gate binds only for endpoint displacements exceeding 70% of the video's maximum horizontal (or vertical) box-center excursion — a physically implausible re-entry, which is exactly its purpose, but it also means the gate cannot resolve the practically important cases (nearby same-team players swapping identities). Verdict: **no veto raised, low discriminative power.** The gate is a sanity filter, not an association mechanism. Its failure regime is the opposite of what a reviewer would guess: with a broadcast camera that pans, the field-boundary prior is violated globally, and because $\Delta_{\max}$ scales with the pan range, the threshold inflates with the violation, so the gate degrades gracefully into uselessness rather than into false vetoes.

**Layer 2 — kinematics.** A biomechanically admissible displacement bound over an occlusion of duration $\tau$ is $\Delta\le v_{\max}\tau$, with $v_{\max}\approx9\text{–}10\ \mathrm{m\,s^{-1}}$ for elite sprinters and typically $\le8\ \mathrm{m\,s^{-1}}$ for outfield play. Over a 3-second occlusion this is $\lesssim24$ m, roughly 23% of a 105 m pitch — comfortably inside the $\beta=0.7$ threshold, confirming Layer 1's finding from an independent direction. No veto.

**Layer 3 — appearance physics.** Illumination is the unmodeled variable. OSNet is trained on SportsMOT and applied unchanged to SoccerNet [PAGE 8]; the paper offers no domain-gap analysis. Indoor arena lighting is near-Lambertian and stable; outdoor soccer introduces sun-angle change, cloud transients, shadow boundaries crossing the pitch, and floodlight onset at dusk. All of these shift embeddings coherently for all players simultaneously, which is precisely the adversarial case for a *relative* cosine threshold like $\epsilon=0.6$: the shift is common-mode, so it compresses inter-identity distances rather than inflating intra-identity ones. **Conditional veto:** on footage with strong global illumination drift, the splitter's $\epsilon$ becomes miscalibrated in the direction of over-merging identities inside one tracklet (mix-ups surviving into the connector), and $k=3$ then caps the damage at three fragments rather than fixing it. Falsifiable prediction below.

**Layer 4 — detection layer.** SoccerNet numbers are conditioned on oracle boxes [PAGE 8]; SportsMOT numbers on YOLOX. Because GTA never changes DetA, the achievable HOTA is bounded by the upstream detector, and any comparison of 81.04 across papers with different detectors is a category error. This is a hard ceiling, not a tuning issue: $\mathrm{HOTA}_{\max}=\mathrm{DetA}$.

**Layer 5 — occlusion vs. absence distinction.** The architecture silently assumes these are separable. Mix-ups arise from *partial* occlusion within continuous view; cut-offs from *total* absence. The temporal-overlap clause in Eq. 1 enforces exactly that separation, and it is the reason the two modules do not interfere. The unverified edge case is a player who is partially occluded for so long that the online tracker's buffer expires and a new ID is spawned while the old ID is still emitting boxes — then the two tracklets overlap in time, Eq. 1 pins $D=1$ permanently, and the cut-off becomes unfixable by construction. **Structural veto on a subset of long-occlusion cut-offs.** This is the sharpest theoretical limitation in the artifact and it is not discussed anywhere in the 14 pages.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>

Each veto below is stated so that it can be executed and can return a negative result. Negative results are the ones that would falsify my reading.

**Veto 1 — short-tracklet degeneracy.** *Claim:* for tracklets with $\lvert T\rvert<s=5$, the splitter is undefined, and the implementation must therefore pass them through unchanged, making splitter output identical to input. *Test:* truncate each SportsMOT test sequence to force a distribution of tracklet lengths with substantial mass below 5 frames; compare GTA-with-splitter against GTA-connector-only. *Prediction:* HOTA delta attributable to the splitter collapses toward zero as the fraction of sub-5-frame tracklets rises above roughly 30%, while connector-only HOTA is unchanged. *Falsifier:* a nonzero splitter contribution on exclusively sub-5-frame tracklets, which would indicate an unstated fallback rule.

**Veto 2 — illumination drift breaks the cosine operating point.** *Claim:* $\epsilon=0.6$ is calibrated to SportsMOT indoor appearance statistics and is not transferable. *Test:* evaluate the frozen SportsMOT-trained OSNet plus fixed $(\epsilon,\alpha)$ on an outdoor-sunset or floodlit-onset segment; sweep $\epsilon$ and locate the optimum. *Prediction:* the optimal $\epsilon$ shifts by more than 0.1, and at the published $\epsilon=0.6$ the splitter's cluster count per tracklet rises (over-splitting into $k=3$ fragments) while AssA falls below the connector-only baseline. *Falsifier:* optimal $\epsilon$ stable within 0.05 across illumination regimes, which would mean OSNet embeddings are illumination-invariant enough for the constants to be universal.

**Veto 3 — quadratic cost forces blocking that destroys the long-absence gains.** *Claim:* the method's headline use case (re-identification across long absences) is the one that cannot be run at match scale. *Test:* measure wall-clock and peak memory for connector construction on a full 90-minute 25 fps soccer sequence at $M\approx1.35\times10^5$ boxes, then re-run with time-window blocking of width $W$ and sweep $W$. *Prediction:* unblocked execution is infeasible (memory $\Theta(N^2)$ and $\Theta(M^2)$ inner products, $\sim1.8\times10^{10}$ operations); as $W$ shrinks to a tractable size, IDF1 gains decay monotonically toward zero and the SoccerNet-style IDS reduction (3281→1374 for SORT) shrinks by more than half. *Falsifier:* a sublinear implementation with an index structure (e.g., ANN blocking in embedding space) that preserves long-range links at near-linear cost — which would make the objection an implementation detail rather than a limitation of the formulation as written.

**Veto 4 — transitivity leak in the temporal constraint.** *Claim:* because merges are decided on the pre-merge matrix with no re-evaluation, chained merges can produce super-tracklets whose aggregate span intersects a third tracklet that was never tested against the union. *Test:* instrument the merge loop to log, at each step, whether any cluster pair with $\Pi\cap\Pi\neq\emptyset$ coexists in the same cluster. *Prediction:* nonzero violation count on both datasets, small but measurable, concentrated on high-density sequences where tracklet spans are long. *Falsifier:* zero violations, which would mean the average-linkage distances of temporally overlapping pairs are always already above $\alpha$ and the constraint is redundant with the distance test.

**Veto 5 — cross-sport parameter fragility.** *Claim:* $\beta=0.7$ and $\Delta_{\max,\mathrm{ver}}$ normalization are calibrated to soccer's horizontal-dominant motion; volleyball's vertical-dominant motion inverts the useful gate. *Test:* run SportsMOT volleyball subsets with $\beta$ swept over $\{0.5,0.7,0.9,1.0\}$ and separately with the horizontal and vertical gates ablated. *Prediction:* on volleyball, the vertical gate does most of the work and the optimal $\beta$ is materially below 1, while on basketball the horizontal gate dominates; a single global $\beta$ is Pareto-suboptimal across the three SportsMOT sports. *Falsifier:* a flat HOTA response to $\beta$ across all three sports, which would mean the gate is contributing nothing anywhere and the published $\beta$ values are cosmetic.
</RLVR_COUNTERFACTUAL_VETOES>
