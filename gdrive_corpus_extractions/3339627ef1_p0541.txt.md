The adversarial equilibrium occurs when t_event is kept in the boundary band τ_regression ≲ t_event ≲ τ_deliberation, trapping the agent between regression and deliberation. Recursive theory of mind therefore becomes a race over clocks: the agent must shorten τ_deliberation or lengthen the effective t_event, while the adversary manipulates t_event to keep the agent inside the regression window.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Three layers must independently pass before a reasonable-type decision is executed.

Neural layer. Prefrontal classification requires working-memory capacity to hold candidate conceptions and reduce H[X_t | 𝒞(X_t)=k] below ε_bits [PAGE 531]. If entropy remains above threshold beyond the working-memory horizon, the neural layer vetoes: no class is committed, and action stays in suspense.

Biomechanical layer. Once k* is selected, u* = ℳ(k*) must be physically executable. Using standard rigid-body dynamics,
M(q) q̈ + C(q, q̇) q̇ + g(q) = τ(u),
with q ∈ ℝ^n joint configuration, M(q) the inertia matrix, C(q, q̇) Coriolis/centrifugal terms, g(q) gravity, and τ(u) the control torque generated by activation dynamics τ_a ȧ + a = u, ||u|| ≤ u_max. These are established continuum/rigid-body relations, not invented ratios. If no u ∈ 𝒰 satisfies the equation while reaching x_goal within joint limits, the biomechanical layer vetoes the motor program.

Weather layer. Let w(t) encode environmental disturbance (wind, precipitation, temperature). It enters dynamics additively and modifies contact mechanics, e.g., available friction μ(w) N_normal. If the required traction force F_req(k*) exceeds μ(w) N_normal, the action is physically impossible under current weather. This is a standard Coulomb friction constraint, not an invented ratio. The weather layer vetoes k* and forces reclassification of X_t with w(t) included in the situation vector.

Adjudication order: neural veto halts deliberation; biomechanical veto aborts the selected motor program; weather veto triggers immediate reclassification under perturbation. A decision is executable only if all three layers return pass. Because James ties motor consequence directly to class [PAGE 531], any layer failure collapses the entire reasonable-type decision back to indeterminateness or forces a search for a new class.
</CROSS_LAYER_VETO_ADJUDICATION>

Verifiable veto: the controller switches class as soon as the disturbance crosses the physical feasibility boundary. Prediction: the reclassification rate ρ(w) increases monotonically with disturbance magnitude and exhibits a sharp transition at the boundary where μ(w) N_normal < F_req(k*). This threshold is an observable physical boundary, not an invented ratio. Verifiable by systematically varying wind speed in a locomotor task and logging class-switch events.
