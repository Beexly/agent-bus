The input layer is spatiotemporal tracking data: for every frame q, each outfield player i has a measured location p_{i,q} on the pitch. Goalkeepers are excluded a priori because the data provider’s GK position labels are assumed accurate across all frames [PAGE 2]. The first computational hop is geometric normalization: actual player positions are scaled to match the maximum width and length of the formation template library [PAGE 3]. This is necessary because raw tracking coordinates live in stadium-specific metric space (e.g., 105 m × 68 m), whereas the 65 templates from mplsoccer v1.5.0 are defined in a canonical static coordinate system [PAGE 2]. Without this scaling, Euclidean distance between a player and a template position is dominated by scale mismatch rather than tactical role proximity; the paper’s Figure 2b shows a centerback mislabeled as a defensive midfielder purely because the unscaled actual formation did not align with the template proportions [PAGE 3].

The second hop is combinatorial optimization. For each template k ∈ K (|K| = 65), EFPI solves a linear sum assignment problem: assign each player i to exactly one template position j so that total distance cost is minimized. The cost matrix C has entries C_{i,j} = distance between player location p_i and template position p_j [PAGE 3]. The objective is nested minimization over template index k and binary assignment matrix X [PAGE 3]. This is the Hungarian algorithm lineage (Kuhn 1955, cited in [PAGE 11] and applied by Wei et al. 2013 [PAGE 1]). After solving all 65 assignments, EFPI selects the template with the lowest total cost and propagates its position labels to the players [PAGE 3]. Because the template library includes variants for 8, 9, and 10 outfield players (to cover red cards and injuries) and attacking skews such as 1432 and 2233, the assignment space is rich but also prone to near-tie degeneracy [PAGE 2].

The third hop is temporal segmentation. Rather than labeling a single frame, EFPI can replace p_i with the segment-average location \bar{p}_{i,m} over q frames [PAGE 4]. Segments may be frames, possessions, fixed windows (e.g., 10 seconds, 5 minutes), or full periods [PAGE 1]. Before assignment, segments are partitioned by attacking and defending direction [PAGE 4]. This averaging smooths high-frequency movement noise but collapses within-segment variance: a box-to-box midfielder who covers 40 meters laterally gets represented by a single centroid, which may sit equidistant from two template roles and induce a label flip that reflects geometry, not tactics.

The fourth hop is the stability filter ε. Because 65 templates include near-duplicate layouts (e.g., 3412 vs. 3412flat, shown in Appendix A [PAGE 8–10]), marginal cost differences can trigger spurious formation changes, especially during transitions [PAGE 4]. EFPI therefore accepts a new template at time t only if the relative cost improvement exceeds ε percent: (C_{t−1} − C_t) / C_t > ε [PAGE 4]. \bar{p}_{i,m} = \frac{1}{N} \sum_{q=1}^{N} p_{i,q}

Paper quote: “we compute the average position for player i over a segment (m) that contains q frames as:” [PAGE 4].

Formula 3 — Stability threshold for template change [PAGE 4]:
\frac{C_{t-1} - C_t}{C_t} > \epsilon
Units: dimensionless. C_t is the best-fitting template cost at time t; C_{t-1} is the cost of the currently assigned template from t − 1. A change is accepted only if the relative improvement exceeds ε percent. Paper quote: “This parameter requires that the cost of assigning a new formation template at time t must be at least ϵ percent lower than the cost of the template assigned at time t − 1 before a change in formation is accepted” [PAGE 4].

EFPI’s segmentation average \bar{p}_{i,m} [PAGE 4] blends the pre- and post-red-card geometries, while the template library offers 8-, 9-, and 10-outfield formations [PAGE 2] and the substitution heuristic drops least-occurring players when >11 unique players appear in a segment [PAGE 5]. Verification method: compare EFPI position labels for the same players in the 5 minutes before and after the red card, using the same segment duration. Prediction: labels will shift artificially (e.g., a central midfielder reassigned to defensive midfielder or center back) not because of tactical reassignment, but because the centroid moved after a teammate’s removal and the 10-player template fit re-optimized the whole team. The veto fires if label entropy spikes at the red-card minute without a corresponding coaching substitution.

Veto Scenario 3 — Tracking noise under adverse conditions. Counterfactual: synthetic Gaussian jitter with standard deviation σ = 2.5 m is injected into clean tracking coordinates, simulating rain-affected optical tracking. EFPI solves the Hungarian assignment for each frame with ε = 0.0. Because the 65-template library includes near-duplicates (Appendix A [PAGE 8–10]), marginal cost differences fall below the distance noise floor, and the algorithm oscillates between similar templates (e.g., “433” vs. “41212”) on consecutive frames. Verification method: run EFPI on noise-injected Metrica or Segunda División open data and compute frame-to-frame label entropy. Prediction: with ε = 0.0, label changes every frame; with ε = 0.1, formation locks to the first noise-favored template and resists genuine tactical changes. The veto fires when label entropy under noise exceeds the entropy observed on clean data by more than 50%, demonstrating that EFPI’s cost function lacks an explicit noise robustness term.
