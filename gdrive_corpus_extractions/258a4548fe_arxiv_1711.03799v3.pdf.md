The state is \(x_k=[\xi_k^\top,\zeta_k^\top]^\top\), with kinematic part \(\xi_k=[x_{R,k},y_{R,k},\phi_k,v_k,\omega_k]^\top\) and extent \(\zeta_k=[a_k,b_k]^\top\). Units are metres for position, radians for yaw, metres/second for speed, radians/second for yaw rate, and metres for width/length. The rear-axle position is fixed at “77% of the vehicle length” [PAGE 2].

3. The multi-object Bayes recursion is the set-valued prediction and update in equations (1)–(2). The integrals are “set integrals as defined in [39]” [PAGE 3]. This is the formal layer that lets detection number, clutter, missed detections, and object identity labels coexist in one posterior.

4. The measurement model is learned by a variational Gaussian mixture (VGM). The raw training data are fitted by a Gaussian mixture with latent component indicators, Dirichlet weight prior, and Gaussian–Wishart mean/precision prior. The variational posterior is approximated by maximizing the functional in equation (8), with factorization \(q(\Phi)=q(L)q(w,M,H)\) [PAGE 4]. Marginalizing parameters produces a predictive mixture of Student’s \(t\) densities, equation (11), not a plain Gaussian mixture, because parameter uncertainty is retained [PAGE 4].

5. To avoid learning a ten-dimensional density directly, the paper applies a manual dimension reduction: positions are normalized by object width and length, \(z'_x=z_{x,OC}/b\), \(z'_y=z_{y,OC}/a\); the expected Doppler is subtracted, \(z'_d=v_D-(\cos\alpha\,s_1+\sin\alpha\,s_2)\); and the state is reduced to \(x'=\phi_{SC}-\operatorname{atan2}(y_{R,SC},x_{R,SC})\) [PAGE 4, equations (13)–(16)]. Thus the learned density is \(p(z',x')\), and the conditional single-object density is \(g_{z'}(z'|x')=p(z',x')/p(x')\) [PAGE 5, equation (17)].

6. The conditional density lives in a normalized space, so it cannot be inserted directly into the polar-space multi-object likelihood. The paper uses equation (24): the object/clutter likelihood ratio is invariant under the same transformation because the Jacobian cancels in numerator and denominator [PAGE 6]. This is a crucial gray-zone step: it is valid only where the inverse transformation exists and where the same transformation is applied to both object and clutter densities.

7. The multi-object likelihood is then the detection-type likelihood of equations (18)–(23): object detection probability \(p_D\), misdetection \(q_D=1-p_D\), Poisson object-measurement count with mean \(\lambda_T\), Poisson clutter with mean \(\lambda_C\), clutter density \(p_C(z)\), and intensity \(\kappa(z)=\lambda_C p_C(z)\) [PAGE 5]. The LMB/GLMB filter updates weights over partitions and associations, then approximates the posterior GLMB by an LMB at each recursion [PAGE 7, equations (32)–(37)].

8. This is an approximation that “discards information about the extent estimate” [PAGE 7], so the extent uncertainty is not fully represented.

The sensors are “not synchronized among themselves” [PAGE 8], and “out-of-sequence problems are not considered” [PAGE 10]. These are not minor details: they define where the end-to-end probabilistic claim is conditional rather than universal.

\pi_{k|k-1}(X_k|Z_{1:k-1})

\]
These are equations (1)–(2); the integrals are set integrals [PAGE 3]. Here \(\pi\) is a density over RFSs, so its units are not a single ordinary probability density: they are set-density units over mixed discrete cardinality and continuous state.

<RETROCAUSAL_GENEALOGY>
The scientific lineage is explicitly retrospective. The paper inherits variational Bayesian mixture fitting from Attias [33]–[34] and Bishop [35], and it inherits RFS/FISST multi-object probability from Mahler [38]–[39]. It then uses the labeled multi-Bernoulli filter [48], generalized labeled multi-Bernoulli distributions [45], and the extended-object LMB filter [37]. The measurement-model lineage runs from manual extended-object models—measurement-source sets, spatial distributions, random matrices, ray tracing, random hypersurfaces, Gaussian processes—to this data-driven VGM [PAGE 1–2]. The “retrocausal” move is that the later variational machinery re-selects which earlier manual structures survive: the reflection-center idea is not implemented as explicit data association; instead, “each mixture component can be interpreted to be a particular reflection center” while “the mixture density is directly used as a spatial distribution model” [PAGE 5]. The model thereby retroactively absorbs the older reflection-center lineage into a learned density.

There is also a retrocausal evaluation choice: the model is trained on one Mercedes E-Class station wagon (S212), but later tested on a similar C-Class and on eleven urban vehicle types from compact cars to vans [PAGE 8, PAGE 12–13]. The later generalization result retroactively justifies the claim that high-resolution radar sees rough extent rather than vehicle-specific detail: “the rough extent of the vehicles is observable but the details that distinguish different vehicles are still concealed” [PAGE 13].

Multi-week traps visible in the source:
- Aspect-angle imbalance. The full dataset has 336,287 points from about 123 minutes, but it contains “roughly three times more measurements from the rear perspective than from the front perspective,” and a \(5^\circ\) rear interval has about 20,000 points while a neighboring interval has 4,736 [PAGE 8]. A model trained on the raw set “tends to favor aspect angles around \(x'=0^\circ\)” [PAGE 8]. The fix is a balanced subset of 95,688 points [PAGE 8]. This is a multi-week data-collection trap: more data is not automatically better if the aspect-angle histogram is skewed.
- Component pruning. Seventy components are initialized, but twenty receive mixing weight below \(10^{-5}\), leaving \(c=50\) [PAGE 9]. A naive implementation that keeps all components pays computation cost for components that explain nothing.
- Single-vehicle training. The training vehicle is one E-Class, so the model risks learning that vehicle’s rear-axle/roof-edge reflections as if they were generic. The paper acknowledges possible low-weight interior components near \(z'_x=0\) and suggests rear-axle or roof-edge reflections [PAGE 9].
- Unsynchronized multi-sensor clock. Four sensors run at 20 Hz but are “not synchronized among themselves” [PAGE 8]. The implementation assumes measurements arrive in recording-time order and does not handle out-of-sequence data [PAGE 10]. A multi-week fusion deployment that adds latency or reordering will violate this assumption.
- Occlusion and delayed initialization. In the T-intersection scenario, a rear sedan is lost during occlusion after 25 update steps [PAGE 13]; second-track initialization is delayed because the initialization routine expects at least a cluster of two measurements [PAGE 11]. These are evaluation traps: good average RMSE can coexist with track-loss events.
- Real-time trap. The prototype spends about 85% of computation on VGM evaluation [PAGE 10]. Porting to C++ may help, but the source does not establish real-time performance.

<RECURSIVE_THEORY_OF_MIND>
This is an instrumental recursive audit, not a claim that the tracker has a mind. The tracker’s “theory of itself” is the predict–update–approximate loop in Fig. 2: LMB prior, GLMB update, LMB approximation, track initialization, feasibility check, prediction [PAGE 6]. Three failure modes can be separated.

Crisis habit regression. When measurements are ambiguous, the system can regress to a habitual manual assumption rather than the learned model. The clearest example is the comparison to the direct scattering model: it “favors a cluster which excludes six measurements that originate from the wheels and exhibit an especially large or small Doppler velocity” [PAGE 11]. That is a crisis habit: rigid-body reasoning discards wheel measurements because they do not fit the habitual rigid-body Doppler model. The variational model instead “has learned the effect of spurious measurements of the rotating wheels and uses a cluster which contains all measurements” [PAGE 11]. The recursive danger is that if the VGM has not seen a particular wheel/clutter pattern, it may either over-trust an out-of-distribution detection or fall back to rigid-body exclusion. The source reports that the VGM automatically learned wheel-related Doppler errors [PAGE 9], but this is learned support, not a universal physical law.

Counter-trap. A data-driven model can counter-trap itself by fitting training-set artifacts. The rear-perspective imbalance is the concrete case: a model from the full set “tends to favor aspect angles around \(x'=0^\circ\)” [PAGE 8], so the balanced subset is a counter-trap measure. A second counter-trap is interpreting low-weight interior components as real structure; the paper offers only a possible explanation—rear axle or roof edge [PAGE 9]. A third is assuming the Student’s \(t\) mixture is automatically calibrated because it is Bayesian; it is calibrated to the training distribution and to the chosen dimension reduction, not to arbitrary weather, vehicle types, or sensor mounting changes.

Clock. The recursive loop is clocked by asynchronous sensor arrivals. “All sensors run at a frequency of 20 Hz and are not synchronized among themselves” [PAGE 8]. The filter triggers a new update each time new data arrives and assumes recording-time order; out-of-sequence problems are “not considered” [PAGE 10]. Persistence is also clocked: the probability of persistence models an average of “10 s in and 0.1 s outside the FOV” [PAGE 9]. Thus the same geometric track can have different existence probability depending on update cadence and FOV dwell time. The clock layer is not cosmetic; it couples to pruning, initialization, and cardinality error.

The recursive self-correction is therefore conditional: the filter can resolve ambiguity by partitioning and association over time, but only if the measurement partitions contain the true cluster, the VGM support covers the aspect angle, the object does not overlap another hypothesis, and the clock assumptions hold. When those conditions fail, the system’s “habit” dominates: it either splits clusters, prunes a track, or trusts a clutter-induced birth.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical veto. The hard physical veto is non-overlap. The paper conditions the predicted multi-object density on physical feasibility \(F\) and sets \(p(F|I)=1\) iff no objects in label set \(I\) overlap [PAGE 7]. In equation (31), any overlapping hypothesis receives zero weight. This is a proof-level veto inside the model: it is not a soft penalty. The predicted mean positions and extents are used to determine possible overlaps [PAGE 7]. Boundary condition: the veto uses predicted means, so two objects whose means do not overlap but whose uncertainty supports overlap are not vetoed by this term; the model’s extent uncertainty is also approximated in the particle step [PAGE 7]. Thus the physical veto is exact for the mean-overlap test and incomplete for full distributional overlap.

Biomechanical/rotational-kinematic veto. The source does not contain a human biomechanical model. The relevant mechanical layer is wheel rotation. The paper states: “Some Doppler measurements may even originate from rotating wheels and thus do not match the motion of the rigid body” [PAGE 1]. The expected Doppler is computed from rigid-body motion through \(s_1,s_2\) in equations (14)–(15) [PAGE 4]. A wheel detection can therefore violate the rigid-body Doppler prediction while still being a real detection. The VGM learns this: “the model expects larger Doppler errors in the vicinity of the wheels” and “the VGM has automatically learned the occurence of spurious measurements from rotating wheels” [PAGE 9]. The cross-layer adjudication is therefore asymmetric. For a rigid-body-only model, the biomechanical/rotational veto is hard: exclude or split the wheel cluster. For the VGM, the veto is soft: the wheel-error component can explain the detection, so the cluster need not be split. The source’s own comparison shows the direct scattering model excluding six wheel measurements while the variational model uses all measurements [PAGE 11]. A correct adjudicator must not apply a rigid-body veto to the VGM without checking whether the learned wheel components support the detection.

Weather veto. The paper claims radar has “robustness to adverse weather conditions” [PAGE 1]. That is a design-rationale claim, not a measured weather experiment in the provided pages. The experimental data are collected “on a closed test site and on public roads” [PAGE 8]; no rain, snow, fog, or temperature sweep is reported. The likelihood model has no explicit weather state. Therefore the verifiable weather veto is: do not infer quantitative adverse-weather tracking accuracy from this source. Weather can change clutter density, detection probability, and Doppler noise, all of which are modeled as fixed or slowly adapted parameters. If weather pushes detections outside the VGM support, the conditional density can become arbitrarily small; the model has no out-of-distribution weather veto beyond low likelihood. This is a proof of evidentiary limit, not a proof of failure.

Sensor-geometry veto. The sensors have “an opening angle of about \(170^\circ\), a range of \(43\,m\),” and axes rotated by \(45^\circ\), giving almost \(360^\circ\) close-range coverage [PAGE 8]. Detection probability is set to \(0.8\) and “slowly decreased towards the boundaries of the FOV” [PAGE 9]. The inverse transformation is undefined at the sensor origin [PAGE 6]. The aspect-angle boundary at \(\pm\pi\) causes non-periodic VGM component switching [PAGE 9]. These are geometric vetoes: a detection at the origin, a track at the FOV boundary, or a state exactly on the aspect-angle discontinuity is in a regime where the nominal equations are singular or discontinuous. The correct adjudication is to regularize, exclude, or flag such measurements rather than treat the likelihood as a smooth finite number.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
I interpret RLVR here as reinforcement learning with verifiable rewards: each counterfactual is a testable intervention with a predicted observable and a veto condition. These are not betting scenarios.

1. Sensor-origin singularity counterfactual. Intervention: inject a detection at range \(d=0\) with finite azimuth \(\alpha\) and Doppler \(v_D\) into the update. The inverse transformation \(f_z^{-1}\) is “not defined at the location of the sensor origin” [PAGE 6], and \(\operatorname{atan2}(0,0)\) is undefined. Prediction: a naive implementation returns NaN or Inf in \(z'\), or a huge Jacobian-scaled likelihood, corrupting the association weights. Veto: the update must explicitly reject, clamp, or route origin detections to a polar-domain clutter term; if the implementation returns a finite ordinary likelihood without a documented regularization, the counterfactual fails. Verifiable observable: finite versus non-finite \(g_{z'}/p_C\) and finite versus non-finite posterior weight under the injected detection.

2. Aspect-angle periodic-boundary counterfactual. Intervention: evaluate the learned conditional density at two states that differ by crossing the \(+\pi/-\pi\) boundary but are physically equivalent, e.g. \(x'=-\pi+\epsilon\) and \(x'=\pi-\epsilon\), with the same transformed detection \(z'\). Prediction: because “the VGM does not consider the periodic nature of the aspect angle,” the mixture component set changes abruptly when the sign changes [PAGE 9], so the two log-densities can jump even though the geometry is continuous. Veto: if a downstream association or track weight changes discontinuously under an equivalent physical rotation, the model is not admissible near the boundary unless a periodic smoothing or component-matching layer is added. Verifiable observable: log-density difference \(|\ln g_{z'}(z'|-\pi+\epsilon)-\ln g_{z'}(z'|\pi-\epsilon)|\) as \(\epsilon\to0\).

3. Rotating-wheel cluster counterfactual. Intervention: take a cluster containing wheel-region detections with Doppler values that are inconsistent with the rigid-body prediction from equations (14)–(15). Compare three variants: (a) direct scattering model with cluster splitting and exclusion; (b) VGM using all measurements; (c) VGM with the wheel-region detections removed. The paper’s evidence is that the direct scattering model “excludes six measurements that originate from the wheels and exhibit an especially large or small Doppler velocity” [PAGE 11], whereas the VGM “has learned the effect of spurious measurements of the rotating wheels and uses a cluster which contains all measurements” [PAGE 11]. Prediction: if the VGM’s wheel components are supported by training data, variant (b) should preserve the length estimate better than variant (a); the paper reports length RMSE \(0.16\,m\) for the variational model versus \(0.49\,m\) for the direct scattering model in the figure-eight scenario [PAGE 11, Table I]. Veto: if removing the wheel detections does not change the VGM length estimate while the rigid-body model changes substantially, then the claimed wheel-learning benefit is not causally verified for that cluster. Conversely, if variant (b) degrades to variant (a) whenever wheel components are absent from the training support, the VGM must not be credited with general rotating-wheel robustness. Verifiable observable: held-out length RMSE and association weight under the three variants, conditioned on the same cluster and same extent constraints.
</RLVR_COUNTERFACTUAL_VETOES>
