The paper proposes SportsSUSHI, an offline hierarchical graph tracker for team-sport player re-identification across long occlusions. The derivation proceeds in multiple hops: (1) raw detections from YOLOX are fed into a feature-extraction module emitting four modalities—appearance (FastReID ResNet50-IBN fine-tuned on the tracking dataset), jersey number (PARSeq scene-text recognition on torso crops selected by pose estimation), team ID (contrastive embedding clustered per clip into Team A / Team B / referee), and field coordinates (homography from Gutiérrez-Pérez et al. projected to meters). (2) These per-detection vectors are not consumed directly; instead, pairwise edge features are constructed: cosine similarity for appearance/jersey/team and absolute Euclidean distance in meters for field position. (3) A graph is built per hierarchy level with nodes = detections at level 0 and nodes = tracklets at higher levels; K=10 nearest neighbors by appearance/spatial distance are retained to bound complexity. (4) Each level has its own MLP encoder but shares GNN weights across levels, enabling data-driven feature selection per temporal distance. (5) Neural message passing performs binary edge classification, and a linear program converts edge scores into binary trajectory decisions with flow conservation. (6) For clips longer than the maximum receptive span of the hierarchy (256 frames for 7 layers, 512 for 9, 1024 for 10 on SoccerNet), a sliding window with stitching is applied.

Gray-zone audit: The method’s strongest assumption is that domain features remain legible across the temporal gap being bridged. Jersey numbers are explicitly marked illegible when PARSeq predicts EOL in the first character position [PAGE 5], which collapses the jersey similarity term to an uninformative or missing cue precisely under motion blur or occlusion—the very conditions that create long absences. Team ID is cluster-learned from the first N player images of each test clip [PAGE 5], so a clip that opens with only one team visible or with referees misclassified as players contaminates the cluster centers and biases all subsequent one-hot assignments. Field registration fails when camera zoom omits sufficient field markings or motion blur obscures lines [PAGE 5]; the paper mitigates with linear interpolation of camera parameters, but this is an interpolation assumption, not a measurement, and degrades during rapid camera motion. The paper acknowledges no motion model is used; association relies on static spatial proximity and appearance, so abrupt non-linear player motion (a known sports-specific failure mode [PAGE 2]) produces association errors precisely when players accelerate into occlusions. Finally, referees wear identical uniforms and lack jersey numbers, so neither jersey nor team-ID features separate referees from one another [PAGE 8], creating a re-identification singularity for that role class. c(d_i d_j) = c_1(d_i)\,c_2(d_j) \quad \text{(two-digit)}, \qquad

<RETROCAUSAL_GENEALOGY>
The intellectual lineage is strictly computer-vision and sports-analytics, with no gambling or wagering content. Foundational layer: offline MOT as min-cost network flow on detection graphs [13, 52] [PAGE 3], solvable in polynomial time, later replaced by GNN edge classification in MPNTrack [9] [PAGE 3] using 15-frame batches—too short for long-term tracking. SUSHI [10, 11] [PAGE 2, PAGE 4] extends MPNTrack into a hierarchy: detections $\to$ tracklets $\to$ longer tracklets, reusing GNN weights across levels while learning level-specific MLPs for appearance and geometric features [PAGE 2]. SportsSUSHI adopts SUSHI wholesale [PAGE 4] and injects domain features absent from generic MOT: jersey number (building on Koshkina et al. [31] PARSeq pipeline [PAGE 3, PAGE 5]), team ID (contrastive learning from Koshkina et al. [32] [PAGE 4, PAGE 5]), and field registration (Gutiérrez-Pérez et al. [21] homography [PAGE 4, PAGE 5, PAGE 7]).

Retrocausal dependencies: The hockey dataset’s stationary full-rink camera [PAGE 1, PAGE 6] removes the need for homography (spatial features in pixels suffice) [PAGE 8], whereas SoccerNet’s broadcast camera motion makes field registration mandatory [PAGE 5]. This is a retrocausal trap: system design is contingent on camera geometry known only after dataset selection. Per-game retraining traps appear in related work: Zhang et al. [53] requires retraining per game [PAGE 3], Maglo et al. [41] fine-tunes re-ID per test clip at inference [PAGE 3], and Lu et al. [37] fine-tunes per new game [PAGE 4]; SportsSUSHI avoids this by clustering team ID per clip from first N images [PAGE 5], introducing a new trap—opening-frame sampling bias. Synthetic-data pretraining (Bhargavi et al. [7] [PAGE 3]) addresses limited jersey labels but introduces domain-shift risk from synthetic to real. Multi-week trap: if a team changes uniforms mid-season or a league introduces new jersey fonts, the PARSeq STR model and per-clip team clusters both require recalibration; the paper provides no domain-adaptation protocol for such distribution shifts. Related short-term specialists (ByteTrack [54], FairMOT [55], CenterTrack [57], Tracktor++ [5], DiffMOT [40]) are explicitly excluded from long-term claims because they lack the hierarchy’s cross-clip reconnection [PAGE 2, PAGE 3].

<RECURSIVE_THEORY_OF_MIND>
Crisis habit regression: When a player is occluded or absent, the tracker’s default regression path is to appearance (FastReID cosine similarity) and raw spatial proximity, because jersey numbers become illegible (EOL-first rule) [PAGE 5] and field registration can fail [PAGE 5]. Under this regression, identity confidence decays predictably with frame gap: fine-tuned FastReID falls from 99.63% at gap 1 to 26.6% at gap 300 on hockey [PAGE 7]. The system thus “regresses” to a generic MOT habit—short-term appearance matching—which the paper identifies as insufficient for long-term sports tracking [PAGE 2].

Counter-trap: SportsSUSHI’s counter-mechanism is the hierarchy-level MLP, which learns to weight jersey number, team ID, and field coordinates more heavily at larger temporal distances [PAGE 5]. Jersey numbers and team ID provide identity priors invariant to appearance decay; field coordinates provide spatial priors invariant to camera zoom. The counter-trap activates only if these cues survived the occlusion: jersey visible enough for PARSeq, team cluster stable, homography valid. If all three fail simultaneously (blurred jersey, contaminated cluster, lost homography), the tracker reverts to appearance-only association and suffers the same gap-decay curve as generic methods.

Clock: The operative clock is temporal gap measured in frames, converted by frame rate (30 fps hockey, 25 fps soccer) [PAGE 7]. The hierarchy’s maximum span (256/512/1024 frames) sets a hard horizon [PAGE 6]. Beyond it, sliding-window stitching applies [PAGE 4], which assumes track continuity at window boundaries—a second-order assumption that fails if a player is absent across the boundary. In hockey, 1,530-frame max clips exceed 1024 frames, so stitching is unavoidable for the longest sequences [PAGE 7]. The recursion: crisis (occlusion) triggers regression to appearance; counter-trap (domain features) extends the effective clock; if the counter-trap’s cues are themselves occluded, regression wins and the track terminates or mis-associates.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical vetoes: Stationary vs moving camera [PAGE 1, PAGE 8]. Hockey’s stationary camera makes pixel-position spatial features valid [PAGE 8]; soccer’s broadcast motion vetoes pixel coordinates and mandates homography [PAGE 5]. Protective gear in hockey occludes jersey numbers and distinctive features [PAGE 1, PAGE 2], vetoing jersey and appearance cues during body checks or pile-ups. Motion blur and fast motion degrade PARSeq legibility and homography line detection [PAGE 1, PAGE 5]. Illumination changes veto color-based team ID [PAGE 4].

Biomechanical vetoes: Abrupt non-linear motion [PAGE 2] invalidates constant-velocity assumptions; the paper notes no motion model is used and leaves it to future work [PAGE 8], so rapid direction changes near occlusion boundaries produce association errors that spatial proximity cannot resolve. DiffMOT’s replacement of the Kalman Filter with a diffusion motion model [PAGE 3] is cited as a short-term alternative, confirming that motion modeling is an independent veto axis SportsSUSHI currently does not cover.

Weather/environmental vetoes: Not explicitly parameterized, but motion blur and lighting changes function as environmental vetoes on PARSeq and homography [PAGE 1, PAGE 5].

Adjudication protocol: At each hierarchy level, the trained MLP assigns weights to edge-feature modalities [PAGE 5]. Adjudication order under veto: (1) if homography fails, substitute interpolated camera parameters [PAGE 5]; if interpolation is invalid (rapid pan), veto field coordinates and fall back to appearance+jersey+team. (2) If jersey is EOL-illegible, zero the jersey similarity and rely on team ID + re-ID + field [PAGE 5]. (3) If referees are present, team ID is uniform across referees and jersey carries no cue, so referee re-identification rests solely on appearance and spatio-temporal proximity—a known failure mode [PAGE 8]. (4) If gap exceeds the level’s span (256/512/1024), promote to the next hierarchy level; if at the top level, invoke sliding-window stitching [PAGE 4, PAGE 6]. The veto chain is greedy: once a modality is vetoed at a level, the MLP’s learned weight for that modality cannot recover it at deeper levels unless the feature is recomputed, which it is not (features are extracted once per detection) [PAGE 4].
