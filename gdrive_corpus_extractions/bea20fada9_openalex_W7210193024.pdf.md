\[

\frac{P(O \mid H_i,D)\,P(H_i \mid D)}
{\sum_j P(O \mid H_j,D)\,P(H_j \mid D)}

All probabilities are dimensionless and lie in \([0,1]\). The denominator is a normalization over mutually exclusive hypotheses. Breakdown regime: if \(\sum_j P(O \mid H_j,D)P(H_j \mid D)=0\), the posterior is undefined; operationally, this means the observation is incompatible with every modeled hypothesis, requiring either a new hypothesis class or rejection of the observation as corrupted.

\[

\]

The unit is bits. If \(T\) is deterministic given \(O\), \(H(T \mid O)=0\). If \(T\) is uniform over \(N\) possible tokens, \(H(T \mid O)=\log_2 N\) bits.
