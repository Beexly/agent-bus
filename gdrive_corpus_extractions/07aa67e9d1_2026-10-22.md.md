Breakdown regimes: (i) if \(A\) is reducible, \(\alpha\) fails to mix across assignments; (ii) if frame spacing \(\Delta t \to 0\), then \(O_t \approx O_{t-1}\), causing forward-variable underflow; (iii) if \(\operatorname{rank}(X) < p\), \(\beta\) is non-identifiable.

Hawkes credit attribution (soccer buildup) [PAGE 1]: Conditional intensity
\[
\lambda^*(t) = \mu + \sum_{t_i < t} \phi(t-t_i), \qquad \phi(\tau)=\alpha e^{-\beta \tau}.
\]
Stability (non-explosion): \(\int_0^\infty \phi(\tau)\,d\tau = \alpha/\beta < 1\). Credit share for player \(i\) on a shot at time \(T\):
\[
\mathrm{CI}_i(T) = \frac{\int_0^T \phi(T-s)\,dN_i(s)}{\lambda^*(T)}.
\]
Units: \(\lambda^*\) in events per second (\(\mathrm{s}^{-1}\)); \(\mathrm{CI}\) dimensionless share in \([0,1]\). Breakdown: \(\alpha/\beta \ge 1\) yields an explosive, non-stationary intensity with infinite expected events over a finite horizon; a misspecified kernel (e.g., ignoring refractory periods or spatial distance) biases attribution and can credit physically disconnected actors.

Concave multi-task aging curves [PAGE 1]: For metric \(a\),
\[
f_a(\mathrm{age}) = \sum_k \theta_k B_k(\mathrm{age}), \qquad \text{s.t. } \frac{\partial^2 f_a}{\partial \mathrm{age}^2} \le 0 \quad \forall \mathrm{age}\in[\mathrm{age}_{\min},\mathrm{age}_{\max}],
\]
with shared latent \(z \sim \mathcal{N}(0,I_{d_z})\). Units: age in years; output metric in z-scores (dimensionless). Breakdown: non-identifiable when \(d_z \ge N_{\text{players}}\) or when regularization \(\lambda \to 0\).

Rugby Markov model [PAGE 1]: State \(s=(\text{score\_diff},\text{time},\text{field\_pos})\). Bellman expectation
\[
\mathrm{EP}(s) = \sum_a \pi(a\mid s) \sum_{s'} P(s'\mid s,a)\big[r(s,a,s') + \gamma \,\mathrm{EP}(s')\big],
\qquad \mathrm{WP}(s) = P(\text{win}\mid s).
\]
Units: points, seconds, meters/yards, probability in \([0,1]\). Breakdown: absorbing at \(t=0\); sparse transitions in late-game score states cause high-variance WP; \(\gamma \to 1\) makes the undiscounted horizon ill-posed without a finite-horizon termination condition.

Polars 2.0 ordering [PAGE 2]: Determinism condition for lazy streaming joins/group-bys/unpivots: output order equals input order iff `maintain_order=True` or an explicit sort is applied. The 6 Oct default violates this. Breakdown: a frame-level tracking join keyed on (game_id, play_id, frame_id) yields mismatched blocker-rusher pairs if upstream code assumes the Polars 1.x sorted order.

<CROSS_LAYER_VETO_ADJUDICATION>
Physical/biomechanical veto: The pass-blocking HMM treats blocker→rusher assignment as Markovian across tracking frames [PAGE 1]. Human visual-motor reaction latency is approximately 150–250 ms; at 60 Hz tracking that is 9–15 frames. If the tracking frame spacing \(\Delta t\) falls below human reaction latency, the transition kernel \(A\) implies state changes faster than biomechanically possible. Veto condition: the HMM must be temporally smoothed or subsampled to respect the reaction-time floor, otherwise hidden-state transitions encode physical impossibility.

Spatial/causality veto for Hawkes credit: A player cannot earn shot credit when physically disconnected from the ball (e.g., beyond a effective passing radius or during a dead ball). A Hawkes kernel lacking compact spatial support or distance decay would attribute credit across stoppages, violating causality. Veto condition: mask the credit integral \(\int \phi(T-s)\,dN_i(s)\) by observable possession and ball-proximity state; actions outside the mask receive zero credit.

Weather/field veto for rugby Markov: The state \(s\) omits weather covariates [PAGE 1]. Wind above a critical threshold \(w_{\text{crit}}\) alters kicking and carrying transition probabilities \(P(s'\mid s,a)\), invalidating a stationary kernel. Veto condition: if wind \(> w_{\text{crit}}\) or precipitation renders field position non-Markovian, \(\mathrm{EP}(s)\) must be recomputed on a weather-augmented state \(s^+ = (s, \text{wind},\text{precip})\).

Data-policy veto: SambaGraph depends on PFF-derived data [PAGE 1], but repo policy prohibits pulling or redistributing it [PAGE 2]. This is an absolute ingestion-layer veto independent of model quality.

Dependency veto: nflreadr has not changed since 1.5.1 (April) [PAGE 2]. If the official NFL stats endpoint changes schema, the R pipeline breaks with no visible upstream fix, vetoing any production model that depends on nflreadr for frame-level or play-level inputs.
</CROSS_LAYER_VETO_ADJUDICATION>
