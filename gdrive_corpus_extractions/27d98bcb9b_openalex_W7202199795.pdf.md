The paper's central causal chain is: dense sports scenes defeat holistic ViT pooling → language priors fill the vacuum → hallucinated actions ("shot" vs "pass") → therefore inject object-level grounding *without* destroying temporal order → therefore regularize the terminal hidden state against motion → therefore calibrate the decision boundary against hard negatives. Each link has a distinct evidentiary status and they are not equally supported.

Link 1 (ViT loses small-entity detail) is asserted in [PAGE 1] — "The inherent patch-based processing and global pooling operations easily discard the subtle movements and complex spatial geometries" — but the remedy in Eq (1) explicitly *removes* global pooling ("By removing the global pooling layer, we preserve the dense grid representations"). So the global branch already keeps N dense tokens; the object branch adds K=15 grounded entities on top. This is coherent.

Link 2 (top-K grounding) hinges on a single un-swept hyperparameter, K=15, justified qualitatively in [PAGE 6] as "an optimal balance" with zero ablation. For soccer (22 outfield players + officials) K=15 is *below* the entity count of a full formation, which is a latent contradiction with the word "dense" and specifically threatens the Dense Disambiguation task. This is my first gray-zone flag.

Link 3 (IGF preserves temporal alignment AND saves compute) contains a subtle conflation. Eq (5) gives sequence length T(N+K(L_box+1)). The "naive" competitor they criticize appends the *same* K entities at the end, which yields the *same* token count, hence the *same* O((T(N+K·L_box))²) attention cost. The genuine 60× saving (M=900 → K=15) comes from top-K selection, not from interleaving. Interleaving's real, separable benefit is temporal correspondence. The paper bundles two orthogonal wins under one complexity claim.

Link 4 (AAS) is the weakest evidentially. The mechanism — back-propagating L_act through h_EOS to force spatio-temporal aggregation — is plausible, but the measured effect (Action 38.4→40.8, +2.4 pp) sits inside the sampling noise of a 1,000-item test set (SE ≈ 1.58 pp; unpaired z ≈ 1.10, p ≈ 0.27). The narrative strength ("compels," "forcing") vastly exceeds the statistical support.

Link 5 (MPO) is the best-supported single component: Spatial 48.6→53.0 (+4.4 pp, z ≈ 1.97, borderline p ≈ 0.05), which is the one ablation delta that clears the noise floor.

Cross-cutting: no error bars, no seeds, no significance tests, no CIs anywhere. The "generalization to FineSports" is not transfer (train-A/test-B) but independent retraining, per [PAGE 6]: "the models for SoccerNet and FineSports are trained independently" — a semantic soft-pedaling of the word "generalization." The Jersey category (33.4) is a conceded loss to the 4B MiniCPM-V and barely beats the IGF-only baseline (32.1), so the grounding apparatus contributes almost nothing to OCR-limited perception.
</THINK_TRACE>

<SOURCE_OPERATORS_AND_EQUATIONS>
All operators below are the paper's own; I add units, domain, and breakdown regimes.

Global grid context [PAGE 3]:
$$Z^{\text{vit}}_t = \Phi_{\text{vit}}(I_t) \in \mathbb{R}^{N \times d_{\text{vit}}} \quad (1)$$
Units: dimensionless activations; N = patch-token count (∝ (H·W)/patch²), d_vit = channel width.

Cross-modal scoring and top-K [PAGE 3], with M = 900 explicitly stated:
$$S = F_c(Q_{sf}) \otimes E_t^{\top} \in \mathbb{R}^{M \times C}, \qquad Z^{\text{sem}}_t \in \mathbb{R}^{K \times d_{\text{dino}}} \quad (2)$$
Units: S entries are inner-product logits (∝ cosine if L2-normalized). Breakdown regime: if the sport vocabulary V_sports is disjoint from OV-DINO's pretraining distribution, max-score separability collapses and top-K degenerates to noise; the paper offers no recall@K curve to bound this.

Interleaved token layout [PAGE 4]:
$$H_{\text{vis}} = \big[\tilde{Z}^{\text{vit}}_1 \oplus \tilde{Z}^{\text{obj}}_1 \oplus \cdots \oplus \tilde{Z}^{\text{vit}}_T \oplus \tilde{Z}^{\text{obj}}_T\big] \in \mathbb{R}^{T(N + K(L_{\text{box}}+1)) \times d_{\text{llm}}} \quad (5)$$
Sequence length S_len = T(N + K(L_box+1)). Self-attention FLOPs scale as O(S_len²·d_llm). The paper's cited "naive" cost O((T(N+K·L_box))²) is algebraically the *same order* as IGF — the reduction is entirely in replacing M=900 by K=15, i.e. a factor ≈ (N+900·L_box)² / (N+15·(L_box+1))².

Action head and masked loss [PAGE 5]:
$$p^{(i)}_{\text{act}} = \mathrm{Softmax}(W_{\text{act}}\,h^{(i)}_{\text{EOS}} + b_{\text{act}}) \in \mathbb{R}^{C} \quad (6)$$
$$L_{\text{act}} = -\frac{1}{\sum_i I^{(i)}_{\text{act}} + \epsilon}\sum_{i} I^{(i)}_{\text{act}} \sum_{c} y^{(i)}_{\text{act},c}\log p^{(i)}_{\text{act},c} \quad (7)$$
Units: nats (cross-entropy). I_act ∈ {0,1} is a task router; ε prevents 0/0 when a batch has no action queries — the singularity regime the balanced sampler is meant to avoid.

Curriculum [PAGE 5]: alignment (8) min L_align = −Σ log P(y_j | H_vis(θ_dino), y_<j); SFT (9)-(10) L_SFT = L_vqa + λL_act with λ=0.1; MPO (11) L_MPO = L_p + αL_q + βL_g with (12) a DPO log-ratio using temperature τ. Notational defect: β is defined in (11) as the L_g mixing weight, yet [PAGE 6] reports "the DPO divergence margin β=0.1" — the DPO temperature in (12) is τ, so the reported β is ambiguous between the mixing coefficient and the KL temperature. This should be reconciled.
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
Lineage of each operator:
- Query-based dense detection: Q_sf with M=900 is a direct descendant of DETR/Deformable-DETR set-prediction (learned object queries), inherited here through OV-DINO's Language-Aware Selective Fusion (ref [38], arXiv:2407.07844).
- Open-vocabulary alignment: Eq (2)'s Q⊗Eᵀ scorer is CLIP-style dual-encoder alignment, re-derived for detection.
- Interleaved grounding: the "grounded chain-of-thought" framing cites SceneCOT [PAGE 2, ref 20]; the anti-concatenation argument echoes the Flamingo/BLIP-2-era lesson that appending perimeter tokens breaks temporal adjacency.
- Preference learning: DPO (Rafailov et al., NeurIPS 2023, ref [30]) → Eq (12); MPO (Wang et al., arXiv:2411.10442, ref [41]) → Eq (11), itself the native InternVL3.5 recipe (ref [42], arXiv:2508.18265).
- Motion supervision: AAS is positioned against MotionBench [11] (SOTA VLMs <60% on motion) and "verifiable action regularizers" GUI-Libra [50].

Multi-week trap: the field repeatedly oscillates between *text-injected* coordinates and *feature-level* fusion. The paper's own Prompt-Injection baseline [PAGE 7-8] is the fossil of the losing side, and it is used rhetorically ("double-edged sword") rather than as an ablation of IGF's ordering. A second recurring trap: reporting single-run benchmark deltas without variance, which the sports-VQA literature (SoccerBench, SportR, X-VARS) has been slow to correct.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
Modeling the authors' incentives: the concession on Jersey (33.4 < MiniCPM-V's 40.3) is pre-emptive — they convert a loss into a "physics" story (OCR scales with parameters), which is largely true and disarms that reviewer axis. The AAS section uses strong verbs ("forcing," "compels") to inflate a +2.4 pp effect; a skeptical reviewer running McNemar will note p≈0.27 and discount the mechanism claim.

Counter-trap prediction: a rigorous reviewer will demand (a) a K-sweep, (b) CIs/paired tests on the 1k sets, (c) FLOP parity between IGF and append-at-end. The paper cannot currently answer (a) or (b) from reported data.

Clock/urgency axis: the arXiv stamp (2608.07932v2, "20 Aug 2026") and MM '26 camera-ready timing mean results are frozen; any post-hoc significance analysis is out-of-scope for the authors but fair game for us. The self-consistency check: does the ablation ordering (IGF-only 47.2 → +AAS 48.9 → +MPO 49.6 → full 51.8) imply additivity? 47.2 +1.7 +2.4 = 51.3 < 51.8, so there is a mild super-additive synergy (~+0.5 pp) when AAS and MPO combine — consistent with AAS sharpening motion features that MPO then calibrates, but the synergy is within noise.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Three physical/information layers can veto the claims:

1. Compute layer (proven partial veto of the complexity claim). IGF and append-at-end share token count S_len = T(N+K(L_box+1)), hence identical O(S_len²) attention. The 60× saving is from M→K, not interleaving. Verdict: the "interleaved topology circumvents quadratic explosion" sentence [PAGE 4] is imprecise; interleaving buys temporal alignment, top-K buys the FLOPs.

2. Sampling-theory (Nyquist) layer — a hard physical veto on action tasks. To separate DribbleJumper / DriveShot / NoDribbleJumper you must resolve ball-release and lower-limb kinematics. With "up to 8 frames per clip" (FineSports, [PAGE 6]) over a ~1–2 s window, effective f_s ≈ 4–8 Hz. A shooting release transient (~0.2–0.3 s) and a hard dribble (~2–3 Hz) sit near the Nyquist edge; aliasing can null the discriminative information. Formally, I(action label; sampled frames) is bounded by the sampled channel capacity; when temporal undersampling drives this mutual information toward 0, no projector (P_dino) or supervision (L_act) can recover it — the model is *forced* back onto language priors, the exact failure the paper claims to fix. Breakdown regime: SoccerNet's "sparse keyframes" [PAGE 6] are more exposed than FineSports' 8-frame clips, consistent with the lower SoccerNet Action score (42.5 vs 43.2).

3. Perception/OCR layer — a conceded veto on Jersey. 33.4 is barely above the IGF-only baseline (32.1) and below MiniCPM-V (40.3/40.3+). Boxed-entity grounding cannot substitute for sub-pixel OCR on distant, motion-blurred numerals. Verdict: the method's benefit is topology/relation reasoning, not fine OCR; the paper concedes this correctly.

Net adjudication: the *architecture* is sound; the *strongest empirical* claim that survives all three layers is the MPO-driven Spatial gain (+4.4 pp). The compute-efficiency and AAS-motion claims do not survive adversarial statistical/physical scrutiny at the reported evidence level.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Three falsifiable scenarios (RLVR = verifiable-reward style checks), each with a concrete prediction:

Veto 1 — K-sweep falsification. Train/eval SportsGrounder at K ∈ {5,10,15,30,45} on SoccerNet Dense Disambiguation. Prediction: accuracy is non-decreasing past K=15 (likely peaks near the on-pitch entity count ≈ 22–25), falsifying the "optimal balance" claim. If instead accuracy is flat/peaking at 15, the claim survives. This is verifiable from a single hyperparameter sweep.

Veto 2 — Statistical-power falsification. Apply McNemar's test (paired, same 1k SoccerNet test items) to Baseline vs Full and to ±AAS. Unpaired conservative bounds: Full−Baseline (51.8 vs 47.2) z ≈ 2.06, p ≈ 0.04; +AAS Action (38.4→40.8) z ≈ 1.10, p ≈ 0.27. Prediction: the AAS Action gain fails significance (p > 0.05); the Full-vs-Baseline overall is borderline. Verifiable by reporting discordant-pair counts, which the paper omits.

Veto 3 — Complexity-attribution falsification. Implement "append-K-at-end" (identical token count to IGF, different order) and measure wall-clock latency and attention FLOPs. Prediction: FLOPs/latency are statistically indistinguishable from IGF (both O(S_len²)), while Action/Spatial accuracy drops. This isolates the true source of both the compute saving (top-K) and the accuracy gain (temporal interleaving), falsifying the paper's bundled complexity claim as stated.

Each veto is executable with the released base model (InternVL3.5-2B), the frozen OV-DINO, and the two datasets, and each yields a binary verdict on a specific sentence in the paper.
</RLVR_COUNTERFACTUAL_VETOES>

Bottom line: a well-engineered, honestly-scoped systems paper whose architecture is defensible, but whose three headline claims — compute efficiency from interleaving, AAS motion regularization, and "generalization" — are individually overstated relative to the reported single-run, n=1,000 evidence. The MPO/Spatial result is the only component that clears the noise floor.
