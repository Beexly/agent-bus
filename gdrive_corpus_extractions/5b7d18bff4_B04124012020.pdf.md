<SOURCE_OPERATORS_AND_EQUATIONS>
Let \(Y_i\in\{H,D,A\}\) be the match outcome for match \(i\), with one-hot vector \(y_{ik}\in\{0,1\}\), \(\sum_{k\in\{H,D,A\}}y_{ik}=1\). Let \(x_i\in\mathbb{R}^d\) be the feature vector; the paper claims \(d=9\) feature families [PAGE 1] and lists goals, shots, corners, attack strength, player performance index, manager performance index, manager wins, and streak [PAGE 6]. The outcome is dimensionless; features carry their own units, e.g. counts for goals/shots/corners, dimensionless indices for performance, and match counts for streaks.

Multinomial logistic regression is:
\[
p_k(x_i;\theta)=\frac{\exp(w_k^\top x_i+b_k)}{\sum_{\ell\in\{H,D,A\}}\exp(w_\ell^\top x_i+b_\ell)},\qquad k\in\{H,D,A\},
\]
with \(w_k\in\mathbb{R}^d\), \(b_k\in\mathbb{R}\), and \(p_k\) dimensionless probabilities. The model is non-identifiable under \(w_k\mapsto w_k+c\), \(b_k\mapsto b_k+c^\top x\) for common \(c\); one class must be fixed as reference or the weights centered. The paper’s binary LR variant is:
\[
p_{\text{win}}(x_i)=\sigma(w^\top x_i+b),\qquad \sigma(z)=\frac{1}{1+e^{-z}},
\]
which is consistent with the statement that “logistic regression techniques could only predict win or lost results” [PAGE 7]. This binary model cannot represent \(D\) as a separate class; it collapses draw into the complement of win.

The ANN operator is a hidden-layer composition:
\[
h_i=\phi(W_1x_i+b_1),\qquad p(x_i;\theta)=\operatorname{softmax}(W_2h_i+b_2),
\]
where \(\phi\) is a nonlinear activation, \(W_1,W_2\) are weight matrices, and \(h_i\) is dimensionless. The training objective with \(\ell_2\) regularization is:
\[
\mathcal{L}(\theta)=-\frac{1}{N}\sum_{i=1}^{N}\sum_{k}y_{ik}\log p_k(x_i;\theta)+\lambda\|\theta\|_2^2,
\]
in nats per match if natural log is used, or bits per match if \(\log_2\) is used. Accuracy is:
\[
A=\frac{1}{N}\sum_{i=1}^{N}\mathbf{1}\{\hat{y}_i=Y_i\},\qquad \hat{y}_i=\arg\max_k p_k(x_i;\theta),
\]
a dimensionless proportion. Its binomial standard error is \(\operatorname{SE}(A)=\sqrt{A(1-A)/N}\). For \(N=110\) and \(A=0.93\), \(\operatorname{SE}\approx0.024\); for \(N=20\) and \(A=0.85\), \(\operatorname{SE}\approx0.080\). The paper reports 110 matches [PAGE 5] and a 20-match illustration [PAGE 7], so both sample sizes matter.

Probabilistic scoring should supplement accuracy. Entropy is:
\[
H(Y)=-\sum_{k}\pi_k\log_2\pi_k\ \text{bits},
\]
and conditional entropy is:
\[
H(Y\mid X)=-\sum_x p(x)\sum_k p(k\mid x)\log_2 p(k\mid x)\ \text{bits},
\]
so mutual information is \(I(Y;X)=H(Y)-H(Y\mid X)\) bits. The Brier score is:
\[
B=\frac{1}{N}\sum_{i=1}^{N}\sum_{k}\left(p_{ik}-y_{ik}\right)^2,
\]
dimensionless, and log loss is \(-\frac{1}{N}\sum_i\sum_k y_{ik}\log p_{ik}\) in bits or nats.

The GA weighting operator is a feature rescaling \(z_{ij}=\alpha_jx_{ij}\), \(\alpha_j\ge0\), with objective:
\[
J(\alpha)=\widehat{\text{CV}}\big(\theta(\alpha)\big)\quad\text{or}\quad \widehat{\text{Err}}_{\text{holdout}}\big(\theta(\alpha)\big),
\]
where \(\alpha_j\) is dimensionless. If \(J(\alpha)\) is optimized on the same data used for the reported accuracy, the reported accuracy is optimistically biased. Feature weight is not a causal effect; it is an in-sample relevance score. The paper’s use of “Optimise Weights (Evolutionary)” [PAGE 6] and the finding that PPI has “a higher weighting” [PAGE 8] therefore require nested validation.

Breakdown and singularity regimes are explicit. First, perfect separation in logistic regression makes the maximum-likelihood weights diverge: if a linear combination perfectly separates classes, \(w\to\infty\) and \(p_k\to0\) or \(1\), while log loss tends to zero but coefficients are non-finite. Second, multicollinearity or duplicate features makes \(X^\top X\) rank-deficient; the inverse used in standard logistic/ANN Hessian approximations does not exist, and weights are unstable. Third, softmax non-identifiability yields a flat direction in parameter space unless a reference class or centering constraint is imposed. Fourth, class imbalance with small \(\pi_D\) means accuracy is dominated by \(H\) and \(A\); a model that never predicts draw can still score high. Fifth, temporal leakage occurs if any feature uses information from \(t'\ge t\) for a match at time \(t\); the correct rule is \(t'\le t-1\). Sixth, distribution shift across weeks and seasons breaks the i.i.d. assumption implicit in random train/test splits. The paper’s ordered probit review also reports a low result: “A relatively low prediction accuracy of 56% was reported when fitted with the Newton Raphson method” [PAGE 4], showing that outcome modeling is sensitive to model class and validation.

The scientific genealogy runs from statistical football forecasting through KDD and machine learning. The paper reviews hidden Markov models, ordered probit regression, Bayesian hierarchical models, and classifier ensembles [PAGES 2–4]. It cites the ordered-probit tradition: “An ordered probit regression was used to model and predict football match results” [PAGE 4]. It also cites a Bayesian hierarchical approach and a Bayesian network for one club [PAGE 2]. The KDD framing is explicit: “The framework for our proposed system is knowledge discovery in databases (KDD)” [PAGE 5]. That lineage matters because KDD’s original promise is not merely fitting a classifier; it is selection, cleansing, transformation, mining, and evaluation under a disciplined process. The paper’s later 85%/93% claim retroactively recasts earlier 55%–56% results as inferior [PAGES 2–4], but the genealogy shows that the tasks differ: some prior work predicted three outcomes, some predicted goals, some predicted team propensity, and some used one-team data. The paper itself admits variation: “Due to the variations observed in these systems, it is difficult to identify which system outperforms the others” [PAGE 4]. That admission undermines any simple “almost two times higher” comparison [PAGE 7] unless the estimand, class set, and validation protocol are aligned.

The multi-week traps are temporal and structural. First, rolling form features must be causal. The paper proposes “moving average of teams’ performance within a season” [PAGE 5] and “Home and Away streak (HASTK)” [PAGE 6]. If these are computed after the season, they encode future results. Second, team strength is non-stationary across weeks: manager changes, injuries, cup participation, and fixture congestion alter the mapping from features to outcomes. The paper notes the injury dispute [PAGE 3] and the cup effect: “[9], claimed that cup participation would imply an increase in league performance, consequently a cup exit would imply decrease in league performance” [PAGE 3]. Sixth, home advantage itself may drift; the paper defines it as “the consistent finding that the home team wins over 50% of the games played under balanced home and away schedule” [PAGE 3], but “consistent” is an average, not a week-specific constant. A genealogy-aware audit therefore treats each match week as a new data-generating process and requires as-of feature clocks, rolling-origin validation, and drift checks. The historical lesson is that football forecasting has repeatedly produced high in-sample or narrow-window accuracy that failed to generalize; KDD does not remove that risk unless the evaluation clock is enforced.

<RECURSIVE_THEORY_OF_MIND>
The crisis-habit regression here is the habit of accepting a high accuracy number as a completed result. The paper’s authors likely believed they had improved the field because they added player and manager indices and used Rapid Miner [PAGE 6], then observed 85% and 93% [PAGE 1]. A reviewer’s recursive model must ask what the authors could see: they saw a tool output, a short match window, and a weighting result. What they may not have seen is the difference between binary and three-class accuracy, because the LR draw limitation appears later [PAGE 7]. The counter-trap is to reconstruct the estimand before praising the number: require a confusion matrix, a baseline, and an out-of-sample protocol. The clock is the as-of kickoff discipline: every feature must be timestamped before the match, every imputer and weight must be fitted inside the training fold, and every reported metric must be computed on held-out matches. A recursive theory of mind also anticipates Motivated reasoning: if the goal is to show improvement over [3]’s 55% [PAGE 2], then a 93% binary result feels like success even when it is not comparable. The counter-trap is to force a three-class macro-recall table and a calibration curve. If draw recall is zero, the model has not solved the three-outcome problem. The clock also applies to the paper’s future-tense data statement: “The data set will be extracted from 110 matches” [PAGE 5] versus past-tense results [PAGE 8] creates an audit gap. The correct stance is neither hostile nor credulous: treat the pipeline as an engineering prototype, but withhold the 93% claim until the task, split, and leakage controls are verifiable.

<CROSS_LAYER_VETO_ADJUDICATION>
Let \(Z=(Z_{\text{phys}},Z_{\text{biomech}},Z_{\text{weather}})\) be unmodeled or weakly modeled state variables, \(X\) the feature vector, and \(Y\) the outcome. The model estimates \(P(Y\mid X)\). If \(P(Y\mid X,Z)\) depends on \(Z\) and \(Z\) is not independent of \(X\), then:
\[
P(Y\mid X)=\int P(Y\mid X,Z)\,dP(Z\mid X).
\]
Under a shift \(P(Z\mid X)\to P'(Z\mid X)\), the predictive distribution changes:
\[
P'(Y\mid X)=\int P(Y\mid X,Z)\,dP'(Z\mid X),
\]
and the risk difference is \(\Delta R=\left|\mathbb{E}_{P'}[\ell(Y,\hat p(X))]-\mathbb{E}_{P}[\ell(Y,\hat p(X))]\right|\). A cross-layer veto is justified when \(\Delta R\) exceeds the model’s calibration error or when the new \(x\) lies outside the training support. A formal support test is the Mahalanobis distance:
\[
D_M(x)=\sqrt{(x-\mu)^\top\Sigma^{-1}(x-\mu)},
\]
dimensionless. Veto if \(D_M(x)>\sqrt{\chi^2_{d,1-\alpha}}\), because the conditional probability is an extrapolation.

Weather veto: the paper acknowledges “weather conditions during the match” in prior work [PAGE 2] but does not report a continuous weather layer. A standard heat index is:
\[
\mathrm{WBGT}=0.7T_{\text{nw}}+0.2T_g+0.1T_{db},
\]
in \(^\circ\mathrm{C}\), where \(T_{\text{nw}}\) is natural wet-bulb temperature, \(T_g\) is globe temperature, and \(T_{db}\) is dry-bulb temperature. For many outdoor sports, a WBGT threshold near \(28^\circ\mathrm{C}\) is a defensible veto trigger, with sport-specific adjustment. Wind alters ball motion through drag:
\[
\mathbf{F}_d=\frac12\rho C_d A\|\mathbf{v}_{\text{rel}}\|\,\mathbf{v}_{\text{rel}},
\]
in newtons, where \(\rho\) is air density in \(\mathrm{kg\,m^{-3}}\), \(C_d\) is dimensionless, \(A\) is cross-sectional area in \(\mathrm{m^2}\), and \(\mathbf{v}_{\text{rel}}=\mathbf{v}_{\text{ball}}-\mathbf{v}_{\text{air}}\) in \(\mathrm{m\,s^{-1}}\). If wind speed or gust variance exceeds the training distribution, passing and shot error change, so the historical conditional probability is not transportable.

Biomechanical veto: a standard load metric is the acute:chronic workload ratio:
\[
\mathrm{ACWR}=\frac{L_7}{L_{28}},
\]
dimensionless, where \(L_7\) is 7-day load and \(L_{28}\) is 28-day chronic load. High ratios, commonly discussed near 1.5, are associated with elevated injury risk, though the threshold is contested. The paper’s injury discussion says injuries of key players “plays significant role on team’s performance” [PAGE 3], while another cited view says the information “is subjective in nature and should not be considered in statistical forecasting” [PAGE 3]. The veto adjudication is that injury is not automatically a veto, but an unmodeled key-player absence is a veto when the team-strength parameter shift \(\Delta\theta\) changes the predicted probability by more than the calibration tolerance. The paper’s nine-feature model [PAGE 1] has no explicit continuous injury-timing or weather-state layer, so it cannot be treated as physically invariant across extreme heat, high wind, waterlogged pitch, or late injury news. The proof is conditional-probability instability: if \(Z\) changes the likelihood and is omitted, \(P(Y\mid X)\) is not the same functional under intervention.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
RLVR-style audit means a verifiable reward computed from pre-registered held-out outcomes and reproducible code, not from narrative claims. Three counterfactual veto scenarios follow.

1. **Temporal leakage veto.** Rebuild all rolling features using only matches with \(t'\le t-1\) for a match at time \(t\), including “moving average of teams’ performance within a season” [PAGE 5] and “Home and Away streak (HASTK)” [PAGE 6]. Put imputation and GA weighting inside the training fold only. Reward: 1 if the three-class accuracy drop from the reported pipeline is at most 0.03 and the 95% interval lower bound exceeds 0.55. Veto if the leakage-free three-class LR accuracy falls to the neighborhood of the no-information baseline or if draw recall is zero. Prediction: the reported 93% LR figure will not replicate as a three-class out-of-sample number; the leakage-free estimate will be substantially lower and the LR model will remain binary. If the original 93% was binary win/loss, it should be reported as such, not compared to three-class ANN accuracy.

2. **Task-collapse veto.** Force a common three-class label set \(\{H,D,A\}\) and report a full confusion matrix, macro recall, balanced accuracy, and Brier score. Reward: 1 if draw recall is positive and macro recall exceeds the majority-class baseline. Veto if the model never predicts draw or if the reported accuracy is computed after removing draws. Prediction: LR will have draw recall \(=0\) or near zero because the paper states it “could only predict win or lost results” [PAGE 7]; its three-class macro recall cannot exceed the structural ceiling of about \(2/3\) even with perfect home/away recall. ANN may predict draws, but its 85% claim still needs a baseline and interval; with \(N=110\), the interval is wide enough that 85% is not a precise estimate.

3. **Nested-validation and imputation-isolation veto.** Use repeated stratified \(k\)-fold cross-validation with the imputer, feature weighting, and hyperparameter tuning all inside each training fold. Reward: 1 if mean accuracy minus one standard deviation exceeds the baseline and if calibration error is below a pre-registered tolerance.
