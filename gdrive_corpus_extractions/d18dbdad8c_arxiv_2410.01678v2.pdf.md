<SOURCE_OPERATORS_AND_EQUATIONS>

Let a LiDAR sequence be $P=\{P_t\}_{t=1}^{T}$, $P_t \in \mathbb{R}^{N_t \times 4}$ (x, y, z, intensity) for a 32-beam sensor [PAGE 4]. Detections are $D_t = \{(b_i, c_i, s_i)\}$ with $b=[x,y,z,w,l,h,\theta]$, $\theta$ in radians, class $c\in C_{base}\cup C_{novel}$, $C_{base}\cap C_{novel}=\emptyset$ [PAGE 2]. Association in 3DMOTFormer is a learned edge classifier: affinity $a_{ij} = \sigma(\text{EdgeAugCrossAttn}(h_i^{track}, h_j^{det}, e_{ij}))$, with $e_{ij}$ built from $\Delta p$, $\Delta v$, $\Delta \text{size}$, $\Delta\theta$, and class embedding. The class-agnostic edit replaces that embedding with zeros and truncates edges at a fixed $\|p_i - p_j\|_2 < 3\,\text{m}$ [PAGE 5]. Supervision is a weighted bipartite match $\Pi^* = \arg\max_\Pi \sum_{(i,j)\in\Pi} \text{IoU}_{3D}(b_i, \hat b_j)$ solved by Hungarian on the IoU matrix; $\text{IoU}_{3D}$ is the volumetric intersection over union of two oriented boxes. The confidence head is $ \hat s_j = \text{MLP}(h^{(L_d)}_{D,j}) \in [0,1]$, trained with $L_c = \frac{1}{|D|}\sum_j (\hat s_j - s_j^{det})^2$, total $L = L_m + \lambda_c L_c$, $\lambda_c = 0.5$ [PAGE 5]. The AMOTA family is

$$\text{AMOTA} = \frac{1}{R}\sum_{r} \frac{\sum_{t} \text{TPA}(t,r) - \text{FPA}(t,r) - \text{IDS}(t,r)}{\sum_t \text{GT}(t)}$$

with recall grid $r$ and $\text{AMOTP} = \frac{1}{\sum \text{TP}}\sum \text{TP}\cdot \text{translational error}$ [PAGE 5]. The depth surrogate is $B_{size} = \frac{B_w B_h}{I_w I_h}$, $\widehat{depth} = \frac{1}{B_{size}}\left(1 - \alpha_p \frac{y_{center}}{I_h}\right)$, halved by an aspect-ratio branch when $\text{AR} > \beta_{ar}$, then $w_{dist} = e^{-\widehat{depth}/\lambda_s}$ with $\alpha_p=0.2,\ \beta_{ar}=2.5,\ \lambda_s=250$ [PAGE 5]. Units: $w_{dist}$ is dimensionless, $\widehat{depth}$ in normalized image-height units, $\lambda_s$ absorbs scale. Breakdown regimes: the exponent is monotone decreasing in box height, so a distant large vehicle and a near small object can tie; $\alpha_p$ is a single scalar fitted to "true depth to calculated depth" and cannot represent pitch-varying road geometry; $\beta_{ar}$ is a distribution heuristic, not a bound. Information-theoretic reading: the class-agnostic constraint removes $H(C)$ from the association feature, so the tracker's channel capacity for identity is bounded by motion+geometry alone, and the open-vocab label channel is re-attached post-hoc via a 2D detector with threshold 0.01 [PAGE 5] — i.e. the system trades a closed-set prior for a noisy external classifier, and the reported AMOTA is a joint statistic over both channels.

<RETROCAUSAL_GENEALOGY>

Lineage: Kalman-filter track-before-detect (AB3DMOT [7], EagerMOT [8], Immortal Tracker [9]) → point-based center tracking (CenterPoint [3], CenterTrack [10]) → category-specific motion priors (Poly-MOT [1]) → graph/transformer association with edge classification (3DMOTFormer [2]) → open-vocabulary 2D detection (GLIP/YOLO-World line, [11]-[14], [24]) → open-vocab 3D perception (PointCLIP [15], OpenScene [18], OpenMask3D [19], Open-YOLO 3D [21]). The paper's own text names the gap explicitly: [PAGE 2] "open-vocabulary 3D tracking remains largely unexplored." The load-bearing prior is that class labels were never a perception input; they were a regularizer. Removing them (class-agnostic GT assignment) raised base AMOTA from 0.504 to 0.536 but *lowered* novel AMOTA from 0.482 to 0.437 [PAGE 6, Table III] — the multi-week trap is that "cleaner" supervision monotonically improves the closed set while degrading the open set, because the 2D open-vocab labels are noisy and the class embedding was implicitly denoising them. The counter-trap is the confidence head: 2D detector objectness does not calibrate 3D box objectness, so plugging $\hat s = s^{det}$ (baseline) is a scale mismatch; regressing $\hat s$ from graph features recovers calibration and lifts both groups (+8.2%P base, +7%P novel, per [PAGE 6]). The third trap is depth: 2D box area is a perspective-dependent proxy, and the paper's own $w_{dist}$ is a heuristic stand-in for true range, so label smoothing inherits 2D quantization error. Historical pattern: every "open-vocabulary X" paper first inherits 2D CLIP-style zero-shot geometry, then discovers the 3D proposal geometry is the actual bottleneck — which is exactly what Table II [PAGE 5] shows.

<RECURSIVE_THEORY_OF_MIND>

Crisis habit regression: when an open-vocab system fails on novel classes, the reflexive fix is to add more 2D label supervision or tighten the 2D confidence threshold. That is the habit the baseline encodes, and it is the wrong reflex here — the ablation shows label quality is not the binding constraint after the confidence head is added. Counter-trap (the paper's actual move): decouple association from classification. Association uses only motion+geometry+heading with a fixed 3 m truncation; classification is a separate, swappable 2D-driven module. This makes the tracker's failure mode legible: identity continuity degrades only through association, not through vocabulary. Clock: nuScenes is annotated at 2 Hz over 20-second scenes [PAGE 4], so the temporal sampling is coarse relative to pedestrian-scale motion (a 1.5 m/s pedestrian moves 0.75 m per frame), which is why a 3 m gate is defensible for base classes and marginal for novel ones at highway speed (a 25 m/s vehicle moves 12.5 m per frame, well beyond the gate). The recursive read: the authors know the 2D detector is the noisy party, so they route around it with track-level voting rather than frame-level trust — a form of temporal error-correcting code. The multi-week trap is believing this makes the system open-vocabulary in the strict sense; it makes it open-vocabulary *conditional on* a 2D detector that must at least once see the object in a camera frame with sufficient resolution.

<CROSS_LAYER_VETO_ADJUDICATION>

Physical layer: LiDAR range error grows with $r^2$ for a fixed beam footprint, so a bus at 60 m has both sparse returns and larger $\sigma_r$; the paper's fixed 3 m association gate is dimensionally a length and therefore scale-blind to that growth. Biomechanical layer: pedestrian tracks require sub-meter heading consistency; $\theta$ is one of seven box parameters and is only weakly constrained by 5-10 points on a 32-beam sweep. Weather layer: rain/fog attenuate 905/1550 nm returns and add low-lying clutter, which inflates false proposals; the paper never evaluates adverse weather, and its splits are statistic-driven (rare, urban-vs-highway, points-per-box) not weather-driven [PAGE 4]. Veto proof by counterexample: the Split-1 "novel" bus class achieves AMOTA 0.612 [PAGE 5, Table I], i.e. a large, high-return-count object is *easier* to track open-vocabulary than a rare small object, because the failure mode is proposal density and point count, not vocabulary. Conversely the Split-3 truck collapses to 0.276 [PAGE 5, Table I] — long, articulated, low-height-profile — which is a geometry failure, not a language failure. Therefore any claim that the method "generalizes to unseen categories" is physically vetoed as a general statement: it generalizes in proportion to proposal quality and point density, and the vocabulary axis is secondary. The honest claim is conditional: given a detector that proposes the object, the tracker maintains it.
