<SOURCE_OPERATORS_AND_EQUATIONS>
The source uses min-max feature scaling. Let \(x\) be a player’s raw value for criterion \(i\), and let \(f_i^{MIN}\) and \(f_i^{MAX}\) be the cohort minimum and maximum. The maximization transform is
\[
\phi_i(x)=\frac{x-f_i^{MIN}}{f_i^{MAX}-f_i^{MIN}},
\]
and the minimization transform is
\[
\phi_i(x)=\frac{f_i^{MAX}-x}{f_i^{MAX}-f_i^{MIN}}.
\]
The paper states: “By formulas (1-2), values x are transformed into values [0,1], so that the best value among all players for a given criterion is 1, and the worst value for a given criterion is set to 0” [PAGE 2]. The four minimization criteria are “Offsides, Fouls, UnschTch, Dispossessed” [PAGE 2]. All normalized coordinates are dimensionless; they are not SI units. Counts are dimensionless, per-game rates are counts per match, pass accuracy is percent, and after normalization all enter as pure numbers in \([0,1]\).

The metric is the Minkowski family
\[
d_p(x,y)=\left(\sum_{k=1}^{n}|x_k-y_k|^p\right)^{1/p},
\]
with \(n=17\) and \(p=1\) for Manhattan distance [PAGE 3]. The paper states: “In our case, each player is considered a point in the 17-dimensional real space, as there are n = 17 parameters evaluating each player” [PAGE 3]. The similarity operator is therefore
\[
d_1(\mathrm{Messi},y)=\sum_{k=1}^{17}\left|\mathrm{Messi}_k-y_k\right|,
\qquad
\hat{y}=\arg\min_{y\in S} d_1(\mathrm{Messi},y),
\]
where \(S\) is the 28-player comparison set. The distance is dimensionless, with range \(0\le d_1\le 17\) in the normalized cube. It is not a probability; it is an absolute coordinate-sum deviation. The reported minimum is Coutinho at \(3.769\), followed by Hazard at \(4.069\) [PAGE 4, Table 1].

The correlation operator is Pearson’s \(\rho\), dimensionless in \([-1,1]\), with p-values as probabilities in \([0,1]\). The source reports “average passes-key passes (Pearson’s ρ =0.80***), dispossessed-dribbling (0.78***), dribbling-fouled (0.77***), or through balls-key passes (0.73***), where ‘***’ means statistically significant at p = 0.01 level” [PAGE 4]. These are linear-association summaries, not causal operators.
