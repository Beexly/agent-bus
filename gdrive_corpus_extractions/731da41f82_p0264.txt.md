I begin by isolating the explicit claims on [PAGE 247]: “there are only 27 disappearances in the fifth step, and only six disappearances in the tenth step”; “the latter would be a curve whose distance from the axis of x increased indefinitely, inasmuch as the expression [missing equation] is greater than one”; “Whenever f1 (x) can be represented by a binomial, as above suggested, we get the equation [missing equation] whence it follows that as r increases indefinitely the value of m0 approaches indefinitely to the value y where [missing equation] that is where y = 1”; “All the surnames, therefore, tend to extinction in an indefinite time”; “This result must not be confounded with that of the extinction of the male population; for in every binomial case where q is greater than 2, we have t1 + 2t2 + etc. + qt_q = 1, and, therefore an indefinite increase of male population”; and “The true interpretation is that each of the quantities, m1, m2, etc., tends to become zero, as r is indefinitely increased, but that it does not follow that the product of each by the infinitely large number N is also zero.”

Multi-hop derivation: Let X be the number of male heirs produced by one male. Define the offspring probability generating function f_1(x) = Σ_{k=0}^{q} t_k x^k, where t_k = P(X = k), t_k ≥ 0, Σ t_k = 1, and q is the maximum possible number of sons. The extinction probability of a single lineage by generation r is η_r = P(X_r = 0 | X_0 = 1), which recurs as η_{r+1} = f_1(η_r), η_0 = 0. Galton’s m_0 is the proportion (or expected count) of surnames with zero representatives, so m_0(r) tracks η_r. The limit y = lim_{r→∞} η_r solves y = f_1(y), the extinction fixed point. Crucially, y = 1 is always a fixed point; the extinction probability is the smallest non-negative root. If the mean offspring μ = f_1'(1) = Σ_{k=1}^{q} k t_k exceeds one, a root y < 1 exists, and extinction is not certain. Galton’s blanket assertion y = 1 therefore holds only in the subcritical or critical regime μ ≤ 1.

Gray-zone audit: The same page asserts that for q > 2 the male population increases indefinitely, which requires μ > 1. This is in tension with y = 1 if y is interpreted as the extinction probability of an arbitrary surname lineage. The resolution Galton gestures at is a double limit and a size-biased survivor effect: m_k(r)/N → 0 for each fixed surname count k, yet N · m_k(r) need not vanish because N is “infinitely large” and surviving surnames can carry “sometimes infinite” numbers of representatives. The non-commuting limit lim_{r→∞} lim_{N→∞} ≠ lim_{N→∞} lim_{r→∞} is the exact singularity regime. OCR dropouts of the displayed equations prevent exact verification of the fixed-point form; the phrase “qt_q = 1” likely contains an OCR or typographical error for a condition involving Σ k t_k > 1. I flag this as a breakdown regime: one cannot simultaneously maintain universal surname extinction (y = 1) and indefinite male population growth (μ > 1) under a standard single-type Galton–Watson law unless “extinction” refers to the vanishing proportion of original surnames while a few surviving names explode in size.

<SOURCE_OPERATORS_AND_EQUATIONS>
Formal operators and units. Let K ∈ {0, 1, ..., q} be the random number of male heirs per male, dimensionless count. Offspring law: t_k = P(K = k), k = 0,...,q, with Σ_{k=0}^{q} t_k = 1 and t_k ≥ 0. Probability generating function: f_1(x) = E[x^K] = Σ_{k=0}^{q} t_k x^k, x ∈ [0,1], dimensionless. Binomial specialization (if K ~ Binomial(q, p)): f_1(x) = (1 − p + p x)^q, with mean μ = q p.

Extinction recursion. η_0 = 0; η_{r+1} = f_1(η_r). Limit extinction probability: η = lim_{r→∞} η_r = min{ y ∈ [0,1] : y = f_1(y) }. Galton’s m_0(r) corresponds to η_r (or N η_r as an expected count). Claim on [PAGE 247]: “as r increases indefinitely the value of m0 approaches indefinitely to the value y ... that is where y = 1.” Valid iff μ ≤ 1. Breakdown: if μ > 1, η < 1, so not all surnames go extinct.

Population operator. Total male count at generation r: M_r = Σ_{k≥1} k · n_k(r), where n_k(r) is the number of surnames with exactly k male representatives. Expectation: E[M_r] = N μ^r, N = initial number of surnames (dimensionless). Regimes: μ < 1 ⇒ E[M_r] → 0 (population extinction); μ = 1 ⇒ E[M_r] = N (critical martingale, extinction a.s. but fluctuations O(√r)); μ > 1 ⇒ E[M_r] grows exponentially (indefinite increase). Galton’s [PAGE 247] claim “in every binomial case where q is greater than 2 ... an indefinite increase of male population” implies μ > 1, which contradicts a blanket y = 1 unless he means only that the proportion of surviving original surnames vanishes while surviving names carry exploding mass.

Double-limit singularity. Galton states [PAGE 247]: “each of the quantities, m1, m2, etc., tends to become zero, as r is indefinitely increased, but that it does not follow that the product of each by the infinitely large number N is also zero.” Formally: lim_{r→∞} m_k(r) = 0 for fixed k, but lim_{r→∞} N m_k(r) may be finite or non-zero because surviving surnames have heavy-tailed sizes. The number of extinguished surnames is order N [PAGE 247], while the number of surnames represented by one, two, three, ... representatives is “infinitely smaller but finite” [PAGE 247]. Exact breakdown: at μ = 1 the process is critical; expected population is constant but extinction is almost sure, and the separation between lineage loss and population count is maximal.

<RETROCAUSAL_GENEALOGY>
Historical lineage. Galton’s Appendix F in Natural Inheritance (1889), [PAGE 247], sits between Bienaymé’s 1845 branching-work, Rev. H. W. Watson’s problem of surname extinction, and the later formal Galton–Watson process. The quantities t_k, f_1(x), m_0, and the generational index r are proto-probability-generating-function machinery. Galton’s verbal insight that “a surname once lost can never be recovered” [PAGE 247] establishes an absorbing state at zero male representatives, the defining feature of a branching process with extinction.

Multi-week trap. In applied lineage forecasting—whether tracking family names, Y-chromosome haplotypes, or cultural markers over weeks-to-generations—the trap is to observe the early regime Galton tabulates (“27 disappearances in the fifth step, and only six disappearances in the tenth step” [PAGE 247]) and extrapolate a smooth, monotonic decline toward total cultural or biological extinction. Because the process is supercritical when μ > 1, the population curve’s “distance from the axis of x increased indefinitely” [PAGE 247] even as most surnames vanish. A short-horizon observer sees attrition; a long-horizon observer sees a winner-take-all surname lottery. The multi-week trap is therefore mistaking the vanishing proportion of original surnames for the vanishing of the people who bear them, precisely the conflation Galton warns against on [PAGE 247]: “This result must not be confounded with that of the extinction of the male population.”

<RECURSIVE_THEORY_OF_MIND>
Crisis habit regression. Under demographic stress—war, famine, epidemic—observers regress to the heuristic that disappearing surnames signal disappearing people. Galton explicitly blocks this on [PAGE 247]: surname extinction and male-population extinction are distinct events. The crisis habit is to treat the curve of surnames as a proxy for the curve of population.

Counter-trap. The correct counter-model conditions on non-extinction. Given a surname has survived to generation r, its expected size is size-biased: E[K | survival] > E[K] = μ. The few surviving names carry most of the population, so the population curve is driven by a rare-event upper tail, not by the modal surname. Recursively, an analyst modeling other analysts must expect policy-makers to regress to the “all surnames die ⇒ all people die” heuristic whenever the surname curve falls, and must deploy a counter-trap communication layer that separates lineage attrition from demographic growth.

Clock. The generational index r is the clock. At r = 5 and r = 10, disappearances are sparse and the surname distribution is still broad [PAGE 247]. As r → ∞, m_0/N → 1 under Galton’s reading, yet the surviving surnames’ representative counts grow without bound. The observer’s theory of mind must therefore nest two clocks: the lineage clock (extinction of names) and the population clock (growth of bodies). They run in opposite directions in the supercritical regime.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Layer 1 — Biological/reproductive. Veto: offspring number is not binomial(q,p); sex ratio at birth deviates from the assumption implicit in counting only male heirs; q is biologically capped by fecundity. If fired, f_1(x) is misspecified and the fixed-point y = 1 claim collapses.

Layer 2 — Social/transmission. Veto: surname transmission is not strictly patrilineal (name changes, adoption, matrilineal or double-barreled surnames, immigration reintroducing “lost” names). Galton’s premise “a surname once lost can never be recovered” [PAGE 247] then fails; extinction is not absorbing, and m_0 need not approach 1.

Layer 3 — Environmental/demographic (weather, famine, epidemic). Veto: μ is time-inhomogeneous, μ_r, with shocks (e.g., severe winters, pandemics) that drive μ_r below one for extended intervals. Indefinite increase of male population is then falsified; the process may hit extinction even if long-run average μ > 1.

Layer 4 — Mathematical/finite-scale. Veto: N is finite and r is bounded (e.g., only the first five generations are observed, as Galton calculated [PAGE 247]). The asymptotic double limit N → ∞, r → ∞ does not apply; m_0 does not approach 1 in any observable window.

Adjudication rule: If any layer veto fires, Galton’s joint conclusions (y = 1 and indefinite male increase) cannot be maintained. The model must be replaced by a multitype, time-inhomogeneous, or immigration-extended branching process. Physical clock: generation time τ (years), so r = t/τ; weather shocks at calendar times t_i enter as shocks at r_i = t_i/τ.
</CROSS_LAYER_VETO_ADJUDICATION>
