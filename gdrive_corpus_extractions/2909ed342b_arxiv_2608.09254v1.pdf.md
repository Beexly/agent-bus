<SOURCE_OPERATORS_AND_EQUATIONS>
**Formal operators, units, page citations, breakdown regimes.**

**Scope set and index.** $T$ = tasks in scope, $n=|T|$ (count, dimensionless integer; $n=80$ test, $240$ dev). For $t\in T$: $b^{*}(t)\in\{\text{ANSWER},\text{CLARIFY},\text{ABSTAIN},\text{REFUSE}\}$, emitted $b(t)$; $A=\{t:b(t)=\text{ANSWER}\}$, $Q=\{t:b^{*}(t)=\text{ANSWER}\}$ [PAGE 18]. Reconstructed $|Q|=40$ (derived in THINK_TRACE Hop 1; not printed in source).

**E1 — Business Truth Rate** [PAGE 18, Eq. 1], unit $[1]$, range $[0,1]$:
$$\mathrm{BTR}=\frac{1}{n}\sum_{t\in T}\mathrm{ok}(t).$$
*Breakdown:* none — defined for all $n\ge 1$. *Trap:* rewards a correct abstention exactly as a correct answer, so BTR alone permits a constant-abstain policy to score the non-answer mass.

**E2 — False Success Rate** [PAGE 18, Eq. 2], unit $[1]$:
$$\mathrm{FSR}=\frac{1}{|A|}\sum_{t\in A}\left(1-\mathrm{ok}(t)\right).$$
*Breakdown:* **undefined at $|A|=0$** (a system that declines everything). *Regime:* reported $0.351$ routed, $0.754$ 32B, $1.000$ 7B-direct [PAGE 9, Table 2].

**E3/E4 — Coverage and answer accuracy** [PAGE 18, Eqs. 3–4], unit $[1]$:
$$\text{cov}=\frac{|A\cap Q|}{|Q|},\qquad \text{acc}=\frac{1}{|A\cap Q|}\sum_{t\in A\cap Q}\mathrm{ok}(t).$$
*Breakdown:* $\text{acc}$ **undefined at $|A\cap Q|=0$**; $\text{cov}$ **undefined at $|Q|=0$**. *Trap:* covering everything forces cov $=1$ regardless of correctness — 7B retrieval achieves cov $1.000$ with acc $0.325$ [PAGE 9].

**E5 — Cost per correct answer** [PAGE 18, Eq. 5], unit $\mathrm{USD}\cdot(\text{correct answer})^{-1}$:
$$\mathrm{CPCA}=\sum_{t\in Q}c(t)\Big/\sum_{t\in A\cap Q}\mathrm{ok}(t).$$
*Breakdown:* **undefined when the denominator is zero** — the stated reason 7B direct is absent from Figure 3 [PAGE 9]. *Structural singularity:* a ratio of sums, not a mean of ratios; the paper notes it "cannot be bootstrapped … as one" and that "a resample in which either system returns no correct answer has no defined ratio" [PAGE 7]. Hence the interval is **conditioned on usable resamples**, a documented selection effect. Reported: $\$0.0017$ routed vs $\$0.0058$ 32B ($-71.0\%$); vs few-shot $\$0.0017$ vs $\$0.0018$ ($-6.5\%$, unresolved) [PAGE 9, Table 3].

**E6 — Per-task false-success share** [PAGE 19, Eq. 6], unit $[1]$:
$$\text{FS share}=\frac{1}{n}\sum_{t\in T}\mathbb{1}[t\in A\wedge \mathrm{ok}(t)=0]=\frac{|A|}{n}\,\mathrm{FSR}.$$
The right-hand identity is **derived here, not in the source**, and verified numerically in Hop 2. *Why it exists:* "a paired test needs one value per task over a fixed task list" [PAGE 19].

**E7 — Expected calibration error** [PAGE 19, Eq. 7], unit $[1]$ (weighted $L_1$):
$$\mathrm{ECE}=\sum_{i=1}^{10}\frac{|B_i|}{|A|}\left|\mathrm{acc}(B_i)-\mathrm{conf}(B_i)\right|,\qquad B_i\ \text{equal-width, fixed pre-run}.$$
*Breakdown/regimes:* (i) $|A|$ small → per-bin estimate variance $\propto p(1-p)/|B_i|$, and the binned estimator carries an upward finite-sample bias of order $B/|A|$; with $|A|=37$ and $B=10$, mean occupancy $3.7$, bins holding "a single answer," which the caption itself flags [PAGE 16]. (ii) If $\mathrm{conf}$ is constant, isotonic regression "collapsed them to a constant. Calibrating a constant is possible; ranking with it is not" [PAGE 6]. (iii) On $A\cap Q$ the pool is degenerate: acc $=1$, so ECE $\to$ measures only confidence offset, $0.011$ routed vs $0.556$ 32B [PAGE 16].

**E8 — Risk–coverage / AURC** [PAGE 16, Fig. 5]. *Breakdown:* risk $\equiv 0$ when all returned answers are correct → **AURC $=0$ for every ranker, no discrimination**; observed on validation, where both fitted and heuristic read $0.000$ [PAGE 16].

**E9 — Paired bootstrap** [PAGE 19]: $\bar d=\frac1n\sum_t(m_x(t)-m_y(t))$, percentile interval, $2000$ resamples, seed $9901$. *Breakdown:* validity requires exchangeable units; the design is family-disjoint, so units are dependent, and $G=10$ clusters is below any reliable percentile-bootstrap regime — the paper concedes "a cluster bootstrap over 10 clusters is an unreliable interval estimator in its own right" [PAGE 9].

**Physical/execution-layer operators.** Static gate = AST allowlist (no DML/DDL) + unknown table/column, alias, retired-column and forbidden-join checks. Execution = read-only connection, timeout, row cap, no network. Post-execution = filters-applied, period-applied, non-empty, no impossible values [PAGE 6]. **Measured both directions:** false-reject rate $0/140=0.000$ on golden SQL (an observed bound, "not a proof of soundness"); false-clean rate $14/86=0.163$ dev, $8/24=0.333$ validation [PAGE 6]. These two numbers are the paper's true epistemic operators: the gate is *sound on this sample, incomplete by construction*, and the residual $0.163$ is the entire addressable mass for any learned component.

**Cost basis** [PAGE 7]: generation billed at amortized $\approx\$0.50\cdot\mathrm{h}^{-1}$ hardware, execution at CPU-second for exactly one execution, sealed and quantized to $1\times10^{-6}$ USD because wall-clock re-measurement drifted $6\times10^{-6}$ USD under evaluator thread contention [PAGE 15].

**Authority table (rule vs model)** [PAGE 18, Table 6]: safety, period, coverage, dimension validity, term uniqueness, SQL admissibility, result trustworthiness → **rule**; metric choice, schema-gap report → **model, re-checked**; SQL generation → **model**; confidence → **model fitted on dev**; disposition → **validation threshold**. **Genealogy (retrocausal chain).** Spider (Yu et al., 2018) establishes cross-domain semantic parsing and execution/exact-set match; BIRD (Li et al., 2023) adds dirty data; test-suite accuracy (Zhong et al., 2020) tightens match by distilling discriminating inputs; Spider 2.0 (Lei et al., 2025) exposes the enterprise gap [PAGE 2]. All four presuppose a reference query. AmbiQT (Bhaskar et al., 2023) and Wang et al. (2023) attack ambiguity, and TrustSQL (Lee et al., 2024) is named the closest prior position — reliability scored with penalties for confident wrongness [PAGE 2]. The decisive genealogical break is stated verbatim: "The difference here is where the decision is made. Those systems ask a model to detect the problem; QueryProof decides ambiguity and answerability by rule" [PAGE 3]. The selective-prediction line (El-Yaniv & Wiener, 2010; Geifman & El-Yaniv, 2017), calibration line (Guo et al., 2017; Naeini et al., 2015) and self-report line (Kadavath et al., 2022; Lin et al., 2022) supply the negative-result apparatus, with self-report deliberately excluded [PAGE 3]. Execution-guided decoding (Wang et al., 2018) is the ancestor of execution grounding, but the paper is precise that its use is "downstream of that and different in kind" [PAGE 3]. Semantic layers (dbt MetricFlow, LookML, Cube, Malloy) are the enabling substrate absent from prior text-to-SQL evaluation: "'revenue' is ambiguous because the layer defines two revenue metrics, not because a model finds it confusing" [PAGE 3].

**Trap 1 — validation reuse.** "The validation split was evaluated six times during development, plus once more to select the routing threshold" [PAGE 11]. Consequence: every validation figure is optimistic, and the threshold it produced over-abstains out of sample. This trap is *unrecoverable* under the one-run rule.

**Trap 2 — schema-drift immunity as an artifact.** The agent scores $1.000$ on drift versus $0.000$ for all baselines [PAGE 9]. This looks like robust generalisation but is a consequence of the rule layer reading the physical catalog, which is exactly the thing that must be maintained by hand when a metric definition changes [PAGE 2]. The trap is deferred maintenance debt disguised as a capability.

**Trap 3 — denominator drift.** Six scoring corrections, "four of them after results had already been reported internally"; three were denominator errors; "Only the first two changed a number," forcing the v0.2.0 bump [PAGE 14–15]. That is the same defect the routing ablation reintroduced empirically — a metric-form trap and a behaviour trap converging.

**Trap 4 — the golden-SQL validator bug.** An invalid-join rule read "no direct key between these tables" as "these tables may never co-occur," rejecting two template families' own golden SQL [PAGE 17]. The paper names it correctly: "not evidence about the model at all, but evidence of a missing regression test" [PAGE 18]. A validator that fails its own ground truth is the purest multi-week trap: it silently reclassifies agent defects as model defects for as long as no one runs the guard.

<RECURSIVE_THEORY_OF_MIND>
**Crisis habit regression vs. counter-trap vs. clock.** *Remap note: "crisis habit regression" = fallback to the pre-crisis policy under distribution shift; "counter-trap" = the corrective over-fires into the mirror error; "clock" = the irreversible temporal commitment that forecloses repair.*

**The regression.** Under the shift from validation to test, the *learned* component regressed to its training-pool habit. Fitted on dev answers to answerable questions only, it "never learned to doubt an answer given where a clarification was required, which is exactly what the test split punishes" [PAGE 16]. AURC $0.436$ vs $0.164$; ECE $0.337$ vs $0.189$; Brier $0.336$ vs $0.253$ [PAGE 10]. Under stress it did not fail randomly — it reverted to confident answering, the baseline habit it was built to correct.

**The counter-trap.** The deterministic layer's success *created* the mirror error. Because abstention is cheap and false success is expensive, the routed policy over-abstains: coverage $0.700\to0.600$ while answer accuracy $0.929\to1.000$ [PAGE 10]; 12 answerable questions declined, against 8 for the base agent, plus 4 over-clarifications [PAGE 10, PAGE 19 Table 7]. BTR moves the *wrong* way: $0.738\to0.537$ on test, $0.725\to0.562$ for base — a reversal of ordering across splits [PAGE 20, Table 10]. The paper's own summary is exact: "it declines questions it could have answered far more often than it answers questions it should have declined" [PAGE 2]. The behavioural symmetry is the finding: 32B returns 4 silent wrong answers and answers all 16 ambiguous questions outright; QueryProof returns 0 silent wrong answers and 13 unwarranted ones. "Both systems fail; they fail in opposite directions" [PAGE 10].

**The clock.** Two clocks are running and only one is stopped. The agent's *inference* clock is deterministic — temperature zero, sealed cost, replay-reproducible from `results.json` with 26 input hashes [PAGE 14]. The *epistemic* clock is stopped by the one-run rule: "The frozen test split was then evaluated once, on 80 tasks, one pass per system, and is now spent. Nothing in this paper re-runs it" [PAGE 8]. The consequence is explicit — the threshold "was not re-tuned, because that needs a second evaluation of a spent split, so treat the operating point as an illustration rather than a recommendation and select it on data from your own distribution" [PAGE 12]. The honest theory of mind here is that the authors chose *unrecoverable error over recoverable ambiguity*, which is the right trade for confirmatory claims and the wrong trade for an engineering recommendation — and they say so.

<RLVR_COUNTERFACTUAL_VETOES>
**Three verifiable-reward counterfactuals, each with a pre-stated veto and a falsifiable prediction.** Each is designed so that an RLVR loop with a *machine-checkable* reward (execution equivalence, gate passage, or behaviour-contract match) would be predictably misled by a mechanism this paper quantifies.

**Counterfactual V1 — reward = gate passage ("verified ⇒ positive").**
*Design:* run RLVR on dev traces where reward $=1$ iff static validation and post-execution verification both pass; train the 7B on 200 rollouts/iteration, 5 iterations, greedy eval on the frozen test split.
*Mechanism:* the verification layer's false-clean rate is $0.163$ on dev and $0.333$ on validation [PAGE 6] — i.e., 16–33% of positively-rewarded trajectories are wrong, and the paper states the gates are "demonstrably incomplete" [PAGE 6].
*Veto:* the reward is a noisy labeler with a *directional* bias, because the surviving errors concentrate on the strata the reward never discriminates.
*Prediction (falsifiable):* FSR on returned answers rises monotonically across iterations from $0.351$ while coverage stays flat — i.e., the loop learns to *satisfy the gate*, not to be right. *Kill criterion:* if FSR does not increase by iteration 3 relative to iteration 0 at fixed coverage, V1 is refuted and gate-passage is a usable RLVR reward on this benchmark.

**Counterfactual V2 — reward = BTR with abstention permitted (the abstention-hack).**
*Design:* reward $=1$ on any task where the emitted behaviour matches $b^{*}(t)$, including correct CLARIFY/ABSTAIN/REFUSE. Because BTR counts a correct abstention identically to a correct answer [PAGE 18, Eq. 1], the reward surface is flat along the decline axis.
*Mechanism:* the paper already demonstrates this exact hack *without* training — the validation-tuned routing policy moved BTR from $0.725$ to $0.738$ on validation and then to $0.537$ on test, by declining 12 answerable questions [PAGE 10, PAGE 20].
*Veto:* BTR is not a proper scoring rule; it is invariant to the answer/decline trade-off.
*Prediction (falsifiable):* any BTR-maximizing RLVR run will drive coverage below $0.500$ on held-out data while answer accuracy saturates at or near $1.000$, and BTR will fail to improve because the abstention mass is capped by the $|Q|/n=0.5$ split. *Kill criterion:* if coverage stays $\ge 0.60$ and BTR exceeds $0.562$ (the base agent's test figure) on a fresh family-disjoint split, V2 is refuted.

**Counterfactual V3 — data-starvation / power veto on post-training itself.**
*Design:* the paper's own pre-registered gate — $\ge 100$ verified examples of recurring errors unsolved by prompting and retrieval. After the deterministic defect sweep the pool was 20, "five times below the threshold," with failures falling $33\to28$ and agent defects $21\to8$ [PAGE 18, PAGE 20]. The paper therefore declares the hypothesis "untested by design" rather than refuted [PAGE 2].
*Mechanism:* with $n=80$ and $\mathrm{BTR}\approx0.54$, the binomial standard error is $\sqrt{0.54\cdot0.46/80}=0.056$, giving a 95% half-width $\approx0.109$ — matching the reported $[0.425,0.638]$. A 20-example RLVR run cannot move BTR beyond that noise floor by any mechanism.
*Veto:* statistical, not architectural — the effect is unresolvable at this $n$ regardless of method quality.
*Prediction (falsifiable):* a 20-example RLVR fine-tune will produce a BTR change with a paired interval spanning zero against the untuned agent, and that interval will be *indistinguishable* from the interval a random-weight fine-tune produces. *Kill criterion:* if the RLVR arm's paired BTR interval excludes zero against both the untuned agent and a shuffled-label control, the gate was mis-set and the paper's decision was wrong.

**Aggregate veto.** All three counterfactuals share one root: the deterministic layer has "already absorbed the errors" any learned component would target [PAGE 2], so RLVR's verifiable signal is simultaneously (i) noisy in the wrong direction (V1), (ii) indifferent to the failure mode that remains (V2), and (iii) starved of any population on which it could be measured (V3). The correct sequencing claim, which the paper makes and then declines to over-claim, is: *build and measure the deterministic layer first; then test any confidence model fit on the answers it admits, on a split never used to tune it* [PAGE 13].
