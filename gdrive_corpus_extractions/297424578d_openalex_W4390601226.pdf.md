1. Video frames are indexed by \(j \in \{1,\dots,T\}\). The source states that videos are “down-sampled to 5 FPS” [PAGE 11], so the sampling rate is  
\[
r = 5\ \mathrm{Hz} = 5\ \mathrm{frames/s}.
\]
Frame time is  
\[
t_j = \frac{j}{r}\ \mathrm{s}.
\]

2. The model operates over a frame or token sequence \(R\). The source describes obtaining “a sequence of frame representations (R)” [PAGE 10]. Let  
\[
R = [r_1, r_2, \dots, r_T] \in \mathbb{R}^{T \times d_v},
\]
where \(d_v\) is the visual feature dimension. The attention uses query, key, and value vectors \(q_j, k_i, v_i \in \mathbb{R}^d\), with hidden dimension set to  
\[
d = 512
\]
per the source: “The hidden dimension d is set to 512” [PAGE 11].

3. The focal-length set is discrete. The implementation says  
\[
\mathcal{F} = \{3, 9, 80\}
\]
with the statement “We set the attention focus to F = {3, 9, 80}” [PAGE 11]. The source describes these as covering short-term, mid-term, and long-term dependencies.

Core equation:

The Auto-Focus Attention equation is given as Equation (1) in the source: “AFA(q j)” with a sum over focal lengths and neighbors [PAGE 10]. Formally, under the source’s definitions,

\[
\mathrm{AFA}(q_j)
=
\sum_{f \in \mathcal{F}}
\alpha_f
\sum_{i \in D_j(f)}
\operatorname{softmax}_i
\left(
\frac{q_j^\top k_i}{\sqrt{d}}
\right)
v_i .
\]

The neighborhood is defined by the source as  
\[
D_j(f) = \{ i \mid |i-j| \le f \},
\]
where “D f j = {i||i − j| ≤f } is the index set of the neighbours of q j within focal length f” [PAGE 10].

The focal attention probability for neighbor \(i\) under focal length \(f\) is  
\[
A_{ij}^{(f)}
=
\frac{
\exp\left(
\frac{q_j^\top k_i}{\sqrt{d}}
\right)
}{
\sum_{m \in D_j(f)}
\exp\left(
\frac{q_j^\top k_m}{\sqrt{d}}
\right)
}.
\]

Units and interpretation:

- \(A_{ij}^{(f)}\) is dimensionless and lies in \([0,1]\).
- For fixed \(j\) and \(f\),  
\[
\sum_{i \in D_j(f)} A_{ij}^{(f)} = 1.
\]
- \(d\) is dimensionless channel dimensionality. The scaling by \(\sqrt{d}\) is a normalization operator that controls the variance of the dot-product logit.
- \(f\) has units of frame index if \(D_j(f)\) is interpreted directly as an index set. If \(f\) is intended to represent seconds, then the neighborhood must be converted to frame units.

Two temporal-unit formalizations are possible:

Frame-radius interpretation:
\[
D_j(f) = \{ i \mid |i-j| \le f \}, \qquad \tau = \frac{f}{r}\ \mathrm{s}.
\]
At \(r = 5\ \mathrm{Hz}\),  
\[
f = 3 \Rightarrow \tau = 0.6\ \mathrm{s},
\]
\[
f = 9 \Rightarrow \tau = 1.8\ \mathrm{s},
\]
\[
f = 80 \Rightarrow \tau = 16\ \mathrm{s}.
\]

Seconds-radius interpretation:
\[
D_j(\tau) = \left\{ i \mid \frac{|i-j|}{r} \le \tau \right\}.
\]
If the intended long-term radius is \(80\ \mathrm{s}\), then  
\[
f = r \tau = 5 \times 80 = 400\ \mathrm{frames}.
\]

This distinction is essential because the source says “for long-term (global) dependency, we set the focal length to the video length, which is 80 seconds” [PAGE 13], while Equation (1) uses index neighborhoods.

Question-conditioned focal weights:

The source states that the focal weights are obtained from the question: “α = {α f }|F| f =1 are obtained by applying linear projection and softmax to the global representation of question” [PAGE 10]. Let \(w\) be the global question representation. A minimal formalization is

\[
\alpha = \operatorname{softmax}(W_\alpha w + b_\alpha),
\]
with componentwise form  
\[
\alpha_f
=
\frac{
\exp(u_f^\top w + b_f)
}{
\sum_{f' \in \mathcal{F}}
\exp(u_{f'}^\top w + b_{f'})
}.
\]

Constraints from the source:

\[
\alpha_f \in (0,1),
\qquad
\sum_{f \in \mathcal{F}} \alpha_f = 1.
\]

The source explicitly states that “α f ∈(0, 1) is the dynamic weight of focus f” and that the weights sum to one [PAGE 10].

Focus concentration can be measured by Shannon entropy in bits:

\[
H(\alpha)
=
-\sum_{f \in \mathcal{F}}
\alpha_f \log_2 \alpha_f
\quad \mathrm{bits}.
\]

For \(|\mathcal{F}| = 3\),  
\[
0 \le H(\alpha) \le \log_2 3 \approx 1.585\ \mathrm{bits}.
\]

This is not a performance predictor; it is a diagnostic of temporal-scale concentration. If \(H(\alpha)=0\), one focal length dominates. If \(H(\alpha)=\log_2 3\), the focal distribution is uniform.

The source says “the multi-head AFA is deﬁned likewise” [PAGE 10]. For head \(h\),

\[
\mathrm{AFA}^{(h)}(q_j^{(h)})
=
\sum_{f \in \mathcal{F}}
\alpha_f^{(h)}
\sum_{i \in D_j(f)}
A_{ij}^{(h,f)}
v_i^{(h)}.
\]

The head outputs are concatenated or projected into the fused representation. The exact projection is not specified in the source, so this is an architectural assumption rather than a quoted operator.

Evaluation operators:

The benchmark uses accuracy and F1-score. Accuracy is

\[
\mathrm{Acc}
=
\frac{1}{N}
\sum_{n=1}^{N}
\mathbf{1}[\hat{y}_n = y_n],
\]
where \(\hat{y}_n\) is the predicted answer class and \(y_n\) is the ground-truth class. Accuracy is dimensionless.

For F1-score, let precision be  
\[
P = \frac{\mathrm{TP}}{\mathrm{TP} + \mathrm{FP}},
\]
and recall be  
\[
R = \frac{\mathrm{TP}}{\mathrm{TP} + \mathrm{FN}}.
\]
Then  
\[
F_1 = \frac{2PR}{P+R}.
\]

The source states that “we evaluate methods using F1-score” because of the long-tail answer distribution [PAGE 11]. The answer distribution is described as long-tailed: “the distribution of answers is long-tailed, and the unbalanced nature adds to the challenge of our dataset” [PAGE 9].

Breakdown regimes:

1. Missing-cue regime.  
Let \(C\) be the visual event required to answer a question, for example the presence of a block immediately before a shot. If \(C\) is not included in the attended set, then the model cannot use it. Formally, if \(i_C \notin D_j(f)\) for every \(f\) with \(\alpha_f > 0\), then the contribution of \(C\) to \(\mathrm{AFA}(q_j)\) is zero. In this regime, the posterior over the answer cannot depend on \(C\) through the temporal attention path.

2. Unit-mismatch regime.  
If \(f=80\) is interpreted as 80 frames at 5 FPS, the temporal radius is 16 seconds. If the intended dependency is 80 seconds, the model fails to cover the required context unless \(f=400\) frames. This is a representational breakdown caused by unit conversion.

3. Overly narrow focal regime.  
If the relevant action duration is \(\Delta_a\) seconds, the minimum frame radius needed to observe the full action is approximately  
\[
f_{\min} \approx \frac{r \Delta_a}{2}.
\]
The MultiSports statistics report an average action duration of “1.0s” [PAGE 5]. At \(r=5\ \mathrm{Hz}\),  
\[
f_{\min} \approx \frac{5 \times 1.0}{2} = 2.5,
\]
so a focal length below approximately 2 or 3 frames may truncate an average action. This is a biomechanical representational limit, not a training heuristic.

4. Global-dilution regime.  
If \(f\) is so large that nearly all frames are included, the attention distribution may assign mass to irrelevant frames. The source observes that “the model with global attention performs less effectively compared to those with local attention” [PAGE 13]. Formally, increasing \(|D_j(f)|\) increases the denominator in softmax without necessarily increasing the signal mass, which can reduce the relative weight of the relevant frames.

5. Focus-collapse regime.  
If \(\alpha\) becomes nearly one-hot, the model loses multi-scale capacity. If \(\alpha\) becomes uniform, the model may average incompatible temporal scales. The entropy \(H(\alpha)\) diagnoses these regimes but does not by itself determine correctness.

6. Closed-label regime.  
Because answers are restricted to 191 classes [PAGE 9], any true answer outside this set is unrepresentable. If the semantic target is \(y^\star\) and \(y^\star\) is not in the label set, the minimum achievable classification error is positive under a closed-world assumption.

7. Template-correlation regime.  
The authors remove or balance answers when a meta-question has an overly frequent answer: “If an answer to a meta-question occurs more frequently than other answers (frequency larger than 0.5), we randomly remove the corresponding QA pairs” [PAGE 8]. This reduces, but does not necessarily eliminate, question-only shortcuts. BlindQA results show that residual correlation remains: BlindQA achieves substantial accuracy and F1 compared with random or frequency baselines [PAGE 12].

<RETROCAUSAL_GENEALOGY>
The lineage of Sports-QA is a convergence of general VideoQA, fine-grained sports action recognition, and transformer-based temporal attention. The paper positions itself against general VideoQA datasets such as TGIF-QA, MSVD-QA, MSRVTT-QA, DramaQA, and NExT-QA [PAGE 3]. These datasets established template-based or manually annotated question-answering tasks, but they mostly focus on everyday video understanding or coarse-grained event reasoning. The source says Sports-QA addresses “ﬁne-grained and professional analysis within sports scenarios” [PAGE 3].

The sports-action lineage comes from MultiSports and FineGym. MultiSports provides spatio-temporal localization of professional sports actions across basketball, football, volleyball, and aerobic gymnastics, with 66 fine-grained action categories [PAGE 4]. FineGym provides hierarchical gymnasium action annotations at action and sub-action levels [PAGE 4]. The source chooses these because “Both sources provide high-quality sports videos with well-deﬁned action labels” [PAGE 2]. This lineage matters because professional sports labels are not atomic verbs such as “run” or “stand”; they include terms such as “volleyball spike,” “football tackle,” and “basketball defensive rebound” [PAGE 4]. The model must therefore reason over semantically narrow, visually rapid events.

The VideoQA-method lineage includes memory networks, heterogeneous graphs, hierarchical graphs, and invariant grounding. The benchmark compares CoMem, HME, HGA, HQGA, IGV, and MASN [PAGE 12]. The source notes that earlier approaches often lack consideration that “different questions may require temporal dependencies of speciﬁc scales” [PAGE 4]. This is the historical gap that AFT addresses. The transformer lineage is explicit: AFT is a Transformer encoder with a modified attention mechanism, and the baseline replaces AFT with a standard Transformer Encoder [PAGE 13].

The multi-week traps in this genealogy are recurring failure modes that appear when a benchmark is designed or mined repeatedly:

1. Coarse-feature trap.  
Early sports models may rely on global appearance or scene context. The source cites Shao et al. to argue that “coarse-grained global video understanding is insufﬁcient for sports analysis where the actions are rapid and hard to differentiate” [PAGE 2]. If a model encodes only global context, it cannot distinguish actions with similar scenes but different motion dynamics.

2. Pretraining mismatch trap.  
The source says “the models pre-trained on coarse-grained datasets are not always beneﬁcial to ﬁne-grained tasks” [PAGE 2]. This is a historical trap because large-scale pretraining can improve general recognition while suppressing fine-grained temporal distinctions.

3. Question-answer correlation trap.  
BlindQA demonstrates that questions alone can predict answers above chance [PAGE 12]. If a benchmark is not carefully debiased, models learn the template-answer distribution rather than the video. Sports-QA attempts to counter this by balancing answer frequencies when a meta-question has an overly dominant answer [PAGE 8].

4. Temporal-shortcut trap.  
Many VideoQA models can answer descriptive or causal questions using local cues but fail on temporal ordering. The source observes that “results for temporal questions are similar between VideoQA methods and BlindQA (except for our AFT)” [PAGE 12]. This suggests that temporal reasoning is not automatically induced by visual feature extractors.

5. Global-attention trap.  
A standard transformer can attend globally, but global attention may not respect the question-specific temporal scale. The source reports that “the model with global attention performs less effectively compared to those with local attention” [PAGE 13]. AFT’s focal mixture is a correction to this historical bias.

6. Chain-of-thought hallucination trap.  
The source reports that chain-of-thought variants of some multimodal models perform worse than their baselines, likely because additional reasoning text introduces noise or hallucinated visual details [PAGE 14]. This is a modern trap: explicit reasoning is not automatically beneficial if the underlying visual evidence is weak.

The retro-causal lesson is that Sports-QA is not merely a dataset addition; it is a corrective artifact against several historical shortcuts. It forces the field to separate question semantics, answer priors, visual action evidence, and temporal-scale inference.

<RECURSIVE_THEORY_OF_MIND>
A recursive theory-of-mind analysis treats the benchmark as an adversarial environment in which dataset designers anticipate model habits, models adapt to benchmark incentives, and designers then tighten evaluation to prevent overfitting to shortcuts.

The first recursive layer is the model’s theory of the benchmark. A model trained on Sports-QA can infer that questions beginning with “Do” or “Is” often require binary answers, while questions beginning with “How many” require numeric answers. The source formalizes this through semantic-aware baselines: binary questions can only choose from “yes” or “no,” and counting questions choose numbers [PAGE 11]. If a model learns only this mapping, it can achieve non-trivial accuracy without visual grounding. This is the crisis habit regression: when visual evidence is weak or ambiguous, the model regresses to the answer prior induced by question type.

The second recursive layer is the designer’s counter-trap. The authors reduce answer frequency bias by examining meta-questions and removing or balancing answers when one answer occurs with frequency greater than 0.5 [PAGE 8]. They also balance questions with respect to spatial and temporal terms, reporting that “the distribution of questions is balanced with respect to both spatial and temporal attributes” [PAGE 9]. This is a direct counter to models that would otherwise infer answers from directional or temporal wording alone.

The third recursive layer is the model’s adaptation to visual features. Models such as CoMem, HME, HGA, HQGA, and IGV use appearance, motion, graphs, or invariant grounding [PAGE 12]. These methods improve over BlindQA, showing that visual evidence matters. However, the source notes that improvements vary by sport: basketball improves substantially, while football improves less because question-answer correlation may already be high [PAGE 12]. This means the model must decide when visual evidence is diagnostic and when it is redundant with the question prior.

The fourth recursive layer is temporal-scale awareness. AFT introduces question-conditioned focal weights \(\alpha_f\). The model’s internal state now includes not only the answer distribution but also a latent estimate of the required temporal scale. The visualization shows that specific-action questions rely on short-term focus, counting questions rely on long-term focus, and relational questions prefer mid-term focus [PAGE 14]. This is a theory of the question’s temporal intent.

The crisis habit regression can be stated probabilistically. Let \(Q\) be the question, \(V\) the video, and \(A\) the answer. A shortcut model approximates  
\[
P(A \mid Q)
\]
instead of  
\[
P(A \mid Q, V).
\]
The counter-trap is to force dependence on \(V\) by making question-only priors less informative. The clock is the temporal-scale variable: if the model can infer whether the question requires short-term, mid-term, or long-term evidence, it can allocate attention more appropriately. AFT’s focus weights are an explicit clock over temporal scale.

The clock can fail in three ways:

1. Fast clock failure.  
If the question requires a local event but the model uses long-term focus, the local cue is diluted. The source’s focus-weight visualization shows that local action questions need short focus [PAGE 14]. If \(\alpha_{3}\) is too small, the model may miss the event.

2. Slow clock failure.  
If the question requires counting or global aggregation but the model uses short focus, it may only observe a fragment. The source says counting questions such as “How many times does the right team do ‘block’?” require stronger long-term information [PAGE 14].

3. Miscalibrated clock.  
If the question representation \(w\) is weak, the projection to \(\alpha\) may be noisy. The source explored a two-layer MLP and found comparable results to linear projection [PAGE 10], suggesting that the bottleneck is not necessarily the complexity of the focal-weight projection. The bottleneck may be the quality of the global question representation.

The recursive endgame is that models trained on Sports-QA may eventually learn the benchmark’s debiasing logic. They may infer that answer balance and question-type constraints have been enforced. At that point, the benchmark must add new sports, new action vocabularies, or open-ended evaluation to prevent overfitting. The limitation section already anticipates this by acknowledging that the 191-class answer pool limits free-form generation and semantic diversity [PAGE 16].
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The cross-layer veto asks whether physical, biomechanical, or environmental constraints make a predicted answer inadmissible even if the classifier produces a label. The answer is yes. A model should veto or abstain when the required visual evidence is not present in the observed video representation.

Formal proof of missing-cue veto:

Let \(X\) be the full video signal, \(Z = g(X)\) the model’s processed representation, and \(Y\) the correct answer. If \(Z\) is a deterministic function of \(X\), the data-processing inequality gives  
\[
I(Y;Z) \le I(Y;X).
\]
If a relevant event \(C\) is not represented in \(Z\), then \(Z\) contains no information about \(C\) beyond what is already present in unrelated variables. If \(C\) is necessary for determining \(Y\), then the model cannot recover \(Y\) from \(Z\) alone.

Let \(C\) be the event that the required action or cue is observable in the attended temporal window. If \(C=0\), then  
\[
P(Y \mid Z, C=0) = P(Y \mid Z, \text{no relevant cue}).
\]
If the remaining observed variables are not informative about \(Y\), this posterior collapses toward the prior. Therefore, a confident answer under \(C=0\) is not evidentially justified. This is a veto condition.

Biomechanical veto:

The MultiSports statistics report an average action duration of “1.0s” [PAGE 5]. At 5 FPS, a 1.0s action spans approximately 5 frames. If the attended neighborhood is shorter than the action span, the model may see only part of the action. For frame-radius focal length \(f\), the total temporal span is  
\[
\Delta t = \frac{2f}{r}.
\]
At \(r=5\ \mathrm{Hz}\),  
\[
f=1 \Rightarrow \Delta t = 0.4\ \mathrm{s},
\]
which is shorter than the average action duration. Therefore, a model using only \(f=1\) for an average-duration action is in a biomechanical breakdown regime: it cannot observe the full event. A veto is justified if the question depends on the completion or effect of that action.

The source defines Cause of Action as actions that cause the current action and says these causes are “mostly temporally adjacent to the current action” [PAGE 6]. If the causal antecedent lies outside the attended window, the causal explanation is missing. For example, a volleyball spike may be caused by a preceding pass or set. If the model attends only to the spike itself, it cannot identify the cause. A causal answer generated without the antecedent should be vetoed as unsupported.

Environmental or visual-quality veto:

The data source selection requires that “The visual quality of the video data should be high enough to conduct ﬁne-grained video understanding” [PAGE 4]. This includes resolution and frame rate. If a video is degraded by occlusion, motion blur, low resolution, or adverse lighting, the visual channel may not preserve the discriminative cues needed for fine-grained action recognition.

Let \(E\) be environmental state, with \(E=1\) for adequate visual quality and \(E=0\) for degraded quality. The relevant mutual information is  
\[
I(Y;Z \mid E=0).
\]
If adverse conditions remove or corrupt the discriminative action cue, then  
\[
I(Y;Z \mid E=0)
\]
may be too low to support reliable inference. The source does not provide a numerical threshold for adequacy, so no exact threshold is asserted here. However, the qualitative veto condition is valid: if the required cue is not observable, the model should abstain or flag insufficient evidence.

Weather is not central to the cited MultiSports and FineGym sources, which are primarily gymnasium and ball-game videos, but the same veto applies to any environmental factor that changes the observation channel. For outdoor sports, rain, glare, shadow, or camera shake could violate the high-quality visual assumption. The formal requirement is that the observation channel preserve the mutual information between the video and the action label.

Temporal-window veto:

For a question requiring relation between actions \(A_i\) and \(A_j\), let their temporal separation be  
\[
\Delta t_{ij} = \frac{|i-j|}{r}.
\]
If the active focal radius satisfies  
\[
\frac{f}{r} < \Delta t_{ij},
\]
then action \(A_i\) is outside the neighborhood of query \(A_j\). If \(\alpha_f\) places negligible mass on any focal length covering \(\Delta t_{ij}\), the relation is not representable. The model should veto a relational answer under this condition.

The source’s focal-length analysis shows that mid-term information is useful for relationships between actions: “Questions pertaining to the relationships between two actions show a preference for mid-term information” [PAGE 14]. If mid-term focus is unavailable or misweighted, relational questions are under-supported.

Closed-label veto:

Because answers are treated as 191 classes [PAGE 9], a model may be forced to choose an answer even when the correct response is outside the label set. If the true semantic response \(y^\star\) is not in the label pool, the optimal classifier under the closed-world assumption is the closest available class, but this is not necessarily correct. The veto condition is: if the model’s posterior mass is dispersed or if the predicted class probability is below an abstention threshold, the model should reject rather than force a class.

This is especially relevant for counterfactual questions. The template “Would SOME-TEAM succeed in doing the i-th SOME-ACTION if the other team did not do SOME-ACTION?” [PAGE 17] asks about a hypothetical event not present in the video. If the causal relation is not explicitly annotated or inferable from sports rules, the answer is underdetermined. A cross-layer veto should trigger when the counterfactual premise has no observable or annotated causal support.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
RLVR-style evaluation requires that rewards be assigned only when a prediction is verifiable from the available evidence. In Sports-QA, three verifiable veto scenarios are especially important.

Veto scenario 1: Counterfactual premise absent.

Sports-QA includes counterfactual questions such as “Would SOME-TEAM succeed in doing the i-th SOME-ACTION if the other team did not do SOME-ACTION?” [PAGE 17]. The video contains the factual sequence, not the alternative sequence. Therefore, the answer is not directly observable. It requires a causal model of the sport, such as knowing that if a blocker fails to block, the attacker is more likely to score.

Verifiable veto rule:  
If the video does not contain the counterfactual condition and the dataset does not provide a validated causal rule for the queried action pair, the model should abstain or return a low-confidence causal estimate rather than a categorical answer.

Prediction:  
A model rewarded only for matching the template answer will overpredict counterfactual outcomes based on correlation. A model with an RLVR veto should reduce false confident answers on counterfactual items. Measurable signature: counterfactual accuracy should not be treated as visual grounding accuracy unless abstention is penalized separately. If abstention is allowed, the verifiable correctness rate should increase because unsupported counterfactual answers are filtered.

Veto scenario 2: Temporal lag outside focal support.

Causal and temporal questions depend on adjacent actions. The source says causes are “mostly temporally adjacent to the current action” [PAGE 6]. AFT uses focal lengths \(\{3,9,80\}\) [PAGE 11]. If the relevant lag between cause and effect exceeds the effective focal radius, the model cannot observe the relation.

Verifiable veto rule:  
Let \(\Delta t_{ij}\) be the temporal separation between the query action and the required antecedent or consequent action. If  
\[
\frac{f_{\max}}{r} < \Delta t_{ij},
\]
where \(f_{\max}\) is the largest effective focal radius, the temporal relation is unverifiable from the attended representation. The model should veto or abstain.

Prediction:  
If focal length is interpreted as frames, \(f=80\) covers only 16 seconds at 5 FPS. If the intended global scale is 80 seconds, then \(f=80\) is insufficient and should fail on long-range temporal questions. If focal length is interpreted as seconds, then \(f=80\) covers the full 80-second clip. The benchmark should report results under both unit interpretations. A verifiable prediction is that temporal accuracy will be sensitive to focal-length unit conversion, and that models with correctly scaled long-term focus will outperform models with truncated long-term focus on questions requiring cross-action counting or long-range ordering.
