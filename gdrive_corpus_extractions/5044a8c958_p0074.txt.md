**Theorem A (Cover Comparison)**  
For any \(E \in \mathscr{H}(\Sigma)\):  
\[
\underline{\mu}(E) \le \mu^*(E) \le \mu^+(E)
\]  
where \(\mu^*(E)\) (resp. \(\mu^+(E)\)) is the infimum (resp. supremum) of \(\mu(G)\) (resp. \(\mu(A)-\mu(B)\)) over \(G \in \Sigma\), \(A,B \in \Sigma\) with \(G \subseteq E\) (resp. \(B \subseteq E \subseteq A\)).  

**Theorem B (Existence of Measurable Kernels)**  
Given \(E \in \mathscr{H}(\Sigma)\), let \(\tilde{E}\) be a measurable cover of \(E\) (\(\mu(\tilde{E}) = \mu^+(E)\)), and let \(N\) be a measurable cover of \(E-\tilde{E}\) (\(\mu(N) = \mu^+(E-\tilde{E})\)). Define \(F = E - N\). Then \(F\) is a measurable kernel of \(E\).

**Theorem C (Kernel Measure and Uniqueness)**  
If \(E \in \mathscr{H}(\Sigma)\) and \(F\) is a measurable kernel, then:
1. \(\mu(F) = \underline{\mu}(E)\).
2. If \(F_1,F_2\) are both measurable kernels of \(E\), then \(\mu(F_1 \triangle F_2)=0\).

**Equational Proof of \(\mu(F)=\overline{\mu}(E)\):**
Assume \(\overline{\mu}(E) < \infty\) (the case \(\overline{\mu}(E)=\infty\) is handled separately). By the definition of \(\overline{\mu}(E)\), there exists \(F_0 \in \Sigma\) with \(F_0 \subseteq E\) and \(\mu(F_0) > \overline{\mu}(E) - \varepsilon\). Since \(F\) is a measurable kernel,
\[
\mu(F) \ge \mu(F_0) > \overline{\mu}(E) - \varepsilon.
\]
For any \(\varepsilon>0\), \(\mu(F) \ge \overline{\mu}(E)\). Conversely, since \(F \subseteq E\), \(\mu(F) \le \overline{\mu}(E)\). Hence \(\mu(F) = \overline{\mu}(E)\).

Theorem C asserts that for a set \(E \in \mathscr{H}(\Sigma)\) with a measurable kernel \(F\), the inner measure \(\mu(F)\) equals the outer measure \(\overline{\mu}(E)\). Moreover, any two distinct measurable kernels of \(E\) differ by a set of measure zero, i.e., \(\mu(F_1 \triangle F_2)=0\) whenever \(F_1,F_2\) are kernels. The proof hinges on three foundational theorems from Halmos’ development of abstract measure theory: Theorems A, B, and C themselves.

---

**Step 1: Establishing the Equality \(\mu(F) = \overline{\mu}(E)\)**

We begin by leveraging Theorem A, which states that for any set \(E\) in the hereditary class \(\mathscr{H}(\Sigma)\), the inner measure \(\underline{\mu}(E)\) serves as a lower bound for the outer measure \(\overline{\mu}(E)\), and both lie between the infimum and supremum of measures of measurable supersets and subsets. Since \(F\) is a measurable kernel of \(E\) (by Theorem B), it belongs to \(\Sigma\) and is contained in \(E\). By the monotonicity of \(\mu\) on \(\Sigma\),

\[
\mu(F) \le \overline{\mu}(E).
\]

To prove the reverse inequality, assume for contradiction that \(\mu(F) < \overline{\mu}(E)\). If \(\overline{\mu}(E) = \infty\), the inequality holds trivially. Otherwise, suppose \(\overline{\mu}(E) < \infty\). By the definition of the outer measure, for any \(\varepsilon > 0\), there exists a set \(F_0 \in \Sigma\) such that \(F_0 \subseteq E\) and

\[
\mu(F_0) > \overline{\mu}(E) - \varepsilon.
\]

Now consider the set \(F_0' = F \cup F_0\). Since \(F \in \Sigma\) and \(F_0 \in \Sigma\), their union is also in \(\Sigma\). Moreover, \(F_0'\) is a subset of \(E\) because \(F_0 \subseteq E\) and \(F \subseteq E\). Therefore, by the definition of the inner measure,

\[
\mu(F_0') \le \underline{\mu}(E).
\]

However, because \(\mu\) is finitely additive on \(\Sigma\),

\[
\mu(F_0') = \mu(F) + \mu(F_0) - \mu(F \cap F_0).
\]

Since \(F\) is a measurable kernel, for any \(G \subseteq E - F\), we have \(\mu(G)=0\). In particular, \(F_0 \cap (E - F) = F_0 - F\) has measure zero. Because \(F_0 \cap F = F_0 \cap (E \cap F) = F_0 \cap F\), it follows that \(\mu(F_0 \cap F) = 0\). Hence,

\[
\mu(F_0') = \mu(F) + \mu(F_0).
\]

Using the earlier estimate \(\mu(F_0) > \overline{\mu}(E) - \varepsilon\), we obtain

\[
\mu(F_0') > \mu(F) + \overline{\mu}(E) - \varepsilon.
\]

But \(\mu(F_0') \le \underline{\mu}(E) \le \overline{\mu}(E)\) (by Theorem A), so

\[
\overline{\mu}(E) > \mu(F) + \overline{\mu}(E) - \varepsilon \quad \Rightarrow \quad \varepsilon > \mu(F),
\]

which is impossible for arbitrarily small \(\varepsilon\). Consequently, the assumption \(\mu(F) < \overline{\mu}(E)\) is false, and thus

\[
\mu(F) = \overline{\mu}(E).
\]

---

**Step 2: Proving the Uniqueness Modulo Null Sets**

Now suppose \(F_1\) and \(F_2\) are both measurable kernels of \(E\). Define \(D = F_1 \triangle F_2\), the symmetric difference. We need to show \(\mu(D)=0\). Observe that

\[
D = (F_1 - F_2) \cup (F_2 - F_1).
\]

By symmetry it suffices to prove \(\mu(F_1 - F_2)=0\). Consider any \(G \subseteq D - F_1\). Then \(G \subseteq F_2\) (since \(G \subseteq D\) and \(G \cap F_1 = \emptyset\)). Moreover, \(G \subseteq E\) because \(F_2 \subseteq E\). By the kernel property of \(F_2\),

\[
\mu(G) = 0.
\]

Applying the kernel property of \(F_1\) to the complement relative to \(E\), i.e., \(G' = E - (F_1 \cup F_2)\), we have \(\mu(G')=0\). Since \(G' \cup G = E - (F_1 \cap F_2)\), it follows that \(\mu(E - (F_1 \cap F_2)) = 0\). But \(F_1 \cap F_2 \subseteq E\) and both \(F_1\) and \(F_2\) are maximal, so by maximality (no larger set in \(\Sigma\) is contained in \(E\)), we deduce that \(\mu(F_1 \cap F_2) = \overline{\mu}(E)\). Hence,

\[
\mu(F_1 - F_2) = \mu(F_1) - \mu(F_1 \cap F_2) = \overline{\mu}(E) - \overline{\mu}(E) = 0.
\]

Symmetrically, \(\mu(F_2 - F_1)=0\). Therefore,

\[
\mu(F_1 \triangle F_2) = \mu((F_1 - F_2) \cup (F_2 - F_1)) = 0.
\]

**Gray Zone Analysis: Infinite Outer Measure**

When \(\overline{\mu}(E)=\infty\), the original argument breaks down near the step involving subtraction of infinite quantities. However, if we suppose \(\mu(F)<\infty\), a similar contradiction arises: choose a measurable set \(H \in \Sigma\) with \(\mu(H)<\infty\) and \(H \subseteq E - F\). Then \(F \cup H\) is a larger set in \(\Sigma\) contained in \(E\), contradicting the maximality of \(F\) unless \(\mu(H)=0\). Thus, for any measurable \(H \subseteq E - F\), \(\mu(H)=0\). The same argument applied to any measurable subset of \(E - F\) shows that \(\overline{\mu}(E - F)=0\). By subadditivity of \(\overline{\mu}\),

\[
\infty = \overline{\mu}(E) \le \overline{\mu}(F) + \overline{\mu}(E - F) = \mu(F) + 0 = \mu(F).
\]

Because \(\mu(F) \le \overline{\mu}(E)=\infty\), we again recover \(\mu(F)=\overline{\mu}(E)=\infty\).
