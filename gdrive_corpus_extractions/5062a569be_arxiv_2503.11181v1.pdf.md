<SOURCE_OPERATORS_AND_EQUATIONS>
The paper supplies a pipeline, not a closed-form reconstruction theorem. The following formalization uses only operators explicitly named or numerically parameterized in the source. Units are stated so that the equations are not dimensionless placeholders.

1. Upscaling and information bound. Let the source image be \(X\in\{0,\ldots,255\}^{H_s\times W_s\times 3}\) and the output be \(Y=G_\theta(X,p)\in\mathbb{R}^{1024\times1024\times3}\), where \(p\) is the prompt. Units: pixels for \(H_s,W_s\); \(G_\theta\) is a mapping between pixel arrays. For 8-bit RGB, the source entropy is bounded by
\[
H(X)\le H_sW_s\cdot 3\cdot 8\ \mathrm{bits}.
\]
For \(64\times64\), this is \(98{,}304\) bits. For \(1024\times1024\), the nominal container is \(25{,}165{,}824\) bits. The data-processing inequality gives
\[
I(X;Y)\le H(X).
\]
Thus the output container is larger, but the mutual information about the source cannot exceed the source entropy. Any detail not present in \(X\) is supplied by the learned prior \(p_\theta(Y\mid X,p)\), not by measured evidence. This is the formal basis for the paper’s own caution that “recreating the intricate details of the shirt logo writings proved challenging” [PAGE 26]. Breakdown regime: when a claimed symbol’s stroke width is below the source Nyquist limit, exact recovery is not identifiable from \(X\); the model can only hallucinate a plausible symbol.

2. Lanczos preprocessing. The paper resizes inputs to \(256\times256\) and later to \(1024\times1024\) using Lanczos resampling [PAGE 9–10]. A one-dimensional Lanczos kernel can be written
\[
K_a(x)=\operatorname{sinc}(x)\operatorname{sinc}(x/a)\mathbf{1}_{|x|<a},
\]
where \(x\) is in pixel units and \(K_a\) is dimensionless. The resampled image is
\[
I_L(u,v)=\sum_{m,n}I(m,n)K_a(u-m)K_a(v-n).
\]
Assumption: band-limited source and adequate sample density. Breakdown: if the source contains frequencies above \(1/(2\Delta x)\) cycles per pixel, aliasing is possible; if the source is already compressed and motion-blurred, Lanczos cannot restore missing high-frequency information. The paper uses Lanczos because Real-ESRGAN and the Stable Diffusion x4 Upscaler were “still heavily degraded and remained largely unusable” [PAGE 9].

3. Forward and reverse diffusion. For a normalized image \(x_0\in[0,1]^{H\times W\times3}\), the forward process is
\[
q(x_t\mid x_0)=\mathcal{N}\!\left(\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I\right),
\]
with \(t=1,\ldots,T\), \(\beta_t\in(0,1)\), and \(\bar\alpha_t=\prod_{s=1}^{t}(1-\beta_s)\). Units: \(x_t\) is dimensionless normalized intensity; \(\beta_t\) and \(\bar\alpha_t\) are dimensionless. The reverse model is
\[
p_\theta(x_{t-1}\mid x_t,c)=\mathcal{N}\!\left(\mu_\theta(x_t,t,c),\Sigma_\theta(x_t,t,c)\right),
\]
where \(c\) is the prompt or conditioning signal. The image-to-image strength operator is
\[
N_{\mathrm{noise}}=\lfloor sN_{\mathrm{steps}}\rfloor,
\]
with \(s\in[0,1]\) dimensionless and \(N_{\mathrm{steps}}\in\mathbb{N}\) in steps. The paper’s example is \(50\times0.8=40\) noise steps [PAGE 11]. Breakdown: as \(s\to1\), the initial image is “effectively ignored” [PAGE 10]; as \(s\) is kept “below 0.8” to preserve structure, the result can be blurry [PAGE 14]. The tested band was \(s=0.75\), \(N_{\mathrm{steps}}=80\) [PAGE 14].

4. Classifier-free guidance. The guidance operator is
\[
\tilde\epsilon=\epsilon_\theta(x_t,t,\varnothing)+w\left[\epsilon_\theta(x_t,t,c)-\epsilon_\theta(x_t,t,\varnothing)\right],
\]
where \(w\) is the guidance scale, dimensionless. The paper uses \(w=3.5\) [PAGE 14]. Breakdown: higher \(w\) prioritizes prompt adherence at the cost of coherence with the input image; lower \(w\) gives the model more freedom. This is a second tradeoff independent of strength.

5. ControlNet residual conditioning. The paper states that ControlNet outputs are “multiplied by this scale factor before being added to the residual connections” [PAGE 15]. A schematic residual update is
\[
h_{l+1}=h_l+\alpha\,C_\phi(h_l,c_{\mathrm{ctl}}),
\]
where \(h_l\) is a hidden feature tensor, \(C_\phi\) is the control branch, and \(\alpha\) is the dimensionless conditioning scale. The tested range is \(\alpha\in[0.5,0.65]\) [PAGE 15]. Breakdown: \(\alpha=0\) leaves the control branch inactive; \(\alpha\to1\) lets the control branch dominate the base model and can over-sharpen or introduce artifacts; too low \(\alpha\) fails to refine blur. The paper’s raw-to-ControlNet test was “extremely poor” [PAGE 16], so the operator is only valid after first-stage denoising.

6. LoRA low-rank update. For a base weight \(W_0\in\mathbb{R}^{d_{\mathrm{out}}\times d_{\mathrm{in}}}\), LoRA uses
\[
W=W_0+\frac{\alpha}{r}BA,
\]
with \(A\in\mathbb{R}^{r\times d_{\mathrm{in}}}\), \(B\in\mathbb{R}^{d_{\mathrm{out}}\times r}\), rank \(r\in\mathbb{N}\), and scaling \(\alpha\in\mathbb{N}\). The factor \(\alpha/r\) is dimensionless. The paper gives “if Alpha = 8 and Rank = 16, then the effective weight strength is 8÷16 = 0.5” [PAGE 24]. In the training script, \(r=8\) and \(\alpha=8\) [PAGE 25], so the effective scale is 1.0. Breakdown: \(\alpha=0\) disables the adapter; \(\alpha>r\) makes the effective scale greater than 1 and the paper warns of “unintended LoRA behavior and instability in training” [PAGE 24]. A high rank increases expressive capacity but also VRAM and convergence time.

7. Dataset exposure count. Let \(N_{\mathrm{img}}\) be the number of source images, \(R\) the repeat count, and \(F\) the flip multiplier. Then
\[
N_{\mathrm{exp}}=N_{\mathrm{img}}RF.
\]
The paper reports \(N_{\mathrm{img}}=460\) [PAGE 18], \(R=5\), and \(N_{\mathrm{exp}}=2300\) [PAGE 22]. If \(F=1\), \(460\times5=2300\). If \(F=2\) deterministically, the count would be 4600. The paper also says flip “effectively doubles the dataset size” [PAGE 22]. Therefore the source is internally ambiguous about whether 2300 is the pre-flip exposure count or the post-flip expected count. This is a reproducibility gray zone. Additionally, the claim that football actions “exhibit left-to-right symmetry without altering the semantics of the scene” [PAGE 22] is not generally valid for chiral jersey text, sponsor logos, and directional tactics; flip augmentation can corrupt exactly the domain-specific text the LoRA is meant to improve.

8. VRAM constraint. Let \(M_{\mathrm{base}}\) be base-model memory and \(M_{\mathrm{ctl}}\) the ControlNet overhead. The paper reports \(M_{\mathrm{base}}\ge24\) GB [PAGE 13] and \(M_{\mathrm{ctl}}\approx4\) GB, with “total VRAM usage to 30 GB” [PAGE 16]. Thus
\[
M_{\mathrm{total}}\ge M_{\mathrm{base}}+M_{\mathrm{ctl}}\approx30\ \mathrm{GB}.
\]
Breakdown: if \(M_{\mathrm{total}}>M_{\mathrm{GPU}}\), the pipeline requires CPU offload, bfloat16, or other memory optimizations [PAGE 13]. This is a hard feasibility veto for edge deployment, independent of image quality.

9. Evaluation operators absent from the paper. For verifiable adjudication, one should report
\[
\mathrm{PSNR}=10\log_{10}\!\left(\frac{\mathrm{MAX}^2}{\mathrm{MSE}}\right)\ \mathrm{dB},
\]
with \(\mathrm{MAX}=1\) or 255, plus SSIM, LPIPS, OCR accuracy for jersey numbers and logos, and anatomical keypoint error. The paper does not report these; its results are qualitative figures [PAGE 26–29]. That absence is itself a breakdown regime for the paper’s strongest claims.

The paper’s lineage runs from SRGAN’s perceptual loss with VGG features [PAGE 3], to ESRGAN’s Residual-in-Residual Dense Blocks and relativistic adversarial loss [PAGE 4], to Real-ESRGAN’s synthetic degradation pipeline for blind super-resolution [PAGE 4]. That GAN line is then rejected for this task because Real-ESRGAN and the Stable Diffusion x4 Upscaler produced “extremely poor” or “still heavily degraded” results [PAGE 9]. The diffusion line runs from DDPM [PAGE 3] to ControlNet conditional control [PAGE 4–5], LoRA low-rank adaptation [PAGE 5], Diffusion Transformers [PAGE 5–6], Rectified Flow [PAGE 6], and finally FLUX.1-dev [PAGE 11–12]. The paper explicitly says FLUX.1-dev is “directly distilled from FLUX.1-pro” and uses a hybrid multimodal/parallel diffusion transformer design scaled to 12 billion parameters [PAGE 11–12]. The multi-stage pipeline is therefore a convergence of three lineages: GAN-style perceptual sharpening, diffusion probabilistic denoising, and parameter-efficient adapter fine-tuning.

The multi-week traps are visible in the paper’s own failed branches. First, architecture hopping: the authors tried Stable Diffusion XL, RealVis V4.0, Stable Diffusion 3.5 Medium, Stable Diffusion 3.5 Large, and FLUX.1-dev before settling [PAGE 11–12]. A team can lose weeks assuming distributed-memory tooling will compose with an experimental LoRA trainer. Third, format conversion: the authors converted KohyaSS LoRA weights into Diffusers format and “observed no notable differences in inference speed or output quality” [PAGE 28]. That is a useful negative result: format conversion is not the lever. Fourth, dataset and captioning traps: 460 source images [PAGE 18], ChatGPT-generated captions with team and kit context [PAGE 18–20], repeat and flip augmentation [PAGE 22], and a future target of “more than 5,000 images” [PAGE 29]. The captioning process can leak context that is not visible in the pixels, especially team identity and jersey combinations; the model can then learn to rely on textual priors rather than visual evidence. Fifth, evaluation trap: proprietary data and outputs are “not publicly available due to proprietary restrictions” [PAGE 30], and there is no quantitative benchmark. The retrocausal lesson is that the final pipeline’s success criteria should have been fixed before the architecture search; otherwise the genealogy becomes a sequence of plausible-looking upgrades rather than a falsifiable improvement path.

<RECURSIVE_THEORY_OF_MIND>
The relevant agents are the broadcast operator, the diffusion model, the LoRA adapter, the human evaluator, and the viewer. The operator’s crisis habit is understandable: under live or post-match deadline pressure, low-resolution cutouts look unacceptable, so the operator reaches for the most aggressive sharpening lever—higher strength, higher guidance, higher ControlNet scale, or LoRA everywhere. The model’s “belief” is not a belief in truth; it is a conditional sample from \(p_\theta(Y\mid X,p)\). The evaluator’s belief is the dangerous recursive link: a sharp, high-contrast image can be read as a faithful image. But perceptual acceptance \(A=\mathbf{1}[Q_{\mathrm{perc}}>\tau]\) is not veridical acceptance \(V=\mathbf{1}[I(X;Y)\ge I_{\mathrm{req}}]\), where \(I\) is in bits and \(Q_{\mathrm{perc}}\) is any perceptual score. High \(Q_{\mathrm{perc}}\) can coexist with low \(I(X;Y)\), because the prior can add plausible texture, logos, or anatomy that were never measured. The paper’s prompt example, “A goalkeeper wearing a green jersey and matching shorts with the number 99 is diving low to make a save” [PAGE 14], is a concrete leakage path: if the operator already knows the number, the model can render “99” convincingly without recovering it from the 64×64 pixels.

The counter-trap is over-constraint. If the operator reacts to hallucination by forcing strength below 0.8, the paper shows the result is blur [PAGE 14]; if the operator forces LoRA into the first stage, the paper shows some images are “better reconstructed without incorporating the LoRA” [PAGE 27]. If the operator applies LoRA only in the second stage, the paper reports more consistent benefit [PAGE 27], but still not uniform. The recursive theory-of-mind failure is double: the operator believes the model is reconstructing, and the model’s output reinforces that belief because it is sharp. The correct counter-trap is a selective gate: generate LoRA and non-LoRA outputs in parallel, as the authors propose [PAGE 29], and choose by an external verifier rather than by sharpness alone. The clock matters because the verifier has a time budget. Offline post-match analysis can afford 80 image-to-image steps, 35 ControlNet steps, and human review; real-time analytics [PAGE 1] cannot afford 30 GB VRAM and 13-hour LoRA training [PAGE 16, PAGE 24] without distillation. The paper’s own future-work plan—parallel generation, GUI, larger dataset, offline captioning, and Img-to-3D [PAGE 29]—implicitly acknowledges that the current system is a human-in-the-loop tool, not an autonomous truth machine.

<CROSS_LAYER_VETO_ADJUDICATION>
Veto layer 1: physical/optical/information. The source resolution is the hard bound. The paper reports average “around 100 × 100 pixels” [PAGE 6] and “often starting as low as 60 × 60 pixels” [PAGE 7]. By Nyquist, a spatial frequency \(f\) is recoverable only if \(f\le1/(2\Delta x)\) cycles per pixel. If a jersey-number stroke or sponsor-letter stroke is narrower than approximately two source pixels, exact character identity is not identifiable from the source alone. The paper’s own admission that “recreating the intricate details of the shirt logo writings proved challenging” [PAGE 26] is consistent with this veto. Additional proof: feeding raw frames directly to ControlNet was “extremely poor” [PAGE 16], so the pipeline depends on a first-stage prior that is itself generative. Therefore any claim that a specific logo word or jersey number was “recovered” must be vetoed unless it is corroborated by independent high-resolution ground truth, OCR on a registered source, or multiple independent samples with controlled prompts. If the number was supplied in the prompt [PAGE 14], the output is not evidence of recovery.

Veto layer 2: biomechanical/anatomical. The paper provides a concrete failure case: without LoRA, “the two legs of the goalkeeper appeared to fuse into one” [PAGE 27]. With LoRA, the legs separate, but that is a single qualitative example, not a validated anatomical guarantee. A formal veto rule can use skeleton keypoints \(p_i\) and bone lengths \(l_i=\|p_j-p_k\|_2\) in pixels, with calibrated bounds from the source camera geometry. If the reconstructed skeleton violates limb count, left-right limb assignment, joint-angle limits, or bone-length consistency beyond the source calibration, the output is vetoed as biomechanically implausible. The same rule vetoes extra fingers, fused limbs, impossible knee/hip rotations, and contact shadows that contradict the pose. LoRA improves some cases, but the paper does not report an anatomical error rate; therefore the veto remains active by default.

Veto layer 3: weather/illumination. The source does not contain an explicit weather model. It describes stadium occupancy and “prominent background elements such as billboards, goalposts, or the corner flag” [PAGE 19], but not rain, fog, snow, or direct-sun metadata. Therefore a weather-specific claim is an out-of-domain claim and must be vetoed unless external metadata is supplied. Illumination consistency can still be checked: specular highlights, shadow direction, and color temperature must be coherent with the source frame. If the reconstruction adds a shadow that implies a light source absent from the source, or removes rain streaks that are visible in the source, the output is a plausible re-imagination, not a reconstruction. The adjudication rule is conservative: accept an output only if physical/optical, biomechanical, and illumination checks all pass; if any layer vetoes, downgrade the output from “reconstruction” to “plausible visualization.” This is especially important for broadcast graphics, where a wrong sponsor word or jersey number is not a cosmetic error but a factual error.
