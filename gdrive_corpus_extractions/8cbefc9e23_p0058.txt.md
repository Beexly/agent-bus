**Operator Definitions:**
- **Hereditary Ring:** For a ring \(\mathcal{R}\) of sets, the hereditary ring \(H(\mathcal{R})\) is defined as:
  \[
  H(\mathcal{R}) = \{ E : \exists A \in \mathcal{R} \text{ such that } E \subseteq A \}.
  \]
  This is the smallest hereditary ring containing \(\mathcal{R}\) [PAGE 43].

- **Outer Measure \(\mu^*\):** Given a set function \(\mu\) on a ring \(\mathcal{R}\), the induced outer measure on any set \(E\) is:
  \[
  \mu^*(E) = \inf \left\{ \sum_{i=1}^\infty \mu(E_i) : E_i \in \mathcal{R}, \ E \subseteq \bigcup_{i=1}^\infty E_i \right\},
  \]
  where the infimum is taken over all countable covers of \(E\) by sets in \(\mathcal{R}\). If no such cover exists, \(\mu^*(E) = \infty\). This definition appears in the context of Theorem A [PAGE 43].
