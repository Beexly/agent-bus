<SOURCE_OPERATORS_AND_EQUATIONS>
The paper’s formal core is a planar homography search. The source states, “Two images of the same planar surface in space are related by a homography (H)” [PAGE 3]. In homogeneous image coordinates, let a point in the broadcast view be x = (u, v, 1)^T and its corresponding point in the top-view model be x' = (u', v', 1)^T. The homography satisfies:

x' ∼ H x,  H ∈ PGL(3, R).

The notation ∼ means equality up to nonzero scalar. If the coordinates are measured in pixels, u and v have units of pixels, although pixel units are sampling units rather than SI units. If the top-view model is calibrated in meters, the projected coordinates can be converted to SI units by a scale map or by normalizing with the camera intrinsic matrix K. A rigorous normalized form is:

\tilde{x}' = \tilde{H} \tilde{x},  \tilde{x} = K^{-1} x,  \tilde{x}' = K'^{-1} x'.

In normalized coordinates, \tilde{H} is dimensionless up to projective scale. The homography has eight degrees of freedom. The source says it “can ideally be estimated using 4 pairs of perfect correspondences (giving eight equations)” [PAGE 3]. In practice, the paper avoids solving for H from noisy correspondences by retrieving H from a dictionary.

The dictionary is defined as D = {I_j, H_j}, where I_j is a synthetic field-line edge map and H_j is the corresponding homography. The source states, “we learn a large dictionary D = {Ij, Hj}” and “we use N ≈ 100K” [PAGE 4]. The dictionary is generated from a small set of manually annotated images. The source says, “we ﬁrst hand label the four correspondences in small set of images” [PAGE 3]. Pan, tilt, and zoom simulations expand this small set into a large synthetic manifold. The assumption is that the synthetic camera-view manifold covers the real broadcast camera-view manifold. Let d_H(H_q, D) be the distance from the true homography H_q to the nearest dictionary homography. If d_H(H_q, D) is larger than the matching tolerance τ_D, the nearest-neighbor operator has a model mismatch. This is a breakdown regime: the true camera pose is not represented in the dictionary.

The chamfer matching operator uses the distance transform T(x). The distance transform assigns to each pixel the distance to the nearest edge pixel. If coordinates are in pixels, T(x) has units of pixels. The chamfer score between input edge map x and dictionary edge map I_j can be written as:

d_C(x, I_j) = \frac{1}{\Vert I_j \Vert_1} \sum_{p} T(x)_p (I_j)_p.

Here (I_j)_p is binary or edge-weighted, \Vert I_j \Vert_1 is the sum of edge weights, and d_C has units of pixels. If a physical scale s with units meters per pixel is available, then s d_C has units of meters. The nearest dictionary index is:

j^* = \arg\min_j d_C(x, I_j).

The source gives the corresponding selection rule and says, “where ∥∥1 is the ℓ1 norm and the index j∗gives the index of the true nearest neighbour” [PAGE 5]. It also defines approximate neighbors using an epsilon:

d_C(x, I_j) \le (1 + \epsilon) d_C(x, I_{j^*}).

The parameter \epsilon is dimensionless. A singularity occurs when the edge map has no overlap with the dictionary edge map. Then T(x) is large almost everywhere, the chamfer score loses discriminative power, and the nearest neighbor becomes dominated by preprocessing noise. Another breakdown occurs if the distance transform is quantized. With pixel-grid chamfer matching, discretization introduces bounded geometric error on the order of half a pixel, but in projective space that error can be amplified by the condition number of the homography.

The HOG operator uses gradient-orientation histograms. Let φ_h(x) be the HOG feature vector of the input edge map. The distance is:

d_H(x, I_j) = \Vert φ_h(x) - φ_h(I_j) \Vert_2.

If HOG features are L2-normalized, they are dimensionless. If not normalized, their units depend on gradient magnitude and bin normalization. The source says the HOG search is performed “using the euclidean distance on the HOG features computed over both the dictionary edge maps and the input edge map” [PAGE 5]. The breakdown regime is feature distribution shift. Synthetic edge maps are cleaner than real preprocessed edge maps. The empirical consequence is visible in the broadcast table: HOG mean IOU is 85.8, while Chamfer mean IOU is 80.5 [PAGE 6]. HOG is less sensitive to sparse edge mismatch, but it can still fail if preprocessing removes or corrupts the line structure.

The CNN operator uses features φ_c(x) from a network. The source removes the last fully connected layer and uses the resulting vector for nearest-neighbor search [PAGE 5]. The distance is:

d_CNN(x, I_j) = \Vert φ_c(x) - φ_c(I_j) \Vert_2.

The features have arbitrary units unless normalized. The breakdown regime is severe. On synthetic data, SketchNet reaches mean IOU 93.1, but on broadcast images it falls to 14.1 with median 0.0 [PAGE 6]. AlexNet also falls from 88.4 to 66.1. The source concludes that features from pre-trained networks “are susceptible to noise and do not transfer well for the given task” [PAGE 7]. This is not a minor calibration issue; it is a domain-transfer singularity.

The MRF operator selects one of k candidate homographies per frame. Let s_t ∈ {1, ..., k} be the selected state at frame t. The global energy is:

E(ξ) = \sum_{t=1}^{N} E_d(s_t) + \sum_{t=2}^{N} E_s(s_{t-1}, s_t).

The source writes the data term as “Ed(st) = log(P(st, t))” [PAGE 5]. For dimensional correctness, P should be a probability, not a raw distance. A formal conversion is:

p(s_t, t) = \frac{\exp(-d_{s_t}/\tau)}{\sum_{m=1}^{k} \exp(-d_m/\tau)},

where d_m is the nearest-neighbor distance for candidate m and τ has the same distance units as d. Then:

E_d(s_t) = -\log p(s_t, t).

If natural logarithm is used, E_d has units of nats. If base-2 logarithm is used, E_d has units of bits. The smoothness term can be written as:

E_s(s_{t-1}, s_t) = \Vert \tilde{H}_{s_t} - \tilde{H}_{s_{t-1}} \Vert_2,

where \tilde{H} denotes normalized homography parameters. If the eight independent parameters are normalized to comparable ranges, the term is dimensionless. If raw homography entries are used, the term mixes incompatible units, because translation, scale, and projective parameters do not share the same physical units. The source notes that the homography matrices are “normalized so that each of the eight parameters lie in a similar range” [PAGE 5]. The MRF is solved by dynamic programming. Its breakdown regimes are: k too small, true homography absent from the candidate set; non-informative distances, making p nearly uniform; excessive smoothness weight, causing failure to follow real camera motion; or editorial cuts, where temporal continuity assumptions fail.

The convex stabilization operator estimates a stabilized parameter sequence. The source parametrizes the projected polygon using six parameters: camera center (c_x, c_y), pan angle θ, zoom angle φ, and two intercepts r_1, r_2 [PAGE 6]. A dimensionally clean form normalizes by a reference length L, for example pitch length:

\bar{P}_t = \left( \frac{c_{x,t}}{L}, \frac{c_{y,t}}{L}, \theta_t, \phi_t, \frac{r_{1,t}}{L}, \frac{r_{2,t}}{L} \right).

The normalized energy is:

E_c = \sum_{t=1}^{N} \Vert \bar{P}^*_t - \bar{P}_t \Vert_2^2
+ \lambda_1 \sum_{t=1}^{N-1} \Vert \bar{P}^*_{t+1} - \bar{P}^*_t \Vert_1
+ \lambda_2 \sum_{t=1}^{N-2} \Vert \bar{P}^*_{t+2} - 2\bar{P}^*_{t+1} + \bar{P}^*_t \Vert_1
+ \lambda_3 \sum_{t=1}^{N-3} \Vert \bar{P}^*_{t+3} - 3\bar{P}^*_{t+2} + 3\bar{P}^*_{t+1} - \bar{P}^*_t \Vert_1.

The first term is a data fidelity term. The next three terms penalize first-order velocity, second-order acceleration, and third-order jerk in L1 norm. If \bar{P} is dimensionless, the weights λ1, λ2, and λ3 are dimensionless. If physical units are used without normalization, λ1, λ2, and λ3 must carry units that compensate mixed translation, angle, and intercept units; that is less robust. The source states, “As Ec is convex, it can be efﬁciently solved using any off the shelf solver” [PAGE 6]. The breakdown regimes are: non-convex-looking behavior from poor initialization is avoided, but solution quality depends on solver tolerance; excessive λ values over-smooth real fast pans; insufficient λ values leave jitter; and the six-parameter model fails if the projected polygon cannot be represented by that parameterization or if the camera trajectory contains cuts.

The second lineage is classical broadcast registration. Earlier systems required manual initialization. The source says prior work uses KLT tracks or manually annotated landmarks, and that manual initialization is impractical because shot changes occur frequently [PAGE 1]. In a typical 45-minute football video, the source says shot changes happen about 400 times [PAGE 8]. This is a major historical trap: methods that depend on re-initializing homographies at each shot cannot scale to full broadcast analysis.

The third lineage is feature-based registration. SIFT, line features, ellipse features, and interest-point tracking appear in the related work. The source notes that Hess and Fern improve automation using SIFT correspondences, but their method may not apply to normal football because of “lack of ground visual features” [PAGE 3]. This is a crucial retro-causal pressure: football’s textureless pitch forced the field toward edge-based or line-based representations.

The fourth lineage is vanishing-point-based registration. The source criticizes reliance on vanishing point estimation because it is “highly unreliable” in difficult viewpoints, sparse edge detections, and shadows [PAGE 3]. This failure mode pushed the authors toward a dictionary search that does not require explicit vanishing point estimation.

The fifth lineage is chamfer matching. The method uses a classical distance-transform matching operator, citing chamfer matching as popular because of “speed and accuracy” [PAGE 4]. The distance transform is an old but stable operator. It converts edge alignment into a simple multiplication and normalization. Its lineage is important because it provides a computationally cheap way to compare binary line maps without requiring point correspondences.

The sixth lineage is HOG. HOG features are gradient histograms originally associated with human detection. The source uses them because they can encode edge orientation structure with some tolerance to small spatial noise [PAGE 5]. This choice is historically significant because HOG provides a middle ground between brittle point matching and overly abstract CNN embeddings.

The seventh lineage is stroke width transform. The source uses SWT to filter field lines in the presence of shadows and mowing stripes. It says SWT is “more robust to noise like shadows, ﬁeld stripes” than usual edge detectors [PAGE 7]. This is a response to the visual grammar of football broadcasts: shadows, stripes, and player occlusion create non-line edges that must be suppressed.

The eighth lineage is temporal camera stabilization. The source builds on the idea that stabilized camera motion can be decomposed into constant, linear, and parabolic segments [PAGE 5]. It also observes that professional camera operators keep the camera static when possible and use smooth acceleration or deceleration when movement is motivated [PAGE 6]. This gives the convex L1 stabilizer a biomechanical and editorial prior.

The multi-week traps in this genealogy are recurring. The first trap is manual labeling: small annotation sets are necessary to seed the dictionary, but they do not scale to all camera angles, venues, lighting conditions, or shot types. The second trap is synthetic-to-real domain gap: the dictionary is synthetic, but the input edge maps come from noisy video preprocessing. The CNN collapse in the broadcast table is the empirical signature of this trap [PAGE 6]. The third trap is preprocessing fragility: field lines can be removed by shadows, motion blur, crowd, players, or excessive stroke width. The source explicitly filters strokes larger than ten pixels [PAGE 7], which can also remove blurred line segments. The fourth trap is temporal ambiguity: smoothing helps jitter but can erase genuine rapid camera motion, especially after events such as a goalkeeper kick [PAGE 8]. The method’s genealogy is therefore not a simple improvement over earlier registration; it is a layered compromise among automatic operation, limited visual texture, synthetic coverage, and temporal regularization.

<RECURSIVE_THEORY_OF_MIND>
A recursive theory of mind for this system must model three agents or layers: the broadcast camera operator, the editor, and the registration algorithm. The camera operator has habits. The source observes that professional camera work tends to remain static when possible and to use motivated movement with acceleration, constant velocity, and deceleration [PAGE 6]. This is a prior over camera trajectories. In probabilistic terms, the operator assigns higher prior probability to low-jerk trajectories and lower prior probability to abrupt unexplained motion. The registration algorithm can exploit this prior through the convex stabilization term.

The editor introduces discontinuities. Broadcast football is not one continuous camera path; it is a sequence of shots selected to follow events. The source notes that shot changes are frequent and that manual re-initialization would be required about 400 times in a 45-minute video [PAGE 8]. The editor’s policy is event-driven: goals, corners, attacks, and goalkeeper kicks motivate cuts or fast pans. The source describes one sequence as starting at midfield, panning to the left goal post, staying static, and then quickly panning back to midfield following a goalkeeper kick [PAGE 8]. This is a crisis regime for temporal smoothing.

The registration algorithm’s naive habit is per-frame nearest-neighbor matching. This habit is locally plausible but globally unstable. It can regress to noise when preprocessing removes field lines, when shadows corrupt edges, or when the dictionary lacks a close match. The source acknowledges that per-frame nearest neighbor may fail due to “noise in the pre-processing stage or the absence of a close match in the simulated dictionary” [PAGE 5]. The counter-trap is the MRF. The MRF does not ask only which dictionary atom is closest; it asks which sequence of dictionary atoms is globally plausible given data evidence and temporal smoothness. This is a recursive correction: the model reasons about the sequence of its own per-frame choices.

A second counter-trap is the convex stabilizer. The MRF removes large outliers and discrete jumps, but it still outputs discrete choices. Small jitter remains. The convex optimizer then treats the trajectory as a controlled physical process with low-order derivatives. The L1 terms allow static, linear, and parabolic segments. This is important because a purely quadratic L2 smoother would over-penalize real camera moves and could create unnatural easing. The L1 formulation is more compatible with the camera operator’s grammar: static holds, constant-velocity follows, and smooth accelerations or decelerations.

The clock is the frame index t. The algorithm uses temporal windows: the viewpoint classifier uses a temporal window of 40 frames [PAGE 7], the MRF uses all frames, and the convex stabilizer solves over the whole sequence. The clock also creates a crisis-regression trap: if a shot change occurs, the temporal prior may incorrectly assume continuity across the cut. The method is fully automatic, but it must still respect editorial boundaries. If the classifier incorrectly labels a non-top-zoom-out frame as top zoom-out, the clock will propagate a bad homography into the temporal optimizer.

The recursive equilibrium is therefore: per-frame evidence proposes homographies; MRF selects a sequence; convex optimization smooths the sequence; camera-operator priors regularize motion; editor-induced cuts must be detected or tolerated. The system is not merely registering images; it is inferring a plausible camera behavior under partial observability.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
A cross-layer veto is required when lower-layer visual evidence conflicts with higher-layer physical or biomechanical constraints. The first physical veto is plane validity. The homography operator assumes that the observed line markings lie on a single plane. The source states that two images of the same planar surface are related by a homography [PAGE 3]. If the observed edges come from vertical objects, such as players, goal posts, referee limbs, or crowd barriers, they do not obey the same planar homography. Let H be the field-plane homography and let x_v be the projection of a vertical point with height Z. In a pinhole camera, the image coordinate depends on both the ground-plane projection and the height-dependent parallax term. Therefore, no single H can map all vertical-object points consistently to the ground plane. If vertical-object edges remain in the input edge map, the nearest-neighbor chamfer score is contaminated by non-plane residuals. The veto condition is: if the fraction of edge energy inconsistent with the dominant field plane exceeds a calibrated threshold ρ_max, reject the registration.

The second physical veto is viewpoint visibility. The source says field lines are only properly visible in the far top zoom-out view [PAGE 7]. It also states in the summary that the method is “only applicable to top zoom-out views” [PAGE 8]. Therefore, ground zoom-in, ground zoom-out, top zoom-in, and miscellaneous crowd shots are outside the valid operator domain. In those shots, the field-line edge map may be too sparse or too foreshortened to identify a unique homography. The veto condition is: if the viewpoint classifier assigns a frame to a non-top-zoom-out class, the registration output should be rejected or marked invalid.

The third biomechanical veto is player and crowd contamination. The source removes crowd by color-based segmentation and removes players using a human detector before forming the edge map [PAGE 7]. If the human detector fails or if motion blur creates human-shaped edge fragments, the edge map contains non-field structures. Biomechanically, players move independently of the ground plane and violate static planar geometry. The veto condition is: if the detected person mask overlaps the candidate field-line edge map beyond a threshold, reject the frame or re-run preprocessing. This is not a cosmetic issue; it changes the homography estimate because chamfer and HOG distances are computed over contaminated edges.

The fourth weather or visibility veto is edge contrast and stroke-width validity. The source uses SWT and filters strokes of size more than ten pixels, preserving field lines with small consistent stroke widths [PAGE 7]. Shadows, rain, low light, motion blur, or low contrast can either erase line edges or broaden them beyond the valid stroke-width range. If line markings are erased, the distance transform has no support; if they are broadened, the stroke filter may remove them. The veto condition is: if the visible field-line completeness C_L falls below a threshold C_min, or if the dominant line stroke width w lies outside the calibrated interval [w_min, w_max], reject registration. Here C_L can be defined as the ratio of detected field-line edge energy to expected field-line edge energy under the current camera view. This is a visibility probability constraint, not a cosmetic quality check.

A formal adjudication rule can be stated as follows. For frame t, accept the homography H_t only if all of the following hold: first, the viewpoint class is top zoom-out; second, the person and crowd residual edge fraction is below ρ_max; third, the field-line completeness C_L is above C_min; fourth, the nearest-neighbor distance d_j* is below τ_d; fifth, the MRF-selected homography sequence has bounded temporal residual under the smoothness model; and sixth, the convex-stabilized trajectory does not introduce a residual larger than τ_stab. If any condition fails, the frame is vetoed. This adjudication prevents a visually plausible but physically invalid registration from entering downstream tracking or analytics.

The cross-layer veto proof is therefore based on dimensional and geometric consistency. The homography layer is valid only for planar field markings. The preprocessing layer is valid only if field lines are extracted with sufficient completeness. The temporal layer is valid only if camera motion follows the assumed low-order segments and does not cross invalid shot boundaries. When any layer fails, the lower-layer distance score alone cannot certify correctness.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
The first verifiable RLVR veto scenario is dictionary undercoverage. Suppose a broadcast frame contains a camera pose whose true homography H_q is not well approximated by any dictionary atom. The source acknowledges that per-frame nearest-neighbor search can fail when there is “absence of a close match in the simulated dictionary” [PAGE 5]. In a reinforcement-learning or verification setting, the reward should be based on a verifiable geometric criterion, such as intersection-over-union between the estimated polygon and a manually verified ground-truth polygon.
