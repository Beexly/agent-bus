Breakdown regimes: (i) R’s numeric type is double precision with exact-integer limit \(2^{53} \approx 9.007\times10^{15}\); ESPN play ids are 18-digit integers that can exceed this, so `play_id` must be passed as `character` or the lookup silently rounds and 404s [PAGE 179]. (ii) `cfbd_game_team_stats()` columns are `character` despite representing counts and yards [PAGE 39–41], so numeric EPA aggregation requires `as.numeric()` coercion or type-promotion failure. (iii) Minimum accepted `year` values span 1869 (CFBD team records [PAGE 37]), 1877 (ESPN schedule [PAGE 253]), 1886 (coaching seasons [PAGE 15]), 1890 (Elo [PAGE 99]), 1936 (rankings [PAGE 95]), 1967 (draft picks [PAGE 23]), 1970 (SP+ [PAGE 101]), 2001 (PPA games [PAGE 51]), 2004 (player stats [PAGE 35]), 2013 (player PPA [PAGE 53]), 2014 (playoffs [PAGE 85]; transfer portal [PAGE 111]), and 2021 (transfer portal minimum [PAGE 111]). Requests below these minima return empty frames or errors.
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
The lineage of `cfbfastR` traces from three historical strata. First, the expected-points tradition: Carter and Machol’s 1971 expected-points model, Romer’s 2006 fourth-down analysis, and the public-EPA lineage popularized by Advanced Football Analytics. `cfbfastR` implements its own "CFB-EPA analogue" [PAGE 71] via `.run_epa_wpa()` [PAGE 75], not a published closed-form Bellman recursion, which means the model inherits the structural assumptions of discrete-state expected points without exposing the transition kernel. Second, the ratings genealogy: Bill Connelly’s SP+/FEI line is represented by `cfbd_ratings_sp()` [PAGE 101] and `cfbd_ratings_sp_conference()` [PAGE 103], while ESPN’s FPI is exposed through `cfbd_ratings_fpi()` [PAGE 100], `espn_cfb_powerindex()` [PAGE 245], `load_cfb_fpi_weekly()` [PAGE 313], and `load_espn_cfb_power_index()` [PAGE 383]. The FPI snapshots are weekly, whereas `cfbd_ratings_core()` [PAGE 98] and `load_cfb_ratings()` [PAGE 315] are season-end, creating a temporal resolution mismatch between as-of-week and final-team ratings. Third, the API genealogy: ESPN migrated from site-v2 to core-v2 endpoints; `espn_cfb_pbp()` is the legacy site-v2 path and `espn_cfb_pbp_v2()` is the core-v2 modular successor [PAGE 211–213]. The CFBD feed remains the older, column-dense source [PAGE 67].

Multi-week traps arise from this genealogy. Weekly power-rating snapshots (`load_cfb_ratings_weekly()` [PAGE 317], `load_cfb_team_summaries_weekly()` [PAGE 327]) are as-of-week estimates that can be revised as the season completes; a model trained on week-8 snapshots and tested on season-end ratings incurs label leakage. The transfer portal only exists in CFBD from the 2021 offseason onward [PAGE 111], so roster-continuity features built from `cfbd_player_returning()` [PAGE 81] for 2014–2020 are structurally incomplete. Coaching tenure can change mid-season (`cfbd_coaches_tenures()` [PAGE 17]), invalidating season-level coach fixed effects. Conference realignment (`cfbd_conference_changes()` [PAGE 21]) breaks conference-stratified models across years. Garbage time (`excl_garbage_time` [PAGE 51, 53–55, 121–123]) is most prevalent in late-season blowouts, so late-week samples are systematically selected on score state. The equivalence harness between legacy and v2 PBP engines enforces equality only on user-facing values [PAGE 77]; internal WPA scratchpad columns may drift across package versions, meaning a model that depends on intermediate WPA components is not reproducible across `cfbfastR` releases even when outputs appear identical.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
Crisis habit regression occurs when an analyst encounters an outlier game-state—extreme weather, a starting-quarterback injury, or a mid-season coaching change—and regresses from opponent-adjusted EPA/WPA to raw, unadjusted totals such as yards or points. This is a habit regression because it replaces the model’s recursive state-value estimate with a one-step heuristic that ignores down, distance, clock, and opponent strength. The counter-trap is to condition on opponent-adjusted, situation-aware metrics: `cfbd_metrics_wepa_players_passing()` and `cfbd_metrics_wepa_players_rushing()` return opponent-adjusted weighted EPA [PAGE 59–61], `cfbd_stats_game_advanced()` supplies standard-down vs passing-down PPA splits [PAGE 114–117], and `load_espn_cfb_adv_situational()` explicitly models down, distance band, field zone, and game state [PAGE 345–347].

The clock layer is central to the theory of mind. `cfbd_pbp_data()` carries `TimeSecsRem`, `adj_TimeSecsRem`, `Under_two`, `Under_three`, `end_of_half`, and the middle-8 window (final 4 minutes of the first half, first 4 minutes of the second half) [PAGE 69]. EPA is non-stationary in clock: a 5-yard gain at \(\tau = 900\) s in a tie game has a different \(\mathrm{EP}(s_{i+1}) - \mathrm{EP}(s_i)\) than the same gain at \(\tau = 60\) s trailing by four. A recursive theory of mind for play-calling is \(V(s) = \mathbb{E}[r + \gamma V(s') \mid s]\), where the offensive coordinator models the defensive coordinator’s response to formation and personnel, and the defensive coordinator models the offensive tendency by down/distance. `cfbfastR` flattens this recursion into lag/lead columns (`lag_pos_team`, `lead_play_type`, `lag_wp_before`, `lead_wp_before2`, etc.) [PAGE 71–73], but the modeler’s own theory of mind must decide whether to trust the `epa_wpa = TRUE` pipeline or the raw CFBD feed. If the engine’s state discretization (e.g., its yard-line binning or clock adjustment) mismatches the true game process, the recursive value function is misspecified, and the analyst inherits that bias when treating `epa` as ground truth.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Four independently falsifiable layers must each pass before a play-level or team-level projection is admitted.

Layer 1 — Weather. `cfbd_game_info()` returns integer fields for temperature (°F), dew point (°F), humidity (0–100%), precipitation (inches), snowfall (inches), wind direction (0–360°, 0 = north), wind speed (mph), pressure (millibars), weather condition code, and free-text condition [PAGE 43]. A veto rule is: if \(v_{\mathrm{mph}} > 15\) on an outdoor non-dome venue and the play type is pass, downgrade passing-EPA confidence; if \(P_{\mathrm{in}} > 0\) or \(S_{\mathrm{in}} > 0\), veto kicking-model reliability because surface friction and ball handling are altered.

Layer 2 — Venue / physical. `cfbd_venues()` supplies capacity, `grass` (Boolean), `dome` (Boolean), elevation, and timezone [PAGE 137]; ESPN’s venue index adds `indoor` (Boolean) [PAGE 301]. A dome venue nullifies the wind veto from Layer 1 because \(\theta\) and \(v_{\mathrm{mph}}\) are causally irrelevant indoors. Elevation (when present as a numeric proxy) affects aerobic output but is recorded as character in the CFBD venue frame [PAGE 137], so any elevation feature requires parsing before use.

Layer 3 — Biomechanical / roster. `cfbd_team_roster()` returns height (inches), weight (pounds), position, year, and jersey [PAGE 135]. Player usage shares are available by down and play type [PAGE 83]. If a projected starter’s height/weight is missing or is an outlier relative to positional norms, the player-level projection is vetoed; the model must fall back to team-level EPA.

Layer 4 — Game state. Down, distance, yards-to-goal, clock, score differential, timeouts, and possession are all in `cfbd_pbp_data()` [PAGE 67–69] and ESPN’s play schema [PAGE 173–177]. If clock \(< 120\) s and \(|\Delta| \le 8\) points, garbage-time exclusion is inappropriate; the model must use end-of-half logic (`end_of_half` [PAGE 69]) rather than regular-play EPA baselines.

Adjudication: a prediction passes only if all layer vetoes evaluate false. Cross-layer conflict resolution example: an outdoor game with high wind (Layer 1 veto on passing) is played in a dome-adjacent stadium where `dome = TRUE` (Layer 2 override), so the physical layer nullifies the weather veto because the causal pathway from wind to passing efficiency is blocked. Each layer is falsifiable directly from the API schema, making this a veto proof rather than a heuristic weighting scheme.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Scenario 1 — EPA sign-flip veto. Verification: pull `cfbd_pbp_data(year = 2024, week = 1, epa_wpa = TRUE)` [PAGE 67]. For every play where `turnover == 1` and `yards_gained < 0`, require `epa <= 0` because a turnover with negative yardage cannot increase expected points under any sane EP surface. Counterfactual prediction: the violation rate should be below 0.1% of plays; any play exceeding this threshold invalidates the EPA model for that game and triggers recalibration or fallback to raw success rate.

Scenario 2 — Win-probability monotonicity veto. Verification: join `cfbd_pbp_data()` `home_wp_before` / `home_wp_after` [PAGE 69] or `espn_cfb_game_probabilities()` `home_win_percentage` / `away_win_percentage` [PAGE 193]. For every play with `offense_score_play == 1` by the home team, require `home_wp_after >= home_wp_before`; for an away-team score, require `away_wp_after >= away_wp_before`. Counterfactual prediction: monotonicity holds on >99.9% of scoring plays; a violation indicates timestamp misalignment or WP-model inversion and the entire WP series for that game is vetoed.

Scenario 3 — 18-digit play-ID precision veto. Verification: `espn_cfb_game_play()` accepts ESPN play ids that are 18-digit integers exceeding R’s exact double-precision range; the documentation states they "must [be] pass[ed] as a character string ... so no precision is lost" and that "a bare numeric literal will be silently rounded and the lookup will 404" [PAGE 179]. RLVR check: `stopifnot(is.character(play_id), nchar(play_id) == 18L)`. Counterfactual prediction: all 18-digit ESPN play IDs must be character-typed; any numeric literal produces a silent rounding error and a 404 lookup, so downstream play-level attribution fails without warning.
</RLVR_COUNTERFACTUAL_VETOES>
