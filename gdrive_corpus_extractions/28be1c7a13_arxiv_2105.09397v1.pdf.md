Single-layer formalism (Page 4): Let G = (V, E) be a simple graph with V = {v_1, ..., v_N}, N ∈ ℕ, and E ⊆ V × V. The adjacency matrix A ∈ {0,1}^{N×N} is defined elementwise as
a_{ij} = \begin{cases} 1 & \text{if } v_i \to v_j \\ 0 & \text{otherwise} \end{cases}, \quad i,j = 1, ..., N. \tag{Eq. 1}
For undirected graphs, A = A^T. The degree of node v_i is the cardinality of its neighbor set:
d(v_i) = |N(v_i)| = |\{v_j : \exists (v_i, v_j) \lor \exists (v_j, v_i), j \neq i\}|. \tag{Eq. 2}
Degree bounds: 0 ≤ d(v_i) ≤ N − 1, where d(v_i) = 0 iff isolated and d(v_i) = N − 1 iff connected to all other nodes. Equivalently, d(v_i) = Σ_{j=1}^N a_{ij}. \tag{Eq. 3}
Tensor formulation (Page 5): With canonical basis ξ = {e_1, ..., e_N} ⊂ ℝ^N, define E_{ij} = e_i ⊗ e_j^T. The relationship tensor is
W = Σ_{i=1}^N Σ_{j=1}^N w_{ij} E_{ij} = Σ_{i=1}^N Σ_{j=1}^N w_{ij} e_i ⊗ e_j^T. \tag{Eq. 4}
In covariant/contravariant notation (Ricci–Levi-Civita), W^α_β = Σ_{i,j} w_{ij} e^α(i) e_β(j). \tag{Eq. 5}
Let u^α = (1,...,1)^T ∈ ℝ^N and U^β_α = u^α u_β. The degree vector is
k_β = W^α_β u^α. \tag{Eq. 6}
Node-specific degree is recovered by projection: k(i) = k_β e^β(i). \tag{Eq. 7}
Multilayer extension (Pages 6–7): A multilayer network is M = (V_M, E_M, V, L), where V_M ⊆ V × L_1 × ... × L_d and L = {L_a}_{a=1}^d. If d = 1, M is multiplex. The multilayer adjacency tensor is fourth-order:
M^{α eγ}_{β eδ} = Σ_{e_h=1}^L Σ_{e_k=1}^L C^α_β(e_h e_k) E^{eγ}_{eδ}(e_h e_k), \tag{Eq. 9}
with E^{eγ}_{eδ}(e_h e_k) = e^{eγ}(e_h) e^{eδ}(e_k). \tag{Eq. 8}
Expanding via the canonical basis ξ^{α eγ}_{β eδ}(i j e_h e_k) = E^α_β(i j) E^{eγ}_{eδ}(e_h e_k) = e^α(i) e_β(j) e^{eγ}(e_h) e^{eδ}(e_k): \tag{Eq. 11}
M^{α eγ}_{β eδ} = Σ_{e_h,e_k=1}^L Σ_{i,j=1}^N w_{ij}(e_h e_k) ξ^{α eγ}_{β eδ}(i j e_h e_k). \tag{Eq. 12}
Projected single-layer network (flattening): P^α_β = M^{α eγ}_{β eδ} U^{eδ}_{eγ} = Σ_{e_h=1}^L Σ_{e_k=1}^L C^α_β(e_h e_k). \tag{Eq. 13}
Aggregate/overlay network (ignoring interlayer edges): O^α_β = M^{α eγ}_{β eγ} = Σ_{e_r=1}^L W^α_β(e_r). \tag{Eq. 14}
Multidegree centrality vector:
K^α = ⟨ M^{α eγ}_{β eδ} U^{eδ}_{eγ} ⟩ u_β = ⟨ P^α_β ⟩ u_β = \Big( Σ_{e_h=1}^L Σ_{e_k=1}^L C^α_β(e_h e_k) \Big) u_β = Σ_{e_h=1}^L Σ_{e_k=1}^L k^α(e_h e_k). \tag{Eq. 15}
Units: all degrees are dimensionless counts of adjacent edges; weights are dimensionless multiplicities (number of meetings or phone calls). Network size: N = 154 nodes, |E| = 439 edges total; Meetings layer: 101 nodes, 256 edges; Phone Calls layer: 100 nodes, 124 edges; overlap: 47 shared nodes (Pages 7–8). Singularity/breakdown: Eq. 6 assumes u^α is well-defined and the tensor contraction does not vanish; if a node exists in only one layer and has degree zero there, k(i) = 0 and the node is structurally invisible to all three approaches unless interlayer coupling creates nonzero C^α_β(e_h e_k) with e_h ≠ e_k, which the paper sets to node-counterpart links only with zero cost (Page 8).
