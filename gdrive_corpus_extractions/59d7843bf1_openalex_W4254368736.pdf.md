1. Raster image operator and physical scaling.

Let the input binary image be
\[
I:\{1,\dots,W\}\times\{1,\dots,H\}\to\{0,1\},
\]
with \(W=2560\) and \(H=3300\) pixels for a Handwriting Sample Form image [PAGE 22]. The scan density is
\[
\rho = 12\ \mathrm{px/mm} = 300\ \mathrm{px/in}.
\]
Thus a pixel displacement \(\Delta n\) corresponds to physical displacement
\[
\Delta \ell = \frac{\Delta n}{\rho}.
\]
For example, the empirical registration error threshold of 4 px is
\[
\Delta \ell = \frac{4\ \mathrm{px}}{12\ \mathrm{px/mm}} \approx 0.333\ \mathrm{mm}.
\]
The source states that the forms “were scanned at 12 pixels per millimeter (300 dots per inch - dpi) binary” [PAGE 12].

2. Registration operator.

The system estimates a linear mapping from ideal reference coordinates \((x_r,y_r)\) to hypothesized coordinates \((x_h,y_h)\):
\[
x_h = A_x + m_x^x x_r + m_x^y y_r,
\]
\[
y_h = A_y + m_y^x x_r + m_y^y y_r.
\]
Here \(A_x,A_y\) have units of pixels, while the coefficients \(m_\bullet^\bullet\) are dimensionless because they multiply pixel coordinates to produce pixel coordinates [PAGE 33].

The least-squares objective is
\[
E^2 = \sum_{i=1}^{n}
\left[
\left(x_{h,i} - A_x - m_x^x x_{r,i} - m_x^y y_{r,i}\right)^2
+
\left(y_{h,i} - A_y - m_y^x x_{r,i} - m_y^y y_{r,i}\right)^2
\right],
\]
with units \(\mathrm{px}^2\). In matrix form, for one coordinate equation,
\[
\mathbf{b} = \mathbf{A}\mathbf{p},
\]
and the least-squares solution is
\[
\hat{\mathbf{p}} =
\left(\mathbf{A}^{\mathsf{T}}\mathbf{A}\right)^{-1}
\mathbf{A}^{\mathsf{T}}\mathbf{b}.
\]
The source describes this as “a technique for detecting form registration failures” and then presents the matrix solution [PAGE 32-34].

Assumptions: the distortion is approximately affine over the form; the located registration points are not gross outliers; the reference points correspond one-to-one with hypothesized points.

Breakdown regimes:
- If fewer than three reliable points remain, the affine estimate is underdetermined or unreliable. The source’s failure pseudocode uses a remaining-point threshold [PAGE 32].
- If \(\det(\mathbf{A}^{\mathsf{T}}\mathbf{A})=0\), the normal-equation matrix is singular and no unique least-squares solution exists. This can occur if reference points are collinear or if duplicate hypotheses collapse the rank.
- If the maximum transformed-point error exceeds the empirical threshold, the point is removed. The source says, “Hsfsys uses an error threshold of 4, which was derived empirically from a set of independent studies.” [PAGE 33].
- The documented tolerance is limited: “Hsfsys has been engineered and tested to tolerate up to 5 degrees of rotation in combination with 1.27 cm (0.5 inches) of translation.” [PAGE 32]. Beyond this, histogram peaks broaden and registration becomes unreliable [PAGE 32].

3. Form-removal operator.

Let \(r_{ij}\) be the registered input pixel and \(m_{ij}\) the dilated form-mask pixel. The output pixel is
\[
o_{ij} = r_{ij} \land \neg m_{ij}.
\]
Equivalently,
\[
o_{ij} =
\begin{cases}
1, & r_{ij}=1 \text{ and } m_{ij}=0,\\
0, & \text{otherwise}.
\end{cases}
\]
The units are bits, since pixels are binary values. The source says, “The form is erased from the registered input image by applying the dilated blank form as a mask.” [PAGE 35].

Assumptions: the registered input is close enough to the blank form that a four-times-dilated mask covers residual form lines without deleting excessive handwriting.

Breakdown regimes:
- If registration residual exceeds the dilation margin, form residue remains.
- If handwritten strokes overlap form lines, the NAND removal can create holes. The source explicitly notes that characters “may be left with holes and discontinuities” and that a complete reconstruction solution has not yet been developed [PAGE 35].

4. Spatial histogram and line isolation operator.

For a field subimage \(F(x,y)\), the horizontal histogram is
\[
H_{\mathrm{row}}(y) = \sum_{x} F(x,y),
\]
with units of black pixels per raster row. The vertical histogram is
\[
H_{\mathrm{col}}(x) = \sum_{y} F(x,y),
\]
with units of black pixels per raster column.

For one-line fields, the system thresholds row bins:
\[
b_y =
\begin{cases}
1, & H_{\mathrm{row}}(y) > 2,\\
0, & H_{\mathrm{row}}(y) \le 2.
\end{cases}
\]
It then computes run lengths over contiguous 1 values and selects the longest run to estimate the vertical middle of the text [PAGE 41]. For left and right boundaries, the source uses a 10-pixel threshold: “The use of a 10 pixel threshold avoids speckle noise in the field and locates the beginning of significant character data, while the reverse search locates the edge of the character data.” [PAGE 41].

Assumptions: the target handprint forms one dominant line; form residue is weaker or spatially separable; the histogram projection preserves sufficient contrast.

Breakdown regimes:
- Multi-line fields cannot be isolated by this one-line method and require the separate multi-line Constitution-field procedure [PAGE 57].
- If handwriting is extremely sparse, the 10-pixel threshold may suppress valid strokes.
- If punctuation or speckle exceeds the threshold, the estimated boundary may expand incorrectly.

5. Connected-component segmentation and blob pasting.

A blob is a maximal connected set of black pixels. Let \(N_b\) be the number of black pixels in a blob. The source uses the size gate:
\[
100 \le N_b \le 1750.
\]
The source states, “if a blob has less than 100 black pixels it is considered too small, and if a blob has more than 1750 black pixels it is considered too big.” [PAGE 44]. The units are pixel counts, dimensionless integers.

For disjoint digits such as a disconnected 5, the paste rule is local. Let \(y_{\mathrm{bottom}}^{\mathrm{next}}\) be the bottom coordinate of the next blob and \(y_{\mathrm{top}}^{\mathrm{curr}}\) the top coordinate of the current blob. Let \(h_{\mathrm{curr}}\) be the current blob height. The paste condition is
\[
y_{\mathrm{bottom}}^{\mathrm{next}} - y_{\mathrm{top}}^{\mathrm{curr}}
<
\frac{h_{\mathrm{curr}}}{2}.
\]
All quantities are in pixels. The source says, “If the difference between the next blob’s bottom minus the current blob’s top is less than half the current blob’s height, then the two blobs are pasted back together as a new plausible character image.” [PAGE 45].

Assumptions: neighboring blobs are ordered left-to-right; vertical separation is meaningful; character height is stable enough for the half-height rule.

Breakdown regimes:
- If two characters touch, the blob is too large and may be discarded or misclassified.
- If a broken stroke has a vertical gap greater than or equal to half the current blob height, the paste rule fails.
- If punctuation lies between blobs, the heuristic may paste or fail to paste incorrectly.

6. Size normalization and shear.

The normalization operator maps a segmented character bounding box into a \(20\times32\) pixel region and then places it inside a \(32\times32\) pixel field. The source says the box “is scaled to fit exactiy within a 20 by 32 pixel region, and the aspect ratio of the original character is not preserved.” [PAGE 46]. The output coordinate space is dimensionless in the classifier’s normalized image coordinates, but derived from pixels.

The shear operator uses a slope factor. Let \(y_t\) be the top row containing black pixels, \(y_b\) the bottom row containing black pixels, \(x_t\) the horizontal position of the leftmost black pixel in the top row, and \(x_b\) the horizontal position of the leftmost black pixel in the bottom row. A formal slope is
\[
f =
\frac{x_t - x_b}{y_b - y_t}.
\]
The shift coefficient for row \(r\) is
\[
s_r = (r - m) f,
\]
where \(m\) is the vertical middle of the normalized image. A positive \(s_r\) shifts row \(r\) right; a negative \(s_r\) shifts it left. The units of \(f\) are \(\mathrm{px}/\mathrm{px}\), so \(f\) is dimensionless, and \(s_r\) has units of pixels [PAGE 46-47].

Assumptions: the leftmost black pixel of the top row and the leftmost black pixel of the bottom row belong to the same dominant vertical stroke.

Breakdown regimes:
- If the character has multiple symmetric strokes, such as H or M, the selected leftmost pixels may not define a single stroke. The source says the technique “occasionally fails to remove the slant from the character when the top-leftmost black pixel in the image and the bottom-leftmost black pixel in the image do not lie on the same vertical suoke.” [PAGE 47].
- If the character is clipped or malformed, the top or bottom row estimate may be noisy.

7. Karhunen-Loeve feature operator.

A normalized \(32\times32\) character image is represented as a vector
\[
u \in \{-1,+1\}^{1024},
\]
where black pixels are mapped to \(+1\) and white pixels to \(-1\) [PAGE 37]. Let \(P\) be the number of training images. The sample mean is
\[
\mu = \frac{1}{P}\sum_{p=1}^{P} u_p.
\]
The covariance matrix is
\[
R =
\frac{1}{P}
\sum_{p=1}^{P}
(u_p-\mu)(u_p-\mu)^{\mathsf{T}}.
\]
Diagonalization gives
\[
R\Phi = \Phi\Lambda,
\]
where \(\Phi\) contains eigenvectors and \(\Lambda\) contains eigenvalues. The source says the covariance matrix is diagonalized “producing the eigenvalues and corresponding eigenvectors in descending order of largest eigenvalue.” [PAGE 48].

The feature vector is the projection
\[
v = \Phi_k^{\mathsf{T}}(u-\mu),
\]
where \(\Phi_k\) retains the top \(k\) eigenvectors. In the system,
\[
k = 64.
\]
The source states, “In hsfsys, k is selected to be 64.” [PAGE 48]. The units of \(v\) are feature-space units inherited from the binary image embedding; they are not physical lengths. The eigenvalue spectrum has units of variance in that same feature space.

Assumptions: the covariance eigenvectors estimated from training images represent the test writer distribution; the largest eigenvalues contain the most useful discriminative variance.

Breakdown regimes:
- If the number of independent training samples is too small relative to dimensionality, the covariance estimate becomes rank deficient.
- If eigenvalues are degenerate, eigenvector orientation may be unstable.
- If test handwriting lies outside the training covariance subspace, projection discards relevant variation.

8. Probabilistic neural network discriminant and pruning.

For class \(i\), with \(M_i\) prototypes \(x_{ij}\), smoothing parameter \(a\), and feature dimension \(k\), the formal Gaussian PNN discriminant is
\[
D_i(y)
=
\frac{\Pr(i)}{M_i(2\pi a^2)^{k/2}}
\sum_{j=1}^{M_i}
\exp\left(
-\frac{\|y-x_{ij}\|^2}{2a^2}
\right).
\]
The discriminant has units of probability density in \(k\)-dimensional feature space. The posterior probability estimate is
\[
\widehat{\Pr}(i\mid y)
=
\frac{D_i(y)}
{\sum_{\ell=1}^{L} D_\ell(y)}.
\]
This is dimensionless and lies in \([0,1]\). The source says the exponential activations are normalized “to estimated probabilities by dividing by their sum” [PAGE 51].

The smoothing parameter is specified as \(a=2.0\) for digits and \(a=3.0\) for alphabetic characters [PAGE 49]. The Euclidean distance is
\[
d^2(y,x) = \|y-x\|^2 = (y-x)^{\mathsf{T}}(y-x).
\]
The pruning inequality, derived from ignoring prototypes whose exponential contribution is negligible, can be written as
\[
d^2(y,x_j)
>
2a^2\ln(10)X + d^2(y,x_c),
\]
where \(x_c\) is the closest prototype found so far and \(X\) controls the approximation error. The source says, “This parameter should not be less than log(P/L), where P is the number of prototypes, and L is the number of classes.” [PAGE 49].

Assumptions: prototypes are representative; class priors are approximately balanced or omitted; feature-space distances are meaningful; the k-d tree can discard subtrees without losing eligible prototypes.

Breakdown regimes:
- If no close prototype is found in the tree search, the source says all prototypes are used in the approximated PNN calculation [PAGE 51].
- If \(X\) is too small, valid prototypes may be pruned; if too large, pruning provides little speed gain.
- If the feature space is extremely sparse or the unknown vector lies outside the training cloud, nearest prototypes may be unreliable.

Information-theoretic interpretation: the posterior can be converted to surprisal,
\[
S_i(y) = -\log_2 \widehat{\Pr}(i\mid y),
\]
with units of bits. High-confidence classifications correspond to low surprisal.

The source notes that writers do “all types of curious things” when running out of room [PAGE 45]. This is a retro-causal pressure: the form design causes the writer behavior, and the writer behavior causes segmentation stress.

The third trap is dictionary mismatch. The Constitution box uses a 38-word lexicon constructed from the Preamble [PAGE 62]. This is powerful because the vocabulary is tiny and known. But it also means the system’s word-level success is tied to a specific document. If the text domain changes, the dictionary advantage disappears. The source compares this to the Second Census OCR Conference, where dictionaries of more than 60,000 multiple-word phrases were used [PAGE 73]. The comparison shows that the standard reference system is not a general-purpose unconstrained OCR engine; it is a form-specific reference system with a narrow linguistic prior.

The fourth trap is evaluation drift. The reported accuracies are tied to the first 500 writers in SD1 [PAGE 65]. If the evaluation sample changes, the measured performance may change because the training prototypes, eigenvectors, and thresholds were tuned to that distribution. The historical lesson is that a benchmark system can become a moving target when the data-generating process changes.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
A recursive theory-of-mind analysis treats the writer, the form designer, the recognition engineer, and the batch operator as agents with interacting expectations. The writer expects the form to provide enough space and clear boxes. The form designer expects the writer to print cleanly inside boxes. The recognition engineer expects the scanned form to preserve registration marks and field boundaries. The batch operator expects the system to run without graphical interaction and produce text files for scoring.

Crisis habit regression occurs when the writer is under time pressure or space pressure. The source identifies this directly: “As a writer begins to run out of room, he will do all types of curious things to fit the remainder of his answer in the field.” [PAGE 45]. In a high-pressure setting, the writer may shrink characters, merge strokes, omit spaces, switch case, or use punctuation inconsistently. The Constitution field is especially vulnerable because the source observes that handprint “often fluctuates significantly within lines as well as across lines” [PAGE 58]. This is not random noise; it is a behavioral regression induced by task constraints.

The system’s counter-trap stack is designed to anticipate those regressions. Registration counteracts global page distortion. Form removal counteracts printed form structure. Histogram isolation counteracts field residue. Blob pasting counteracts disconnected strokes. Size normalization counteracts scale variation. Shear normalization counteracts slant variation. Karhunen-Loeve features counteract raw pixel dimensionality. PNN classification counteracts local feature noise. Phrase reconstruction counteracts line-reading-order failures. Dictionary matching counteracts character substitution, insertion, and deletion errors.

However, each counter-trap has a failure signature. If the writer’s regression becomes too extreme, the system’s local heuristics may lock onto the wrong structure. For example, a comma or stray mark can create a false neighbor in the phrase bubble search. The source’s phrase search is intentionally conservative: it can preempt the search and restart rather than blindly follow erratic trajectories [PAGE 60]. This is a counter-trap against the writer’s erratic line motion. Similarly, the blob paste rule is narrow: it only rejoins vertical fragments that satisfy a half-height condition [PAGE 45]. If the writer’s disconnection is too large, the system will not guess.

The clock dimension is explicit. The source reports that classification and dictionary postprocessing dominate runtime: classification is \(29.2\%\) of measured time and spelling is \(26.0\%\) [PAGE 66]. The system is also memory sensitive. It can run with 8 Megabytes, but the source warns that this is not recommended because the system is resource intense [PAGE 11]. Under a stricter clock or memory budget, the operator may select small-memory mode, which reduces prototype count and lowers accuracy: digit output accuracy falls from \(92.9\%\) to \(92.3\%\) [PAGE 65], and word accuracy falls from \(60.5\%\) to \(59.0\%\) [PAGE 65].

The recursive prediction is therefore conditional: if the writer regresses mildly, the counter-trap stack recovers the text. If the writer regresses severely, the system must choose between failing locally or guessing globally. The engineering design chooses local failure detection, such as registration failure, blob rejection, or low dictionary signal, rather than uncontrolled global guessing. This makes the system safe for benchmarking but brittle for open-world deployment.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The physical and biomechanical veto proof can be constructed from the source’s own thresholds.

First, global registration veto. The system tolerates “up to 5 degrees of rotation in combination with 1.27 cm (0.5 inches) of translation.” [PAGE 32]. If an input form exceeds either bound, the spatial histogram projections used to locate registration marks become shorter and wider, and the source says they become “decreasingly reliable and increasingly inaccurate.” [PAGE 32]. Therefore, any physical deformation beyond that envelope vetoes the assumption that the form can be mapped reliably to the template. The proof is direct: registration point localization fails, least-squares residual grows, and the failure detector removes points or declares failure [PAGE 32-33].

Second, registration-mark occlusion veto. The system depends on six marks. If noise or handwriting occludes marks, the hypothesis set may fall below the minimum required for reliable affine estimation. The source’s failure pseudocode removes high-error points until either the error falls below threshold or too few points remain [PAGE 32]. Therefore, occlusion is a physical veto when it causes the remaining point count to fall below the operational minimum. The source does not give the exact numeric minimum in the prose, but the pseudocode uses a remaining-point limit and says registration fails if too few points remain [PAGE 32].

Third, form-removal residual veto. The system erases the form using a dilated mask. If handwritten strokes cross form lines, the removal can delete parts of the character. The source says characters “may be left with holes and discontinuities” and that a complete solution has not been developed [PAGE 35]. This is a biomechanical veto: the writer’s stroke trajectory crosses a printed line, and the mask cannot distinguish ink source. Once holes are created, downstream segmentation and classification may be irrecoverably damaged.

Fourth, blob-size veto. The segmentor rejects blobs with fewer than 100 black pixels or more than 1750 black pixels [PAGE 44]. If a digit is broken into fragments each below 100 pixels, the fragments are discarded. If two characters touch and form a blob above 1750 pixels, the blob is also discarded. This is a combinatorial veto: the true character lies outside the allowed connected-component mass interval.

Fifth, paste-heuristic veto. The digit paste rule requires the next blob’s bottom minus the current blob’s top to be less than half the current blob’s height [PAGE 45]. If a writer’s disconnected 5 has a vertical gap equal to or greater than half the height, the system will not rejoin the pieces. This is a geometric veto based on the writer’s stroke separation.

Sixth, shear veto. The shear estimator uses the leftmost black pixel in the top and bottom rows. If those pixels do not belong to the same vertical stroke, the estimated slope is wrong. The source specifically notes failure for characters such as H and M where multiple peaks exist [PAGE 47]. This is a topological veto: the character’s shape violates the single-stroke assumption used by the shear operator.

Seventh, memory veto. The system can run with 8 Megabytes, but the source warns that this is not recommended because the system is resource intense [PAGE 11]. If the available memory forces small-memory mode, prototype count decreases and accuracy decreases [PAGE 65]. This is a computational veto: the hardware budget changes the statistical model.

Eighth, dictionary-vocabulary veto. The Constitution field postprocessor uses a limited lexicon. If the true word is absent from the lexicon, dictionary postprocessing cannot restore it. The source’s lexicon contains the Preamble words, including “CONSTITUTION” as the longest word of 12 characters [PAGE 62-64]. If the writer’s intended word is outside that set, the dictionary stage cannot veto the error.

The adjudication is therefore strict: the system is valid only when the input respects the registration envelope, the form-removal mask remains compatible with stroke topology, blob masses fall within the accepted interval, shear assumptions hold, memory permits full prototypes, and the vocabulary contains the intended words. If any of these physical or biomechanical conditions fail, the corresponding layer issues a veto and the final recognition result should not be treated as reliable.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
1. Registration-mark occlusion veto.

Counterfactual: introduce a small black mark or handwriting stroke near one of the six registration points. The system uses spatial histograms to locate the mark, but the source warns that “noise such as extraneous marks or writing in the vicinity of a registration mark” can confuse or occlude the mark [PAGE 32].

Verifiable prediction:
- If the corrupted point produces a transformed error above the empirical threshold of 4 px, the failure detector removes it [PAGE 32-33].
- If removal leaves enough points, registration continues and the final transform may still succeed.
- If removal leaves too few points, the system outputs “form registration failed” [PAGE 32].
- If the corrupted point is not removed but biases the fit, the transformed image will show increased residual error at other points, causing further point removal or degraded field isolation.

This veto is verifiable by comparing hypothesis files before and after occlusion: either registration succeeds with changed parameters, or the system reports failure.

2. Disjoint-five paste veto.

Counterfactual: modify a digit so the top stroke of a 5 is disconnected from the lower portion, with a vertical gap larger than half the current blob height.

Source rule: the blobs are pasted only if
\[
y_{\mathrm{bottom}}^{\mathrm{next}} - y_{\mathrm{top}}^{\mathrm{curr}}
<
\frac{h_{\mathrm{curr}}}{2}.
\]
[PAGE 45].

Verifiable prediction:
- If the gap is smaller than half the current blob height, the system pastes the blobs and classifies one digit.
- If the gap is equal to or larger than half the current blob height, the system treats the pieces as separate blobs.
- If each fragment has fewer than 100 black pixels, it is rejected as too small [PAGE 44].
