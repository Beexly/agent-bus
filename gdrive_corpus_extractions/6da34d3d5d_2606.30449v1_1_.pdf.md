The threshold monitor is valid iff $\text{supp}(P_{\text{ctx}}) \subseteq \text{supp}(P_{\text{constr}})$ under a shared scale. At L40 this fails (prompt-distribution shift), so any L40 threshold-crossing claim is vetoed a priori; the larger descriptive AUC 0.644 at L40 cannot be promoted to threshold evidence [PAGE 5, PAGE 12]. L24 survives precisely because the scales coincide.

Veto 2 — Temperature-protocol veto. The canonical sweep is T = 0.7 (n = 300); the matched-marginals run is T = 1.0 (n ≈ 150) [PAGE 7–8]. Cross-comparisons "against the matched-marginals run, which used T = 1.0, should be read with that documented protocol divergence in mind" [PAGE 17]. Any claim that mixes rate points across these temperatures is vetoed; only within-temperature contrasts are admissible. Concretely, the calm-vs-random non-rejection (13/149 each, p = 1.000 at T = 1.0) [PAGE 8] cannot be pooled with the T = 0.7 random point of 16.7%.

Veto 3 — Weather (semantic-control) veto, verbatim-grounded. The "weather" direction is literally a learned content control in this paper, not a meteorological variable. At matched α = 0.10, weather = 8.0% sits below random = 16.7% [PAGE 7]; the weather/cats/random three-way omnibus rejects equality on Gemma (p = 0.0042) but is not reproduced on Qwen3-32B (p = 0.555) [PAGE 8, PAGE 14]. Adjudication: because an unrelated learned direction (weather) moves the blackmail rate and its three-way structure fails to transfer, the emotion-specificity interpretation is vetoed as non-robust — the effect is attributable to "a property of coherent learned directions" rather than to the intended semantic family [PAGE 4]. This is the paper's core specificity veto, and it holds in both models (either weather moves rates on Gemma, or the structure does not transfer on Qwen3).

Joint proof: a robust emotion-specific pre-action monitor requires surviving Veto 1 (comparable scale — satisfied only at L24/L16), Veto 2 (single protocol — satisfied only within-temperature), and Veto 3 (specificity — failed by weather/cats/sports/geography). Since Veto 3 fails in at least one model unconditionally, the strong mechanistic-precursor claim is vetoed; only the weaker descriptive claim survives.
