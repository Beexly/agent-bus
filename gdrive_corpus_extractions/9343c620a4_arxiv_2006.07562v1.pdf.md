PELEG extends this to structured linear bandits for the first time, per the authors [PAGE 2]. The third strand includes prior suboptimal or geometry-limited methods: XY-static [17] (worst-case optimal but d-dependent), LinGapE [15] (scales with K), ALBA [19] (suboptimal), LUCB [21] (limited to 2–3 arms) [PAGE 2–3].

Multi-week traps specific to deployment: (1) assuming vanilla EXP-WTS/Hedge suffices without self-tuning learners like AdaHedge [5]; PELEG shows phased elimination removes the need for AdaHedge [PAGE 5], but only if phases are correctly synchronized to the gap clock ε_m = 2^{−(m+1)}. (2) Ignoring C geometry: if feature vectors are poorly conditioned over weeks of data collection, C = λ_min(∑xxᵀ) collapses, and the 1/C² penalty in Theorem 1 [PAGE 6] inflates sample requirements beyond operational budgets. (3) Rounding trap: fractional allocations from an oracle must be integerized; PELEG avoids this via tracking [PAGE 5], but legacy systems inheriting RAGE’s rounding may accumulate O(K) slack per phase, violating δ-PAC over long horizons. (4) The δ₀ existence in Lemma 2 [PAGE 7–8] is non-constructive; a system tuned for δ=0.1 may silently operate outside the proven regime if δ₀ is smaller.

<RECURSIVE_THEORY_OF_MIND>
Crisis habit regression versus counter-trap versus clock.

The algorithm embodies a recursive theory of mind across two learners. The MAX player (EXP-WTS) maintains a belief distribution w_t over arms, assuming the MIN player will select the most confusing alternative model λ. The MIN player best-responds by solving argmin_{λ∈∪ C_m(x) ∩ B(0,D_m)} ||λ||²_{W_t} [PAGE 5 line 16], effectively modeling MAX’s next sampling distribution. This nested modeling converges to a saddle point via no-regret dynamics, obviating the need for a centralized minimax oracle [PAGE 4–5].

Crisis habit regression: when uncertainty is high (early phases, large ε_m), the learner regresses to a static, uniform-like exploration habit because every arm difference appears plausible; this is exactly the failure mode of XY-static in Setting 1, where uniform allocation is optimal only when Δ≈0 [PAGE 8]. The regression is a habit because it treats all directions as equally informative, wasting samples on non-confusing arms.

Counter-trap: PELEG’s phased elimination is the counter-trap. By shrinking ε_m ≈ 2^{−(m+1)} each phase [PAGE 5–6], the algorithm forces the MAX player to concentrate on the currently most confusing arm pairs rather than regressing to uniformity. The elimination rule at line 26 [PAGE 5] removes arms with estimated gap > 2^{−(m+2)}, making the habit regression progressively more expensive and the game-theoretic focus progressively more valuable.

Clock: the phase index m and δ_m = δ/m² [PAGE 5 line 5] act as the recursion clock. Corollary 2 bounds total phases by ⌈log₂(1/Δ_min)⌉ [PAGE 20], so the clock ticks at most logarithmically in the inverse minimum gap. However, per-phase cost grows quadratically in 2^m through r_m and B_m terms [PAGE 7–8], meaning the clock’s later ticks are exponentially more expensive. If Δ_min is extremely small, the clock runs long, and the cumulative sample complexity approaches the Θ(log(1/δ)/D_{θ*}) lower bound only up to the C² and logarithmic factors [PAGE 6 Theorem 1].
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical, geometric, and environmental veto conditions under which the theory breaks.

Physical layer: The source assumes ||x_k||₂ ≤ 1 for all x_k∈X [PAGE 3]. If any arm vector is unbounded, the design matrix V_m^t no longer uniformly dominates ∑ x xᵀ, and the ellipsoid shrinkage in Lemma 1 fails because λ_min(V_m^t) cannot be lower-bounded by C [PAGE 13 proof]. This is a hard veto: normalized features are required for the confidence-ellipsoid contraction.

Biomechanical/analog (noise) layer: Reward noise must be conditionally 1-subgaussian [PAGE 3]. Heavy-tailed or unbounded noise invalidates the sub-Gaussian concentration used in Lemma 6 and the Key Lemma [PAGE 12, 19–20]. The veto is exact: without the sub-Gaussian mgf bound, the probability that the true parameter lies outside the ellipsoid exceeds δ, so the δ-PAC guarantee collapses and the error probability is no longer bounded by δ.

Geometric/singularity layer: C := λ_min(∑_{k=1}^K x_k x_kᵀ) [PAGE 11 glossary; PAGE 3 Table 1]. Veto: C → 0 occurs when arms are nearly collinear or fail to span ℝᵈ. Then D_m ∝ 1/√C [PAGE 6 line 7], the 1/C² factor in Theorem 1 [PAGE 6; PAGE 20–21] diverges, and the OLS estimate bθ_m = V⁻¹∑Yx becomes ill-defined at C=0. This is a singularity: exact breakdown when the Gram matrix loses positive-definiteness.

Decision-layer tie veto: The problem statement assumes θ such that argmax is unique [PAGE 3]. If θ*ᵀ(x*−x) = 0 for some x, then Δ_min = 0. Corollary 2’s phase bound log₂(1/Δ_min) becomes infinite [PAGE 20], and the strict elimination inequality bθ_mᵀ(x′−x) > 2^{−(m+2)} [PAGE 5 line 26] cannot reliably separate tied arms; estimation noise may eliminate the true best arm or preserve a tied suboptimal arm indefinitely.

Experimental veto: The proof of Lemma 4 and the regret analysis require the ellipsoid to remain within B(0,D_m) [PAGE 7 Note 2; PAGE 12]. The implementation explicitly drops this intersection [PAGE 9; PAGE 21]. This vetoes the formal regret bound in practice, though the authors report empirical robustness [PAGE 7 Note 2; PAGE 8]. The veto is conditional: theory intact only if B(0,D_m) is retained or an alternative bounded-loss argument is supplied.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Three verifiable counterfactual veto scenarios with falsifiable predictions.

Veto Scenario 1 — Degenerate geometry (C → 0).
Construct an arm set in ℝ² with x₁ = e₁ and x₂ = (1−ε)e₁ + εe₂ for ε∈(0,1). Then C = λ_min(x₁x₁ᵀ + x₂x₂ᵀ) scales as Θ(ε). Prediction from Theorem 1 [PAGE 6]: sample complexity τ scales as O(1/C²) = O(1/ε²). As ε → 10⁻³, predicted τ increases by a factor ≈10⁶ relative to C=Θ(1). Verifiable test: compute C numerically before running PELEG; if C < 10⁻³, the algorithm should require orders-of-magnitude more pulls than the oracle lower bound and may exceed any finite sampling budget before identifying a* with probability 1−δ.

Veto Scenario 2 — Non-subgaussian noise.
Replace η_t with i.i.d. Cauchy noise (infinite variance, undefined mgf). The condition 𝔼[e^{γ η_t}] ≤ exp(γ²/2) [PAGE 3] is violated. Prediction: the Key Lemma confidence ellipsoid no longer contracts at the stated rate [PAGE 12], and Lemma 6’s sub-Gaussian tail bound [PAGE 19] fails. Empirically, with δ=0.1 passed to the algorithm, the observed best-arm identification success rate should fall below 90% across repeated trials, contradicting the claimed δ-PAC guarantee [PAGE 1; PAGE 8 experiments report 100% success under Gaussian noise].

Veto Scenario 3 — Non-unique argmax (Δ_min = 0).
Set θ* such that θ*ᵀx₁ = θ*ᵀx₂ for two distinct arms, while all other arms are strictly suboptimal. Then Δ_min = 0 [PAGE 3]. Prediction from Corollary 2 [PAGE 20]: the maximum number of phases ⌈log₂(1/Δ_min)⌉ is unbounded, so the algorithm has no finite termination guarantee. The elimination rule at line 26 [PAGE 5] uses a strict threshold 2^{−(m+2)}; under estimation noise, either the true best arm is eliminated or a tied arm survives indefinitely. Verifiable test: initialize θ* orthogonal to x₁−x₂ and observe whether PELEG terminates within any prescribed phase budget; it should fail to return a unique best arm with probability tending to 1 as the budget grows, falsifying the Corollary 2 bound in the tied regime.
</RLVR_COUNTERFACTUAL_VETOES>
