The derivation chain begins with the physical imaging degradation of underwater scenes. Light propagation through water follows exponential attenuation governed by the Beer–Lambert relation I(z) = I₀ exp(−c z), where c [m⁻¹] is the bulk attenuation coefficient and z [m] is optical path length. As c increases with turbidity and suspended particulate concentration, image contrast collapses toward the sensor noise floor, causing the feature-space separation between a camouflaged marine animal and its background to degenerate. The paper identifies precisely this failure mode for correlation-filter trackers, Siamese networks, pure Transformers, and Mamba-based sequence models under “low-contrast and turbid environments,” “cluttered underwater backgrounds,” and “underwater-specific degradations” [PAGE 1].

The first multi-hop inference is that a generic appearance model cannot recover identity once the signal-to-noise ratio in the visible spectrum falls below the discrimination threshold of the backbone. SAM- and SAM2-based trackers bypass this by relying on a pre-trained visual foundation model’s strong generalization ability and prompt-guided segmentation, enabling semantic-aware feature extraction and adaptive multi-scale processing [PAGE 1]. VL-SAM2 extends this by injecting a language description into the mask decoder through a frozen CLIP ViT-B/32 language encoder and a linear projector, producing sparse embeddings e_sparse = [E_vis(b₀); Proj(E_lang(d))] ∈ ℝ^(d_vis + d_lang), where b₀ = [x, y, w, h] is the initial bounding box in pixel coordinates [PAGE 4].

The second multi-hop inference concerns temporal drift. Underwater animals exhibit non-rigid locomotion—seahorses sway, octopuses undulate, stingrays glide—violating the constant-velocity assumption encoded in the MATP Kalman filter state transition. Algorithm 1 [PAGE 3] reveals a gray-zone switching logic: if IoU(b_max_response, b̂_E) < conf = 0.6, the tracker sets match_state = True and selects b_M = argmax(scores); otherwise it falls back to b_M = max response box. The response-map threshold threshold = 0.8 and NMS IoU threshold = 0.5 introduce two additional hard boundaries where candidate extraction and suppression become sensitive to calibration.

Fourth, encoder staleness: because CLIP and Hiera-L are frozen, the model cannot assimilate new underwater camouflage categories encountered after deployment without full retraining, creating a recursive obsolescence loop where the tracker’s performance degrades relative to the evolving data distribution it was meant to monitor.

<RECURSIVE_THEORY_OF_MIND>
Theory of mind here is modeled recursively across three levels: (L0) the tracker’s internal estimate of the target state; (L1) the animal’s effective “policy” of remaining camouflaged (a passive adversarial behavior); (L2) the researcher’s model of the tracker’s failure modes.

Crisis habit regression is instantiated in Algorithm 1 lines 8–17 [PAGE 3]. Under nominal conditions, the Kalman prediction b̂_E and the response-map maximum are aligned (IoU ≥ conf = 0.6), so match_state = False and b_M = max response box, a low-variance, memory-guided choice. Under crisis—when a visually similar distractor displaces the true target—IoU(b_max_response, b̂_E) falls below 0.6, match_state flips to True, and the system regresses to b_M = argmax(scores) over the NMS-filtered candidate set C′_t. This is a habit regression from smooth Kalman extrapolation to greedy response-map maximization, precisely the regime where distractor-induced drift is most likely.

The counter-trap is the language branch. Because CLIP ViT-B/32 aligns text and vision in a shared feature space over vast data [PAGE 5], the linguistic description (“The yellow pygmy seahorse on the willow coral” [PAGE 2]) supplies an L2 semantic prior that the animal itself cannot locally mimic through camouflage. The language embedding acts as a counter-trap to the distractor trap: even if the visual response map is hijacked by a look-alike background region, the projected language embedding biases the mask decoder toward the described attributes (color, behavior, surroundings), raising the score of the true target in C′_t and reducing the probability that argmax(scores) selects the distractor.

The clock operates at multiple scales. Inference speed is bounded by model size [PAGE 4, Table 3]: SAM2-T runs at 47.2 FPS, SAM2-L at 24.2 FPS. At 24.2 FPS, the Kalman predict-update cycle completes every Δt ≈ 41 ms; if an octopus changes direction or a seahorse sways faster than this cycle, the constant-velocity process model accumulates innovation error. The memory bank in SAM2 also ages: stale memory entries from pre-occlusion frames become misleading after long absences (a_t = 1), requiring MATP to gate memory updates [PAGE 3, PAGE 4]. Recursively, the researcher anticipates this regression and installs the MATP gate, but the researcher’s own model of the animal’s maneuverability may be wrong, producing a second-order blind spot: the tracker regresses under crisis, the counter-trap (language) is trusted, yet if the language description is generic (e.g., “fish moving in water”), the semantic margin collapses and the system loses both L0 precision and L1 disambiguation simultaneously.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Three layers can independently veto a tracking update. The veto operator at frame t is defined as V_t = 1 ⇔ skip update / retain prior state ∨ request re-prompt; otherwise V_t = 0.

Physical layer: underwater radiative transfer. Attenuation I(z) = I₀ exp(−c z) [PAGE 1 context: light attenuation, scattering effects]. If the diffuse attenuation coefficient c [m⁻¹] exceeds the sensor’s dynamic range such that target-background contrast ΔC < C_min (sensor noise-equivalent contrast), the visual branch produces low-confidence embeddings. Additionally, caustics from surface waves and backscatter from suspended sediment create spatially varying false positives that violate the assumption of spatially stationary background clutter.

Biomechanical layer: animal kinematics. The MATP Kalman filter assumes near-constant velocity over Δt = 1 frame. Seahorses “swaying” [PAGE 2], octopuses undulating, and stingrays executing rapid turns violate this assumption, making the process noise Q under-specified. When the animal’s acceleration exceeds the filter’s gating threshold, the innovation z_t − H x̂_{t|t−1} grows, and if the Mahalanobis distance d² = (z_t − H x̂)ᵀ S_t⁻¹ (z_t − H x̂) exceeds the chi-squared gate, the measurement should be vetoed as an outlier.

Weather/environmental layer: surface and volumetric conditions. Turbulence, thermal layers, sediment resuspension, and changes in downwelling irradiance alter c and the scattering phase function mid-sequence. These are non-stationary in time and can invalidate the frozen CLIP/Hiera feature extractors, which were trained on open-air and generic video data [PAGE 4].

Veto adjudication logic, concretized from Algorithm 1 [PAGE 3]:
V_t = 1 iff
(a_t = 1)                                 [target absent/occluded]
∨ ( max_{b ∈ C′_t} IoU(b, b̂_{E,t}) < conf = 0.6 )   [Kalman-response mismatch]
∨ ( max response map value < threshold = 0.8 )      [weak detector confidence]
∨ ( NMS-pruned candidate set C′_t = ∅ )             [no valid candidate]
∨ (estimated visibility ζ_t < ζ_min)              [physical layer veto]
∨ (biomechanical jerk j_t > j_max)               [kinematic layer veto]

When V_t = 1, the tracker must not update the SAM2 memory bank with b_M (per Algorithm 1 line 19, kf.update(b_M) is skipped implicitly), and it should fall back to b̂_{E,t} or trigger a language re-prompt to re-acquire the target. The cross-layer veto is necessary because no single layer—visual, linguistic, or motion—is sufficient to guarantee identity under underwater camouflage; failure in any layer corrupts the sparse embedding stream or the Kalman state.

<RLVR_COUNTERFACTUAL_VETOES>
We define a verifiable reward function R = AUC ∈ [0,1] (reported on 0–100 scale) and a counterfactual do-operator do(X = x) that intervenes on component X while holding all else fixed. Three veto scenarios:

Veto Scenario 1 — Language-encoder ablation (do(language_encoder = T5)). Verifiable prediction: replacing CLIP ViT-B/32 with T5 collapses VL-SAM2 from AUC = 71.3, Pre = 75.2, nPre = 78.2, cAUC = 70.8, mACC = 72.4 (Table 4, [PAGE 5]) to AUC = 54.6, Pre = 54.8, nPre = 59.3, cAUC = 53.9, mACC = 55.1. This is a relative AUC drop of (71.3 − 54.6)/71.3 ≈ 23.4%. Verifiability: re-run VL-SAM2 with T5 encoder on UW-COT220; the score table must reproduce the T5 row within experimental variance. The causal mechanism is loss of vision–language feature-space alignment; T5 is not contrastively aligned with the visual encoder over image–text pairs [PAGE 5].

Veto Scenario 2 — MATP removal (do(MATP = ∅)). Verifiable prediction: removing the Kalman-based MATP module from SAM2+LB+MATP reduces AUC from 71.3 to 68.2, Pre from 75.2 to 71.0, nPre from 78.2 to 73.8, cAUC from 70.8 to 67.8, mACC from 72.4 to 69.3 (Figure 4 ablation values, [PAGE 5]). The AUC delta is −3.1 points. Verifiability: run SAM2+LB without MATP on UW-COT220 and confirm the intermediate ablation bar. The counterfactual isolates the drift-correction value of MATP against similar distractors [PAGE 3].

Veto Scenario 3 — Center-point prompt veto (do(prompt_type = random_point) on SAM2-B). Verifiable prediction: switching the initial SAM2 prompt from the center point to a random point inside the target box drops AUC from 55.0 to 40.5 and Pre from 56.0 to 40.4 (Table 2, [PAGE 4]); nPre falls 62.2 → 45.8, cAUC 54.2 → 39.5, mACC 55.4 → 40.2. Relative AUC drop ≈ 26.4%. Verifiability: execute SAM2-B with randomly sampled point prompts on UW-COT220 and reproduce the “Random point” row. This validates that prompt quality is a first-order bottleneck, not a secondary tuning detail [PAGE 4].

All three scenarios are falsifiable with public code and the UW-COT220 dataset; each veto targets a distinct layer (language interface, temporal motion prior, visual prompt initialization), and each predicts a measurable, non-toy change in unitless AUC/Pre/nPre/cAUC/mACC without recourse to betting lines or ad-hoc ratios.
