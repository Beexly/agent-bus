The source’s core inferential chain is: a football match is encoded as a directed, weighted passing matrix \(P=(p_{ij})\) over \(n=11\) players; loops are excluded; the matrix is reduced to the 16-class directed triad census \(\mathbf T=(T_1,\ldots,T_{16})\); the observed \(\mathbf T\) is compared first with a conditionally uniform random digraph benchmark, U|MAN, and second with reference triadic profiles via a Dirichlet-Multinomial one-sample test. The paper states the first link explicitly: “A passing network G is defined as the ordered triple ... consisting of a set of 11 first team players” [PAGE 127], and “values on the main diagonal in Table 1 are constrained to be null since we assume that a player cannot pass the ball to himself. Thus the so-called “loops” are not allowed in this framework” [PAGE 127]. The triad reduction is justified because “the minimal group is represented by a triad, involving a subset composed by three agents” [PAGE 127], and because “when k = 2,3 the number of isomorphism classes is 3 and 16, respectively” [PAGE 128]. With \(n=11\), the triad-count vector has a hard sum constraint: “the total number of triads for each team (n = 11 players) in each match was constrained” [PAGE 132], i.e. \(\sum_\eta T_\eta=\binom{11}{3}=165\).

The first test is an omnibus departure test. Under U|MAN, the vector \(\mathbf T\) is approximately multivariate normal for increasing \(n\), with mean vector \(\boldsymbol\mu\) and covariance matrix \(\Sigma\) derived from Holland–Leinhardt results. The paper then forms standardized departures \(\tau_\eta\) and the quadratic statistic \(\tau^2_{\max}\). The key asymptotic claim is: “Holland and Leinhardt (1978) prove that, given a random reference distribution and if the vector T is approximately Normal, τmax2 asymptotically follows a χ2 distribution with degrees of freedom equal to the rank of Σ” [PAGE 129]. That rank is not automatically 16. In this football dataset the paper reports “a mode of 13 for the ranking of the triad census matrix among all networks” [PAGE 139], so the null reference is a rank-deficient chi-square, and the pseudo-inverse is material rather than cosmetic.

The second test is the paper’s methodological move. Instead of only asking “is this non-random?”, it asks whether a team-match or a team’s six-match aggregate is consistent with a triadic reference profile. The source builds four \(k\)-means centroids after correspondence analysis and uses them as null profiles \(T_1,\ldots,T_4\). The empirical summary is: “the OSDM tests help to identify almost three different strategies according to the triadic distribution” [PAGE 141]. \(T_3\) is tied to “highly tactical and technical teams, able to reach around 70 % of two types of more connected triads (“300” and “210”)” [PAGE 141]; \(T_1\) is described as “prerogative of Dutch and French teams, presenting greater balance between types “210” and “201”” [PAGE 141]; \(T_2\) is “mainly composed of teams from Eastern Europe, sharing the types of triad “120” characterized by asymmetric links” [PAGE 141]. These are empirical labels, not pre-registered causal categories.

Third, the OSDM reference profiles are derived from the same data by CA and \(k\)-means, so the test is partly a consistency test with a post hoc partition, not a fully external validation. The adjacency matrix is \(P=(p_{ij})\), with \(p_{ii}=0\). Units: \(p_{ij}\) is a dimensionless event count; \(T_\eta\) is a dimensionless triad count; probabilities and test statistics are dimensionless. The dyad total is \(\binom{11}{2}=55\), and the triad total is
\[
N_3=\binom{n}{3}=\binom{11}{3}=165.
\]
The triad census vector is
\[
\mathbf T=(T_1,\ldots,T_{16}),\qquad \sum_{\eta=1}^{16}T_\eta=165.
\]
The paper’s U|MAN reference fixes the numbers of mutual, asymmetric, and null arcs, \(M,A,N\), with \(M+A+N=\binom{n}{2}=55\). Under U|MAN, the first two moments are written schematically as
\[
\mu_\eta=\mathbb E[T_\eta]=\binom{n}{3}p(\eta),
\]
\[
\Sigma_{\eta\nu}=\operatorname{Cov}(T_\eta,T_\nu),
\]
where \(p(\eta)\), \(p_0(\eta,\nu)\), and \(p_2(\eta,\nu)\) are the Holland–Leinhardt probabilities tabulated in the source’s Appendix A [PAGE 141]. The standardized class departure is
\[
\tau_\eta=\frac{T_\eta-\mu_\eta}{\sqrt{\Sigma_{\eta\eta}}},
\]
and the omnibus statistic is
\[
\tau^2_{\max}
=
(\mathbf T-\boldsymbol\mu)^\top
\Sigma^{+}
(\mathbf T-\boldsymbol\mu),
\]
where \(\Sigma^{+}\) is the Moore–Penrose pseudo-inverse. Under the null, \(\tau^2_{\max}\sim\chi^2_{\operatorname{rank}(\Sigma)}\), with \(\operatorname{rank}(\Sigma)\le 16\); the source reports an empirical modal rank of 13 [PAGE 139]. The singularity/breakdown regime is explicit: because \(\Sigma\) is rank-deficient, the degrees of freedom are not 16, and the pseudo-inverse must discard null eigenvalues. In finite \(n=11\) samples, the asymptotic chi-square approximation can be conservative, which the paper acknowledges in its discussion of finite-sample behavior [PAGE 139].

For the strategy test, the source uses the Dirichlet-Multinomial family. With \(m=16\), \(\mathbf X\sim \mathrm{DM}_m(\boldsymbol\pi,\theta)\), \(0\le\pi_i\le1\), \(\sum_i\pi_i=1\), and overdispersion \(\theta\ge0\), the second parameterization is \(\alpha_0=(1-\theta)/\theta\) and \(\alpha_i=\pi_i(1-\theta)/\theta\). The density is
\[
f(\mathbf x\mid\boldsymbol\pi,\theta)
=
\frac{x_0!}{\prod_{i=1}^{m}x_i!}
\frac{\Gamma(\alpha_0)}{\Gamma(x_0+\alpha_0)}
\prod_{i=1}^{m}
\frac{\Gamma(x_i+\alpha_i)}{\Gamma(\alpha_i)},
\]
with \(x_0=\sum_i x_i\). The positivity condition \(\alpha_i>0\) means the displayed parameterization requires \(0\le\theta<1\); the source states \(\theta\ge0\), so the boundary \(\theta=1\) is a breakdown/parameter-constraint zone. As \(\theta\to0\), the model approaches the multinomial case. The one-sample DM hypotheses are
\[
H_0:\boldsymbol\pi=\boldsymbol\pi_0
\quad\text{versus}\quad
H_1:\boldsymbol\pi\ne\boldsymbol\pi_0.
\]
The source describes the statistic as a quadratic-form goodness-of-fit statistic using the Moore–Penrose inverse; its null reference is
\[
X_{\mathrm{obs}}\sim\chi^2_{\operatorname{rank}\left(\left(\operatorname{diag}(\boldsymbol\pi_0)-\boldsymbol\pi_0\boldsymbol\pi_0^\top\right)^{+}\right)},
\]
as stated in the text: “The test statistic Xobs asymptotically converges to a χ2 distribution with degrees of freedom equal to the rank of the matrix (diag(π0) − π0π0^T)+” [PAGE 130]. The aggregation property permits collapsing rare classes:
\[
(x_1,\ldots,x_m)\sim \mathrm{DM}_m(\pi_1,\ldots,\pi_m,\theta)
\]
implies
\[
\left(x_1,\ldots,x_s,x_0-\sum_{i=s+1}^{m}x_i\right)
\sim
\mathrm{DM}_{s+1}\left(\pi_1,\ldots,\pi_s,1-\sum_{i=s+1}^{m}\pi_i,\theta\right),
\]
as given in the source’s discussion of “collapse” [PAGE 130]. Breakdown regimes: structural zeros in rare triads such as “003” and “030C”; small \(g=6\) team-level samples; small \(n=11\); multiple testing with \(p=\alpha/G\) [PAGE 139]; post hoc \(k\)-means centroids; and the unweighted binary reduction that ignores pass counts. <RECURSIVE_THEORY_OF_MIND>
The recursive decision layer can be stated without inventing toy ratios. At each match state \(s_t=(\text{score state},\text{time},\text{opponent shape},\text{player availability})\), the team selects a passing policy \(\pi(a\mid s_t)\). The observed triad vector \(\mathbf T_t\) is a projection of that policy and its execution. The coach models the opponent’s likely pressure; the opponent models the coach’s likely build-up; teammates model each other’s runs. When those nested models agree, the triadic profile should be relatively stable. When they disagree, the observed profile shifts.

Three failure modes matter. First, crisis habit regression: under late-match pressure or a deficit, a team may regress to its lowest-entropy triadic habit—either extreme connectivity (“300”/“210”) or sparse isolation (“012”/“102”). This is consistent with the source’s contrast between \(T_3\), “highly tactical and technical teams, able to reach around 70 % of two types of more connected triads (“300” and “210”)” [PAGE 141], and \(T_4\), which has lower “300” and higher low-link triads [PAGE 136, Table 5]. The source does not prove crisis regression, but the triadic vocabulary makes it testable: compare a team’s first-half and last-20-minute triad vectors against its own match-level DM profile. Second, counter-trap: the opponent deliberately occupies passing lanes, forcing asymmetric “120” structures and reducing “300”/“210.” The paper’s \(T_2\) profile is defined by “types of triad “120” characterized by asymmetric links” [PAGE 141], which is exactly the kind of signature an opponent-induced trapping scheme could produce. Third, clock effects: time remaining changes risk tolerance and tempo, so the passing graph’s density and reciprocity can change even without a tactical change. The source does not model clock explicitly; it aggregates six matches and tests against U|MAN or a centroid, so clock is an unmodeled confounder.

The recursive-theory-of-mind verdict is therefore conditional. If a team’s triadic profile is stable across opponents and match states, a style interpretation is defensible. If the profile flips when the opponent changes pressure height or when the clock enters a late-game regime, the profile is better interpreted as a state-dependent response rather than a fixed habit. The paper’s own language supports this caution: “sometimes the football teams were unable to pursue a given strategy” [PAGE 140]. That sentence is a theory-of-mind statement: the intended policy and the executed policy diverged because the opponent’s policy intervened.

The passing network definition is purely relational: players as vertices, passes as weighted arcs, loops excluded [PAGE 127]. Therefore a formal cross-layer veto is not identifiable in this source. Define the veto predicate as
\[
V_t=
\mathbf 1\left\{
\exists Z_t\in\mathcal Z_{\text{phys/bio/weather}}:
\Pr\left(\mathbf T_t\mid H_{\text{style}},Z_t\right)
\text{ is incompatible with }H_{\text{style}}
\right\},
\]
where \(Z_t\) is a physical/biomechanical/weather covariate vector. Because \(Z_t\) is absent, \(V_t\) cannot be computed; “no veto observed” is not “no veto possible.” The correct adjudication is “unresolved cross-layer veto.”

There are concrete reasons the veto is plausible. Pass execution depends on surface, weather, fatigue, and player biomechanics; those factors change the binary adjacency matrix and therefore the triad counts. A wet pitch or a fatigued pressing unit can convert “300”/“210” triads into “120”/“201” or sparse “012” triads. The source’s own future-work statement that “passes may have different features according to their length, their position on the pitch” [PAGE 141] is an admission that the current network is a coarse projection. A weighted or spatial triad model that conditions on pass length, location, and pressure could therefore veto a style label that is really a physical-execution artifact. Until such covariates are included, the only defensible claim is conditional on the binary passing graph and the U|MAN/DM testing design.
