<RETROCAUSAL_GENEALOGY>

Lineage. The paper sits on the Finite Set Statistics program (Mahler) descending through the PHD/CPHD filters into the labeled-RFS GLMB (Vo–Vo conjugate priors, [51]) and its multi-sensor extension MS-GLMB (Vo–Vo–Beard 2019, [52]). Its immediate parent is MV-GLMB with occlusion handling (Ong–Vo–Vo–Kim–Nordholm 2020, [17]), which the authors explicitly improve upon: [17]'s occlusion model "does not address partial occlusions," "the re-identification functionality was neglected," and track initiation "requires a combination of accurate prior birth models ... with clustering" [PAGE 3]. The adaptive-birth operator is imported from Trezza–Bucci–Varshney 2022 ([54]), with a deliberate modification: they replace the injection $\theta_B$ with a multi-view association map $\mathring\gamma$ because "$\theta_B$ relaxes this constraint and allows each single-camera detection to originate from multiple objects, which can result in increased false track initiations, especially for scenarios with large areas" [PAGE 7]. A parallel lineage runs through 2D feature tracking (SORT [4], DeepSORT [38], FairMOT [9]) supplying the appearance channel.

Multi-frame trap. The recurring engineering trap in this family is *hypothesis accretion over a temporal window*: batch methods carry growing per-step cost, and even online GLMB truncates an exponentially growing component set each cycle. The design pressure is to keep per-step complexity independent of history ("computational complexities per time step that are independent of time" [PAGE 3]). The subtle, repeatedly-hit trap is that the two operations that restore functionality — occlusion-aware $P_D$ and adaptive birth — each *regrow* the very term count that truncation had suppressed, so the efficiency gains are constantly at risk of being clawed back. The paper manages this by using features to sharpen association (fewer survivors) and by clustering to make birth cheap (Alg. 1, mean-shift on ground-plane projections).

<RECURSIVE_THEORY_OF_MIND>

Model the environment as an adversary over observation quality. "Crisis" = a mass simultaneous-loss event (the paper manufactures one: "turning off all cameras mid-scene for 30 frames" [PAGE 9]). Under crisis, existence probabilities collapse and truncation fires. "Habit regression" = the filter's default failure mode of permanent deletion; the paper names it precisely: "component truncation deletes labels with prolonged low existence probabilities permanently from the GLMB density. This means they cannot be recovered even when new data support their reappearance" [PAGE 8]. "Counter-trap" = the TT-track reservoir plus feature relabeling, which anticipates reappearance rather than waiting for evidence that truncation has already discarded. "Clock" = two timers: the prescribed TT deletion period, and the survival ratio $(k-s)/e(\ell)$ that lets longer-lived labels win re-ID contests.

Second-order modeling of the detector. The measurement model reasons about the detector as an agent: clutter is Poisson with intensity $\kappa^{(c)}$ (set to 5 per sensor, "can be estimated on-the-fly ... if a higher number of false positive measurements is observed" [PAGE 8]); miss-detection is folded into $P_D$. The recursive move is that the birth model is estimated *from the current measurement* (Eqs. 15–17), i.e., the filter infers "what new objects must exist to explain unassociated detections" using $ \bar r_{U(j^{(1:C)})}=\prod_c\big(1-\sum_{I,\xi}\mathbf 1_{\xi^{(c)}(I)(j^{(c)})}\omega^{(I,\xi)}\big)$ [PAGE 7, Eq. 16] — the probability a detection is orphaned by all existing tracks. This is a one-step game against the scene's own clutter.

<CROSS_LAYER_VETO_ADJUDICATION>

Physical/model-consistency vetoes that override tracker tuning:

1. Constant-velocity breakdown. The near-CV transition assumes bounded acceleration encoded by $Q$. A person *falling* violates this; the paper acknowledges the regime by swapping extent variance ("$\upsilon_e^{(c)}=[0.0025,0.00995]^\top$ for fallen objects" [PAGE 8]) — an admission that a single dynamic model cannot span upright and fallen poses. Veto proof: when true acceleration spectral density exceeds $\upsilon(\zeta)$, the innovation $z-\hat z$ becomes non-Gaussian, the Gaussian $\psi$ under-weights the true association, and truncation deletes the correct track.

2. Ground-plane/homography assumption. Remark 3 infers front/back ordering by "compare the lower bottom corners of the bounding boxes ... those with lower bottom corners are closer to the camera" [PAGE 7], valid only under "all objects are on the same ground level" [PAGE 7]. Off-level terrain (stairs, a fallen vs standing target) breaks $Fr^{(c)}$, mis-computing $O^{(c)}$ and hence $P_D$.

3. Feature-stationarity veto (the dominant empirical one). Re-ID presumes "slow variations in the visual appearance" [PAGE 1]. When features are non-unique or unstable, re-ID fails: "Recall is poor when the objects have similar appearance ... (CMC3), or change their appearance quickly ... (CMC5)" [PAGE 9]; "CMC5 where re-identification fails because the features are not stable" [PAGE 12]. This is a hard veto, not a tuning issue — confirmed by CMC5 IDF1 collapsing to 39.1 even with all cameras restored [PAGE 10, Tab. 4].

4. Calibration veto. $\Phi^{(c)}(x)$ is "computed analytically via the projection matrix" [PAGE 4]; reconfiguration "only the camera matrices ... need to be updated" [PAGE 1]. Miscalibrated matrices bias both the box likelihood and $Fr^{(c)}$, and there is no in-filter correction.
