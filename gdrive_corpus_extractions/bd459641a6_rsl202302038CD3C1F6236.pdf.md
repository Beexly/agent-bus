It also states that SVR tries “to fit the error inside a predetermined threshold” and approximates the best value “within a predetermined margin known as the "-tube."” [PAGE 4]. The missing epsilon symbol before “-tube” is a typographical omission, but the method is recognizable as epsilon-insensitive SVR. The paper selects an RBF kernel: “This work concentrated on use of RBF kernel function.” [PAGE 5]. It gives the kernel as “𝑓(𝑥, 𝑥𝑗) = exp⁡(−г ∗‖𝑥−𝑥𝑗‖^2       ----------------------------------------------------------- (1)” [PAGE 5]. The symbol “г” is presumably gamma, and the equation is dimensionally incomplete because gamma’s units and feature scaling are not stated in the equation itself. The paper does say: “Feature scaling helps to normalize this variation in the data which helps the outcome.” [PAGE 5]. That implies features were scaled, but no scaling range, gamma value, C value, epsilon value, or train/test split is reported. This is a major reproducibility gray zone.

The third hop is metric interpretation. The paper reports “R2 0.8780, MSE 0.0028, MSE 0.0530 for football and R2 0.8189, MSE 0.0021, RMSE 0.0464 for hockey using SVM algorithm.” [PAGE 1]. The abstract repeats MSE for football where the table later gives RMSE. Table 3 resolves the intended values: “Football R2 0.8780  MSE 0.0028  RMSE 0.0530” and “Hockey R2 0.8189  MSE 0.0021  RMSE 0.0464” [PAGE 10]. The internal consistency is mostly acceptable: sqrt(0.0028)=0.0529, close to 0.0530; sqrt(0.0021)=0.0458, close to 0.0464 after rounding. However, the paper claims: “The R2 score ranges from 0% to 100%.” [PAGE 9]. That is not universally true; out-of-sample R-squared can be negative when residual variance exceeds target variance. This matters because a high in-sample R-squared can coexist with poor forward prediction.

The gray-zone audit therefore turns on validation design. The paper reports data sources “fbref.com” and “hockey-reference.com” [PAGE 3], 498 Premier League players from 2020 to 2021 [PAGE 3], NHL regular-season data, and six hockey seasons from 2016-17 to 2021-22 [PAGE 4]. It does not report the number of training rows, test rows, cross-validation folds, season-blocked splits, hyperparameter search, uncertainty intervals, or baseline models. It also does not explain whether player-level rows were aggregated to team-level targets, despite describing 498 players [PAGE 3] and team-level outcomes such as points percentage [PAGE 6]. This is a classic leakage risk: if same-season goals, points, or standings-derived features are used to predict same-season goals or points, the model may be describing the season after the fact rather than forecasting it. The paper’s conclusion says: “Our research focused on eliminating the restrictions by adding more features and getting a more accurate and realistic outcome.” [PAGE 11]. Adding features without temporal blocking can increase apparent accuracy while increasing leakage. The multi-hop conclusion is that the reported R-squared values are not sufficient evidence of deployable predictive skill.

<SOURCE_OPERATORS_AND_EQUATIONS>
Formal SVR operator, with units and assumptions. Let the training set be \(\{(\mathbf{x}_i,y_i)\}_{i=1}^{n}\), where \(\mathbf{x}_i \in \mathbb{R}^{d}\) is the scaled feature vector and \(y_i \in \mathbb{R}\) is the continuous target. For football, the displayed target is “Per_Gls Goals per Game” [PAGE 6], so \(y_i\) has units of goals per game, i.e. \(\mathrm{G}\cdot\mathrm{game}^{-1}\). For hockey, the displayed target is “PTS% Points Percentage” [PAGE 6], so \(y_i\) is a dimensionless fraction if expressed as proportion, or percent if expressed as percent. The source does not fix whether PTS% is 0–1 or 0–100, which affects the numerical scale of MSE.

The epsilon-insensitive SVR primal problem is
\[
\min_{\mathbf{w},b,\xi_i,\xi_i^{*}}
\frac{1}{2}\|\mathbf{w}\|^2
+C\sum_{i=1}^{n}(\xi_i+\xi_i^{*})
\]
subject to
\[
y_i-\mathbf{w}^{T}\phi(\mathbf{x}_i)-b \le \epsilon+\xi_i,
\]
\[
\mathbf{w}^{T}\phi(\mathbf{x}_i)+b-y_i \le \epsilon+\xi_i^{*},
\]
\[
\xi_i \ge 0,\quad \xi_i^{*} \ge 0.
\]
Here \(C\) has units that make the objective commensurate; in practice \(C\) is a regularization parameter with no physical unit after scaling. The tube half-width \(\epsilon\) has the same units as \(y_i\): goals per game for football, dimensionless or percent for hockey. The source describes this as a “predetermined threshold” and a “predetermined margin known as the "-tube"” [PAGE 4], but it does not report \(\epsilon\), \(C\), or the kernel parameter.

The RBF kernel in the source is quoted verbatim as “𝑓(𝑥, 𝑥𝑗) = exp⁡(−г ∗‖𝑥−𝑥𝑗‖^2       ----------------------------------------------------------- (1)” [PAGE 5]. Corrected notation is
\[
K(\mathbf{x},\mathbf{x}')=\exp\left(-\gamma\|\mathbf{x}-\mathbf{x}'\|_2^2\right),
\]
where the exponent must be dimensionless. If \(\mathbf{x}\) is scaled and dimensionless, then \(\gamma\) is dimensionless in the implemented model. If \(\mathbf{x}\) retains physical units, then \(\gamma\) has units of inverse squared feature units. The source does not specify the scaling, so the unit status of \(\gamma\) is unresolved. The SVR prediction is
\[
\hat{y}(\mathbf{x})=\sum_{i=1}^{n}(\alpha_i-\alpha_i^{*})K(\mathbf{x}_i,\mathbf{x})+b.
\]

The reported metrics are
\[
\mathrm{MSE}=\frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2,
\]
\[
\mathrm{RMSE}=\sqrt{\mathrm{MSE}},
\]
\[
R^2=1-\frac{\sum_{i=1}^{n}(\hat{y}_i-y_i)^2}{\sum_{i=1}^{n}(y_i-\bar{y})^2}.
\]
MSE has squared target units. For football, MSE has units \((\mathrm{G}\cdot\mathrm{game}^{-1})^2\); RMSE has units \(\mathrm{G}\cdot\mathrm{game}^{-1}\). For hockey, if PTS% is a fraction, MSE and RMSE are dimensionless; if PTS% is percent, they are in percent-squared and percent respectively. Therefore the football and hockey MSE values in Table 3 are not directly comparable: “Football R2 0.8780  MSE 0.0028  RMSE 0.0530” and “Hockey R2 0.8189  MSE 0.0021  RMSE 0.0464” [PAGE 10]. The paper also states: “The average of the squares of the errors is called mean square error (MSE).” [PAGE 9]. That definition is correct, but the paper’s claim that “The R2 score ranges from 0% to 100%” [PAGE 9] is only true for some in-sample settings; it is false for general out-of-sample evaluation.

Assumptions required by this operator: independent and identically distributed rows; stationarity of the feature-target relationship across train and test; correct feature scaling; a positive-semidefinite kernel; no target leakage; and a validation split that respects the sports calendar. Breakdown and singularity regimes are exact: if \(\gamma \to 0\), then \(K(\mathbf{x},\mathbf{x}') \to 1\) for all pairs, the kernel matrix approaches rank one, and the model collapses toward a constant predictor; if \(\gamma \to \infty\), then \(K(\mathbf{x},\mathbf{x}') \to 0\) for distinct points and \(K(\mathbf{x},\mathbf{x})=1\), producing extreme local overfitting and numerical underflow. Duplicate feature rows create linearly dependent kernel columns and non-unique dual coefficients unless regularization or a solver convention resolves them. If \(C \to \infty\), the model becomes maximally sensitive to residuals and can overfit; if \(\epsilon\) is too large, all residuals fall inside the tube and the model predicts an approximately constant bias. If \(y_i\) is constant, the \(R^2\) denominator is zero and \(R^2\) is undefined. If a test point lies far outside the training support, the RBF kernel tends to zero and the prediction tends toward the bias term, not toward a calibrated uncertainty statement.
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
The scientific lineage is clear: SVM is a kernel-based statistical-learning method, and SVR is its regression form with an epsilon-insensitive loss. The paper’s own lineage is visible in its reference list and related-work section. It cites Bunker and Thabtah’s machine-learning framework for sport result prediction [PAGE 11], McCabe and Trevathan’s neural-network sports prediction with “a median accuracy of 62.6%” [PAGE 2], Sushant and Rana’s comparison of classifiers with “a mean accuracy of 56.67%” [PAGE 3], Bosch and Bhulai’s NFL comparison where “machine learning techniques achieved a mean accuracy of 62.95%, and deep learning techniques had a mean accuracy of 63.36%” [PAGE 3], Singla’s standardization result where “the typical accuracy obtained before standardization was 55.8%; however, after standardization, the accuracy leaped down to 54.7%” [PAGE 3], and Vistro’s cricket work with “a median accuracy of 89.95%” [PAGE 3]. The paper therefore descends from a sports-analytics tradition that mixes classification accuracy, regression error, and feature ranking. Its novelty claim is not a new operator; it is the application of RBF-SVR to football and hockey data with many engineered performance features.

The retrocausal trap is that many of the strongest features are genealogically downstream of the outcome. In hockey, the feature list includes “SRS Simple Rating System,” “GF/G Goals for per game,” “GA/G Goals against per game,” and “PTS% Points Percentage” [PAGE 6]. SRS, goals for, goals against, and points percentage are all constructed from season results. If the target is PTS% and the predictors include same-season SRS, GF/G, and GA/G, then the model is partly reconstructing a known season table rather than forecasting a future season. The source does not state that features were lagged to prior seasons. In football, the feature list includes “xG Expected Goals,” “npxG Non-Penalty Expected Goals,” “G/Sh Goals per shot,” “G/SoT Goals per shot on target,” and “Per_Gls Goals per Game” [PAGE 6]. Several are direct transformations of scoring or shot outcomes. Without a clear temporal cutoff, high R-squared can be a post-hoc fit.

Multi-week traps follow from the sports clock. A season is not an i.i.d. sample: rosters change, injuries accumulate, travel and rest patterns vary, managerial changes alter tactics, and rule enforcement can shift. The football data are from “2020-to 2021” [PAGE 3], a period with unusual scheduling disruption; the hockey data span “2016-17 to 2021-22” [PAGE 4]. Pooling those seasons without season-blocked validation mixes different regimes. If hyperparameters are tuned on a random split, information from future seasons can leak backward into the model. If the model is tuned on the full season and then evaluated on a random holdout from the same season, it can memorize team identity and season-specific strength. The paper reports only final metrics in Table 3 [PAGE 10] and does not report the split, so the genealogy of the reported numbers cannot be audited.

<RECURSIVE_THEORY_OF_MIND>
The recursive theory-of-mind layer has three agents. The first is the model builder in “crisis habit regression”: under a short paper deadline, the habitual move is to choose a familiar kernel method, add many features, scale them, fit RBF-SVR, and report R-squared, MSE, and RMSE. The paper’s objective list reflects this habit: it wants “freedom to choose and work on their favorite sport with any formation of their choice” [PAGE 2]. That is a user-facing convenience claim, not a validation claim. The second agent is the user or evaluator, who may reason: “The authors report R2 0.8780 and R2 0.8189 [PAGE 10], so the model understands football and hockey.” The counter-trap is to ask what the model would have known before the match or before the season ended. A high R-squared on same-season aggregates does not answer that question. The third agent is the deployment clock: the sports calendar fixes the information set. A prediction must be made with only pre-cutoff data, and the evaluation must move forward in time.

The recursive failure is that each agent assumes the other has handled the clock. The author assumes the reader understands the split; the reader assumes the reported metrics are out-of-sample; the evaluator assumes the features are lagged; the deployment user assumes the model’s confidence is meaningful. The source does not resolve these assumptions. It says “Feature scaling helps to normalize this variation in the data which helps the outcome” [PAGE 5], but scaling does not fix temporal leakage. It says “Our research focused on eliminating the restrictions by adding more features and getting a more accurate and realistic outcome” [PAGE 11], but adding features can increase leakage if the features are same-season outcomes. The counter-trap is therefore an ablation-and-clock protocol: first remove target-proximal features, then evaluate only on future seasons, then compare against a simple baseline. The clock is not a cosmetic detail; it is the difference between a retrospective description and a prospective predictor.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The physical, biomechanical, and weather layer can veto the model because those variables are absent from the reported feature tables. The football table lists performance and rate statistics such as xG, xA, shot percentages, passes received, pressures, and tackles [PAGE 5][PAGE 6]. The hockey table lists team-performance statistics such as SRS, SOS, GF/G, GA/G, power-play percentage, save percentage, Corsi, Fenwick, expected goals, and high-danger chance percentages [PAGE 6]. Neither table contains player injury status, minutes load, sprint distance, acceleration counts, travel time, rest days, altitude, temperature, wind, precipitation, pitch or ice quality, or referee assignment. The data sources are “fbref.com” and “hockey-reference.com” [PAGE 3], which are performance-statistics sources, not biomechanical or weather sources.

Formal veto proof. Let the target be
\[
Y=m(X,Z)+\varepsilon,
\]
where \(X\) is the observed feature vector used by SVR and \(Z\) is the omitted physical, biomechanical, or weather context. The SVR estimate approximates
\[
\hat{m}(x)=\mathbb{E}[Y\mid X=x]=\mathbb{E}[m(x,Z)\mid X=x].
\]
For a specific context \(z\), the bias is
\[
b(x,z)=\mathbb{E}[m(x,Z)\mid X=x]-m(x,z).
\]
If \(Z\) has a nonzero effect on performance and is not independent of \(X\), then \(b(x,z)\neq 0\) in general. Even if \(Z\) is independent of \(X\), extreme \(z\) produces a nonzero conditional bias unless \(z=\mathbb{E}[Z\mid X=x]\). Therefore a model trained only on \(X\) cannot be adjudicated as physically valid for extreme \(Z\). A simple linearized version makes the point exact: if \(m(X,Z)=f(X)+\beta Z\), then
\[
\hat{m}(x)=f(x)+\beta\mathbb{E}[Z\mid X=x],
\]
so the prediction error for context \(z\) is \(\beta(\mathbb{E}[Z\mid X=x]-z)\). When \(z\) is far from its training conditional mean, the error is large.

Adjudication rule: if a match or player observation lies outside the training support in injury load, rest days, travel, or weather, the model output should be flagged or suppressed rather than treated as a valid point prediction. The source gives no such flag and no uncertainty interval. This is a cross-layer veto because no amount of kernel tuning inside \(X\) can recover the missing \(Z\) effect.
</CROSS_LAYER_VETO_ADJUDICATION>

Scenario 1: Temporal-split veto. Counterfactual: retrain the same RBF-SVR pipeline with a season-blocked forward split, training only on seasons before the test season and testing on the held-out future season. Verifiable prediction: the reported football \(R^2\) of 0.8780 and hockey \(R^2\) of 0.8189 [PAGE 10] will fall materially; a reasonable veto threshold is future-season \(R^2 < 0.60\) or test MSE at least 50% larger than the random-split MSE. If the future-season score remains near the reported value, the temporal-leakage veto is not supported. If it collapses, the original claim of realistic prediction is vetoed.

Scenario 2: Target-proximal feature ablation. Counterfactual: remove features that are direct or near-direct transforms of the target. For hockey, remove SRS, GF/G, GA/G, and any points-derived feature while predicting PTS% [PAGE 6]. For football, remove G/Sh, G/SoT, xG, npxG, and Per_Gls-adjacent scoring features while predicting goals per game [PAGE 6]. Verifiable prediction: if the high \(R^2\) is genuine and not target leakage, a lagged or non-scoring feature set should retain nontrivial skill, for example \(R^2 \ge 0.50\). If the ablated model falls below \(R^2=0.30\), the original result is vetoed as largely reconstructive rather than predictive. This test is directly verifiable by re-running the ablation and comparing Table 3 metrics.

Scenario 3: Context-augmentation veto. Counterfactual: add rest days, travel distance or time-zone shift, injury availability, and weather or venue variables to the feature set, then evaluate on extreme-context rows. Verifiable prediction: if physical and weather context matters, the augmented model should reduce RMSE by at least 10% on the extreme-context subset and reduce residual autocorrelation across matchweeks. If the RMSE reduction is below 5% and residuals show no context dependence, the physical/weather veto is not supported. If extreme-context residuals are more than 1.5 times the baseline residual standard deviation, the unaugmented model is vetoed for those rows. These three counterfactuals are verifiable because each specifies a retraining rule, a metric, and a decision threshold.
