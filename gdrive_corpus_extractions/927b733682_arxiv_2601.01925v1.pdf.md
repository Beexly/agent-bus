The source is not a sports or wagering document; it is an arXiv-style computer-vision paper on AR-MOT, an autoregressive multi-object tracking system. The central multi-hop derivation is: (i) MOT is reformulated as next-token prediction over a structured sequence; (ii) a detector supplies region-level object tokens to compensate for low-resolution global image tokens; (iii) a Region-Aware Alignment module projects bounding boxes into the image-token grid to fuse local and global features; (iv) a Temporal Memory Fusion module compresses history into a recurring token state; and (v) inference uses either a sliding window or TMF plus a Temporal Context Manager, with a pruning threshold \(\tau_{\mathrm{loss}}\). The paper states the paradigm directly: “we propose AR-MOT, a novel autoregressive paradigm that formulates MOT as a sequence generation task within a large language model (LLM) framework” [PAGE 1]. The autoregressive factorization is given on [PAGE 3]: “P(x1, x2, · · · , xn) = \n n\nY\n t=1\n P(xt|x1, x2, · · · , xt−1)”. The MOT-specific objective is on [PAGE 4]: “maximize\n Ni\nX\n j=1\n logP(sIDj\n i |spastj\n i )”, with the conditioning sequence defined by “spastj\n i = Concat({sFt}i−1\n t=i−T , sIi, {sEn\n i , sIDn\n i }j−1\n n=0, sEj\n i )” [PAGE 4]. The training loss on [PAGE 6] is “L = λclsLcls + λl1Ll1 + λgiouLgiou + λceLce”. Thus, the derivation from Eq. 1 to Eq. 4 is a change of random variable: the generic token sequence \(x_{1:n}\) becomes a frame-conditioned token sequence consisting of image tokens, object tokens, and ID tokens; the joint likelihood is factorized left-to-right; and the model maximizes the conditional log-likelihood of the next object ID given all previous frame and object context.

The gray-zone audit concerns where the derivation stops being valid. First, Eq. 1 has a singularity if any conditional probability is zero: the product is zero and the log-likelihood is \(-\infty\). Second, Eq. 4 is undefined for an object that the detector does not represent, because the conditioning sequence in Eq. 5 contains the object token \(s^{E_j}_i\); if the detector returns no query for object \(j\), there is no \(s^{E_j}_i\) to condition on. Third, the RAA module averages image tokens inside a projected bounding box; if the box has zero area or covers no patch in the image-token grid, the average is an empty sum and is undefined. Fourth, the TCM pruning rule states: “A trajectory is considered expired and removed from the reference set when nloss > τloss” [PAGE 6]; after expiry, the model has no stored token for re-identification, so it can only predict the special token “<new>” and rely on manual ID assignment. Fifth, manual assignment after “<new>” is not a learned one-to-one constraint; if two new objects receive the same ID, identity ambiguity is introduced outside the likelihood. Sixth, the paper’s own comparison shows detector dependence: “the overall tracking performance of the model is highly dependent on the quality of the detection results” [PAGE 9]. The strongest empirical gray-zone evidence is the ablation: vanilla MLLM HOTA 19.32, DetA 29.89, MOTA 11.82, AssA 12.77, IDF1 22.36, versus “W/ DETR” HOTA 31.88, DetA 69.06, MOTA 75.41, AssA 14.94, IDF1 26.56 [PAGE 7]. The paper also reports “With this addition, the model’s DetA score improved by 131 %, and AssA increased by 17 %” [PAGE 7]. The audit therefore treats object tokens as a necessary condition for the claimed behavior, not a cosmetic add-on.

A second gray zone is temporal memory. The paper says “When τloss = 1, the model retains no historical information, leading to lower AssA scores” [PAGE 8]. Table V on [PAGE 8] shows τloss = 1 with HOTA 33.53, DetA 65.90, MOTA 70.84, AssA 17.36, IDF1 28.03, while τloss = 10 gives HOTA 42.18, DetA 70.61, MOTA 77.62, AssA 25.51, IDF1 37.62. This is a multi-hop causal chain: longer retention \(\rightarrow\) more history in the reference set \(\rightarrow\) fewer premature identity removals \(\rightarrow\) higher association. But the gray zone is that longer retention can also inject stale tokens; τloss = 15 gives HOTA 42.39 and AssA 25.88 but DetA 70.39, slightly below τloss = 10’s DetA 70.61 [PAGE 8]. So the memory benefit is not monotone in every metric. The audit rejects any claim that “more history is always better” and instead asserts a bounded temporal-context regime.

A third gray zone is the MLLM backbone. Table VI on [PAGE 9] reports Transformer Decoder HOTA 15.17, DetA 44.28, MOTA 13.08, AssA 5.24, IDF1 12.36, versus Qwen2-0.5B HOTA 31.88, DetA 69.06, MOTA 75.41, AssA 14.94, IDF1 26.56. The paper’s interpretation is that the pretrained LLM supplies scene-level understanding and can interpret positional prompts; the shallow decoder cannot. The audit accepts this as a backbone-level causal claim but notes that the LLM is still conditioned on detector tokens, so the result does not prove that LLM reasoning alone solves MOT. Finally, the MOT17 limitation is explicitly physical: “The slightly lower performance compared with state-of-the-art methods is mainly due to the large number of extremely small objects in MOT17, which are challenging for the visual encoder of the MLLM” [PAGE 9]. This is the cross-layer veto: if the object is too small at the image-token resolution, neither the LLM nor memory can reconstruct the missing spatial evidence.
</THINK_TRACE>

<SOURCE_OPERATORS_AND_EQUATIONS>
The formal operators in AR-MOT are best expressed as sequence operators, not as invented ratios. The generic autoregressive operator is
\[
P(x_1,\dots,x_n)=\prod_{t=1}^{n}P(x_t\mid x_1,\dots,x_{t-1}),
\]
quoted on [PAGE 3] as “P(x1, x2, · · · , xn) = \n n\nY\n t=1\n P(xt|x1, x2, · · · , xt−1)”. Here \(x_t\) is a discrete token index; \(P(\cdot)\in[0,1]\) is dimensionless probability. If \(\log\) is natural, \(\log P\) has units of nats; if base-2, bits; the paper does not specify the base. The cross-entropy loss \(L_{\mathrm{ce}}=-\log P\) is therefore in nats or bits under the same convention. If any conditional probability is zero, the product is zero and \(\log P=-\infty\); this is the exact likelihood singularity.

The frame/object representation is
\[
S=\{F_i\}_{i=1}^{M},\qquad
F_i=\{I_i,\{\langle E_i^j,ID_i^j\rangle\}_{j=1}^{N_i}\},
\]
as stated on [PAGE 3]. Units: \(I_i\in\mathbb{R}^{H\times W\times C}\), where \(H,W,C\) are integer pixel height, width, and channel count; \(N_i\) is an integer object count; \(E_i^j\) is an embedding vector; \(ID_i^j\) is a discrete identity token. The image-token operator is
\[
s_i^I\in\mathbb{R}^{(HW/P^2)\times d_{LM}},
\]
where \(P\times P\) is the patch size and \(d_{LM}\) is the language-model hidden dimension [PAGE 3–4]. The object-token operator is
\[
E_i^j\in\mathbb{R}^{1\times d_{LM}},
\]
projected from the D-DETR query \(Q_i^j\in\mathbb{R}^{1\times d_D}\) through the object adapter [PAGE 4]. The MOT objective is
\[
\maximize \sum_{j=1}^{N_i}\log P(s_i^{ID_j}\mid s_i^{\mathrm{past}_j}),
\]
quoted on [PAGE 4] as “maximize\n Ni\nX\n j=1\n logP(sIDj\n i |spastj\n i )”, with
\[
s_i^{\mathrm{past}_j}
=\operatorname{Concat}\left(
\{s_{F_t}\}_{t=i-T}^{i-1},
s_i^I,
\{s_i^{E_n},s_i^{ID_n}\}_{n=0}^{j-1},
s_i^{E_j}
\right),
\]
matching the [PAGE 4] line “spastj\n i = Concat({sFt}i−1\n t=i−T , sIi, {sEn\n i , sIDn\n i }j−1\n n=0, sEj\n i )”. The loss operator is
\[
L=\lambda_{\mathrm{cls}}L_{\mathrm{cls}}
+\lambda_{l1}L_{l1}
+\lambda_{\mathrm{giou}}L_{\mathrm{giou}}
+\lambda_{\mathrm{ce}}L_{\mathrm{ce}},
\]
quoted on [PAGE 6] as “L = λclsLcls + λl1Ll1 + λgiouLgiou + λceLce”. The metrics MOTA, IDF1, HOTA, DetA, and AssA are dimensionless percentages or bounded scores; MOTA can be negative, while HOTA/DetA/AssA are commonly reported in \([0,100]\) percent units. The paper reports them without SI units [PAGE 6–9].

Assumptions: (A1) the detector returns an object query for each tracked object; (A2) the text vocabulary includes the special token “<new>” for unseen objects; (A3) the TCM stores the latest object token for each object and prunes when \(n_{\mathrm{loss}}>\tau_{\mathrm{loss}}\) [PAGE 6]; (A4) the TMF attention update uses current hidden states and previous history, with the previous memory as query/key and current embeddings as value [PAGE 5]; (A5) manual ID assignment occurs after “<new>” [PAGE 4]. Exact breakdown regimes: if \(P(x_t\mid x_{<t})=0\), the likelihood is singular at \(-\infty\); if the detector misses object \(j\), then \(E_i^j=\varnothing\) and Eq. 5 lacks \(s_i^{E_j}\), so the conditional ID probability for that object is undefined; if a projected bounding box covers no image patch, the RAA average over an empty patch set is undefined; if \(n_{\mathrm{loss}}>\tau_{\mathrm{loss}}\), the trajectory is removed from the reference set and reappearance cannot be assigned the old ID through the stored token; if two new objects receive the same manually assigned ID, the ID map is not injective; if \(\tau_{\mathrm{det}}\) is too high, valid objects are omitted, and if too low, false positives consume object/ID tokens; if bounding-box discretization is too coarse, spatial aliasing occurs. The paper’s Table III shows this granularity effect: \(\alpha=0.4\) gives HOTA 28.97 and MOTA 63.96, while \(\alpha=1.0\) gives HOTA 37.09 and MOTA 78.01 [PAGE 7]. These are empirical operators, not toy ratios.
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
The retrocausal genealogy of AR-MOT runs through three lineages. First, tracking-by-detection: SORT, DeepSORT, StrongSORT, OC-SORT, JDE, FairMOT, and ByteTrack supply the detection-plus-association tradition; the paper summarizes this as “a two-stage tracking paradigm that first detects objects in each frame and then associates them” [PAGE 2]. Second, tracking-by-query: TransTrack, TrackFormer, MOTR, CO-MOT, MOTRv2, MeMOT, MeMOTR, and SambaMOTR move association into transformer query updates; the paper describes track queries as encoding “spatial location and identity embedding” and being “iteratively updated over time” [PAGE 3]. Third, autoregressive vision: Pix2Seq, Pix2Seq-v2, OFA, Florence-2, Unified-IO, LLaVA, and LLaVA-OneVision recast vision outputs as token sequences. AR-MOT’s “retrocausal” move is to reinterpret the earlier association problem as a next-token problem: the ID token becomes the object of prediction, the detector query becomes an object token, and the temporal cache becomes a recurring memory token. The design then retroactively justifies older modules: RAA is a response to the global/local feature gap, and TMF is a response to the sliding-window cost and the irrelevance of distant frames [PAGE 2].

Multi-week traps are visible in the experimental protocol. The paper trains with “a random sampling interval for DanceTrack to range from 1 to 10”, initializes clip length at 2 frames and extends “to 3, 4, and 5 frames”, and performs “a separate round of domain-specific pretraining” for each dataset [PAGE 6]. A first trap is to treat DanceTrack validation gains as proof of MOT17 generalization: the paper itself reports AR-MOT MOT17 MOTA 66.1, IDF1 60.7, HOTA 50.1, and DanceTrack HOTA 48.1, MOTA 86.3, IDF1 43.9 [PAGE 9], so the two benchmarks exercise different failure modes. A second trap is to tune \(\tau_{\mathrm{loss}}\) on DanceTrack validation and then claim universal temporal memory: Table V shows HOTA rising from 33.53 at \(\tau_{\mathrm{loss}}=1\) to 42.39 at \(\tau_{\mathrm{loss}}=15\), but DetA is 70.61 at 10 and 70.39 at 15 [PAGE 8], so the optimum is metric-dependent. A third trap is detector dependence: the paper states that performance “is highly dependent on the quality of the detection results” [PAGE 9]. A fourth trap is the small-object regime: MOT17 contains “extremely small objects” that challenge the MLLM visual encoder [PAGE 9]. A fifth trap is training/inference mismatch: sliding-window inference without TMF uses past \(T\) frames, while TMF inference uses “only \(T_{i-1}\) and the current frame features” [PAGE 6]. Any multi-week evaluation that changes the history mechanism without matching the training sampler risks measuring the mismatch rather than the model. These traps are not speculative; they are implied by the paper’s own ablations and dataset descriptions.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
In AR-MOT, the recursive theory-of-mind layer is the model’s self-conditioning on its own previously generated ID tokens and on its stored memory of objects. Eq. 5 conditions each ID prediction on \(\{s_i^{E_n},s_i^{ID_n}\}_{n=0}^{j-1}\), so the model’s later decisions depend on earlier identity commitments. This creates three regimes. The crisis-habit regression regime occurs when the visual evidence is ambiguous: the model can regress to a local detector cue or to the “<new>” token rather than maintain a consistent identity. The paper’s vanilla MLLM result makes this concrete: without object tokens, HOTA is 19.32 and MOTA 11.82 [PAGE 7]; with D-DETR object tokens, HOTA is 31.88 and MOTA 75.41 [PAGE 7]. The counter-trap regime occurs when memory is over-extended: \(\tau_{\mathrm{loss}}\) from 1 to 15 raises HOTA from 33.53 to 42.39 and AssA from 17.36 to 25.88 [PAGE 8], but stale or noisy history can degrade detection, as DetA slips from 70.61 at \(\tau_{\mathrm{loss}}=10\) to 70.39 at 15 [PAGE 8]. The clock regime is the temporal horizon: \(T\) in the sliding window, the TMF recurrent state \(T_{i-1}\), and the pruning threshold \(\tau_{\mathrm{loss}}\). The paper explicitly notes that “frames that are temporally distant from the current frame may lose their reference value and even negatively impact tracking performance” [PAGE 2]. Therefore, the correct theory-of-mind for this tracker is not “remember everything”; it is “maintain a bounded, refreshed belief state about object identity.” The TCM and TMF are the mechanisms that make that belief state recursive, but they do not eliminate the clock constraint.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The cross-layer veto is a necessary-condition argument. Let the physical/visibility layer be \(V_{\mathrm{phys}}\), the detector layer \(V_{\mathrm{det}}\), the memory layer \(V_{\mathrm{mem}}\), and the LLM ID layer \(V_{\mathrm{LLM}}\). A valid ID association for object \(j\) at frame \(i\) requires at least a detector object token \(E_i^j\) and either current evidence or retained memory. If \(V_{\mathrm{det}}=0\), then \(E_i^j\) is absent; Eq. 5 has no \(s_i^{E_j}\), and the LLM cannot evaluate \(P(s_i^{ID_j}\mid s_i^{\mathrm{past}_j})\) for that object. This is a hard veto: the LLM cannot recover a token that the detector never produced. If \(V_{\mathrm{mem}}=0\) because \(n_{\mathrm{loss}}>\tau_{\mathrm{loss}}\), the trajectory is “removed from the reference set” [PAGE 6]; a reappearing object cannot be matched to the old ID through memory and must be treated as “<new>” unless another cue exists. If \(V_{\mathrm{phys}}=0\) due occlusion, the detector may still hallucinate or miss; the paper’s DanceTrack description names “frequent occlusions, crossings, deformations” and “highly similar visual appearances due to uniform costumes” [PAGE 6]. The biomechanical layer is therefore a veto on appearance-only association: uniform costumes and non-linear motion make local appearance ambiguous, which is exactly why TMF and \(\tau_{\mathrm{loss}}\) matter. The illumination/weather layer is also explicit: MOT17 includes “varying illumination conditions including daylight and nighttime” [PAGE 6]; low illumination can push detector confidence below \(\tau_{\mathrm{det}}\), vetoing object tokens before the LLM sees them. The small-object layer is another physical veto: “extremely small objects in MOT17” challenge the MLLM visual encoder [PAGE 9]. Thus the adjudication is layered: RAA can fuse region and global tokens, and TMF can extend temporal context, but neither can override a missing physical observation, a sub-threshold detection, or an expired memory entry. The proof is by undefined conditioning: without the object token or memory token, the likelihood in Eq. 4 has no valid argument. This is a structural veto, not a preference.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
Three verifiable counterfactual veto scenarios follow. Each is stated as a falsifiable test with a prediction tied to the paper’s reported metrics.

1. Object-token necessity veto. Counterfactual: remove the Object Tokenizer and retain only the MLLM image tokenizer, as in the “vanilla” row. If object tokens are not causally necessary, the vanilla model should approach the full model. The paper reports vanilla HOTA 19.32, DetA 29.89, MOTA 11.82, AssA 12.77, IDF1 22.36, versus “W/ DETR” HOTA 31.88, DetA 69.06, MOTA 75.41, AssA 14.94, IDF1 26.56 [PAGE 7]. Prediction: the veto holds; without object tokens, DetA and MOTA collapse, and the model cannot reliably localize or associate. Verifiable metric: the DetA gap 69.06 − 29.89 = 39.17 percentage points and the MOTA gap 75.41 − 11.82 = 63.59 percentage points under the paper’s DanceTrack validation protocol [PAGE 7]. If a replication shows no material gap, the object-token causal claim is vetoed.

2. Temporal-memory necessity veto. Counterfactual: set \(\tau_{\mathrm{loss}}=1\), which the paper says “retains no historical information” [PAGE 8], versus \(\tau_{\mathrm{loss}}=10\). If temporal memory is causally relevant, association should improve with retention. Table V reports \(\tau_{\mathrm{loss}}=1\): HOTA 33.53, DetA 65.90, MOTA 70.84, AssA 17.36, IDF1 28.03; \(\tau_{\mathrm{loss}}=10\): HOTA 42.18, DetA 70.61, MOTA 77.62, AssA 25.51, IDF1 37.62 [PAGE 8]. Prediction: the veto holds; the AssA gap 25.51 − 17.36 = 8.15 percentage points and the IDF1 gap 37.62 − 28.03 = 9.59 percentage points are attributable to retained history. Verifiable metric: if a controlled run with identical detector weights and identical clips shows no AssA/IDF1 increase, the memory causal claim is vetoed.

3. Pretrained-LLM backbone veto. Counterfactual: replace Qwen2-0.5B with a 6-layer Transformer causal decoder while keeping the same positional prompts. If the LLM is not essential, the shallow decoder should be competitive. Table VI reports Transformer Decoder HOTA 15.17, DetA 44.28, MOTA 13.08, AssA 5.24, IDF1 12.36, versus Qwen2-0.5B HOTA 31.88, DetA 69.06, MOTA 75.41, AssA 14.94, IDF1 26.56 [PAGE 9]. Prediction: the veto holds; the shallow decoder has enough positional information but lacks scene-level reasoning, so AssA and MOTA fall sharply. Verifiable metric: the MOTA gap 75.41 − 13.08 = 62.33 percentage points, which the paper itself cites as “+62.33” in the discussion [PAGE 9]. If a replication with the same object tokens and prompts closes that gap, the LLM-backbone claim is vetoed.

A fourth optional veto is the granularity claim: Table III shows \(\alpha=0.4\) HOTA 28.97/MOTA 63.96 versus \(\alpha=1.0\) HOTA 37.09/MOTA 78.01 [PAGE 7]. If finer bounding-box discretization did not improve both detection and association, the RAA/visual-prompt rationale would be vetoed. These counterfactuals are verifiable because each corresponds to an ablation row or threshold sweep reported in the source, and each prediction is a directional metric change rather than a subjective judgment.
</RLVR_COUNTERFACTUAL_VETOES>
