\]
where \(\Pi\) is the set of monotone warping paths. The predicted tactic is
\[
\hat y_q=y_{j^\star},\qquad j^\star=\arg\min_{j=1,\ldots,134}d_{\mathrm{FastDTW}}(S_q,S_j).
\]

<CROSS_LAYER_VETO_ADJUDICATION>
Cross-layer veto adjudication should treat the CV/action layer as the factual floor and the LLM narrative as a fallible explanation layer. The paper’s R1 principle supplies the normative rule: “The alignment between the video content and the provided explanations is essential” and explanations should be “directly tied to the observable tactics and actions in the video” [PAGE 3]. Therefore, for a factual claim \(c\) and detected action set \(A\), define the veto predicate
\[
V(c;A,\mathcal{P},\mathcal{B})=\mathbf{1}\left[c\not\models A\lor\exists\phi\in\mathcal{P}\cup\mathcal{B}:\phi\text{ is violated by }c\right],
\]
where \(V=1\) means suppress or flag the claim, \(\mathcal{P}\) is the physical constraint set, and \(\mathcal{B}\) is the biomechanical constraint set. Units: \(V\) is Boolean; \(A\) is categorical/positional; \(\mathcal{P}\) and \(\mathcal{B}\) are predicate sets.

Physical-layer vetoes include court bounds, ball continuity, and possession consistency. If the LLM says a pass occurred from player X to player Y, but \(o_t\) never changes within the same team, the PASS predicate fails [PAGE 4]. If the narrative places a screen at a court location where the offensive player is not near the defender, the SCREEN proximity condition is unsupported [PAGE 4]. If the ball trajectory implied by the narrative is discontinuous with tracked ball location, the physical layer should veto. This is directly consistent with the paper’s warning that mismatches “can lead to significant user confusion” [PAGE 3].

Biomechanical-layer vetoes include the CUT speed threshold and the SCREEN interaction requirement. The paper uses a concrete threshold: “a CUT is detected if an offensive players moves at a speed of 6 feet per second or faster to a different sub-region” [PAGE 4]. If the narrative claims a cut but \(v_i(t)\) is below \(6~\mathrm{ft\,s^{-1}}\) and no sub-region change occurs, the claim fails. For SCREEN, the narrative must be consistent with a marking or covering change [PAGE 4]; a proximity-only story is not enough. The paper does not report a numerical \(\epsilon_s\), so the system must treat that threshold as a calibrated parameter, not as a universal biomechanical constant.

Weather is the weakest layer in this source. The paper studies NBA games and multi-camera 3D tracking [PAGE 4][PAGE 6]; it does not model weather, wind, rain, or outdoor surface effects. For indoor basketball, weather vetoes are physically vacuous except as video-quality proxies: lighting, occlusion, and broadcast artifacts can degrade tracking, which the paper indirectly acknowledges when it says “The precision of 3D tracking data from single monocular videos is often insufficient” [PAGE 9]. If the system were ported outdoors, weather would become a real cross-layer covariate affecting ball flight and traction; that would require new sensors and new constraints, none of which are validated here.

Adjudication order: first, reject any claim contradicted by a high-confidence action predicate; second, flag any claim requiring data the source does not provide, especially defensive tactics [PAGE 9]; third, allow stylistic first-person content only when marked as narrative, not fact; fourth, if tracking confidence is low, abstain or ask the user to rephrase, which is the paper’s own fallback for hallucination [PAGE 9]. This is a proof by design consistency: if the system’s purpose is grounded explanation, then ungrounded factual claims violate its own R1 contract.
