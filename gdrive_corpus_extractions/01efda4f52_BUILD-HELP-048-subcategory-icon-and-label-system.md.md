<SOURCE_OPERATORS_AND_EQUATIONS>
Let X be the discrete random variable representing the true function of a navigation subcategory item, with alphabet size k. Let S be the composite signal emitted by the icon-label-help tuple S = (icon, label, summary, next_action, trust_note, media) [PAGE 1]. The comprehension task is to estimate X from S within a deadline.

Formal constraint (from source): P(T_c <= 10 s) >= 1 - epsilon [PAGE 1], where T_c is comprehension time and epsilon is a small failure probability.

Channel capacity: The mutual information required to identify one of k subcategories is I(X; S) >= log_2 k bits. The effective information rate is R = I(X; S) / E[T_c] bits/s. For k = 8 and E[T_c] = 8 s, R >= log_2(8)/8 = 0.375 bits/s.

Hick-Hyman choice-reaction time: E[T_c] = a + b log_2(n + 1) seconds, where n is the number of competing navigation items and a, b are empirically fitted constants (a in seconds, b in seconds per bit).

Fitts's law for mobile tap acquisition: MT = a + b log_2(1 + D/W) seconds, where D is distance to target and W is target width. For one-handed thumb use, W >= 48 dp (approximately 9 mm physical) to keep false-tap probability low.

Reduced-motion boundary: If animation frequency f > 3 Hz or peak angular acceleration alpha_peak exceeds the vestibular comfort threshold, the component must honor prefers-reduced-motion: reduce and substitute static media [PAGE 1].

Assumptions: the user reads the app language at functional literacy; corrected-to-normal vision; viewport width >= 320 CSS px; touch input with finger-pad diameter approximately 8-10 mm.

Breakdown regimes:
1. Icon-ambiguity singularity: when semantic entropy H(icon | context) > H_max, the icon alone cannot disambiguate X; the label must carry the full log_2 k bits. If the label is truncated by viewport width, comprehension fails.
2. Trust-boundary singularity: if copy implies a deterministic outcome for probabilistic content, this violates "No fake certainty" [PAGE 1] and triggers method-boundary rejection.
3. Motion singularity: autoplay video plus a reduced-motion preference equals a vestibular veto; shipment is blocked until media is paused or replaced.

<RETROCAUSAL_GENEALOGY>
The lineage traces from Shannon (1948) information theory, which defines the bits required to resolve uncertainty, to Hick (1952) and Hyman (1953), whose choice-reaction law models navigation time as logarithmic in item count. Fitts (1954) adds the biomechanical pointing constraint for touch targets. Xerox PARC (1970s) established icons as spatial signifiers, and Norman (1988) formalized affordances and signifiers: an icon without a clear signifier is not an affordance but a puzzle. Nielsen (1994) heuristics require visibility of system status and error prevention, which the trust-note and next-action slots implement [PAGE 1]. WCAG 2.1 supplies the reduced-motion and contrast constraints.

Multi-week traps: Week 1-2, ad-hoc icon expansion causes semantic drift as new subcategories are added without label validation. Week 3-4, localization truncation breaks 10-second comprehension in morphologically rich languages. Week 5-6, the media slot fills with auto-playing, non-trust-safe video, triggering motion complaints. Week 7+, the feature-flag rollback path is forgotten, converting a contained UI experiment into permanent technical debt.

<RECURSIVE_THEORY_OF_MIND>
Crisis habit regression: under time pressure or stress, users stop parsing novel icons and regress to memorized muscle memory from prior sessions. If the subcategory icon set changes during a crisis period, experienced users misfire because their internal model no longer matches the emitted signal S.

Counter-trap: when confusion is observed, the instinctive designer response is to add more icons, tooltips, and badges. This increases visual clutter and produces banner blindness; the "help affordance" [PAGE 1] becomes ignored noise rather than a signal.

Clock: the 10-second comprehension deadline [PAGE 1] is an external forcing function. As t approaches 10 s, the system should degrade gracefully: suppress decorative motion, prioritize the text label over the icon, and surface the next action explicitly so that even a user who has not decoded the icon can still act.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical layer: device viewport, pixel density, and outdoor glare. If text contrast falls below 4.5:1 under bright ambient light, the label is unreadable and the component is vetoed. Biomechanical layer: thumb reach and tap-target size. If W < 48 dp or the target lies outside the one-handed thumb zone, false taps rise and the component is vetoed unless an alternative interaction is provided. Weather/environmental layer: sunlight readability and motion in transit. A user riding in a vibrating vehicle with prefers-reduced-motion: reduce should not be subjected to autoplay parallax media; the vestibular load compounds with vehicle motion and triggers nausea.

Adjudication rule: a veto in any single layer blocks shipment. Rollback is executed by removing the isolated component or hiding it behind a feature flag, with no data or billing changes [PAGE 1]. Because the failure domain is confined to UI content, cross-layer vetoes do not require database migrations or billing rollbacks.
