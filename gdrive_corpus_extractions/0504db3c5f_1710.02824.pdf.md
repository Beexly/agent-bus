Weather layer: Expected weather is a model input [PAGE 6], but if realized weather diverges materially from expectation between the 5-hour pre-match scan and kickoff, the consensus probability becomes stale. The [-5,-1] hour window [PAGE 13] is specifically exposed to this because terms move as weather forecasts update.

Exact singularity: The betting inequality max(Ω) > 1/(p_cons − α) defines a non-empty feasible set only when some bookmaker deviates sufficiently from consensus [PAGE 8-9]. When all bookmakers align such that max(Ω) ≤ 1/(p_cons − α), no bet is placed—a soft veto by signal absence. A hard veto occurs at the execution layer when the bookmaker-imposed maximum stake falls below the fixed $50 unit [PAGE 16, PAGE 24 Fig. 4: William Hill ¥2,428.33 cap, Interwetten $11.11 cap, Sportingbet $1.25 cap, Betway $10.45 cap]. Under this hard veto, expected payoff is positive but unrealizable; the strategy's return collapses not because E[Π] ≤ 0, because feasible stake s_max → 0.
