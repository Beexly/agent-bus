<THINK_TRACE>
The paper’s derivation is best read as a four-hop construction: first, a single-label distribution-free set predictor is converted into a finite-sample calibrated threshold; second, the detector is decomposed into proposal, presence, and location components; third, component-level PAC guarantees are composed by union bounds into an end-to-end detector guarantee; fourth, the tracker adds an edge-level set over adjacent-frame detections and composes it with the detection set. The initial hop is stated in [PAGE 2]: “The goal of PAC prediction sets is to ﬁnd a predicﬁon set C : X →2Y that contains the true label with high probability, while minimizing the expected prediction set size.” The key object is not a point prediction but a set-valued map. The error is a probability of exclusion, not an average calibration score. The PAC requirement is stated as “given ϵ, δ ∈(0, 1), we want” the randomized calibration event to satisfy the error bound with high confidence [PAGE 2]. This distinction is crucial: the guarantee is over the draw of the calibration set, not over a single deterministic dataset. The gray zone begins here, because the theorem is valid only under the assumption that the calibration examples are i.i.d. from the same distribution as evaluation data. In detection, the paper extends this by replacing the scalar label with a composite label y=(b,c,e), where b is a bounding box, c is a class, and e is a presence flag [PAGE 3]. That extension is nontrivial because the components are not independent black boxes; the proposal set feeds presence and location, and the final detection set is a union over proposals, classes, presence values, and boxes.

The second gray zone is the composition mechanism. The paper does not assume that component errors multiply away. Instead, it proves additive error bounds using event decomposition. For example, Theorem 2 says that if the proposal set is correct and the presence set is correct using the true proposer, then the presence set remains correct when using the estimated proposer, with error bounded by the sum of the two errors [PAGE 4]. Theorem 3 repeats this structure for location [PAGE 4]. Theorem 4 then combines presence and location, yielding an additive composed guarantee [PAGE 4]. The proof style in the appendix is explicit: errors outside a corrected event are bounded by the probability of the bad event, and corrected events inherit the component guarantee [PAGE 11]. This is a union-bound style proof, but the paper’s careful framing matters: it separates “estimation error with the true proposer” from “error induced by replacing the true proposer with the estimated proposal set.” Without that separation, one could mistakenly treat the detector as a monolithic classifier and apply a single conformal threshold. That would be invalid because the detector’s internal components have distinct score semantics, distinct calibration sets, and distinct failure modes.

The third gray zone is the irreducible proposal error. The paper explicitly states that the object proposer only outputs a finite number of proposals, so even with threshold zero there can be misses [PAGE 5]. This is a singularity in the guarantee: if the true object is never proposed, no downstream threshold can recover it. The same logic applies to non-maximum suppression: if a proposal is suppressed, the implementation treats the presence score as zero, which is conservatively incorrect [PAGE 3]. These are not numerical bugs; they are structural breakdown regimes. The guarantee remains valid as a PAC statement about the realized pipeline, but the achievable error floor can exceed a desired ϵ if the desired ϵ is smaller than the irreducible miss probability. The experiments acknowledge this by choosing component budgets such as ϵprp=0.03, ϵprs=0.01, and ϵloc=0.06 for detection [PAGE 5]. The chosen budgets reflect the fact that proposal failure is not infinitely compressible.

The fourth gray zone is temporal. Tracking uses edge prediction sets over adjacent frames. The edge score is IoU-based, with a zero score if classes differ or either detection is absent [PAGE 4]. This is elegant but fragile under occlusion, abrupt motion, class switch, or frame-rate mismatch. The edge guarantee is still PAC, but only with respect to the edge distribution and the detection set distribution. The paper’s empirical metrics, false-negative rate and average false-positive, make the tradeoff explicit [PAGE 5][PAGE 6]. The recursive audit therefore must distinguish three layers: distributional validity, component composition validity, and physical-temporal plausibility. A model can satisfy the mathematical PAC conditions on a benchmark and still fail deployment if the deployment distribution differs from the calibration distribution. The paper’s own limitation section says the sets may be conservative and may include spurious edges under occlusion [PAGE 8]. That is the correct gray-zone admission: the guarantee controls false negatives only within the calibrated distribution, and the cost is potentially larger sets, not universal robustness.

1. Base PAC set predictor.  
The source defines the example space \(X\), label space \(Y\), and distribution \(D\) over \(X \times Y\) [PAGE 2]. The prediction set is \(C:X\to 2^Y\). The prediction-set error is  
\[
L_D(C) := P_{(x,y)\sim D}\left[y \notin C(x)\right].
\]
The PAC requirement is  
\[
P_{Z\sim D^n}\left[L_D(C)\le \epsilon\right]\ge 1-\delta,
\]
with \(\epsilon,\delta\in(0,1)\) [PAGE 2]. The one-dimensional thresholded family is  
\[
C_\tau(x)=\{y\in Y \mid f(x,y)\ge \tau\},
\]
where \(f:X\times Y\to \mathbb{R}_{\ge 0}\) is a score function [PAGE 2]. The calibration threshold is computed by  
\[
\hat{\tau}=\arg\max_{\tau\in\mathbb{R}_{\ge 0}} \tau
\quad \text{subject to} \quad
\sum_{(x,y)\in Z} \mathbf{1}\left(y\notin C_\tau(x)\right)\le k^*,
\]
with  
\[
k^*=\arg\max_{k\in \mathbb{N}\cup\{0\}} k
\quad \text{subject to} \quad
F(k;n,\epsilon)\le \delta,
\]
where \(F(k;n,\epsilon)\) is the Binomial\((n,\epsilon)\) cumulative distribution function:
\[
F(k;n,\epsilon)=\sum_{j=0}^{k}\binom{n}{j}\epsilon^j(1-\epsilon)^{n-j}.
\]
If the optimization is infeasible, the source states that the procedure “returns the trivial solution \(\hat{\tau} = 0\)” [PAGE 2]. This is a breakdown regime: zero threshold maximizes recall but can make the set large or uninformative.

2. Detection label space and components.  
For detection, \(x\in X\) is an image, \(b\in B\) is a bounding box, \(c\in K\) is a class, \(e\in\{0,1\}\) is a presence flag, and  
\[
y=(b,c,e)\in Y:=B\times K\times\{0,1\}
\]
[PAGE 3]. The paper assumes the two-stage detector generally assumes one instance per class per proposal, and it uses this assumption when designing prediction sets [PAGE 3]. It also assumes two boxes match if \(\mathrm{IoU}>0.25\) [PAGE 3].

Proposal component:  
\[
\hat{f}_{prp}:X\to (B\times \mathbb{R}_{\ge 0})^*
\]
outputs pairs \((r,s)\), where \(r\) is a proposed region and \(s\) is an objectness score [PAGE 3]. The proposal prediction set is  
\[
C_{\hat{\tau}_{prp}}(x)
=
\left\{
r\in B
\;\middle|\;
(r,s)\in \hat{f}_{prp}(x)
\ \wedge\
s\ge \hat{\tau}_{prp}
\right\}.
\]

Presence component:  
\[
\hat{f}_{prs}:X\times B\times K\to \mathbb{R}_{\ge 0}
\]
outputs the likelihood of the target class in a proposal [PAGE 3]. The presence set is  
\[
C_{\hat{\tau}_{prs}}(x,r,c)
=
\left\{
e\in\{0,1\}
\;\middle|\;
e\hat{f}_{prs}(x,r,c)
+
(1-e)(1-\hat{f}_{prs}(x,r,c))
\ge
\hat{\tau}_{prs}
\right\}.
\]
If the detector implementation suppresses a proposal score, the source says they “treat it as if \(\hat{f}_{prs}(x,r,c)\) outputs 0” [PAGE 3]. This creates a conservative miss regime.

Location component:  
\[
\hat{f}_{loc}:X\times B\times K\to P_B
\]
outputs a distribution over bounding boxes \(B\) [PAGE 3]. The location set is  
\[
C_{\hat{\tau}_{loc}}(x,r,c)
=
\left\{
b\in B
\;\middle|\;
\hat{f}_{loc}(b\mid x,r,c)
\ge
\hat{\tau}_{loc}
\right\}.
\]

Composed detection set:  
\[
\hat{C}_{det}(x)
:=
\bigcup_{
r\in C_{\hat{\tau}_{prp}}(x),\,
c\in K,\,
e\in C_{\hat{\tau}_{prs}}(x,r,c),\,
b\in C_{\hat{\tau}_{loc}}(x,r,c)
}
\{(c,e,b)\}.
\]
This matches the source definition of the detection prediction set as the union over proposal, presence, and location prediction sets [PAGE 3].

3. Component error operators.  
The proposal loss is  
\[
\ell^{01}_{prp}(C_{\hat{\tau}_{prp}},x,y)
:=
\mathbf{1}\left(b\notin C_{\hat{\tau}_{prp}}(x)\right),
\]
and the proposal error is  
\[
L_{Ddet}(C_{\hat{\tau}_{prp}})
:=
\mathbb{E}_{(x,y)}\left[\ell^{01}_{prp}(C_{\hat{\tau}_{prp}},x,y)\right]
\]
[PAGE 3]. If one ground-truth box can match multiple proposals with \(\mathrm{IoU}\ge 0.25\), the source says they “choose the \(r\) with the smallest score \(s\) when constructing the prediction set” [PAGE 3]. This is a conservative selection rule.

The presence error is defined as  
\[
L_{Ddet}(C_{\hat{\tau}_{prs}};C_{\hat{\tau}_{prp}})
:=
\mathbb{E}_{(x,y)}
\left[
\ell^{01}_{prs}
(C_{\hat{\tau}_{prs}},C_{\hat{\tau}_{prp}},x,y)
\right],
\]
where  
\[
\ell^{01}_{prs}(\cdot)
:=
\mathbf{1}
\left(
e\notin
\bigcup_{\hat{b}\in C_{\hat{\tau}_{prp}}(x),\,\hat{b}=b}
C_{\hat{\tau}_{prs}}(x,\hat{b},c)
\right)
\]
[PAGE 3]. The location error is analogously  
\[
L_{Ddet}(C_{\hat{\tau}_{loc}};C_{\hat{\tau}_{prp}})
:=
\mathbb{E}_{(x,y)}
\left[
\ell^{01}_{loc}
(C_{\hat{\tau}_{loc}},C_{\hat{\tau}_{prp}},x,y)
\right],
\]
with  
\[
\ell^{01}_{loc}(\cdot)
:=
\mathbf{1}
\left(
b\notin
\bigcup_{\hat{b}\in C_{\hat{\tau}_{prp}}(x),\,\hat{b}=b}
C_{\hat{\tau}_{loc}}(x,\hat{b},c)
\right)
\]
[PAGE 4].

4. Compositional detection guarantees.  
Theorem 2 states: “If \(C_{\hat{\tau}_{prp}}\) is \((\epsilon_{prp},\delta_{prp})\)-correct, and estimating \(C_{\hat{\tau}_{prs}}\) with \(C^*_{prp}\) is \((\epsilon_{prs},\delta_{prs})\)-correct, then estimating the \(C_{\hat{\tau}_{prs}}\) based on \(C_{\hat{\tau}_{prp}}\) is \((\epsilon_{prp}+\epsilon_{prs},\delta_{prp}+\delta_{prs})\)-correct” [PAGE 4]. Theorem 3 gives the analogous result for location [PAGE 4]. Theorem 4 then states that if the presence set is \((\epsilon'_{prs},\delta'_{prs})\)-correct and the location set is \((\epsilon'_{loc},\delta'_{loc})\)-correct, then the composed detection set is  
\[
(\epsilon'_{prs}+\epsilon'_{loc},\ \delta'_{prs}+\delta'_{loc})
\]
-correct [PAGE 4]. In the experiment, the paper sets \(\epsilon_{det}=0.2\), \(\delta_{det}=10^{-5}\), \(\epsilon_{prp}=0.03\), \(\epsilon_{prs}=0.01\), \(\epsilon_{loc}=0.06\), and \(\delta_{prp}=\delta_{prs}=\delta_{loc}=1/3\times 10^{-5}\) [PAGE 5]. The additive budget is therefore not decorative; it determines feasibility.

5. Tracking edge operator.  
For adjacent frames \(x_t\) and \(x_{t+1}\), with detections \(y_t\) and \(y_{t+1}\), the edge score is  
\[
\hat{f}_{edge}(\cdot)
:=
\begin{cases}
\mathrm{IoU}(b_t,b_{t+1}) & \text{if } c_t=c_{t+1}\ \wedge\ e_t=e_{t+1}=1,\\
0 & \text{otherwise,}
\end{cases}
\]
[PAGE 4]. The edge prediction set is  
\[
C_{\hat{\tau}_{edge}}(x_t,x_{t+1})
:=
\left\{
(y_t,y_{t+1})
\in
\hat{C}_{det}(x_t)\times \hat{C}_{det}(x_{t+1})
\;\middle|\;
\hat{f}_{edge}(x_t,x_{t+1},y_t,y_{t+1})
\ge
\hat{\tau}_{edge}
\right\}.
\]
The edge error is  
\[
L_{Dedge}(C_{\hat{\tau}_{edge}};\hat{C}_{det})
:=
\mathbb{E}_{x_t,x_{t+1},y_t,y_{t+1}}
\left[
\mathbf{1}
\left(
(y_t,y_{t+1})
\notin
C_{\hat{\tau}_{edge}}(x_t,x_{t+1})
\right)
\right]
\]
[PAGE 5]. Theorem 5 states that if \(\hat{C}_{det}\) is \((\epsilon_{det},\delta_{det})\)-correct and the edge set based on the true detection set \(C^*_{det}\) is \((\epsilon_{edge},\delta_{edge})\)-correct, then using the estimated detection set gives  
\[
(\epsilon_{det}+\epsilon_{edge},\ \delta_{det}+\delta_{edge})
\]
-correctness [PAGE 5]. The empirical false-negative rate is  
\[
\mathrm{FNR}
=
\frac{1}{|Z_{eval}|}
\sum_{(x,x',y,y')\in Z_{eval}}
\ell^{01}_{edge}(\cdot),
\]
[PAGE 5], and average false-positive is  
\[
\mathrm{AFP}
=
\frac{1}{|Z_{eval}|}
\sum_{(x,x',y,y')\in Z_{eval}}
\left[
|C_{\hat{\tau}_{edge}}(x,x')|
-
\mathbf{1}\left((y,y')\in C_{\hat{\tau}_{edge}}(x,x')\right)
\right]
\]
[PAGE 6].

Breakdown regimes.  
First, calibration breakdown: if \(Z\) is not i.i.d. from \(D\), the Binomial bound no longer controls \(L_D(C)\). Second, proposal singularity: if the finite proposal set misses the true object, then \(L_D\) has a positive floor even when \(\hat{\tau}_{prp}=0\) [PAGE 5]. Third, suppression singularity: non-maximum suppression can force missing component scores to zero [PAGE 3]. Fourth, matching singularity: the \(\mathrm{IoU}>0.25\) convention changes what counts as success; near-threshold boxes can flip labels discontinuously [PAGE 3]. Fifth, temporal singularity: if class changes, presence changes, or IoU becomes zero, the edge score becomes zero and the true transition may be excluded unless \(\hat{\tau}_{edge}=0\) [PAGE 4]. Sixth, budget singularity: if the desired \(\epsilon\) is below the irreducible component miss probability, no finite calibration set can satisfy the desired guarantee without increasing set size or changing the detector.
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
The lineage begins with PAC learning, cited by the paper as Valiant’s “A theory of the learnable” [PAGE 10]. The immediate statistical ancestor is calibrated prediction and PAC confidence sets, especially the work by Park et al. that provides PAC confidence sets for deep neural networks via calibrated prediction [PAGE 9]. The detection lineage runs through Faster R-CNN and two-stage detectors: the paper says it builds on Faster R-CNN because “the component-wise design makes it easier to incorporate prediction sets” [PAGE 2]. The tracking lineage runs through Tracktor and detection-based multi-object tracking, where objects are first detected and then associated across frames [PAGE 2]. The paper uses Tracktor’s object detection and object connection components, and it adds edge prediction sets on top of them [PAGE 1].

The multi-week traps are not merely historical; they are repeated engineering failure modes. One trap is calibration leakage: if calibration frames, sequences, or camera conditions overlap with evaluation, empirical error can look better than the distribution-level guarantee. A second trap is temporal leakage in tracking: if calibration and test halves contain correlated occlusions, motion blur, or camera motion, the edge threshold can be tuned to a non-representative temporal regime. A third trap is component mismatch: applying one global threshold to detector scores ignores that proposal objectness, class presence, and box regression have different score distributions and different calibration sets. The paper avoids this by calibrating proposal, presence, and location separately and composing them [PAGE 3][PAGE 4]. A fourth trap is treating IoU as sufficient for association. IoU is a simple edge score, but it collapses under occlusion, fast motion, class change, or detection disappearance [PAGE 4]. A fifth trap is assuming that larger sets are harmless. The paper’s limitation section explicitly warns that sets may be conservative and may include false detections or spurious trajectories [PAGE 8]. The genealogy therefore is: PAC theory gives distribution-level confidence; calibrated prediction gives finite-sample thresholds; component decomposition gives modularity; composition theorems give additive safety budgets; and tracking extends the same logic from boxes to transitions.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
The crisis-mode regression is this: under latency pressure, a detector or tracker tends to collapse uncertainty into a single high-score box, because downstream planners often expect one object, one track, one decision. The paper’s method counters that habit by making uncertainty explicit as a set. The recursive belief structure is: the perception system believes the true object is contained in \(C(x)\); the tracker believes the true transition is contained in \(C_{edge}(x_t,x_{t+1})\); the safety layer believes the false-negative rate is bounded; the planner believes it can act without missing a pedestrian. If any layer uses a point estimate instead of the set, the guarantee is broken. The paper’s detection experiments show that the composed detection set can include all person objects when the baseline detector misses one [PAGE 5]. The tracking experiments show that the edge set can retain the true track when Tracktor switches objects or loses the track [PAGE 7].

The counter-trap is over-conservatism. If the clock budget is \(T_{compute}\le 1/f\) seconds per frame, where \(f\) is frames per second, a large prediction set may increase downstream association or planning cost. The set can control false negatives but may introduce false positives, as the paper says: “controlling the false negative rate by allowing a few false positives is a worthwhile tradeoff to ensure safety” [PAGE 5]. Still, if false positives grow without bound, the system may stall, reject valid trajectories, or flood the planner with spurious edges. The recursive solution is not to abandon PAC sets but to improve the underlying score functions. The paper states this explicitly: “to improve our prediction sets, it sufﬁces to improve the underlying models used for detection and tracking” [PAGE 8].

The clock layer is also a belief layer. Online tracking uses adjacent frames; if the frame interval changes, the IoU prior changes. A track that overlaps at 30 Hz may not overlap at 5 Hz for the same physical velocity. Formally, if an object of characteristic box length \(L\) meters moves at speed \(v\) meters per second, the inter-frame displacement is approximately \(v\Delta t\) meters, where \(\Delta t\) is seconds per frame. If \(v\Delta t\) is comparable to or larger than \(L\), IoU can collapse. This is not a betting heuristic; it is a geometric temporal constraint. The recursive theory of mind therefore says: the tracker must model not only object appearance but also its own temporal uncertainty. The safest belief is set-valued, but the useful belief is set-valued with sharp scores, calibrated components, and honest failure floors.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The cross-layer veto is decided by the source’s own distributional assumption. The PAC guarantee is conditioned on \(D\), the data-generating distribution [PAGE 2]. If the physical, biomechanical, or weather layer changes the image or motion distribution, the calibrated threshold is no longer guaranteed to control error at the desired \(\epsilon\). The paper’s limitation section concedes that sets may be conservative and that poor underlying models or occlusions can enlarge sets [PAGE 8]. Therefore, a physical veto is valid when the deployment regime is outside the calibration support.

Physical veto proof sketch. Let \(b_t\) and \(b_{t+1}\) be ground-truth boxes at adjacent frames. The edge score uses \(\mathrm{IoU}(b_t,b_{t+1})\) only when class and presence match [PAGE 4]. For a box of characteristic length \(L\) meters and object speed \(v\) meters per second, the inter-frame displacement is approximately  
\[
d \approx v\Delta t,
\]
where \(\Delta t\) is the frame interval in seconds. A necessary condition for positive IoU is, up to shape and orientation,  
\[
d < L.
\]
If \(v\Delta t \ge L\), the boxes may fail to overlap, so the edge score becomes zero. If the calibrated threshold \(\hat{\tau}_{edge}>0\), the true edge is excluded. This creates a deterministic physical miss regime. The paper’s own construction cannot veto this by score calibration alone, because the edge score itself is zero.

Biomechanical veto. Pedestrian motion can involve occlusion, limb articulation, pose change, and temporary disappearance behind objects. The paper’s tracking experiments acknowledge difficult sequences where Tracktor switches objects or loses the target [PAGE 7]. If a person is occluded for multiple frames, the detection presence flag may drop, or the box may shrink, causing \(\mathrm{IoU}=0\) or presence mismatch. Under the edge definition, this yields no valid edge unless the threshold collapses to zero. The PAC edge guarantee remains mathematically valid for the edge distribution, but it cannot guarantee that the physical trajectory remains continuously observed under occlusion.

Weather and illumination veto. Rain, fog, low light, glare, or snow can change the image distribution and degrade detector scores. The paper’s guarantee is not a weather-proof guarantee unless the calibration set contains the same weather, sensor, and exposure conditions. If the calibration distribution excludes night or rain, the PAC bound is not transferable. This is a cross-layer veto: the perception model may be mathematically calibrated on clear-day COCO-style images, but the physical deployment distribution has shifted. The correct adjudication is therefore conditional: the source’s PAC construction is internally valid for the calibrated detector and edge distribution, but it is vetoed as a safety guarantee when the cross-layer distribution changes outside the calibration support. The paper’s conservative-set warning is the formal admission of this limit [PAGE 8].
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
1. Counterfactual veto: calibration-distribution shift.  
Assumption: the calibration set \(Z\sim D_{cal}^n\) is used to compute \(\hat{\tau}\), but deployment uses \(D_{dep}\neq D_{cal}\). Let the total variation distance be  
\[
\mathrm{TV}(D_{cal},D_{dep})
=
\sup_A |P_{D_{cal}}(A)-P_{D_{dep}}(A)|.
\]
If \(\mathrm{TV}(D_{cal},D_{dep})\) is non-negligible, the Binomial calibration bound no longer controls \(L_{D_{dep}}(C)\). Verifiable test: hold out a deployment-matched set, compute empirical exclusion rate, and compare with \(\epsilon\). Prediction: if the deployment set contains night, rain, sensor change, or new object scale, the empirical detection or edge false-negative rate will exceed the nominal \(\epsilon\), even if calibration-set error is below \(\epsilon\). The paper’s guarantee is valid only under the same distribution, as implied by the PAC definition [PAGE 2].

2. Counterfactual veto: irreducible proposal miss.  
Assumption: the true object is not present in the finite proposal set. The paper states that the proposer “only outputs a finite number of proposals in practice, so it introduces irreducible prediction set error even with \(\tau_{prp}=0\)” [PAGE 5]. Let  
\[
p_{miss}
=
P_{(x,y)\sim D}
\left[
b\notin \bigcup_{r\in \hat{f}_{prp}(x)} \{r\}
\right].
\]
Then the proposal component satisfies  
\[
L_D(C_{\hat{\tau}_{prp}})\ge p_{miss}
\]
for every threshold, including \(\hat{\tau}_{prp}=0\). Verifiable test: compute ground-truth proposal coverage over calibration and test images. Prediction: if \(p_{miss}>\epsilon_{prp}\), the proposal component cannot meet its allocated budget; if \(p_{miss}\) consumes the total \(\epsilon_{det}\) budget, the composed detector guarantee becomes infeasible without changing the proposal network, increasing proposals, or relaxing the target error.

3. Counterfactual veto: temporal edge collapse.  
Assumption: the true transition exists but the IoU-based edge score is zero because of occlusion, class change, presence drop, or fast motion. The edge score is defined to be zero unless classes and presence flags match [PAGE 4]. Let  
\[
p_{edge-zero}
=
P\left[
\mathrm{IoU}(b_t,b_{t+1})=0
\ \vee\
c_t\neq c_{t+1}
\ \vee\
e_t=0
\ \vee\
e_{t+1}=0
\right].
\]
If \(\hat{\tau}_{edge}>0\), any true edge with score zero is excluded, so  
\[
L_{Dedge}(C_{\hat{\tau}_{edge}};\hat{C}_{det})
\ge
p_{edge-zero}.
\]
Verifiable test: annotate adjacent-frame gaps where the ground-truth object is occluded, class-labeled differently, or displaced beyond box overlap. Prediction: the false-negative rate will exceed \(\epsilon_{edge}+\epsilon_{det}\) on those subsequences unless the edge threshold is set to zero or the edge score is replaced by a motion-aware, re-identification-aware, or occlusion-aware score. The paper’s own experiment setup notes that better score functions reduce prediction set size, and that arbitrary edge scores are allowed [PAGE 4]. Therefore, the IoU-only construction is a valid baseline but not a universal veto-proof tracker under occlusion or fast motion.
</RLVR_COUNTERFACTUAL_VETOES>
