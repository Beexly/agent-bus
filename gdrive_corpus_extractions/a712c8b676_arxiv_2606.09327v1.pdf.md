D_out = K·d + d_con = 28·32 + 15 = 911 dimensions.
Units: dimensionless real-valued embedding vector in R^911.

Self-attention over feature embeddings. For feature embeddings E ∈ R^{K×d}, queries Q = E W_Q, keys K_mat = E W_K, values V = E W_V produce contextualized features [PAGE 5]:
Attn(Q,K_mat,V) = softmax( Q K_mat^T / √d_k ) V,
with d_k = d / h, h = 8 attention heads, L = 6 encoder layers [PAGE 5, Table 1]. Pairwise dependencies among categorical attributes (e.g., right-footed action × attacking third position) are modeled at the feature-column level rather than treating the event as an atomic token [PAGE 4].

Masked Language Modeling pretraining objective. Each categorical feature is independently masked with probability p_mask = 0.15 [PAGE 6]. The model reconstructs masked features from unmasked context within the same event. If p_mask → 0, the denoising regularization vanishes and the model degenerates to an identity lookup; if p_mask → 1, insufficient context remains for reconstruction and gradients collapse. Stable regime: p_mask ∈ (0.1, 0.3).

Downstream sequence handling for xG. Attacking sequences are truncated or zero-padded to fixed length T_max = 48 events, with a binary validity mask m_t ∈ {0,1} excluding padding from attention [PAGE 7]. Breakdown: any possession exceeding 48 events loses terminal context; sequences shorter than 48 introduce sparse mask gradients.

Probability calibration metrics. For predicted probability f_i ∈ [0,1] and binary outcome o_i ∈ {0,1} over N samples, Brier score and LogLoss are [PAGE 7–8]:
BS = (1/N) Σ_{i=1}^N (f_i − o_i)^2,
LL = −(1/N) Σ_{i=1}^N [ o_i log f_i + (1 − o_i) log(1 − f_i) ].
Units: probability-squared for Brier; nats for LogLoss. A well-calibrated model assigns f = 0.2 to shots that score 20% of the time [PAGE 8]. Reported xG results: TabTransformer Brier = 0.0923, LogLoss = 0.3173; MLP baseline Brier = 0.1010, LogLoss = 0.3283 [PAGE 8, Table 2].

VAEP formulation. Action value equals the change in scoring/conceding probability over the next k = 10 actions [PAGE 8]:
ΔVAEP = P(score within k | post-action state) − P(concede within k | post-action state) − [P(score within k | pre-action state) − P(concede within k | pre-action state)].
Evaluated with AUC and Brier [PAGE 8, Table 3].

sim(u,v) = (u · v) / (||u||_2 ||v||_2) ∈ [−1,1].

<CROSS_LAYER_VETO_ADJUDICATION>
Physical, biomechanical, and weather vetoes. The model consumes event data only: coordinates, timestamps, event types, body parts, outcomes [PAGE 3]. It explicitly excludes posterior features such as shot end coordinates to prevent leakage [PAGE 6], and the StatsBomb open data lacks player and opponent positioning at event time [PAGE 7]. Consequently, three hard veto layers apply.

Biomechanical veto: player fatigue, sprint velocity, acceleration, heart rate, and muscular load are absent from event data. An event embedding cannot distinguish a cross delivered by a fresh full-back in the 15th minute from the same cross by a fatigued full-back in the 89th minute. Biomechanical state is a latent confounder; any valuation of action quality that assumes constant physical capacity is vetoed under fatigue regimes.

Weather veto: no meteorological variables (precipitation, wind speed/direction, temperature, pitch humidity) are present in the source [PAGE 3, 6]. Wet conditions alter ball roll, pass success probability, and shot trajectory; a model trained on mixed-weather events without conditioning on weather cannot assign contextually correct action values during extreme weather. Forecasts under heavy rain or high wind lie outside the model’s observed support.

Physical/defensive veto: opponent positioning and pressing intensity are not encoded in the open event features [PAGE 7]. The paper admits that the proprietary StatsBomb xG benefits from “additional spatial features capturing player and opponent positioning” [PAGE 7, 8]. Without defender coordinates, the model cannot compute whether a passing lane is physically open or whether a shot is taken under defensive pressure. Geometric proxies (distance to goal, angle to goal [PAGE 6]) are necessary but insufficient: a shot from a favorable angle is physically vetoed if a defender is within interception range. Breakdown occurs when defender-to-attacker spacing falls below roughly two body widths (tight pressing), at which point geometric features dominate the embedding while physical constraint dominates the outcome.

Singularity: when continuous spatial coordinates are discretized into a 16 × 12 grid [PAGE 6], sub-zone positional nuance is lost. Events within the same zone but separated by several meters receive identical zone embeddings, creating a resolution singularity for actions whose value is highly sensitive to exact location (e.g., shots inside versus just outside the penalty area).
