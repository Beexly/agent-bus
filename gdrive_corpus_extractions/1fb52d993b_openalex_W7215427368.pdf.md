All symbols are stated with domain/units; breakdown regimes are the exact regimes in which each operator fails or is undefined in this pipeline.

1. Structural Similarity (Eq. 3.1, [PAGE 21]), verbatim:
$$\mathrm{SSIM}(x,y)=\frac{(2\mu_x\mu_y+c_1)(2\sigma_{xy}+c_2)}{(\mu_x^2+\mu_y^2+c_1)(\sigma_x^2+\sigma_y^2+c_2)}.$$
Units: dimensionless, range $[0,1]$ (higher = more similar). $\mu_\bullet,\sigma_\bullet$ are per-window mean and standard deviation; $\sigma_{xy}$ is window covariance; $c_1,c_2$ are stabilizing constants ($c_k=(K_kL)^2$ with $L$ the pixel dynamic range). Assumptions: local stationarity within the sliding window; luminance/contrast/structure factorize multiplicatively. Breakdown: it is a photometric/structural metric, not semantic — two images with identical structure but a displaced icon can score high, so SSIM certifies appearance similarity but only weakly certifies the label alignment that this pipeline actually requires. On the 256×256 raster with ~21×21 boxes ([PAGE 50]) window size strongly conditions the value, which is why the author argues IoU 0.5:0.95 is "not relevant on an image of size 256x256 pixels" ([PAGE 50]).

2. Fréchet Inception Distance (Eq. 3.2, [PAGE 25]), verbatim:
$$d^2\big((\mathbf{m},\mathbf{C}),(\mathbf{m}_w,\mathbf{C}_w)\big)=\lVert \mathbf{m}-\mathbf{m}_w\rVert_2^2+\mathrm{Tr}\!\big(\mathbf{C}+\mathbf{C}_w-2(\mathbf{C}\mathbf{C}_w)^{1/2}\big).$$
Units: squared distance in Inception feature space (dimensionless). Range $[0,\infty)$, lower better. Assumptions: both feature distributions are multivariate Gaussian with means $\mathbf{m},\mathbf{m}_w$ and covariances $\mathbf{C},\mathbf{C}_w$; the matrix square-root term requires $\mathbf{C}\mathbf{C}_w$ to have a well-defined principal square root. Breakdown: Gaussian assumption fails at the small evaluation set used here (250 images, [PAGE 25]), biasing $\mathbf{C}$; the $(\mathbf{C}\mathbf{C}_w)^{1/2}$ term is numerically unstable in high dimension; and FID is alignment-blind, which is exactly why it correlates only partially with detector accuracy.

3. Recall (Eq. 4.1, [PAGE 36]): $\mathrm{Recall}=\dfrac{\text{total true positives}}{\text{total ground-truth}}$. Dimensionless $[0,1]$. Breakdown: rewards over-detection — trivially maximized by flagging every candidate.

4. Precision (Eq. 4.2, [PAGE 37]): $\mathrm{Precision}=\dfrac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FP}}$. Dimensionless $[0,1]$. Breakdown: undefined when the model outputs nothing; maximized by abstention.

5. Average Precision (Eq. 4.3, [PAGE 39]): $\mathrm{AP}=\sum_{k=0}^{N-1}\big(\mathrm{Recall}(k)-\mathrm{Recall}(k+1)\big)\cdot \mathrm{Precision}(k)$, where "N is the number of IoU thresholds" per the author's notation (more precisely, recall sampling points). Weight is the recall increment, confirming the author's own statement that mAP "gives great weight to the recall" ([PAGE 48]).

6. Mean AP (Eq. 4.4, [PAGE 39]): $\mathrm{mAP}=\frac{1}{Q}\sum_{q=1}^{Q}\mathrm{AP}_q$, $Q$ = number of classes (here up to 162 champions). This is the class-averaged quantity reported as mAP@0.5, mAP@0.5:0.7, mAP@0.5:0.95.

7. F1 (Eq. 4.5, [PAGE 39]): $F_1=\dfrac{2\cdot \mathrm{Precision}\cdot \mathrm{Recall}}{\mathrm{Precision}+\mathrm{Recall}}$. Dimensionless; harmonic mean. Breakdown: undefined when $\mathrm{Precision}+\mathrm{Recall}=0$; and because it is a harmonic mean it penalizes precision–recall divergence, which is precisely the property the author exploits to argue F1 is "more meaningful" for their balance objective ([PAGE 48]).

The GSI ID-assignment heuristic (majority "object id ⇔ class ID" occurrence, [PAGE 47]) is proven to veto itself under high overlap: it "does a very good job on situations of easy to medium complexity ... but it remains risky in very complex situations (very strong overlapping of four or more champions icons)" ([PAGE 55]), producing the observed precision dip (0.997 → 0.962, Model B → D, [PAGE 55]).

Falsifier: if the "98%" cannot be reproduced at IoU 0.5 but only at looser effective IoU, the abstract's phrasing is confirmed as loose, not wrong.

Veto/Scenario 2 — SSIM-as-predictor. The author concedes only a "partial correlation" between GAN SSIM and detector mAP ([PAGE 34], [PAGE 52]). Counterfactual test: compute rank correlation (Spearman $\rho$) between per-checkpoint SSIM (Table 5.5) and downstream mAP across the 15 augmented runs (Tables 5.2–5.4). Prediction: $\rho>0$ but with a concrete counterexample already in the data — training B (SSIM 0.620) underperforms training A (SSIM 0.615) at 1000 images (mAP@0.5 0.832 vs 0.933, [PAGE 52]), i.e., SSIM monotonicity is violated. Falsifier: if $\rho \approx 1$ with no inversions, SSIM would be a sufficient checkpoint selector, contradicting the author's own hedge.

Veto/Scenario 3 — GSI high-overlap precision collapse. Construct adversarial clips with ≥4 champion icons co-located within a 1–2 tile area and run Model B vs Model D. Prediction: Model D recall exceeds Model B (interpolation recovers TP) but precision falls below B (majority-vote ID assignment mislabels interpolated boxes), reproducing the 0.997→0.962 precision drop ([PAGE 55]) and widening it as overlap count grows. Falsifier: if precision is preserved at ≥4-icon overlap, the stated limitation ([PAGE 60]: "ID assignment to detections interpolated by the GSI algorithm is a bit trivial") is overstated.

Net adjudication: the thesis's central, verifiable contribution is the label-alignment-preserving GAN augmentation (SSIM 0.37 → ~0.655 lifting detector mAP@0.5 from ~0.53 to ~0.98 at IoU 0.5), directly analogous to Sonoda & Kimoto's 80%→97% GPR result.
