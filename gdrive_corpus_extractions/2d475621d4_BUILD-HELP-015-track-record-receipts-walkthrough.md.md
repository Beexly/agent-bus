<SOURCE_OPERATORS_AND_EQUATIONS>
Define the comprehension-time random variable T_c [s] for a new user encountering the Track Record help component. Requirement from [PAGE 1]: "A new user understands the item in 10 seconds." Formal bound: sup(T_c) <= T_max = 10 s, or in probabilistic form P(T_c <= 10 s) >= 0.95 across the QA population.

The help component must convey a minimal information vector H = [H_identity, H_why, H_how, H_next], where each term is measured in bits. Total conveyed information H_total = sum_i H_i [bits]. Human reading and visual parsing impose an effective channel rate R [bits/s]. For 10-second comprehension, the required rate is R_req = H_total / T_c. If H_total = 48 bits (approximately six to eight short sentences plus one visual anchor) and T_c = 10 s, then R_req = 4.8 bits/s, well within the human textual channel (~40-60 bits/s for prose) but tight if the media slot includes uncaptioned video.

Accessibility operator: WCAG contrast ratio C_r = (L_1 + 0.05) / (L_2 + 0.05), where L_1 and L_2 are relative luminances of lighter and darker colors (dimensionless, normalized to [0,1]). Acceptance: C_r >= 4.5:1 for normal text; C_r >= 3:1 for large text. Breakdown regime: C_r < 4.5:1 triggers immediate visual QA veto.

Next-action acquisition operator: Fitts' law movement time MT [s] = a + b log_2(1 + D/W), where D is distance to the next-action target [px] and W is target width [px]. Breakdown: MT > 2 s or W < 44 px (minimum accessible touch target) fails mobile readability/help-affordance checks.

Reduced-motion operator: Let f_anim [Hz] be the dominant frequency of any motion in the media slot. If the user agent reports prefers-reduced-motion: reduce, then f_anim must be set to 0 (static fallback). Breakdown: f_anim > 0 under reduced-motion preference is a cross-layer veto.

Feature-flag rollback operator: R ~ Bernoulli(p_rollback), where p_rollback is near zero for an isolated component because [PAGE 1] specifies no data or billing changes. Breakdown: if the flag leaks beyond the component boundary, p_rollback approaches 1 due to entanglement.

<RECURSIVE_THEORY_OF_MIND>
Crisis habit regression: Under launch pressure, product and support teams tend to regress to one-off explanations—exactly the anti-pattern the internal-value clause rejects [PAGE 1]. The recursive model predicts that when the clock is short (T_c <= 10 s), teams either ship a minimal, correct help pattern or fall back to unmeasured manual text.

Counter-trap: Over-documentation is the inverse failure. Adding multiple videos, expandable tables, and lengthy summaries buries the next action and pushes T_c beyond 10 seconds. The counter-trap is that "more help" equals "better help," whereas the ticket demands the smallest help pattern [PAGE 1].

Clock: The 10-second bound acts as a recursive forcing function. Each QA iteration (visual screenshot, mobile readability, copy audit, reduced-motion, help coverage) re-evaluates the user model under the same temporal constraint. Recursion depth is bounded by the sprint; if T_c cannot be brought under 10 seconds after two remediation cycles, the component is hidden behind the feature flag per rollback [PAGE 1].

<CROSS_LAYER_VETO_ADJUDICATION>
Physical layer: The component must render across mobile viewports (e.g., 375 px width minimum) with dynamic type scaling. Touch targets for the help affordance and next action must satisfy W >= 44 px; otherwise Fitts' law MT exceeds acceptable thresholds and mobile readability fails.

Biomechanical layer: Users with motor impairment, tremor, or limited dexterity require large targets and generous hit areas. Users with vestibular disorders require the reduced-motion path: if f_anim > 0 under prefers-reduced-motion: reduce, the component is vetoed. Cognitive accessibility requires plain language; complex copy raises H_total and risks T_c > 10 s.

Environmental/weather layer: Ambient luminance L_ambient [cd/m^2] affects effective contrast. In glare or direct sunlight, screen-emitted luminance L_screen must overcome ambient reflection; if C_r falls below 4.5:1 under worst-case L_ambient, visual QA vetoes the component. Low-light modes require dark-theme contrast parity.

Veto proof: Any layer failure—physical target size, biomechanical motion/contrast, environmental readability—triggers the rollback plan: hide behind feature flag or remove the isolated entry [PAGE 1]. No data or billing changes means the veto is stateless and safe. The component ships only when all layers pass concurrently; a pass in one layer does not waive a fail in another.
</CROSS_LAYER_VETO_ADJUDICATION>
