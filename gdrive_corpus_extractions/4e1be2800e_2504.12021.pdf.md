The paper’s central derivation is a causal inversion of football video understanding. Classical action spotting is retrospective: a model sees a long untrimmed broadcast and localizes events that have already occurred. The source states this contrast directly: “Unlike action spotting, where models can access the entire video sequence to detect actions, action anticipation requires predicting future events without access to future frames” [PAGE 1]. That single sentence creates the entire probabilistic architecture of the task. The observable variable is a context video v_n of length T_c seconds. The latent target is a future action set A_n inside an unobserved anticipation window w_n of length T_a seconds. Therefore the learning problem is not merely classification or localization; it is conditional forecasting under partial observability.

The first multi-hop consequence is that the evaluation metric must separate two epistemic questions. The first question is whether the model knows that an action will occur. The second question is whether the model knows when it will occur. The paper formalizes this through mAP@δ. A prediction is correct if it falls “within a window of δ/2 seconds before or after the ground truth” [PAGE 3]. This creates a metric family: δ = 1, 2, 3, 4, 5 seconds measures increasingly precise temporal alignment, while δ = ∞ “completely disregards localization and focuses only on the correct identification and counting of action classes” [PAGE 3]. The gray zone is immediately visible: a model can be good at action occurrence but poor at temporal precision. The ablation on anticipation-window length confirms this: performance decreases as T_a increases, but “the only exception is mAP@∞, which remains stable throughout” [PAGE 7]. Thus the bottleneck is not merely recognizing that football actions are stochastic; the bottleneck is predicting their precise temporal coordinate inside a short future interval.

The second multi-hop derivation concerns dataset structure. SN-BAA is adapted from SoccerNet Ball Action Spotting, but the authors remove rare classes: “we exclude goals and free-kicks from the SN-BAA dataset, reducing the set to C = 10 classes” [PAGE 3]. The reason is explicitly metric instability: “a single correct or incorrect anticipation can cause large fluctuations in performance” [PAGE 3]. This is a crucial gray-zone decision. Removing rare classes improves metric robustness but also removes high-consequence events from the benchmark. The resulting dataset is therefore biased toward frequent on-ball actions. The supplementary statistics reinforce this: passes and drives dominate, while shots, successful tackles, ball player blocks, and other rare events have much lower support [PAGE 13]. The paper also reports “a total of 12433 actions across the entire dataset (i.e., one action every 3.30 seconds)” [PAGE 4], and within a T_a = 5 second window there are on average 1.5 actions with a maximum of 8 actions [PAGE 4]. This distribution shapes model design: query count, class weighting, and loss design must accommodate both dense short windows and long-tail sparsity.

The third derivation is architectural. FAANTRA adapts FUTR to football by using a RegNetY backbone, local temporal attention in the encoder, learnable decoder queries, and a prediction head with actionness, class, and timestamp outputs [PAGE 4–5]. The auxiliary segmentation task is not decorative; it supplies dense supervision inside the observed context. The paper states that segmentation “helps the model learn the semantics of different action classes, which improves predictions within the anticipation window” [PAGE 5]. Empirically, removing the auxiliary segmentation task causes a severe drop: average mAP falls from 20.30 to 7.13 in the reported ablation [PAGE 7]. This is a major finding: anticipation is not learned solely from sparse future labels; it requires dense reconstruction of what is happening before the future window.

The final gray-zone audit concerns the gap between anticipation and spotting. T-DEED, given access to the anticipation window, reaches much higher mAP values, for example 56.69 average at T_a = 5 with 400MF and joint training [PAGE 6]. FAANTRA’s best comparable anticipation result is 24.08 average [PAGE 6]. The paper explicitly says: “We observe a consistently large performance gap between FAANTRA and the upper bound” [PAGE 6]. This gap is the empirical proof that football action anticipation is not a solved detection problem. It is a problem of latent intention, sparse cues, temporal uncertainty, and adversarial concealment.

<SOURCE_OPERATORS_AND_EQUATIONS>
Let the dataset contain N observed trimmed videos:

\[
V = \{v_1, v_2, \ldots, v_N\}
\]

Each video v_n has an observed context window of length T_c seconds. The task is to predict a future action set:

\[
A_n = \{a_1^n, a_2^n, \ldots, a_{|A_n|}^n\}
\]

where each action a_k^n is defined by two variables: a class c ∈ {1, ..., C} and a timestamp t ∈ [0, T_a]. The source states that actions are defined by “a class c ∈ {1, ..., C}” and “a timestamp t ∈ [0, T_a], indicating the exact moment the action will happen in the anticipation window” [PAGE 3]. The units are therefore explicit: T_c, T_a, and t are measured in seconds; C is a dimensionless count of action classes.

The formal anticipation operator is a conditional predictive mapping:

\[
f_\theta : v_n \mapsto \hat{A}_n
\]

subject to the constraint that f_θ may access only the context window. The probabilistic form is:

\[
p_\theta(A_n \mid v_n)
\]

where p_θ is a probability distribution over future action sets. Each predicted action may be represented as:

\[
\hat{a}_k = (\hat{c}_k, \hat{t}_k, \hat{y}_{d,k})
\]

where \hat{c}_k is a class distribution, \hat{t}_k is a timestamp in seconds, and \hat{y}_{d,k} is an actionness probability in [0, 1].

The evaluation operator is mAP@δ. For a temporal tolerance δ, a prediction is counted as correct if its timestamp lies within δ/2 seconds before or after the ground truth. The source says: “a prediction is considered correct if it falls within a window of δ/2 seconds before or after the ground truth” [PAGE 3]. For class c, let AP_c(δ) be the average precision at tolerance δ. Then:

\[
\text{mAP}@\delta = \frac{1}{C} \sum_{c=1}^{C} \text{AP}_c(\delta)
\]

The units of δ are seconds for finite tolerances. The case δ = ∞ is dimensionless in effect because localization is ignored. The source states: “When δ = ∞, the metric completely disregards localization and focuses only on the correct identification and counting of action classes” [PAGE 3].

The model’s feature extractor maps an input video tensor:

\[
v_n \in \mathbb{R}^{F_c \times H \times W \times 3}
\]

to a sequence of frame representations:

\[
X \in \mathbb{R}^{F_c \times d}
\]

where F_c is the number of context frames, H × W is spatial resolution, and d is the embedding dimension [PAGE 4]. In the reported implementation, T_c = 5 seconds at 6.25 fps gives F_c = 32 frames, spatial resolution is 448 × 796, and d = 512 [PAGE 5].

The transformer encoder uses local self-attention. The source states that the encoder uses “a multi-head local self-attention module with h heads, restricting tokens to attend within a neighborhood of k tokens” [PAGE 5]. This introduces a locality operator:

\[
\mathcal{N}_k(i) = \{j : |j - i| \le k\}
\]

where i and j are frame indices, and k is an integer number of neighboring tokens. The ablation shows that smaller neighborhoods such as k = 7 or k = 15 are preferable to global attention [PAGE 8].

The decoder uses q learnable queries:

\[
Q \in \mathbb{R}^{q \times d}
\]

Each query represents a possible anticipated action. The prediction head outputs:

\[
\hat{y} = (\hat{y}_d, \hat{y}_c, \hat{y}_t)
\]

with:

\[
\hat{y}_d \in [0,1]^{q \times 1}
\]

\[
\hat{y}_c \in \Delta^{C}
\]

\[
\hat{y}_t \in [0, T_a]^{q \times 1}
\]

where Δ^C denotes a probability simplex over C classes. The source describes the three components as “a binary classifier to detect action presence, a classification module to identify action class, and a timestamp predictor to estimate the precise temporal position of the anticipated action” [PAGE 4].

The anticipation loss is:

\[
L_A = \lambda_D L_D + \lambda_C L_C + \lambda_T L_T
\]

where L_D is action-detection loss, L_C is action-classification loss, and L_T is temporal-position loss [PAGE 5]. The temporal loss is mean squared error between predicted and actual temporal positions, with positions scaled by T_a and learned in exponential space [PAGE 5]. If natural logarithms are used, the loss is expressed in nats; if base-2 logarithms are used, the units are bits. The loss value itself is dimensionless, while its inputs include timestamps in seconds.

The auxiliary segmentation loss is:

\[
L_S = \text{CrossEntropy}(S, Y_{\text{dilated}})
\]

where S is a per-frame segmentation output of size F_c × (C + 1), including background, and label dilation is applied within a radius r = 4 frames [PAGE 5]. The total loss is:

\[
L = L_A + \lambda_S L_S
\]

as stated in the source: “The final loss function is then computed as L = L_A + λ_S L_S” [PAGE 5].

During inference, the final class-specific confidence is:

\[
\hat{p}_{k,c} = \hat{y}_{d,k} \cdot \hat{y}_{c,k,c}
\]

This follows the source: “we multiply the per-class probabilities (ŷ_c) with the actionness score (ŷ_d) to represent the confidence of specific action classes occurring at the predicted temporal position (ŷ_t)” [PAGE 5].

Breakdown regimes follow directly. First, when δ is small, temporal localization error dominates. At δ = 1, a prediction must be within 0.5 seconds of ground truth, so even modest timestamp error produces zero credit. Second, when T_a increases, the temporal search space expands. The source observes that “anticipating actions further in the future is more challenging, as shown by the performance drop when increasing the anticipation window from T_a = 5 to T_a = 10 seconds” [PAGE 6]. Third, when class frequency is low, AP estimates become unstable. The authors removed goals and free-kicks because “only six and two observations, respectively, in the test split” made the metric unstable [PAGE 3]. Fourth, when spatial resolution is reduced, small ball-related cues are lost. The ablation reports that halving resolution “results in a performance drop of 5 points on average” [PAGE 7]. Fifth, when the auxiliary segmentation task is removed, semantic supervision collapses, with average mAP dropping from 20.30 to 7.13 [PAGE 7]. Sixth, when query count mismatches the empirical maximum number of actions, performance degrades; q = 8 is optimal for T_a = 5 because it “coincides with the maximum number of actions observed within a T_a = 5 second anticipation window” [PAGE 8].
</SOURCE_OPERATORS_AND_EQUATIONS>

<RETROCAUSAL_GENEALOGY>
The scientific lineage of the paper can be reconstructed as a three-stage transition: recognition, spotting, and anticipation. Recognition asks what action is present. Spotting asks when an action occurred inside an already observed stream. Anticipation asks what action will occur and when it will occur inside a future unobserved stream. The source situates itself after action recognition and action spotting: “Much progress has been made in action recognition, which classifies actions, and action spotting, which localizes them in time. Yet, action anticipation, which predicts actions before they occur, remains largely unexplored” [PAGE 1]. This establishes the paper as a missing-layer contribution.

The first lineage is dataset evolution. SoccerNet originated as a scalable benchmark for action spotting in soccer videos [PAGE 10]. The Ball Action Spotting dataset provided untrimmed professional football videos with precise localization of on-ball actions [PAGE 3]. The new SN-BAA dataset adapts this resource for anticipation. This is not a clean transplant. Spotting annotations are retrospective; anticipation requires future labels aligned to context clips. The authors therefore preserve original splits but clip test and challenge videos into 30-second windows with a stride of T_a seconds, enabling context windows T_c from 0 to 30 seconds [PAGE 3]. This adaptation reveals a genealogical trap: the original dataset was built for detecting known events, not for forecasting unobserved events.

The second lineage is architectural. The paper draws from FUTR, a transformer-based action anticipation model, and from T-DEED, a state-of-the-art action spotting method [PAGE 2, PAGE 4]. FUTR contributes the query-based anticipation paradigm. T-DEED contributes efficient feature extraction and dense temporal supervision. The source says FAANTRA “builds on top of FUTR” and also “leverages an efficient feature extractor from T-DEED” [PAGE 2]. This hybrid genealogy is important. If the model borrows too heavily from spotting, it risks assuming access to future frames. If it borrows too heavily from generic anticipation, it risks ignoring football-specific cues such as ball position, player posture, pitch geometry, and broadcast camera framing.

The third lineage is metric genealogy. mAP was originally adapted by Giancola et al. for action spotting [PAGE 3]. The paper extends it to anticipation by applying it to unobserved future windows. The source states: “we adapt the mean Average Precision (mAP) metric, proposed by Giancola et al. for Action Spotting, to evaluate performance within the non-observed anticipation window” [PAGE 3]. This creates a subtle trap: mAP is a ranking-based metric, but anticipation adds a temporal regression burden. A model may rank actions well but still fail strict temporal precision. The paper’s multi-tolerance metric family is designed to expose this failure.

A multi-week research trap follows from the genealogy. One trap is to treat anticipation as spotting with a shifted window. The paper explicitly rejects this: spotting methods “require access to the complete video stream containing the actions to spot them, including past, present, and future contextual frames” [PAGE 2]. A second trap is to assume that larger backbones always help. The results show that a larger feature extractor “does not always improve performance when training only on SN-BAA, but it does when incorporating SN-AS” [PAGE 6]. A third trap is to assume longer context is always better. The ablation shows performance “plateaus or slightly declines beyond T_c = 5 seconds” [PAGE 7]. A fourth trap is to ignore long-tail classes. The per-class results show that frequent actions are learned well, while spontaneous or rare actions remain difficult: “highly spontaneous actions with limited examples, such as shots, ball player blocks, or successful tackles, are not well captured by the model” [PAGE 7].

The deepest genealogical lesson is that anticipation inherits the uncertainty of adversarial sport. The source emphasizes that football has “the fast-paced and adversarial nature of football, where players attempt to hide their intentions from opponents” [PAGE 3]. This makes the task fundamentally different from scripted daily-activity anticipation datasets such as cooking or assembly tasks. In cooking, the next action often follows procedural syntax. In football, deception, tactical disguise, and spontaneous reaction are constitutive. Therefore the lineage is not merely video understanding; it is forecasting under adversarial concealment.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
The recursive theory-of-mind layer is unavoidable in football anticipation. A player does not merely act; the player models the opponent’s expectation. In adversarial sport, the observable cue may be intentionally misleading. The paper recognizes this at dataset level: football actions are “less predictable and more challenging than in others” because of “the fast-paced and adversarial nature of football, where players attempt to hide their intentions from opponents” [PAGE 3]. This is a theory-of-mind problem: the model must infer not only the current biomechanical state but also the strategic intention behind the state.

Crisis habit regression is the first failure mode. When future evidence is unavailable, a model tends to fall back on high-frequency priors. In SN-BAA, passes and drives dominate the action distribution. The supplementary statistics show pass and drive means far above all other classes [PAGE 13]. Under uncertainty, a model can regress to these frequent classes because they minimize expected loss. This is rational under class imbalance but epistemically weak. It produces predictions that are statistically plausible but tactically shallow. The paper’s per-class results show exactly this pattern: “the most frequent actions, such as passes and drives, are better captured by the model” [PAGE 7]. The crisis-habit regression therefore appears as high performance on common actions and poor performance on rare or spontaneous actions.

Counter-trap is the second failure mode. A model may overfit observable pre-action cues and mistake correlation for intention. For example, a player’s body orientation may precede a pass, but elite players can disguise orientation. If the model learns superficial cues, it becomes vulnerable to deception. The paper’s low scores for spontaneous actions illustrate this: “highly spontaneous actions with limited examples, such as shots, ball player blocks, or successful tackles, are not well captured by the model” [PAGE 7]. These actions often lack long preparatory windows, so the model cannot rely on stable cue sequences. The counter-trap is that the model’s confidence should decrease precisely when the action is strategically concealed, but many models instead output confident but incorrect predictions because the visual cue appears familiar.

The clock is the third failure mode. Anticipation has multiple temporal scales: context length T_c, anticipation horizon T_a, frame rate, and tolerance δ. The paper uses T_c = 5 seconds, T_a = 5 or 10 seconds, and temporal tolerances from 1 to ∞ seconds [PAGE 5–6]. The ablation shows that increasing T_a harms precise metrics but not mAP@∞: “performance related to the proportion of action classes predicted remains unaffected by longer anticipation windows, the challenge lies in localizing those actions” [PAGE 7]. This means the model can know that something will happen without knowing when. The clock failure is therefore not merely slower prediction; it is temporal misalignment. A correct class at the wrong time receives no credit under small δ.

A recursive theory-of-mind audit yields three design constraints. First, the model should represent uncertainty explicitly. Actionness is a necessary component; the ablation shows that removing actionness and replacing it with end-of-sequence or background classes reduces performance [PAGE 8]. Second, the model should not assume smooth temporal continuity. Football actions can be sudden. The dataset’s high spontaneity rating supports this [PAGE 3]. Third, the model should be evaluated on both occurrence and timing. mAP@∞ alone would reward class prediction while hiding the clock failure. mAP@δ exposes it.

The deepest recursive insight is that the model is not predicting a physical event in isolation; it is predicting an event generated by strategic agents who anticipate being predicted. Therefore the optimal policy is not maximum confidence. It is calibrated anticipation: high confidence when observable constraints strongly determine the next action, low confidence when adversarial disguise is likely. The paper’s gap to the spotting upper bound is the empirical signature of this recursive difficulty.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Cross-layer veto adjudication separates the paper’s video-learning layer from physical, biomechanical, and environmental constraints. The source defines the task at the video layer: predict future actions using only observed context frames [PAGE 1]. However, a valid anticipation cannot violate physical or biomechanical possibility. Therefore a veto hierarchy is required.

Layer 1: Observational admissibility. The model may use only the context window. The source states that anticipation “requires predicting future events without access to future frames” [PAGE 1]. Any method that secretly uses future frames, leaked annotations, or post-hoc labels is invalid. This is a formal admissibility veto:

\[
\text{Prediction valid} \implies \text{input} \subseteq v_n
\]

where v_n is the observed context video. If future frames are used, the prediction is not an anticipation under the paper’s definition.

Layer 2: Temporal-window admissibility. Each action timestamp must lie inside the anticipation window:

\[
\hat{t}_k \in [0, T_a]
\]

The source defines each action timestamp as t ∈ [0, T_a] [PAGE 3]. If a model predicts an event outside this interval, the prediction is invalid for the benchmark. If the timestamp is inside the interval but outside the tolerance δ/2 of the ground truth, it receives no positive AP credit under mAP@δ. The strictest veto occurs at δ = 1, where only a 0.5-second neighborhood is accepted.

Layer 3: Class-set admissibility. The benchmark uses C = 10 classes after removing goals and free-kicks. The source states: “we exclude goals and free-kicks from the SN-BAA dataset, reducing the set to C = 10 classes” [PAGE 3]. Therefore any prediction outside the 10-class set is invalid. This is not a physical veto but an evaluation-layer veto. It prevents unstable rare-class metrics from dominating.

Layer 4: Biomechanical admissibility. Let x_b(t) be ball position in meters and x_p(t) be a player position in meters. For a predicted on-ball action at time t_a, there must be a physically possible trajectory connecting the last observed state to the predicted state. If the model predicts an action after a time interval τ = t_a - t_c, and the required displacement is Δx, then a necessary condition is:

\[
\frac{\|\Delta x\|}{\tau} \le v_{\max}
\]

where v_max is a maximum plausible speed in meters per second. For human motion, v_max is bounded by sprint biomechanics; for the ball, v_max is bounded by kick dynamics and drag. The source does not provide explicit speed limits, so v_max must be supplied by an external physics layer. The veto proof is conditional: if a predicted action requires a speed or acceleration outside the plausible biomechanical envelope, the prediction should be rejected or assigned low confidence.

Layer 5: Contact and action-type admissibility. Certain classes require specific physical preconditions. A shot requires ball possession or a plausible striking opportunity. A successful tackle requires proximity between player and ball carrier. A throw-in requires the ball to have left the field and a restart context. A header requires aerial ball-player interaction. The source’s per-class examples show frames before, during, and after actions [PAGE 14–15], implying that actions have observable preconditions. If the context lacks any plausible precondition, a high-confidence prediction should be vetoed. This is not a proof of impossibility from the paper alone, because the paper does not annotate full player kinematics. It is a necessary-layer veto: without physical preconditions, the prediction is not grounded.

Layer 6: Environmental admissibility. Weather, pitch condition, lighting, and camera occlusion can alter anticipation. The paper does not provide weather annotations. It does note that broadcast videos cover large areas and key actions occupy only a small portion of the frame, making resolution important [PAGE 7]. Therefore weather-related vetoes cannot be quantitatively adjudicated from this source. The correct decision is abstention: any claim that rain, wind, or pitch wetness systematically changes FAANTRA performance is unsupported by the provided text. If such a claim is made without additional environmental metadata, it must be vetoed as out-of-source.

The final adjudication is therefore conservative. A prediction is admissible only if it satisfies observational causality, temporal-window membership, class-set membership, biomechanical plausibility, action-type preconditions, and environmental consistency. The paper proves the difficulty of the video-learning layer but does not prove environmental generalization. Thus physical and weather vetoes remain external constraints, not empirical findings inside the source.
</CROSS_LAYER_VETO_ADJUDICATION>

<RLVR_COUNTERFACTUAL_VETOES>
The following three counterfactual veto scenarios are verifiable from the paper’s task definition, dataset statistics, metric definitions, or reported ablations. Each scenario defines a reward-hacking or invalid-prediction condition and gives a testable prediction.

Scenario 1: Strict temporal-precision veto.
Condition: A model predicts the correct action class but its timestamp error exceeds δ/2 for a chosen tolerance δ. Under mAP@δ, the prediction receives no temporal precision credit. The source defines correctness as falling “within a window of δ/2 seconds before or after the ground truth” [PAGE 3]. For δ = 1, the allowed error is 0.5 seconds.
Verifiable test: Compare predictions at δ = 1 versus δ = ∞. If a model has high mAP@∞ but low mAP@1, it is predicting occurrence without precise timing.
Prediction: FAANTRA-like models will show a large gap between mAP@∞ and mAP@1. This is already visible: FAANTRA’s best T_a = 5 average is 24.08, while T-DEED upper bound is 63.85 under the same joint-data 400MF setting [PAGE 6]. The gap should widen at strict δ because the task lacks future-frame verification.
RLVR veto: Any reward that credits class correctness alone should be rejected. The reward must include temporal tolerance.

Scenario 2: Horizon-query mismatch veto.
Condition: A model trained for T_a = 5 is evaluated at T_a = 10 without increasing query capacity or long-horizon supervision. The paper doubles decoder queries for T_a = 10: “For T_a = 10 experiments, the number of queries is doubled to q = 16” [PAGE 5]. If q remains too small, the model may miss multiple actions or assign queries to implausible duplicates.
Verifiable test: Compare T_a = 5 and T_a = 10 results with fixed query count versus doubled query count. The source shows performance drop when increasing T_a [PAGE 6], and mAP@∞ remains stable while precise metrics degrade [PAGE 7].
Prediction: If query count is not adapted, mAP@δ at T_a = 10 will collapse more severely than mAP@∞. If query count is adapted but temporal supervision is weak, mAP@∞ may remain stable while mAP@1 and mAP@2 remain poor.
RLVR veto: Any claim of long-horizon anticipation capability without query-capacity scaling, temporal supervision, and strict-tolerance evaluation should be rejected.

Scenario 3: Rare-spontaneous-class overconfidence veto.
Condition: A model outputs high confidence for a rare spontaneous class such as shot, ball player block, or successful tackle despite limited training support and weak observable cues. The paper removed goals and free-kicks because of extreme rarity and metric instability [PAGE 3]. It also reports that “highly spontaneous actions with limited examples, such as shots, ball player blocks, or successful tackles, are not well captured by the model” [PAGE 7]. The per-class results show low average mAP for successful tackle (8.02) and ball player block (9.16) [PAGE 6].
Verifiable test: Measure precision and recall for rare classes under high-confidence thresholds. If high-confidence predictions exceed the empirical test support or have low precision, the model is overconfident.
Prediction: Inverse-frequency class weighting may improve recall but will not fully solve rare-class precision. The model should abstain or lower actionness for spontaneous rare events unless strong pre-action cues are present.
RLVR veto: Any reward that encourages high-confidence rare-class predictions without calibrated abstention should be rejected, because the dataset’s long-tail distribution and low per-class performance make such predictions likely false positives.

These three vetoes define a verifiable reward policy. A prediction is rewarded only if it passes temporal admissibility, horizon-capacity admissibility, and rare-class confidence calibration. The paper supports each veto through its formal task definition [PAGE 1, PAGE 3], dataset statistics [PAGE 3–4, PAGE 13], model design [PAGE 5], metric ablations [PAGE 7–8], and per-class results [PAGE 6].
</RLVR_COUNTERFACTUAL_VETOES>
