Three hard veto layers are defined below; each is a necessary precondition, and when any veto fires, \mathcal{M} returns the empty set \emptyset (no valid molar behavior), leaving only molecular physiology.

1. Physical-layer veto. Let the neural and metabolic substrate be \mathcal{V}_{phys} \in \{0,1\}. \mathcal{V}_{phys} = 0 iff there is lesion, metabolic failure, or neurotransmitter depletion sufficient to prevent goal-directed commerce. Proof: if \mathcal{V}_{phys} = 0, then no route r \in \mathcal{R} can be executed, so \mathcal{R} = \emptyset and \mathcal{M} is undefined. Singularity: severe hypoxia or cortical disruption collapses the molar description entirely.

2. Biomechanical-layer veto. Let the effector capability map be \mathcal{E}: \mathcal{R} \to \{0,1\}, where \mathcal{E}(r) = 1 iff the organism can physically traverse route r. Veto: if \forall r \in \mathcal{R}, \mathcal{E}(r) = 0, then \mathcal{R} = \emptyset. Units: route length [m] compared against maximum effective range [m]. Example: a goal-object placed beyond the rat’s jumping or climbing capacity is selected in \mathcal{G} but unreachable in \mathcal{R}; commerce cannot occur [PAGE 1].

3. Weather/environmental-layer veto. Let environmental volatility be \sigma_{env} (variance in goal-object location or route blockage per unit time [s^{-1}]). The special conditions \Sigma required to trigger behavior-adjustment \mathcal{A} [PAGE 1] presuppose a sufficiently stable environment for remoulding to take effect. Veto: if \sigma_{env} > \sigma_{crit}, then \Sigma cannot be sustained, \mathcal{A} does not converge, and the immanent determinant \mathcal{P} cannot be reliably remoulded into a new overt behavior. Proof: convergence condition \|\mathcal{P}_{n+1} - \mathcal{P}_{n}\| < \epsilon requires \mathcal{A} to act on a quasi-static \mathcal{P}; high volatility makes \mathcal{P}_{n} non-stationary.

Composite veto operator:
\[
\mathcal{V} = \mathcal{V}_{phys} \land \big(\exists r \in \mathcal{R} : \mathcal{E}(r)=1\big) \land (\sigma_{env} \le \sigma_{crit}).
\]
If \mathcal{V} = 0, then \mathcal{M} : \mathcal{G} \times \mathcal{R} \times \mathcal{C} \to \emptyset. Breakdown regime: all three layers veto simultaneously (e.g., injured animal in a storm with blocked goals), at which point Tolman’s molar phenomenon is inapplicable and only the underlying molecular physiology remains [PAGE 1]. These are hard constraints, not probabilistic softeners; no amount of inferred purpose can override a physical veto.
