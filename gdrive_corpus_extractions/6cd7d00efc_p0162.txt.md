**Theorem A (Null Sets and Sections):**
For a measurable set $E \subseteq X \times Y$:
$$ \lambda(E) = 0 \iff \mu\left(\{x \in X : \nu(E_x) > 0\}\right) = 0 $$
where $E_x = \{y \in Y : (x,y) \in E\}$ is the $X$-section. Equivalently for $Y$-sections.
*Units:* Measure units (e.g., Lebesgue measure in $\text{m}^d$). Probability units if $\mu, \nu$ are probability measures.
*Assumptions:* $E$ is $\lambda$-measurable; sections $E_x$ are $\nu$-measurable for all $x$ (guaranteed if $\lambda$ is completed or spaces are standard Borel).
*Breakdown Regime:* The equivalence fails if sections are not measurable. In pathological cases (e.g., non-complete product measures on non-separable spaces), a set can have measure zero while some sections are non-measurable, violating the "almost every" quantification.

**Theorem B (Tonelli’s Equality):**
For a non-negative measurable function $h: X \times Y \to [0, \infty]$:
$$ \int_{X \times Y} h \, d\lambda = \int_X \left( \int_Y h(x,y) \, d\nu(y) \right) d\mu(x) = \int_Y \left( \int_X h(x,y) \, d\mu(x) \right) d\nu(y) $$
*Derivation Steps:*
1. Base case: $h = \chi_E$. Then LHS $= \lambda(E)$. RHS inner integral $= \nu(E_x)$. Outer integral $= \int_X \nu(E_x) d\mu(x)$. Equality follows from product measure definition (cited as 35.B).
2. Simple functions: $h = \sum_{i=1}^n c_i \chi_{E_i}$. Linearity extends the base case.
3. General $h \ge 0$: Construct sequence $h_n \uparrow h$ of simple functions (cited 20.B). Define $f_n(x) = \int_Y h_n(x,y) d\nu(y)$. By monotonicity, $f_n \uparrow \int_Y h(x,y) d\nu(y)$. Apply Monotone Convergence Theorem (cited 27.B) to interchange limit and outer integral:
   $$ \lim_{n\to\infty} \int_X f_n \, d\mu = \int_X \lim_{n\to\infty} f_n \, d\mu $$
   This yields the desired equality.

*SINGULARITY/BREAKDOWN REGIMES:*
- **Non-Measurable Sections:** If the product measure is not completed, there exist measurable sets $E$ where some $E_x$ are non-measurable, making $\int_Y \chi_E(x,y) d\nu(y)$ undefined. Completion of $\lambda$ resolves this by declaring such sections null.
- **Signed/Complex Functions:** Theorem B requires $h \ge 0$. For signed functions, absolute integrability ($\int |h| d\lambda < \infty$) is required (Fubini's Theorem); otherwise, iterated integrals may differ or diverge.
- **Infinite Measures:** If $\mu(X) = \nu(Y) = \infty$, constant function $h=1$ yields $\infty = \infty$, which is valid but provides no information about convergence of approximations. The MCT holds for extended reals, so the singularity is merely trivial divergence.
- **Uncountable Products:** The construction of product measure $\lambda$ via Carathéodory extension assumes finite products. For uncountable products, Kolmogorov extension applies, but section-wise integration loses meaning without cylinder set structures.
