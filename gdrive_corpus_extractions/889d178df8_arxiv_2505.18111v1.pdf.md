The first multi-hop derivation is therefore: [PAGE 4] “memory bank feature” plus [PAGE 5] “minimum and maximum coordinates” yields a box sequence. The second hop is: box sequence yields ratio changes via Equation (1) [PAGE 6], a threshold via Equation (2) [PAGE 6], and interpolated boxes via Equation (3) [PAGE 6]. The third hop is: boxes are compared with ground truth through Equation (5) [PAGE 7], thresholded by Equation (6) [PAGE 8], and averaged into Equation (7) [PAGE 8].

The gray-zone audit must separate three claims. First, the claim that SAM2 is a strong VOT engine is supported by the paper’s qualitative architecture description and by the challenge result. Second, the claim that backward tracking improves difficult sequences is conditional: [PAGE 5] says reverse tracking “allows the model to leverage different memory states and object features,” and it “may lead to better tracking results in certain challenging frames.” This is not a universal guarantee. If the final forward bounding box is wrong, reverse initialization can amplify error because the reverse pass begins from a contaminated object state. Third, tracklet interpolation assumes limited deformation: [PAGE 6] states, “Most objects in the dataset exhibit limited deformation and maintain relatively stable bounding box ratios and sizes.” If that assumption fails, linear interpolation of box coordinates may smooth away true motion, deformation, or partial occlusion, reducing IoU rather than increasing it.

A further ambiguity is the modality claim. The challenge mentions RGB, infrared thermal, depth, and event data [PAGE 7], but the reported SAM2 modality comparison contains only depth, infrared, and RGB [PAGE 9]. The empirical ordering is explicit: depth is severely weak, infrared is intermediate, and RGB is strongest. The source says, “Among all the modalities, RGB achieve the highest performance” [PAGE 8], and Table 2 reports SAM2-l scores of 19.8 for depth, 56.5 for infrared, and 88.6 for RGB [PAGE 9]. Thus, the first-place result is not evidence that SAM2 equally solves all modalities. It is evidence that RGB segmentation is the dominant information source under this evaluation.

The metric audit is also delicate. Equation (5) defines IoU [PAGE 7]. Equation (6) defines a success rate as the fraction of frames where IoU exceeds a threshold [PAGE 8]. Equation (7) averages success rates over thresholds [PAGE 8]. If the target is absent or occluded and the ground-truth box is empty, the source explicitly sets overlap to zero: [PAGE 8] “If the target is out of view or occluded (Gt is empty), Rt is set to 0.” This means that occlusion frames cannot receive positive reward unless the target becomes visible again and is tracked. The reward structure is therefore not “survive occlusion”; it is “be visible and accurate when the target is visible.”

<SOURCE_OPERATORS_AND_EQUATIONS>
The following operators are extracted directly from the source and formalized with units, assumptions, and breakdown regimes.

1. Mask-to-box operator.
The source states that the method uses SAM2’s segmentation mask and then “we extract the bounding box from the segmentation mask by calculating the minimum and maximum coordinates of the mask in each frame” [PAGE 5]. Let frame index be \(t \in \{1,\dots,N\}\). Let the RGB image be \(I_t \in \mathbb{R}^{H \times W \times 3}\), with height \(H\) and width \(W\) in pixels. Let SAM2 output a binary mask \(M_t \subset \{0,\dots,H-1\}\times\{0,\dots,W-1\}\). The extracted axis-aligned bounding box is
\[
b_t = (x_t, y_t, w_t, h_t)
=
\left(
\min_{(x,y)\in M_t} x,\,
\min_{(x,y)\in M_t} y,\,
\max_{(x,y)\in M_t} x - \min_{(x,y)\in M_t} x,\,
\max_{(x,y)\in M_t} y - \min_{(x,y)\in M_t} y
\right).
\]
Units: \(x_t,y_t,w_t,h_t\) are pixels; the box vector is in \(\mathbb{R}^4\) with pixel coordinates. Assumptions: \(M_t\) is nonempty and represents the target. Breakdown regime: if \(M_t = \varnothing\), the minimum and maximum are undefined. If \(M_t\) contains a single pixel, then \(w_t=0\) or \(h_t=0\) may occur, causing later ratio calculations to fail.

2. Candidate-selection operator.
The source says SAM2 treats each frame as a new detection instance and selects “the prediction with the maximum Intersection over Union (IoU) out of Nmax predictions for the subsequent frame t+1 with the current frame t” [PAGE 5-6]. If candidate masks for frame \(t+1\) are \(\{M_{t+1}^{(k)}\}_{k=1}^{N_{\max}}\), the selected candidate is
\[
k^\star = \arg\max_{k} \operatorname{IoU}\left(M_t, M_{t+1}^{(k)}\right),
\]
where IoU is dimensionless and lies in \([0,1]\) under nonempty masks. Assumption: at least one candidate overlaps the true target sufficiently. Breakdown: if all candidate IoUs are zero, selection is arbitrary and tracking may switch objects.

3. Backward tracking operator.
The source defines a forward pass and then a reverse pass initialized from the last forward box [PAGE 5]. Let \(F_\theta\) denote SAM2 forward tracking and \(R_\theta\) denote SAM2 reverse tracking. The forward output is
\[
B^F = F_\theta(I_1,\dots,I_N; b_1),
\]
where \(b_1\) is the first-frame ground-truth or initialization box. The backward pass is initialized using the last forward box:
\[
B^B = R_\theta(I_N, I_{N-1}, \dots, I_1; b_N^F).
\]
Units: boxes are pixel vectors; frame order is dimensionless. Assumption: \(b_N^F\) is a reliable final target state. Breakdown: if \(b_N^F\) is false, the reverse pass can reinforce a wrong object identity. The source provides no explicit arbitration rule for choosing forward versus backward boxes per frame, so the operator is conditional.

4. Bounding-box ratio change operator.
The source defines the first-pass box sequence as \(B=\{b_1,\dots,b_n\}\), with \(b_i=(x_i,y_i,w_i,h_i)\) [PAGE 6]. The aspect ratio is
\[
r_i = \frac{w_i}{h_i}.
\]
The percentage change between consecutive frames is given by Equation (1):
\[
\Delta r_i
=
\left|
\frac{(w_i/h_i)-(w_{i-1}/h_{i-1})}{w_{i-1}/h_{i-1}}
\right|
\times 100\%.
\]
Units: \(\Delta r_i\) is a percentage, hence dimensionless. Assumption: \(h_i>0\) and \(h_{i-1}>0\). Breakdown: if any height is zero, the ratio is undefined. If the denominator \(w_{i-1}/h_{i-1}=0\), the expression diverges.

5. Threshold operator.
The source computes the mean ratio change as Equation (2):
\[
\tau = \frac{1}{n-1}\sum_{i=2}^{n} \Delta r_i.
\]
Here \(\tau\) replaces the source’s threshold symbol \(t\) to avoid confusion with frame index. Units: percentage. Assumption: \(n\ge 2\). Breakdown: if \(n=1\), the mean is undefined. If all \(\Delta r_i=0\), then \(\tau=0\), and the condition \(\Delta r_i>\alpha\tau\) becomes degenerate: any positive jitter may be flagged.

6. Interpolation operator.
Frames with \(\Delta r_i > \alpha \tau\) are labeled “frames to interpolate” [PAGE 6]. Let unaffected anchor frames be \(a\) and \(b\), with \(a<b\). The source interpolates boxes using Equation (3):
\[
b'_i = b_a + \frac{i-a}{b-a}(b_b-b_a), \qquad a<i<b.
\]
Units: \(b'_i\) is a box vector in pixel coordinates; indices are dimensionless. Assumption: anchors exist and are reliable. Breakdown: if \(b=a\), the denominator vanishes. If no unaffected frames exist, interpolation cannot be applied. If the true object changes shape nonlinearly, linear coordinate interpolation may produce a false box.

7. Convergence operator.
The source states that interpolation can be repeated until Equation (4):
\[
\max_{i=2,\dots,n} \Delta r_i < \beta \tau,
\]
where \(\beta\) is “typically set slightly higher than \(\alpha\)” [PAGE 6]. Units: both sides are percentages. Assumption: \(\tau>0\). Breakdown: if \(\tau=0\), the convergence condition may be impossible or trivial depending on \(\beta\).

8. IoU overlap operator.
Equation (5) defines overlap between predicted box \(P_t\) and ground-truth box \(G_t\):
\[
R_t = \frac{|P_t \cap G_t|}{|P_t \cup G_t|}.
\]
Units: dimensionless probability-like score in \([0,1]\). Assumption: both boxes are valid axis-aligned rectangles. Breakdown: if \(P_t\cup G_t\) has zero area, the fraction is undefined; the source resolves the occlusion case by setting \(R_t=0\) when \(G_t\) is empty [PAGE 8].

9. Success-rate operator.
Equation (6) defines
\[
SR(\theta_i) = \frac{1}{N}\sum_{t=1}^{N} u_t(\theta_i),
\]
where \(u_t(\theta_i)=1\) if \(R_t>\theta_i\), otherwise \(0\) [PAGE 8]. Units: estimated probability in \([0,1]\). Assumption: the frame set is fixed. Breakdown: if \(N=0\), the estimate is undefined. The strict inequality \(R_t>\theta_i\) means that exact equality at \(\theta_i=1\) does not count.

10. AUC operator.
Equation (7) defines
\[
AUC = \frac{1}{n}\sum_{i=1}^{n} SR(\theta_i).
\]
The challenge threshold set is \(\theta_i \in \{0,0.05,0.10,\dots,1.0\}\) [PAGE 8]. If all thresholds from 0 to 1 in steps of 0.05 are included, \(n=21\). Units: dimensionless; reported as percentage when multiplied by 100. Breakdown: if threshold spacing is nonuniform and not weighted, the reported AUC becomes sensitive to the chosen threshold grid.

11. Empirical modality operators.
Table 2 reports SAM2-l performance by modality: depth 19.8, infrared 56.5, RGB 88.6 [PAGE 9]. These are AUC percentages, hence empirical success probabilities under the challenge threshold grid. The source also reports the final system at 89.4 AUC [PAGE 9]. Information-theoretic note: if SAM2’s memory state is treated as a random variable \(M_t\), its uncertainty is
\[
H(M_t) = -\sum_m p(m)\log_2 p(m),
\]
with units bits. The source does not provide \(p(m)\), so this is an audit quantity, not a measured result.

<RETROCAUSAL_GENEALOGY>
The lineage runs from classical correlation-filter tracking to learned Siamese trackers, then to segmentation-based tracking, and finally to SAM2 adaptation. The source cites DCF methods such as KCF and ECO as strong frame-correlation trackers that are “vulnerable to occlusion, scale variation, and deformation” [PAGE 2]. It then cites SiamFC and SiamRPN as Siamese-network improvements that still “struggle when significant appearance changes occur or when objects leave and re-enter the scene” [PAGE 2]. Hybrid methods such as SiamMask and SAMURAI combine tracking with segmentation, but the source says they still faced issues with complex backgrounds and long-term tracking [PAGE 2-3]. Transformer trackers such as TransT and STARK improve long-range dependencies but may be computationally expensive [PAGE 3]. SAM2 enters as a memory-equipped segmentation model with video propagation ability [PAGE 4]. The present work inherits this lineage: it does not invent a new backbone; it adapts SAM2 by adding bounding-box extraction, backward tracking, and interpolation.

A retro-causal trap is to assume that because SAM2 is strong in segmentation, it is automatically optimal for every tracking modality. The source contradicts this simplification: depth-only SAM2-l achieves only 19.8 AUC, infrared achieves 56.5, and RGB achieves 88.6 [PAGE 9]. Another trap is to treat the challenge leaderboard as proof that every component is necessary. The source reports the final score but does not isolate the contribution of each trick. A third trap is to ignore the dataset’s peculiarities. The source says the training set, despite being described as 400 videos, actually provides only 10 images per case with annotations for three modalities [PAGE 7]. This means any learned adaptation cannot be assumed to have benefited from full video supervision. A fourth trap is the long-horizon assumption. Test sequences vary from 100 to 600 frames [PAGE 7], and the evaluation includes occlusion, distractors, and motion speed [PAGE 8]. Therefore, memory drift over hundreds of frames is a structural hazard, not a minor edge case.

The interpolation lineage also carries a multi-week trap. If a target slowly changes scale due to perspective, distance, or partial occlusion, the box ratio may drift gradually. Interpolation may smooth this drift into a plausible trajectory, but the smoothed box may diverge from the true object boundary. The source’s convergence condition only checks ratio smoothness [PAGE 6], not semantic correctness. Thus, the historical lineage supports robustness, but the evaluation remains vulnerable to long-term identity switches, occlusion recovery, and modality imbalance.
</RETROCAUSAL_GENEALOGY>

<RECURSIVE_THEORY_OF_MIND>
A recursive model of the challenge solver must consider three competing tendencies: crisis habit regression, counter-trap insertion, and clock pressure.

Crisis habit regression occurs when the solver defaults to the most familiar evidence source. Here, the source reports that RGB is the strongest modality: “Among all the modalities, RGB achieve the highest performance” [PAGE 8], and Table 2 gives RGB 88.6 versus infrared 56.5 and depth 19.8 [PAGE 9]. A rational solver under pressure may therefore reduce the problem to RGB-only SAM2. This habit is reinforced by the simplicity of the pipeline: first-frame box, memory bank, mask-to-box conversion. The regression becomes dangerous if the evaluation includes low-light or thermally visible objects where RGB evidence degrades. The solver’s recursive belief is: “RGB worked best in the visible test, so RGB will dominate hidden test.” The counter-belief is: “RGB may fail under poor lighting, while thermal or depth could provide orthogonal evidence” [PAGE 3].

The counter-trap is the set of mechanisms that prevent simple RGB regression. The paper introduces backward tracking to “retrieve missed detections, recover from errors” [PAGE 5], and interpolation to reduce jitter under stable aspect ratios [PAGE 6]. In recursive terms, the solver anticipates that forward-only memory will drift, so it adds a reverse pass. The solver also anticipates that frame-by-frame box extraction will be noisy, so it adds a smoothness prior. These are not arbitrary; they target known VOT failure modes: occlusion, motion blur, and appearance change [PAGE 1].

Clock pressure is the temporal dimension. The source says test sequences range from 100 to 600 frames [PAGE 7], and evaluation is framewise through success rates and AUC [PAGE 8]. The solver’s internal clock is not wall-clock time but frame budget: the longer the sequence, the more opportunities memory can drift, the more interpolation can accumulate error, and the more a single late-stage identity switch can depress many frames. A recursive counter-trap must therefore balance two failure modes: under-smoothing leaves jitter; over-smoothing hides real deformation. The paper’s convergence criterion, \(\max \Delta r_i < \beta\tau\) [PAGE 6], is an attempt to control this temporal accumulation, but it is a ratio-smoothness condition, not a semantic identity guarantee.

The recursive theory-of-mind conclusion is: the winning behavior is not merely “use SAM2.” It is “use RGB-dominant SAM2, but add backward recovery and ratio-based smoothing because the evaluator rewards visible-frame IoU over many thresholds and penalizes empty-target frames with zero overlap” [PAGE 8].
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
Physical, biomechanical, and weather layers can veto a tracking claim even if the model-level architecture is plausible.

1. Photometric veto.
RGB tracking depends on sufficient visible-light photons. The source notes that RGB-only systems “can struggle under poor lighting conditions, heavy occlusion, or when the object’s appearance changes significantly” [PAGE 3]. If illumination is below the sensor’s usable signal floor, the RGB feature extractor receives insufficient evidence, and SAM2’s mask posterior becomes unreliable. This does not contradict the paper’s RGB result because the reported dataset likely contained sufficient visible evidence for many frames; however, it proves that RGB-only SAM2 cannot be treated as physically universal. The modality table confirms an information hierarchy: RGB 88.6, infrared 56.5, depth 19.8 [PAGE 9]. The low depth score is a direct empirical veto against depth-only SAM2 under this evaluation.

2. Depth-sensor veto.
Depth tracking fails when depth maps contain missing pixels, edge noise, or poor surface reflectance. The source reports depth SAM2-l AUC as 19.8 [PAGE 9]. This is a formal empirical veto: a depth-only adaptation is not a competitive solution in this benchmark. The breakdown regime is not merely algorithmic; it is sensing-physical. If depth returns are sparse, the mask boundary cannot be localized consistently, and bounding-box extraction becomes unstable.

3. Thermal-contrast veto.
Infrared can help when visible contrast is low, but thermal contrast can collapse when the target and background have similar temperature. The source lists infrared thermal as one of the dataset modalities [PAGE 7] and reports an intermediate AUC of 56.5 [PAGE 9]. This shows that infrared is not automatically superior. The veto condition is thermal ambiguity: if target and background radiance are nearly equal, the segmentation boundary becomes physically underdetermined.

4. Biomechanical motion-blur veto.
The source identifies “motion blur, caused by rapid movement of the object or camera” as a core VOT challenge [PAGE 1]. If frame exposure time is \(\Delta t\) seconds and target image velocity is \(v\) pixels per second, blur displacement is
\[
L_{\text{blur}} = v\Delta t
\]
with units pixels. If \(L_{\text{blur}}\) exceeds the target’s minimum distinguishable boundary scale, mask precision degrades. The source claims SAM2 can handle fast-moving scenes [PAGE 2], but that claim is not a physical guarantee. Under extreme motion blur, the mask boundary becomes ambiguous, and the box extraction operator inherits the ambiguity.

5. Biomechanical deformation veto.
The interpolation method assumes limited deformation: [PAGE 6] “Most objects in the dataset exhibit limited deformation and maintain relatively stable bounding box ratios and sizes.” If a target is articulated, non-rigid, or partially occluded in a way that changes its true silhouette, the ratio-change threshold may flag the frame as unstable, but linear interpolation may replace a true shape change with a false smooth trajectory. The veto proof is by assumption violation: if true deformation exceeds the limited-deformation assumption, the interpolation operator no longer estimates the physical object; it estimates a stylized box trajectory.

6. Weather veto.
The source notes that multi-modal systems are relevant for autonomous driving and adverse conditions, where certain sensors may become unreliable [PAGE 3]. Rain, fog, snow, dust, or smoke can attenuate visible and infrared signals, while depth sensors can be degraded by scattering or absorbent surfaces. If visibility or signal-to-noise falls below the sensor’s operational regime, no amount of memory-based post-processing can recover absent physical evidence. This is a cross-layer veto: the physical sensing layer can invalidate the perception claim before the tracking algorithm is evaluated.
</CROSS_LAYER_VETO_ADJUDICATION>
