<THINK_TRACE>
The derivation must be treated as a multi-stage estimator, not as a single classifier. The first hop is image formation and edge extraction. The source states that the method begins with “a binary edge image” and that the detector window is “shifted over the edge regions” [PAGE 1]. This is important because the paper explicitly removes appearance variability before classification. The source says the diffusion stage “removes the appearance variations of an object while preserving the shape information” [PAGE 1]. Thus, the logical chain is: frame → Canny edges → geometry mask → sliding windows → edge-count gating → diffusion-based shape image → polar mapping → Fourier magnitude → low-frequency descriptors → SVM → non-maximal suppression → detection evaluation.

The second hop is geometric gating. The paper uses a “geometry-based playground mask” obtained by a homography from image coordinates to ground-plane coordinates, written as \(M = \{(x,y) \mid H(x,y) \in C\}\) [PAGE 3]. This is not merely cosmetic: it reduces the search space and prevents audience/advertisement edges from entering the detector. The source notes that edges outside the playground are removed “to restrict further processing and accelerate detection speed” [PAGE 2]. The window is then scanned only where edge density is sufficient. The source gives the gate: “If the total number of edge points, inside a window, is higher than a pre-defined threshold (i.e. T = 10 in our experiments), we employ feature extraction and classification” [PAGE 4]. This is a hard singularity boundary: below ten edge points, the diffusion stage is not invoked, so the entire shape-recovery mechanism is bypassed.

The third hop is the core PDE. The paper replaces a standard heat equation with a spatially varying diffusion coefficient built from the binary edge map. The source states: “Given a set of binary edges in a sliding window, we introduce and solve a particular diffusion equation to generate a shape information image” [PAGE 2]. Formally, the equation is
\[
\frac{\partial I(x,t)}{\partial t} = E(x)\nabla^2 I(x,t),
\]
with initial condition \(I(x,0)=1-E(x)\) and boundary condition \(I(x,t)=0\) on the window boundary [PAGE 5]. The coefficient \(E(x)\) is binary: “the edge positions are zero and the rest of the positions are one” [PAGE 5]. This creates an unusual but interpretable dynamic. At edge pixels, \(E(x)=0\), so the PDE gives \(\partial I/\partial t=0\); those pixels retain their initial value \(1-E(x)=1\). They behave like fixed hot sources. At non-edge pixels, \(E(x)=1\), so ordinary Laplacian diffusion occurs. The boundary is held at zero, so the window boundary acts as a heat sink. The resulting scalar field is the “shape-information image” [PAGE 5]. This is the main theoretical contribution, and the source explicitly calls it “the key stage and the main theoretical contribution” [PAGE 2].

The fourth hop is invariance construction. The shape image is polar mapped to a fixed \(32 \times 32\) representation [PAGE 5]. In the polar image, rotations become translations. Then the 2-D Fourier transform is applied, and the magnitude is used because “The resultant Fourier magnitude image, \(|F(k,l)|\), is translation invariant which means that it is player rotation invariant” [PAGE 7]. Scale normalization is obtained by dividing all Fourier magnitudes by the DC value \(|F(0,0)|\) [PAGE 7]. Low-frequency descriptors are then selected inside a radius of 5 around the DC component, yielding 100 features in the reported implementation [PAGE 7]. This gives the final descriptor vector before SVM classification.

The fifth hop is decision-making. The SVM is a Gaussian radial-basis-function classifier with scaling factor 2.1 and Lagrange upper bound 5 [PAGE 7]. The system then applies pairwise max suppression if bounding-box overlap exceeds 0.2, using
\[
\Gamma_{ij} = \frac{\text{area}(BB_i \cap BB_j)}{\text{area}(BB_i \cup BB_j)}
\]
[PAGE 8]. For evaluation, a detection is correct if \(\Gamma_{ij} > 0.25\) [PAGE 12]. Precision, recall, and F-score are then computed as probability-like quantities: \(P = P_c/P_t\), \(R = R_c/R_t\), and \(F = 2PR/(P+R)\) [PAGE 12].

The gray-zone audit must examine where this chain breaks. First, the PDE depends on meaningful edge topology. The source admits that field-line edges can cause failures: “In this case, we may observe failures in player shape estimation” [PAGE 5]. Second, low resolution creates missing edges, but the diffusion is designed to tolerate this; the source says “the proposed diffusion can fill inside the object’s shape while preserving the shape information” [PAGE 3]. Third, the window boundary condition is dangerous: if a player silhouette touches the detector window boundary, the zero boundary condition can drain diffusion energy and truncate the shape. Fourth, the scale model assumes players are approximately 1.8 m tall and uses predefined pixel window sizes: “if the height is less than 40 pixels, the window dimensions are 40 × 25” and so on up to 64 × 40 [PAGE 4]. Players outside these ranges, or unusual poses, violate the aspect-ratio assumption of 1.6 [PAGE 4]. Fifth, the Fourier normalization becomes unstable if the DC value is near zero, because scale normalization divides by \(|F(0,0)|\) [PAGE 7]. Sixth, the SVM and non-maximal suppression are only as good as the descriptor distribution; false positives that do not overlap sufficiently may survive suppression because suppression only applies when \(\Gamma_{ij} > 0.2\) [PAGE 8].

In sum, the paper’s logic is coherent, but its reliability is conditional. The strongest regime is a fixed camera, calibrated ground plane, sufficient edge response, player-like silhouette, and moderate scale variation. The weakest regimes are severe low contrast, field-line clutter inside the window, boundary contact, extreme pose variation, and scale outside the predefined window bins. Those are the zones where the estimator should be vetoed, recalibrated, or supplemented by additional geometric or temporal constraints.

<SOURCE_OPERATORS_AND_EQUATIONS>
The source supplies a chain of formal operators. I list them with units, assumptions, and breakdown regimes.

1. Canny edge extraction and automatic hysteresis thresholds.

The source uses Canny edge detection with Gaussian filtering, Sobel gradients, non-maxima suppression, and hysteresis thresholding [PAGE 3]. The automatic thresholds are
\[
TH = c \cdot \operatorname{median}(G),
\qquad
TL = \frac{TH}{2},
\]
with \(c=9\) in the reported experiments [PAGE 3]. Here \(G\) is the gradient magnitude image. If \(x,y\) are measured in pixels, then \(G\) has units of intensity per pixel, while \(TH\) and \(TL\) have the same units as \(G\). The ratio between thresholds is fixed at 2: “The ratio between high, TH, and low, TL, thresholds is 2” [PAGE 3].

Breakdown regime: if the image is locally flat, \(\operatorname{median}(G)=0\), then \(TH=TL=0\), and the threshold rule becomes singular. In practice, this means no reliable edge structure is available. If \(c\) is too large, valid weak edges disappear; if \(c\) is too small, noise edges appear. The source states that the optimum value was determined experimentally as \(c=9\) [PAGE 3].

2. Geometry-based playground mask.

Let \(H\) be the homography from image coordinates to ground-plane coordinates and let \(C\) be the valid ground-plane coordinate range. The mask is
\[
M = \{(x,y) \mid H(x,y) \in C\}.
\]
[PAGE 3]
The operator maps image pixels into a binary validity mask. Units: \(H\) maps pixel coordinates, with units px, into normalized or world-plane coordinates. If \(C\) is expressed in meters, then \(H\) implicitly contains a scale conversion from pixels to meters. The source uses this mask to remove edges from audience and advertisements [PAGE 2, PAGE 3].

Breakdown regime: if camera calibration or homography is inaccurate, the mask either excludes true player regions or admits background clutter. If \(H\) is rank-deficient or estimated from poor correspondences, the mask becomes invalid.

3. Edge-density gate before feature extraction.

The source scans only windows with enough edge points:
\[
N_e(\omega) > T,
\qquad T = 10,
\]
where \(N_e(\omega)\) is the number of binary edge pixels inside detector window \(\omega\) [PAGE 4]. Units: \(N_e\) is a count, dimensionless; \(T\) is a count threshold.

Breakdown regime: if \(N_e \leq 10\), the method does not perform diffusion-based shape estimation. In low-contrast weather, fog, rain, or low illumination, \(N_e\) may fall below this threshold even when a player is present. This is a hard veto boundary.

4. Window aspect ratio and world-height projection.

The detector window aspect ratio is
\[
a = \frac{h}{w} = 1.6,
\]
where \(h\) and \(w\) are window height and width in pixels [PAGE 4]. The source assumes players are 1.8 m tall and projects the bottom-center point to the ground plane, then projects a point 1.8 m above it back into the image to estimate pixel height [PAGE 4]. The predefined window sizes are:

- if \(h < 40\) px, use \(40 \times 25\) px;
- if \(40 \leq h < 48\) px, use \(48 \times 30\) px;
- if \(48 \leq h < 56\) px, use \(56 \times 35\) px;
- if \(56 \leq h \leq 64\) px, use \(64 \times 40\) px [PAGE 4].

Units: \(h,w\) are in pixels; the world height is \(H_w = 1.8\ \mathrm{m}\). The camera is mounted on poles 20 m high, and frames are \(959 \times 539\) pixels [PAGE 3, PAGE 8].

Breakdown regime: if the true projected height exceeds 64 px, no predefined window is specified. If the pose is not standing, walking, running, or bending, the 1.6 aspect ratio may fail. The source constrains the pose to “standing, walking, running and bending” [PAGE 2].

5. Standard heat equation.

The classical heat equation is given as
\[
\frac{\partial T(x,t)}{\partial t}
=
\alpha \nabla^2 T(x,t)
=
\alpha
\left(
\frac{\partial^2 T(x,t)}{\partial x^2}
+
\frac{\partial^2 T(x,t)}{\partial y^2}
\right),
\]
with initial condition
\[
T(x,0)=F(x),
\]
and Dirichlet boundary condition
\[
T(x,t)=\Phi(x).
\]
[PAGE 4, PAGE 5]
Units: \(T\) is temperature or normalized scalar field; if physical, units may be kelvin, K. \(\alpha\) is thermal diffusivity with units \(\mathrm{length}^2/\mathrm{time}\), for example \(\mathrm{m^2/s}\) or \(\mathrm{px^2/s}\) if pixel coordinates are used. \(\nabla^2\) has units \(\mathrm{length}^{-2}\).

6. Proposed edge-modulated diffusion equation.

The paper’s core operator is
\[
\frac{\partial I(x,t)}{\partial t}
=
E(x)\nabla^2 I(x,t),
\]
with
\[
I(x,0)=1-E(x),
\qquad
I(x,t)=0 \text{ on the window boundary}.
\]
[PAGE 5]
Here \(E(x)\in\{0,1\}\). The source states that “the edge positions are zero and the rest of the positions are one” [PAGE 5]. If \(x,y\) are in pixels, then \(\nabla^2 I\) has units \(\mathrm{px^{-2}}\) when \(I\) is dimensionless. \(I\) is a normalized shape intensity, dimensionless. \(E\) is dimensionless. The time variable is a normalized diffusion time; if one restores a physical diffusivity \(\alpha\), the equation becomes \(\partial I/\partial t = \alpha E(x)\nabla^2 I\), where \(\alpha\) has units \(\mathrm{length}^2/\mathrm{time}\).

Interpretation: because \(E=0\) at edge pixels, the PDE gives no time change at those pixels. With initial value \(1\), edge pixels remain fixed sources. Non-edge pixels evolve by diffusion. The zero boundary condition makes the window boundary a sink.

Breakdown regimes:

- If \(E(x)=1\) everywhere, then \(I(x,0)=0\) everywhere and the boundary is zero, so the solution remains zero. No shape is generated.
- If \(E(x)=0\) everywhere, then \(I(x,0)=1\) everywhere and \(\partial I/\partial t=0\); the solution is uniform and carries little discriminative shape information.
- If an object silhouette crosses the window boundary, the zero boundary condition truncates the shape.
- If field-line edges appear inside the window, false edge sources create false hot regions. The source explicitly warns that field-line background clutter can cause failures in shape estimation [PAGE 5].
- For an explicit finite-difference discretization with grid spacing \(h_{\text{grid}}\), a standard 2-D stability condition is
\[
\Delta t \leq \frac{h_{\text{grid}}^2}{4\max_x E(x)}.
\]
Since \(\max E=1\) in the proposed binary mask, this becomes \(\Delta t \leq h_{\text{grid}}^2/4\) for an explicit scheme. The source instead uses a multigrid solver because it is computationally more efficient [PAGE 5].

7. Polar mapping.

A point \((x,y)\) is converted to polar coordinates around the window center \((x_c,y_c)\):
\[
r = \sqrt{(x-x_c)^2 + (y-y_c)^2},
\qquad
\theta = \tan^{-1}\left(\frac{y-y_c}{x-x_c}\right).
\]
[PAGE 5]
Units: \(r\) is in pixels; \(\theta\) is in radians. The polar image is mapped to fixed dimensions \(32 \times 32\) [PAGE 5]. Invalid pixels that fall inside the circle but outside the rectangular image are set to zero [PAGE 6, PAGE 7].

Breakdown regime: the polar transform is singular at \(r=0\), where \(\theta\) is undefined. If the object is not centered, or if the silhouette touches the circular boundary, the polar representation may distort shape evidence. The method also assumes in-plane rotation; out-of-plane pose changes are not removed by this transform.

8. Fourier magnitude and scale normalization.

The 2-D Fourier transform of the polar image \(P(r,\theta)\), of size \(M \times N\), is
\[
F(k,l)
=
\frac{1}{MN}
\sum_{r=0}^{M-1}
\sum_{\theta=0}^{N-1}
P(r,\theta)
e^{-j2\pi(kr/M + l\theta/N)}.
\]
[PAGE 7]
Units: if \(P\) is normalized to dimensionless intensity, \(F(k,l)\) is dimensionless. \(k,l\) are discrete frequency indices. The magnitude \(|F(k,l)|\) is used. The source states that this magnitude is translation invariant, and therefore player rotation invariant [PAGE 7]. Scale normalization divides by the DC value:
\[
\widetilde{F}(k,l) = \frac{|F(k,l)|}{|F(0,0)|}.
\]
[PAGE 7]
A low-frequency disk of radius 5 around the DC value is selected, producing 100 features in the reported implementation [PAGE 7].

Breakdown regime: if \(|F(0,0)|\approx 0\), scale normalization becomes singular. If the shape information is mostly high-frequency, discarding high frequencies may remove discriminative detail. If the radius-5 disk includes too few or too many descriptors, the representation becomes biased; the source’s count of 100 features is an implementation-dependent discrete-frequency count.

9. SVM classification.

The classifier is an SVM with a Gaussian radial-basis-function kernel. The source gives the Gaussian kernel scaling factor as 2.1 and the upper bound on Lagrange parameters as 5 [PAGE 7]. A generic RBF decision function is
\[
f(z)
=
\operatorname{sign}
\left(
\sum_i \alpha_i y_i
\exp\left(-\gamma \|\phi(z)-\phi(x_i)\|^2\right)
+ b
\right),
\]
where \(\phi(z)\in\mathbb{R}^{100}\) is the shape descriptor vector, \(y_i\in\{-1,+1\}\), \(\alpha_i\) are Lagrange multipliers, and \(\gamma\) is an inverse-squared feature-distance scale. Units: \(\phi\) is dimensionless if Fourier magnitudes are normalized; \(\gamma\) has units of inverse squared feature units. If raw unnormalized features are used, \(\gamma\) absorbs feature scaling.

Breakdown regime: if the descriptor distribution shifts strongly because of camera view, resolution, or background clutter, the fixed kernel scale may become poorly matched. The source tunes parameters by cross-validation on the training set [PAGE 7].

10. Non-maximal suppression and evaluation overlap.

Bounding-box overlap is
\[
\Gamma_{ij}
=
\frac{\text{area}(BB_i \cap BB_j)}
{\text{area}(BB_i \cup BB_j)}.
\]
[PAGE 8]
The system applies suppression if \(\Gamma_{ij} > 0.2\) [PAGE 8]. For detection correctness, the paper uses \(\Gamma_{ij} > 0.25\) [PAGE 12].

Breakdown regime: if \(BB_i \cup BB_j\) has zero area, \(\Gamma_{ij}\) is undefined. Degenerate or extremely small boxes should be vetoed before applying IoU.

11. Precision, recall, and F-score.

The paper defines
\[
P = \frac{P_c}{P_t},
\qquad
R = \frac{R_c}{R_t},
\qquad
F = \frac{2PR}{P+R}.
\]
[PAGE 12]
Units: all are dimensionless probabilities or rates in \([0,1]\), or percentages when multiplied by 100. Average precision is computed over fixed recall levels \([0,0.1,0.2,\ldots,1]\) [PAGE 12].

12. Computational cost.

The source reports average detection time per frame in seconds [PAGE 17]. For the proposed method, the times are 44.79 s, 42.89 s, and 33.55 s for Cameras 1, 2, and 3 respectively [PAGE 17]. For background subtraction, the times are 16.78 s, 18.50 s, and 17.09 s [PAGE 17]. Units are seconds per frame. This matters because the clock budget determines whether the method can be used online or only offline.

<RETROCAUSAL_GENEALOGY>
The lineage of this paper is a convergence of heat-diffusion PDE theory, classical edge detection, invariant shape description, and statistical learning. The deepest ancestor is the heat equation itself. The paper cites Holman’s heat transfer text and describes the classical equation as “The change of temperature over time at each point of a two-dimensional material” [PAGE 4]. That gives the physical backbone: a scalar field evolves under a Laplacian operator with a diffusivity coefficient, initial condition, and boundary condition. The novelty is not the heat equation in general, but the replacement of a uniform diffusivity with a binary edge map as a spatially varying coefficient. The source states: “However this is the first time a particular heat diffusion equation is used for estimating shape over the binary edge maps” [PAGE 3].

A second lineage is edge detection. The method depends on Canny edges [PAGE 3]. Canny’s procedure is described in the source as Gaussian noise reduction, finite-difference gradient computation, non-maxima suppression, and hysteresis thresholding [PAGE 3]. This lineage matters because the diffusion coefficient is only as reliable as the binary edge map. If Canny misses weak boundaries, the PDE lacks fixed edge sources. If Canny produces clutter, the PDE creates false shape energy.

A third lineage is invariant shape representation. The source acknowledges that applying Fourier transforms after polar mapping is not novel: “First it has been introduced as a part of the Fourier-Mellin transform algorithm” and later used in region-based shape description techniques [PAGE 7]. The paper’s specific contribution is not the polar-Fourier stage alone, but the fact that it applies these transforms to “the solution of the proposed heat diffusion equation” rather than directly to binary object masks [PAGE 7]. This is an important retro-causal distinction: later invariance machinery makes the earlier diffusion stage look like a canonical preprocessing step, even though the diffusion stage is the actual theoretical novelty.

A fourth lineage is object detection. The paper compares against background subtraction, HOG+SVM, DPM+LSVM, selective search, CNN feature extraction, PSHOG, and shape-representation ablations such as MORPH, Gauss, and SIGD [PAGE 8, PAGE 9, PAGE 11]. The historical framing is that earlier field-sports detection often relied on dominant color or background subtraction. The source says background-subtraction and segmentation methods “fail when a single segmented region contains multiple players or when a single player is segmented into multiple regions” [PAGE 2]. The paper’s response is to avoid relying primarily on appearance segmentation and instead rely on edge-based shape evidence.

The multi-week traps are mostly parameter and validation traps. First, the Canny scale factor \(c=9\) is experimentally selected [PAGE 3]. If a new camera or lighting condition changes the gradient distribution, that constant may no longer be optimal. Second, the edge-count gate \(T=10\) is experimentally selected [PAGE 4]. In adverse weather, many true players may fail this gate. Third, the window aspect ratio 1.6 and predefined window sizes are estimated from annotated player regions [PAGE 4]. If the annotation distribution does not include unusual poses, the detector will underrepresent them. Fourth, non-player samples are camera-specific because “each camera view has a different background image” [PAGE 8]. This creates a trap: a model tuned on one camera may not transfer without recalibration. Fifth, hard negative mining is applied for two rounds [PAGE 10]. This can improve precision, but it can also amplify camera-specific false-positive patterns if overused.

A further retro-causal trap concerns the CNN comparison. The source fine-tunes AlexNet as a feature extractor and resizes images to \(227 \times 227\) [PAGE 9]. The paper notes that low-resolution players are resized, and this “affected the performance of the CNN” [PAGE 12]. Later results therefore retroactively explain why the proposed method can outperform CNN on Camera 2: the diffusion representation is less dependent on AlexNet’s input-size normalization. This is a classic genealogical trap: an apparently generic classifier comparison is actually mediated by preprocessing assumptions.

Finally, the paper’s evaluation lineage is tied to PASCAL-style average precision and single-threshold precision-recall analysis [PAGE 12, PAGE 13]. The use of \(\Gamma_{ij} > 0.25\) for correctness [PAGE 12] means that small localization errors can change conclusions. Because players are small in the field, the paper observes that tightening overlap to 0.5 reduces accuracy: “the players’ scales appear to be small in the datasets and this makes the detection bounding boxes rather imprecise” [PAGE 15]. That sentence is a retro-causal warning: a method that looks strong under loose overlap may be weaker under tight spatial precision.

<RECURSIVE_THEORY_OF_MIND>
A recursive theory of mind for this system must model not only the pixels, but also the operators, coaches, analysts, and engineers who interpret detections. In a crisis regime, such as sudden weather change, low light, rain, or a camera exposure shift, human operators often regress to familiar habits. The most tempting habit is background subtraction, because it is simple and historically common. The source lists background subtraction as “a common method for player detection with a fixed camera infrastructure” [PAGE 2]. However, the source also warns that such methods fail under “variability of lighting and weather conditions as well as low resolution” [PAGE 12]. Therefore, the counter-trap is to preserve the edge-diffusion pipeline rather than revert to background subtraction when conditions deteriorate. The diffusion stage is specifically designed to handle appearance variation: it “removes the appearance variations (i.e. color and texture) of an object” [PAGE 3]. That makes it psychologically and technically more robust than a background model that may absorb players into the background when they stand still, a problem noted by the source for goalkeepers and stationary players [PAGE 2].

However, the counter-trap itself can become a new habit. If operators over-trust diffusion, they may ignore its documented failure mode: field-line clutter. The source shows that “In this case, we may observe failures in player shape estimation” when field lines are present [PAGE 5]. In a recursive sense, the system must know that its strongest counter-trap has a known adversarial boundary. The correct behavior is not “always diffusion,” but “diffusion plus geometric clutter veto.”

The clock is the second recursive constraint. If the system is used for live tactical analysis, the processing time must satisfy
\[
T_{\text{proc}} \leq T_{\text{deadline}},
\]
where \(T_{\text{proc}}\) is seconds per frame and \(T_{\text{deadline}}\) is the allowed latency. The source reports that the proposed method requires 44.79 s, 42.89 s, and 33.55 s per frame for Cameras 1, 2, and 3, respectively [PAGE 17]. Background subtraction is faster, requiring 16.78 s, 18.50 s, and 17.09 s per frame [PAGE 17]. If the operational deadline is, for example, one frame per second, the proposed method is not viable without massive parallelization or algorithmic reduction. If the use case is offline post-match analysis, the clock constraint is weaker, and the higher accuracy of the diffusion method may dominate.

The recursive habit loop can be written as a decision rule:
\[
\text{If crisis and } N_e \leq T, \text{ do not force diffusion; collect more frames or lower threshold carefully.}
\]
\[
\text{If crisis and } N_e > T \text{ but field-line clutter is present, apply geometric line veto.}
\]
\[
\text{If real-time deadline is active, use a faster coarse detector and reserve diffusion for offline verification.}
\]

Another layer of theory of mind concerns trust. Coaches and analysts may overreact to a small number of false positives. Because non-maximal suppression only merges detections with overlap greater than 0.2 [PAGE 8], isolated false positives can survive. If the user sees a phantom player, trust drops. If the user misses a heavily occluded player, trust also drops. The source shows that heavy occlusion remains difficult: for overlap greater than 0.5, the proposed method detects 284 of 762 heavily occluded players, while HOG+SVM detects 323 [PAGE 16]. Thus, the system should communicate uncertainty in occlusion-heavy cases rather than presenting detections as equally reliable.

The clock also interacts with hard negative mining. The source retrains with two rounds of hard negative mining [PAGE 10]. This improves average precision in several cases, but it adds training complexity and may overfit to recurring false-positive patterns. In a live system, if the false-positive distribution shifts rapidly, a stale hard-negative-trained SVM may become miscalibrated. The recursive countermeasure is to monitor precision on recent frames and trigger recalibration only when a drift statistic exceeds a validated bound.

In short, the system’s mind must contain three competing agents: the habit agent that wants familiar background subtraction, the counter-trap agent that trusts diffusion shape recovery, and the clock agent that enforces latency. The correct adjudication is conditional: use diffusion when edge evidence and geometry are valid; use faster background or coarse detection when the clock dominates; and never allow crisis-driven habit regression to override the documented failure modes of either pipeline.
</RECURSIVE_THEORY_OF_MIND>

<CROSS_LAYER_VETO_ADJUDICATION>
The cross-layer veto proof must separate physical scale, biomechanical plausibility, edge evidence, weather-induced signal loss, and geometric clutter. Each layer can independently veto a detection candidate.

1. Physical scale veto.

The detector window is tied to an assumed player height of 1.8 m [PAGE 4]. Let \(h_{\text{px}}\) be the projected pixel height of a standing player. The source’s predefined window regime covers approximately 40 to 64 px in height [PAGE 4]. If \(h_{\text{px}}\) falls outside this range, the window representation is either undersized or unsupported. Formally, define a scale-validity indicator:
\[
V_{\text{scale}} =
\begin{cases}
1, & 40 \leq h_{\text{px}} \leq 64,\\
0, & \text{otherwise}.
\end{cases}
\]
If \(V_{\text{scale}}=0\), the candidate should be vetoed or sent to a recalibration path. The source’s rule that heights below 40 px use a \(40 \times 25\) window [PAGE 4] is a conservative fallback, but it also means the window may include too much background for very small players. For heights above 64 px, the source provides no predefined window, which is a direct breakdown regime.

2. Biomechanical pose veto.

The method constrains pose to “standing, walking, running and bending” [PAGE 2]. The window aspect ratio is fixed at
\[
a = \frac{h}{w} = 1.6.
\]
[PAGE 4]
If a candidate region has an observed aspect ratio far from this calibrated range, the shape prior is violated. A formal veto can be written as
\[
V_{\text{pose}} =
\begin{cases}
1, & a_{\text{obs}} \in [a_{\min}, a_{\max}],\\
0, & \text{otherwise},
\end{cases}
\]
where \([a_{\min},a_{\max}]\) must be estimated from annotated player regions for the specific sport and camera. The paper gives the central value 1.6 but not a full interval [PAGE 4]. Therefore, the exact interval must come from validation data. The veto proof is biomechanical: a crawling, lying, or heavily foreshortened player is not well represented by a 1.6 aspect-ratio upright window.

3. Edge-evidence veto.

The diffusion equation requires binary edges. The source gates windows by edge count:
\[
N_e(\omega) > T,
\qquad T=10.
\]
[PAGE 4]
If \(N_e \leq 10\), the diffusion operator is not applied. This is a direct informational veto: without enough edge constraints, the PDE has insufficient boundary evidence to generate a reliable shape field. In low contrast, the Canny threshold may remove too many edges. The threshold rule is
\[
TH = 9 \cdot \operatorname{median}(G),
\qquad
TL = TH/2.
\]
[PAGE 3]
If weather or illumination reduces the gradient distribution, \(\operatorname{median}(G)\) may become small, and the absolute edge response may vanish. The veto condition is therefore:
\[
V_{\text{edge}} =
\begin{cases}
1, & N_e > 10,\\
0, & N_e \leq 10.
\end{cases}
\]

4. Boundary-truncation veto.

The PDE uses a zero Dirichlet boundary condition on the detector window:
\[
I(x,t)=0 \quad \text{on } \partial \Omega.
\]
[PAGE 5]
If the true player silhouette intersects the window boundary, the boundary condition drains diffusion evidence. Let \(B\) be the set of boundary pixels occupied by the true silhouette. If \(B\neq\varnothing\), the shape estimate is vulnerable to truncation. A practical veto is:
\[
V_{\text{boundary}} =
\begin{cases}
1, & B = \varnothing,\\
0, & B \neq \varnothing.
\end{cases}
\]
This is a mathematical and physical veto: the estimator assumes the object is contained inside the window, with boundary outside the object.

5. Weather and illumination veto.

The method relies on edge detection, so weather-induced contrast loss can suppress edges. If fog, rain, snow, or glare reduces gradient magnitude, the Canny operator may fail before diffusion begins. Let \(C_{\text{local}}\) be a local contrast measure, such as RMS contrast or gradient interquartile range. If \(C_{\text{local}}\) falls below the contrast level required to maintain \(N_e > 10\), then the candidate should be vetoed or delayed. The source’s empirical claim is that background subtraction fails under “variability of lighting and weather conditions” [PAGE 12], while the proposed method handles low resolution better because diffusion can fill missing edges [PAGE 17]. However, this advantage only holds while enough edge pixels survive Canny. If edge evidence collapses, the weather veto dominates.

6. Field-line clutter veto.

The source explicitly warns that field-line edges can corrupt shape estimation: “In this case, we may observe failures in player shape estimation” [PAGE 5]. Let \(L_e\) be the number of edge pixels inside the window that belong to known field lines, and let \(N_e\) be the total edge count. A clutter fraction is
\[
\eta_{\text{line}} = \frac{L_e}{N_e}.
\]
The exact threshold \(\eta_{\text{crit}}\) must be calibrated. If \(\eta_{\text{line}} > \eta_{\text{crit}}\), the diffusion field is likely contaminated by line-induced hot sources. The veto is:
\[
V_{\text{clutter}} =
\begin{cases}
1, & \eta_{\text{line}} \leq \eta_{\text{crit}},\\
0, & \eta_{\text{line}} > \eta_{\text{crit}}.
\end{cases}
\]
This veto is geometric and uses the same homography or line model that defines the playground mask [PAGE 3].

7. Occlusion veto for high-confidence claims.

The source divides occlusion into no occlusion, partial occlusion, and heavy occlusion. It defines heavy occlusion as over 50% area occluded [PAGE 16]. Let \(v\) be visible fraction:
\[
v = \frac{A_{\text{visible}}}{A_{\text{full}}}.
\]
Heavy occlusion corresponds to \(v < 0.5\) under the source’s definition [PAGE 16]. The source’s results show that heavy occlusion remains difficult: for overlap greater than 0.25, the proposed method detects 532 of 762 heavily occluded players, while HOG+SVM detects 531 [PAGE 16]. Therefore, a high-confidence detection claim should be vetoed or downweighted when \(v < 0.5\), unless additional evidence such as temporal tracking is available.

8. Clock veto.

Let \(T_{\text{proc}}\) be the processing time per frame and \(T_{\text{deadline}}\) the allowed latency. The source reports processing times in seconds [PAGE 17]. If
\[
T_{\text{proc}} > T_{\text{deadline}},
\]
then the diffusion pipeline should be vetoed for live use. The source’s proposed method is slower than background subtraction: 44.79 s versus 16.78 s for Camera 1, 42.89 s versus 18.50 s for Camera 2, and 33.55 s versus 17.09 s for Camera 3 [PAGE 17]. This is a decisive cross-layer veto for real-time deployment unless parallelization or approximation reduces the cost.

The adjudication rule is therefore: a candidate survives only if all active vetoes return 1. If any physical, biomechanical, weather, clutter, boundary, occlusion, or clock veto returns 0, the candidate must be rejected, deferred, or routed to a different estimator.
</CROSS_LAYER_VETO_ADJUDICATION>
